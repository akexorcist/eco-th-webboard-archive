ไมได้มาตอบกระทู้ตัวเองจากเครื่องตัวเองนานเท่าไหร่แล้วนะ ( >_<" น่าจะครึ่งเดือน )

หลังจากโมเดมเสียครั้งก่อน ก็ไม่ได้แวะเข้ามาเต็มๆ แบบตอนนี้เลย ( อ้อ ตอนนี้โมเดมใช้ได้แล้วนะ )

เรปนี้เป็นพูดคุยถาม-ตอบนะ ไมได้มาคุยเต็มๆ กับทุกๆ คนแบบนี้นานแล้ว คิดถึงจัง ^ ^"

ก็... สำหรับคุณ ~RashenZ~ ทีได้ส่งตัวละครมาหลังกำหนดแล้วนี้..

ผมยังให้คำตอบไมได้นะครับว่าจะสามารถใส่ตัวละครลงไปในบทที่ได้วางไว้แล้วนี้ได้หรือเปล่า >_<" ไงผมจะพยายามดูก่อนนะครับ

แล้วก็ กระทู้ตกไปนี้ คาดว่าพักนี้คงจะตกลงไปบ่อยๆ เพราะสถานการณ์ทั้งในบอร์ดทั้งการเมืองก็ไม่ค่อยจะสู้ดี >_<" แต่ก็ขอขอบคุณทุกๆ คนนะครับที่ช่วยรั้งกระทู้ของผมเอาไว้ ^0^"

เอ มีอะไรอีกนะ อ้อๆ บ่นๆ ชีวิตตัวเองดีกว่า อันตัวผมเองก็ทำงานเกี่ยวข้องกับการคีย์ข้อมูลเข้า database นะครับ วันๆ นึงคีย์ชื่อเข้าฐานข้อมูลก็ไม่ต่ำกว่า 1000 ชื่อเลยทีเดียว ข้อมูลก็ได้จากการส่งรายชื่อมาจากลูกค้าเอง ไม่ก็คีย์จากสมุดหน้าเหลือง วันๆ นึงพิมพ์กันจนมือหงึกเลย >_<" แต่ก็เพื่อปากท้องอ่านะครับ ^ ^"/ สู้ๆ

แต่พักนี้ผมลงฟิคได้ช้า ก็มีหลายสาเหตุ บ้างก็มาจากอาการ " ล้า " ขอตัวผมเองด้วยแหละ พิมพ์งานทั้งวัน พอกลับมาบ้านก็อยากจะเล่นเกมส์ฟังเพลง พักมือพักสายตา ไม่ก็เป็นหวัด อาการเปลี่ยนแปลงบ่อย พักนี้ผมทานยาแก้หวัดแทบจะวันเว้นวันเลย T^T" ทุกคนต้องดูแลสุขภาพกันด้วยนะครับ อย่าให้เป็นแบบผมนะ

นอกนั้นก็มีสาเหตุอื่นๆ ที่ควบคุมไมได้ ไฟดับมั่งเอย น้องสาวจะทำรายงานด่วนมั่งเอย ( ไฟลนก้น แล้วมันก็ยิงยาว~ ) ไม่ก็เกิดเหตุอะไรที่ทำให้ไม่สบายใจ ( ล่าสุดก็เรื่องตังค์ๆ กับพ่อนี่แหละ สุดท้ายก็จำนำมือถือตัวเองไปเรียบร้อยแล้ว T^T" )

มาบ่นๆ พอเป็นพิธี แต่ยังไงผมก็ยังรักการแต่งนิยาย ยังรักทุกตัวละคร ผมอยากให้ทุกๆ ตัวละครดำเนินไปตามแรงจิตนาการของผม มันเป็นความฝันที่ขาดหายไปสมัยเด็กๆ ผมอยากจะเป็นอย่างนู้น อย่างนี้ อยากจะเป็นอิสระเล่นไปเหมือนเด็กทั่วๆ ไป แต่ช่วงวัยเด็กของผมเหมือนขาดสิ่งนี้ไป ผมเด็กๆ นั้นไม่ค่อยมีเพื่อน บ้านผมเค้าเป็นสไตล์ต่างคนต่างอยู่ ช่วงตอนเด็กมากๆ ของผมจึงได้อยู่แต่ในบ้าน เล่นคนเดียวอยู่แต่ในห้องนอน ผมเป็นคนอัธยาศรัยไม่ดี ติดไปที่โรงเรียนก็ไม่มีใครกล้าคบด้วย แต่ตอนเด็กผมก็คิดนะ ว่าอยากจะอยู่แบบนี้แหละ ไม่วุ่นไม่วายดี

แต่เหมือนจิตใจเรียกร้องบางอย่าง ผมมีจิตนาการมากมายฝันอยู่แต่ตัวเอง แต่ไม่มีที่แสดงออก พอโตขึ้นมาผมเองก็ได้รู้จักกับพี่นัด ( ผมจำนามปากกาเค้าไมได้แล้วแฮะ ) แต่พี่คนนี้เค้าแต่งฟิคโดยใช้ code name " Hikaru " ของผมไปยืนเป็นเพราะเอก แล้วเค้าก็บอกว่า ฟิคนี้ขอเอาตัวละครของนายมาเป็นพระเอกนะ ผมก็ให้เขา แล้วพี่เขาก็แต่งฟิคมาให้อ่าน สนุกมากๆ เลย เป็นแฟนฟิคเกมส์ Tokimeki 2 ครับ ผมเป็นพระเอก ที่คอยช่วยเหลือนางเอกคนหนึ่งในเกมส์ที่ชื่อ Kaori Yae ซึ่งผมก็เคยบอกว่าผมชอบตัวละครตคนนี้มากที่สุดในเว็ปบอร์ด welcome.to/nagaze ( ไม่รู้เว็ปนี้ปิดไปหรือยังนะ แต่เป็นบอร์ดรวมคนรักเกมส์นี้ และเป็นการหัดเล่นเว็ปบอร์ดครั้งแรกของผมด้วย ) จนผมก็เร่งๆๆ ให้เค้าแต่งตอนต่อไป เค้าก็พยายามเร่งให้นะ แต่เค้าก็เมล์มาขอโทษด้วยว่าออกช้าหน่อยเพราะติดงาน ก็ไม่เป็นไรฮะ แต่เค้าทิ้งท้ายไว้นิดนึงว่า ไม่ลองสนใจแต่งฟิคดูบ้างหรอ ตอนแรกๆ ผมก็คิดว่า ตัวผมไม่น่าจะเขียนอะไรยาวๆ ออกมาได้หรอกมั้ง แต่พี่เค้าก็กลับมาขะยั้นขะยอผมมั่งละ ว่าให้ลองแต่งดู อ๊ะๆ ลองๆ

แรกๆ ผมแต่งก็เป็นประมาณเอาเกมส์นู้นนิด เนื้อเรื่องนี่หน่อย มายำๆ เปิดเป็นนิยายมั่วซั่วๆ หาเริ่มจับจบไม่ถูก สุดท้ายก็ท้อแล้วก็เลิกไปพักใหญ่ๆ จนกระทั่งผมหัดไปเล่น Pirch แล้วก็เจอกับกลุ่มคนรักการเขียนนิยาย เค้าก็แนะนำวิธีการเขียน เอาเรื่องของตัวเองมาแลกันอ่าน ผมเลยเกิดความพยายามขึ้นมาอีกรอบ แล้วก็ลองแต่งเรื่องยาวเรื่องแรกในชีวิต ได้จนจบฮะ ชื่อเรื่องว่า Chosen Destiny เป็นเรื่องราวของแวมไพร์หนุ่มที่เดินในเวลากลางวันได้ กับสาวน้อยที่กุมโคชะตาของโลกเอาไว้ ( เรื่องนี้ได้แรงบันดาลใจมาจากการ์ตูนเรื่อง Black Cat ครับ แล้วในเรื่อง Saga of Acronia ก็เอาชื่อตัวละครจากเรื่องนี้มาใช้ด้วยเป็นจำนวนมากเลย เช่นครอส ปริ๊นซี่ เคร์อาร์ แดเรียล มีซา ประมาณนี้ ) หากใครอยากจะอ่านฆ่าเวลาระหว่าง Saga of Acronia แต่งนั้น เดี๋ยวผมมาลงให้นะครับ ( แต่ถ้าไม่มีเสียงตอบรับก็จะข้ามไปนะ ^ ^" )

ทั้งนี้ทั้งนั้น ผมยังมีนิยายเรื่องอื่นๆ ที่ลงไว้เฉพาะที่อย่าง pocketonline.net อีกหลายเรื่องเลยเหมือนกัน ซึ่งหากใครอยากจะอ่านก็โพสขอไว้ได้นะครับ ^ ^"

เรื่องที่เคยแต่ง นั้น มีดังนี้ครับ

- Chosen Destiny ( แต่งเรื่องนี้เรื่องแรกในชีวิต มี 8 ตอนจบมั้ง ลืมแล้ว >_<" เรื่องราวเกี่ยวกับครอสซึ่งเป็นแวมไพร์เผ่าเดินเวลากลางวันได้ กับอีฟที่เป็นสายเลือดบริสุทธิ์ ผู้ดูแลช่วงกาลเวลา โดยมีความลับอีกอย่างนั้นคือ การได้ดื่มเลือดของเธอนั้น จะทำให้ได้พลังแห่งพระผู้เป็นเจ้ามาครอบครอง )

- CD02 ก็เป็น Chosen Destiny ภาค 2 อ่าครับ แต่แต่งไม่จบ แดเรียลได้ออกภาคนี้อยู่หลายช่วงเลยทีเดียว ( เริ่ม Yuri กะมีซาก็จากเรื่องนี้แหละ >///<" )

- White Chocolate & Black Whip Cream เรื่องนี้เป็น Yuri Fanfic เกมส์ Lineage2 ครับ ( ตอนแต่งเรื่องนี้รู้แล้วว่ารสนิยมของตัวเองเป็น Yuri >///<" ) เป็นเอลฟสาวและดาร์คเอลฟที่กำลังทำเควสอยู่ แต่ทว่ากลับมีเรื่องราวทำให้ทั้สองแตกแยกกัน แต่สุดท้ายพวกเธอจะกลับมาดีกันหรือไม่นั้น... ( ถ้ารีเควสมาก็จะแปะให้น๊า ^ ^ 2 ตอนจบจ้า)

- Eternal River / Secret Report / เรื่องนี้เป็นฟิคที่เกี่ยวข้องกับนิยายของมาสคอตผมเอง ( Hikaru ชื่อเต็มก็ Hika zerora - Hikaru ) โดยเป็นภาคของลูกสาวสุดเฮ้ว Hikari จัง แต่เป็นนิยายแบบว่า... เรท Yuri >///<" ดังนั้นคนอ่านต้อง 18+ นะครับ ( ถ้ารีเควสไว้จะส่งให้ทาง pm ละกาน >///<" ) แบบว่า ลองแต่งแบบเรทๆ ดูบ้าง ไงเป็นนักเขียนที่ดีต้องลองหัดทุกอย่างชะมะล่ะ ^0^/

บ่นๆ มาเยอะแล้ว มีแจ้งกำหนดการอีกนิดหน่อยเกี่ยวกับ Saga of Acronia ละกันครับ

- จะมีโซน Soundtrack ด้วย จากเวลาผมแต่งนิยาย บางทีผมก็ใช้เพลงในการสร้างอารมณ์ร่วมไปในแต่งะฉาก จนอยากจะแบ่งปันเพื่อนๆ บ้างครับ เร็วๆ นี้ ^ ^"

ความล้านี่ก็เป็นอุปสรรคที่สำคัญอย่างนึงในการแต่งฟิคค่ะ
ถ้าเหนื่อย ยังไงก็หาอะไรอย่างอื่นทำ เล่นเกม ฟังเพลง ก็ดีค่ะ

การฝืนแต่งฟิคตอนเหนื่อยนี่มันจะทำให้ออกมาได้ไม่ดีเท่าที่ควรเนอะ ไว้อารมณ์ดี สบายๆ แล้วค่อยๆแต่งไปก็ได้ค่ะ เผื่ออาจจะนึกไอเดียหรือพล็อตใหม่ๆ เพิ่มขึ้นมาด้วยก็ได้

ปรางเองก็เพิ่งหัดแต่งฟิคเมื่อ 2-3 ปีก่อนเอง
ได้แรงบันดาลใจและกำลังใจมาจากคนรู้จักนี่แหละ แต่ช่วงนั้นยังเด็กอยู่ ยังขาดความตั้งใจในการแต่ง เป็นคนเบื่อง่ายด้วยแหละ
ทั้งที่คิดเรื่องไปล่วงหน้าไว้ตั้งเยอะแยะ แต่เอาเข้าจริงก็ดันแต่งไม่จบซักเรื่อง ^^"
แต่ตอนนี้ก็คิดว่าอาจจะอยากรื้อเรื่องเก่ามาปัดฝุ่นซะใหม่ก็ได้

อ่านเรื่องของท่านแล้วมีกำลังใจขึ้นมานิดนึงแล้วล่ะ ขอบคุณที่เล่าสู่กันฟังนะคะ

ยังไงทั้งเรื่องงานและเรื่องฟิคก็สู้ๆ นะคะ เป็นกำลังใจให้ค่ะ
รู้สึกท่านจะชอบแต่งแนวยูริมากๆ เลยเนอะ ^^

แจ้งกำหนดการณ์ครับ ( แต่ไม่ใช่ของ Saga of Acronia นะ )

ช่วง 4 ทุ่ม 15 นาที ผมจะลงนิยายเรื่องอื่นให้ได้ติดตามกัน และคั่นเวลาระหว่างกำลังแต่งสรรค์ Saga of Acronia ครับ

เรื่องทีจะลงนั้น เป็น The Story of Cinderella ครับ ซินเดอร์เรลล่าในแบบฉบับของผม ซึ่งผมได้แต่งเรื่องนี้เพื่อเข้าร่วมกิจกรรมแต่งฟิคชั่นที่บอร์ด Pocket School ด้วยครับ

เรื่องราวของซินเดอร์เรลล่า ในนิทาน เป็นเด็กสาว ที่โดนแม่เลี้ยงใจร้าย และเหล่าลูกสาวของแม่เลี้ยง รุมกันจิกหัวซินเดอร์เรลล่าใช้งานสารพัดเยี่ยงทาส ( ลูกเลี้ยงนะเนี่ย ) แล้วเจ้าชายในวังนั้นได้จัดงานเลี้ยงเพื่อดูตัวเจ้าสาวในอนาคต ซึ่งซินเดอร์เรลล่าอยากไปแต่ก็แน่นอน เหล่าพี่สาวต่างมารดาของเธอขัดขวางทุกวิธีทาง แต่นางฟ้าได้เห็นความดีในตัวซินเดอร์เรลล่า จึงให้เธอได้แต่งชุดสวยๆ และนั่งรถฟังทองไปงาน โดยมีเงื่อนไขว่า เธอนั้นจะอยู่ในงานได้เพียงถึงเวลาเที่ยงคืนเท่านั้น

ซึ่งเวลาความสุขของเธอก็หยุดลงที่เที่ยงคืน ระหว่างเต้นรำกับเจ้าชายอย่างเข้าด้ายเข้าเข็ม เธออกวิ่งมาจากปราสาท แต่ก็สะดุดกับดันได และทิ้งรองเท้าแก้วเอาไว้ดูต่างหน้าให้เจ้าชาย

วันต่อมา เจ้าชายนั้นป่าวประกาศตามหาซินเดอร์เรลล่า โดยเขาให้หญิงสาวทุกคนลองสวมใส่รองเท้าแก้ว และซินเดอร์เรลล่าซึ่งเป็นเจ้าของรองเท้าแก้วตัวจริงก็สวมมันได้อย่างพอดิบพอดี และสุดท้ายเธอและเจ้าชายก็อภิเสกสมรสและอยู่ด้วยกันในวังอย่างมีความสุข..

แต่ในแบบฉบับของผมนั้น รับรองว่ามีรายละเอียดที่แตกต่าง และอารมณ์ที่มากกว่าในนิทานที่ได้ฟังกันมาเนิ่นนานนี้อย่างแน่นอน เป็นซินเดอร์เรลล่าในอีกรูปแบบนึง ซึ่งจะเป็นแบบใดนั้น 4 ทุ่ม 15 นาที คืนนี้ พบกันครับ ^ ^/
