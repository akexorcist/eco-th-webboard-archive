มาตรา ๙ ผู้ใดทำให้เสียหาย ทำลาย แก้ไข เปลี่ยนแปลง หรือเพิ่มเติมไม่ว่าทั้งหมดหรือบางส่วน ซึ่งข้อมูลคอมพิวเตอร์ของผู้อื่นโดยมิชอบ ต้องระวางโทษจำคุกไม่เกินห้าปี หรือปรับไม่เกินหนึ่งแสนบาท หรือทั้งจำทั้งปรับ
มาตรานี้คงเป็นที่ถูกใจของหลายคน เพราะเกี่ยวข้องกับ BOT โปรแกรม BOT นั้น ต้องมีการเขียนชุดคำสั่งใหม่เพื่อใช้สำหรับโปรแกรม BOT ซึ่งข้อมูลเดิมนั่นเป็นของบริษัทเกมส์ ฉะนั้น การเขียนชุดคำสั่งขึ้นใหม่ทั้งหมด (External ไม่ถือเป็นการแก้ไข Client ... แต่สามารถเอาผิดได้ในโทษฐานหลอก Server = ส่งข้อมูลไป update ตัวละครโดยมิชอบ ... ผิดมาตรา ๙ ก็จริงแต่จับยากสุดๆ) หรือแก้ไขบางส่วน (Internal ไม่ว่าจะต้องอาศัย Client ตัวจริงประกอบการใช้งาน หรือ ดัดแปลง Client ... อันนี้ผิดมาตรา ๙ แน่นอน แต่เป็นการยากที่จะหาคนที่เป็นเจ้าของไอเดียที่ว่า) การกระทำดังกล่าวก็เป็นการแก้ไข เปลี่ยนแปลง ข้อมูลคอมพิวเตอร์อย่างแน่นอนครับ ส่วนผู้ใช้โปรแกรม BOT ในที่นี้ ผมยังไม่ขอสรุปน่ะครับ (ผู้ใช้ไม่ผิด มาตรา ๙ ... เว้นเสียแต่ทางตุลาการ จะตีความว่า User จงใจแก้ไขข้อมูลใน Server อย่างมิชอบ ด้วย Client ปลอม=bot) แต่ในความเห็นส่วนตัวผมเห็นว่า เมื่อมีการ Run โปรแกรม BOT แล้ว ผู้ใช้ก็น่าจะเป็นผู้การแก้ไข เปลี่ยนแปลง ข้อมูลคอมพิวเตอร์ด้วย ซึ่งจะมีความผิดตามมาตรานี้
(ทั้งนี้ทั้งนั้นไม่มีส่วนไหน บ่งบอกถึงกรณีของการใช้ Automouse = โปรแกรมภายนอกที่ถูก Run เพื่อช่วยควบคุม Client โดนไม่สนใจ Feed Back จาก Client แต่ประการใด = Client ยังคงเป็น Client ที่ถูกต้องตามกฎหมาย)
