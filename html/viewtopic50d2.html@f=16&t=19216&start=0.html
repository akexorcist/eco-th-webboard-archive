Effect:
1. สกิลนี้มีผลเฉพาะสิ่งที่หินเท่านั้นครับ ถ้าสิ่งนั้นไม่ใช่หิน จะเป็นโจมตีปกติ (เหมือนทุบ)
2. เมื่อโจมตีมอนเตอร์มีผลทำให้มอนเตอร์หยุดฃะงักประมาณ 2 วินาที
    • คำว่าหินในที่นี้คือ หินทุกชนิด รวมไปถึงมอนเตอร์ที่เป็นชนิดหินด้วยครับ ซึ่งในเกมส์มีอยู่ 7 ชนิดด้วยกัน

    • แล้วถ้ากรณีถูกสาปให้เป็นหิน สาปให้เป็นน้ำแข็ง ? คำตอบคือไม่ได้ครับ

สรุป
1. ข้อดีหลักๆของมันคือทำให้มอนหยุดซักพักครับ คนที่เซียน Blow จะรู้ :P
2. แก้ปัญหายามฉุกเฉินได้ดี
3. มอนเตอร์หินในอนาคตคุณอาจจะต้องอยู่กับมันครับ
4. NvN มีรูปปั้นให้ตีด้วยนะ

ปล. สกิลจะดีหรือไม่อยู่ที่ตัวคุณดึงออกมาใช้ครับ
