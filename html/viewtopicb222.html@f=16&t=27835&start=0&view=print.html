อาชีพFarmer นั้น สาย AGI กับ สาย VIT
แบบไหนมีข้อดีข้อเสียต่างกันอย่างไร

สาย agi มีข้อดีตรงที่ตีเร็วครับ ข้อเสียคือ อัพเยอะแค่ไหนก็ยังหลบไม่ได้ เลือดน้อยพลังโจมตีเบา
สาย vit มีข้อดีตรงอึดขึ้นนิดนึงแต่ไม่มาก ถ้าไม่มีพระหรือของปั๊มก็แย่ ตีก็เบา ตีช้าเท่าเดิมตลอดปัจจุบันเป็นไงอนาคตก็เป็นแบบนั้น

อาชีพ อาเคมิส กับ อาชีพ มาริโอเนส
มีข้อดีข้อเสียต่างกันแย่งไร

สองอาชีพนี้ไม่น่าจะเอามาเปรียบเทียบกันเพราะมันต่างกันมากเกินไปมันเป็นคนละแนว

สกิว Blow กับ Banish Blow
มีข้อดีข้อเสียต่างกันอย่างไร

Blow เบากว่า 10% ใช้ sp น้อยกว่า 1 สามารถใช้ต่อเนื่องได้เพราะมอนไม่กระเด็น
BB แรงกว่า 10% ใช้ sp มากกว่า 1 มอนจะกระเด็นออกไปกว่ามันจะวิ่งเข้ามาก็สวนไปได้อีกโดยไม่ถูกโจมตี ข้อเสียคือมันขัดจังหวะ IAI ของเบลด ขัดการโจมตีของอาชีพอื่น ไม่เหมาะกับการเล่นกับปาร์ตี้

ที่ผมเล่นอยู่สาย str ใช้ Blow อย่างเดียวคับ
เลเวล 56
str 71+xx
vit 25+xx
agi 15+xx
