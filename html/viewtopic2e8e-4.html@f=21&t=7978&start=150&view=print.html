แนะนำสถานที่ 4 ว่าด้วยเรื่องการกิน

1.โรงอาหาร แน่นอนว่ากองทัพต้องเดินด้วยท้อง ดังนั้นทางโรงเรียนจึงสร้างโรงอาหารด้านหลังอาคารเรียนขึ้นโดยมีอาหารนานาชาติให้เลือกซื้อรับประทาน รสชาติดีเลิศแต่ราคาถูกเหลือเชื่อ(ทั้งนี้ราคาจะขึ้นอยู่กับชนชาติอาหารที่จะรับประทาน ของเอเชียจะถูกหน่อย :wink: ) หากมีปัญหาอะไรก็ติดต่อคุณนามิ(ในรูป)ผู้ดูแลโรงอาหารได้


2.ดาดฟ้า หากใครเบื่ออาหารในโรงอาหารหรือต้องการอวดความสามารถในการทำอาหารแก่เพื่อนๆ(หรือบ้านจน)ก็สามารถนำปิ่นโตไปปิคนิครับประทานอาหารบนดาดฟ้าได้โดยไม่ต้องกลัวตัวดำเพราะโรงเรียนตั้งอยู่ห่างจากเส้นศูนย์สูตรค่อนข้างมาก แต่เมื่อรับประทานเสร็จแล้วโปรดรักษาความสะอาดด้วย นอกจากนี้สามารถไปปิคนิคในจุดใดก็ได้ภายในโรงเรียนแต่ต้องคำนึงถึงความเหมาะสม(จะไปปิคนิคในห้องน้ำก็ไม่ไหวนะ - -")


3.หากใครรับไม่ได้กับอาหารในโรงอาหารหรือคุณพ่อคุณแม่ไม่ให้ทานเกรงว่าผื่นคันจะขึ้น(ไฮโซอะไรนักหนานิ -*-)หรือไม่อยากหิ้วข้าวกล่องมาให้เมื่อยมือก็สามารถให้คนรับใช้ทางบ้านของนักเรียนจัดโต๊ะรับประทานอาหารภายในโรงเรียนได้(ต๊าย ลูกคุณหนู -*-)
โดยทางโรงเรียนจะออกใบอนุญาตในการเข้ามาให้แก่คนรับใช้ของนักเรียนแต่การทำเช่นนี้อาจทำให้ผอ.หมั่นไส้เล็กน้อย เนื่องจากผอ.กินข้าวกล่อง(อนาถชิบ - -")
