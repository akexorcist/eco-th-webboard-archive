...ต้องบอกว่า ทำใจน่อ เพราะกับดักของเรนเจอร์มีดังนี้

Pit Trap (Lv 17)- สร้างหลุมให้มอนสเตอร์ตก.... ไม่มีดาเมจ คงแรงขึ้นไม่ได้หรอก

Grass Trap (Lv 25)- ดาเมจตามพลังชีวิตของมอนสเตอร์ที่เหยียบกับดัก จะแรงขึ้นก็ขึ้นอยู่กับมอนสเตอร์ตัวนั้นน่ะ ก็คงจับตัวใหญ่ๆหน่อยถึงจะแรง

Slip Trap (Lv 50)- วางกล้วย มอนสเตอร์ปลิวหกล้มแล้วเสียเวลาลุกขึ้น - -" ไม่มีดาเมจยังไงก็ไม่แรงขึ้น

...ต้องบอกว่าทำใจอ่ะ แต่ถ้าเป็น Explorer จะอีกเรื่องนึง แต่เราไม่ได้เล่นสายกับดักนะ เลยไม่รู้ว่าเป็นยังไง
