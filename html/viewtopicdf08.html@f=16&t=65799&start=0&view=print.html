คือผมเล่นtataเวล60กว่าๆแล้วมานั่งคำนวนว่าอับสกิวไหนบ้างดี
อ่านมาเจอสกิวนี้เลยสงสัยอะครับ

Throw Nugget
Active
Lv.Job : Lv. 43
Lv.Max : Lv.5
skill Level 1 2 3 4 5
SPที่ใช้ 10 16 22 28 34
ความรุนแรง 200% 300% 400% 500% 600%
Effect : ขว้าง Nugget หลายชนิดใส่เป้าหมาย ความแรงขึ้นอยู่กับ Status ของผู้ขว้าง,Level skill และ ชนิดของ Nugget ที่ใช้ (Gold Nugget รุนแรงสุด)

-ที่มัน600%นี่มันคิดจากไหนหรอครับ
-nuggetแต่ละอันมันแรงต่างกันขนาดไหนคับ ทำdamageประมานเท่าไหร่บ้าง
-ระยะไกลเท่าไหนหรอคับ
-***ปกติเค้าอับกันมั้ยคับ (ได้ใช้รึเปล่า)***

ใครรู้หรือเคยใช้ช่วยตอบทีคับ ขอบคุนคับ
