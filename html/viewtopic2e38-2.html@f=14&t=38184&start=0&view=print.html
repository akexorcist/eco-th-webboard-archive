จะให้บอก ก็คงยากอะครับ คุณต้องบอกด้วยว่า สเตตัสอะไร บางทีมันเหมาะกับสาย Agi Str บางทีมันเหมาะ กับ Vit Str อะครับ ถ้าเอาคร่าวๆตามที่ผมเคยเล่นก็คงจะ

1-15 ตี Bau

15-25 หมาป่าขาว เพนกวินเหนือ มินิดูล

25-40 ซินนามอน กับหนอนที่ใต้

40-50 ดันใต้ หาปาร์ตี้กับสายเวทย์แชร์เวลกัน หรือ ปราสาทอันเดท ครับ

50-ุ65 ไลท์ทาวเวอร์ และ ฟูชิงกิ (แนะนำ หาตี้กับพระ ดีที่สุด)

65-80 ไลท์ทาวเวอร์ ฟูชิงกิ ดันส่วนตัว ( กรณีดันส่วนตัว ต้องมีเพื่อนที่เลเวล 70+ เปิดดันนะครับ หากเวลยังไม่ถึง 70 )

ps. อันนี่ ประสบการณ์เล่นของผมนะครับ ใครจะไม่เห็นด้วย ก็ไม่เป็นไรครับ

ps. ขออภัย จำชื่อมอนไม่ได้ T^T

ps. ผมเล่นสายแอสนะครับ

นักธนูช่วงแรกจะลำบากนะครับ เพราะยังไม่มีสกิลโจมตี(ยกเว้นสกิลธนูธาตุ)

ช่วงเลเวล28-40ถ้าอัพสกิลธนูธาตุลมไว้ก็ไปเก็บกับCinnamonที่แมพVolcano-ไฮเวย์เมืองใต้(แต่ต้องละวังหนอนหินนะ)

ถ้าอยากเก็บเลเวลไวๆต้องเป็นคลาส2ก่อนครับ เพราะจะมีสกิลยิงรัวที่ทำให้เลเวลอัพไวมากมาย

พอช่วง40-50นิดๆ ถ้ามีความอดทนและไม่เบื่อก็เก็บCinnamonต่อไปเรื่อยๆครับ
EXP-JOBให้ดี เงินก็ดี แถมกระป๋องชินยังส่งเควสได้อีกด้วย

พอเวล50-60น่าจะเปลี่ยนคลาส2ได้แล้วซึ่งจะทำให้เราได้สกิลหากินคือสกิลยิงรัว(จำชื่อไม่ได้- -*)

ทีนี้ก็ขึ้นอยู่กับว่าจะไปเก็บที่ไหนแล้ว ส่วนตัวแนะนำดันใต้ชั้น1-2น่าจะดี(มั้ง)นะครับ
