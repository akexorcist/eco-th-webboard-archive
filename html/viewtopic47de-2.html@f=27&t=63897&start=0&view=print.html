ข้อ 1) part1มานมะช่าย .rar
part 1 เป็น .exe ครับ เพราะฉะนั้นไม่ต้องไปกด extract ที่ตัวไฟล์ rar อันอื่น
แต่ให้ double click ที่ part 1 จากนั้นเลือก run
เสร็จแล้วก็เลือกตำแหน่ง folder ที่ต้องการจะวางไฟล์ไว้เลย

ข้อ 2) คอมมานบอกว่าไฟล์ใหญ่เกินไป
ลองเช็คดูว่าที่ว่างของคอมเหลือพอหรือไม่ ควรมีที่ว่างอย่างน้อย 1.3 - 1.5 GB สำหรับการ extract file และ อีกประมาณ 1.5 GB สำหรับการ install

ถ้ายังมีปัญหาขณะแตกไฟล์อีก ให้ลองเช็คที่ขนาดไฟล์แต่ละอันว่ามีขนาด 50 MB หรือไม่(ยกเว้น file สุดท้าย 14.05 MB) เนื่องจากอาจโหลดมาไม่ครบได้
