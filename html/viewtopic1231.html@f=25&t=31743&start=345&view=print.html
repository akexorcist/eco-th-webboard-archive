tree เขียน:พอดีว่าเซ่ออ่ะครับ หาเจอกะคงมะถาม(- -)

ก็ไม่ได้ว่าขนาดนั้น แต่แหมแบบผมว่าเห็นคำถามนี้บ่อยมากน่ะครับ

ฝึกเวทมีสองแบบ
-แบบที่เขาว่ามา >เปิดทิ้งไว้ >อันนี้รักสบาย กึ่งๆเหมือนพวกใช้ออโต้ แต่เป็นเทกนิค
-แบบผม >ฝึกเอาเอง พาไปไหนมาไหนด้วยกัน แมวมันจะใช้เวทเองเรื่อยๆ>อันนี้รักแมว

จริงๆผมก็ไม่ได้รัก/ฝึกแมวจริงจังเท่าไหร่หรอก เปิดเกมมานาน เพิ่งจะล้ม7 ห่วงแต่เล่นเกมอื่น,เวลตัวเองมากกว่า แต่ตอนนี้เลิกเวลละครับ เล่นแค่เกมอื่นที่คาไว้ แล้ววันไหนที่มันไม่แลค ก็เข้ามาฝึกแมวที

ซาก้า6มาีนี่ทิตย์นึงไม่แลควันเดียวมั้ง
