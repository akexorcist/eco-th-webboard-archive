อัพเทดไหม่ กับ เควสเหมียวๆ หรือ (เนโก๊ะน้อย)

เอาหละเริ่มกันเลยนะครับ

1.คุยกับถังขยะ แล้วกด ' ยกเลิก ' เรื่อยๆ จนกว่าจะได้หนวด (ต้องอดทนนะครับ)

พอกดจนได้หนวดแล้ว ให้กดใช้หนวด แล้วหนวดจะพาเราวาป ไปหอเปลี่ยนอาชีพชั้น 5

2.พอไปถึงหอเปลี่ยนอาชีพแล้ว เราจะพบกับ NPC 3 ตัว คุยกับ NPC ให้หมดทุกตัวเลย

แล้วเค้าจะบอกว่า ' เข้ามาที่นี้ไม่ได้อะไรประมาณนี้หละ '

3.ให้เราออกมาจากหอเปลี่ยนอาชีพ แล้วดิ่งไปหาหมอดูใน ดาวน์ทาวน์

แล้วหมอดูจะให้ไปหาพระ ที่ ' โบถขาว ' แล้ว หลวงพ่อก็บอกว่า ช่วยไม่ได้

4.ให้เรากลับไปหา ' หมอดู ' อีกที่นึง แล้วหมอดูก็จะให้ไปหา ' วิญญาณศักดิ์สิทธิ์ดู '

5.ให้เราไป ที่ ' หาดหนอนม่วง ' ทางตะวันออก พอเราถึงหาดหนอนแล้ว

ให้เราขึ้นไปบนสุด ให้หา ' นางฟ้า ' หาดีๆนะครับ เพราะตัวนาฟ้าตัวจะเล็กมาก

6.พอคุยกับนางฟ้า เค้าจะช่วยเรา ปัดแมวออกจากร่าง แต่ทำไม่ได้

แล้วให้เรากลับไปหา ' หมอดู ' คุยกับหมดดูแล้ว ให้ไปหลวงพ่อ ที่โบถขาวคุยกับหลวงพ่อ

7.พอคุยกับหลวงพ่อแล้ว ให้เราไป ' ร้านตัดเย็บ ' ในอัพทาวน์

แล้วเค้าจะให้หาของ ดังนี้

-1. Cotton Ribbon 1 อัน

-2. Needle (เข็ม) 1 อัน

-3. Fabric 1 อัน

-4. Thread (ด้าย) 1 อัน

8.พอให้ของป้าร้านตัดเย็บแล้ว เราก็จะได้ หมวกของเนโกะมา

แล้วให้เราหา Rainbow Heart ดอปจาก Angel Feather (ดอปไม่ยากเท่า)

9.พอได้ Rainbow Heart แล้ว ให้กด ' ใช้ ' แล้วเราจะวาปไปหา

นางฟ้า 2 คน แล้วให้คุย แล้วมันจะมีให้ ' เลือก ' 2 ข้อ

1. เอาแมวออกจากร่าง

2.ดำเนินชีวิตต่อไป

ให้เราตอบ ' ข้อ 2 ' นะครับ ถ้าตอบข้อ 1 แมวจะหาย แล้วเราต้องทำไหม่หมดทุกอย่าง

พอ ตอบข้อ 2 แล้ว เราก็จะได้ เนโกะ (เนโกะสีชมพู) แล้วครับ


เดียวผมจะเอา เนโกะสีเหลือง มาอัพเอท อีกที่นะครับ

เนโก๊ะ (สีเหลือง)

ถ้าทำสีเหลืองต้อง เลเวล 30 ผ่านเควสมาแล้วไม่ต่ำกว่า 10 ครั้ง นะครับ

เริ่มกันเลยนะครับ :lol:

1.ให้เราไปว่า NPC ที่ชื้อ Return Goldo ที่เกาะเรือรบ หรือที่ฝัก ไข่มังกร ครับ

คุยกับ Return Goldo แล้วให้เราตอบ ข้อ 1 ทั้ง 2 รอบเลยนะครับ

เราก็จะได้ กระเป๋าใบใหญ่ 1 ใบ

2.ให้เรากลับไปหา Merchant ที่อยู่ใน หอเปลี่ยนอาชีพ ชั้น 4 ทางเหนือ

พอส่งกระเป๋าให้ Merchant แล้ว แต่กระเป๋าเราจะถูกขโมย นะครับ

แล้วเราก็จะถูก สอบสวน แล้วจะมี NPC ขึ้นมาประมาณ 7 ตัว

ให้เราคุยให้ครบทุกตัวเลยนะครับ (เน้น) คุยทุกตัวเลยนะครับ

3.พอคุยครบแล้ว ให้เรากลับไปหา Return Goldo ที่เกาะเรือรบ แล้วเค้าจะด่าเราเป็นชุด

พอคุยกับ Return Goldo แล้ว ให้เราไปหา Guide Machine จะอยู่หน้า หอเปลี่ยนอาชีพ

จะเป็นตัวหุ่นยนนะครับ แล้วเค้าจะบอกว่า ไม่เจอคนต้องสงสัยเลย

4.แล้วให้เราไปคุบกับ ปาร้านตัดเย็บ ใน อัพทาวน์ แล้วป้าจะบอกว่า

คนร้ายน่าจะเป็นเด็กตัวเล็กๆ พอคุยกับป้าแล้ว

ให้เรา กลับไปคุยกับ Guide Machine ที่อยู่ตรงหอเปลี่ยนอาชีพอีกที่ แล้วคุยกับเค้า

5.พอคุบกับ Guide Machine หรือหุ่นยน แล้ว ให้ไปหอเปลี่ยนอาชีพชั้น 5

ถ้าเล่นตัวละครเป็น เผ่าคน จะขึ้นไปชั้น 5 ไม่ได้นะครับ

ต้องขอ สิง พวกมีปีกขึ้นไปนะครับ

6.พอขึ้นไปชั้น 5 แร้ว ให้ไปทาง ห้อง เหนือ แล้วเราจะเข้าไม่ได้ จะมีกระจอหรืออะไร

บังอยู่

7.ให้เราไปร้าน จังช๊อป แล้วคุยกับเจ้าของร้าน แล้วเค้าจะให้หาของที่จะเข้าเข้าไปหอชั้น

5 ได้ มันจะมี 2 ตัวเลือกนะครับ

1. Crysta 1 ชิ้น

2. Crystal piece 5 ชิ้นl

ให้เราเลือกอย่างใดอย่างหนึ่ง ไปให้เจ้าของร้าน จังช๊อป แล้วเข้าจะทำ แร่อะไรซักอย่าง

ที่จะเข้าไปได้

8.แนะนำว่า หาของปั้มไปเยอะๆแล้วเราก็ต้องหาคนสิงขึ้นไป ชั้น 5 อีกที่ แล้วไปห้องทาง

เหนือเหมือนเดิม แล้วเราก็จะเข้าได้ แล้วจะเจอเด็กคนหนึ่ง

ให้คุยกับเด็ก แล้วเด็กก็จะพาเราวาปไป สู้กับ หุ่นยน

8.ฆ่าหุ่นยนให้ตาย แล้วเก็บแขนของหุ่นยน มา ให้เรานำไปให้ Merchant Master

ที่อยู่ ในหอเปลี่ยนอาชีพ ชั้น 4 แล้วคุยกับเค้า

9.พอคุยกับ Merchant Master แล้ว ให้เราไปหา Return Goldo ที่เกาะเรือรบ

แค่นั้นเราก็จะได้ (เนโกะสีเหลืองละครับ)
