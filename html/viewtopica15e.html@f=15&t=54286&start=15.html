3 จอนะครับ .. ถ้าคอมรับได้ ก็จัดไป

เอาสาย mag สิงที่มือ 2 ตำแหน่งสิงที่เหลือ
- แม่ค้า 1 (ต้องมี)
และ - พระ หรือ เอเล อาชีพไหนก็ได้ 1 ใน 2

แต่ เน้น +เลือด และ def
ตัวสิงพอลงดันให้กดออกตี้แล้วให้ตี้กันเอง (แม่ค้าตี้พระ หรือแม่ค้าตี้เอเล)

ในที่นี้แม่ค้าต้องมีไรออท+ถืออาวุธจำพวกค้อนในระหว่างสิง
ดาเมจได้จากการที่ตี้กับพระ หรือ เอเล

วิธีนี้คาบาตัวเดินได้ exp เต็มๆ

อีวิล+พระบัพ+แม่ค้าคอยฮีล mp
(ข้อดี คือ มีทั้งพระบัพเตตัสให้และมีแม่ค้าคอยเพิ่ม mp และกดเพิ่ม exp 5%
// พระและแม่ค้าไม่มีข้อจำกัดอะไรมากนัก แม่ค้าเอาแค่พอฮีลแล้ว mp เด้ง ไม่ต้องสายฮีลล้วน
// แม่ค้าคอยทุบไรออทซ้ำจากด้านใน)
(ข้อเสีย เวทไม่แรงที่สุด มอนไม่ตายทีเดียวอาจจะต้องซ้ำดาบสอง// แม่ค้าฮีลไม่ถึงที่สุดเพราะไม่ใช่สายฮีลล้วน และถือพัด)

หรือ

อีวิล+เซ็น+แม่ค้าสายฮีลล้วน
สเต็ปนี้ลากมากองๆ แล้ว bomb dark blazer ไม่ก็ shadow blast ตูมเดียวอยู่

(ข้อดี ตูมเดียวอยู่ // แม่ค้าเพิ่ม hp mp sp และเพิ่ม exp )
(ข้อเสีย เซ็นมีระยะเวลา 15 วิ ต้องกะจังหวะดีๆ // เอเลเป็นอาชีพที่ไม่ถึกเอามากๆ
ถ้า vit น้อย ระวังจะโดนกระชากหลุดสิงเอาง่ายๆ // แม่ค้าช่วยซ้ำได้ช้า)
