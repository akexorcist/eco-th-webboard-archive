“ห๊า !? ตาฉันแล้วหรอเนี่ย !?”


เกียร์ล๊อตอุทานขึ้นมาอย่างตกใจ ดูท่าทางเขาจะจำไม่ได้ว่าตนเองได้หมายเลขอะไร เพราะว่าตอนนั้นเหมือนกับว่าเขาหมดสติอยู่ จึงไม่อาจจะรับรู้อะไรได้ “ร้องซะดังเลยนะจ๊ะ” เสียงใสดังขึ้นด้านข้างเขา เกียร์ล๊อตแทบอยากจะร้องไห้ เพราะเขารู้ว่าเสียงนั้นเป็นของใคร


“อ่า ... เอ่อ ... อือ ...” เกียร์ล๊อตตอบด้วยน้ำเสียงสั่น ๆ ... เขาแทบจะไม่อยากนึกถึงตอนนั้น ค่ำคืนอันโหดร้ายนั้น


หลังจากวันนั้น เกียร์ล๊อตก็ต้องอยู่กับฮิเมะ แม้ว่าเขาจะพยายามหนีไปกี่ครั้งกี่หน แต่ว่าเขาก็โดนเธอ ( เขา ? ) ตามเจอตลอดเวลา ตอนนั้น ... ก่อนที่เขาจะหมดสติไป รู้สึกว่า ...


...
...
...


“เอ๋ !? จะเข้าร่วมงานประลองซิลเวอร์ฮาร์ทงั้นหรอ !?” เกียร์ล๊อตเอ่ยถามฮิเมะอย่างตกใจ ฮิเมะพยักหน้าด้วยใบหน้ายิ้มแย้ม หากใครไม่รู้ว่าตัวตนที่แท้จริงของเธอนั้นเป็นยังไง คงจะเผลอใจแอบหลงรักเธอแล้วก็เป็นได้


“ใช่แล้วจ๊ะ !” ฮิเมะตอบเสียงใส ถ้าเป็นชายหนุ่มคนอื่นละก็ คงแทบหลงกับความน่ารักไร้เดียงสา แต่ทำไมกันนะ ? ในสมองของเกียร์ล๊อตกลับเห็นใบหน้าเข้มเต็มร้อยอย่างลูกผู้ชายตัวจริงอยู่บนใบหน้าเธอคนนี้ตลอดกันแน่ “รู้รึเปล่า ? ว่าถ้าฉันได้ซิลเวอร์ฮาร์ท ฉันจะเอาไปทำอะไร ?”


“... ไม่รู้ ...” เกียร์ล๊อตตอบด้วยน้ำเสียงเอื่อยเฉื่อย “ม่ะ ... ไม่รู้ครับ !” แต่เขาก็ต้องเปลี่ยนวิธีการพูดแทบจะในทันทีที่มือของเขาที่โดนมือของฮิเมะจับอยู่นั้นเริ่มโดนบีบแรงขึ้น ...


“ก็ ...” ฮิเมะปล่อยมือของเกียร์ล๊อตออก ก่อนจะยืนขึ้นพร้อมกับยกมือชี้ท้องฟ้าอย่างมั่นใจ “เพื่อจะได้เป็นผู้หญิงจริง ๆ น่ะสิ !!!”


“........” เกียร์ล๊อตนิ่งไปครู่นึง ในสมองของเขาตอนนี้กำลังนึกถึงภาพฮิเมะที่กลายเป็นผู้หญิงจริง ๆ หากแต่มีใบหน้าที่เข้มเต็มร้อยเช่นเดิม ... ไม่รู้ทำไมเมื่อนึกถึงตอนนี้ ขนทั่วร่างของเขาเหมือนกับโดนไฟช๊อตลุกขึ้นมาดื้อ ๆ ซะงั้น


“ไม่ดีหรือไง ? ... ถ้าฉันเป็นผู้หญิงจริง ๆ แล้ว นายจะได้แต่งงานกับฉันไง ...” ฮิเมะทำท่าเขินอายพร้อมกับใบหน้าแดงก่ำ โดยไม่ได้รู้เลยว่าคนที่กำลังฟังอยู่นั้นน้ำลายฟูมปากนอนหงายไปเรียบร้อยแล้ว และดูท่าทางเธอจะไม่ได้สนใจอะไรด้วย เพราะในหัวกำลังจินตนาการภาพของตนเองอยู่ในชุดเจ้าสาวสีขาวบริสุทธิ์


“โอ๊ะ ... หวังว่าคงจะไม่ได้คิดชิ่งนะเกียร์ล๊อตคุง ... เพราะนายเข้ามาจีบฉันแล้ว ถือว่านายมีพันธะกับฉันคนนี้เรียบร้อยแล้ว ...” ฮิเมะหันกลับมาด้วยใบหน้าเคร่งเครียดและเข้มเต็มร้อยสมชายชาตรี หากว่าเกียร์ล๊อตไม่ได้หมดสติไปก่อนแล้วล่ะก็ เขาได้หัวใจวายตายอีกรอบแน่นอน “ว๊าย ! เกียร์คุง ! เป็นอะไรหรือเปล่า !?”


ฮิเมะรีบก้มลงดูอาการของเกียร์ล๊อต ... เธอเขย่าตัวเขาเท่าไร เกียร์ล๊อตก็ไม่ยอมตื่นเสียที ...


ควับ ... เธอหันซ้าย

ควับ ... เธอหันขวา


“ต้องแบบเจ้าหญิงนิทราสินะ ...” ฮิเมะพึมพำขณะที่ใบหน้าของเธอนั้นก้มต่ำลง และใกล้ใบหน้าของเกียร์ล๊อตมากขึ้น มากขึ้น ...


...
...
...


เกียร์ล๊อตหน้าซีดเมื่อนึกถึงเหตุการณ์ที่เกิดขึ้น แม้ว่าจะหมดสติอยู่ แต่ก็รู้สึกน่าขนลุกอยู่ดี เขาขอตัวจากฮิเมะเพื่อไปเตรียมตัวที่ห้องของผู้เข้าแข่งขัน แต่ตอนนั้นเองที่เกียร์ล๊อตแว่บเข้าห้องน้ำไปเสียก่อน เขาถอดเสื้อกล้ามสีเขียวของตนออก เผยให้เห็นร่างกายที่กำยำและดูแข็งแรง ไม่แปลกที่หญิงสาว ( ? ) อย่างฮิเมะจะหลงใหล


เกียร์ล๊อตเริ่มหมุนตัวไปมาเพื่อดูร่างกายตนเอง พร้อมกับเพ่งหาสิ่งผิดปกติ “แผ่นหลัง ไม่มีรอยเล็บ” เกียร์ล๊อตพึมพำเสียงเบา ก่อนที่จะเริ่มใช้มือลูบบั้นท้ายของตนเองไปมาเบา ๆ “ไม่เจ็บแฮะ ... โอเค ! ตูรอด !” เขาเอ่ยอย่างดีใจก่อนที่จะเดินไปเตรียมตัว และตอนนั้นเองที่เขาก็สวนกับเดลที่เตรียมตัวเสร็จเรียบร้อยแล้ว


“โฮ่ย ! นายหรือเปล่าที่ต้องสู้กับฉันน่ะ ! ยินดีที่ได้รู้จักนะ !” เกียร์ล๊อตยกมือขึ้นทักทาย


เดลหยุดกึกทันทีที่เกียร์ล๊อตมีท่าทีเช่นนั้น ตอนนี้เขาอยู่ในเสื้อโค้ทสีดำขลับและมีลายปักที่ด้านหลังเป็นตัวอักษรสีแดงว่า ‘死’ ดวงตาสีเหลืองทองนั้นจ้องมายังเกียร์ล๊อตอย่างมุ่งร้าย เขายกมือขึ้นลูบเรือนผมสีเงินที่ปิดดวงตาข้างขวาพร้อมกับพึมพำอะไรบางอย่างที่เกียร์ล๊อตไม่ได้ยิน


“อ่า ... เอาเถอะ งั้นฉันขอตัวไปเตรียมตัวก่อนนะ” เกียร์ล๊อตทำท่าไม่สนใจ เขากลับเดินผ่านเดลไปเฉย ๆ ...


“ฮะ ฮะ ฮะ !!!!”


วูบ ! ! ...


เกียร์ล๊อตกลิ้งตัวหลบทันทีที่เขารู้สึกถึงอะไรบางอย่าง เขาตั้งหลักลุกขึ้นยืนพร้อมกับจ้องมองเดลด้วยแววตาไม่ไว้วางใจ “( เมื่อกี้ ... มัน ... )” เกียร์ล๊อตใช้มือลูบลำคอของตนเองอย่างแผ่วเบา เมื่อครู่นั้นเขารู้สึก ... รู้สึกเหมือนมีคมเคียวของมัจจุราชมาจ่อที่คอของเขา


“เป็นอะไรไป ?” เดลเอ่ยน้ำเสียงเย็นยะเยือกที่ทำเอาเกียร์ล๊อตนั้นขนลุก ปีกสีดำของเขาสยายออกอย่างน่าเกรงขาม ใบหน้าเต็มไปด้วยความชั่วร้าย และรอยยิ้มนั้น ... คือรอยยิ้มที่เต็มไปด้วยความกระหายเลือดและบ้าคลั่ง ! “น่าแปลกนัก ที่สวะ ... ก็ยังรับรู้ได้ถึงจิตสังหารของข้า ...”


“เอ๋ ? จิตสังหารอะไรหรอ ?” เกียร์ล๊อตเอียงคอทำท่าสงสัย “เมื่อกี้แค่รู้สึกว่ามีแมลงวันมาบินโฉบ ชิ้ว ! ก็เลยหลบแค่นั้นแหละ เผอิญถูกปลูกฝังมาให้เป็นคนรักความสะอาดด้วยสิ” เขาเอ่ยพร้อมกับยักไหล่ ใบหน้าของเกียร์ล๊อตตอนนี้นั้น บอกได้คำเดียวว่า ‘กวนประสาท’


“ไปก่อนนะ ! เดี๋ยวจะเตรียมตัวไม่ทัน !” เกียร์ล๊อตว่าแล้วรีบวิ่งไปที่ห้องเพื่อเตรียมตัว


เดลเงียบไปครู่ใหญ่ ... เขามองตามเกียร์ล๊อตจนหายไป ก่อนจะเดินมาที่ประตูเพื่อเตรียมตัวที่จะขึ้นสู่เวที ...


“... คู่ควรที่จะฆ่า ...”


“นี่ครับ ! คุณซิลเวีย” ลูร์กลับมายังที่นั่งพร้อมกับน้ำมะนาวแก้วนึง ซึ่งเขาแค่ต้องการไปห้องน้ำเท่านั้น แต่กลับโดนฝากซื้อน้ำมะนาวซะนี่ “ขอโทษนะครับที่มาช้า เผอิญคนเยอะนิดนึง”


“น่า ๆ ! ไม่เป็นไรหรอก” ซิลเวียเอ่ยด้วยรอยยิ้มพร้อมกับรับน้ำมะนาวมาอย่างอารมณ์ดี “มันก็สนุกอยู่หรอกเนอะ แต่ว่าบางครั้งก็รู้สึกเบื่อเหมือนกันเวลาที่ต้องนั่งนาน ๆ เนี่ย เฮ้อ ! ฉันไม่ค่อยชอบใจเลย” ซิลเวียทำแก้มป่องอย่างไม่ค่อยจะพอใจเท่าไรนัก ใจจริงเธอนึกอยากจะให้รีบ ๆ สู้กันไปเลยซะมากกว่า จะได้จบเร็ว ๆ แล้วเธอจะได้สู้บ้าง


ซิลเวียดูดน้ำมะนาวอึกใหญ่ ก่อนจะยื่นให้ลูร์ “อ่ะ ! นายก็ดื่มด้วยสิ เดี๋ยวคอแห้งนะ”


“อ่ะ ... ครับ” ลูร์ยิ้มแล้วรับแก้วน้ำมะนาวมาจากซิลเวีย เขากำลังจะดูดน้ำจากหลอด แต่ก็ต้องชะงัก ... เมื่อคิดได้ว่า อย่างนี้มันต่างอะไรจากจูบทางอ้อมกันล่ะ !? ยิ่งใกล้ ... เขาก็รู้สึกได้ถึงกลิ่นหอมที่ลอยขึ้นมาจากปลายหลอด คงจะเป็นกลิ่นของอะไรบางอย่างที่ซิลเวียไว้ทาแก้ปากแห้ง “( จะดีหรอ ... จะดีหรอ ... )” เขารู้สึกได้ถึงความคิดที่กำลังผุดขึ้นในสมองของตนเองเรื่อย ๆ


“( เอาเลยสิ ... เอาเลยสิ ... )”


ให้ตายเถอะ ... ยังมีอีกความคิด ที่ดูท่าทางจะเป็นความคิดด้านมืดขึ้นมาค้านเขาแล้ว แถมทำไมเสียงของมันดันดังกว่าเสียงของความคิดเดิมเสียอีกนะ ? มันดังขึ้น ... ดังขึ้น ... จนในที่สุด ลูร์ก็ดูดน้ำมะนาวจากหลอดนั้นพร้อมกับน้ำตาที่ไหลริน ( ซึ่งไม่รู้ว่าเพราะความรู้สึกพ่ายแพ้ความคิดด้านมืด หรือว่าความปิติยินดีกันแน่ ? )


“ขอบคุณครับ” ลูร์ส่งมันคืนให้ซิลเวีย ก่อนที่จะนั่งเหม่อไปถึงภาพบางอย่างที่ ... ทำให้เจ้าตัวจู่ ๆ ก็หน้าแดงได้ ...


“อ๊ะ ! จะเริ่มแล้วล่ะ !” ซิลเวียไม่ได้สนใจท่าทางของลูร์ เพราะว่าสายตาของเธอนั้นกลับมองไปที่กลางเวที ซึ่งโฆษกคนเดิมกำลังเดินขึ้นมาบนเวทีแล้ว “มาแล้วลูร์ !” ซิลเวียเรียกลูร์ หากแต่ลูร์นั้นยังหลุดไปกับจินตนาการอันแสนสุขอยู่ เธอจึงปล่อยเขาไว้แบบนั้นก่อนดีกว่า


“ขออภัยที่ต้องให้รอนานนะครับ !! ท่านผู้ชม !!”


โฆษกเอ่ยพร้อมกับโค้งลงอย่างนอบน้อม “เพื่อไม่ให้เป็นการเสียเวลา มาเริ่มกันเลยดีกว่า ! กับศึกประลองซิลเวอร์ฮาร์ทคู่ที่ 2 การปะทะกันระหว่าง ! ‘เกียร์ล๊อต อุรัสเซ่’ และ ‘เบลทราน เดลครุซ’ !!!”


เฮฮฮฮฮฮฮฮฮฮ --- ฮฮฮ !!


เสียงของผู้ชมดังก้องไปทั้วสนามประลอง การประลองคู่แรกนั้นสร้างความตื่นเต้นได้โดยไม่ทำให้พวกเขาผิดหวังกันเลยแม้แต่น้อย และพวกเขาก็หวังว่า การประลองคู่ที่สองนี้ ก็จะไม่ทำให้พวกเขาผิดหวังเช่นเดียวกัน ...


ประตูทั้งสองฟากของสนามประลองถูกเปิดออกอีกครั้งนึง พร้อมกับร่างของสองบุรุษที่ค่อย ๆ ย่างกรายออกมาจากสองประตูนั้น ทั้งสองเดินขึ้นมาบนเวที น่าแปลกอยู่ที่ทั้งสองนั้นต่างไม่ได้ถืออาวุธกันมาเลยสักคน เกียร์ล๊อตนั้นทำท่ามองซ้ายมองขวา ก่อนจะหันกลับไปมองที่นั่งของผู้แข่งขัน เขาป้องปากแล้วตะโกน “เฮ้ !! พวกนาย !”


“ใครสักคนตรงนั้นมีดาบให้ฉันยืมไหม !? ลืมเอาของตัวเองมา !”


สิ้นเสียงของเกียร์ล๊อต แทบจะทำให้ทั้งสนามเงียบกริบ ฮิเมะเอามือตบหน้าผากตัวเองอย่างหน่ายใจ ก่อนที่จะค้นในกระเป๋าทองของเธอ เพื่อหาของที่เกียร์ล๊อตจะใช้ได้ “เอ้า ! เอาไป ! แล้วห้ามแพ้นะค๊า ที่ร๊ากกกกก !!” ฮิเมะตะโกนดังลั่นทำเอาผู้ชมโห่แซวเกียร์ล๊อตที่อยู่ในสนาม พร้อมกับโยนบางสิ่งออกไปอย่างแรง


ฉึก ! ... บางสิ่งตกลงมาปักที่เบื้องหน้าเกียร์ล๊อต มันคือดาบ ... ดาบซามูไรสีเงินยาวประมาณเกือบสองเมตร ตัวกระบังดาบนั้นทำเป็นรูปดอกกุหลาบบาน และตัวด้ามดาบก็ถูกประดับอย่างสวยหรู “โห ... เอาไปขายถ้าจะแพงแฮะ ...” เกียร์ล๊อตเอ่ยเสียงเบา ที่จริงเขาไม่อยากจะใช้ของที่ฮิเมะให้มาเท่าไร แต่ถ้าเป็นอย่างนี้ ก็น่าจะพอสู้ได้ !


“แหม ... หวานกันจังเลยนะคะ” ทรีทที่เห็นเหตุการณ์และนั่งอยู่ข้างฮิเมะเอ่ยให้กับเธอด้วยรอยยิ้ม แต่ทรีทก็ต้องถึงกับแทบช็อกเมื่อใบหน้าของฮิเมะนั้นเต็มไปด้วยความเข้มเต็มแมนอีกครั้ง ฮิเมะมองทรีทด้วยสายตาเหยียดหยามและดูถูก ...


“ไม่ใช่เรื่องของหล่อนย่ะ นังชะนี ...” ฮิเมะเอ่ย โดยเน้นคำว่า ‘นังชะนี’ เป็นพิเศษ ก่อนจะสะบัดหน้ากลับไปมองการแข่งขันต่อ ปล่อยให้ทรีทนั่งหน้าซีดด้วยความตกใจไปแบบนั้น


“เอาล่ะ ... อ้าว ? แล้วอาวุธของนายล่ะ ?” เกียร์ล๊อตเหวี่ยงดาบไปมาสองสามครั้ง แต่เขาก็ต้องถามด้วยความแปลกใจ เมื่อพบว่า เดลนั้นไม่ได้นำอาวุธติดตัวมาด้วย “ลืมหรือเปล่า ? ให้ฉันขอยืมคนแถวนี้ให้เอามะ ?”


“เฮ้ ! ทางนั้นน่ะ !” เกียร์ล๊อตตะโกนไปยังผู้เข้าแข่งขันอีกครั้ง “เหมือนคู่ประลองของฉันจะลืมเอาอาวุธมา ขอยืมอันนึงได้ไหม !?”


“หุบปากได้แล้ว ไอ้สวะ ...”


เดลเอ่ยด้วยเสียงอันเยือกเย็น หากแต่ดังกึกก้องไปทั่วจนทั้งสนามนั้นเงียบกริบ “ที่ข้าไม่ใช้อาวุธ ... ก็เพราะว่าแกมันไม่มีค่าพอที่จะให้ใช้น่ะสิ ... เข้าใจหรือยัง เจ้าขยะ ...” เดลผายมือทั้งสองข้างออก ออร่าสีดำแผ่ขึ้นรอบกายของเดล และเหมือนกับว่ามันจะแผ่ออกไปโดยรอบด้วย


“คุณโฆษก ! พ่อหนุ่มคนนี้อยากจะต่อสู้จะแย่แล้วครับ !” เกียร์ล๊อตตะโกนบอกโฆษก ซึ่งเหมือนจะนิ่งไปครู่ใหญ่แล้ว “... พอใจหรือยังล่ะ ?” เขาเอ่ยพร้อมกับยกดาบชี้ไปยังเดลที่ยืนอยู่ตรงนั้น


“การประลองคู่ที่สอง ! ศึกชิงซิลเวอร์ฮาร์ท เริ่มต้นได้ !!”


สิ้นเสียงของโฆษก ทั้งสองก็พุ่งเข้าใส่กันอย่างรวดเร็ว เดลกางปีกมารของเขาออกอย่างเต็มที่ และพุ่งเข้าใส่เกียร์ล๊อตด้วยความรวดเร็วที่เหนือกว่ามาก ! “ฮะ ... เฮ้ย ๆ ! ช้า ๆ หน่อยสิโว้ย !” เกียร์ล๊อตตกใจอยู่บ้าง แต่ก็ยังวิ่งเข้าใส่เดลโดยไม่ยอมหยุดเช่นกัน


วูบ !! ... ชิ้ง !! ...


เป็นเวลาช่วงพริบตา ที่เดลง้างแขนพร้อมกับฟาดมันเข้าใส่เกียร์ล๊อต ออร่าสีดำนั้นล้อมรอบแขนของเขาจนดูเหมือนเป็นกงเล็บ ! ส่วนเกียร์ล๊อตนั้น ตวัดดาบที่เขาได้มาจากฮิเมะสวนเดลกลับไปเท่านั้น ... ร่างของทั้งสองเคลื่อนผ่านกันไปราวกับว่าไม่มีอะไรเกิดขึ้น


ปึด ! ... เสื้อกล้ามของเกียร์ล๊อตขาดออก ... เดลแสยะยิ้มออกมาเล็กน้อย “... ต่อไป ... คือหัวของแกที่ต้องขาด ... ไอ้สวะ ...”


“เฮ้ ๆ ! ใจร้อนจังนะ ...” เกียร์ล๊อตเอ่ยพร้อมกับดึงเศษเสื้อกล้ามที่เขาสวมอยู่ให้ขาดออกไป “ให้ตายเถอะ เสื้อตัวโปรดของฉันซะด้วยสิ จบงานนี้สงสัยฉันต้องให้แกชดใช้ซะแล้วสิ ...” เขายิ้มราวกับไม่มีอะไรเกิดขึ้น


แป๊ะ ! ...


เกียร์ล๊อตดีดนิ้ว ... จู่ ๆ ที่แก้มด้านซ้ายของเดลก็เกิดบาดแผลที่เกิดจากของมีคมขึ้น ... โลหิตสีแดงฉานไหลรินจากบาดแผลเล็กน้อยที่เกิดขึ้นบนแก้มของเขา แต่ทว่า ... มันกลับสร้างความรู้สึกเคียดแค้นมากไปอีก เมื่อคนที่เขาดูถูกว่าเป็นแค่ ‘สวะ’ นั้น ... กลับสร้างบาดแผลให้กับเขาได้


“เลิกเล่นได้แล้วน่า ... เอาจริงซะที ...” เกียร์ล๊อตตวัดดาบของตนไปมาอย่างคล่องแคล่ว ราวกับว่าใช้มันมานานนับปี “... แล้วแกจะเสียใจ เพราะถ้าแกไม่เอาจริง แกโดน ‘สวะ’ คนนี้เล่นงานแน่ !”


ฮึ ...


เดลหลับตาลงพร้อมกับยื่นมือขวาออกมาข้างหน้า ... “ได้ ... ถ้างั้น ... ข้าจะเอาจริงกับแก ...” ครืน ... ลมกรรโชกพัดกระหน่ำอย่างรุนแรง “แล้วแกจะเสียใจ ที่ท้าทายข้าคนนี้ ... ชีวิตของแกจักมลาย วิญญาณของแกจะดับสูญ จักไม่ได้ผุดไม่ได้เกิด ! ไม่ว่าชาติไหนก็ตาม !”


“เฮ้ ... เลิกลิเกเถอะน่า รำคาญแล้วหนา ...” เกียร์ล๊อตบ่น


“T O R N A D O T E R R O R ! ! !”


“นะ ... นี่มัน !?”
