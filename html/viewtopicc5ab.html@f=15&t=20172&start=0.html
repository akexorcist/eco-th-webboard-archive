บ่ายวันอาทิตย์ที่อากาศข้างนอกแสนร้อน คงไม่มีอะไรที่มีความสุขไปกว่าการนั่งเล่นเกมอยู่ภายในบ้านอันแสนเย็นสบายของคนบ้าเกมแบบผม
นั่งลงหน้าคอมพ์ เข้าเกม(ECO)แล้วเลือกเล่นตัวละครหลักที่เล่นอยู่ประจำ คือ Sorcerer
วันนี้ตั้งใจว่า "เอาว่ะ วันนี้ให้ได้สักเลเวลนึงละกัน"ด้วยความมุ่งมัน จึงมุ่งหน้าไปยัง IronCity เป้าหมายการเก็บเลเวลคือ IronSouth Dun.
ไปคนเดียวคงขึ้นช้า ลองเดินหาปาร์ตี้ละกัน...
เข้าเมืองไปไม่ทันไร ก็มี SwordMan คนนึงกดชวนเข้าร่วมปาร์ตี้มา ผมก็กดตอบรับ
ภายในปาร์ตี้ รวมทั้งผม(Sorcerer) ก็จะมี คนวิ่ง(SwordMan)และก็ พระ(Vates)ที่สิงอยู่ในตัว SwordMan ก่อนหน้านี้แล้ว
เราเลยคุยกันว่าจะลงดันแค่ชั้น 1 เพราะมีคนยิงอยู่คนเดียว จากนั้นผมก็สิงในตัว SwordMan ให้เขาพาวิ่งลงดันไป
...ก้าวย่างเข้าสู่ดันชั้น 1 ผมก็ทำหน้าที่โดยการบัพ MagicShield + SolidAura ให้คนวิ่งตามสเตป...
SwordMan : (วิ่งเข้าไปอัดสกิลใส่มอนที่อยู่ข้างหน้าทันที)
Sorcerer : (ยิงเวทย์ใส่มอนช่วยให้มอนตายไวขึ้น)
SwordMan : ไม่ต้องช่วย ผมชอบการฟัน ไว้ลากมามากๆค่อยยิงนะ
Sorcerer : - -.
SwordMan : (ยังคงเดินหน้าอัดสกิลใส่มอนทุกตัวที่ขวางทาง)
Sorcerer : (บัพแต่ SolidAuraอย่างเดียวเพื่อให้SwordManฟันอย่างเมามัน)
...เวลาผ่านไปไม่ถึง 5 นาที...
SwordMan : เติม SP ให้หน่อย
Sorcerer : ...
SwordMan : กดยาเติม SP ให้หน่อย
Vates : - -*
Sorcerer : - -
Sorcerer : สายเวทไม่มีใครพกยาเติม SP มากันหรอก
Vates : นั่นดิ
SwordMan : เอ้า ก็เผื่อเก็บมากันบ้างไง
Sorcerer : ...
Vates : ...
...ถึงตอนนี้มอนสเตอร์หลายตัวได้เข้ามารุมโจมตี SwordMan ที่วิ่งไปมา...
Sorcerer : (เห็นว่ามีมอนมารุมโจมตี 4-5 ตัว จึงบัพ SolidAura ให้ถี่ๆ)
SwordMan : ยิงๆๆๆ อย่าเอาแต่ใส่เกราะ ช่วยยิงด้วย
...ในขณะที่SwordMan ออกคำสั่งนั้น เขาก็ได้ยืนปักหลักดวลดาบกับมอนที่เข้ามารุม 4-5 ตัว...
อนิจจา ในปาร์ตี้มีคนยิงอยู่คนเดียว(ผม)แล้วต้องคอยบัพกันไม่ให้คนแทงค์โดนโจมตีด้วย แต่...
เป็นที่น่าจะรู้กันว่า SolidAura ที่เลเวลสูงสุดที่เลเวล 5 นั้น จะกันโดนโจมตีได้ 7 ครั้งภายในระยะเวลาอันแสนสั้น...
Sorcerer : (เมื่อได้ยินดังที่ SwordManสั่งดังนั้น ก็ทำการบัพ SolidAura อีกครั้ง แล้ว เปลี่ยนเป็นยิงเวทย์ใส่มอนแทน)
...โลกนี้ไม่มีอะไรยั่งยืน เกราะSolidAuraที่กันโจมตีได้เพียง 7 ครั้ง ก็โดนมอนสเตอร์ที่อยู่โดยรอบรุมโจมตีจนแตกภายในระยะเวลาอันสั้น...
แม้แต่ Vates ก็ไม่สามารถฮิลช่วยชีวิตของ SwordMan ที่ห้าวหาญ ได้ทัน ซึ่งแม้จะโดนมอนจำนวนมากรุมโจมตี เท้าของเขาก็ไม่ขยับหนีศัตรูแม้แต่น้อย มีเพียงดาบของเขาที่กวัดแกว่งฟาดฟันใส่มอนอย่างบ้าคลั่ง
ฟู่........
ฝูงมอนสเตอร์ที่บ้าคลั่งต่างกระจายตัวไปกันคนละทิศละทาง...
สิ่งที่เหลืออยุ่คือ ร่างอันไร้วิญญาณของผู้ห้าวหาญ...
Vates : (ทำการชุบชีวิต นำดวงวิญญาณของผู้ห้าวหาญกลับมา)
Sorcerer : (บัพSolidAura+MagicShield)
...................................
SwordMan : (ยังคงตั้งหน้าตั้งตาวิ่งเข้าไปฟันกลุ่มมอนสเตอร์)
Sorcerer : นายคับ ถ้าจะให้เราช่วยยิง ก็วิ่งหน่อยคับ เราจะได้ยิงได้ ถ้านายยืนอยู่กับที่ โดนมอนรุม เราก็ต้องคอยบัพกันให้นาย ไม่มีเวลายิงให้คับ
SwordMan : นายยิงมอนได้แค่ทีละ 700-800มอนมันไม่ตาย เราต้องฟันด้วย
Vates : งั้นนายก็ตายบ่อยสิ
...การเก็บเลเวลก็ยังคงดำเนินต่อไป...
SwordMan : นาย ยิงให้ได้ทีละ 800+ ตลอดสิ จะได้ยิงมอนทีเดียวตาย (เขาพูดกับSorcererที่ทำหน้าที่ในการยิงเวทย์)
Sorcerer : - -* เวทย์มันแกว่งน่ะคับ...
...เวลานับตั้งแต่ผมเข้าเกมก็ผ่ามมาราวๆ 20 นาทีได้ เหตุการ์ณเดิมที่ผ่านมาก็ได้กลับมาเกิดอีกครั้ง...
SwordMan ผู้ห้าวหาญ แต่โ** ก็ได้ทำการลากมอนจำนวนมาก มายืนปักหลักฟันอย่างไม่คิดถึงชีวิต
เหตุการ์ณ เหมือนที่เพิ่งผ่านมาไม่กี่นาทีนี้
ร่างของผู้ห้าวหาญ นอนจมอยู่กับพื้น แต่คราวนี้ เขาปฎิเสธการชุบชีวิตจาก Vates ...
วิญญาณผู้กล้ากลับสู่เมือง IronSouth พร้อมกับที่ Vates และผม ออกจากการสิงสู่...
และแล้ว SwordMan ผู้กล้าก็วิ่งหายลับไป...
