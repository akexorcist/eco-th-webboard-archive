วิธีใช้มันจะยุ่งยากนิสๆนะเพราะผมก็ใช้.Dllไม่ได้
เอางี้สอนให้เลยละกันอันดับแรกสร้างโฟเดอร์ใหม่อีก1
2.นำไอตัวexeไปวางไว้ในโฟเดอร์นัน
3.พอวางเสร็จมันจะยังใช้ไม่ได้มันจะร้องหาตัวควบคุมระบบให้ทำตามนี้
3.1 ไปที่โฟเดอร์ตัวเกมของจริงอะ(ไม่ใช่โปรexeนะ)
3.2 ก๊อปพวกระบบต่างๆมาไม่รวมไอคอน กะตัวเข้าเกมของจริง
3.3 นำมาว่างไว้ในโฟเดอร์ที่สร้างใหม่ที่ว่างตัวexeตอนแรกอะ
4.กดเล่นเข้าเกมตามบายจะกี่จอกะกดไป


*ถ้ายังไม่ได้ลองรีสตาทเครื่องดู
*ถ้าเปิดexeก่อนจะไปสามารถเปิดตัวจริงได้เพราะงันให้เปิดตัวจริงก่อนจึงค่อยเปิดexe
*เวลามีอัพแพชอะให้ลบระบบต่างๆตัวเก่าทิ้งแล้วทำตามขอ3ใหม่อีกรอบ
