ถ้าตอนช่วง early game (เลเวล 1 นั่นแหละ)-> mid game (เลเวลประมาณ 50) ยามาบุกิ ไม่ก็ โมโม จะโอเคครับ เพราะมันฮีลได้ ทำให้ไม่ต้องเปลืองยา ถ้าเป็นยามาบุกิจะัมี buff+ Matk ด้วย

แต่พอ Late game (เลเวล 50 up) เนโกะจะตัวไหนก็เอาไปด้วยไม่ได้แล้วล่ะครับ เพราะมอนแต่ละตัวชอบเวทหมู่โคตรๆ แถมบางตัวชอบเล็งตีเนโกะก่อนตีคนเล่นอีกต่างหาก แล้วเนโกะยังอัพ def ได้สุดแค่ 18 อีกด้วย(ถ้าไม่ล้มนะ) ทนพลังโจมตีมอนระดับ 50+ ไม่ไหวแน่ๆครับ
