Intro

พวกเราพรากจากกันตั้งแต่เมื่อใดกันนะ ? ...
ทำไมกัน ...
เราน่ะ ...
เป็น “พี่น้อง” กันไม่ใช่หรือ ?

...
...

“อีมิลลลล - ล ! อีมิลลล !!” เสียงแหลมสูงตะโกนเรียกคนหลับอุตุในผ้าห่ม

“ไอ้คนขี้เซา !!!” พรึ่บบ - บบ !! .. สะบัดผ้าห่มขึ้น ทำให้เจ้านายตกล้มครืนกับพื้น ตามมาด้วยเสียงหัวเราะจากสัตว์เลี้ยงคู่ใจของเขา “ฮ่าฮ่าฮ่า ! สมน้ำหน้า เจ้าบ้าอีมิลเอ้ยย !”

“ยัยแมวเถื่อน อูย ... เธอทำบ้าอะไรเนี่ย วันนี้วันหยุดนะ !!” อีมิลยันตัวให้นั่งลง แล้วหันไปโวยวายกับวิญญาณแมวน้อยสีชมพูที่กำลังทำหน้าเอือมๆ ..

“โง่เด็ดๆ หรือโง่มากๆ เนี่ย ? หา ! วันนี้นายนัดกับมาช่าไว้ไม่ใช่หรือไง !!!” โมโมะโผเข้ามาตบหน้าเสื่อมๆ ของอีมิลทีหนึ่ง เพื่อเรียกความจำสั้นๆ ของนายเอ๋อเหร๋อนี้กลับคืนมา

“จริงดิ้ !! ... เอ่อ ... แน่ใจเรอะ ?” ถามกันไว้ก่อน ยัยแมวป่านี้ยิ่งไม่น่าเชื่อถือ

“ฉันจะโกหกหาซากอะไร ในเมื่อรู้ๆ อยู่ว่านายอดสูขนาดไม่มี Pet Food มาเลี้ยงฉันเนี่ยเหมียว !” ร่ายซะยาว ความจริงก็คือพูดจริงๆไม่ได้โกหกนั่นแหละ โมโมะโมโหกระฟัดกระเฟียด มองดูเจ้านายเซ่อซ่าคนนี้คว้าชุดเก่งที่ไม่ได้ซักมาประมาณ 3 เดือนเข้าไปในห้องน้ำ และออกมาพร้อมชุดเน่าๆ นี้ภายใน 1 นาที ... จะไม่ให้หนักใจได้ไงกันล่ะ ดูสภาพสิ ...


จะไปเดตทั้งทีเนี่ยนะ !!!!


ฉันล่ะเหนื่อยใจกับท่าทีของหมอนี่จริงๆ ... โมโมะลอยตามหลังของอีมิลที่กำลังเดินไปหามาช่าอยู่

“ว่าแต่นายน่ะ ...”

“หือ ?”

“รู้เหรอว่ามาช่านัดนายไว้ที่ไหนน่ะ ?”

“ไม่รู้อะ” ปึด ... เส้นเลือดกระตุก นี่ฉันตายไปแล้ยังมีเส้นเลือดให้ชักกระตุกอยู่เหรอเนี่ย ? ... ไม่อยากจะมองหน้าคนตรงนี้ซะจริงๆ อะไรจะงั่งได้ขนาดนี้เมี้ยว ?! ฉันจะสงสารคนที่หลงผิดมาชอบหมอนี่จริงๆ ...

“ขอโทษนะ ... จะช่วยรู้ตัวสักทีได้มั้ย !!!!” เสียงดังแผดลั่นทำเอาจนฉันกับเจ้าบ้าอีมิลสะดุ้งไปตามๆ กัน ก่อนที่จะค่อยๆหันไปตามต้นเสียง ... มาช่าเด็กสาวผู้มีใจให้อีมิลอยู่เล็กๆ แต่ท่าทางจะรู้ว่าอีมิลเบ๊อะจนไม่สามารถรับรู้ความรู้สึกอะไรเลย หอบแฮ่กๆ อยู่ข้างหลัง เธอตามมาตั้งแต่เมื่อไหร่เนี่ย ? ...

“เหวอ ! มาช่า โทษที กำลังจะไปที่นักอยู่พอดีเลยล่ะ”

“อีตาบ้า !! ชั้นนัดนายไว้ที่ดาวน์ทาวน์ แต่นายกลับเดินไปเมือง Mrog เนี่ยนะ !!?” เฮ้อ ... ไม่ไหว ไม่ไหว .. ฉันล่ะหน่ายกับคู่ขาปาท่องโก๋ที่รู้สึกว่าจะบ๊องตื้นกันทั้งคู่นี่จริงๆ อะไรกัน ? จะรักกันก็ต้องให้แมวช่วยงั้นเหรอ ? รับไม่ได้นะเหมียว !


ฟุดฟิด ฟุดฟิด ... กลิ่นอะไรน่ะ ? ได้กลิ่นมั้ย ?? ...เมี้ยว ฉันสะกิดอีมิลที่กำลังโดนมาช่าแว้ดใส่อยู่ “นี่ๆ ... ได้กลิ่นอะไรมั้ย ?”

“ก็ไม่นิ”

“สงสัยคงจะคิดไปเองมั้ง ... เมี้ยว ..”

“มีอะไรเหรอ โมโมะจัง ?”

“เปล่าหรอกเมี้ยวว ... สงสัยคงจะเบลอไปหน่อยน่ะ” ตามมาด้วยเสียงหัวเราะกลบเกลื่อนของฉันอีกนิดๆ กลิ่นนี้มันอะไรกันนะ สัมผัสได้ถึงอะไรบางอย่าง ...



ม ... โม ... โมโมะ ... ใช่มั้ย ? เมี้ยว .. อยู่ไหนที่ไหนน่ะ ? ....

ประวัติส่วนตัวโดยรวม

ชื่อ : ซิกครอส ไคท์ (SiegX kite)

รูปร่างลักษณะ : ผมชี้ตั้งยุ่งๆ ไม่เป็นทรงสีขมพู เพราะตื่นแล้วไม่หวี(ลุกจากเตียงมาสภาพไหน อยู่สภาพนั้นเลย) ดวงตาสีมรกต สูง 170 ซ.ม.
สวมเสื้อแขนยาวสีน้ำเงินทับเสื้อเชิ้ตสีขาว กางเกงขายาวสีดำ รองเท้าหนัง สวมผ้าพันคอสีแดงเอาไว้ตลอดเวลา

เพศ : ชาย

อายุ : 17 ปี

เผ่าพันธุ์ : อีมิล

อาชีพ : วิซาร์ด

ประวัติ : เป็นพาร์ทเนอร์กับคุโระ ที่คุโระต้องคอยดูแลเสมอๆ นิสัยตรงกันข้ามกับคุโีระแทบจะทุกอย่าง ในขณะที่คุโระ รอบคอบ เป็นผู้ใหญ่และใจเย็น ซิกครอสจะซุ่มซ่าม ไม่คิดหน้าคิดหลัง เอาความรู้สึกเข้าว่า ทำให้คุโระต้องเหนื่อยหน่ายใจประจำ
ได้เจอกับคุโระในโรงเรียนเวทมนตร์ ระหว่างกำลังทดลองเวทมนตร์ใหม่ ก็ได้ไปทำการปลุกวิญญาณแมวขึ้นมา

สกิลนอกเหนือจากอาชีพตัวเอง : สกิลทำอาหาร Lv.99 ต่อให้ซุ่มซ่ามแค่ไหน แต่พออยู่ในครัวแล้วกลายเป็นยอดฝีมือ

เพิ่มเติมอื่นๆ : เป็นคนอารมณ์ดี ชอบยิ้มตลอดเวลา เฮฮาร่าเริงไม่คิดมาก ซื่อๆ จนคนอื่นคิดว่าซื่อไม่พอ มันต้องบื้อด้วยแหงมๆ


ป.ล.ตอบแคปคุง ผมก็ตัวละครโทนนี้ประจำแหละ ฮาๆ มันเป็นสีตัวละครผมในทาโกะน่ะ จริงๆ เป็นไททาเนีย(เพราะตาสีเขียว) แต่ช่วงนี้นิยมอีมิลไงไม่รู้

สกิลนอกเหนือจากอาชีพตัวเอง : เป็นสายแบคแพค แต่มีสกิลการต่อสู้ที่ทัดเทียมกับสายไฟท์เตอร์ มีสกิลเฉพาะตัวดังนี้

-Heartbreaker ปาค้อนใส่ศัตรู ความรุนแรงสูงแถมทำให้มึนได้


เพิ่มเติมอื่นๆ : มีนิสัยชอบดื่มเหล้านอกเวลางาน แล้วมานอนเมาที่บ้านมาช่าเสมอๆ แต่โดยรวมแล้วเป็นคนที่ใจกว้าง ไม่ค่อยคิดมาก ผลงานการสร้างอาวุธของเธอนั้นอยู่ในระดับพอใช้ได้เท่านั้นเนื่องจากเธอเป็นคนแรงเยอะ เลยเผลอทำอาวุธพังไปบ้าง

ชื่อ : Mery Cross Rosenberg [Mery C Rosenberg]
รูปร่างลักษณะ : ผมยาวรวมหลัง(ทรงManager)สีไททาเนียไลท์ ตาสีฟ้าน้ำทะเลและมีกางเขนแดงใต้ตาซ้าย(ตามอวัต)
เพศ : ญ เด่ะทั่น
อายุ : เพราะเป็นไททาเนียเลยมีอายุเกิน100ปี (ราวๆ119ปี)
เผ่าพันธุ์ : ไททาเนีย
อาชีพ : ไนท์

ประวัติ : นักรบพเนจรที่ออกตามหาความจำของตัวเอง(ความจำได้หายไปหลังสงคราม3โลก เพราะใช้พลังงานมากเกินขีดจำกัด) แล้วพบกับอันสึที่สิงอยู่ในโถในบ้านหลังหนึ่ง แล้วก็รับเลี้ยงอันสึตั้งแต่นั้นมา

สกิลนอกเหนือจากอาชีพตัวเอง : Crushing Spiral - ทะลวงเป้าหมาย5ครั้งติดต่อกัน(จะเป็นการฟันหรือการแทงก็ได้)และสามารถทะลวงทะลุเกราะหรือการป้องกันของเป้าหมายได้ เวลาโจมตีจะเห็นโจมตีครั้งเดียว เพราะเวลาโจมตีมันจะเร็วมากจนมองไม่ทัน เป็นท่าโจมตีที่แรงที่สุดเท่าที่มี
Tornado Fang - พุ่งตัวแทงหอกออกไปข้างหน้า ขณะแทงจะมีคลื่นลมหมุนอยู่รอบๆปลายหอกอยู่ด้วย
Sakura Wall - ท่าป้องกันเพียงหนึ่งเดียว จะเป็นการสร้างดอกซากุระเวทย์มนต์ขนาดใหญ่ขึ้นมาป้องกันการโจมตีจากศัตรู
Sakura Rain - ท่าต่อเนื่องจากSakura Wall จะเป็นการใช้อาวุธแทงไปที่ดอกซากุระที่สร้างขึ้นมาเพื่อให้เกิด เกล็ดซากุระพุ่งออกไปโจมตีเป้าหมายที่อยู่ด้านหน้าทั้งหมด
Slash of Sakura - ท่าต่อเนื่องจาก Sakura Rain จะเป็นการฟันดอกซากุระให้แตกแล้วเกิดคมดาบขนาดใหญ่พุ่งเข้าไปฟันศัตรูที่อยู่ตรงหน้าให้สิ้นซาก
Soul Destroyer - ฟันหอก(หรือเรเปีย)เพื่อให้เกิดคลื่นสุญญากาศพุ่งออกไปโจมตีศัตรู เป็นท่าระยะไกลและท่าหากิน เพราะใช้ง่าย
เพิ่มเติมอื่นๆ : มีอาวุธ2อย่างคือ หอกBrionac(หอกแห่งแสง) กับดาบเรเปียRaybirth(ดาบแห่งแสง)
