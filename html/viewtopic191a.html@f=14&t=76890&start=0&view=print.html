ขอตั้งหน่อยนะครับเนื่องจากช่วงนี้มีกระทู้ที่ถามอะไรซ้ำๆ เดิมๆ และมีอยู่ในไกด์เยอะมากไม่ว่าจะเป็น "ขอแนวทางสเตตัสอาชีพ____สายxxxหน่อย" "สกิลxxx" "อาชีพxxxเวลxxเวลที่ไหนดี?"
ผู้เล่นเก่าหลายๆคนเองก็คงไม่ชอบที่จะต้องมานั่งตอบคำถามเดิมๆ
""ทั้งๆที่มีไกด์ให้เข้าไปอ่านอยู่แล้ว เขียนข้อมูลต่างๆเอาไว้เรียบร้อย""
และผู้เล่นใหม่ก็อยากได้คำตอบไวๆทันใจ
สิ่งที่อยากขอความร่วมมือจากผู้เล่นใหม่ทุกท่านก็คือ
-เปิดดูไกด์เสียว่ามีไกด์อะไรที่ยังไม่ตาย(มีคนถาม-ตอบกันอยู่เรื่อยๆ)
-เปิดดูFAQ(ไกด์ส่วนใหญ่จะมีFAQและมีคำที่ช่วยในการค้นหาข้อมูลอยู่แล้วครับ)
-หาไม่เจอ? โพสถามในไกด์เลยครับ
สิ่งที่อยากขอความร่วมมือจากผู้เล่นเก่าคือ
-เวลาโพสตอบ ขอให้เน้นย้ำผู้ถามให้ไปถามในไกด์แทน ในคราวหน้า
-ถ้าใครเหลืออด โยนลิงค์กระทู้ไกด์อาชีพนั้นๆทิ้งไว้สั้นๆก็โอเคแล้วครับ
____
เพียงแค่ผู้เล่นใหม่โพสถามในไกด์ให้เรียบร้อย
สำหรับผู้เล่นใหม่
-เมื่อคุณเข้าไปในไกด์ จะมีข้อมูลพื้นฐาน เทคนิคสกิล สกิลแนะนำ การอัพสเตตัสเบื้องต้น/สเตตัสตอนเลเวลสูง แหล่งเก็บเลเวล
-FAQจะมีคำถามที่คนส่วนใหญ่สงสัย และต้องการคำตอบ จึงประหยัดเวลาได้มาก ถ้าคุณสงสัยในสิ่งที่ชาวบ้านเขาสงสัยกัน
-ไม่มีในไกด์?ไม่เคยมีใครถามเลย! เมื่อคุณถาม และมีคำตอบ จะง่ายต่อการหาข้อมูลในไกด์(เนื่องจากหลายๆกระทู้ทำลิงค์ไปที่คำตอบต่างๆ) กลายเป็นว่าคุณ ที่เป็นผู้ถาม มีส่วนในการทำให้ไกด์สมบูรณ์มากขึ้น!
สำหรับผู้เล่นเก่า
-ลดคำถามที่ถูกถามซ้ำๆ
-ไม่ต้องเปิดกระทู้ไล่ตอบทีละกระทู้ให้เสียเวลา คำถามมากองๆอยู่ในไกด์กระทู้เดียวเลย
ทำให้สะดวกแก่การโพสตอบของผู้เล่นเก่า
และที่สำคัญคือ
ไม่รกบอร์ด!

**ถ้าเป็นคำถามที่เคยมีคนถามอยู่แล้ว คนที่เคยตอบมักจำได้และโควตคำตอบเก่าให้อ่านได้อย่างรวดเร็วแน่นอน

ผมไม่เห้นด้วยครับ ( ฮาๆ ชอบขัดคนอื่นซะจริง ! ขอโทษค้าบ )

เดี๋ยวก่อนๆไม่เห้นด้วยในบางเรื่อง ...ขอให้เหตุผลไว้หน่อย

สิ่งที่เห็นด้วย
- ให้ศึกษาข้อมูลเองก่อนจะตั้งถาม

สิ่งที่ไม่เห้นด้วยคือ
- ให้ไปถามในไกด์ โดยยึดว่ากระทู้ไกด์เป้นหลัก เพื่อจัดระเบียบและไม่รกบอร์ด !!

ที่ผมไม่เห็นด้วยเพราะว่า !!
1. ไกด์เป็นแค่ของคนในบอร์ดคนนึงหรือกลุ่มนึงทำขึ้นมาเท่านั้น ซึ่งไกด์ก็ถือเป็นกระทุ้หนึ่งของบอร์ด ไม่ใช่เรื่องที่จะต้องผูกมัดว่า ทุกคนต้องเข้าไป ... และคนอื่นก็ย่อมมีสิทธิ์ทำไกด์ขึ้นมาได้เหมือนกัน มองว่าการรณรงค์นี้ จะทำให้ ความคิดเห้นไม่แตกหลาย แบ่งพรรคพวก ผูกขาดแต่เพียงกลุ่มเดียว(คนทำไกด์ท่านอื่น อาจน้อยใจได้) และการที่คนถามต้องเข้าไปถามหลายๆไกด์ ซึ่งต่างๆคน ขอบอกว่า สับสน กุจะต้องตั้งในไกด์ของใครดี จะถามเหมือนกันดีไหม ...

2. จุดประสงค์ที่ว่าเพื่อไม่รกบอร์ดนั้น มันตกไปแล้ว เพราะ .. บอร์ดนี้ ได้ซอยย่อยหมวดได้ระเอียดโคตร ทำให้หมวด fighter นี้กระทู้แทบไม่ขึ้นแล้ว จึงไม่จำเป็นต้องลิ้งไปอยู่ในกระทุ้ไกด์เดียวอีกต่อไป และ การให้มาตั้งกระทู้ใหม่ จะช่วยให้มีประเด็นใหม่มาบ้าง ไม่งั้นเงียบแน่ (แม้ว่าจะประเด็นซ้ำ แต่การถามซ้ำ จะทำได้เกิดกระบวนพัฒนา update อยู่บ่อยๆ ซึ่งถือว่าดี ) รวมๆแล้วยังไม่มีปัญหาถึงขั้นต้องบอกว่า รก แนวโน้มก้น้อย....เดี๋ยวค่อยว่ากันในอนาคต แต่ถ้ารวมๆปัญหามีแน่ๆ การหาข้อมูลมันยากกว่า (รึมันมี option ค้นเฉพาะในกระทู้นั้นอย่างเดียวได้ล่ะนี่ บอกหน่อย ไม่รุ้จริงๆ)

3. การหาข้อมูลในไกด์นั้น ไม่ใช่ว่าจะหาง่ายๆ เพราะ ข้อมูลกระจัดกระจายหลายหน้ามากๆ อ่านจนตาลาย นอกจากคนทำไกด์จะใจดี update บ่อยๆ

4. ประเด้นที่ถูกตอบในไกด์นั้นไม่ใช่ของเจ้าของไกด์เพียงคนเดียว .... อย่างที่ว่าไว้ในข้อแรก เหมือนจะเป้นการผูดมัดสิทธิ์ไว้แค่คนกลุ่มเดียว และสนับสนุนการแตกแยก - -

5. ความพอใจของแต่ละคนไม่เท่ากัน

ซึ่งผุ้เล่นเก่าๆ ที่ขี้เกียจตอบ ก้มีทางเลือกว่า จะไม่ตอบก็ได้ หรือแค่ส่ง link เก่าๆ ไปให้อย่างสันติก็ได้นี่

ซึ่งเกมส์นี้ก็นานแล้ว ในแง่การค้นข้อมุลมากๆ ถามเลยจะง่ายกว่า แต่ก็เห้นด้วย เรื่องรณรงค์ให้หาเองก่อนถามนะ..

2. จุดประสงค์ที่ว่าเพื่อไม่รกบอร์ดนั้น มันตกไปแล้ว...
อันนี้ยอมรับว่าจริงครับ มันก็ไม่รกบอร์ดอะไรขนาดนั้น เอาจริงๆผมรู้สึกว่ามันรกตารกใจคนตอบมากกว่ามั้งครับที่มีกระทู้แนวเดียวกัน ถามผุดออกมาเรื่อยๆ โดยที่เรายังตอบกันเหมือนเดิม เช่น สกิลXXXต้องมีเงื่อนไขอะไรบ้าง? คิดค่าอะไรถ้าสวมไ้อเท็มนี้ตอนใช้สกิลนี้? สกิลที่แอสสายมีดสายสนับอัพมีอะไรบ้าง? กันเนอร์สายagiอัพสเตตัสเท่าไหร่ ฯลฯ
3. การหาข้อมูลในไกด์นั้น ไม่ใช่ว่าจะหาง่ายๆ เพราะ ข้อมูลกระจัดกระจายหลายหน้ามากๆ อ่านจนตาลาย นอกจากคนทำไกด์จะใจดี update บ่อยๆ

ที่ผมออกมาขอความร่วมมือผู้เล่นเพราะเหตุผลที่ผมคิดๆข้างต้นแหละครับ ถึงคิดๆดูบางข้อจะออกไร้สาระไปก็เถอะ
แต่ผมรู้สึกว่าถ้าเข้าไปอ่านไกด์แล้ว คำถามหลายๆคำถาม คงจะไม่ต้องถามอีกต่อไป(อย่างเช่นแนวทางอัพสเตตัส อัพสกิล) FAQเกี่ยวกับไอเท็มที่เกี่ยวข้องกับสกิล ซึ่งนอกจากช่วยให้คนหลายๆคนที่เบื่อกับการตอบคำถามแนวเดิมๆ ตอบคำถามน้อยลง และ "ไม่ต้องเปิดกระทู้ไล่ตอบทีละกระทู้ให้เสียเวลา คำถามมากองๆอยู่ในไกด์กระทู้เดียวเลย
ทำให้สะดวกแก่การโพสตอบของผู้เล่นเก่า" ดังที่กล่าวไว้ครับ
ส่วนนึงก็เป็นประโยชน์ต่อตัวผู้เล่นใหม่เองด้วย
ขอบคุณสำหรับเหตุผลที่ยกมาค้านครับ ผมจะได้มองในมุมอื่นบ้าง
ถ้ามีใครคิดว่าสมควร หรือไม่สมควร ก็ขอให้โพสแนะนำ แสดงความเห็นต่อการที่ผู้เล่นใหม่ตั้งกระทู้แบบนี้ และช่วยกันหาทางออกที่จะทำให้ผู้เล่นใหม่ได้ข้อมูลเร็วขึ้น+คนโพสตอบไม่ต้องมาตอบคำถามซ้ำๆให้เบื่อ หรือรู้สึกว่า พวกเราช่วยกันเขียนไกด์ให้คนศึกษาทำไมในเมื่อไม่คิดจะอ่านกันเลย

ถ้ามองแบบนั้น กระทู้ไกด์ก็คือห้องเรียนไงล่ะ อาจมีหลายห้อง น่าจะถูกกว่านะ

-พูดถึงกระทู้ขยะ จำพวก "ขอแนวทางสเตตัสอาชีพ____สายxxxหน่อย" "สกิลxxx" "อาชีพxxxเวลxxเวลที่ไหนดี?" "
(บางคำถามที่ยกมาผมว่าบางอันก็ไม่ขยะนะ แต่ตัวอย่างเฉยๆ )

คือ... ผุ้เล่นเก่าเลือกที่จะไม่ตอบก็ได้นิครับ รึจะแค่โยนlinkไปก็ได้ ไม่ต้องเห็นว่ารกหูรกตาขนาดนั้น ใจเย็นๆ บอร์ดเป็นของทุกคน อาจจะหงุดหงิดที่เห้นเด็กน้อย เอาแต่ขอๆๆ แต่ขอให้ทำใจ คุณมีสิทธิ์ที่จะไม่ตอบเช่นกัน และปล่อยให้เด็กน้อย งงต่อไปได้ ซึ่ง มันเป้นเรื่องที่ช่วยไม่ได้ เราไม่สามารถช่วยเขาได้ หากเข้าไม่ช่วยเหลือด้วยตัวเอง เขาได้รับกรรมของเขาแล้ว ( เราไม่ตอบ เขาไม่หา เขาก็โง่ต่อไป ซึ่งตรงนี้ หากเขาคิดเป้น จะเป้นตัวกระตุ้นให้เขาวิ่งเข้าหาไกด์เอง) ไม่จำเป้นต้องหงุดหงิดไป
