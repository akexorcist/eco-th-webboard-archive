goldsnake เขียน:เอาที่ตอบในกระทู้อื่นมาให้ดูครับ จะได้ไม่ต้องตอบหลายรอบ

goldsnake เขียน:สวัสดีคับ เห็นว่ายังมีที่ไม่เคลียอีกเยอะพอดีผมเป้นคนเลี้ยงหนอนเหมือนกัน เลี้ยงตัวเล็กอยู่ครับ พยายามจะพัฒนาให้มันเต็ม30ครั้งอยู่เนื่องจากอ่านจากเวปญี่ป่นมาเลยจะเอา ข้อมูลมาให้ดูกันครับ

- การเพิ่มค่าAgiอย่างเดียวหลังจากพัฒนาไม่มีผลกับการที่หนอนเร็วขึ้นมากเท่าเพิ่มทุกค่า
- ความเร็วสูงสุดของหนอนอยู่ที่ 407 mass(ก้าว) ต่อ 100 วินาที
- สูตรคำนวนความเร็วคือ
speed=210 + (จำนวนstatที่เพิ่ม)x3/4 + (จำนวนครั้งในการพัฒนา)x8/3

คำนวนยังไง ดูจากตัวอย่างนะครับ

1.คุณเลี้ยงหนอนตัวเล็กแล้วพัฒนาไป1รอบ โดยรอบแรกมีstatที่เพิ่มตัวเดียวคือ agi+1(ดูได้จากตอนคุยกับ god of petแล้วเขาบอกว่าเพื่มอะไรบ้าง) นั่นคือ speed = 210 + (1)*3/4 + (1)*8/3 ก็จะได้ความเร็ว คือ 214(ปัดเศษขึ้น)

2.คุณเลี้ยงหนอนแบบตามยถากรรมพัฒนา30รอบ แต่รอบนึงเต็มแค่2ค่า ก้จะได้ speed = 210 + 60*3/4 + 30*8/3 ก็จะได้ความเร็ว คือ 335

3.คุณเลี้ยงหนอนแบบบ้าพลัง30รอบ รอบนึงได้ค่าเพิ่มรอบละ6ค่า นั่นคือ speed = 210 + 180*3/4 + 30*8/3 ก็จะได้ความเร็ว คือ 425 แต่ความเร็วสูงสุดคือ407 เลยได้407

สรุป
- ต้องเลี้ยงหนอนตัวเล็ก Puchi crawler เท่านั้น ถึงจะทำให้ Ride crawler เร็วขึ้น
- หนอนจะเร็วได้มากสุดคือ ประมาณ2เท่าของหนอนที่ช้าสุด
- ถ้าอยากได้ความเร็วสูงสุด ถ้าคุณพัฒนา30รอบ ไม่จำเป็นต้องอัพstatให้เต็มทุกอันก่อนพัฒนาในแต่ละรอบ เฉลี่ยอยู่ที 5.2 พ็อนต์ต่อรอบก้พอ หรือรวมกันทั้งหมดอยู่ที่ 156 พ็อนต์
- ความเร็วการเดินปรกติของตัวละครอยู่ที่ 380 ก้าว ต่อ100วินาที
- ความเร็วการเดินของมังกรแดง(เดินข้างนอกดัน) อยู่ที่ 429 ก้าวต่อ100วินาที

ฉนั้นถ้าหนอนได้ความเร็วสูงสุดมาคือ407ก้าวต่อวินาที ก็จะเดินเร็วกว่าคนแล้ว แล้วเร้วน้อยกว่ามังกรแดงนิดหน่อย
