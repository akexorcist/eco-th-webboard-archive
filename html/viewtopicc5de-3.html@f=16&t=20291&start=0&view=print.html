มิต เขียน:หามากขึ้นอะขอรับ GM มายืนยันและอะ ขอรับ

เคยอ่านเจอถ้าเจออีกจาเอามาลงให้นะขอรับ


เคยเห็นเหมือนกันค่ะ ที่จีเอ็มมาโพสต์ พออ่านปุ๊บ เราเลยไปอัพมานี้แหละคะ

แต่พอใช้จริง มันไม่ใช่หนะสิคะ เปอร์เซ็นเท่าเดิมค่ะ แม้จะมีสกิล analysis ก็เถอะ

จากการไปตีดอกไม้ดำค่ะ ไม่ได้จะมากขึ้นกว่าเดิมเลย เท่าๆเดิมด้วยซ้ำ

แถมเสียเวลามาร่าย ทีละต้นๆ อีก เลยไปเอาออกแล้วค่ะ จากที่ใช้มา ด้วยประสบการณ์ตัวเอง นะคะ เห็นเหมือนความเห็นนี้อ่าคะ

มีผลให้คนที่ไม่มีสกิล plant knowledge สามารถตีของจากเป้าหมายแล้วตกของเหมือนเรา ครับ


เพราะลองสิงเพื่อนที่เป็นนักธนู แล้วเราร่ายก่อน เสร็จแล้ว ให้เพื่อนนักธนูตี ปรากฎว่า ดร๊อปออกมา เป็นกลีบดอกไม้ค่ะ

แสดงว่าสกิลนั้น ใช้ประโยชน์เพื่อให้คนที่ไม่มีสกิลดร๊อปของ มีโอกาสของตกเหมือนเราค่ะ

เพราะกลีบดอกไม้ ไม่ตกในอาชีพอื่น นอกจากฟาร์มเมอร์ ด้วยประการชินี้ จึงไปเอาออก

นี้เป็นความรู้สึกของเรานะคะ ว่าเป็นเช่นนั้น ไม่คอนเฟริมว่าชัว 100 แต่มั้นใจว่า ถ้าเพิ่ม % ดร๊อปมากกว่า knowledge จริงๆ

นี้คงเป็นบัคแล้วค่ะ ที่มานเพิ่มน้อยมากๆ จนแทบไม่เห็นความต่าง ... แต่คิดว่าสกิลนี้ คงตั้งใจทำให้เป็นแบบนี้มากกว่านะ

ตอนนี้ สกิลที่เราอัพคือ ทำยา กะโกอ่าคะ ไม่รู้จะอัพอะไรต่อดี อยากได้ระเบิดงิ แต่ใช้เวลจ๊อบเยอะโหด - -
