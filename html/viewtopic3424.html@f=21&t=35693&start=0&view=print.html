แต่งล้อเลียนเกรียนอิอิคงม่ายว่านะเอาฮาลูกด้วย[เหอๆ]อะไปชมกานดีกว่าอ่านเอาฮาหนออย่าคิดไปไกล
"วันนี้ได้เป็นวันจบปีการศึกษาของนักเรียนทุกคนแล้วนะครับ"ครูใหญ่ประกาศทางไมค์แรงสูง
"เฮ้ยๆๆ!! โห!! ว้าว!!"เสียงของนักเรียนเกรียนทั้งหลายได้พูดเป็นเสียงวุ่นวายทั้งโรงเรียน
"ส่วนผู้ที่ได้คะแนนในการเกรียนมากที่สุดครั้งนี้คือ ด.ช.TatatabeAngle ครับยินดีด้วย"ครูใหญ่ประกาศด้วยไมค์แรงสูงอีกครั้ง
"แล้วจะได้อะไรหรอครับคุณครูใหญ่"TatatabeAngle กล่าวถามครูใหญ่
"อือหนูจะได้รับไอเทมดังนี้"คุณครูตอบ


"พอใจมะจ้ะ"ครูใหญ่ถาม TatatabeAngle
"พอใจมากครับ ครู"TatatabeAngle ตอบ
"ส่วนที่อื่นๆจะได้รับเกรียนติบัตรทุกคนนะครับยกเว้นบัตรการเรียนรู้เรื่องการตัดผมที่จะมอบให้ที่หนึ่งแทนตบมือให้ TatatabeAngle หน่อยเร็ว~!!"
"ตูม!!ต้าบ!!ตบ!!เปรี้ยบ!!ปัง!!"เสียงอาวุธของนักเรียนแสนเกรียนทั้งหลายพุ่งตรงไปที่ TatatabeAngle จึงทำให้ TatatabeAngle ไปณที่

ขนาดตายยังไม่เว้นต้องไปที่ศาลาเกรียนเขาสร้างมาไว้เพื่อเกรียนหรือเปล่านั้นไม่ทราบต้องติดตามตอนต่อไป
- - ฮามะผมว่ามุขฟืด แล้วจะทำอย่างไรจะหาบุคคลเกรียนมาเพิ่มล่ะกานอิอิ แล้วจะมาลงอาทิตย์ล่ะครั้งนะครับ เป็นรายสปดาห์
