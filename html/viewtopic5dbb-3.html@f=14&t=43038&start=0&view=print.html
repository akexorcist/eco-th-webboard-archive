ใครฟันธงได้บ้างครับ ว่าการคิด damage จริงๆ จากการใช้สกิล คิดหัก DEF อย่างไรกันแน่

สมมุติ ATK เข้าไป 1000 ด้วยสกิลที่ Damage 200% คนโดน DEF 50-100

1. คิดเป็น (1000*0.5)-100 = 400 แล้วค่อยมาคำนวน 200% = 800

2. คิดเป็น 1000 * 200% ก่อน = 2000 แล้วมาหัก (2000*0.5)-100 = 900

ปล.ใครช่องตัวละครเหลือ ทำตัว DEX ล้วนไป Blow ทดสอบมาที :twisted:
