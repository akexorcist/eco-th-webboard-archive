3.หา ขนไก่ ตกจาก cocko map farest highway, หา barch จากต้นไม้

แบบละเอียด แบบว่าพึ่งเวล1เลย
- คุยกะหมายเลข 5 สีน้ำเงิน (ไม่แน่ใจนะ แต่ถ้าคุยแล้วมันมีอธิบายถึงวิธีเข้าUptown ล่ะ ก็ใช่เลย ถ้าไม่ใช่หมายเลข 5 ก็คุยกะnpcทุกตัวเดี๋ยวก็เจอเองอ่ะ) ถ้าไม่คุยกะคนนี้ก่อน แล้วไปคุยกะป้าสูงศักดิ์ จะไม่ได้บัตร
- ไปที่ร้านเหล้า ใกล้ๆ NPC เลข8 เข้าไปแล้วคุยเพื่อขอทำเควส (เควสอะไรก็ได้ ถ้าเคยทำเควสแล้วก็ไม่ต้องทำ)แนะนำเลือกเควส กำจัด purupuruตะวันออกนะ เพราะเดินออกร้านเหล้าแล้วขึ้นบรรไดก็ออกไปเมืองตะวันออกได้เลย
- ตีpurupuruครบ 5 ตัว ยังไม่ต้องเข้าdown town ให้ไปเดินตามทางไปmap ตะวันออกอันที่2-3 น่าจะชื่อ fareast highway เพื่อตีไก่ cocko เอาขนไก่ แล้วไปตีต้นไม้ ต้นที่ลำต้นตรงๆข้างบนเป็นพุ่มกลมๆอ่ะ เอา branch มา(ไม่ต้องตีแค่วิ่งเก็บ หรือขอคนอื่นก็ได้)
- ถ้า int ยังไม่ถึง10ให้เก็บเวลเพื่ออัพ intให้ถึง10ก่อน
-กลับไปที่ร้านเหล้าส่งเควส จะได้ไม้ปลายแหลมมา เก็บไว้ก็ได้เพราะถ้าไม่ได้เป็น noviceแล้วจะใช้ ดาบที่ได้มาตอนแรกไม่ได้แล้ว เผื่อใช้ตอนลูกธนูหมด
-ไปคุยกะป้าสูงศักดิ์เลข6สีนำเงิน ป้าจะให้บัตรเข้าuptown มา
- เข้า uptowng เดินไปที่ตึกที่อยู่ทางเหนือ เข้าไปเลือกชั้นสอง แล้วเดินไปที่ห้องที่อยู่ทางเหนือ เจอ archer master ก็คุยไปเรื่อยๆเค้าจะให้ทำลูกธนู(ขนไก่ crocko กับ branch ใช้ทำลูกธนู)
-ไป downtown ไปร้านที่รับทำลูกธนูจำไม่ได้แต่อยู่1ใน4ทิศแหละ เหนือ ใต้ ออก ตก น่าจะ ออกนะ หรือไม่ก็ซื้อลูกธนูจากคน หรือ ไม่ก็ขอ หรือไม่ก็ให้ คนที่เล่น archer ทำให้
