ผลสกิลคือช่วยให้เป้าหมายนั้นๆ ดรอบของดีขึ้น (พูดง่ายๆคือตกของแรร์ขึ้นนั่นเอง)

การใช้งานคือกดสกิลใส่เป้าหมายครับ
การเพิ่มอัตราดรอบไม่แน่นอน ข้อมูลคลุมเครือ
สกิลยิ่งเลเวลมากก็เพิ่มอัตราดรอบมากขึ้น(มั้ง) ไม่ก็ร่ายเร็วขึ้น จำไม่ได้

แต่โดยรวม สกิล analysis ทั้งหลายไม่น่าอัพครับ
เพราะใช้ยาก และเห็นผลไม่แน่นอน

แต่ที่แน่ๆ ถ้าร่ายสกิล tree analysis ใส่ fallen tree แล้วท่านอื่นๆ ที่ไม่ใช่ชาวนามาตี จะมีโอกาสได้ strong wood เหมือน ชาวนาที่มี tree knowledge ตีไม้ท่อนนั้นเอง

สรุปง่ายๆ ถ้าใช้ใส่มอนหรือสิ่งของ แล้วบุคคลท่านอื่นๆมาฆ่า ทุบ มอนหรือ ของชิ้นนั้น จะมีโอกาสได้เหมือน สกิลมีสกิล knowledge

แต่เรื่องดรอปแรร์ ง่ายขึ้นหรือไม่ ไม่สามารถทดสอบได้ เพราะมีหลายปัจจัยที่มีผลกระทบจนไม่สามารถวัดผลที่แน่นอนได้
