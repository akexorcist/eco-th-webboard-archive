นำแสดงโดย
นักแสดงนำฝ่าย เอ่อ ญ มั้ง กายจัง รุดซี่

นักแสดงนำฝ่ายชาย (หรือเปล่า) กิม คาเนชิโร่

ร่วมด้วย อึ๊บ ปอลลีน (นาย/นางร้าย-9-)

อัลเต้ เคนโด้

เล็ก เอลนิโย่

และ เดียว กึมยองยอง

บทสรุปเรื่องราวความรักของพวกเค้าเหล่านี้ จะเป็นเช่นไร เสาร์นี้ ห้ามพลาด!










สนับสนุนโดย : Ring Harvest Moon


เอิ้กๆ ข้างบนนี้เป็นภาพนึกสนุกของพี่เป้ ที่อยากเห็นหนุ่มๆในริงเซ็กซี่เลยเกิดคอนเซ็ปชุดดั่งกล่าวออกมา (นู๋ไม่รู้เรื่องนะเค๊อะ) สำหรับน้องๆพี่ๆในริงคนไหนที่พลาดโอกาส (ก็ระวังตัวกันให้ดีๆ ) อะมะช่าย ยังมีโอกาสหน้าได้ร่วมสนุกกันอีกนะเจ้าค่ะ

สำหรับเพื่อนๆที่แวะมาเยี่ยมชมไม่ทราบว่าใครเป็นใคร บอกใบ้ให้ละกัน ว่ามีดาวประจำเซิฟ และนักทำไกด์บอร์ดรวมอยู่ในนี้ด้วย ใบ้อีกนิดว่าเป็นเจ้าของกระทู้ไกด์อาชีพวิสาจและกระทู้เครื่องประดับ อุ๊บบบ ได้เวลาเผ่นละ ฟิ้ววววววว

ป.ล.ขออภัยที่ไม่ได้แต่งรูป เพราะ - - มันเกินบรรยายเจงๆ
