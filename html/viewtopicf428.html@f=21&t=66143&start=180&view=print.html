"เธอมองเห็นสิ่งนั้นไหม?" หญิงสาวบอกกับเด็กวัยกระเตาะ
"มันคืออะไรคะ?" เด็กหญิงถาม
"มันจะช่วยปกป้องเจ้าจากภัยอันตรายต่างๆ" หญิงผู้นั้นพูด "หากเกิดเรื่องใดขึ้น เจ้าจงมาที่ี่นี่นะ..."

เด็กสาวตื่นจากความฝันที่เกิดขึ้นเมื่อวัยเยาว์ เธอรู้สึกแปลกใจเล็กน้อยที่ฝันแบบนั้น แต่ตอนนี้เธอห่วงเรื่องของเวลามากกว่าสิ่งอื่นใด เธอหลับมาเท่าไหร่กันแล้ว
"นี่มัน เวลา 09.15 pm แล้วอย่างงั้นหรอ" ใช่ เธอหลับเพลินไปหน่อย เธอจึงตื่นมาช้ากว่่าที่เธอตั้งไว้เยอะ เธอรีบแต่งตัวหมายจะไปให้ทัน...

ทันงานที่สำคัญที่สุดในชีวิตของเธอ

"เอ๊ะ! เข็มกลัดหาย" เธอควานหาตามเก้าอี้ ที่นอนเพื่อหาเข็มกลัดอันนี้ แต่เธอก็ไม่พบ
"มันจะหายไปได้ยังไงล่ะเนี่ย" แล้วเธอก็เอามือล้วงกระเป๋ากระโปรงด้านซ้ายของเธอ เธอจึงเจอเข็มกลัด4สีที่เธอต้องการจะหา
"นึกว่าหายซะแล้วนะเนี่ย" ไม่รอช้า เธอจึงรีบติดเข็มกลัด แล้วออกเดินทางไปที่ปราสาทต้องคำสาบ ด้านทิศใต้ของเมืองตะวันออกไกล
' หวังว่าคงทันนะ '
เธอมาถึงทางเข้าปราสาทแล้ว เธอกระหืดกระหอบมานานมากแล้ว แต่แล้วเมื่อเธอ จะเดินเข้าไปข้างในปราสาท เธอรู้สึกเหมือนมีบางสิ่้งจ้องเธออยู่ หญิงสาวเริ่มเงียบ ได้ยินแต่เสียงหัวใจของเธอเต้นดังระรัว ตึกตัก ตึกตัก ตึกตัก ...
"ใครน่ะ!" เธอหันหลังกลับอย่างรวดเร็วพร้อมที่จะต่อสู้ แต่ก็ม่มีใครอยู่ข้างหลังเธอเลยแม้แต่คนเดียว
' แสดงว่ามันต้องรู้แล้วเป็นแน่ ' เธอเริ่มฉุกคิด ' ต้องรีบปลอมตัวซะก่อน ' เธอล้วงไปในกระเป๋าข้างเอวสีม่วงดำ หยิบหน้ากากสีขาวราวกับหิมะ และมีสีแดงป้ายพองาม ให้ดูมีลวดลาย
