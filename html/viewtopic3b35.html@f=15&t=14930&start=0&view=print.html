ไปที่สมาคมเวทย์มนต์ในเมือง Northan Blomnard (ที่รีสกิล) เดินเข้าไปที่วาร์ปด้านในจะมี Event ที่ตัวละครรู้สึกอะไรบางอย่าง ให้เลือกตอบ"ไป" ตัวละครจะมาโผล่ที่ห้องลับของสมาคม และจะพบกับ "Titania ตกสวรรค์" (ตัวเบ้อเริ่ม) ให้คุยกับเขา

หลังจากนี้เราจะสามารถเข้าออกห้องลับของสมาคมได้แล้ว

หลังจากนั้นให้เราไปคุยกับ"ท่านพ่อมด"ในห้องรีสกิล จากนั้นให้นำดอกไม้ไปให้ไททาเนียในห้องลับดู แล้วกลับไปคุยกับท่านพ่อมดอีกครั้ง

เมื่อคุยกับท่านพ่อมดครั้งที่ 2 แล้ว ให้เราไปคุยกับไททาเนียอีกครั้ง แล้วไททาเนียจะขายชุดประจำอาชีพให้กับเรา โดยจะขายเฉพาะชุดสำหรับอาชีพของเราเท่านั้น (เช่นถ้า Druid ไปซื้อก็จะซื้อได้เฉพาะชุดของ Druid) * คงจะซื้อได้เฉพาะนักเวทมั้ง
