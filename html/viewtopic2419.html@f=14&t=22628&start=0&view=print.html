แนวทาง(ของผมนะครับ)ในการเล่นอาชีพสาย Sword Man

ถ้าอัพสาย AGI ให้ใส่ AGI ให้ มากกว่า STR หรืออาจจะพอๆกัน ไม่ควรอัพ STR นำ AGI มากๆ เพราะจะทำให้หลบไม่ได้ และจะเก็บเลเวลลำบาก

ถ้าสาย VIT สามารถใส่ STR ให้สูงนำ VITเพื่อให้สามารถเก็บเลเวลได้สะดวก เช่นใส่ VIT 50 ที่เหลือให้ลง STR และอัพDEX ไว้ที่ 40 และเก็บเลเวลด้วยสกิลโจมตีเป็นหลักครับ

Atk Brust - เหมาะสำหรับสาย Str ล้วน
