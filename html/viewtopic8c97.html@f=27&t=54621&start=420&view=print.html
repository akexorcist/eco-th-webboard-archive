ในขณะที่แอสใช้ไม่ได้ และสกิลก็จะไม่เหมือนกันด้วย
โดนการสวิตนั้นจะสามารถนำสกิลของจ๊อบที่เราเป็นก่อนสวิตไปได้ด้วยตามจ๊อบเลเวล
สมมุติว่าผมเป็นแอสจ๊อบ30สวิตไปเป็นคอมมานโดผมก็จะเอาสกิลของแอสไปใช้ตอนเป็น
คอมมานโดได้3สกิล(สกิลที่นำไปได้=Jobตอนนั้น/10โดยปัดเศษทิ้ง )

[จ๊อบของอาชีพที่จะสวิตไป- (จ๊อบเลเวลของอาชีพที่เป็น/5(เศษปัดทิ้ง))]
