ในกระบวนการสายเวทของลาวๆ++ มีไม่กี่สาย รวมถึงสายพระ เน้นวอ vit100 ผสมให้ลงตัว dex 108 เพื่อให้ได้ 800 กระชากวิญญาณและท่า50 ที่เหลือ int หมดจด Mag ไม่ต้องแตะ สายนี้ดีที่สุดในวอ Mixer ไม่ใช่เหล้า ^ ^ แค่มีดีวาย47สายนี้โดนรุ้งก็ไม่ตายแล้ว แต่ ถ้าจะเอาแบบ เทพจนคนจดจำชื่อเราได้แล้วนั้นไซร้ ควรจะมีวิซาดคู่ใจที่มีท่า47ด้วย ฉะนั้นการที่จะเก่งโดยตัวนั้นเองแล้ว หาได้ไม่ทุกสาย โดยไม่มีการใช้ดีวายหรือโอนอิ้น ในสายพระ สา มา รด ได้== ด้วยการเก่งแบบนาน มิใช่โอนอิ้น นั้นหรือคือการ ทำเวทแบบ 0 ด้วย vit 100+ dex ที่ c.spd 750 และ int ที่จะประมาณ 70 แล้วให้ซอ ดีวาย47 ให้ Mdef=0 หรือแค่ 90 แต่ 0 ก็ดีไปอย่างเพราะจะทำให้นักเวทถอดใจและขี้เกียจตีลาว++ ด้วยเหตุฉะนี้และฉะนั้น ในความเก่งของพระก็จะจำกัดแค่พระ หรือ ในทุกอาชีพที่เล่นในทุกวันนี้ ถ้าไม่มีดีวาย47 == ในเหตุฉะนี้และฉะนั้น มันก็มีแค่นี้++ เข้าใจป่าว 5 5 5+ 1.1 ตามข้างบน vit 100 dex 800 เหลือ int เดินดุ่มๆ ชุบและชุบ 1.2 vit 100 dex 750 int 70 ลดบวกเอาเองกะ 47 ให้ได้ mdef 90 หรือ 100 1.3 สายผสมที่แทบจะนำไปประยุกได้ทุกอาชีพของสายเวทย์++ vit 100 dex 800 หรือ 750 ที่เหลือ agi ^ ^ อย่าพึ่งงง โดยอาศัยการโอน int ของซอ สายนี้สมบูรแบบเกิน== แต่ข้อเสียคือการโอน int นั้นสั้นมาก ทำให้การปะทะกันนานๆบางทีอาจตายได้ แต่ในข้อ 1.2 อมตะเวทย์พอควรแต่ไม่สมบูรแบบเท่า 1.3 เลยนั้นไซร้ ในข้อ 1.3 ถ้าอ่านดีๆในทุกอาชีพทุกคนแทบจะเอาไปใช้ได้ในทางที่โคตรเทพได้ทุกอาชีพ ถ้านิทานอีสปเรื่องนี้ ท่านอ่านแล้วไม่เข้าใจนั้นไซร้ ใครเล่า จะพาท่านไปทางส่าวงได้ฦอ ++
