แล้วถามหน่อย เค้าจะรู้มั้ยว่าใครวาด เหมือนกับเวลาคุณเซฟรูปสวยๆมาอ่ะ สนใจมั้ยว่าเป็นใครวาด

โดยเฉพาะอย่างยิ่งรูปโป๊เนี่ย มีใครที่ไหนเค้าใส่ชื่อคนวาดไว้บ้าง หรือคุัณว่ามี เอามาให้ดิชั้นดูหน่อย

ถึงเค้าจะลอกลายมาหรือไม่ มันเป็นสิทธ์ของเค้า ยังไงเสียสุดท้ายแล้วเค้าก็ได้ทำออกมาด้วยตัวเอง

คุณอย่าลืมว่า คุณเองเคยเอารูปของคนอื่นมาลงสี โดยไม่ได้ให้เครดิตเจ้าของเหมือนกัน

ถ้าจะเถียงเชิญ รูปและเรปของคุณยังแปะตราตรึงเอาไว้ในบอร์ดริงของดิชั้น เชิญไปค้นดู

ไม่ทราบว่าคุณเป็นอะไรกับกระทู้นี้นักหนา ดิชั้นรู้สึกเหมือนคุณจงเกลียดจงชัง จขกท. เหลือเกิน

รู้สึกเหมือนตัวเองประเสริฐเลอเลิศเวลาได้เหยียบย่ำคนอื่นหรือไง

ถ้าคนเก่งจริงเค้าไม่มาใส่ใจกับเรื่องเล็กน้อยแค่นี้หรอก

หรือจริงๆแล้วคุณรู้ว่าฝีมือคุณไม่ถึงขั้น จะอวดใครก็ไม่ได้ อย่างน้อยขออวดกะคนที่เพิ่งหัดดีกว่า

ถึงได้ไม่กล้าทำกระทู้รูปของตัวเอง กลัวไม่มีคนเข้า ต้องเอารูปมาฝากไว้ในกระทู้คนอื่น

ไม่ใช่แค่กระทู้นี้ กระทู้ริงของดิชั้นก็ด้วย ถามหน่อยเถอะ เอาไปแปะทำไม ใครเค้าอยากดู

ให้พูดตรงๆ หน้าด้านมาก มั่นใจในตัวเองจนออกนอกหน้า

โดยเฉพาะกับคนที่ตัวเองคิดว่าอ่อนด้อยกว่า กะคนที่เก่งกว่าล่ะ หุบปากเงียบ หงอหางจุกตูด

ไม่ได้ดูหรอกว่า ระดับตัวเองน่ะ จริงๆแล้วมันแค่ไหน

เอาให้่เก่งระดับโปรก่อนเถอะ ค่อยมาว่าคนอื่น ตักน้ำใส่กะโหลก ชะโงกดูเงาตัวเองบ้าง

ปากอ่ะ หุบมั่งก็ดี รู้ตัวไว้ซะว่ามันน่ารำคาญ

ดิชั้นจะว่าคุณหลายครั้งแล้ว แต่ จขกท. ห้ามเอาไว้ รู้ไว้ว่าคนไม่ว่า ไม่ใช่เค้าไม่ได้เกลียดคุณ

ถ้าจะโกรธก็เชิญ ดิชั้นคิดว่าได้พูดไปตรงๆแล้ว ข้องใจอะไรก็ว่าไว้ แล้วว่างๆดิชั้นจะมาดู

อ้อ อีกอย่าง ดิชั้นมั่นใจว่าฝีมือของดิชั้นดีกว่าคุณ ถึงได้พูด และรูปของดิชั้นก็ไม่ได้ลอกใครมา

และไม่ได้วาดแบบหยาบกระด้างหรือลงสีแบบพื้นๆเหมือนงานของคุณด้วย

ปล. ดิชั้นไม่กลัวโดนล็อคเมม เพราะงั้นไม่ต้องห่วงว่าจะหนีไปไหน ดิชั้นจะตามมาแขวะคุณเรื่อยๆ

จนกว่าคุณจะสำเหนียกในพฤติกรรมไร้มารยาทและสมบัติผู้ดีของคุณ
