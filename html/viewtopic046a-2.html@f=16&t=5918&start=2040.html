[G-T-A] เขียน:ขอโทษครับ พอดีผมมีเรื่องคาใจอยู่นะ

ถ้าเราเอาหุ่นไปล้มแล้วค่าสเตตัสที่เต็มแล้วจะลดลงไปเยอะมั้ยครับ หรือว่ากลายเป็น 0 hock:


กลายเป้น 0 + โบนัสจากการ ล้มส่วนของค่าที่เต็มเท่านั้นครับ
ค่าที่ไม่เต็มก็จะอยู่คงเดิม ไม่มีลด

เช่น Atk 150 + 150 (สมมุติว่าเต้มแล้ว)
ล้มแล้ว จะเหลือ 150+1(<< ค่าที่ได้จาก bonus จากค่าที่เต็ม)
สามารถอัพต่าให้เป็น 150+151 ได้ครับ
