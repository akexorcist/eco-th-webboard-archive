Discuss Skill by kiKie เขียน:Groove Arrow เป็น skill ที่ใช้แบบ Active ในลักษณะ กดแล้วยิงออกข้างหน้าเลย
แบบเดียวกับที่เอเลใช้สาดน้ำอ่ะ
ความต่างก็คือ
- Groove Arrow เป็น A.Attack ไม่ใช่ Magic Attack
- เพราะงั้นเวลาคิด def สำหรับตัวรับ damage จะไปคิดค่า def ไม่ใช่ m.def
- ยิงออกไปเป็นเส้นตรงช่องเดียว ในขณะที่ของเอเลที่สาดคลื่นเป็นสามช่อง
- เนื่องจากเป็น A.Atk เพราะงั้นมันมีโอกาส miss ได้ ในการดันให้ถอยแต่ละช่อง
เพราะงั้นถ้า miss สักช่องสองช่อง...ม่อนก็หลุดแระ (ดันไม่ไป เพราะ miss)


เพราะงั้นเลยอยากรู้ว่าใช้ Groove เก็บเวลจริงๆ หรอ???
ถ้าไปยิงม่อนไม่ถึก (ดัน70) ใช้ Blast ไม่เร็วกว่าหรอ
ถ้าไปยิงม่อนถึกๆ (ไมไม) กว่าม่อนจะตายแต่ละตัว คุ้มหรอที่ใช้ Groove เมื่อเทียบกับ exp ที่ได้


ปล. เค้าก็อัพนะ Groove Arrow อ่ะ...แล้วก็ได้ใช้นะ ในบางสถานการณ์อ่ะื
