- Cloaking (ยังไงๆ ก้อไม่น่าทิ้งสกิลนี่อะ)
- Poisonreate1

สรุปคือ เวิร์ค แต่ต้องเล่นนานก่อนเปลี่ยน (หรือถ้าจะเอาแค่วางระเบิดแล้วรีกลับ ก้อไม่ต้องสนใจที่ว่าไปนี่หรอก) [/list]
