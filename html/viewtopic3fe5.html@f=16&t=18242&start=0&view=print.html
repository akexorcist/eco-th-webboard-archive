เป็นการ ส่อ ให้รู้ถึง สายอาชีพ ที่คนให้ความสนใจที่จะเล่น ความยากง่าย และอื่นๆ

จากภาพดังกล่าว ทำให้รู้ว่า
Swordman เป็นสายอาชีพที่ เล่นง่าย เพราะคนเล่นเยอะสุด
Tatarabe เป็นสายอาชีพที่เล่นยาก เพราะคนเลือกที่จะเล่นน้อยสุด

หรือมองอีกมุมนึง

Swordman เป็นสายอาชีพที่ ไม่ว่าใครที่ไหนก้เล่นได้ (เข้หมู เข้หมา ที่ไหนมา ก้เล่นได้)
Tatarabe เป็นสายอาชีพที่ ค่อนข้างซับซ้อน เล่นยาก (ถ้าไม่ศึกษาจริงๆ เก่งยาก)

หรืออีกมุมนึง

Swordman เป็นสายอาชีพที่สำคัญ คนจึงให้ความสนใจเล่นกันเยอะ (ในตี้ขาด Swordman แล้วจะขาดใจ)
Tatarabe เป็นสายอาชีพที่มองแล้ว จะเล่นไปทำไม ให้คนอื่นเล่นไปนะดีแล้ว...(ในตี้ขาด ทาทา ก้ไม่เหนจะเปงไร)

หรือ..
