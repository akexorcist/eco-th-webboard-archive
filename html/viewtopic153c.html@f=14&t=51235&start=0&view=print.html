โดย ECO
1.Fly Fish !!! ถ้าstrเยอะยิง2ทีตาย ฆ่าได้ไว+เน้นจำนวน แต่ตังห่วยมากๆ~ เก็บได้จนLV30-35

2.แมพ momo plain ตังดี มอนexpกลางๆ (expเยอะกว่าแต่ความถี่มอนเตอร์สู้Fly FishในUtena River ไม่ได้ มอนอยู่ห่างๆกันอะนะ)เก็บได้เรื่อยๆถ้าไม่เบื่อก็ยิงกบเหลืองจน50ได้เหมือนกัน ถ้าเอจิเยอะหน่อยได้ดีเลย์ยิงกบเหลืองได้แล้วถ้ายิงไวพอ มานจะเดินไม่ได้

3.LV35-50 ชินนามอน~ ที่แมพ วอคาโน่ ตังดี ใช้เบิล2ทีตาย ใช้Minประมาน200(ไม่นับmiss avoid) ถ้าตำกว่านั้นก็ดันแล้วเบิลก็ได้เพราะโอกาศที่เบิล2ทีไม่ตายมีสูง หรือใช้ลูกนู+แอด เนื่องจากชินนามอนดรอปของราคาดี ใช้ลูกนู+แอดลูกละ3-5Gก็ไม่ขาดทุน

4.ดูด จาก1>60+(ไม่เกิน3วัน LV50ชัว ถ้ามีเวลา จะให้ดี ดูดตัวของตัวเองดีกว่า เอาตัวเก่ามาให้ตัวใหม่ดูด ไหนๆก็เล่นเกมเก็บเลเวลทั้งที เก็บเองจน90ซักรอบก็ดีนะ)

5.ช่วง50-60+ เก็บที่ตันใต้ ฝั่งซ้ายที่มืดๆ ครึ่งล่างหรือบนก็ได้ มีมอนเยอะมากๆจนได้ยิงแบบแทบไม่มีเวลาพัก บนจะตังดีกว่าล่างเพราะมี Buriking RX3 เยอะกว่าครึ่งล่าง แล้วแต่ชอบละกัน ใช้สะเตปดันแล้วยิง

6.ช่วง50-60+ดันฟาอีส ใช้สะเตปดันแล้วยิง ตังดีมากแต่ช้ากว่าตันใต้พอสมควร เอจิ81หลบได้ (ชั้น1นะ ที่มีพวกไก่ดำ หมูที่มีสีสันเยอะๆอะ หุ่นไล่กา)

7.60-90 ฟุจิกิ ช่วงแรกๆอาจจะยิงแต่แบนดิดก่อนก็ได้เพราะมันไม่อึด พอเริ่มยิงแรงก็ยิงได้หมดเลย เอจิที่รวม81 หลบได้หมด ถ้าเอจิ72หลบแบนดิดได้พอสมควร

8.70-90 ดันส่วนตัวเลเวล70~

*ไม่ควรเปลี่ยนStrikerก่อนจอบ40(จะให้ดีก็จอบ50 ถ้าอดทนไหว จะได้หวังผลระยะยาว)เพราะ จะไม่ได้สกิล Strike Arrow(สกิลอาเชอจอบ40) ซึ่งมีผลเพิ่มความแรงให้กับสกิล Blast Arrow ของ Striker เว้นแต่จะไม่คิดจะเล่น Striker เลย แต่มีไว้ก็ดี เผื่อเปลี่ยนใจ
