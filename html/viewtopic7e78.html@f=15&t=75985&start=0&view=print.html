รีเป็นสาย VIT เท่านั้นครับ

Stats -> STR=VIT>DEXรวม64 ที่เหลือ INT

Skill ที่ต้องมี ->Necro Resurrection, Shield Mastery, Blow, Dark rise, Dark power circle

ไอเทมที่ต้องมี -> อาวุธอะไรก็ได้ยัดการ์ดให้ได้ธาตุแสง 1 รู / เกราะหรือประดับธาตุมืด


วิธีสู้ -> ลากมา 1 ตัว ร่าย dark rise ใส่ศัตรูให้เกราะมันกลายเป็นธาตุมืด + dark power circle ลงพื้น เพื่อให้เกราะมืดมันระดับสูงขึ้นอีก เพื่อที่จะได้ใช้อาวุธแสง Blow ใส่มันได้อย่างสุดแรง
การที่เราใส่เกราะมืดเหมือนกัน จะช่วยลด damage ได้มากถ้ามันเปลี่ยนธาตุที่ไม่ใช่ธาตุแสง.. กรณีเจอมันเปลี่ยนเป็นธาตุแสงให้เปลี่ยนเกราะที่ใส่ก็พอ

ด้วยวิธีนี้ blow จะได้ประมาณ 4000-5000 ต่อครั้งครับ

====================

นอกเหนือจากนี้ผมคิดว่าเป็นไปไม่ได้แล้วครับ.. ไม่ว่าจะสาย MAG หรือสาย STR AGI ก็เสี่ยงมากกว่าสาย VIT ทั้งนั้น
