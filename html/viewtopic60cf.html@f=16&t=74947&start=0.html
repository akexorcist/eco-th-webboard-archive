ให้เรนเจอร์ไปหาของเควสเองมันยากจริงๆแหละครับ เนื่องจากไม่มีท่าโจมตีแรงๆต่อให้
ใช้ท่า50ของTHก็ยังไม่ค่อยดีเมื่อเทียบกับของอาชีพอื่นในสายBPแต่ข้อดีของเรนเจอร์คือ
นอกจากความแรงแล้วอย่างอื่นมีความสมดุลและยืดหยุ่นสูงมาก

นอกเรื่องไปไกล พูดถึงเรื่องวิธีสู้กับตัวก๊อปปี้นั้นก็มีอยู่หลายวิธีเช่นกันเพียงแต่จำเป็นต้อง
สู้แบบ1-1เพราะมันค่อนข้างโหดถ้าโดนรุมจะตายเอาง่ายๆ ส่วนวิธีสู้นั้นผมอยากให้คิดเอง
มากกว่าครับเพราะเวล99แล้วจะใส่ชุด99ก็น่าจะรู้ทริคการใช้สกิลขั้นสูงของอาชีพตัวเองบ้าง
การหาไม่ครบ100ชิ้นเหมือนบ่งบอกเป็นนัยๆอยู่แล้วว่ายังไม่เหมาะสมที่จะสวมชุด

แต่ถ้าคิดว่าตัวเองไม่ไหวจริงๆผมจะบอกใบ้วิธีที่ผมใช้ให้นะ
[กับดักกล้วย กับดักหญ้า โบลว แบดิชโบลว]
