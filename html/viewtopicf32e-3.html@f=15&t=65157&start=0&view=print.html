แต่ถ้าเล่น Sage แล้วเอาสกิลซอ เป็น Reserve 5 สกิลที่ผมจะเอามา คือ Raving Sword,Noise,Devine Barrier,Solid Aura,อีก 1 สกิลนี้มีหลายอย่างให้เลือกครับ เช่น Soul ไว้ช่วยเวลาสิงคนอื่น,Energy Burn สกิลโจมตี,Teleport เพื่อชิงความเร็วในการเข้าใกล้และถอยหนี,Invicible ไว้หนีมอนและไว้หนี แอบผู้เล่นเวลาสู้กันเอง ในกรณีที่เค้าไม่มีสกิลขุด,Invicible Break เอาไว้ขุดผู้เล่น เวลาสู้กับคนอื่น

ปล.ผิดถูกยังไง ก็ลองเสนอมานะครับ เพราะผมเองก็เล่นได้ไม่นาน อาจจะไม่ถูกต้องนัก
