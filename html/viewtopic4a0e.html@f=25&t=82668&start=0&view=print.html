ประกาศ กฎ และ ข้อบังคับในการใช้เว็บบอร์ด

เว็บบอร์ด http://eco.froztic.in.th/archive/ecofanclub เปิดขึ้นมาเพื่อให้ทุกคนที่สนใจในเกม Emil Chronicle Online หรือ ECO ได้มีโอกาสแสดงความคิดเห็น พูดคุย แลกเปลี่ยนข้อมูลและประสบการณ์ ตลอดจนสอบถามข้อมูลที่เป็นประโยชน์ ได้แบ่งปันความสนุก และ ความประทับใจใน ECO ร่วมกันความสนุกสนานจะเกิดขึ้นได้ก็ต่อเมื่อทุกท่านที่เข้าร่วมสังคมเว็บบอร์ดนี้ ปฏิบัติตามกฎ กติกา และมารยาทค่ะ

ดังนั้น จึง ขอ ประกาศ กฎและข้อบังคับในการใช้เว็บบอร์ด เพื่อความเข้าใจตรงกันค่ะ

...............

กฏการตั้งชื่อเล่นในกระดานสนทนา

1. ห้ามใช้ชื่อที่กล่าวถึง กล่าวพาดพิง หรือล้อเลียนสถาบันชาติ ศาสนา พระมหากษัตริย์และพระบรมวงศานุวงศ์
2. ห้ามใช้ชื่อที่หยาบคาย ใช้คำแผลง คำที่พ้องเสียงกับคำหยาบ หรือ ส่อไปในเรื่องเพศ ลามกอนาจาร ข่มขู่ ยุยง/ส่งเสริมให้เกิดความแตกแยกในสังคมหรือขัดต่อศีลธรรมอันดีของไทย รวมไปถึงชื่อที่แสดงออกเชิงเสียดสีหรือ Discredit บริษัท หรือบุคคลอื่น
3. ห้ามใช้ชื่อที่เกี่ยวข้องกับผู้ดูแลระบบ เช่น “GM”, “Game Master”, "webmaster", "web editor", "admin", "member(s)", "customer / customer service" / หรือคำอื่นๆ ที่พิจารณาว่าไม่เหมาะสมสำหรับการใช้เป็นชื่อ ชื่อเล่น
4. ห้ามใช้ชื่อเป็นชื่อ web, ชื่อสินค้าและบริการ, ชื่อหน่วยงาน หรือชื่อเข้าข่ายโฆษณาและส่งเสริมการขาย หรือ ชื่อ บริษัทเกมส์ออนไลน์ต่างๆ


...............

กฏการใช้กระดานสนทนา

1. ห้ามใช้ข้อความที่เป็นการวิพากษ์วิจารณ์สถาบันพระมหากษัตริย์และพระบรมวงศานุวงศ์เป็นอันขาด
2. ห้ามใช้ข้อความหรือความคิดเห็นที่เป็นการดูหมิ่นต่อศาสนาหรือคำสอนของศาสนาใดๆ ทุกศาสนา
3. ห้ามดูถูก ดูหมิ่น ประเทศชาติ หรือชนชาติใดๆ ก็ตาม
4. ห้ามเสนอข้อความและรูปภาพที่หยาบคาย ลามก อนาจาร รวมทั้ง URL, รูป หรือชื่อ Website ต่างๆ ที่สื่อความหมายไม่เหมาะสม รวมไปถึงถ้อยคำหรือข้อความที่เป็นศัพท์แสลง คำแผลง คำผวน และภาษาวิบัติ ที่จงใจ หรือสื่อความหมาย
เข้าข่ายดังกล่าว
5. ห้ามเสนอข้อความอันเป็นการท้าทายชักชวน โจมตี หรือกล่าวร้ายผู้อื่น ยุยงให้เกิดการทะเลาะเบาะแว้ง ไม่ว่าผู้ตั้งกระทู้หรือผู้ตอบนั้นจะตั้งใจหรือไม่
6. ห้ามเสนอข้อมูลส่วนตัวของผู้อื่น เช่น ชื่อ-นามสกุลจริง อีเมล หรือหมายเลขโทรศัพท์ โดยมีเจตนากลั่นแกล้งให้ผู้อื่นได้รับความเดือดร้อนรำคาญ
7. ห้ามใช้ข้อความที่มีลักษณะแอบอ้างเป็นบุคคล หรือองค์กรใดๆ เพื่อเรี่ยไร, หาผลประโยชน์ หรือก่อให้เกิดความเข้าใจผิดต่อสมาชิก และขอสงวนสิทธิ์ในการลบกระทู้ที่ลักษณะเข้าข่ายดังกล่าว
8. ห้ามทำการโฆษณาชวนเชื่อ หรือทำการขายสินค้า หากตรวจพบกระทู้จะถูกลบและมีบทลงโทษ รวมไปถึงการตั้งกระทู้หรือเสนอความคิดเห็น พาดพิงบริษัทอื่น บุคคลอื่น เกมอื่น หรือนำประเด็นข้อพิพาทของบริษัทอื่น บุคคลอื่นมาพูดคุยกันภายในเว็บบอร์ด
9. ห้ามนำเสนอข้อความอื่นๆ ที่ไม่ได้ระบุไว้ในข้อ 1-8 แต่อาจก่ออันตรายต่อเว็บ เช่น ทำให้โดน Block โดนปิดกั้นเนื่องจากตรวจพบข้อความไม่เหมาะสม หรือกระทบความมั่นคง หรือก่อให้เกิดความเสื่อมเสียต่อเว็บ
10. ทีมงานขอสงวนสิทธิ์ในการตอบคำถามเชิงลึกเกี่ยวกับเกม โดยเฉพาะที่มีลักษณะเป็นการเปิดเผยข้อมูลเชิงโครงสร้างของเกม และข้อมูลเชิงเทคนิคต่างๆ
11. การตัดสินของทีมงานถือเป็นที่สิ้นสุด และขอสงวนสิทธิ์ในการชี้แจงในแต่ละกรณีตามความเหมาะสมและเห็นควรของทีมงาน

Moderator และ Administrator มีสิทธิ์อ่าน ลบ หรือแก้ไขทุกข้อความ

มาตรการดำเนินการกรณีมีการใช้เว็บบอร์ดที่ไม่เหมาะสม

ลบหรือแก้ไขข้อความที่ขัดต่อข้อตกลงทันที โดยไม่ต้องแจ้งให้ทราบล่วงหน้า

ระงับ ID ที่ขัดต่อข้อตกลง ในกรณีที่กระทำการละเมิด 3 ครั้ง

มารยาท ในการใช้กระดานสนทนา

1. ไม่ควรตั้งกระทู้ซ้ำ โดยไม่มีเหตุจำเป็น หากเกิดข้อผิดพลาดในการตั้งกระทู้
สามารถแจ้งทีมงานเพื่อขอลบกระทู้ได้ โดยทีมงานขอสงวนสิทธิ์ในการพิจารณาเพื่อดำเนินการ

•หากทีมงานพบเห็นสมาชิกที่ตั้งกระทู้ซ้ำกับกระทู้เดิม ไม่ว่าในด้านเนื้อหา หรือหัวข้อ ที่เคยถูกตั้งมาก่อน

2. ไม่ควรโพสต์เพื่อปั้ม Reply หรือโพสต์ข้อความที่ไม่มีส่วนเกี่ยวข้องกับกระทู้นั้น เว้นแต่ว่าเนื้อหาในกระทู้จะเป็นการคุยเล่นระหว่างสมาชิก ตัวอย่างเช่น

• การ post ในกระทู้ใดๆ โดยไม่ได้มีส่วนร่วมกับเนื้อหา
• การตอบกระทู้ติดๆ กันในกระทู้เดียว กรุณาใช้ปุ่ม edit
• การตอบโดยมีแต่ emoticon หรือ ข้อความที่ไม่เกิดประโยชน์ โดยไม่แสดงความเห็นในกระทู้

3. ทางทีมงานขอสงวนสิทธิ์ในการลบกระทู้ที่ไม่มีประเด็น และไม่ก่อให้เกิดประโยชน์
4. ทีมงานขอสงวนสิทธิ์ในการระงับไอดีของสมาชิก หากเกิดกรณีพิพาทระหว่างสมาชิกภายในเว็บบอร์ด
5. ถ้าพบสมาชิกประพฤติตัวไม่เหมาะสม ขอให้แจ้งทีมงานโดยตรง
6. ทางทีมงานถือว่าสมาชิกทุกคนรับทราบ และยอมรับ กฎ/ข้อตกลง/กติกา มารยาทในการใช้เว็บบอร์ด โดยสมาชิกจะต้องปฏิบัติตามกฎของทางเว็บบอร์ดอย่างเคร่งครัด
7. ทางทีมงานงานขอสงวนสิทธิ์ในการแก้ไข เพิ่มเติม กฎ/ข้อตกลง/กติกา ของเว็บบอร์ด โดยไม่จำเป็นต้องแจ้งให้ทราบล่วงหน้า
บทลงโทษ การทำผิดกฏ หรือกติกา มารยาท ทางทีมงานขอสงวนสิทธิ์ในพิจารณา ลบ Edit ตักเตือน และระงับการให้บริการ ID ตามดุลยพินิจของทีมงานทั้งนี้อาจมีการเพิ่มเติมกฎต่าง ๆ ในภายหลัง
