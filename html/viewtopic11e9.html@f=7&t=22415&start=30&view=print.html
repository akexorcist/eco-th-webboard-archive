ดีค่ะเพื่อนๆ วันนี้นู๋จุดจะมาสอนวิธีการใช้โฟโต้ช๊อปลดขนาดรูปนะคะ

มาละค่ะ หลังจากอัพโหลดรูปอยู่นาน
เรามาเริ่มกันเลย
เริ่มด้วยเปิดโปรแกรมนะคะ
แล้วไปที่แทบเมนูด้านบน
กดไปที่ File > Open จะได้ดังรูปค่ะ แล้วก็หารูปที่เราจะเอามาย่อขยายนะคะ

จากนั้นก็เปิดรูปที่เราจะย่อขยายออกมาค่ะแล้วเลือกที่เมนู
Image > Image Size ตามรูปค่ะ

จากนั้นก็ปรับขนาดตามใจชอบเลยนะคะ และกด OK เมื่อปรับไซต์เส็ด
ปล.ปรับแค่ส่วนของ Document size จะดีที่สุดนะคะ โดยที่ไม่ต้องปรับส่วนของ
Pixel size ค่ะเพราะระบบจะปรับให้บัลลานท์อัตโนมัติแล้วค่ะ

เดี๋ยวจะมาอธิบายต่อนะคะขอไปเก็บเวลก่อน
