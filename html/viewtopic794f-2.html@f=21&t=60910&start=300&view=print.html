ความสามารถพิเศษ ( Versus ) :
-Free Planting : ปลูกพืชได้ทุกๆที่ไม่เว้นแม้แต่บนร่างกาย สามารถใช้สกิลนี้ทำร้ายคู่ต่อสู้ได้โดยการปลูกเมล็ดพืชที่มีผลกระทบต่างๆกันบนร่างคู่ต่อสู้เมื่อสบโอกาส
-Watering : รดน้ำเมล็ดพืชที่ปลูกไว้ตามที่ต่างๆให้งอกออกมาพร้อมแสดงผลของพืชนั้นๆ ใช้คู่กับสกิลFree Planting
-Heredity : ตัดต่อพันธุกรรมเมล็ดพืชผสมกับพันธุกรรมจากเลือดของมอนสเตอร์ต่างๆให้ได้เมล็ดพืชชนิดใหม่ที่มีความสามารถของมอนสเตอร์ชนิดนั้นๆแฝงอยู่

ประวัติตัวละคร : โครอลเกิดในเมืองทางทิศใต้ของอาณาจักรอโครเนีย...ในเมืองที่ร้อนระอุไปด้วยเพลิงของภูเขาไฟแต่ทำไมกลับมีเด็กสาวคนหนึ่งสามารถปลูกพืชต่างๆได้เจริญงอกงามดียิ่งกว่าในฟาร์อีสต์ซะอีก?...โครอลเกิดมาพร้อมกับความสามารถที่ช่างแตกต่างจากสภาพแวดล้อมที่เธอเติบโตขึ้นมา คุณพ่อเลี้ยงเธอมาตั้งแต่ยังเด็กส่วนคุณแม่นั้นหายสาบสูญไปพร้อมๆกับคุณตาของเธอขณะที่พวกเขาไปสำรวจซากโบราณสถานแห่งหนึ่ง...ในใจลึกๆโครอลก็อยากจะไปตามหาคุณแม่ที่หายไปของเธอ แต่เธอก็มีคุณพ่อที่ต้องคอยดูแลเพราะตั้งแต่คุณแม่หายตัวไป สุขภาพของคุณพ่อของเธอก็แย่ลงราวกับว่าท่านได้ขาดชิ้นส่วนที่สำคัญที่สุดของชีวิตไปหนึ่งชิ้น...และแล้ววันหนึ่งก็มีเด็กหนุ่มคนหนึ่งเดินทางมาจากเมืองทางด้านทิศตะวันตกของอาณาจักรอโครเนีย "เดสไทร์"เด็กหนุ่มผู้มาพร้อมกับความหวังที่ว่าแม่ของโครอลยังมีชีวิตอยู่...เดสไทร์ได้นำจดหมายฉบับหนึ่งมาให้โครอลและพ่อของเธอ จดหมายฉบับนั้นเป็นจดหมายฉบับสุดท้ายที่คุณตาของเธอได้เขียนไว้ก่อนที่จะสิ้นลม...เมื่อทั้งสองได้อ่านจดหมายจึงรู้ว่าเดสไทร์เป็นคนที่ช่วยคุณตาของเธอไว้ระหว่างการสำรวจซากโบราณแห่งที่2"Heaven Tower" แต่คุณแม่ของเธอได้หายสาบสูญไปในหอคอยสวรรค์แห่งนั้น...เดสไทร์เอ่ยปากว่าเขาไม่มีที่พึ่งอื่นนอกจากคุณตาของโครอลซึ่งเสียไปแล้ว นอกจากคุณตาจะสั่งให้เดสไทร์นำจดหมายฉบับนี้มามอบให้แล้ว ท่านก็ยังฝากให้เดสไทร์ช่วยดูแลโครอลและพ่อของเธอด้วย...เพราะเขาเป็นคนที่คุณตารักแล้วไว้ใจมากที่สุดเหมือนลูกหลานเลยทีเดียว...ในที่สุดเมื่อเวลาผ่านไปโครอลก็ตัดสินใจที่จะลาจากบ้านเกิดเพื่อเดินทางออกตามหาคุณแม่ของเธอ ณ ที่แห่งนั้น...Heaven Tower...
