ต่อไป โปรเจ๊ด Fox ละเย้ วาดๆไว้ - -+ไม่รู้จะได้ทำจริงๆหรือเปล่า


Ichi คุงหรือ 1หางนี้เอง ใครชอบหนุ่มแว่นอ่อนแอต้องคนนี้


Niคุง สาวน้อยหน้าตายของเรา ไม่ว่าจะสถานการณ์ไหน ก็หน้าตาแบบนั้น - -


Sanซัง ท่านผู้นี้เป็นคนที่มีนิสัยเข้มงวด ร่างสูงใหญ่ให้นึกว่าเมะ แต่จริงๆแล้วร่างแท้จริงเป็นจิ้งจอกน้อยตัวเท่าฝ่ามือ แต่ก็น้าเป็นคนที่แก่ที่สุดในบ้าน หมาน้อยแล้ว


Yonจัง สาวงามแห่งบ้านหมาน้อย ละเป็นคนจิตใจดีใจเย็น เว้นแต่สะสมมากๆจะสติแตกได้


Koจัง สาวน้อยผู้น่ารักแห่งบ้านหมาน้อยเป็นคนที่ร่าเริงมากชอบอะไรน่ารักๆเป็นที่สุด


Roku พ่อหนุ่มแอบหล่อคนนี้ ป่าหลับน้อยวาดเองก็อธิบายไม่ได้เลย....


Nana แม่สาว 7หางคนนี้ ป่าหลับน้อยชอบที่สุด >< แสบซ่าท้านรก (สังเกตรายละเอียดเยอะกว่าตัวอื่น)
เป็นตัวละครเจ้าแม่ที่ชอบรังแกคนอื่นไปทั่วมีความน่ารักในตัว


Haji หนุ่มน้อยน่ารักที่มีนิสัยซื่อสัตย์แบบลูกเสืออย่างแรงเป็นเด็กดีที่แล้ว

=_=a 9หางยังเป็นปริศนาเนื่องจากป่าหลับน้อยคิดไม่ออกซะทีฮ่าและไม่รู้ว่าจะวาดไปแล้วจะได้ทำเป็นการ์ตูนช่องให้อ่านหรือเปล่าแง้
