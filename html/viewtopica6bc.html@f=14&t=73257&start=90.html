กลับไปอ่านหน้าแรกมั่ง

แก้ให้โป๊ยเซียนนิดนึง
Damage = [(Atk ของผู้โจมตี - Def ซ้ายของผู้ถูกโจมตี)*(100 - Def ขวาของผู้ถูกโจมตี) / 100]

อันที่จริงต้อง
物理ダメージ = ceil[(補正ATK-右DEF)×(1-左DEF/100)] - floor[VIT/3]


Damage = {[Damage ดิบ - Def ขวาของผู้ถูกโจมตี]*[1 - (Def ซ้ายของผู้ถูกโจมตี/100)]} - Vit/3

ถ้า Def ซ้าย 100 = [Damage - Def ขวา]*0 เลยตีไม่เข้า
