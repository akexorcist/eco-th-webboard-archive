กรณีนี้คือต้องเอาชุดแมวเป็นตัวแสดงภาพ แล้วหาของอื่นมาหลอมเป็นตัวคุณสมบัตินะจ๊ะ

เท่าที่จำได้ สายอาเชอร์ไม่มีชุดที่เป็นประเภท Body Suit แล้วเลเวลสูงๆ ใส่ได้นะ

ซึ่งชุดแมวควรเอาไว้ใส่เดินเล่นนั่งเล่นเฉยๆ หรือถ้าอยากใส่เก็บเลเวลก็ได้อยู่ (แต่อาจจะโดนตีแรงนะ)

ส่วนชุดที่เหมาะจะหลอมด้วยคือ ชุดเห็ดจ้ะ เอาชุดเห็ดเป็นตัวคุณสมบัติ แล้วไปหลอมด้วยกันได้

แล้วชุดแมวตอนนี้ก็ใส่ให้แตก แล้วซ่อมไปเรื่อยๆ ก่อนก็ได้ แล้วพอซ่อมจน ค่าความทนทานสูงสุดเหลือซัก 2

แล้วค่อยเอาชุดเห็ดไปหลอมนะ

ปล. ชุดเห็ดอันที่ขายกัน 200 - 300K อะจ้ะ ไม่แพง แล้วก็หลังจากหลอมแล้วสามารถให้ตัวอาชีพอื่นใส่ได้อีกด้วย
