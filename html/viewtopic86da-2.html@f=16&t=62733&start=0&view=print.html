โดย ECO
ไม่เข้าใจคำถามครับ

แต่ความสามารถของสกิลนี้เข้าใจง่าย ๆ ครับ จะขออธิบายเป็นข้อ ๆ ดังนี้ครับ

- ใช้กับ Undead และ Boss รวมไปถึง Mini Boss ไม่ได้ จะบอกว่าไม่สามารถใช้ Skill ได้ แต่ใช้กับ Boss ในแผนที่ฝึกสัตว์ได้ (หนอนม่วง ลูกไฟเหลือง ผมลองมาแล้วครับ จับได้แน่นอน ... แต่จะจับไปเพื่อ ?)
- มอนสเตอร์ที่จับมาจะอยู่ในสถานะ Pet ไม่สามารถถอดออกหรือสวมใส่ได้
- หากเรากดใช้งาน Pet ในขณะที่เรามี Monster ที่เราจับมาจาก Skill Monster Chaming อยู่ Monster จะหายวับไปทันทีและไม่กลับมาเป็น Monster ปกติ
- เราสามารถใช้คำสั่ง Go! หรือ Come Back! ได้ แต่ Monster ไม่ถือว่าเป็น Pet แค่อยู่ใน "สถานะ" Pet เท่านั้น สกิลส่วนมากของ Bleeder จึงไม่มีผล
- Monster ที่เราจับมาถือว่า "ตาย" ไปแล้ว ดังนั้นจะมีมอนสเตอร์ชนิดเดิมเกิดขึ้นมาใหม่ทันที (เคยเอาลูกไฟเหลืองดวลลูกไฟเหลืองเหมือนกัน สู้กันเป็นชั่วโมงมั้ง ถ้าจะสู้กันจริง ๆ ==)
- Monster ที่จับมาหากเปลี่ยนแผนที่จะหายไป และ Monster จะอยู่ในสถานะ Pet เพียง 5 นาทีแล้วก็จะหายไป
- หากใช้กับคนสำเร็จ คน ๆ จะตายทันทีและมี Pet เป็นคน ๆ นั้นและมีความสามารถเดียวกันรวมถึง Skill ด้วย
- โดน Reflex สะท้อนกลับมาหาตัวเองได้ เพราะถือว่าเป็นเวทย์ และหากตัวเองโดนก็ตายเช่นเดียวกัน + มี Pet ออกมาด้วย O.o แต่ยังไม่สามารถยืนยันได้ว่าหากชุบแล้ว Petจะยังอยู่

โดนคร่าว ๆ ก็ประมาณนี้แหละครับ จะว่าง่าย ๆ skill นี้เหมือน Skill ไว้ใช้เล่นมากกว่าเอาไว้ใช้จริงนะครับ (ยกเว้นเอาไว้จับ Red Alert ไว้ช่วยสู้ แต่จับยากมากมาย )

Edit : ไม่แน่ใจว่าบอสบางตัวจะจับได้รึเปล่านะครับ เพราะไม่ได้ไปลองมาทุกตัว รอผู้ที่เคยลองบอกดีกว่า ==
