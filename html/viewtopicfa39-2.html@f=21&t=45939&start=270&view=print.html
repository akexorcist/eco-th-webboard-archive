"ทุกคนมีหน้ากากทั้งนั้น เพียงแต่มันไม่ได้ออกมาชัดเจนเหมือนกับหน้ากากที่คนใส่เล่นละคร เท่านั้น และการต่อสู้กับ 'ความจริง' นี้ก็ไม่มีอะไรดีไปกว่าการเผชิญหน้ากับตัวเอง ที่ฉันให้พวกเธอเข้าไปที่นั่น..... ก็เพื่อให้พวกเธอได้พบว่า ในจิตใจของเธอยังมีสิ่งใดแฝงอยู่ อย่างน้อยที่สุด พวกเธอ..... ก็ควรจะรู้แล้วว่า ... ระหว่างคนที่เธอเกลียด กลัว .... กับตัวพวกเธอเอง ใครจะเป็นศัตรูที่น่ากลัวกว่ากัน..."

เร็นกำลังจะพูด ก็พอดีกับได้ยินเสียงเหมือนคนร้องให้ช่วยแผ่วๆ แล้วตามด้วยเสียงอะไรสักอย่างตกน้ำดังขึ้นมา

เร็นเลยพูดว่า "เมื่อกี๊ เธอสองคน ได้ยินเสียงเหมือนคนขอความช่วยเหลือรึเปล่า?" ระหว่างนั้นเธอใช้พลังจิตร่วมกับหูของเธอตรวจหาอย่างรวดเร็วว่าจุดกำเนิดเสียงอยู่ตรงไหน ที่ให้มิกิกับไอริสช่วยฟัง ก็เพื่อให้ระบุตำแหน่งได้ชัดเจนขึ้น ก่อนจะรู้ตัวว่ากบซามูไรกำลังสะกิดแขนเธอยิกๆ ทำท่าเหมือนบอกว่า ให้รีบตามมา ฉันรู้ว่าเสียงนั่นมาจากที่ไหน

เร็นจึงหันไปหาเจ้ากบ แล้วพูดว่า "ช่วยนำทางทีนะ รบกวนด้วยล่ะ" แล้วเจ้ากบก็วิ่งนำทางไปทันที เร็นก็หันไปหามิกิกับไอริส แล้วพูดว่า "ตามมาเร็ว " แล้วก็ออกวิ่งตามกบซามูไรไปทันที
