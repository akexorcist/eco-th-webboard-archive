เรื่องนี้ต้องอธิบายกันยาวแฮะ สรุปคร่าวก่อนก็คือ
- def/m.def จากของสวมใส่ จะได้ค่า defตัวหลัง มันจะหักจากค่า atk ของผู้โจมตีตรงๆ (ก่อน+%ความแรงของ skill)
- ค่า status vit,int จะทำให้ได้ def/m.defตัวหน้า มันจะหักจากค่า atk ของผู้โจมตี (หลัง+%ความแรงของ skill แล้ว) โดยคิดเป็น % นั่นหมายถึงถ้าเรามี def/m.def ตัวหน้าเป็น 100 ก็คือป้องกันได้ 100% ดาเมจก็จะขึ้นเป็น 1หรือ0 นั่นเอง


ดังนั้นก็อยู่กับการเล่นของเราล่ะ
ว่าเราต้องการค่าป้องกันจากชุด หรือ ป้องกันจากstatus
อย่างไหนดีกว่าคงบอกไม่ได้ ขึ้นอยู่กับความละเอียดของการคิด status

จะเอา vit ให้ได้ def หน้าเยอะ
หรือจะเอาเครื่องป้องกันที่ไปหักกับ atk ของผู้โจมตีตรงๆ

ยกตัวอย่างเพื่อให้เห็นภาพ เขียน:ผู้โจมตีมีค่า atk 200 // เรามีค่า def 60-2 (ใส่ชุดdef2)
มอนโจมตีธรรมดา
ค่าโจมตีของมอนจะเหลือ 200-2=198
แล้วมาหักจาก defตัวหน้า60 คือ 60% = 198x(60/100)=119
มอนโจมตีธรรมดาจะขึ้นดาเมจ 198-119=79
กันเนอร์ยิงสกิว CrossCrest (ความแรงสกิว 1300%)
ค่าโจมตีของกันเนอร์จะเหลือ 200-2=198
แต่สกิวมีความแรง1300% ทำให้ได้ค่าโจมตี 198x13=2574
แล้วมาหักจาก defตัวหน้า60 คือ 60% = 2574x(60/100)=1544
กันเนอร์ยิงสกิวใส่จะขึ้นดาเมจ 2574-1544=1030

มอนมีค่า atk 200 // เรามีค่า def 40-60 (ใส่ชุดdef60 แต่มีvitน้อยลงมาก)
มอนโจมตีธรรมดา
ค่าโจมตีของมอนจะเหลือ 200-60=140
แล้วมาหักจาก defตัวหน้า40 คือ 40% = 140x(40/100)=56
มอนโจมตีธรรมดาจะขึ้นดาเมจ 140-56=84
กันเนอร์ยิงสกิว CrossCrest (ความแรงสกิว 1300%)
ค่าโจมตีของกันเนอร์จะเหลือ 200-60=140
แต่สกิวมีความแรง1300% ทำให้ได้ค่าโจมตี 140x13=1820
แล้วมาหักจาก defตัวหน้า40 คือ 40% = 1820x(40/100)=728
กันเนอร์ยิงสกิวใส่จะขึ้นดาเมจ 1820-728=1092

จะเห็นว่าค่าไม่ต่างกันมากนัก
...แต่จะต่างมาก ถ้า atk ของผู้โจมตีมีค่ามากๆ....ไม่เชื่อลองคิดดู
ก็อยู่ที่ดุลยพินิจละกัน
