อาจจะมีบางจังหวะที่อัพแล้วไม่ขึ้น หรือบางจังหวะเพิ่ม 2-3

อยากรู้ว่าค่าที่เท่าไรเพิ่มเยอะพิเศษก็ลองกดสูตรดู แต่มันจะซับซ้อนกว่าค่า stat ตัวอื่นๆ ที่หารลงตัวกันง่ายๆ (แต่บางคนก็ยังไม่เข้าใจ)
