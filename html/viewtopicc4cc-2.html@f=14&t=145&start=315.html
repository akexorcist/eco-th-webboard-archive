JojoJung เขียน:อ่อผมนึกว่าเป็นรูป ตาราง สเตตัส อะ งั้นไม่เปงไรครับไม่ต้องเอารูปแล้วละครับ ไว้ผมได้หนังสือของECOก่อนว่ามันจามีบอกรายระเอียดอีกรึเปล่า แต่โดยส่วนตัว ผมอยากเล่น มนุษย์นะ ไม่ชอบบินอะกลัวเด่วเวลาจาเดินไม่มีแรง อิอิ



ตาราง Statusเริ่มต้น นะคับ



ส่วนค่าต่างๆ ก้นี้คับ

STR มีผลต่อค่า ATK, MAX.PAYL
STR Bonus เมื่ออัพค่า STR ถึงจุดที่กำหนด ค่า ATK, MAX.PAYL จะเพิ่มขึ้น

DEX มีผลต่อค่า ATK, M.DEF, S.HIT, C.SPD, MAX.CAPA, อัตราการป้องกันของการใช้โล่ห์ และช่วยลดการเกิดสถานะผิดปรกติ
DEX Bonus เมื่ออัพค่า DEX ถึงจุดที่กำหนด ค่า S.HIT, C.SPD, MAX.CAPA จะเพิ่มขึ้น

INT มีผลต่อค่า M.ATK, M.DEF, MAX.SP, L.HIT, L.AVOID, MAX.CAPA และช่วยลดการเกิดสถานะผิดปรกติ
INT Bonus เมื่ออัพค่า INT ถึงจุดที่กำหนด ค่า M.DEF, L.HIT, MAX.CAPA จะเพิ่มขึ้น

VIT มีผลต่อค่า MAX.HP, MAX.SP, DEF, M.DEF, MAX.PAYL
VIT Bonus เมื่ออัพค่า VIT ถึงจุดที่กำหนด ค่า MAX.HP, DEF, M.DEF, MAX.PAYL จะเพิ่มขึ้น

AGI มีผลต่อค่า A.SPE, S.AVOID, L.AVOID
AGI Bonus เมื่ออัพค่า AGI ถึงจุดที่กำหนด ค่า A.SPE, S.AVOID จะเพิ่มขึ้น

MAG มีผลต่อค่า M.ATK, MAX.MP
MAG Bonus เมื่ออัพค่า MAG ถึงจุดที่กำหนด ค่า M.ATK จะเพิ่มขึ้น

***จะเห็นว่าค่า Status ส่วนใหญ่ ให้ Bonus ไม่เท่ากับ ผลลัพธ์ของค่า Status นั้นๆ
เช่น DEX มีผลต่อค่า ATK แต่ไม่ให้ Bonus เป็น ATK
ซึ่งก็ไม่ต้องไปสนใจมัน เพราะค่าที่ได้มันคือ Bonus

ATK = ความแรงของการโจมตีทางกายภาพ
M.ATK = ความแรงของการโจมตีทางเวทย์มนตร์

S.HIT = พลังโจมตีระยะใกล้
L.HIT = พลังการโจมตีระยะไกล

DEF = การป้องกันทางกายภาพ
M.DEF = การป้องกันทางเวทย์มนตร์

S.AVOID = การหลบหลีกจากการโจมตีระยะใกล้
L.AVOID = การหลบหลีกจากการโจมตีระยะไกล

A.SPD = ความเร็วในการโจมตี
C.SPD = ความเร็วในการร่ายเวทย์

MAX.HP = ค่าHPสูงสุด
MAX.MP = ค่าMPสูงสุด
MAX.SP = ค่าSPสูงสุด

MAX.PAYL = น้ำหนักของ ของที่บรรทุกได้
MAX.CAPA = จำนวนของ ของที่บรรทุกได้
