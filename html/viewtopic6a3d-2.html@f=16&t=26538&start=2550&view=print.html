ค่าการฮีลจะขึ้นกับค่าต่างๆดังนี้
1. Lv ของสกิล plant healing
2. ค่า vit ของผู้ถูกฮีล
3. ค่า Hp recovery
4. มี holy feather หรือไม่
5. ค่า M.Atk ของผู้ฮีล

ตามสูตรนี้

Healing formula

Lv1 = basic recovery * (100 + HPR correction + HF correction + [VIT/3])/100

basic recovery = 30 + [minimum M ATK * 0.6]
HPR (hp recovery) correction = 15 + 3*HPRLv
HF (holy feather) correction = 25

plant healing
Recovery = [Lv1 recovery ratio * Lv]
Lv1 = 1.0
Lv2 = 1.8
Lv3 = 2.4
Lv4 = 2.8
Lv5 = 3.0



โดย status ผมมี vit 82, hp recovery Lv.5
ส่วนไชเท้าถือว่ามี M.Atk = 229 ซึ่งถือเป็นค่าสูงสุด, hp recovery+3
อ้างอิงจาก: http://board.onenet.co.th/viewtopic.php ... start=2458
ทำการฮีลโดยใช้ plant healing Lv.5

ดังนั้นจะฮีลได้
= 3*[30+(229*0.6)][100+(15+3*5)+0+(82/3)]/100 = 786
(ให้ปัดทศนิยมลงตอน vit/3 กับตอน M.Atk*0.6)




ส่วนไชเท้า ถ้าแทนค่าจากสมการโดยคิดย้อนกลับเพื่อหาค่า vit และ hp recovery ว่ามีผลหรือไม่ โดยแทน vit = a, hp recovery = b
จะได้ดังนี้
516 = 3*[30+(229*0.6)][100+b+0+(a/3)]/100
516*100/3 = [30+137][100+b+(a/3)]
17200 = 167[100+b+(a/3)]
103 = 100+b+(a/3)
3 = b+(a/3)

จากที่บอกไปว่า ไชเท้าผมมี hp recovery+3 ส่วน vit ไม่รู้
ดังนั้นน่าจะเข้ากันได้ว่า pet ไม่มี vit หรือ vit ไม่มีผลกับการฮีล (a = 0)
โดยการฮีลจะคิดเฉพาะ hp recovery เท่านั้น (+เท่าไหร่ก็ใส่สูตรตามนั้นเลย)
ดังนั้นจึงไม่แปลกเลยที่ pet จะสามารถถูกฮีลได้แรงกว่าคนถ้ามี +hp recovery เยอะๆ เพราะคนมีค่าจำกัดอยู่ที่+30เท่านั้นที่ Lv.5

2. ค่า hp recovery
3. มี holy feather หรือไม่
4. M.Atk ของผู้ฮีล
