ไม่ได้แวะมานาน เข้ามาก็เลยแวะมาตอบให้หน่อยนึง

Fast Draw ใช้ได้แต่กับปืนสั้นครับ ( ปืนคู่ก็ไม่เกี่ยว )

คนส่วนใหญ่ก็เล่นกันปนๆไปนะครับ จะบอกข้อดีของปืนแต่ละแบบให้แล้วลองไป

ตัดสินใจดูเอานะครับ

1. ปืนสั้น เวลาร่ายเร็ว ความแรงปานกลาง ระยะยิงปานกลาง

2. ปืนยาว ( ไรเฟิล ) ความแรงปานกลาง ระยะยิงไกล เวลาร่ายปานกลาง

3. ปืนสั้นคู่ ความแรงสูงสุด ( เพราะกระสุนที่เพิ่มมาอีก 1 นัดในการยิงเกือบทุกแบบ )

ระยะยิงปานกลาง เวลาร่ายช้า
