SoulTowerหอคอยวิญญาณ ภาคที่1 Mur the Islandมหัศจรรย์อาณาเขตเงือกน้อย
พงศาวดารของมิติ

เมื่อหลายปีก่อน... ลูกแก้วแห่งแสง และ ลูกแก้วแห่งความมืด
เป็นของสำคัญมาก เพราะ เป็นทางปิดประตูพิภพทั้ง สอง เนื่องจากมีมนต์สะกดไว้อยู่โดย
ราชินีแสง และราชาเมฆหมอก หลังจาก สตาร์เชี่ยล พ่อหมดวัยแก่ซึ่งมีลูกแก้วทั้งสอง
ต้องเสียชีวิตไปเพราะ สละชีวิตต่อมังกรขาวแห่งเมืองบาดาล แต่แล้วลูกแก้วทั้งสอง
หลังจากอโคเนียได้ยุบสลาย ไป และก่อขึ้นมาอีกครั้งแล้วก่อขึ้นมาอีกครั้งโดยฝีมือของชนเผ่าโบราณ แต่มอนเตอร์ชื่อ เดม(DEM) ทุกเผ่าพันธุ์ แพร่ไปอย่างรวดเร็วแล้วมันก็มี สมอง

ยุคเวลาผ่านไปอย่างรวดเร็ว เดมทั้งหลายได้คิดค้นพลังวิเศษที่เหนือมนุษย์ แต่ก็ไม่สำเร็จ
เพราะมีนับรบชื่อ อีเมอร์ (อีเมอร์นะไม่ใช่อีมิล มันมีคนใช้เยอะๆๆๆๆ)
ได้ผ่าพลังของมันไปได้ โดยมีนางฟ้าไททั่น คอยช่วยเหลือทำให้เกิดการ คลาดเคลื่อน
และการหักเหของเวลา จึงทำให้มิติทุกภพทุกชาติ และลูกแก้วทั้งสองแตกสลายกลายเป็น
เศษขยะไปตามพื้นทำให้ไม่สามารถทำให้อโคเนียอยู่สงบ สุขต่อไปได้

แนะนำตัวละคร
1.อีเมอร์ (Emer )
ผู้ชายที่เก่งด้านการใช้ดาบที่สุดในโลกมีพลังพิเศษและกระบวนท่าอีกมากมาย
2.ไททั่น (Tition )
หญิงสาวที่แสวงหาธาตุต่างๆเพื่อรักษาเมือง
กลุ่มฟู๊ด
3.มีท (Meet )
อุ้ยเนื้อนุ่มๆ เอ้ยไม่ใช่ นี่มีทครับ ชายหนุ่มสุดอารมณ์ดีและเพียบพร้อมไปด้วยสายธนูอันเฉียบคม
4.แอนนา (Anna)
สาวน้อยทอมดี้แต่งตัวโป้เปรียว ใช้ดาบเป็นอาวุธ
5.คลาส (Class)
หนุ่มอัจฉริยะที่1ในดินแดนอโคเนีย
6.คู๊ก (Cook)
ไม่มีบทบาทอะไรมากนักเพราะเขาเป็นสิงห์แดนใต้ไม่มีเวลามาคุยกับเรา
7.นางหัตตฤดี(นางฟ้า)
เป็นเจ้าเมืองเงือกน้อย เมื่อก่อนอยู่กับไคบะแต่ตอนนี้...
8.ไคบะ
เขาเป็นคนที่ถูกครอบงำโดยShadowsoulจนเสียการควบคุมไป

Story เข้าสู่เนื้อเรื่อง
บทที่๑
หลังจากอีเมอร์ได้หลุดไปยังประตูเวลาที่คลาดเคลื่อน ทำให้ยุคสมัยทั้งหมดอารยธรรมต่างๆ ฟื้นขึ้นมา
- 2 เดือนให้หลัง กลุ่มนักสู้ฟู๊ดนักผจญภัยหน้าใหม่ได้เดินอยู่ที่ภูเขาเพื่อออกหาสมบัติล้ำค่าที่ตั้งใจไว้แต่แล้ว ก็เกิดเรื่องขึ้น พายุพลัดกระหน่ำ
ให้ลมฝนตก แต่จู่ๆ ก็มีอุโมงค์หนึ่งผุดขึ้นมาพวกเขาจึงเข้าปผักกันและเข้าสู่อารยธรรมที่สมบูรณ์แบบ
- หลังจากทื่กลุ่มฟู๊ดมาถึงเมืองอโคเนียไททั่นถูกพวกเดมไปส่งให้เงามืดที่แปลกประหลาด และไม่มีใครรู้ว่ามันคืออะไร แล้วอีกเพียง5เดือน
จะจับไททั่นบูชายันต์เพื่อความอยู่รอดของเผ่าพันธุ์
- อิเมอร์ หลังจากหลุดเข้ามาที่ห้วงกาล เวลา จึงทำให้เสียสติไปส่วนหนึ่ง แต่ก็ยังพบคนที่ใส่ชุดเก่าๆเป็นเด็กกลุ่มหนึ่ง และก็เข้าใจกันว่าพวกเขาหลุดมาจากห้วงเวลา ถ้าเรากำจัดต้นตอเรื่องนี้แล้ว เรื่องทุกอย่างจะไม่เกิดขึ้นอีกถ้าพลังมืดสิ้นสุดลง ทั้งหมดจึงไปที่พวกเขาเคยอาศัยเมื่อก่อนอีเมอร์เป็นคนเปลื่ยนคนอื่นให้เป็นมือดาบแต่ เดี๋ยวนี้เป็นลูกศิษย์ของเขา เขาทำแบบที่อิเมอร์บอกเขาทุกอย่างและหายไปอย่างลึกลับ

การเดินทางไปยังเกาะUndead

หลังจากการคลาดเคลื่อนของเวลา
อีเมอร์ และ เด็กๆได้ทำความรู้จักกับอโคเนียมากขึ้น และไม่ทราบข่าวคราวของไททั่นอีกเลย
อีมิลจึงเดินทางไปหานางฟ้า แต่ก็ได้รับคำแนะนำว่า จงเดินทางไปหาภูตทั้ง2เถอะ พวกเขารอเธออยู่ อีเมอร์จึงถามราชินีว่าไปทางไหนราชินีว่าทิศตะวันออกทางถำปลาศักสิทธิ์ และแดนนกไฟแห่งทิศใต้ อิเมอร์ฝ่าฟันมอนเตอร์มากมายจนถึงถ้ำอมตะ ชั้นสุดท้าย...
อีเมอร์พยายามช่วยภูต แม่น้ำโขง เอ้ยไม่ใช่ อีเมอร์จึงช่วย ภูตแห่งแสงไว้ได้จากหมีขาวส่วนพวก เด็กๆ ก็ออกเดินทางไปยังแดนปลาดิบ แต่ก็ไม่สำเร็จเพราะกระดูก ซากศพต่างๆก็ลุกขึ้นมา โจมตีแต่ก็หยุดลงเพราะ พลังการคุ้มครองของภูติดำ ภูตดำอาศัยอยู่ในป่าดงดิบ
