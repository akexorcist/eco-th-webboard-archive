แอสกับคอมมาโดใครเก่งกว่ากันคับ
คือผมเล่นแอสจนจอบ40แล้ว(อยากใช้สนับอะ)(อยากเล่นพิษด่วย)แต่จะรอจอบ50แล้วเปลี่ยนไปเป็นคอมมานโดมันก็นานและเอาสกิสไปได้เพิ่มอีกแค่1สกิสเอง จอบ40ก็ได้4สกิสและ และอาชีพคอมมารโดสกิสที่ผมสนใจมันก็อยู่จอบสูงๆทั่งนั้น เลยอยากรู้ว่าคอมมานโดถ้าเปลี่ยนไปแล้วมันจาเก่งกว่าแอสมะคับ
อย่างมัก่อนผมเล่น ranger คราส2แล้วพอเปลี่ยนไปคราส3ทั่งเลือดทั่งพลังต่างๆมันเก่งกว่าของคราส2อะ
แต่คราวนี้เล่นสายสนับกับพิษของแอสถ้าจะไปคอมมานโดก็เอาสกิสไปไม่พออะครับเลยอยากรู้ว่าคอมมานโดมันเก่งกว่า แอสมากไหม่ถ้านิดหน่อยได้ไม่เปลี่ยน

แอสพิษ (vit+agi+int) ป่วนในวอมากถึงมากที่สุดถ้ามีซอสิงเฟลคให้ แถมยังถึก พริ้วมหาศาลถ้ามีซอดีไวให้ต่อให้รุ้งยังไม่เกิน 500 เลยเพราะอัพ vit เยอะมาก int เยอะถ้าปาระเบิดแฟลชแม่น ๆ สามารถฆ่าสาย agi ได้ในพริบตาเดียว หรือพวกที่อัพ vit ไม่เยอะมากก็ตายได้เพราะระเบิดแฟลชสตันนานแต่โดนยาก และยังมีระเบิดใบ้ ที่ใช้ง่ายแค่วิ่งเข้าไปชาจใกล้ ๆ แล้วกดก็ติดใบ้ทันที ค่อนข้างนาน แถมแอสประมาณ 90% ใน nvn จะมีคนสิงมาด้วยแน่นอนเพราะมีสกิล clocking ดักตุ๋ยสบาย

com สายปืน (str+agi+int+vit) อย่างที่เห็นต้องแบ่งพ้อยอัพ stat เยอะมากถึง 4 ค่าถ้าจะเอาเลือดเยอะมันก็ยิงไม่แรงถ้าจะเอายิงแรงตัวก็นิ่ม ยิงเบากว่า gunner แต่ว่ามี clocking ทำให้เนียนตุ๋ยได้มากกว่า com 95% จะต้องมี sudden atk ของแอสติดมาด้วยสกิลตีหัวคนใช้ได้ตอน clocking มีโอกาสติดสตันด้วย dmg ถ้าตัวที่โดนทุบ vit ไม่เยอะมากก็แรงเอาการอยู่ และยังมีกับระเบิดของ com มากมายตามที่อยากอัพ ( แต่เอาจริง ๆ ผมว่าได้ใช้ไม่กี่สกิล ) และต้องใช้ความใจเย็นเป็นอย่างยิ่งในการตุ๋ยคนเพราะมันไม่ถึกแบบแอส โดนเวททีเดียวปลิวจริง ๆ เพราะเลือดอันน้อยนิดอัพ vit มาน้อย mdef กะ def ก็น้อยตามไปด้วยแต่ความพริ้วเยอะพอ ๆ กับแอสไม่ต่างกันมาก โดน gunner สอยทีเดียวตายเช่นกันแต่ถ้าสอย gunner ทีเดียว gunner ก็ปลิวเหมือนกันถ้าไม่มีคนสิงเวอร์ ๆ อ่านะที่สำคัญคือมันเท่ =w='

เลือกเอาเองละกันเนอะชอบแบบไหนพูดถึงแต่ใน nvn นะการเก็บเลเวลตอนเป็นแอสมันก็เก็บสบายทั้งคู่อยู่แล้วคงอัพสนับมาตีมอนกัน คงไม่มีใครอัพ vit ละเอาพิษให้มอนดมจนตายหรอกล่ะมั้ง
