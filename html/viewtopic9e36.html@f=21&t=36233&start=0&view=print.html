ผมฮิคุเระครับ หรือจะเรียกผมว่าฮิคุเรก็ได้นะ

และถ้าผมล่วงเกินคนบางคนไปก็ต้องขอโทดไว้ด้วยนะ


แล้วก็อีกเดือนสองเดือนก็จะลองแต่งฟิคดูสักเรื่องไว้ถึงตอนนั้นก็ช่วยชี้แนะหน่อยก็แล้วกันนะครับ
