ชุด Lv 70 น่ะมี

ของสาย Fighter ต้องขึ้นไปหอแสงชั้น 12 แล้วเดินออกไปที่ระเบียง

วนๆขึ้นไปจะเจอ NPC คนนึง นั่นแล่ะคนขาย

ส่วนของอาชีพทั่วไป จะอยู่ที่เมือง Morg

เป็นชุดแบบที่ดรอปวันตรุษจีนแล่ะ มี 2 สี และมีหมวกด้วย (คล้ายๆหมวกผีดิบ)

ร้านจะอยู่แถวๆจุดเซฟ

จากจุดเซฟ เดินลงบันไดไปทางทิศ "เหนือ"

ลงบันไดปุ๊บ ให้มองหันย้อนกลับมา จะมี 2 ร้าน ซ้ายมือและขวามือ

ซ้ายมือขายเครื่องประดับ และขวามือนี่จะขายชุด
