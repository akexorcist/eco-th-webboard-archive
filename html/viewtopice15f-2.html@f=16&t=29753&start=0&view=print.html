สำหรับมอนบางตัวจะมี type เป็น plant ด้วยนะ แล้วสกิลจะมีผลกับพวกนี้ด้วย แนะนำว่าอัพไปทั้งคู่เหอะ เพราะของบางอย่างจะไม่ดรอปถ้าเราไม่มีปราช เช่นกลีบดอกไม้ hard branch

เรื่องทำของ ถ้าจะเอาที่ไม่มี npc ทำ นี่ก็มี
1 ทำสวน(gardening) กำลังขายได้ดี เนื่องจากสวนมันเพิ่งมา เอาไปประดับได้ (สำหรับผมที่อยู่ในสวนเอาหลักๆ แค่ตู้เท่านั้นแหละ อย่างอื่นมีไม่มีช่างมัน)
2 ซ่อมผ้า(sewing kit) เสื้อผ้าทุกอาชีพ ต้องใช้ทั้งนั้น
3 ซ่อมไม้(wood kit) อาจจะมีของที่ต้องการให้ซ่อมแค่ไม่กี่อย่าง แต่ก็ขายได้เหมือนกัน
สกิลซ่อมไม้ ซ่อมผ้าจะดีขึ้นอีกถ้าสกิลทำไม้ ทำผ้า สูงด้วยนะ

ส่วนสกิลสร้างของจากที่เล่นมาประหยัดตังไปประมาณ 5-6 หลักได้อะ
