เงื่อนไข จำเป็นต้องเปิดการใช้งานคุ๊กกี้ของเว็บเบราเซอร์ที่เราใช้เข้าเกมอยู่ อาทิ IE,Firefox


1. เมื่อเข้าไปหน้าเว็บล๊อคอิน ให้คลิกที่ Account Tool จำแหน่งมุมขวาบนตามรูป



2. หลังจากนั้นคลิกที่ปุ่มดังภาพ ตำแหน่งปัจจุบันอยู่ด้านล่างขวาสุดของหน้าเว็บเพจ



3. คลิกที่ปุ่มดังภาพอีกครั้ง



4. ระบบจะแสดงอีเมล์ที่เราใช้ลงทะเบียนอยู่ และจะใช้อีเมลนี้เพื่อส่งลิ้งไว้สำหรับสร้างไฟล์ Cookies ไว้ในเครื่องที่ต้องการจะเข้าเกม


5. ให้เราเข้าไปเช๊คอีเมลของเรา ซึ่งหัวข้อจะเป็นดังนี้ จากนั้นก็ Copy ลิ้งไปเปิดในหน้าต่าง IE ที่เราใช้เข้าเกม



6. เมื่อหน้าเพจโหลดเสร็จ จะขึ้นหน้าต่างยืนยันการสร้างคุ๊กกี้ที่ไว้ใช้สำหรับล๊อคไอดีไว้ในเครื่องของเรา

กดปุ่มที่ ログインぺージへ　เพื่อกลับไปที่หน้าล๊อคอิน


7. ล๊อคอินเข้าเกมตามปกติ =w=~♬


____________________________________________________________________________________________

ข้อดีคือ เมื่อมีเครื่องอื่นมาล๊อคอิน ID เรา ในกรณีที่ไม่ได้บันทึกคุ๊กกี้ไว้(หลังผ่านขั้นตอนที่ 6.) IP เครื่องนั้นจะถูกส่งเข้ามายังอีเมล์ของเราว่าได้มีการล๊อคอินมา ณ เวลานั้นๆ และจะไม่สามารถล๊อคอินเข้าไอดีของเราได้จนกว่าจะผ่านกระบวนการขั้นตอนที่กล่าวไว้ดังต้น ส่วนเครื่องที่ทำแล้วก็แค่ล๊อคอินเข้าเกมปกติ ไม่จำเป็นต้องทำขั้นตอนซ้ำ ยกเว้นเราไปลบไฟล์ Cookie นั้นทิ้งไปภายหลัง

สรุปโดยย่อ เป็นระบบป้องกันคน Hack ID ดีๆนี่เอง
