เพราะเป็นstat ตอนที่เววมันตันที่80
จริงๆมีแต้มเหลืออีกเยอะมากๆครับ

int ผมอัพรวม50 นะถ้าจำไม่ผิด หรือรวม40นี้แหละ

สกิว50 ก็ใช้งานดีนะ ไปชั้นบนสุดหอแสงแจ่มใช้ได้เลย
ส่วนเรื่องติดง่าย หรือยาก อันนี้มันก็แล้วแต่มอน
ผมกะจะอัพagi มาช่วยเสริมไง หน้าก่อนเคยถามไปเรื่อง
Agi ช่วยให้ร่ายสกิว50 ไวขึ้นไหมเพื่อเหตุนี้หละ
ยังไงไรออทมันต้องไวขึ้นแน่ๆอยู่แล้ว(สำหรับผมไรออทร่ายลดไปครึ่งนึงก็okแล้ว)
แต่ถ้าเราจะลงทุนอัพagi เพื่อทำได้แค่ไรออทเนี่ยผมว่ามันดูจืดไปนะ
ผมเลยกะว่าถ้ามันทำให้ สกิว50 ร่ายไวขึ้นก็ยอดเลย
ใช้ใส่มอนได้หลายทีหน่อย ในเวลาไม่นาน
ดองแต้มไว้อยู่อีกพักจะกดอัพ statตอนนี้เลยอยู่ที่
Vit mag ประมาณ 70-80
int ก็รวม50ได้ (ตอนนี้เป็นเทรดเดอร์)

แต่เอาเข้าจริงไม่ได้ใช้นักหรอกไรออทอ่ะ
แล้วแต่โอกาสจริงๆ ตอนนี้ยังมีโควต้ารีฟรีอยู่
ถ้าจะรีก็กะไว้ว่าจะเปลี่ยนมาสาย Mag 100 ที่เหลือก็Vit ไปเลย
แล้วปรับมาใช้ Random healing lv อื่นแทน หรือยังไงก็ดูตามสถานการณ์
ผมไม่ได้ใช้พัดเหล็กนะ ผมใช้พัดกระดาษขาวๆที่ไม่มีความทนทานอ่ะ
เพราะยังไงใช้พัดเหล็ดไปเวลาเราฮิวเลือดมันก็ลดเยอะกว่าเดิมเปล่าๆ
(แต่ก็ปรับเปลี่ยนเอามาใช้บ้างบางสถานการณ์ ส่วนนี้ก็ค่อยว่ากันไป)
