1. มีสกิลของไนท์สกิลไหนบ้างไหมที่ใช้ค่า mac โจมตี
2. ถ้าจะเล่นเพื่อ pvp ควรเล่นสายไหน เผ่าอะไร
3. ถ้าเก็บเวลคนเดียวสายไหนสบายสุด
4. ถ้าเล่นสาย mac vit เป็นไนท์ นี่คือหมดสิทธิ์เก็บเวลคนเดียวเลยใช่ไหม
5. ถ้าเล่นสาย mac vit เป็นไนท์ จะ PVP สู้คนอื่นไหวไหม
6. เท่าที่ดูรูปที่เอามาลงกันส่วนมาก ไนท์ กับ ds จะเป็นเผ่าเทพซะส่วนใหญ่
