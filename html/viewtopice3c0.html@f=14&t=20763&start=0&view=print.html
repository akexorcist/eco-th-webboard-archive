ร้านขายของอยู่ข้างในปราสาทอันเดตครับ
วิธีทำก็คือขึ้นไปที่ชั้น 5 ของ Undead Castle นะครับ

หาห้องของเจ้าหญิงให้เจอแล้วคุยกับเธอ

เธอจะให้เราหา ต่างหู ของท่านแม่ 2 ข้าง ซ้ายกับขวา

จะเปิดร้านใหม่อีกครั้งก็ต้องหา ต่างหู ใหม่อีกรอบนะครับ
