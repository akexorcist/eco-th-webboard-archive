สายสนับ เรามาทราบข้อดีก่อนเลยละกัน

1.ฟันเร็วมาก (ยิ่งเร็วก็ยิ่งแตกT-T)

2.ไม่เปลืองยาปั้มเหมาะกับพวกไม่มีเงินหรือขี้เกียจเดินซื้อยา

ผมทําได้ละกัน)

และข้อเสียของสายสนับคือ

1.แตกง่าย ต้องซื้อของมาซ่อมบ่อยแนะนําให้สิงมือขวาไว้จะไม่แตก

2.ราคาแพงอย่างแรง สนับ80กับ90 (เป็นแสนอ่ะผมหายากนะยุคนี้

เศรษกิจตกต่ำ เหอๆ)
