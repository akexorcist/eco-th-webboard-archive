โดย ECO
ไม่รู้ว่ามีคนโพสแล้วรึยัง แต่อยากทำเพราะใจรัก..ล่ะมั้ง



จุดรับเควส : ①

เข้าไปข้างในแล้วคุยกับนักเขียน Jiggy โดยให้คุยจนกว่ามันจะขอร้องให้เราช่วยเหลือมันในการหาหลักฐานเพื่อเขียนข่าวเปิดโปงการทุจริตของ Diamant หน่อย ให้ตอบตกลงไป จากนั้นมันจะวานให้ไปหาคนที่ Fighter Giuld ที่อยู่ติดๆกัน

Fighter Guild : ③

เข้าไปแล้วให้คุยกับ Violet ที่อยู่ข้างใน บอกว่า Jiggy ขอร้องให้เรามา เขาจะให้เราไปหาคนอีกคนที่โรงถลุงของเมือง

โรงถลุง : ⑤

เข้าไปแล้วให้คุยกับ Hinmeru บอกว่า Violet ใช้ให้เรามา เขาจะบอกเรามาว่าคนที่มีหลักฐานมันหนีขึ้น Light Tower ไปแล้ว..รออะไรกันล่ะ วิ่งขึ้นหอคอยกันเถอะ

Light Tower :

เนื่องจากที่นี่ไม่มีแผนที่ หรือต่อให้มีก็เดินหลงได้อยู่ดี ผมแนะนำให้เปิดมองช่อง system ไว้จะได้รู้ว่าตอนนี้เราอยู่ชั้นไหน และทางที่ดีพกพระมาด้วย เพราะศัตรูหลายตัวมันโจมตีก่อน (ผมเอาแม่ค้า 52 มาทำเควสคนเดียวก็วิ่งพอไหวนะ)

Light Tower ชั้น A-8F　รอบนอกหอคอย :
ที่นี่จะมี NPC ชื่อ Doubtful Man ให้เข้าไปคุย แล้วตอบว่า "มีหลักฐานมั้ย" มันจะหัวเราะแล้วบอกว่าแกมาสายไป เพราะมันโยนหลักฐานลงทะเลไปแล้ว (น่าเตะจริงๆ)
แน่นอนว่าอย่าพึ่งยอมแพ้ ให้เราวิ่งลงมาชั้น Main Floor

Light Tower ชั้น Main Floor - 1F :
พอมาถึงแล้วให้วิ่งออกนอกตึก จากนั้นให้วิ่งรอบไปจนกว่าจะเจอทางยื่นออกไปคล้ายๆท่าเรือ ให้วิ่งไปที่แท่นที่มันยื่นออกมาไกลสุด ดังรูปข้างล่างนี่




แล้วเราจะเห็นอะไรบางอย่างติดอยู่ที่ปลายสะพาน ตอบสำรวจแล้วจะได้ proof file มา

เสร็จแล้วให้กลับไปหา Jiggy เขาจะให้รางวัลมา 5000G แต่สิทธิพิเศษไม่ได้จบแค่นี้

Merchant Guild : ②
ที่นี่จะมี Diamant และพนักงานขายของ 2 คน ซึ่งถ้าปกติเราไม่ได้ทำเควส พนักงานจะขายแค่รองเท้า กับ กระเป๋าดำ แต่ถ้าเราทำเควสเสร็จแล้วจะมีของมาขายเพิ่มดังนี้






Sepheria เขียน:Event นี้นอกจากเปิดร้านชุดและกระเป๋าแม่ค้าแล้ว ยังช่วยลดค่าตั๋วไป Light Tower อีกครึ่งนึงด้วยนะ ถ้าทำเสร็จครั้งต่อๆไปถ้าจะไป Light Towerจะเสียเงินแค่ LV x50 g จาก LV x100g

ขอบคุณ คุณ Sepheria สำหรับข้อมูลเพิ่มเติม

จริงๆกว่าจะ 80 ไม่ต้องรีบทำก็ได้ แต่กระเป๋าสวยๆทั้งซ้ายขวามันล่อใจแม่ค้ามากเลยล่ะ =w=] ใส่แล้วดูเป็นนักธุรกิจดี

หมายเหตุ : ราคาที่เห็นเป็นราคาที่ลดแล้วจากสกิล Discount ของแม่ค้าและชุดที่ขายเป็นชุดที่ใส่ได้ทุกอาชีพ สลับกับชุดของ Spell User (ชุด Fortune Teller)
ข้อมูลเพิ่มเติม : ร้านอัญมณีเมืองนี้มี Red,Blue,White Talisman ขายด้วยนะ อันละ 40k แม่ค้ามาลดก็เหลือ 32k เลยทีเดียว.. แบบนี้ของผลิต กับตัวสินค้าราคาตลาดคงตกลงฮวบฮาบกันเลยล่ะนะ.. - -" อ้อ นอกจากนี้ร้านขายอาวุธมีสนับมือ แส้ พิณ ขายด้วยนะ
