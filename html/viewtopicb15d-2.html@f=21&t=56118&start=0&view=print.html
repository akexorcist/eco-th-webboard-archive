โลกนี้ล้วนแต่มีแต่ความเศร้าหมอง...คนต่างเริ่มคิดค้นคำว่าวิทยาศาสตร์มาแทนการใช้เวทย์จนกระทั่งพ่อมดแม่มดต่างสร้างสิ่งที่เรียกว่ามอนเตอร์ขึ้นมา เช่น Pururu Bau และ
มอนเตอร์อีกหลายตัวซึ่งมอนเตอร์เหล่านั้นเคยเป็นสัตว์เลี้ยงของมนุษย์มาก่อน
นางปีศาจจึงถือกำเนิดมาในฐานะมอนเตอร์แต่แล้ววันหนึ่งเมืองหนึ่งที่ชื่อดาวน์ทาวน์
กำเนิดขึ้นมา และตามมาด้วยอัพทาวน์ซึ่งอยู่เป็นเมืองหลวง และเมืองแห่งเวทมนต์น็อท และเมืองไอรอน เมืองฟาร์มอีส เมืองทอนก้า นรก สวรรค์ต่างๆและทางเชื่อมต่อระหว่างพิภพ

ตอนที่1 สิ่งก่อสร้างที่เสีนสมดุลย์

นานครั้งแล้ว ที่เมืองใต้ กับ เมืองม็อคได้ เป็นเพื่อนสนิทกัน เจ้าเมืองของม็อคคือ ปรมจารย์จอมเวทย์ เมืองใต้เป็นนักเล่นแร่ชื่อดังตามหาแร่ต่างๆจึงสร้างเหมืองแร่ไว้มากมาย
ต้นเหตุของเรื่องราวทั้งหมด เรื่องมีอยู่ว่า...
ปรมจารย์จอมเวท นาม...สตาร์เชี่ยล หลังจากเมืองใต้ได้ดูถูกเมืองม็อคด้าน เวทย์มนต์

จึงทำกำแพงล้อ3ภิพบขึ้นมา นานนับ100ปี....
เรื่องนี้ลามไปอย่างรวดเร็ว จนทหารเมืองของตน ....นำเรื่องนี้ไปบอกราชินี
ราชินีรู้เรื่องนี้จึงหานักผจญภัยต่างๆที่เปี่ยมไปด้วยเมตตา...มิตรภาพ...สดใส
