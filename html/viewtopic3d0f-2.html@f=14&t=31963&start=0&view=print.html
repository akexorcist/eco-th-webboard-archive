อยากรู้อันใหนแรงกว่า มาคิดดูครับ

War Fork มี atk (ทุบ) 28 และมี atk (แทง) 58
สมมติให้ตัวละครมี max. atk. เมื่อไม่ใส่อาวุธ อยู่ที่ 500

และเมื่อใส่หอกตัวนี้เข้าไป ท่าของตัวละครก็จะถูกเปลี่ยนเป็นการแทง ทำให้มี max. atk. 558

กด LS ซึ่งเป็นท่าแทง ความแรง 210%
คำนวณค่า atk ที่ทำได้คือ 558 คูณ 2.1 = 1,172

และเมื่อกด BB ซึ่งเป็นท่าทุบ ความแรง 270%
เมื่อเป็นท่าทุบ max. atk. ก็จะลดลงตาม status ของหอกครับ ซึ่งจะได้แค่ 528
คำนวณค่า atk ที่ทำได้คือ 528 คูณ 2.7 = 1,426

ตัวเลขมันบอกครับว่าอันใหนแรงกว่ากัน

ปล. แต่การใช้งานจริงขึ้นอยู่กับว่า Atk ที่ทำได้จะแกว่งมากน้อยเท่าไรนะครับ
