1. Item ประเภท Replica หลอมติดดาวได้หรือป่าวครับ

2. Item ประเภท Replica ใส่ได้ทุกอาชีพหรือเปล่าครับ

3. ถ้าสามารถหลอมและใส่ได้ทุกอาชีพ ผมสามารถหลอมดาบ Replica กับแส้ของ Tresure Hunter ได้หรือเปล่า ครับ โดยส่วนแสดงภาพเป็น ดาบ ประเภท Replica และส่วนความสามารถเป็นแส้

4. อันนี้ขอถามเพิ่มเติมครับ ธงรักพ่อ เอาไปหลอมติดดาวกับอะไรดีครับ โดยความสามารถเป็นของธงรักพ่อ ส่วนภาพเป็นของเครื่องประดับติดอกอื่นๆ พอดีหาเครื่องประดับติดอกที่ NPC ยอมให้หลอมกับธง ยากมากเลยครับ เท่าที่มันให้หลอมรวมได้มีแค่ เครื่องหมาย Breeder อันเดียวเอง อื่นๆมันไม่ให้เลย
