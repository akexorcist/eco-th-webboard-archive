“ บางสิ่งที่ข้า ... มิเคยพบมาก่อน สองสิ่งที่ทรงพลานุภาพเหนือสิ่งใด หากแต่กลับแตกต่างกันโดยสิ้นเชิง การปรากฏตัวของทั้งสองสิ่งนั้นทำให้ ‘ บางสิ่ง ’ ที่เหนือกว่านั้นเคลื่อนไหวเสียแล้ว ”


ใช้คำว่า "สิ่ง" เยอะไปหน่อยอาจทำให้บางคนอ่านแล้วรู้สึกขัดๆ ถ้าเป็นไปได้ลองเปลี่ยนบางบรรทัดดีกว่า

ประมาณว่า "กระปรากฏตัวของทั้งสองสิ่ง ทำให้มีอะไร "บางอย่าง" เริ่มเคลื่อนไหวแล้ว" บราๆๆ

คงเพราะถูกพลังในด้านที่ตนเองแสนจะรังเกียจเข้าทำร้านกระมัง? ถึงได้รู้สึกแน่ถึงเพียงนี้ ...


ไม่ต้องเอื้อนเอ่ย ใดๆ

แต่มันก็ช่วยไม่ได้นี่ อาจจะทำให้เวลน์สบายใจขื้นบ้างก็ได้นี่นา


ไม่รู้ว่าจะต้องการสื่อแบบไหน แต่ถ้าเป้นแบบที่โนเข้าใจ ไม่น่าเรียกเวลน์ ด้วย ชื่อแบบนั้น

เพราะมันให้ความรู้สึก "เหินห่าง" สุดๆ เพราะไม่ใช่บุคคลที่ 3 แต่กลับถูกเรียกด้วยชื่อ


เวลน์ที่หันหลังให้กับรินกะอยู่นั้นถึงกับตาเบิกกว้าง ใบหน้าร้อนผ่าน หัวใจเต้นแรงราวกับจะพุ่งทะลุออกมาจากอก นี่แค่จูบหน้าผากนะ


หันหลัง + นอนตะแคง แล้วจะจุ๊ฟจากข้างหลังยังง๊ายยย จิ้นไม่ออก

อา ... บ้าไปแล้วสินะ


น่าจะใส่นามซักนิด ว่าใครบ้า เพราะดูแล้ว "บ้า" ทั้งคู่เลย


เวลน์หรี่สายตาลงเล็กน้อยราวกับว่ากำลังพินิจพิจารณาอีกฝ่ายที่บัดนี้กำลังนอนฟุบคาโต๊ะอ่านหนังสือมุมดีที่สุดของเขาอยู่


นึกว่าจะเจอ เซวี่ เดาพลาดเลยเรา


“ ยัยเซวิเนียร์ส่งแกมาหรือไง? ” มาถึงตรงนี้ชายหนุ่มปริศนาเข้าประชิดตัวเวลน์มากกว่าเดิม มือของเขายกขึ้นจับคอเสื้อของเวลน์เอาไว้พร้อมกับดึงขึ้นด้วยแววตาคาดคั้นใน บางสิ่ง ไม่รู้ว่าทำไมเวลน์กลับไม่รู้สึกกลัวเลยแม้แต่น้อย หากแต่รู้สึกแอบขำในใจเสียมากกว่า “ เดี๋ยวนี้ยัยนั่นมีคนทวงหนี้ด้วยรึ? หืม ... ”


เผากันซึ่งๆหน้า -___ -
