เคยเข้าไปทำ สองสามรอบ
ถ้าเดาไม่ผิดมันจะบังคับให้วิ่งครบทุกห้อง ( ทุกแยก )
ถ้าไม่ครบ ยังไงก็ไม่เจอ

รอบแรกวิ่ง ด้วยเกาะกำแพงด้านซ้าย ไปเจอ ห้องขวาสุด( ทางสุดท้าย )

รอบสอง เอาใหม่ เลาะกำแพงด้านขวาดูสิ
ไปเจอ ห้องซ้ายสุด( ทางสุดท้าย )

รอบสามเอาใหม่ วิ่ง ซ้ายไปครึ่งนึง แล้วก็วิ่งขวาอีกครึ่งนึง
ไปเจอตรงกลาง(ทางสุดท้ายเช่นเคย)

ประมาณว่า มีปลายทาง 20 ทาง
หากไม่เปิดทางครบ 19 ทาง ก็จะไม่เจอห้องสุดท้ายแน่นอน

บังคับให้ไปกันหลายๆคน แยกกันเดิน หากเดินเป็น ก็ไม่น่าจะเกิน ชม.
