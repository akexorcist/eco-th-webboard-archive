กฎ ระเบียบการใช้งาน Chat Palringo
• ชื่อกลุ่ม : neco ( ใช้ในการเข้ามาในกลุ่มแชทปาลริงโก้ )
• ใช้คำพูดที่สุภาพ ไม่หยาบคาย ด่าทอ ยุแยง ใส่ร้าย หรือ เสียดสีผู้อื่น
• ห้ามโพสต์ข้อความ รูปภาพ หรือลิงค์ที่ขัดต่อศีลธรรม วัฒนธรรม ขนบธรรมเนียมและประเพณี หรือเรื่องที่ไม่เหมาะสมอื่นๆ
• ไม่รันข้อความ พิมพ์ข้อความเร็วจนเกิน ควรเว้นวรรคการพิมพ์บ้าง
• อย่าใช้ Emotion เยอะเกินความจำเป็น
• ควรงดคุยเรื่องการเมืองในห้องแชท
• ถ้าไม่เข้าใจให้กลับขึ้นไปอ่านข้างบนใหม่

กฎ กติกาภายในเกม Neco
• อย่าทำป้ายเป็นภาษาไทย
• ถ้าไม่จำเป็นพยายามอย่าพิมไทยออกมาจนบ่อยเกิน
• อย่าตั้งชื่อตี้ว่า ไทยเท่านั้นอะไรทำนองนี้
• ใช้คำไม่สุภาพในการพูดคุย หรือประกาศข้อความ รวมไปถึงการพูดหรือประกาศข้อความใดๆ ที่เป็นการรบกวนผู้อื่น
• ห้ามไม่ให้ผู้เล่นกระทำการใดๆ ทีเป็นการก่อกวน หรือขัดขวางการเล่นของผู้เล่นอื่น
• ห้ามผู้เล่นใช้ และรับผลประโยชน์ใดๆ ทั้งสิ้น
• ห้ามใช้ Bug ของเกมในการแสวงหาผลประโยชน์ใดๆ
• ขอให้ความเคารพในกฏด้วย ไม่เช่นนั้นทางเกม Neco อาจจะบล็อค IP บ้านเราก็เป็นได้

ขอนิดหนึ่งเนาะ เราว่าเข้าใจผิดประเด็นค่ะ เราไม่ได้เคืองคนที่อ่านแล้วไม่พอใจเรา แต่เราเพิ่งได้รู้ความจริงว่า คนที่มาบอกเราว่า ขอบคุณครับ จะเป็นคนๆเดียวกะที่ทำการบล็อกเฟสเราก่อนจะพิมข้อความนี้

" แต่บางคนก็น่าเบื่อนะ บอกไปก็ถามแล้วถามซ้ำ (รวมเราด้วย) แต่ว่าบางท่านก็อาจจะตอบแรงไปหน่อย ไม่รู้ว่าเพราะอะไร กะแค่เกมๆนึงที่ตัวเเองชำนาญ แต่อีกคนเขาไม่ชำนาญเขาก็อยากจะรู้คำตอบ แต่ดันไม่ตอบหรือตอบอ้อมๆแล้วแอบ"ด่าทางอ้อม"อีก โดยความคิดส่วนตัวคงไม่ว่าอะไรเกี่ยวกับเรื่องงี้ แต่ก็เกลียดนัก คนที่ชอบเอาคนอื่นไปนินทาไปว่าอยา่งงู้นอย่างงี้ ด่าคนอื่นอ่ะเก่งจัง ใช้รูปการ์ตูนขึ้น ทำไมไม่ใช้รูปจริงขึ้นจะได้เห็นๆหน้ากันเลย จะด่าก็ด่า แล้วก็จะจำไว้ แต่ถ้าด่าอ้อมๆหรือทำการประชดประชันแบบนี้ก็ไม่ไหวอ่ะ"

กรุณาอย่าคิดว่าคนเขาจะไม่รู้และไม่เห็น คุณผิดใจกับคนอื่นมากี่คนละคะ ด้วยการกระทำแบบนี้ อย่างที่คอมเม้นข้างบนบอกละกันค่ะ ต่อไปนี้ก็ทางใครทางมัน ก็เลิกแล้วต่อกัน เราขอโทษกับข้อความที่ได้พิมๆไปละสร้างความไม่พอใจ ส่วนคุณ เราไม่ต้องการคำอธิบายแต่ควรจะคิดมั่งนะคะว่ากำลังทำอะไร สวัสดีค่ะU_U
อย่ามาว่ารูปจิบิสุดเลิฟหนูว่าเป็นการ์ตูนเห้ๆซิคะ มันดูดีกว่า2หน้าแบบบางคนเยอะมากๆเลยนะ

ที่หาว่าเข้าใจผืดนี่คงมีคนเข้าใจผืดเยอะเนอะครับถ้าแบบนั้น ก็อีกกลุ่มก็ไม่รู้จะบล้อคผมด้วยทำไม ประชดประชันจริงๆ ไม่อยากจะพูดดีๆสักเท่าไร แต่ก็ถนอมน้ำใจไว้บ้าง เพระว่าเราเป็นคนพอมีมารยาทกับคนที่ดีด้วย หรือไกล้เคียง ก่อนที่เราจะมาโพสต์ เราก็ถามทุกๆคนแล้ว ว่ายังไงดี ใครผิด อันนี้ไม่อยากตอบครับว่าใครผิดไม่ผิด ผมก็ไม่ได้คิดว่าตัวเองถูกเสมอนะ แล้วไอเรื่องแอดมินกลุ่มคุมอำนาจคนเดียว ก็คืออยากหาคนที่จิตใจดี คอมเมนท์ดี ฉลาดมีการศึกษา ไม่ใช่แค่เก่งและเป็นคนคอมเมนท์และโน้วน้ามที่ดี ไม่ใช่จะแอด คนกึ่งๆเข้าเป็นแอดมินก็แอด บอกว่าให้เข้ากลุ่มไปดู ก็ดันบล็อคเราไว้ตั้งนานแล้ว อัดอั้นกันมานานแล้วทั้งเพื่อนๆในเกม แลดเพื่อนๆในกลุ่มที่เขาเอาข้อมูลมาบอกเรา ผมทำอะไรผมคิดดีแล้วครับ ไม่ชอบคนนินทาลับหลัง บอกตรงๆถึงได้อยู่กันได้ด้วยดี จริงๆมาคไม่มช่เป็นคนที่พิมพ์มีมารยาทนะถ้ามาแบบนี้ ไม่รู้อ่ะยังไงมันก็ "แหล" กันอยู่แล้วในเมื่อเหตุการณ์แบบนี้เกิดขึ้น ทำมาเป็นพูดดีกัน ^^ ผมคิเถูกละครับ คนอื่นๆก็คิดแบบผมส่วนมาก ถ้าคิดว่าผมทำอะไรควรรู้บ้างควรส่งข้อความไปบอกพวกเขาครับ คนที่ในกลุ่มเกือบร้อยคน ไม่อยากพาดพิงไรมากวีรกรรมต่างๆเยอะ
