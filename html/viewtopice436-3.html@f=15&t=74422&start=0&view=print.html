paxg4567 เขียน:แล้ว อัพ อะไร มาก สุด อ่าคับ สาย สาป Int หรอคับ

ผมว่า vit ดีกว่ามั้งครับ
Vit ~90+
Dex ~70+ (กะให้บวกของกับโบนัสอาชีพแล้วลง 90 99 108)
Int ~60+ (อันนี้คือที่เหลืออ่ะครับ ถ้าเอา Dex แค่ 90 จะได้ Int ซัก 70 ถ้าเอา Dex 99 108 Int ก็จะน้อยลง)

ตรงนี้ที่ลง int น้อยกว่าเพราะเห็นว่าผลของ Vit มันชัดเจนกว่าอ่ะครับ ได้ทั้งอึดโจมตีและอึดเวท
แล้วถ้าเผื่อในตี้มีซอโอนอิ้น Int เราก็ไม่จำเป็นต้องอัพเยอะด้วยครับ
(แต่ถ้ามีซอโอนอิ้นตลอด ผมว่าเล่นสายผสมไปเลยก็ดีนะครับ ไม่ต้องลง Int เอง)
