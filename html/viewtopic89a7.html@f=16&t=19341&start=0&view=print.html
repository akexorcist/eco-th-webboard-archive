Cystal Knowledge
Job.51
- มีการเปลี่ยนรูปร่างแร่ที่ดรอปอัญมณีเป็น แร่คริสตัล มีผลกับปราชญ์นี้เท่านั้น
- เปลี่ยนชนิดมอนเตอร์พวก Zircon เป็นมอนประเภทเพชร
- Summon Stone ธาตุต่างๆจะไม่ตกแบบง่ายๆอีกต่อไป มีผลตกง่ายเฉพาะปราชญืชนิดนี้

Accessory Create
Job.53
Max: Lv.5
SP: 5
- ผลิตเครื่องประดับ
- ผลิตกับป้าเสียตังแล้วด้วยครับ

Accessory Repair Kit
Job.54
- ใช้ระบบการผลิตเดียวกับชุดซ่อมชนิดอื่นๆ
Copper >> Cut Out Machine + Copper Rasp (item ใหม่)
Silver >> Diamond Power + Silver Rasp (item ใหม่)
Gold >> 2 Cut Out Machine + 5 Great Pebble + Gold Rasp (item ใหม่)

Rock Stop Blow
Job.57
Lv.1 [ATK 50%]
Lv.2 [ATK 80%]
Lv.3 [ATK 110%]
Lv.4 [ATK 140%]
Lv.5 [ATK 170%]
- มีโอกาสโจมตีแล้วทำให้มอนเตอร์เป็นหิน ( ไม่ใช่สาปนะ )
- คงใช้ Combo กับ Rock Crusher

BP Knowledge Harmony
Job.60
Max Lv. 1
- ถ้ามีอาชีพ BP อยู่ในปาร์ตี้บริเวณใกล้ๆ ปราชญ์ชนิดต่างๆที่มีจะส่งผลถึงผู้เล่นทุกคน โดยมีโอกาส 50% ที่จะแสดงผล
