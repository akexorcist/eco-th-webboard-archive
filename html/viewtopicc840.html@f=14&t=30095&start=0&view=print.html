ของเราเริ่มมาเป็นสาย Str-Int ก่อนอ่ะ

1-10 รอบเมือง + แว็บไปทางทะเลสาบบ้าง
11-20 ทะเลสาบ + แมปหน้าถ้ำปลากระโห้
21-30 ถ้ำปลา ชั้น 2-3 เลย วิ่งลาก Rocky มาทีละตัว ให้สัตว์เลี้ยงเราอยู่ข้างหลัง
แล้วพอ Rocky อยู่ใกล้สัตว์เลี้ยง ให้ยิงมัน 1 ที Rocky จะเปลี่ยนเป้าไปหาสัตว์เลี้ยงเราทันที
แล้วก็ ซอยยิกเลย (ใช้ได้เฉพาะ Rocky เน้อ Cave กะหุ่นกระบอก ใช้ชาร์ตArrow เอาแล้วกัน)
31-40 มี Dual Arrow แล้ว ลงดันน้ำแข็งเลย เปลืองยานิด เสี่ยงหน่อย แต่ขึ้นพรวดๆ
41-50 หน้าปราสาทอันเดท เน้นยิงเป็ดดำ กะนางไม้ ม้าขาวกะFury อย่าเพิ่งไปยุ่งกะมัน
50-60 ที่เดิม อัพMulti แล้วสอยหมดMap ขึ้นดีเหมือนกัน แต่ถ้าหาตี้ได้ แนะนำฟูชิกิ

พอถึง 60 เีรารีเป็น Str-Agi-Int แล้วเปลี่ยนกันเนอร์อ่ะ แล้วลุยรอบๆหอคอย
