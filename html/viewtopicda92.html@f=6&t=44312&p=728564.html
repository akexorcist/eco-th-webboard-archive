มันเป็นเรื่องทางเทคนิคเกี่ยวกับโปรโตคอลที่ใช้ในการคุยกันระหว่าง client กับ server นะคะ เป็นเรื่องของโปรโตคอล TCP/IP ถ้าคนที่เรียนเกี่ยวกับคอมพิวเตอร์จะทราบค่ะ

โดยสรุปก็คือ เมื่อ client กับ server สร้าง connection ในการติดต่อกันได้แล้ว (หรือเรียกว่า socket) ทั้งสองฝั่ง ก็จะรอรับข้อมูลจากอีกฝั่งนึง ไปเรื่อย ๆ จนกว่าฝั่งใดฝั่งหนึ่ง จะส่งข้อมูลบอกอีกฝั่งว่า ขอตัดการเชื่อมต่อ

ทีนี้ ถ้าเราเน็ตหลุด หรือเครื่องแฮง ทาง server จะไม่รู้เลย ว่าเราไม่อยู่แล้ว (เนื่องจากเราไม่ได้ส่งข้อมูลไปบอกว่าขอตัดการเชื่อมต่อ เพราะเราเน็ตหลุด ไม่ได้ออกจากเกมตามปกติ) server จะรู้ ว่าเราหายไปแล้ว ก็ต่อเมื่อ server จะพยายามส่งข้อมูลมาหาเราอีกครั้ง แล้วพบว่า เราไม่ยอมตอบรับ เมื่อนั้น ทางฝั่ง server ถึงจะตัดการเชื่อมต่อค่ะ
