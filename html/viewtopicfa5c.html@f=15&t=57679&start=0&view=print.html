เหมือนเคยได้ยินแว่วๆมาว่า Reborn ของเนโครมีโอกาศติดกะไม่ติด ก็เลยสงสัยว่า All rate up ของคาบาจะส่งผลให้ติดง่ายขึ้นรึเปล่าครับ

แล้วมอนจาก Reborn นี่เกิดมามันกัดเราเลยหรือกัดมอนทั่วไปก่อนครับ
แล้วก็ถ้าเรารวมด้วยช่วยอัดจะได้Expเต็มๆรึเปล่า
พอดีไม่ได้เลยนานความจำมันเลือนๆ กำลังจะswitchพอดี กะเอา Mark ไปเลยเอา All rate up
ไปไม่ได้ = = ใครรู้ช่วยตอบทีครับ

โดยส่วนตัวผมคิดว่าน่าจะอัพไว้นะเพราะช่วยให้สาปติดสถานะผิดปรกติง่ายขึ้นอะ
Skill Reborn ก็ถือว่าเป็นสถานะผิดปรกติ คิดว่าคงมีผลช่วยให้ติดง่ายขึ้นอะครับ
