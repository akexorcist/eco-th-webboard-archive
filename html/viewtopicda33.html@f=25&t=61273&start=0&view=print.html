ช่วยด้วยค่ะเควสอากาเนะจัง

โพสต์แล้ว: พฤหัสฯ. 26 ก.พ. 2009 8:54 am
โดย ECO
คือว่าทำเควสแล้วติดค่ะเป็นอย้างนี้นะคะ

หลังจากคุยกะมาช่าแล้วที่สำนักงานทหารทิศใต้ มาช่าพาขึ้นฟลายอิ้งการ์เด้นไปลงที่ไลท์ทาวเวอร์

หลังจากลงที่ไลท์ทาวเวอร์เสร็จแล้วพอลงบันไดจะไปชั้นล่าง ก่อนลงก็มีอีเว้นค่ะ

หลังจากนั้นที่อ่านในวิธีทำ คือเค้าให้กลับขึ้นมาคุยกะ เอเมลและก้อมาช่าอีกรอบนึงก่อง

เราก้อเลยกลับมาหาเอเมล์กะมาช่า

แต่เอเมลกะมาช่าหายไปแล้วค่ะ OwO

ก้อเลย เลยตามเลย ไปหาไอเท็มอีเว้นเลย

แต่พอเดินไปถึงส่วนที่เค้าบอกว่ามีไอเท็มอีเว้นอยู่ รอตั้งนานนนนนนนไม่มี ลัมพ์ เอนจิ้นออกมาให้ตีเลยค่ะTwT

ก้อเลยจำใจใช้กุญแจกลับเมืองไม่รู้จะทำไงดีแล้ว ใครเคยเจอแบบนี้ช่วยบอกวิธีหน่อยนะคะ

Ps1 หลังจากกลับมา ลองไปทอนก้าอีกรอบแล้วค่ะ ไม่มีไรเกิดขึ้น

Ps2 ลองไปหามาช่าที่สำนักงานทหารทิศใต้อีกรอบแล้วค่ะ มาช่าไม่อยู่แล้ว

Ps3 ลองไปหาป้าที่ดาวทาวน์แล้วค่ะ ไม่มีไรเกิดขึ้น
