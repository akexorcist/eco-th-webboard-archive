ดังนั้นจึงอยากให้ช่วยกันกำหนดราคากลางในการรับครับ เพื่อกันปัญหาราคามันพุ่งขึ้นเกินเหตุ

จริงอยู่ว่าบางครั้งกระเป๋าหนักอยากได้ไวๆ แต่อยากให้ลองคิดถึงเพื่อนๆ ดูซักนิดครับ และปัญหาราคาระยะยาวด้วย

แล้วเหตุผลสำคัญคือถึงรีบ Up หุ่นไปตอนนี้ก็ยังคงไม่เก่งมากครับ เพราะต้องรอสกิลหลังๆ ที่จะใช้ได้ดีบนหุ่นครับ เป็นผลเสียกับคนที่รับราคาแพงด้วยนะ เสียเงินเยอะ + ไม่คุ้ม

ค่อยๆรับด้วยราคาปกติ และช่วยกันเก็บกับเพื่อนๆเป็นทางเลือกที่ดีกว่าครับ
