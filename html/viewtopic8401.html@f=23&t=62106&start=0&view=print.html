วันนี้ฝนมีเรื่องอยากจะขอความช่วยเหลือจากชาวสนุก! ทุกท่าน เพราะมีชาวสมาชิกสนุก ชื่อน้อง ปอนด์ เจริญพานิช กำลังไม่สบายเป็นไข้เลือดออก ขั้นวิกฤติ ต้องการรับบริจาคเกล็ดเลือด กรุ๊ป O rh+ Subgroup Parabombay แบบเร่งด่วน หากใครมีกรุ๊ปเลือด ตรงตามนั้น ฝนอยากขอความกรุณาช่วยบริจาค เพื่อช่วยน้องปอนด์ด้วยนะคะ
