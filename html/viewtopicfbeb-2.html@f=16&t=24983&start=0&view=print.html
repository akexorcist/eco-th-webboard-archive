ตอบ 870

ตอบ 13

Territoty,Northan Island ,Undead Island ,Around Light Tower เอาในแต่ละ Dungeon ความเป็นไปได้ที่จะเดินวนไปวนมาระหว่างดันเจี้ยนมีกี่วิธี
