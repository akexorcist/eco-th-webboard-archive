โพสต์แล้ว: พุธ 17 ก.ย. 2008 4:10 pm
โดย ECO
- -a ขอตอบในฐานะที่มีตัวชาวนา2ตัว สายผลิตกับสายบู๊ละกันนะ...
ตัวอย่างตัวละครที่มีอยู่
- ตัวสายผลิตสกิลที่อัพๆไว้มี รีไฟน์ คุกกิ้ง ผลิตผ้า ผลิตไม้ ทำสวน ซ่อมผ้า ซ่อมไม้ ฮีลลิ่งทรี
- ตัวที่อัพสายผลิต ทำเควสสกิลพ้อยน์เกือบครบ ก็ยังไม่สามารถอัพสกิลที่จำเป็นต้องใช้ได้ทั้งหมดถ้าจะเป็นสายบู๊ด้วย เพราะสายบู๊ต้องอัพโบลวหรือแบลนิชโบลว และสกิลมาสเตอรี่อีกด้วย
- ตัวสายบู๊ อัพสกิลบู๊ได้เกือบหมด(ใช้โบลว) สกิลเต้นท์อีก5เลเวล และมีสกิลของสายผลิต เช่น รีไฟน์และคุกกิ้ง+ฮีลลิ่งทรี

ถ้าจะให้แยกว่าสกิลสายผลิตอะไรไม่ค่อยสำคัญ
- ซ่อมไม้ ไม่ได้ใช้เลยนอกจากเพิ่งมาทำที่ซ่อมส่งเควสตอนเลเวลสูงมาก
- ซ่อมผ้า ถ้าไม่จำเป็นต้องใช้บ่อย ก็ซื้อที่เขาขาย
- ผลิตผ้า จริงๆเลยก็คงไม่ได้ใช้มากอีกเหมือนกัน
- ผลิตไม้ ถ้าใครชอบแต่งสวนลอยก็สำคัญ
- ทำสวน อันนี้ไม่อัพก็ได้ ซื้อจากโกเล็มเอาจะง่ายกว่า ยกเว้นหวังรออนาคตอาชีพคนสวนจะมา

ขอถาม
-ถ้าอัพสกิล ผลิตของสำคัญๆ และสกิลบู๊เช่น แบนดิสโบว และอื่นๆ
จะต้องใช้ SP(Skill Point) เท่าไร และต้องหาเพิ่มซักเท่าไรถึงจะ พออัพ สกิลผลิดของเต็ม
-ต่อ...สกิลผลิตของที่ สมควรอัพมีไรบ้าง



ถ้าจำไม่ผิดก็คือ ในครั้งแรกที่เราเปลี่ยนอาชีพเราจะโดนบังคับได้สกิลCultivation(สกิลปลูกพืช)มาในทันทีนะคะ
ถ้าเอาเฉพาะสกิลผลิตของก็
Cooking maxLv5=3+1+1+1+1=7แต้ม
Wood Create maxlv3=3+1+1=5แต้ม (สำหรับพวกทำบ้านลอยฟ้า)
Item Refine maxlv3=3+1+1=5แต้ม
Gardening(สกิลนี้จะอัพหรือไม่อัพก็แล้วแต่คน แต่เราอัพนะ) maxlv3=3+1+1=5แต้ม(สำหรับพวกทำบ้านลอยฟ้าเหมือนกัน)
Sewing Create(อันนี้ไว้ทำชุด สำคัญพอสมควรค่ะ)maxlv5=3+1+1+1+1=7แต้ม
Wood Kit 3+1+1+1+1=7แต้ม
Sewing Kit 3+1+1+1+1=7แต้ม
Bow Create (อันนี้ไม่ได้อัพอ่ะค่ะ) maxlv5=3+1+1+1+1=7แต้ม

รวมแล้วจะได้ 7+5+5+5+7+7+7=43แต้มค่ะ
ส่วนสกิลโจมตีBlow กับ B Blow maxlvที่5ทั้งคู่ค่ะ =7แต้ม สองตัวนี้ให้เลือกเอาว่าจะเอาสกิลไหนนะคะ^^" (แต่เราไม่อัพอ่ะ ส่งเควสอย่างเดียว)

จริงๆมันไม่สำคัญแค่สกิลผลิตของหรอกค่ะ
มีสกิลที่สำคัญอีก2-3สกิล ก็คือ Plant Knowledge กับ Tree Knowledge ซึ่งเป็นสกิลที่สำคัญของฟาร์มเมอร์เลยทีเดียวนะ
ถ้าถามว่าควรหาSPเพิ่มอีกเท่าไหร่ ตอบไม่ได้หรอกค่ะ ขึ้นอยู่กับว่าจะเก็บจนเวลเท่าไหร่ เล่นสายไหน สายบู๊หรือสายผสมของ
สรุปก็คือ ทำเควสSPให้ครบๆไปอ่ะค่ะ ง่ายสุดละ
