ดูเหมือน Random จะใช้งานดีที่สุด ฮีลรายคน mag ยิ่งเยอะยิ่งฮีล HP MP SP เยอะขึ้น
นานๆทีจะฮีลแล้วพลาด เลือดลดเอง ( ถ้าอัด mag ไปเต็มๆ ก็รับไปเต็มๆล่ะ เลือดน้อย ฮีลเข้าตัวเองพลาด 2 ทีติด สงสัยต้องมีนอนกันมั่ง แทนที่จะฟื้นเลือดกลับหด % ไปเล่นๆซะ งานนี้ไม่มี Vit ลำบากหน่อย เอ่อ...เล่นแกมเบลอนะ อย่านึกว่าไปเล่นพระเข้า ฮีลกระจาย
MP SP ไม่มีหมด ) ตอนนี้ Mag 71 + ? ฮีลได้ HP 180 - 600หน่วย นิดๆ MP 150 - 550
SP 150 - 550 อันนี้ดีหน่อย ฮีล MP SP ทีเดียวเต็มเลย ไม่ต้องกินยา ( ทำไมมีเราคนเดียวเล่นแม่ค้า Vit Mag เนี่ยะ ? ) สายนี้ดำรงชีพแบบฉบับเดิม เดินเก็บของตามเคย แต่ดีหน่อย ช่วยได้เยอะ คนตีใช้สกิลได้ตลอดเลย ( ติดตรง ถ้าสดกับตัวที่โจมตีหนักไป เดี๋ยวจะฮีลไม่ทัน เพราะมันไม่ใช่พระนะ :o )
