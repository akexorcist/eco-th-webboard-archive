รองริง คนเป็นหัวริงสั่งเปลี่ยนได้ตลอดเวลา

ส่วนการเปลี่ยนหัวริงมีขั้นตอนดังนี้

1. นำคนที่ต้องการจะเป็นหัวริงคนใหม่ ไปลงสมัครเป็นหัวริงที่ counter ริงในอัพทาว
2. ภายใน 3 วัน ถ้าได้รับการโหวตจากสมาชิกในริงที่เหลือเกินครึ่งของทั้งหมด ก็จะได้เป็นหัวริง
