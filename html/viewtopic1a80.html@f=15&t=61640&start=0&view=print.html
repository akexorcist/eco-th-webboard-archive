โดย ECO
คำอธิบายสกิวมันพูดถึงparry กับ counter
2สกิวที่ว่ามาไม่รู้เหมือนกันว่าได้ผลไหม
ตัวเราที่เอาไปเทสมันไม่มี2สกิวนี้

แต่มันใช้ได้แน่ในกรณีที่เป้าหมายอยู่ในสถานะDelay cancel
(DC = สถานะของพวกสายFtที่ช่วยให้ตีไวอ่าแหละ)
ขณะที่DCยังมีผลอยู่หากเรากดFeintไป
จะทำให้ฝ่ายตรงข้ามมีโอกาสติดสถานะเกร็ง(โอกาสติดสูงมาก)
ในทางตรงกันข้ามถ้าใช้ใส่เป้าหมายที่ไม่มีDCติดตัว
เราจะเป็นฝ่ายเกร็งซะเอง
รายละเอียดอื่นๆลองค้นในกระทู้เบลดครับ
มีภาพพร้อม ละเอียดใช้ได้ครับ
