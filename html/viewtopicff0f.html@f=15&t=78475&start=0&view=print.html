โพสต์แล้ว: อังคาร 04 ม.ค. 2011 10:20 pm
โดย ECO
เราเล่น Bard เพิ่งจ๊อบ 50 ว่าจะกลับไปเล่น Druid ต่อให้ถึง 50 (จะเอาสกิลใหม่ *0*) มีเรื่องสงสัยหลายอย่างค่ะ

- ถ้าจะ switch ควรเอา Session กับ Loud Song ไปด้วยไหม
เพราะว่ามันก็ให้ผลเหมือน ๆ Dead March อ่า (ตีหมู่+ติดสถานะผิดปกติ)
- เอา Musical Blow ไปดีไหม เผื่อไว้ใช้ตีอะไร เช่น กล่อง+ต้นไม้ ที่ยิง Holy Light แล้วมัน 0 T^T
- แล้วควรอัพสกิล Attract March ไหม มันมีประโยชน์อะไรอ่ะคะ
- ถ้า switch กลับไปเป็น Druid Hp จะลดไหมคะ
- Mag 100+16 / Vit 80+8 / Dex 61+16 / Int 25+17 / Hp 2494 / Mp 1395 / Sp 435 ถือว่าโอเคหรือยังคะ
สำหรับสายเก็บเวล/ล่าบอส
- พระเวล 99 ไปเก็บเวลที่ไหนดีคะ (ไม่มี Holy groove) ทั้งแบบตีเอง/รับวิ่ง/ตี้ ตอนนี้เราอยู่แต่ที่เดิม ๆ อ่ะ ฟูชิกิ ไมไม ดัน70 ซึ่งขึ้นช้ามากกกกก ชม.ละไม่ถึง 5%
- ถ้าเก็บกับเพื่อนที่เป็น Gunner ปืนสั้น สาย Str+Vit เวล 99 เหมือนกัน ควรไปเก็บไหนดีคะ ที่ขึ้นดี ๆ และไม่ตายทั้งคู่

- ถ้าจะ switch ควรเอา Session กับ Loud Song ไปด้วยไหม
เพราะว่ามันก็ให้ผลเหมือน ๆ Dead March อ่า (ตีหมู่+ติดสถานะผิดปกติ)
ตอบ seeson เราใช้สำหรับวอ กับไว้ใช้โอดีวออ่ะค่ะให้มอนที่เข้ามาในพื้นที่มึน
- เอา Musical Blow ไปดีไหม เผื่อไว้ใช้ตีอะไร เช่น กล่อง+ต้นไม้ ที่ยิง Holy Light แล้วมัน 0 T^T
ตอบ ถ้าเหลือก็เอาไปได้จ้า ของเราเอา
1.Musical Mastery
2.Attract March
3.Dead March
4.Samba
5.Fusion
- แล้วควรอัพสกิล Attract March ไหม มันมีประโยชน์อะไรอ่ะคะ
ตอบ ถ้าวอก็จำเป็นสำหรับไว้ลากผู้เล่นทิศอื่นค่ะ ส่วนลากมอนจากที่ลากๆมาไม่ค่อยติดนะคะ แต่ไว้ใช้เรียกมอนเพื่อไม่ให้มีดาเมจเกิดขึ้นได้
- ถ้า switch กลับไปเป็น Druid Hp จะลดไหมคะ
ตอบ ลดค่ะ โบนัส vit น้อยกว่า
- Mag 100+16 / Vit 80+8 / Dex 61+16 / Int 25+17 / Hp 2494 / Mp 1395 / Sp 435 ถือว่าโอเคหรือยังคะ
สำหรับสายเก็บเวล/ล่าบอส
ตอบ ลองหาเสื้อ +10 หรือไม่ก็ทำเซต Hp 2000 มาใส่เพิ่มด้วยนะคะจะได้ลุยสบายยิ่งขึ้น
- พระเวล 99 ไปเก็บเวลที่ไหนดีคะ (ไม่มี Holy groove) ทั้งแบบตีเอง/รับวิ่ง/ตี้ ตอนนี้เราอยู่แต่ที่เดิม ๆ อ่ะ ฟูชิกิ ไมไม ดัน70 ซึ่งขึ้นช้ามากกกกก ชม.ละไม่ถึง 5%
ตอบ เราเก็บเลเวลเป็นปาร์ตี้ที่ดันไมไม กับทะเลทราย B ค่ะ
- ถ้าเก็บกับเพื่อนที่เป็น Gunner ปืนสั้น สาย Str+Vit เวล 99 เหมือนกัน ควรไปเก็บไหนดีคะ ที่ขึ้นดี ๆ และไม่ตายทั้งคู่
ตอบ ลองชวนกันไปเก็บเลเวลที่ทะเลทราย B นะคะ หาเอเล กับ ทาทาไปสิงปืนด้วยนะคะ
