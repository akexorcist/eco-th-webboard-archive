สกิลนี้เป็นสกิลที่ไว้ใช้เก็บเลเวลในช่วงแรกไปจนถึงช่วงกลางๆอยู่แล้วนะครับ ถ้าไม่อัพก็จะทำให้ช่วงแรก(เก็บเลเวลคนเดียว)ลำบากมากเลยนะครับ เพราะว่าอาชีพ Warlock นั้นแรกๆคงจะสู้มอนเก่งๆได้ลำบากมาก เพราะชุด def จะน้อย ในความจริงที่ว่าเลเวล1จะร่ายไวแต่ว่าความแรงนั้นจะแรงไม่มากเท่าเลเวลที่สูงกว่านี้

จริงๆแล้วเกมส์นี้มีระบบรีสกิลอยู่นะครับ ถ้าจะแนะนำก็คือเล่นตามสายไปก่อนแล้วค่อยไปรีสกิลรีสเตตัสเพื่อเปลี่ยนสายเล่นก็ได้ครับเมื่อเลเวลเราสูงขึ้น
