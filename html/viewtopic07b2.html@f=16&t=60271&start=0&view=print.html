สอบถามสักนิดว่า ถ้าจะเล่นสาย Agi ให้พอบู๊กับมอนได้เนี่ย ควรลงสเตตัส ขั้นต่ำ
Agi Vit Dex Str ซักเทาไหร่ดี ค่า Str ถ้าจะลงยาวสเตตัสอื่นควรมีขั้นต่ำซักเท่าไหร่ดี

ขอแจงแบบละเอียดหน่อยนะขอรับ ตอนนี้อัพจนมันบู๊ไม่ค่อยจะรุ่งซะละ

โดย ECO
ไม่บอกการอัพแบบแน่นอนนั่นถูกต้องแล้วล่ะ ความต้องการของคนเรามันไม่เท่ากัน
ตีแรง หลบเก่ง ตีแม่น อึด เลือดเยอะแค่ไหนถึงจะพอมันอยู่ที่ตัวเองครับ ถ้าคนอื่นเขาบอก
ค่าที่แน่นอนของคนนั้นมาแล้วคุณลอกแบบมา มันก็จะทำให้คุณคิดเองไม่เป็นแถมเสีย
สเตตัสเฉพาะต้วอีกต่างหาก

หลักการอัพง่ายๆคืออัพจนกว่าตัวเองจะพอใจครับ ถ้ารู้สึกยังตีไม่แรงก็อัพstrไปอีก
ถ้าตัวเปราะเลือดน้อยก็อัพvitเข้าไปอีก ถ้าตีช้าหลบไม่เก่งก็อัพagiเข้าไปอีก ถ้าตีไม่แม่น
ก็อัพDexเข้าไปอีก ถ้าปามีดไม่แม่นติดโรคง่ายก็อัพIntเข้าไปอีกก็เท่านั้นแหละ

โดย ECO
อืมครับ ก็พอจะเข้าใจแล้ว ว่าแต่อย่างอยากรู้ว่า พวกท่านยังอัพ Dex กันต่อหรือเปล่าหลังจาก dex ครบ40 ไม่รวมโบนัสแล้ว เพราะมีหุ่นปืนกลที่ดันไมไม อยู่ตัวหนึ่ง

กระผมฟาดเนี่ย ขึ้น Miss รัวเลยนานๆทีจะโดน หรือเพราะมันเลเวลสูงกว่าตัวกระผม เลยฟาดไม่โดนก็ไม่รู้น่ะครับ เพราะชื่อมันยังแดงอยู่เลย เลยเริ่มสงสัยว่า

ค่า Dex เราไม่พอที่จะตีเหรอ หรือ ว่าความห่างเลเวลก็มีผลด้วย หรือเป็นลักษณะพิเศษของมอนตัวนี้อยู่แล้ว

ด้วยเหตุดังกล่าวทำให้ผมคิดว่าตัวเองอัพผิดอ้ะเปล่า ถ้ายังไง ช่วยไขความกระจ่างเกี่ยวกะมอนที่ว่าตัวนี้หน่อยได้ไหมครับ ตัวผมเวล 77 จะทำเควสเอากุญแจสวรรค์ เจอห้องที่มีไอ้ตัวเนี้ย
ฆ่าให้ตายหมดห้องไม่ได้ซักที
