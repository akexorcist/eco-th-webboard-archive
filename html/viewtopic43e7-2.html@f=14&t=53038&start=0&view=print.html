สาย VIT ควรจะเป็นสายหลักสายหนึ่งของเกมนี้ด้วยซ้ำ

เพราะเกมนี้ค่า DEF ไม่ได้ขึ้นกับชุดมากนัก (ยกเว้น+10 ทั้งโล่ทั้งชุด) ดันไปขึ้่นกับ VIT เยอะมากๆ

ร่วมกับ การใช้สกิลเก็บเลเวลของเกมนี้ ทำได้ง่ายมาก เนื่องจากมีเร่งจากพระ

อ่อ แล้ว กรงเล็บที่ว่าความเร็วไม่ลดลงนี่จริงๆ ลดลงครับ (เยอะด้วย)

แต่ด้วยความเป็นสนับ ทำให้มันลดลงช้ากว่าคนอื่น 3 เท่า่ เลยดูเหมือนไม่ลด อาจจะร่วมกับกำลังรู้สึกภาคภูมิใจในความอึดขึ้นนิดหน่อยพอดีครับ ทำให้มันบังตาไป

สายนี้ ในหนังสือ ไกด์ที่วางขายก็มีบอกไว้ หุๆ... แต่ว่า แอสนี่ def ไม่ค่อยเยอะหนิ -..- ระวังเจอมอนตีแม่นๆ แรงๆ จะม่องเอานะ
