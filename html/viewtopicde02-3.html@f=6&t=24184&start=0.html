ข้าพเจ้าก็เป็นเหมือนกันครับ และเพิ่งเป็นวันนี้หลังเปิด server

ข้าพเจ้าเก็บเวลอยู่เมืองใต้ ซึ่งพออยู่ในเมืองเวลาเควสมันเพี้ยน แต่...เมื่อข้าพเจ้าเดินไปเก็บของที่ห้องคลัง(merchant guild)เวลากลับตรงเหมือนเดิม พอออกจากห้องคลังออกมาที่เมืองใต้ใหม่เวลาก็เพี้ยนต่อ หึหึ

ข้าพเจ้าลองทดสอบใหม่ เดินเข้าไปที่ร้านเหล้าปรากฏว่าเวลาเควสตรงอีกแล้ว และแน่นอนเมื่อเดินออกมาเวลาก็เพี้ยนอีก

สรุปว่า เวลาจะเพี้ยนเมื่ออยู่ในแมพเมืองใต้รวมทั้งดันใต้ (แมพอื่นๆไม่ได้ออกไปเลยไม่ทราบ) ข้าพเจ้าสันนิษฐานว่า แมพเมืองและดันใต้ใช้ server ตัวเดียวกัน และเป็น server ที่เวลาเพี้ยน ส่วนแมพห้องคลังและร้านเหล้าใช้ server อีกตัวหนึ่งซึ่งเวลาตรง

ทางแก้... ตั้งเวลา server ที่เพี้ยนเสียใหม่ :)
