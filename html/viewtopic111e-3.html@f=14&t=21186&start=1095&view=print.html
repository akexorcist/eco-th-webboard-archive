ความเห็นมีดังนี้

1. เป็น Cross Bow จึงมีระยะยิงสั้น ลดความน่าสนใจระดับหนึ่ง

2. หากยิงในพื้นที่ไร้ธาตุ และมอนไร้ธาตุ ยังไงมันก็ไม่ต่าง

3. ต้องอัพสกิลประเภทธนูยัดธาตุ ไม่งั้นเพิ่มความแรงได้ยาก

4. ใช้ล่าบอสก็น่าสนเพราะ สามารถเพิ่ม Damage ได้ดีหากใช้ร่วมกับข้อ 3
