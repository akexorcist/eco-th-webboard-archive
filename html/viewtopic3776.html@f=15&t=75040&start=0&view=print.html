อิงธาตุที่ตัวเป็นหลักครับ
ส่วนธาตุที่พื้น เป็นการเสริมพลังธาตุให้กับตัวละคร/มอนสเตอร์ที่มีธาตุนั้นๆอยู่ในตัว

ซาก้าก่อนๆ ยิงเวทย์ลมใส่ชินนาม่อน ธาตุดิน (ชนะลม แพ้น้ำ) กลับแรงกว่าเดิม เพราะมันคิดจากธาตุที่พื้นเป็นหลัก (พื้นธาตุไฟ แพ้ลม)

แต่หลังจากนี้ จะคิดธาตุที่ตัวมอนสเตอร์เป็นหลักแทนครับ ส่วนธาตุไฟที่พื้น ไม่มีผลกับชินนาม่อน เพราะชินนาม่อนไม่ใช่ธาตุไฟ

แบบเข้าใจง่ายกว่าเดิม

กระทาชายนายเอเลกระจอกตัวหนึ่งนาม•Griffith• ใช้Water Shieldใส่ที่ตัว ทำให้ในตัวมีค่าธาตุน้ำอยู่25
เดินไปตรงพื้นธาตุดิน(ค่าพลังธาตุ50) ค่าธาตุน้ำยังคงเป็น25 ค่าธาตุดินเป็น0 เพราะไม่มีธาตุดินในตัว จึงไม่ได้รับผล
แต่เมื่อโดนGroove Arrowผลักกระเด็นไปพันลี้ ตกอยู่ตรงพื้นธาตุน้ำ ค่าธาตุน้ำกลายเป็น75(ได้รับผลจากพื้น เพราะธาตุตรงกัน)
ทำให้ถึกกับธาตุดินมากขึ้น(ดินแพ้น้ำ)
แล้วก็ลงไปนอนตายอนาถ เพราะศัตรูมันดันเปลี่ยนไปใช้ธนูไฟ~♪
