Blast ดีกว่าแน่นอน ด้วยเหตุผลดังต่อไปนี้
1. ไม่มีดีเลย์
2. ดาเมจแรง
3. Plurality ทำให้ความแม่นยำลดลง (int เยอะ ก็มี miss ได้บางดอก)
4. ประหยัดลูกธนูมากๆ (ใ้ช้เวลาเก็บเลเวลจะเห็นว่าต่างกันชัดเจน!!!)

ทริค/ข้อจำกัดของ Blast คือ
1. ต้องอัพ strike arrow ของคลาส archer มาด้วย จะทำให้ Blast แรงขึ้นมาก
2. ถ้าเป้าหมายอยู่เป็นกลุ่ม จะแชร์ดาเมจ

แต่ก็ยังยืนยันว่า Blast ดีกว่าแน่นอน!!!

เพิ่มเติมการใช้งานส่วนตัว
....เค้าใช้ Blast ยิงมอนในดัน70 ถ้าไม่ตายก็ dual arrow ซ้ำได้เลย
เนืื่องจาก Blast ไม่มีดีเลย์ DualArrow ไม่มีเวลาร่าย
