ย้vยี้จัv เขียน:เป็นชิ้นส่วนเสริม ให้กับสวนลอย ( ไม่สำคัญมาก )

1. 飛空庭のデッキ = Deck of flying empty garden = 1,600,000 G ( DC 1.28 m )
2. ターボエンジン = Turbo engine = 3,200,000 G ( DC 2.56 m )
3. 汽笛 = Steam whistle = 2,400,000 G ( DC 1.92 m )


คืออยากจะทราบว่า
1. ไอเท็ม ที่เป็นส่วนเสริมให้กับสวยลอยฟ้า ด้านบนนี่ NPC ตัวไหนขายหรอค่ะ คือลองไปที่เมืองใต้ ตรง NPC ขายของทำสวยสวยฟ้า แล้ว ไม่มีไอเมเหล่านี้อะค่ะ รบกวนด้วยนะคะ

2. แล้วแต่ละอย่างนี้มีประโยชน์ยังไงบ้างคะ

3. Big Canvas Of Flying Garden ที่เอาไว้เปลี่ยนรูปแบบใบพัดของสวยลอยฟ้า ใช้ยังไงหรอค่ะ และต้องใช้กี่ใบ จะมีวิธีรวมรวมอย่างไรบ้าง

4. เราจะเดินทางไปยัง Airport ต่างๆ โดยใช้สวนลอยฟ้าจะต้องทำยังไงบ้างคะ (ไม่แน่ใจว่าเดินทางได้ป่าว เหงได้ยินมาอะค่ะ)

หวังว่าคำถามนี้ คงมีหลายคนข้องใจอยู่นะคะ รบกวนผู้รู้ด้วยค่ะ ขอบคุณล่วงหน้าจ้า
