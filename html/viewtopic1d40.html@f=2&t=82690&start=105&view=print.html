คลิปสาธิต การสมัคร ID

ให้ไปที่ http://www.wavegame.net/ จะมีช่องให้กรอกดังภาำพ



จากนั้นกรอกข้อมูลให้ครบ



Wave Id (คือไอดีที่ใช้เล่นเกมของ Wavegame ทั้งหมด)

- Gender (เพศ Laki = ช , Perempuan = ญ)

- Passwaord (รหัสผ่านของ Wave ID ไม่ใช่รหัสผ่านของเกม)

- PIN (ตัวเลข 6-8 ตัว ใช้ในการยืนยันการเล่นเกมต่างๆ และลบตัวละคร)

- Email (อีเมล์ที่ใช้ในการสมัคร สามารถใช้ซ้ำได้)


จากนั้นติ๊กถูกที่ช่อง [Saya setuju dengan isi perjanjian] (ฉันยอมรับในข้อตกลงดังกล่าว) แล้วคลิก Submit / Next
