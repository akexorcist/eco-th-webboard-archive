หน้าไม้ธาตุ + ลูกธนูธรรมดา



708 ไม่ต่างกันเท่าไร :P










หน้าไม้ธาตุ+ลูกธนูธาตุดิน



757 (บางครั้งก็800) แรงขึ้นมาหน่อย เพราะประสิทธิภาพของหน้าไม้+ลูกธนูธาตุ




Reenei เขียน:- ใส่ลูกธนูธรรมดายิง จะออกมาเป็นธาตุตามหน้าไม้อันนั้น (อย่างเอาหน้าไม้ลม+Wooden Arrow ก็ยิงออกมาเป็นธาตุลม 50)
- ใส่ลูกธาตุอื่นยิง ก็ออกมาเป็นธาตุตามลูกธนูที่ใส่ (หน้าไม้ลม+Earth Arrow ยิงออกมาเป็นธาตุดิน 100)
- ใส่ลูกธาตุเดียวกับหน้าไม้ยิง ก็ออกมาตามลูกที่ใส่ (หน้าไม้ลม+Wind Arrow = ธาตุลม 100 ไม่เพิ่มเป็น 150)
- มีผลเฉพาะตอนยิงธรรมดาเท่านั้น สกิลไม่เกี่ยว



สรุปแล้ว:


ข้อดี
-ยิงแรงขึ้นกับธาตุที่แพ้ทาง(เจ๋ง!)

ข้อเสีย
-ทำได้เฉพาะStriker's Bow หน้าไม้ระยะยิงสั้น5ช่อง(ทำให้ผู้ใช้เสี่ยงภัยยิ่งขึ้น)
-ยิงแรงได้เฉพาะธาตุที่แพ้ทางกันเท่านั้น -3-(เอาธาตุน้ำไปยิงธาตุน้ำด้วยกันล่ะงานเข้า)
(ข้อนี้แก้ได้โดยพกพาลูกธนูธาตุไปเยอะๆ เพราะหน้าไม้ธาตุน้ำใส่ลูกธนูไฟ จะยิงออกเป็นธาตุไฟ^ ^)


จบแล้วครับโหลดโหดนิดนึง- -"
