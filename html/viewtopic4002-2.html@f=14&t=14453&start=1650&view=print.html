เออ คุณ Nitro_Z คับ ผมขอขยายความ ท่าจั่กจั่นลอกคราบ กับ Back Attack หน่อยนะคับ

ท่าจั่กจั่นลอกคราบ : ขณะกดใช้ ถ้ากด Skill อื่น หรือกดฟันมอนเตอร์ จะมีโอกาสที่ ไม่เกิดผล skill จั่กจั่น ( = เหมือนไม่ได้กดจั่กจั่น - -'')

ท่า back Attack : คำว่า ดีเลย์นั้น หมายถึง ทั้งเราและมอนเตอร์ นั่นคือ เมื่อเราจิ้มมอนไป ไม่ว่าจะถูกทางหรือไม่ถูกทาง เราจะใช้ท่าอะไรไม่ได้ ( ใช้ของไม่ได้ ฟันไม่ได้ skill ไม่ได้ ) แต่จะเคลื่อนที่ได้ ส่วนมอนเตอร์ ถ้าหากเราจิ้มเข้าข้างหลังมันเต็มๆ มันจะดีเลย์เหมือนเรา แต่มันจะตีเราได้ก่อน - -'' แต่ถ้าเราจิ้มไม่โดนด้านหลัง เช่นข้างๆ เยื้องๆ เราจะดีเลย์ ส่วนมอนเตอร์ไม่ดีเลย์คับ TT^TT ...

ปล: Back Attack เท่ห์ = ใช้มือเปล่า แล้วไล่ Back Attack แรงสะใจดี
ปล: ท่าจั่กจั่น ค่อนข้างใช้ได้ผลดี ผมอัพไว้ 1 เอาไว้ใช้หลบมอน ทั้งเวทย์ สกิล โจมตีธรรมดา หลบได้หมด แล้วมันจะยืนนิ่งๆ ค่อย charge skill ใส่
