ตอบละ
1.อะเคมิส กับ มารีโอเนตส์ เด่นแตกต่างกันยังไง
อัลเคมิสจะมีโบนัสสเตตัสซัพพอร์ทไปทางการโจมตีกายภาพ(เน้น str-dex-vit) ในขณะที่มาริโอเน็ตจะเน้นไปที่การโจมตีทางเวทย์มนต์มากกว่า(เน้น dex-agi-mag)

2.ควรเล่นอันไหนก่อน-หลัง
แล้วแต่ความชอบ เพียงแต่ถ้าสาย str dex vit แนะนำให้ไปเอา 3 สกิลมาริโอเน็ตก่อน (จ็อบขั้นต่ำ 34) ดังนี้ Marrionette Mastery, Marrionette Overload, Management Mastery หรือถ้ายังสู้ไหวก็ไปจ็อบ 40 เลย แล้วเอาสกิล change marionette มาด้วย จากนั้นก็กลับมาอัลเคมิสต์ยาวจน 50 ได้เลย

ความจริงก่อนมามาริโอเน็ตน่าจะเอาสกิลโจมตีหมู่ของอัลเคมิสต์มาด้วยจะทำให้เวลตอนเป็นมาริง่ายขึ้นครับ (ขั้นต่ำควรมี phalange สูงไปหน่อยก็เป็น delay bomb)

อันนี้รูปแบบการเล่นของผม
=> ชาวนา จ็อบ 50
=> อัลเคมิสต์ 30
=>สวิตท์จ็อบ(เอา phalange, potion fighter, two hand axe mastery ไปด้วย)
=> มาริโอเน็ต 40
=> สวิตท์จ็อบ (เอา 3 สกิลที่กล่าวมาข้างบน + puppet(ตอนนั้นยังไม่มี change มาริโอเน็ต)) (ปล.ไม่จ่ายค่านาฬิกาทรายเพราะไม่มีตัง :P)
=> อัลเคมิสต์ 50 (เพราะ exp*2 นี่ล่ะ)
=> เลิกเล่นจนกว่าซาก้า 8 จะมา -*- (ไม่ว่างเล่นเฟร้ย)
