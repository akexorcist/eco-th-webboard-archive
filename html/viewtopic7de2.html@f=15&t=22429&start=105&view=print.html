- Min M.Atk สูงขึ้น กล่าวคือ ค่าเวทที่แก่วงจะ แคบลง โอกาสยิงแล้วมอนเตอร์ไม่ตายจะลดลง

- -* งงอารายกาน อัพ INT เพิ่มดังนี้ :

- min M.ATK เพิ่มเพดานค่าต่ำสุดของพลังโจมตีด้วยเวทย์ ทำให้เวทย์ลดความแกว่งของพลังโจมตีลง

- MAX SP เพิ่มหลอด SP

- เพิ่ม M.DEF ทำให้พลังป้องกันทางเวทย์สูงขึ้น

- L.HIT ทำให้การโจมตีทางกายภาพจากระยะไกลแม่นยำขึ้น และหลบหลีกการโจมตีทางกายภาพจากระยะไกลดียิ่งขึ้น

- L.AVOID เพิ่มความสำเร็จในการโจมตีให้เป้าหมายติดค่าสเตตัสต่างๆ มากขึ้น และลดการติดค่าสเตตัสต่างๆจากการถูกโจมตีมากขึ้น

ที่เห็นได้ชัดๆคือ อัพ INT ได้ประโยชน์เยอะ และสำคัญกับการเล่นหมด อย่าง L.HIT ที่ได้จากการอัพ INT นี่ทำให้ผมหลบการโจมตีจากหุ่นน้ำตาลได้บ่อยครั้ง เพราะมันโจมตีระยะไกลประมาณ 2 ช่องมัง ส่วนสาบนี่ก็ สาบใส่พวกมอนชอบร่ายเวทย์นะ ติดดี มีหลุดไม่ติดบ้าง แต่รวมๆก็ใช้ได้ดี

ถามหน่อย
ทำไงให้ Sorcerer ตัวผู้หญิง มี mag ถึง 127 ได้อะ
ถ้าตัวผู้ชายมันจะอัพ mag 99 + จ๊อบโบนัส mag 24 + หน้ากากมังกรแลกจากแหวนชั้น30 mag 3 + เสื้อเลเวล5 (Tracery) mag 1 = 127
แต่ Tracery ที่ + mag 1 ตัวผู้หญิงใสไม่ได้อะ
เลยถามว่าในเกมส์มีเสื้อที่ +mag ที่ตัวละครผู้หญิงใส่ได้ไหมอะครับ
ผู้รู้ตอบหน่อยครับ
