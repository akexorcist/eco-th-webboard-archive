Kuren เขียน:05. วาดให้หันไปทางเดียวกันหมดตลอดเลย(ใช่เลย ดูในกระทู้เราก็ได้...)

06. ใส่ใจวาดแค่ส่วนใบหน้า แต่ส่วนสำคัญอย่างร่างกายดันวาดไม่ได้(ใช่เลย อกเบี้ยว มือยาว บลาๆๆๆ)

09. เขียนแบ่งแยกซ้ายขวาไม่เป็น (ลองวาดหันท่าเดิมอีกทาง เละตุ้มเป๊ะ OTL)

13. ภาพนึงวาดตัวละครได้แค่คนเดียว (เคยวาดนะ แต่เละ...)

16. ไม่สามารถวาดภาพที่มีการเคลื่อนไหวได้ (วาดได้ แต่เละ OTL)

18. วาด 俯瞰 ( มุมมองลงต่ำ / bird's eye view ) หรือ アオリ ( มุมมองขึ้นสูง / worm's eye view ) ไม่เป็น(แดเมจแรงมาก โฮกกกกกกก)

22. วาดเป็นแต่คน หรือ วาดแค่คน ไม่ก็ตรงกันข้าม(วาดอย่างอื่นเน่าไปเลย อึก...)

24. วาดแต่วัยสะรุ่นเลยวาดคนแก่ไม่เป็น(ฉึก! อีกดอก)

25. วาดมือ, นิ้วออกมาสวยๆไม่ได้(แดเมจแรงมาก อ๊ากกกกกกกกกกกกกกกกกก)

28. พยายามแทบเป็นแทบตายวาดตาข้างนึงออกมาซะสวยนิ้ง แต่พอไปวาดตาอีกข้างแล้วภาพเละหมด(ส่วนใหญ่นะ เละ...)

30. ยิ่งวาดออกมาดูดีเท่าไรยิ่งไม่ยอมเอาไปลงสี ( กลัวเละ.. ถูกเผง... )

35. ตำแหน่งหน้าอกมั่วแหลก ( เคยวาดชุดว่ายน้ำ มั่วแหลกลาน อกสูงเลย OTL )

38. พอเผลอฟลุควาดภาพที่ออกมาดูดีได้ภาพนึง ก็มักจะเอาภาพนั้นมาดูซ้ำแล้วซ้ำอีกแล้วยิ้มน้อยยิ้มใหญ่ ("orz แดเมจแรงสุดๆข้อนี้....)

40. วาดได้แป๊บๆก็ตบะแตก หนีไปทำอย่างอื่นแทน(เป็นบางครั้ง)

43. ตอนวาดงานเสร็จใหม่ๆแล้วภูมิใจในงานตัวเองอย่างมาก แต่เมื่อนอนไปได้ตื่นนึงแล้วกลับมาดูภาพตัวเองอีกทีแล้วอยากตาย ( พอมองเห็นข้อผิดพลาดที่มองข้ามไปทีแรกแล้วเฟลแดกกันเลยทีเดียว )

<<<< เมาส์หนูเทพมีเยอะจริงครับ ผมก็เคยใช้เมาท์หนูทั้งวาดทั้งลงสีมาก่อน แต่การใช้เมาท์หนูวาดกับการใช้แท็บเลทนี่มันต่างกันฟ้ากับเหวเลยนะ เนื่องด้วยเมาท์หนูเส้นแข็งมาก หักเลี้ยวยาก แทบจะเรียกได้ว่าวาดเส้นโค้งทีนี่กุมขมับกันเลยทีเดียว ลบแล้วลบอีก บอกกันตรงๆ เลยว่าแท็บเลทสะดวกกว่ามากๆ ปาดชะวาบๆ ก็ได้ละ แถมเส้นหรือไลน์สีทีไ่ด้คมกว่าเห็นๆ เมาท์หนูนี่ถ้าไม่ปรับขนาดภาพให้มันเล็กเข้าไว้(ไม่เล็กมากขนาดนั้นหรอกนะ พองามๆ) ก็จะเห็นวาบางจุดเป็นเหลี่ยมๆ กันเลยทีเดียว พอขยายเต็มสตรีม 300dpi ไม่เนี้ยบเลยซักนิดเดียว แรกอาจจะยังไม่ชินกับแท็บเลท แต่ใช้ไปเรื่อยๆ มันดีอย่างที่จอร์จกับซาร่าบอกจริงๆ
