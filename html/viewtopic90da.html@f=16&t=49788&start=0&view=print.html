treasure hunterถ้าเล่นสายแซ่ให้อัพสกิลฟาดแซ่5ครั้งให้เต็มครับ
หรือถ้าอยากหาของก็อัพสกิลฟาดแซ่ไปรอบๆ(สกิลหมู่)ไว้1-5ครับ
และก็ถ้าอยากหากล่องก็อัพสกิลหากล่องครับ
และถ้าอยากหากล่องง่ายขึ้นอัพสกิลunlock mastery
อยากจะเปิดcontainer อัพสกิล ถอดรหัสครับ
อยากจะหลบเวทได้อัพ หลบเวทครับ
อยากมีโซลอัพ โซล of explorer
เหนื่อยๆ
อยากได้ข้อมูลเพิ่มเติมเปิดไกย์เอาเลยครับ

เชื่อผมดีกว่า ถ้าโอนจะโอนดังนี้
Unlock Mastery = เบื่อของกาก เพราะเล่นเรนเจอร์เป้น(ตัว)หลัก
Whip Florish = ชอบโดนรุม มอนหมั่นไส้ที่ผมหล่อกว่ามัน *0*
Sonic Whip = ผมปราศจากความอ่อนโยน 8 ทีไม่ตายแสดงว่าอยากตายมากๆ เอ้อ! เกือบลืม ถ้าคิดจะอัพ เอาแส้ไป +cri 7 เลย ซึ่งอกหักไปหลายราย ยกเว้นผม เพราะไม่รู้ว่าตีที่ไหน กับใคร อย่างไหร เท่าไหร่
Lucky = Ranger กันกายภาพดีกว่าเวทยื ต้องกันเวทยืด้วย เผื่อจะยืดเวลาเก็บเวล
Whip Rush = สกิลทำกินช่วงแรกของหมู่เฮา
