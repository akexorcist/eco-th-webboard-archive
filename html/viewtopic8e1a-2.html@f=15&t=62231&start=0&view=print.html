mag60-70 ก่อน... จากนั้น vit50-60
แล้วก็ลง dex สัก 30-40 ก่อนครับ

จากประสบการณ์ดอง point ไว้เกือบๆพัน
status ของพระจริงๆแค่นี้ก็พอเล่นตี้ได้แล้ว
สำคัญที่พระต้องมีสกิลเร่งเท่านั้นเองครับผม

จากนั้นก็ค่อยๆปรับตามที่เราชอบ
อยากฮีลแรงก็ mag ต่อ
อยากร่ายเร็วก็ dex ต่อ
อยากอึดไว้ลากคลื่นก็ vit ต่อ

แต่ถ้าเป็นสาย nvn จะไม่เน้น mag สูงเวอร์
จะไปอัพหนักๆตรง dex-vit ครับ
