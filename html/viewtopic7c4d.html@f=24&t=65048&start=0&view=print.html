เควส ของแมวแฝด คุรุมิ / วากาเนะ เนื้อเรื่องเศร้านะ ถ้าอ่านละเอียดทั้งหมด (แถทยากพอตัว ตอนเล่นมินิเกมแล้วพลาด) + เพลงช่างได้อารมณ์เหมาะเจาะ (- -)ซวย ดันไปอ่านบอร์ดเริ่มเควสโซระ(ตอนนั้นทำแมวแฝดด้วย)หายไปเลย เรื่องของโซระ


สำหรับเรา เควสไอไม่น่าเศร้างะ น่ากลัวมากกว่า เกี่ยวกับหุ่นต้นแบบโปรแกรมให้ทำลายล้าง(มันเศร้าก็ตอนปิดสวิทแล้วลืมผ้าสามเหลี่ยม)

อีกเควสก็ ปิดผนึกธาตุทั้ง 4 ที่ปราสาทอันเดด (บอกไม่ถูกงะชื่อเควส แต่ได้เขากาเซลของโดมิมาละกัน) อยากรู้เรื่องราวตำนานของปราสาทอันเดดงะ ทำใมปราสาทดีๆถึงร้างได้ แล้วทำใมดรุยในตำนานคนนั้นถึงตาย
