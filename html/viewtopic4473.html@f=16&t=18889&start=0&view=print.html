แต่ทำไมเวลาผมสกัดแล้วมันพังเยอะจังหว่า =="
เคยลองเอาน่องไปทำสโมคชีส เอ๊ย!! สโมคแฮม
NPC = 50 ชิ้น เน่าไป 2 / รอบสองเน่า 5
ตรูเอง = 50 ชิ้น เน่าไป 7 / รอบสองเน่า 8
( ลองทั้งหมด 2 รอบ )
- แล้วก็ทดลองทำ(เอง) สไปซ์ 1 อัน ก็เน่า =="
- ขนนกแดง 50 อันหามา 1 ชม. จะทำพู่กัน ( สรุปเน่า )
หลัง ๆ ทำอะไรที่ราคาแพง ๆ วิ่งหา npc
( รึว่าเราจะไม่เหมาะกะสายนี้หว่า เพราะทุกเกมที่เคยเล่น เอะอะ วิ่งเฉาะ ๆ )
