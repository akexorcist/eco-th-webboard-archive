ที่นายถามมาอ่ะ ว่าจะเอา DEX หรือ INT ไปคิด มันไม่ได้ใช้2ค่านี้ครับใช้ค่า ATK

ความแรง = ATK*Lv.Skill ครับ

ขยาย DEX หรือ INT มีผลต่อค่า ATK เช่นกัน แต่ STR มีผลมากสุด

ปล.ย้ำ ใช้ ATK !!!!!!คำนวน


อืม จะบอกว่าเรื่องความแรงระเบิดใช้ ATK คำนวณความแรงอะ รู้นานแล้ว

แล้วก็สกิลระเบิดจะคำนวณความแม่นจากประเภทอาวุธที่ถือ (Int/Dex เรื่องพื้นๆไม่พูดแล้ว)

แต่สกิลบางสกิล ถึงจะถืออาวุธขว้าง/ปืน เวลาใช้สกิลก็จะคำนวณความแม่นจาก Dex ทำให้สายอาวุธไกลใช้สกิลพวกนี้วืดได้

ทีนี้ก็ไม่รู้ว่าสกิลไหนมันจะใช้ Int คำนวณความแม่นได้บ้างถ้าเราถืออาวุธขว้าง/ปืน ที่รู้ตอนนี้ก็มีสกิล summersault กับพวกสกิลระเบิด

แล้วก็ไม่รู้ว่าสกิล Sudden Attack มันจะใช้ Int หรือ Dex คำนวณความแม่น ถ้าเราถืออาวุธระยะไกล

เข้าใจยัง ถึงไม่เข้าใจก็ไม่อธิบายแล้วนะ พูดยาวเกินไปแล้วกับเรื่องง่ายๆ แค่นี้

ขี้เกียจตอบในคำถามเดิมที่คำตอบก็ได้ลงไปแล้ว ถึงข้อมูลเบื้องต้นที่น่าจะรู้
