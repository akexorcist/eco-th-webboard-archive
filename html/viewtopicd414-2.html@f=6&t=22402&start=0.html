BeauX เขียน:และแล้วก้มาถึง จุดที่ทุกคนสงสัย และเป็นคำถามยอดฮิต ว่า แล้วมันจะเร็วขึ้นได้อย่างไร
คำตอบอยู่ตรงนี้แล้ว...

การคำนวนค่า ความเร็ว ของหนอนซิ่ง ที่ผ่านการเลี้ยงดูมาอย่างดี นั้นมีสูตรคำนวนดังนี้

โค้ด: เลือกทั้งหมด
ค่าความเร็วที่ได้ = 210 + (ค่า stat รวม x 3 / 4) + (จำนวนครั้งการพัฒนา Lv x 8 / 3)

ค่าความเร็วที่ได้ มีหน่วยเป็น ช่อง ต่อ 100 วินาที
ค่า stat รวม = ค่า STR DEX INT VIT AGI MAG รวมทุกรอบการพัฒนา

ยกตัวอย่าง จากหนอนน้อยตัวนี้ เมื่อพัฒนา Lv ครบ 30 รอบ

เข้าสูตรคำนวนก้จะได้
โค้ด: เลือกทั้งหมด
210 + (248x3/4) + (30x8/3) = 476 ช่อง / 100 วินาที


หากแต่ว่า... ความเร็วที่ได้นั้น ถ้าเทียบกับ ข้อมูล ความเร็วอื่นๆเช่น
ความเร็วหนอนซิ่ง ที่ได้จากสูตรคำนวน = 476
ความเร็ว คนวิ่ง = 380
ความเร็ว มังกรแดง = 451
ความเร็ว มังกรฟ้า (นอกดัน) = 429

ถ้ามองแค่นี้ โหย!!! เร็วกว่ามังกรแดงอีก !!! แต่มันไม่ใช่อย่างนั้น
นี่คือข้อมูลทาง ทฤษฎี แต่ในทาง ปฏิบัตินั้น ความเร็วของมังกร ถ้าวิ่งเทียบกัน มังกร เร็วกว่า
นั่นคือ หนอนซิ่ง จะถูก ล๊อคสปีดไว้ที่ จุดๆ หนึ่ง ซึ่งเราไม่รู้ว่า เท่าไหร่แต่จากข้อมูลเวป
ต่างประเทศ เค้าประมาณค่าสปีดของหนอนซิ่งที่ถูกล๊อคไว้ ประมาณ 407 ช่อง/100วิ
ไม่ว่า คุณจะฝึกโดยเกบค่า stat ได้ต่อรอบสูงที่สุดคือ 12 แต้ม ต่อรอบ รวม 30 รอบแล้ว
เข้าสูตรคำนวนได้ สปีด 560 ก้ตาม!!

ซึ่งก้คือ ไม่ว่าคุณจะฝึกหนอนให้ได้ stat สูงสุดแค่ไหน มันก้จะถูกปรับลดให้ลงมาเหลือแค่
ค่าที่ล๊อคไว้นั่นเอง... หากแต่ว่า ค่าที่คำนวนได้ เป็นการคำนวน จากการจับเวลาการวิ่ง
ของหนอนซิ่ง จากจุดหนึ่ง ไปยังอีกจุดหนึ่ง แล้วหาค่า เฉลี่ยออกมา...

ดังนั้น ค่าที่คำนวนได้ ถือว่าเป็นค่าประมาณ ไม่สามารถวัดได้จากตัวเลขตรงๆ ต้องพิสูจน์
ด้วยการ ทดสอบความเร็วกันอย่างเดียว

และการทดสอบที่ได้เคยทดสอบอย่างไม่เป็นทางการนั้น สปีดของ หนอนตัวดังภาพก้ใช่ว่า
จะขี้เหร่ วิ่งทดสอบกับคน ก้เทียบคู่กันไป โดยที่ คนไม่แซง ทั้งระยะไกล และ ใกล้
ต่างจากมังกร ที่ เริ่มออกตัวพร้อมกัน แปปเดียวหนอนซิ่งก้โดนแซง...

ดังนั้นจึงขอสรุปอย่างไม่เป็นทางการเกี่ยวกับ สปีดของหนอนซิ่งว่า...

1. ความเร็วของหนอนซิ่ง จะขึ้นอยู่กับ ค่า stat รวม และ จำนวนรอบการพัฒนา ของหนอนน้อย
ยิ่ง หลายรอบ + แต่ละรอบ stat เยอะๆ ยิ่งเร็ว
2. การเอาหนอนซิ่ง ไปฝึกแล้วพัฒนา ไม่ทำให้สปีดเพิ่มขึ้น
3. ความเร็วสูงสุดของหนอนซิ่ง ณ ปัจจุบัน มากกว่า หรือ เท่ากันกับ ความเร็วของคน
4. หนอนซิ่ง ก้คือหนอน จะกระดึ๊บได้เร็วสักแค่ไหน ก้ตามมังกรไม่ทันอยู่ดี มันคือข้อเท็จจริง
(ข้อมูลของsaga3)

ถ้าลองคิดเล่นๆ ปรับสูตรคำนวน จากเดิม ที่ว่า

โค้ด: เลือกทั้งหมด
ค่าความเร็วที่ได้ = 210 + (ค่า stat รวม x 3 / 4) + (จำนวนครั้งการพัฒนา Lv x 8 / 3)

ลองเปลี่ยนมาเป็น แบบนี้ดู
โค้ด: เลือกทั้งหมด
ค่าความเร็วที่ได้ = 110 + (ค่า stat รวม x 3 / 4) + (จำนวนครั้งการพัฒนา Lv x 8 / 3)

น่าจะใกล้เคียงความจริงมากกว่ามั้ย อย่างเช่น หนอนเรา ถ้าคำนวนด้วยสูตรที่แก้ไขแล้วจะได้
โค้ด: เลือกทั้งหมด
110 + (248x3/4) + (30x8/3) = 376 ช่อง / 100 วินาที


ซึ่งเทียบกับคนแล้ว สูสี แทบไม่รุ้สึกแตกต่าง....
สปีดคนวิ่ง = 380
สปีดหนอนที่คิดใหม่ได้ = 376
น่าจะใกล้เคียงความจริงกว่า...

เพราะว่า 210 มันก้เป็นค่าคงที่ ที่ตั้งมาจากการวัดสปีดหนอนซิ่งที่ช้าที่สุด ที่เชื่อได้หรือเปล่า
ก้ไม่รู้ ปรับแต่งซะหน่อย ก้น่าที่จะไม่มีปัญหาอะไร...







ข้อมูลอาจข้างต้น เป็นข้อมูลที่ได้จากการลงมือปฏิบัติจริง ในเซิฟ ทาโกะยากิ ณ ปัจจุบัน
อาจมีข้อผิดพลาดได้ บางประการ หากผิดพลาดตรงไหน ขออภัย มา ณ ที่นี้ด้วย...
มือใหม่ หัดตั้งกระทู้ อาจจะดูไม่ดีในสายตาใครบางคน แต่ก้น่าที่จะไม่ได้ทำให้ใครเดือดร้อน
