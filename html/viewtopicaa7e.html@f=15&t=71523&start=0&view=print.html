เอเลสายวอ ส่วนใหญ่จะเป็นสาย mag-dex เหมือนสายเก็บเลเวลละ (หน้าที่ในทัพ เป็นหน่วยแจก Superman ชาวบ้านและตัวเอง)

ส่วนถ้าจะเล่นสายถึก จำเป็นต้องมีซอสายอิ้น มาคอยโอน int + เฟคด้วย (โอน int เพื่อให้โดนสะท้อนจากรุ้งเบาหรือ 0 และมีเฟค เพื่อให้ป้องกันจากสกิลบล็อค และสาป ถึกขนาดไหน โดนสกิลพวกนี้ไปที นิ่มทันใด)
และต้องคอยบัฟสกิลบ่อยๆด้วย เนื่องจากสกิลจำพวกออร่าต่างๆ กับ โอน int มีระยะเวลาที่สั้น

ถ้าใน NvN ก็แนะนำสาย Mag-dex นี่ละ เล่นง่าย แจก Damage แรง
ค่าที่เหลืออาจนำไปลง vit ก็ได้ (เผื่อโดนลูกซอไล่ตามยิงจะได้ตายยากขึ้นมานิด)
หรือจะลง int เพื่อให้ลดระยะห่างของค่า Matk
