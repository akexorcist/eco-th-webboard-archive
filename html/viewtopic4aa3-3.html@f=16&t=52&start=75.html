Marionest นะค่ะ ..


สามารถเล่นได้ 2 สาย ค่ะ

สาย Str >> Agi >> Vit >> Dex ( หรือจะสลับตามความชอบนะค่ะ )

สายนี้คือสายบู้ค่ะ เวลารวมร่างกับ มารีโอเน็ต ก็จะสามารถ โจมตีได้รุนแรง มากขึ้น

เพราะจะได้โบนัส จาก มารีโอเน็ต ที่เรารวมค่ะ ..


ส่วนอีกสายนึง สาย Mag >> Dex >> Vit

สายนี้เป็นสายเวทย์ เลยค่ะ เอาไว้ใช้ได้ดีตอน รวมร่างกับมารีโอเน็ต แล้วใช้สกิล ยิงเวทย์นะค่ะ .. ส่วน โบนัสของอาชีพนี้มีค่า Mag และ Int เยอะ

เพื่อรองรับกับสายนี้ และ Int มีผลต่อสกิลบางสกิล เช่นจับมอนมาเป็นหุ่นกระบอก *0*

สกิลควบคุม ศัตรู ทำให้ติดง่ายขึ้นค่ะ ( แต่ไม่จำเป็นต้องค่านี้เพิ่มก็ได้ )
