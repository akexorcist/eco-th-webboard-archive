ผมเป็นเด็กที่อยากรู้และขี้สงสัยนะ เลยะมาถามว่า เงิน90นี่ไม่ใช่น้อยๆนะครับ

วันนี้ผมเติมเงินไป90บาท ซื้อตั๋วหมายเลข10กะหมายเลข7ไป ได้แป้นบาสกะตัวไรมะรุออกมาช่วยไรเนี่ย

ไม่รู้ว่าเมื่อไหร่ะได้ของที่อยากได้ อยากถามว่าเติมกันไปเท่าไหร่แล้ว แล้วเสียดายกันมั่งไหม หรือไม่ได้อยู่ที่ดวง แต่อยู่ที่จำนวนครั้งในการเติม เงินจะได้เข้าพนักงานหรอ


เติมแล้วรู้สึกเสียดาย เลยมาถามความรู้สึกของคนที่เติมเยอะๆบ้าง
