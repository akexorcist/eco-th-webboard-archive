แนะนำให้ใช้บลาสลมขั้น5ครับ ดาเมจจะสูงมากเมื่อใช้กับชินาม่อน(เพราะพื้นที่เป็นธาตุไฟ)
สามารถยิงให้ตายในนัดเดียวได้ครับถ้าmagสูงพอ ตรงนี้แนะนำให้อัดmagเยอะๆเพื่อสะดวกต่อการสอยให้ตายในบลาสทีเดียว
เลเวล40 อยู่นั่นจน50-55ได้เลยครับแล้วค่อยไปหอแสง(ไปตรงทุเรียนลอยฟ้า เข้าไปแล้วออประตูข้างครับ หรือไม่ก็ เดินไปชั้น1(เสี่ยงหน่อย) แล้วออกไปข้างนอกครับ )
ให้เก็บกระป๋องชินไว้ครับพอเวล44ให้เอาป๋องชินไปส่งเร่งเวลให้ไวขึ้น+เอาเงินมาซื้อลูกอม
ใช้มาริโอเน็ตดินก็ได้ครับฟื้นmpไวๆ
พอเวล55(กำลังดี) ให้ย้ายที่ไปหอแสงตามที่กล่าวมาข้างต้น แล้วก็อยู่ทุเรียนจนกว่าจะมีzenครับ แล้วให้ไปยิงบลาสที่แพลตตินั่ม สเตปง่ายๆครับ กดเซน แล้วยิงบลาสดินใ่ส่ สองทีน่าจะตาย
อยู่นั่นจนได้Icycle Templest(จ๊อบ40)ครับ แล้วใช้สกิลนั้นเก็บกับแพลตตามเดิม จนได้คลื่นเลย
พอได้คลื่น จะไปสาดที่ไหนตามสะดวกครับ
หมายเหตุ : เป็นแค่คำแนะนำชี้แนะเป็นแนวทาง ไม่ใช่วิธีเวลที่ไวที่สุดครับ
ปล.อาจจะมีข้อมูลผิดพลาดเล็กน้อยนะครับเพราะตั้งแต่เอเลผมมีรุ้ง ผมก็ไม่เคยเวลตัวละครเด็กด้วยวิธีปกติเลย ออนดูดตัวเองอย่างเดียว ตั้งแต่1ยัน99 (ถ้าเป็นสายเวทย์แบบเซจหรือคาบา ผมก็เอาออกมายิงเองด้วย)
