ลองให้มอนส์เตอร์มาตีตัวเองสัก 1 ตัวแล้วกด Abetment ใส่มอนส์เตอร์ตัวอื่น
แล้วมันจะทำให้มอนส์เตอร์ที่ตีเราอยู่ติดสถานะ Confuse แล้วก็ไปตีมอนส์เตอร์ตัวที่เราเล็งไว้
สมมติว่า DEM-Sniper กำลังยิงเราอยู่แล้วกด Abetment ใส่ Killer Machine
จะทำให้ DEM-Sniper ติดสถานะ Confuse แล้วหันไปยิงใส่ Killer Machine

กรณีลากมาหลายๆตัวจะสุ่มติดเพียง 1 ตัวเท่านั้น
สมมติว่า ลาก Dem-Sniper 3 ตัว, DEM-01 3ตัว พอกด Abetment ใส่ Killer Machine
จะทำให้ Dem-Sniper หรือไม่ก็ DEM-01 1 ใน 6 ตัวติด Confuse ไปโจมตีใส่ Killer Machine

Note
-เมื่อสถานะ Confuse หมดไปค่า Hate จะกลายเป็น 0 ทันที ถ้ามอนมันออโต้ก็จะวิ่งเข้าหาเพลเยอร์ใหม่
-อย่างไรก็ดีถ้ามอนมันกำลังตีกันเองอยู่แล้วเราไปแจมมันอาจจะหันมาทุบเราทั้งที่โดนผลของ Abetment อยู่ก็ตาม
-สกิลนี้ไม่มีผลต่อเพลเยอร์ด้วยกันเองดังนั้นถ้าจะเอาไป PvP หรือ NvN ก็ขอให้คิดใหม่น๊า
