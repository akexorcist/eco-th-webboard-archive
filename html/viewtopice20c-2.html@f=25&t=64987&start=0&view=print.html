โดย ECO
เห็นคำอฺธิบายเพิ่มอัตราการเจริญเติบโตสัตว์เลี้ยง ให้สัตว์กิน

เเต่พอกดเเล้วไหงคนกินละครับเนี่ย เเล้วค่าเเสดงสถานะการใช้สกิลมันไปอยู่กับคน ไม่ได้ไปอยู่กับสัตว์เลี้ยง งี้สตว์จะได้รับผลมั้ยครับเนี่ย

อย่างพวกเวทย์หรือสกิลต่างๆพอกดใช้ให้สัตว์ เเล้วกดคลิ๊กขวาที่สัตว์เลี้ยงเลือกดูรายละเอียด ยังมีเเสดงสกิลที่กำลังส่งผลต่อสัตว์เลี้ยงในขณะนั้น เเต่พอใช้ไอเท็มตัวเนี้ย ค่าเเสดงสถานะสกิลดันมาอยู่กับคน ไม่ไปอยู่ที่สัตว์เลี้ยง หรือจะต้องโยนให้สัตว์กิน?

เหอๆๆ มันมีสกิลโยนอาหารให้สัตว์เลี้ยงด้วยเหรอครับ
