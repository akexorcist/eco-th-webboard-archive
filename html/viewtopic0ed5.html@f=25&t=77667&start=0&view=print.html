ซื้อผงนอนหลับแมว ที่ป้าร้านขายpet ในหมู่บ้าน Easter Cape ครับ

จากนั้น ก็กดคุยกับแมวบนบ้าน แล้วจะมีให้เลือกใช้ผงนี้ได้ครับ

แต่ต้องวางแมวไว้บนบ้านก่อนนะ

ส่วนเตียงนี่ ไม่ต้องก็ได้ครับ แต่สอยมาประดับคู่กันกับน้องเหมียวเราก็ได้นะ

ตอนแมวเรานอนแล้ว กด"วางอีกครั้ง" จะย้ายที่ไปไหน มันก็ยังคงท่าหลับให้อยู่นะครับ แต่อย่ากด"เอาออก"
เพราะมันจะเข้าตัว พอวางใหม่ แมวเราก็จะไม่หลับแล้วละ
