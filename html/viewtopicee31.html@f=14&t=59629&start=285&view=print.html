แวะมา ตอบบางชีวิต

AGi และ Int ช่วยเพ้ม L.Avoid จริง

แต่ข้อแตกต่างคือ

1 Agi จะได้ 1 L.Avoid

10 Agi จะได้ 10 L.Avoid

30 Agi จะได้ 30 L.Avoid

ส่วน Int

1 Int จะได้ 1 L.Avoid

3 Int จะได้ 5 L.Avoid (1 2 2)

10 Int จะได้ 16 L.Avoid

30 Int จะได้ 50 L.Avoid

จะเห็นได้ว่าแตกต่างกันพอสมควร

แต่ถ้าจะเน้นเอาหลบระยะไกลจริงๆ ก็ต้องมี Agi ควบคู่ไปด้วย เพื่อความสมบูรณ์ ในหลายๆอย่าง

เพราะ อัพ Int ก็ได้ทั้ง L.Hit และ L.Avoid อยู่แล้ว

เพราะฉะนั้นการที่จะหลบผู้ที่มี Int เท่าๆกันก็คือ การอัพ Agi เพิ่ม

แต่ว่า แอส จะเสียเปรียบ อาชีพยิงไกลแต่กำเนิดตรงที่ว่า

ไม่มีสกิลเพิ่ม แม่นระยะไกล จึงทำให้ ต่อสู้กับพวกนี้ได้ยาก และ ไปต่อสูกับพวก แอสสาย Agi ยาก

ถ้าหาก Int ไม่ถึงเกณ แต่ถ้าหากอัพ Int มากเกินไป ผลที่ตามมาก็คือ Str - Agi น้อยลง ตามลำดับ

แต่ว่าก็ ได้ผลดีหากว่า เป้าหมายไม่ใช่แอส หรือ กันเนอ-สไตรเกอ เพราะ ถึงแม้จะเป็นสาย Agi

ก็มี L.Avoid ที่ไม่มากอยู่ดี โดยส่วนมาก แอสสายปา+ปืน จะแพ้พวกอึดๆถึกๆ เพราะสายนี้ โจมตีไม่ค่อยแรงนัก

(ทฤษฏี ยิ่งไกล ยิ่งเบา จำไว้ให้แม่น)

จึงทำให้สาย ปืนหรือสายปา ค่อนข้างมีเป้าหมายในการสังหารที่ ตายตัว

ไม่สามารถสดได้ อีกเพศทุกวัย เหมือนสายพิษนัก

ใครจะอัพทางไหน แนวไหน ไว้เก็บใคร ก็สุดแต่จะคิดเน้อ
