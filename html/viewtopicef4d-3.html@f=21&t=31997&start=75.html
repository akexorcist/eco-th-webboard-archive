นิสัยเป็นเงือกที่รักสนุก ชอบช่วยเหลือคน และชอบว่ายขึ้นไปบนโขดหินเพื่อดูมนุษย์

ความสามารถ เธอสามารถมีขาได้ช่วงเวลาพระอาทิตย์ ถ้าพระจันทร์ขึ้นเมื่อไรเธอจะเป็นเงือกดังเดิม ความสามารถ อีกอย่างคือ สามารถพาเพื่อนๆลงน้ำได้โดยไม่ขาดอากาศหายใจ

ท่าไม้ตาย ไทเดิ้ลเวฟ กับ โซนิกเวฟ สามารถเรียก Jormangruad มังกรแห่งท้องทะเล พาคลื่น ซัดศัตรูได้ ราบเป็นหน้ากลอง แต่ต้องเป็นช่วงเวลาคับขัน ผลึกบนหน้าผากจะเปล่งแสง อีกเวทย์คือ รีซีฟเวอร์ นำหยดน้ำตาเป็นยาฟื้นชีวิต

ประวัติ อคอ เป็นเงือกที่อยู่ใต้บาดาล แต่มีความสนใจที่จะขึ้นมาใช่ชีวิตบนโลกมนุษย์ แต่เธอมีขาได้ เพียงช่วงที่มีพระอาทิตย์เท่านั้น ทำให้เธอได้แต่เฝ้ามอง ผู้คนที่อยู่บนโลก อคอเป็นลูกสาวของเทพแห่งท้องทะเล เทพองค์นี้มีสมบัติให้ถ้าทำให้ลูกสาวของเธอได้มีขาทั้งตลอดวัน เธอจึงเฝ้ารอคนที่มีพลิกชะตาของเธอ ด้วยการจุมพิต แต่เงือกอย่างเธอไม่มีมนุษย์คนไหนกล้าคบด้วย

สิ่งที่ชอบคือได้อยู่บนโลกมนุษย์นานๆ

2.เพศ : หญิง
3.เผ่าพันธุ์ : เผ่ามังกร
4.นิสัย : อ่อนโยน ห่วงใยคนอื่น อินโนเซ้น ไรประมาณนี้
5.น้ำหนัก/ส่วนสุง/กรุ๊ปเลือด : หนัก 45 สูง 167 เลือดกรุ๊ป เอ

1.ชื่อ : หลวิชัย
2.เพศ : ชาย
3.เผ่าพันธุ์ : อมนุษย์ ตัวเป็นคนหัวเป็นเสือ
4.นิสัย : ขี้เล่นเป็นกันเอง ไปไหนมีน้องตามไปด้วยเสมอ โกรธง่ายหายเร็ว
ชอบหาตัง+ของวิเศษแต่มักดวงซวยเสมอเวลาไปหาของ 555+
5.ความสามารถ : จับม่อนเตอร์เป็นสัตว์เลี้ยงหลอกคนอื่นได้ว่าเพทตัวใหม่ 555+
ทำอาหารอร่อยด้วย ช่วยได้ทุกสถานะการเป็นนักประดิษฐ์ตัวโยง
อีกหนึ่งอย่าง ชอบสะสมของ หาของจากพืชได้ดีเยียม สามารถสือสาร
กับภูติและสัตว์ได้ มีเวทย์มนต์นิดหน่อย สามารถยืมพลังจากภูติได้
แปลงร่างให้คล้ายคลึงกับเหล่าภูติได้
6.ประวัติส่วนตัว : แต่ก่อนเป็นเสือเจ้าแห่งป่าตะวันออกทางฟาอีสอยู่กะน้องต่าง
เผ่าพันธุ์1ตัวชื่อ ~คาวี~ เป็นวัวของชาวบ้านที่พัดหลงเข้ามาในป่าแห่งนี้
แต่ช่วงหลังๆเกิดปรากฎการแปลกๆที่ป่านั้น เหล่าภูติแห่งป่าต่างสับสน
วุ่นวายกับพลังประหลาดที่เกิดขึ้น ทำให้ภูติบางส่วนที่ติดอยู่ในป่านั้นเริ่ม
เปลี่ยนแปลงไปจากภูติแห่งความสุข กลายเป็นภูติแห่งหายนะก่อเรื่อง
วุ่นวายต่างๆมากมาย ส่วนภูติที่ออกมาได้ก็ได้กระจายออกไปหาที่อยู่
ใหม่ ตามที่ต่างๆ ผมและน้องจึงออกเดินทางหนีพลังประหลาดที่ว่าออก
มาหาที่อยู่ใหม่ พอหนีออกจากป่าได้สักพักก็ไปเจอกับฤษีตนหนึ่ง
อาศัยในทุ่งหญ้าโมโม (ก็บ้านที่อัพเกรดเพทอะ) ท่านฤษีเป็นผู้มีน้ำใจ
ขว้างขวาง จึงนำข้าและน้องมาเลี้ยงไว้ ฝึกปรือวิชาต่างๆให้ ทั้งด้าน
เวทย์มนต์ การใช้ชีวิต การดำรงค์อยู่ จนท่านสิ้นชีวิตลง
แต่ก่อนท่านสิ้นชีวิตลง ก็ได้มอบคัมภีร์เล่มหนึ่งให้กับข้าและได้บอกไว้ว่า
"จงฝึกให้สำเร็จแล้วใช้มันให้เป็นประโยชน์" คัมภีร์นั้นคือ คัมภีแปลงร่าง
72 กระบวนท่า และ วิธีอัญเชิญภูติ ซึ่งสามารถฝึกได้ครั้งเดียว ถ้าไม่
สำเร็จคัมภีร์จะหายไป ถ้าสำเร็จคัมภีร์จะเข้าไปแทนที่ในระบบต่างๆ
ของร่างกาย ทำให้แข็งแกร่งยิ่งขึ้น แต่มีข้อแม้ว่า ต้องเป็นผู้ที่สื่อสาร
เหล่าภูติได้ ซึ่ง สิ่งนี้น้อง ~คาวี~ ไม่เคยทำมาก่อนจึงอดในการเรียน
วิชานี้ไป จึงต้องเป็นวัวต่อไป หลังจากที่หลวิชัยฝึกคัมภีร์สำเร็จ
จึงพาน้องออกเดินทางตามหาเหล่าภูติที่เหลือ ของวิเศษต่างๆ
มาเพื่อช่วยเหลือเหล่าภูติที่หลงอยู่ในป่าหายนะแห่งนั้น
