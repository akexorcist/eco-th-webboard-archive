คือแบบว่า

ถ้าเป็นชื่อตัวเรา อาจใช้คำว่า first name หรือ given name หมายถึงชื่อที่พ่อแม่ตั้งให้มา แต่ถ้าเป็น surname หรือ last name หรือ family name หมายถึงนามสกุล แต่บางคนมี middle name คือ ชื่อกลาง (ส่วนใหญ่ก็เป็นคนตะวันตกอ่ะนะ เอเชียไม่มีหรอก) พูดจริงๆแบบไม่ไ่ด้กวน- -" ชื่อกลางก็คือชื่อที่เขียนไว้ตรงกลางระหว่าง ชื่อตัว และนามสกุล ชื่อกลางอาจเป็นชื่อของคนที่ครอบครัวรักใคร่นับถือ เช่น ปู่ย่าตายาย หรือ พ่อแม่ทูลหัว หรือเป็นนามสกุลเดิมของคุณแม่ ก็ได้ จะเห็นบ่อยๆในหนังที่ตั้งชื่อลูกตามชื่อปู่ หรือบางที่ก็เขียน middle name เป็นอักษรย่อ เช่น ประธานาธิบดี John F. Kennedy เขียน F ย่อจาก Fitzgerald ซึ่งเป็นนามสกุลของคุณตา John Francis Fitzgerald
ยกตัวอย่างอีกคนก็ จอร์จบุช
คนพ่อชื่อ George Herbert Walker Bush
ส่วนคนลูก George Walker Bush
ชื่อกลาง Walker เหมือนเดิม แต่ ตัด Herbert ออก
อันนี้ก็ไม่รู้ว่า Herbert เป็นชื่อใครอ่ะนะ
