เล่นอัลเคมิส ก็ดีตรงที่เลือดเยอะ กับ def เยอะนี่หละแต่ +Mag น้อยมากๆ

ตอนนี้วิท 117 เลือดก็ 4700+ แล้วใส่แค่ชุด 99 นะ
ถ้าใส่เซ็ท 2000 กับ +10% HP แล้วเลือดเพิ่มอีกเพียบ 4700+2000 = 6700+10% = 6700+670 = 7370 แ้ล้ว
ได้คนมาสิงโล่ เกราะ แล้วก็อก+ได้ดีไวน์บาเรีย def 99 พอดีเลย เดินเล่นทะเลทรายสบายๆ
แต่กว่าจะตีตายตัวนึงเหนื่อยจริงๆ แครอททุบได้ 3000 กว่าๆเอง ถ้ายัดธาตุ+เฟรมฮาร์ทให้แครอทได้ก็คงจะดี *0*

แต่ปกติไม่มีคนสิงถ้าไม่เวลทะเลทราย ไปที่อื่นนี่อยู่คนเดียวสบายๆเลยอาชีพเรา พระไม่ต้องแม่ค้าไม่ต้อง แปลงร่างได้ *0*
ทั้งมาริโอ้ ทั้งอัลเคมิส เล่นสบายดีพอๆกับเรนเจอร์ลงดันเลย HP SP MP Infinity
ยิ่งไปคู่กัน มาริ+อัลเค อัลเคชนแล้วมาริยิงนี่ เวลเร็วดีเหมือนกันนะ
