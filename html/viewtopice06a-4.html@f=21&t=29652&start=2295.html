ตอนนี้มัน ... แอบสะเทือนใจคนแต่ง ...

===============================================

ตำนานบทที่ XV
“Triste Kiss – [ Sad Kiss ]”


ช่วงวันเวลาที่ได้หัวเราะด้วยกัน ...


ช่วงวันเวลาที่ได้ผจญภัยร่วมทางกัน ...


และ ...


ช่วงวันเวลา ที่หัวใจของฉัน ... กลายเป็นของนาย โดยที่ฉันไม่รู้ตัว ? ...


ฉัน ... จะจบมันลงตรงนี้ ...


ท่ามกลางความตกตะลึงของผู้ชมและผู้เข้าแข่งขัน เมื่อร่างของเอเลน่ายืนอยู่บนหอกของวิล หอกที่พุ่งเข้าใส่ด้วยความเร็วสูงเช่นนั้น เธอกลับกะจังหวะ พร้อมกับดีดตัวขึ้นไปได้อย่างทันท่วงที แสดงถึงฝีมือที่ไม่ธรรมดาแม้แต่น้อย “... มันคงจะเจ็บปวดนะ ... วิล” หญิงสาวเอ่ยด้วยรอยยิ้ม หากแต่รอยยิ้มนั้น ช่างดูเศร้าเหลือเกิน


“แม้นว่า ... นายจะเจ็บปวดด้วยหนามกุหลาบที่ทิ่มแทง ... แต่ฉัน ...”


“กลับเจ็บปวดมากกว่านายนัก ...”


โดยที่หญิงสาวไม่รู้ตัว หยาดน้ำตาแห่งความเศร้าไหลรินจากดวงตาคู่สวยนั้น และหยดลงบนคมหอกของชายหนุ่มทีละหยด ... ทีละหยด ... ดวงตาของวิลที่จับจ้องใบหน้าของเอเลน่านั้นเต็มไปด้วยความสับสนและความไม่เข้าใจในหลายสิ่ง เธอจะร้องไห้ทำไม ? ทำไมต้องทำใบหน้าเช่นนั้นกัน ? ทำไม ... ? “เอ ... เอเลน่า ...”


“ถ้าฉันชนะนาย ... จงไปจากเมืองนี้ซะ พาทรีทไปด้วย ... และอย่ากลับมาให้ฉันเห็นหน้าอีก !”


วูบ !


สิ้นเสียงของเธอ เอเลน่าก็หายตัวไปจากหอกของวิล พริบตานั้นเองที่วิลรู้ซึ้งถึงความน่ากลัวของหญิงสาว เมื่อแส้หนามสีดำสนิท ดูราวกับหนามกุหลาบดำ ได้ตวัดรัดลำคอของเขาเอาไว้อย่างแน่นหนา เขารู้สึกเหมือนลำคอของตนกำลังจะถูกกระชากออกไปจากตัว ไม่น่าเชื่อว่าหญิงสาวที่ดูบอบบางอย่างเอเลน่าทำไมถึงมีแรงขนาดนี้กัน ?


“... อึก !” วิลเริ่มรู้สึกว่าลมหายใจของเขาเริ่มขาดช่วงและอึดอัดเต็มทีแล้ว เขากระโดดขึ้นพร้อมกับหมุนตัวให้แส้ที่รัดคออยู่นั้นคลายตัว เพื่อตนเองจะได้ตั้งหลักบ้าง เขายกหอกขึ้นพร้อมกับหันคมหอกไปทางเอเลน่าที่ยืนนิ่งราวกับเป็นรูปสลัก “... ฉันไม่เข้าใจเธอ ... เอเลน่า” วิลเริ่มเอ่ย


“แต่ฉันรู้ว่า ... ฉันจะแพ้ไม่ได้ ... !!”


วิลวิ่งเข้าใส่เอเลน่าอีกครั้ง พร้อมกับขยับมือที่จับอยู่ที่บริเวณกลายด้ามหอก ให้มาอยู่ตรงปลาย เพื่อเป็นการจำกัดวงในการใช้หอกของตนให้กว้างขึ้น อีกทั้งยังสามารถที่จะปัดป้องแส้ที่ไม่อาจจะรู้ได้ว่าจะถูกตวัดออกมาอีกครั้งเมื่อไรกัน ? แต่จู่ ๆ เกราะที่ขาของวิลก็แตกออก ! วิลถึงกับชะงักไปครู่นึงด้วยความตกใจทีเดียว


ในตอนนั้น ... เอเลน่าก็ตวัดแส้ด้วยความเร็วที่เขามองไม่เห็นอีกครั้ง ร่างของเธอยังคงยืนนิ่ง และคราวนี้ เผ้าหมายของเธอก็อยู่ที่ ... “อึก !” เปรี้ยง ! ... วิลเหมือนจะรู้ตัว เขายกหอกขึ้นในระดับสายตา และก็เป็นดังคาด หากเขาไม่ยกหอกขึ้นป้องกันล่ะก็ เขาอาจจะเสียดวงตาไปเลยก็เป็นได้ “เธอคิดจะทำอะไร เอเลน่า !” ชายหนุ่มเริ่มบังเกิดโทสะ


“อย่ามาบังคับฉันทางอ้อมนะ !” เขาเอ่ยต่อ “เธอเป็นอะไรของเธอ !? แล้วร้องไห้ทำไม !? ... ทำไมทำแบบนี้ !?”


คำถามที่ถูกเอ่ยขึ้นจากปากของชายหนุ่ม ... ทำให้ใบหน้าของหญิงสาวผู้ถือแส้ดูราวกับโลกใบนี้ได้จบสิ้นลงเสียแล้ว “... วิล ...” นามของชายหนุ่มถูกเอ่ยขึ้นอย่างแผ่วเบา โดยที่เจ้าตัวนั้นไม่ได้ยิน “... สุดท้ายแล้ว ... ทั้งตลอดมา นายเป็นยังไง ก็เป็นอย่างนั้นเลยนะ”


“อย่าบอกว่า ... นายไม่เข้าใจฉัน ... แต่นาย ...” วูบ ... เอเลน่าย่อตัวลงเล็กน้อย มือที่ถือแส้ถูกยกขึ้นอีกครั้งนึง ดูราวกับว่ากำลังเตรียมพร้อมจะทำบางสิ่ง และในอีกชั่วพริบตา ร่างของเธอก็หายไป มีเพียงแต่หยาดน้ำตาที่ลอยอยู่เหนืออากศเท่านั้น ในทัศนวิสัยของวิล


“ไ ม่ เ ค ย คิ ด จ ะ เ ข้ า ใ จ อ ะ ไ ร ฉั น ต่ า ง ห า ก ! ! !”


“ท่วงท่าอันงดงาม ! ความวิจิตรสะกดสายตา ! บทวินาศแห่งความระทม !”


ก่อนที่วิลจะรู้ตัว ... ร่างของเอเลน่าก็ปรากฎขึ้นที่ด้านหลังของเขา เมื่อเขาหันไป เขาก็รู้สึกเหมือนตนเองตกอยู่ในดงหนามกุหลาบที่ไร้ทางออก หญิงสาวเจ้าของน้ำเสียงแสนทุกข์ และเจ้าของใบหน้าที่เต็มไปด้วยน้ำตาสะบัดมือที่ถือแส้ของตนอย่างรวดเร็ว จนไม่น่าใช่ความเร็วของมนุษย์ ...


ความหนักหน่วง ... ที่ดูราวกับว่าความทุกข์ของหญิงสาวแปรเปลี่ยนเป็นพลัง และปลดปล่อยออกมาทางแส้ ...

ความเกรี้ยวกราด ... ที่ดูราวกับการตอกย้ำตัวเอง ถึงสิ่งที่ตนเองได้ถลำลึกลงไป และปลดปล่อยออกมาทางแส้ ...


วิลไม่สามารถทำอะไรได้ เมื่อแส้หนามกุหลาบดำของเอเลน่านั้น โหมกระหน่ำฟาดเขาอย่างบ้าคลั่ง เขาได้แต่ยกหอกของตนขึ้น เพื่อปัดป้องใบหน้าของตนเองเท่านั้น ขณะที่เกราะที่เขาสวมนั้น เหมือนไมได้ช่วยอะไร เมื่อปะทะเข้ากับแส้หนังที่เต็มไปด้วยพลังอันเกรี้ยวกราดของหญิงสาว ...


“... ( ฉันก็ยังไม่เข้าใจอยู่ดี ) ...” วิลคิดในใจ ... “... ( ทำไมเธอถึงพูดอย่างนั้น ... ทำไมเธอถึงร้องไห้ ... ทำ ... ! )”


ตอนนั้นเองที่วิลเหมือนกับนึกอะไรออก เขากัดฟันแน่นดูราวกับว่าโกรธแค้นกับความหัวช้าของตนเอง ทั้ง ๆ ที่ทุกอย่างที่เอเลน่ากำลังทำอยู่นี้ ล้วนแต่เป็นสิ่งที่ไม่ต่างอะไรจากเขา ... ในอดีตเลยแม้แต่น้อย ความทุกข์นี้ ... ความทรมานนี้ ... เขาล้วนแต่พบเจอกับตนเองทั้งสิ้นไม่ใช่หรือ ?


วิลถอนหายใจออกมาเฮือกใหญ่ ก่อนจะลดหอกที่ปัดป้องใบหน้าลง และยืนนิ่งอยู่เช่นนั้น ราวกับจะให้เอเลน่าใช้แส้ของเธอฟาดเขาให้หมดลมหายใจ ซึ่งเธอก็ไม่ได้ลดความรุนแรงลงแม้แต่น้อย โลหิตสีแดงฉานของวิลกระเซ็นทั่วสนาม เมื่อแส้ของเธอฟาดลงบนผิวหนังของเขา พร้อมกับกระชากเนื้อของเขาออกมาส่วนนึง ...


วิลเหมือนจะเข้าใจ ... และตอนนี้เขารู้แล้ว ... ว่าความเจ็บปวดของเขานั้น เทียบไม่ได้กับของเธอเลย ...


ฉึ ก ! ! ! ...


เสียงเชียร์ของทั้งสนามเงียบสงัด เมื่อครู่ ... เมื่อเอเลน่าสะบัดแส้ของตนอย่างแรงไปทางด้านหลังและแส้ของเธอนั้นก็เหมือนกับแข็งตัวจนเหมือนกับหอกเรียวยาวเส้นนึง และมัน ... ก็พุ่งทะลุท้องน้อยของวิล ... โลหิตไหลรินออกมาจากทางด้านหน้า ... และด้านหลังที่แส้ของเอเลน่าแทงทะลุ ทรีทยกมือขึ้นปิดปาดอย่างตกใจ และก้มหน้าลงราวกับไม่อยากจะเห็นภาพตรงหน้า


ความรู้สึกที่ถูกแทง ... ในตอนแรกนั้นรู้สึกร้อนฉ่าไปทั่วร่าง และก็ .. แปรเปลี่ยนเป็นเย็นเฉียบ ...


ร่างของผู้แทง ... เริ่มสั่นสะเทิ้ม และก้มหน้าราวกับไม่อยากจะรับรู้สิ่งใด มือที่ถือแส้นั้นยิ่งสั่นกว่าเดิม หยาดน้ำตาแห่งความโศกเศร้าไลรินอย่างมิอาจจะบังคับตนเองได้ ความเจ็บปวดทางใจเสียดแทงทั่วร่างราวกับตกลงไปในน้ำเย็นยะเยือก ความสับสนบังเกิดขึ้นอย่างมิอาจจะควบคุมได้


เธอทรมาน ... ทรมานจนไม่รู้สึกถึงร่างของชายหนุ่มตรงหน้า ที่กำลังเดินให้แส้นั้นทะลุท้องน้อยของตนเอง เพื่อจุดหมายเดียวเท่านั้น นั่นคือ ... การเข้ามาหาตัวเธอ ...


จากความรู้สึกทรมานในตอนแรกนั้น ก็กลับแปรเปลี่ยนเป็นความอบอุ่น เมื่อเธอรู้สึกถึงไออุ่นของชายหนุ่มที่เข้ามาสวมกอดร่างของเธอ ในตอนแรกนั้นดวงตาของเธอเบิกกว้างขึ้นด้วยความตกใจ แต่สักพักเธอก็หลับตาลงราวกับจะซึมซับความอบอุ่นนี้อย่างเต็มที่ ในใจส่วนลึกของเธอนั้นภาวนาต่อทวยเทพ ...


... หากนี่เป็นความฝัน ขอให้เธออย่าเพิ่งตื่นขึ้นตอนนี้เลย ...


ทางที่นั่งของผู้เข้าแข่งขันนั้น ... ทรีทยกมือขึ้นปิดปาก ด้วยความที่กลัวจะว่าจะพูดอะไรออกมา และเธอก็ไม่เข้าใจด้วยเช่นกัน ? ว่าทำไมวิลถึงเดินเข้าไปกอดเอเลน่าแบบนั้น !? แล้ว ... แล้ว ! ... แล้วความรู้สึกเจ็บขึ้นมาในหัวใจของเธอนี่กันล่ะ !? ...


เวลาเหมือนกับว่าจะหยุดนิ่ง ทั้งผู้ชม และ ... รวมทั้งตัวเอเลน่ากับวิลก็ด้วยเช่นกัน ทั้งสนามประลองไม่มีใครที่จะพูดขึ้นมา จนเวลาผ่านไปสักพัก เมื่อเอเลน่าปล่อยมือออกจากแส้ของเธอ และเดินออกมาจากอ้อมกอดของวิล เธอยกมือขึ้นเช็ดน้ำตา และหันหน้าไปทางโฆษกที่ยืนเงียบอยู่ “ฉัน ... ฉัน ... เอเลน่า อาบิเกลล์ ...”


“ขอยอมแพ้ !” เธอเอ่ยขึ้นเสียงดัง แล้วหันหลังให้วิล ก่อนจะวิ่งลงจากเวทีไป ...


ทั้งสนามยังคงเงียบกริบอยู่ ... เมื่อโฆษกประกาศชื่อของผู้ชนะ ทั้งสนามก็ยังคงเงียบ จนวิลเดินลงจากเวทีไปสักพัก ถึงเริ่มมีเสียงวิพากษ์วิจารณ์การประลองจากผู้ชมทั้งหลายดังขึ้น วิลกัดฟันดึงแส้ออกจากร่างของตน พร้อมกับเอาไปล้างน้ำจนสะอาด


ตอนนี้ ... เขาก็มาหยุดอยู่ที่หน้าห้องของเอเลน่าแล้ว ...


วิลนิ่งไปครู่ใหญ่ ราวกับว่ากำลังคิดอะไรอยู่ เขาไม่ได้เคาะประตู แต่กลับเดินเข้าไปในห้องของเธอด้วยท่าทีที่ปกติที่สุด เมื่อเขาเปิดประตูเข้าไป ก็พบกับเอเลน่าที่นั่งอยู่ม้านั่งยาว และเธอก็หันหลังให้เขาอยู่ด้วยเช่นกัน ท่าทีของเธอนั้นนิ่งสงบ ราวกับรู้ว่าผู้มาเยือนนั้นเป็นใครกัน ?


“... เข้ามาทำไม ... ?” เสียงของเธอนั้นเยือกเย็น และเย็นชา ...


“... ฉันเอาแส้มาคืน ...” ชายหนุ่มตอบ


“... แค่นั้น ? ...”


ชายหนุ่มนิ่งไปครู่นึง ก่อนจะตัดสินใจเดินเข้าไปใกล้เธอมากขึ้น “หยุดอยู่ตรงนั้นนะ วิลาเนเซีย มัลฟอร์ด !” เอเลน่าเอ่ยเสียงดังลั่น จนชายหนุ่มต้องหยุดนิ่งตามคำพูดของเธอ “อย่าเข้ามาใกล้กว่านี้นะ ... อย่าเข้ามา ...” เสียงของเธอนั้นดูราวกับว่ากำลังหวาดกลัวอะไรบางอย่างอยู่


“ฉัน ... แพ้นายแล้ว ...” เอเลน่าเอ่ยต่อ “... ฉัน ... ตัดสินใจแล้วนะวิล ...”


“ฉันจะไปจากพวกนาย ...”


ใบหน้าของชายหนุ่มไม่อาจจะทราบได้ว่าเขากำลังคิดอะไรอยู่ “... เอเลน่า ...” เขาไม่รู้ว่าควรจะพูดเช่นไรดี


“... ทำไม ? ...”


เขาตัดสินใจถาม ...


“... เข้ามาสิ แล้วฉันจะบอก ...”


วิลเดินเข้าไปหาเอเลน่า พร้อมกับนั่งลงข้างเธอ เขาหันไปทำท่าเหมือนจะถามซ้ำอีกรอบ ...


แต่เขาก็ต้องเบิกตากว้างด้วยความตกใจ เมื่อริมฝีปากของเอเลน่าประทับเข้าที่ริมฝีปากของเขาอย่างแนบแน่น ใบหน้าของเธอนั้นดูไม่ออกว่าเศร้าใจ ? หรือว่าดีใจ ? เธอหลับตาพริ้มและรับความรู้สึกของไออุ่นจากริมฝีปากของวิลอย่างเต็มที่เท่านั้น สักพัก ... วิลก็หลับตาลงเช่นเดียวกับเธอ ทุกอย่างนิ่งไปหมด ... มีเพียงความสุขระคนความเศร้าที่เกิดขึ้นในใจของทั้งคู่เท่านั้น


สักพัก ... เอเลน่าก็เป็นฝ่ายที่ละออกมาจากริมฝีปากของวิล ... เธอเบือนหน้าหนีไปทางอื่น “... วิล ...”


“... ฉันรักนาย ...”


เสียงของเธอนั่นสั่นเครือ ... หยาดน้ำตาแห่งความสุขจากการที่ได้บอกความรู้สึกของตนเองบังเกิดขึ้น และหยาดน้ำตาแห่งความเศร้าที่แสดงถึงการลาจากก็ไหลรินเช่นเดียวกัน “... ขอโทษ ...” คำพูดเดียวที่หลุดออกมาจากปากของชายหนุ่ม หากแต่หญิงสาวกลับยิ้มออกมา ...


“... ดีแล้ว ... ที่ตอบแบบนั้น ... ฉันจะได้ไม่ลังเล ...” เอเลน่าลุกขึ้นทั้งน้ำตา ... ก่อนจะเดินตรงไปที่ประตู ทิ้งไว้ให้วิลนั่งอยู่ตรงนั้นตามลำพัง “... ขอบคุณนะ วิล ...” เธอเอ่ยขึ้นขณะที่มือจับลูกบิดประตู ...


“สำหรับทุกสิ่ง ... ลาก่อน ... ‘คนที่ฉันรัก’ ...”


แกร่ก ...


และนั่น ... ก็เป็นประโยคสุดท้ายที่วิลได้ยิน ... จากเอเลน่า


ตอนนั้นเอง ... ที่หยาดน้ำตา ก็ไหลรินจากดวงตาของบุรุษผู้เข้มแข็ง ...
