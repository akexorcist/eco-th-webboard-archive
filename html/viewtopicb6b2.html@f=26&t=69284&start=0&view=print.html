log หาจาก fallen tree ด้วยปราชญ์ฟาเมอร์ อาจจะยังมีให้เห็นตามโกเลมไม่มากเท่าไร
row ดันปลาชั้น 1 ตี ochre jelly หรือตรงทางเข้ารังผึ้งตี yellow pururu ใครตีก็ได้ หรือไปตีหอยทาก ที่ป่าไมไม
greater cloth หุ่นไล่กา ณ บึงพิษ ดันฟาอีส อย่าเอานักเวทมีปราชญ์ไปตีละกัน
หรือ ถ้ามี great cloth*2 + great thread ก็ผสมได้ ที่ร้านตัดเย็บ
great thread หาได้จากแมงมุมทารันทูลาในเหมือง ปราชญ์ เรนเจอร์ครับ ถ้าเงินเยอะ ก็ไปที่ร้านผ้าเมืองเหนือ หรือทองก้า dc เหลือพันนิดๆ
wood ฟาเมอร์ตีต้น wood เนี่ยแหละครับ มีทุกแมพด้านตะวันออก เยอะหน่อยก็ที่ฟูชิกิ
หรือซื้อเอาเลยที่คนขายเฟอนิเจอ ราคา 800

เปิดกล่องสมบัติเบอร์ 12 อาจได้ great strap, log, waterproof fabric, row
