โดย ECO
^
สำหรับผมที่ปั้นเทรเดอร์มาแรนดอมฮิล int ไม่ได้อัพน่ะครับ

ปกติ int ใช้สำหรับแกมเบลอสายปาไพ่(เพิ่มแม่นระยะไกล)
กับอีกอย่างคือเพิ่ม min M.ATK ครับ ซึ่งก็มันจะลดการแกว่งของการยิงสกิลเวทมนต์
ปัญหาคือ จากที่ดูในวิกิ การฮิล MP เขียนไว้แต่ factor M.atk ไม่ได้บอกว่า min หรือ max
คิดว่าคงเป็นการสุ่มค่าเหมือนการยิงเวทปกติ แต่ถ้าอัพ mag มากๆมันก็เยอะอยู่ดี

ส่วนการเพิ่มสูตรจะเป็น สูงสุดที่ M.atk*1.60+80 ต่ำสุด M.atk*0.60+30 ครับ สำหรับ HP MP หรือ SP ก็ไม่รู้
เพราะเทรเดอร์ที่ปั้นมาฮิล MP ได้เยอะๆก็ 1000+ แต่ Sp กะเลือดได้ไม่กี่ร้อย

สิงอกอัพ vit ก็ได้ครับ แต่ไม่จำเป็นมากนักเพราะ
- อกโดนตีเข้าค่อนข้างน้อย
- การเพิ่ม stat จากโซลอกค่อนข้างกระจายไปทุกๆค่า ก้อขึ้นกับอาชีพจะดีกว่าว่าอัพเยอะดีไหมครับ
