แนะนำให้สิงไปยิง ชินนิม่อนครับ อัพท่าสายฟ้าก็พอ
แต่ใจจริงผมอยากให้เก็บ Level แบบทุกMonster อะครับไม่อยากให้เวลาถามว่า
เก็บlevel ที่ไหน ตอบกันแต่ว่า ชินเนม่อน ตั้แต่ 1ไป40 อะไรแบบนี้อะ
เพราะว่า ภายในเกมมี Monsterหลายแบบ เช่นทางฟาร์อีสก็มีพวก Animal สัตว์ต่างๆ
ทางใต้ก็มี ไฮดร้า กับหุ่นยนต์ มากมาย ทางเหนือก็มี หมีขาว กับ หมาป่า
ทางตะวันตกก็มี หมี กับผึ้ง และทุกด้านก็มี ดันเจี้ยนครับผม อยากให้ลองเล่นให้ทั่วถึงทุก
Map ซะมากกว่า ไม่ใช่ มาเก็บแต่ ชินเนม่อนอะ แต่ถ้า ใครอยากจะเก็บก็ขึ้นไวดีครับผม
ดังนั้นผมแนะนำ วิธีง่ายสุดคือไป ตี้กับเพื่อนๆแล้วยิงชินเนม่อนดีก่า - -' ขึ้นไวแน่ ถ้า Level
สูงๆแล้วแนะนำลงดันบ้างก็ดีงับอิอิ
