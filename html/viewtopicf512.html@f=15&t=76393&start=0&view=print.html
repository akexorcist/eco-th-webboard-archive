แล้วก็หาพระมาเร่ง(Holy Feather)+ฮีลไว้ ปล่อยให้ตายไงMPก็ไม่หมด HPลดก็ให้พระฮีล(ไม่ก็ยืนชิดเอเล ออโต้เร่ง+ฮีลหมู่ กลายเป็นดันออโต้โดยสมบูรณ์)
ซึ่งมันก็บอทดีๆนั่นแหละ แต่Gmจัดการไม่ได้ เพราะไม่สามารถเข้าไปตรวจสอบภายในดันส่วนตัวได้
