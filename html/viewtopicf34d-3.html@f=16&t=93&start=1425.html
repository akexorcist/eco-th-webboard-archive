ต๊กโกวคิ้วป้าย เขียน:1agi+str โหดใหมครับ ออกแนว bsสายบู้ roป่ะ
>>>>>agi+str ก็โหดนะครับ แต่จะออกไปทางเน้นร่ายสกิลไวกับโจมตีไว(เพราะค่าagi) แต่โดยส่วนตัวแล้วผมมองว่าอาชีพนี้นั้นเหมาะกับสายvitมากกว่าเพราะสกิลที่สนับสนุนนั้นดีไปกับทางvitมากกว่า แล้วอาวุธของbsคือค้อนซึ่งค่าความไวของอาวุธค่อนข้างช้าถึงแม้จะมีagiมากๆ ฉะนั้นผมมองว่าstr vit dexพอประมาณกำลังดีครับสำหรับอาชีพนี้แต่ทั้งนี้ทั้งนั้นก็ขึ้นกับความถนัดและเทคนิคของแต่ละบุคคล :P
2ล่าบอสได้เวิกใหม ในช่วงกลางๆของเกมส์และปลายๆ
>>>>ล่าบอสสายagiหมดสิทธ์ครับเพราะเลือดน้อยโดนบอสตบตายง่ายๆ สายvitนี่เลือดเยอะแท้งบอสได้สบายอยู่เลยครับแล้วถ้าเป็นMACสบายเลยครับตอนcb ผมลองกับบอสนกที่โหดมากๆร่ายเวทที่ตายเกลี้ยงเหลือผมขี่หุ่นรอดอยู่คนเดียว
3 pvp อยุ่ในขั้น ต่ำ ปานกลาง หรือเทพ (ถ้ามีของดีๆ)
>>>>pvp เกมนี้เน้นแพ้ทางตามสาอาชีพมากกว่าครับแล้วก็ขึ้นกับว่าเราเน้นอัปสกิลไหนซัพพอตกับstatusไหนซะมากกว่า
4Hp ในเกณฑ์ ปกติของทุกอาชีพอยุ่ในระดับไหน หากเล่น agi+str ค่าhp จะอยุ่ในระดับไหน
>>>>ถ้าเล่นไม่อัปvitเลยโดยทั่วไปhpจะอยู่ราวๆ600-1000ต้นๆเท่านั้นแต่ถ้าbsอัปvit จะทำให้สูงได้ถึง4000เลยทีเดียวเพราะมีสกิลhp maxในการสนับสนุน
5ความคล่องตัวในการเก็บเลเวลมีเย้อะใหม เช่นการแบกของได้เย้อะไม่ต้องกลับเมืองบ่อย เก็บของมาขายได้เย้อะ เบแร่ได้ตอนเก็บเวลอีกทั้ง item ที่ดรอบ ทำให้ วงเงินหมุนอยุ่โดยรอบแบบคล่องตัวกว่าอาชีพอื่นๆ (หากเล่น agi+str เดินหวด ยาวๆ)
>>>>- -จากที่อ่านรู้สึกว่าจาอยากเล่นagi str เกมนี้บอกได้เล่ยว่าไม่เหมือนroครับค่าagi หากอยากเก็บเวลโดยอัปagiหากต้องการตีเก็บเวลตัวมอนเวลเท่ากันนั้นจะต้องอัปค่าagiสูงมากๆเลยทีเดียว(ผมเคยลองรีstatus agiล้วนๆยังหลบมอนเวลเท่ากันได้ประมาณ50-70%เท่านั้นเองแถมโดนตบไม่ถึง5ทีตาย) อาชีพนี้แบกของได้เยอะครับเพราะเป็นสายbp แต่ต้องเล่นemilนะจะได้ใช้เป้ช่วยแบกของ อาชีพนี้เงินหมุนดีมากหากว่ารู้จักค้นคว้าหาตีไอเทมขายซึ่งอาชีพเราเป็นอาชีพที่ดรอปวัตถุดิบในการทำของหากนำวัตถุดิบเหล่านั้นมาแปรรูปแล้วย่อมได้ราคาที่ดีทีเดียว
6เทคนิคการคอมโบสกิลหรือวิธีการต่อสุ้เป็นกลุ่มในการpvpและกิลวอรอยุ่ในลักษณะใดบ้างครับ (เห็นมีแต่คนถาม 1-1 ตลอด -*- ผมชอบรุมอ่า อิอิ )
>>>>ในการpvpกลุ่มนั่นยังไม่เด่นชัดเพราะตอนcb ไม่ได้ลองครับแต่ที่แน่ๆถ้าสู้หมู่อาชีพเราต้องให้คนอื่นสิงครับขี่หุ่นวิ่งไวเพื่อนสิงจะกลายเป็นหุ่นรบครบรูปแบบเลยทีเดียว
7Berserkอะไรนั่นน่ะมีระยะเวลเท่าไหร่บ้างครับ
>>>>ระยะเวลาหากมีการต่อสู้อยู่เบอเซิคจะไม่หายจนครบ60sec (ที่skill lv3)หากไม่มีการต่อสู้จะหมดใน3sec
8หุ่นยนต์ถ้าพังแล้ว ต้องซื้อใหม่อย่างเดียวป่ะ
>>>>หุ่นมีค่าเสียได้30ครั้งครับ(เหมือนpetทั่วไป) แล้วสามารถซ่อมได้ วันละ1ค่าความเสียหาย หากเสียจน0 จะไม่หายแต่ไม่สามารถเรียกออกมาใช้ได้จนกว่าจะซ่อม ส่วนวิธีซอ่มก็หาลูกอมฟื้นฟูสัตว์เลี้ยงมากินก็ได้
9bsขี่หุ่นยนต์ได้ม่ะ
>>>>ได้ครับด้วยการเป็นMACแล้วสวิทอาชีพกลับมาเป็นBSโดยน้ำสกิลขี่หุ่นมาใช้
10Bsกะ ทาทา อาชีพไหน ลงตัวกว่าครับ หรือ แนวทางในการอัพสกิล ตอนเป็นทาทาในแบบของ จขกท และแนวทางในการอัพ สกิลที่มีความสัมพันธ์กับค่า statในแนวทางของ จขกทเป็นอย่างไรบ้าง ผมจะลองนำมาเปรียบเทียบกับแนวทางผมดูว่ามันจะมีข้อแตกต่างตรงส่วนไหนบ้าง(อธิบายแบบนี้มองไม่ค่อยเห้นภาพอ่าครับ -*-)
>>>>แนวทางการอัปนั้นผมแนะนำว่าให้ลองเล่นดูก่อนนะครับเพราะสกิลบางอันมันก็แค่สร้างภาพแต่ใช้จริงๆไม่ได้ดีเลย ลองดูก่อนครับแล้วค่อยรีสกิลหรือstatusเอา(ถ้าไม่มีอะไรเปลี่ยนแปลงจากของญี่ปุ่นและcb จะรีstatusและskillได้)
11ที่ว่า พวก โดมิ มีstrที่สุงกว่า อีมิล หากเรานำเผ่า โดมิมาเล่น ทาทา ในสายagi+str ข้อเสียเปรียบในการแบกของจะมีผลกระทบสูงมากใหมในเรื่องการกระเป๋าและถุงย่ามมัน มีผลต่อการดำเนิน ชีวิตในการเก็บเลเวลและitemมากไหม เช่นว่าโดมิ strสุงกว่า อีมิล จะตีแรงในระดับไหน ถ้าโดมิตีเพิ่มมา สมมุติที่ 20% จขกท มีความคิดเห็นอย่างไรในการเอา ความแรง20%นั้นไปแลกกับ กระแบกของ ที่สูญเสียไปในกรณีท่ไมได้เป็น อีมิล
>>>>เป้นั้นสำคัญมากๆในการเล่นสายbp แต่หากชอบเล่นเผ่าอื่นก็ตามแต่ชอบครับ

2ล่าบอสได้เวิกใหม ในช่วงกลางๆของเกมส์และปลายๆ
>>>>ล่าบอสสายagiหมดสิทธ์ครับเพราะเลือดน้อยโดนบอสตบตายง่ายๆ สายvitนี่เลือดเยอะแท้งบอสได้สบายอยู่เลยครับแล้วถ้าเป็นMACสบายเลยครับตอนcb ผมลองกับบอสนกที่โหดมากๆร่ายเวทที่ตายเกลี้ยงเหลือผมขี่หุ่นรอดอยู่คนเดียว
3 pvp อยุ่ในขั้น ต่ำ ปานกลาง หรือเทพ (ถ้ามีของดีๆ)
>>>>pvp เกมนี้เน้นแพ้ทางตามสาอาชีพมากกว่าครับแล้วก็ขึ้นกับว่าเราเน้นอัปสกิลไหนซัพพอตกับstatusไหนซะมากกว่า
4Hp ในเกณฑ์ ปกติของทุกอาชีพอยุ่ในระดับไหน หากเล่น agi+str ค่าhp จะอยุ่ในระดับไหน
>>>>ถ้าเล่นไม่อัปvitเลยโดยทั่วไปhpจะอยู่ราวๆ600-1000ต้นๆเท่านั้นแต่ถ้าbsอัปvit จะทำให้สูงได้ถึง4000เลยทีเดียวเพราะมีสกิลhp maxในการสนับสนุน
5ความคล่องตัวในการเก็บเลเวลมีเย้อะใหม เช่นการแบกของได้เย้อะไม่ต้องกลับเมืองบ่อย เก็บของมาขายได้เย้อะ เบแร่ได้ตอนเก็บเวลอีกทั้ง item ที่ดรอบ ทำให้ วงเงินหมุนอยุ่โดยรอบแบบคล่องตัวกว่าอาชีพอื่นๆ (หากเล่น agi+str เดินหวด ยาวๆ)
>>>>- -จากที่อ่านรู้สึกว่าจาอยากเล่นagi str เกมนี้บอกได้เล่ยว่าไม่เหมือนroครับค่าagi หากอยากเก็บเวลโดยอัปagiหากต้องการตีเก็บเวลตัวมอนเวลเท่ากันนั้นจะต้องอัปค่าagiสูงมากๆเลยทีเดียว(ผมเคยลองรีstatus agiล้วนๆยังหลบมอนเวลเท่ากันได้ประมาณ50-70%เท่านั้นเองแถมโดนตบไม่ถึง5ทีตาย) อาชีพนี้แบกของได้เยอะครับเพราะเป็นสายbp แต่ต้องเล่นemilนะจะได้ใช้เป้ช่วยแบกของ อาชีพนี้เงินหมุนดีมากหากว่ารู้จักค้นคว้าหาตีไอเทมขายซึ่งอาชีพเราเป็นอาชีพที่ดรอปวัตถุดิบในการทำของหากนำวัตถุดิบเหล่านั้นมาแปรรูปแล้วย่อมได้ราคาที่ดีทีเดียว
6เทคนิคการคอมโบสกิลหรือวิธีการต่อสุ้เป็นกลุ่มในการpvpและกิลวอรอยุ่ในลักษณะใดบ้างครับ (เห็นมีแต่คนถาม 1-1 ตลอด -*- ผมชอบรุมอ่า อิอิ )
>>>>ในการpvpกลุ่มนั่นยังไม่เด่นชัดเพราะตอนcb ไม่ได้ลองครับแต่ที่แน่ๆถ้าสู้หมู่อาชีพเราต้องให้คนอื่นสิงครับขี่หุ่นวิ่งไวเพื่อนสิงจะกลายเป็นหุ่นรบครบรูปแบบเลยทีเดียว

>>>>ระยะเวลาหากมีการต่อสู้อยู่เบอเซิคจะไม่หายจนครบ60sec (ที่skill lv3)หากไม่มีการต่อสู้จะหมดใน3sec

>>>>หุ่นมีค่าเสียได้30ครั้งครับ(เหมือนpetทั่วไป) แล้วสามารถซ่อมได้ วันละ1ค่าความเสียหาย หากเสียจน0 จะไม่หายแต่ไม่สามารถเรียกออกมาใช้ได้จนกว่าจะซ่อม ส่วนวิธีซอ่มก็หาลูกอมฟื้นฟูสัตว์เลี้ยงมากินก็ได้

>>>>แนวทางการอัปนั้นผมแนะนำว่าให้ลองเล่นดูก่อนนะครับเพราะสกิลบางอันมันก็แค่สร้างภาพแต่ใช้จริงๆไม่ได้ดีเลย ลองดูก่อนครับแล้วค่อยรีสกิลหรือstatusเอา(ถ้าไม่มีอะไรเปลี่ยนแปลงจากของญี่ปุ่นและcb จะรีstatusและskillได้)

อื้มมมมม พอเห็นคำตอบแบบลึ้งซึ้งของท่าน Vespyผมพอจะเห็นแนวทางการเล่นในสไตล์ของตัวเองได้ล่ะ

ระบบปืนใหญ่นี้คล้ายระบบเก็บเลเวลของเกมส์สามก้กเลย น่าสนใจดีแฮะ ขอศึกษาเรื่องสายปืนใหญ่ล่ะกันน่ะฮับ

เอา ช่วงไหนก่อนดี หว่า....

งั้นเริ่มแรกเลย การ Tank การยืนชน มอนเตอรเพื่อให้ปืนใหญ่ ทำการโจมตี ปืนใหญ่สามารถได้รับความเสียหายจากการโจมตีของมอนเตอรหรือปปล่าวครับ
(ปืนใหญ่มันยิงออโต้ป่ะหรือว่า เราต้อง ctrl แบบว่ายินนิ่งๆแล้วมอนเตอรเข้ามาไกล้ปืนใหญ่ก็จะทำการยิงอัตโนมัติ)

ปืนใหญ่โจมตีแบบกายภาพป่าวครับ

ความรุนแรงมีระดับใดบ้าง

มีการพัฒนาใหม

ปืนใหญ่มีสกิลใหม

การเคลื่อนที่ของปืนใหญ่เป็นยังไงบ้างครับ

มีอัตตราการแม่นยำมากใหม

ระยะยิง ประมาณไหนครับ

ระบบปืนใหญ่มีผลต่อการได้expที่แตกต่างแต่หากเราไป เปิดมอนเตอรและร่วมโจมตีก็จะได้exp(จำนวนอาจจะไม่แน่ชัด) แต่ถ้าเป็นกรณี เก็บเลเวลเป็นปาร์ตี้ การทำดาเมจของปืนใหญ่จะลดจำนวนของ expที่ได้รับ ต่อกลุ่มหรือปล่าวครับ

ฝากใว้แค่นี้ก่อนน่ะครับ นี่แค่stepแรก -*-
