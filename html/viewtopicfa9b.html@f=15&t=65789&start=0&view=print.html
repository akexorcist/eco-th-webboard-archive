ที่นิยมลง VIT มากกว่า INT เพราะเวลาเก็บเอเลจะลากคลื่นได้ไงครับ
แถมลง VIT ก็ได้ MDEF ก็เพิ่มเหมือนกันแน่ะ พระมีสกิลกันสถานภาพผิดปกติอยู่แล้วด้วย

ถามว่าพระควรอัพ INT ไหมก็ควรอัพไว้บ้างครับ แต่ไม่ต้องเน้นจนเกินงาม
เพราะสกิล50บาร์ดโอกาสติดสถานภาพน่าจะเกี่ยวกับ INT เหมือนกัน

.

เลเวล99 ที่ดีสุดน่าจะประมาณนี้ครับ
แต่ไม่ล๊อคนะ ปรับเปลี่ยนได้ตามสไตล์ตัวเอง

- หมวกปาร์ตี้แดง
- กุหลาบคาบแดง
- พิณ90 +10 Magic
- เกราะ90 +10 Life
- ผ้าคลุมมังกร +10 Magic
- ปาป้า/ชิลเดอร์ เลือกเอาตามที่อยากได้ (ชิลเตอร์ต้องเผ่าเอมิลเท่านั้น)

กางเกง/กระโปรง/ถุงน่อง/รองเท้านี่แล้วแต่แฟชั่นครับผม
วัดผลกันจริงๆก็ไม่ต่างกันมากหรอก ถ้าไม่สนแฟชั่นก็รองเท้าเหลือง+DEX2 ครับ

หรือจะเลือกเป็นเซตชุดพระ 85 ก็ได้ (แต่โดยมากพระชายจะไม่ค่อยเลือกอันนี้กัน)

- หมวกปาร์ตี้แดง
- กุหลาบคาบแดง
- พิณ90 +10 Magic
- เกราะ85 +10 Life
- กางเกงพระ85 (เฉพาะพระชาย)
- รองเท้าพระ85
- ผ้าคลุมมังกร +10 Magic
- ปาป้า/ชิลเดอร์ เลือกเอาตามที่อยากได้ (ชิลเตอร์ต้องเผ่าเอมิลเท่านั้น)

อาจไม่ดีที่สุด แต่โดยคร่าวๆก็ราวๆนี้ครับ
