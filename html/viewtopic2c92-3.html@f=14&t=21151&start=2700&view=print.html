Astralitas เขียน:อยากทราบว่า.. int หรือ mdef เท่าไหร่ถึงจะโดนเวทย์ 0 ทั้งหมดครับ


ถ้าถามถึงสเตตัสก็ปรับได้หลายแบบมาก

ยกตัวอย่างคือ VIT รวม 126 INT รวม 103 ก็จะได้ def 70 mdef 65 (ด้านซ้ายนะ)

คือจะใช้ค่า INT อย่างเดียวไม่ได้ครับในการทำ mdef สูงสุด เนื่องจากค่าสเตตัสตัวนี้เป็นผลรวมของ VIT+INT ครับ

เหมือนกับที่ค่าการหลบระยะไกลมันขึ้นกับ AGI+INT ไม่ใช่ AGI อย่างเดียว

นับสเตตัสก็ทำได้แค่นี้แหละครับ mdef ซ้าย 65 เป็นค่าดีที่สุด (มากกว่านี้เปลือง)

โดนเวทย์ 0 0 0 0 0 0 0 0 ก็ต้องมี mdef ซ้าย 100 ทำได้โดยใส่ ดีไวน์บาเรีย ของซอเซอเรอร์
