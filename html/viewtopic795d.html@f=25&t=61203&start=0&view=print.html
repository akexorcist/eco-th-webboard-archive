หนอนซิ่งนี่ใส่แล้วมอนในแมพจะไม่ตีเราใช่ป่ะคับ

คือเมื่อวานผมใส่หนอนซิ่งจะไปทำเควสคริสตัลที่เกาะอันเดท แต่ตัวสเกลเลตันมาเข้ามาตีผมเฉยเลย 2 รอบ

รอบหนึ่งเกี่ยวเปล่าไม่รู้อะคับ แต่ผมไปตีดอกไม้ในแมพนั้นดอกหนึ่งก่อนจะโดนตีดับกลับมา
รอบสองโดนตีหลังจากคุยกับดาคโซลเสร็จแล้ว

หรือว่าพอใส่หนอนตัวนี้เราห้ามทำอะไรทั้งสิ้นจะตีมอนตัวอื่น คุยกับเอ็นพีซีมิเช่นนั้นมอนจะมองเห็นหรอครับ
