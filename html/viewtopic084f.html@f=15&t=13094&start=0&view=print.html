ตาม topic คือไม่มีผลคับ แต่ละเลเวล มีค่าเพิ่มที่คงที่อยู่ ไม่ได้คิดเป็นเปอเซ็นของที่เรามี

max mp ไม่เกี่ยวกับฟื้นฟู แต่อัพแล้วดีคือหลอดเราจะใหญ่ ตอนใช้มาริโอฟื้นจะกลับมาเต็ม แล้วเยอะกว่าคนที่ไม่อัพ พอมาริโอหาย เราก็จะใช้ยิงได้นานกว่านั่นเอง

increase recovery ต่างหาก ที่เกี่ยวกับการฟื้นฟูครับ และมีผลเฉพาะตอนนั่ง กับ ตอนกินยา ---- ดังนั้นควรอัพไม่ว่าจะสายงก นั่งพัก หรือสายปั๊มรวย กินยา
ส่วนสายสิง ไม่ค่อยแน่ใจ แต่คิดว่ามีผลเหมือนกัน
