DonutLove เขียน:เพื่อความสะดวกในการอ่านและทำความเข้าใจ ผมขอสรุปเป็นข้อๆดังนี้นะครับ

1. ปัญหาการเข้า website
- เนื่องจากมีผู้เข้ามาที่ website ทั้ง www.onenet.co.th และ www.eco.in.th เยอะกว่าที่เราคาดไว้มากๆๆๆๆๆๆ
ทำไมระบบรองรับไม่ไหวครับ ฉะนั้นช่วง1-2 วันแรกจึงทำให้มีปัญหาในการเข้า website ทั้ง 2 ครับ

2. ปัญหาการเข้า webboard
- จุดที่มีผู้เข้าชมมากๆ จะมาจาก 2 ส่วนหลักๆคือ 1. ส่วนของการลงทะเบียน และ 2. ส่วนของ webboard ครับ
ซึ่งเป็นเหตุทำให้ website ทั้งระบบเกิดการอาการที่ว่าขึ้นมา ฉะนั้นจึงทำการปิด ในส่วนของ การลงทะเบียน และ webboard ชั่วคราวเพื่อปรับปรุงครับ
และหลังจากที่ปิด webboard ไปนั้น ... ทางเราได้ทำการเพิ่มประสิทธิภาพให้ webboard สามารถรองรับคนได้เยอะขึ้นแล้วครับ

3. ปัญหาการลงทะเบียน
- ส่วนนี้ต่อเนื่องมากจากข้อ 1. เช่นกันครับ ทำให้ server ของเราเต็มอย่างรวดเร็ว และทำให้เกิดปัญหาดังกล่าวขึ้นมา
ซึ่งตอนนี้ได้ทำการแก้ปัญหาต่างๆ ที่เกี่ยวข้องกับระบบลงทะเบียนเป็นที่เรียบร้อยแล้วครับ
ถ้าคนไหนยังไม่สามารถลงทะเบียนได้ ให้ติดต่อมาที่ 02-769-5999 หรือ gm@onenet.co.th ครับ

4. ปัญหาการเข้าเกมไม่ได้ เนื่องจาก id หรือรหัสผ่านไม่ถูกต้อง
- id และ password ที่มีภาษาไทย หรือ ASCII code ( เช่น •, ♥, ) หรือสัญลักษณ์อื่นๆ
จะทำให้ไม่สามารถเข้าเกมได้ครับ ( แต่ยังเข้าเวปไซต์ได้อยู่ )
วิธีแก้ไขเบื้องต้นคือ ให้ทำการ log-in เข้าหน้าข้อมูลสมาชิกเพื่อเปลี่ยน password ให้เป็นตัวเลขหรือภาษาอังกฤษ ไม่เกิน 12 ตัว ครับ
ส่วนผู้ที่ id มีภาษาไทย, ASCII code หรือสัญลักษณ์ ให้ทำการติดต่อ GM ที่ 02-769-599 หรือ gm@onenet.co.th ครับ

5. login timeout หรือ ย้ายแผนที่แล้วหน้าจอดำ อาการ lag
- ส่วนนี้เกิดขึ้นเพราะผู้เล่นเข้ามาเยอะกว่าที่เราคาดการณ์ไว้มากๆๆๆๆๆๆครับ ทำให้เกิดการ overload ในบางครั้ง
ซึ่งตอนนี้ เราได้ทำการเพิ่มจำนวน server เพื่อทำการรองรับผู้เล่นที่เข้ามาอยู่ครับ
วิธีแก้ไขเบื้องต้นในส่วนนี้นั้น เรากำลังเร่งมืออย่างเต็มที่ในการเพิ่มจำนวน server ให้รองรับกับจำนวนผู้เล่นครับ
ส่วนถ้าใครที่เจอปัญหานี้ ... อาจจะต้อง log-in หลายครั้งหน่อยครับ
( ไม่ใช่ server down เหมือนช่วง closed beta แต่อย่างใดครับ )

6. Account นี้ถูกล็อคฟังชั้นการรับรอง
- ส่วนนี้จะเป็นระบบป้องกันการมั่ว password ครับ ซึ่งเมื่อใส่ id หรือ password ผิดหลายๆครั้งติดกัน
จะทำให้ข้อความนี้ถูกแสดง และจะไม่สามารถเข้าเกมได้ชั่วคราวครับ
วิธีแก้เบื้องต้นคือ ต้องใช้เวลาประมาณ 5-10 นาที และทำการ log-in อีกครั้งด้วย id และ password ที่ถูกต้องครับ
และถ้าไม่มั่นใจว่า password ถูกต้องหรือเปล่า สามารถตรวจสอบได้จากระบบลืม password ทางหน้าเวปไซต์ครับ
http://www.onenet.co.th/Member/Forget_pwd.aspx

7. ปัญหาการ download ต่างๆ ที่ไม่สามารถกดปุ่ม start เพื่อเข้าเกมได้

- Get version information หรือ patch error
วิธีแก้ไขเบื้องต้น
1. uninstall ตัวเกมออก รวมถึงการลบ folder ตัวเกมออกด้วยครับ
2. setup หรือ install ใหม่อีกครั้ง ( โดยที่อย่าเพิ่งทำการ update )
3. โหลดไฟล์ชื่อ "econew.ver" ที่ http://www.eco.in.th/download_game.html
ทำการแตกไฟล์และนำไป copy ทับตัวเก่าใน folder ที่ลงเกมไว้ครับ
4. กดเข้าเกมที่ eco launcher เพื่อทำการ update ก่อนเข้าเกม

- Transmission Served
สาเหตุ - เกิดจากปัญหาการเชื่อมต่อของ internet ซึ่งสามารถเกิดได้หลายอย่างเช่น
• program Anti-virus ต่างๆ
วิธีแก้ไขเบื้องต้น - ปิด program anti-virus ให้หมดก่อนทำการ download patch
ถ้ายังไม่ได้ทำตาม step เทพนี้ ... เปิด anti-virus ให้หมด - ลบตัวเกมแล้วลงใหม่ - download patch
• firewall ต่างๆ
วิธีแก้ไขเบื้องต้น - ปิด firewall เช่นกัน ซึ่ง firewall นี้จะอยุ่ในหลายๆที่เช่น ตัว window เอง หรือตามโปรแกรม anti-virus ต่างๆ ปิดให้หมดก่อนทำการ download patch
• internet ที่ทำการ share กับเครื่องอื่นๆ ... ส่วนนี้จะมี 2 ปัญหานะครับ
internet(1) - เมื่อทำการ share แล้วจะทำให้ speed หรือความเร็วตกลง หรือขาดตอนในบางช่วง ซึ่งมีผลทำให้ไฟล์เสียหาย หรือไม่ครบ เป็นเหตุให้เกิด transmission served ได้เช่นกัน
วิธีการแก้ไขเบื้องต้น - uninstall เกมออก .. ใช้ internet ที่ไม่ต้อง share กับคนอื่นเพื่อให้ได้ speed ที่คงที่
internet(2) - สำหรับ wireless ต่างๆ ที่ถูก share ในหอพักหรือตามมหาวิทยาลัยต่างๆ จะมีการ block port ต่างๆไว้พื่อความปลอดภัยนะครับ ไม่ให้ download หรือติดไวรัสมาลงทั้งระบบ
วิธีแก้ไขเบื้องต้น - บอกให้ผู้ดูแลเปิด port 21 สำหรับการ download patch และ port 12000 สำหรับการเล่นเกม
• hardware - อุปกรณ์ การเชื่อมต่อต่างๆ
ส่วนนี้ ทีม GM เจอกับตัวเองเลยครับ ว่า set ทุกอย่างเรียบร้อยพร้อมที่จะ update patch แล้ว internet speed ก็ไม่ช้า แต่ว่ายังขึ้น transmission served อยู่ ?
วิธีแก้ไขเบื้องต้น - ให้ทำการเช็คอุปกรณ์การเชื่อมต่อต่างๆ (โดยเฉพาะสายแลน ) ว่าสมบูรณ์ดีหรือเปล่า เพราะไม่ไม่งั้นแล้ว จะทำให้การเชื่อมต่อไม่ลื่นไหลและมีปัญหา transmission served ครับ

- eco/patch/econew.ver : Download failed (ErrCode=9)
สาเหตุ - ส่วนใหญ่ปัญหานี้จะกิดกับร้าน internet ที่ทำการลง program การจัดการร้านค้าไว้
ซึ่ง program เหล่านี้จะทำการ block การ download หรือการเข้าเวปต่างๆ
วิธีแก้ไขเบื้องต้น - แนะนำให้เจ้าของร้าน เปิด "port 21" ซึ่งเป็น port ที่ใช้สำหรับการ update patch ต่างๆ
ถ้าเป็น program ฟรี อาจจะต้องทำการลบ program นั้นๆแล้วลงใหม่
ส่วนถ้าเป็น program ลิขสิทธิ์ - ให้ทำการติดต่อเจ้าของ program เพื่อเปิด port 21 ดังกล่าว

วิธีแก้ไขดังกล่าว เป็นวิธีแก้ไขเบื้องต้นครับ ซึ่งอาจเกิดขึ้นได้จากปัจจัยอื่นๆอีกมากมาย
และถ้าผู้เล่นยังไม่สามารถเข้าเกมได้ หรือไม่มีปุ่ม START ขึ้นให้กดเพื่อเข้าเกม
เพื่อความสะดวกรวดเร็วและเข้าใจตรงกันแนะนำให้ใช้ระบบ one-touch service ครับ
เพื่อขอข้อมูลเพิ่มเติมในส่วนรายละเอียด computer และ internet ที่ใช้ครับ
เช่น spec ของ computer, OS ที่ใช้, การ์ดจอ, ขั้นตอนการลงเกม, รูปภาพขณะทีเกิดปัญหา หรือ อื่นๆ
ส่งรายละเอียดได้ที่ http://www.onenet.co.th/service/
