สูตรคำนวณการหักพลังโจมตีทางกายภาพ (ยังไม่รวมธาตุ)

ดาเมจที่ได้ = [(ค่าATK-DEFขวา)×(1-DEFซ้าย/100)] - [VIT/3]

ตัวละครที่ถูกนำมาเป็นตัวอย่าง ตัวที่ 1 -> Sorcerer LV 100/50
VIT88 +12(โบนัส) -1 ชุดอาชีำพ = VIT 99
ใส่ Divine Barrier LV5 (DEFซ้าย+19ขวา+20)
DEFซ้าย = 74
ชุดที่ใส่
หัว -> หมวก80 (DEFขวา+13)
หน้า -> แว่นตา (DEFขวา+1)
ท่อนบนล่าง -> ชุด sorcerer 99 (DEFขวา+85)
รองเท้า -> เท้า sorcerer 99 (DEFขวา+15 VIT-1)
ประดับอก -> Female Tear (DEFขวา+3)
DEFขวา = 137

ตัวละครที่ถูกนำมาเป็นตัวอย่าง ตัวที่ 2 -> Sorcerer LV100/50
VIT88 +12(โบนัส) +8 ชุดแฟชั่น = VIT 108
ใส่ Divine Barrier LV5 (DEFซ้าย+19ขวา+20)
DEFซ้าย = 79
ชุดที่ใส่
หัว -> Party Hat (DEFขวา+2 VIT+2)
หน้า -> กุหลาบแดง (DEFขวา+1)
ท่อนบน -> Bernado Cloth (DEFขวา+10 VIT+3)
ท่อนล่าง -> เกงยีนทั่วไป (DEFขวา+3)
รองเท้า -> Animal Boot (DEFขวา+3)
ประดับอก -> คลุมตั๋ว7 (DEFขวา+1 VIT+3)
DEFขวา = 40
====================================

หากศัตรูมี ATK 500 ถ้วน
คำนวณตามสูตรได้ดังนี้ (ทศนิยมมากกว่า 0.5 ปัดขึ้น)

ตัวอย่างแรก = [(500-137)×(1-74/100)] - [99/3]
= (363 - 74%)-33 = 94-33
= โดนดาเมจ 61 หน่วย
ตัวอย่างสอง = [(500-40)×(1-79/100)] - [108/3]
= (460 - 79%)-36 = 97-35
= โดนดาเมจ 62 หน่วย

สรุปผล - ชุดอาชีพที่ DEF ขวาสูง จะป้องกันดาเมจได้แทบไม่ต่างจากชุดแฟชั่นที่ DEFขวาน้อยแต่ +stats เลยสักนิด
(แต่ราคาทุนค่าชุดทั้งตัวต่างกันฟ้ากับเหว)

=====================================
สูตรคำนวณการหักพลังโจมตีเวทย์ (ยังไม่รวมธาตุ)
ดาเมจที่ได้ = [(ค่าMATK-MDEFขวา)×(1-MDEFซ้าย/100)] (ไม่ต้องหาร INT แบบกรณี VIT)

ตัวละครที่ถูกนำมาเป็นตัวอย่าง ตัวที่ 1 -> Sorcerer LV 100/50 (ตัวเดิมกับที่ใช้ข้างบน)
INT92 +19(โบนัส) +1 ชุดอาชีำพ = INT 112
ใส่ Divine Barrier LV5 (MDEFซ้าย+35ขวา+20)
MDEFซ้าย = 97
ชุดที่ใส่
หัว -> หมวก80 (MDEFขวา+12)
หน้า -> แว่นตา (MDEFขวา+1)
ท่อนบนล่าง -> ชุด sorcerer 99 (MDEFขวา+100)
รองเท้า -> เท้า sorcerer 99 (MDEFขวา+15)
ประดับอก -> Female Tear (MDEFขวา+2)
MDEFขวา = 150

ตัวละครที่ถูกนำมาเป็นตัวอย่าง ตัวที่ 2 -> Sorcerer LV 100/50 (ตัวเดิมกับที่ใช้ข้างบน)
INT92 +19(โบนัส) +6 ชุดแฟชั่น = INT 117
ใส่ Divine Barrier LV5 (MDEFซ้าย+35ขวา+20)
MDEFซ้าย = 101 (เวทย์ยิงเข้า 0 ร้อยเปอร์เซน)
ชุดที่ใส่
หัว -> Party Hat (MDEFขวา+2)
หน้า -> กุหลาบแดง (MDEFขวา+1 INT+5)
ท่อนบน -> Bernando Cloth (MDEFขวา+10 INT+1)
ท่อนล่าง -> เกงยีนทั่วไป (MDEFขวา+2)
รองเท้า -> Animal Boot (MDEFขวา+3)
ประดับอก -> คลุมตั๋ว7 (MDEFขวา+1)
MDEFขวา = 39
====================================

หากศัตรูยิงเวทย์ MATK 2000 ถ้วน
คำนวณตามสูตรได้ดังนี้ (ทศนิยมมากกว่า 0.5 ปัดขึ้น)

ตัวอย่างแรก = [(2000-150)×(1-97/100)]
= 1850 - 97%
= โดนเวทย์ทีละ 56
ตัวอย่างสอง = ไม่ต้องไปคิด ในเมื่อ MDEF ซ้ายเกิน 100 ไงๆเวทย์ก็เข้า 0

สรุปผล - โดน 0 กับ โดน 56 ต่างกันตรงที่เพิ่มภาระในการที่ต้องฮีลขึ้นมานานๆครั้งเท่านั้นเอง อีกอย่าง กรณีของตัวอย่างแรก ช่วงเลเวล 101 ถึง 110 คุณมีแต้มพอที่จะเพิ่ม INT ทำ MDEF ซ้าย 100 ได้แน่ๆครับ ไม่ต้องห่วงเลย

=====================================

สรุปรวบยอด ดูจากสูตรการคำนวณ ชุดประจำอาชีพ 99 มันก็แรงเทียบเท่าชุดแฟชั่นที่ราคาแพงกว่า 2-3 เท่าได้นั่นแหละครับ.. แค่เจ็บตัวกว่านิดหน่อยในเรื่องเวทย์เท่านั้นเอง เจ็บทีละหลักสิบแบบนี้ โดนสัก 20 ที แล้วค่อยให้พระฮีล ทีนึงเลือดก็เต็มอยู่ดี..
หรือจะเสียเงินเพิ่มอีก 2-3 เท่า เพื่อให้โดนทีละ 1 หรือ 0 ก็แล้วแต่ท่านจะเลือกละกันครับ

ส่วนเรื่องความสวยงาม.. ระบบหลอมช่วยท่านได้

ยังไงก็ขอให้สูตรนี้ช่วยท่านทั้งหลายที่กำลังจะตัดสินใจซื้อ ชุดแฟชั่น หรือ ชุด99 ได้นะครับ จะได้รู้ว่าผลมันต่างกันขนาดไหน
ยังไงเสียนี่มันก็ตัวอย่างเปรียบเทียบเดียวเท่านั้น ถ้ากรณีชุดแฟชั่นแบบผสม stats อย่างอื่น อาจจะให้ผลต่างกันก็ได้เมื่อเอามาเทียบกับชุด 99 อีกรอบ

*หมายเหตุ* หากผมไม่ตาลาย ก็คิดว่าไม่น่าบวกลบเลขผิดพลาดนะครับ ยังไงท่านที่ชำนาญคณิตศาสตร์ หรือ ตรวจทานเก่ง ช่วยเช็คให้ผมอีกรอบละกันนะครับ ว่าเลขตรงไหนตกหล่นไป แล้วทำให้สูตรคำนวณออกมาผิดบ้างรึเปล่า

ขนาด DEF 84 - 42 ( Vit 99 + 18 = 117 ) ยังโดนกันเนอร์ยิงทีละประมาณ 2000 ได้

ซึ่งถ้าคิดตามสมการด้านบนนะฮะ

กำหนดให้ x = ค่า ATK
2000 = ( x - 42 )(1 - 84/100) - (117/3)
2000 = ( x - 42 )(0.16) - 39
2039 = ( x - 42 )(0.16)
2039/0.16 = x - 42
12,743.75 = x - 42

x = 12,785.75

นั่นคือค่า ATK จากกันเนอร์ในวอร์ที่บัพ Flame Heart + Attack Assist และยิงด้วย Cross Crest นะครับ
