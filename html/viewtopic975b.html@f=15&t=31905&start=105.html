กำ จะเล่น freak ก็อัพให้ครบ 3 อย่างดิ ไปแนะนำให้อัพอย่างเดียวทำไม

ประโยชน์ของสาปทั้ง 3 ชนิด
- พิษ ทำให้มอน atk matk ลดลงครึ่งนึง << เค้าหวังกันตรงนี้กัน ไม่ได้หวังให้มอนเลือดลดเพราะพิษกันเลย
- ใบ๊ ทำให้มอนร่ายเวทย์ไม่ได้ พวก atk ธาตุก็ไม่ได้
- หิน ทำให้มอนยืนเฉยๆ นิ่งๆ avoid เหลือ 0 แต่เพิ่ม def กรูฟได้แต่มอนจะไม่เด้ง เพราะติดหินอยู่ ถ้ามอนติดหินตอนร่ายเวทย์อยู่ มันก็ยังสามารถร่ายต่อได้จนจบ

สรุป สาปทั้ง 3 ชนิดมันมีการสนับสนุนกันของมันเองในตัวอยู่แล้ว
หิน ใช้หยุดเวทย์ไม่ได้ ต้องพึ่งใบ้
ใบ้หยุดการโจมตีไม่ได้ ต้องพึ่งหิน
พิษจะเปนตัวช่วยลดความรุนแรง สำรองในกรณีที่หินกับใบ๊เกิดไม่ติด
