มาละจ้า ภาพเผา เอ้ยยไม่ใช่ ภาพกิจกรรม X-Mas หรรษาปาร์ตี้แอ๊บแบ๋ว
และ กิจกรรม ปาร์ตี้หรรษา Happy New Year 2008
ตอน วอคแรลลี่ ท่องโลกอโคเนีย

อันนี้ต้องขออภัยที่เลื่อนเวลาการจัดกิจกรรมออกไปเนื่องเนื่องเหตุผลบางประการ
กิจกรรมแรกนั้น X-Mas หรรษา จัดขึ้นที่เมืองหน้าด่านฟาร์อิส
ซึ่งเรียกรวมพลตั้งแต่เวลา19.00น. แต่กว่าจะมากันครบปาเข้าไปเกือบ 3ทุ่มกว่าๆ
ซึ่งสมาชิกก็มากันบางตาพอสมควรเนื่องจากไม่ได้แจ้งข่าวกิจกรรมล่วงหน้า

ขออภัยแทนเพื่อนๆที่ไม่ได้มาร่วมด้วยนะจ้ะ

สำหรับการร่วมสนุกกิจกรรมในครั้งนี้ จะให้เพื่อนๆทั้งสมาชิกหน้าเก่า
และหน้าใหม่ได้รู้จักสนิทสนมกันมากขึ้น
โดยทุกคนที่มาร่วมงานต้องแต่งกายแอ๊บแบ๋ว ตามชอบเพื่อประกวดแฟนซีปาร์ตี้แอ๊บแบ็ว (โดยจะประกาศผลในกิจกรรมครั้งต่อไป )
จากนั้นหัวหน้าริงอาช้างก็จะทำการแบ่งเพื่อนๆออกไปทีม ทีมละ 2คน
โดยจับคู่ให้ เพื่อนให้สมาชิกเก่าและใหม่ได้มีโอกาสทำความรู้จักกันมากขึ้นด้วย >< ~~~~ งานนี้นู๋แนนซึ่งมาใหม่ถึงกับถามหาว่าพี่คนไหนคือบัดดี้ทีมนู๋
ส่วนนู๋มื่นก็ถอนหายใจเฮือก เมื่อรู้ว่าตนเองได้บัดดี้คือนู๋ไอซ์คุง
เด็กน้อยประจำริง จอมป่วน

โดยแต่ละคนจับคู่เป็นบัดดี้และออกหาไอเทมในแมพรอบๆเมืองหน้าด่านต
ามที่ทางทีมงานกำหนด และกลับมาส่งยังจุดให้คะแนน
งานนี้มีการพลิกล็อคเกิดขึ้นซะด้วยสิ
ปิดท้ายด้วยภาพบรรยากาศประทับใจของกิจกรรมนี้จ้า


รอรวมพล นานแล้วยังไม่มากันสักที เค้ารออยู่น๊า!!!!


มาแชะอีกรูปละกัน ก่อนกิจกรรมจะเริ่ม ^O^


ขึ้นมา ณ จุดเช็คคะแนนและทำการแบ่งทีมเป็นคู่ๆดังนี้

ทีมแรก พี่กิม คู่กับ พี่เป้

ทีมที่สอง พี่อึ๊บ คู่กับ นู๋แนน

ทีมที่สาม นู๋มิ้น คู่กับ ไอซ์คุง

ทีมที่สี่ นู๋ตั้ม คู่กับ บอยคุง ( รายนี้เน็ตเกิดเน่าหลุดไปก่อน นู๋ตั้มเลยฉายเดี่ยวคว้ารางวัลมาเพียวๆเลย )




เสียดายที่ไม่สามารถส่งสปายไปเก็บภาพการร่วมกิจกรรมได้ แต่ผลการแข่งขันทีมพี่กิมพี่เป้ แม้จะนำโด่งมาโดยตลอด แต่ก็พลาดท่าให้กับทีมพี่อึ๊บในนาทีสุดท้ายไปอย่างขาดเลย งานนี้มีม้ามืดจิงๆ

สำหรับของรางวัลอาจจะวุ่นวายสักหน่อย เพราะมีเวลาหาเพียงแค่ 3-4ชั่วโมงก่อนทำการแข่งขัน ทีมชนะได้หัวแพนด้าจังไปครอง อันดับสองได้เสื้อกันหนาวสีชมพูสดใส ปิดท้ายด้วยการถ่ายภาพหมู่อีกครั้ง



อะๆ แถมให้อีกรูปหนุง



งานนนี้ของรางวัลไม่ใช่เรื่องใหญ่ หากแต่สมาชิกได้ใจซึ่งกันและกันไปเต็มเลยจ้ะ

หลังจบกิจกรรมครั้งนี้ สมาชิกหน้าใหม่อย่างนู๋แนน ก็จ้อเป็นต่อยหอย รู้จักและสนิทกับพี่ๆในริงมากขึ้น ส่วนไอซ์คุงก็คงยังป่วนต่อปาย

จุดประสงค์ที่จัดไม่ใช่อื่นใดเลย เพียงอยากให้พวกเราชาวHM รู้จักกันมากขึ้น พูดคุยกันมากขึ้น และรักกันมากขึ้น สุขสันต์วันคริสมาตค่ะ
