สกิลโอนอิ้นนี่เป็นสกิลที่ใช้ให้กับผู้เล่นอื่นนอกจากตัวเอง
ถ้าตัวละครเรามี intเยอะ ก็ควรเอาไปเหมือนกันครับ
เพราะเวลาวอก็โอนให้เพื่อนในตี้จะได้โดนเวทเบาๆ
แต่สกิลโอนอิ้นมันเป็นสกิลที่ใช้ให้เป้าหมายอื่นนอกจากตัวเอง
ดังนั้นถ้าคิดว่าในวอจะได้ใช้ประโยชน์ก็ควรเอาไปนะครับ
ส่วนสกิลเอ็นช๊านบล็อคนี่ถ้าไม่ได้ลงintเยอะๆ
หรือไม่ได้เล่นสายโอนก็ควรเอาสกิลนี้แทนจะดีกว่าครับ
ความจำเป็นสกิลนี้ใช้ขัดจังหวะคู่ต่อสู้ดีมากครับ
ลองชั่งใจดูว่าสกิลไหนที่คิดว่าใช้งานบ่อย
ก็ควรเอาสกิลนั้นมาอะครับ
