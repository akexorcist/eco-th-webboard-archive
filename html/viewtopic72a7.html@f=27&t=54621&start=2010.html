นี่ครับข้อมูลบอสDoomDoom


• เควสบอสสุดมันส์สนั่นไอเท็มแรร์
วิธีทำ -เริ่มแรกให้เพื่อนๆเข้าไปคุยกับ NPC Tasomboonอยู่ในแผนที่Fruit Forestนะครับ
-แล้วอย่าลืมเลยนะครับทุกคนที่จะเข้าไปในนั้นต้องมี Momo สัตว์เลี้ยงที่เป็นวัวที่เราทำจากเมือง Fareast City โดยหายาทำวัว(ซึ่งผมลืมชื่อไปแล้ว)ซึ่งตกจากGeckoในแผนที่Momo PlainและBarnทางไปปราสาทอันเดท(UndeadCastel)(ป.ล.ลืมชื่อแมพอะ- -)แล้วหาหญ้ามาอีกตามที่ลุงในฟาร์มวัวบอกครับ ในกรณีที่เรามีวัวแล้วให้ติดตั้งวันแล้วคุยกับเอ็นพีซีได้เลยครับ
-เมื่อคุยแล้ว NPC Tasomboon จะบอกเงื่อนไขการเข้าห้องบอสครับ(หรือประตูมิตินั่นเอง)
กรณีของพวกไม่มีวัวแล้วไม่ลงทุนคือตี้มันเข้าไปกี่คนก็ได้อย่างน้อย3คน 2คนต้องมีวัว แล้วคนที่จะส่งวัวต้องมีสกิวหายตัวซึ่งรับงานจากพวกไม่ลงทุนลงไปมอนวัวให้ พวกไม่มีวัวยืมแล้วพวกยืมวัวนั้นก็ต้องเอาไปคืนเจ้าของแค่นี้ก็เสร็จพิธี- -คิดดูผมแฉทั้งบอสช้างทั้งแผนชั่วของพวกลักลอบเข้ามาฆ่าบอสช้างโดยไม่มีวัว ได้เด็ดขนาดใหน- -
• ของรางวัลที่เราได้ฆ่าบอส(ไอเท็มที่ดรอป)มีดังนี้
- Fighter Box *
- Spell User Box *
- Backpacker Box *
* ป.ล. ในกล่อง1กล่อง จะสุ่มไอเท็มเพียงอย่างเดียวแล้วไม่ไช่ครบชุดมี2เพศก็สุ่มเพศอีกตามเคย- -
- Weapon Box (อาวุธในกล่องนี้จะมี3อาชีพใหญ่ซึ่ง1กล่องจะออกมา1สายอาชีพเท่านั้น)
*1กล่องต่อ1ตัวบอสช้าง ไม่ใช่อาวุธ90 มีเร่งใช้เร่ง(เร่งของตก2อย่าง)ตก2กล่องอาจจะเป็นไปได้ถ้าอาวุธ90 แชทั้งปาตี้เยยพี่น้องตกกันไปคนละ1ถุง ถ้าไช้เร่ง(เร่งของนะของตก2อย่าง)แนะนำควรจะมีคนเปิดแล้วปิดซึ่งคนที่เปิด บอสนั้นถ้าจะดีเปิดกระจกตกของ2อันได้เลยแล้วไห้คนที่เปิดกระจกไปปิดท้ายบอส เอาให้ตายแค่นี้ก็ได้ถุงมา2ใบแล้วแต่ก็ไม่แน่นอนนะว่าจะต้องได้อาวุธทุกถุง

• สกิลโหดของบอส
- Absolute Terror = ทำให้ Mp Sp ของตัวละครที่อยู่ในขอบเขตแสดงผลกลายเป็น 0
- Megadark Blaze = Skillที่ใช้MeteoและNassingensเกิดขอบเขตรอบๆตัวเองขนาด12*12
- Esse Real Body = การโจมตีทางกายภาพไม่เกิดในช่วงระยะเวลาหนึ่ง
- Dispel Aura = การโจมตีด้วยเวทย์มนตร์ไม่เกิดผลในช่วงเวลาระยะหนึ่ง
- Dark Elephant Call = เรียกSummon Dark Elephantออกมา *
*ป.ล. ในกรณีการใช้สกิลนี้คือการตีบอสครั้งแรกไปตีโดนมันถ้าตีลูกน้องมันตายทั้ง หมดมันก็จะเรียกอีกเรียกเรื่อยๆด้วยดังนั้นเราจึงต้องแท๊งลูกน้องไว้1ตัวบอส ตายเราก็เก็บมันซะ
