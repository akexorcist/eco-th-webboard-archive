ลักษณะ Skill : Active
SP ที่ใช้ : 3
ความสามารถ : ทำการแยกส่วนเฟอร์นิเจอร์ หรือของตกแต่งที่ไม่ต้องการ เพื่อให้ได้ของกลับมาใช้ใหม่ได้
เป้าหมาย : เป้าหมายเดี่ยว (สิ่งของ)
ระยะ Skill : 3
** รายละเอียด Skill : ทำการแยกส่วนเฟอร์นเจอร์ที่ไม่ต้องการ เพื่อให้ได้ของกลับมาใช้ใหม่ (ใช้ไม่ได้ขณะ Possession)
- ใช้กับเฟอร์นิเจอร์ตัวเองเท่านั้น <<< แอบเนียนไปใช้กับของคนอื่นไม่ได้เน้อ
- เฟอร์นิเจอร์มีระดับของตนเอง ยิ่งระดับสูงยิ่งมีโอกาสได้ของดี เช่น หินตีบวก(หินสายฟ้า) หรืออื่น ๆ หรืออาจได้ Mixture Failure ก็ได้
