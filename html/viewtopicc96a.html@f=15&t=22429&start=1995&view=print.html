เอาเถอะๆ เรื่องกะเบลดที่ฟุจิกินี้แทบจะเรื่องธรรมดา
สมัยทำเควสฆ่าโจรแดง ก็พยายามตื่นแต่เช้าไปทำ
ส่วนเรื่องเววนี้หวังยาก= = ไม่รู้มันจะรีบฟันไปตายไหน
ก็เข้าใจอยู่สกิว มันเปลืองsp + ผลมันไม่นาน
แต่มันก็น่าจะเห็นใจกันบ้าง

ยังมีบางกรณีเจอ ออกแนวว่าขอฟันซัก1ฉับก็ยังดี อะไรทำนองนี้

ใครดีด้วยเราก็ดีตอบ ถ้ามีน้ำใจให้เรา เราก็มีน้ำใจให้ (แต่หายาก )

ไหนจะตอนมันเบอเซิกหรืออะไรซักอย่างที่ทำให้ตีมั่วๆอ่าแหละ
