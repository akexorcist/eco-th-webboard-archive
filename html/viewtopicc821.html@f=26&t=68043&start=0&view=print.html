ขอข้อมูลเควสแลกฟอนิเจอร์[Furniture Recycle]

โพสต์แล้ว: จันทร์ 17 ส.ค. 2009 7:02 pm
โดย ECO
ผมรับเควสจาก Furniture Craftfman มันให้เอาฟอนิเจอร์ต่างๆไปส่งแล้วจะได้ฟอนิเจอร์ไหม่ ส่วนการหาฟอนิเจอร์ ก็ให้เอาถังสีต่างๆไปแลกกับ npc ตามคำใบ แต่คำใบที่มันให้มา ไม่รู้ว่ามันคือ npc ตัวไหนอะคับ

เควส วันอาทิตย์ ส่งโคมกระดาษ เอาถังสีฟ้าไปให้ ผู้หญิงถือตะเกียงแล้วจะได้ Lump เพื่อเอาไปส่งเควส(ผุ้หญิงถือตะเกียงมันอยุ่ไหนอะ)

เควส วันจันทร์ ส่งพรมปูพื้น เอาถังสีเขียวไปให้ รัด ถะ มน ตี ฝ่านซ้าย แล้วจะได้พรมมาส่งเควส (แล้วคนที่แลกมันอยู่ไหนหว่า)

ใครรุ้ขอข้อมูลที่นะครับ

เคยเข้าไปดูแล้วครับแต่ข้อมูลมันไม่ตรงกันเลยสักอัน ที่ตรงก็แค่ให้รู้ว่ามีเควสนี้ กับเควสเปลี่ยนทุกวัน ขนาดของยงไม่ตรงกันเลย

ตอนนี้เดินหาเองอยู่เดินวันอาทิตย์ครึ่งโลกไปวันและ ยังไม่เจอ วันนี้เดินไหม่อีกเควสถ้าเจอnpcที่แลกก็คงดี
