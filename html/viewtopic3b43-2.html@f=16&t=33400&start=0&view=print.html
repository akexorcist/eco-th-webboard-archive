ลองเปิดดูโกเลม Catalog หมวดของขาย ที่ Uptown กับ Downtown ดูละกัน
ของแบบนี้ มีคนตั้งขายหลายคน .... ตั้งราคาใกล้เคียงกับเขา หรือจะตัดราคาเขาก็ตัดสินใจเอาเองละกัน

บอกแต่ราคาคร่าวๆ นา .... ราคาจริง ต้องสำรวจตลาดปัจจุบันเองค่ะ ดูแค่ร้านที่ลง Catalog ก็พอ


Steel nugget = ไม่เกิน 1k
Silver nugget = 10k (เควสทาทา)
Lead nugget = เก็บไว้ให้ BS เก่งๆ หรือ เพื่อนที่เป็น Gunner เถอะ ... ถ้าไม่อยากเก็บก็ OC ค่ะ
Gold nugget = ครึ่งหมื่น (เควสBS)
Copper Lump = ตอนนี้ยังไม่มีประโยชน์ ... ถ้าไม่อยากเก็บรอซาก้าหน้า ก็ OC ค่ะ
Plattinum Lump = ครึ่งแสน
Titanium Lump = หมื่นเดียว ... เอาไปทำเป็นแว่นตาแล้วจะขายได้แพงกว่ามาก
Asphalt = ไม่เกิน 10k
Sand = เอาไปทำ Sand Paper ส่งเควสทาทาเท่านั้น ขายไม่ได้
Cut out Machine = ไม่เกินสองพัน
Hoka Stone = ส่งเควสถั่วที่เกาะไทนี่
Hot Stone = เอาไปทำระเบิดขายให้ชาวนาบางคน ... ถ้าขายเป็นหิน จะขายไม่ออก


ปล. ของที่เธอซื้อจาก NPC ในราคา 1000 ซึ่งDCเหลือ800 จะขายกลับ NPC ได้ 100 และOC ได้ 144
... นี่เป็นความจริงที่คนที่ริจะเป็นพ่อค้าแม่ขาย ทุกคนต้่องเข้าใจ :lol:
