เอ่อช่วยทีงับไดรเวอร์การ์ดจอทำเหตุซะแล้ว-*- ก่อนหน้าที่ลงอีโค่หนแรกก็เป็นมาทีนึงแล้วคือพอเข้าเกมจะเห็นพื้นเป็นสีดำ ก็ไปอัพเดตไดรเวอร์การ์ดจอใหม่ก็ใช้ได้ตามปกติ ทีนี้นานๆเข้าเครื่องมันเริ่มช้า+มีอาการเอ๋อๆเลยตัดสินใจฟอร์แมตลงวินโดว์ใหม่

พอลงอีโค่อีกรอบมันก็เป็นพื้นดำเหมือนเดิมอะงับ ในใจก็ยังคิดว่าเด๋วโหลดไดรเวอร์ตัวใหม่ก็น่าจะหาย พอเอาเข้าจริงปรากฏว่าแค่เข้าวินโดว์ความละเอียดกับสีก็เพี้ยนแล้วอะงับ พอลองไปปรับดูที่ความละเอิยดอยู่ที่800*600 ไม่สามารถปรับเป็นค่าอื่นได้ ส่วนตรงบิทสีเป็น lower 4 bit เลยงับอันเดียวโดดๆ -*- เซงมาก

ทีนี้เลยตัดสินใจ rollback driver กลับเป็นตัวเดิม ผลคือความละเอียดและบิทสีของวินโดวส์ปกติทุกอย่าง แต่พอเข้าอีโค่หน้าล็อกอินสีเพี้ยนแบบไม่สามารถดูออกเลยว่าเป็นรูปอะไร (เพี้ยนประมาณว่ามันแสดงภาพด้วยบิทสีน้อยๆอะไรแบบนั้นอะงับ สีเปรอะเป็นจุดๆเต็มหน้าต่างไปหมด) แม้แต่ปุ่มออกยังไม่สามารถดูออกเลยงับว่าอยู่ตรงไหน

ตอนนี้กำลังงงมากๆเพราะก่อนหน้าที่จะอัพเดตไดรเวอร์การ์ดจอ ยังเข้าเกมได้เพี้ยนแค่สีพื้นเป็นสีดำ

อันนี้รุ่นของการ์ดจองับ nvidia geforce4 mx440 64mb (ตอนที่ซื้อจำได้ว่ามันเป็น geforce2 mx400 นิหว่าแต่ลองตรวจสอบดูหมดแล้วมันดีเท็คเป็นตัวบน)

ลิ้งค์ข้างล่างนี้ก็ไปดูมาแล้วอาการแบบเดียวกันเลยงับสีพื้นเป็นสีดำ ไดร์เวอร์ที่อัพเดตก็ตัวเดียวกันกับที่คุณหน้าตาดีลงไว้
http://board.onenet.co.th/viewtopic.php?t=60125

ปวดเฮดสุดๆ เอ่ออีกนิดงับก่อนหน้าที่จะฟอร์เมตไปเมืองน้ำมาก็เห็นเป็นสีดำหมดทั้งแมพ เว้นแต่หลอดเลือด(ตอนนั้นสิงไป) อันนี้เป็นที่การ์ดจอใช่มั้ยงับ อัพเดตไดรเวอร์จะมีโอกาสหายมั้ยงับ (ถ้าไม่หายเปลี่ยนการ์ดจะแก้ปัญหาได้หมดสินะ-*-)
