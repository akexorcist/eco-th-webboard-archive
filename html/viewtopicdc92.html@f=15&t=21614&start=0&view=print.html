โดย ECO
คือตามคำอธิบายเคยอ่านเจอในกระทู้ Magic barrier เลเวลยิ่งมากยิ่งเพิ่มเวลาให้นานมากขึ้น Magic Shield คือเพิ่มพลังป้องกันเวทย์มนย์ ยิ่งอัพเยอะยิ่งป้องกันเพิ่มขึ้นเยอะ

ตามที่ผมเข้าใจคือ
1.ต้องร่าย Magic Shield ก่อน แระร่าย Magic barrier ตามถึงจาใช้งานได้ใช่มั้ยคับ
2.ถ้าไม่ได้อัพ Magic Shield พอเป้นซอแระอัพ Magic barrier พอร่าย Magic barrier จะเพิ่มค่าป้องกันเวทย์มนย์เปล่าคับ

ปล.ผมมะได้อัพ Magic Shield อ่ะ
