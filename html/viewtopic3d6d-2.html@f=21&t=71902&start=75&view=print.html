หญิงสาวผมดำผู้เป็นแม่ทัพอมนุษย์ที่มาสืบข่าวและก่อวินาศกรรมในเมืองฟิลาเดลอัสหันไปมองตามเสียงถามที่ดังขึ้นข้่างๆ ก็พบกับเจ้าของหอพักกำลังนั่งอยู่ตรงข้ามกับตน

ในวินาทีแรกที่สมองของเธอแปลผลของสิ่งที่ได้ยินมาครบถ้วน นาจิเรคก็คิดในใจทันที "เข้ามาหอพัก ถ้าไม่ได้มาหาห้องพักค้างแรม แล้วจะเข้ามาหาพระแสงอะไรฟะ นี่มันคำถามอะไรกันเนี่ย?" แล้วก็เกิดความรู้สึกว่า ปกติคนที่ดีดพิณได้ไพเราะ มีดนตรีในหัวใจ ไม่น่าจะหาเรื่องกวนบาทาคนอื่นแบบนี้นี่นา ยิ่งเป็นงานอย่างเปิดหอพักบริการคนทั่วไปด้วยแล้วนี่...

แต่ความคิดระแวง และระวังภัยในฐานะแม่ทัพก็เข้ามาแทนที่ เธอฉุกคิดว่า "หรือว่าเธอคิดจะถามว่า 'เรามาทำอะไรที่เมืองนี้' เพื่อสืบข่าวสารให้กับทางการกันแน่?" แต่แล้วก็ต้องสลัดความคิดนี้ทิ้งไป เพราะความเป็นไปได้ที่ฝ่ายฟิลาเดลอัส จะลงทุนจ้างเจ้าขอหอพักและโรงแรมทุกแห่งในเมืองกันกว้างใหญ่ไพศาลแห่งนี้ ให้เป็นสายลับกันหมด คงไม่ทำแน่ๆ ยังกับพวกชนชั้นสูงจะระแวงว่ามีคนทำลายหอคอยงาช้างของพวกเขาได้งั้นแหละ...

ที่เป็นไปได้ที่สุดคือเจ้าของหอพัก ถามเพื่อชวนพูดคุย... ถ้าจะไม่ตอบ... ก็คงได้ แต่มันคงจุดประกายความสงสัยเสียเปล่าๆ และเธอเองก็ไม่อยากใช้ความสามารถสะกดความทรงจำพร่ำเพรื่อ

ถ้าอย่างนั้น แล้วเราจะตอบอย่างไรดีล่ะ...

นาจิเรคนั่งนิ่งคิดอยู่พักหนึ่ง ก่อนจะตัดสินใจตอบกลับไปว่า

"ฉันเอง... เข้ามาพักที่หอพักนี้... เพราะมีธุระสำคัญที่ผู้มีพระคุณในต่างแดนไหว้วานมา ที่อาจใช้เวลานานกว่าจะสำเร็จต้องทำในเมืองนี้น่ะค่ะ..."

ให้ตายสิ ทำไมฉันต้องพูดเรื่อง "ผู้มีพระคุณในต่างแดน" ไปด้วยนะ... ดูเหมือนความสามารถในการแทรกซึมและปลอมตัว คงไม่เหมาะกับเราที่ค่อนข้างบ้า "ความเป็นสุภาพบุรุษ และความซื่อตรง" จริงๆ นั่นแหละ... เธอคิดในใจหลังจากที่ตอบคำถาม ของเจ้าของหอพักที่มีตาสีเดียวกับเธอเปี๊ยบไป...
