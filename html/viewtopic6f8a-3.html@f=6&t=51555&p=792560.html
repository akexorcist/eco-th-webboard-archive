ด้านสว่าง

Awake (ตื่น)
Active
เป้าหมาย : ผู้อื่น
การแสดงผล : เหมือนสกิลคืนชีพพระ
MP - SP : 20-0

The End Of The World (โลกาวินาศ)
Active
เป้าหมาย : ทุกสิ่งในแผนที่
การแสดงผล : ทุกอย่างในแม็บจะตายหมดแม้กระทั่งตัวเอง โดยของที่ดร็อปจะเก็บได้ทันที
(คนที่เพิ่งมาก็สบายบรื๋อ)
MP - SP : สุดๆ จนขาดดิ้น

Cool Blood (เลือดเย็น)
Passive
เป้าหมาย : ตนเอง
การแสดงผล : แย่งไอเท็มดร็อปได้โดยไม่ต้องรอนาน

Human B-Ing (เป็นคนหรือเปล่า)
Active
เป้าหมาย : คนอื่นๆ
การแสดงผล : ตรวจสอบความมีมนุษยธรรมโดยสังเกตจากสีชุดและสัตว์เลี้ยง ถ้าแต่งตัวคล้ายสัตว์เลี้ยง จะถูกส่งไป Safe Point ทันที

ด้านมืด

Sudden (อยู่หรือตาย)
Active
เป้าหมาย : ผู้อื่น, มอนสเตอร์
การแสดงผล : โจมตีโดยแลกชีวิตโอกาสสำเร็จขึ้นอยู่กับ JobLv*2 ถ้าล้มเหลวอาจเสียชีวิตถ้าสำเร็จจะได้ exp. จากสิ่งที่ฆ่า แต่ถ้าเป็นคนจะเสีย exp. ตามค่ามาตรฐาน ก็คือ exp. ที่ได้จะเท่ากับ exp. ของผู้ตายที่ลดไปแล้ว ยิ่งใกล้ 100 % ยิ่งดี และจะใช้ต่ำกว่าเลเวล 50 ไม่ได้

Men In Black (ชายชุดดำ)
Active
เป้าหมาย : ตนเอง
การแสดงผล : เปลี่ยนสีผม เปลี่ยนชุด เปลี่ยนตาของตัวละครให้มีสีดำในเวลา 10 นาที

Clone (ตบตา)
Active
เป้าหมาย : ตนเอง
การแสดงผล : กลายร่างเป็นอะไรก็ได้แม้แต่ NPC (ยกเว้นกล่อง คริสตัล ต้นไม้ เพราะมันเดินไม่ได้) ภายใน 15 นาที

Blindness (ไก่ตาฟาง)
เป้าหมาย : ผู้อื่น, มอนสเตอร์
การแสดงผล : ทำให้ทุกคนมองไม่เห็นเรา จะได้ไม่โดนโจมตี แต่ถ้าย้ายแผนที่จะหมดฤทธิ์

สายกลาง

Get Out! (ออกไป)
Active
เป้าหมาย : ผู้อื่น, มอนสเตอร์
การแสดงผล : เป่าคู่ต่อสู้ให้กระเด็นด้วยอาวุธ

Outrage (ผม่ยอม)
Active
เป้าหมาย : ผู้อื่น, มอนสเตอร์
การแสดงผล : ขัดขวางการโจมตีของผู้อื่น, มอนสเตอร์ แต่ต้องอึดนะ ไม่งั้นตาย

B-Wax (ขี้ผึ้ง)
Active
เป้าหมาย : ผู้อื่น, มอนสเตอร์
การแสดงผล : สาปให้เป็นหุ่นขี้ผึ้ง (จะแพ้ไฟมากๆ) ใช้ได้ดีกับ PvP, NvN

แย่หน่อยนะ สายกลางไม่มี Passive มีแต่หวังทำร้าย และ
ทำไมผมเปลี่ยนข้อมูลตัวเองไม่ได้ล่ะ
