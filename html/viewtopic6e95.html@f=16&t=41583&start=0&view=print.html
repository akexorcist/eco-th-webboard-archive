เวล 35*
เสื้อ - เมืองใต้
รองเท้า - เควสเปิดร้าน อัพทาวน์ จำไม่ได้ร้านไหน
กางเกง - ไม่ทราบ แต่หาซื้อยาก
หมวก - ทำเอง

เวล 45*
ทั้งชุด - เควสเปิดร้านชุดที่ อีสเตอร์เคป
(ลอง ค้นหา ดู ชุด 45 สาย BP)

เวล 55*
รู้สึกจาเป็นเควส ยาของท่านแม่มั้งคะ
อันนี้ไม่ทราบแน่ แต่เราซื้อเอาตาม โกเลมอะ

เวล 65*
ทั้งชุด- เควสฆ่า mini-doo เมืองเหนือ
(ค้นหา ชุดเวล 65)

ชุด 75*
ทั้งชุด - เควสฆ่ามอน 999 ตัว
รับกับมาดามที่ อัพทาวน์ (ชุดน่าร๊ากก ><*)

ถ้าข้อมูลผิดผลาด ขอโทษคะ เอามาจากประสปการณ์จริง
