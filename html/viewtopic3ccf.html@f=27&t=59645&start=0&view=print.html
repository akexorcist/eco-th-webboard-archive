(เอาเฉพาะโฟลเดอร์ eco ) (เหตุผล : ที่ร้านเกมส์นี้ ไม่มีเกมส์ eco

(แล้วไอตู้นั้น ก็ไม่ได้อัพเดตแพ็ทซาก้า7ด้วย พอโหลดมาก็โดน undo - - ขี้เกียจโหลดใหม่)

พอจะเข้าเกมส์ ปรากฏว่า เป็นดังภาพ...





มันไม่โหลดอะไรเลย ...

มีปัญหามากกว่าแร็คซะอีก (ก็อบแร็คมาจากบ้านมาเล่นยังเล่นได้ปกติเลย =w=)
