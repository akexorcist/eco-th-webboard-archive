ชายชุดนักเรียนหันไปมอง สาวในชุดกระโปรงบานสีฟ้า ด้วยใบหน้าที่หน้ากลัวมาก ราวกับยักษ์ที่กำลังโกรธ

"ไม่มีอะไรเลย ชั้นแค่อยากให้ ผู้หญิงคนนี้" ชายชุดนักเรียนชี้ไปทางเซเรน แล้วพูดต่อว่า "ชดใช้สิ่งที่ทำกับชั้นไว้ แค่นั้น"

"เฮ้ย" โซลเฟล เอ่ยด้วยสีหน้าตกใจ "ชั้นยังทำหน้าที่ไม่สำเร็จเลย" โซลเฟลเริ่มบ่น

"ก็ไม่ต้องทำแล้ว" ควอเร่เอ่ยขึ้น แล้วทั้งคู่ก็ถอนหายใจเฮือกใหญ่ เฮ้อ

New Character สินะ ขึ้น saga ใหม่มันต้อง New Character งั้นสินะ ...
พอดีกับ ที่จำไม่ได้แล้วว่า ตัวที่ใช้อยู่ 2 - 3 ตัวมันเป็นไงจำได้แค่แมวตัวเดียว
คือตอนนี้เวลามันผ่านไปนาน จนหอโดนปิด ซะงั้น == เอาเป็นว่าไอ้ที่ต่อไป อย่าคิดไรมาก

รอ ขึ้นกฏ ใหม่ แล้วค่อยมาต่อบ้าง เพราะคิด ตัวใหม่ได้พอดี

ดิท

พูดงั้นแต่มันก็อยากต่อสักนิดส์ 55

+ + + + +

หน้าหอเห่งความฝันมีเด็ก สวมเสื้อฮู้ดสีชมพูกับสีดำ กำลังเดินตรงไปที่หอสีขาว(ถ้าจำไม่ผิดน่ะ)
และเด็กที่สวมเสื้อสีดำก็ถอดฮู้ด ออก พร้อมเผยให้เห็น ผมทรงทวินเทล ผมสีดำ ดวงตาสีน้ำตาลอ่อน

"ที่นี้สินะที่ คุณพ่อ กับคุณแม่เคยมาพักอยู่น่ะ?" เด็กหญิงพูดขึ้นพร้อมหันไปถามแมวสีดำที่เดินตามมา แมวตัวนั้น ผงกหัว

"เฮ้อ กว่าจะถูกที่ พี่อ่ะ พาหลงไปตั้งหลายรอบ"เด็ก หญิงพุดพร้อมมองหน้าไปทางพี่ของตน

"อ่ะ คะ คือ ว่าแหม่ๆ มันก็ต้องมีผิดพลาดกันบ้างอ่ะ พี่ไม่ค่อยคุ้นทางเท่าไหร่นี้ ฮ่ะ ฮ่ะ" พี่ของเด็กหญิงพูดกลบเกลื่อน ออก

"แต่ไหนๆ ก็มาถึงแล้วนี้หน่า แต่ว่ามันดูโทรมๆ ไปนิดนึงว่าไหม ครับคุณ มิคาเอล" เด็กที่สวมฮู้ดสีชมพู(อ่านไม่ผิดหรอกน่ะ)หันไปถามแมวสีดำ ที่มีชื่อว่า "มิคาเอล" (นี้ตัวเก่าอ่ะน่ะแต่ไม่ค่อยมีบทเอามาเล่นซร้า)

"นั้นสิน่ะ แต่ก็มาถึงแล้วล่ะ น่ะ ที่นี้เป็นที่ที่ พ่อกับแของพวกเธอ เคยมาพักอยู่จริงๆนั้นแหละ หอแห่งความฝัน" แมวัวนั้นพูดออกมาโดยที่ดูเหมือนทั้งสองไม่ค่อย ตกใจอ่ะไรที่แมวมันพูดได้
