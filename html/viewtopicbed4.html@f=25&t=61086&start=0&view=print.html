White Wolf และสัตว์ที่เปลี่ยนร่างได้อื่น ๆ ถ้าจะฝึกแนะนำฝึกตอนก่อนเอาไปเปลี่ยนร่างครับ

เพราะอะไรงั้นเหรอ ... เพราะ

1. ค่าล้มเท่าเดิม คือ ก่อนเปลี่ยนล้ม 15 หลังเปลี่ยนก็ยัง 15 ไม่ได้รีเป็น 0 หรือ 1
2. ค่าที่บวกข้างหลังเท่าเดิม ... คือ ค่าที่บวกหลังจากล้มแล้วน่ะครับ อันนี้คงต้องอธิบายเพิ่ม

* สมมติ DEF 20+20 (หลังจากล้มครั้งที่ 15) แล้วเก็บจน DEF 20+40 แล้ว แต่ไม่ได้เอาไปล้ม แต่เอาไปเปลี่ยนเป็น A เลยจะกลายเป็น DEF 30+20 ไม่ใช่ DEF 30+40 นะครับ ^^" <<< ทดสอบมานานมากแล้ว แต่คิดว่าตอนนี้คงจะยังไม่เปลี่ยนไปจากเดิม

3. หลังจากเปลี่ยนเป็น A แล้ว ค่า + ข้างหลังจะเยอะกว่าเดิม ทำให้ล้มยากขึ้นกว่าเดิม

แล้วก็เท่าที่ทดสอบดู ถ้าไม่ได้จะเอาสัตว์ออกมาลุยกับพวกเก่ง ๆ จริง ๆ การล้ม 30 ครั้งแบบ Perfect มันแทบจะไม่จำเป็นเลยครับ เปลี่ยนเป็น A แล้วเก็บให้เต็มหมดทุกอันไม่ต้องล้มก็เก่งพอแล้วล่ะครับ (การล้มทำให้เก่ง + ถึกขึ้นอีกนิดนึง ... มันจะคุ้มค่ากับเวลามั้ยนั่น ==)
