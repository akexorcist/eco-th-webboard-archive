ซ่อมกางเกง น่าจะเป็นชุดซ่อมผ้า ไม่ก็ชุดซ่อมหนังน่ะครับ
หาไอเท็ม Clothes Repair Kit (ซ่อมผ้า) Coat Repair Kit(ซ่อมหนัง)
แต่ละชนิดจะมี สามแบบ แบบGold ,Silver, Copper แบบตามระดับของlv
ดูได้จากแถมข้อมูลของไอเท็มนั้นๆ

เมือถือไอเท็มซ่อมไว้ในตัว ก็ดับเบิ้ลคลิ๊กที่ชุดซ่อม กดซ่อมได้เลยครับ(กรณีนี้ต้องมีของที่เสียถืออยู่ในตัวและชุดซ่อมตรงชนิดกัน) ไม่ต้องมีสกินใดๆ ใครๆก็กดซ่อมได้

ที่ฝากดูอีกข้อคือค่าความทนทานของชุดซ่อมนั้นๆครับ
สูงสุดที่เคยทำได้ สำหรับผมคือ ทนทาน19ครับ บางครั้งทำออกมาได้ทนทาน8เอง

ทุกครั้งที่มีการกดซ่อมแต่ละครั้ง ค่าความทนทานสูงสุดของ ไอเท็มนั้นๆจะลดลง 1น่ะครับ

เช่นมีค่าทนทานสูงสุด 24 เราใช้ ชุดซ่อม ทนทาน19 ซ่อมแล้วก็จะเหลือเป็น
"ทนทาน19 ทนทานสูงสุด23"
แต่ถ้าเราใช้ชุดซ่อม ทนทาน10ซ่อม ก็จะเหลือเป็น
"ทนทาน10 ทนทานสูงสุด23"
กดสะสมกดบวกกันไม่ได้คับ

ชุดซ่อมที่มีค่าทนทานสูง ก็จะขายในราคาแพง เพราะฉะนั้นเลือกให้เหมาะสมน่ะครับ
ของยังไม่เสีย ใช้ไปให้จนเสียก่อนค่อยไปซ่อมถึงคุ้มครับ

*ของบางอย่างทิ้งไปดีกว่า ซ่อมมาก็ไม่คุ้ม
*ของบางอย่าง อีกเดี๋ยวเลเวลเราก็เกินแล้ว อย่าไปซ่อมเลยครับ
*ของที่มีค่าทนทานสูงสุด 1 ถ้าเสียอีกจะไม่สามารถซ่อมได้ ดูดีๆก่อนซื้อครับ
*ของเสียไปแล้วซ่อมไม่ได้แล้ว เรายังเอารูปมาโชว์ได้ครับ โดยไปหลอมกับของอย่างอื่น
