ในความคิดเรานะ ตีของหรือมอนที่มี def สูงๆ หรือตีข้ามเลเวลมากๆ เช่น กล่องเขียว มอนพวกหิน ผีดิบ ยิ่งค่าแดเมจที่เราทำได้น้อยๆ แล้วต้องโจมตีหลายๆครั้งถึงจะตาย อาวุธจะพังเร็วขึ้น แต่ลอง ใช้คำสั่งค้นหาดูอาจจะมีคำตอบที่ดีกว่าที่เราตอบก็ได้นะ

โดย ECO
จะเจออะไรก็ให้กด Delay Cancle แล้วตีดะเลยครับ ไม่ควรกดสกิลตีแรงๆ ใส่มอนนะ

เพราะค่าความทนทานจะมีโอกาสลดลง เกิดจากความถี่ที่เราโจมตีอ่ะครับ ยิ่งตีมาก + ตีโดนแบบถี่ๆ + มอนมี def สูงๆ โอกาสที่ความทนทานจะลดลงย่อมมีมากขึ้นไปด้วยครับ

ปล. เจอหิน เจอคอน ผมก็กด Delay Cancle อ่ะครับ แหะๆ
