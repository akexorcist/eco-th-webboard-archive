คืออยากจะรู้ว่ามันมันจะลดเดมเมจได้เท่าไหร่
สเตตัทค่า Def และ M.Def มันจะมีทั้งตัวหน้าและหลัง พอจะทราบมาคร่าวๆ ว่า
ตัวหน้าลดเดมเมจเป็น% ส่วนตัวหลังหักลบตามค่าที่แสดง
แล้วมันจะลดเดมเมจจากตัวหน้าหรือตัวหลังก่อน
สมมุติ อีกฝ่ายทำเดมเมจ 1000 จากเบลดแล้วกันโจมตีกายภาพ
ค่าสเตตัทเรา Def 50 หลัง 100
M.Def 50 หลัง 100
ขอบคุณล่วงหน้า แหะๆ

ระบบมันก็เหมือน ro นิ

หักลบ % ก่อน ค่อยมาหักลบ แบบโดยตรง

"อีกฝ่ายทำเดมเมจ 1000 จากเบลดแล้วกันโจมตีกายภาพ
ค่าสเตตัทเรา Def 50 หลัง 100 "

1000 / 50 = เหลือ 500 ลบอีก 100 เท่ากับเราจะโดน 400

แต่ไม่รู้ว่าเกมนี้จำกัดค่า def หน้าด้วยรึเปล่า

เพราะเคยทำ 100 - 130 มาแล้ว (วิทเต็ม + แปลงร่างมาริหุ่น + บัฟดิน ) โดนมอนอัด 1 สกิล 1 (แต่มอนตัวนี้ อัดแค่ 100-200 สกิล สูงสุด 500 )

เวทก็คิดแบบเดียวกัน ...

สรุป ตัวหน้า หักลบแบบ % ส่วนตัวหลัก หักลบตรงๆ โดยคิดตัวหน้าก่อนแล้วค่อยคิดตัวหลัง งงไหมนั่น
