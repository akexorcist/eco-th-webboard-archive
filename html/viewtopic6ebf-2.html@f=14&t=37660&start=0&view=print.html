บอสนี้ ตอนนี้ก็ดัน80 ก็ไม่ได้เก่งมากนะ แต่มันdefเยอะเลยตีโดนน้อน เอาแอสตี สาดพิษด้วย 3-5นาทีก็ตาย มิสไซมันก็แรงนิดหน่อย ร่างสะท้อนของมัน3ตัวถ้าไม่ไปยุ่งมันก็ไม่ระเบิด

คอน2ของดีที่ได้ก็ พลาสเตอร์แปะเข่า แผ่านเสียง มีอีกนะ แต่จำไม่ด้ มันนานแล้ว
อยากได้พิณ80มากก่า
