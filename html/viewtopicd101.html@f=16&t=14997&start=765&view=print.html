ต่อมาก็ยัดธาตุที่มันแพ้ลงไป
เสร็จแล้วก็วางพื้นธาตุที่มันแพ้ลงไปอีก เพื่อ "เพิ่มความเป็นธาตุในตัวของมัน" ให้สูงขึ้นอีก
