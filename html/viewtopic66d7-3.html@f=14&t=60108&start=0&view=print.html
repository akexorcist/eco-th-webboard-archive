เห็นด้วยเช่นกัน เคยมีสายเวทย์มาถามแล้วไม่ตอบ เขาว่าไม่เห็นจะลับตรงไหน

(ก็เงี้ยละ ไม่ใช่ไฟท์เตอร์ไม่เข้าใจเราหรอก)

ส่วนแอสผมว่าใช้อาวุธปาสเตตัสจะสามารถยืดหยุนได้ดีกว่า

เพราะเมื่อถืออาวุธปาแล้วความแม่นของสกิล 50 จะอยู่ที่ int (L.hit)

แล้วส่วนคนมากจะไม่มี L.avoid ถึงจะเป็นแอสอัพ agi 100 ถ้าไม่ได้อัพ int

L.avoid ก็ไม่เกิน 200 (นอกจากจากกันเนอร์ที่มีทั้ง agi และ int เลยแพ้ทางอย่างมาก)

อัพแค่นิดหน่อยก็ทุบโดนแล้ว พอยท์ที่เหลือสามารถเอาไปอัพ vit เล่นพิษควบไปด้วยได้

อาชีพอื่นๆถึงจะมี int มากแค่ไหนถ้าไม่มี agi L.avoid ก็ไม่ได้มากตามไปด้วย

แต่ถ้าจะอัพให้ int ให้ทุบกันเนอร์โดนด้วยก็ไม่ต่างกับการอัพ dex ของสายมีด
