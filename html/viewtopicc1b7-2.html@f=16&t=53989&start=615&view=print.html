ก็ท่าเสกไพ่ไงครับ แต่ต้องมีไพ่ด้วย ซื้อที่ แกรมเบอร์ มาสเตอร์

JobLv. 42 Alcana Card
Max LV: 5
Equipment : No
เป้าหมาย : พื้น
ระยะ : 5
Active
Summon Alcana Series ออกมาโดยการสุ่มจำเป็นต้องใช้ไอเทม [Alcana Card] ด้วย

- ร่าย 1 วินาที / ดีเลย์ 0.5 วินาที / ที่ skill Lv.5 ใช้ MP 20 - SP 20
- ถ้าซัมม่อนไพ่ที่เรียกออกมาไม่พบเป้าหมาย ก็จะเดินไปเดินมา ซักพักก็จะหายไป
- ถ้าเกิดไป ซัมม่อนไพ่หัวใจไปโจมตีใส่ Refection พวกซัมม่อนไพ่แจ๊กที่อยู่รอบๆ จะหายไป

หัวใจ : วิ่งต่อยประมาณ 3 หมัด (ATK460-580)
แจ๊ค: เอาหอกไล่เสียบประมาณ 5 ที (ATK1002-1122) *แรงกว่าเบลดเวล 80 อีก
ควีน : ฮีลให้เจ้าของประมาณ 600
คิง: กระทืบพื้นเป็นวงกว้างประมาณ 11x11 ช่องได้ 2 ที ( ติดสตั้น และ คอนฟิวชั่น ) * ทั้งหน้าจอ
