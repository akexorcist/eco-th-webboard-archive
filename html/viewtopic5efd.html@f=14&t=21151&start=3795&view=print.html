ปล. คุณ NaTee ในซิกของ ทั่น นั่นมัน มังกะเรื่องอาไรอ่า ลายเส้นถูกใจ อยากหามาอ่านบ้าง

ถ้าให้ดี pm link มาก็จะดีไม่น้อย อิอิ ขอบคุณคับ


สายmag ไม่เหมาะสมในการเก็บเวลนักเท่าไหร่อ่าฮะ

ในการตีมอนกว่าจะตาย ตัวนึง มันสิ้นเปลืองmp จำนวนมาก ยิ่งปรับแพทใหม่
แรนด้อมฮิล ไม่ค่อยติด mp ยิงไป3-4ตัว mp ก็รีไม่ทันแล้ว
(เวทไนท์ ร่ายไว ไร้ดีเลย์ ยิงได้ต่อเนื่อง เผาผลาน mp ดีนักแล ยิ่งมีเซนด้วยนะ กด 10 ทีเอมพีหมดถัง)

ดังนั้นสายนี้จึงเหมาะกับพวก ไปตีรันฟันแทงหัวชาวบ้าน
เป็นสายที่ค่อนข้าง ประหยัด สเต เพราะ เน้นหลักๆ แค่ vit กับ mag
ค่ารอง ก็มี dex (สำหรับ คนที่ต้องการ ความเร็วในการร่ายสำหรับสกิลอื่นๆ การกดยาชุป และ อัตราบล๊อคโล่ dex ราวๆ 80 นี่ บล๊อคกระจายนะ เคยโดนแรนมา บล๊อคได้3-4 ดอก ต่อแรนชุดนึง )
หรือ int ( สำหรับคนที่เน้นป้องกันเวท กันสาป และในแพทน่า ช่วยกัน อีว่า ด้วยนะ )
