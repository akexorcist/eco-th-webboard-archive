แวะมาเสริม คอมเม้น

สกิลพิษ 2 ที่เพิ่ม Def สายที่น่าอัพก็มีแต่สายพิษ นั่นล่ะ สายอื่นๆ ช่างมันเถอะ

สกิลปาเข็มพิษ น่าใช้สำหรับสายพิษ เพราะสกิลพ้อยจะเหลืออยู่พอตัว (สายปา+ปืนก็พอไหว แต่สายพิษอัพเอาป่วน)

ส่วนสกิลที่น่าสนใจสำหรับสาย สนับ

ลดจำนวน ลงหน่อยก็ดี เพราะว่าสนับต้องอัพ Claw Strike 3 ซึ่งกินพ้อยไปเยอะเลยทีเดียว

พิษ 3 ถึงแม้ว่าจะเพิ่มโจมตี แต่ก็อยู่ไม่นานนัก แถมมีโอกาศ เพิ่มพลัง วาย แล้วตบเบา (ฆ่าไม่ลงค่อยๆคั่ว)

ไม่ค่อยน่าอัพเท่าไหร่นัก

ถ้าจะให้พูดก้คือ แต่ละสาย มีบทบาทต่างกันพอควร

สนับ : เวล เวล เวล !!!!!

มีด : สายมาตรฐาน ทำอะไรได้หลายอย่าง มีการพลิกแพลงพอควร

พิษ : เกิดมา ล่า !! (และ ลาก) ทั้งคนทั้งบอส สกิลป่วนมีมากหลาย (เนื่องจากไม่ต้องอัพสกิลโจมตีมากมาย)

ผสม : เพื่อการเอาตัวรอด ไปไหนมาไหนง่าย (มั้ง) แต่เล่นแล้วเบื่อยากง่ายแล้วแต่คน (ของเล่นเยอะ + ไม่โดดเด่น)

ปา : สายกำหลาบ เบลด ค่อนข้างเหมือนสายมีด แต่มีความสามารถในการล่าดีกว่า แต่ก็แลกกับเก็บเลเวลยากกว่า

ไม่ค่อยมีเวลาแหะ จี้ตรงจุดมะไหว
