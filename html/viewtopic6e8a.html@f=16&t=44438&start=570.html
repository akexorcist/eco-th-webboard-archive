SeaFaryMoji เขียน:มีคำถามสำหรับเอกพอเรอร์มืออาชีพทุกท่านหน่อยนะคะ
พอดีหนูเพิ่งหัดเล่น เรนเจอร์ค่ะอยากทราบว่า

1.ถ้าหนูไม่อยากเปลี่ยนเป็น Treasure Hunter หนูจะใช้อะไรดีคะ ระหว่าง มีด กะฆ้อน

น่าจะใช้ค้อนถ้าไม่มี scout สิง กด skill short sword delay cancle ให้ แต่แนะนำว่าควรจะเล่นเป็นTh สักระยะหนึง เพราะ Th มีสกิลโจมตีอย่างอื่น (whip rush ,Whip Flourish , Sonic whip ) กับสกิลที่จะช่วยในการหากล่อง เปิดกล่อง (Code Break ,Unlock Mastery) หลบเวทย์ (Lucky) สกิลเพิ่ม def ชั่วคราว ( Caution ) และราคาแส้ ค่อนข้างจะถูกกว่าค้อน ถ้าไม่อยากเล่นจริงๆ อย่างน้อยก็น่า ็เอาสกิลเปิดกล่องเขียว( Code Break ) มาก่อน คิดว่าถ้าลงดันยังไงก็ต้องได้ใช้แน่ๆ

2.แล้วอยากถามว่า สกิลโจมตีของเอกพอเรอร์ (ไม่นับTreasure Hunterนะคะ)มันมีอะไรอีกบ้างคะ (ใช้แต่ B.Blow เศร้าT^T)

คิดว่าไม่มีแล้วนะ สกิลที่จะใช้โจมตีเป็นสกิลหลัก

3.เอกพอเรอร์สายเอจิ ดีมั้ยอ่าคะ แล้วเทียบกะสายวิทแล้ว อันไหนเก็บเวลง่ายกว่ากันคะ


ส่วนตัว ถ้าเล่นคนเดียวคิดว่าสาย Str vit เพราะจะตายค่อนข้างยาก ทุบแรงพอสมควร และเพราะสกิล B.Blow ร่ายค่อนข้างจะเร็ว agi ไม่ค่อยมีผลเท่าไหร่ ยกเว้นอยากจะเล่นเป็น Th กับมี scout สิง


4.ควรเลี้ยงหมามั้ยอ่าคะ -..-

ข้อนี้แล้วแต่คน เพราะเวลาเก็บเลเวลจริงก็ไม่ได้ใช้มากเท่าไหร่ แต่ถ้าอยากเลี้ยงจะเลี้ยงก็ได้ เพราะ ex มีสกิลเกี่ยวกับสัตว์เลี้ยงค่อนข้างเยอะ แต่กว่าจะฝึกให้เก่งได้ก็ใช้เวลานานเหมือนกันนะ

5.สกิลกับดัก ดีมั้ยอ่าคะ ถ้าดีสกิลไหนน่าสนใจบ้างอ่าคะ


สกิลกับดักค่อนข้างจะใช้งานยาก ยิ่งจะใช้เป็นหลักด้วยแล้วยิ่งหาโอกาสใช้ยากเข้าไปอีก ที่ใช้อยู่ก็ กับดักเปลือกกล้วย (Slip Trap) ใช้ในการแยกบอสออกจากลูกน้อง

6.สถานที่เวล ของสายเอจิ ช่วยแนะนำ ช่วงบั้นปลายชีวิตหน่อยนะคะ(LV 80+)


ข้อนี้เราคงแนะนำอะไรไม่ได้ เพราะตอนนี้ถ้าไม่่ส่งเควสก็อยู่ดัน 70 ที่เกาะใหม่ กับ maimai มอนแข็งแกร่งเกินไปที่จะไปคนเดียวแล้ว

7.สุดท้ายละค่ะ ถามว่าจำเป็นมั้ยที่เราต้องเล่น เอกพอเรอร์ถึงจ็อบ 50
ข้อนี้ตอบไม่ได้ ขึ้นอยู่กับว่าอยากจะเอาไปกี่สกิลตอนเล่น Th แต่สกิลมีถึงเลเวล 44 เท่านั้น


ขอรบกวนแค่นี้หน่อยนะคะ พอดีเพิ่งหัดเล่นสายBPค่ะ รู้ซึ้งเลยว่าเก็บเวลยากมาก
แต่รู้สึกสนุกกะมันมากเลยค่ะ ^____^

ตอบในฐานะเล่นเอ็กโพรเรอร์(EX)อาชีพ(ไม่ใช่THอาชีพนะ)
1.แนะนำว่าให้เปลี่ยนเป็นTHก่อนครับแล้วเล่นสักจอป20เพื่อโอนสกิล เปิดคอนกับunlockครับ
แล้วค่อยกลับมาเป็นEXเพราะสองสกิลนี้จำเป็น
ส่วนอาวุธก็เลือกเอาครับมีสามแบบ ค้อน+โล่ ค้อนสองมือ มีด+โล่ ถ้าเน้นโบลวให้เลือกอาวุธ
ประเภทค้อนครับ ถ้าเน้นฟันก็ใช้อาวุธมีด
2.ไม่มีครับ สายEXนั้นไม่มีสกิลโจมตีดีๆเลยส่วนมากจะเป็นสกิลสนับสนุนมากกว่า
3.ช่วงแรกวิทจะดีกว่าครับแต่พอช่วงหลังจะพอๆกัน สายวิทดีตรงเลือดเยอะตัวหนาแต่ฟันช้า
ส่วนสายเอจิหลบเก่ง โจมตีเร็วแต่เลือดน้อยป้องกันน้อย ขึ้นอยู่กับว่าชอบสไตล์ไหน
4.เลี้ยงก็ดีครับ ถ้าจะใช้ให้ได้ประโยช์นคุ้มสุดนั้นต้องเอาไปฝึกจนเต็มเกือบหมดทุกค่า
ถึงจะเหมาะใช้ลุยด้วยครับโดยเฉพาะค่าMAX HP แต่ช่วงหลังเวล70ขึ้นไปหมาจะช่วยไม่
ค่อยได้เพราะศัตรูค่อนข้างโหดและเปลืองค่ายาฟื้นพลังหมาพอควร
5.Barbed TrapกับBungestacครับแต่ไม่ใช่สกิลดีเท่าไหร่เพราะต้องใช้traptool1อัน
ต่อการใช้1ครั้ง พลังโจมตีไม่มากเหมาะเอาไว้หยุดฝ่ายตรงข้ามแล้วโจมตีมากกว่า
6.ช่วง80+แนะนำให้ไปเกาะมัยมัยตีนก เสือ แมงมุมเพื่อหาของเควสครับ ได้ทั้งของเควส
ได้ทั้งEXPคุ้มดีและตีได้เรื่อยๆด้วย
7.ไม่จำเป็นครับ สกิลส่วนมากเป็นสกิลสนับสนุนเลยไม่ต้องเร่งเก็บเพราะถึงเร่งเก็บก็ไม่มี
