ถ้ารักจะเล่นสายสาป
ลดvit กับagiดีกว่ามั้งครับ ดูเหมือนจะเยอะเกินไป
Kabalist vitรวม40 ใส่ของ+hpบ้าง HPก็ประมาณ 2200+ แล้วครับ แต่ถ้าเป็นNecroคงไม่ถึง
ตัวไม่บางมากอย่างที่คิดหรอกครับ ยังมีดีตรงมีLife Takeอยู่
agiเอาให้ได้รวม 90 ก็คิดว่ามากพอแล้วครับ สำหรับlv.99 อยากได้มากกว่านั้นรออัพหลังจากนี้ดีกว่า
int 50 อัพpassive All Rate Up ใช้สาปน้ำแข็ง/หินlv.3กับMonsterก็ติดบ่อยพอสมควร lv.5ติดบ่อยมาก

Kabalistสายstrมีปัญหาเรื่องstatusไม่ค่อยสมดุลอยู่แล้วครับ ได้อย่างเสียอย่าง

แต่ถ้าเน้นเล่นแบบสับสดๆ หรือAssassinสิงกดDelay Cancel ก็เน้นagiมากๆเข้าไว้ก็ได้ครับ แล้วตัดสายสาปทิ้งไป เพียงแต่ถ้าเป็นKabalist bonus agiจะต่ำมาก ถ้าอยากได้agi108 ก็ต้องอัพagi100อย่างเลี่ยงไม่ได้
pointส่วนต่างระหว่าง agi 90 / 99 / 108 ต่างกันมหาศาล เอาpointไปเสริมdex vit intน่าจะมีประโยชน์กว่าเยอะเลย
