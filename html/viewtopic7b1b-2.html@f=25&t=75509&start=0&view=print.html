TIP:สู้บอส สบ๊าย สบาย(สำหรับคนเวลน้อย)
วิธีนี้เราใช้ทำเนโกะมาตัวแล้วตัวเล่าค่ะ มีวิธีดังนี้
สิ่งที่ต้องการ
1.สัตว์เลี้ยงสุดโหด 1 ตัว(เผื่อไว้อีกก็ได้เผื่อตัวเเรกม่อง)
2.เข็มกลัดบรีเดอร์ หรือมีสกิลสั่ง Go! ก็พอ
3.อาหารสัตว์ไว้ปั๊มเลือดสัตว์เลี้ยงรึกองไฟบรีเดอร์ก็ได้แต่ส่วนมากจะไม่ทัน
4.เสริมความถึกตัวละคร ด้วยยา+มาริโอเน็ต (เผื่อมันมาตบเรา)
*ทำใจไว้อย่างหากสัตว์เลี้ยงโดนตบตาย*0*
วิธีการ
1.เราเข้าไปเปิดก่อนหรือให้สัตว์เปิดก่อนก็ได้ แต่เราต้องตีให้โดนอย่างน้อย1ที ถ้าไม่แน่ใจเอาซัก2-3ทีหรือ4-5ที
2.จะหลบฉากกลับมาแบ็กอัพสัตว์เลี้ยงหรืออยู่สู้ก็ได้(แต่ถ้าเห็นท่าไม่ดีก็หลบเหอะ)
3.รอจนสัตว์เลี้ยงฆ่าบอสตาย(ระหว่างนั้นก็ดูเลือดกันดีๆน่อ)
4.เสร็จแล้วไง ทำไรก็ไปทำดิ
