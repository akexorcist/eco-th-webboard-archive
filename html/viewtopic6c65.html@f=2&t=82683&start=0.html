เข้าไปที่ Control Panel แล้วเลือกไปที่เซ็ทภาษานะ จะขึ้นหน้าจอมา ให้เราเลือก Add ภาษาญี่ปุ่น โดยให้เราติ๊กที่ Microsoft IME ตามรูป ถ้าเราไม่เข้าไปติ๊กจะพิมพ์ภาษาญี่ปุ่นไม่ได้

อ่านอ่าน>>>>>>>ข้อควรปฏิบัติ<<<<<<<อ่านอ่าน

1.เล่น server JP แล้วอย่าคิดว่าเหมือน server ในไทย เพราะเขามีสังคมและมารยาทที่ไม่เหมือนเรา
ควรเคารพและรักษามารยาทแล้วควรรู้จักในกลุ่มของคนไทยที่เล่น ใน Server JP จะดีที่สุด
นอกจากจะรู้จักกับเพื่อนใน JP ก็ว่าไปอย่าง

2.ไม่สร้างความเดือดร้อนให้กับคนใน sv ไม่ว่าจะไทยหรือญี่ปุ่นก็ตาม เช่น ขอของ ขอเงิน
เพราะเขาอาจนำเราไปประจานในทางที่เสียหายหลายอย่าง และอาจถูกแบน แม้กระทั่ง VPN

3.ไม่ควรพิมพ์เป็นภาษาอังกฤษ - ไทย ในที่สาธารณะ ถ้าจะคุยกันควรซิปหากันดีกว่า
อย่าลืมว่าเขาบล๊อค IP ในไทย เดี๋ยวจะมีเรื่องเดือดร้อนตามมาทีหลัง

4.ในการเก็บเลเวลมอนสเตอร์ ไม่ควรลาก เทรน แจม ควรเก็บเลเวลอย่างมีมารยาท
แม้จะยากก็ต้องอดทน

5.ไม่ใช้สกิลที่ก่อความวุ่นวายภายในเมือง

6.อย่าเห็นแก่ตัวดึงของเพิ่มเลือดเพิ่มเอสพีในโอดีวอร์ที่ขายอันละ1gไว้คนเดียว(หยิบเท่าที่จะใช้วออย่าเห็นแก่ตัวเหมาหมด)

ของคุณที่พึ่งลงใหม่จะยังไม่มีห้องให้เห็น ให้ทำตามขั้นตอนนี้ก่อน

1. กด Groups ที่อยู่ข้างบน
2. กด Join a Group
3. ในช่องว่าง ใส่ "eco-th"

เรียบร้อย แค่นี้คุณก็โผล่ในห้องแล้ว



- วิธีแชทหน้าหลัก ให้ดับเบิลคลิกที่รูปเลเนตจัง (eco-th ข้างบน) จะโผล่หน้าต่างคุยขึ้นมา
- เวลาจะซิบหาใครให้ดับเบิลคลิกที่ชื่อในลิสท์ข้างล่างครับ จากรูปตัวอย่างตอนนี้ก็มีอยู่ 3 คน



วิธีโพสรูป ที่หน้าต่างแชทให้กด photo จะมีปุ่ม capture photo กดเข้าไป จะมีให้เลือกว่า
- Capture อันนี้คือใช้กล้อง cam ถ่ายสดๆเลยครับ
- Load file ไว้โหลดรูปสกุล jpg bmp gif ฯลฯ จากเครื่องมาโพส
- Paste ไว้โหลดรุปที่คุณพึ่งกด printscreen หรือ copy มาหมาดๆเมื่อครู่ครับ
- Send กดเพื่อส่งรูปที่คนจะโพสลงห้องแชทครับ

*ข้อแนะนำเรื่องการโพสรูป เพื่อไม่ให้คนอื่นโหลดรูปอืดดึงเนตช้า ผมแนะนำให้เอารูปที่คุณ printscreen มาไปตัดก่อน
เช่น คุณติดตรงสมัครไม่ได้เพราะกรอกอะไรบางอย่างผิด ก็ printscreen จากนั้นเปิดโปรแกรม paint ไปตัดมาเฉพาะ
ส่วนที่เป็นสีแดงว่าคุณกรอกผิด จากนั้น copy มาวางโพสในห้องแชท เป็นต้น
