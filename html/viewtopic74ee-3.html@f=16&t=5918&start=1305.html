รัก MAC จริง ต้องอดทน!!!

อย่างว่าละครับ กว่าจะเก่งหมดตัวก่อนพอดี อย่างผมก็หมดไปประมาณ 4-5 M ละครับ
หุ่นยังไม่ถึง 50 % เลย ทั้งๆที่คาดว่า ได้สกิล 30 มาแล้ว จะเก็บเวลได้ไวขึ้น (ซึ่งมันไม่ช่วยอะไรตูเลย)
แต่สกิลหากันก็ยังมีอยู่นะครับ มามองในข้อดีของ MAC แล้ว หุ่นมี def ที่เยอะมาก ถึงแม้ว่ายังไม่มีใคร
ออกมายืนยันเรื่อง เลเวลของม่อนกับค่า def ของหุ่นก็ตาม อีกเรื่องนึงที่น่าจะเป็ข้อได้เปรียบมากที่สุดเท่าที่ผมทดสอบมาก็คือ
HP ครับ 2000+1500 เป็น 3500 ถ้าอัพสกิล HP UP ของหุ่นก็ + ไปอีก 22% (770)= 4200 เชียวนะครับ
ต่อให้ไม่อัพ def ทราน ก็ยังตั้ง 2440 แน่ะ ก็ถือว่าค่อนข้างเยอะ แล้วยังมีสกิลช่วยอีก 1 สกิลสำคัญ นั่นก็คือ สกิล Maintenance
ที่เด้งเลือด ซึ่งมีเอี่ยวกับสกิล HP recovery ของผู้ขับหุ่นด้วย

ตามความเห็นของผม ในซาก้านี้ MAC ก็ไม่ได้ห่วยซะทีเดียวนะครับ (พยายมมองโลกในแง่ดี) เพราะงั้น
