เริ่มจากต้องเข้าอัพทาวน์ให้ได้ก่อน วิธีหาดูเอาเอง
จากนั้นที่เปลี่ยนอาชีพทั้งหมด ยกเว้น วารอค กับวาเทส จะอยู่ตึกใหญ่ทางด้านเหนือของอัพทาวน์ ที่มีธงปักหน้าตึกเยอะๆ ชั้น 1-4 เลือกเอาเองว่าจะเป็นอาชีพอะรัย ก้อเข้าไปคุยซะ
