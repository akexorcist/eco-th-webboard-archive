:oops: ต้องใช้ Circuit แบบต่างๆ ในการอัพค่ะ

มี 6 ชนิด ดังนี้

:!: Power Circuit = Memmory + CPU + Power Transister
พลังโจมตี +2
ความแม่นยำในการโจมตีระยะใกล้และไกล +1

:!: Defence Circuit = Memmory + CPU + Defence Transister
พลังป้องกัน +2
อัตราการหลบหลีกระยะใกล้และไกล +1
HP +2

:!: Magic Circuit = Memmory + CPU + Magic Transister
พลังโจมตีด้วยเวทมนต์ +2
ความแม่นยำของ
ความแม่นยำของเวทมนตร์ +2

:!: Magic Defence Circuit = Memmory + CPU + Magic Defence Transister
พลังป้องกันเวทมนต์ +2
Magic Resistant +2

:!: Critical Circuit = Memmory + CPU + Critical Transister
Critical +2
การหลบหลีก คริติคอล +2

:!: Founded Circuit = Memmory + CPU + Restore Transister
พลังการฟื้นฟู +2
พลังการฟื้นฟูเวทมนต์ +2
