ศัตรูที่เป็นรูปร่างคนที่ sketch ได้มีไม่มากครับ

หลักๆก็ 3 สาว Tita Masha Ruruie ที่มาจากกล่องมอนเท่านั้น กดติดออกมาก็วาดได้ตามสะดวกจนกว่าเราจะพอใจน่ะแหละ

ที่เหลือคือตัวดังต่อไปนี้ ซึ่งได้จาก event เท่านั้น หาจากที่อื่นไม่ได้แล้ว
1. Nekomata(Sora) ร่างคน ตัวนี้ต้องทำเควสแมวโซระ แล้วพอถึงตอนที่ต้องสู้กับมันก็วาดไปเลย พกบอร์ดวาดไปเยอะๆด้วยละกัน

2.Arc ตัวนี้เป็นตัวชายเผ่าไททาเนีย ใส่ชุดบรีดเดอร์สีเขียว เราจะได้สู้ักับมันตอนทำเควสมังกรดำ แน่นอนว่าวาดได้สบาย แต่เนื่องจากเควสมันโหดเอาเรื่อง ถ้ามัวแต่วาดอาจจะถูกหมามันกัดตายก็ได้นะ

3. อันนี้ไม่ใช่คนซักเท่าไร แต่เป็นสาวงูแบบพิเศษ สู้ได้ตอนทำเควสแมวแฝด แน่นอนว่าวาดได้เช่นกัน ตัวมันก็ลวดลายเด่นไม่เหมือนใครดี ก็น่าวาดเก็บๆไว้นะ

4. หุ่นปืนใหญ่ตัวเป้ง ใหญ่กว่าหุ่นทั้งหมดที่เป็นรุ่นเดียวกัน มันจะอยู่ในเควสแมวม่วง สุมิเระ ที่ต้องสู้กับหุ่นตอนไปคุยกับเด็ก แน่นอนว่าวาดได้

5. เงือกใน Waterlayer วาดได้ตอนเราโดนจับขังคุก

ทางผมเองก็ถึงกับทำ sage ไว้วาดพวกนี้โดยเฉพาะเลยล่ะ (ทำเควสไว้แบบค้างคาไม่ให้มันจบ จะได้เข้าไปวาดได้เรื่อยๆ)
