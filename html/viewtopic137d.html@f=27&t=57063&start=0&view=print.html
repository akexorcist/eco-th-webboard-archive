วิธีการลงSkin
Skin ที่ได้โหลดไปนั้น เมื่อแตกไฟล์ Rar ออกมาจะได้เป็น โฟลเดอร์ที่ข้างในมีรูป Skin นะครับ
ให้ Copy นำไปวางในโฟลเดอร์ของตัวเกม
ECO\data\sprite\interface
ตามรูป

จิ้มเพื่อดูรูปที่นี่้เลย

และเข้าเกมมาปรับได้ตามรูป

จิ้มเพื่อดูรูปที่นี่้เลย

สำหรับคนที่ทำตามข้างบนแล้วไม่ได้ผล

ให้วางโฟลเดอร์ Skin ไว้ในโฟลเดอร์ดังข้างบน
แล้วสร้างโฟลเดอร์สำหรับเก็บ Skin ที่เราใช้ไว้ก่อน เผื่อเปลีั่ยนใจทีหลัง

จิ้มเพื่อดูรูปที่นี่้เลย

แล้วก็ Copy ไฟล์ไปเก็บไว้ในโฟลเดอร์ีท่พึ่งสร้างดังรูป (แนะนำอย่าตั้งชื่อตามรูป เด๋วสับสนเวลาเลือก Skin)

จิ้มเพื่อดูรูปที่นี่้เลย

แล้วจากนั้นให้ Copy ไฟล์ Skin ที่ต้องการลงมาวางทับ(วางทับไฟล์ของเก่านะไม่ใช่ที่เรา Copy เข้าโฟลเดอร์ที่สร้างใหม่นะ)

จิ้มเพื่อดูรูปที่นี่้เลย

ปิด-เปิดเกมใหม่แล้วลงดู

ถ้าไม่ได้ลองดูว่า Option ของเราได้เลือกสกิน Default ไว้หรือเปล่า
