- -* ระบบ มาริโอเนต รู้สึกว่า ไม่จำเป็นว่าต้องเป็นอาชีพ มาริโอเนตเท่าน้นนะคับ
และเมื่อแปลงร่างเป็น มาริโอเนต เองแล้วเราจะมีความสามารถแปลกๆ ขึ้นมาตาม
ร่างที่ตัวเองได้ทำการแปลงร่าง
***และที่ไม่ธรรมดา คือเราสามารถสั่งให้ Marionette เก็บของ,ตั้งร้านขายของ
หรือเก็บแร่เองได้ด้วยถึงแม้ว่าเราจะ Logout ออกจากเกมไปแล้วก็ตาม !! hock:

ปล. อ่านเพิ่มได้ที่นี้เด้อ http://ecoshino.balder.prohosting.com/tip5.htm


>>> หุ่นกระบอกของอาชีพ มาริโอเนต
ก็คือมาริโอเนตเป็ผู้เรียกออกมานะคับ (เรียกลูกน้องว่างั้น) และตัว มาริโอเน็ตเองก็สามารถ
แปลงร่างเป็น หุ่นกระบอกได้อีกทีนะคับ อันนี้แล้วแต่ว่า อยากแปลงกันรึเปล่า

>>> MP SP ต่างกันยังไงครับ
คือถ้าเราเพิ่มค่า Int จะส่งผลกับค่า Sp
แต่ถ้าเราเพิ่มค่า Mag จะส่งผลกันค่า MP
** น่าจะมีผลกับพลังโจมตีเวทย์มนต์เหมือนกัน ต่างกันตรงท้ายแหละคับ
(แต่ Int ดูจะส่งผลกับการ โจมตี-หลบ ระยะไกล และก็จำนวนของบรรทุกด้วย)


>>> ค่า MAG กับ Dark Stalker
อันนี้ไม่ทราบแน่ชัด แต่ดูเหมือนว่าค่านี้จะมีผลกับ Dark Stalker มากว่าค่า int :roll:
