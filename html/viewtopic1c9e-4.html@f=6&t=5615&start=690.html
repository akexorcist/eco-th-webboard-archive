จะอธิบายเกมก่อนนะจ๊ะ
ต้องบอกก่อนว่า เกมนี้สามารถ Reskill และ Restatus ได้หลายรอบค่ะ (รอบแรกฟรี~~)
ซึ่งจุดนี้ทำให้เราสามารถเปลี่ยนแปลงการเล่นของเราได้เรื่อยๆค่ะ ^0^

อย่างที่ทุกคนรู้ จากFarmerก้อจะเปนAlchemist จาก Alchemistไปswitchจ๊อบเปนMarionetteได้อีกที ซึ่งอาชีพพวกนี้ บางทีstatusอาจพลิกแพลงและเปลี่ยนไปบ้างตามskillของอาชีพนั้น
เช่น Farmerส่วนมากจะเล่นสายบู๊เพื่อที่จะเกบเลเวล Alchemistก้อเหมือนกัน แต่พอเปนMarionette มันจะมีสกิลเรียกMarionette (คล้ายๆPet) ซึ่งตัวพวกนั้นจะโจมตีเปนเวท ความแรงของเวทนี้ จะขึ้นอยู่กับค่าMAGของตัวผู้เล่น ซึ่งถ้าเราจะเล่นสายนี้ จากFarmerสายบู๊เราก้อต้องไปรีให้เปนสายเวทค่ะ

ตามปรกติตอนที่เริ่มเล่นฟามเม่อนั้น ควรจะอัพ ไปทางสายบู๊ (หรือ STR AGI VIT) เพื่อที่เราจะได้เกบเลเวลง่ายๆ
ยกเว้นเรามีเพื่อนดีให้ดูดจ๊วบ >o< เราจะอัพยังไงก้อได้ค่ะ จะอัพMAGเตรียมไว้เพื่อเล่นมารีโอเนสเลยก้อได้นะคะ

แต่ต้องบอกก่อนว่า โอเพ่นของเซิฟไทย อาชีพMarionette หรือ technical job ยังไม่เข้า เพราะฉะนั้น ก้อเล่นAlchemistกานไปก่อน

ส่วนเรื่องskillนั้น... skillของฟามเม่อ คือskillที่เราจะสามารถเกบไว้ได้ ไม่ว่าจะเปลี่ยนเปนmarionette หรือ Alchemist
แต่ถ้าสมมุดตอนแรกเปนAlchemist แล้วตอนหลังอยากเปนMarionette สกิลของAlchemistจะหายไปหลังจากสวิชจ๊อบแล้วนะคะ จะเกบได้แค่5สกิลพ๊อยเท่านั้น แต่ถ้าอยากเกบสกิลเพิ่ม ก้อต้องใช้ไอทั่มนาฬิกาทราย (แพงมากมาย)

แนวทางการเล่นนะคะ (นี่เปนความเห็นส่วนตัวของเราน๊า)
ตอนเปนฟามเม่อก้อบู๊อย่างเดียวค่ะ (ตามที่เกรซได้โพสไปก่อนแล้ว)
ส่วนสกิลที่จำเปนมากๆก้อคือ
1. Cultivation ( ปลูกต้นไม้ ได้มาตอนเปลี่ยนอาชีพ ) max lv 1
2. Plant Knowledge ( ปราชญ์แห่งพืช ) max lv 1
3. Tree Knowledge ( ปราชญ์แห่งไม้ ) max lv 1
4. Cooking ( ทำอาหาร ) max lv 5
5. Item Refine ( แปรรูปวัตถุดิบ ) max lv 3
อย่างที่เกรซบอกไว้ สกิลพวกนี้จำเปนมากที่สุดค่ะ สกิลอื่นๆเช่นเต๊น เย็บผ้า ซ่อมเสื้อผ้า ทำธนูก้อสำคัญ แต่ส่วนนี้มันขึ้นอยุ่กะว่าเราชอบเล่นแบบไหน
แต่อีกสกิลนึงที่อยากเพิ่มเติมคือ Blow เอาไว้ใช้ในการเกบเลเวลค่ะ (ฟาดหัวพูรูรู อิอิ)

ส่วนAlchemistนี่สกิลที่สำคัญๆจะมีพวกผสมยา (ไว้ผสมยาชุบ ยาฮีล) เราคิดว่าสกิลนี่น่าสนใจที่สุดนะคะ
อื่นๆก้อจะมีพวกสกิลที่ช่วยให้ของดรอปมากขึ้น สกิลโจมตีหมุนรอบตัว(จำชื่อมะได้) หรือถ้าเราจะใช้Petต่อสู้(น้องแคร่อท) พอเปนAlchemistแล้วจะมีสกิลช่วยเหลือน้องแคร่อทค่ะ

Marionette ยังไม่ได้เล่นเลย (ตอนโคสพอดีว่าสกิลบั๊ก) แต่รู้คร่าวๆว่าสามารถเรียกตัวเท่ๆออกมาปล่อยเวทได้ค่ะ (ชุดผญก้อน่ารักอีกตะหาก) แหะๆ...

มันไม่มีสายเวท หรือ สาย บู๊ แยกไปเลยนะคะ มันแล้วแต่ว่าเราอยากจะเล่นสกิลแบบไหนมากกว่า (พลิกแพลงได้เยอะ)
