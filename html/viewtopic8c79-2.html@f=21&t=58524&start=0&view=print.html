"อ่อสิ"เขาตอบผมมา แต่มันเป็นเรื่องที่น่าแปลกเพราะว่าไฟล์นี่มีเฉพราะเครื่องที่ ผมและราฟาเอลนั่งเท่านั้น
จากนั้นผมก็ไม่คิดอะไรมากหันไปหาราฟาเอลแล้วตอบตกลงจากนั้นก็คลิกเข้าไฟล์
และมันเขียนว่า
'เราเตือนท่านแล้วว่าอย่าเข้ามา ความตายกำลังรอพวกแกอยู่ ประวัติของพวกแกทุกเก็บไว้ในนี้
หมดแล้ว ฮ่าๆๆๆๆ'
มันอะไรกันเนี่ย -_- มีทั้งภาพศพคนตาย มีทั้งตัวอักษรลับๆ
แต่ตอนนั้นผมก็ไม่ได้คิดอะไรหันไปบอกราฟาเอลว่า
"เลิกเหอะครูเขาสอนไปถึงโน้นแล้วเร็วครูมาแล้ว"
จากนั้นผมกับราฟาเอลก็ปิดไฟล์นั้น แต่ดูท่าราฟาเอลจะไม่ทันได้อ่านเพราะเครื่อง 32 ค่อนข้างช้า และตกลง
ไฟล์เมื่อกี้มันอะไรกันแน่นะสงสัยจัง....
