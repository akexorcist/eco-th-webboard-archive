- ชั้น 5F จะได้หน้ากากเสือ ( Tiger Mask ) +3Str
- ชั้น 10F จะได้หน้ากากหมาป่า ( Fox Mask ) ยังไม่เห็น
- ชั้น 15F จะได้หน้ากากโครงกระดูก ( Skeleton Mask ) ยังไม่เห็น

- ชั้น 30F จะได้หน้ากากมังกร ( Dragon Mask ) ยังไม่เห็น
- ชั้น 40F จะได้หน้ากากดำน้ำ ( Snockle ) กัน5 ไม่ค่อยดีหรอก

ของในเควสนี้ หน้ากากเสือ ดีสุดจ้า เหมาะสำหรับ ไฟเตอร์
