ส่วน MSN โค้ดนี้เกิดจากวันและเวลาไม่ถูกต้องครับ ส่วนใหญ่นะ
ให้ลองตั้งปฏิทินที่ด้านขวาล่างใหม่ ให้ตรงตามเวลาและวันที่ของเครื่อง ถ้าให้ดีเข้าไปปรับที่BIOS ด้วย โดยการกดปุ่ม delete ตอนเครื่องมันกำลังบูธ ถ้ามันบูธไวมาก พอเปิดเครื่องหรือรีเครื่องแล้วเครื่องมันดังปิ๊บปุ๊บก็กด delete รัวๆ เลยครับ*-*

เข้ามาหน้าแีรกจะเจอหน้าไบออสสีฟ้าท่าทางน่ากลัว ให้ตรวจสอบว่าเวลาและวันที่ถูกต้องหรือยัง ถ้าไม่ตรงกับปฏิทินก็จัดการแก้ไข จากนั้นออกจากไบออสโดย Save & exit ครับ
แล้วลองออนMSN ดู

ถ้ายังไม่ได้อีก
ให้คลิกที่ปุ่ม start > run จาก start menu ของเรา จากนั้นจะมีไดอะล็อบ็อกซ์ของคำสั่ง run ขึ้นมา ให้พิมพ์ regsvr32 softpub.dll แล้วกด OK
ลองออนMSN ดู

ถ้ายังไม่ได้อีก แก้กับIE (แต่คิดว่านาโอโกะจังใช้ไฟร์ฟ็อกซ์ อันนี้อาจไม่ใช่ก็ได้มั้ง? แต่ลองๆ ดู)
เปิดหน้าต่างของIE ขึ้นมา 1 หน้า คลิกที่เมนู Tools > Internet options > เลือกหัวข้อ connection > คลิกปุ่ม LAN setting > เอาติ๊กถูกตรงช่อง Use a proxy server for your LAN ออก
ลองออนดู

ถ้ายังไม่ได้อีก!?
ให้เอาMSN ออกจากเครื่องไปเลย เช็ควันที่และเวลาให้ถูกต้องใหม่ตามวิธีที่ 1 อีกครั้ง แล้วก็ลองลงMSN ใหม่ครับ

วิธีสุดท้ายเลยถ้า 4 วิธีบนหมดปัญญา ก็ให้เปลี่ยนเวอชั่นMSN ครับ ฮาๆ ลองใหม่กว่าเดิม 1 เวอชั่น ถ้าใหม่สุดอยู่แล้ว ลดลงมา 1 เวอชั่นครับ*-*
