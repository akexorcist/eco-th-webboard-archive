เกิดอารมณ์อยากตั้งกระทู้

คือ เพลงในเครื่องเล่นแผ่นเสียง

เวลากดเพลงๆนึง แล้วเอาเครื่องเล่นออก

มันยังเป็นเพลงเดิมอยู่ งงมากเห้ยได้ไง

ลองลงบ้านขึ้นไปใหม่ เหมือนเดิม เพลงที่เพิ่งกด

เก็บบ้านเอาออกมาใหม่ก้อเหมือนเดิม เพลงในเครื่องเล่นน่ะแหล่ะ

ออกเข้าใหม่ก็เหมือนเดิม เอาตัวอื่นมาขึ้นก้อแบบเดิม

แสดงว่ามันจะเป็นแบบจดจำ เหมือนสกิลของบาด

แล้วทำไมเอาเครื่องเล่นออก

และยังเป็นเพลงในเครื่องเล่น

อาจจะ

1.เฉพาะเครื่องของผม

2.จดจำแบบของบาด

แล้วทำไมเอาเครื่องเล่นออกมันไม่เปลี่ยนเป็นเพลงแรกเริ่มล่ะ บัค หรือเปล่า สงสัย

แต่ก้อดีได้ไม่มีมือคนอื่นมาเปลี่ยน

ปล.อย่าด่า เตือนได้ ถ้าไม่เหมาะสม แค่สงสัย ขอบคุณทุกคอมเม้นครับ
