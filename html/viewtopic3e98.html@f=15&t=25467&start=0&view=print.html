ตามที่ได้ลองมาจริงๆอ่ะคับ คือ มันก็ดี แต่จะเก่งช้ากว่าสายที่เน้น mag dex สองค่า

ตอนนั้นผมตัด mag ไว้ที่ 60 มั้ง แล้วกลับมาอัด dex ให้ได้ c.speed 400+


(400 ต้นๆมั้ง ไม่แน่ใจ) หลังจากนั้นยัด mag ต่อ จนมันหารลงตัว

int ผมไม่ได้ไปแตะเลย เพราะ mag มีผลมากกว่าในตอนต้นๆอ่ะคับ
(ตอนแรกเคยคิดว่าถ้าอัพไปคู่กันแล้วมันจะเก่งไว)

mag 39 ตามที่บอกนี่ยิงไฮดรายังไม่อยากจะตายเลย

ที่ผมคิดนะ
ตอนต้นๆไม่ต้องเน้นเร็วหรอกคับ เพราะได้ cw มาก็ร่ายเร็วอยู่แล้ว ( เพราะกว่าจะจ๊อบ 40 เรายังต้องหากินกับ cw ไปอีกนาน)
ส่วน int ตอนแรกที่อัพเพราะมันช่วยเพิ่ม min matk เลยอัพ แต่มันไม่ได้เพิ่มไวเหมือน mag (mag เพิ่มทั้งสองค่าเยย)
และก็ dex ที่ผมให้ความสำคัญเป็นอันดับสอง เพราะมันจะช่วยให้หายหงุดหงิดกับ cb ไปได้เยอะ ^^
