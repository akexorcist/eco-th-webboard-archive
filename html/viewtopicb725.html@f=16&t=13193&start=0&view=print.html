:-: Review [ BP's Characters ] :-:
    • บทความนี้จะเป็นการ แนะนำสายอาชีพใน BP ทั้งหมดครับ
    • ใน Job แรกของ BP นี้จะมีด้วยกัน 4 อาชีพเริ่มต้นครับ และจะเติบโตเป็น สาย Expert(Job2) ครับ
    • ในอนาคตเราจะสามารถเลือกที่จะ Switch ไปเล่นสาย Technical ได้อีกด้วยครับ
Backpacker คืออะไร มีดีอย่างไร?
    • Backpacker หรือ BP คือสายอาชีพที่เน้นการผลิตและรวมรวมครับ เพื่อให้เกิดความสมดุลในการเล่นเกมส์ ไม่ว่าจะเป็นเงิน หรือ Item ต่างๆครับ และสุดท้ายจะกลายเป็นสังคมขึ้นมาครับ
    • ดังนั้นจุดเด่นของอาชีพสาย BP ก็คือความสามารถในการหา Item, ผลิต Item และการแบกของที่แบกได้มากกว่าอาชีพสายอื่นๆครับ
    • อีกทั้งคงจะขาดไม่ได้สำหรับกระเป๋าหลัง กระเป๋าถือ ครับ
ข้อเสียของ BP ?
    • จุดแรกเลยครับ คือความสามารถในการต่อสู้ จะไม่สูงมากครับ
    • ความลำบากในการเล่นช่วงแรกๆครับ เอาการเลยทีเดียว > <
