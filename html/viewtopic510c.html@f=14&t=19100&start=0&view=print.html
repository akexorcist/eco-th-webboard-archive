ไม่ใช่ว่ามันออกแล้วนักเวทรุมกินโต๊ะมันไปแล้วหรือครับ?
เท่าที่สังเกตุดูแมพนั้นซินนามอนจะออกเป็นจุดๆทีละสามตัวครับ ข้างบังเกอร์ ด้านล่างของเนิน ตรงต้นไม้ แถวๆทางเข้า เดินวนๆแถวนี้เดี๋ยวมันก็ออกมาให้ยิงเองอะครับ




ที่สังเกตุอีกอย่าง เล่นตีสาม ซินนามอนออกไม่เยอะเท่า6โมงเย็นครับ

ไม่รู้ระบบมันปรับจำนวนการเกิดของมอนตามจำนวนผู้เล่นรึเปล่า?
