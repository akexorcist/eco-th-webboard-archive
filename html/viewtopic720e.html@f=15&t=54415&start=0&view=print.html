คือ . . .

ปลดคิดเป็น % การปลดนะ ไม่ได้อยู่ที่ int เลย

คาบาผมไม่อัพ int เลย แต่ปลดได้บ่อยมากถึงมากที่สุด

น้อยครั้งที่จะปลด 1-2 ครั้งไม่ออก แต่ครั้งที่ 3 ก็ออกทุกที


ส่วนสาปนี่ไม่แน่ใจเท่าไร เพราะอย่างที่บอก คาบาผมก็ไม่อัพ int เลย

แต่ก็ใช้สุ่มสาป สาปติดทุกครั้ง (5% ที่จะไม่ติด) หรือว่าฝ่ายตรงข้ามไม่มี int

เช่นกันก็ไม่รู้ ?? ยังไม่อาจพิสูจน์ได้ รอผู้รู้แจ้งมาคอนเฟิร์ม



ปล. เวล 59 ลง Dex กะ Int ไปขนาดนั้น แล้ว Mag ละท่าน ?? ไม่ใช่ว่าสาปไป 1-2 ครั้ง ปลดอีก 1-2 ครั้ง mp หมด จบกัน -*-
