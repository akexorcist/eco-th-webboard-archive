ฐานดิน



ปล. พื้นที่นอกบ้านไม่สามารถปลูกอะไรได้ทั้งสิ้น
- ถ้าเห็นที่บ้านคนอื่นเป็นต้นไม้ที่พบ+ตีได้ตามแม็บเช่นโซลทรี เห็ดยักษ์ => เป็นรูปปั้น
- ถ้าเห็นที่บ้านคนอื่นเป็นต้นไม้ที่ตีไม่ได้เช่นต้นไม้ใหญ่ ต้นซากุระ => ของแคช ของกิจกรรม
- ถ้าหมายถึงกระถางดอกไม้ต่างๆ => สกิลการ์เดนนิ่งของชาวนา
- พื้นดิน พื้นหญ้า => ก็สกิลการ์เดนนิ่งของชาวนา
- พื้นอื่นๆ => พื้นไม้ก็ช่างไม้ พื้นอิฐก็ช่างอิฐ พื้นอื่นก็คงต้องซื้อของแคช
