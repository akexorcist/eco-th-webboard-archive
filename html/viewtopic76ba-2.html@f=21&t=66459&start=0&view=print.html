ขอเชิญ เพื่อน ๆ ชาวโมจิ ส่งผลงานการประพันธ์บทร้อยกรอง ไว้ใน ลิ้งค์นี้ นะครับ

เพื่อสะดวกต่อ คณะกรรมการในการทำการคัดเลือกพิจารณา

ปล. ขอความร่วมมือให้ใช้เฉพาะ ส่งบทร้อยกรอง นะคับ
ขอความกรุณาอย่า คอมเม้นท์เล่น ขอบพระคุณมากครับ จากคณะผู้จัดกิจกรรม

ลงชื่อ ผู้แต่ง โดยใช้ ชื่อตัวละคร ใน Sv. โมจิ ห้ามลง ID นะคับ เพื่อความปลอดภัย
กรุณาลงชื่อ ตัวละคร ไว้ด้านล่าง บทกลอนที่ส่งด้วยนะคับ
กรณีการแอบอ้างไม่ต้องกลัวนะคับ สำหรับผู้ที่ได้รับรางวัล ขอเชิญท่าน มาช่วยลงชื่อ พร้อมบอก อาชีพ/เลเวล/คาสของท่าน รับรองครับว่างานนี้ ไม่มีการสวมประวัติมารับรางวัลแน่

ลักษณะของกลอนแปด
http://www.st.ac.th/bhatips/glon.htm เครดิต. ครูภาทิพ ศรีสุทธิ์


กรุณาตรวจสอบผลงานที่ส่งมาว่า มีความถูกต้องตามกฏระเบียบหรือไม่

1. ใช้บทร้อยกรองประเภท กลอนแปด ต้องมีความถูกต้องตามอักขระ การสัมผัส ความยาวไม่เกิน 4 บท
2. บทร้อยกรองต้องมีเนื้อหาเกี่ยวข้องกับ เกม ECO เช่น มีคำว่า ECO ในบทร้อยกรอง
3. เนื้อหาในบทร้องกรอง ต้องไม่มีการล่วงเกินสถาบัน ไม่ดูหมิ่นศาสนา ไม่เกี่ยวข้องกับการเมือง ไม่ระบุชื่อ หรือว่าร้ายบุคคล ในเกม
4. บทร้อยกรองที่ส่งประกวดต้องแต่งขึ้นเอง ไม่ไปทำการคัดลอกมาจาก Web หรือ หนังสือ
