เห็นหลายๆคนอยากรู้ เอ้า มาดูกันเริ่มจาก


Mark

เงื่อนไข : Kabbalist Job Lv 20

ประเภท : Active Skill

Lv 1 / 2 / 3 / 4 / 5
MPที่ใช้ 3 / 4 / 5 / 6 / 7
SPที่ใช้ 3 / 3 / 3 / 3 / 3
ระยะเวลาเวท 8 / 10 / 12 / 14 / 16
จำนวนวงที่วาง 3 / 4 / 4 / 5 / 5

- วางวงเวทใว้ที่พื้น แล้วใช้ Dark Pain ระเบิดต่อ อาณาเขต 1x1 ระยะวาง 6 (เท่าระยะ SB)
- ไม่มีเวลาร่าย วางได้สูงสุด 5 วง เมื่อร่ายวงที่ 6 วงแรกจะหายไปแทน
- ร่ายใต้ตำแหน่งที่ศัตรูยืนไม่ได้ และร่ายซ้ำวงเวทเดิมไม่ได้
- มีอุปสรรคเช่น โขดหิน พื้นไม่เรียบ บางจุด วางไม่ได้
- ใช้เป็น Trap ได้ วางแล้ว ศัตรูติดเดินต่อไม่ได้
- % ที่ศัตรูติด Trap ขึ้นอยู่กับเวล Skill (ไม่ได้ติดทุกครั้ง)
- ระยะเวลาที่ศัตรูติด Trap ขึ้นอยู่กับเวล Skill
- ใช้ตอน Possession ได้


Dark Pain

เงื่อนไข : Kabbalist Job Lv 20

ประเภท : Active Skill

Lv 1 / 2 / 3 / 4 / 5
MPที่ใช้ 14 / 16 / 18 / 20 / 22
ความแรง(Matk) 180% / 210% / 240% / 270% / 300%

- ระเบิดเวทธาตุมืดจากวง Mark ที่วาง อาณาเขตระเบิด 3x3 (เท่า SB)
- หาร Damage ถ้ามีศัตรูมากกว่า 1 ตัวเข้ามาในวง 3x3 (เหมือน SB อีกนั้นแหละ)
- ออกมาร่ายได้ไกลจากวง Mark ระยะน่าจะ 9+ (ยังไม่ได้ลองระยะไกลสุด)
- ทำ Damage ได้แรงมาก 1500% ถ้าโดนหมด 5 วง พร้อมกัน
- โดนยากถ้าศัตรูเดิน เพราะใช้เวลาร่ายอยุ่ประมาณ 2วิ
- จะให้ง่ายๆ ให้ทดลองใช้กะ StarTar ที่ Fareast Dungeon มันจะยืนนิ่งถ้าไม่เห็นเหยื่อ
- คอมโบ กะ MF , MM ได้ ทำให้นิ่ง แล้ว ทำให้ศัตรูเป็นธาตุ น้ำ,ดิน มันจะโดน DP แรงขึ้น
- ใช้ระหว่าง Possession ได้
- หมดแล้วมั้ง คิดมะออกแล้ว -*-

ทั้งหมดมาจากประสบการณ์ของ จขกท เอง และก็มาจาก Wiki เรื่องข้อมูล
