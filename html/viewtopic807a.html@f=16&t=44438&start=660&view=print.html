ไม่รู้ว่าคนอื่นคิดว่าไงนะครับ
แต่ส่วนตัวผมคิดว่า TH เหมาะกับสาย Vit Agi ใช้เป็นตัวชนไปเลยครับ
ด้วยปัจจัยดังต่อไปนี้
1. bonuspoint
str+6 dex+12 int+12 vit+20 agi+21 mag+6
จะเห็นได้ว่า มันเหมาะกับสายชนชัดๆเลยครับ

2. TH มีทั้ง lucky หลบเวทย์ 20% และสกิล caution defตัวหน้า+20 และกันคริ
ตรงจุดนี้ถ้าเทียบกับอาชีพอื่นแล้ว ทำให้ได้เปรียบเรื่องความถึกมากเลยครับ

3. TH มีสกิล backlash ใช้หยุด มอนสเตอร์ให้คนอื่น ลุยต่อ ซึ่งตอนนั้นเราจะทำอะไรไม่ได้ และหลบไม่ได้ด้วย จึงควรที่จะต้องอัพ vit ให้อึดๆเข้าไว้

ถ้าทดสอบแล้ว TH สาย VIT AGI จะสามารถชนได้เก่งกว่า อาชีพอื่นเลยนะครับ (ทำ DEF หน้า 100 ได้ถ้ามีปัจจัยครบ)
แต่ต้องมีคนช่วยเลเวลให้นะ ถ้าให้ดีอัพ INT เลยครับ จะได้ทนเวทย์ด้วย แล้วตัวท่านจะเป็นกึ่งอมตะคนนึงเลยทีเดียว
