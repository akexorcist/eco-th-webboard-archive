ผมลองอัพ Throw Stone (40) ดูแล้ว ผลของสกิลเป็นตามนี้ครับ

1. ระยะสกิล 3 ช่อง เป็นสกิลระยะไกล
2. ความแม่นยำขึ้นอยู่กับค่า Int
3. ความรุนแรงที่เลเวล 1-5 คือ "เท่ากับโจมตีปรกติ หรือ น้อยกว่าเล็กน้อย" - -''
4. เลเวลของสกิลเพิ่มขึ้น มีผลแค่ลดเวลาการร่ายสกิลเท่านั้น (ที่เลเวล 5 ใช้เวลาประมาณ 0.5 วินาที)
5. ไม่ต้องใช้ Pebble หรือ Great Pebble (ไม่เหมือน Throw Nugget ของ BS)
6. ปัจจุบัน รีออกไปแล้ว ใครจะอัพไว้ใช้กับ Mec ก็อาจจะเวิร์ค (มั้ง) ครับ
