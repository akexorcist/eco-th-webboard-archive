MendoraXX เขียน:
สรุป skill Max HP ถ้าอัพแล้วมันจะเพิ่ม Max HP ต่อเลเวลให้รึเปล่าอะ


ขุดรอคำตอบ - -


เพิ่มครับ


ชื่อภาษาไทย : เพิ่ม HP สูงสุด
Lv. Require : Lv.2
Lv.Max : Lv.5
Effect : เพิ่ม HP สูงสุด
* คือค่าต่ำสุดที่เพิ่มแต่ละ Lv. จะเพิ่มมากกว่านี้ แปรผันตามสูตรด้านล่างครับ
Lv.1 : [ Max HP + 10 ] [ Skill Factor = 1% ]
Lv.2 : [ Max HP + 10 ] [ Skill Factor = 3% ]
Lv.3 : [ Max HP + 10 ] [ Skill Factor = 6% ]
Lv.4 : [ Max HP + 20 ] [ Skill Factor = 10% ]
Lv.5 : [ Max HP + 10 ] [ Skill Factor = 15% ]
• เมื่อสิงคนอื่น ความเร็วในการฟื้น HP = MaxHP/10
• สูตรคำนวน Max HP = floor [(VIT×3 + floor [VIT/5] ^2 + LV×2 + floor [LV/5] ^2 + 50) ×HP factor] the revision with the revision + equipment with + Skill Factor
- HP Factor ของ Tatarabe = 1.5, BS = 3.0, Machinery = 2.6
- Floor หมายถึง คิดออกมาแล้ว ปัดทศนิยมทิ้งครับ

หวัดดีเรนเจอร์ทุกท่านฮับ เราเล่น moji ตอนนี้เวล 52 แร้ว

stat ก็ str 50 dex 20 vit 45 agi 38 คับ

ตอนแรกเล่นสาย วิท แต่ตอนหลังกะ มิกซ์

statของผม เรยมั่วๆนิสนึง ทีนี้อยากรบกวนสอบถาม

คนที่เล่นสายมิกซ์อยู่อ่ะฮะ ว่าเปงไงมั่ง เจ๋งไหมฮะสำหรับสายนี้ มีใครเล่นสายนี้อยู่มั่งคับ

แร้ว stat แบบของผมนี้ถือว่าเลวร้ายไหมคับ อัพไรยังไงต่อไปดีรวมถึงเก็บเวลที่ไหนดีฮะ

ปล.ผมเล่นมีดคับ เกบคนเดียวด้วย จู๊ฟๆๆๆ ขอบคุณล่วงหน้าครับ
