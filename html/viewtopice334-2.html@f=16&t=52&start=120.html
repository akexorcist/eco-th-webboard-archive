4. ทำไอเทม lv 3
5. ปราชณ์แห่งพืช lv 1

7. เย็บผ้า lv 5
8. งานไม้ lv 3
9. Healling Tree lv 5 ( อันนี้มีดีกว่ากองไฟคือ เลือดคนและสัตว์เลี้ยงฟู้นฟู ด้วย และก็สวยงาม ความชอบส่วนตัวอ่ะน๊า แต่ใช้พ้อย 7 พ้อยแนะ )

ชุดไฮโซ = ด้าย 1 ชิ้น + ผ้า 2 ชิ้น ( + อุปกรณ์เข็มถัก )


ด้ายแข็งแรง = ด้าย 1 ชิ้น + พาลาฟิน 1 ชิ้น


ผ้า = ฝ้าย 1 ชิ้น
