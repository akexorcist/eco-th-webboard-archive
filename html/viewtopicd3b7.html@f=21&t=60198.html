สวัสดีครับ อาจจะเบื่อผมเข้าไปใหญ่เลยโทดทีครับเวลาไม่ค่อยจะว่างเลย T-T
ผมเลยเอาเรื่องนี้มาแทนให้ก่อน เพราะว่ากำลังอ่านประวัติตัวละครอยู่ ซึ่งเวลาผมไม่ค่อยว่างเลย
เดี๋ยวต้องสอบแล้ว เลยเอาเรื่องที่เคยร่างไว้แล้วเอามาแต่งใหม่แล้วกัน ซึ่งนิยาย NFD Evolution
ชื่อเต็มๆคือ Need For Death Evolution ซึ่งเป็นนิยายแนวแอคชั่นแฟนตาซีซึ่งใครที่เคยอ่าน
Need For Death แล้วอาจงงหน่อยคือเรื่องนี้ผมว่ามันเข้าขั้นเรื่องใหม่แล้ว เป็นเรื่องราวหลังจาก
ภาค 3 ของ Need For Death นิดหน่อยคือมันมาจากการที่อาคาโดะหายไปซึ่งผมจะหาลิงค์
ภาคที่แล้วมาให้สำหรับคนที่อยากอ่าน เพราะมันเกี่ยวข้องนิดหน่อย ส่วนใครที่อยากสมัครใหม่
ผมจัดให้เรื่องนี้จะมีการรับสมัครอยู่ 4 เผ่า อิอิ แอบสร้างเผ่าใหม่
1.เผ่ามนุษย์ 2.เผ่าสวรรค์ 3.เผ่านรก 4.เผ่าความมืด อิอิ 4 เผ่านี้ล่ะ
ซึ่งเรื่องอาคาโดะกลายเป็น อุ๊บ >x< เกือบไปแล้วให้อ่านเองดีกว่านะอิอิ ซึ่งผมมีเรื่องราวที่ทำให้งงกันด้วย
ซึ่งมันคือบทนำ แล้วใครที่งงในบทนำก็ต้องอ่านจนถึงตอนอวสาน เพราะจะเฉลยว่าอาคาโดะเป็นอะไร

"ไปถึงที่นั่นให้ได้"

ทันใดนั้นก็มีแสงจากดวงจันทร์ เอ่อเกือบลืมว่าวันนี้เป็นวันที่พระจันทร์จะเป็นสีเลือดแล้วคราวนี้จะเป็นยังไงล่ะ...
อาคาโดะถูกดูดเข้าไปอยู่อีกมิตินึงยังไงล่ะ -...-
"แค่ก แค่ก ทะที่นี่ที่ไหน"อาคาโดะกล่าวถามลม เฮ้ย!!พูดได้ว่าสงสัยล่ะมั้งอิอิ
"เจ้าจะต้องนำลูกแก้วสีเลือดที่แดงฉ้านอยู่ตอนนี้กลับมา"
"แกเป็นใคร ทำอะไรกับข้า"อาคาโดะกล่าวถาม เนื่องจากมองเห็นเป็นภาพเรือนราง
"ฮิ ฮิ เดี๋ยวเจ้าก็จะรู้แต่ตอนนี้มันยังเร็วเกินไป"
"เดี๋ยววววววววววววว!!"อาคาโดะตะโกน เมื่อรู้สึกว่าตัวเองเริ่มไกลห่างจากชายผู้นั้น ชายผู้ที่ใส่เสื้อคลุมดำ
.....
"แกเป็นใคร..."อาคาโดะละเมอ
"ฮ่ะ!นี่เราฝันไปหรือเนี่ย"อาคาโดะพึมพำ
"ไม่สินี่ รู้สึกว่าเรามีพลังเพิ่มขึ้นแฮะ เหมือนกับว่าท่านผู้นั้นคือเทพแห่งปีศาจดวงจันทร์ที่ถูกกล่าวไว้
ในคัมภีร์ของนรก เป็นผู้ที่ตามหาลูกแก้วอยู่ลูกแก้วหนึ่ง
กึก กึก กึก เสียงฝีเท้าของใครบางคนกำลังเดินมา
"เจ้าสินะ ที่ข้ามอบหน้าที่ให้ เจ้ามีพลังที่สามารถกำจัดสิ่งที่เจ้าเกลียดชังได้ แต่ยังไม่เพียงพอ"ชายในชุดดำกล่าว
"แล้วทำไม"อาคาโดะถาม
"ถ้าเจ้าอยากจะได้พลังเพิ่มเจ้าจงรับปากข้าว่าจะนำลูกแก้วนั้นกลับมาให้ข้า ข้าจะทำให้เจ้า
สามารถปกครองได้ทุกภพ"
"แน่หรอ ถ้าข้ารับปากแล้วไม่ทำตามสัญญาล่ะ"อาคาโดะท้าทายพร้อมกับหัวเราะนิดหน่อย
"ฮิ ฮิ ฮะ ฮ่าๆๆๆๆ"ชายชุดดำหัวเราะพร้อมกับกล่าวว่า
"ถ้าผิดสัญญาเจ้าก็จะตายยังไงแล้วด้วยพลังของข้าว้ากกกกกกกฮ่าๆๆๆๆ"
"ก็ได้ๆถ้าอยากมากขนาดนั้นเรามาร่วมมือกันก็ได้"อาคาโดะเสนอ
"เพราะถ้าเกิดข้าได้ปกครองทุกอย่างได้ล่ะก็ ขอแค่อโคโปลิสก็พอฮ่าๆๆ"อาคาโดะคิดในใจ
แต่!!อาคาโดะคิดอะไรอย่างนี้น่ะ อย่าน้าอาคาโด้!!!~

xiahjunsu เขียน:รูป


ชื่อ : Sopitia
อายุ : 18
อาชีพ : Holy Brade
เผ่า : Titania-Emil
ความสามารถ :
1. มีความสามารถ ในการต่อสู่ ระยะประชิด ทุกแขนง โดย เฉพาะ ชำนาญ การใช้ ดาบ ชนิดหนึ่งที่ ชื่อว่า "Katana"
2. เธอมักจะใช้ เพลงดาบ แบบจีนโบราณ ผสม กับ ญี่ปุ่นโบราณ เป็นศิลปะการต่อสู้ แบบ เอเชีย ลักษณะจะเป็นลีลา ที่อ่อนช้อย อ่อนหวาน แต่ดูแข็งแกร่ง และ ว่องไว
3. เพลงดาบ ที่ เธอมักจะใช้ บ่อยที่สุด ก็คือ เพลงดาบ "นางฟ้าโปรยดอกไม้ หรือ เซียนนวี่ ซ่านฮัว (仙女散花) " เป็นการ ร่ายรำเพลงดาบ อย่างอ่อนช้อย ก็แต่แฝงไปด้วยคนของดาบที่แหลมคม
4. เธอสามารถ สื่อสารกับแมว รู้เรื่อง นั่นเป็น ความสามารถพิเศษ อีกอย่างหนึ่ง
5. เธอมีสายลม เป็น ภูติ ประจำตัว ทำให้เธอสามารถ ปล่อย สายลม ผ่านคมดาบไปได้ ทำให้การโจมตีของเธอ แผ่กว้าง ออกไปเป็นระยะไกล
6. เธอมีคสามสามารถในการควบคุมสายลมได้ดั่งใจ เธอสามารถใช้เวทย์มนต์สายลมได้อย่างคล่องแคล่ว อาทิ สร้างบรรยากาศ รอบๆ ให้หนาแน่น เป็น โล่กำบัง ใช้สายลมที่อ่อนโยน รักษา บาดแผลได้


อื่นๆ อยากใส่ก็ตามสบาย :
เธอเป็นสายเลือดผสมระหว่าง Titania และ Emil เธอไม่ได้รับการยอมรับจากชนชั้น Titania ที่สูงศักดิ์ เพราะแม่ของเธอ ไปมีความรักกับ มนุษย์ ผู้ชาย ซึ่งเป็นการผิดลิขิตสวรรค์ ทำให้แม่ของเธอถูกพิพากษ์ษา ประหารชีวิต และเธอ ก็ถูกเนรเทศจากเมืองสวรรค์ มายังเมืองมนุษย์ ด้วยเหตุนี้เอง ทำให้เธอไม่เคยมีเพื่อนเป็นชนเผ่า Titania เลย เมื่อเธอมาถึงยังโลกมนุษย์ เธอต้องได้รับความยากลำบากอย่างที่เธอไม่เคยประสบมาก่อน เหตุการณ์นี้ทำให้เธอเป็นคนไม่ค่อยพูด เก็บตัว เธอต้องการเดินทางตามหาพ่อของเธอ จึงได้พบกับเหล่าเพื่อนๆ ที่ทำให้เธอเริ่มเปิดใจยอมรับ คนอื่นมากขึ้น เธอมีความลับที่ไม่สามารถบอกใครได้ คือในคืนเดือนมืด เธอจะมีร่างกาย จากภูติสวรรค์กลายเป็น มนุษย์ นี่เป็นผลที่เกิดจาก สายเลือดผสมของเธอนั่นเอง (555+ อินุยาฉะ คุ้นปะ )
