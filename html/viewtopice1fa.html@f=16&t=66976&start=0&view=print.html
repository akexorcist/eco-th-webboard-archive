คือพวกของที่ดัน 70 อ่าครับ อาทิหนังม่วง บลัดโน้ต cpu memory ขาหุ่น อะไรพวกนี้อ่ะที่เค้ารับกันคือมันเอาไป OC ได้ใช่ไหมครับหรือว่าผมเข้าใจผิด ถ้า OC ได้ต้องไปขายแมพไหนครับเผื่อผมจะได้ลองรับดูบ้าง
- เอาไปขายที่ หน้าดันหลังเมืองเหนืองับ OC ได้ 80% ของราคาปกติ เช่น หนังม่วง จาก 1000 ก็ขายได้ 1800

แล้วสกิล Trust ของ Trader นี่จริง ๆ แล้วมันทำไรได้แน่เหรอครับขอบคุณมากครับ
- ทำให้ NPC สามารถรับของที่ราคาเกินกำหนดได้ระดับนึงงิ
เช่น NPC อ้วลเขียว รับซื้อของในราคาไม่เกิน 2500 เราจะขายของบางอย่าง เช่น ชุด 45 ซึ่งราคา 3000 ไม่ได้
แต่ถ้า อัพ Trust ไว้ จะสามารถขายได้งิ
