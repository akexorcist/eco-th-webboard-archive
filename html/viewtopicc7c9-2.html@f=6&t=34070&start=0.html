*~[ซิ๊มโบ๊ะ]~* เขียน:หนังสือ เลเวล 15 : ทำเควสกับ sage master ( เลเวล 16 - 25 )
- ให้หา กระดาษ paper 100 ใบค่ะ

หนังสือ เลเวล 25 : ทำเควสกับ sage master ( เลเวล 25 ขึ้นไป )
- ให้หา กระดาษ paper 200 ใบค่ะ

หนังสือ เลเวล 45 : หาซื้อได้ใน ดันเจี้ยนน้ำแข็ง บนเมืองนอนเทิน ราคา 49000G

หนังสือ เลเวล 52 : ( เควสส่งเอกสาร )

หนังสือ เลเวล 60 : มีขายที่ปราสาทอันเดธ ชั้น 5 ราคา 58000G

หนังสือ เลเวล 70 : ดรอปจากมอน ที่หอแสง เมือง มอร์ค ชั้น B - 8B
- มอนสเตอร์เป็นกึ่งมนุษย์ และต้องให้เทรดเดอร์ที่อัพ Human knowledge ไปหานะค่ะ
มอนชื่อ Spell Limitant >_< นอกจากนี้ก็มอนเลเวล 92 Dominion Penancy

หนังสือ เลเวล 80 : สร้างขึ้นมาเอง โดยใช้สกิล สร้างไม้เท้า เลเวล 5 หรือจ้าง npc ทำในราคา 5000G
- ของที่ใช้ในการทำหนังสือเลเวล 80 ก็มี " ancient Book " ได้จากกล่อไม้ 2 หรือหาจากมอนสเตอร์ที่ดรอป หนังสือเลเวล 70 เลยค่ะ ต้องให้เทดเดอร์ที่อัพ Human knowledge ไปหาด้วยค่ะ ของอีกชิ้นก็คือ " String " เชือกที่ทำจากด้าย 2 ชิ้น ( ง่ายแหะ )
