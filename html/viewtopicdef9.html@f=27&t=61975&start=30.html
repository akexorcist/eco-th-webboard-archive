เพิ่มเติมครับ ส่วนของ

ข้อจำกัดของ FPS
ปรับระดับของ Frame Per Second มี 3 แบบ
ไม่มี

เต็มที่กับคอมคุณเลย คอมเทพเท่าไรยิ่งไวเท่านั้น (กิน CPU สุดๆ)

30

30 Frame ต่อวินาที เหมาะสำหรับคอมสเปคต่ำๆ (หรือเปิดหลายๆจอแล้วไม่อยากกระตุกก่อนจอที่...อันควร )
(กิน CPU ไม่มากครึ่งหนึ่งของ60/ไม่มี แยกความไวระหว่าง 60 กับ 30 ไม่ออกแต่แยกความลื่นของเกมออกนะ)

60

60 Frame ต่อวินาที (กิน CPU มากๆ แทบไม่ต่างกับไม่มี)
