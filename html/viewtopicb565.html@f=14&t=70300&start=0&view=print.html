ใครมีวิธีเวลกับหนามเหลืองยังไงโพสต์มาเลยครับ


ของผมต้องมีแมชชีนหรือแรนเจอร์หรือฟาร์มเมอร์1คน คนที่จะตี1คน(ผมเป็นดาบ)+ยาเติมเลือดนิหน่อย+ยาเติมเอสพีนิดหน่อย+มาริโอเนตปลา

1.ขั้นแรกมาที่หอแสงพร้มกับเอาตัวสายแบ็คแพ็คที่มีสกิลเตนท์
2.กางเตนท์ไห้ตัวสายแบ็คแพ็คอยู่ข้างในตลอดเวลา
3.ไห้ตัวดาบที่จะเวลออกไปตีหนามเหลืองโดยการกดอีไอ1อีไอ2อีไอ3ติดต่อกัน(ต่อหนามเหลือง1ตัว)
4.เมื่อเอสพีหมดกดมาริโอเนตปลาแล้วกดสกิลอีไอตามแบบเดิม
5.เมื่อโดนอัดไกล้ตายก็วิ่งเข้าเตนท์ไปพัก

ง่ายๆคับใครมีวิธีเจ๋งๆก็โพสต์เลยครับ

กรณีสาย vit เยอะหน่อย + ใ่ส่เสื้อหนา (ตามเลเวลตัวเอง) ก็กดมาริหุ่นยนต์สู้เอา
พกโทนิกสัก 50-100 ถ้าพกไหว

สาย agi ก็ใช้ได้ แบบข้างบน เมื่อทำค่า S.avoid ได้ราวๆ 180+ ก็สู้ไหวแล้ว

เหตุผลหลัก เพราะเวทมันแรง แปลงร่างช่วยให้โดนเบา แถมหุ่นมันเลือดเด้งด้วย

( ส่วนค่า S.avoid กับค่า S.Hit นี่ ไม่รู้ว่านับที่เลเวลเหมือนเกมแร็คนรกรึเปล่านะ )

ไม่แนะนำให้ใช้สกิลใส่มันเท่าไหร่ มันประเภทไวต่อเวท ใครร่าย มันจะไปหาทันที จังหวะไม่ดี
กดร่ายสกิล มัน ! พร้อมกัน 3 ตัวจะแย่เอา
