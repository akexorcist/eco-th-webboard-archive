II . ) Niwre Lemmor ( นิฟรี เลมเมอร์ ) / นิฟ , จอมพลนิฟรี , จิ้งจอกสีเงิน / 236 ปี / หญิง / Dominion / Sage – [ Thepingman ]


ฟู่ ... อ่านจบจนได้ สำหรับสาวน้อย ? ( ไม่สิ ไม่น้อยแล้ว ) เจ้าของตำแหน่งจอมทัพแห่งเผ่าพันธุ์ `DEM` หญิงสาวผู้เข้าฝ่าฝันข้าศึกเป็นคนแรก และกลับออกมาเป็นคนสุดท้าย เปี่ยมด้วยพรสวรรค์สำหรับผู้นำโดยแท้ ราวกับว่าตำแหน่งนี้มีขึ้นเพื่อเธอก็ว่าได้กระมัง ? อีกทั้งยังเพื่อนรักผู้อยู่ข้างกายเธอราวกับว่าจะไม่มีวันแยกจากกัน นับว่าเป็นตัวละครที่น่าสนใจมากตัวนี้ ! แต่ต้องขอกล่าวว่าบทที่ได้รับนั้นอาจจะช้าหน่อยเพราะว่ามีการเล่นเรื่องของเผ่าพันธุ์อยู่มาก ดังนั้นจะออกมาในรูปแบบไหน ก็ขอให้อดทนรอก่อนละกัน อย่างว่าแหละ นิยายเจ๊นั้นเปลี่ยนแปลงไปมาได้เสมอ ขึ้นอยู่กับความเหมาะสมของบทและตัวละคร เผลอ ๆ อาจจะโผล่มาเร็วเพราะว่าภาคนี้อย่างที่ว่ากัน ทั้งฆ่ากัน , สงคราม และอะไรอีกมากมา ทุกอย่างผ่านหมด แต่กระนั้นจะขอลดความสามารถใน `บางจุด` เพื่อเป็นการรักษาสมดุลบ้างเล็กน้อย ( เพราะตามวิจารณญาณของเจ๊ บางจุดยังดูโหดเกินไปนิด ) ส่วนอื่นก็ไม่มีอะไร ถือว่าละเอียดและเป็นตัวละครที่น่าสนใจมากทีเดียว !!

III . ) มิกิ ริกี้ / มิ / 105 ปี / ชาย / Titania / Archer – [ Guntapilus ]


เอ้า ! ลุยต่อเลยสำหรับตัวที่สาม ! หนุ่มน้อยผู้มีนามแสนประหลาด ! นามว่า `มิ` !! เรื่องลักษณะภายนอกรวมทั้งเครื่องแต่งกายนั้นไม่มีปัญหาอันใด จะมาสับที่ส่วนนิสัยเลยละกัน สำหรับนิสัยนั้นก็ถือว่าโออยู่บ้าง เขาคนนี้ปรับตัวได้อย่างดีเยี่ยมเมื่อพบกับใครก็ตามที แต่ก็ยังมาติดที่จุดนี้อยู่ดี นั่นคือที่บอกว่า `หากคนอื่นชอบในสิ่งที่เขาไม่ชอบ เขาแทบจะเป็นศัตรูกับคน ๆ นั้นเลยทีเดียว` แล้วในกรณีที่ว่าต้องอยู่กับคนบางคนโดยจำเป็นมาก ๆ แต่ว่าไม่ชอบสิ่งที่เขาชอบเลยสักนิดล่ะ ? จะอยู่ร่วมกันได้ยังไง ? ต้องขอถามดูก่อนว่าเขาสามารถที่จะปรับตัวในจุดนี้ได้ไหม ? ยังไงชี้แจงเจ๊ด้วยนะคะ อีกจุดนั่นคือเรื่องชื่อ อยากจะขอให้เปลี่ยนชื่อเรียกเป็น `มิกิ` ไปเลยได้ไหม ? เพราะคำว่า `มิ` นั่น ใช้ในนิยายของเจ๊หลายจุด จะพาลเอาสับสนเอาได้น่ะค่ะ ... เรื่องอาวุธนั้นไม่เป็นปัญหา ชอบใจถุงมือที่ว่าใส่แล้วปาแม่นทุกอย่างนี่สิ ตลกดี ( ฮา ) เอ้า ! ก็ถือว่าขอให้ชี้แจงในจุดที่เจ๊ถามละกัน ถ้าโอเค เจ๊เก็ทแล้ว ก็ผ่าน แต่ตอนนี้ก็ถือว่ายังไม่ผ่านไปก่อนละกันนะ

ลุยรวดเลย !! ย๊ากกกกก ---- กกก !! สับแหลก วินาทีแรกที่อ่านชื่อ ... “ยาวขิง ...” แล้วก็เจ๊ขอเปลี่ยนคำอ่านภาษาไทยให้มันดูดีขึ้นนิดนึงนะคะ เพราะว่าเจ๊โรคคคคจิต ! ชอบเห็นภาษาสวย ๆ ( ฮา ) เอาล่ะ มาถึงเรื่องการแต่งกายก่อนเลย ต๊าย ... แต่งตัวดูสมกับเป็นโชตะจริง ๆ เลย ( เจ๊ชอบ ! ฮา ไม่ใช่และ ) ตรงนี่เนี่ย เจ้าตัวชอบสวมรองเท้าแบบไหนคะ ? ยังไงอย่าลืมใส่เพิ่มเข้ามานะ โอเค๊ ? เอาล่ะ นอกเรื่องมาเยอะแล้ว มาพูดกันที่เรื่องนิสัยเลยดีกว่า ไม่รู้สินะ ไอ้ประเภทว่าเดี๋ยวดวงดีเดี๋ยวดวงร้ายเนี่ย มันมีตัวละครแบบนี้แล้วตัวนึง คงจะไม่มีซ้ำกันหรอก ตรงนี้ขอตัดออกไม่ก็เปลี่ยนเป็นอย่างอื่นแทนนะ เรื่องอาวุธรวมทั้งความสามารถพิเศษเนี่ย ถือว่าสร้างสรรค์ออกมาได้มีเอกลักษณ์มากมาย ตรงนี้ขอชม แต่แหม ... พ่อหนุ่มน้อยคนนี้จะไปต่อกรกับใครค๊า ใครจะรังแกเด็กตัวแค่นี้ลง จริงมิ ? แล้วที่บอกว่ารู้เรื่อง `พวกนั้น` เยอะเนี่ย !! หมายความว่าไงยะ พ่อเด็กแก่แดด !!
