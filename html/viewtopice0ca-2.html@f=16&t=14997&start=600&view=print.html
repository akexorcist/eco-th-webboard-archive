ในภาพนั่น เรา

โซล Mag 100 3 ตัว ขวา / ซ้าย / อก + โอนอิ้น + บัฟพระ + แปลงมารี(ที่เกาะไทนี่ถึงสิงมันก็แปลงให้) + ลงพื้นแสง (Holy power circle) + noise (ลด Mdef) แค่นี้อะ
ทำให้แรงกว่านี้อีกก็ได้ + ของ Cash+10 + เพลง Mag ของพระ

ป.ล1 ใส่ของครบเซตนะ(แต่ขาดอีก1อย่าง) มินิซากุระ หมวกตี้เหลือง หนวดแมวขาว Mag+7 ขาดคลุมนางฟ้าอิก2 ถ้าครบเซตนั่น Mag+9
ป.ล2 ไม่ได้ลองพื้นน้ำนะ ลงพื้นน้ำมันน่าจะแรงกว่านี้ นั่นลงพื้นแสงอะ
ป.ล3 ลองเอาไปยิงคน 18k (โซล 3 บัฟพระ พื้นแสง สาปแข็ง)
