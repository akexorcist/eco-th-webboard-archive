ค่าหลบหลีกไกล้-ไกล-Hp ไม่มีMax ครับ ค่าเหล่านี้ขึ้นอยู่กับเเต่ละสายอาชีพซึ่งจะได้มากน้อยขึ้นอยู่กับไอเท็มที่สวมใส่+สเตตัสของตัวละคร

หลบไกล้-ไกล อย่างมากก็350-400 ถ้าเป็นเเอสอาจจะมากขึ้นอีกหน่อย

HPอาชีพอื่นที่ไม่ใช่ไนท์กับเบลด 3000-4000 เเต่ถ้าเปนไนท์กับเบลดอาจจะมากถึง6000ขึ้นไป


ปล.ค่าที่ผมกล่าวมาอาจจะมากขึ้นอีกถ้าหากในอนาคตมีการอัพเลเวลสูงสุด+อัพชุดใหม่ๆ ที่+สเตตัสแบบโหดๆ
