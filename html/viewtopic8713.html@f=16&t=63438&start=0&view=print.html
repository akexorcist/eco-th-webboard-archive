จากประสบการณ์เล่นมานาน

- back rush เวลาใช้ควรมีปาตี้อยู่ข้างๆ ไม่งั้นเราจะกลายเป็นเป้านิ่ง สกิลนี้ดีสุดๆ ถ้าเราเป็นสายถึก (ใช้คู่กับสกิล caution) เอาไว้เกร็งพวกที่ชอบสิงมา แต่อย่างว่าถึกแค่ไหนโดนอีวาทีก็ตาย

- pull whip ต่างกับ catch ตรงที่ มีเวลาร่ายประมาณ 1 วิ และก็สร้างดาเมจได้ ที่เลเวล 5 ความแรง 3.15 เท่า (เราอัพ catch เต็ม 5 เพิ่มความแรง)

- สกิล 50 อาชีพนี้ เป็นอะไรที่ใช้ยากเพราะร่ายนานและกว่าจะคอมโบจบท่าก็กินไป 4 วิ ถ้าใช้ในวอร์ pull whip จะดูยืดหยุ่นกว่า

- เป็นอาชีพแรร์ ไม่ค่อยพบในวอร์เท่าไร เราปั้นอาชีพนี้ตัวแรก แต่ตอนนี้ปั้นพ่อค้าไปวอร์แทนแล้ว

- ถ้าลดดีเลย์ท่าแส้ ใช้หมาดีสุด เราก็ใช้อยู่
