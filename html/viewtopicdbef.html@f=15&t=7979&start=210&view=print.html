.สาย นักเวทย์ผู้ใช้ซากศพ
B1.MAG only
- สายบ้าพลังเน้นเวทย์ระดมเข้าใส่ เป็นสายที่เปราะพอควรแต่ทดแทนตรงที่ เรามีอสูรแท้งส่วนตัว ! ดังนั้นจึงเป็นรูปแบบที่น่าจะเก็บเลเวลเพลินมากที่สุด เอาอสูรไปตี เราคอยเป็นกำลังเสริมยิงอยู่แถวสอง ..และสายนี้ยังเป็นสายที่สามารถใช้สกิลยิงลำแสงความมืด สุดยอดของสกิลเนโครมานเซอร์ให้มีประสิทธิภาพสูงสุดอีกด้วย ข้อเสียคือร่ายช้า และเปราะบาง

B2.MAG>DEX
- สายพิมพ์นิยม ไม่บ้าแรงเหมือนสายแรก แต่เน้นยิงเร็ว ไม่ตายก็ยิงอีกที (ฉันรวย ฉันมีตังซื้อยา) ประมาณนี้ แนวทางเก็บเลเวลคือแบบข้างต้น ข้อเสียก็เช่นเดียวกัน คือ บ๊าง บาง -*-

B3.MAG>INT
- สายนี้สำหรับคนชื่นชอบคำสาป(ถ้าคำสาปติดไม่ติดขึ้นอยู่กับ int นะครับ) เป็นสายที่ใช้อสูรเข้าตี เราสาปอยู่ข้างหลัง ผสมผสานการใช้เวทย์ น่าสนุกดีเหมือนกันน้า สงครามก็ป่วนได้ดีเช่นกัน!

B4.MAG>DEX>INT
- เป็นสายที่นำสองสายด้านบนมาผสมผสานกันจนเกิดเป็นโกโก้ครั้นช์ ! เอ้ย ผิดงาน เป็นสายที่เน้นความสมดุลสำหรับพวกหลายใจ อยากโจมตีเวท อยากร่ายเร็ว และอยากใช้คำสาป

งั้นถ้าผมอยากเล่นปลุกซากศพ กับ คำสาป นี่ ถ้าอัพ int อย่างเดียวเลยได้ไหมอะคับ เพราะเรียกซากศพนี่มานไม่เกี่ยวกะmagไหมอะคับ หรือเกี่ยวอะคับ
