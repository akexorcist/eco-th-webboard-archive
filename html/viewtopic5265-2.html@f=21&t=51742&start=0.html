เพิ่มเติมประวัติมิกะค่ะ



Information : มิคังโนะคุชิ มิกะ



ยามเช้าของโรงเรียนมัธยมต้นแห่งหนึ่งนาม ‘มิโดริฮะ’ โรงเรียนหนึ่งอยู่ไกลจากเมืองหลวงยิ่งนัก โรงเรียนแห่งนี้ล้อมไปด้วยธรรมชาติ อาจารย์และเด็กนักเรียนก็รักใคร่กลมเกลียวกันดี โรงเรียนแห่งนี้จึงมีแต่ความสุข สนุกสนาน ... ทว่าข่าวร้ายก็แจ้งมาถึงทางโรงเรียน

‘แจ้งทุบตึกสร้างโรงแรมทัวร์’

จดหมายอันน่าเศร้าส่งมาถึงหลังจากงานวันปีใหม่ไม่กี่อาทิตย์ เด็กนักเรียนส่วนใหญ่ต่างทำใจไม่ได้กับเหตุการณ์นี้ โดยแต่ละคนก็เริ่มมีการประท้วงกันในกลุ่ม จนถึงขั้นจริงจังยกป้ายขึ้นประท้วง

ผู้อำนวยการของโรงเรียนมิโดริฮะ พยายามต่อรองกับเจ้าหน้าที่อย่างเต็มที่ ทั้งๆที่รู้ว่าทำไปก็ไม่ได้ประโยชน์อะไร เจ้าหน้าที่ยังคงยืนยันคำเดิม เวลาแห่งความสุขของเหล่านักเรียนโรงเรียนมิโดริฮะเหลือเพียงไม่ถึงเดือน นักเรียนบางคนเมื่อออกจากโรงเรียนนี้ไปก็อาจจะไม่มีที่เรียนบ้างบางกลุ่ม

...โดยเฉพาะเหล่านักเรียนกลุ่มนี้... ที่จะต้องจากเพื่อนๆสุดที่รักไป

“โหยยย – ยย !! นี้มันเรื่องอะไรกันล่ะเนี่ย -*- ทุเรศชะมัดอยู่ๆก็จะมาทุบโรงเรียนของเรา ...” เด็กหญิงร่างสูงในกลุ่มคนหนึ่งโวยวาย

“นั่นสิคะ ... อย่างนี้มันคงไม่ถูกต้อง” เด็กสาวผมน้ำตาลอีกคนกล่าวอย่างไม่พอใจ

“แบบนี้เค้าเรียกกันว่า ‘แงะนิสัยไปให้สุนัขมิรับประทาน’ หรอกค่ะ ... แย่มากๆ” เธอพูดต่อ เพื่อนๆในกลุ่มกลั้นหัวเราะ ส่วนบางคนก็หัวเราะก๊ากใหญ่ออกไปเรีบยร้อยด้วยคำพูดอันสุภาพที่ เจ็บลึกถึงจิตใจของเด็กสาวผมน้ำตาลคนเดิม

“... อืม ถ้าออกจากโรงเรียนนี้ไปพวกเราคงไม่ได้เจอกันอีกแล้วล่ะเนอะ ...” เด็กชายผมดำทำหน้าเศร้า ทำลายเสียงหัวเราะเมื่อตะกี้นี้ออกไปจนหมดสิ้น เพื่อนๆมองมุมต่ำลงมาที่โต๊ะ

“งั้นหรอ ... งั้นสินะ ... ถ้าจากโรงเรียนนี้ไปทั้งชั้นจะต้องไปอยู่โอซาก้าอีกรอบ นางิก็คงกลับฮอกไกโด ... และ มิกะจัง ...” หญิงสาวร่างสูงเงียบไป พร้อมค่อยๆหันไปมองเด็กหญิงร่างเล็กเจ้าของเรือนผมสีเงิน

“คงจะต้องกลับไปโตเกียว กลับไปเรือนใหญ่ผม ‘มิคังโนะคุชิ’ อีกรอบ”

บรรยากาศเริ่มมืดมนลง ความเงียบเข้าสู่ร่างของทุกๆคนเด็กสาวร่างเล็กที่ถูกกล่าวถึงยังคงทำหน้าตายพร้อมกับตักอาหารเข้าปากไป ทีละคำ ทีละคำ ... โดยไม่สนคำพูดของหญิงสาว

“ทำไมจะอยู่ด้วยกันไม่ได้ ... ตั้งยุคนี้แล้วโทร เมลล์ โห ! มีเยอะแยะ จดหมายก็ได้เอ้า ! ...”

เด็กหญิงผู้ถูกกล่าวถึงทุบโต๊ะดัง ปึง ! อย่างแรงจนคนรอบๆหันมามอง

เธอคนนี้เป็นลูกสาวคนแรกและคนเดีผม ‘มิคังโนะคุชิ’ 1 ใน 7 ผม่าแก่ของโตเกียว ซึ่งตอนนี้เธอได้ออกมาจากเรือนใหญ่ผมียนอยู่ที่โรงเรียนชนบท โดยมีเพื่อนสนิทอยู่ก๊วนหนึ่ง เธอมีเรือนผมสีเงินที่ตัดบ๊อบดูน่ารักเหมือนเด็กๆ ตากลมโตสีนิลของเธอก็ถูกพวกเพื่อนๆ และ คนรอบกายเธอชมอยู่บ่อยๆ แต่ทั้งๆที่มีคนชมว่าน่ารักเยอะ แต่เธอกลับไม่สนใจเลยแม้แต่น้อย

นามของเธอคือ ‘มิกะ’ เธอเป็นคนที่เส้นลึก แต่ถ้าโดนใจเธอจะหัวเราะอย่างเต็มที่โดยไม่อายใคร เธอออกแนวค่อนข้างเก็บกดในเรื่องอดีผม ถูกสั่งสอนมาอย่างลูกผู้หญิงที่ดี ในเรื่องแบบนี้เธอไม่ถนัดเอาเสียเลย เมื่อมีใครมาเปรียบเทียบกับคนอื่นเธอจะโวยวายกลับเป็นส่วนใหญ่

และถึงจะเห็นอย่างนี้เธอ ‘เกลียด’ แมว ‘อย่างมาก’ เห็นทีไรเป็นหักคอทารุณเกือบทุกครา ... ก่อนหน้าที่จะมาถึงโรงเรียนชนบทเธอก็ก่อวีรกรรมอันเลวร้ายไว้ที่โรงเรียนเก่าๆอยู่เยอะ จนต้องลาออกจากโรงเรียนทุกปี ทั้งๆที่เป็นคนผลการเรียนค่อนข้างใช้ได้ถ้าเอาจริงก็คือหัวดีมาก ปกติแล้วไม่ชอบแสดงความรู้ที่มีมากออกมาให้เห็น การสอบในแต่ละปีคะแนนก็ยิ่งแย่ลง คงจะมีแต่โรงเรียนมิโดริฮะนี้ ที่มิกะอยู่รอดมาได้จนถึง 3 ปีเต็ม

“... มิกะจัง ...” เพื่อนๆในกลุ่มต่างเอ่ยชื่อเธอเบาๆ ก่อนที่จะฉีกยิ้มกัน “ก็นั่นสินะ ! มิกะนิก็พูดถูก ถึงจะไม่มีโรงเรียนก็ไม่ใช่ว่าเราจะลืมจากกันไปจริงๆเสียหน่อย ฮ่าฮ่า ...” เด็กชายผมแดงหัวเราะอย่างมีความสุข

บรรกาศหมองหายไปแล้ว ราวกับสายรุ้งออกมายามหลังฝน ทุกคนดูร่าเริงกันมาก เวลาพักเที่ยงก็หมดลง เสียงกระดิ่งดังเป็นสัญญาณถอยหลัง เหล่าเด็กนักเรียนต่างรีบวิ่งไปยังห้องเรียนของตน ในความกลัวที่จะถูกลงโทษ
