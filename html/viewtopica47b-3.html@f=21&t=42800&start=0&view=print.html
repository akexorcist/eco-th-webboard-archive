ก่อนจะเริ่มเรื่องมิ้นมีเรื่องอยากจะพูดอีกสักอย่างนะคะ
มิ้นอยากขอบคุณทุกคนในริงStardust Memeory ที่เป็นกำลังใจให้มิ้นและได้ให้มิ้นทำตามความฝันของตัวเองดูสักครั้ง ขอบคุณนะคะ เริ่มจากพี่นู พี่สา พี่แอน พี่หลิน มายน้อย และทุกๆคนเลย

งั้นจะขอแนะนำเผ่าพันธุ์ที่ออกมาในเรื่องเลยนะคะ

เผ่าพันธุ์มนุษย์ที่ปรากฏในเรื่อง
โลกเลินบัลม์(โลกที่พวกเราอาศัยอยู่)

การ์เดี้ยน ชนเผ่าโบราณเป็นชื่อที่ถูกเรียกจากเผ่าพันธุ์อื่น เป็นเผ่าพันธุ์ที่มีอารยะธรรมมานานและอยู่ในโลกมามากกว่าหมื่นปีมาแล้ว เป็นเผ่าพันธุ์ที่มีมากที่สุดในโลกและเป็นต้นแบบของการกำเนิดเผ่าพันธุ์อื่นๆหลายๆเผ่า

ไททาเนีย เผ่าพันธุ์มนุษย์ที่มีปีกสีขาวงอกมาจากกลางหลังเชื่อว่าวิวัฒนาการมาจากชาววิหค เป็นเผ่าพันธุ์ที่ยึดมั่นในหน้าที่มาตั้งแต่กำเนิดคอยช่วยเหลือเผ่าการ์เดี้ยนมาตลอด 200 ปี เป็นเผ่าที่เต็มไปด้วยพลังเวทย์และคำพยากรณ์

โดมีเนียน เผ่าพันธุ์ที่ยังไม่รู้แน่ชัดว่ามาจากไหนเชื่อกันว่าวิวัฒนาการมาจากปีศาจ มีลักษณะดวงตาสีแดงหรือสีเหลืองมีปีกสีดำบางคนก็มีหาง เป็นเผ่าที่เต็มไปด้วยพละกำลังมหาศาลเป้าหมายของพวกเขาที่มาอาศัยอยู่ร่วมกับเผ่าพันธุ์การ์เดี้ยนคืออะไรกันแน่

ไซคลอปเปอร์ เผ่าพันธุ์มนุษย์ยุคโบราณ ลักษณะมีลายอักขระแปลกๆบนหน้าผากตั้งแต่กำเนิดมีผิวคล้ำเชื่อว่าสามารถเบิกดวงตาที่สามจากบนหน้าผากได้ เป็นเผ่าพันธุ์ที่อาศัยอยู่ใต้ดินตอนที่เกิดสงครามนิวเคลียร์

เอลฟ์ เผ่าพันธุ์ที่อยู่คู่กับเผ่าการ์เดี้ยนมานานแต่อาศัยอยู่ตามชนบทคอยช่วยเหลือเผ่าการ์เดี้ยนมาตลอด ลักษณะมีนัยน์ตาและสีผมสีเหลืองมีใบหูเรียวบาง

ฮาล์ฟโฮโม เผ่าพันธุ์ที่ได้รับเชื้อสายมาจากมนุษย์นอกโลก มีลักษณะลำตัวผิวสีเขียวอ่อนนัยน์ตาสีดำเป็นเผ่าพันธุ์ที่เกิดขึ้นมาใหม่พบเห็นได้ยากมาก เป็นเผ่าที่ไม่มีข้อมูล

โลกชาเพลส(หรือโลกปีศาจ)

เมย์เทอร์บาเป็นเผ่าพันธุ์ที่มีมากที่สุดในโลกแห่งนี้ส่วนใหญ่จะเป็นมนุษย์ที่มีบางส่วนคล้ายกับสัตว์ป่า เช่นบางคนมีหูแบบแปลกๆ ปีกหรือหาง สีผมและนัยน์ตามักจะเป็นสีแปลกๆตา หลายพวกมักจะมาอาศัยอยู่ในโลกเลินบัลม์

ชาโว้โซลเป็นเผ่าพันธุ์ที่ไม่มีรูปร่างที่แน่นอน คล้ายกับพวกวิญญาณ มักจะเข้าสิงหรือควบคุมเครื่องจักรหรือสิ่งมีชีวิตที่ไม่มีวิญญาณอยู่บ่อยๆ เพื่ออาสัยร่างติดต่อกับเผ่าพันธุ์อื่นๆมีบางส่วนอาศัยอยู่ในโลกเลิมบัลม์

เซริกซีตร้าเป็นเผ่าพันธุ์ที่ชั่วร้ายคอยแย่งชิงถิ่นที่อยู่และรุกรานชนเผ่าอื่นๆมีลักษณะคล้ายมนุษย์แต่มีหางยาวหรือบางพวกมีปีก หน้าตาน่ากลัวแฝงไปด้วยความชั่วช้าเป็นพวกที่มีพละกำลังสูงและเต็มไปด้วยพลังเวทย์

ฟินด์สปิริตเผ่าพันธุ์ที่มีอยู่น้อยในโลกแห่งนี้ส่วนใหญ่จะเป็นพวกภูติ มีความสามารถอำพรางตัวได้อย่างดีเยี่ยมและแปลงร่างได้หลายรูปแบบ มีลักษณะส่วนสูงค่อนข้างเตี้ย พลังเวทย์สูง

ตรงทางออกหมู่บ้าน
ขณะนี้ทุกคนได้มารวมตัวกัน และอากิระอาสาที่จะนำทางให้ทุกคน
“ถ้าเราเดินมุ่งหน้าไปทางเหนือประมาณสามสิบนาทีผ่านป่าโทวาน่าก็จะไปถึงแล้วล่ะ”เด็กชายจิ้งจอกพูดปลาว
ออกมาพร้อมกับนำทาง

ตามด้วยเสียงของเด็กชายผมม่วง
“อือ งั้นไปกันเลย!!”

ก่อนที่อากิระจะหันมาพูด
“ป่าที่จะผ่านมีสัตว์ค่อนข้างจะเยอะต้องระวังตัวหน่อย”
แล้วทุกคนก็เดินทางไปจนถึงทุ่งดอกไม้ แล้วเอลก็หยุดเมื่อเห็นภาพตรงหน้า มีใครยืนอยู่ก่อนที่เด็กสาวเอ่ยขึ้น
“เอ๋! นั่นพี่เนสตี้นี่”

“เค้าคงจะรู้สึกโดดเดี่ยวมากเลยล่ะ เราไปหาเค้านะ”โรห์เอ่ย แล้ววิ่งนำไปทุกคนก็ตามไปทันที

ภาพที่เห็นคือเนสตี้ที่กำลังยืนมองท้องฟ้าท่ามกลางสายลมพัดอ่อนๆแล้วมีกลีบดอกไม้ และเส้นผมของเนสตี้ปลิวไปตามแรงลม
“พี่เนสตี้คะ!!”เด็กสาวเจ้าของผมชมพูอ่อนพลางมองคนตรงหน้าแล้ววิ่งเข้าไปตามหลังของโรห์

หญิงสาวนึกเอะใจพลางหันหน้ามาทางต้นเสียงทันที
“เอ๋! แอร์หรอจ๊ะ!” แล้วหันมาตามเสียงเรียก แล้วทุกคนก็ไปอยู่ตรงหน้าเธอ

ตามด้วยเด็กชายผมเหลืองเอ่ยขึ้น
“ไม่สบายใจหรอครับ เรื่องอาเมลน่ะ”

“อือ”เธอตอบรับแล้วก้มหน้าลง

ก่อนที่โรห์จะเอ่ยต่อ
“ผมเชื่อว่าเขาต้องไม่เป็นอะไรแน่นอนครับ”

ตามด้วยเสียงของภูติตัวจิ๋วซาเน่เอ่ย
“ค่ะ เพราะคุณโรห์บอกว่าจะช่วยตามหาเค้าให้ได้คะ”
และทามาเอะก็พูดต่อทันที
“ใช่แล้วล่ะ ยังไงก็เชื่อใจพวกเราเถอะค่ะ”

“ขอบคุณนะโรห์ ทุกคน” หญิงสาวหันมาก่อนจะเอ่ยเสียงที่อ่อนหวานและแผ่วเบา

เมื่อได้ฟังแล้ว นัยน์ตาสีฟ้าหันมาสบตาหญิงสาวตรงก่อนจะเอ่ยอย่างแผ่วเบา
“พูดอะไรน่ะครับ พี่เนสตี้เหนื่อยมามากแล้ว ไว้เป็นหน้าที่ของพวกเราเอง”

เด็กชายผมม่วง เอล ยิ้มออกมาก่อนจะเห็นด้วย
“ใช่แล้วล่ะ”

ก่อนเด็กสาวข้างๆจะเอ่ยขึ้นต่อ
“พวกเราจะช่วยเหลือพี่เองนะคะ ตอบแทนที่ให้พวกเราอยู่”

หญิงสาวผมแดงตรงนัยน์ตามองเหล่าพวกเด็กๆตรงหน้าอย่างเป็นห่วงก่อนที่จะเปรยออกมา
“จ้า ขอให้เดินทางปลอดภัยนะทุกคน ขอบใจมากจ้า!! แล้วกลับมาก่อนค่ำนะ”

ตามด้วยคำกล่าวของโรห์
“ครับ ต้องกลับมาแน่ พี่ก็รักษาตัวด้วยนะครับ”

แล้วทุกคนก็ลาเนสตี้ออกมาแล้วเดินทางมุ่งไปทางเหนือเข้าป่าไป

ผ่านไปได้สักพักเมื่อเดินเข้าป่าแสงอาทิตย์สาดส่อง เป็นหย่อมๆพลางมีร่มเงาตามใต้ต้นไม้ทืบๆ
ตามด้วยเสียงเอ่ยของเด็กผู้ชาย
“เอ๋! ป่านี่ดูแปลกๆอยู่นะป่าเขตภูเขาหรอ”

“อือ ก็ทำนองนั้นแหละมั้ง นี่คือป่าโทวาน่า”อากิระกล่าว แล้วเดินนำหน้าไป

ตามด้วยเสียงเอ่ยของเด็กผู้ชายเจ้าของแววตาสีฟ้าผมเหลือง
“ว่าแต่เอล นายน่ะ จะเดินทางไปเมืองหลวงแต่ระหว่างทางมาที่นี่มีแม่น้ำ ภูเขามากมาย แล้วผ่านมาได้ยังน่ะ ฉันยังไม่ถามเรื่องของนายละเอียดซักทีเลย”
“เอ่อ~ ที่จริงแล้วพวกเรากำลังเดินทางด้วยยานเหาะแล้วก็ถูกพวกโจรโจมตี ทำให้เราต้องออกเดินทางแบบนี้ไงล่ะ”

“หา! จริงหรอ แย่จังนะ แล้วนายจะเดินทางต่อไม่ใช่หรอ”โรห์กล่าวถามขึ้นอย่างสงสัย

ตามด้วยเสียงเอ่ยขึ้นของเด็กสาว
“ใช่ แต่พวกเราทิ้งพี่มาค่าไปไม่ได้หรอก”
“ใช่แล้วล่ะ พี่เค้าเป็นผู้มีพระคุณกับเรามาก”เอลหันมากล่าวเห็นด้วย

ก่อนที่โรห์จะเอ่ยเล่าต่อพลางหยุดชะงักขึ้นมาถาม
“พูดถึงผู้มีพระคุณนะ อาจารย์แม็กน่าก็เลี้ยงดูฉันมาตลอด เอ๋! จริงสิ แล้วบ้านพวกนายเป็นยังไงบ้าง พ่อ แม่พวกนายล่ะ”

“แม่พวกฉันเป็นนักโบราณคดีน่ะ พูดถึงแม่แล้ว ป่านนี้จะเป็นยังไงบ้างนะ”เด็กชายผมม่วงกล่าวแล้วพลางครุ่นคิด

“เอ๋! ตอนนี้แม่นายเป็นนักโบราณคดีหรอ”โรห์กล่าวถาม
“ใช่แล้วล่ะ ฉันชอบแม่ฉันมากเลย แต่ไม่ค่อยอยากอยู่กับเค้าบ่อยๆหรอกนะ ไม่งั้นมีหวังฉันได้คะแนนเต็มวิชาประวัติศาสตร์แน่ๆเลย พูดถึงเค้าแล้ว แม่ชอบเล่าเรื่องต่างๆให้ฉันฟังเรื่อยเลย”เอลกล่าว

เมื่อตอนอดีตเอลตอนอายุ 10 ปี
ในห้องสมุดชั้น 3 บ้านทอเรียส
