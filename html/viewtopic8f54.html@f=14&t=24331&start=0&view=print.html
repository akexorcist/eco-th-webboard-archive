เอาจอบ 50 ไปเรยครับ
ผมเองก็เล่นเฟนเซอนะ เข้าใจว่าสกิวมันไม่น่าสนใจแล้วก็รู้ด้วยว่าสกิวที่ใช่จิง ๆ มีแค่ Banishbow แต่เล่นจอบ 50 ไปเหอะ เอาพอยเยอะ ๆ ไว้อัพสกิวติดตัสก็ได้ครับ หรือเอาสกิว + ป้องกันก็ได้ เพราะอีกหน่อยเราได้ลากมอนกันแน่ ๆ ครับ แล้วผมมีเรื่องอยากบอกว่า

การเปลี่ยนก่อน จอบ 50 ไม่ได้ช่วยอะไรท่านเรยในการเก็บเวลเพราะถ้าท่านเปลี่ยนก่อน โบนัสท่านจาหายไป อ่อนไปซักพักนะ แล้วไนท์โบนัสมันมีแต่ vit ครับ เปลี่ยนแล้วระวังตีไม่แรงนะ แล้วไนท์ก็มีสกิวดี ๆ ตอนช่วงหลัง ๆ ( อันนี้อ่านข้างล่างนะว่าทำไมไม่ดี ) แถมที่สำคัน เปลี่ยนก่อนเราก็แค่เลือดเพิ่ม กะตีลดมานิดหน่อย ไม่มีไรดีเรยครับ รอจอบ 50 ค่อยเปลี่ยนเหอะ จาได้ไม่เสียใจวันหลัง ทำวันนี้ให้ดีที่สุดครับ

อีกเหตุผลที่ให้เปลี่ยนจอบ 50 ก็คือ จอบ 2 มันเก็บเวลยากครับ เปลี่ยนไปก่อนจอบก็ขึ้นยากสกิวได้ช้า รอเวลเยอะ ๆ ดีก่าตีมอนเก่ง ๆ สกิวจาได้ขึ้นไวอีกนิดนึง ( มันนิดเดียวจิง ๆ )
