ผมเด็กใหม่อยากจะขอคำปรึกษาหน่อยคัฟ

โพสต์แล้ว: พุธ 04 ก.พ. 2009 7:47 pm
โดย ECO
ที่ผมตั้งกระทู้ถามไม่ใช่ว่าผมไม่ได้ไปลองหาข้อมูลมาเลยนะคับผมนั่งอ่านหาข้อมูลมา2วันแล้วยิ่งอ่านมากก็ยิ่งมีคำถามเข้ามาในหัวมากมายT_Tคำถามที่ผมสงใสมากที่สุดเลยตอนนนี้ก็คือ

1. Warlock-->>Kabbalist-->>Necromancer อ่านมาหลายกระทู้เห็นเค้าบอกWarlockไม่ค่อยจะเก่งเล่นก็ยาก <<< แต่คำพวกนี้ผมไม่ค่อยจะสนใจเท่าไหร่เพราะอันนี้ผมเข้าใจอาชีพแต่ละอาชีพมันสร้างมาเพื่อหักล้างกับอีกอาชีพหนึงไม่มีอาชีพไหนเก่งสุด แต่พออ่านไปเลื่อยๆก็ไปเจอกระทู่นึงที่ทำให้ผมคิดหนักก็คือมอนเตอร์หลังๆจะมีมอนเตอร์ ธาตุมืด,แสงเยอะ ซึ่ง Warlock ใช้เวทลงใส่พวกธาตุสองอันนี้ไม่ค่อยจะแรง ( หลังๆจะมีมอนเตอร์ ธาตุมืด,แสง เยอะจิงเปล่าคัฟ )

2. FIGHTER >>SPELL USER >>BACKPACKER ผมอยากทราบว่าอาชีพไหนสายไหนเก็บเวลสนุกๆมั่งคับ ที่จิงก็อยากจะเล่น Vates เพราะเล่นมาทุกเกมก็ถนัดพวกสายซัพพอทเพื่อนมากกว่า มาติดตรงที่กัวหาตี้ยากเลยอยากจะเปรียนมาเล่นสายโจมตีแทนเลยไม่ค่อยจะมีความรู้สายโจมตีซักเท่าไหร่ T___T

ปล.คำถามที่1ผมไม่ได้ตั้งมาให้ทะเลอะกันนะคับเห็นมาหลายกระทู้แล้วผมแค่อยากจะทราบเฉยๆเท่านั้นเองคัฟว่าเวลยากจริงไหมหลังๆน่ะ

พิมมาซะเยอะเลย ~>_<~ ยังไงก็ขอขอบคุณที่เสียเวลามาอ่านนะคับแล้วก็ขอบคุณทุกคำชี้แนะที่ให้กับผมด้วยคัฟ
