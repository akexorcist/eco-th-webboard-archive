9สิ่งที่ไม่ชอบ คือ ไม่ชอบคนโกหกกับคนคดโกง
10 เป็นคนที่ไม่เคยยอมใคร ถ้าคิดจะทำอะไรก็จะทำให้สำเร็จไม่ว่าจะยากแค่ไหน

ลักษณะนิสัย : หากจะกล่าวว่าความชั่วร้ายบนโลกนี้คืออะไรกัน ? คงได้แต่บอกว่ารูนคือสิ่งเหล่านั้น ตัณหา ราคะ ความโลภ เธอคือศูนย์รวมของทั้งหมด ลักษณะนิสัยของรูนนั้น เธอเป็นคนที่ชอบเห็นความตาย และความหายนะของผู้คน หรือแม้กระทั่งโลกนี้ เธอปรารถนาให้โลกนี้เต็มไปด้วยสงคราม และการฆ่าฟัน นั่นแหละคือสิ่งที่เธอต้องการ เธอเป็นคนที่มั่นใจในฝีมือของตนเองอย่างสูง และมีความมั่นใจกับทุก ๆ เรื่อง เธอชอบพูดจาเหยียดหยามคนอื่น สำหรับเธอแล้ว ‘คนอื่น’ ก็เปรียบเสมือนกับสิ่งมีชีวิตไร้ค่าเท่านั้นเอง เธอนิยมชมชอบกับการทำลายสิ่งสำคัญของผู้อื่น ไม่ว่าจะเป็นของรักของหวง หรือแม้กระทั่งคนในครอบครัว เสียงกรีดร้องยามโหยหวนเมื่อเหยื่อสูญเสียสิ่งที่รักยิ่งไป ไม่ต่างอะไรกับดนตรีอันแสนไพเราะที่เธอนิยมชมชอบ รวมแม้แต่เสียงร้องขอชีวิตที่เธอมิเคยมอบให้ผู้ใดก็ด้วยเช่นกัน


เธอชอบการวางแผน และนึกถึงความหายนะ สิ่งที่เธอชื่นชอบมากที่สุดและเหนืออื่นใด คือกองซากศพที่กองเป็นภูเขา โดยที่เหยื่อบางส่วนยังมีชีวิตและร้องโหยหวนอยู่นั่นเอง รูนมักจะชอบหลอกใช้คนอื่น และจัดการทิ้งในภายหลัง แต่แม้กระนั้น ก็ใช่ว่าเธอจะไม่มีคนที่เธอไว้ใจ เธอมักจะเลี้ยงคนที่มีฝีมือเอาไว้ และพร้อมที่จะพลีกายเพื่อผู้เป็นนาย เธอมักจะเรียกซากศพทั้งหลายว่า ‘ศิลปะ’ เพราะว่าสำหรับเธอแล้ว ทำให้เธอรู้สึกจรรโลงใจเหลือเกิน ความปรารถนาอีกอย่างของเธอคือการยึดครองทุกสิ่ง ... และกำจัดพวกไร้ประโยชน์ให้หมดไปจากโลกนี้ สายของเธอนั้นมีอยู่ทั่วไป เธอมักจะใช้สายของเธอทำให้เกิดการแตกแยกภายใน และเกิดเป็นสงคราม ... ที่เธอแสนจะชื่นชอบ


ในยามว่างของรูนนั้น เธอมักจะใช้พลังของเธอบังคับซากศพให้มากัดกินกันเอง โดยที่เธอจะนั่งจิบเลือดที่ต้องคั้นมาจากหญิงสาวที่ยังเป็น ๆ อยู่เท่านั้นไปด้วยอย่างสบายใจ หรือไม่ก็หาเหยื่อซึ่งจะไม่พ้นหญิงสาวหรือเด็ก ๆ มาให้วิ่งหนีผีดิบกระหายเลือดอย่างเอาเป็นเอาตาย โดยมีเธอยืนมองด้วยความสนุกสนาน ... ในการต่อสู้ เธอจะไม่รู้จักคำว่าเมตตา เธอรู้จักอยู่เพียงคำเดียวเท่านั้น นั่นคือ ‘ทรมาน’ ... เธอไม่เคยที่จะปลิดชีพเหยื่อในทันที แต่เธอจะทรมานให้สาสมแก่ใจเธอก่อนเท่านั้น เธอถึงจะจัดการเหยื่อของเธอซะ


ลักษณะร่างกาย : สูงราว 165 ซม. หนัก ... ไม่บอก รูนนั้นเป็นคนที่จัดว่าหน้าตาดีทีเดียว ผิวของเธอนั้นขาวนวลไร้มลทินใด ๆ และจะดูยิ่งมีเสน่ห์ ? ( ตรงไหน ? ) ยามที่ผิวขาวนวลนั้นถูกย้อมไปด้วยเลือดสีแดงฉาน เธอมีเรือนผมยาวสลวยดีน้ำเงินทึบ ผมของเธอนั้นยาวจนถึงเกือบบั้นท้าย ดวงตาสีน้ำเงินเข้มนั้นดูลึกลับและน่าค้นหา หากแต่มองดี ๆ จะเห็นความน่ากลัวและความต้องการฆ่าอย่างสูงในดวงตาคู่นั้น ริมฝีปากบางสีกุหลาบดูราวกับดอกไม้แรกแย้มที่น่าค้นหา


ลักษณะการแต่งกาย : การแต่งกายของรูนนั้นจะกล่าวถึงสองแบบ คือยามที่เธอจะอยู่ในและนอกที่พำนักของเธอ ยามที่เธออยู่ในปราสาทของเธอนั้น เธอมักจะอยู่ในชุดเกาะอกที่บางและเบาสบายสีดำออกแนวโลลิโกธิค ( อย่างในรูป ) และใส่เพียงกงเกงในผ้าไหมสีดำตัวเดียว หรือไม่ก็ผ้าบางสีดำที่ผูกไว้รอบเอวเท่านั้น ที่แขนทั้งสองข้างของเธอนั้นจะสวมถุงมือผ้าไหมสีดำเอาไว้ด้วยเช่นกัน


ส่วนเครื่องแต่งกายอีกแบบนั้น คือยามที่เธอออกจากปราสาทของเธอ ไม่ว่ายามศึก หรืออะไรก็ตาม เธอจะสวมแบบเดียวกันตลอดคือจะสวมเสื้อเกาะอกสีดำสนิทพร้อมกับกางเกงผ้าสีดำยาว รองเท้าบูทแบบส้นสูงที่ถูกออกแบบมาให้แข็งแกร่งโดยการติดแผ่นเหล็กเอาไว้ที่ส้นเท้าและปลายเท้า และที่ส้นเท้านั้นก็มีกลไกคือใบมีดคมกริบที่ถูกลับออกมาอย่างดี เข็มขัดของเธอนั้นจะเป็นเข็มขัดหนังสีขาวสองเส้นที่จะสวมแล้วไขว้กันมาติดกันที่หัวเข็มขัดสีเงินเงียบตรงกลาง จากนั้นรูนจะสวมทับทั้งหมดด้วยเสื้อโค้ทสีขาวแขนยาวคอปกตั้ง ซึ่งยาวจนถึงบริเวณตาตุ่มเลยทีเดียว โดยข้างในเสื้อโค้ทนั้นเธอซ่อนมีดสั้นที่ใช้เขวี้ยงไว้สิบเล่มเพื่อเป็นอาวุธลับอีกด้วย ส่วนที่แขนทั้งสองข้างนั้น เธอจะสวมถุงมือหนังสีดำยาวถึงศอก และโผล่นิ้วออกมาได้ไว้ทั้งสองข้าง ก่อนจะสวมเกราะแขนสีเงินทับเอาไว้อีกที ซึ่งตัวเกราะแขนนี้ก็ยาวถึงศอกเช่นกัน และเมื่อสะบัดแรง ๆ จะสามารถงัดใบมีดตรงข้อศอกมาใช้ได้อีกด้วย และเอกลักษณ์อย่างนึงที่สำคัญของรูนนั่นคือ ‘หน้ากาก’ เธอจะสวมหน้ากากสีขาวสนิทไว้ที่ครึ่งหน้าด้านซ้ายตลอดเวลา ( เปิดเพียงแต่ลูกตา ) และที่บริเวณแก้มของหน้ากากนั้นจะมีรอยสลักสีดำเป็นรูปกุหลาบเอาไว้ด้วยเช่นกัน ดังนั้นจึงมีคนเรียกเธอว่า ‘Nero Rose [ กุหลาบดำ ]’


สิ่งที่ชอบ : เลือด , ความตาย , สงคราม และเสียงกรีดร้องของผู้คน

สิ่งที่ไม่ชอบ : ครอบครัวที่มีความสุข , รอยยิ้ม และผัก ...


อาวุธ : Bianco Esecutore [ เบียงโกร์ ] ดาบคู่ใจของรูน ... เป็นดาบที่แปลก เพราะว่าส่วนปลายของคมดาบที่ควรจะเป็นปลายแหลมนั้นกลับกลายเป็นลักษณะมนคล้ายกับไม้ไอติม และที่น่าแปลกกว่านั้น คือตัวดาบทั้งเล่มนั้นกลับเป็นสีขาวสนิท ตามชื่อของมันที่แปลว่า ‘เพฌรฆาตสีขาว’ เป็นดาบที่ถือว่ายาวมากทีเดียว เฉพาะตัวคมดาบนั้นก็ยาวเกือบสองเมตรแล้ว และตัวด้ามนั้นก็ยาวราวฟุตนึงเลยทีเดียว


ความสามารถพิเศษ :

- Diavolo Della Notte [ Devil of The Night ] : ด้วยความสามารถนี้ของรูน ทำให้ความสามารถยามค่ำคืนของรูนนั้นพุ่งสูงมากขึ้นไปอีก ทั้งความแข็งแกร่งและความรวดเร็ว อีกทั้งเธอสามารถที่จะกลืนกินไปกับความมืดได้ ทำให้เธอเป็นนักฆ่าที่น่ากลัวอยู่มากทีเดียว

- Carnefice [ Executioner ] : ความสามารถนี้ของรูนนับว่าเป็นความสามารถของรูนที่น่ากลัวมาก เมื่อเธอใช้คู่กับดาบประหารเบียงโกร์ จะทำให้คมดาบของเธอนั้นพุ่งเข้าใส่ลำคอของเหยื่ออยู่ตลอดเวลา ! และยิ่งถ้าเป็นยามค่ำคืนแล้วด้วย จะไม่มีใครรอดพ้นจากคมดาบประหารของซิลเวียได้ ...


ประวัติตัวละคร : รูนนั้นตอนเด็ก ๆ นั้นก็เป็นแค่เพียงเด็กน้อยธรรมดาคนนึงเท่านั้น เธออาศัยอยู่ในหมู่บ้านที่เต็มไปด้วยความสงบสุข จนกระทั่งเธออายุราวแปดขวบ เธอไปเล่นในป่า ก็พบกับดาบสีขาวเล่มโต ที่เธอรู้สึกหลงใหลตั้งแต่แรกที่เห็น เธอพยายามลากมันกลับมาที่บ้าน หากแต่ว่ามันหนักจนเธอไม่อาจจะทำได้ เธอจึงตามพ่อกับแม่ของเธอมาดู ฉับพลันแสงสว่างจ้าก็ปรากฎและอาบร่างของรูน ตอนนั้นเองที่เธอรู้สึกอบอุ่นอย่างประหลาด ... พอเธอรู้สึกตัวอีกที เธอก็รู้ว่าความอบอุ่นที่เกิดเมื่อครู่นั้น คือโลหิตของบุพการีของเธอนั่นเอง ! แต่น่าแปลกนัก ที่เธอไม่รู้สึกเศร้าเลยแม้แต่น้อย ที่จริง เธอกลับรู้สึกดีด้วยซ้ำ ... ดาบสีขาวที่ตอนแรกนั้นหนักอึ้ง ตอนนี้กลับกลายเป็นเบาจนเธอสามารถถือได้อย่างสบาย ...


เธอเดินฮัมเพลงพร้อมกับแบกดาบเดินเข้าไปในหมู่บ้าน ... และเพียงแค่คืนเดียว ทั้งหมู่บ้าน ... ก็ถูกลบออกไปจากแผนที่โลกอโครเนีย ...


เธอไม่รู้เธอจะทำยังไงต่อดี เธอจึงออกเดินทาง ... และฆ่า ฆ่า ... น่าแปลกที่พัฒนาการของเธอนั้นรวดเร็วมาก เธอสามารถวิเคราะห์สถานการณ์ต่าง ๆ ได้อย่างแม่นยำ อีกทั้งยังสามารถวางแผนอันชาญฉลาดได้ จนตอนนี้เธอเริ่มที่คนที่เข้ามาภักดีกับเธอ ... ปัจจุบันนี้ ... เธออยู่ในปราสาทสีดำสนิทที่ตั้งอยู่ในหุบเขาลึก ... กาลเวลาเปลี่ยนแปลงทุกสิ่งบนโลกนี้ เปลี่ยนแปลงแม้แต่ความกระหายเลือดและความบ้าคลั่งของเธอ ... หากแต่ว่า ...
