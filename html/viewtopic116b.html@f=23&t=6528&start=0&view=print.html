http://www.usamimi.info/~kudryavka/eco/wiki/index.php?Tool%2FMrbViewer

^^ ไว้แต่งตัวละครได้เลย มีรูปมอนเตอร์ NPC Marrionette ด้วยคับ
อาจจะผิดบ้างเน้อ *0* บอกได้คับ แต่บางอันก็มะมี เช่น พ่อค้าไม่รองเท้า - -
อีกอย่างเยอะเกินเลยมึนๆ อาจมีผิดบ้างคับ อิอิ

โหลดนี่ไปละกันคับ จะได้ไม่งง

http://www.upload.th.la/download.php?id=C78DF72F7

วิธีใช้ กดเข้ามาก็หา Folder ECO เลยครับ แล้วไปงมต่อเอาเองน้า ไอเท็มเป็นร้อยฃิ้น ^^

• ชื่อไอเทมมาจากตัวเกมส์ไทยหละคับ บางอันอ่านไม่รู้เรื่อง ก็คงเพราะ ตัวเกมส์ยังไม่สมบูรณ์
• ชื่อชุด ชื่อเสื้อผ้า ต้องนั่งงมเอาเองครับ มันอยู่ตรงไหน^^
• มีมอนเตอร์ NPC Furniture Marionette ด้วยคับ ลองงมๆ ดู
• มีวิธีเปลี่ยนสี Backgroud ด้วยนะคับ อยากรู้ก็ลองถามดูครับ
• เตื่อนนิดนึงครับ โปรแกรมนี้รันเหมือนกะ เราใช้ โปรแกรม พวก 3D สั่ง Render เลยครับ เช่น 3D Max, Maya อาจจำให้ค้างได้ บางกรณีถ้า Spec ต่ำ
• ขอให้สนุกกับการหาครับ ^^ งมให้เจอกันนะ บางทีเจอตัวน่ารักๆ เต็มเลย

เด๋วลงของผู้ ญ ให้นะ
