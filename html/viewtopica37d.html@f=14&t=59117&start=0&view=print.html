ว่าจะไม่ตั้งถามล่ะ แต่ถามในกระทู้แอสแ้ล้วก็ไม่ได้คำตอบใดๆ

สกิล Land Mine ของ commando นั้น ใช้ระเบิดแบนๆ สีเขียว Mine [For Land Mine]
อันนี้ไม่แปลก

แต่คราวนี้ ผมลองอัพ Claymore Trap โดยที่ในตัวผม มี Land Mine[For Claymore Trap]
ที่เป็นรูปคล้ายๆ ถังน้ำมันสีดำ ...

พออัพไปที่เวล 1 กดใช้ ไม่ติด ก็แปลกใจ (เฮ้ย เราก็มีกับดักแล้วนิ ทำไมใช้ไม่ได้)
ก็เลยคิดว่า อาจจะวางระเบิดในเมืองไม่ได้ ก็เลยลองลงดัน 70ไป

มากดใช้อีก ก็ยังไม่ได้อีก


สรุปว่า เป็น BUG หรือว่า จริงๆ แล้ว ให้ใช้ระเบิดสีเขียวแทน ?!?
[**ไปลองมาแล้ว ใช้สีเขียวจริงๆ ด้วย แล้วจะมีไอ้ระเบิดถังไว้ทำแพะหรอ? ]

จนตอนนี้ทำให้ผมคิดว่า สกิล Flash HandGrenade
ที่น่าจะใช้ ระเบิดมือ ที่เป็นรูปน้อยหน่า และมีชื่อว่า Flash Grenade
กลับใช้ ลูกระเบิด แกสน้ำตา ของ Gunner ซะงั้น ?!?
[ แล้วมันจะมีไอ้ระเบิดมือ มาให้ทำไม ถ้าใช้ลูกปืนของ Gunner อ่ะ ]


สรุปแล้ว มันเป็น BUG หรือ "จงใจ" ให้ใช้ของพวกนั้นอยู่แล้วกันแน่
แล้วทำไมคำอธิบายสกิล มันบอกใช้อย่างนี้ แต่ใช้จริง กลับใช้อย่างอื่น

(ไ่ม่แปลกใจเท่าไหร่ เกี่ยวกับการแปล ขนาดสกิลธนูฮีล ยังมั่วได้ใจ)
(เกมส์อื่นเค้าแปลดีหมด คนเล่นจะอัพอะไรก็อัพได้ถูก เกมส์นี้ ต้อง"ลองเอง" สินะ)

ปล. บอร์ด Fighters คนน้อยกว่ากระดานสนทนาจริงๆ สินะ
ปล2. อยากรู้อะไร ต้อง "ลอง" เอง สำหรับเกมส์นี้ ไม่เหมือนแร็คที่มีข้อมูลจากเว็บหรือ
หนังสือ ro club , ro new ที่เอามาบอกว่าดีหรือไม่ดีอย่างไร

ปล3. ผมมันจนครับ เงินจะเติมซื้อยารีสกิลยังไม่มีเลย แต่ก็อัพไปซะแล้ว ช่างมัน...

ที่ผมไม่ค่อยพอใจก็คือ "ระบบคำอธิบายสกิล"

บอกว่าใช้ไอนี่ แต่พอใช้จริง กลับใช้อีกอย่าง
ทำให้เสียเวลาไปล่าไปหา นั่งรับมา เพื่อลองใช้ (ถ้ารู้ว่าเป็นระเบิดเขียวคงรับไปเป็นร้อยล่ะ)

ถ้ามีเถื่อนจะว่าไปอย่าง จะได้ไปลองสกิลว่าเป็นอย่างไร น่าอัพหรือไม่

แต่เอาเถอะ ไม่แก้ก็ไม่เป็นอะไร แต่เกรงว่า ไปรับ Land Mine มาซะเยอะ พอจะใช้ กลับแก้ไข
