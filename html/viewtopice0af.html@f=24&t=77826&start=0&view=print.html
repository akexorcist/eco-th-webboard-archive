อยู่ ทาโกะครับ แต่ไม่ค่อยมีเวลาเนี่ยสิครับ เลยนัดกับใครแล้วไปทำด้วยไม่ทันทุกที (3 รอบแล้ว ที่แป้ก)
แถมมีตัวที่อยากพาไปรวมกัน 3 ตัว ซะอีก งั้นขอถามหน่อยละกันครับ ถ้า 3 จอ มี เบลด พระ กับ ซอเซอร์เรอร์
เลเวล 97 up ทุกตัว พอจะฟัดกับมังกรไหวรึเปล่าครับ ความเร็วในการเปลี่ยนจอกดสกิล ของเราพอจะเร็วอยู่เหมือนกัน

แต่ติดตรงที่ ต้องเก็บ ไอเทมจากลูกโยนใส่ัตัว แม่เนี่ยสิโยนครั้งหนึ่งตัวแม่มันจะวิ่งเข้ามานานไหมครับเนี่ย
อีกข้อ ตัวลูกมัน ตี ออโต้ รึเปล่าครับ

จริงๆแล้วอยาก เอา เอกโปเรอร์ ไปด้วยแต่ดันอยู่ id เดียวกับเบลดเนี่ย สิ T_T (ไม่มีตัวทำดาเมจ)
