...แบบนี้แน่ๆใช่เปล่าครับ..กว่าจะได้ชุดใบเรือ...^.^

Rotary Sail Set = Rotary Sail 6ใบ > สร้างโดย NPC Flying Garden ที่ Map Fareast Highway

Rotary Sail > ใช้สกิล Item Refine Lv.3 ในการสร้าง ประกอบด้วย:

- Log 1 ท่อน
- Water Proof Fabric 5 ผืน
- Wood 5 ชิ้น (ซื้อได้จาก NPC ขายเฟอร์นิเจอร์)
- Great Strap 5 เส้น

Water Proof Fabric > ใช้สกิล Sew. Create Lv.4 ในการสร้าง ประกอบด้วย:

- Greater Cloth 1 ผืน (เท่าที่รู้มี ดรอปจากหุ่นไล่กา ที่ดันฟาอีส)
- Row 4 ชิ้น

Great Strap > ใช้สกิล Sew. Create Lv.2 ในการสร้าง ประกอบด้วย:
- Great Thread 4 หลอด (สามารถซื้อได้จากร้านคุณป้าเย็บปักถักร้อยที่เมืองเหนือ ^.^)

Great Thread > ใช้สกิล Sew. Create Lv.2 ในการสร้าง ประกอบด้วย:
- Thread 1 หลอด
- Row 1 ชิ้น

...สรุป...ไอเท็มที่จำเป็นต่างๆทั้งหมดเพื่อสร้าง Rotary Sail Set ก็น่าจะเป็น

- Log 6 ท่อน
- Water Proof Fabric 30 ผืน = ( Greater Cloth 30ผืน + Row 120ชิ้น )
- Wood 30 ชิ้น
- Great Strap 30 เส้น = Great Thread 120 หลอด

...เออ...ค่อยง่ายก่าแบบแรกมาหน่อยนะ ^.^'

...แล้วของที่เหลือนี่อะไรหาซื้อจากNPCที่ไหนได้...รึดรอปจากมอนตัวใดที่ไหนบ้างก็ช่วยทีนะครับ...ช่วยบอกเราหน่อย

ขอบคุณครับ ^.^

ปล. รายละเอียดนี้ได้มาจากร้านค้าในเมือง อโคเนีย ครับ หุๆๆ โดยแกะดูจาก Recipe ของใบเรือที่วางขาย อิๆๆ...และซอยย่อยลงไปถึงว่ามานมายังไงถึงประกอบเป็นใบเรือได้ (เพื่อนหลายคนอาจรู้แล้วก็ได้...แหะๆๆ) แล้วมาลองคิดคำนวณดูเอา ^.^v
