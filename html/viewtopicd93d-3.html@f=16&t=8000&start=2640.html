สวัสดีเรนเจอร์ทุกท่าน พอดีจะเล่นเรนเจอร์สายประหลาดเลยมาถามว่ามันจะไปรอดไหมครับ

ไม่ต้องดีนะ ชอบเป็นการส่วนตัวจริงๆ

1. ใช้มีด เซ้งมาจากสเกาท์ สายผสม แบบ STR>AGI=VIT>DEX

2. ไม่ใช้แส้ อัพกับดักแทน(บางอันก็ไม่อัพ)

ISSH 5

สูตร 1 Passive HPMAX + SPMAX
สูตร 2 กับดัก Pittrap+Glasstrap
สูตร 3 dmg Blow +Glass trap
สูตร 4 ผสม HPMAX+ Blow

พอ 50 เล่น TH ก่อนเอา Lucky + Code break + Unlock Mas มา

EX Skill

ยังไม่คิดแต่อัพกับดัก 3 สกิลนั้นแน่ๆ

----------------------------------------------------------------

ถามว่ามันเล่นรอดไหมครับ ขอแค่เก็บของส่งเควสได้เองก็พอ ไปช้าหน่อยก็ไม่เป็นไร

ถ้ายากแต่ไม่ถึงกับไม่รอดก็จะเล่นสายนี้ละครับ อ้อ

- 2 สกิลที่เหลือผมเลือกสูตรไหนดีครับ
- ไม่มี HPMAX มันมีผลมากไหมครับ
- กับดักของ EX ใช้ LHit จริงหรือเปล่าครับ
