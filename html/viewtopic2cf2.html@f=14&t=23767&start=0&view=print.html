สกิลดีๆเกี่ยวกับอาวุธขว้าง อยู่ที่สเกาท์กับแอสซาซินหมดเลย
ถ้าพูดกันจริงๆ คอมมานโดนั่นแหละ ที่ไม่มีสกิลสายขว้าง แต่เป็นสายปืนพกแทน ซึ่งใช้กับสายขว้างไม่ได้
---------------------------

กลับมาเข้าเรื่อง ตอบเจ้าของกระทู้

Stat ที่แนะนำ
Str > agi > int(รวมโบนัส int ให้ได้ 30 ก็น่าจะพอแล้ว)

*ความเห็นส่วนตัว คิดว่าน่าจะอัพ str ให้เยอะหน่อย เพราะอาวุธขว้างมันทั้งแพงทั้งหนัก แต่ละอันควรจะโยนให้คุ้ม

Skill แนะนำ
Scout
- Continue Throw
เลเวลห้า จะขว้างต่อกันหกครั้ง ที่ความแรง 120% ถือเป็นท่าหากินเลย
แต่มีข้อเสียคือร่ายนาน (เลเวลห้าจะร่าย 2.5 วิ) ควรจะมี agi ไว้ลดเวลาร่ายและดีเลย์มากพอสมควรถึงจะใช้ได้อย่างมีประสิทธิภาพ
- Throw mastery
- Summersault kick
มีประโยชน์มากๆเวลาถูกประชิดตัว ใช้เตะศัตรูออกไปไกลๆแล้วยังค้างอีกแป๊บนึงให้เราเอามีดปาหัวมันฟรีๆ

*นอกนั้นแล้วแต่ชอบ อาจอัพสกิลมีดไปด้วย เผื่ออาวุธขว้างหมด จะได้เอาตัวรอดได้
*อาจอัพ Sp max หรือ Sp recover ไปด้วย จะได้ใช้ท่าได้บ่อยๆ แต่อันนี้ก็แล้วแต่ความถนัดเหมือนกัน

Assasin
- Increase Throw range เพิ่มระยะปาอาวุธ เลเวลละช่อง สูงสุดที่เลเวลสาม
- อัพ Increase Throw hit ถ้าคิดว่าความแม่นไม่พอ แต่ไม่อยากอัพ int เพิ่ม
- อาจอัพ Throw Create เพื่อเอาผลแฝงของสกิล ที่ทำให้เวลาขว้างบางครั้ง จำนวนอาวุธขว้างที่มีจะไม่ลดลง

*สกิลที่เหลือ เลือกอัพได้ตามใจชอบเหมือนกัน
*สกิล Utsusemi (จักจั่นลอกคราบ) ถือว่าน่าสนใจ แต่ผมยังไม่เคยลองด้วยตัวเอง ขอข้ามไปนะ

:เปลี่ยนเป็นคอมมานโดจะดีรึเปล่า:
ถ้าไม่คิดจะเปลี่ยนไปใช้ปืน ก็ยังพอจะมีสกิลที่พอใช้สนับสนุนสายอาวุธขว้างอยู่บ้าง
เพราะสกิลสายกับระเบิด จะคิดความแม่นยำตามอาวุธที่ถือในตอนนั้น จึงไม่น่าเป็นห่วงเรื่องความแม่น
แต่ทั้งนี้ทั้งนั้น ต้องไม่ลืมว่า สกิลสาย Martial art (summersault uppercut tackle combination ashibarai) นั้นเป็นการโจมตีประชิด ซึ่งอาจจะวืดได้เสมอ ถ้าคุณไม่ได้อัพ dex เลย
