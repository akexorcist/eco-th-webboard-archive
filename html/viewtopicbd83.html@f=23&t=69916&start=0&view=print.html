ตามชื่อกระทู้เลยค่ะ

ถ้าหากนำ ไอเทมดาว ไปหลอมอีกทีให้เป็น ไอเทมแสดงภาพ

แล้วการแสดงภาพของไอเทมทีได้

จะเป็น ภาพ หรือ ความสามารถ ของไอเทมดาวคะ

ขอบคุณล่วงหน้านะคะ

โพสต์แล้ว: เสาร์ 07 พ.ย. 2009 9:54 pm
โดย ECO
ไอเทมที่เคยนำมาหลอมแล้วสามารถหลอมซ้ำอีกเท่าไหร่ก็ได้ครับ

และสามารถหลอมเป็นแสดงความสามารถ หรือ โชว์ภาพก็ได้ครับ

โพสต์แล้ว: เสาร์ 07 พ.ย. 2009 11:35 pm
โดย ECO
ถ้า หลอมหูหมาดำเป็นแสดงภาพ กับหมวกคาบาลิสเป็นความสามารถ

แล้วเอาไปหลอมเป็นแสดงภาพอีกที จะได้แสดงภาพเป็นอะไรค่ะ



ภาพยังเป็นหูหมาดำเหมือนเดิมรึเปล่าคะ หรือเป็นหมวกคาบาลิส
