BOUNTY เขียน:1. ในกรณีมอนที่มีธาตุอยู่แล้ว (ดิน น้ำ ลม ไฟ มืด) ถ้าผมใช้ Holy Up ใส่ มันจะเปลี่ยนไปเป็นธาตุแสงไหม?
ขึ้นอยู่กับธาตุของมอนว่าสูงกว่าธาตุที่ตัวเองใส่ไปไหม ที่สกิลเวล 5 ส่งผลค่าธาตุ 50
ถ้ามอนมีธาตุอื่น น้อยกว่า 50 ก็โอเค ซึ่งมอนส่วนใหญ่มีไม่ถึง 50 หรอก

(ทั้งผู้เล่นและมอน สามารถแสดงผลธาตุที่มีค่ามากที่สุดได้เพียงธาตุเดียวเท่านั้น
ถ้ามีธาตุเท่ากัน ให้นับธาตุด้านซ้ายของตาราง element)

2. ถ้าผมใช้สกิล Holy Up ใส่มอน แล้วเอาอาวุธที่มีธาตุติดมา (เช่น ดาบลม 60 ดาบไฟ 90) จะตีมอนแรงขึ้นไหมครับ?
(เทียบกับเมื่อใช้อาวุธปกติ ไม่มีธาตุติดมาอ่ะครับ)
ถ้าชนะทางตามระบบธาตุ ก็แรงขึ้นครับ

3. สมมุติว่า ถ้ามอนธาตุดิน แล้วผมใช้ สกิล Holy Up ใส่ แล้วเอาดาบธาตุลม ไปตี จะตีเข้าไหม? ถ้าเข้าจะแรงไหมครับ?
(ธาตุลมแพ้ดิน นี่ผมจำไม่ผิดใช่ไหมนะ?)
ถ้าใส่แสงแล้วมอนมีธาตุอื่นไม่เกิน 50 มอนนั้นก็กลายเป็นแสงแล้วครับ
แสงแพ้ ดิน น้ำ ลม ไฟ

4. ความแรงนี่ ระหว่าง ดิน vs ลม กับ แสง vs ลม อันไหนจะแรงกว่ากันหรอครับ? หรือเท่ากัน?
คือยังไงอ่ะ ดินยิงลม หรือ ลมยิงดิน เอาเป็นข้อๆล่ะกัน
ดิน --ยิง--> ลม : แรงมาก ถึง มากที่สุด
ลม --ยิง--> ดิน : เบาลง ขึ้นอยู่กับค่าธาตุว่ามากน้อยขนาดไหน ถ้าดินเยอะเกิน 50 นี่ลมก็ยิงไม่เข้าเลย
แสง --ยิง--> ลม : เบาลง เงื่อนไขเหมือน ลม --ยิง--> ดิน
ลม --ยิง--> แสง : แรง แต่ไม่เท่า ดิน --ยิง--> ลม



ระบบธาตุเป็นระบบที่ควรศึกษาไว้ เพราะถ้าใช้ถูกที่ถูกทาง มันจะทำให้เราตีแรงขึ้น 2-3 เท่า
