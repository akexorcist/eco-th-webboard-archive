เอามาให้ดูบ้าง เพื่อเป็นแนวทางในการอัพ แต่ละค่าของสเตตัส เพื่อให้เหมาะกับการเล่นของเรา (ไม่ได้ให้เลียนแบบ ไม่ได้บอกว่าสเตตัสนี้เทพ แค่เอามาให้ดูกัน) เน้นยิงคน ไม่ได้เน้นยิงมอน

อาชีพ: Gunner(rifle)
เลเวล: 99/50
เผ่า: Dominion

โค้ด: เลือกทั้งหมด
สเตตัสตอนนี้
STR: 98+16  (ถ้าใส่หมวก+str2 จะลงโบนัส Min.ATK แต่ใส่หมวก ออร่า+str 3 จะลงโบนัส Max.ATK) ATK ~ 301-739
DEX: 6+12   (point เหลือ 1 เลยลง เพื่อเพิ่ม MIN.ATK) ~ DEF16 / M.def 40
INT: 71+24  (ใส่กุหลาบคาบ 71+29) ~ L.HIT 312 / L.AVOID 292
VIT: 21+9   (ลงโบนัสHP) ~ HP 1580 / SP 647
AGI: 78+12  (ลงโบนัสA.SPD) ~ A.SPD 688 / S.AVOID 266
MAG: 8+4

*เป็นสเตตัสตอนแข่ง rvr (95/50) แต่มาอัพเพิ่ม เลยดูไม่ค่อยลงตัวเท่าไร แต่ก็ใช้ประโยชน์ได้ดี

สเตตัสหลักคือ STR INT AGI เด่นในทาง ยิงแรง และยิงโดน ถ้าจะเก็บเลเวล ควรลด INT ไปเพิ่ม AGI เพื่อให้ ยิงให้ไว และหลบเก่ง จะดีกว่า

สเตตัสนี้กับ pvp / nvn
ข้อดี:
ยิงแรง - เมื่อใช้ Cross Crest หรือ Bullet Dance ถ้า def ไม่เยอะจริง ทีเดียวน่าจะตายหมด
ยิงแม่น - ถึงไม่บัฟ Precision Fire(บัฟยิงโดน100%) แทบไม่เคยยิงคนไหนวืดเลย นอกจาก GM
ยิงไกล - เมื่อถือไรเฟิล + บัฟ (Over Rage) จะยิงได้ไกลสุดๆ

เกือบจะดี:
หลบหลีกได้พอสมควร - ถ้าเจอพวก สายเวล มักจะหลบได้เกือบทั้งหมด ทั้งระยะใกล้ และ ไกล แต่อาจ หลบได้บ้างสำหรับพวกที่มี dex หรือ int น้อย
ร่ายสกิลไว - ร่ายเกือบไว ทำให้ยิงคนอื่นได้ก่อน

ข้อเสีย:
ตัวบาง - เลือดและพลังป้องกันต่ำ มักจะเป็นลมได้ง่าย(แปบๆ ตาย)

ข้อได้เปรียบของสเตตัสนี้
เมื่อเจอสายไฟเตอร์ - ยิงฟรี เพราะเรายิงไกล อาจใช้สกิลได้2ทีติดก่อนอีกฝ่ายจะถึงตัวยิ่งเรายิงแรงด้วย ถ้าไม่ถึกจริงคงไม่รอดเข้ามาทำอะไรเราได้
เมื่อเจอสายเวทย์ - ณ ปัจจุบัน 80%+ ที่เราจะยิงตายภายใน 1 สกิล
เมื่อเจอสายสาป - อาจจะทนสกิลสาปที่คิดค่า int ได้ เพราะ int เราสูง
เมื่อเจอปืนสายเวล หรือแอสสายปืน - จะหลบลูกปืนได้หมด

ปัญหาของสเตตัสนี้
เมื่อเจอแอสปล่อยพิษ - ทนพิษได้น้อย โดนไม่กี่ทีตาย
เมื่อเจอสายไฟเตอร์ที่s.hitเยอะ - อาจหลบได้บ้างบางhit แต่80%+ เราจะโดนละก็ตาย
เมื่อเจอสายเวทย์ - ถ้าโดนสกิลยิงที่ตัวมักจะตายภายใน 1 hit
เมื่อเจอไพ่ของGambler - ไพ่ของGambler ตอนนี้แทนโดนตลอด def และ hp ที่น้อยทำให้เรา โดนไพ่แทงไม่เกิน 3 ทีตาย (ซาก้าก่อนไพ่แทงเราไม่โดนเลย)

สเตตัสนี้กับการใช้สกิลยิง
ทุกอาชีพที่defน้อย - ใช้สกิล Plurality Bullet 1ครั้ง โอกาศยิงตาย 80%+
ทุกอาชีพที่defพอสมควร - ใช้สกิล Cross Crest หรือ Bullet Dance 1ครั้ง โอกาศยิงตาย 80%+

ข้อจำกัดของทุกสเตตัส
ทุกอาชีพที่defสูง - ปัญหาของอาชีพนี้เลย เพราะทุกสกิลโจมตีจะหักล้างกับdefศัตรู อาจจยิงสร้างดาเมจได้แค่ 1 -*- (แต่ยังดีที่gunner มีสกิล stun เพื่อหยุดฝั่งตรงข้ามได้)

*อ้างอิงประสบการณ์จากการเล่นเซิฟทาโกะ
