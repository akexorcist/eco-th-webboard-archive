ท่าไม้ตาย //
- Grace Au Enfer (กราซ โอ อองแฟรฺ) - สร้างซิปบนอากาศและรูดออกเพื่อเปิดช่องว่างของมิติและส่งสัตว์ประหลาดออกมากัดกิน-ฉีกทึ้งเป้าหมาย
+ การสร้างซิปนี้ต้องใช้จิตเพ่งนะจ้ะ และถ้าจิตอ่อนเกินไปก็จะถูกสัตว์จากช่องมิตินั้นรุมกัดกินเสียเอง
+ การรูดซิป แค่วาดมือออกไปเหมือนกำลังรูดซิปก็พอ ไม่จำเป็นต้องสัมผัสตัวซิป
+ สัตว์ที่ออกมา แค่นึกก็พอว่าอยากให้มันเก่งขนาดไหน... แต่ยิ่งเก่ง ก็ยิ่งควบคุมลำบาก จึงเสี่ยงต่อการโดนกินเสียเองในกรณีที่ไม่สามารถใช้จิตควบคุมสัตว์นั้นได้
- Tendre (ตองเดรอ) - ลูบมือซ้ายผ่านบาดแผลต่างๆ แล้วแผลนั้นก็จะหายไป แต่มีซิปปรากฎขึ้นแทน... ถ้ารูดทิ้ง แผลก็จะกลับมาเป็นเหมือนเดิม พร้อมกับรอยบาดเหมือนโดนมีดเฉือนเป็นทางยาวบนบาดแผล
+ ถ้าเป็นแผลโดนมีดบาดอยู่แล้ว แผลก็จะลึกขึ้นนั่นเอง
+ ความสามารถนี้มีเวลา2ชั่วโมง ถ้าเกินจากนี้แม้แต่วินาทีเดียว บาดแผลนั้นจะรุนแรงขึ้นเป็นสองเท่าต่อครึ่งชั่วโมง
- Tramontane (ทรามงตาน) - ทำให้เกิดลมเหนือพัดกระหน่ำใส่คู่ต่อสู้ และพัดเอาพลังเวทย์ของลีเก้ไปด้วยในสายลมนั้น... เมื่อพลังเวทย์นั้นสัมผัสกับสิ่งใด ก็จะปรากฎซิปขึ้นตรงจุดที่สัมผัส...
+ ก่อนอื่น ลีเก้จะสร้างพลังเวทย์ที่มีลักษณะเป็นแผ่นสี่เหลี่ยมบางๆหลายแผ่น แล้วปล่อยให้พัดไปพร้อมกับลมเหนือที่สร้างขึ้นจากพลังเวทย์
+ ซิปที่ปรากฎขึ้นนั้นดึงไม่ออก เว้นแต่ว่าจะรูดซิปทิ้ง
- Aniter (อานีเต้) - มักจะใช้ต่อจาก 'Tramontane' เพียงแค่วาดมือผ่านอากาศครั้งเดียว ซิปทั้งหมดที่ลีเก้สร้างขึ้นมาก็จะถูกรูดออกพร้อมๆกันโดยไม่มีข้อยกเว้น ราวกับลมใต้ ที่พัดหวนขึ้นอีกครั้ง
+ แน่นอน รวมถึงซิปที่เกิดขึ้นจากความสามารถ 'Tendre' ด้วย..

นิสัย // ค่อนข้างจะ... บ้าๆบวมๆ ไร้สาระ ไม่ค่อยอยู่กับร่องกับรอย ติดจะไฮเปอร์นิดๆ ไม่เคยจำอะไรได้นานกว่า3นาที ยกเว้นแค่สองเรื่องคือเรื่องเงินและแอลกอฮอล์... เป็นพวกเฮฮาๆ หาเพื่อนได้ง่าย... แต่ในจำนวนที่หามาได้นั้น ส่วนใหญ่จะเลิกเป็นเพื่อนกับเจ้านี่ไปกว่าครึ่งเพราะรับไม่ได้กับความบ้า โดยเนื้อแท้เป็นคนดีนะ แต่ไม่ค่อยแสดงออก พอๆกับที่ฉลาดแต่ไม่แสดงออกเลยโดนมองว่าโง่ซะเป็นส่วนใหญ่(ฮา)
โดนคนเข้าใจผิดบ่อยๆว่าเป็นเกย์ เพราะไม่เคยสนใจควงผู้หญิงเลยสักครั้ง... เจ้าตัวพยายามปฏิเสธเต็มที่ แต่ก็น้อยคนนักที่จะเชื่อคำปฏิเสธนั้น..? เป็นพวกตัดสินใจอะไรได้เด็ดขาดสุดๆ และจะไม่มีวันเปลี่ยนแปลงผลการตัดสินใจนั้นด้วย.. ยกเว้นว่าจะได้หนังสือเก่าๆแรร์ๆสักเล่มหนึ่งถึงจะยอมเปลี่ยนแปลงการตัดสินใจนั้นอ่ะนะ..(สรุปว่าแกนี่มันฉลาดหรือไม่ฉลาดกันแน่เนี้ยยยยย)

ความสามารถพิเศษ // ที่ๆลีเก้ใช้มือซ้ายลูบผ่าน จะมีซิบปรากฏขึ้นมา รูดได้ครั้งเดียวและจะสลายไปเมื่อรูดจนสุด
แต่ถ้าต้องการให้หายไปโดยที่ไม่รูด ก็แค่ใช้มือขวาลูบลงไปบนนั้น แน่นอนว่าถ้าต้องการให้ซิบอื่นๆที่ลีเก้ไม่ได้สร้างหายไป แค่ใช้มือขวาลูบก็เรียบร้อย
ถ้าใช้ความสามารถนี้บนเนื้อคน ก็คือการเถือเนื้อให้เลือดกระฉูดนั่นเอง... แต่ถ้าใช้ตรงกลางลำตัว แผลนั้นก็จะเป็นเหมือนโดนคุณหมอห้องผ่าตัดกรีดจนเห็นอวัยวะภายในเลยล่ะ :3
นอกจากนี้ก็พอจะใช้เวทย์โจมตีพื้นๆได้นิดหน่อย ที่พื้นๆเพราะตอนนี้กำลังทุ่มเทให้กับการฝึกใช้ความสามารถข้างบนในระยะไกลอยู่น่ะ!!
.. อ้อ ความสามารถพิเศษอีกอย่างก็คือ กระดิกหางแบบควงสว่านได้เมื่อดีใจสุดๆ!!(เป็นต้นว่า ได้หนังสือเก่าๆแรร์ๆ.. นี่แหละต้นเหตุของฉายา!!)

ประวัติ // เอ่อมมมมม... เอาเป็นว่า ก่อนที่จะมาที่นี่ หมอนี่อยู่กับป๊ะป๋าบุญธรรมแค่สองคน(เนื้อเรื่องก่อนหน้านี้ก็ดรามาทั่วๆไป ทำนองว่า ถูกทิ้งเพราะเจือกมีหูมีหางอะไรทำนองเนี้ย) แต่แล้วก็ถูกไล่ให้มาเข้าโรงเรียนนี้เนื่องจากความบ้าและไร้สาระของลีเก้มันชักจะทวีคูณขึ้นทุกวัน ป๊ะป๋าเลยคิดว่าถ้าให้มันมาอยู่ร่วมกับคนอื่น ความบ้าอันนี้อาจจะน้อยลงก็ได้... มั้งนะ
... ประวัติเจาะลึกลงไป!! > เรื่องราวของลีเก้ตอนเด็กๆนั้นแม้แต่เจ้าตัวก็ไม่รู้ ความทรงจำทั้งหมดที่มีนั้นเริ่มต้นขึ้นที่บ้านที่อาศัยอยู่กับพ่อบุญธรรม
แน่นอน ลีเก้ไม่รู้ว่าก่อนหน้าที่เขาจะมาอยู่ที่บ้านนี้ 'คุณพ่อ' ไปเจอเขาได้อย่างไร และเมื่อพยายามนึก สิ่งที่ผุดขึ้นมาในหัวก็มีแต่ความเจ็บแปลบเหมือนโดนเสียดแทงพุ่งพล่านไปทั่วร่าง
และลีเก้จะไม่มีวันได้รู้ ว่าเมื่อแปดปีที่แล้ว คุณพ่อ เป็นคนพาเขาออกมาจากซากปรักหักพังที่ห่างไกลออกไป โดยที่เขาถูกพบในสภาพที่ถูกมัดติดกับเก้าอี้หมุดตัวหนึ่ง เลือดโทรมกายราวกับเป็นเพียงประติมากรรมที่ผิดพลาดของพระเจ้า
ลีเก้เติบโตขึ้นที่บ้านหลังนั้น คุณพ่อที่ใจดีไม่เคยแสดงท่าทางรังเกียจแม้แต่ตอนที่ลีเก้ค้นพบความสามารถของตนเองอันเป็นต้นเหตุให้ถูกขับไล่... จะมีแต่ตัวลีเก้เท่านั้น ที่พยายามฆ่าตัวตาย แต่ก็ไม่เคยประสบผลสำเร็จ เพราะทุกครั้งที่คมมีดถูกจ่อเข้ากับผิวหนัง ก็จะปรากฎซิปขึ้นมาดูดกลืนมีดเหล่านั้นหายไปทันที ราวกับว่า พระเจ้าต้องการให้เขาทนทรมาณกับตัวตนของตนเองต่อไปฉันใดก็ฉันนั้น
ไม่ว่าจะเป็นเพราะเล็งเห็นความทุกข์ของลีเก้หรืออะไร คุณพ่อ ก็ได้ตัดสินใจส่งลีเก้เข้าเรียน โดยที่เป้าหมายหลักๆนั้นก็คงเป็นการแสดงให้ลีเก้เห็นว่า ชีวิตนั้นไม่ได้อดสูและทุกข์ทนอย่างที่ลีเก้คิดเสมอไป
