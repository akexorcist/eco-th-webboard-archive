- delay 0s
- ระยะสกิล 5

*ถ้าใช้ตอน possession อยู่ จะยิงไปในทิศที่เจ้าของร่างหันหน้าอยู่เสมอ
- ใช้ mp 23/26/29/32/35
- พลังโจมตี
- - 250% m.atk (มี skill ธาตุลม 1-5 lv)
- - 300% m.atk (มี skill ธาตุลม 6-8 lv)
- - 350% m.atk (มี skill ธาตุลม 9-11 lv)
- - 400% m.atk (มี skill ธาตุลม 12-35 lv)
- ระยะเวลาร่าย 4.0/3.5/3.0/2.5/2.0s
- delay 0s
- ระยะสกิล 6


สกิลนี้ Delay 0 อาจจะจริง แต่ติด โมชั่น แทน (กดรัวๆ ไม่ได้ต้องรอสักระยะ)
ส่วนความแรง ... ลองที่ลานแพ็ตมา ( Mag 100+24 )
(สกิลธาตุลม รวม = 13 )

แพ็ตตินั่ม โดน 1500-1900 , Zen 3000-3900 (ค่อนข้างแกว่ง)
็พี่ Hell โดน 1900-2200 , Zen 4000-4600 (แกว่งเช่นเดิม)
Fox HoundB3 1700-2200, Zen 3500-4400
GigantoC4 800-1100 , Zen 1800-2200
(จากข้างบน เป็นการทดลอง อย่างละ 5 ตัว )

ส่วนตัวให้ "ไม่ดี" สำหรับสกิลนี้ ต้องยืน+ ถ้าไม่ยืน+ ก็ต้องเล็งดีๆ (แต่มอนส่วนใหญ่จะเดิน
ค่อนข้างบ่อย กะไม่ดีก็เสีย MP ฟรี)
แต่ถ้าข้อดี ให้ ข้อเดียว คือ "ร่ายได้ต่อเนื่อง" หรือง่ายๆ เป็นเวทเดียวที่ delay 0
(อย่าไปนับสกิลลูกไฟ ถึงจะ delay 0 แต่ถ้าร่ายต่อเนื่อง อันเก่าก็จะหายไป เพื่ออะไร? )
