เผ่าที่เหมาะสม : Emil

ความเก่งกาจ/โหด : ★★★★★

ความยืดหยุ่นในการเล่น : ★★★

ข้อเสีย : อาจแบกของแบกยาได้ไม่มากเท่าที่ควร หาตังค์ได้ไม่มาก


Backpacker - Ranger ( นักผจญภัย )

นักผจญภัย คือ คนที่ต้องเข้าไปสถานที่อันตราย เพื่อที่จะได้สิ่งของอันล้ำค่า

เผ่าที่เหมาะสม : Emil

ความเก่งกาจ/โหด : ★★

ความยืดหยุ่นในการเล่น : ★★★★

การหารายได้ : ★★★★★

ข้อดี : มีสกิลที่สามารถฟื้นHP ได้มาก และแบกของได้มาก และมีสกิลหาของแรร์ช่วยอีก รวยๆ ^^
