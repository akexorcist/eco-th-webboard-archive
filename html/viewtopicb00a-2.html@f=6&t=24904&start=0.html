ผมโดนแบนไปแล้วครับ แต่ไม่ใช่คนในภาพนะ

ความจริงมันเป็นแค่โปรแกรมเพิ่ม speed CPU แค่นั้นเองครับ ซึ่งโปรแกรมนี้ผมโหลดมาจากบิต ชื่อโปรแกรมว่า Game Optimizer

โปรแกรมตัวนี้ที่ผมทดลองแรกๆ ก็คือมันจะคอยเครียร์แรมประมาณนั้น

แต่ซักพักผมลองไปกดคลิ๊กขวาที่ icon มุมขวาล่างของ วินโดว์ มันก็จะมี list menu ขึ้นมาครับ ซึ่งมันมีเขียนว่า speed *1 *2 และคูณ 3 ผมก็ลองกดดู พอลองแล้ว ภาพตามเว็บหรือการทำงานของ วินโดวมันจะเร็วขึ้นมากเลยครับ (สังเกตุจากการเปิดปิดหน้าต่างวินโดวและภาพ animation ในเว็บมันเคลื่อนไหวเร็วมาก)

ผมก็เลยรองเข้าเกม ECO ดู คืออยากรู้ว่ามันจะทำให้ในเกมเร็วขึ้นรึป่าว ซึ่งพอเข้ามามันก็เร็วขึ้นจริงๆ ครับ ผมก็รองวิ่งไปวิ่งมาแถวๆ หน้าเมือง แล้วก็รองยิงเวทใส่มอน ก็ได้ข้อสรุปว่ามันร่ายเร็วก็จริงแต่เวลาที่เวทออกไปโจมตีจริงๆ ก็เหมือนเดิมเพราะมันร่ายเสร็จแต่เวทก็ยังไม่พุ่งไป ผมรองยิงได้ 3 - 4 ตัว แล้วก็รองบินไปบินมา ซักพักก็โดนตัดออกจากระบบ แล้วพอ login เข้าใหม่ก็โดน BAN พร้อมกับบอกว่าให้โทรติดต่อไปหา GM

ซึ่งผมก็ไม่โทรหรอกนะครับ ขี้เกียจอธิบาย ผมไม่ค่อยชอบคุยโทรศัพท์กับคนแปลกหน้าอยู่แล้ว และผมไม่ได้เป็นพวกบ้าเกมจนต้องดิ้นรนอะไรแบบนั้น แบนไปก็ไม่เล่นแค่นั้นครับ ผมเล่นเพื่อคลายเครียดไม่ให้เล่นผมก็ไม่ดิ้นรนให้เครียดหรอก กลับไปเล่น Warcraft จบไปเป็นตาๆ ดีกว่า

เออแล้วไม่ต้องกลัวนะครับว่าผมเอาชื่อโปรแกรมมาเผยแพร่ เพราะมันใช้ไม่ได้อยู่แล้ว คิดว่ามันคงเป็นระบบแบนอัตโนมัติเมือมีการตรวจพบการส่งแพคเกจที่เร็วกว่าปกติ เพราะที่ผมโดนนั้น ยังไม่ถึง 1 นาทีเลยมั้งครับ

ปัจจุบันผมก็ไม่ได้ใช้โปรแกรมนี้เพิ่มความเร็ว CPU แล้ว เพราะกลัวมันพัง ใช้แค่ให้มันจัดการแรมเท่านั้นครับ

แต่ก็แอบดีใจนิดหน่อยที่ระบบของเกมนี้ทำออกมาได้ดีทีเดียว และผมก็ยังไม่เคยเห็นบอทในเกมนี้ด้วย คนที่เล่นอยู่สบายใจได้ครับสำหรับเกมนี้
