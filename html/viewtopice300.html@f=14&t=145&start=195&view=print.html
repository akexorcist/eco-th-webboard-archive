Q : ถามความเป็นไปได้หน่อยครับว่าดาร์กสาย str-vit หรือ str-agi ที่จะเก็บ lv ดีกว่ากัน
A : ผมคิดว่า น่าจะ str - vit นะคับ น่าจะเก็บเลเวลง่ายกว่า แต่ถ้าสาย str - agi ตอนแรกๆ อาจจะลำบากหน่อยนะคับ(ยิ่งเผ่าปีศาจอาจจะลำบากตอนแรกเพราะ def 0 จะโดนโจมตีแรงมากๆ แต่ตอนหลังๆ น่าจะตีได้แรงคับ)

Q : ดาร์คเปลี่ยนตอนเวลเท่าไหรครับ ?
A : ระบบเปลี่ยนอาชีพจะคล้ายๆ กับเกมส์ ragnarok คับ คือถ้ามีค่า Job ครบตามที่กำหนดไว้ก็สามารถเปลี่ยนได้ (กำหนดไว้ต่ำสุดที่ Job 40 คับ แต่ถ้าเราเก็บถึง Job 50) เราจะสามารถเลือก Skill จากอาชีพขั้นแรกมาได้คับ(ไม่แน่ใจนะคับแต่คาดว่าน่าจะใช่)
