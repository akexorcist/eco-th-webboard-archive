ระเบิดเวลา ", หนึ่งเป็นแรงกระตุ้นให้กิน.
ระเบิดเวลาตั้งเพื่อหลีกเลี่ยงการนางสาว / Guard ในการตัดสินใจ.
เป็นเวลาที่วางระเบิดกด-พึ่งพาของพวกเขาอัตรา,必中ระเบิด.
ระหว่างการตั้งนางสาว / หลีกเลี่ยง / Guard หากบันดาลไม่บริโภค.
ตรวจสอบความเสียหายเป็นลำยองพิเศษ.
ตั้งระเบิดที่ข้าศึกหลังจากความเสียหายที่เกิดกับร่างกายคนเดียวและเนื่องจากศัตรูถูกกำหนดเป็น 3 &times; 3 วินาทีเพื่อทำให้ขอบเขตของความเสียหาย.
※ ในสั้นกระทำการต่อสู้ทักษะ.
ฉันประหลาดใจเมื่อศัตรูได้กำหนด経TAZU วินาทีและทันที exploded.
แน่นอนแม้ว่าทันทีระเบิดมาลงที่สองโจมตี.
อย่างไรก็ตาม 3 &times; 3 ถ้าไม่มีคนอยู่ในช่วงของไม่มี.
ใช้ทักษะหลังจากระเบิดแม้ว่าคุณกดปุ่ม SETTOBOMU ฆ่าโดยระเบิด.
ล้วน-ผลคุณคิดว่ามันจริงๆ exploded.
เวลาโทรศัพท์ทางไกลทรุดโทรมและระยะทางห่างจากการระเบิดที่ศัตรู.
หากคุณสำลัก交ฉันปีกตั้งต่อความเสียหายของระเบิดเป็นกดที่นั่นเกินไป.
