ถึง [GM]เป๊ปเป้กับเพื่อนๆนะ คับ ผมเจอมากะตัวเลยอ่ะคับ ขอเล่าเลยละกัน เบื่อไอ่พวกเกรียนจิงๆ

คือเรื่องยังงี้คับ ผมได้รับเมลล์จากคนที่แอบอ้างเป้น [GM]เป๊ปเป้ คับ แล้วตอนแรกผมก็ไม้ได้เอะใจอะไร

เห็นว่าถูกรางวัล ได้มังกรแดงฟ้าอย่างละตัวละก็ ให้เลือกมาริโอเนทได้อย่างละตัว (ใครโดนอย่างผมบ้าง) ตอนแรกก็ดีใจอยู่ อยากได้มังกรฟ้าน่ะ ได้มังกรแดงมา4ตัวละเบื่อ อุๆ ได้มังกรมาวันละตัวเลย *0* เข้าเรื่องๆ แล้วที่นี้เหลือบไปเห็นคำว่า

ให้ส่งไอดีพาสเวิดตอบกลับมาและทางเราจะส่งไปรันกับเครื่องคอมอะไรซักอย่างนี่แหละ ผมก็เลยอ๋อ ด่ากลับเลยคับ เพราะ [GM] ทุกคน ทุกเกมส์ ไม่เคยขอ ไอดีพาสเวิดจากผู้เล่น ผมเลยพิมด่ากลับไป แต่เรื่องยังไม่จบนะ ผลจากวันแรก พอมาวันที่2 ผมก็ไปสิงอยู่ที่ทางเข้าเมืองเหนือไปเก็บเรื่อยๆ จนมีคนๆนึงเข้ามาถามซื้อไข่มังกร เพราะผมตั้งแลกไข่มังกรไว้ เมื่อคนนั้นเข้ามาถามซื้อไต่อผมก็ไม่ได้ขายให้แต่อย่างใดเพราะจะเอาไปไข่แดงแลกไข่ฟ้า ต่อมาผมก็เล่นจนเวลาล่วงเลยมาอีกวัน ผมก็เหนคนที่เข้ามาถามแลกไข่ซิปเข้ามา
(มันซิปมาแอบอ้างน่ะแหละ เจอกับตัวเลยมาเล่าเพื่อเป็นอุทาหร) ซิปมาประมานว่าได้ไข่จิงนะ เพื่อนเรา ได้ไขมังกร2ฟอง ได้มาริโอเนทนกไฟ

เราก็เลยตามน้ำไปเลยถามว่า ถึงไม่มีคำว่า[GM] นำหน้าชื่อ มันยังหน้าด้านตอบอยู่นะ นายว่าไม่รุเหรอ [GM] เค้าไม่มีคำว่า[GM] นำหน้าชื่อ มีแต่คำว่า เป๊ปเป้ สารธยายมานานมากๆ จนเราไม่ตอบพอซักพักไอ่เมลล์จดหมายนรกได้มาอีกละ หลังคุยกับบุคคลดังกล่าวเสร็จ (เพื่อสงวนสิทของบุคคลดังกล่าวเราจะไม่ขอเอาชื่อมาลงไว้ เพราะเค้าอาจเป้นเหยื่อที่ถูกหลอกมาเหมือนกัน แต่เราเชื่อว่าเป็นมันนั่นแหละ555)

ต่อคับ ข้อความมีอยู่ว่า ถ้าไม่ส่งกลับทางเราจะได้ส่งของรางวัลไปให้คนอื่นต่อไป (แน่ะดูมัน..ยังหน้าด้านอีกเกรียนชัดๆ) ไอ่เราก็นึกอุดส่าบอกว่าไม่ส่งแล้วนะ

จากนั้นก็เลยพิมกลับไปด่าในจดหมายว่าถ้าเป็น[GM]เป๊ปเป้ จิง กรุณาเอาของมายื่นให้ถึงมือเองเลยนัดสถานที่มา และจดหมายนรกก็ส่งมาอีกฉบับ ขณะนี้ทางเราได้ส่งของขวัญไปให้คนอื่นแล้ว (จะส่งให้ใครก็เรื่องของ...เหอะ ตีเอาเองเด๋วก็ได้ไข่มังกรน่ะ ฟันธงมังกรแดงหาไม่ยากอย่างที่คิด ที่ยากจิงๆ คือมังกรฟ้า - -* )
พอเสร็จไอ่นายนั่นก็ซิปมาอีกละ เราได้ข้อความจาก [GM]เป๊ปเป้ ละ ดีใจมากเลย (โธ ไอเกรียนความตั้งใจไม่มียังอุดส่านะ ) จบคับ เพื่อเป้นอุทาหรนะคับเลยมาบ่นให้ฟังในที่นี้ เจอไอ่คนแบบนี้เซพชื่อส่ง ทางone touch service ตามที่[GM]เป๊ปเป้ บอกเลยคับ ตอนนั้นเราเสียรมเกิน เลยไม่ได้เซพชื่อกับรูปตอนไอ่พวกมิจฉาชีพนี้ส่งมา

ป.ล.เรามะได้ส่งให้มันนะส่งXXX ด่ากลับไปแทน 555 สะใจดีแท้ร่วมกันประนามเลย ใครที่อ่านแล้วขัดลูกกะตาก็ขอโทดด้วยนะคับ เปนเรื่องจิงที่เกิดมากะตัวเองอ่ะเลยมาเล่าให้ฟัง

เห็นว่าถูกรางวัล ได้มังกรแดงฟ้าอย่างละตัวละก็ ให้เลือกมาริโอเนทได้อย่างละตัว (ใครโดนอย่างผมบ้าง) ตอนแรกก็ดีใจอยู่ อยากได้มังกรฟ้าน่ะ ได้มังกรแดงมา4ตัวละเบื่อ อุๆ ได้มังกรมาวันละตัวเลย *0* เข้าเรื่องๆ แล้วที่นี้เหลือบไปเห็นคำว่า

ให้ส่งไอดีพาสเวิดตอบกลับมาและทางเราจะส่งไปรันกับเครื่องคอมอะไรซักอย่างนี่แหละ ผมก็เลยอ๋อ ด่ากลับเลยคับ เพราะ [GM] ทุกคน ทุกเกมส์ ไม่เคยขอ ไอดีพาสเวิดจากผู้เล่น ผมเลยพิมด่ากลับไป แต่เรื่องยังไม่จบนะ ผลจากวันแรก พอมาวันที่2 ผมก็ไปสิงอยู่ที่ทางเข้าเมืองเหนือไปเก็บเรื่อยๆ จนมีคนๆนึงเข้ามาถามซื้อไข่มังกร เพราะผมตั้งแลกไข่มังกรไว้ เมื่อคนนั้นเข้ามาถามซื้อไต่อผมก็ไม่ได้ขายให้แต่อย่างใดเพราะจะเอาไปไข่แดงแลกไข่ฟ้า ต่อมาผมก็เล่นจนเวลาล่วงเลยมาอีกวัน ผมก็เหนคนที่เข้ามาถามแลกไข่ซิปเข้ามา
(มันซิปมาแอบอ้างน่ะแหละ เจอกับตัวเลยมาเล่าเพื่อเป็นอุทาหร) ซิปมาประมานว่าได้ไข่จิงนะ เพื่อนเรา ได้ไขมังกร2ฟอง ได้มาริโอเนทนกไฟ

เราก็เลยตามน้ำไปเลยถามว่า ถึงไม่มีคำว่า[GM] นำหน้าชื่อ มันยังหน้าด้านตอบอยู่นะ นายว่าไม่รุเหรอ [GM] เค้าไม่มีคำว่า[GM] นำหน้าชื่อ มีแต่คำว่า เป๊ปเป้ สารธยายมานานมากๆ จนเราไม่ตอบพอซักพักไอ่เมลล์จดหมายนรกได้มาอีกละ หลังคุยกับบุคคลดังกล่าวเสร็จ (เพื่อสงวนสิทของบุคคลดังกล่าวเราจะไม่ขอเอาชื่อมาลงไว้ เพราะเค้าอาจเป้นเหยื่อที่ถูกหลอกมาเหมือนกัน แต่เราเชื่อว่าเป็นมันนั่นแหละ555)

ต่อคับ ข้อความมีอยู่ว่า ถ้าไม่ส่งกลับทางเราจะได้ส่งของรางวัลไปให้คนอื่นต่อไป (แน่ะดูมัน..ยังหน้าด้านอีกเกรียนชัดๆ) ไอ่เราก็นึกอุดส่าบอกว่าไม่ส่งแล้วนะ

จากนั้นก็เลยพิมกลับไปด่าในจดหมายว่าถ้าเป็น[GM]เป๊ปเป้ จิง กรุณาเอาของมายื่นให้ถึงมือเองเลยนัดสถานที่มา และจดหมายนรกก็ส่งมาอีกฉบับ ขณะนี้ทางเราได้ส่งของขวัญไปให้คนอื่นแล้ว (จะส่งให้ใครก็เรื่องของ...เหอะ ตีเอาเองเด๋วก็ได้ไข่มังกรน่ะ ฟันธงมังกรแดงหาไม่ยากอย่างที่คิด ที่ยากจิงๆ คือมังกรฟ้า - -* )
พอเสร็จไอ่นายนั่นก็ซิปมาอีกละ เราได้ข้อความจาก [GM]เป๊ปเป้ ละ ดีใจมากเลย (โธ ไอเกรียนความตั้งใจไม่มียังอุดส่านะ ) จบคับ เพื่อเป้นอุทาหรนะคับเลยมาบ่นให้ฟังในที่นี้ เจอไอ่คนแบบนี้เซพชื่อส่ง ทางone touch service ตามที่[GM]เป๊ปเป้ บอกเลยคับ ตอนนั้นเราเสียรมเกิน เลยไม่ได้เซพชื่อกับรูปตอนไอ่พวกมิจฉาชีพนี้ส่งมา
