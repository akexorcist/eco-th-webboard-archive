4สายพิษเหมาะกับการเกบเลเวลไหม

ส่วนเรื่องสเตตัส ที่ผมใช้อยุ่ตอนนี้ก็

str 100(อันนี้ที่จริงเกินเเอสเเต่อัพไว้เผื่อคอมมานโดในอนาคต(เเอสจริงมีเเค่ประมาณ92ก็ลงโบนัสเเล้ว))

dex 33(มอนหลังๆบางตัวหลบขั้นเทพต้องมีรวมโบนัสไว้50)

vit 22(ที่จริงไม่ค่อยจำเป้นเเต่อัพไว้กันดดนทีเดียวตาย)

agi 84(เอารวมโบนัสให้ได้108ก็พอเเล้วครับเพราะเยอะกว่านี้ความเร็วการดจมตีก็ไม่ขึ้นเเล้ว(เเต่พอเป้นคอมต้องอัพ90เพราะโบนัสลด))

int 28-38 (อันนี้สำหรับสายปาหรือคอมมานโดเท่านั้นเลย(ใช้ปืน)เเต่เล่นเเต่สนับก้อัพเเค่dexพอ)
