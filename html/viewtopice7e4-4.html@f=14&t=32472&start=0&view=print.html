เพิ่มเล่นFencerได้ไม่นาน lv.ยังไม่พอใส่ชุดประจำอาชีพเลย แต่เท่าที่อ่านๆGuideมาบ้าง ดูSkillมาบ้าง ก็เลยได้ข้อสรุปที่น่าสนใจพอที่จะเลือกเล่นสายหอก 2 มือมา 2-3 ข้อครับ

1.Two-hand Spear Mastery
Memories เขียน:
Two-hand Spear Mastery (@ @ @ @ @)
JobLv: 3

ใครที่ต้องใช้หอกสองมือยังไงก็ต้องไม่พลาดสกิลนี้แน่นอนล่ะนะ เพราะจะเพิ่มค่า min atk ยิ่งขึ้นไปอีก
ตีแรงขึ้น แกว่งน้อยลง แถมใช้คู่กับสกิลข้างล่างนี่ ถูกใจไนท์สายตีโหดและสายเอจิดีนักแล


2.Spear Strike2
Memories เขียน:
Spear Strike2 (@ @ @ @ @)
JobLv: 5

double attack ดีๆนี่เอง มีผลกับหอกสองมือและดาบแทง (rapier) เท่านั้น แม้โอกาสติดจะต่ำ
แต่สกิลนี้จะคิดโอกาสติดจากการโจมตีทุกครั้ง ยิ่งโจมตีได้ไว โอกาสติดยิ่งสูงขึ้นทวีคูณเลยทีเดียว
