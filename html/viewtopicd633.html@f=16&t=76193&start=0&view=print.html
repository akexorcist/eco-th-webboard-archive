แล้วแต่แนวเราด้วยล่ะครับ ผมว่าถ้าจะเล่นหลายๆตัวหนึ่งในนั้นก็ควรจะมีพ่อค้านะครับ

ในช่วงแรกยังต้องพึ่ง Npc ในการซื้อของ ขายของ ประหยัดไปได้เยอะครับ ส่วนในระยะหลัง

ก็จะเป็นการที่เราตั้งโกเลมรับของอื่นๆแล้วใช้พ่อค้าไปขายกับ Npc อีกทีครับ


มันก็จะเน้นไปทางขายของล่ะครับ ส่วน Ranger จะเน้นไปถ้าล่าของ ล่ากล่องมาขายครับ

แต่ขอบอกนะครับพ่อค้าเวลาเก็บเวลก็ต้องใช้ค้อนล่ะครับ กระเป๋าตีน้อย+เดี๋ยวพังหมด
