อีกอย่าง ปราชญ์ผมว่าไม่มีผลต่อการดรอป น้องแครอทเท่าไรนะ

เพราะขนาด เอเลเมนทาเล่อร์ ของผมไปยิง ยังได้มา 2 ตัวในระยะเวลาไม่ถึงครึ่ง ชม. เลย



ซ้ำร้าย ผมว่ามันทำให้โอกาสในการเจอน้องแครอทลดลงอีกต่างหาก

อันเนื่องมาจาก สกิลนี้ เมื่ออัพแล้ว

พอไปตี Weed จะให้เจอเมล็ดสำหรับปลูกบน Flyong Garden มากขึ้นกว่าเดิม
(บางเมล็ดอาชีพอื่นตีไม่ตก)

ซึ่งพอมีโอกาสตกเมล็ดมากกว่าเดิม ทำให้โอกาสเจอแครอท อาจจะลดลงด้วย (มั้ง)
