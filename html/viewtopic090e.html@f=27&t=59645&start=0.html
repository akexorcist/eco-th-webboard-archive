เล่น eco ที่ร้านเกมส์ร้านหนึ่งไม่ได้

โดย ECO » อาทิตย์ 28 ธ.ค. 2008 10:39 pm

พอดีว่า ก็อบ eco จากบ้านมา จะเล่นที่ร้าน โดยยัด zip มาแตกไฟล์ที่ร้าน
(เอาเฉพาะโฟลเดอร์ eco ) (เหตุผล : ที่ร้านเกมส์นี้ ไม่มีเกมส์ eco
แต่มีที่ตู้ๆ หนึ่ง ซึ่งเล่นได้แค่ตู้เดียว ลองนั่งตู้อื่นแล้วดึกเกมส์มาเล่นก็ไม่โหลดดังภาพ)

(แล้วไอตู้นั้น ก็ไม่ได้อัพเดตแพ็ทซาก้า7ด้วย พอโหลดมาก็โดน undo - - ขี้เกียจโหลดใหม่)

พอจะเข้าเกมส์ ปรากฏว่า เป็นดังภาพ...





มันไม่โหลดอะไรเลย ...
ปกติมาเล่นที่ร้าน ส่วนใหญ่จะมา dota ไม่ก็ C.S.O. แต่พอว่างๆ ก็จะเล่น eco นี่ล่ะ
มีปัญหามากกว่าแร็คซะอีก (ก็อบแร็คมาจากบ้านมาเล่นยังเล่นได้ปกติเลย =w=)

ไม่ทราบว่ามีวิธีแก้ไหม หรือว่า อาจต้องไปก็อบไฟล์บางไฟล์มาด้วย จาก windows system32
ด้วยรึเปล่า
