มันไม่มีสุดยอด anti ที่กันได้หมดแน่นอน เพราะต่อให้ยามเข้มแค่ไหน ถ้าเจ้าของบ้านเปิดประตูเชิญก็จบ = ="


พอๆ
ถ้าโดนบ่อยตัวที่แนะนำให้ติดเครื่องไว้นอกจาก anti แล้วเอา scanner อย่าง Hijackthis ไปด้วยก็ดีงิ (www.spywareinfo.com) จะใช้ scan พวกโปรแกรมที่เกี่ยวข้องกับ registry, start up, etc. ได้ ช่วยในการตรวจสอบได้ดีในระดับสูงเลย (ถ้าไม่มั่นใจการใช้งานอย่าซนกด fix มั่วน่อ ขี้คร้านจะพาเครื่องรวน)

ยังไม่รู้ว่าแก้ยังไงก็เอาวิธีป้องกันไปพลางๆ
มี anti ไว้ใจได้คอยป้องกันซะตัว
จากนั้น
- เลี่ยง web พวกหนัง เพลง crack หรือ 18+ เลี่ยงให้มากที่สุด โดยเฉพาะที่มี pop-up ขึ้นมา (ไม่ว่า toolbar ของท่านจะ block ไว้หรือไม่ก็ตาม)
- ไม่ยุ่งเกี่ยวกับ mail ของคนไม่รู้จัก
- ไม่ยุ่งเกี่ยวกับ mail ของคนรู้จักที่ใจความมันไม่ได้มาจากเจ้าตัวส่งแน่นอน (เช่นเคยส่งแต่ภาษาไทยมารอบนี้มาแบบ eng แถมชวนเข้ากลุ่มเพื่อนอะไรเทือกนี้)
- ห้ามกดโฆษณาตาม web ดังกล่าว
- ห้ามกด Pop-up ที่เด้งขึ้นจาก web ใดๆยกเว้นจะมั่นใจว่ามันเป็น pop-up ที่เกี่ยวข้องกับสิ่งที่ต้องการใช้งานและไม่ใช่การโฆษณา
*หากกดไปแล้ว จังหวะที่มันเด้งขึ้นมา alt+f4 ทิ้งไปเลยหรือกดปิดให้เร็วที่สุด อย่าให้มันมีเวลาจะโหลดออกมาได้ โดน process อื่นดับไปบ้างก็ไม่เป็นไร หรืออยากจะนั่งรบกับปัญหาก็ไม่อยากขัดศรัทธา*
- คอยตรวจสุขภาพเครื่องเป็นประจำ
- เจ้าบ้านทำไม่ได้ทุกอย่าง จ้างยามมาไว้ซักคน มี anti ช่วยเตือนยังดีกว่าปล่อยประตูบ้านว่าง =w="
