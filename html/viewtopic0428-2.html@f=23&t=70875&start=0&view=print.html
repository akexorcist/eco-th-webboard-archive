โพสต์แล้ว: อังคาร 05 ม.ค. 2010 7:01 pm
โดย ECO
คือเด้วนี้ปาป้ามีขายกัน 45m ก้มี
การที่ต้องสะสมแตมทั้ง 108 ดวงโดยเฉพาะมีแตมบอส 8 ดวงเนี่ย

มันคุ้มกันหรอคับ!!

แตมบอสหนวดก้ขายได้อย่างต่ำ 16 เอ็มละ แตมบอสหมาบอสนกบอสไก่อีก
ไม่ใช่แค่บอสนะแต่มีแตมมอนอีก 100 ดวง บางอันก้ไม่กี่หมื่น บางอันก้หลายแสน

ผมสงสัยว่าทำไมคนถึงยังแลกกันอยู่ทั้งๆที่ผมคิดว่าขายแตมทั้ง 108 ดวงเนี่ย
ได้เงินมากกว่า 50 เอ็มอีกอะ
หรือว่าแลกปาป้าแล้วจริงๆมันคุ้มกว่า เพราะตัวผมเองก้ไม่เคยแลกซะด้วย

ยังไงใครมีความคิดเห็นยังไงก้บอกด้วยนะครับ
ผมอยากรู้จริงๆ
