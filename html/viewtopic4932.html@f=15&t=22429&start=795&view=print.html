ผมไปคำนวนมาแล้วครับ ถ้าแพทนี้ ตันที่ เลเวล80

เล่นสาย Mag+Int or Mag+Dex ไม่อัพค่าอื่นๆ จะได้ Mag 100 กับ Int or Dex 66 ครับ ไม่รวมค่าโบนัส

ตอนนี้ ผม Int 51 สาป โจร ก้ติดมั่งครับ ได้ Blue T.(ของทำ) และ สกิล เลเวล 31 ของ Sage

ก็ติดบ่อยดีครับ

แนะนำว่า...ถ้าจะเล่น ให้เลือกสายใดสายหนึ่งดีกว่าครับ ระหว่าง Mag+Dex และ Mag+Int
เพราะข้อดี ข้อเสียจะแตกต่างกันไปครับ ถ้าอัพ ปนๆ ความสามารถจะไม่ถึงที่สุด
ของสายใดสายหนึ่งครับ ซึ่งสองสายนี้มันมีผลต่อสกิลแต่ละท่าแตกต่างกันไป

ถ้าสาย Dex จะใช้สกิลที่มี ดีเลย์นานๆ ฆ่ามอนก่อนถึงตัว ได้เร็วมาก แต่สาปติดยากกว่า สาย Int
แต่สาย Int จะใช้สกิลสาปติดบ่อย แต่ร่ายช้าเป็นเต่าไม่เร็วเท่าสาย Dex ถึงร่ายโซลิดแล้วก็อาจจะไม่ทันครับ

แต่ถ้าอยากจะใช้สกิลที่ ร่ายนานๆด้วย ก็ต้องใช้ สกิล เมดูซ่า ร่วม อ่ะครับ อัพให้เลเวล 5 เลย
แล้วแช่งให้มอนเตอร์อยู่กับที่ อย่างน้อยๆก็ตรึงได้ 6-7 วิ พอตัดเวลาในการร่ายสกิลนานไปได้บ้างอ่ะครับ

ปล.ผมเล่น สาย Mag+Int ครับ (แต่เผลอไปอัพค่าอื่นอย่างละนิด ถ้าเลเวล 80 ได้ Int แค่ 57 เองอ่า ส่วนต่าง ตั้ง 9แต้ม แนะ T_T)
