คือขอถามหน่อยได้มะครับ คือเท่าที่ผมลองอัพดูนะครับถ้าค่า S.Aviod Max เวลาเอาไปอัพมันจะได้ Agi+1แล้วจะเหลือ 2 ค่าคือ S.Aviod กับ L.Aviod อย่างนี้มันจะเท่ากับว่า
จำนวนstatที่เพิ่ม = 2 ไหมครับ เพราะว่าหลังจากอัพไปแล้วจากที่เราต้องเก็บค่า
จาก L.Avoid 16 แต่ต้องเกบถึง 17 ทั้งที่ยังไม่เคย Max เลย เช่นเดียวกัน ถ้าค่า L.Avoid Max เวลาเอาไปอัพก็จะได้ S.Avoid ไปด้วยแล้วยังมีอีกหลายค่าที่ Max แล้วมีผลกับ ค่าอื่นๆด้วย อย่างเช่น Def Max เวลาเอาไปอัพ จะได้ Vit+1 ค่า Def กับ ค่า Hp จะเพิ่มเพราะว่าค่าstatมันเป็นสีเหลือง
จากที่อัพดูค่าที่มีผลด้วยกันจะมี
เพิ่ม Vit จะได้ Def กับ Hp
เพิ่ม Agi จะได้ S.Avoid กับ L.Avoid
เพิ่ม Int จะได้ L.Hit กับ M.Hit (M.Atk ด้วยป่าวมะแน่ใจ)
เพิ่ม Dex จะได้ S.Hit ไม่แน่ใจว่าได้ Cri ด้วยหรือป่าวเพราะว่าอัพไปอัพมาค่า Cri ดันเป็น
สีเหลือง
หรือว่าจำนวนstatที่เพิ่มนั้นคิดจากพวก Str Agi Dex Int ที่เพิ่มแบบนี้ครับ
