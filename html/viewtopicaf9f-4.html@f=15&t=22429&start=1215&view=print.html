กรำเฮ้ย นึกว่าจะได้เจอสาระ กลายเปนโยนต่อซะงั้น

เอาสาระของเก่ามาแปะใหม่ละกัน

เกี่ยวกับ lv ของ saga 5 ที่กำลังจะมา(Base lv เพิ่มจาก 80 -> 90)

status point ที่ได้ทั้งหมดก็ 308 หน่วย อัพสแตตได้มากมายเลย คิดว่าซาก้านี่ซอเสจเรา
คงจะเล่น 3 สายได้แล้วหล่ะ(Mag dex int หรือ Mag dex vit อะไรก็ว่ากันไป)

เช่น แต่เดิมนั้น lv 80 mag dex จะได้ mag 90 dex 78

พอเพิ่ม lv เปน 90 จะเอาไปลง mag เพิ่มเปน 100 ที่เหลือไปลง int ก็จะได้ int 40

หรือว่า เอาไปลง int ยังเดียว mag ปล่อยเท่าเดิม ==> mag 90 dex 78 int 59

กรณีเล่น mag vit int ก็ได้เลือดเพิมอีก 600-700 ได้ def เพิ่มอีก เกือบ 40 หน่วย

อะ อันนี้เวปให้ไปอัพเล่น http://www.geocities.jp/jasmin_clover/e ... atus2.html

อันนี้เรื่อง exp

http://ec.gamedb.info/wiki/exptable.html

จากการจิ้มเครื่องคิดเลขโดยคร่าวๆ

base lv 80 -> 90 = job 50 1lv + job 49 ประมาณ 50% (แต่ต้องห้ามเสีย % จากการตายนะ เพราะมันคนละอัตรากันมากๆ)

เพราะฉะนั้น ซาก้านี้ ฝึกถึงแค่ job 48 สัก 50-70% ก็พอแล้วแหละ
