เลเวลน่ะ จริงๆไม่้ต้องไปรีบหรอก ส่งเควสไปวันๆก็พอครับ ที่เหลือลองทำเควสตามเมืองต่างๆหาความสนุกดูสิ เลเวลมันจะตามมาเองแหละ

สำหรับคนเล่นใหม่ ไม่มีเพื่อนเล่นมาก่อน ไม่มีไอดีคนเก่าๆเวลสูงหน่อย ผมยอมรับว่ายากหน่อยนะ

แต่ถ้ามีเพื่อน หรือไอดีเพื่อนที่เลิกเล่นไปแล้ว เวลเยอะๆหน่อยเอามาเปิด 2 จอ แชร์ให้ก็ขึ้นมะยากหรอก

แต่มันไม่หนุกอ่ะดิ-0-

คนเยอะขึ้นป่าวไม่รู้ง่ะ แต่รู้สึกเยอะก่าตอนที่ผมเลิกเล่นไปเมื่อปีที่แล้ว ฮ่าๆ

แต่ในเกทอย่าไปดูเลยว่าเยอะขึ้นป่าว 4ตัว บางทีคนเล่นคนเดียว (อย่างเช่นผม-0-)

ก็นะ ผมว่าเด๋วนี้คนที่เล่นใหม่แล้วเก็บเองยัน 60+ คงน้อยละอ่ะ คนเวลต่ำๆ เล่นใหม่ๆ เก็บเวลเองน้อยมาก อย่างว่าเกมมันนานแล้วน่ะ

แล้วที่สำคัญมันแชร์ได้ไม่กำหนดความต่างเวลที่นี้ก็คนเวลสูงก็ปั้นใหม่สบาย

ผมเล่นเองยัน 70 แค่ 2 ตัวเอง (ตัวพ่อ ตัวแม่) ตัวอื่นๆที่เหลือดูดตัวพ่อตัวแม่เอา พูดจิงๆช่วง เวล40-60 ประมาณนี้มั้งจำได้ว่าเป็นช่วงที่เวลค่อนข้างช้าจนน่าเบื่อ-0-
