:: ตำแหน่งตัวละครที่รับสมัครปัจจุบันของนิยาย :: Update : 16/1/08

1.ลอร์ด อเวซ เวโดเชล : ต้องเป็นพ่อค้า (เพศชายนะ)หน้าตาไม่เกี่ยง เลเวล 45 ขึ้นไปเผ่าอีมิลเท่านั้นค่ะเป็นพ่อค้ารวยที่สุดในฟาอีสซิตี้ มีบูสปาป้าที่ผม่าแก่ บ้าแต่งตัว เจ้าชู้ แต่รักเพื่อนมากๆ
ตัวละครตัวที่หนึ่งมีคนรับแสดงแล้ว

2.โรเซตต้า อลิซ : สาวสวยน่ารัก เพื่อนของลอร์ด อเวซ อาชีพ Vates เผ่า Titania
เท่านั้น ต้องใส่ชุดประจำอาชีพ เลเวล 35 ขึ้นไป บ้าแต่งตัว ใจดี
ตัวละครตัวที่สองมีคนรับแสดงแล้ว

3.เจ้าหญิงอเล็กซานเดรีย ออสเตรีย คิเมียน่า กวิเนเวียร์ ที่ 8 : เจ้าหญิงลึกลับที่ถูกกักขังในปราสาทอันเดทซึ่งเป็นปราสาทร้างที่ผีเต็มไปหมด ตำนานของเจ้าหญิงเป็นที่เล่าขานกันมา
แต่ว่า เจ้าหญิงองค์นี้อาจจะยังมีชีวิตอยู่ก็เป็นได้........ ขอเผ่าไททาเนีย ใส่ชุด Vates
เลเวล 75 ตาสีฟ้าสวยงดงาม ผมยาวสีทอง,สีน้ำตาล,สีดำ,สีเงิน เท่านั้นนะคะ
ตัวละครที่สามมีคนรับแสดงแล้ว

4.อัศวินสาว เฮเลน อะคีร่า : สาวนักรบเก่งกาจ อาชีพ Swordman หรือ Fencer ขึ้นไป
ใส่ชุดประจำอาชีพ เลเวล 75 ขึ้นไป เผ่าใดก็ได้ ตำนานเล่าขานกันว่า
เป็นทหารองค์รักษ์ประจำเจ้าหญิงอเล็กซานเดรีย มีเวทมนตร์ในตัวอยู่ เพราะบิดาของเธอได้มอบพลังของธาตุมืดให้ แต่ไม่เคยใช้มาก่อน แต่ว่า เธออาจจะยังมีชีวิตอยู่ก็เป็นได้........
ตัวละครที่สี่มีคนรับแสดงแล้ว

5.ราชาโคมุ : ราชาเชื้อญี่ปุ่นแห่งเมืองนอร์ทเทอร์น ผู้ครอบครองแหวนวิเศษ เคยเป็นอัศวินที่เก่งกาจและชำนาญการต่อสู้เป็นอย่างมาก ขอเผ่าอีมิลหรือเดวิล อาชีพสายไฟท์เตอร์ยกเว้น Archer เลเวล 45 ขึ้นไป
ตัวละครตัวที่ห้ามีคนรับแสดงแล้ว

6.ราชินีราเชล : เปลี่ยน (ถ่ายราชีนีที่เมืองเหนือแทน)

7.หนุ่ม/สาว ผจญภัยสาย BP ชื่อตามใจชอบ ขอภาษาอังกฤษหรือไม่ก็ ภาษาญี่ปุ่น เกาหลีอะไรได้หมด อย่าเอาชื่อไทยนะงิ ^^"
ตัวละครตัวที่เจ็ดสองตัวมีคนรับแสดงแล้ว

8.ชาแมน ชื่อตามใจชอบ ขอชื่อภาษาอังกฤษ ญีปุ่น กรุณาอย่าใช้ชื่อไทยนะคะ
เผ่าไททาเนีย โดมิเนียน หรืออีมิล ใส่ชุดประจำอาชีพเลเวล 70 ขึ้นไป
ตัวละครตัวที่แปดมีคนรับแสดงแล้ว

9.หมาป่าดำ : เป็นหมาป่าดำที่ขี้เล่นผิดกับพวกเพื่อนๆจึงไม่สามารถอยู่กับเพื่อนๆได้จึงต้องมาอยู่ร่วมกับมนุษย์
ตัวละครตัวที่เก้ามีคนรับแสดงแล้ว

10.GramSypia : พี่ชายของ GinnySypia เบลดมาสเตอร์ที่เชี่ยวชาญในด้านการรบและมีนิสัยชอบเกรียน :twisted:
ตัวละครตัวที่สิบมีคนรับแสดงแล้ว

11.ทหารประกอบ : ทหารประกอบฉากต้องการ 2 คน ใครสนใจลงชื่อไว้ที่นี่เลยนะคะ
ขออาชีพสาย Fighter เท่านั้นนะคะ ใส่ชุดประจำอาชีพ เลเวล 35 ขึ้นไป
