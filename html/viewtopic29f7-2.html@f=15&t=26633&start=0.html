นี่เอเลคับเพ่ ถ้าไม่อยากได้สกิลพวกพายุทาด อัพไปเราไม่ว่าไรหรอกนะ

แต่ดองสกิลพ๊อยไปอัพพวกพายุจะดีกว่า ใช้เกบเวลได้ดีกว่าสกิลพวกคำสาปได้แน่แหละ

อีกอย่าง ตอนจ๊อบแรก เราไม่มีสกิลพวกคำสาป การอัพ INT จึงไม่ค่อยได้อัพ

พอจ๊อบสองแล้ว การใช้สกิลพวกนี้จะลำบากมากกก อัพไป โอกาสติดก็ยาก

คำแนะนำของผมคือ ดองสกิลไว้อัพพายุ เพราะผมเล่นมาแล้ว ชาแมนเล่นคำสาปไม่รุ่งหรอกคับ
