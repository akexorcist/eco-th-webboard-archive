ไม่ใช่เรยครับ
การเปลี่ยนอาชีพไนท์นั้นไม่จำเปนต้องมีสกิวอะไรเรย
แค่จอบเลเวล 30+ ก็พอครับ ผ่านเปลี่ยนได้เรย
แต่คงตีมอนคนเดียวไม่ไหวนะครับ
ควนเล่นจอบเวล 50 เพราะจะได้มีสกิวใช้เยอะ ๆ สกิวหลัก ๆ ที่ผมใช้คือ BanishBow ครับ เพราะแรงดี ผมใช้สกิวเดียวนี่แหละ เพราะที่เหลือเปนแบบติดตัว ( ผมสายวิดครับ )
ไม่ควนดองจอบไว้จน เวล 28 ค่อยอัพสกิวโจมตีนะครับ ควนอัพแต่ต้นแล้วไปรีเอาออกซะ จาเก็บเวลง่ายกว่าครับ

สรุปแล้ว สกิวไม่มีผลต่อการเปลี่ยนอาชีกเรย ขอแค่จอบ 30 + ก็เกินพอครับ จบข่าว
