มะนิว กิ๊วๆ เขียน:stun short นี่โอกาสติด 50 50 ป๊ะ กับ Tearing Grenade ที่โดนเปนกลุ่มแบบไหนดีกว่ากันอะคับคุณๆ

ส่วน Charge โอกาสที่จะไม่ถอยไปก็มีใช่ไหมคับ(หรือยิงไงก็ถอยตลอดๆ)


สตัน ช๊อต โอกาศติดขึ้นกับ int ครับ แต่จิงๆ มันก็ดวงด้วยแหละ บางทียิงแล้วติดบ่อยๆ กะมี บางทีไม่ติดเลยกะมี

อย่างผมนี่ไม่มี int เลย บางทีก็สตันติดถี่เหมือนกัน เหมือนกับว่าผ่านที่คุณจะยิงมี int น้อยก็ติดง่าย ประมาณนั้น ผมคิดเอาเองนะเหอๆ

Tearing ยิงเป็นกลุ่มจริง แต่ใช้งานลำบากคับ มันไม่ไวเท่าสตันน่ะ แถมต้องมาเปลี่ยนกระสุนอีก

Charge เท่าที่เล่นๆ มาถอยหมดนะครับ ยกเว้น เบลด ร่ายสกิล โซลิดบอดี้ ถ้ายิงไปแล้วจะไม่ถอย
