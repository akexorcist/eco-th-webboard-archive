รวมรูปกิจกรรมจุดพลุถวายพระพรในหลวงของเรา ทั้ง 2 Sv (โหลดโหด)

โพสต์แล้ว: พุธ 05 ธ.ค. 2007 10:50 pm
โดย ECO
วันนี้เวลา 19.00 น. ณ เกาะไทนี่พวกเราชาว Eco ได้รวมตัวกัน
จุดพลุถวายพระพร เนื่องในปีมหามงคลที่ในหลวงของเรามีพระชนมายุครบ 80 พรรษา
และมีผู้เล่นให้ความสนใจและมาร่วมกันจุดพลุเป็นจำนวนมาก จนรู้สึกอบอุ่นเลยทีเดียวค่ะ ^^
ซึ่งในตอนแรกก็มีติดๆ ขัดๆ บ้างต้องขออภัยด้วยนะคะ ซึ่งมีผู้เล่นส่วนใหญ่ไม่สามารถซื้อพลุได้
ซึ่งก็มี GM ลงไปแจกพลุทั้ง 2 Sv ในเวลาก่อนจะเริ่มจุดพลุและมีผู้เล่นหลายๆ คนที่มีน้ำใจ
แบ่งปันพลุให้เพื่อนๆ ที่ยังไม่ได้มากมายทีเดียวเห็นแล้วปลื้มค่ะ =^^=

มาดูรูปกันดีกว่าใครติดมาบ้างก็หาดูเอานะคะ แหะๆ

Sv. Moji










Sv. Takoyaki












ต้องยกความสมัคคีให้ชาว Takoyaki เป็นพิเศษค่ะที่สามารถแปลขบวน
เป็นเลข 80 ได้อย่างไม่ได้นัดหมาย เนื่องจากมีผู้เล่น (จำชื่อไม่ได้ โทษทีค่ะ = =) ได้ pm รีเควสมา
ว่าอยากให้แปลขบวนเป็น 80 ซึ่งชาว Takoyaki นั้นให้ความร่วมมือเป็นอย่างดีเลยได้ภาพประทับใจ
มาอย่างที่เห็นค่ะ เก่งมากๆ ^^

ชาว Moji อย่าน้อยใจน๊า ไว้งานหน้าเราทำกันบ้าง :wink:
