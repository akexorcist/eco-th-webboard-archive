เอาOs มาลงด้วยดีกว่า จะได้ไปควบคู่กับอาวุธ
ช่วงนี้ลงช้าหน่อยน้า เพราะคิดไม่ค่อยออก ใครคิดออกก็ช่วยๆกันคิดหน่อย

บอกไว้ก่อน tech point หมายถึงความพัฒนาทางด้านคอมพิวเตอร์ของผู้เล่น โดยสามารถพัฒนาได้โดยการจ่ายเงินให้คนที่เปลี่ยนอาชีพ มูลค่าอยู่ที่10 G = 1 tech point
เมื่อtech pointถึงระดับของOsถัดไป ผู้เล่นจะเปลี่ยนOs หรือรอจนข้ามระดับไปอีกระดับหนึ่งแล้วค่อยเปลี่ยนOsก็ได้

เมื่อเปลี่ยนOs แล้ว Tech pointจะไม่ลด
------
Os คือระบบปฏิบัติการณ์ของคอมพิวเตอร์ เป็นโปรแกรมหลักที่จะใช้เมื่อเปิดคอมพิวเตอร์

เรียงตามลำดับเก่า - ใหม่

Ms - Dos
ต้องการเลเวล1
เมื่อเปลี่ยนอาชีพเป็นWebboard user ก็จะใช้OS ตัวนี้เป็นพื้นฐานเลย
ความเร็วในการประมวลผล ต่ำมากกกก
ข้อดีคือ เปลี่ยนอาชีพปุ๊บ ได้เลย
แต่ความแรงในการโจมตีจะลดลง30%(หากใส่อาวุธเป็นคีย์บอร์ดหรือเมาส์)
ค่าTech point 0

Windows 5.1(ใช่ป่าวหว่า รุ่นเก่าๆมากๆๆ)
ไม่สามารถใส่เมาส์ได้ ความแรงในการโจมตีลดลง20%(หากใส่อาวุธเป็นคีย์บอร์ดหรือเมาส์)
Tech point 50

windows 95
ใส่เมาส์ได้แล้ว ความแรงในการโจมตีลดลงเพียง10%(หากใส่อาวุธเป็นคีย์บอร์ดหรือเมาส์)
แต่ไม่สามารถใช้เมาส์กับคีย์บอร์ดพร้อมกันได้
เมื่อใช้แล้วจะมีโอกาสError 1% ทุกๆ1ชั่วโมง
tech point 100

Windows 98
ใส่เมาส์กับคีย์บอร์ดพร้อมกันได้ ความแรงในการโจมตีลดลง5%
ความเร็วในการโจมตีลดลง5%(หากใส่อาวุธเป็นคีย์บอร์ดหรือเมาส์)
tech point 250

Windows NT
เป็นOsที่ออกจะใหม่แล้ว รองรับระบบเซิฟเวอร์ ทำให้สามารถออน2ตัวได้พร้อมกัน
แต่ว่ายังคงมีปัญหาเรื่องความเข้ากันกับไอเท็มใหม่ๆ
Tech point 500
