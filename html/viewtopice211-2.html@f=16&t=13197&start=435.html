ZAN-zi-BAN เขียน:หวัดดีครับ
ติดตามกระทู้นี้มานานแล้ว ขอบคุนสำหรับทุกข้อมูลนะครับ เยี่ยมจิงๆเลย

เล่นสายBPทั้งAccoutเลยครับ ชอบรู้สึกว่าskillผลิตของมันเยอะดี

ได้อ่านแต่หัวข้อของคนอื่น
วันนี้ผมขอถามบ้างนะครับ
1.คือถ้าผมจาทำตะกร้ากะเป้เองเนี่ย ใช้ทุนแพงกว่าซื้อของไม๊ครับ คือไหนๆเล่นBPแล้วก้ออยากจะผลิตของใส่เอง มันภูมิใจไงบอกมะถูก(เกี่ยวมะเนี่ย ) แล้วมีnpcเย็บผ้าป่ะครับ
เพราะกว่าเราจาเย็บได้เอง ต้องJobLv.25เลยอะ - -'
- คิดว่า ถูกกว่าครับ กับตะกร้าเนี่ย ราคาที่เคยเห็นผู้เล่นอื่นขาย จะอยู่ที่ประมาณ 60k
แต่ราคาวัตถุดิบที่ทำเองหากไม่คิด สกิล DC(ของสายพ่อค้าแม่ค้า) จะอยู่ที่ 21400 g
โดยอ้างอิงจาก กระทู้นี้<<<Click!!!
ส่วนกระเป๋านั้น ราคาวัตถุดิบกับ ราคาขายนั้นพอๆ กันเลยครับ เลือกได้ทั้ง 2 ทางครับ
- NPC ตัดเย็บนั้น ก็คือ คุณป้า ที่เราไปทำเควส เนโกะมาตะ โมโมะน่ะล่ะครับ
โดยเลือกหัวข้อ "สั่งงานตัดเย็บ" น่ะครับ

2.npcทำอาหารไม่มีใช่ป่ะครับ ใช้สกิลCookingของเราอย่างเดียว
- มีครับ NPC ชื่อ Aunt of Restuarant ที่อยู่ตาม 4 มุมเมืองของเมือง Acropolis อ่ะครับ
โดยเลือกหัวข้อ "ขออาหาร" น่ะครับ

3.Light Skill Wood ดรอปอะไรนอกจาก กิ่งไม้มะครับ แล้วมันเอาไปทำอะไรได้อีกนอกจากลูกธนูป่ะครับ ถ้ามันทำได้แค่นั้นจาได้ไม่ไปยุ่งกะมันอีก :x
- จากที่ผมเคยถามได้ความ "อย่าไปสนใจมันเลยครับ" -*-

4.ผมเก็บเวลโดยทำเควสเป็นหลักเพราะมี3ตัวก้อผลัดๆกัน คืออยากได้ข้อคิดเห็น
หน่อยน่ะครับ คือส่วนใหญ่ผมจะรับเควสโจมตีที่QuestCounterในช่วง1-14อะครับ
เพราะมันให้JobLv.เยอะเงินก้อดีด้วย แต่ให้EXPน้อยมาก ซึ่งก้อไม่เป็นไรเพราะผมคิดว่าJobLv.น่าจำสำคัญกว่าทำให้เราได้สกิลมาใช้อย่างรวดเร็ว แต่พอถึง14นี่คิดหนักครับ ว่าจารับเควสโจมตีหรือเควสอาชีพดี เพราะ เควสอาชีพมันให้EXPค่อนข้างสูงแระ แต่JobLv.กะเงินก้อให้น้อยกว่าเควสโจมตีอยู่ดี อยากถามว่าน่าจารับทำเควสไหนมากกว่ากันครับ
- ถ้ามีเวลาเล่นทั้ง 3 ตัว ก็เลือกได้ทั้งเควสโจมตี และ เควสอาชีพเลยครับ สลับๆ กันไปก็ได้ ^^

5.การReSkill กะ ReStatus ครั้งแรกฟรีหรอครับ มีเงื่อนไขอะไรป่ะ จะได้อัพBlow แล้วค่อยเปลี่ยนไปเป็นBanish Blow เห็งบอกว่าแรงกว่า10%
- ฟรีครับ ครั้งแรกไม่มีเงื่อนไขอะไรเลย

6.พวกบัตรผ่านประตูเมืองทั้ง4ทิศ เราหาซื้อได้จากที่ไหนบ้างครับ
- เมืองเหนือ ซื้อได้ที่ NPC ที่เราเปลี่ยนอาชีพของสาย Spell User โดยให้สาย Spell User ซื้อ
- เมืองใต้ ซื้อได้ที่ NPC เปลี่ยนของสาย Fighter โดยให้สาย Fighter ซื้อ
- เมืองตะวันออก ซื้อได้ที่ NPC เปลี่ยนอาชีพของสาย BP โดยให้สาย BP ซื้อ
(บัตรผ่านเมืองตะวันออกคุ้มสุด ลงทุนครั้งเดียว ผ่านได้ตลอดชีพเลย)
- บัตรผ่านเมืองตะวันตกไม่มี เพราะทางตะวันไม่มีเมือง

7.ทำอาหารอะไรขายดีครับ ที่เป็นที่ต้องการของตลาด ขายได้เท่าไหร่ ขายที่ไหน
- เอาจากประสบการณ์ของผมนะครับ ที่ผมทำตอนนี้ก็มี
1. แซนวิซ (ทั้งธรรมดา และ แซนวิซไข่)
2. แกงกะหรี่ (เพิ่ม 300)
3. แกงกะหรี่ (เพิ่ม 500)
4. Cherry Jam
5. Grape Jam
ทั้งหมดนี้ วัตถุดิบหาง่ายครับ
นอกนั้นแล้วแต่จะสนใจครับ
ส่วนขายที่ไหนนั้น ก็ได้ทั้งเมืองเหนือ และเมืองใต้ครับ

8.ผมเห็นในกระทู้ของRide Crawlerมาอะครับ คำว่า "การชุบเลี้ยง"
