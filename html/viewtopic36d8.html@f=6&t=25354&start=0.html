ขอพูดไรก่อนนิดนึง .. ไม่มีรูปให้ดูแต่ต้นนะ คือว่า


มีคนคุยกัน แล้วเราได้ยิน ว่า มังกร แลกบัตร


A :: บอก แลกกะบัตร 150
B :: บัตร 300
A :: ได้ๆๆ
B :: เดินไปห่างๆ
A :: ตามไปคุยๆเจรจา กับ คนโกง

ไปดูรูปเลยดีกว่า โกงยังไง



Stage 1




รูปที่ 1 เรา เปนคนเดลไป กดไปก่อน 1m มันใส่มังกรมา

หลังจากนั้น ดูรุปต่อปาย~~


Stage 2





รูปที่ 2 คลิก ดู คุณสมบัติ มังกร อ้า ถูกชิบ... แล้ว เรา ก็ กด Ok ปาย แล้ว ทันใด คลิกดูอีกที ...ก็ hock: hock:




Stage 3





มังกร ล้ม หาย ไรอ่า โกงกันด้านๆ *-*



จบแล้ว วิจารณ์ ได้ๆ-*-


ปล. ผิดสังเกตุอะ เลย กดเดลไปเลย 1m ดูดิ +100 ของแกเปนไง

เดลไปประมาณ 4 รอบ กดเงินไปทุกรอบ มันก้อให้ดูมังกร ล้ม 2 จนตายใจ

แล้วค่อย พิชิต ใจ ด้วย มังกร หัวขวด *-*


แต่ว่า มาหลอกเราไม่ได้ แต่คนอื่น ระวังนะ เดลเกมนี้มัน มี 2ที

คลิกเช้คสถาพสินค้ากันก่อน นะ ไม่งั้นอาจซวย -*-





อยากรุ้จัง ตัวหลักแม้ง ชื่อไร เลวทราม


ก่อนมาลงบอร์ด มัน เปลี่ยนเปน มังกร หัวขวดใช่มะ เลยพิมไป


อืม ลงบอร์ดแปป สะใจ แม้งยกเลิก เดินหน้าเข้า Downtown เลย-.-
