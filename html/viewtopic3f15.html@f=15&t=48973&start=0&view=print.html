20-30 ลองไปที่มอคคิบ หรือวอสชิบอิสแลน
30-40 ลองไปหาตี้ที่โวโคโน่นะ
40-50 ลองไปหาตี้ดันใต้
50-60 ลองหาตี้หอแสง
60-70 ลองไปที่ฟูจิกิหาตี้
70-80 ไปหาตี้ลงดันสิ หาเอเลไปสักคน
80-90 พี่รู้ว่าน้องคงมีปัญญาเก็บเองแล้วละ
