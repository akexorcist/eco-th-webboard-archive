เห็นตอนนี้ red talisman ราคามันประมาณ 300k ได้ (เซิร์ฟทาโกนะ) เลยมีคำถามขึ้นมาคับ
1. คุ้มกะราคามั้ยครับ
2. พลังโจมตีเพิ่มขึ้นมากรึเปล่า (แบบว่าใช้แล้วเห็นผลเลยรึเปล่า)
3. อนาคตราคามันจะมากขึ้นหรือน้อยลงครับ กลัวซื้อมาผ่านไปอีกเดือน ราคาเหลือ 150k
(เว่อร์ไปมั้ยเนี่ย + - +)

ปล. ใครจะรู้ คนขี่มังกรร่อนไปร่อนมา ตอนนี้มีตังยังไม่ถึงแสนเลย - -lll (ดรอปได้มาตัวนึง)
