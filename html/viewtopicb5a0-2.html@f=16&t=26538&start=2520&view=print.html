งืม ทำอาหารก็ตามลิงค์นั้นล่ะนะ
ปลูกผักนี่ ถ้าไม่ชอบสะสมเมล็ดก็อาจจะไม่จำเป็นต้องใช้น่ะ
ประโยชน์อีกอย่างของปราชญ์ต้นไม้คือทำให้ตีต้นผลไม้แล้วดรอปผลไม้ขั้นสูงด้วย ส่วนตีไม้สร้างบ้านก็ตามนั้น ตั้งแต่ใบเรือซึ่งเป็นวัสดุเริ่มแรกในการทำฟลายอิ้งการ์เด็นก็ต้องใช้ไม้ log แล้ว รวมไปถึงเฟอร์นิเจอร์ต่าง ๆ มักมีไม้เป็นส่วนประกอบโดยทั้งสิ้น ถ้าต้องการสร้างบ้านและแต่งบ้านด้วยตัวเองไม่ต้องไปเสียเงินซื้อไม้จากคนอื่น ก็น่าอับนะสกิลนี้ แต่ก็อย่างว่า ถ้าไม่ทำบ้านก็คงไม่ค่อยมีประโยชน์ อย่างมากก็ใช้ตีไม้เอาไม้ไปขายหาตังกับหาผลไม้ดี ๆ มาทำเป็นผลไม้แห้งเท่านั้น : (
