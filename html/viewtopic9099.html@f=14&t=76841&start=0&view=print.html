เธอจ๋า เอาไปถามในบอร์ดไกด์ก้อได้ เพื่อว่าถ้ามีคนถามภายหลังจะได้อ่านในนั้นไปในตัว

ปืน 3 แบบ ความเร็วการยิงต่างกัน จำนวนกระสุนที่ใช้ก็ต่างกัน รวมทั้งระยะยิง และความคล่องตัว

ไม่ชำนาญเป็นพิเศษแต่ก็พอมีประสบการณ์ในการใช้บ้าง

ปืนพก : ความเร็วระดับกลาง การหน่วงเวลาสกิล ระดับดี ความสวยงามในการถือ ดี ระยะยิง ประมาณ 4 ช่อง ความคล่องตัว ดี
ปืนพกคู่ : ความเร็วเหลือครึ่งนึงของปืนพกปกติ หน่วงเวลาสกิล ปานกลาง ความสวยงามการถือ ดีมาก ระยะยิงประมาณ 4 ช่อง ความคล่องตัว ต่ำ จำนวนกระสุนที่ใช้ สูง ความรุนแรงในการยิง สูงเพราะใช้กระสุนเพิ่ม
ไรเฟิล : เป็นที่ยอมรับกันว่า เป็นอาวุธที่ดีที่สุด สำหรับปืน ระยะยิงไกล 7 ช่อง ความคล่องตัว สูง ความเร็ว สูง หน่วงเวลาสกิลน้อยมาก ความรุนแรงในการยิงพอๆกับปืนพก ความสวยงามในการถือปานกลาง
