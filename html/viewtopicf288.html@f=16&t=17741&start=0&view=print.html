คือไม่อยากหาว่าตัวเองงกหรือไรหรอกนะคะ แต่อาชีพสาย BPคือสายหาเงิน อย่างพวกของที่เฉพาะแรงเจอ ทาตีตกได้สังเกตุไหมคะว่าราคามันคงตัวแล้ว คือไม่มีคนตัดราคากันเวอร์เกินไปอ่ะค่ะ ขอรบกวนชาวนาช่วยกันปรับราคาให้สมดุลไม่ต้องกัวขายกันไม่ออกหรอกค่ะ คนนึงก็ต้องใช้12กลีบ แถม1ไอดีมีตั้ง3ตัว ช่วยขายๆให้ราคาเท่าๆกานนิดนึงนะคะ
อย่างเราตั้งขายทุกอันอันละ5000ก็ออกหมด วันก่อนเห็นพันนิดๆ แล้วคิดว่าถ้ามีแต่คนตัดราคาอีกหน่อยคงเหลือกลีบละ1000 ทั้งๆที่เราว่าก้อตีตกยากพอควร แถมยังหายากอีก แมพนึงก็มีน้อย รบกวนออกความเห็นด้วยนะ

เหตุผลที่ขอขุด >>ทำไมเดี๋ยวนี้แข่งกันขายจัง กลีบละ2000 -*-
ถ้าคงราคาขั้นต่ำไว้4000ทุกคนก้อน่าจะไม่มีปัญหานิ แล้วสีที่หายากๆก็ค่อยขายแพง
ชาวนานี่กะจะไม่คิดจารวยกันเลยหรอ ยังไงเควสนี้ก็ต้องพึ่งชาวนา ลู่ทางหาเงินอาชีพนี้ยิ่งน้อยๆอยู่อย่ามาตัดราคากันเองเลยค่ะ แทนที่คุณจะตีได้20กลีบขาย4000 ก้อได้ไป80เคละ ขายไป2000เงินที่ควรได้หายไปตั้ง40เคนะ แถมเสียเวลาหากลีบมากขึ้นอีก(ไม่ใช่ขายเน้นปริมาณ เอาเวลาไปหาอย่างอื่นมั่ง ดันมาตัดราคากันเอง)

ใครจะว่าเรางกก็ไม่เป็นไรค่ะ ก็ตังมันหายากนิ ไม่มีปัญญาไปตีบอสโหดๆ หาของแรร์กะเค้า
พวกเวลเด็กๆแทนที่จะมีตังตั้งตัวเร็ว มาแย่งกันขายงี้ มะไหร่นู๋จารวยล่ะ
สามัคคีกันนิดนึง อาชีพเดียวกันอย่ามาตบกันเองเลย
