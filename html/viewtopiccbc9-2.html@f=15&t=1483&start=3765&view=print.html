ว่าด้วยเรื่องของกำแพงดินครับ :P (ใครอยู่เชียงใหม่อย่าคิดไปไกลนะ)

พอดีเพิ่งอัพกำแพงดินมาลองใช้ดู พบว่าบางทีร่ายมอนก็ไม่ติดกำแพง(เดินทะลุผ่านมาเฉย)

แต่บางทีร่ายก็ติดกำแพง ลองหลายทีแล้ว หาจังหวะ+จุดที่ลงตัวไม่ได้ซักที ตอนร่ายกำแพงมอนจะต้องอยู่ห่างเราไปกี่ช่อง หรืออย่างน้อยๆ มันต้องอยู่ในหน้าจอเราหรือเปล่า?

ว่าด้วยเรื่องของค่า stat กันต่อที่ผมยังคาใจไม่หายกับค่า Int และ Mag

เท่าที่ลองหาข้อมูลมา ค่า Int จะช่วยในเรื่องของคำสาปมากกว่า สาปติดไม่ติดหรือเราจะติดคำสาปง่ายหรือยากขึ้นอยู่กับค่านี้ ไม่รู้เข้าใจถูกหรือเปล่า?

ถ้าอย่างนั้นชาแมนอย่างเราๆ ก็อาจไม่จำเป็นต้องใช้ Int เลย ทุ่ม Mag ไปเลยดีกว่า?

แต่ทีนี้ค่า Min M.atk ของผมมันค่อนข้างห่างกับค่า Max m.atk อยู่มาก (เวล 37/37 Min-Max = 145-210)
ทีนี้เลยลองหันไปอัพ Int ดูบ้าง (เหมือนจะอัพได้โบนัสล่ะมั้ง ผมไม่ค่อยชัวร์)

ค่าที่เพิ่มก็มี Min m.atk 145 --> 146
L.avoid , MDEF , MaxSP ตามนี้ครับ

มันเพิ่ม Min m.atk ด้วย- -!! แล้วตกลงชาแมนต้องอัพ Int เผื่อไว้ซักเท่าไรถึงจะโอเคครับ?
เพื่อนๆ อัพไว้เท่าไรกันบ้างเอ่ย?

กำแพงดินส่วนมากไม่ค่อยมีคนใช้กันมอนเท่าไรนะ ถ้ากันมอนใช้กำแพงไฟจะโอเคกว่า (กันแล้วยิงกลับ)

อัพไว้เหมือนกันกำแพงดิน แต่ไมได้ใช้กันมอนเท่าไร เพราะถ้ารำคาญก็วิ่งหนียาวไม่ก็ฆ่ามันตรงนั้นเลย - -

ส่วนค่า Int ก็เพิ่มมาตามที่เห็นนั่นละ ส่วนมากไม่รู้อัพสเตตัสกันยังไงนะตรงจุดนี้ แล้วแต่ความชอบของคน

บางคนก็ชอบที่จะไปเพิ่มความแรง M.atk และ M.def โดยการลง Int ส่วนบางคนก็ชอบที่

จะเลือดเยอะขึ้นและเพิ่ม Def ด้วยการอัพ Vit ตรงนี้ก็แล้วแต่คนอ่ะนะ ชอบแบบไหนก็อัพแบบนั้นไป

ยังไงสายชาแมนค่าสเตตัสหลักๆส่วนใหญ่มันก็ Mag Dex อยู่แล้ว ที่เหลือก็ตามใจชอบและสไตล์ของแต่ละคน
