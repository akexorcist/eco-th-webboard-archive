ในขณะเดียวกัน มีชายผู้หนึ่ง เดินท่ามกลางแสงอาทิตย์ยามเย็น ดูจากท่าทางการเดินแบบไร้วิญญาณแล้ว เขาเหมือนคนสิ้นหวังจากบางสิ่งที่บุคคลธรรมดามิอาจเข้าใจได้

แสงอาทิตย์ส่อง เผยให้เห็นใบหน้าของเค้า เค้ามีผมค่อนข้างยาวและมีสีทองธรรมชาติ ถูกจัดทรงให้มาปิดตาซ้าย คิ้วที่เห็นมีหางม้วนดูทรงพลัง ไว้เคราเล็กน้อย จัดได้ว่าหน้าตาดีในระดับหนึ่ง แต่สีหน้าของชายผู้นี้กลับขัดแย้งกับลักษณะหน้าตาของตัวเอง เค้ากำลังเศร้าหมองอย่างหนัก และอาจจะพร้อมที่จะฆ่าตัวตายได้ทุกเมื่อ
