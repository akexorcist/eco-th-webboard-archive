เนื่องจากทางเซิฟญี่ปุ่นเกิดมีผู้เล่นที่ถูก Account Hacking หลายราย
ทาง Gungho จึงประกาศรณรงค์ให้ผู้เล่น ทำ ID Lock หรือใช้ One Time Password (OTP)
เพื่อเพิ่มความปลอดภัยของ Account ให้มากขึ้น

ผมจึงตั้งกระทู้นี้มาบอกต่อ เพื่อความปลอดภัยของตัวละครที่น่ารักของท่าน

วิธีการตั้งค่า ID lock สำหรับผู้เล่นอีโค่เซิฟเวอร์ JP
