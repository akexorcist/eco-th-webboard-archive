ผมมีข้อสงสัยเกี่ยวกับ Skill ทั้ง 3 อย่างนี้นะครับ

Go!
เป็นคำสั่งโจมตีที่ใช้ได้กับ Pet ทุกชนิด

Grinder Attack
เป็นคำสั่งโจมตีที่ใช้ได้กับ Pet ประเภทสุนัขเท่้านั้น (แต่ได้ความแรงเพิ่ม)

Pincer Attack
เป็นท่าที่เราต้องสั่งให้สุนัขไปกัดเป้าหมายก่อนแล้วเราค่อยใช้ท่านี้ซ้ำตาม

ไม่ทราบว่าผมเข้าใจถูกหรือเปล่าครับ คือผมกำลังหนักใจกับการอัพท่่าพวกนี้นะครับ กลัวเสีย Point ไปฟรีๆนะครับ (ขนาดอ่านในเว็บแล้วยังงงเลย)

ผู้รู้ช่วยไขความกระจ่างทีครับ

1. Princer Attack เนี่ย กดใช้ในขณะที่ เรากับหมา โจมตีมอนตัวเดียวกันก็พอใช่เปล่า

อธิบายไงดี

Pincer ใช้สำหรับควบคู่กับการวางกับดักได้นะ

O = เรา
๐ = หมา
x = ศัตรู

1) O๐ x

2) ๐O ---> x พอเราเริ่มเดินเข้าไปหา หมาจะออกตัวช้ากว่านิดหน่อยแล้วตามหลัง

3) ๐ O x จังหวะที่เราประชิดตัว หมาจะทิ้งเราไกลประมาณนี้

4) ๐ x O พอเราเดินไปข้างหลังมอน/ศัตรู หมาก็จะอยู่หน้ามอน ก็เป็นระหว่างกลางพอดี

จังหวะนี้เอาหมาหวดนำได้เลย แล้วก็วางกับดักให้มันตาม (กรณี NvN/ล่าบอส) ก็ได้

ส่วนหลังจากกด Pincer/Grinder ผมไม่เคยสังเกตว่าหมามันตีต่อมั้ย เพราะผมจะ
สั่งเก็บหมาทันที แต่คิดว่ามันน่าจะตีธรรมดาต่ออัตโนมัตินะครับ
