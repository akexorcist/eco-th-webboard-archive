โพสต์แล้ว: อังคาร 07 ต.ค. 2008 1:57 pm
โดย ECO
อย่างที่ตอบมา รวบรวมจากสามท่านข้างบนอีกรอบ

1. สามารถเข้าเมืองทิศที่สังกัดเป็นทหารได้เรื่อยๆ ไม่ต้องใช้บัตรเข้า
2. รับชุดทหารประจำทิศได้ที่กองกำลังสังกัด ชุดเวล???? จำมะได้ :?
3. เมื่อใช้บ้านบิน สามารถบินเข้าไปในเขตเมืองที่สังกัดได้
4. เควสพิเศษเพิ่มเติม รับได้ที่ทหารประจำทิศ (แต่ผมไม่เคยรับเลยแฮะ - -)
5. ส่ง ruin report ให้ทิศตนเองเพื่อรับชุดได้
ที่จริงมันจะสร้างบ้านลอยฟ้าประจำทิศได้อีกด้วย (แต่ก็นะ มันไม่ได้แล้วแหละ)

ผมอ่านเร็วไปหน่อย - - ถามข้อเสียด้วยนี่นา
ข้อเสีย
1. เข้าร้านค้าลับที่ดาวทาวน์ไม่ได้
2. ไม่สามารถถอนตัว หรือเปลี่ยนกลุ่มกองกำลังได้อีก
นึกไม่ออกละ
