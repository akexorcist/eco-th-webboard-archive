อยากถามว่ามีคนลองทำยัง?

คือผมก็ทำไปมั่วๆ

แต่ไปต่อไม่ได้

ในบอร์ดก็ไม่มีใครเอามาลง(หรือผมแค่หาไม่เจอยัง)

ผมใช้ตัวละครเผ่าTitaniaนะครับไปทำ
event ประมาณไปคุยที่ office ที่ West port city
แล้วให้ไปตาม Emil Masha Berial กลับมา
พอผมตามกลับมาหมดก็มีประชุมอะไรสักอย่างที่Office(ให้อ่านเยอะมากเลยไม่ได้อ่าน....)
ต่อจากนั้นก็เป็นก็วาร์ปไปWest port city (ที่ไม่ใช่แมปปกติ) แล้วก็ตามคุยก็คนในแมปเรื่อยๆคุยครบมันจะให้ตอบว่า "นอน" (ผมก็ไม่รู้ว่าต้องคุยกับตัวไหนบ้างเจอตัวไหนก็คุยมั่วให้หมด)
จากนั้นมันก็ให้ไปที่Mapใต้ดินเกาะเรือรบไปคุยกับ พวกของEmil คุยเสร็จมันก็วิ่งเข้าไปในแมปที่จะเป็นเหมือนในท่อระบายน้ำ......จากนั้นผมก็ไม่รู้จะทำยังไงต่อ

ฝากผู้รู้ช่วยทีนะครับจนปัญญาจริงๆไปต่อไม่ได้
แถม Event Navigation ก็ชี้ไปที่Office ในเมือง West port ตลอด(ไม่ช่วยอะไรเลยจริงๆ)
เลยทำเควสต่อไม่ได้




ปล.มอนเตอร์ในแมปท่อระบายน้ำดรอปของเอาไปทำเควสอะไรหรือเปล่า?ตอนนี้เก็บไว้หนักมากมาย
