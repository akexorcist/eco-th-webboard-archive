เปลี่ยนร่างโดยใช้ของแคชครับ (แพงเอาเรื่องอยู่ )
สกิลอาวุธเป็นเหมือนสกิลอาวุธ 99 แต่เป็นสีฟ้าครับ ที่ต้องผ่านอีเวนท์อาวุธ110มาเองถึงจะใช้ได้(ใช้ได้แค่ร่างอาวุธนะ)

สกิล : 竜眼開放・極(อาวุธ Lv110)
ประเภท : Active
ใช้ SP150/MP150
ร่าย : 2 วิ
ดีเลย์ : 1 วิ
ไม่สามารถใช้ในขณะสิงได้
ข้อกำหนดเบื้องต้น : ต้องถืออาวุธ 110
เงื่อนไข : ผ่านอีเวนท์อาวุธ 110
เป้าหมาย : ตัวเอง
Effect : ปลดปล่อยพลังที่แท้จริงของอาวุธในช่วงเวลาหนึ่งเพื่อเพิ่มพลังโจมตีให้กับผู้ใช้
    - เพิ่มดาเมท 1.5 เท่า ในระยะเวลา 120 วิ
