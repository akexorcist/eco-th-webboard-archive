วิธีคำนวนให้เอา Cspd หาร 1000 = X
X คูณ เวลาร่ายของสกิล = เวลาที่ลดลงไป

ผมกำลังจะสื่อว่า ไม่ว่าสกิลจะร่ายเร็วหรือร่ายช้าแค่ไหน ไม่มีทางเกิดอาการ"ไม่ร่าย"
ยกเว้นว่ามันเป็นสกิลที่ไม่ร่ายอยู่แล้ว วิธีคิด Aspd กับ Cspd จะเหมือนกันนะ

ถ้ามี Cspd 800 ร่ายแครอท 7 วิก็ลดลงไป 5.6 วิ เหลือ 1.4 วินาที

หวังว่าคงเข้าใจนะ

ปล.ถ้าไม่อยากร่ายเอาแบบปุ๊บปั๊บฉับไวก็ทำให้ spd เป็น 1000 สิ
