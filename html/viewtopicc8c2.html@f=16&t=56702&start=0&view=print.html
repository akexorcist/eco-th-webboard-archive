ครับ แล้วแต่ความชอบ สำหรับผมทาทา(เลยไปถึง BS และแมชชีนด้วย) มีสองสาย

Str-vit-dex อย่างที่ -คนหน้าตาดี- ว่าไป ตีได้แรง อึดพอสมควร และมี hp สูงมาก
Str-agi-dex สายพริ้ว ตีไว หลบมอนเก่ง ตีแรงเช่นกัน แต่ hp ต่ำ (ที่จริงก็ไม่ต่ำมาก เพราะสายทาทามี hp ratio สูงอยู่แล้ว)

ทั้งนี้ทั้งนั้น agi,vit ต้องอัพทั้งสองสายเหมือนกัน แค่อัพไม่ต้องมากในสายที่ไม่ต้องการน่ะครับ
