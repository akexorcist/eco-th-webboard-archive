Crimson Violet เขียน:สงสัยเรื่องสคิล light add น่ะครับ สคิลนี้มีผลทำให้อาวุธกับตัวเราเปลี่ยนเป็นธาตุแสงเหรอครับ?

เห็นในวิกิมันมีเวลาอะไรอีกไม่รู้ทั้งที่เป็นสคิล passive ยิ่งอ่านในหน้าแรกก็ยิ่งงงครับ = =


Light Add จะเพิ่มความพิเศษในการรับสกิล Light Weapon/Light Shield จากวาเทสครับ

กรณีได้รับ Light Weapon จะได้อาวุธแสง 20% เกราะแสง+40
กรณีได้รับ Light Shield จะได้รับอาวุธแสง 10% เกราะแสง+80

(นับที่สกิลเลเวลสูงสุด ตรงอาวุธแสงไม่แน่ใจว่าเป็น 10%/5% รอคนมาคอนเฟิร์มนะ)

เหมาะมากๆ สำหรับการเก็บเลเวลที่ปราสาทอันเด๊ด+ตีบอสหมากรณีมีวอล็อคร่ายพื้นมืด
แต่จะเซ็งเอามากๆ ถ้าไปโดนร่ายอาวุธแสงในบางพื้นที่... จะโดนเวทธาตุหนักกว่าปกติ

ส่วนตัว : ถ้าไม่คิดเก็บเลเวลที่ปราสาทอันเด๊ด ไม่จำเป็นต้องอัพครับ
เดี๋ยวผมสวิทช์กลับเป็นไนท์ก็คงอัพโซลแทนคงจะเวิร์คกว่า


อ้อ ถ้าไม่ได้รับผลจาก Light Weapon/Light Shield มันก็ไม่แสดงผลอะไรใช่มั้ยครับ
(ผมอัพไปนานแล้วล่ะครับ นึกว่ามันจะตีผีแรงขึ้นตอนเก็บเลเวลคนเดียว - -)

แล้วเกราะแสง +40 +80 นี่หมายถึงลดเป็นหน่วยตามนี้แบบชุดสวมใส่เลยเหรอครับ
