ทำเควส "ขนส่งเอกสาร" ที่ร้านเหล้า โดยให้รับเควสที่ Acropolice จะมีเวลา 15 นาที
ให้เราเดินไปหา Sage Master ที่อัพทาวน์ (บ้านของ Sage Master จะอยู่ข้างๆ บ้าน
คุณป้าช่างเย็บ หากไปไม่ถูกให้ถามทางจาก Guide Machine ดู)
เมื่อคุยกับ Sage Master แล้วจะได้รับ"ประมวลกฎหมาย" มา 1 เล่ม ให้นำ
ประมวลกฎหมายไปส่งให้กับ Miriaria ที่สมาคมพ่อมดเมือง Northan Blomnard
(ที่เดียวกับ Event ข้างบน แต่เลือกเข้า"Motoyama Room"แทน/หากไม่ใช่สาย
Spell User จะไม่มีให้เลือก ให้เดินเข้าไปเลย) ก่อนหมดเวลา (วิ่งตาเหลือก)
เมื่อทำเควสสำเร็จครั้งแรกจะได้รับ"Text Book"จาก Miriaria (อาวุธสายเวทย์ Lv52)
หลังจากนั้นให้เรารับเควสนี้อีกครั้ง (ถ้ารับที่ Northan ต้องตายกลับสถานเดียว
ไม่งั้นไม่ทัน 15 นาที) เมื่อทำเควสสำเร็จครั้งที่ 2 Miriaria จะให้ skill point เรามา 1 สกิล
*เมื่อเคลียร์ Event นี้แล้วจะสามารถซื้อหมวก Lv.55 ของสายเวทย์จาก Miriaria ได้
