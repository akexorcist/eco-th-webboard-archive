ตัวที่ต่างกันมีชัดๆอยุ่ตัวเดียวครับ คือหนอนขี่ (ล้มก่อนแปลง กับแปลงก่อนล้ม เร็วต่างกัน)
ส่วนตัวอื่นๆ ถ้าแปลงร่างแล้ว พวก stat บางอย่างจะ max สูงขึ้นไปอีก เช่น hp 1600 >> 1850
ส่วนเรื่องฝึกยากง่ายอันนี้แล้วแต่ เพราะ pet ที่แปลงร่างจะมี สกิลเพิ่ม อาจทำให้ pet ออกสกิลเองได้บ้าง
