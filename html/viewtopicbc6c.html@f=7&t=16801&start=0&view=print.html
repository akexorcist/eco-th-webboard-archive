เรื่องราวมันมีอยู่ว่า ผมเลี้ยงหนอนอยู่ดี ๆ หมอนี่ก็มาเอามังกรยิงเอายิงเอา โดยไม่บอกกล่าว
บอกให้ให้พ้นอย่างยุ่งกับผมก็ไม่ใส่ใจ
ด้วยประโยคนึงทำให้เขาโมโหมใส่ผม ซึ่งผมโมโหมมากเป็นทุนเดิมอยู่แล้ว ทำให้มีการปฏิสัมพันธ์กันในด้านไม่ดีในการเล่นในระดับหนึ่ง จนหมอนี่เขา หยุดแหง่กเพื่อรอจะทำผมกลับคืน แต่ทว่าผมมาทำรูปนี่นี่ให้หลาย ๆ คนดูเล่น
ดูแล้ว เห็นแล้ว ก็เลี่ยง ๆ ไว้ เพราะท่าทางเขายิ่งใหญ่น่าดูนะ ลองดูประโยคสุดท้ายสิ :lol:
