คำศัพท์ที่ควรรู้
archen = urchin = เม่น,เด็กซน (คาดว่าทีมงานแปลผิด จริงๆต้องชื่อ urchin)
blacklist = รายชื่อคนที่ทำผิดหรือต้องรับโทษ
brooch = เข็มกลัด
component = ส่วนประกอบ,ส่วนเสริม
crest = ยอด,หงอนไก่,โหนก,ขนแผง,สิ่งประดับบนยอด
cusp = จุด,ปลายแหลม,จุดสัมผัส,ยอด,ปลายโผล่
distil = กลั่น
distilled water = น้ำกลั่น
fixative = สารยึดติด,สารที่ทำให้การระเหยช้าลง
halberd = ง้าว
hurricane = พายุหมุนเขตร้อนที่เกิดขึ้นจากมหาสมุทรแอตแลนติกและพัดเข้าสู้ชายฝั่ง
mallet = ตะลุมพุก,ไม้ตีคลี,ไม้ตีลูกโครเก้
nugget = ก้อนโลหะ(หรือก้อนอื่นๆ)
ogre(โอเกอร์) = ยักษ์กินคนในเทพนิยาย,คนดุร้ายน่ากลัวหรือป่าเถื่อน
rivet = หัวหมุดย้ำ, หมุดโลหะ
sal = เกลือ
scythe = เคียวตัดหญ้า
sprinkler = เครื่องโปรย, เครื่องสาด
tomahawk = ขวานขนาดเบาของอินเดียแดง,ขวานหินของชาวพื้นเมืองในออสเตรเลีย
tong = คีมหนีบ, ปากคีบ
whirlwind = ลมบ้าหมู,กระแสน้ำวน,ลมกรด

เกี่ยวกับโลหะ
โลหะ ถ้ากล่าวโดยทั่วไปก็หมายถึง วัตถุที่มีความยืดหยุ่นสูงนำไฟฟ้าได้ดี และมีความมันวาว
Iron(อ่านว่าไอร์ออน) = Ferrum(Fe) ธาตุตัวที่ 26 ของตารางธาตุ เกิดสนิมได้ง่าย
Steel = เหล็กกล้า ได้จากการนำธาตุเหล็ก(Fe) มาทำปฏิกิริยาจนได้เป็น oxide ซึ่งจะไม่เกิดสนิม
Rust = สนิม เกิดจากการที่ oxigen ทำปฏิกิริยากับโลหะเกิดเป็น oxide ของโลหะ ซึ่งโดยส่วนมากแล้วจะเกิดขึ้นกับเหล็ก
*จริงๆเรื่องการเกิดสนิมมีรายละเอียดเยอะ ถ้าใครอยากได้ข้อมูลก็จะนำมาลงเพิ่ม
Gold = Aurum(Au) ธาตุตัวที่ 79 ในตารางธาตุ มีความหนาแน่นสูงและราคาแพง
Platinum(Pt) ธาตุตัวที่ 78 ในตารางธาตุ มีความหนาแน่นสูงกว่าทอง และราคาแพงกว่า
Silver = Argentrum(Ag) ธาตุตัวที่ 47 ในตารางธาตุ
Copper = Cuprum(Cu) ธาตุตัวที่ 29 ในตารางธาตุ เป็นโลหะที่ราคาถูกสามารถนำไปใช้ประโยชน์ได้หลากหลาย
Lead = Plumblum(Pb) ธาตุตัวที่ 82 ในตารางธาตุ มีความสามารถในการป้องกันการรั่วไหลของกัมมันตภาพรังสีได้ดี
Titanium(Ti) อ่านว่าทิเทเนียม เป็นธาตุตัวที่ 22 ในตารางธาตุ มีความแข็งแรงมาก
ส่วน Titan(ชื่อเทพในตำนานกรีก) อ่านว่า ไททัน อย่าสับสน
และ titania ก็อ่านว่า ไททาเนีย
ส่วน NPC ที่ปรากฎตัวในฉากเริ่มต้น ชื่อว่า Tita อ่านว่า ทิทา
Oriharukon = ชื่อโลหะที่มักจะปรากฎในนิยายแฟนตาซีบ่อยครั้ง
