1.สกิว Phalanx คิดความแรงจาก การฟันของอาวุธประเภทขวาน ความแรงจึงไม่แรงมาก

M atk

ไม่น่าอัพทั้งสอง เพราะคุณคงไม่ไปให้ น้องไชเท้าเท้าไล่ฆ่าม่อนนักหรอกนะ แต่ถ้าจะอัพสำหรับเราคิดว่า Plant Poison เพราะเอาไว้อัพค่าM atk ของไชเท้าได้ เวลาฝึกสัตว์ จะได้ฮิวแรงขึ้น
