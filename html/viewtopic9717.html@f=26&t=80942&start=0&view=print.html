ไปรับชิ้นส่วนทำบ้านบินไม่ได้

โพสต์แล้ว: ศุกร์ 20 พ.ค. 2011 2:30 pm
โดย ECO
ตอนนี้เราทำเควสบ้านลอยฟ้าให้บินได้อะค่ะ เราไปรับชิ้นส่วนชิ้นแรกคือ whistle ไปรับกับโจรสลัดไทนี่ที่เกาะไทนี่มาแล้วค่ะ เมื่อวานวันพฤหัสฯ แล้วมาวันนี้วันศุกร์ เราก็ทำเควสเข้าเกาะโจรแดง2 เพื่อเข้าไปคุยกับไทนี่ข้างใน หลังจากนั้นเขาบอกว่าให้มาคุยกะไทนี่ที่เกาะไทนี่ดู แล้วเราเลยกลับมาค่ะ แต่ก้รับเอาชิ้นส่วนไม่ได้อ่าค่ะ
เราทำผิดขั้นตอนไหนไปรึป่าวคะ อีกอย่างเราจำได้ว่าในกระทู้ของ viewtopic.php?f=26&t=41284 ได้บอกไว้ว่า การรับชิ้นส่วน สามารถ รับได้อีกชิ้นในวันศุกร์ หรือว่าเราเข้าใจอะไรผิดไป ช่วยตอบเราด้วยนะคะ
