คือผมอ่านไปเจอข้อมุลดีๆในกระทู่ กล่องเควสล่าสมบัติ และการใช้สกิส ranger ในการหา

http://board.onenet.co.th/viewtopic.php?t=59392

เลยพอจะรุ้วิธีลงดันและทำให้เวลาในเควสไม่นับ
คือเอาตัวที่เราจาเวลเป็นหัวปาตี้และรับตัวละครอีกตัวนึงมาที่ไม่ต้องการเวลให้มารับเควสแทน แล้วเข้าดัน พอเข้าดันครบทุกคนแล้วก็เอาตัวที่รับเควส ล็อกเอ้าออกจากเกมไป แล้วตัวที่เหลือก็เวลกันได้เลย เวลาเควสมันจาไม่นับเพราะตัวรับเควสออกเกมไปแล้ว แต่คนในปาตี้ที่อยุ่ในดันจะคงอยู่ในดันต่อ

เอาไปลองดูกันนะ (ผมพ่องอ่านไปลองกับเควสล่าสมบัติแล้วแจ้มมาก)ถ้าดันมัน 3ชั่วโมงล้ม ก็แค่เอาตัวรับเควสมาวิ้งเข้าดันไหม่แล้วก็ออกเกมอีกรอบ (ประหยัดแต้มเควสมากมาย)

ผมไม่แน่ใจว่าเวลาดันมันจะยังนับ3ชั่วโมงอยุ่ป่าวนะ (ถ้าไม่นับแจ่มเลยเวล24ชั่วโมง)*-*

ผมยังไม่ได้ลองจิงนะครับ ช่วงนี้หาแต่ตังเลยไม่ได้เวล ใครลองแล้วเป็นไงก็มาบอกกันมั่งนะ
