อยากรู้จังว่าซิลเวียจะสั่งให้ไปทำอะไร จะเกี่ยวข้องกับเจ้าเวลน์หรือเปล่า...อยากอ่านต่อเร็วๆ (ฮา)
-----------------------------------------------------------------

น้ำเสียงอันเรียบเฉยหากแต่เต็มไปด้วยพลังอำนาจถูกเอื้อนเอ่ย “ ... วลานิเดียสล่ะ ? ”


ตรงนี้อ่ะเจ๊ ที่สงสัยเล็กน้อย ตอนที่เจ้าเวลน์แนะนำตัวมันชื่อวลาดิเนียสไม่ใช่รึ

ทำไมตอนนี้เป็นวลานิเดียสล่ะ

และเมื่อกี้เพิ่งอ่านย้อนๆผ่านๆดู มีจุดตำหนิตรงนี้อ่ะเจ๊ ที่บท กาลอวสานบทที่ III : `La Missione` ( The Mission )

“เป็นเวลานานเหลือเกิน ที่แม่ไม่ได้เจอลูก ... วลานิเนียส ...” เคร้ง ! หอกคู่กายถูกปล่อยตกลงพื้นอย่างมิได้สนใจ


กัุบ

วูบ ! ทั้งบลูอายและฮิโยโกะต่างพุ่งเข้าหาซิลเวียและจีพีด้วยความรวดเร็ว แต่กระนั้นสายตาของทั้งสองกลับไม่ได้จับจ้องที่ทั้งคู่แม้แต่น้อย แต่กลับไปจับจ้องที่วลานิเดียส ! องค์ชายแห่งอโครเนียแทน !


ส่วนตอน กาลอวสานบทที่ IV : `Il Re Della Follia` ( The King of Madness )

วลานิเดียสก็หายตัวไปเช่นเดียวกัน ...
