คำแนะนำที่ผ่านมาถูกทั้งนั้นเรยครับ

หลักๆแล้ว mag-dex กันทั้งนั้น

เพราะข้อดีของสายวิสาด ยิงแรงทุกสกิลครับ
แต่ข้อเสียก้อคือร่ายนานมากๆ ทุกท่าเรย

ละถ้าถามว่า mag-dex อัพเรียบร้อยแล้วไปทางไหนต่อดี

ตอบได้เรยว่ามีสองทางเลือกครับ
๑.ก้อคือเลือก vit เพราะวิสาดเลือดน้อยมาก เวล ๙๙ แล้ว
เลือดผมยังไม่เกิน ๑๕๐๐ เรย อีกอย่างถ้าอัพ วิท ก้อจะถึกทางกายภาพมากขึ้น

๒.ก้อคือเลือก int เพราะว่าวิสาดมีสกิลสายสาปหลายสกิล อันที่ผมใช้เยอะๆเรย
ก้อคือ E Freak สมมติว่ามอนตัวนี้ยิงด้วยท่าที่แรงที่สุดของเรา(ดาบ50/โนว่า)
แล้วไม่ตายโดยเหลือเลือดน้อยกว่า ๑ ใน ๕ เราก้อเปิดด้วย E Freak ซึ่งอาจทำให้มอน
ติด"หิน" ละตามด้วยท่าไม้ตายเรา คือในกรณีเลือก int นอกจากจะเน้นไปทางสาปแล้ว
ยังช่วยเพิ่ม min matk ของเราด้วยครับ ทำให้ในการยิงเวทย์แรงขึ้น (แกว่งน้อยลงนั่นเอง)
สุดท้ายที่เป็นประเด็นหลักที่น่าสนใจก้อคือ เพิ่ม mdef ครับ ทำให้ถึกเวทย์มาขึ้น

ความคิดเห็นของผมเองนะ :
ผมเลือก int โดยที่อัพ vit ไว้นิดหน่อย อาศัยถึกทางกายภาพด้วย เกราะ+10 เอา
ละก้อโซลิดด้วย ช่วยได้เยอะครับ ส่วน int ก้อช่วยให้รับเวทย์ได้มากขึ้น ละรีเฟลคจะช่วยได้
แค่ครั้งเดียว ช็อตต่อไปจะๆได้เอาตัวรอดได้บ้าง

การเก็บเวลคนเดียวนะครับ ผมอ่ะประจำเรย
แวะไปดูได้ครับแถวๆฟุจิกิ ก้อเทคนิคคือไม่นิยมโซลตัวเอง และเน้นการใช้ท่าดาบ 50
ของซอร์ พอเรายิงเวทย์จนหมดหลอด ก้อใช้มาริโอเนต พอหมดมาริโอเนต ก้อยิงจนหมดอีก
หลอด พอหมดก้อเดินเข้าเมืองฟาอีสไปนั่ง เต็มแล้วก้อทำซ้ำ

พระไม่ต้อง...อ๊ะพระไม่ต้อง....อิอิ
