ชมรมเพิ่มเติม

13.ชมรมดนตรี เป็นชมรมที่คอยขับกล่อมบทเพลงให้ในงานโรงเรียนหลายๆงานใครเคยเข้าฟังก็อาจเคลิ้มได้ และดูเหมือนบทเพลงของชมรมนี้จะช่วยเยียวยาบาดแผลทางจิตใจ(คือช่วยฟื้นฟูสภาพจิตใจได้ว่างั้นเหอะ - -") ฟังแล้วหายเครียด ชมรมนี้มักจะทำงานร่วมกับชมรมศิลปการแสดง


14.ชมรมเดินเล่น ดูเผินๆชมรมนี้ดูเหมือนจะไม่ค่อยมีประโยชน์ซักเท่าไหร แต่ก็มีความสำคัญมากเหมือนกันเพราะชมรมนี้รู้ตรอกซอกซอย ทางหนีทีไล่เป็นอย่างดี ไม่ว่าจะในโรงเรียนหรือนอกโรงเรียนก็ตาม แต่ที่เป็นปัญหาคือชมรมนี้เป็นนักชอปปิ้งตัวยงเลยล่ะ(ผลาญเงินเก่งมาก - -") ร้านค้าต่างๆไม่เคยรอดพ้นสายตาจากชมรมนี้เลย ครั้งหนึ่งเคยซื้อแร่ยูเรเนียมมาโดยรู้เท่าไม่ถึงการณ์(ไอ้ที่เอาไปทำระเบิดนิวเคลียร์นั่นล่ะ) เล่นเอาผอ.ต้องโทรเรียกกระทรวงกลาโหมมาเก็บไปโดยด่วน(ไปซื้อมาจากไหนกันอ่ะ - -")


15.ชมรมว่ายน้ำ เป็นชมรมที่เสริมสร้างพลานามัยให้แก่ร่างกาย แต่จริงๆเป็นชมรมอวดหุ่นประชันโฉมกันซะมากกว่า - -" ผู้ชายที่อยู่ในชมรมนี้เตรียมเลือดกำเดาพุ่งได้เลย ส่วนที่ส่งไปแข่งว่ายน้ำข้างนอกโรงเรียนได้มาแต่รางวัลขวัญใจช่างภาพ(เอ๊ะ ยังไง นี่ส่งไปแข่งอะไรหว่า? -*-)


16.ชมรมบาสเก็ตบอล เป็นชมรมที่ดูปกติ(เป็นผู้เป็นคน)มากที่สุดแล้วในขณะนี้


17.คณะกรรมการนักเรียน เป็นส่วนที่สำคัญที่สุดของโรงเรียนเปรียบดั่งฝ่ายรัฐบาล ที่ต้องทำหน้าที่ในการบริหารภายในโรงเรียน โดยจะเป็นตัวแทนที่คอยประสานงานระหว่างผอ.กับนักเรียนและต้องคอยดูแลรักษาความสงบเรียบร้อยภายในโรงเรียน ราวกับเป็นผู้พิทักษ์โรงเรียนฉันใดฉันนั้น

โดยมีอำนาจพิเศษคือได้รับอนุญาตให้ใช้อาวุธและเวทมนต์ในการยับยั้งเหตุรุนแรงต่างๆได้อย่างเต็มที่

โดยมีอำนาจคล้ายๆกับตำรวจ แต่หากเห็นว่ามีการใช้อำนาจในทางมิชอบหรือเกินสมควรแก่เหตุสามารถยื่นเรื่องต่อศาลปกครอง เอ๊ย!!! ไม่ใช่ ยื่นเรื่องต่อผอ.ได้โดยตรง(เมาล่ะ - -")
และยังได้รับการสนับสนุนจากชมรมต่างๆ(คือขอให้ชมรมต่างๆช่วยเหลือในด้านต่างๆได้)เช่น ไปที่ชมรมวิทยาศาสตร์ขอยืมอาวุธขั้นสูงไฮเท็คได้(อย่าเอาไปทำของเขาพังล่ะ - -")

แต่อย่างไรก็ดีดูเหมือนทางคณะกรรมการนักเรียนจะไม่กินเส้นกับชมรมปราบผีเท่าใดนัก(ไม่รู้เป็นเพราะอะไร สงสัยมาระงับเหตุได้เร็วกว่ามั้ง - -") ส่วนใครจะได้เป็นกรรมการนักเรียนนั้นให้ผู้แต่งเป็นคนคัดเลือกเอง

"เฮ้อ...เปิดเทอมมาวันแรกก็มีงานเยอะเหมือนกันนะเนี่ย" ผอ.บ่น

"มันก็เป็นธรรมดาของวันแรกในการเปิดเทอมอยู่แล้วค่ะท่าน" เลขาพูดปลอบใจผอ.

"อ่า...นั่นสินะ - -" อ้อ ใช่ แล้วรายงานข่าวสารชมรมของเทอมนี้มีอะไรบ้างล่ะ" ผอ.ถามเลขา

"อยู่ในนี้ทั้งหมดแล้วค่ะท่าน นี่ค่ะ" เลขายื่นแฟ้มเอกสารให้ผอ.

"ไหนดูดิ อืม...

ชมรมทำอาหาร - กราบขออภัยที่ทำให้ท่านผอ.ต้องเข้าโรงพยาบาลเป็นเวลา 1 อาทิตย์ พวกเราขอแก้มือกันใหม่ค่ะ(ฮะ...เฮ้ ไม่เอาน่า รสชาติแห่งความสยองมันยังติดลิ้นชั้นอยู่เลยนะ - -")

ชมรมวิทยาศาสตร์ - เตรียมพบกับปืนโปรตอนเคนน่อนเร็วๆนี้(เฮ้ย! คราวที่แล้วเพิ่งหมดค่าซ่อมห้องทดลองไปแล้วนะ - -")

ชมรมไสยศาสตร์ - ...(ไอ้ชมรมนี้จะทำอะไรไม่บอกซักคำ - -")

ชมรมปราบผี - การจับตาดูชมรมไสยศาสตร์คือหน้าที่ของเรา(เออดี ทำไปเถอะ)

ชมรมคอมพิวเตอร์ - โปรแกรมปราบเกรียนสำเร็จรูปพร้อมใช้งานในระบบคอมพิวเตอร์ทั่วโรงเรียนแล้ว(เฮ้ย! เป็นไปได้เรอะ - -")

ชมรมเกษตร - ต้นแมนเดร็กวิ่งหนีเข้าป่าไป 1 ต้นหากใครพบเห็นโปรดแจ้งชมรมเกษตร(เออ ปล่อยมันไปเถอะ - -")

ชมรมกีฬา - กราบขออภัยที่ทำให้ทรงผมของผอ.เปี๋ยนไป๋(อ่า...ไม่เป็นไรตอนนี้ใช้ครีมนวดผมป้องกันเส้นผมแตกปลายอยู่ หายเป็นปรกติแล้ว ให้ตายสิอยากรู้จริงๆว่าใครทำ - -")

ชมรมศิลปการแสดง - เตรียมพบกับละครเวทีเรื่องผอ.โฉด โหด เฮ้วฮา เร็วๆนี้(เอ...มันคุ้นๆชอบกล - -")

ชมรมศิลปะ - ขอเชิญร่วมชมงานแสดงภาพวาดศิลปแบบประยุกต์ โอ้!!!มีภาพตัวอย่างให้ดูด้วย ชื่อภาพ"การปฎิวัติเข้าสู่ยุคสมัยแห่งความโมเอะ" ไหนดูจิ

ชมรมนักสืบ - เตรียมพบกับคู่รักใหม่ระหว่างเจ้านายกับสัตว์เลี้ยงเร็วๆนี้(เอ...ใครหว่า - -")

ชมรมเย็บปั่กถักร้อย - ชุดแฟชั่นตัดเย็บเสร็จเรียบร้อยเตรียมส่งประกวดที่ปารีส(ไฮโซ ชะมัด - -")

ชมรมธุรกิจSME - เครปอร่อยๆ อย่าลืมอุดหนุนพวกเราด้วยนะคะ (จ้าๆ - -")

ชมรมว่ายน้ำ - โรงเรียนฟอริเอลกวาดรางวัลขวัญใจช่างภาพอีกแล้วครับท่าน(ตกลงฉันส่งไปแข่งหรือส่งไปประกวดกันแน่ฟะเนี่ย - -")

ชมรมบาสเก็ตบอล - แป้นบาสพังอีกแล้ว ไอ้โปรดขออนุมัติงบซ่อมโดยด่วน(จ้าๆ แรงเยอะกันจัง - -")

“จะเข้าชมรมอะไรดีน๊า”เรย์บ่นกับตัวเองในใจ พลางเดินไปรอบโรงเรียน
“พี่เรย์ หาชมรมที่จะอยู่ได้ยังจ๊ะ” เสียงของหญิงสาวคนหนึ่งดึงขึ้น
“อ่อ..เอมิลี่หรอ ยังเลย พี่ยังไม่รู้เลยว่าจะเข้าชมรมอะไรดี นี่ก็เดินทั่วโรงเรียนแล้วเนี่ย แล้วเธอหล่ะ? จะเข้าชมรมอะไรหรอ?”
“ชมรมเดินเล่นจ้ะ หนูคิดว่ามันน่าจะสบายดี(มั้ง)ไม่ต้องทำอะไรมากมาย โฮ๊ะๆๆๆ”
“- -“ อ่อคร๊าบๆ งั้นเดี๋ยวพี่ขอตัวเดินดูชมรมต่างๆทั่วโรงเรียนก่อนนะ”
“ได้จ้า ให้หนูไปเป็นเพื่อนมั๊ยค่ะ” เอมิลี่ส่งยิ้มให้เรย์ พร้อมกับ มอบคำถามที่เด็กหญิงตัวเล็กๆอายุ14ต้องการฟังคำตอบอย่างใจจดใจจ่อ
“อ่า...แล้วเอมิลี่ ไม่มีธุระอะไรหรอครับ” เรย์ส่งยิ้มหวานๆให้กับเด็กสาว พร้อมโต้คำถามคืน
“ไม่จ้ะ วันนี้หนูว่างทั้งวันเลย”
เรย์ยิ้มให้กับเด็กสาวตัวเล็กๆอีกที ก่อนที่จะตอบตกลง “งั้นก็ได้ แม่สาวน้อย ^^”

เอมมิลี่ก็เดินนำหน้าเรย์ตลอดที่พาเรย์เดินชมชมรมต่างๆทั่วโรงเรียน พร้อมกับให้คำแนะนำกับพี่ชายผิดๆถูกๆไปบ้าง - -“
“ว่าแต่ เอ่..??? พี่เรย์สนใจชมรมอะไรค่ะ” หลังจากที่เดินมานาน เอมิลี่ เริ่มเหนื่อย แต่ก็ยังไม่เห็นท่าทีของเรย์ว่าจะสนใจชมรมอะไรเลย
“เอ่อ...ชมรมเกี่ยวกับพวกการต่อสู้ มีมั๊ย” เรย์ทำท่าครุ่นคิดอยู่พักใหญ่ๆ พร้อมกับตอบไปโดยไม่รู้ตัว
“อะอะอะไรนะ....ชมรมเกี่ยวกับการต่อสู้หรอค่ะ” เอมิทำหน้า เหวอ และตกใจกับคำตอบที่เรย์ตอบออกมา
“เอ่อ - -“ เอ่อ ใช่ๆ”
