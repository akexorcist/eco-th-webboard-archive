CFK เขียน:อยากทราบว่าไอ้ damage type ของอาวุธนี่ขึ้นกับอะไรหรือครับ เห็นเวลาเปลี่ยนmapมันจะบอกว่าเปลี่ยนท่าเป็น การ ฟัน แล้วทุบ/แทงนี่ใช้อย่างไรครับ


อาวุธเกือบทุกประเภทจะมีพลังโจมตี 3 แบบครับคือ

พลังโจมตี(การทุบ)

พลังโจมตี(การฟัน)

พลังโจมตี(การแทง)

แล้วสกิลแต่ละประเภทจะมีการแบ่งประเภทการใช้พลังโจมตีแต่ละด้านมาคำนวณพลังโจมตีของสกิล

เช่น พลังโจมตี(การฟัน) เช่น สกิล IAI ของ swoadman

พลังโจมตี(การแทง) เช่น สกิล Lighting spear ของ Fencer

พลังโจมตี(การทุบ) เช่น สกิล Blow,Banish Blow ซึ่งมีแทบทุกอาชีพ
