จะเล่นระหว่าง farmerสายขวาน กะexpoสายแส้

ถ้า
1.ผมมีทาๆอยู่แล้ว เปนตัวหาตัง
2.คลังข้อนข้างรกเพราะเก็บแร่ เอาแบบไม่ต้องมีของตุนมาก
3.ผมเล่นเวลาไม่มีคน ขอลุยเดี่ยวแต่เวลน้อยๆ
4.อยากได้แบบหาของเควสง่ายๆ หาไห้ชีพทาๆได้ยิ้งดี
5.ไม่เอาผลานตังมาก (ผลานน้อยก่าพ่อค้าอะ)


มันได้หมดอะนะครับ
มีทาทาเป้นตัวหาตังอยู่แล้ว ถ้าสร้างชาวนามาเพิ่มชาวนาจะกลายเป้นตัวหาตังแทนโดยเอาของจากทาทามาทำเป็นเฟอร์นิเจอร์ หรือถ้าเล่นเรนเจอร์ก็จะหาของมาขายเพิ่มๆแต่คลังจะรกยิ่งขึ้น(ของผมนะฮาๆ) ทั้ง2อาชีพไม่ผลาญตัง(พ่อค้าก็ไม่ผลาญนะ ) ของเควสทาทาต้องให้ทาทาหาเองเพราะทาทามีปราชหินอยู่แล้วอาชีพอื่นไม่มี
