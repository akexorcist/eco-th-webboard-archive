สกิลบางอย่าง พอใช้แล้ว จะอยู่ในโหมดสแตนบายทันที แต่อาจจะมีบางสกิล พอใช้แล้วให้ขยับตัวหรือทำAction ก่อน ถึงจะอยู่ในโหมดสแตนบาย ในกรณีการใช้ Potion Arrow จะทำได้ง่ายที่สุด ได้ผลทั้งผู้ใช้ และเป้าหมายพร้อมๆกัน(เป้าหมายที่เล็งถ้าอยู่เฉยๆจะไม่มีผล ให้ใช้Action อะไรก็ได้ 1 ครั้ง หรือจะยิงPAก่อนและกดทักทายใส่ ก็มีผลแล้ว)
