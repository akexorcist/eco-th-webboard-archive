ฆ่ามานนนนนนน พวกนิสัยเสียต้องกำจัด!!!!

ผมมะรู้ เวลา ผมเวล อ่ะ ผมจะไปเวลที่เกาะ ก็หาพระ ไปด้วย

ส่วนใหญ่ จะหาพระไปปั้นอ่ะ ขอดี มะเรื่องมาก มานยอมเราตลอด

หาพระ กะ หน้าทาง เข้า ฟุจิกิ มองๆ ดู เด๋วกะ เจอ พระ เวล 30-40

เวลาไปเวล โทนิค อ่ะ ซื้อไปเยอะๆ ไม่ต้องให้ พระ เร่ง มะเคย มีปัญหานะ

กะ กางเต็น ไว้ ให้พระ น้อย หลบ ให้มาน อยู่ติดเต้นไว้ แล้ว กะ หามอนตี ข้างๆเต้น

พอเลือดเหลือ น้อย กะเดินมาให้พระฮีล ใช้สกิล กราบ เพื่อรักษา เลือดอ่ะนะ

พยามอย่าตี ลูกไฟ กะ นก เน้นตีโจร ขาว พอ เวล 68 รับเควส ลับได้ ไปตี อีกเกาะ
