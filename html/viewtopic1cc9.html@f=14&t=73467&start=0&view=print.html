ได้แค่โบนัสของจ๊อบที่เป็นอยู่ปัจจุบันครับ ถ้าใส่ของก็ + เพิ่มเข้าไปอีก

เช่น เล่นบาวตี้จ๊อบ 50 แล้วสวิทไปเป็นเบลดจ๊อบ 50 ก็จะได้แค่โบนัสเบลดจ๊อบ 50 ครับ

อยากได้โบนัสของคลาสไหนก็ต้องเลือกเอาครับผม

ตามข้างบนครับ

ถ้าเอาหลายจ๊อบรวมกัน จะไม่เทพไปหรอ เหอะๆ

โบนัสที่จะเพิ่มมากกว่าที่ตัวเองมีก็หลายวิธีครับ
1.ของสวมใส่ที่บวกค่าต่างๆครับ(หาได้ตามตั๋วทั่วไป(โฆษณาตั๋วตุ๋น))
2.โซลครับ จะบวกตามผู้สิงครับผม

ตกหล่นยังไงบอกด้วยครับ เพราะมีคนตอบให้แล้ว
