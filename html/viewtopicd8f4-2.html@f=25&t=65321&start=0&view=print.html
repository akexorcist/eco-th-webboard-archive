อย่างถ้าเราเล่น พ่อค้า ก็ ควรที่จะจ้างทหาร

หรือ เรนเจอร์ กะ ควรจะเป็นหมา ( ปลอกคอ )

และ อาเชอร์ ก็ เหยี่ยว หรือ หมาป่า จะดีกว่าใช่ไหมครับ แม้ว่าแมวจะมีบัฟต่างๆ

แต่อาชีพสามอย่างนี้ ต่อไปมันจะมีสกิวที่สนับสนุนกัน

อ่อ ชาวนา ก็ แครอทด้วย

ผมคิดถูกป่าว

และ Scout เหมาะกะแมวตัวไหนไหมครับ ผมแปลสกิวไม่ค่อยออก

หรือสุดท้ายก็แล้วแต่ไสตล์คนเล่นอีก

สาย BP แล้วอาเชอร์

การใช้ PET ประจำอาชีพ จะช่วยให้มีสกิลในการต่อสู้เพิ่มขึ้น

ถ้าจะถามว่าดีกว่าไหม แล้วแต่คนถนัดอ่ะครับ

บางที พวก PET ก็ถ่วงเราเหมือนกันนะ

ดังนั้น จะใช้ยังไง มันแล้วแต่ความพอใจล้วนๆเลย



ส่วน Scout จะใช้ เนะโกะมาตะตัวไหน

ก็แล้วแต่เราอีกเหมือนกันอ่ะ - -"

สกิลถ้าแปลไม่ออก ลองพาแมว ไปวิ่งเล่นดูก่อน ก็จะได้คร่าวๆมา

ถ้าเน้นหลบหลีก ก็ ไอจัง

ป้องกัน อากาเนะ และ สุมิเระจัง (เพิ่มพลังป้องกันและโต้กลับ)

ตีเร็ว อันสึคุง

เพิ่งพลังโจมตี โมโมจัง (สมดุล) ไม่ก็ ยามะจัง (เพิ่งพลังโจมตีและโต้กลับ)



ป.ล. เค้าใช้มั่วไปหมดอ่ะ แล้วแต่ความน่ารัก ใช้งานจริงๆ แค่โมโม
ตอนเก็บเลเวลที่ฟู เพราะเก่งแล้ว พึ่งพาได้จริงๆ
