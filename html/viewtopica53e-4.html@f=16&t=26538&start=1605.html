มีคำถามเรื่องไชเท้าคับ

ปกติค่า max def ของไชเท้าจะเป็น+20ใช่ไหมคับ
ทีนี้ตั้งแต่อัพแพทมา เพิ่งเอาไชเท้าไปฝึกอีก
ปรากฏว่า ค่า def มานเด้งขึ้นอีก

เลยถามว่า
1. ค่าสูงสุดถูกปรับใช่หรือไม่
2. ถ้าปรับแล้วจะ max เท่าไหร่
3. จะตรงตามในวิกิไหม (max def = +135)
ถ้าเป็นจิงๆ น้องไชเท้าก็อึดขึ้นดีนะ แต่คิดอีกแง่นี่กว่าจะได้ล้มนี่เหนื่อยเลยนะ -*-
