การเก็บค่า stat ต่างๆ ให้ max ทุกค่า นั้น จะทำให้ได้ค่า +เยอะกว่า +1 ขึ้นอยู่กับ stat หลัก
ของ pet (str dex int vit agi mag) ตามนี้เลย

Str+1 = Atk+1 Hp+1
Dex+1 = S.hit+1 Critical+1
Int+1 = L.hit+1 M.hit+1 M.atk+1
Vit+1 = Hp+1 Def+1
Agi+1 = S.avoid+1 L.avoid+1
Mag+1 = M.atk+1 M.def+1 M.resist+1
