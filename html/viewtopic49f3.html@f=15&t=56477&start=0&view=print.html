ถ้าเกิดจัดปาร์ตี้ บู้ล้างผลาญ PVP สงคราม วัดใจเกรียน ณ ลาน

แล้วปาร์ตี้เราก็เป็นสายเวทย์ทั้ง 4 ตัว

แล้วเราต้องให้เลือกตัวนึงเป็นตัว ต้นร่าง อีก 3 คนสิง ( อย่างไม่มีเหตุผล 555+ )

ท่านจะเลือกสายไหนเป็นตัวต้นร่าง ( Host ) ?

แล้วก็ อีก 3 คนสิงตรงไหนมั่งดี :lol:

หมายเหตุ
1. กระทู้นี้เน้นแลกเปลี่ยนความคิดเห็น ไม่สนันสนุนการโชว์พาวอย่างเป็นทางการ
2. ขอเหตุผล + แนวคิดประกอบการตัดสินนิดนุง

สุดท้าย~ ขอบคุณงับ

อันนี้ของเค้าเสนอคนแรก

Host - ดรูอิด แล้วกัน กางซัมบ้าแล้วถึกดี =w=
อก - ซอ เนอะ คอยกางโซลิด + รีเฟล็คให้ ให้อยู่ที่ปลอดภัยหน่อย
คทา - เอเล + MAG เยอะๆ จะได้ฮีลแรงๆ =w=
เสื้อ - คาบา นี่แหละ เพราะเลือดเยอะสุดแล้ว

คนอื่นมีความเห็นยังไงก็มาแชร์กันเน้อ :wink:

กลางใจ ยกให้ vates
