เควสยาของท่านแม่ นะค่ะ ( ลิ้งเก่า มันหายไปไหนหว่า -*- เข้าไม่ได้ )

เอาคร่าวๆ ละกันนะค่ะ

หลังจากที่คุยกับเด็กแล้วนะค่ะ ก็ไปรับเควสที่ร้านเหล้า (เลือกเควส ยาของท่านแม่ )

จากนั้น ให้ไปที่ เมืองเหนือ เข้าไปที่ร้านเวทย์มนต์ หมอดูเขาจะบอกว่า

ให้ไปหา กลีบดอกไม้ มา 6 ชนิด ชนิดละ 1 กลีบ

ซึ่งดอกไม้มีทั้งหมด 6 สี คือ แดง เหลือง ส้ม ขาว ดำ ฟ้า ( ตกจากดอกไม้ตามสีนะค่ะ )

สีแดง หาได้จาก แมปทางด้านใต้เลยค่ะ อย่างแมปบอสหุ่นยนต์ นี่ก็มี

สีขาว หาได้จาก แมปทางตะวันออกเฉียงใต้ หน้าดันปลากะโห้ หรือ หุบเขาโมโม หน้าฟาอิส ค่ะ

สีฟ้า หาได้จาก แมปริมหาดทางทิศเหนือ ที่มีบอสหมีขาว ( ใส่แว่นดำ ) อ่ะค่ะ

สีดำ หาได้จาก เกาะอันเดธ ไปทางด้านตะวันตก นะค่ะ หรือปราสาทอันเดธ ก็มีค่ะ

สีส้ม หาได้จาก แมปทางตะวันตกเช่นกัน ที่มีภูมิแห่งลม ( ตะวันตกเฉียงใต้ เลย )

สีเหลือง หาได้จาก หุบเขา โมโม หน้าฟาอิสค่ะ

ได้ครบแล้ว เอาไปให้หมอดูที่ร้านเวทย์มนต์ เมืองเหนือ เราจะได้ยา มาส่งเควส ที่ร้านเหล้า

ก็จะสามารถซื้อเสื้อระดับ 55 ได้ค่ะ ถ้าทำ อีกรอบ ก็จะได้ สกิลพ้อย จ๊อบแรก 1 พ้อย ค่ะ


( ล้วนแต่จำชื่อแมปไม่ได้ -*- แย่จริงๆ เลยฉาน ใครก็ได้มาคอนเฟิม ชื่อแมปทีค่ะ )
