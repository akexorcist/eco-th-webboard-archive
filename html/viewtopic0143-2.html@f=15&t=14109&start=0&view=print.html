ทางเข้า Northan Dungeon จะอยู่ที่ Map Middle North Mountain ทางด้านขวาบนค่ะจะมีอยู่แค่ชั้นเดียวนะคะ
ซึ่ง NPC จะอยู่ในบ้านด้านซ้ายล่างของ Map Northan Dungeon ค่ะ
ส่วนที่บอกว่าชั้น 3 ตรงนั้นจะเป็น Frozen Cave ซื้อจะขายอาวุธ lv30 ค่ะ เข้าที่ Map Snop Snowfield
ส่วนอาวุธ lv45 ถ้าไม่อยากซื้อจะมีเควสที่รับอาวุธฟรีได้อยู่ ถ้าเป็นสาย Spell User จะได้รับ Great Staff lv45 M.atk42 (เยอะกว่า Opal Rod อีกค่ะ)
ส่วนสายอื่นๆจะได้รับเป็นอาวุธประจำอาชีพ lv45 ค่ะ
ซึ่งสามารถรับเควสได้ที่ NPC Ancient Story Talker อยู่ใน Assembly Robby ที่ Iron City ค่ะ
โดยรายละเอียดเควสจะเป็นการนำอาวุธชิ้นนั้นๆไปทำให้ค่าความทนทานเหลือ 0
และนำมาส่งจะได้รับรองเท้าประจำอาชีพ lv55 ค่ะ (รับเควสตอน lv45 และใช้อาวุธนั้นไปเรื่อยๆเลยค่ะ จนถึง lv55 ความทนทานคงหมดพอดีแล้วมารองเท้า lv55 ได้เลยค่ะ :oops: )
