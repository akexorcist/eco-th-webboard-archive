ศาลเจ้าฮาคุเรย์

ผู้อยู่อาศัย - เรย์มุ,ซุยกะ(มาๆไปๆ),ซันนี่,ลูน่า,สตาร์




- เป็นศาลเจ้าที่ตั้งอยู่ในเขตแดนระหว่างโลกภายนอกและเก็นโซเคียว
- ถ้ามองจากศาลเจ้านี้จะสามารถเห็นเก็นโซเคียวได้ทั้งหมด
- ศาลเจ้าฮาคุเรย์มีสองแบบ คือแบบที่เห็นกันอยู่นี้กับแบบที่ตั้งอยู่ในโลกภายนอก
- ศาลเจ้าฮาคุเรย์ที่อยู่ในโลกภายนอกดูเหมือนจะเป็นศาลร้างไปแล้ว แต่ก็อาจจะมีคนเอาเครื่องเซ่นมาไว้ในบางครั้ง
- ไม่ใช่แค่ตัวศาลเจ้า แต่รวมทั้งต้นไม้และสิ่งแวดล้อมเป็นบริเวณกว้างก็อยู่ในเขตแดนเก็นโซเคียว
- ถ้ามีสิ่งใดในพื้นที่นี้ถูกทำลายไป มันจะถูกแทนที่ด้วยสิ่งที่อยู่ในโลกภายนอกเพื่อรักษาสมดุล
- ยกเว้นก็แต่ตัวศาลเจ้าเองน่ะแหละ
- มีครั้งหนึ่งที่ต้นไม้ใหญ่ใกล้ๆศาลเจ้าถูกฟ้าผ่าจนไม่เหลือสภาพเดิม แต่มันกลับฟื้นคืนสภาพภายในไม่กี่วันด้วยหลักการนี้
- ปัจจุบันต้นไม้ที่ว่าเป็นที่สิงสถิตของแฟรี่แห่งแสงทั้งสาม(ซันนี่ ลูน่า สตาร์)
- ศาลเจ้านี้ไม่มีเทพประจำศาล อาจเพราะโกรธที่มิโกะขี้เกียจสันหลังยาวและแทบไม่มีผู้ศรัทธาก็เป็นได้
- มิมะที่เคยยึดตำแหน่งเทพประจำศาลไว้ก็ดูเหมือนจะจากไปที่อื่นแล้ว
- มีเครื่องสูบน้ำ
- ใช้ห้องครัวแบบสมัยใหม่
- เนื่องจากเป็นศาลเจ้าแบบเก่า โครงสร้างจึงมีที่ว่างให้อากาศถ่ายเทอยู่เยอะ ในฤดูหนาวจึงหนาวมาก
- เดิมทีศาลเจ้ามีสภาพไม่ค่อยดีเท่าไหร่เพราะเรย์มุไม่มีเงินที่จะใช้ดูแล แต่หลังจากโดนทำพังไปสองรอบติด(ภาค10.5)ตัวศาลเจ้าก็ถูกสร้างขึ้นใหม่โดยซุยกะกับพวกเทนงู ทำให้แข็งแรงขึ้นเยอะ
- มักมีของจากโลกภายนอกหล่นมาอยู่ใกล้ๆบ่อยๆ
- เคยมีเสาส่งสัญญาณโทรทัศน์รุ่นเก่าโผล่ใกล้ๆด้วย
- ที่แท่นบูชาจะมีไวน์โผล่ออกมาเสมอ เรย์มุจึงได้ไวน์ฟรีกินประจำ เธอบอกว่ามันเป็นของเซ่นไหว้ที่ได้มาจากศาลเจ้าฮาคุเรย์ที่อยู่โลกภายนอก
- กล่องรับเงินบริจาคจะเปิดไว้ตลอดเวลาไม่ว่าจะเกิดอะไรขึ้น ยกเว้นวันที่พายุแรงจัดมากๆ เรย์มุถึงจะออกไปปิด
- บอลหยินหยาง สมบัติผม็เก็บไว้ในกล่องรับเงินบริจาคนี่แหละ
- สวนซากุระหลังศาลเจ้าของเรย์มุขึ้นชื่อว่าเป็นจุดชมซากุระที่สวยที่สุดในเก็นโซเคียว
- ทุกครั้งที่มีงานฉลองใดๆก็มักจะจัดที่สวนนี้แหละ
- เรย์มุเป็นคนเก็บกวาดเสมอ ถ้าเธอโชคดีเธอจะจับมาริสะกับซุยกะมาช่วยได้
- ดูเหมือนเก็นจิ เต่ารับใช้ของเรย์มุจะยังใช้ชีวิตอยู่ในสระหลังศาลเจ้า
- หลังศาลเจ้ามีต้นแอปเปิ้ลด้วย
- ทุกครั้งที่มีงานวัดหรืองานเทศกาล เหล่าโยวไคจากทั่วทุกสารทิศจะมาเปิดร้านไม่ก็เที่ยวงานกันเนืองแน่น
- ก็เลยไม่มีมนุษย์หน้าไหนกล้าเข้าใกล้ศาลเจ้าแห่งนี้ซักที
- แทบจะกลายเป็นศาลเจ้าโยวไคไปแล้ว
- มีศาลเจ้าสาขาย่อยขนาดเล็กประมาณบ้านหมาของโมริยะตั้งอยู่เพื่อแบ่งศรัทธามาให้กับที่นี่ด้วย
- กิจวัตรของเรย์มุ = ดื่มชา,กวาดใบไม้,ดื่มชา,กวาดใบไม้,ดื่มชา,กวาดใบไม้
- ในโกดังเก็บของข้างๆศาลเจ้าเต็มไปด้วยหนังสือพิมพ์(แทบจะทั้งหมดคือบุนบุนมารุของอายะ)ที่เรย์มุแทบไม่ได้อ่านเลย

- เป็นป่าที่อยู่ใกล้กับหมู่บ้านมนุษย์
- คาดว่าเป็นสถานที่ที่มีเนื้อที่กว้างใหญ่ที่สุดในเก็นโซเคียว
- ถ้าพูดถึงป่า ทุกคนในเก็นโซเคียวมักจะนึกถึงป่าแห่งนี้เป็นอย่างแรก
- มีความชื้นสูงมาก และในบางบริเวณแสงแดดส่องไม่ถึง
- เป็นป่าที่มีระดับพลังเวทมนต์สูง จัดเป็นสถานที่ชั้นดีสำหรับการฝึกฝนของจอมเวท
- แต่จัดเป็นสถานที่อันตรายมากสำหรับคนธรรมดา
- ในป่าจะมีไอพิษที่เกิดจากละอองเห็ดเป็นอันตรายต่อร่างกายมนุษย์ซึ่งกินพื้นที่ทั้งป่า มาริสะกับอลิสไม่ได้รับผลจากไอนี้
