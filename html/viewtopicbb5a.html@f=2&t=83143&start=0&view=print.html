โดย kokomi
เราก็ตระเวนหาๆในบอร์ดอยู่นานก็เพิ่งค้นพบว่าหัวข้อ Ring ไม่มีใครแบ็คอัพมาด้วย

ว่าจะเข้าไปดูที่เคยโพสไร้สาระกะชาวริงซะหน่อย คิดถึงทุกคนจังเลยน้า

ทุกวันนี้ทำงานปวดหัวแทบตายเหมือนตกนรกทุกวันๆ คิดถึงตอนเฮฮากะเพื่อนๆในริงไปวันๆไม่ต้องคิดอะไรให้มากที่สุดเลย ECO กลับมาซะทีเซะขี้เกียจรอแหละน้าาาา เล่นยุ่นก็ไม่หนุกเท่าไรเยยอะ อยากเล่นเซิฟไทยมากกว่า - -*
