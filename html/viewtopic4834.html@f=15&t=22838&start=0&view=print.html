มาตอบเพิ่มเติมเรื่องสกิลเลเวล50ของวิซาร์ด Magic Groove ครับ

สกิลนี้จะใช้ให้ประสิทธิภาพสูงสุดคือต้องอัพถึงเลเวล5 แล้วเวลาใช้งานให้ได้ดาเมจสูงสุดก็ต้องให้ศัตรูยืนประชิดตัวเราหรือ ยืนช่องเดียวกับเรา แล้วทำการยิงให้สุดระยะยิงที่ไกลสุด จะทำให้โดนหลายHit

เพราะฉนั้นการที่จะต้องยิงในระยะใกล้ขนาดนั้นคือใช้ SolidAura ตามที่คุณ Lugia แนะนำครับ แต่ถ้าคุณ จขกท. จะอัพสกิล Magic Medusa มาเพื่อใช้หยุดมอนสเตอร์เพื่อยิง Groove ก็สามารถทำได้ครับ แต่ไม่คุ้ม เพราะ...

ส่วนมากเวลาผมจะใช้ Magic Groove ยิงมอนสักตัว มอนตัวนั้นมันต้องยิงเวทย์อื่นไม่เข้า ยิง Dancing Sword ก็ลดน้อย + เลือดมอนเยอะอย่างเช่น Block(ดันใต้) กบดันตะวันออก ซึ่งพวกนี้ใช้ Groove ยิงจะง่ายกว่าครับ แต่มอนพวกนี้ส่วนใหญ่กันเวทย์อยู่แล้วครับ(High M.Def) เพราะงั้นยิงเวทย์อย่าง Magic Medusa ไม่ติด 100% ถ้าคาดหวังนำมาใช้ร่วมกับ Groove จึงไม่เหมาะสมนัก

เวทย์สาบอย่าง Magic Medusa ที่ผมใช้งานได้จริงๆคือไม่ได้ใช้เพื่อหยุดมอนสเตอร์ที่โจมตีระยะประชิดครับ แต่ใช่หยุดมอนสเตอร์ที่ยิงเวทย์ได้แรงๆมากกว่าเช่น Fury

ทริคเล็กน้อย การใช้ Magic Medusa ยิงใส่มอนสเตอร์ที่ผู้อื่นตีอยู่นั้น ไม่ถือเป็นการโจมตีที่ทำดาเมจครับ เพราะฉนั้นต่อให้เรายิงสาบติด ก็ไม่ได้รับแชร์ค่า EXP เวลาผู้อื่นกำจัดมอนตัวนั้นได้ครับ เพราะงั้นสามารถใช้เวทย์นี้ช่วยเหลือผู้อื่นได้เลยครับ ไม่ถือว่าแจม

ปล.ควรใช้กับผู้ที่เข้าใจนะว่าที่เรายิงไม่ได้ไปแย่ง EXP เขา
