1. Cave Hiding ไว้ซ่อนตัวในดันน่ะครับ(คล้ายๆหายตัวของสเกาท์ เพียงแต่ใช้ได้แต่ในดันเท่านั้นน่ะ) ส่วน FakeDeath คือแกล้งตายครับ ทำให้มอนเลิกสนใจเราและไม่สามารถโจมตีเราได้น่ะ(ระยะเวลาผลของสกิล 60วิ และต้องรอ 30วิ หลังจากเลิกแกล้งตายเท่านั้นถึงจะใช้ได้อีกทีน่ะ ไม่ใช่จากการใช้ครั้งแรก) ทั้ง 2 สกิลคิดว่าใช้กับบอสได้ด้วยน่ะครับ

2.Biat Trap
-Passive Skill ล่อเหยื่อทำให้มอนสเตอร์มาทางเหยื่อ มอนสเตอร์ที่ล่อมาจะแตกต่างกันตามเหยื่อ ถ้ามอนสเตอร์ LV สูงก็ต้องใช้เหยื่อมากขึ้น
LV1เหยื่อของแมลง
LV2 เหยื่อของปลา เหยื่อของนก
LV3 เหยื่อของสัตว์

ก็ตามข้อมูลน่ะครับ ใช้กี่อันมากี่ตัวก็บอกไม่ได้เหมือนกันน่ะ

3.Blinding
-ที่เลเวล 1 ใช้ sp 18, ความแรงในการโจมตี 125%, S.HITลด 36.3%, L.HITลด 33.2%, ระยะเวลาผลของสกิล 8วิ, ดีเลย์ 0.5วิ
-ที่เลเวล 2 ใช้ sp 20, ความแรงในการโจมตี 135%, S.HITลด 40.4%, L.HITลด 35.4%, ระยะเวลาผลของสกิล 10วิ, ดีเลย์ 1วิ
-ที่เลเวล 3 ใช้ sp 22, ความแรงในการโจมตี 145%, S.HITลด 44%, L.HITลด 39.1%, ระยะเวลาผลของสกิล 12วิ, ดีเลย์ 1.5วิ

สกิลนี้คิดว่าใช้ได้เลยไม่ต้องร่ายครับ

4.Gathering Class เป็นสกิลที่ต้องร่ายนะครับ คล้ายๆบัฟหมู่ของสายเวทน่ะ คือ ปาร์ตี้เราใครอยู่ในขอบเขต(11 x11)ก็จะได้ผลของสกิลไปน่ะ ส่วนที่ว่าใช้ตอนสิงได้รึเปล่านั้นไม่แน่ใจเหมือนกันนะครับ

ข้อมูลอ้างอิงจากที่มีในเกม จากเว็บ eco และ wiki นะคครับ
