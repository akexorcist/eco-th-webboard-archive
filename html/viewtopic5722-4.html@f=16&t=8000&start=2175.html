จากที่เล่นมาพวกสกิลใหม่ๆ

Whip Rush โจมตี 6 ครั้ง ไม่ปลื้มเยยกดไม่กี่ทีแส้ความทนทานลดเฉย+ไม่แรง กลับไปใช้ Blow เหมือนเดิมดีก่า เร็วก่า ชัวก่า

Unlock Mastery : สามารถเก็บ Wood Box Treasure และ Container ได้ดีขึ้นอัพไว้ที่เวล5 คิดว่าน่าจะแบบตีกล่องแล้วดรอปกล่องบ่อยขึ้น ก็บ่อยจริงๆอะส่วนมาก90% ได้แต่กล่อง
แต่ที่อ่านจำได้ว่ามันเพิ่มโอกาสเปิดกล่องได้ของดีไม่ใช่หรอ ทำไมอัพเต็ม5 ยังได้ของเน่าๆอยู่เลย อันนี้ก็ไม่แน่ใจสำหรับสกิลนี้อ่าครับ ใครรู้มาบอกทีนะครับ

Whip Flourish : ท่านี้เหมาะสำหรับสายวิทนะที่ลองดูมันมีดีเลย์เวลาใช้ด้วยตอนเหวี่ยงแส้
ถือว่าเสียเวลาพอสมควรสายเอจิอาจโดนรุมตายก่อนถ้ากดสกิลทีเดียวไม่ตาย

Snatch : ระหว่างโจมตี จะมีโอกาสขโมยไอเทมที่เป้าหมายมีได้ ไม่สามารถใช้กับผู้เล่น Pet และMonster บางชนิดได ตอนนี้อยากรู้สกิลนี้มากมายครับใครใช้แล้วเป็นไงบอกด้วยนะมันจะเอาไปขโมย
จากกล่องได้ป่าวอะ ถ้าได้ละก็แจ่ม แล้วก็พวกมอนดรอปของเควส บอส ไรเงี้ย
