อันนี้ต้องบอกก่อนว่า Add จะไม่ทำงานถ้ายังไม่เสกเกราะหรืออาวุธธาตุนะครับ
เพราะฉะนั้นโจมตีปกติไม่ต้องห่วง... เท่าเดิม

แต่ทีนี้ถ้าเกิดเสกเกราะ/อาวุธธาตุ มันจะได้ % ธาตุมากกว่าไม่อัพ Add นั่นเอง
ถ้าเสกอาวุธ อาวุธจะได้ % เพิ่มเยอะ ถ้าเสกเกราะ เกราะจะได้ % เพิ่มเยอะ ราวๆ นั้น

สำหรับโจมตีกายภาพ (สาย STR/AGI ทั่วไป) ชนธาตุ แพ้ธาตุแทบไม่มีผล
คิดเฉพาะชนะธาตุครับ เพราะฉะนั้น อัพ Dark Add+Dark Weapon นั่นแหละ
เพราะว่าทำให้โดนเวทธาตุ+เวทมื่ด เบาลงด้วย

(คำว่าไม่มีผล หมายถึง ไม่ได้ % โจมตีแรงขึ้น แต่ก็ไม่โดนหัก % น่อ - -/)

ส่วน Light Add พอเล่นจริงๆ แล้ว ไม่ไหวครับ ถ้าไม่ได้เก็บที่อันเดธอย่างเดียว
เราอยากได้อาวุธแสง แต่โดนแถมเกราะแสง โดนเวทธาตุทีแทบร้องไห้ ยิ่งที่หอแสง
มอนแต่ละตัวเวทลมโหดๆ ทั้งนั้น หวังจะตีสกายไรเดอร์ เจอค้างคาวลงธันเดอร์ เลือดฮวบ...

อย่าลืมว่า เกราะธาตุ ไม่คิดการโจมตีปกติ (หรือมีผลก็แทบไม่เห็น เล่นกี่ตัวก็ยังไม่เห็นผลมาก)
แต่กับเวท ให้ผลยังไง ลองไปอ่านกระทู้ชาแมนเลยครับ ตรงตามนั้น เป๊ะๆ
http://board.onenet.co.th/viewtopic.php?p=133007#133007

Stigma ก็บวกเข้าไปอีก... ยกเว้นลืมเสกอาวุธมืด ใส่ไปก็เท่านั้น
(และยกเว้นอีกถ้าใช้สกิลดูดเลือด เพียงแต่ถ้าเสกอาวุธมืดมันจะแรงกว่า)

ปล. คิดพื้นที่ด้วยเน่อ... อย่างถ้าใส่เกราะแสง ไปลงพื้นไฟ (เช่น ดันใต้ชั้น 3 ส่วนบน)
โดนเวทไฟสองสามทีอาจจะลงไปนอนดูดาว - -\

พยายามคิดว่าตรงไหนแรงกว่ากัน แต่ที่แน่ๆ เกราะมืดสบายครับ มอนที่ยิงเวทแสง
ใช่จะเยอะ ไปเก็บแถวแพลตตินั่ม ค้างคาว งู ลงดัน 70-80 ทั่วไป โดนเบากว่าชาวบ้านหลาย

ปล.2 เลเวลประมาณนั้น ไม่แนะนำดันใต้นะครับ ยกเว้นมีคนฮีล เหตุเพราะมอนมันชุมหลายๆ
ขอแนะนำเก็บฟุชิกิโซนติดกับโมโม (ทิศตะวันตก) ตีได้เรื่อยๆ ของดรอปคุ้มเงิน อัพไวพอใช้
แต่ถ้ามีพระก็ลงลุยอันเดธตีห้องกระดูกเลยครับ ไวสุดช่วงนั้นละ

ตอน 65+ ใส่เสื้อแสงผมลง "หาสมบัติใน Ancient" หาพระเป็นงานสักคนไปตี Gaz
ได้ตัวละ 3600/1800 จ๊อบช้าไม่เป็นไร เอาเลเวลไว้ก่อนช่วงนี้ เป็นเวลาโกย
พอสัก 68+ ลงหอแสงชั้น 1 ตีได้ทุกตัวยกเว้น C4 หลังนั้นลงดัน 70 ไม่เอาห้อง
ที่มีสกายไรเดอร์ (ยกเว้นสายดีไวน์ ตีเข้าแรงดี) กะวาซาบิ แป๊บเดียวก็ 80 ละ -.-
