ถามแนวนี้ไม่ค่อยมีคนอยากตอบหรอกนา น่าจะไปอ่านในบอร์ดพ่อค้าบ้าง

พ่อค้าสายเวท ถ้าเล่นเป็นสายฮีลเต็มตัวแล้วแทบจะไม่ได้ลงสเตตัสเอาไว้บู้หรอกครับ
ลำพังแค่ Mag Vit ก็กินแต้มสเตตัสไปเยอะแล้ว เอาไปลงอย่างอื่นได้น้อย(เอาไปลง Int ก็ได้ถ้าเน้นตัวฮีลที่อึดๆ)
ส่วนสกิลเอาไว้โจมตีก็มีหลักๆแค่ Common Mercenary ของ Trader จ็อบ 47 กับ Alcana Card (น่าจะ)จ็อบ 42 ของ Gambler
ถ้าเล่นสายนี้ก็ควรจะอยู่ฝั่ง Gambler มากกว่า
สกิลที่จะเอามาจาก Trader
-Trust ทำให้ขายของได้แพงขึ้น
-Connection เพื่อสิทธิพิเศษกับ Merchant Guild
-Soul เอาไว้สิง
-Attack Assist เอาไว้ใช้ตอนสิงสายเวท
-Common Mercenary

สกิล Gambler
-Random Healing สกิลสามัญที่ต้องอัพ
-Roulette Healing ฮีลหมู่เวลาลง NVN
-Lucky เอาไว้ Avoid เวท
-Bad Lucky เอาไว้ Avoid ที่ไม่ใช่เวท
-Double Up เพิ่มพลังฮีล 2 เท่า คูลดาวน์ 30 วินาที
-Woman Charming... ลดพลังโจมดีของศัตรู
-Alcana Card เจ้ามือแจกไพ่ -.-

ที่เหลือหากสงสัยไปถามคนในบอร์ดพ่อค้าเลย เราเล่นสายฮีลกับสายปาไพ่ก็จริงแต่ไม่ได้เล่นเป็นตัวหลัก
เลยตอบได้เท่าที่เคยเล่นมา
