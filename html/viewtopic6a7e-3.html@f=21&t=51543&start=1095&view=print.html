หลังจากชาย4คนตะโกนออกมา(เรียวโจทย์นายอ่ะ)เสียงคาโต้ดังออกมา"เหยื่อยมาถึงที่แบบนี้ไม่ต้อนรับคงเสียมารยาทนะ"เสียงของเรียวดังขึ้นมาและเดินออกมาจากข้างในหอ
"แก่เอาลูกพี่เราไปขึ้นเงินรางวันแบนี้ยอมไม่ได้"ชายใน4คนนั้นกระโดดเข้ามาพร้อมถือดาบขนาดใหญ่จะฟันเข้าที่หัว เคร้ง เสียงของปืนที่เรียบหยิบขึ้นมาปัดดาบของศัตรูแล้วทันใดนั้น
เรียวก็หมนุตัวเตะ ตูม "อ็อก" สิ้นเสียงชายคนนั้นเลือดก็ทะลักออกมาแล้ว1ในนั้นก็วิ่งมาจับชีพจร"ตาย แล้ว"พอสิ้นเสียงชายที่เข้าไปหาเพื่อนอีก1ครที่จะเข้าไปหาเรียว"แก ตาย"
ปัง เสียงปืนดังขึ้นลูกกระสุนก็ทะลุหัวของชายคนนั้นแล้วล้มลง
" หึ หึ ฝีมือแค่นี้เนี้ยนะจะฆ่าฉัน ฮ่าๆ ไปฝึกมาใหม่3ชาติแล้วค่อยมาสู้กับฉันสิ"เสียงของเรียวดังขึ้นพร้อมมหัวเราะไป"หนอยแก พวกเราไปกันเลย"ชาย2คนนั้นก็กระโดดไปพร้อมกัน
แล้วเรียวก็ หมุนตัวเตะแล้วก็กระโดดต่อยไปที่ศีรษะของศัตรู "อ้ากกกกก"เสียงของทั้ง2ร้องโหยหวนอย่างเจ็บปวดแล้วสลบไป"หึ หึ ฝีมือแค่เนี้ยกระจอกสิ้นดี อ่าๆๆๆ"แล้วเรียวก็เดินไปที่ชายทั้ง2แล้วชักดาบขึ้นมา"หนอยแก แค่กๆ อย่ากนึกนะว่าแค่เนี้ยจะเอาชนะเราได้" ชึก
เสียงดาบทะลุหัวชองชายคนหนึ่ง"แหม่วันนี้สนุกแหะ สิ้นเสียงของเรียว เรียวก็ทรุดลงไป(ฉันเหนื่อยแล้วพักก่อนละกัน)สีผมกลายมาเป็นสีชมพู"หึบ กลับร่างเดิมแล้ว"หลังจากนั้นคาโต้ก็เข้าหอไป
