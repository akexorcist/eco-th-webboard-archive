ถ้าให้แปลจากคำนั้นแล้วก็จะได้ว่า stardust อะไรประมาณนี้อะค่ะ แต่ก็ยังไม่แน่ใจ เพราะเราเองก็ไม่ได้เก่งภาษาเลยอาจจะแปลผิด

แต่ถ้าเธอไปดูชื่อทรงผมที่เซิร์ฟเถื่อนละก็อาจแปลไม่ตรงกันนะค่ะ เพราะบางทรงชื่อทรงผมเซิร์ฟเถื่อน กับ เซิร์ฟจริง ไม่เหมือนกันค่ะ

เช่นเชิร์ฟจริง ทรงผม Isushima Miharu's Letter เชิร์ฟเถื่อนจะเป็นชื่อว่า Aquarian Introduction
เช่นเชิร์ฟจริง ทรงผม Soilder Introduction Letter เชิร์ฟเถื่อนจะเป็นชื่อว่า Army introduction
และยังมีทรงผมอื่นๆอีกที่ชื่อไม่ตรงกัน

แต่ถ้าใครที่เก่งภาษา ก็ช่วยแปลให้ทีนะค่ะ 星屑の紹介状 แปลว่าอะไร เพราะที่ยุ่นเป็นชื่อนี้อ่ะ
