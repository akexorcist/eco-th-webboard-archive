บางที ถ้าเราลองสังเกตุอะไรเล็กน้อยๆ อาจจะพบเกร็ดอะไรบางอย่างในเกมส์ได้
เรากำลังจะพูดถึง wizard และ shaman
เราพบจุดร่วมของนักเวท 2 สายนี้ว่า

- 2 อาชีพนี้ สมัครอาชีพและเปลี่ยนอาชีพที่เดียวกัน กับ NPC คนเดียวกัน(Spell user Master) เสมือนศิษย์สำนักเดียวกัน ต่างจาก warlock และ vates ที่เปลี่ยนกับ NPC คนละตัวกันเลย แถมกีดกันเรื่องเผ่าเล็กๆด้วย
- วิธีสมัครอาชีพคลาส1ก็คล้ายๆกัน คือการทดสอบความร้ และไม่มีข้อแม้เรื่องเผ่าพันธ์
- แม้ตอนเปลี่ยนอาชีพคลาส 2 ก็ยังเปลี่ยนที่เดียวกันอีก
- ไอเทมประจำอาชีพของ2อาชีพนี้ มักจะเอามาขายคู่กันในร้าน เสมอ.......
- มีสกิลบางอย่าง ที่เหมือนกัน(อันนี้ไม่ค่อยแปลก เพราะนักเวททั้ง4สายก็มีสกิลคล้ายๆกันอยู่แล้ว)

เคยเห็นกระทู้เถียงกันเรื่อง wizard กับ Shaman ก็บ่อย...
ลองคิดในมุมกลับ 2อาชีพนี้อาจเกิดมาคู่กันก็ได้นะ................
