Bladekill : ก็... ตรงนั้นเจ้าที่แรง มีถังขยะผีสิงอยู่ใบหนึ่ง ใครไปในบริเวณนั้นโดนหลอกประจำ โดนหลอกไม่พอ โดนทำร้ายร่างกายอีกต่างหาก จากคำบอกเล่านะ ลักษณะบาดแผลจะคล้ายๆกับแมวข่วนเต็มตัว และยังบอกอีกว่าได้ยินเสียงเหมียวๆด้วย สงสัยแถวนั้นจะมีฝูงแมวป่าอาศัยอยู่ละม้างงง เอ๊ะ...แมวมันอยู่กันเป็นฝูงเหรอ..? เออช่างเหอะ เอาเป็นว่า อย่าไปตรงนั้นเลยนะ แต่ถ้าจะไปก็แล้วแต่น้อง พี่ไปล่ะ
ฟลอน : อืมๆ... (คิดในใจ)‘เอ....เสียงเมี้ยวๆเหรอ... น่าสนใจแฮะ คล้ายๆในฝันเลย ลองไปดูดีกว่า’
หลังจากบอกลากันเสร็จ ฟลอนก็มุ่งหน้าไปยังที่ทิ้งขยะเก่าทันทีด้วยความตื่นเต้น
เมื่อไปถึงก็พบว่าบรรยากาศในบริเวณนี้มันเหม็นเน่ามาก เอ่อ...เพราะขยะนะ-*- เหมือนกับในฝันเด๊ะ
ฟลอน : ถังขยะ...ถังขยะ....อ๊ะนั่นไง!
หลังจากมองหาถังขยะอยู่ซักพัก ก็เจอใบนึง เป็นถังที่เก่ามาก และมีกองขี้อยู่ข้างหน้าถังเหมือนในฝันด้วย- -
ฟลอน : อึ๋ย...ขี้-*- ที่นี่เป็นที่ทิ้งขยะเก่า แล้วนั่นจะเป็นกองขี้เก่าด้วยรึเปล่าวะน่ะ...? เออช่างเถอะ ไปดูในถังดีกว่า
เมื่อเลิกสนใจขี้ ฟลอนก็หันไปสนใจถังขยะแทน และเริ่มเดินไปที่ถังขยะ ที่อยู่ห่างไปอีก 8 เมตร และเริ่มได้กลิ่นแปลกๆ คล้ายๆกลิ่นแมวแรงขึ้นทีละนิด
ฟลอน : อืมๆ ...สงสัยที่นี่จะแมวเยอะ กลิ่นงี้...- -
เมื่อมาถึงหน้าถังขยะ ก็เป็นจุดที่เหม็นได้ใจมาก โอย..เหม็น ฟลอนไม่รอช้า รีบชะโงกดูภายในถังขยะทันที
และพบกับ...
ฟลอน : เห้ย......อะไรวะเนี่ย-*- ขี้กับขนแมว...เต็มถังเลยว่ะ... แหวะ อ้ววววววกกกกกก!!!
“แง๊วววววว!!!!???”
ฟลอน : เอ๊ะเสียงอะไร? อะ ...ฮะ ฮะ ฮัด เช่ย!!!
*วิ้งงงง*
ไม่รู้ทำไมเหมือนกัน แต่พอเธอเริ่มจามก็มีแสงสีขาวประหลาดๆมาจากในตัวถัง ทำให้มองไม่เห็นไปชั่วขณะ รู้สึกตัวอีกทีก็มาอยู่ที่ไหนแล้วก็ไม่รู้ เป็นห้องที่มีปลากระโห้หน้าหนาอย่างผิดปกติที่กระโห้ทั่วไปจะเป็น พีโน และ ไทนี่ อยู่ต่อหน้า
ฟลอน : อึ๋ยๆๆๆ มะกี้มันแสงอะไรน่ะ.... อะ เห้ยยยย ตัวอะไรวะเนี่ยยยย!?
กระโห้ : แล้วแกล่ะเป็นตัวอะไร ?!
พีโน : แกเป็นตัวอะไร
ไทนี่ : ไผ(ใคร)กันน่ะ
ในขณะที่ในห้องกำลังเต็มไปด้วยความสับสนปนมาคุ ฟลอนก็เหลือบไปเห็นริมฝีปากของกระโห้แบบชัดๆเต็มตา และคิดว่า มันหนาเสียเหลือเกิ๊นนนน

กระโห้ : ......ฮึ่ย...อีนังนี่...วอนซะแล้ว..ดันมาล้อปมด้อยตูได้- -*.... ห๊ะ!?
“มิ...เหมี๊ยวววว 55555555+”
ฟลอน : (หยุดหัวเราะแล้ว)....’เมื่อกี้มันเสียงตัวอะไรหัวเราะน่ะ...’

ฟลอน : เห้ย...? ข้องใจนะเว้ย ชั้นไม่ได้พาตัวอะไรมาด้วยสักหน่อย มั่วนิ่มใหญ่แล้ว!?
“เหมียว...”
กระโห้ : อี๋~~~!!!! สงสัยมันจะหิว เอามันไปห่างๆพวกเราน๊าาาาา
พีโน : เอามันออกไป!
ไทนี่ : Get out!
แล้วฟลอนก็โดนถีบออกมานอกห้อง และพบว่าตัวเองอยู่ในสถานที่ๆคล้ายกับหออะไรซักอย่าง...
“เหมี๊ยวววววว คิคิคิ”
