ชี้แจงเรื่อง Skill OC ของ merchant และ Skill Trust ของ Trader นะคับ
Skill OC ของ Merchant นั้นจะทำให้เราสามารถขายของได้ในราคาที่สูงขึ้น
ต.ย. เรามีไอเทม 1 ชิ้นราคา 100G เมื่อเรามี Skill Oc แล้ว จะทำให้ขายไอเทมชิ้นนั้นเป็น 120G เป็นต้น

ส่วนในเรื่องของ Skill Trust ของ Trader ที่สงสัยกันคือ Skill นี้เป็น Skill ที่สามารถทำให้ขายของราคาแพงได้ >> ซึ่งหมายความว่าเราจะสามารถไอเทมที่มีราคาแพงได้นั่นเอง ไม่ใช่ทำให้ขายของแล้วเงินเยอะขึ้น
ต.ย. ลองสัังเกตุดูว่ามีไอเทมบางชนิดที่มีราคาสูงแต่ไม่สามารถขายให้กับ NPC ได้ (จะเป็นตัวหนังสือสีดำไม่สามารถกดขายได้) เช่น เรามีหอกที่ขายได้ราคา 5000G อยากจะขายเข้าร้านแต่ขายไม่ได้ เราจำเป็นต้องอัพ Skill Trust ก่อนถึงจะขายของที่มีราคาสูงได้ ซึ่ง Skill นี้เมื่อเลเวลมากขึ้นจะทำให้ขายของที่มีราคาสูงมากให้แก่ NPC ได้ตามลำดับคับ
