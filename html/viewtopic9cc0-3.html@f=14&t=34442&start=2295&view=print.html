บังเอิญได้ทิปเล็กๆน้อยๆในการใช้พูวราริตี้ แอโรว โดยพื้นฐาน สกิลนี้จัดว่าแรงสูสีกับแบลซแอโรวเลย แต่มักจะมีปัญหา ยิงวืดบางดอก ความเสียหายเลยไม่คงที่อย่างมาก แต่ก็ แก้ลำด้วยการยิงชาร์จแอโรวไปก่อน(ผลัก+เกร็งประมาณ 2 วิ ) ช่วงพริบตานี้ยิงพูวราริตี้ แอโรว ทันที จะไม่มีพลาดเลย(เว้นAvoid)

แต่ว่า วิธีนี้จะไม่เหมาะกับหน้าไม้(ระยะยิงสั้นเกินไป) ตอนยิงชาร์จ หน้าไม้จะเสียจังหวะการซ้ำด้วยพูวราริตี้


ปล. ประยุกต์กับ พูวราริตี้บูลเล็ต+ชาร์จ บูลเล็ตก็ได้นะ
