ถ้าไม่เน้นเก็บเวล ก็อัพไรก็ได้ครับ
อัพ ๆ ไปเหอะ ไงก็ดูดเอาอยู่แล้วนี่ครับ
เพราะสกิลสร้างมันไม่ขึ้นอยู่กะ stat อะไรเลย

ถ้าจะเล่นเอง stat หลัก ๆ ก้มี 2 สาย คือ Vit กะ Agi ตามlink ที่เค้าบอกแหละ
ส่วนจะให้อัพเท่าไหร่ ก็คงต้องแล้วแต่ความชอบแต่ละคนละครับ
คงไม่มีสูตรสำเร็จให้

เพราะทาทา มีความหลากหลายในการเล่นมากครับ
