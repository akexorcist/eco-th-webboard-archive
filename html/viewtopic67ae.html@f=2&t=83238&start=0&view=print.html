- อินโดนีเชีย : wavegame.net ก.พ. 2009
- ไต้หวัน-ฮ่องกง : gamecyber.com.hk ก.ค. 2007 ต่อสัญญา มิ.ย. 2011
- ประเทศไทย : ONENET CO. ก.ย. 2010
- ประเทศจีน : the9.com ม.ค. 2007 หมดสัญญา ม.ค. 2010
- ประเทศจีน : accessbright.com CBT Test ก.พ. 2011
