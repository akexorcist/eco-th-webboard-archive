ยังไง Bonus ก็นับใหม่อยู่ดีครับ ไม่เกี่ยวว่าเปลีย่นก่อนจะไม่เก่ง เพียงแต่ถ้าเล่น Shaman ควร

ที่จะเปลี่ยนตอน 50 มากๆครับ เพราะสกิลพื้นฐานจะเอามาได้ครบ ในสกิลหนึ่งถ้าจะอัพถึง

เลเวล 5 ต้องใช้ถึง 7 พอยท์ (เลเวล 1 จะใช้ 3 พอยท์นะครับ) พื้นฐานของ Shaman

ควรที่จะอัพสกิลดังนี้ไว้ ๐ ๐ ๐

• Max Mp
• Recovery MP
• Fire Blast
• Aqua Blast
• Lightning Blast
• Crack Blast

ซึ่งสกิลพื้นฐานก็ปาไป 6 แล้ว ก็คือจะใช้พอยท์ทั้งหมด 6x7 = 42 พอยท์ นอกเหนือจากนี้

ต้องอัพ Skill เริ่มต้นเพื่อใช้ในการยิงมอนอีกด้วย ซึ่งคือธาตุใดธาตุหนึ่ง ถ้าอัพเต็มเวล 5 ก็จะ

ใช้พอยท์อีก 7 พอยท์เป็น 42+7 = 49 พอยท์ และเผื่อใครอยากอัพเกราะธาตุต่างๆไปอีก

ก็ใช้อีก 49+7 = 56 พอยท์ ..การไปเอาสกิลฟรีด้วยเควสต่างๆก็ช่วยได้ครับ ๐ ๐ ๐



ปล. สุดท้ายก็แล้วแต่คน แต่การเปลีย่นตอนจ๊อบ 50 จะทำให้มีสกิลไว้ใช้เยอะกว่าครับ :oops:
