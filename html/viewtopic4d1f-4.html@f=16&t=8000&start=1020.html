ยูคิมุระ บันทึก:
คำพูด:
แต่รบกวนคุณยูคิมูระหรือผู้รู้ช่วยตอบประเด็นนี้หน่อยนะคับ
1. ควรจะฝึกให้wan wan โตสุดก่อนแล้วอัพเกรด หรือ อัพเกรดก่อน แล้วค่อยเอามาฝึก มันจะต่างกันมั้ยอ่ะคับ
2.สกิล Mace Mastery มีผลกับอาวุธ Type Hammer อย่างเดียวหรอคับ แล้วเกมนี้มีอาวุด Type Mace มั้ยคับ





1. ต้องฝึกให้เต็ม อย่างใดอย่างนึงก่อน แล้วถึงอัพเกรดได้งับ

2. มีผลงับ อย่างเดียวกันงับ อาวุธประเภท Mace ยังม่ายมีน่ะครับ ถ้ามีจะรีบนําข้อมูลมา

บอกงับ ขออภัยด้วยน่ะครับ

ขอบคุณมากคับ แล้วควรจะรอให้ฝึกเต็มทุกอันก่อนมั้ยอ่ะคับแล้วค่อยไปแปลงร่างจะได้เก่งๆ หรือไม่เกี่ยวคับ



ฝึกเต็มอันใดอันหนึ่งก่อนอ่ะครับ อันเดียว แล้วค่อยไปอัฟเกรดงับ แล้วมันจะเก่งขึ้นมากกกก
