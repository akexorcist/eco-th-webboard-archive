Copy มากจากเพื่อนผมอีกทีนะครับ by JobOBo

Base LV. >>>

Point จากเลเวล 1 ไป 2 นะครับ จะได้ = 3
จากเลเวล 2 ไป 3 นะครับ จะได้ = 3
จากเลเวล 3 ไป 4 นะครับ จะได้ = 3+1 = 4
จากตรงนี้จะเห็นได้ว่าเริ่มต้นจะมี Point ให้เราใช้ที่3และจะ +1 เพิ่มให้ทุกๆ 3 เลเวลครับ
ตัวอย่าง LV. 4-6 Point = 4
LV. 7-9 Point = 5
LV. 10-12 Point = 6 ไปเรื่อยๆอย่างนี้

หรือจะคิดจากสูตรก็ได้ Floor[ (N-1)/3 ] + 3 = Point ของ LV. ที่ N
โดยที่ N คือ เลเวลถัดไปของตัวละคร(เลเวลปัจจุบัน+1นั่นแหละครับ)
Floor คือ ปัดเศษลง


Job LV. >>>

อัพ1ครั้งจะได้ 1 ลูกเล็ก โดยที่ 3 ลูกเล็กจะรวมได้ 1 ลูกใหญ่(มันมีลูกเล็กลูกใหญ่จิงๆน้า)
การจะเปิดสกิลใหม่(อัพให้สกิลนั้นขึ้นเป็น LV.1) จำเป็นที่จะต้องใช้ 1 ลูกใหญ่
ถ้าจะอัพให้สกิลเป็น LV.2,3,4,... ใช้แค่ 1 ลูกเล็ก
ตรงนี้ถ้ายังไม่เคยเล่นอาจจะงงนิ้สนึงครับ
