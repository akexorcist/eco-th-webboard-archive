:: สิ่งที่ควรรู้ในโลก 'เฟลาเทียร์' ::


- ค่าเงินในโลกเฟลาเทียร์นั้นจะใช้สกุลเงิน ‘ฟาเลน’ หากให้ประมาณค่าเงินก็ 2 บาท = 1 ฟาเลน ( เช่นอาหารในโลกเฟลาเทียร์อาจจะมีค่าประมาณ 50 – 60 ฟาเลน สำหรับอาหารธรรมดา )


- โรงเรียนในโลกเฟลาเทียร์นั้นจะสอนทุกอย่างตั้งแต่เวทย์มนต์รวมทั้งศาสตร์หลากหลายแขนงแล้วแต่ว่าผู้ที่เรียนจะเลือกเอา


- ในโลกเฟลาเทียร์นับถือพระเจ้าหลายองค์ หากแต่พระเจ้าสูงสุดคือ ‘เซลันเทียร์’ ซึ่งถูกเปรียบว่าเป็นผู้สร้างโลกใบนี้เลยทีเดียวและในโบสถ์ก็จะมีเทวรูปของพระองค์ตั้งอยู่ทุกแห่ง


- แม้นว่าเทคโนโลยีจะเจริญ หากแต่เรื่องของพาหนะก็ยังเป็นลักษณะที่คล้ายกับรถยนต์อยู่ ยังไม่ถึงขั้นที่จะลอยเคว้งคว้างไปมาในอากาศ เพื่อเป็นสิทธิพิเศษสำหรับเผ่าพันธุ์ที่มีปีก

:: RULE ! ::


1. คุณสามารถควบคุมกริยาและคำพูดได้แค่ตัวละครที่อยู่ในสังกัดของคุณเท่านั้น ส่วนผู้ร่วมเล่นคนอื่นไม่สามารถที่จะให้ตัวละครของคุณพูดหรือว่าแสดงกริยาใดขึ้นมาได้ ( นอกเสียจากมีการนัดแนะกันทาง PM แล้ว )


2. การแสดงออกของตัวละครรวมทั้งคำพูดนั้น ควรจะมีเหตุผลที่พอรับได้ ไม่ใช่ว่าจะฆ่าได้หรือว่าทำอะไรไร้เหตุผล หรือว่าอาจจะกระทำสิ่งใดก่อน เช่นเข้าโจมตี ก็ขึ้นอยู่กับว่าอีกฝ่ายนั้นต้องการจะทำเช่นไร ( อาจจะตอบโต้ หรือว่าอาจจะหนีแทน )


3. การสร้างตัวละคร สามารถมีได้หลายตัว ไม่จำเป็นต้องลงรายละเอียด หากแต่ตอนปรากฎตัวนั้นคุณต้องอธิบายลักษณะหน้าตาและเครื่องแต่งกายของตัวละครออกมาด้วย เพื่อจะได้สะดวกต่อการเห็นภาพของอีกฝ่ายที่กำลังเล่นกับคุณอยู่


4. การสร้างตัวละครขึ้นมาตัวนึงนั้น เวลาเจอกับตัวละครที่ไม่เคยเจอมาก่อน ก็อาจจะเลือกได้ว่าจะแนะนำตัวหรือว่าจะทำเช่นไรก็ได้ แล้วแต่คุณจะต้องการ และการสร้างตัวละครนั้นควรจะคำนึงถึงเรื่องความเหมาะสมด้วย ไม่ใช่ว่าจะเก่งเกินไปอะไรเช่นนี้ และการสร้างตัวละครที่มากกว่าหนึ่งตัว อาจจะให้มีความสัมพันธ์อยู่แล้วกับตัวละครตัวเก่า หรือว่าไม่เคยพบกันเลยก็เป็นได้


5. การคุยกันเองระหว่างตัวละครในสังกัด สามารถทำได้ และการพูดหรือกล่าวถึงตัวละครของผู้อื่นนั้นก็สามารถทำได้ด้วยเช่นกัน หากแต่เราไม่สามารถควบคุมอะไรได้


6. หากอีกฝ่ายที่กำลังต่ออยู่กับคุณนั้นหายไปโดยไม่บอกกล่าว อาจจะทำการตัดไว้ก่อน และข้ามเหตุการณ์ช่วงนั้นเพื่อกลับมาต่ออีกทีตอนหลังก็สามารถทำได้


7. แต่ละ Rep 2 บรรทัดและความมีความยาวพอสมควร ไม่ใช่แค่ว่า "ครับ" ตัวประกอบ A พูดขึ้น

:: บทนำ ::


เคยได้ยินทฤษฎีที่กล่าวเอาไว้เกี่ยวกับโลกต่างมิติ ? หรือว่าโลกคู่ขนานไหม ? มีคำกล่าวถึงโลกเหล่านั้นมากมาย ว่าแตกต่างจากโลกของเรามากแค่ไหน ? โลกของคุณอาจจะเป็นโลกที่เต็มไปด้วยเทคโนโลยีล้ำสมัย หรือว่าอาจจะเป็นโลกในยุคโบราณที่ยังคงใช้สัตว์ในการลากเกวียนเพื่อเดินทางก็เป็นได้


หากแต่ ...


ยังคงมีโลก ... โลกที่งดงาม และเต็มไปด้วยปริศนามากมาย เป็นโลกที่มีแต่คนใฝ่หา โลกที่มี ‘เวทย์มนต์’ ...


นามของโลกนั้นคือ ‘เฟลาเทียร์’ ...


แผ่นดินอันกว้างใหญ่และงดงาม ราวกับเป็นผลงานชั้นยอดจากพระผู้เป็นเจ้าก็ว่าได้ ทั้งธรรมชาติที่สวยงาม และเผ่าพันธุ์ทุกเผ่าที่อยู่ร่วมกันอย่างปรองดอง ราวกับถูกเชื่อมกันไว้ด้วยด้ายเส้นเดียวกันทั้งโลกใบนี้ ด้วยหลักของการวิวัฒนาการที่นำพาเผ่าพันธุ์ทั้งหลายให้มีความแตกต่างกัน ทั้งทางบุคลิก , กายภาพ รวมทั้งสภาพจิตใจก็ด้วยเช่นกัน แต่ละเผ่าพันธุ์นั้นก็แตกแขนงออกไปนับไม่ถ้วนจน ‘เฟลาเทียร์’ นั้นเต็มไปด้วยหลากหลายเผ่าพันธุ์มากมายเหลือคณาเกินกว่าจะนับไหว


พวกเขาต่างอาศัยอยู่ในถิ่นที่แตกต่างกันตามสภาพแวดล้อมที่พวกเขาพึงพอใจจะอยู่ แต่ทว่าหลังจากนั้นก็เริ่มมีการอยู่ร่วมกันมากขึ้นในแต่ละสถานที่ และพวกเขาก็ตั้งมันขึ้นเป็นทั้ง ‘เมือง’ หรือว่าแม้แต่ ‘อาณาจักร’ ก็ด้วยเช่นกัน และเวลาก็ผ่านไปหลายร้อยปี ... จนทุกสิ่งทุกอย่างลงตัว ด้วยความรู้ทางเวทย์มนต์และทางวิทยาศาสตร์ทำให้วิทยาการของ ‘เฟลาเทียร์’ เต็มไปด้วยความน่าอัศจรรย์ ความรู้ทั้งสองด้านในแต่ละแขนงล้วนแต่นำคุณและโทษแก่โลกใบนี้ทั้งสิ้น ซึ่งก็ขึ้นอยู่กับมือของผู้ใช้ ว่าจะเลือกหนทางไหนกัน ?


ตอนนี้เราจะกล่าวถึงอาณาจักรที่สำคัญในโลกของ ‘เฟลาเทียร์’ กัน ...


‘อาณาจักรฟิลาเดลอัส’ – เป็นอาณาจักรที่ขึ้นชื่อว่าใหญ่โตและเต็มไปด้วยความรู้หลากหลายแขนงที่สุด อีกทั้งกองกำลังทหารของที่นี่ก็แข็งแกร่งมากทีเดียว สิ่งขึ้นชื่อคงไม่พ้นกำแพงมนตราแห่งฟิลาเดลอัส ซึ่งหากมีผู้ใดประสงค์ร้ายต่อกำแพงแห่งนี้ จักถูกเวทย์มนต์อันกล้าแข็งเผาไหม้จนสิ้นไป ที่นี่ใช้ระบอบกษัตริย์เป็นใหญ่ที่สุด ซึ่งตอนนี้ก็คือ ‘ฟาลาเดลที่สาม’ ซึ่งครองราชสมบัติมาเป็นเวลาเกือบห้าสิบขวบปีแล้ว พระองค์ทรงปกครองด้วยหลักพ่อปกครองลูก ทรงถือว่าประชาชนของพระองค์ทั้งมวลเปรียบเสมือนบุตรชายและบุตรสาวของพระองค์


ในโลกแห่ง ‘เฟลาเทียร์’ ฟิลาเดลอัสเป็นสถานที่เพียงแห่งเดียวเท่านั้นที่ถูกเรียกว่า ‘อาณาจักร’ นอกนั้นล้วนแต่เป็นหัวเมืองซึ่งมีอิสระในการปกครองตัวเอง แต่กระนั้นก็ขึ้นอยู่กับอาณาจักรฟิลาเดลอัสอยู่ดี ซึ่งเมืองแต่ละเมืองนั้นก็มีความเล็กใหญ่และระบอบการปกครองที่แตกต่างกันไป ทั้งนี้ก็ขึ้นอยู่กับเจ้าเมืองนั้น ๆ ด้วยเช่นกัน


เราจะกล่าวถึงหัวเมืองที่สำคัญทั้งสาม ที่ได้ชื่อว่ามีความสำคัญรองจากฟิลาเดลอัสกัน ...


เมืองซากิเดล – เมืองท่าที่สำคัญมากสำหรับอาณาจักร ด้วยความที่มีท่าเรือขนาดใหญ่ที่สุดบนโลกเฟลาเทียร์ ทำให้เมืองนี้เป็นเมืองที่มีผู้คนมากมายหลายเผ่าพันธุ์อยู่ร่วมกันไม่ต่างอะไรจากฟิลาเดลอัสเท่าไรนัก มีทั้งตลาดสดรวมทั้งตลาดที่เปิดขึ้นเพื่อเป็นศูนย์กลางของการค้าขายให้กับแต่ละเผ่าพันธุ์ด้วยเช่นกัน ขนาดของเมืองนั้นถือว่าใหญ่เป็นอันดับสาม ( รองจาก ฟิลาเดลอัส และ มากิดัส ) เมืองท่าซากิเดลนั้นใช้วิธีคัดผู้นำโดยยึดถือความใหญ่โตของกิจการ และความร่ำรวยของคนผู้นั้น และเมืองนี้อยู่ทางทิศตะวันออกของฟิลาเดลอัส


เมืองมากิดัส – หากจะกล่าวถึงคำนิยามของเมืองนี้ คงไม่พ้น ‘เมืองแห่งเวทย์มนต์’ จุดเด่นของเมืองคงไม่พ้นหอสมุดเวทย์มนต์ขนาดยักษ์ที่ตั้งเด่นเป็นสง่าอยู่กลางเมือง ลักษณะคล้ายกับหอคอยสีขาวที่สูงเทียมฟ้า และมีคำเล่าลือว่า บนสุดของหอคอยนั้น เต็มไปด้วยคัมภีร์เวทย์มนต์ล้ำค่าที่หายากและทรงพลานุภาพมากมาย แต่สุดท้ายแล้วก็เป็นเพียงแต่ข่าวลืม เพราะว่าไม่มีใครที่สามารถพิสูจน์ได้ ตลาดตามเมืองนี้ล้วนแต่เป็นตลาดที่ขายพวกวัตถุดิบในการปรุงยา ลักษณะตัวเมืองนั้นเต็มไปด้วยตรอกและซอยมากมาย ซึ่งเป็นสถานที่สำหรับหาซื้อสิ่งของผิดกฎหมายก็ว่าได้ เมืองนี้ถูกใหญ่เป็นอันดับสอง รองจากฟิลาเดลอัสเท่านั้น แม้นว่าประชากรนั้นจะน้อยกว่าซากิเดลก็ตามที ผู้ปกครองเมืองนี้คือ ‘ปราชญ์เซกิส’ ผู้ได้ขึ้นชื่อว่าเป็นอาจารย์สอนเวทย์มนต์ให้กับกษัตริย์ ตั้งอยู่ทางทิศตะวันตกของฟิลาเดลอัส


เมืองวิลาเนีย - เมืองแห่งการเกษตร


ดินแดนลับแล ‘คาบาเวียร์’ – ไม่อาจจะกล่าวว่าเป็นเมืองได้ แว้นว่าแผ่นดินจะกว้างใหญ่ แต่ก็เต็มไปด้วยความแห้งแล้งและแร้นแค้น เผ่าพันธุ์ที่อยู่ ณ ที่นี้ก็ล้วนแต่เป็นพวกกระหายเลือด อีกทั้งยังป่าเถื่อนเหลือคณา ซึ่งผู้คนที่กระทำความผิด ก็จะถูกศาลสูงตัดสินให้โดนเนรเทศมายังคาบาเวียร์ ซึ่งก็ไม่ต่างอะไรจากโทษประหารเท่าไรนัก อีกทั้งยังเต็มไปด้วยสัตว์ประหลาดหน้าตาน่ากลัว และเต็มไปด้วยความหยากเนื้อสด ดังนั้นที่นี่จึงไม่ต่างอะไรจากนรกภูมิเท่าไรนัก มีข่าวลืออยู่ ... ว่ามีพวกอมนุษย์ตระเตรียมกองทัพเพื่อเข้าทำลายฟิลาเดลอัส ดังนั้นที่ชายแดนของดินแดนนี้ จึงมีทหารมาประจำการอยู่ตลอดเวลาเพื่อเป็นการเตรียมพร้อม


แต่สำหรับ ... สถานที่ที่เราจะกล่าวถึงนี้ ... ตั้งอยู่ทางทิศตะวันออกของฟิลาเดลอัส ซึ่งมีพร้อมสมบูรณ์ทั้งโบสถ์ , โรงเรียน และสิ่งอำนวยความสะดวกทั้งมวล ซึ่งก็ต้องขอกล่าวไว้ก่อนว่าฟิลาเดลอัสนั้นแบ่งการปกครองเป็นห้าส่วน ส่วนแรกคือส่วนที่ใหญ่ที่สุด คือส่วนกลาง และอีกสี่ส่วนนั้นก็คือ เหนือ , ใต้ , ออก และ ตก ซึ่งแต่ละส่วนนั้นก็จะมีโบสถ์หรือว่าโรงเรียนของแต่ละส่วน เช่น โรงเรียนเวทย์มนต์ฟิลาเดลอัสตะวันออก


สิ่งที่สำคัญที่สุดสำหรับมนุษย์นั้น อาจจะไม่ใช่ความรู้ หรือว่าพลังอำนาจ หากแต่เป็น ‘จินตนาการ’ ...


ประโยคนี้ เป็นประโยคที่ถูกสลักไว้หน้าตึกสีขาวขนาดกลาง ประตูรั้วสีขาวนั้นดูอ่อนโยนและสบายตา สวนดอกไม้ที่อยู่หลังรั้วนั้นส่งกลิ่นหอม รวมทั้งสร้างความจรรโลงใจให้แก่ผู้พบเห็นอย่างยิ่ง พื้นหินอ่อนที่ทอดยาวตั้งแต่ประตูรั้วไปจนถึงประตูสีขาวบานใหญ่ และที่นั่น ก็มีนามของสถานที่นั้นอยู่ ...


... ‘หอพักเพื่อผู้ไขว่คว้าความฝันและจินตนาการอันไร้ขอบเขต’ ... หรือเรียกว่า ‘The Dream’ ...


จากประตูทางเข้าไปนั้น เมื่อเข้าไปจะพบกับเคาน์เตอร์สีขาว ซึ่งไม่เพียงแต่เคาเตอร์เท่านั้น ทั้งเก้าอี้ รวมทั้งโซฟาต่าง ๆ ล้วนแต่เป็นสีขาว ซึ่งเข้ากับผนังห้องสีน้ำตาลอ่อนดูสบายตา เมื่อเดินต่อเข้าไปจะพบกับห้องนั่งเล่นรวมขนาดใหญ่ ที่มีทั้งโทรทัศน์และโซฟาเพื่ออำนวยความสะดวกสบาย อีกทั้งยังมีตู้เย็นรวมเพื่อใช้รวมกันอีก หน้าต่างถูกเปิดออก และแขวนไม้ประดับไว้เพื่อความรู้สึกอบอุ่น และถัดไปนั้นก็เป็นห้องน้ำรวม โดยฝั่งตรงข้ามนั้นก็เป็นห้องครัวและห้องทานข้าว ซึ่งแน่นอนว่าอาหารนั้น ก็มีบริการให้ด้วยเช่นกัน ( แน่นอนว่าเสียเงิน ) รวมทั้งเครื่องดื่มก็ด้วยเช่นกัน


จากนั้นเมื่อเดินขึ้นบันไดไป จะพบกับห้องพักห้องแรก และไล่ยาวไปราวสิบห้องเลยทีเดียว ซึ่งที่หน้าห้องนั้นก็มีหมายเลขห้องติดอยู่ ( ไล่ตั้งแต่ 1 – 10 ) ห้องพักทุกห้องนั้นมีห้องน้ำในตัว และเตียง รวมทั้งตู้ด้วยเช่นกัน และเมื่อเดินขึ้นไปอีกชั้นนึง จะเป็นสระว่ายน้ำกลางแจ้ง รวมทั้งห้องฟิตเนสเพื่อสุขภาพของคนในหอพัก ส่วนที่ดีที่สุดคงไม่พ้นบ่อน้ำร้อนรวมที่ช่วยให้ผ่อนคลายอย่างดีเยี่ยม ...


หากจะบอกว่าสิ่งเหล่านี้ไม่แพงเลย คงไม่เชื่อ เจ้าของคนปัจจุบันนั้นมีนามว่า ‘เซเรนเซีย เอส. เฟลาเทียร์’ ... มันเป็นหอพักที่น่าประหลาด เพราะด้วยความสะดวกสะบายพร้อมขนาดนี้ และที่ดินในตัวเมืองอย่างนี้ ราคาน่าจะแพงโขอยู่สำหรับการเข้าพัก หากแต่ ... จนถึงตอนนี้ ยังไม่มีใครที่ได้เข้าพักในที่แห่งนี้เลย ด้วยความที่ว่าเข้าไปแล้ว เซเรนไม่ได้พูดอะไร หากแต่ชี้ให้คนที่เดินเข้าไปกลับออกมาเท่านั้น และเอ่ยด้วยน้ำเสียงเย็นชาว่า ...


... “หากท่านมิได้ปรารถนาสิ่งใด จงอย่าเข้ามา หากท่านมิได้ตามหาความฝัน จงอย่าเข้ามา” ...


เอาล่ะ ... หากคุณเป็นคนนึง ... ที่กำลังตามหาความฝัน ลอง ... เดินเข้ามาในหอพักแห่งนี้ดูสิ ...


ที่เหลือก็เป็นหน้าที่ของเธอนะ ... “เซเรน” ...

“ คุณแม่คะ ... นั่นแสงอะไร? ” เด็กสาวตัวน้อยเอ่ยกับมารดาขอองตนพร้อมกับยกนิ้วเล็ก ๆ ขึ้นชึ้ไปยังแสงสีชมพูเจิดจ้าที่ทอประกายอยู่เหนือฟากฟ้า แต่ก่อนที่มารดาของเธอจะได้เอ่ยตอบอันใด ...
เปลวเพลิงสีแดงฉานลุกโชนทั่วเมืองแห่งการเกษตร ‘ วิลาเนีย ’ แทบจะในทันทีหลังจากที่แสงสีชมพูนั้นถูกยิงลงมาจากบางสิ่งที่ลอยอยู่เหนือฟากฟ้า อาคารบ้านเรือนพังทลายพร้อมกับเปลวเพลิงแห่งความตายและการสูญเสียลุกโชนขึ้นอย่างไม่มีท่าทีว่าจะหยุดลง ...
ภาพสุดท้ายที่ผู้รอดชีวิตได้เห็นคือเกาะลอยฟ้าขนาดใหญ่ที่กำลังปลดปล่อยแสงแห่งการทำลายล้างลงมาอย่างบ้าคลั่ง
สิ่งนั้นถูกขนานนามต่อมาว่า ‘ M E S S I A H ’ (เมไซอาห์)


มังกรเร็วถูกส่งออกมาจากป้อมปราการฟิลาเดลอัสประจำเมืองวิลาเนียอย่างรวดเร็ว บุรุษผู้สูญเสียทุกสิ่งกำสาร์นในมือแน่นพร้อมกับน้ำตาที่หลั่งไหลออกมามิอาจหยุดจนแทบจะกลายเป็นสายเลือด สิ่งเดียวที่ร่างซึ่งหมดสิ้นแล้วทั้งกำลังกายและกำลังใจสามารถจะทำได้ คงเป็นแค่การส่งสาร์นนี้ให้ถึงพระหัตถ์ของกษัตริย์เฟลาเทียร์
... เพื่อมิให้เกิดความสูญเสียเหมือนที่ตัวเขาเองได้พบเจอ! …


ช่างน่าเศร้า ... ไม่ทันที่มังกรที่ได้ขึ้นชื่อในเรื่องของความเร็วจะได้บินออกจากตัวเมืองที่ล่มสลาย ศีรษะของบุรุษผู้ส่งสาร์นและตัวพาหนะของเขาเองนั้น ถูกสะบั้นจนขาดกระเด็น ทั้งร่างของมนุษย์และมังกรกระตุกสองสามครั้งก่อนที่จะร่วงหล่นสู่เปลวเพลิงแห่งความตาย
เหนือกำแพงเมืองวิลาเนีย ร่างบางยกคมดาบที่ยาวกว่าสองเมตรขึ้นมองด้วยความพึงพอใจ ก่อนจะใช้ปลายลิ้นเลียไปตามคราบเลือดที่ติดอยู่บนคมศาสตราวุธ ดวงเนตรสีแดงฉานราวกับปีศาจ เรือนผมสีดำยาวสลวยปลิวไสวตามแรงระเบิดและไอร้อนจากเปลวเพลิงเบื้องหลัง


“ ฉันกลับมาแล้ว ... ”


เพียงเวลาแค่ไม่ถึง 3 วัน ...
เมืองลูกของอาณาจักรเฟลาเทียร์ได้ถูกทำลายลงอย่างรวดเร็ว เหล่าผู้รอดชีวิตอันน้อยนิดต่างพากันแบกสัมภาระเท่าที่จะหาได้พร้อมกับความสิ้นหวังและสูญเสียเดินทางเข้าสู่เมืองหลวงเพื่อหวังจะพึ่งพาพระบารมีของกษัตรืย์ผู้ทรงธรรม ไม่ว่าจะเป็นอัศวินผู้ทรงเกียรติหรือแม้กระทั่งกองกำลังทหารรับจ้างผู้หวังเพียงแค่เศษเงินถูกเรียกรวมตัวอย่างรีบร้อน เหล่าร้านค้าและแผงลอยในเมืองต่างพากันคึกคักมากขึ้น แต่กระนั้นก็ยังมีบางส่วนที่ปิดร้านเตรียมพร้อมจะอพยพได้ทุกเมื่อ ...
แต่ความฝันยังคงต้องดำเนินต่อไปใช่ไหมล่ะ? ... เกล ...


เหนือแผ่นหินอันจารึกไว้ถึงนามของผู้มีพระคุณนั้น หญิงสาวเจ้าของเรือนผมสีดำยาวสลวย หญิงสาวผู้ที่เคยมีรอยยิ้มงดงามดุจดังเทพธิดา กำลังยืนมองแผ่นหินนั้นด้วยดวงเนตรไร้วิญญาณ ขณะที่สองมือนั้นกอดช่อดอกกุหลาบสีขาวสะอาดเอาไว้แน่นราวกับมันเป็นสิ่งที่สำคัญยิ่ง ดวงเนตรของเธอนั้นจับจ้องไปยังคำจารึก ...
“ เพื่อนและพี่ชายที่แสนดีตลอดกาล ได้หลับใหลอยู่ ณ ที่แห่งนี้ - การิเดส เฟธ. แสตนฟิลด์ ”


เซเรน ... คือนามของเธอ
หญิงสาวผู้ที่เคยได้ขึ้นชื่อว่าเป็น “ ผู้ดูแลหอพักแห่งความฝัน ” หอพักอันพร้อมจะทำให้ผู้ที่มี “ ฝัน ” ได้พบกับความปรารถนาของตน แต่กระนั้น ก็ขึ้นอยู่กับตัวพวกเขาเอง
หากแต่ด้วยความสูญเสีย “ ครอบครัว ” คนสุดท้ายไปนั้น ได้ทำให้จิตใจของเธอได้รับความกระทบกระเทือนอย่างรุนแรงจนจำเป็นที่จะต้องทำการปิดตัวหอพักแห่งความฝันไป เซเรนได้แต่จมลึกอยู่ในห้วงสมุทรแห่งความทุกข์อันไร้ทางออก เวลาในแต่ละวันผ่านไปแค่การนั่งอยู่ในห้องคนเดียว พร้อมกับทอดสายตาอันไร้วิญญาณนั้นออกไปด้านนอก


แต่กระนั้นหญิงสาวอีกคนกลับปรากฏตัวขึ้นในเวลาที่เมไซอาห์กำลังใกล้เข้ามายังเมืองหลวงเฟลาเทียร์ หญิงสาวเจ้าของเรือนผมสีฟ้ายาวสลวยและดวงเนตรสีน้ำเงินดูลึกลับปรากฎตัวในชุดกระโปรงสีฟ้ายาวต่อหน้าเซเรน โดยเธอนั้นได้ทำการบุกรุกเข้าไปพบเซเรนด้วยตัวของเธอเอง ทั้งสองมิได้เอ่ยสิ่งใด แต่กลับเข้าใจในสรรพสิ่ง


เซเรนลุกขึ้นเดินไปรับจดหมายที่อยู่ในมือของหญิงสาวลึกลับและเปิดมันขึ้นอ่าน สีหน้าของเธอนั้นกลับมายิ้มแย้มอีกครั้งนึงราวกับได้รับปาฎิหาริย์ เธอสวมกอดหญิงสาวลึกลับแน่นก่อนจะเอ่ยด้วยน้ำเสียงอันไพเราะ
“ ขอบใจนะ เอเลน ”


กระเป๋าเดินทางถูกเตรียมพร้อมอย่างรวดเร็ว เซเรนจัดกระเป๋าของเธอด้วยใบหน้าที่เปี่ยมไปด้วยความหวังและชีวิตชีวา เธอเดินเข้าไปเปิดตู้เก็บของที่ฝุ่นเกาะราวกับว่ามันไม่ได้ถูกเปิดออกเป็นเวลานาน “ อาวุธคู่กาย ” ของ “ เขาคนนั้น ”
“ ง้าวอาญาสวัสดิกะของเกล ”
ง้าว ... ศาสตราคู่กายอันถูกทำขึ้นอย่างประณีตด้วยหยกจากดินแดนลึกลับ ลงอาคมไว้ด้วยมนตร์วิเศษจากแดนเหนือ
เธอหยิบมันขึ้นมองด้วยสายตาราวกับว่าได้เห็นเกลอีกครา ก่อนจะสะพายไว้ด้านหลัง “ ไปด้วยกันนะคะ พี่เกล ”


ระยะเวลาผ่านไปครู่หนึ่ง ร่างของเซเรนพร้อมกับกระเป๋าเดินทางใหญ่ รวมทั้งง้าวอาญาสวัสดิกะที่ถูกสะพายไว้ด้านหลังก็ยืนอยู่หน้าหอพัก เธอหันกลับไปมองมันด้วยสายตาราวกับว่าจะไม่ได้เห็นมันอีกครั้งหนึ่ง ...
