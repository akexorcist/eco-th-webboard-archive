แมพที่มีมอนแปลกๆที่สงสัยกัน เป็นแมพใหม่ที่เกี่ยวข้องกับการตกปลาครับ

จะมี NPC ขายเหยื่อกับเบ็ดตกปลาให้ ตรงที่วงกลมไว้



วิธีตกปลาก็ไม่ยาก แค่ใส่เบ็ดละจะมีช่องใส่เหยื่อขึ้น ก็กดใส่ ละกดสกิลที่มีเพิ่มให้ตกปลาริมฝั่ง

ก็จะตกปลาได้ รอไปเรื่อยๆมันจะตกปลาเองจนกว่าเหยื่อจะหมด หรือจะหยุดก่อนก็ได้

แล้วปลาที่ตกได้ก็จะถูกบันทึกไว้ในสมุกตกปลาที่ NPC ให้ (ส่วนปลาก็เข้าตัว)

ใครอยากลอง ไปลองได้นะครับ ระวังตกมอนขึ้นมาด้วยล่ะ
