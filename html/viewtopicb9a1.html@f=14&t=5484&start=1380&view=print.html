ก่อนอื่น... ต้องทำความเข้าใจว่า Skill Point ในอาชีพแต่ละอาชีพนั้น แยกออกจากกันอย่างเป็นอิสระชัดเจน ไม่นำมาคิดรวมกัน
ดังนั้น ถึงแม้ว่าคุณจะทำการเปลี่ยนอาชีพเป็นสไตรค์เกอร์ แต่ Skill Point ที่ได้มาตอนเป็นอาเชอร์ยังมีอยู่ คุณก็สามารถเอาพอยน์นั้นไปอัพสกิลของอาเชอร์ได้

แต่! ไม่สามารถนำพอยน์ของอาเชอร์ไปอัพให้กับสกิลของสไตรค์เกอร์ได้นะ อัพได้เฉพาะสกิลที่ได้พอยน์มาจากตอนเป็นอาชีพนั้นๆเท่านั้น


เช่น
ถ้าคุณเอาอาเชอร์ที่มีสกิลพอยน์ 40 ไปเปลี่ยนเป็นสไตรค์เกอร์ สไตรค์เกอร์ตัวใหม่ของคุณก็จะมีสกิลพอยน์ของสไตรค์เกอร์ 0 และมีสกิลพอยน์ของอาเชอร์อีก 40

อาเชอร์ (อาเชอร์สกิลพอยน์ 40) > สไตรค์เกอร์ (สไตรค์เกอร์สกิลพอยน์ 0 + อาเชอร์สกิลพอยน์ 40)

เท่ากับว่า เมื่อคุณเปลี่ยนเป็นอาชีพสไตรค์เกอร์มาหมาดๆ ยังไม่ได้ออกไปเก็บเลเวลเลย คุณจะสามารถอัพสกิลได้ดังนี้
- พอยน์สไตรค์เกอร์ สามารถนำไปใช้อัพสกิลสไตรค์เกอร์ได้ทั้งหมด 0 แต้ม
- พอยน์อาเชอร์ สามารถนำไปใช้อัพสกิลอาเชอร์ได้ทั้งหมด 40 แต้ม
