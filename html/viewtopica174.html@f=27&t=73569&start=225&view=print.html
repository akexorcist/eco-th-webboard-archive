ลืมบอกไปอย่างนะ

พวกอาวุธ110 ต่างๆ ที่ ร่างแปลง[pet] ใช้ทุกชนิด หรือแม้แต่เราเองที่แก้ไขอาวุธ90 99 ให้แสดงผล110 ก็ตาม

พวก effect ของอาวุธ จะไม่ติดมาด้วย เช่น แสงไฟ หรือ motion ของตัวอาวุธเอง

เพราะเหตุใดนั้นก็ไม่สามารถทราบได้

ขนาดทำการ add ไฟล์ของเหล่าอาวุธครบแล้วก็เถอะ [ anim attr mrb tex ]

คงต้องรออนาคตให้อาวุธ 110 เข้าไทย ถึงจะมี effect เหล่านั้น (และก็จะเป็นการง่ายเพียงแค่แก้ไขเลขที่ itempict ด้วย)

ปล. ถ้ารูนเข้ากระทู้นี้ อยากจะบอกว่า ลืม add อาวุธ หอก110 ทั้ง 1 และ 2 มือไปนะ ; w ; ขอโทดด้วย ลืมไปเลยว่าต้องหาอาวุธด้วย

Folder effect

เข้าไปเติม pri- ทั้งหมด แล้ว rebuild ก็เหมือนเดิม

อาจจะต้องใช้ folder อื่นด้วย แต่ไม่อยากลองเท่าไหร่ เพราะมีครั้งนึงเคยทำ pri- ทั้งหมดเลยของยุ่น

ผลที่ได้คือ พวกหน้าต่าง สกิล ฯลฯ เป็นภาษายุ่นหมด แม้กระทั้งคำอธิบายสกิล (ถ้าอ่านออกก็คงจะดีกว่า ดีกว่าภาษาถ้วย eco ไทยเยอะ)

สรุปคือเพิ่ม folder effect เข้าไปด้วยแล้วก็ไม่ได้ผลเหมือนเดิมนิ อาวุธก็ไม่มีแสงหรือควันไฟขึ้น
