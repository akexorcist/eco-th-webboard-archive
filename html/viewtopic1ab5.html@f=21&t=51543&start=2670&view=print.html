อ้าวแล้วแบบนี้มันไม่ผิดกฎของบอร์ดหรือ?
- ถ้าแต่งแบบ
เรปที่1 "นายAเดินมา"
เรปที่2 "นายBแทงนายAตาย"
เรปที่3 "นายAฟื้นแล้วเอาปืนมายิงนายB"
แบบนี้และครับผิดแน่นอน แต่เราจะไม่แต่งแบบนั่นเพราะมันเหมือนปั้มกระทู้อย่างหน้าด้านๆ แล้วเราจะแต่งกันยังไงล่ะ?

ที่ เราจะแต่งคือฟิกต่อแบบมีการกำหนดเรื่อง ตัวละคร รวมถึงองค์ประกอบเอาไว้ครับ และให้แต่ละคนแต่งส่วนของตัวเองขึ้นมาให้อยู่ในพล็อต ฟังดูงงๆใช่มั้ยครับ ลองมาดูตัวอย่าง
เช่นเราแต่งฟิกแนว Srw ที่จะให้ผู้เข้าร่วมคิดค้นหุ่นออริจินอลของตัวเองขึ้นมาคนละตัว แล้วมาแต่งเนื้อเรื่องร่วมๆกัน โดยประชุมและวางแผนพล็อตเรื่องในกลุ่มผู้แต่งหลังจากนั่นก็แต่งๆ
กันไป ส่วนฟิกแนวแฟนตาซีอาจจะสร้างเรื่องขึ้นมาว่าเช่นจอมมารต้องการจะยึดครองโลก ก็ให้ผู้เข้าร่วมแต่งตัวละครของตัวเองขึ้นมาแล้วเข้าร่วมในพล็อตเรื่อง เช่นนายAอาจจะแต่งเป็น
ผู้กล้าไปฆ่าจอมมาร แต่นายBกับแต่งเป็นสมุนของจอมมารแทน ซึ่งการแต่งต่อกันเรื่อยๆ ตัวละครของแต่ละคนจะเข้ามาเชื่อมหากันและมาพับปะกันเช่นอาจมาเป็นพวก หรือเป็นศัตรูเป็นต้น ส่วนแนวชีวิตโรงเรียนอาจสมมุติโรงเรียนสอนพลังขึ้นมาแล้วให้ผู้เข้าร่วมแต่ง เป็นนักเรียนหรือบรรดาอาจารย์ในโรงเรียนเป็นต้น

พอจะเข้าใจขึ้นมา บ้างแล้วรึยังครับส่วนคำถามที่ว่าใครจะเป็นกำหนดควบคุมเรื่องนี่ผมยังไม่ได้ ตัดสินใจ อาจใช้หลักเสียงข้างมากโดยระดมความคิดของคนแต่งทุกคน หรืออาจจะกกำหนดให้คนคนนึงกำหนดไปทั้งหมดเลยก็ได้ แต่ไม่มีส่วนร่วมในการแต่ง(อาจจะมาแต่งบางครั้งเพื่อควบคุมไม่ให้ออกนอก พล็อต)
