Flare String

ตอนนี้อัพได้แค่ Lv2 - - พอยท์หมด


สกิลนี้ น่าจะต้องเล่นสายผสมนะค่ะ Str Mag เวลาใช้แล้วมันจะเปนการโจมตี 2 ครั้ง

ครั้งแรกจะแทงด้วยหอก คิดAttack และต่อด้วย เวท Dark Flare คิด Mattack มีโอกาสติด Flare ด้วย(คล้ายพิษ แต่ไม่ลด Def กับ Attack)


จากการที่ผมดูท่าflare string น่าจะเหมาะกับพวกสาย strมากกว่านะครับ(แรงกว่าท่าdivine spearอีกถ้าแทงคน)

เพราะถ้าหากแทงทีแรกไม่โดนจะไม่เกิดดาเมจจาก matk ในฮิตที่สองใช่มั้ยครับ

ถ้าเป็นสาย str จะคาดหวังดาเมจจากฮิตแรก ส่วนฮิตสองนั้นเหมือนแถมมาให้ลุ้นติด flareเฉยๆ

ถ้าเป็นสาย mag ก็คาดหวังดาเมจจากฮิตสอง ฮิตแรกเอาแค่ตีให้โดนซึ่งคงยากเพราะว่าสาย mag คงไม่มีใครอัพ dexกันมั้ง - -"(แต่ถ้าอัพผลก็คงเหมือนสายstrครับ)

ส่วนสาย str mag อาจจะอยากได้ดาเมจจากทั้งสองฮิต แต่ว่า การที่จะต้องเจียดแสตตไปอัพทั้ง str dex mag vit อาจจะทำให้เป็นเป็ด

ก็คือ นอกจากจะมีโอกาสตีวืดแล้ว(เนื่องจากอัพdexได้น้อยเพราะต้องเอาไปลง magกะstr)

ดาเมจที่ได้ยังเบาหวิวอีกตะหาก(เนื่องจากลงstrกับmagได้ไม่เต็มที่)

คนอื่นมีความเห็นยังไงก็บอกกันได้นะครับ ผมอยากฟังความเห็นจากหลายๆคนอ่ะครับ(กะลังตัดสินใจเลือกระหว่างflare stringกับdarkness of night)
