Agi 1 = L.avoid 1

Int 1 = L.avoid 2
แต่พออัพถึง 3 จะได้แค่ 1 สรุปว่า อัพ Agi 1 ก็จะได้แค่ L.avoid เพิ่มมา 1

แต่อัพ Int ครบทุกๆ 3 จะได้ L.avoid 5 ( 2+2+1 )

สาย agi ล้วน ค่า L.avoid จะอยู่ราวๆ 180-200 ครับ อัพ int ไปแค่ 40-50 ก็ยิงสาย Agi โดน

ยกเว้นเค้าอัพ int มาเพิ่ม

ปล. อัพแต่ int ไม่มี agi เลย ก็ได้ค่าหลบหลีกระยะไกลไม่พอหรอก ยังไงก็ต้องอัพ
ปล2. ไม่รู้ว่าค่า int มีโบนัสการหลบหลีกด้วยรึเปล่านะ ไม่เคยสังเกตเหมือนกัน OTL
