(นอกเรื่อง)ถึงเรื่องMSNช่วยตอบที

โพสต์แล้ว: อังคาร 24 มี.ค. 2009 12:15 am
โดย ECO
ก็คือผมเล่นสายสเปลยูสแล้วก็ไม่มีที่จะถามก็เลยอยากจะถามเพื่อนที่เล่นอิโค่ด้วยกัน


ก้อคือตอนนี้เล่นMSNแล้วโลภอยากได้เวอชั่นไหม่จึงไปโหลดมาแต่พอโหลดเสร็จปรากฏ


ว่าลงไม่ได้ก็ไม่ได้อะไรมากมาย กะเลยนั่งเล่นอิโค่ต่อแต่ไม่ได้ออนMนะพอตกกลางคืน


กะจะนั่งเล่นMก็เลยเข้าเอ็มปรากฏว่าขึ้น ไห้เรากดYES/NOท่ากดYESมันจะโหลดอะไรไม่รู


ท่าแปลแบบตรงๆตัวจะแปลได้ว่า โหลดMSNเวอร์ชั่นไหม่ที่ใหญ่มาก พอโหลดเสร็จมันก็เอา


เราไปที่เว็บตรงที่โหลดMSNผมก็โหลดมาแล้วพอลงขึ้นแบบนี้


ไม่สามารถติดตั้งโปรแกรม


ใช้ WINDOWS UPDATE เพื่อดาวน์โหลดเวอร์ชั่นล่าสุดของ WINDOWS INSTALLER


แล้วลองอีกครั้ง

แล้วผมก็ลองกดที่แสดงรายละเอียด

มันขึ้นว่า

ข้อผิดพลาด : MSI_SHECK:0X80280002
ขั้นตอนต่อไป : WINDOWS INSTALLER ชองคุณเป็นเวอร์ชั่นที่ล้าสมัย


ต้องทำยังไงเครียดมากไม่ได้ออนเอ็ม
