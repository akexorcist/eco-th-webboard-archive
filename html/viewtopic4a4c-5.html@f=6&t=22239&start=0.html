หน้ากากเสือได้จากการเอาแหวนชั้น 5F ( เควส ที่หอคอย 40 ชั้น ) ไปแลก กะลุงในอัพทาว์ครับ ( ลุงแก่ๆยืนอยู่ที่ตะวันออก )

ส่วนแหวนชั้น อื่นๆ จะไปหน้ากากดังนี้ ครับ

- ชั้น 5F จะได้หน้ากากเสือ ( Tiger Mask )
- ชั้น 10F จะได้หน้ากากหมาป่า ( Fox Mask )
- ชั้น 15F จะได้หน้ากากโครงกระดูก ( Skeleton Mask )
- ชั้น 20F จะได้หน้ากากอัศวิน
- ชั้น 25F จะได้หน้ากากหมีเพนด้า ( Panda Mask )
- ชั้น 30F จะได้หน้ากากมังกร ( Dragon Mask )
- ชั้น 40F จะได้หน้ากากดำน้ำ ( Snockle )

แหวนที่เอาไปแลก จะเป็นแบบสุ่มไอเท็ม แล้วแต่ดวงนะครับว่าจะได้ไอเท็มอะไร ทุกทั้งมีทั้งขยะ และ ของแรร์ แต่ ขยะก็มีเยอะ เช่น Bone ( กระดูก ) หรือ Seriko เป็นต้น

ปล.นอกจากจะมีหน้ากากแล้ว ยังมีของแรร์อีกมากมาย เช่น ชุดนักเรียนหญิง , ชุดนักเรียนชาย , หูกระต่าย ( Rebbit Ear ) , มาริโอเน็ต P-Bot ฯลฯ

ปล.2 ขอให้ทุกท่านโชคนะดีคร๊าบบบบ ได้แต่ของแรร์กานทุกคน สาธุ~~~~
