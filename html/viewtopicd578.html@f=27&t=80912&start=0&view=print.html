ฟังดูแล้ว คงเป็นให้ตัวละครตัวหนึ่งในไอดีเราสิงไว้ อีกตัวเก็บไปใส่แล้วใช้เวล
โดยคนที่สิงไว้จะได้ EXP 10% ของคนที่เอาไปใส่ และคนที่ใส่ไอเท็มที่สิงนั้นๆ ยังได้ EXP 100% อยู่

แต่จริงๆแล้ว ถ้าเราสิงตัวหนึ่งไว้บนพื้น แล้วล็อกอินอีกตัวในไอดีเดียวกันมาแทน
ตัวที่สิงไว้จะหายไปทันทีที่ล็อกอินครับ
หรือก็คือเราไม่สามารถสิงของให้อีกตัวในไอดีเดียวกันได้ครับ

ที่ จขกท ฟังมาน่าจะเป็นว่า ไอดีนึงเก็บของที่สิงไว้อีกไอดีนึงแล้วไปเวล ไอดีที่สิงของไว้จะได้ EXP 10% ครับผม
