[ECO-Jp] ประกาศอัพเดทระบบป้องกัน ID

โพสต์แล้ว: อังคาร 03 ก.ย. 2013 5:25 pm
โดย NETIX
เนื่องจากทาง GungHo ได้อัพเกรตระบบรักษาความปลอดภัยให้กับ ID ของผู้เล่นทุกคน
เพื่อป้องกันตัวละครที่น่ารักและทรัพย์สินในตัวละครของทุกท่านให้ปลอดภัยจากการ Hacking มากขึ้น

จึงให้ผู้ที่มี ID ของ GungHo ทุกท่านต้องเข้าไปยืนยันเบอร์โทรศัพท์(ญี่ปุ่น) ภายในวันที่ 17 ธันวาคม 2013
หากไม่ทำการยืนยันหลังจากวันที่ 17 ธันวาคม 2013 จะไม่สามารถเข้าใช้บริการใดๆของ GungHo ได้เลย

หากใช้ OTP(One Time Password) จะไม่ต้องทำการยืนยันเบอร์โทรอีก
และการเปลี่ยนข้อมูลอื่นๆใน ID หรือทำธุรการใดๆหลังจากการทำการยืนยันเบอร์โทรไปแล้ว
จะต้องใช้รหัส OTP ในการยืนยันทุกอย่าง
เช่นเปลี่ยน password , เติมเงิน หรือการยืนยันรหัส ID Lock เป็นต้น

หมายเหตุ OTP (One Time Password) คือรหัสผ่านที่ใช้ได้เพียงครั้งเดียว
โดยสามารถรับรหัสนี้ได้จากทางโทรศัพท์มือถือหรืออุปกรณ์ที่สามารถรับ OTP ได้เท่านั้น

ดูข้อมูลเพิ่มเติมได้ที่
