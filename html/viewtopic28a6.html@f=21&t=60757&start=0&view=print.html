The Memory

"อ้ากกกก"เสียงของชายหนุ่มอันเจ็บป่วยได้ดังขึ้น
"นาย นาย นายนี้เป็นอะไรรึเปล่า"เสียงของเด้กหญิงซึ้งตกใจกับเสียงของชายหนุ่ม
และชายหนุ่มนั้นก็ลุกขึ้นมา
"เหวอ ทะ เธอ เธอเป็นใครกัน...ละ แล้วฉันเป็นใครละ"เด็กหนุ่มถามใส่หญิงสาวผมสีน้ำเงินผู้ซึ่งนั่งอยู่ข้างๆกับชายหนุ่ม
"เอ๋ เธอความทรงจำหายไปอย่างงั้นเหรอ"
"ใช่แล้วที่นี้ละทะที่นี้ ที่ไหนกันละ....อุ่ก"ชายหนุ่มที่ลุกโผลงออกมาจากเตียงเจ็บกับแผลที่ตาข้างขวาของตน
"นี้เธอ อย่าพึ่งลุกมาสิเธอยังเจ็บอยู่นะ"เด็กสาวเข้าไปพยุ่งตัวเด็กหนุ่มขึ้นมา
"ละ แล้วเธอคือใครละ"เด็กหนุ่มถามเด็กสาวผู้อยู่ตรงหน้าอีกครา
"ฉันเหรอ ฉันชื่อว่าริน เทลย่า ส่วนที่นี้เป็นบ้านของฉันจ๊ะ ที่นี้นะน้า ไม่ค่อยมีคนหรอกเพราะว่ามันอยู่ไกลจากหมู่บ้านทีเดียวละ"เด็กสาวมีนาวว่าริน ได้พูโตอบกับคำถามที่เด็กหนุ่มถามมาก่อนหน้านี้
"แล้วชื่อฉันละ"เด็กหนุ่มถามรินไป
"อืม ถ้าเธอไม่รู้ชื่อละก็มาอยู่กับฉันก่อนก็ได้นะ"รินได้พูดชักชวนเด็ฏหนุ่มให้อยู่กับตน
"เพราะว่าเธอคงไม่มีที่ไปใช่ไหมละ"
"อะ อืม"เด็กหนุ่มตอบตกลง
"งั้นชื่อของเธอก็เอาเป็น อืม"รินทำท่าคิดหนัก
"ฉันชื่อรินงั้นเอาเป็น เร็นละกัน เร็น เทลย่า"
"ระ เร็น เทลย่า"
"ใช่แล้วละจากนี้นั้นเป็นชื่อของนายจนกว่าจะจำชื่อของนายได้ละกันนะเร็น"รินเข้าไปลูบหัวของเร็น

The first memory:THE EYE

ช้าวันรุ่งขึ้น

“นี้เร็น นี้เร็น” เสียงของเด็กสาวผมสีน้ำเงินที่กำลังพยายามปลุกเด็กหนุ่มผมสีฟ้าอ่อนๆ ที่นอนหลับอยู่บนเตียงอย่างสงบสุข และก็ค่อยๆลืมตาตื่นขึ้นมาที่ละเล็กที่ละน้อย “อะ อืม มีอะไรเหรอริน” เสียงของเด็กหนุ่มผมฟ้าถามเด็กสาวที่ทำหน้าตาไม่ค่อยสบอารมณ์ “ก็เธอ นะสิฉันปลุกเธอมาตั้งสิบกว่านาทีแล้วนะ นอนหลับเป็นตายเลยนะเธอนะ” และเด็กสาวก็ลุกขึ้นหลังจากที่ปลุกเร็นได้แล้ว “จะ ไปเหรอริน”เสียงอันงัวเงียของเด็กหนุ่มผมสีฟ้าถามขึ้นมา “อ้อ จะเข้าเมืองนะ นานๆทีก็ต้องแวะไปตลาดซื้อของมาทำอาหารมั้งสิ แล้วจะไปด้วยกันไหมละ”รินก็ได้เอ่ยถามออกไปพร้อมกับคว้าตะกล้าที่วางไว้อยู่บนโต๊ะ “อืม ไปซิ”เด็กชายตอบด้วยท่าทางร่าเริง”พร้อมกับรีบเข้าไปอาบน้ำในห้องน้ำทันที “เฮ้อ เมื่อกี้ยังงัวเงียอยู่เลยแท้ๆ”รินพูดพร้อมถอนหายใจ

เวลา 7:30 น

ณ ใจกลางเมืองของเมืองแห่งหนึ่งในตลาดซึ่งอยู่หน้าเมือง ในตลาดแห่งนั้นมีผู้คนเดินอยู่มากมายพร้อม กับมีร้านค้าต่างๆซึ่งขายของต่างๆมากมาย อาทิ ผัก ผลไม้ เนื้อ หมู เนื้อไก่ ข้าว ของจิปาทะ ฯลฯ พร้อมกับผู้คนส่งเสียงมากมาย และเหล่าแม่ค้า พ่อค้า ที่ ส่งเสียงเรียกเหล่านักเดินทาง ที่เดินผ่านไปผ่านมา
“นะ นี้ริน คนพวกนี้เข้ามาทำอะไรกันเหรอ”เร็นเดินเกาะแขนของรินก็ได้กล่าวถามขึ้น(เจ้าเร็นตัวมันไม่ค่อยจะสูงสักเท่าไหร่นัก)
“อ้อ เข้าก็ขายของกันยังไงละ แล้วคนที่เดินไปเดินมาเนี้ยเข้าก็มาเที่ยวกันยังไงละ”รินตอบคำถามที่เร็นถามตนมา
“งะ งั้นเหรอครับ”เร็นก็เงียบไปสักพักแล้วเห็นลังผลไม้ขนาดใหญ่ตั้งอยู่
“นี้ ริน ของที่อยู่ในลังนั้นคืออะไรอย่างงั้นเหรอ”รินพูดพร้อมชี้ไปที่ลังขนผลไม้
“อ้อ นั่นก็แอปเปิลไงละ อย่างได้เหรอ” แล้วเร็นก็พยักหน้า
“นี้คุณลุง ขอแอปเปิลหนึ่งลูกจ้ะ”รินตรงเข้าไปพร้อมเข้าไปซื้อแอเปิล
“อ้าวรินจัง นี้แอปเปิลหนึ่งลูกราคา 5 gold ลดให้พิเศษกับรินจังเลยนะ”
“ขอบคุณจ้า คุณลุง”รินพูดขอบคุณพร้อมจ่ายเงินให้คุณลุงทันที
“ทะ ทำไมเข้าใจดีจังละครับ”เร็นพูดถามเพราะสงสัย
“อ้อ ฉันเป็นลูกค้าประจำแถวนี้เลยนะ คุณลุง คุณป้า เข้าจำหน้าฉันได้หมดแหละ”
“งั้นเหรอครับ” เร็นก็เดินเกาะแขนของรินไป และก็ไปหยุดที่หน้าร้านขายผักซึ่งอยู่ติดติดกับร้านขายเนื้อ ต่างนาๆ
“คุณป้าค่ะ หนูขอผักกับเนื้อแบบเดิมนะค่ะ”รินพูดกับป้าที่ขายผักกับเนื้อรวมๆกัน
“นี้จ้า รินจัง ทั้งหมดก็ 325 gold จ๊ะ”ตุณป้ายืนของให้รินส่วนรินก็ยืนเงินให้กับแม่ค้าเช่นกัน
“หือแล้วเด็กเนี้ยใครเหรอ”แม่ค้าถามรินที่โดยที่เร็นก็หลบไปด้านหลังของริน
“อ้อ เด็กคนเนี้ยนะเหรอ ก็คือ....”โครม!
“คุณป้า ของแค่เนี้ยให้กันฟรีๆไม่ได้รึไงกัน”เสียงของอันธพาล ส่งเสียงดังไม่พอใจกับผลไม้ที่ตนถืออยู่
“นี้ของซื้อของขายนะหนู”
“อะไรกันป้าของแค่เนี้ยหยวนๆหน่อยก้แล้วกัน”
“เดี๋ยวสินาย คุณป้าเข้าไปพอใจก็คืนของไปสิ” รินส่งเสียงอย่างไม่พอใจสุดๆ
“อะไรกันนังหนู”เหล่าคนพวกนั้นก็พูดต่อเถียงกัน
“พะ พี่ รินฮะคนพวกนี้เป็นใครกันครับ”เร็นที่แอบอยุ่ด้านหลังพูดขึ้นมา
“อะไรกันเจ้าหนูเนี้ย” ชายร่างสูง2คนเดินไปอยู่ด้านหลังพร้อมกับคว้าคอเสื้อของเร็นขึ้นมา
“อะ อะ พี่รินชะ ช่วยด้วย”
“พวกนายจะทำอะไรเร็นนะ” โดยที่เร็นโดนขว้างไปที่เสาแต่ว่ารินกระโดดเอาตัวไปขว้างไว้ดังนั้นรินจึงโดนกระแทกเข้าไปเต็มๆ
“พะ พี่ รินเป็นอะไรไหม”
“มะไม่เป็นอะไร หรอก นะ....”มือของรินที่ลูบหัวของเร็นก็ได้ไปทำให้ผ้าปิดตาของเร็นหลุดออก

ซึ่งดวงตาดวงนั้น มีสีเขียวมรกต ซึ่งทุกทุก สิ่งนั้นเหมือนหยุดนิ่ง
