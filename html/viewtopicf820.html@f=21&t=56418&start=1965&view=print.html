เล่าเรื่องผีสักเรื่องละกัน......

เรื่องมีอยู่ว่า.....

เมื่อปีก่อน....ซึกิได้กลับไปเยี่ยมบ้านญาติ...

แล้วพอตกกลางคืน...ตัวซึกิเองก็ได้ไปนอนคนเดียวในห้องที่ญาติเตรียมไว้ให้ก่อนหน้านี้เรียบร้อยแล้ว..

ตอนแรกก้อคิดว่ามันไม่น่าจะมีอะไร...แต่เวลานอนนี่สิ...

มองบนเพดานมันเป็นรอยด่างดำๆติดอยู่บนฝ้าเพดาน..ซึ่งทะลึ่งอยู่ตรงกับจุดที่ชั้นนอนอีก..

ตอนนั้นรู้สึกไม่ค่อยจะดีเท่าไหร่เลยบอกให้ญาติมาช่วยทำอะไรกับรอยด่างดำนั่นหน่อย..

แล้วญาติของซึกิเนี่ยก็เอาแผ่นวอลเปเปอร์มาปิดทับรอยด่างบนฝ้าเพดานนั่นไว้..

ซึ่งก็ทำให้ซึกิค่อยโล่งใจขึ้นมาหน่อย......

พอฝันถึงโคทาโร่ไปได้ซักพัก(ยังมีฝันหากันอีก = =''). ก็ต้องสะดุ้งตื่นขึ้นมากลางคัน..

เพราะไอ้แผ่นวอลเปเปอร์ที่เอาไปติดเมื่อกี้มันหลุดตกลงมาใส่หน้าพอดี..

ด้วยความง่วง+อยากฝันต่อจึงไม่ได้สนใจก็หลับต่อ..

แล้วอีกสักพักมั้ง... ก็รุ้สึกแปลกๆ..เหมือนมีอะไรมาสัมผัสหน้าไปๆมาๆ..

พอลืมตาขึ้นมา...ก็ได้เห็น...

ผู้หญิงคนหนึ่งยืนห้องหัวลงมาจากรอยด่างดำด้านบนเพดาน...เส้นผมของผู้หญิงคนนั้นปัดไปตามหน้าตาของเค้า....โชคดีด้วยความมืดจึงมองเห็นส่วนที่เป็นหน้าไม่ค่อยจะชัดนัก.


ตอนนั้นซึกิกลัวมาก....ถึงกลับกรี๊ดดดไปงอแงนอนด้วยกับญาติเลยแหละ

แต่ดูว่า...ญาติบอกว่าตัวซึกิคงฝันไปเองน่ะแหละ..(ฝันบ้าไรยะ!!! กะลังฝันว่าโคจังกะลังชวนไปเที่ยวพอดี!!! ชริ!!!)

หลังจากวันที่ไปเยี่ยมญาตินั้น.....เมื่อได้ไปอีกที..ซึกิไม่กล้านอนห้องนั้นอีกแล้วค่า...



จบเหอะ....
