วิธีทำ มาริโอเน็ท Nymph
(ขออภัย ไม่มีรูปตอนทำจริงๆ เพราะไม่มีของ + ขี้เกียจไปทำใหม่ด้วย)

อุปกรณ์ที่ต้องมี

1. jade (สีเขียว) ทำได้จาก
- รับฟรีจากน้องหมาหน้าดันฟาร์อีสเมื่อมีเลเวล 45 ขึ้นไป (1 ครั้งต่อ 1 ไอดี)
- ผสมเองจาก GreenCrytal3+Cutoutmachine ในหมวดเครื่องประดับ
- ตีตกจาก bansi (momo plane) หรือ fury (barn or fushigi) => ต้องมี knowledge
ปล. ถ้าคุณมีสีฟ้า แปลว่าคุณหามาผิดรึโดนหลอกแล้วล่ะ เพราะนั่นมันเครื่องประดับ

2. miracle crisalid
=> หาได้จากหนอน crawler, Big Crawler, Sand Crawler, Caterpillar (ต้องมี insect knowledge)
=> หรือ ตีตกจาก soul tree ในดันฟาร์อีสต์ (ไม่ต้องใช้ knowledge แต่ตกยาก + ต้นไม้น้อย + มอนออโต้เพียบ)

เอาล่ะ ถ้ามีครบแล้วก็มาทำกันเลย
1. ไปดันฟาร์อีสต์เลย เข้าไปที่ทางเข้าหมายเลข 2 (สีฟ้า)



2. สภาพในดัน จากนั้นไปที่แม็พต่อไปทางหมายเลข 2



3. จะมาเจอแม็พนี้ ให้เดินไปที่หมายเลข 2 เดินตรงไปเรื่อยๆจนสุดทาง ถ้ามี jade แล้วคุณจะตกหลุมลงไป (ถ้ายังหาไม่เจอก็เดินไปจนสุดแล้วกดรอบๆแถวนั้นดู)



4. คุณจะโผล่มาที่หมายเลข 3 ของแม็พนี้



5. จากนั้นให้เข้าวาร์ปไป โดยวาร์ปจะทำปฏิกิริยากับ jade

6. แล้วคุณก็จะโผล่มาที่หมายเลข 4 ของแม็พนี้ โดยจะมี NPC Nymph อยู่ตรงกลาง



7. ถ้าคุณมี miracle crisalid มาด้วย ให้คุยกับ NPC แล้วคุณก็จะได้ มาริโอเน็ท Nymph มาแล้ว

หลังจากนั้น ตัวใครตัวมันเน่อ หนีหมูหนีกบหนีคางคกทั้งหลายให้ทันละกัน ขอให้ออกจากดันโดยสวัสดิภาพ
