เรื่องราวหลังคำสาปปาร์ตี้ อย่างน้อยก็ไม่ได้เลวร้ายอย่างที่คิด



หลังจากโดนคำสาป เรนเจอร์ จึงได้ออกเดินทางเพียงคนเดียว ซดไก่แลกกะหมูโดยมีแมวผีคอยเชียร์( เพื่อ? )..... oO(สงสัยได้คำสาปปาร์ตี้ จะมาพร้อมคำสาปของหล่อนนี่แหล่ะ)


แต่ดูเหมือนว่าสวรรค์ยังมีตา ฟ้ายังเข้าข้าง เรนเจอร์ยังพอมีโชคดีเหลืออยู่บ้าง ...



เมื่อรู้สึกเช่นนั้น เรนเจอร์ จึงตัดสินใจเดินทางสู่นอร์ทโพลเพื่อเดิมพันด้วยโชคที่มีอยู่ ( ด้วยชุดที่มีอยู่ ไม่หนาวตายก็บุญแล้ว~ )


และแล้ว ...ถึงแม้ว่าจะต้องโดดเดี่ยวจากคำสาปปาร์ตี้ แต่ เรนเจอรื ก็ได้พบกับคู่หูคน( ตัว )ใหม่~ ไปเลยทรอมเบ้!!

บินไปเลยทรอมเบ้!! .........บินสิยะ!! แน่จริงบินเซ่!!!!
