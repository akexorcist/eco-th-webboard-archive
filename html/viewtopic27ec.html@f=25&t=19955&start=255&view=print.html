วิธีการฮีลหนอนแบบเจ้าของปลอดภัย

1. ต้องฆ่าตัวที่มัน auto attack แถวๆนั้นทิ้งให้หมด


2. ให้หนอนเราตีจนหนำใจ(เกือบตายน่ะแหละ)


3. เรียกเก็บหนอน(ถอดการติดตั้ง) และ เรียกออกมาใหม่(ติดตั้งใหม่) และฮีล


4. ส่งมันไปเข้าดงตรีนใหม่



คำเตือน
- หนอนควรมี HP + ข้างหลังมากกว่า 100 ขึ้นไป หรือไม่ก็มี def+ ข้างหลังมากกว่า 10 ขึ้นไป ไม่งั้นได้เรียกเข้าเรียกออกทุกๆ 3 วินาที(เคยเปนมาแล้ว)
- เจ้าของควรจะสามารถฆ่าตัวที่ auto ได้ในการโจมตีครั้งเดียว (ไม่งั้น กว่าเราจะฆ่ามันตาย เราก็ลากตัวอื่นมาหมดพอดี)

หาแมพที่มีทางตรงยาวๆที่ไม่มีอะไรขวาง

วิธีวัดก็

1. set option เวลาปรับกล้องให้ปรับไปทิศเหนือ
2. กด /where จะได้ตำแหน่งเริ่มต้นเปนพิกัด (x,y)
3. กดปุ่มซ้ายยาว ไม่ก็ขวายาว (ตามทิศที่จะวิ่งอ่าแหละ) เปนเวลา 25 วินาที
4. กด /where จะได้ตำแหน่ง (x,y) อีกอันนึง
5. เอา |x2-x1| = เท่าไร แล้วเอามาคูณ 4 จะได้ความเร็วต่อเวลา 100 วินาที
