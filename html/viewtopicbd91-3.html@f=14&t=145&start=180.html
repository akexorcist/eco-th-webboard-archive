นั่งอ่านบอร์ดเกมส์นี้มานานสนใจอยากเล่นมากก ><"

ที่ถูกใจมีอยู่ 3 อาชีพแหน่ะ 1.เบลดมาสเตอร์ 2.ไนท์ 3.ดาร์ก

อยากถามหน่อยๆอะครับชอบแนวเล่นบู๊เดี่ยวๆไม่ค่อยหาตี้แต่อยากเล่นดาร์กสายโจมตีดู

จะดีไหมหรือไนท์ดีกว่า และเท่าที่ดูสกิลไนท์และดาร์กถืออาวุธอื่นนอกจากหอกจะดีไหมครับ

พอดีชอบอาวุธพวกดาบมาก - -

ขอรายละเอียดเปรียบเทียบอาชีพ ไนท์ กับ ดาร์ค หากเล่นสาย str-vit str-agi และเผ่าทีนะครับ

ขอเปรียบเทียบหากใช้อาวุธประเภทดาบนอกจากหอกด้วยก็จะดีมากครับ

1.แล้ว skill ของ ทั้งสองอาชีพนี้ มันใช้ mp หรือ sp เป็นหลักละครับ เห็นมีทั้ง เวทมนต์(ฮิล,ลำแสงความมืด) แล้วก็พวก skill โจมตี (สกิลหอกนะครับ)
แล้วสังเกตุว่า ค่า INT,MAG Bonus point ทั้งคู่ให้เยอะมากเมื่อเทียบกับอาชีพอื่น

2.งั้นเล่นสาย vit + int+mag ไปเลย แล้วยิงเวทรั่วๆ หรือ +str อีกนิด แล้ว ยิงเวทกับ สกิลโจมตีอย่างเดียว จะได้รึปล่าวครับ (สรุป คือไม่เน้นโจมตีธรรมดานะครับใช้สกิลอย่างเดียว)

ขอบคุณครับ
ปล.ผมค้นกระทู้แล้วนะครับ เห็นไม่มี สาย Vit int mag เลยถามขึ้นมา
