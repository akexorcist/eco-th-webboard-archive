เวลาผมจะหาเองผมมักจะไปแถวๆ bed rock น่ะคับ (หรือแมปที่ผ่านด่านเมืองใต้เข้ามา)
ตีหินสีเหลืองโอกาสได้ประมาณ 50%(ใช้ตัวอื่นที่ไม่ใช่ทาทา = ไม่มีปราชญ์หิน)
ส่วนถ้าเอาทาทามาตีจะเยอะหรือน้อยกว่านี้ไม่เคยลอง เพราะรำคาญมอนรุมเยอะ
ทาทาของผมไม่มีสกิลหมู่เลยไม่ได้เอามาใช้งานนี้
อีกที่นึงที่น่าจะได้พอๆกันก็หินเหลืองที่ warship island น่ะคับ
หลักๆที่ผมหาก็จะสองที่ๆว่ามานี้

ป.ล.เควสทาทาที่ส่งหินเงินนี่ผมไม่ทำเลยนะ รู้สึกว่าไม่คุ้ม
ถ้ามีเควสอื่นเลเวลต่ำหน่อยก็ทำอันนั้นไปจนกว่าจะมีเควสใหม่มาดีกว่ามั้งคับ...

----------------------------------------------------------

ขอถามมั่ง ขอเป็นชุดคำถามเลยละกัน เกี่ยวกะคำสาป

1. เห็นว่าคำสาปแต่ละอันมันมี % สูงสุดเป็นเพดานอยู่ แบบที่ว่า
ใส่ Int มากแค่ไหนมันก็ไม่ติดง่ายไปกว่านั้นแล้ว
อยากทราบว่าค่า Int ที่ว่านั้นควรจะซักเท่าไหร่คับถึงจะพอใช้ออกงานได้ไม่น่าเกลียด

2. ค่า mag.hit มีความสัมพันธ์กับ % การสาปติด/ป้องกันสาปยังไง กี่แต้มถึงจะได้เพิ่มซักกี่ %

3. บัฟของพระหรือสกิล passive อื่นๆที่ช่วยในเรื่องการสาปนี่
จะช่วยให้ % ทะลุเพดานตามข้อ 1 ได้ไหมคับ

4. สกิล resist ต่างๆของพระ ที่ max level จะช่วยลด % ติดคำสาปกี่ % คับ
