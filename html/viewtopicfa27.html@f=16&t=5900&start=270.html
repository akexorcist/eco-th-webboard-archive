koh เขียน:แล้วสาย ร็อดแฮมเมอร์ เนี่ย เค้า อัพ สเตตัสยังไงหรอ


เอ่อ..... ช่วยอ่านให้เป็นซักอย่างเถอะ
ไรออท หรือ รีออทก็ได้ ไม่ช่ ร็อด
ร็อด มันสะกดได้แค่ Rod, Rot เองนะ T T

หลังจากบ่นเรื่องภาษาไปแล้วก็ว่าด้วย status
มี 4 ค่าให้เลิือก
agi - vit - mag - int

agi -> เพิ่ม a.spd ร่ายเร็วขึ้น(soul ไม่เพิ่มค่านี้, rouse body agi+15, speed enchant a.spd+20%)
vit -> เพิ่ม hp พลังโจมตี(riot)สูงขึ้น(soul เพิ่ม, rouse body vit+10, ....... )
mag -> เพิ่ม m.atk เพื่อใช้กับ random healing / roulette healing (สายเก็บเลเวล)
int -> เพิ่ม l.avoid เพื่อ NvN, PvP โดยเฉพาะ

โดยจะกดแค่ 2 ค่าแรกก็ได้
