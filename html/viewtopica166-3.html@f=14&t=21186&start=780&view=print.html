ค่า Agi ที่แนะนำคือ ราวๆ 63 หรือ 72 เพราะจะร่ายสกิลได้เร็วพอสมควร และหลบได้บ้างยามที่มอนไม่ตาย

ซึ่งก็แล้วแต่คนจะเล่นแต่ส่วนมากก็เล่น Str ยิงให้ตายไวที่สุดกันอยู่แล้ว

ส่วนค่า Int นั้นอัพรวมซัก 40-50 ก็ไม่มีปัญหาเรื่องวืดแล้ว เพราะหลบระยะไกล มอน (และคน) ที่พริ้วๆนั้นมีไม่มาก

ส่วนสกิลที่จะสวิทไปนั้น ม๋า เลือกไป 4 สกิล แต่ม๋าเอาไปได้เพียง 3 เพราะจ๊อบ 30

ม๋า ต้องเลือกระหว่าง Hunting กับ Violent แล้วว่าจะเอาด้านไหน เก็บเวล หรือ ฆ่า
