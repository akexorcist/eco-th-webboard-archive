พ่อค้าฝากของ -> จัดการ Jewel Gold

Jewel Gold 1 ก้อน = 1M

สมมุติซื้อขาย 150m ก็ซือมา 150 ก้อน แล้วเทรดไป

ข้อควรระวัง : การซื้อ Jewel Gold ต้องเสียเงิน 1% เป็นภาษี เช่นซื้อ 150m คุณจะเสียเงินภาษีไป 1.5m รวมเป็น 151.5m

หมายเหตุ* การแลก Jewel Gold กลับเป็นเงิน ทำได้ที่พ่อค้าฝากของเช่นกัน
