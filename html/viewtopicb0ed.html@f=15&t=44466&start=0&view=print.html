ถ้าด้านสกิลดรูอิดดีกว่า แต่ถ้าความถึกบาร์ดถึกกว่าค่ะ ถ้าจะเล่นบาร์ดตามนั้นแล้วสวิชไปเลยก็ได้ค่ะหรือจะเล่นให้จ็อบ50เลยเอาสกิลบัฟsuกับกันทุกอย่างไปด้วยก็ดีค่ะ
แต่ถ้าจะเล่นดรูอิด สกิลที่น่าจะเอามาจากบาร์ดก็มี มิวสิคเคิลโบวค่ะ ร่ายไว ดาเมจไม่เบาไป เอามาแก้ขัดโฮลี่ไลท์ได้ สกิลอื่นๆก็ตามแต่ประสงค์ค่ะ แต่สกิลบาร์ดบัฟค่อยข้างยากหน่อยนะ- -
