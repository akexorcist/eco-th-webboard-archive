นิยายเรื่อง : นักเวทย์พเนจร

โพสต์แล้ว: ศุกร์ 11 ก.ค. 2008 11:33 pm
โดย ECO
ผมก็ไม่ค่อยรู้เรื่องการแต่งนิยายมากหรอกนะครับแต่จะพยามให้ถึงที่สุดนะคร้าบ

บทนำ

ณ ที่แห่งหนึ่งซึ่งไกลออกไปจากตัวเมืองอโครโพลิทเป็นอย่างมาก มีกระท่อมแห่งหนึ่งซึ่งอยู่ใกล้กับน้ำตกและมีเด็กชายคนหนึ่งอยู่ในกระท่อมและจ้องมองไปที่กระดาษแผ่นหนึ่ง และมีรูปของพ่อและลูกยืนคู่กัน

"ถ้าอย่ากได้ก็จงไคว่คว้ามา มิฉะนั้นก็จะไม่มีทางสำเร็จ" หลังกระดาษแผ่นนั้นเขียวไว้

"ถ้าอย่ากได้ก็จงไคว่คว้ามา มิฉะนั้นก็จะไม่มีทางสำเร็จ"เด็กคนนั้นเอ่ยออกมา และมีน้ำตาไหลออกมาจาใบหน้าของเข้า "พ่อครับผมจะทำความฟันของพ่อให้สำเร็จครับ"หลังจากเด็กคนนั้นพูดจบเขาก็คว้าเสื้อคลุม เงิน และกระเป๋าซึ่งมีของกินเสื้อผ้าและข้าวของเครื่องใช้ต่างๆ
ปัง พอเสียงประตูปิดก็มีลูกหมาป่าตัวเล็กวิ่งมา"เอะ นายก็อย่ากไปด้วยเหรอ โต๊ะโตะ"เด็กคนนั้นถาม"โฮ่ง"หมาป่าขานรับ "งั้นเราไปกันเลยไปยังอโครโพลิท

รับสมัครตัวละครนะครับ รับไปเรื่อยๆจนกว่าจะจบ

ประวัติ

-----------------------------------------------------------------------------------------------------------

ตัวละคร

ชื่อ : kiss

อายุ : 15

เผ่า : เทวดา

อาวุธประจำตัว : กำไลข้อมือ

อาชีพ : enchanter

รูปร่างหน้าตา : หน้าตาก็แบบอีโค่แหละ ดวงตาสีเขียวเข้ม ผมออกจะยุ่งๆเหมือนพึ่งตื่นนอน

ประวัติ : เข้าเป็นเด็กที่ค่อยข้างจะมีนิสัยมองโลกในแง่ดีสุดๆ และพ่อของเข้าก็หายสาบสูญไปเขาคิดว่ายไปแล้วจึงจะทำความฝันของพ่อเข้าซึ่งต้องการที่จะเป็นนักเวทย์ที่แขร็งแกร่งที่สุด

แต่งเป็นยังไงดีไม่ดีติด้วยนะครับ
