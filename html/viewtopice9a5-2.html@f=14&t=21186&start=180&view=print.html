เทียบกับ Multi Arrow

Blast Arrow ความแรงเต็มที่สุด ๆ ที่เลเวล 5 ก็แค่... 410 %

มัลติแอโร่ลูกล่ะ 120 % ที่เลเวล 5 ยิงได้ 4-5 ลูก ถ้าโดนหมด ความแรงต่ำสุด = 120 * 4 = 480 %

เทียบกับ Dual Arrow

Blast Arrow ใช้เวลาชาร์จ 2 วินาทีไม่มีดีเลย์ = 410 %

Dual Arrow ภายใน 2 วิยิงได้ 2 ครั้ง เพราะไม่มีดีเลย์ และชาร์จ = 250 * 2 = 500 %

สรุป...

ถ้าจะปิดเกมใน 1 Hit ... Multi Arrow เป้นทางเลือกที่ดีที่สุด...

ถ้าต้องการเกบเลเวลแบบเรื่อย ๆ กับศัตรูที่ต้องยิงหลายๆ ครั้ง ... Dual Arrow เป็นทางเลือกที่ดีที่สุดเช่นกาน
