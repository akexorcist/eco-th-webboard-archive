จากการตรวจสอบพบว่ามันเหลือแค่เควสเลเวล 84 เควสอื่นหายหมด

ซึ่งก็ต้องส่ง มาร์ชเมลโลว์ 15 ชิ้น ต่อเควส

แล้วคนที่เวลไม่ถึงละ(แน่ละว่าเราเวลถึง)

กิจกรรมจะหมดสัปดาห์นี้แล้ว ยังไม่เห็นของรางวัลของเควสนี้โผล่ออกมาสักชิ้น

ถ้าอัพมาลวกๆแบบนี้ก็ไม่ต้องขึ้นหน้าเว็บมาโฆษณาว่ามีสิ

แบบนี้เข้าข่ายหลอกลวงผู้บริโภคมิ สงสัยๆ แต่เอาเถอะก็แค่เกม อดพรมไปปีนึงละกัน

ปล.แต่คราวหน้า กรุณาเถอะ อย่าเอาเควสที่ไม่มี(เวล84มีก็เหมือนไม่มี คนที่เวลเท่านั้นแล้วใครจะทำ) มาขึ้นหน้าเว็บ มันเหมือนการหลอกลวงคนเล่น

...บางที GM อาจจะดูแค่กระดานสนทนาแล้วด้วยสินะ แต่ขี้เกียจไปบ่นที่นั่นละ
