-คนหน้าตาดี- เขียน:
รายละเอียดบอส Meiou
บอสตัวนี้นั้นเป็นบอสที่เก่งที่สุดในปัจจุบัน และมีจุดแปลกจากบอสตัวอื่นคือถ้าลูกน้องหมด มันจะเรียกออกมาใหม่ ซึ่งลูกน้องมันก็คือ Magic Wolf 4 ตัว
Meiou จะเกิดใหม่ทุกๆ 60 นาที หลังจากทีึ่ตาย
ของที่ดรอบ
-แบบตามจำนวน Party Member : Copper Medal, Tiny Medal
-แบบชิ้นเดียว : Silver Medal, Tiny Rainbow Medal, Fox Ear, Dominion Hair Catalog

วิธีการอันดับแรกนั้นเราต้องหาไอเท็ม ที่ชื่อ Purple Gem ให้ได้ก่อน

ซึ่งของชิ้นนี้นั้นดรอบจาก Anumus Dominian และ Malicious Dominian ซึ่งมอนสเตอร์เหล่านี้ได้อยู่ที่ปราสาท Undead ที่หน้าห้องเจ้าหญิง และห้องในสุด


หลังจากที่ได้ไอเท็มมาแล้วนั้น ให้เรามาที่โรงแรมในแมป Momo Plain โดยนำ Purple Gem มาด้วย แล้วคุยกับลุงเจ้าของโรงแรมดังภาพ


แล้วเราก็จะถูกวาปมาในจุดที่ใช้เริ่ม EVENT แล้วคุยกับ NPC ข้างใน


หลังจากคุยเสร็จ Purple Gem จะยังไม่หายไป(เพราะเอามาให้ดูอย่างเดียวว่าเรามี ^^)
แล้วจากนั้นให้เข้ามาใน East Dungeon จากทางขวาของเมือง Far East โดยพก Purple Gem มาด้วย

หลังจากที่เราตกหลุมลงมานั้น พอเราเข้าวาปแล้ว Purple Gem จะแตกสลายไป(อันนี้ไม่ทราบว่าหากเราพก Jade มาด้วยมันจะพาเราไปหา Nymph แทนรึเปล่า ทางที่ดีอยากไปทางไหนก็พกของชิ้นนั้นมา)

แล้วเราก็จะได้มาอยู่ในสถานที่ที่บอส Meiou อยู่(แมปแบบเดียวกับที่ Nymph อยู่แหละ แค่คราวนี้เป็นของ Meiou)
