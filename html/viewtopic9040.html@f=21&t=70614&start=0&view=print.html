อืม ... ผมขอว่าตรง ๆ เลยล่ะกัน (ว่าอ้อม ๆ มันคงจะเยอะไป -3-)

ผมไม่ค่อยสนใจหรอกนะครับว่าคุณจะอายุเท่าไหร่ แค่อยากจะบอกว่าการดำเนินเรื่องมันค่อนข้างมั่วไปนิดนึง (ตามความรู้สึกอ่ะนะ ... แต่จะว่าไปของตูเองก็มั่วเหมือนกันนี่ฟร่า ) การเกริ่นเรื่องที่อยู่ ๆ ก็โผล่มาแบบ งง ๆ ... แต่ถ้าจะให้สนใจว่าคุณอายุ 13 ปี ก็ถือว่าดี แต่ยังไม่ดีมากพอสำหรับคนอายุ 13 (จริง ๆ ช่วง 13 นี่ควรจะมีจินตนาการที่สูงส่งอย่างมากแล้วนา ... มากกว่าผู้ใหญ่ด้วยซ้ำ)

เอาเป็นว่าถ้าเป็นผมให้คะแนนตอนที่ 1 ของคุณนะครับ

เนื้อเรื่อง 7/10 - ขอติเรื่องการเริ่มเรื่องก่อนเลย แม้ว่าจะเป็นตัวละครที่เรา ๆ รู้จักกันแต่ก็น่าจะเกริ่นบ้างว่าเขามาเพื่ออะไรและเพราะเหตุใดจึงต้องผจญภัย (แบบว่า งง มาก มาช่าจะออกผจญภัยกับอีมิลก็พอรับได้ แต่ดันไปหับผู้หญิงที่ไม่รู้จักได้หน้าตาเฉย ... แต่จะว่าไปก็ทาบทามกันเรียบร้อยแล้วนี่เนอะ ) เพราะอย่างนั้นก็ขอลบคะแนนส่วนนี้ไปนิดนึงนะครับ

ภาพ 8/10 - ผมไม่ค่อยสนใจเรื่องอายุหรอกนะครับ ผมสนใจการพัฒนามากกว่า อายุน้อย = ยังพัฒนาได้มาก เพราะฉะนั้นใช้ความได้เปรียบนี้ให้ดีนะครับ ที่ขอลบคะแนนส่วนนี้ลงนิดนึงก็เพราะว่าบางฉากมีการจัดตัวละครมั่วไปหน่อย (ของตูก็มั่วเหมือนกัน ) ... ค่อย ๆ ฝึกไปนะครับ บางทีอาจจะได้คะแนนมากขึ้นก็ได้ (ผมไม่ค่อยสนใจลายเส้นหรอกนะครับ สนใจการจัดวางมากกว่า)

เสียง ... ไม่มีนี่หว่า ...

สุดท้ายนี้ก็พยายามเข้านะครับ อาจดูเหมือนผมต่อต้านคุณไปหน่อย แต่ผมพูดเพราะต้องการให้คุณพัฒนา ... ผมจะติดตามดูผลงานนะครับ (พูดยังกับตัวเองเทพมากอย่างนั้นแหละ )

ปล. ว่าง ๆ ไปดูกระทู้ผมบ้างนะครับ อยากให้มีคนติแทบตายดันไม่มีใครติ + ร้างด้วย
