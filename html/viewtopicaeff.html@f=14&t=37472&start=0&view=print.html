แอสซาซิน
การโจมตีที่รวดเร็วหลบซ่อนตัวได้แถมยังมีความสามารถในการโจมตีคริทิคอลที่รุนแรงกว่า
อาชีพอืนๆครับ สกิลมีความรุนแรงสูงครับ เหมาะกับการลอบสังหาร หรือหากจะเล่นเป็นสายปล่อยพิษ ก็เก่งเหมือนกันครับ สามารถวางหมอกพิษที่ทำให้ศัตรูตายได้(วางพิษโหดมาก แต่เก็บเวลได้ไม่เร็ว)

คอมมานโด
มีท่าสังหารศัตรูหลายแบบ อาวุทที่เหมาะสมน่าจะเป็นปืน(หรือจะสนับก็ได้เพราะคอมมานโดอาจโจมตีไม่แรงเท่ากันเนอร์) สกิลส่วนใหญ่มีความรุนแรงสูง เน้นในด้านการก่อก่วนซะมากกว่า ไม่ว่าจะระเบิด ปืน รวมทั่งการโจมตีศัตรูจนทำให้ไม่สามารถ เพิ่มHp ตัวเองได้ครับ

ส่วนเรื่องการฟันเร็ว หรือ ฟันแรงนั่น คุณต้องถามตัวเองแล้วละครับ ว่าชอบแบบไหน แต่ถ้าเป็นผมเก็บเลเวลคนเดียวแล้วไม่มีพระเก็บด้วยประจำ ผมจะชอบฟันแรงมากกว่า แต่ต้องมี Agi ระดับที่พอจะหลบมอนพ้นด้วยอะครับ
ชอบสะใจ ก็เล่นฟันเร็วครับ - -"
ชอบรวดเร็ว ก็ฟันแรงครับ
