ตอนนี้เป็นKnightอยู่..อยากรู้ว่าเมื่อเล่นจนจ๊อบครบ50แล้ว

จำเป็นต้องเปลี่ยนเป็นDarkไม๊อ่าค่ะ.. :?:

แล้วถ้าเปลี่ยนเป็นDarkแล้วเอาสกิลไนท์ไปได้หรือเปล่า :?:

สรุปว่าDarkมานเป็นอาชีพขั้นต่อจากKnightหรือว่าเป็นแค่ทางเลือกกันแน่อ่าค่ะ :?:

แบบ Fencer>Knight>Dark

หรือ Fencerแล้วจะเล่นไรต่อก็แล้วแต่เล่นอีกอาชีพจนจบไปเลยไม่ต้องเปลี่ยนแล้ว

แล้วเล่นสายAgi+Strเนี่ยควรเป็นKnightsรือDarkดีอ่าค่ะ :?:

fencer >>> Knight <<<>>> Dark Stalker
