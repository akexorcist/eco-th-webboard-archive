โดยไม่ต้องเอาปราชญไปมันจะคิดให้ไหม

คำถามเดียวกัน
เอเล เล่น สายพายุน้ำแข็ง ซึ่งต้องอัพ ลมกับน้ำ
แล้วจึงพายุน้ำแข็งจะมีผลแรงมาก
ถ้าเราสวิทเป็นเอนแชน
แล้วเราเอาแต่พายุน้ำแข็งมาไม่เอา ลมกับน้ำมาจะคิดให้ไหม
