อันนี้ ผมและเพื่อนผมช่วยกันแต่งบางอันเพื่อนผมแต่ง

อันแรกสมมุตว่า คุณมีแฟนแอบชอบชื่อมิ้วนะ เราต้องพูดว่า

พี่ชื่อไวตาน้องชื่อมิ้วเราเกิดมาคู่กันไวตามิ้ว มุขนี้เพื่อนผมคิด

ต่อไป เราไปถามคนที่แอบชอบว่า เทอเหนื่อยไหม คนที่แอบชอบจะงงซักนิด

เทอมาวิ่งในหัวใจเราไง (มุขนี้คิดเอง)

ต่อไป สมมุตว่าคนที่แอบชอบอยู่ในกลางแดด เราต้องพูดว่า

เทอร้อนไหม ท่าร้อนมาอยู่ในใจเราจะได้ไม่ร้อน (เพื่อนผมคิดเอง)

ต่อไป

นี่เทอ เทอระวังตกนะ คนที่คุณแอบชอบจะงง ตกไรอ่ะ

ตกหลุมรักไง (คิดเอง)

ต่อไป

เทอนั้นผึ้ง คนที่แอบชอบจะงง ผึ้งอยู่ไหน แล้วเราบอกว่า

ผึ้งรู้ว่ารักเทอไง มุขนี้บางคนบอกว่าผึ้งมันต้องพึ่งจริงๆแล้วมันถูกแล้วครับผึ้งอ่ะ

เดี่ยวมาต่อใหม่ท่าคิดได้ บางมุขนําเน่า
