Fencer Type
สายการเล่นของเฟนเซอร์ แยกตามการใช้อาวุธ กับการอัพสเตตัส
แต่ละสายจะมีข้อดี ข้อเสียแตกต่างกัน สามารถเลือกเล่นได้ตามศรัทธาครับ
และอาวุธที่เราใช้ กับสเตตัสของเรา จะเป็นตัวกำหนดแนวทางการอัพสกิลครับ

Classify type by Weapon
สายการเล่นแยกตามการใช้อาวุธ ควรอัพสกิลที่สนับสนุนอาวุธที่ถือ
สามารถเลือกอัพสกิลให้สนับสนุนการใช้อาวุธหลายๆประเภทได้
คลิกที่นี่!! เพื่อเข้าสู่หน้า แยกสายการเล่นจากการใช้อาวุธ

Skill Discussion

- วิธีการเปลี่ยน Fencer

Base Class - Fencer
คลาสพื้นฐานของสายอาชีพนี้ ประกอบด้วยสกิลติดตัว และสกิลบัพพื้นฐานต่างๆ ที่จำเป็นสำหรับทุกสายการเล่น
คลิกที่นี่!! เพื่อเข้าสู่หน้า รายละเอียดสกิล Fencer

- วิธีการเปลี่ยน Knight

Expert Class - Knight
สำหรับคลาสนี้ จะโดดเด่นด้วยค่า Vit และ HP ที่เยอะกว่าทุกสายอาชีพ และสกิลโจมตีกายภาพหลากหลายให้เลือกใช้
คลิกที่นี่!! เพื่อเข้าสู่หน้า รายละเอียดสกิล Knight

Technical Class - Dark Stalker
สำหรับคลาสนี้ จะโดดเด่นด้วยสกิลธาตุมืดที่หลากหลาย ทั้งสกิลติดตัว โจมตี และสกิลบัพ รวมถึงสกิลที่โจมตีด้วยเวทย์มนต์
คลิกที่นี่!! เพื่อเข้าสู่หน้า รายละเอียดสกิล Dark Stalker

Chronical Class - Guardian
สำหรับคลาสนี้ ยังไม่เข้าไทย
คลิกที่นี่!! เพื่อเข้าสู่หน้า รายละเอียดสกิล Guardian
