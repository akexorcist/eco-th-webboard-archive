สกิลแรงตาม Matk ซึ่งได้จากค่า MAG นะครับ
ส่วน INT มีผลแค่ทางอ้อมคือเพิ่ม MinMAtk ลดความแกว่งของการฟื้นฟู

ถ้าจำไม่ผิด Lv.3 ค่าสูงสุด ฟื้น HP : MAtk*1.6+90

จะฮีลเด้งมากเด้งน้อย ขึ้นอยู่กับ

- VIT
- Increase HP Recovery
- Holy Feather

และค่าอื่นๆ ที่ฟื้น (MP/SP) ก็ได้รับผลจาก MP/SP Recovery เช่นกัน

ปล. คิดแบบสุดๆ MAG 100 ก็ฮีลได้ราวๆ 1,100 แถมมันสุ่มลดเลือดตัวเองอีก
ดังนั้น อัพ MAG พอให้ฟื้น MP/SP ได้พอดีๆ จะดีกว่า

ปล.2 สกิลนี้ชื่อ Random Heal นะครับ ไม่ใช่ Random Help
