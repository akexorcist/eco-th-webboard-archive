ปล.ไม้นี้แรย์ระดับเทพ -*- ต้องมีปราชน์ชาวนาเท่านั้นและตีได้จาก fallen tree เท่านั้นด้วย
(จขกท.ไปซื้อต่อมา ขนาดชั้นเป็นชาวนานะเนี่ย T^T ตีไม่ตกเลย)

จากนั้นให้ไปคุยกับ Rena ที่ Tonka city (ห้องที่มีซาลามานดราอยู่)



Rena จะถามขอให้ทำมาริโอเน็ตพีโน่ให้เอาไหม
โดยเราต้องหาส่วนประกอบดังนี้ นอกจากไม้
1. part of Buriki => ผมีโน่
2. knot => ซื้อได้ที่ร้านดาวทาวน์ตะวันตก
3. nail => ซื้อได้ที่ร้านดาวทาวน์ตะวันตก
4. log => ไปตี fallen tree
5. nut => หุ่นที่หอแสงชั้นสูงๆ
6. Bar => ลองมาแล้ว จริงๆคือ giant Knot ตกจาก non-crystal archen ที่หอแสง
7. fabric => refine จาก cotton
8. thread => ตีตกจากแมงมุม
9. needle => ซื้อได้ที่ฟาร์อีสอันละ 1000









เมื่อได้ของครบก็เอาไปให้ Rena เราก็จะได้ marionet peeno มาครอบครองแล้ว(อีกตัว ^^)









ปล. ไม่คุ้มเล้ย -*- แต่อย่างน้อยก็ทำเควสคนแรกล่ะ หุหุ
