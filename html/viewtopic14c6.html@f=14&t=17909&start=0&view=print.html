วิธีการอัพของสายSwordmanง่ายๆ หวังว่าคงรู้
ควรอัพSTR+DEX+VIT+AGI สำหรับAgiไม่ควรอัพมากเพราะเน้นสำหรับพวกที่ชอบตีเร็วๆ

วิธีการอัพของFencerเหมือนกับSwordเป๊ะๆ

วิธีการอัพของScoutควรเน้นAgiแทนที่จะอัพVitนะครับนอกนั้นก็อัพเหมือนกับพวกSwordmanกับFencerละกันนะครับ

วิธีการอัพArcherควรเน้นIntนะครับเพราะว่ามันโจมไกลได้ถ้าใครชอบสายเลือดแนะนำให้อัพVit

โดย ECO
ขอคอมเม้นท์หน่อยนะคับ
เรื่องวิเคราะห์นี้ จริงๆมันก็ดีนะถ้าจะวิเคราะห์เพื่อเปรียบเทียบความแตกต่างและจุดเด่นด้อยของแต่ละสาย และหลายๆอย่างที่ต่างกันทั้งแนวทางการเล่นในรูปแบบของสกิลหรืออาวุและ stat ต่างๆด้วย
แต่เท่าที่ผมอ่านมา(อ่านเมื่อวาน) ก็เห็นว่าเป็นแค่การวิเคราะห์พื้นๆไม่ได้มีรายละเอียดอะไรน่าสนใจเท่าไหร่คับ อีกอย่างก็คือบางอันก็เหมือนจะพูดแค่ภายนอก และที่สำคัญคือบางอย่างเหมือนไม่รู้จริงน่ะคับ
อย่างผมเล่นนักธนูก็รู้เลยว่า int มันใช้แค่นิดหน่อยก็พอแล้วไม่ต้องเน้นมาก เพราะเกมส์นี้ค่าหลบระยะไกลมันเพิ่มน้อยคับ agi ก็มีแต่โบนัสระยะใกล้ int ก็ไม่มีโบนัสหลบไกล (มีแต +1 +1 มันเลยหลบไกลไม่ค่อยได้ ไม่ต้องอัพเยอะคับ)

หรืออย่างเฟนเซอร์ที่บอกว่าเหมือนนักดาบเป๊ะๆนี้ก็ไม่จริงเท่าไหร่ อยู่ที่แนวทางการเล่นและความเหมาะสมของวิธี+รุปแบบการเล่น+สกิลที่ใช้+ความชอบ มีหลายปัจจัยมากคับ

ส่วนผมอันนี้ขอบายคับ ถ้าจะวิเคราะห์จริงมันเขียนยาวมากๆ ไม่มีเวลาว่างขนาดจะมีเขียนยาวเยื้อยอ่ะนะ (ที่เมื่อวานไม่ได้เขียนตอบเพราะมัวแต่เขียนยาวนี่ละ แต่มันไม่ไหวเลยปล่อยไปก่อน)

ปล.ถ้าบางอันพูดไม่ดีหรือว่าแรงไปก็ขออภัยด้วยนะคับ ปกติผมเม้นท์ก็ตรงๆ

โพสต์แล้ว: พฤหัสฯ. 09 ส.ค. 2007 6:14 pm
โดย ECO
ขอวิเคราะห์แต่นักธนู(ด้วยความเห็นส่วนตัว) ละกัน เพราะเล่นแต่นักธนู(ฮา)
นักธนู
ข้อดี - มีระยะโจมตีค่อนข้างไกล แต่ก็ไม่ได้มากมายนัก (คันธนู7ช่อง หน้าไม้5ช่อง) ความแม่นยำสูง สามารถใช้ธนูธาตุได้ ยิงแรงในระดับนึง มีสกิลดีๆหลายๆอย่าง ที่ซัพพอร์ตการใช้ธนู เช่น
Maskman Aura - ที่lv5 +L.hit 30
Throw Create - มีโอกาส50%(เลเวล5) ที่เมื่อยิงธนูออกไปจะไม่เสียลูกธนู(ง่ายๆก็ประมาณ ยิงไป2ดอก เสีย1ดอก) และไว้ทำธนูใช้/ทำของขว้างอื่นๆขาย
Bow Delay Cancel - รู้กัน
Dual Arrow - ซอย2ดอกติดกัน Spใช้แค่10เองมั้ง
และสุดท้าย สามารถรับไข่นก/ลูกหมาขาวฟรีๆ และอัพเกรดได้โดยไม่ต้องปั๊มค่าStatusให้เต็ม(จากที่ได้ยินมา)

ข้อเสีย - ต้องใช้ความอดทนค่อนข้างสูง เพราะจะว่าตีแรงหรือถึก ก็ไม่เท่าซอร์ดแมน/เฟนเซอร์ จะว่ายิงเร็ว ก็สู้สเก้าท์ไม่ได้ เก็บเลเวลค่อนข้างยาก ยิงมอนสเตอร์แปปๆก็ถึงตัว โดนตบทีก็กระอัก
เวลาลูกธนูหมด+ไม่มีของทำ มันอาภัพมากๆๆๆๆๆๆๆๆๆๆๆๆๆๆๆๆๆ มีดจ้วงก็ไม่ค่อยโดนเพราะไม่อัพdex-*-
เงินต้องหนาพอควร เพราะต้องมีเงินซื้อลูกธนูเรื่อยๆ ควรมีตุนไว้ในตัวเพราะถ้าหมดแล้วไม่มีของทำจะลำบาก
และช่วงว่างของสกิลค่อนข้างยาววววววว เพราะไม่มีอะไรน่าอัพเลย ตั้งแต่ได้Maskmanมา(จ็อบ8) หรืออาจจะเป็นCharge Arrow(จ็อบ15) ไปจนถึง L.range Strategyที่จ็อบ30 ซึ่งระยะห่างมันมากถึง22(หรือ15)จ็อบเลเวล- -" และยังต้องดองสกิลพ้อยนท์ ไว้มากถึง19พ้อยนท์!! เพื่อจะอัพL.range(7pts) / BDC(5pts) / Dual(7pts) ให้เต็ม เพราะถ้า3อันนี่ไม่เต็มไม่รุ่งแน่ๆ
และที่สำคัญ(ข้อนี้ขอหน่อย รำคาญมาก) มักโดนหลายๆคน เหมารวมว่าเป็นพวกชอบแจม!!!
เข้าใจนะว่าเห็นนักธนูยิงไกล แล้วมายิงแจม แต่มันไม่ใช่ทุกคนนะเฟ้ย จะเหมารวมไปทำไม?
อาชีพอื่นมันก็แจมเหมือนกันน่ะแหละ!!!
