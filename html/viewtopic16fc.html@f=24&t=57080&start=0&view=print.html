เควสอาวุธ 60 นี้ จะเริ่มต้นที่ เจ้าหญิง ( สัญลักษณ์สี่เหลี่ยมบนแผนที่ ) ที่อยู่ที่ชั้น 4 ของปราสาท

ให้คุยกับเจ้าหญิง แล้วเจ้าหญิงจะให้ไปหา ต่างหู ข้างซ้าย และ ข้างขวา ของราชินีมาให้

ซึ่งจุดที่เราจะต้องไปหานั้น มีทั้งหมด 6 จุด และทั้ง 6 จุดนั้นจะกระจายอยู่ภายในปราสาท undead ทั้ง 4 ชั้น

นั่นก็คือ สัญลักษณ์ดาว ที่อยู่บนแผนที่ สังเกตได้จาก แสงแวววับ วิ้งๆ บนพื้น

แต่ต่างหู มีเพียง 2 ข้าง ฉะนั้น จะต้องวิ่งไปดูตามจุดต่างๆเอา

ในแต่ละครั้งที่รับ Event นี้มา จุดที่จะเจอต่างหู ทั้ง 2 ข้างนั้น จะถูกสุ่มไปเรื่อยๆ

และหลังจากที่เราเก็บต่างหูครบทั้ง ซ้ายและขวาได้แล้ว ก็นำกลับไปให้กับเจ้าหญิง

แล้วเจ้าหญิงจะขายของเลเวล 60 ให้เรา โดยของที่ขายนั้นจะมี 3 ชุดซึ่งจะสุ่มขายให้ดังนี้ครับ

** ของทุกชิ้น lv60

Set A
1. ดาบ2มือ เอฟเฟคสายฟ้า passive critical (12/59/38/-)
2. ไม้เท้า (39/-/27/59)
3. ธนู (-/-/53/-)
4. หนังสือ (36/1/1/60)
5. เรเปียร์ (22/37/50/-)
6. กระบอง (mace) (47/26/33/-)

Set B
1. โล่ เอฟเฟค เรืองแสง (21/15) (12/12/5)
2. ไม้เท้า (40/-/26/57)
3. ดาบสั้น (30/48/34/-)
4. หอก (24/35/51/-)
5. หอก 2 มือ (28/38/58/-)
6. ขวาน 2 มือ (57/57/30/-) << อาวุธชิ้นนี้ ถ้าตีเองจะมี skill passive critical ด้วย

Set C
1. ดาบ มือเดียว (35/52/36/-)
2. ลูกคิด (38/-/-/-)
3. ขวานมือเดียว (49/40/35/-)
4. ธนู (-/-/56/-)
5. ไม้เท้า (รูปสายฟ้า) (41/-/28/58 )
6. โล่สีฟ้า (23/17) (10/10/6)


สรุปได้ว่า กว่าจะได้ของที่ต้องการ อาจจะต้องวิ่งหลายรอบ เพราะของที่ขาย สุ่มตลอดครับ

ทำรอบแรกอาจได้ Set A รอบ 2 ก็มีโอกาสได้ Set A อีกเหมือนกัน


ข้อควรระวัง : 1 . ถ้าคุยแล้ว พอ npc ทำการขายของ กดตกลง/ยกเลิก ถือเป็นการจบ Event ทันที ถ้าอยาก ซื้ออีก เริ่ม Event ใหม่

2. หากน้ำหนักเกินอยู่ หรือเมื่อซื้อแล้ว น้ำหนักเกิน NPC จะไม่ทำการขายของให้
