1.ชื่อ : Rafaels
2.เพศ : ชาย
3.เผ่าพันธุ์ : Titania
4.นิสัย : เป็นคนที่ภายนอกดูสดใสร่าเริง แต่ภายในนั้น เป็นคนที่มีแต่ความเศร้าเก็บไว้ในใจ
แต่เป็นคนมีน้ำใจ และใจกว้างเพราะว่าไม่อยากให้คนอื่นนั้น ต้องประสบพบ บางสิ่งบางอย่างเหมือนกับตนเอง สิ่งนั้นคือ.......
5.น้ำหนัก/ส่วนสุง/กรุ๊ปเลือด : น้ำหนัก50 สูง180 เลือด โอ
6.สิงที่ชอบ : ความเงียบสงบ
7.ความสามารถ : สามารถ รับรู้ความรู้สึกของฝ่ายตรงข้าม ดังนั้นจึงเข้าใจและพยายามที่จะช่วยเหลือผู้อื่นตลอดเวลา มีพลังที่สามารถทำลายล้างทุกอย่างได้ แต่เป็นพลังที่ถูกปิดผนึกเอาไว้
8.อาวุด : คทา แก้วใส มีผลึกแห่งแสงอยู่ตรงยอดของ คทา
9.ประวัติส่วนตัว : เป็นเด็กที่เกิดมาพร้อมกับปีกสีขาว และพรสวรรคอันน่าประหลาดที่พระผู้เป็นเจ้าประทานให้มา ครั้งเมื่ออายุยังน้อยนั้นได้เกิดเหตุการณ์ที่ทำให้ เมืองๆหนึ่งต้องดับสิ้นไป เนื่องจากหนูน้อยคนนี้ได้ระเบิดพลังออกมาโดยไม่รู้ตัว จากนั้น หนูน้อยคนนี้ก็ถูกกักขังไว้และถูกปิดผนึกแห่งพลังเอาไว้ในที่ที่มีแต่ความว่างเปล่า จนเวลาล่วงเลยไป และถูกปล่อยตัวออกมา โดยที่ตนนั้นไม่อาจรู้เลยว่าทำไม ถึงต้องถูกกักขังไว้ จนกระทั่ง พลังของเขาเริ่มตื่นขึ้น และเขาก็เริ่มจำเหตุการณ์บางอย่างได้ และเค้ายัง ได้รับพรสวรรค์ใหม่จากพระผู้เป็นเจ้า คือสามารถอ่านความคิดของผู้อื่นได้ แต่พลังที่ถูกปิดผนึกไว้นั้น ยังคลายออกไม่หมด จึงทามให้เขา ยังสามารถดำเนินชีวิต อยู่พร้อมกับปีกสีขาวเอาไว้ได้ และเขายังต้องพยายามที่จะต้องปิดผนึกพลังนี้เอาไว้ เพื่อไม่ให้....เกิดขึ้นมา
