เสียงฝีเท้าที่น่ากลัวกำลังใกล้เข้ามาเรื่อยๆ จนทำให้ ฟรอน รู้สึกกลัวขึ้นมา
'มีใครกำลังตามเรามา'ฟรอนคิด แล้วไม่รอช้า เธอวิ่งอย่างสุดกำลัง แต่เขาคนนั้น ก็ตามมาติดๆ
"ช่วยด้วย! ใครก็ได้ช่วยด้วยค่ะ"
ขณะนั้นเอง เธอก็ไปชนเข้ากับบางสิ่งบางอย่างที่อยู่เหนือพื้น เมื่อเธอเหลือบดู เธอก็...
"กรี๊ดดดดดดดดดดดดด...!" สิ่งที่เธอเห็นคือ เพื่อนๆของเธอถูกแขวนคอตาอยู่กลางอากาศ ฟรอนเริ่มทำอะไรไม่ถูก ขณะที่ฟรอนใกล้จะสติแตก ก็มีดาบพุ่งตรงมาที่เธอ แต่เธอรู้ตัวทัน เธอเลยหลบได้ทัน
"นายเป็นใคร?นายจะทำอะไรฉันน่ะ?"
ผู้ชายคนนั้นไม่ตอบ แต่กลับถือมีดขึ้นมา ฟรอนถอยไปเรื่อยๆ ตอนนี้ฟรอนรู้สึกหวาดกลัว และเธอก็ไม่มีแรงวิ่งต่อแล้ว แล้วผู้ชายคนนั้นก็...
"ม่ายยยยยยยยยยยยย...!"
