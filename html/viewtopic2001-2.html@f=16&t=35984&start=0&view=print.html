Trader กะ Gambler
เราว่า Gambler เก่งกว่าตรงที่มีสกิวหลบ แต่เรายังไม่อยากสวิทเป็น Gambler เพราะอยากลองสกิวจ๊อบ 45 เอากระเป๋าฟาดBeat Smash ของTraderดูก่อน ว่าแรงขนาดไหน ตอนนี้ขุนตัวสิงอัพโซลเตรียมไว้แล้ว

ตอนนี้เราเป็น Trader เวล80 จ๊อบ43 กว่าแล้วค่ะ อีกไม่นานคงได้ลองสกิว 45 แล้วค่อยสวิทเป็น Gambler เพื่อต้องการแค่สกิวหลบหลีกและสกิวฮีลHP/SP แต่แนวทางการเล่นคงเป็นเอากระเป๋าทองไล่ฟาดหัวมอนเตอร์ของTraderค่ะ (ไม่ชอบปาไพ่ >.<" เพราะมันดูเหมือนกำลังตั้งวงแจกไพ่เล่นดรัมมี่ยังไงก็ไม่รู้ เฮ้ยๆ แจกไพ่ๆ)

ปกติเก็บเลเวลคนเดียวตลอด ลงดั้น 70 หาใบเลื่อย70ขายได้เรื่อยๆ แบกยาได้เยอะ แบกของได้เยอะ แถมใช้สกิวFirst Aidทำให้ไม่ต้องแบกยาเพิ่มเลือด เพราะสกิวนี้สามารถฮีลHPตัวเองได้ครั้งละเกือบ587 และไอเท็ม[First Aid]มันไม่มีน้ำหนัก

นานแสนนานจะมีเพื่อนๆมาช่วยซักที แต่ปกติชอบเก็บเวลในดั้น 70 คนเดียวมากกว่าเพราะเวลาดรอปใบเลื่อยเก็บคนเดียวขายคนเดียว 555

ส่วนสกิวปัจจุบันเราใช้แค่ Banish Blow ของMerchant เก็บเลเวลไปเรื่อยๆ ค่ะ เพราะTrader เกือบไม่มีสกิวต่อสู้เลย ก็ทนๆเอาหน่อยจนถึงจ๊อบ 45 เพื่ออนาคตที่สดใสของความแรง อิอิ

เราเป็นTrader สายvit+str ค่ะไม่เน้น PVP เพราะมันเปลืองเงิน และเสียเวลาหาเงิน(ในหัวมีแต่หาเงินโดยไม่พึ่งแคลช) ตอนนี้ตีทหารขาวในดั้น70 ความแรงอยู่ที่ 900-2000+ ค่ะ(ไม่มีคนสิง) ใช้แค่(ใช้แค่สกิว Banish Blow ของMerchant )

ส่วนเรื่องยาหมดคงยากมากเพราะแบกยาได้เยอะมหาศาลแถมมีสกิวTraderจ๊อบ43 Summon Dealer

ได้สกิวจ๊อบ 45 แล้ว ><" ดีใจมากมาย

ผลของสกิวจ๊อบ 45 ของเทรดเดอร์ ลองใช้ดูความแรงมันอยู่ที่ประมาณ 1100-1800+ จำนวนครั้งที่ตีมันจะแรมดอมตั้งแต่ 2-3 ครั้งติดต่อกัน ความแรงในการตีแต่ละครั้งก็จะไม่เท่าทุกครั้ง ><" ความแรงเฉลี่ยที่ได้จากการตีหนามทองจะไม่แน่นอนเลยอยู่ที่ 3300-5000 โดยประมาณ(ถ้าตีได้ 3 ครั้งติดต่อกัน) แต่หนามทองตีทีเดียวตายเกือบทุกครั้ง สกิวนี้มี MISS ด้วย บางทีก็ตีวืดแต่ไม่บ่อย

***ปัจจุบันสวิทเป็น Gambler เรียบร้อยแล้วค่ะ จะเอาสกิวหลบ กับ 777 มาเล่น แล้วค่อยสวิทกลับมาเป็น เทรดเดอร์อีกที เพราะอยากเป็นเทรดเดอร์จ๊อบ 50 *0*


เดี๋ยวแรงเดี๋ยวเบาแต่ความแรงประมาณอยู่ที่ 1100-1800+ ต่อครั้งตามจำนวนที่แรนดอม
กำลังคิดอยู่ว่าถ้าเอากระเป๋าไปตีบวกพาวมันจะแรงกว่าเดิมหรือเปล่า ตี 2 ข้าง ข้างละ +3

ในภาพมีตัวดูดสิงอยู่ด้วยนะ เพราะกลัวกระเป๋าพัง >0<" แต่ก็พอใจกับความแรงที่ได้มา ถึงแม้จะแรงสู้อาชีพอื่นไม่ได้ แต่ตัวนี้มันเป็นตัวทำเงินให้อย่างดีเลย รวยมาก็เพราะซื้อของตามดั้นราคาถูกๆเอาไปขายแพงๆ และขายใบเลื่อย 70 นี่แหละ เอิ๊กๆๆ

ถ้าสามารถทำดีมานได้1800ติดต่อกันบ่อยๆคงจะดีไม่น้อยเลย ความแรงจะอยู่ที่ 1800*3ครั้ง= 5400 โดยประมาณ กำลังพยายามขุนตัวสิงให้เก่งๆอยู่ มีแต่ตัวดูดเวลอ่อนๆ ><" ตอนนี้คงทำได้แค่ฝันกลางวันไปก่อน - -"
