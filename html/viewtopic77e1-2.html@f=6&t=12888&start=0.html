Physical damage = ceil [(revision ATK- right DEF) ## (1 - left DEF/100)] - floor [VIT/3]

Conclusion:

Left DEF : Reduce dmg by x %, after calculate from right DEF
Right DEF: Reduce dmg by y directly from damage

*** Both Left & Right DEF need to round up first before taken into calculation
***

VIT : Reduce damage by 1 for every 3n

Left Def:
+1 when VIT = 3n
+3 when VIT = 9n

Credits: ECO Wiki

สรุปอีกที (แปลจากใน wiki เองนะ ไม่รู้ผิดเปล่านะ)

สมมุติฐาน

  • monster ทำ dmg ได้ 100
  • Vit = 22
  • Left Defense = 10
  • Right Defense = 30

Dmg ที่เราจะโดนจะถูกคิดจาก
  1. (100 - 30 ) = 70
  2. (1 - 11 / 100 ) = (1 - 0.11 ) = 0.89
  3. ceiling ของ 70 x 0.89 = ceiling ของ 62.3 = 63
  4. floor ของ ( 22 / 3 ) = floor ของ 7.33 = 7
  5. Dmg ที่โดนจริงๆ = 63 - 7 = 56


สรุปแล้ว คนที่ Def 21 - 30 จะโดน dmg เท่ากับคน Def 22 - 30 และเท่ากับ Def 23 - 30 ดังนี้

Vit 21
Dmg taken = ceil [ (100-30) * (1 - 11/100) ] - floor ( 21/3) = ceil (62.3) - floor (7) = 63 - 7 = 56
Vit 23
Dmg taken = ceil [ (100-30) * (1 - 11/100) ] - floor ( 21/3) = ceil (62.3) - floor (7.66) = 63 - 7 = 56

ในขณะที่ ถ้าอัพ Vit ให้ได้ bonus 9n จะเห็นผลต่างกันเยอะกว่า
Vit 18 (3n) => Left Def = 10
Dmg taken = ceil [ (100-30) * (1 - 10/100) ] - floor ( 18/3) = ceil (63) - floor (6) = 63 - 7 = 56
Vit 24 (3n) => Left Def = 12
Dmg taken = ceil [ (100-30) * (1 - 12/100) ] - floor ( 24/3) = ceil (61.6) - floor (8) = 62 - 8 = 54
Vit 27 (9n) => Left Def = 15
Dmg taken = ceil [ (100-30) * (1 - 15/100) ] - floor ( 27/3) = ceil (59.5) - floor (9) = 60 - 9 = 51

จะอธิบายง่ายๆนะ

เอา damage จาคนที่มาตีเรา - def ขวา
ได้ผลเท่าไร ค่อยเอามา ลบ ด้วย เปอร์เซนต์จาก def ซ้าย

เช่น def 10 5
คือ เอา damage-5 ได้ผลเท่าไรแล้วเอามา ลบกับ 10%ของdamage-5

เอาง่ายๆเขียนเป็นสูตรเลยว่า
(damage - def ขวา) - ( (defซ้าย/100)*(damage - def ขวา) )

เอาเป็นว่า ถ้าdef ขวา 50 ก็คือ demage คนที่ตี ลดเกินครึ่งอ่ะ
*0*
100*3=300
งั้นถ้า vit 300 defซ้าย ก็เป็น 300/3 =100

คือ อมตะหรอ โดนไรมาลดไป100%
