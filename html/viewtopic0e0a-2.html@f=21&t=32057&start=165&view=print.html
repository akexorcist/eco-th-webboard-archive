แอน ดูจากอาการนะ มาจากการ์ดจอ ไม่แสดงผลภาพ 3 มิติ
จากที่แอนบอกว่าใช้การ์ดของ GEFORCE นะ
ตัวนี้ตอนซื้อจะมีแผ่น Driver ของมันอยู่ ก่อนทำตามขั้นตอนที่เราบอก
ให้แน่ใจว่ามีตัวแผ่น Driver นี้อยู่กับตัวนะจ๊ะ

คิดว่าตัวการ์ดเองไม่ได้เสีย เพราะยังสามารถแสดงผลได้ แต่ก็อาจมีปัญหาในตัวของ
ชิฟแสดงภาพ 3D

เข้าไปที่ Control Panel > System > Device Manager
ดูตรง root ที่แสดงเรื่อง Graphic Card นะจ๊ะ
ถ้าเป็นสัญลักษณ์เหลืองๆแสดงว่า ไดร์เวอร์มีปัญหา ให้เลือก update
แล้วเลือกให้มันค้นหาจากแผ่น
กรณีที่ 2 เป็นรูปกากบาท แสดงว่าไม่ได้เปิดใช้งาน เลือกที่ Enable

หรือกรณีไดร์เวอร์ถูกต้อง ลองเข้าไปในโปรแกรมของ GeForce ในเครื่อง
และแต่งค่าใหม่

วิธีสุดท้าย ลองเปิดเคส ถอดการ์ดจอออก ใส่ใหม่
เปิดเครื่องให้ Run เครื่องจะแจ้ง Device ใหม่
แล้วลง Driver ใหม่นะ

ลองดูนะแอน ถ้าไม่แน่ใจยังไง ลองยกไปให้ที่ร้านดูให้นะ จะเอาใจช่วยจ้า

ปล. คิดถึงแอนงิ ไม่ได้เจอตั้งนาน ~~~
