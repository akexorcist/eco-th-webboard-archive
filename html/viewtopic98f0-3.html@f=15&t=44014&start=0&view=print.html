โมจิครับ

ก็เล่นอยู่ไม่เคยคิดเปลี่ยนใจหรือเลิกลา
ที่เล่น warlock ก็เพราะเห็นว่าเครื่องแต่งกายดูเป็นนักเวทผู้ดี
เมื่อเทียบกับชุดสายนักเวทอาชีพอื่น

ขอหน่อยเบียดนิดนึง
Vates: เสื้อผ้าบ่งบอกเลยว่าเพิ่งไปร้างบาปมา
Shaman: คนกวาดลานวัดญี่ปุ่น แต่หลังๆชุดก็เวอร์ขึ้นทันที
Wizard: ชุดไม่เหมือนนักเวทเลย หลังๆเริ่มกลายเป็นชุดนักเรียน
Warlock: ชุดมีจีบมีชายมีปก ดูแล้วเหมือนผู้ดี หลังๆก็เทห์ดี


สกิลแปลงร่างก็ใช้บ่อยนะครับ
ตอนเก็บเวลก็เป็นหมาดำ เพราะว่ารวดเร็วและวาง mark ไก้เร็วด้วย

ค้างคาวเป็นเฉพาะตอน NVN และที่ที่มอนหนาตา เอาตัวรอดได้ดี

ผีก็เป็นเฉพาะบัฟและเก็บเวลในดัน

ตอนนี้ทำ guide ของ warlock อยู่แต่ยังไม่เสร็จ
เพราะว่าติดเล่นอยู่งอมแงม
