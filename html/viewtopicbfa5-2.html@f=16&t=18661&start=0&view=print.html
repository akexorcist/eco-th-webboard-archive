appche' เขียน:เรนเจอมันต้องเลี้ยง หมาขาว หรือ นกล๊อคเบิร์ด

เลี้ยงลูกหมา wan wan(หรือลูกหมาอื่นๆ ที่ขายโดยNPCป้าขายสัตว์เลี้ยง) น่ะถูกแล้ว ถ้าจะเลี้ยงเป็นสัตว์เลี้ยงสำหรับอาชีพของสายเรนเจอร์
แต่จะมีคำสั่ง GO นอกพื้นที่ Pet School ก็ต่อเมื่อคุณ เปลี่ยนอาชีพเป็น Explorer

ส่วนหมาขาว/นกล็อคเบิร์ด นั่นมันของสายธนู และจะมีคำสั่งGO(นอกPet School)ก็ต่อเมื่อเปลี่ยนอาชีพเป็นStikerแล้ว
