ไม่รู้ว่ามีใครโพสต์ไว้รึยัง ถ้ามีก็ขออภัยด้วยนะครับ

ตัวละครที่ทดสอบใช้ชาวนา LV.84 ครับ
มีอยู่หลายเควสครับ
อยู่ที่ Quest Counter ทั่วไป
ทุกเควสใช้ 1 Skill Point ครับ

1) ส่ง Mushroom Bread LV.84
Item : Mushroom Bread x 5
EXP : 46205/46205
Reward : 6800 G

2) ส่ง Mushroom Stew LV.74
Item : Mushroom Soup x 3
(ตรงนี้ระวังนะครับ ชื่อเควสเป็น Stew ก็จริง
แต่ item ที่ใช้ส่งคือ Soup ครับ) (คงมีอะไรผิดพลาดบางอย่าง) = ="
EXP : 36081/36081
Reward : 6000 G

3) ขอเว้นไว้ก่อน ไม่แน่ใจว่ามีเควส 64 มั้ย
(เอาตัว LV.82 ไปดูไม่เจอเควส 64)

4) Mushroom Bread x 2 LV.54 (ในเกมจะเห็นเป็น LV.14)

5) Mushroom Soup x 2 LV.44 (ในเกมจะเห็นเป็น LV.4)

6) Mushroom Stew x 1 LV.34

7) Mushroom Curry x 1 LV.24

8) Mushroom Bread x 1 LV.14

9) หาเห็ดฤดูใบไม้ร่วง!
Item : Mushroom x 5
EXP : 0/0
Reward : Petfood x 1
(เควสนี้ไม่รู้ว่า item ที่ได้มีแต่ Petfood หรือเปล่าครับ
เท่าทีส่งมา 4 ครั้ง Petfood หมดเลย)

ช่วง LV ที่ทำเควสได้
14-99 (เดาเอานะครับ)

เมนูเห็ดต่างๆ (สามารถดูได้ที่ Quest Counter)
Mushroom Bread = Bread x 1 + Mushroom x 1 + Salt x 1
Mushroom Soup = Mushroom x 1 + Veggy Juice x 1
Mushroom Curry = Mushroom x 1 + Meat x 1 + Mineral Water x 1 + Spices x 1
Mushroom Stew = Mushroom x 1 + Great Meat x 1 + Mineral Water x 1
+ Butter x 1

แหล่งหา Mushroom

ทุกแมพที่ไม่ใช่ดันเจี้ยนครับ

East Acronia Field,Acronia Forest
Green Mushroom/ Brown Mushroom/ Blue Mushroom
North Acronia Field
Brown Mushroom/ Blue Mushroom/ Orange Mushroom
West Acronia Field
Brown Mushroom/ Blue Mushroom/ Mushroom
South Acronia Field
Green Mushroom/ Blue Mushroom/ Mushroom

แนะนำมี่โลกโด แมพคล้ายๆ Morg Cliff (จำชื่อไม่ได้) เห็ดก๊เยอะครับ เกิดเฉพาะที่ด้วย

เห็ดทุกต้นจะดอบ item คล้ายๆกันครับ
จะต่างกันแค่ item ไม่กี่ชิ้น
สู้ๆคับ

เพิ่มเติม:

ใครมีตัวละคร LV.64 - 73
ลองไปคุย Quest Counter ทีครับ ว่ามีเควส 64 มั้ย
ได้ยังไงฝากมารายงานด้วยเน้อ
