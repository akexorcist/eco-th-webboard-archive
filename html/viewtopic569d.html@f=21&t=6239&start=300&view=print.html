ใครที่ต้องการให้วาดตัวละครให้นะคะ (หน้าตาก็คล้ายๆกะข้างบนแระนู๋วาดได้โทนเดียว><)
ให้PMมาบอกรายละเอียดต่อไปนี้

1. ทรงผม ขอรายละเอียดผมด้านหน้าด้วย เช่น ผมยาวประบ่ามีหน้าม้าแบบแสกกลางหน้าผาก
2. หน้าตา จะสาวหวาน หนุ่มโรคจิต ขอแนวภาพโดยรวมด้วย
3. สีผม สีตา
4. อุปกรณประกอบอื่นๆ เช่น แว่น หมวก
อนึ่ง ผู้วาดโดนลอคคอจาก จขกท.ไม่สามารถวาดไปถึงชุดด้วย แปลว่านู๋ขอวาดแค่ช่วงหัว><
5. จขกท. เลี้ยงชาบูเป็นค่าตอบแทนนู๋ซะดีๆ :twisted:


ข่าววงใน!!

3. พระเอกคนที่ 2 จะได้เห็นเนื้อเรื่องของเขาในช่วงบทที่ 3
