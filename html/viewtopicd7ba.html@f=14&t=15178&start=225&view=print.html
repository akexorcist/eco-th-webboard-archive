ผม มีข้อสงสัย (อีกแล้ว) เกียวกับค่า def

อย่างที่ได้อ่านข้อมูลมาคร่าวๆในบอร์ดนี้

ค่า def ในตาราง status จะแบ่งเป็นสองส่วน คือ def หน้า+หลัง

เช่น def 21+95

ตัวแรกคือค่า def จาก vit โดยยึดหลัก เมื่อค่าvitหารด้วย3ลงตัวจะได้+1def

และเมื่อค่า vit หารด้วย9 ลงตัวจะได้ +3def

ตัวละครผมมีค่า vit 33+7=40 ดังนั้นจึงมีค่า defตัวหน้า= (1*9)+(3*4)=21

def ตัวหลัง มีค่าเท่ากับผลรวมของพลังป้องกันจากอุปกรณ์สวมใส่ + อัตราการตี+

ที่ข้องใจก็คือว่า เกมนี้นั้น def ตัวหน้าลดพลังโจมตีจากมอนเป็น % และ def ตัวหลัง

ลดพลังโจมตีจากมอน เป็นหน่วยดาเมจ

ถ้าเป็นแบบนี การตี+def อุปกรณ์สวมใส่ ด้วยหิน power crystal จึงไม่ค่อยมีประโยชน์

เพราะ def ที่ได้จากการตี + ช่วยลด dmg ได้เป็นหน่วยๆเท่านั้น (สมมติมอนอัดเรามา 500

ก็ลดดาเมจได้แค่ 1หน่วย/การตี+1หน)

ที่ผมคิดแบบนี้เพราะผมมี +6white soldier suit soft(lv39) ที่มีค่าป้องกัน 38+12 เทียบเท่ากับ

เกราะไนท์ lv55 ที่ตี+3 (def43+6)

โดยส่วนตัวผมยังคิดว่าโดนโจมตีจากมอนแรงไม่ต่างกับชุดเดิมเท่าไหร่นักเลย

ถ้าเป็นแบบนี้ ผมเอาหิน life crystal ไปตี+อุปกรณ์ป้องกันเพื่อเพิ่มเลือดดีกว่าไหมครับ

เพราะเอาหิน power ไปตี+def ที่ได้มาก็ไม่คุ้มกันเอาซะเลย

อีกทั้งราคาหิน power ก็ดีดสูงขึ้นมาก ส่วนนึงก็อาจจะเพราะเอาไปตี+อาวุธ

แต่นั่นก็เช่นกัน ผมสังเกตว่าอาวุธในเกมนี้ atk ที่ต่างกันมีผลน้อยกว่า status bonus มาก

ถือ lance มือเดียว lv30 atk 30 กับถือ +3trident สองมือ lv40 atk 43+6

ดาเมจก็ยังแตกต่างกันไม่มากเท่าไหร่เลย (แตกต่างกันไม่ถึง20~50หน่วยเมื่อใช้สกิล)

แต่เมื่อ status ลงตัว ที่ 5n+1 หรือ 9n ดาเมจจะเปลี่ยนหรือพุ่งพรวดอย่างมาก


ทำให้ผมฉุกคิดว่า การตี+ต่างๆนั้นเราอาจจะไม่ได้ใช้เกณฑ์พิจารณาแบบเกมอื่นๆก็ได้

ถ้าเป็นผม ผมคงเลือกตี+ critical ลงในอาวุธ (เพราะในขณะโจมตีด้วยสกิลก็ติดคริติคอลได้)

แล้วก็ เลือกตี +life ลงในเกราะ เครื่องประดับ โล่ (เพราะ+def ไปก็มีค่าน้อยเทียบกะ hp)
