-------------------------------------------จุดประสงค์ของร้าน---------------------------------------------------------


นี่คือคาเฟ่เปิดไหม่ในโมจิค่ะ(เห็นโมจิเขาไม่มีคาเฟ่กันหนิ)

เราจัดทำคาเฟ่หรือร้านขายของ เพื่อให้ลุกค้ามานั่งคุยนั่งเล่นกันและรับส่งคนไปไหนมาไหนได้
เพื่อความสะดวกสบายของคนที่ไม่มีบ้านบิน
และทุกวันจะมีมินิเกมในร้าน อย่างเช่นเกมทายปัญหา ต่อคำ
จึงขอความเห็นของทุกคนน่ะค่ะว่าจะทำยังไงได้บ้างรบกวนหน่อยนะคะ

ถ้ามีประกาศกิจกรรมอะไรก็จะมาลงในบอร์ดนี้ค่ะ

ก่อนอื่นกรุณาอ่านกฏนี่ด้วยนะ เพื่อการพูดคุยโต้ตอบกระทู้นี้ไม่ให้เกิดดราม่า

1.ถ้ามีอะไรไม่พอใจให้พูดคุยกับคู่กรณี1-1ก่อน อย่างไม่ใช้อารมณ์ บอร์ดเป็นที่ๆห่วยแตกที่สุดต่อการเคลียร์
เพราะบุคคลภายนอกมักจะเข้ามาเสพ/ก่อมาม่า

2.อย่าใช้อารมณ์ในการที่มีอะไรไม่พอใจ ส่วนจะดูอย่างไรว่าเราใช้อารมณ์หรือไม่ ในวินาทีที่เราพิมพ์ข้อความ
ถามตัวเอง ว่าอารมณ์เราปกติอยู่รึเปล่า หงุดหงิดอยู่ไหม ไม่ชอบใจอยู่ไหม
ถ้าใช่ ต่อให้เราบอกว่าแยกแยะได้ ไม่ควรพิมพ์ ควรรอเฉยๆให้อารมณ์ปกติก่อน พออารมณ์ดีค่อยมาดูอีกที คิดช้าๆ
ว่าควรตอบกลับอย่างไรให้อีกฝ่ายไม่เคืองกลับแล้วเราเองไม่เสียงหาย
ถ้าทำได้จากภาพ คนทะเลาะกัน2คน จะกลายเป็น คนหนึ่งหาเรื่องกับอีกคนหนึ่ง
เมื่อเรื่องมันดำเนินเข้าถึงในบอร์ด ไทยมุงก็ช่วยกันกระทืบตัวหาเรื่องเอง

3.พูดคุยกันอย่างมีเหตุและผล
