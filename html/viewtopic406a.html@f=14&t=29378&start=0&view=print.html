โห เรปบน ดันเหนือมันเกบถึงหกสิบได้ด้วยหรอ มันมีมอนสูงสุดแค่เวล 44 เองอ่ะ แถมเป็นมอนพิเศษด้วย(หายากในบริเวร) นอกจากนั้นก็บอส

ถ้าผมแนะนำ ให้ลงดันใต้เอ่ะครับ รวยด้วย เวลเร็วด้วย ตีบุริคิง อาร์เอ็ก3 แล้วก้อหุ่นเขียวอ่ะ หรือผีก็ได้ ตัวชมพูก้อให้ดี(แต่มันฮีลได้ ไม่แนะนำ)

ลงไม่เกิน หนึ่งชั่วโมง เอาของออกมาขายได้ประมาณ สองถึงสามหมื่นอ่ะครับ รวยด้วย เวลเร็วด้วย สมใจ

วิธีตีนะครับ ใส่ แคนเซิลดีเลย์ แล้วตีใส่ได้ประมาณสองตัวอ่ะครับ หรือไม่ก็ลากกลุ่มแล้วตีเรย เบลดเลือดเยอะแล้วชิมิ
