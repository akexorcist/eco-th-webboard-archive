เป็นDmg ที่รุนแรงมากๆ เป็นการโจมตีทั้งหมด 5 ครั้ง

ต่อมาเป็นการทดสอบระยะสกิล โดยมีผู้ถูกรับเชิญให้มาเป็นผู้ร่วมทดสอบสกิล พีทคุง ที่เจอกับบ่อยๆที่หอแสงชั้น 16 อิอิ

และในการทดสอบครั้งที่ได้เกิดความบังเอิญขึ้น เพราะมีการโจมตีที่ขึ้น Avoid ด้วยแต่จากการทดสอบให้แอสใช้สกิล Avoid ก้ไม่มีผลแต่อย่างใด คือ ไม่สามารถหลบได้โดยการใช้สกิล Avoid นั่นเอง การจะเกิด Avoid ขึ้นอยู่กับดวงเท่านั้น

จากการทดสอบแล้วได้ผลว่า def มีผลทำให้ความแรงของสกิลลดลง ส่วน mdef ไม่มีผลให้ความแรงของสกิลลดลงแต่อย่างใด

โดยสรุปแล้วเป็นสกิลที่มีความแรงในระดับสูงแต่เป้นสกิลที่ใช้ค่อนข้างยากเพราะต้องอยู่ในระยะประชิดถึงจะทำ Dmg ได้รุนแรง และถ้าเจอผู้เล่นที่มี def สูงๆก็อาจจะทำให้พวกเราจ๋อยได้เหมือนกัน งิ
