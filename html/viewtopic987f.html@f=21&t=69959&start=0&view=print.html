......ณ โลกเอมิลเมืองหลวงอโครเนีย ในมุมหนึ่งของเมืองนี้ได้มีองค์กรใหญ่กลุ่มหนึ่งที่แม้แต่ทหารกองกำลังแห่งอโครเนียไม่อาจต่อกรได้ แต่หนึ่งในนั้นได้มีเด็กสาวคนหนึ่งที่มีโค้ตเนมว่า"เมรี่"ออกมาต่อกรกับองค์กรนี้ด้วยตัวคนเดียวโดยที่ตัวเธอไม่มีความกลัวสิ่งใดเลยแม้แต่น้อย

และในขณะที่เธอกำลังหาทางจู่โจมองค์กรนั้น ได้มีชายผู้หนึ่งจากองกรออกมาปะทะมือกับเธอผู้นั้น การปะทะกันดุเดือดมากจนผลออกมาว่าเสมอกัน ต่างคนต่างบาดเจ็บ และเด็กสาวก็ได้หลบหนีไปก่อน

ในขณะที่หลบหนีอยู่เธอก็ได้ไปชนกับหญิงสาวที่เดินอยู่ตามเส้นทางในเมือง และคนที่เธอชนเป็นนักเรียนเวทย์ที่มีความสามารถสูงมีนามว่า"เซเรเน่"แต่เพราะพรหมลิขิตหรือชะตาที่ต้องกันทำให้ทั้งคู่ต้องมาพบกันอย่างไม่คาดคิด....
