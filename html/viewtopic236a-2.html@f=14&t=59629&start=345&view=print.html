ดีเลย์อาจจะนานไปสักหน่อย แต่ถ้าเล่นปืนจนชำนาญก็ไม่น่าจะมีปัญหาอะไร เพราะปืนยิงทีนึงก้อดีเลย์ 2 วิแล้ว

ความเจ๋ง**

ประการแรก ใช้พุ่งผ่านเวทได้ เช่นลาวา เคออสเกท พุ่งผ่านเล่นๆ เลย ไม่โดนเวท หรืออยากจะเก่งกว่านัน้ ใช้พุ่งออกจากวงรุ้ง ถ้าท่านทำได้ -*- (ผมยังทำไมได้เร็วจัด เลิกคิดจะทำไปแล้ว)

อีกประการ ใช้ฆ่าคนสิงครบใน nvn หรือในลานได้ (nvn น่าจะดีกว่า ตอนเพื่อนๆ กะลังชุลมุนเราก้อ ชะแว๊บซะ ) โดยที่สกิลนี้ แดเมจของการสไลด์จะเข้าตัวสิงโดยตรงไม่ไปหารไปแชร์แดเมจใดๆ ทั้งสิ้น แรนด้อมคนโชคร้าย 1 คน จาก 3 คน เข้าเหนาะๆ ถ้าสเตงเยอะ พอที่จะตายใน 1 ชะแว๊บได้ก็ร่วงเลย

ลองใช้กันดูงิ ของดีที่...ใช้ยากไปนิด


แหะๆ ใช้อยู่เหมือนกัน มาเพิ่มเติมสกิล สกิลนี้ถ้ามีคนยืนอยุ่ซ้อนข้างหลัง ดาเมจจะหาร
เอาไว้ฆ่าคนคงลำบาก แต่ก้อใช้ ไว้วาป เหมือนของซอ ได้ ถ้าเอาไว้เวลหรือทำดาเมจคงสู้สกิลอื่นไมได้( ต่อให้ถือมีดความแม่นยำก้อขึ้นกับ INT )
