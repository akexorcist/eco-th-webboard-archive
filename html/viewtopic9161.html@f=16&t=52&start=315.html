Coal สามารถทำเองได้ ( ง่ายจัง ) ค่ะ .. แต่ต้องมีสกิล งานไม้ก่อนนะ

วัสดุในการทำ Coal ต้องมี ท่อนไม้ (ที่ใช้ก่อกองไฟนี่แหละ) + เตาหลอม ( หาซื้อได้จ้า )

แค่นี้เราก็จะได้ Coal แล้ว แต่ ว่า อาหารที่ใช้ coal ทำนั้น รู้สึกจะบัคอยู่นะ หลุดกานหมด
