### เพิ่ม Min ATK เมื่อตัวละครใช้อาวุธประเภท Throwing
ประเภท :: Passive Skill
[ได้ตอน Job Lv.3]
:!: จำเป็นต้องสวมใส่อาวุธ ประเภท Card (ไพ่)
:!: สกิลมีผลเช่นเดียวกับ สกิลของ Scout
:!: เพิ่มพลังโจมตี,ระยะการโจมตี,ค่าHit ขั้นต่ำของCard





### สามารถผลิตอาวุธประเภท Throwing เลเวล Skill ยิ่งเยอะยิ่งใช้วัตถุดิบน้อยลง
ประเภท :: Active Skill
[ได้ตอน Job Lv.5]
:!: Card ที่ถูกสร้างมีโอกาสเสียหาย
:!: Card ทีใช้จะลดจำนวนลง , แต่เราสามารถใช้สกิลสร้างขึ้นใหม่ได้
:!: ที่สกิลเลเวลสุดท้าย การ์ดที่ถูกสร้างขึ้นจะเข้ามาอยู่ในมือ(คิดว่า ทำเสร็จปุ๊ป เข้ามาในมือปั๊ป)




### เพิ่มค่าพลังโจมตีขั้นต่ำ
ประเภท :: Passive Skill
[ได้ตอน Job Lv.7]
:!: ค่าพลังโจมตีขั้นต่ำที่เพิ่มขึ้น ไม่เกี่ยวข้องกับ Status
:!: ค่าที่เพิ่มขึ้นไม่เกี่ยวกับ ค่า Atk พื้นฐานและ Status รวมไปถึง BaseLV และ JOBLV





### ฟื้นฟูแบบเสี่ยงดวง ถ้าโชคดีก็ ฟื้นฟู HP ถ้าพลาดก็ ลดHPแทน
ประเภท :: Active Skill
[ได้ตอน Job Lv.9]
:!: (รายละเอียดเยอะมากครับ คงแปลนานหน่อย ยัง งงไอตรง X+Y อยู่เนี่ย)





### ฟื้นฟูHP ให้เพื่อนในปาร์ตี้แบบผู้โชคดี นั้นก็คือ Random ว่าใครจะได้
ประเภท :: Active Skill
[ได้ตอน Job Lv.12]
:!: ระยะการใช้งาน 13*13 ช่อง โดยมีผู้ใช้เป็นศูนย์กลาง
:!: ปริมาณการฟื้นฟู ขึ้นอยู่กับ MATK , รักษาได้ทุกคนในปาร์ตี้ รวมไปถึงคนที่ Possession อยู่ และ Pet ด้วย

### โจมตีใส่เป้าหมายด้วย อาวุธประเภท Throwing ติดๆกัน จำนวนการขว้างขึ้นอยู่กับเลเวลสกิล
ประเภท :: Active Skill
[ได้ตอน Job Lv.19]
เป้าหมาย :: ศัตรู1ตัว
:!: ใช้กับ อาวุธขว้าง,ไพ่

:!: พลังโจมตีจะเพิ่มขึ้นอย่างมหาศาล เมื่อโจมตีพร้อมกัน(ฟิ้วๆๆ ปิ้วๆๆ)





### ลดพลังโจมตีของเป้าหมายลง เพราะเรามีเสน่ห์(โอ้ จอร์จ มันยอดมาก)
ประเภท :: Active Skill
[ได้ตอน Job Lv.22]
เป้าหมาย :: ศัตรู1ตัว





###กำหนดพื้นที่ แล้วสุ่มตัวเลขแบบสล็อตแมชชีน เมื่อได้เลขตามกำหนด จะเกิดผลต่างกันไปตามตัวเลขที่สุ่มได้
ประเภท :: Active Skill
[ได้ตอน Job Lv.25]
เป้าหมาย :: กำแพง หรือ พื้นดินที่มีเครื่องหมายเป็นศุนย์กลาง
:!: ระยะสกิล 4
:!: เวลาร่าย 4 วินาที(ลดได้ด้วยค่า Dex )
:!: ค่าดีเลย์ 2.5 วินาที
:!: (ยังมีรายละเอียดอีกเยอะมาก เดี๋ยวจะแปลมาให้ภายหลังครับ ใครจะช่วยแปล PM มาได้ครับ มันเยอะจริงๆ)
