statคาใจ คาใจตรงvitเท่ากันเดะ- -
มันก็ไม่รู้จะว่าไงนะ ถ้าไปลงintมันก็ได้แต่Mdef กะmin matk
ไปลงวิทได้เลือด(ถึงไม่มากแต่ก็มีความสำคัญทีเดียว)
ได้ทั้งMdef / def
Mdefจะต่างจากแบบintประมาณ1-2ได้หละมั้ง
แต่มันจะได้Defไปด้วย ซึ้งถ้าไปทางเพิ่มint มันจะไม่ได้Defเลย

ขอลงคะแนนให้ไปvitละกัน มองในแง่ความทนทานที่เพิ่มขึ้นนะ
เพราะจะเอาความแรงด้านint มันเพิ่มแค่นิดเดียวเอง
(แต่ตัวผมเล่นผมลงint เพราะวิทเล็งกะไว้ที่45นั่นหละ แล้วintหน้า30)
