---- 2.1 Mineral water ได้จากการ Purify [ 2 Turbid ]
---- 2.2 Turbid ได้จากการ Purify [ 2 Seriko ]


ฟังดูยุ่งยาก อยากลัดขั้นตอน ก็ไปที่แมพ ทางทิศเหนือเลยขอรับ ไม่ว่าจะเป็น แมพ Snop Hill / Snop Triangle / Nozarn cape

แถม มี NPC คอย Purify ให้ ที่หน้าด่านตรวจบัตรเข้าเมืองเหนือ
ทำให้ สามารถแบกกลับได้คราวละ มากๆ ในสภาพที่ Purify แล้ว

listening เขียน:แล้วมียาที่ทำให้เล่นเกมส์ทนๆ ตื่นเช้าๆมาทำงานได้บ้างไหมครับ


มีครับ เท่าที่ทราบมา มี 2 ชนิดนะครับ

1. ยาทัณฑ์บนวินัย เอาไว้ อันนี้ จะเพิ่มขยัน + 100 เล่นเกมส์ดึกดื่น โต้รุ่งแค่ไหน ก็แหกขี้ตา วิ่งโร่มาทำงานในสภาพ กึ่งตาย ( Half Undead ) ได้อย่างสบายๆเลยครับ
ถึงแม้น จะมีผลข้างเคียง ทำให้สุขภาพจิต -10 สุขภาพกาย - 50

แต่ หาก อัพค่า Vit ให้กับใบหน้า มากๆไว้ ก็จะไม่เสียสุขภาพจิตมาก ส่วนสุขภาพกาย อันนี้ตัวใครตัวมัน
หาทางอัพเอาเอง + พักผ่อนให้พอ และ กินอาหารที่มีประโยชน์




2. ยาเจ้านาย และ เพื่อนร่วมงานเพ่งเล็ง อันนี้ หากคนที่ อัพค่า Vit หนังหน้า มาน้อยๆ อาจจะลด สุขภาพจิตสูงมาก แต่ค่าความขยัน จะเพิ่มถึง +250

ยานี้ จะทำให้พวกที่อัพค่า Vit หนังหน้ามาน้อยๆ มีความกระตือรือร้น สูงกว่าพวก หน้าหนา เอ๊ย พวก อัพ Vit หนังหนามาสูง




วิธีทำยาเหล่านี้

1.ทำงานสาย
2. อู้งาน
3. หยุดงาน - ขาดงานบ่อยๆ แบบหาเหตุผลไม่ค่อยได้
4. ตอนทำงาน ชอบแว่บ หายหัว หายตัว หายไปจากโลกนี้ เข้าสู่โลกส่วนตัว

หากทำได้ 4 ข้อ จะได้รับยา 2 ชนิดนี้มาเอง

แล้วเมื่อต่อให้เราเล่นเกมส์ ไม่หลับไม่นอน เล่นหัวซุกหัวซุน อย่างไร ยังไง้ ยังไง ก็ต้องลากสังขาร
ออกมาจาก วิมานสถาน ไปยังสถานที่ทำงานได้ครับ
