ต่างกันนะครับ bullet dance เป็นท่ายิงรอบตัว ไว้ใช้ในการลากแล้วยิงหมู่ครับ

ถ้าจะให้เทียบกัน ควรเทียบกับท่า Plurality Bullet มากกว่า ถ้าคุณมั่นใจว่าจะใช้ Fast Draw แล้วก็ไม่ต้องไปอัพ Plurality Bullet ครับ หรือถ้าคิดว่าขย้นพอ ไม่ต้องอัพ gun delay cancel เลยก็ได้ กดแต่ fast draw ตลอดเกม

Fast Draw Lv3 = ท่าสำหรับปืนมือเดียว.. ปืนคู่+ไรเฟิลใช้งานไม่ได้ - ยิง 1 นัด ความไวตามมือคนเล่น

Plurality Bullet Lv5 = ใช้ได้ทุกปืน แต่ปืนคู่ถ้าใช้แล้วจะเพิ่มโบนัสจำนวนครั้งที่ยิง - ยิงรัวทั้งหมด 4-6ครั้ง (ปืนคู่ 5-7 ครั้ง)

Gun Delay Cancel Lv3 = เพิ่มความเร็วในการยิงของปืนทุกชนิด 33% และลดเวลาในการร่ายท่าต่างๆด้วย อันนี้ต่อให้คุณใช้ Fast draw แต่ผมแนะนำให้อัพนะ
