โดย ECO
สกิล ชาตชอต กับสกิล ยิงรัว บางคนอาจจะเล่นแบบผมนะครับ
คือใช้ ชาตชอต แล้ว ยิงรัว แต่เวลามอนเข้ามาหาแล้วจะใช้สกิลชาตชอต มีดีเล ผมแนะนำทำให้ดีเลหายครับ
คือยิง สกิลตามที่ผมบอก แล้วจะยิงชาตชอต แล้วขยับไปตรงไหนก็ได้ครับแนะนำว่าเดินใกล้ๆ แล้วค่อยต่อสกิลครับ ลดดีเลที่ทำให้้ หลายคนตายมาแล้วมั้ง- -a หลายคนอาจจะรู้แล้ว แต่ผม ก็บอกไปงั้นแหละ เผื่อจะดีขึ้น [อย่าว่ากันเลยนาว่ามันตื้นไปหน่อย]

ชาร์จ ในกระทู้บอกว่าไม่มีดีเลย์ แต่ใช้จริงๆรู้สึกมีนะ - -
ตอนนี้ผมใช้จนกะเวลาดีเลย์ได้แล้ว กะนิดๆหน่อยแล้วกดบาร์ราจต่อ เพื่อนบอกโหดโคตร = =
มอนแทบจะมาไม่ถึงตัว

ชาร์จช็อต จริงๆควรอัพไว้แค่เลเวล1ก็น่าจะพอ หวังผลแค่ให้มอนสเตอร์กระเด็นไป ซึ่งดูๆแล้วน่าจะเหมือนชาร์จแอร์โร่ว ที่เลเวลสกิลสูง มอนก็นิ่งนานเท่าเดิม
เพราะถ้าหวังที่ความแรง ก็ต้องอัพสกิลเวลสูงๆ ซึ่งเปลืองพ้อยนท์ - -
และไม่แน่ว่าอาจจะมีดีเลย์นานขึ้นด้วย

แต่คิดดูละกันว่า คอมโบ2สกิลนี้ ก็แรง+โหดมากๆแล้ว
ยิ่งสกิลเลเวลสูงๆนี่

อึ๋ย คิดแล้วหยอง* *

กะลังคิดอยู่ว่า ชาร์จ+สตั๊น+ครอสท์เครส์/บัลเล็ทแดนซ์ จะโหดแค่ไหน
