ติดตามกระทู้มานาน แต่ไม่มีโอกาสได้เล่นตอนโคลส
และก้อคงจาติดตามข้อมูลจากกระทู้ในนี้ต่อไปคร้าบ(ซื้อหนังสือไม่คุ้มหรอกชอบกั๊กไว้ขายหลายเล่ม)
เปงกำลังใจให้เจ้าของกระทู้นะคับ เปนธรรมดาแหละ ทำดีมักโดนอิจฉา 555+

อ่า...จะถามด้วยว่า หัวข้อ *~ :: แนวทางการอัพ Skill Farmer // วิเคราะห์ Skill Farmer :: ~* ตรง Skill ที่สำคัญของ Farmer ที่ทุกคนจะต้องอัพเลย อย่างเลี่ยงไม่ได้ มีอยู่ 5 สกิลค่ะ

1. Cultivation ( ปลูกต้นไม้ ได้มาตอนเปลี่ยนอาชีพ ) max lv 1
2. Plant Knowledge ( ปราชญ์แห่งพืช ) max lv 1
3. Tree Knowledge ( ปราชญ์แห่งไม้ ) max lv 1
4. Cooking ( ทำอาหาร ) max lv 5
5. Item Refine ( แปรรูปวัตถุดิบ ) max lv 3

โดยทั้ง 5 Skill นี้ค่ะ Farmer ทุกคนขาดไม่ได้เลย ถ้าไม่อัพก็ไม่ใช่ Farmer นะค่ะ
ทั้งหมดนี้ เราจะเสีย skill point ไป 21 point ค่ะ ซึ่ง Skill point ที่เหลือ
ก็ขึ้นอยู่กับตัวเอง แล้วว่า จะอัพ Skill อะไร ที่นำมาใช้ประโยชน์ได้มากที่สุดค่ะ

แต่ลองนับตามเลวลดูมันแค่ 11 ไม่ใช่หรือคับ รึว่ามีสกิลไหนที่จะต้องใช้ 2 Point ในการอัพ?
จะเหมารวมว่าต้องอัพก็ไม่ถูก เพราะเรากะไม่อัพ cooking แน่นอน (ถ้าจะเล่น farmer เป็นตัวหลักนะ) แต่ refine จำเป็นมากยังไงก็คงต้องอัพจริงๆ อีกสกิลที่คิดว่าจำเป็นก็คือ mace mastery หรือ axe mastery แล้วแต่ว่าเล่นอาวุธอะไร เป็นสกิลที่สาย backpacker ไม่ควรพลาดเลย ไม่งั้นจะตีเบามาก
