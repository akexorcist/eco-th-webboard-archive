Skill DarkShield ทำให้เกราะเป็นธาตืมือ 50 คืออะไรหรอคะ
แล้วมันทำให้ป้องกันสูงขึ้นรึป่าว
แล้วมันใช้ป้องกันเห็นผลจิงมากแค่ไหนคะ
สุดท้ายคือใช้จิงได้บ่อยแค่ไหน
