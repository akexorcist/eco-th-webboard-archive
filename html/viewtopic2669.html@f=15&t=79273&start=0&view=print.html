สกิลที่ส่งผลต่อ แรงโจมตีเวท มีหลายสกิลครับ
สกิลที่สายเวทมืดควรมีติดตัวเลยคือ

Evil Soul ทำให้ยิงเวทธาตุมืดแรงขึ้น 1.95 เท่า
พวกสกิล อื่นๆที่โจมตีเป็นธาตุมืดก็ส่งผลด้วย
( Soul Steal / Grim Reaper / Darkness Arrow / Dark Wall Wind / Darkness Of Night )

ZEN ของเอเลก็เป็นอีกสกิล
ทำให้ยิงเวทแรงขึ้น 2 เท่า และใช้ MP เป็น 2 เท่าจากปกติ
ใช้ซ้อนกับ Evil Soul ได้

ถ้าใช้แค่ 2 สกิลนี้ Dark Blazer เวล 3 ที่ยิงแรง 400% จะกลายเป็น 1560% ทันที (ยังไม่นับแพ้ทางธาตุกับป้องกันเวท)


อีกสกิลของคาบาที่พึ่งมาใหม่
My Sacrifice
ได้ตอน JOB 50
ทำให้ เพิ่มแรงโจมตีขึ้น 2 เท่า ทั้งโจมตีปกติ และโจมตีเวท
และเพิ่มพลังป้องกัน 0.3 เท่า ทั้งป้องกันปกติและป้องกันเวท
แต่ข้อเสียคือ เสีย HP 24% จาก Max HP และฟื้นฟูไม่ได้จนกว่าจะหมดระยะเวลาสกิล


ยังมีวิธีสาป หิน/น้ำแข็ง อีก ทำให้ยิงแรงมากๆ(เล่นธาตุ)

วิธีสู้มันมีมากมายมันก็แต่คนจะใช้ล่ะครับ
