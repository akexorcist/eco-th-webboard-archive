หมูน้อยน่ารัก เขียน:แค่โหลดแมพ ก็นานแล้ว แมพ โมโมเงี้ย เดินทีแลคที ต้องรอให้เข้าที่สัก5นาทีถึง
ผมแยกให้เป็นข้อๆนะครับ
1. การ์ดจอ แต่มันไม่เกี่ยวกับการโหลดเข้าแม็พช้า จะเป็นในส่วนเวลาเล่นแล้วภาพสะดุด หรือการแสดงผลไม่สมบูรณ์
ในกรณี การ์ดออนบอร์ด ก็ไม่น่าจะส่งผลมากขนาดนั้น
กรุณาตอบกลับด้วยได้ไหมครับใช้ การ์ดจอรุ่นอะไร

2. ความเร็วอินเตอร์เน็ต ผมว่าจะเป็นในส่วนนี้มากกว่า เพราะเสป็คเครื่องของท่านเล่นเกมส์ได้สบาย(ตามที่กล่าวอ้างมา)
แต่ถ้าท่านใช้เน็ต Adsl อยู่แล้ว(Hi Speed นั่นแหละครับ) ผมอยากให้ท่านลองตรวจดูความเร็วเน็ตที่ได้จากการทดสอบ
http://speedtest.adslthailand.com/
ซึ่งถ้าความเร็วที่ได้ต่ำกว่าที่เป็นจริงมาก ควรตรวจหาไวรัสหรือเวิร์มในเครื่อง เพราะมีบางชนิดมันกินแบนวิชครับ

3.Windows Vista (วิสต้า นะครับ) ตัววินโดวส์ยังคงมีอาการบั๊กในตัวระบบเองครับ และด้วยตัววินโดวส์ที่รับประทานทรัพยาการอย่างมากมายอาจเป็นเหตุที่ทำให้เครื่องของท่านไม่เหลือทรัพยากรณ์ในการเล่นเกมส์
(Vista ต้องการ Ram อย่างน้อย 1G อยู่แล้วครับ นั่นหมายความว่า เครื่องของท่านอาจมี Ram ไม่พอสำหรับตัวเกมส์)

4.เกมส์นี้ออกมาก่อน Vista นานมากครับอาจทำให้ตัวเกมส์มีปัญหาเวลาเล่นบน Vista ก็เป็นได้ครับ(ต้องให้คนที่เล่นบน Vista ตัวจริงมาตอบละครับ ผมเล่น บน Xp)

*อันนี้ความเห็นส่วนตัวนะครับ*
อยากให้ท่านเปลี่ยนไปใช้ XP จะดูดีกว่า เนื่องด้วยตัววินโดวส์ที่กินทรัพยากรเครื่องต่ำกว่า Vista มาก
ทำให้มีทรัพยากรอย่างเหลือเฟือในการเล่นเกมส์ครับ
