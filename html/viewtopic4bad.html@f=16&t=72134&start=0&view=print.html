สายไพ่ไม่จำเป็นต้องอัพ vit มากก็ได้ครับ แล้วแต่สไตล์เรา

dex ไม่ต้องอัพเพราะ สายไพ่มันจะโดนไหมขึ้นกับ int

ส่วนระยะเวลาการร่ายขึ้นกับ agi ครับ อยากปาเร็วๆก็กด agi ไปเลย 108

ส่วนจะอัดแรงไหมก็ขึ้นกับ str เหมือนเดิม เพราะฉะนั้น vit จะอัพยังไงก็แล้วแต่ตามสเตตัสน่ะครับ

สายนี้ผมเล่นไว้วออยู่ผมอัพ vit กดเต็มที่ หรือจะลงโบนัส

agi รวม 108

int ตามสเตป ผมอัพรวมๆได้ 50-60

ถ้าสดก็ประมาณนี้อ่ะครับ ถึก ร่ายเร็วป่วนได้ทุกสถาการณ์

อัพสกิลพวก lucky จะกันตายได้เยอะเลย ส่วน dex ไม่ต้องอัพ

หรือจะไม่อัพ int ไปอัพ mag เพื่อใช้สกิลRandom Heal ก็ได้เพิ่ม hp mp sp
