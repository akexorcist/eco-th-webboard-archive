โซล Mag

แล้วให้เอเล Zen กับ กด Speed Enchant ให้ที่ดัน 70 แล้วยิง Energy Burn หรือ Dancing Sword ได้สบายๆนะ โดยมากแล้ว ยิง Dancing Sword ทีเดียวก็ตายได้ โดยเฉพาะ โจรขาว, หุ่นแดงและ งู แต่ไม่ตายภายในหนึ่งครั้งก็มี วาซาบิ, G4, Kodama (พูดถึงห้องที่เก็บประจำนะงิ ><)

พอจบตรงนี้แล้วคิดว่า Vit กับ Int ไม่ควรอัพในกรณีสายเก็บ lv. เมื่อก่อนเคยคิดเหมือนกันว่าการอัพค่า

Int แล้วเวทย์ไม่แกว่ง แต่อัพไปไม่ได้ช่วยมากเท่าไหร่ - -* เพราะ Mag เราสูงมาก ก็ทำให้ Int ที่เพิ่ม min ไม่ close กับ max อย่างที่คุณ Aussibum ว่า อะงิ

ส่วน Vit ตอนเล่นตัวของน้องสาวสมัยก่อนไปดันใต้ก็อัพ vit ไว้เผื่อรอด ในกรณีเล่นคนเดียว แต่ปัจจุบัน ถ้าเรามีปาร์ตี้ครบพร้อมแบบข้างต้นแล้วก็จะไปได้สบายๆ ดังนั้นค่า Vit นี่แล้วแต่วิจารณญาณของแต่ละบุคคลจ้า

แต่ส่วนตัวไม่ได้อัพค่า Int กับ Vit เพราะใช้หลักแนวคิดว่า ยิงให้แรงที่สุด แล้วก็ให้ตายไวที่สุด แล้วก็เชื่อคนในปาร์ตี้แหละงิ ว่าเราต้องรอดได้งิ ทั้งนี้ทั้งนั้น ขึ้นอยู่กับวิธีเก็บ lv. ของแต่ละคนว่าเป็นแบบไหน แล้วมันจะเกิดสายเก็บ lv. ในแบบที่ตัวเองชอบงิ ^w^
