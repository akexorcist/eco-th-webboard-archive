1. สกิล First Aid
-เพิ่ม hp ตาม lv สกิล โดยใช้ไอเทม First Aid (ใช้ fabric + ether จะได้ first aid x 5) สกิลนี้เหมาะกับผู้เล่นสาย vit ครับ ถ้าเล่นสาย agi มองข้ามไปได้เลยครับ

2. สกิล Grinder Attack กับ สกิลตีทะลุหลังหมาอ่ะครับ
-ก็เป็นการสั่งหมาไปโจมตีโดยใช้สกิลน่ะครับ Grinder Attack ที่เลเวล 5 จะโจมตีแรง 400% น่ะ(ใช้ sp 17) ส่วนอีกสกิลขอชื่อ eng ก็ดีครับ บอกมางั้นไม่รู้น่ะ(จริงๆมันไม่มีนะสกิลแบบนั้นน่ะ มีแต่ สกิลหอน(roaring)ของหมาทำให้มอนติด stun กับ สกิลโจมตีมอนที่อยู่ระหว่างเรากับหมาน่ะ(pincer))

3. สกิล analysis ต่างๆ
-ตามความคิดผม เป็นสกิลที่ไม่จำเป็นต้องอัพก็ได้ครับ เพราะมีสกิล knowledge อยู่แล้วน่ะ

4. สกิล Attack Assist
-ผลของสกิลเพิ่มพลังโจมตีให้คนสิงหรือเราเอง ข้อมูลเพิ่มเติม http://board.onenet.co.th/viewtopic.php?t=20465 ครับ

แต่สำหรับผลคิดว่าเป็นสกิลที่ไม่จำเป็นเท่าไหร่เลยอ่ะนะ
