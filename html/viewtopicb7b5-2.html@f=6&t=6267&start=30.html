ชุด 60 ต้องทำ Event ครับ ซึ่งเริ่มต้นที่เจ้าหญิง หลังจากคุยแล้วเจ้าหญิงจะให้หา ตุ้มหู ซ้าย และ ขวา ซึ่งอยู่ภายในปราสาท undead ทั้ง 4 ชั้น (เจ้าหญิงอยู่ชั้นที่5) สังเกตได้จาก ประกายแสงแวววาว ซึ่งมีประมาณ 6 จุด แต่ตุ้มหูมีเพียงแค่ 2 ใน 6 สรุปคือมันสุ่มครับ ต้องวิ่ง ๆ เอา (แนะนำมีเวสไปด้วย มอนตีแรง-เร็วใช้ได้) หลังจากที่เราเก็บตุ้มหูทั้ง ซ้ายและขวาได้แล้ว เจ้าหญิงจะขายของให้เรา โดยของที่ขายมี3 ชุดดังนี้ครับ (random อีกแล้ว)

** ของทุกชิ้น lv60

Set A
1. ดาบ2มือ เอฟเฟคสายฟ้า passive critical (12/59/38/-)
2. ไม้เท้า (39/-/27/59)
3. ธนู (-/-/53/-)
4. หนังสือ (36/1/1/60)
5. เรเปียร์ (22/37/50/-)
6. กระบอง (mace) (47/26/33/-)

Set B
1. โล่ เอฟเฟค เรืองแสง (21/15) (12/12/5)
2. ไม้เท้า (40/-/26/57)
3. ดาบสั้น (30/48/34/-)
4. หอก (24/35/51/-)
5. หอก 2 มือ (28/38/58/-)
6. ขวาน 2 มือ (57/57/30/-) << อาวุธชิ้นนี้ ถ้าตีเองจะมี skill passive critical ด้วย

Set C
1. ดาบ มือเดียว (35/52/36/-)
2. ลูกคิด (38/-/-/-)
3. ขวานมือเดียว (49/40/35/-)
4. ธนู (-/-/56/-)
5. ไม้เท้า (รูปสายฟ้า) (41/-/28/58)
6. โล่สีฟ้า (23/17) (10/10/6)
