อย่าง small capet (พิมพ์ถูกป่ะหว่า - -*) เนี่ย
ตัวไอเทมรูปมันเหมือนๆ กันหมด แต่มันจะมี (...) กำกับไว้ข้างหลังว่า อันนี้เป็นลายอะไรสีอะไร


ฉะนั้น มันก็เลยเป็นปัญหาตรงนี้อ่ะครับ
ถ้าอ่านญี่ปุ่นไม่ออก ก็เลยจะสับสนนิดๆ
