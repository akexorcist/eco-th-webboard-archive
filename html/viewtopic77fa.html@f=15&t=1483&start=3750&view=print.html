เท่าที่หมารู้มันมีผลเฉพาะไปทุบนะ
แต่ที่ไม่ทราบตอนนี้คือธาตุที่เขียนไว้นี่

1. มันเอา atk ของอาวุธไปคิดเป็น %
2. หรือแปลง atk ทั้งหมดไปเป็น %
3. หรือได้ atk เพิ่มเป็น % ตาม atk อาวุธ
4. หรือได้ atk เพิ่มเป็น % ตาม atk ทั้งหมด

เช่น atk รวม 1000, atk อาวุธ 100, ธาตุ = 5
1. = atk 95 ธาตุ 5
2. = atk 950 ธาตุ 50
3. = atk 100 ธาตุ 5
4. = atk 1000 ธาตุ 50
