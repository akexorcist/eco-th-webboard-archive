การถอด PET ฉับพลันสามารถทำได้โดยการ

1.เปิด Ctrl+Q หรือช่อง Equip ขึ้นมา (สวมใส่ PET ไว้ด้วย )
2.ลาก PET จากช่อง ขึ้นมาไว้ที่ Hot key ( F1-F12 )

พอกด ปุ่ม ตามที่ ตั้งไว้ PET ของเราก็จะกลับไปอยู่ที่เดิมของมัน อย่าง เฉียดฉิว hock:

hock:

เพียงแค่นี้การ เก็บ PET ก่อน จะเสียค่าความเคยชินก็ ไม่ใช่เรื่องยากแล้วล่ะครับ :lol:


PS* ช่อง Hot key ที่ลาก PET ใส่ไว้แล้ว เมื่อเปลี่ยน ชนิด ของ PET ก็ ไม่ต้องลากใหม่อีก ถือว่าสะดวกสบายมากที่สุดแล้วครับและลดอัตตราการตายได้อยากเห็นได้ชัด !! (เท่าที่ผมคิดดู) :idea: :idea: :P
