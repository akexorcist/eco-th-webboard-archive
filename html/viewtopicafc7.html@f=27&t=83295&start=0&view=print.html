จะเป็นการเปิดหน้าต่างแสดงสถานะของ Recycle System
_______________________________________________________________________

อธิบายรายละเอียดในหน้าต่างแสดงสถานะ

1.World Gauge แสดงระดับคะแนนรีไซเคิลรวมกันทั้งเซิร์ฟเวอร์

2.ผลที่จะได้รับเมื่อ World Gauge เต็มได้แก่
    - 基本経験値・職業経験値1.5倍
    (ค่าประสบการณ์เพิ่ม1.5เท่า)
    - カードスロット拡張成功率上昇
    (เพิ่มอัตราสำเร็จในการเจาะสล็อตการ์ด)
    - カードアセンブル成功率上昇＋カードスロット拡張成功率上昇
    (เพิ่มอัตราสำเร็จในการรวมการ์ด และ เพิ่มอัตราสำเร็จในการเจาะสล็อตการ์ด)
    - 武具強化成功確率上昇
    (เพิ่มอัตราสำเร็จในการตีบวก)
3.Recycle Point ของเรา(เมื่อเรามี 2000 Recycle Point สามารถแลก ECO Medal ได้ 1 ชิ้น)
