•STR+VIT สายอึด เพราะว่าอัพ VIT ทำให้อึดกว่าสายอื่น ระยะแรกจะไปได้ไว เพราะไม่ต้องนั่งบ่อย แต่หลัง ๆ จะลำบาก เพราะหลบไม่ค่อยได้ แถมมอนหลัง ๆ ก็ตีแรงใช่ย่อย จึงรับไปเต็ม ๆ เลยค่ะ สายนี้ ><"
•STR+AGI สายพริ้ว เนื่องจากอัพ AGI ทำให้ตีเร็ว หลบได้ ระยะแรกจะเก็บลำบาก หลัง ๆ ก็พอไปได้ แต่พอโดนมอนอัด แทบแย่เหมือนกันค่ะ = =" ลองดูเอานะคะ
