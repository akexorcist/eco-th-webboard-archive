โดย ECO
คือว่าปกติถ้าถือบัตรทองไปคุยวาปทิศตะวันออก แล้วก็จะเข้าไปได้เลยใช่มั้ย

อันนี้เราไปคุยแล้วมันให้บัตรคอนเสิร์ตบุดด้าเบลสมา ก็เลยไปคุยอีก 3 ทิศที่เหลือ

แล้วก็เอาการ์ดสี่ใบไปเปิดประตูกลาง เหมือนตอนทำเควสไปเอาเอเว่นคีย์อะค่ะ

แล้วก็กลับมาคุยกับวาปตะวันออกอีกที ก็ยังเข้าไม่ได้ค่ะ จะทำเควสอาวุธ 90 อะ

แต่ตัวนี้เราผ่านทุกเควสแล้วนะ แล้วก็ไม่ได้รับเควสอะไรค้างไว้

ทำไมไปคุยแล้วมันไม่ให้เข้าล่ะ หรือต้องไปทำเควส "สู่ส่วนลึก ฯ" อีกรอบนึงรึเปล่าคะ
