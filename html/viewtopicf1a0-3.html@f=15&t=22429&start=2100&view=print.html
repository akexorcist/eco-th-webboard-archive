โดย ECO

Decoy
-ทุกเลเวล เสก ร่างจำแลงขนาดเล็ก ได้มากสุด 3 ตัว (เลเวลเป็นตัวกำหนดแค่ระยะเวลาร่าย กับระยะเวลาการคงอยู่ของร่างจำแลง)

-ทุกตัวเลือด HP=1

-เสกออกมา ล่องลอยไร้การควบคุม

-โซลิดใส่ ได้

-มอนเตอร์ ที่มีการตรวจจับ จะไวกับร่างจำแลงมาก ขนาดร่างจำแลงลอยไปไกลแล้ว มอนที่ตีเรายังวิ่งไปหาร่างจำแลงได้

-ถ้าเราโดนมอนโจมตีอยู่ แล้วเรา เรียกร่างจำแลง มอนจะหันไปตี ร่างนั้น

-ถ้ามอนตี ร่างจำแลงตาย มอนที่ตี จะชะงัก (ซักพักใหญ่) แล้วถึงจะหันกลับไปโจมตีคน หรือ ถ้าเป็นมอนเตอร์ที่ไม่โจมตีคนก่อน ก็จะ หยุดโจมตี กลับเป้นมอนสงบปกติ

สรุปว่าสงสัยอะไรอะ ไม่เห้นมีคำถาม แต่น่าจะครอบคลุมที่สงสัยได้
