Serinc เขียน:มาขอความเห็นในนี้แล้วกัน

ชาวนาสาย STR > Vit > Agi จ้า
สายเก็บเลเว่ล
เป้า หมาย คือตีบวกหิน + ปั้นเด็ก

อยากทราบว่า โอนสกิลจาก มาริโอเนส --> อัลเคมิส 4 สกิล อะไรดี =w=


ส่วนตัวผมแล้ว ผมคิดว่า ควรจะเน้นเป็น
Str >> Vit >> Dex มากกว่า

เพราะส่วนมากจากที่เห็นหลายๆ คนบอกมาว่า
ถึงอัพ Agi ไปก็ไม่ได้ทำให้หลบอะไรได้ดีขึ้นเท่าไหร่
สกิลก็ไม่ได้ร่ายเร็วขึ้นเลย

สู้เอามาอัพ Dex ดีกว่า ไม่ใช่เพื่อแม่นอย่างเดียว
แต่เพื่อเพิ่ม Min Atk ไม่ให้ค่าการโจมตีแกว่งมากเกินไปด้วย

ส่วนสกิลนั้น สำหรับผมนะ
อัลเคมิส แน่นอน คงไม่ได้เล่นสาย Mag แน่ๆ
ฉะนั้น สกิลสายเวทย์ อย่าเอามาเลย

ของผมเอามา 3 สกิลก็มี
- มาริโอเนท มาสเตอร์รี่ เพิ่มพลังโจมตี และป้องกัน ในขณะที่เป็น มาริโอเนท
- สกิลเพิ่มระยะเวลาในการแปลงร่างเป็นมาริโอเนท จาก 3 นาทีเป็น 4 นาที
- สกิลลดระยะเวลาดีเลย์การใช้มาริโอเนท จาก 5 นาที ให้เหลือ 3 นาที

3 สกิลนี้ล่ะครับ กำลังดีในความคิดผม
ส่วนอีก 1 ก็แล้วแต่ความชอบครับ หรือจะเลือกอะไรก็ตามใจจ้า

Str Vit เล่นไปแล้วตัวนึง ก็ถึกดีแต่ลงดัน 70 คนเดียวแล้วเซ็ง หลบไม่ได้แล้วมีปัญหาไปหมด def ตัวหลังใช่ว่าจะเยอะเหมือน Fighter เขาอีก = ="

Str Agi ที่เล่นอยู่อีกตัว ก็พริ้วดีลงดัน 70 ก็หลบได้ตามประสาสาย agi ทั่วไป (ตัวไหนสาย agi หลบไม่ได้ก็ตัวนั้นแหละที่ไม่ต้องสู้) เสียแค่มีแค่ blow ให้ใช้ ก็ไม่คิดอะไรมาก blow นำแล้วสับไปเรื่อยๆ

4 skill หลักๆส่วนมากที่ไม่ใช่ mag จะใช้ก็
Marionette Mastery - เพิ่ม atk, def เวลาแปลงร่าง
Marionette Overload - เพิ่มเวลาใช้งาน 1 นาที ใช้ mp ในการร่าย
Managing Mastery - ลดเวลารอแปลงร่างใหม่
skill เสริมก็มี
Puppet - ทำให้เป้าหมายติดเกร็ง ความน่าใช้ก็ถือว่าพอตัวแต่ต้องมี agi และถ้ามี agi สูงพอจนหลบได้ก็ไม่ต้องใช้มันดีกว่าด้วยซ้ำ (vit > agi ก็ถือเป็น skill ที่น่าสนใจ)
Marionette Call + In Soul - ใช้เรียก Tiny Zero มาช่วยสาป ก็ใช้ช่วย tank หรือล่อเป้าได้ แต่บางทีจะซวยถ้ามันซน puppet ดูน่าสนใจกว่า
skill แถมก็มี
Marionette Create - ใช้สร้าง marionette กรณีขี้เกียจปีนหอชั้น 4 บ่อยๆ
Fairy/ Marionette Damage - ใช้ตี spirit หรือ marionette แรงขึ้น แต่ตัว spirit ไม่ได้เยอะมากมายอะไรนัก
Create Figure - ใช้ปั้นหุ่น ถ้าปั้นบ่อยเป็นชีวิตมีไว้ก็ได้ ค่าปั้นมัน "ตัวละ" 1000 อยู่ละ
Change Marionette - กรณีอยากเปลี่ยนร่างไปมาเหมือน ruruie ก็เอา :3
