หลักๆก็ str/vit/dex ไม่ก็vit/str/dex แล้วแต่คน บางทีก็mag/int/vit แต่ส่วนมากอันนี้จะใช้รีเอาหลังจากเปลี่ยนเป็นมารีโอเนตสำหรับคนอยากเล่นสายเวทมารีโอเนต(เล่นลำบากพอสมควร แต่หนุก+แปลกดี)

ตัวที่เคยเล่นตอนเมื่อนานมาแล้วก็ strเกือบล้วนจนเวล60+เลยอัพdexนิดหน่อยพอเริ่มตีวืด เน้นพกมิกจุ๊ย/ซาลาเปา ปั้มเอา เวลจะไวมากๆแต่เปลืองมากๆเช่นกัน หลังๆมอนเริ่มตบแรงก็อัพvitคู่ไปด้วย+ให้petที่เก่งๆคอยชนให้

ส่วนคนที่เคยรู้ว่าเล่นสายถึก(lafara) เค้าจะอัพvitนำstr เล่นแบบตายยากๆช้าแต่ชัวร์(ตีหลายทีกว่ามอนจะตายอยู่) เล่นไปหาของไปอะไรประมาณนั้น เช่นไปพวกดันใต้ตีหาของเพราะมันที่นั่นเวท+รุม มาก(ตัวบางๆไปตายง่าย) เล่นแบบนี้ไม่ค่อยเปลืองอาหาร

สุดท้ายก็แล้วแต่สไตล์อ่าจ้า
