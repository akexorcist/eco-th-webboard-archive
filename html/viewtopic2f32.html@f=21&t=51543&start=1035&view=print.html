ต่อล่ะ แต่ว่าเราไม่ค่อยว่างบ่อยนะซิ
===============================================
นับตั้งแต่วันที่มิกุริกับยาคุออกมาจากดาร์กโซนได้แล้ว(มันกี่วันกัน) ก็อยู่ในหอตามปกติ

จนกระทั่งวันนี้ มิกุริกับยาคุกำลังลงไปที่ห้องอาหารเพื่อหาอาหารทาน แต่ในใจลึกๆของทั้งคู่ยังนึกถึงวันที่เกิดเหตุการณ์ในดาร์กโซนอยู่เสมอ
===============================================

จะเข้าเรื่องก็ได้นะ แต่เราไม่ค่อยว่าง อย่างคืนนี้ต้องไปนอนล่ะ ถ้าจะให้ดีก็อย่าเพิ่งรวมอีเวนท์กันนะ เดี๋ยวเราจะถ่วงอีเวนท์
