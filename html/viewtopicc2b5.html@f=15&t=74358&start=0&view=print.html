elemental analyst
เหมือนแปะ element knowledge ลงไปในมอนส์เตอร์ตัวนั้นอ่ะ
เวลาตายโดยที่ใครฆ่าก็แล้วแต่มีโอกาสดรอปของเหมือนกับมีปราชญ์

origin of spirit
เพิ่มความเข้มของธาตุในระยะ 5*5 ช่องโดยมีตัวเองเป็นศูนย์กลาง
อย่างเช่นยืนอยู่บนพื้นที่เป็นธาตุไฟ ก็จะทำให้ 5*5 ช่องรอบตัวเราเป็นธาตุไฟที่แรงขึ้น
หากว่าพื้นที่บริเวณนั้นไม่มีธาตุ สกิลนี้ก็ยังแสดงผลโดยการกินพื้นที่นั้นๆอยู่
กรณีที่พื้นที่เราเหยีบยมีหลายธาตุจะเพิ่มเพียง 1 ธาตุเท่านั้น
ธาตุที่ถูกเพิ่มความเข้มขึ้นจะมีจุดสีๆลอยอยู่เหมือน sense element
Element Power Circle และ origin of spirit ไม่สามารถวางทับกันได้
