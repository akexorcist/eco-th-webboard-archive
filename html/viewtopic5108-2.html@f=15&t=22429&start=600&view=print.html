สายNVN จะเอาแบบไหนหล่ะ

1.สายยิง ทำเดเมจ MAG DEX INT

2.สายป่วน ตัวโดนหมายหัว (ทีมตรงข้ามหมายหัว) VIT INT DEX ถึก โดนเวทเบา สาปติด
-สกิวที่โดนแล้ว สาป 3 สถานะผิดปกติเลย ร่ายทีเดียว
-บัฟเพิ่ม DEF MDEF
-บัฟเพิ่มความแม่นยำในการสาป

ยังไม่เคยเจอเหมือนกันนะว่าถ้าเล่นสายนี้แล้ว HP จะได้เท่าไร
(แต่อาจะไม่รุ่ง สำหรับคนเก็บเลเวล)

ปล.เวลาNVN แนะนำ ใส่ชุดธรรมดาที่ไม่ช่ายชุดอาชีพ จะไม่โดนหมายหัวมากนัก
