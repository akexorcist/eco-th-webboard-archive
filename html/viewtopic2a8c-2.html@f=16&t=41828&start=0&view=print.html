เราเป็นเทรดเดอร์เวล 65 ต้องไปเก็บเวลไหนดีคะ ลุยเดี่ยวค่ะและบางครั้งก็ไปกับเพื่อน เป็นซอ 78 เวลขึ้นช้ามากค่ะ เราเล่นสายโบลวอยู่ค่ะ ช่วยแนะนำการอัพสเตตัสหน่อยค่ะ อัพมั่วหมดละ ช่วยแนะนำสกิลดีๆให้ด้วนะคะ



ตอนนี้กำลังจะเล่นเรนเจอร์ค่ะ อยากเล่นสายหาเงิน แต่ฝึกหมาทองไว้ อยากเล่นสกิลหมา แต่อยากรู้ว่าสกิลของหมาเช่น สกิล Grinder Attack ใช้กับหมาทองได้ไหมคะ กลัวใช้ไม่ได้ ช่วงนี้เราไปเวลหอแสงให้หมาทองช่วยสู้แต่ตายเร็วมากเพราะโดนเวทย์ อยากรู้ว่าจะฝึกหมาที่ไหนคะให้ทนเวทย์
