มันมี 3 วิธีน่ะจริงๆแล้ว

1.สำหรับคนที่มีบ้านบินไปได้เลย ไม่ต้องซื้อบัตรผ่าน

2.สำหรับคนที่เคยลงทะเบียนสวนลอยฟ้าที่ทอนก้าแล้ว ก็จะสามารถบินได้เช่นกัน วิธีไป

ไปที่อัพทาวน์บริเวณขวาล่าง จะมี npc ที่จะพาเราไปทอนก้า แต่ต้องมีบัตรทอนก้าด้วย

3.วิธ๊นี้สำหรับคนที่ไม่มีบ้านบินต้องไปที่เมืองให้ก่อน และเข้าไปข้างในดันใต้

แต่ไม่ต้องไปชั้น 2 ให้เดินตรงไปเข้าวาปแทน แมพนี้จะมีแต่หิน ถ้ามีมอนแสดงว่ามาผิด

และก็เดินขึ้นไปตามทางจนบยสุด จะมี npc พาเราไปเองครับ อย่าลืมบัตรเช่นกัน
