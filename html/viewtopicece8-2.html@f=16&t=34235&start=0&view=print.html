สกิล Random Healing ของ Gambler อัพอะไรให้เติมแรงขึ้น

โพสต์แล้ว: จันทร์ 07 ม.ค. 2008 11:58 am
โดย ECO
ตอนนี้ผมเอา Gambler สิง นักดาบ ดีมากๆเลย ( Sp มีใช้ตลอดเลย อิอิ )
ถ้าเอา พระสิงอีกตัว ( Hp ก็มีใช้ตลอดเลย โฮโฮ )

ให้ gambler ใช้สกิล Random Healing ( ใช้ MP )
มันจะเติม HP / MP / SP ได้ตั้งแต่ 0-133
( แน่นอนว่าไม่ได้ทุกครั้ง )
แต่ Mp ของ Gambler 1ขีดเต็ม
กดใช้จนหมด ต้องได้ Hp , MP , SP อย่างล่ะไม่ต่ำกว่า 250 แน่นอน
Gambler สิงอยู่รอเดี๋ยวเดียว Mp เราก็เต็มแย้ว

เลยคิดจะเปลี่ยน Status ของ Gamber
1. ไม่แต่ใจว่า อัพ MAG จะทำให้สกิล นี้ แรงขึ้นหรือเปล่า
2. แล้วโอกาสที่จะฮิลติด บ่อยขึ้นต้อง อัพอะไรครับ

รบกวนผู้รู้ด้วยครับ

แรงตาม M.Atk ที่ขึ้นกับ MAG ครับ
ค่าสูงสุดฟื้นฟูได้ (ไม่รวม Recovery) = 1.6*M.Atk+90

ถ้า MAG 100 ก็คงได้ราวๆ 1 พันต้นๆ รวม Recovery นั่นแหละ
ปัญหาหลักคือ เมื่อไหร่มันจะฮีลติดมากกว่า

อัตราการสุ่ม ผมนั่งจับไต๋มันหลายทีก็ยังไม่ได้ คงจะเป็นการสุ่มจริงๆ
อย่างไรถ้าเลเวล 60 มาถือพัด แบบนี้...



จะฮีลได้แรงขึ้นพอสมควรครับ MAG อัพราวๆ 30-40 ก็เหลือเฟือละ
