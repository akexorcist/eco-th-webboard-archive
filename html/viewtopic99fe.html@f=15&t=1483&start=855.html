แก้นิดหน่อยนะ เราพิมสูตรผิดไปนิดนึง

เมื่อโจมตีด้วย 4 ธาตุหลัก
อัตราขยายการโจมตีธาตุ = floor[(100+ผลรวมผลของทั้ง 4 ธาตุ) * (100+ผลของธาตุแสงหรือความมืด) / 100]
เมื่อโจมตีด้วยธาตุแสงหรือความมืด
อัตราขยายการโจมตีธาตุ = 100 + ผลของธาตุใน 4 ธาตุที่มีค่ามากที่สุด + ผลรวมผลของธาตุแสงและความมืด
ผลรวมผลของทั้ง 4 ธาตุ = ผลของธาตุน้ำ + ผลของธาตุไฟ + ผลของธาตุลม + ผลของธาตุดิน
ผลของธาตุใน 4 ธาตุที่มีค่ามากที่สุด หมายถึงให้ดูว่า ผลของธาตุน้ำ,ผลของธาตุไฟ,ผลของธาตุลม,ผลของธาตุดิน อันไหนมากที่สุดให้ใช้ค่านั้น
ผลรวมผลของธาตุแสงและความมืด = ผลของธาตุแสง + ผลของธาตุมืด
ผลของธาตุแสงหรือความมืด อันนี้ยังไม่แน่ใจ..
ผลของธาตุ = floor[ ความแรงของธาตุ * สัมประสิทธิ์สัมภัทธภาพธาตุ ]

ค่าสัมประสิทธิ์สัมภัทธภาพธาตุ
ธาตุที่โจมตี→ธาตุที่โดนโจมตี
สี่ธาตุ→สี่ธาตุ(ชนะทาง) +2/3
สี่ธาตุ→สี่ธาตุ(แพ้ทาง) -1/2
สี่ธาตุ→สี่ธาตุ(ทั้งหมด) -1.0
สี่ธาตุ→แสง +1/3
สี่ธาตุ→ความมืด -1/3
แสง→สี่ธาตุ -1/2
แสง→แสง -1.0
แสง→ความมืด +2/3
ความมืด→สี่ธาตุ +1/2
ความมืด→แสง -1/2
ความมืด→ความมืด -1.0

*floor หมายถึงทำให้เป็นจำนวนเต็มโดยปัดเศษลง

ค่าสัมประสิทธิ์สัมภัทธภาพธาตุ
ธาตุที่โจมตี→ธาตุที่โดนโจมตี
สี่ธาตุ→สี่ธาตุ(ชนะทาง) +2/3 ไฟ ยิง น้ำ โดนแรงขึ้น 165%
สี่ธาตุ→สี่ธาตุ(แพ้ทาง) -1/2 น้ำ ยิง ไฟ ความแรงลดลงเหลือ 50 %
สี่ธาตุ→สี่ธาตุ(ทั้งหมด) -1.0 ไฟ ยิง ไฟ -1 หรือก็คือ ยิง 0 นะเอง สาเหตุที่บางตัว
ธาตุไฟ แต่ยิง ไฟ แล้วยังลดเพราะว่า มีธาตุอื่นประกอบด้วย
สี่ธาตุ→แสง +1/3 (ดิน น้ำ ลม ไฟ) ยิง แสง ความแรงเพิ่ม 130%
สี่ธาตุ→ความมืด -1/3 (ดิน น้ำ ลม ไฟ) ยิง มืด ความแรงจะเหลือ 67%
แสง→สี่ธาตุ -1/2 แสง ยิง (ดิน น้ำ ลม ไฟ) ความแรงลดลงเหลือ 50 %
แสง→แสง -1.0 0 นะ
แสง→ความมืด +2/3 โดนแรงขึ้น 165%
ความมืด→สี่ธาตุ +1/2 โดนแรงขึ้น 150%
ความมืด→แสง -1/2 ความแรงลด เหลือ 50 %
ความมืด→ความมืด -1.0 0 นะ
