สกิลทั้ง 2 อย่างเเตกต่างกันอย่างไรหรอครับผมได้อัพไปเเล้วเเต่ว่าสกิล Trust ที่สามารถขายของได้เเพงขึ้น สกิล นี้ไม่มีผลเลยครับ เหมือนจะไม่ได้ช่วยอะไรเลยครับ

ขอบคุณครับ

OC = เพิ่มราคาขายสินค้าต่อชิ้น เช่นสินค้า A ขายได้ 1000 ถ้าOCเต็ม จะขายได้ 1440

Trust = เพิ่มขีดจำกัดการรับซื้อของ NPC เช่น NPC A รับสินค้าราคาสูงสุดที่ 2000
ถ้านำสินค้าที่ราคาขายเกิน 2000 ไปขาย มันจะเป็นสีเทา(ขายไม่ได้) ถ้าอัพ Trust
จะทำให้ขีดจำกัดการรับซื้อสูงขึ้น เช่น ทำให้ขายของที่มีราคา 3000 กับ NPC A ได้
แต่ไม่ได้ช่วยเพิ่มราคาขายของสินค้าแต่อย่างใด
