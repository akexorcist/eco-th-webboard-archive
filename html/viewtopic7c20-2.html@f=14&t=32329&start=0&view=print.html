ผมก็เล่นสาย vit ครับ แล้วก็ ส่วนตัวผมคงไม่อัด vitจนสุด แหะๆ

คือ def ซ้ายได้50ก็แจ๋วแล้วครับ ตอนนั้นวิทคงประมาณ80กว่าๆมั้ง

ผมอ่านจากไกด์ของเฟนเซอร์มาครับ หน้าแรก def ซ้าย ขวา

ซ้าย เป็นเปอร์เซ็นต์ ขวาเอามาหักลบจริงๆ รายละเอียดลองไปอ่านดูนะครับ

(เครดิตให้เจ้าของไกด์ด้วยุ) 50เปอร์เซ็นต์ หุหุ โดนน้อยลงไปครึ่งนึงเลย

:wink: ยิ่งเป็นไนท์นะครับ อึดดี ส่วน M.defซ้าย อัพ int ครับ

ถ้ามีแต้มเยอะ จะลงมันจริงๆนะเนี่ย vit int เนี่ย แต่เวทมันแรงเป็นทุนอยูแล้วนี่หว่า
