แล้วshamanอ่านว่า ชาแมน หรือชามังอ่ะ


ว่าจะพูดเรื่องนี้มานานล่ะ
shaman ถ้าอ่านตามแบบอังกฤษ จะได้ ชาแมน แต่ถ้าอ่านแบบญี่ปุ่นจะได้ ชามัง

ว่าด้วยเรื่องของตัว ん(ฮิระ) / ン(คะตะ) (-n)
ถ้าเขียน shaman เป็นตัวญี่ปุ่น(คะตะ)จะได้　シャマン　ตัว ン จะอ่านออกเสียงได้ 3 แบบค่ะ
-น -ม -ง
ซึ่งจะออกเป็นแบบไหนนั้นขึ้นอยู่กับคำแต่ละคำที่ตัวンไปอยู่ด้วย ในกรณีนี้ จะออกว่าชามังเนื่องจากคำส่วนใหญ่ที่ตัวンลงท้ายจะออกเสียงเป็น -ง
ส่วนอีก2เสียงล่ะ จะยกตัวอย่า
งให้ค่ะ
-น เช่น せんせい sensei แปลว่า ครู
-ม เช่น せんぱい sempai แปลว่า รุ่นพี่

ตอนนี้ไม่ค่อยว่างเท่าไหร่ถ้าอยากรู้เพิ่มดึกๆจะมาบอกวรรคแต่ละวรรคจะเป็นเสียงอะไร (ถ้าอยากรู้เพิ่มนะ)
