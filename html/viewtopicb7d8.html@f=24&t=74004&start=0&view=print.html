June Bride Event ปี3

เริ่มแรกต้องมี Bounquet of Love ช่อดอกไม้สีแดงๆ หาได้จากต้นดอกไม้บนเกาะไทนี่นั่นเอง จากนั้นไปคุยกับเครื่องทำสายรุ้ง
   
   

พอเข้ามาในโบสถ์ ให้มาคุยกับ NPC Command Frog จากนั้นเหล่าตัวโน๊ตทั้งหลายจะหายไป และให้เราออกตามหา
   
   
     อันนี้ เลือกอันไหนก้อได้
      รับเควส

เดินขึ้นไปที่แท่นรูปหัวใจเพื่อเข้าไปตามหา Sound Pururu's Egg [Do~Si]
   

พอได้ครบทั้ง 7เสียงแล้ว เอามามอบให้ NPC Command Frog
   

เย้ๆ ได้ของตอบแทนแล้ว เป็น Cutie Tadpole
   
   
แต่ยังไม่หมดเท่านี้ มาคุยกับ คู่รักข้างๆ NPC Command Frog ต่อ
   
เค้าจะให้เลือกของรางวัล 1ชิ้น เป็นกางเกง และ กระโปรงสีต่าง
   

ปล. ครัยที่มี Sound Pururu's Egg เหลือเยอะๆ เอาไปแลก หัวตัวโน๊ตได้น้า 10อันต่อ1หัว แลกกะเหล่าปูรูรูตัวโน๊ต ตามเสียงที่มี
