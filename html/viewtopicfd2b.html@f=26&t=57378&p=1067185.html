คือว่าผมอยากทราบว่า
ไอเทม Rotary Sail Set นี้นี่หมายถึงมาทีเดว 6 ใบเลยป่ะครับ
แล้วผมอ่านในไกด์บอกว่าดรอปจาก คอนเทนเนอร์ 1
(แล้วคอนเทนเนอร์1นี่อยู่ที่ไหนคับผมไม่ทราบจิงๆ)


อันนี้คือวิธีทำทีละใบเรือ
- Log :: 1 (ผมคิดว่าคงหาซื้อได้ไม่ยาก)
- Waterproof Fabric :: 5 (หามาจากไหนอ่ะครับเนี่ย บอกผมทีครับ)
- Wood :: 5 (ซื้อเอาก้ได้)
- Great Steap :: 5 (คืออะไรหรอครับ หาได้ยังไง แมพไหน บอกผมทีนะ)

Sail Set จะมาทั้ง 6 อันเลยครับ ( คือ ประกอบแล้ว )

อันนี้คือวิธีทำทีละใบเรือ
- Log :: 1 (ผมคิดว่าคงหาซื้อได้ไม่ยาก) ราคาอยู่ราวๆ 60-80k
- Waterproof Fabric :: 5 (หามาจากไหนอ่ะครับเนี่ย บอกผมทีครับ) ใช้ Greater Cloth + 4 Row ( สกิลเย็บปักของชาวนา หรือป้าร้านตัดเย็บ)
- Wood :: 5 (ซื้อเอาก้ได้)
- Great Steap :: 5 (คืออะไรหรอครับ หาได้ยังไง แมพไหน บอกผมทีนะ) มันคือเชือกครับ ใช้ Great Thread 4 อัน
