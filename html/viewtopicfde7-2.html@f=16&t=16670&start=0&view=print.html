สาเหตุที่ไม่มี recipe เพราะว่า
Melody hammer ที่สร้างได้กับเปิดกล่องได้ เป็นคนละชนิดกัน

ถ้าเป็นแบบที่เปิดกล่องได้ จะเป็น melody hammerโง่ๆ ที่ไม่มีติดความสามารถ Critical up

แต่ถ้าเป็นแบบที่สร้างเอง จะมีสูตรส่วนผสมแสดงให้ดู และมีความสามารถ Critical up

เวลาซื้อเลือกดูให้ดีด้วยนะครับ มันต่างกันเยอะเวลาเอาไปใช้งาน

(อาวุธกลุ่ม Mace เลเวลหลังๆจะมีบางอันเป็นแบบนี้เหมือนกัน คือสร้างเองแล้วจะมี Critical up ขณะที่เปิดกล่องหรือซื้อร้านแล้วจะไม่มี)
