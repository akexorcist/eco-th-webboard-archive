มาขอตอบ~~
มันไม่ได้แรงขนาดเป็นหมื่นอ่ะ (= ="

ถ้าบอกว่าเบากว่า Plurality อันนี้ไม่จริง...คืิองี้

Blast ยิงนัดเดียว แต่ดัมเมจพอๆ กับ Plurality
ฺBlast ถ้า miss หรือ avoid ก็ไม่มีดัมเมจเลย...แต่ Plurality มันยิง5นัด น่าจะโดนสักนัดอ่ะ
ฺBlast ใช้เวลาร่ายเท่ากับ Plurality
ฺฺBlast ไม่มีดีเลย์ยิงซ้ำๆ ได้เลย แต่ Plurality ยิงแ้ล้วต้องรออีกแป้บนึงถึงจะต่อได้

สรุปคือ ดัมเมจพอๆ กันแหละ ...แต่ Blast ไม่เปลืองลูกธนู ยิงเร็วกว่าด้วย แต่เวลา miss แล้วมันชอกช้ำ 5555+

ที่เห็นเป็นหมื่นๆ ในภาพนั่น เค้าว่ามันต้องอาศัยหลายอย่างนะถึงจะได้ขนาดนั้นอ่ะ (= ="
ปกติยิงได้ 5000 ก็กระโดดดีใจแระ

ถ้าจะยิงแรงๆ ตามภาพได้นี่ต้องตามนี้เลย
- ใช้ธนูเทพๆ หน่อย หัวเสือบวก str อะไรใส่ให้เต็ม!!
- ไปยิงตัวที่ def น้อยๆ แต่ดูเอามาโชว์ได้เช่น แบนดิต (ตามภาพ)
- ติดตั้งธนูธาตุที่ได้เปรียบ เช่น ยิงแบนดิตที่ฟูิจิกิด้วยธนูน้ำ (ตามภาพ)
- สร้างปาร์ตี้ที่มีตัว str อยู่รวมกันเยอะๆ (อัพสกิว combine force จะได้เก่งขึ้นตามปาร์ตี้)
- ใส่ soul ที่บวก str ให้เต็มตัวอ่ะ
- ให้คนอื่นสาปเป้าหมายให้ผิดปกติ (อัพสกิว arrow damage)
- ให้พระมาเล่นดนตรีลด def ของเป้าหมายลงอีก (ตามภาพ)
- ยิงจ่อๆ ระยะประชิด (ตามภาพ)
*** ถ้าพร้อมตามนี้แล้วก็ซัดด้วย blast arrow เลย (ที่อัพ stike arrow แล้ว)

ได้ตามภาพชัวร์~~~
