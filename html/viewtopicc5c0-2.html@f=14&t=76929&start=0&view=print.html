กระทู้เดิม แต่เปลี่ยนเนื้อหา

หน้าไม้ 70 + อัณญมณี ธาตุ
ไฟ - Ruby
น้ำ - Aquamarine
ลม - Topaz
ดิน - Emerald
ไปหา ภูติ ธาตุ

เราจะได้หน้าไม้ ธาตุนั้นๆ มา

เราแนะนำ สำหรับ อาเชอร์ ทุกๆคน
เพราะการเปลี่ยนหน้าไม้ ธาตุ จะ เพิ่ม ธาตุ ในการโจมตี ถึง 150
เนื่อจาก ช่วงนี้ ในไทยเกิด บัค ลูกดอก ธาตุ + 100 อยู่
เราได้ข่าวมาว่า ซาก้า หน้า มันจะ เหลือ 25
เพราะ ฉะนั้น ช่วงนี้ ถ้าใช้ ลูกดอกธาตุ + หน้าไม้ธาตุ ไม่รสมการ์ด จะ เพิ่มธาตุ โจมตี ได้ถึง 250 เลยทีเดียว

ดังนั้น นิสัยคนไทย โกงได้ โกงเอา รีบๆ กอบโกย เวล ซะ ก่อน มันจะ ปรับ เหลือ 25 นะ
