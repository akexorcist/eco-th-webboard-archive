DonutLove เขียน:- Transmission Served
สาเหตุ - เกิดจากปัญหาการเชื่อมต่อของ internet ซึ่งสามารถเกิดได้หลายอย่างเช่น
• program Anti-virus ต่างๆ
วิธีแก้ไขเบื้องต้น - ปิด program anti-virus ให้หมดก่อนทำการ download patch
ถ้ายังไม่ได้ทำตาม step เทพนี้ ... เปิด anti-virus ให้หมด - ลบตัวเกมแล้วลงใหม่ - download patch
• firewall ต่างๆ
วิธีแก้ไขเบื้องต้น - ปิด firewall เช่นกัน ซึ่ง firewall นี้จะอยุ่ในหลายๆที่เช่น ตัว window เอง หรือตามโปรแกรม anti-virus ต่างๆ ปิดให้หมดก่อนทำการ download patch
• internet ที่ทำการ share กับเครื่องอื่นๆ ... ส่วนนี้จะมี 2 ปัญหานะครับ
internet(1) - เมื่อทำการ share แล้วจะทำให้ speed หรือความเร็วตกลง หรือขาดตอนในบางช่วง ซึ่งมีผลทำให้ไฟล์เสียหาย หรือไม่ครบ เป็นเหตุให้เกิด transmission served ได้เช่นกัน
วิธีการแก้ไขเบื้องต้น - uninstall เกมออก .. ใช้ internet ที่ไม่ต้อง share กับคนอื่นเพื่อให้ได้ speed ที่คงที่
internet(2) - สำหรับ wireless ต่างๆ ที่ถูก share ในหอพักหรือตามมหาวิทยาลัยต่างๆ จะมีการ block port ต่างๆไว้พื่อความปลอดภัยนะครับ ไม่ให้ download หรือติดไวรัสมาลงทั้งระบบ
วิธีแก้ไขเบื้องต้น - บอกให้ผู้ดูแลเปิด port 21 สำหรับการ download patch และ port 12000 สำหรับการเล่นเกม
• hardware - อุปกรณ์ การเชื่อมต่อต่างๆ
ส่วนนี้ ทีม GM เจอกับตัวเองเลยครับ ว่า set ทุกอย่างเรียบร้อยพร้อมที่จะ update patch แล้ว internet speed ก็ไม่ช้า แต่ว่ายังขึ้น transmission served อยู่ ?
วิธีแก้ไขเบื้องต้น - ให้ทำการเช็คอุปกรณ์การเชื่อมต่อต่างๆ (โดยเฉพาะสายแลน ) ว่าสมบูรณ์ดีหรือเปล่า เพราะไม่ไม่งั้นแล้ว จะทำให้การเชื่อมต่อไม่ลื่นไหลและมีปัญหา transmission served ครับ
