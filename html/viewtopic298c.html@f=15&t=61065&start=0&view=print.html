ผมยังไม่ค่อยเข้าใจเกี่ยวกับแพ้ธาตุชนะธาตุเท่าไหร่

1. กรณีที่รับการโจมตีธาตุมืด
ระหว่างเกราะแสงที่เป็นธาตุที่ชนะกับเกราะมืดที่เป็นธาตุชน
อันไหนจะป้องกันการโจมตีจากธาตุมืดได้ดีกว่ากันคับ

2. ใส่เกราะทุกธาตุพร้อมๆกัน ดี หรือว่าไร้ประโยชน์คับ
มันหักล้างกันหรือเปล่า เพราะโดนโจมตีมาธาตุนึง
เราก็จะมีธาตุนึงลดการโจมตี แต่ขณะเดียวกันก็มีธาตุที่แพ้อยู่
มันจะหักล้างกันเหมือนไม่ได้ใส่อะไรเลยหรือเปล่าคับ

3. ได้ยินเค้าพูดๆว่ากันว่าแมปนี้ดิน 45% หรือมอนตัวนี้น้ำ 25%
พวก % ทั้งหลายที่เค้าว่ามานี้มันดูได้จากไหนคับ

^ ตอบให้นะเท่าที่รู้
1 คือ น่าจะแสงป้องกันมืดได้ดีกว่า มืดป้องกันมืด แต่ดันใต้ชั้นสามมีพื้นที่เป็นธาตุมืด ถ้าเรามีเกราะมืด จะป้องกันธาตุมืดได้ 100% คือโดนยิงเวทใส่ลด 0 นั่นเอง

2 การหักล้างของเกราะธาตุ ไม่แน่ใจมีผลใหม แต่คิดว่ามีนะ แต่ประโยช์ที่เราเห็น คือถ้าเป็นแมพธาตุดินแล้วบัฟโล่ลม เราจะป้องกันเวทธาตุลมได้ 100% คือโดนยิงเวทธาตุลมใส่ลด 0 นั่นเอง

3 ไม่แน่ใจนะ บางเมพมีหลายธาตุ เช่นดันใต้ชั้นสามครึ่งฉากล่างเป็นไฟ อีกครึ่งเป็นมืด แมพประสาทผี เป็นเป็นดินกับมืดปนกันทุกจุด แมพดันฟาอีสเป็นแมพที่มีทุกธาตุผสมกันทุกจุด และการแพ้ธาตุของมอนเตอ ส่วนใหญ่คิดจากพื้นที่ธาตุจ้า
