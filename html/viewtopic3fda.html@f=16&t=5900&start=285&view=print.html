ใช่จ้า
Str : เพิ่มความรุนแรง
Int : เพิ่มความแม่นยำ และ min atk (ความรุนแรงขั้นต่ำ ทำให้แกว่งน้อยลง)
Agi : เพื่อความเร็วในการใช้สกิลต่างๆ
Vit : เพิ่ม เลือด และความถึก (หากมีพระไปด้วย และเล่นชำนาญแล้ว คงไม่ต้องอัพ เพราะเราใช้ไพ่ปา ก็ไกลพอควร เลยไม่ค่อยโดนมอนตีเท่าไหร่)
Mag : เพิ่มความแรงเวทย์ (เอาไว้ใช้ท่า Random Healng)

ส่วนไพ่แต่ละแบบ atk นั้นต่างกัน น้ำหนัก และราคาก็ต่างกัน
