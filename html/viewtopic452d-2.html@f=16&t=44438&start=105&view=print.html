เส้นทางที่ง่ายดายและน่าเบื่อแต่ปลอดภัย
เวล49หากยังไม่เปลี่ยนอาชีพเป็นEXหรือTH(หวังjob50)แนะว่าให้ไปตีขนนกดำแถว
เมืองเหนือครับเพื่อเก็บเลเวลและของทำเควสประจำอาชีพเลเวล44ไปส่งเควสเรื่อยๆ
วิธีนี้ไม่ยากแค่เพียงพยายามอย่าให้โดนรุมเกิน2ตัวก็พอครับ ถ้าโดนรุมก็ให้หนีออกมาหรือ
กางเต็นท์แล้วหลบซะ(ถ้า) ฟาดเก็บของเควสส่งและตีมอนแถวนั้นเก็บเวลเรื่อยๆก็จะจอป50เอง
กรณีเปลี่ยนเป็นEXหรือTHแล้วก็ไปเก็บเวลพร้อมกับทำเควสประจำอาชีพเลเวล49ได้เลย
ไม่เกินความสามารถแน่นอน

เส้นทางที่ยากและเสี่ยงตายแต่ท้าทายความสามารถ
วิธีนี้เหมาะกับคนมีฝีมือซักหน่อย ยิ่งถ้าคุณเป็นแรนเจอร์ที่ส่งเควสประจำอาชีพเป็นกิจวัตร
ไล่ตามระดับเลเวลมาจนถึง49รับรองว่าไม่ยากเกินแน่แต่ก็ค่อนข้างยากอยู่
วิธีคือให้เราหาของเควสประจำอาชีพเลเวล49หรือไปตีหมีดำกับคิเมร่าเพื่อหาของเควสนั่นเอง
ขอบอกแค่ตอนเป็นแรนเจอร์ที่ยังไม่เปลี่ยนอาชีพเท่านั้นเพราะเปลี่ยนแล้วมันง่ายมาก
วิธีนั้นอยู่กับว่าเราอัพstatusกับskillยังไงนั้นเอง
มีBlowหรือBanish Blow - ให้ดูครับว่าความเร็วกับพลังโจมตีเรามากแค่ไหนทุบศัตรูตายได้
ในกี่ทีโดยคำนวนให้เราทุบศัตรูตายก่อนเราตาย(แหงเดะ)
มีGrass trap - หากใช้ชำนาญให้วางดักแล้วล่อให้หมีดำหรือคิเมร่าเดินเข้ามาเหยียบ
ถ้ายังไม่ชำนาญให้รอมอนมันโจมตีเราก่อนแล้ววางกับดักแล้วเดินถอยไปก้าวนึงให้มอนเหยียบ
กับดักนี้ใช้ฆ่าใครไม่ได้แต่มันจะลดเลือดราว1/4ของที่มอนมีเหมาะเอาไว้วางเปิดเกมหรือ
ใช้กับมอนที่ตัวหนาหรือเลือดเยอะแล้วทุบซ้ำให้ตายแต่ใช้กับมอนที่บินไม่ได้
มีThrow Dirt - กรณีเราเล่นสายเอจิหรือสายผสมแล้วมีเอจิสูงพอให้ลองปาใส่หมีดำกับ
คิเมร่าดูครับโดยถ้าติดล่ะก็ความแม่นยำจะลดลงไปมากแต่ข้อเสียคือมีดีเลย์เยอะพอควร
ต้องดูก่อนใช้ครับว่าใช้แล้วเราหลบได้เยอะขึ้นคุ้มกับที่ใช้รึเปล่า
มีPit Trap - ข้อเสียเหมือนกับGrass trapคือเราต้องชำนาญการวางพอควรและใช้กับดัก
Traptoolในการใช้แต่ละครั้งเสมอวิธีวางก็เหมือนกัน แต่ดีกว่าตรงที่ถ้าศัตรูติดแล้วมันจะนิ่งเลย
ให้เราตบฟรีได้หลายที
มีCamp - ถ้าอัพไว้เลเวลสูงๆหรอืเต็มให้กางเต็นท์ไว้ในจุดที่เราเข้าได้สะดวกครับเหมาะมาก
กรณีไม่อยู่หน้าจอหรือไว้หลบเข้ามาตอนกำลังแย่ หากใช้บ่อยก็ควรอัพเลเวลสูงๆไว้เพราะ
จะทำให้เต็นท์พังยากขึ้น

*ที่พูดข้างบนสำหรับแรนเจอร์เวล49ยังไม่เปลี่ยนอาชีพเท่านั้นแต่ประยุกต์ใช้ได้

หาสถานที่เก็บเลเวลไม่ได้ทำยังไงดี?
ง่ายๆครับสำหรับอาชีพเราคือให้ไปเปิดเควสประจำอาชีพดูจากranger masterซะ
ที่เก็บเลเวลของเราคือเควสประจำอาชีพอันบนสุดเสมอ เก็บมอนแถวที่เก็บของเควสนั่นแหละ
ยกเว้นเควส39และ49จะค่อนข้างยากสักหน่อย(หากยังไม่เปลี่ยนอาชีพ)และเควส69ที่
ยากมากพอสมควรหากไปคนเดียวและโครตยากถ้าฝีมือไม่พอ(ไม่ใช่เลเวล)


ส่วนวิธีของเราจะนานกว่า เสี่ยงตายกว่าด้วย คือลงดันน้ำแข็ง เก็บไพ่ ไทนี่ แล้วก็หากล่องไปด้วย กับทะเลทรายล่า tentacle กับกล่อง
