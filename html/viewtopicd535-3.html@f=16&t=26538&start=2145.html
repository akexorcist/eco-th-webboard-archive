ฝึกไก่อย่าลืมปั้นซอด้วยนะ..

เพราะเราดันฝึกโดยแรกๆให้ตีหินที่เมืองใต้ มันก็อัพไวดีอยู่หรอก เสียอย่างเดียว มันอัพแต่โจมตี เลือดยังกระจึ๋งนึงอยู่เลย พอเอาไปสู้กับ ปุรุรุ อาเชน หนอนเขียว มันก็ตีทีเดียวตาย แต่เอาไปสู้กับมอนที่เวลสูงกว่านี้ก็โดนตีทีเดียวตายเหมือนกัน ฝึกยากมากมาย

สุดท้ายหันไปพึ่งเกราะ 0 ของซอน่าจะเวิร์คอ่ะ ไม่ก็รอให้ป้าคีตินขายขนมเพิ่มพลังป้องกัน >w<

เวลหลังๆสกิลgoไม่ค่อยมีประโยชน์นะถ้าใช้เก็บเวล เพราะสัตว์เลี้ยงเรามีค่าMaxในการฝึก แต่มอนเวลหลังๆมีแต่ตัวตีแรงๆเลือดหนาๆ อย่างหมาเราที่ว่ามันก็เกือบmaxทุกค่า ยังตีหุ่นดัน70ไม่ค่อยไหวเลย วาซาบินี่ไม่ต้องพูดถึง

ถ้าเอามาชามมิ่งแล้วให้ตีก็ไม่คุ้มเพราะเราเคยเอาวาซาบิชามมิ่งมาตีกะวาซาบิธรรมดา มันตีกันนานมากกว่าเลือดจะใกล้หมด เหมือนนั่งดูคู่มวยผักทะเลาะกันมากกว่า

ส่วนในnvn พอชามมิ่งใส่คนได้แล้วส่งผลให้คนตายและเราได้วิญญาณมาเป็นสัตว์เลี้ยง(ขอเรียกวิญญาณนะเพราะร่างมันกองที่พื้นนิ) ถ้าคนนั้นเกิดใหม่ตัวชามมิ่งมันจะหายไป(ไม่แน่ใจ..ใช่เปล่าอ่ะ) ถ้าเป็นอย่างนั้นเราว่าไม่ทันได้ใช้โกหรอกมั้ง
