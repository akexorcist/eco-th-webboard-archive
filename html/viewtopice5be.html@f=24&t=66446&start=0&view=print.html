ค่าชื่อเสียงเพิ่มได้จากการทำเควสต์ที่ต้องเสีย Quest Point ทุกชนิดครับ

หากทำเควสต์สำเร็จจะได้เพิ่มทีละ 1 แต้ม

ค่าชื่อเสียงเป็นเงื่อนไขในการรับ Event แต่ละอย่าง (เช่น Event เนโกะมาตะ หรือ Event เทศกาล)

ซึ่งระบบนี้ทางญี่ปุ่นสร้างขึ้นมาเพื่อไม่ให้เกิดการปั้นตัวทำ Event กันน่ะครับ


สามารถเช็คดูชื่อเสียงตัวเองได้จากหมอดูเมือง Iron South
แต่มันจะบอกเป็นคำพูดไม่ได้บอกเป็นแต้ม
