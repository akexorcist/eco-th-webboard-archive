PET Carrot - Radish mandrake

1 ใน pet ที่ทุกคนบอกว่าเก่งและโกงกับสกิล plant healing ของมันในตอนที่ยังไม่มีดรอบ

และเกือบจะไม่มีทางตีดรอบจากในเกมอีกแล้ว ( ถ้า onenet ไม่แก้บัค )

และเป็นหนึงใน PET ที่กำลังจาสูญพันธุ์ ( เนือ่งจากไม่เห็นมีคนใช้กันเลย )





ข้อดี

1. ฮีลเจ้าของได้

2. น่ารัก

3. ทนเวทสูงมาก ( ถ้าฝึกดีๆ )

4. ฝึกง่าย ( มานโจมตีเบาและหลบไม่ได้เรยอัพเร็ว )

ข้อเสีย

1. ตายง่ายมากถ้าโดนตีแล้วฮีลหรือเก็บไม่ทัน

2. โดนโจมตี physical แรงมาก ( Def น้อย )

3. เสียงเดินน่ารำคาญมากๆๆๆๆๆๆๆ


SKILL ที่แน่ะนำให้อัพ

1.

อัพให้เต็มเลยคับ ใช้ได้ทั้งฝึกไชเท้าและใช้ในการต่อสู้ ฮีลตัวเองอยู่กะที่เฉยๆ

ก้ออัพได้น่ะคับ

ที่ LV 5 heal 300%




รูป 1. แครอทฮีลเวล 5 รูป 2. ไชเท้าฮีลเวล 5

รูป 3. ไชเท้าเลี้ยงเต็มแล้วฮีลเวล 5 รูป 4.ไชเท้าเลี้ยงเต็มแล้วบัพเร่งคับ

( คิดจากค่า status vit ผม 55+14 น่ะคับ )


2.

อัพไว้ Lv 1 หรือ อัพ Go แทนก้อได้คับ ของผมอัพเอาไว้สั่งตีแทน Go คับ

ปล. 1 ผมคิดว่าผมไม่คิดจาเลี้ยง pet ตัวอื่นนอกจาไชเท้าเรยไม่อัพ Go คับ

ปล. 2 พอใช้สกิลนีไชเท้าเราจาตีมอนต่อเลยคับ และจาช่วยฝึกเพิ่ม Mag ด้วย


3.

สกิลนี่จาช่วยเราในตอนที่ฝึกไชเท้าตอนแรกๆคับ ทำให้เราทนต่อการโจมตีได้ดี

ถ้าคิดจาเลี้ยงไชเท้าให้สบายๆแล้ว ก้ออัพไปเถอะคับ


4.

สกิลนี้เป็นสกิลสำคัญสำหรับใช้ในการต่อสู้คับ เพราะมันจาทำให้ไชเท้าฮีล

เราแรงขึ้นอีก อัพเต็มไปเลยคับ

5.

สกิลนี่ทำให้เราเลี้ยงไชเท้าหรือสัตว์เลี้ยงอื่นๆได้ด้วยนะคับ


ปล. สกิล rose whip ผมไม่ค่อยโดนใจอ่าคับเพราะว่าค่า physical atk มานนอ้ยอ่าคับ

และก้อผมเอาไปตีมอนเวลสุงๆหลังๆก้อไม่สะกิดเรยอ่าคับ และอย่างเก่งมานก้อจา

เป็น physical atk 48 + 100 + 60 แค่นั้นเองอ่าคับ รวม atk = 208 คงเอาไปตี

มอนหลังๆไม่ได้อ่าคับ



ค่า status สูงสุดของไชเท้านะคับ




ค่า status ต่างๆอัพยังไง ( ผมแนะนำให้ไปดูกระทู้ของคุณ sarawutss คับ )

http://board.onenet.co.th/viewtopic.php ... 1%A7%A1%E3


วิธีการเลี้ยง

ผมแน่ะนำอยู่ 2 แมพน่ะคับ

1. แมพ หนอนม่วง แมพนี้มีข้อดีคือมีมอนที่กระจอกอยู่เยอะคับ ตีง่าย (แนะนำฝึกแมพนี้ก่อน)

2. แมพ nursery corridor ในนี้ชั้น 3 มีมอนเวทเยอะคับไปฝึกแล้ว M.def และ M.resist

จาขึ้นเร็วมาก (ถ้าเก่งแล้วก้อค่อยมาฝึกชั้นนี้คับ)


TacTic การเลี้ยง

1. ไชเท้าลาก ให้เราใช้สกิล Go (ที่มานมีให้อยุ่แล้วในแมพ) ตีมอนเสตอร์แล้ว

กด comeback แล้วไปตีตัวอื่นต่อคับ (ก้อคงรู้ๆกันอยู่แล้วอ่าคับ)

2. ผู้เล่นลาก ก้อให้เราวิ่งล่อมอนที่เราต้องการจาฝึกด้วยพอได้จำนวนที่พอใจแล้ว

ก้อกด ให้ไชเท้าฮีลตัวเราเอง ที่นี้มอนก้อจามารุมไชเท้าเราแล้วคับ

(ใช้ได้ทั้งการลากนกแมพหนอนม่วง และ ลากมอนในชั้น 3 ของแมพคอริดอคับ)

3. กดโจมตีด้วย plant poison ไปเรื่อยๆคับ เพราะจาทำให้ เพิ่มโอกาสในการอัพ Mag

4. ฮีลตัวเองหรือคนในตี้เรื่อยๆคับ (ไชเท้าจาอัพค่า Mag ได้ต่อเมือใช้สกิลอะไรก้อได้

ที่ไม่ได้ใช้กับตัวเองคับ เพราะฉะนั้น ไชเท้าจาไม่อัพค่า Mag จากการฮีลตัวเองและ

บัพตัวเองด้วยสกิล change)


การใช้ PET ในการต่อสู้


- แนะนำให้ใช้ มาริโอเนต inmouse น่ะคับ (เหมือนกับทีคุณ busluv พูดหล่ะคับ)

และใช้ไชเท้าฮีลไปด้วยในการต่อสู้ช่วงพักก็กดโทนิกเอาน่ะคับ


- เมื่อไชเท้าที่เลี้ยงเต็มที่แล้วโดนโจมตีด้วยเวท - พลังป้องกันเวทเยอะมากคับ




ค่า status ไชเท้าผมน่ะคับ ล้มไป 3 ครังน่ะคับ






ขอสารภาพวิธีฝึกไชเท้าของผมนิดนึงคับ

1. ช่วงแรกไปตีในแมพอินทีเรียคอริดอชั้น 3 คับจน ค่า phy.atk M.def กับ M.resist

เต็มคับตอนนี้ hp จา + ประมาน 300 คับ


2. ช่วงนี้หลังจากนั้นผมมานั่งฮีลตัวเองทั้งด้วยกดมือ และ ก้อใช้ออโต้เมาส์ช่วยด้วยคับ

(มานอึดอัดเหมือนกันคับ รู้สึกเหมือนหลอกคนอ่านกระทุ้ยังไงไม่รู้ เรยสารภาพดีกว่า)

แต่ส่วนใหญ่พอ m.def กับ m.resist เต็ม ก้อจาเอาไปเวลแล้วคับ

ส่วนเรืองความเห็นเรื่องออโต้เมาส์ ผมไม่พูดละกัน แต่ก้อขอให้รู้ว่าไชเท้าที่ฝึกจน

hp + 1006 ผมก้อฝึกมานมาด้วยความรักเหมือนกันคับ



ขอขอบคุณ คุณ colamed ที่ใช้สกิล first aid น่ะคับ

ขอขอบคุณ คุณ Yugaiya ที่ช่วยกันบอก tactic ฝึกไชเท้าด้วยน่ะคับ
