คือสงใสสกิล Rose Whip กับ Plant Poison อะค่ะ

ว่า Plant Poison ที่ว่า เป็นการสั่งให้พืชที่มีชีวิตโจมตีด้วยการใช้พิษ นี้แรงกว่า Rose Whip ทีเป็นการสั่งให้พืชที่ยังมีชีวิตอยู่โจมตีด้วยการทิ่มแทง หรือ Rose Whip แรงกว่า ค่ะ

แล้วความแรงต่างกันแค่ไหน

Rose Whip แรงมากแค่ไหน ค่ะ

สุดท้าย พิษนี้เป็นแบบไหน ระยะการติดนานมั้ย หลังติดพิษแล้ว ลดลงเยอะมั้ย โอกาศ ที่ติดกับมอนทั่วไปสูงมั้ยค่ะ

ถามเป็นชุดไม่ว่ากันนะค่ะสงใสมานาน ข้อมูลที่เจอก็ไม่ระเอียด หรือ ถ้ามีคนลงไงช่วยลงลิ้งไป ไม่ก็ข้อมูลด้วยนะค่ะ

ยังไงก็ขอบคุณไว้เลย...ค่ะ ^^

ปล.ทำมั้ยสมักสมชิกไม่ได้อะนี้เลยต้องขอโมยของคนอื่นมาลงแทนเลยTT
