ตอนล้อกอินเข้าไป ถ้ายังไม่กดใช้ไอเทมโกเลม จะสามารถเดินได้ใช่มั้ยครับ
แต่ถ้ากดแล้วจะมีแสงขึ้นมา แต่ไม่ปรากฎหน้าต่างเลือกหน้าที่การทำงานให้โกเลม
แล้วจังหวะนี้ ทำให้ตัวละครคุณเดินไม่ได้ ทำอะไรก็ไม่ได้ใช่มั้ยครับ


ถ้าเป็นปัญหานี้ ตัวผมเองก็เป็น ไอดีนั้นมีตัวเดียวด้วย เพราะมันถูกสร้างมาเป็นโกเลมโดยเฉพาะนั้นเอง


วิธีแก้ ได้จากพี่ในริงบอกมา

อย่าเพิ่งกดใช้โกเลม ให้ตัวละครของคุณเอาโกเลมนั้นไปใส่ไว้ในคลัง แล้วทำการล้อกเอาท์
จากนั้นล้อกอินเข้าไปใหม่ ก็จะนำโกเลมออกมาใช้ได้ตามปกติครับ
