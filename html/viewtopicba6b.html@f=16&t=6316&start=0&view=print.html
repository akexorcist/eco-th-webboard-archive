ที่นี่เป็นที่รวบรวมสูตร Purify ไอเท็ม เพื่อพี่น้องสายอาชีพ Farmer และผู้สนใจนะครับ

:idea: ทำไมต้อง Purify? การ Purify ไอเท็มคือการแปรรูปไอเท็มคล้ายๆ กับทำอาหารนั่นล่ะครับ (แต่สามารถแปรรูปไอเท็มที่กินไม่ได้ด้วย) สำคัญมากในการแปรรูปไอเท็มบางอย่างให้เป็นวัตถุดิบที่เราจะนำไปใช้ทำอาหารต่อครับ

:idea: Purify ไอเท็มได้ที่ไหน? เราสามารถ Purify ได้ที่ NPC "ช่างหลอมไอเท็ม"(เสียเงิน) หรือจะทำเองก็ได้ถ้าคุณเป็น Farmer, Ranger และอัพสกิล Purify ไว้ (Lv. สกิลเต็มที่ 3 ครับ)

:idea: ถ้าจะ Purify ไอเท็มกับ NPC จะเสียเงินมากมั้ย? จะเสียเงินตาม Lv. สกิลที่ต้องใช้ ยิ่งของที่ต้องใช้ Purify Lv. สูงยิ่งต้องเสียเงินแพงครับ เสียเป็น "ครั้ง" ครั้งละกี่ชิ้นก็ได้ ถ้าของเป็นชนิดเดียวกันหลายๆ ชิ้นก็เสียเงินเท่าเดิมครับ *หมายเหตุ : ของที่ต้องใช้ Purify Lv.1 ไม่ต้องเสียเงินครับ NPC ใจดี ทำให้ฟรีๆ

:idea: เคล็ดลับเล็กๆ น้อยๆ กับการ Purify : การ Purify นั้น นอกจากจะช่วยให้ไอเท็มบางอย่างมีประสิทธิภาพมากขึ้นแล้ว ยังทำให้ไอเท็มนั้นขายเข้าร้าน NPC ได้ราคามากขึ้นอีกด้วย ยกตัวอย่างเช่น Meat(ขายเข้าร้านได้ 30 G) เมื่อเอามา Purify จะได้ Smoke Ham (ขายเข้าร้านได้ 45 G) และต่อให้คุณไม่มีสกิล Purify ก็สามารถจ้าง NPC ให้ Purify ให้เราได้... อย่างที่ได้กล่าวมาข้างต้นแล้วว่าการจ้าง NPC นั้นจะเสียเงินเป็น "ครั้ง" ถ้าเราสะสมไอเท็มมาเป็นจำนวนมากๆ แล้ว Purify ทีเดียวนั้น ยังงัยซะก็ยังได้กำไรอยู่ดี
