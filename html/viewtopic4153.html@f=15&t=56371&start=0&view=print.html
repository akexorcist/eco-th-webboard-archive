มิวสิกโบล์ ก็เหมือน โฮลี่ไลท์ เป็นเวทล๊อกตัว ความแรงไม่มาก แต่เมื่อเทียบกะโฮลี่ไลท์จะร่ายนานก่าเล็กน้อย

ลาวด์ซอง เวทคลื่นเพลง ที่กวาดไปข้างหน้า รัศมีวงพัด (ภาพเอฟเฟกสกิว ดูกว้างไกล แต่ระยะจริงสั้น สัก2-3ช่องได้มั้ง จำไม่ได้ ) ความแรงปานกลาง กดรัวๆได้ แต่แรกเริ่มร่ายจะนานนิด

เวทยิงบาร์ดไม่ค่อยมีสกิวแรงๆ หรอก เอาไว้แค่ยามฉุกเฉินโดนมอนรุมก็ ยังพอยิงเอาตัวรอดได้
