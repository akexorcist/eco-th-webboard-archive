ถ้าคุณอยากได้ภาพเด็ดๆแจ๋วๆงามๆช็อตๆจากเกมEco คุณก้อคงจะต้องใช้กาscreenกันใช่มิ
พอคุณscreenมาแล้ว คุณก้อจะได้รูปเป็นนามสกุล bmp จิงมะ ในเมื่อนามสกุลภาพมัน
เป็นบีเอ็มพี kb[กิ๊กกะไบ้]มันก้อจะมาก ไม่สารถฝากรูปได้ เราจึงต้องเปลี่ยนให้เป็น เจพีจี[jpg] หรือจิฟ [gif] และพีเอ็นจี [PNG] ค่ะ


วิธีการเปลี่ยนจากbmp เป็น jpg gif ฯ
ดูตามภาพน้า


1. เราคิกขวาที่รูปภาพ และกดโอเพนวิด[open with] แล้วไปที่ ไมโครซอฟ ออฟฟิด พิก
เช่อมานาเกอร์ [Microsoft office picture manager]





2. จากนั้น ให้เราไปที่ฟาย [File] และไปที่เอ็กพร์อต [Export]
ก้อจะเกิดแถบทางด้านขวามือค่ะ ตามภาพเลย



3. พอเราเห็นหัวข้อ Export with this file Format ก็จะมีlist ให้เลือก
แล้วคุณก็เลือกนามสกุลภาพที่คุณต้องการจ้า

แล้วจากนั้นก็กดโอเคเป็นอันเสร็จตำนานการเปลี่ยนนามสกุลภาพจ้า

4.จากนั้นเราก็ฝากรูปภาพได้เยย ที่ http://www.compgamer.com แล้วไปที่ฝากรูป
ตามภาพจ้า




ถ้าคุณต้องการฝากภาพไหน ก้อBrowse ตามภาพด้านล่างเยยพี่น้อง




จากนั้นก็กดอัพโหด






5. ถ้าคุณต้องการภาพมาใช้ ก็ copy โค๊ด ตามภาพเลยจ้า
