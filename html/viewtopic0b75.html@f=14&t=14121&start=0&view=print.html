คือผมได้เข้าไปอ่านไกด์ของอาเชอร์มาแล้วแต่ยังมีข้อสงสัยและลังเลเกี่ยวกับสกิลนิดหน่อย
Charge Arrow ได้ตอนจ๊อบ15
Long-range Strategy ได้ตอนจ๊อบ30
ละก็ Doul Arrow ได้ตอนจ๊อบ35

ความคิดผมค่อยข้างจำเป็นนะ 3 สกิลเนี่ย (ถ้าจะเล่น Striker, แต่ถ้าจะเล่น Gunner สกิลธนูอย่าอัพนะ!)

Charge Arrow เป็นสกิลยิงของธนูสกิลแรก แรงพอใช้อยู่ (และอาจจะเป็นสกิลเดียวถ้าเราเล่นแค่ Job30 - -a อนาจดี)

Doul Arrow แรงกว่า Charge Arrow ละครับ ถ้าเล่นถึง Job35 ก็ควรจะอัพละนะ เพราะสกิล 40 กับ 50 เหมือนมันห่วยๆ เหอะๆๆ

ส่วน Long-range เนี่ย มันเป็น passive ไม่ต้องกดใช้ ดีออก ผมว่าอัพไว้ก็ไม่เสียหายนะ
