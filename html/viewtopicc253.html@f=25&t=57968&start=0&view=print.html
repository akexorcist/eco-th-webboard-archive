คุรุมิ & วากานะ

เงื่อนไข : เลเวล30+ ชื่อเสียง20+ เคยผ่านเควสเนโกะมาตะมาแล้ว

- ติดตั้งเนโกะมาตะแล้วไปคุยกับคุณป้าเย็บปักที่อัพทาว

- เลือก"ไป" แล้วจะไปที่สวนลอยฟ้าของมาชะ ให้ไปคุยกับเอมิลและมาชะ

-ที่บ้านของมาร์ คุยกับมาชะ จะมีเนโกะมาตะที่ต้องการออกมาจากมาร์ ให้เราเลือก"จับไว"แล้วจะได้ผ้าสามเหลี่ยม2ผืนมา จากนั้นที่สวนของมาชะ มาชะกับอิมิลจะคุยกัน

-จากนั้นเราจะมาที่บ้านของคุณป้าเย็บปัก ให้คุยกับคุณป้าซะ

-ไปคุยกับไททาที่เกาะไทนี่ แล้วก็มาคุยกับคุณป้าเย็บปัก พอออกมาจากบ้านของคุณป้าให้เลือก"ไป"เราจะไปอยู่ที่สวนของมาชะ

-ไปคุยกับไททาที่เกาะไทนี่อีกครั้ง แล้วจะได้ไปยังถ้ำ (จากที่แปลเข้าใจว่าไททาจะส่งเราไปถ้ำ- - โน้ตบอกว่าถ้ำเหมือนดันแหวน)

-ในถ้ำ ให้หาข้อผิดพลาดที่ผิดระหว่างความเจ็บปวดของจิตใจ(งงสิ อะไรง่ะ???) (ตามคำอธิบายคือให้หาNPCที่รูปร่างเหมือนเราแล้วไปคุย)

-ที่แมปเดิมจะมีลูกแก้ว6ลูกลอยอยู่ ให้เข้าไปตรงกลางแล้วสู้กับมาร์ (HPประมาณ 7000 พอใกล้ตายมันจะใช้แบล็คโฮล)

-จัดการมาร์เรียบร้อยก็ให้กลับออกมาทางลูกแก้วทางเดิม

-จากนั้นจะมาที่สวนของมาชะ แล้วเราก็จะได้เนโกะแฝดมา ^^
