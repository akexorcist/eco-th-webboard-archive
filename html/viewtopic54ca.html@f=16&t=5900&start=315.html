อยากจะถามว่า

1. ถ้าจะเล่นเกมเบลอ์สายสนับสนุนนี่จะเล่นยังไงเหรอ ต้องอัพพวกแรนด้อมฮีลลิ่งด้วยรึปล่าว หรือพวกท่าปาไพ่อะไรประมาณนี้ เท่าที่ดูแนวทางแล้วอัพ AGI + INT + MAG ได้ใช่หรือไม่ มันสามารถสนับสนุนการเล่นของสายปาไพ่ + สนับสนุนได้ใช่หรือไม่

2. ไพ่ที่ทำออกมานั้นต่อ 1 ชุด ( Paper 1 อัน + ไอเท็มมอนสเตอร์อีก 1 อัน ) จะได้ไพ่ออกมาทั้งหมดครั้งละกี่ใบ ?

3. ถ้าเล่นสายสนับสนุนแล้วเอาสกิลเกี่ยวกับบอดี้การ์ดของทางเทรดเดอร์มาใช้จะดีหรือไม่ เพราะเท่าที่ดูคาดว่ายังไงคงไม่ลงไปปาไพ่เองอย่างแน่นอน แล้วอยากจะทราบว่าท่าพวกปาไพ่นี่ใช้ขณะสิงอยู่ได้หรือไม่ แล้วท่าสนับสนุนบอดี้การ์ดของเราใช้ตอนสิงได้หรือไม่

* อันนี้ม่ายรู้ ม่ายเคยทดสอบ

* สู้คงจะไม่ไหว ต้องช่วยมันสู้ด้วย ส่วนการพัฒนาเป็น เบ๊ A นั้น สำหรับพ่อค้าทำได้เลย
