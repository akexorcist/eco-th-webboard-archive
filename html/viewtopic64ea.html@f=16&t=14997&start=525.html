ราชินีเงือก เขียน:รบกวนหน่อยสิค่ะ คืออย่างรู้ว่า ใช้ค่า C.spd ลดเวลาการร่าย สกิลของมริคิงเนี้ย คำนวณไงอะค่ะ ค่า C.spd เท่าไหร่ ลดเวลาได้เท่าไหร่อะค่ะ


เวลาลดไปเท่าไหร่ผมไม่แน่ใจนะ แต่เจอตามสูตรนี้

ค่าร่ายคิด C.spd = ค่าร่ายปกติ x ( 1 - C.spd / 1000 )

ดังนั้นเวลาร่ายมาริคิงที่ C.spd 800 ( Dex 108 ) = 5 x 0.2 = 1 วิ ---> 1 ใน 5 นั่นเอง
C.spd 750 ( Dex 99 ) = 5 x 0.25 = 1.25 วิ --> 1 ใน 4
C.spd 688 ( Dex 90 ) = 5 x 0.312 = 1.56 วิ

อ้างอิงจาก EcoWiki นะ

โดยทุกๆ dex รวมกันแล้วถ้า 9 หารลงตัวจะได้โบนัสครับ เลยคุ้มที่จะอับ

โดย C.spd 800 จะมากสุดเท่าทีเกมส์จำกัดไว้ ( C.spd 800 = Dex รวม 108 )

ถ้ามากกว่านี้ต้องมีสกิลของ Enchanter ที่ชื่อ Speed Enchant

ถ้าประสบการณ์ก็ dex 99 ก็เร็วพอสมควรแล้ว แต่ dex 108 ดีกว่า
