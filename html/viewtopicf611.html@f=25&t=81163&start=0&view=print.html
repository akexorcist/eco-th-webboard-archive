So Wrong เขียน:จากสภาพการณ์แล้ว ผมว่าคุณน่าจะติดเควส OD war อยู่อ่ะครับ

ขอเดาว่าตอนที่มันให้เลือกเนื้อเรื่องหลังเควส OD รอบแรก คุณคงเืลือกไปกับ Berial และยังทำเควสต่อจากนั้นไม่เสร็จ
เพราะงั้น เวลาเข้าไปหา leader มันเลยพาคุณไปหาเนื้อเรื่องของ Berial แทนที่จะเจอเควสคุโระ

วิธีแก้ คิดว่าคงต้องทำเควส OD ให้หมดก่อนแล้วค่อยกลับมาดูอีกทีครับ

แต่ปัญหาก็คือ ครั้งสุดท้ายที่ผมอ่านกระทู้เรื่องนี้ ดูเหมือนว่าเควสในส่วนของหมอนี่จะติดบัคอยู่ ไม่รู้ว่าป่านนี้แก้ได้รึยัง
ลองไปไล่หาวิธีผ่านเนื้อเรื่องของ Berial แล้วทำตามดูก่อน .....ไว้ถ้ามันยังบัคอยู่จริงๆก็ค่อยลองแจ้งวันทัชดูละกัน


แต่ว่านะ พูดก็พูดเถอะ ผมว่าเค้าก็มีเขียนเตือนไว้ในกระทู้วิธีทำแมวนี่นาว่าเวลาทำเควส OD เสร็จก็อย่าเพิ่งไปรับเควสต่อเพราะมันจะยาว รึถ้าเลือกเควสควรจะไปทางมาช่าเพราะไม่มีบัค


แล้ววิธีผ่านเนื้อเรื่องนี่ มันต้องทำยังไงเหรอคะ เราหาไม่เจออะ แล้วอืีกอย่าง เราไม่ค่อยรู้เรื่องอะไรเกี่ยวกับ OD war เลย
