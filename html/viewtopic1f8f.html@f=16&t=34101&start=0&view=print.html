ผมเล่น Treasure Hunter แล้วพอวันนี้ลองเช็ค Skill ที่น่าสนใจแล้วปรากฏว่า เทียบกับในว็บ+หนังสือแล้ว มี Skill ที่ไม่มีในเกมครับ(ไม่รู้เป็น Bug หรือยังไม่เข้าใน Saga นี้)

Skill ที่ไม่มีเกม
1. Caution = ในช่วงเวลาที่แสดงผล จะเพิ่มพลังป้องกันและจะไม่ได้รับการโจมตีแบบ Critical
2. Pull Whip = โจมตีพร้อมกระชากเป้าหมายเข้ามาใกล้ ผลลัพธ์จะเพิ่มขึ้นตาม LV ของสกิล [Catch] ที่เรียนมา
3. Escape = พาตนเองหลบหนีออกจาก Dungeon รวมถึงผู้ที่สวมวิญญาณอยู่ ไม่สามารถใช้ในขณะ Possession ได้
4. Sonic Whip =ฟาดแส้กระชากเป้าหมายเข้ามาใกล้ และรัวเป็นคอมโบ 8 ครั้ง ไม่สามารถใช้ในขณะ Possession ได้[/list][/list]

ไม่ทราบว่า Treasure Hunter คนอื่่นเจอแบบเดียวกันหรือเปล่าครับ
