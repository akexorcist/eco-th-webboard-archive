หลังซาก้า 5 มารุสึกว่าแมวมันฝึกง่ายขึ้นมากเลย

เมื่อก่อน def มัน max 18 ยังไงแมวมันก็ชนบอสในโรงเรียนไม่ได้ ต้องลากเอาอย่างเดียว ให้ปล่อยให้แมวโดนรุมตื๊บ ซึ่งพอแมวค่า atk aspd เยอะๆ มันก็ต่อยแปปเดียวพวกที่ลากมาก็ตายหมด

ปัจจบัน def max 140+ พอ def เต็ม จับลากฝึกต่อเรื่อยๆจน avoid เต็ม ค่าด้าน atk เต็มเกือบหมด(atk, aspd, cri) แล้วก็จับมันไปร่วมต่อยบอสหนอนเลย
สักพักมันก็ได้ชนบอสเองด้วยค่า cri +60 กะ aspd อันมากมายของมัน
พอเลือดเยอะ (600+) ก็ชนสบายๆละ นานๆฮีลที บางทีฮีลไปบอสก็ไม่หันกลับมาตีคนฮีล
