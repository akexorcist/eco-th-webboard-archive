มาเล่าความหลังตอนเด็กห้าย ทุกท่านได้ฟังดีกว่า.....

เมื่อก่อน ตอนเค้ายังอยู่ป.3 มีลูกพี่ลูกน้องคนนึงชอบแกล้งเค้ามากๆ. ส่วนใหญ่แกชอบเอาเรื่องผี มาแกล้งเจ๊

วันนึงมันมาบอกเค้าว่า มีผีอะไรซักอย่างอยู่ในห้องเก็บของหลังบ้าน. เค้าไม่ได้อยากไปกะมันหรอกนะ. มันบังคับ ฉุดกระชากลากถูเค้าไปอย่างโหดร้าย
พอเค้ายื่นหน้าเข้าไปในห้องเก็บของ ชิมิ. มันก็ผลักเค้าเข้าไปในห้องเก็บของแล้วล็อคประตูไม่ให้เค้าออกมา. แต่ว่าเค้าก็ไม่ได้โวยวายอะไรมากมาย. กลับยิ่งดีใจซะอีก(อืม...- -*)
เพราะในห้องเก็บของมันมีหนังสือดีๆเก่าๆเยอะ. คนรักการอ่านอย่างเค้าก้อ Happyน่ะสิ.
พอมันรู้นะว่าเค้าไม่กลัว ก็โมโหใหญ่. ไม่ยอมกินข้าวเย็น ซึ่งเค้าก้อมะเชข้าใจว่ามันโกรธอะไรเค้านักหนา.
ยังมีอีกหลายครั้งที่มันแกล้งเค้านะ. น่ากลัวกว่านี้กะมี(เอาไปทิ้งในป่าช้าก็มีนะ... ) แต่มันก็ล้มเหลวทุกครั้ง เพราะตอนนั้นเค้าซื่อบื้อมาก -- *
มารู้อีกทีก็ตอนขึ้น ม.2 เนี่ยแหละว่ามันโกรธอะไร.

ตอนนี้มันเลิกแกล้งเค้าไปละ เพราะมันคิดว่าเค้าน่ะ มัน "ซื่อบื้อเกินไปน่ะแหละ "
