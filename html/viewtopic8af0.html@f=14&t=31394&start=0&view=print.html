คือถ้าแทบไม่ได้ใช้กันผมจะเปลี่ยนและ ประมาณว่าใจร้อนน่ะ

เห็นว่าถ้าใช้ตอนใส่เล็บจะช้าอืดด้วยนี่ แถมส่วนใหญ่ผมเห็นคนใส่เล็บตีธรรมดาตลอดไม่เห็นใช้สกิลอะไรกันเลย

โพสต์แล้ว: จันทร์ 03 ธ.ค. 2007 2:08 pm
โดย ECO
ใช้สิครับ ผมใช้ประจำ ใช้ดีด้วย ช้าเพราะคุณใช้แต่คอนทินิวนิ ลองเอาไปคอมโบ้กะสกิลอื่นสิ ผมตีมอนในดัน 70 ใช้ท่าน คอนทินิวทัส + เค้าเตอร์ และคริติคอล ตีมอนในดัน 70 ชุดเดียวหลับ แล้ว

สกิลดีมากๆ อีกอย่างสกิลทุกสกิลมันดีหมดอ่ะครับขึ้นอยู่กะคนใช้อ่ะครับว่าใช้เป็นหรือป่าว

ใช้ค่ะ บ่อยมากมาย แค่เอาคอมโบกะคริสติคัล และกดใช้คอนตีนิว แค่นี้มอนก็หลับแล้ว แถมไม่ค่อยจะเสียเลือดด้วย

เราใช้แค่2สกิลเอง คริ กะ คอนฯ หากินได้ยาวเลย สกิลอื่นแทบไม่ใช้เลย
