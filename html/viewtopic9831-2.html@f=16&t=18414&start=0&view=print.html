การสุ้ มินิดูยักษ์ เป็นอะไรทีไม่ยาก ขอแค่ ไปเป็น ตี้ ก็พอค่ะ แค่ระวัง ตอนที่ เจ้า มินิดู

ตีไปนานๆ ตัวโต จน น่ากลัว อิอิ ช่วงนี้ระวัง นะค่ะ มินิดูจะ ระเบิด ตัวเอง เจ้าค่ะ
