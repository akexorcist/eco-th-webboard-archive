dark flower มีอยู่ที่
1. ปราสาทอันเดด อยู่ตะวันออกสุด เข้าไปก็เจอเลย มีประมาณ 3-4 ดอก
2. เกาะอันเดด อยู่ตะวันตก ต้องใช้ paper note ในการเข้า มีประมาณ 3 ดอก มอนชุกชุมมาก ไม่อึดก็อย่าไปเลย
3. ใช้เพื่อนชาวนาที่ใจดี+มีเมล็ดปลูกให้ ปลูกที่ไหนก็แล้วแต่ศรัทธา

มาริโอเน็ตปลา จะต้องมี strange dry fish ก่อน อันนี้ไม่แน่ใจนะว่าต้องไปคุยกับกระโห้ที่หอเปลี่ยนอาชีพชั้น 5 ก่อนรึป่าว ไปลองดูละกัน (ไม่ได้ทำนานละ -*- )

รูฟ <= น่าจะหมายถึงกรูฟ (Dark Groove) เป็นจ็อบ 50 อาชีพขั้นแรก จะเป็นการปล่อยลกบอลความมืดออกไปเป็นเส้นตรง โดนได้หลายฮิท ฉะนั้นคทาจะแตกเร็วขึ้นกว่ายิงบล้าสซึ่งตีได้แค่ทีละ 1 ครั้ง
