ตั้งแต่ 50 กว่าๆ ผมเริ่มส่งเควสอย่างเดียวเลยอ่ะครับ

พอเข้า 60 ปลายๆ ก็ขึ้น ดาดฟ้าหอแสงฝั่ง B อ่ะครับ

เพราะเควสเวล 69 จะให้ส่ง Bean ครั้งละ 1 เม็ด

ซึ่งดาดฟ้าหอ B จะมีต้นถั่วให้ตีด้วย

ได้ทั้งเวล ได้ทั้งของเควส

แรกๆ ตีแต่หนามเหลือง ส่วนปืน พอสู้ได้ อาจจะตึงมือนิด

ส่วนลิ้นจี่ กับ ยักษ์ กับผี อย่าเพิ่งไปตี ไม่ไหว

พอสัก 70-80 กว่า ยักษ์เริ่มตีไหวแบบสบายๆ

แต่ลิ้นจี่ยังตึงมือไปนิด ถ้าจะตี ต้องแปลงเป็นมาริโอหุ่นก่อน


พอสัก 90 ลิ้นจี่ก็สบายแล้ว

ส่วนผี ไม่ว่าเวลเท่าไหร่ แนะว่าถ้าเลี่ยงได้ ก็อย่าไปยุ่งกับมัน
เพราะถึงมันไม่ค่อยเก่ง แต่มันมีเวย์สาปช้า

ถ้าโดนล่ะก็ วิ่งเต่ามากกกกก
แถมสาปนานเป็นนาทีด้วย

ผมเก็บที่นี่ยัน 90 กว่าเลยนะ

ตอนนี้ก็ยังเก็บอยู่
ไปไหนไม่ถูก
