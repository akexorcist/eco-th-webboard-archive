ก็คล้ายๆกับ NPC item teacherอะไรสักอย่างทำให้ครับ(ที่เปิดกล่องให้)
เหมือนกับคำสั่ง "PURIFY ไอเท็มให้หน่อย"
เพียงแต่ไม่ต้องเสียตัง เหมาะกับคนที่เงินยังไม่เฟ้อ(น้อยกว่า1m เพราะrefineทีละ1000)

ยกตัวอย่างการใช้งาน
ไปตีแมพหมีขาว มีดรอป"เนื้อใหญ่" ซึ่งหนักแต่ถ้า refine แล้วจะเบาลงมาก
จะรวมๆหลายๆอันแล้วกลับทีเดียว ก็ขี้เกียจเดินมาอีก
ดังนั้นก็ REFINE เองเลย คุ้มไม่เสียเวลา 555+

ส่วนใหญ่จะแนะนำนะครับ เพราะสกิล(ถ้าเก็บ event job pointอีก24แต้ม)
ก็จะเยอะเพียงพอจะอัพได้ แต่ถ้าเอาแค่อัพเล่นๆ ก็พักไว้ก่อนก็ได้
