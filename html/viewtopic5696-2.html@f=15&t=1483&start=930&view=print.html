แยกเป็น case นะครับ

1. ยิงชินนาม่อนที่เป็นธาตุดิน แต่พื้นที่เป็นไฟให้ดู ต.ย. นี้ครับคล้ายๆกัน

- สมมุติว่าโจมตีด้วยธาตุน้ำใส่มอนสเตอร์ที่มีพลังธาตุ น้ำ 50 ดิน 100
ผลของธาตุดิน = floor[ความแรงของธาตุดิน*สัมประสิทธิธาตุ(น้ำ->ดิน)]
ผลของธาตุดิน = floor[100*(+2/3)] = +66
ผลของธาตุน้ำ = floor[ความแรงของธาตุน้ำ*สัมประสิทธิธาตุ(น้ำ->น้ำ)]
ผลของธาตุน้ำ = floor[50*(-1)] = -50
ผลรวมผลของทั้ง 4 ธาตุ = ผลของธาตุน้ำ + ผลของธาตุดิน = +66 -50 = +16
เนื่องจากมอนสเตอร์มี 2 ธาตุ
ผลของธาตุแสงหรือความมืด = 0 เนื่องจากมอนสเตอร์ไม่มีธาตุแสงหรือธาตุความมืด
ดังนั้น
อัตราขยายการโจมตีธาตุ = floor[(100+ผลรวมผลของทั้ง 4 ธาตุ) * (100+ผลของธาตุแสงหรือธาตุความมืด) / 100]
อัตราขยายการโจมตีธาตุ = floor[(100+16) * (100+0) / 100]=116%
สรุปว่าเราจะโจมตีมอนสเตอร์ตัวนี้ได้แรง 1.16 เท่าของปกติ

ในกรณีของเรา จะยิงธาตุน้ำใส่ monster ที่เป็นธาตุดินแต่จะถูกพื้นที่ที่เป็นธาตุไฟ หักลบออกไป จะเห็นได้ว่าจะยิงธาตุน้ำได้แรงขึ้นแน่นอนครับ


2. ยิงคิเมร่าที่เป็นธาตุไฟและพื้นที่ก็เป็นธาตุไฟ

ต่าส.ป.ส. ธาตุ (ชนะทาง) = +2/3 = 66.66% + ค่าเสริมพลังจากพื้นที่ n

ไม่ถึงกับคูณ 2 ครับราวๆ 175-190% (จากประสปการ์ณในการเก็บ lv ที่คิเมร่านะครับ -- ยิงในพื้นที่ธรรมดา dmg ราวๆ 1500-1800 แต่เมื่อมีพื้นทีธาตุไฟเข้ามา dmg ทำได้ที่ 2200- 2800 ) การคำนวนก็ค้ายๆเดิมนะครับ เพราะ monster มีความแรงธาตุไฟ 100 และได้เพิ่มจากพื้นที่อีก (ซึ่งผมไม่ทราบค่าว่า เวลาได้เพิ่มพลังจากพื้นที่จะขึ้นมาเท่าไหร่ครับ)
