คือว่า จากสกิล mace mastery คำว่า mace ก้อคือคทา(หรือกระบอง)อันนี้พอเข้าใจค่ะ
แต่ในเกม อาวุธชิ้นไหนมันคือคทา(หรือกระบอง)บ้างคะ
จะว่าไปมีแต่ ไม้เท้าของพวกนักเวท
เลยอยากรู้ว่า ถ้าเราใช้ค้อนกับขวาน เราจะได้รับผลจากสกิล Mace mastery มั้ยคะ
ถ้าไม่มีจะได้รีทิ้ง -..-

สกิล Mace mastery จะส่งผลกับอาวุธ 2 ชนิดคือ
1. ชนิิดที่เป็น Mace
2. ชนิดที่เป็น Hammer ก็พวกค้อนต่างๆ

ส่วน ขวาน มีสกิล Axe Mastery กับ 2 Hands-Axes Mastery อยู่แล้วงัับ ที่เห็นมาเป็นสกิลสำหรับอาชีพชาวนาอะจ้ะ

เพราะฉะนั้ั้น ที่คุณ จขกท อัพ สกิล Mace Mastery ก็จะมีผลแค่กับค้อนอย่างเดียว
ส่วนขวานไม่ได้รับผลจากสกิลนี้จ้ะ
