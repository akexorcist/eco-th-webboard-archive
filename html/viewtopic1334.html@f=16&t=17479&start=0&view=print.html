ว่า ด้วย เรื่อง Skill Analysis ของ แต่ ละสาย BP กับสกิลjob33

โพสต์แล้ว: อาทิตย์ 05 ส.ค. 2007 9:09 am
โดย ECO
Skill Analysis ตามที่ ผม เข้าใจคือ เป็น สกิล ที่เสกใส่ mob หรือ สิ่งของที่ ประเภท ปราชนั้นๆ ระบุไว้ ตามชื่อ สกิล และ มี 3 เลเวลเพื่อ ให้ ใช้ได้นานขึ้น แต่ มี ผล เท่า กับ ปราชธรรมดา หรือ สกิล Knowlege ต่างๆ นั้นเอง (ถ้าเราแบ่งให้คนอื่น ตี หรือ สัตว์ เลี้ยง เราตี สกิลนี้ พอมี ประโยชน์ บ้าง ตามที่คิด)

ฉะนั้น สกิล ประเภท Analysis จึงไม่ค่อย น่าอัพ เท่าที่ควร ( ประโยชน์ที่ผม คิดได้ คือ เอาไว้เสก มอนสเตอร์ ตามที่ ประเภท สกิล นั้นๆ แล้ว สั่งให้ Pet เราจัดการ แทน เช่น Merchant กำลังสู้กับี ศัตรู ประเภท Human แต่ ตัวเอง ฆ่า เจ้าตัวนี้ไม่ไหว เลย สั่งให้ Pet ฆ่า แล้ว เสก สกิล Human Analysis ลง บนตัว monster ตัวที่ กำลัง สู้ ก่อน ที่มันโดน Pet เรา ฆ่า ก็ จะโอกาส ของ ดรอป แบบ Skill Human Knowledge ที่ เราต้อง ฆ่ามันเอง)


แต่ อีก สกิลที่ พัฒนาจาก สกิล Analysis คือ Skill ตอน Job 33 ที่ แจก Knoledge ให้กับคนใน Party ทั้งหมด (ยกเว้น Merchant หรือ Trader จะไม่มี สกิลแบบนี้)

สกิลนี้ คล้าย สกิล Analysis แต่ ต่างตรงที่ เรา จะเสกใส่ทุกคน ใน ปาตี้เรา ให้มี Knowledge แบบเรา สกิลนี้ สำหรับ ทาทาราเบะ กับ ชาวนา ไม่ค่อย น่าสนใจ เพราะ มี ปราช ไม่กี่แบบ และ มอนเตอร์ ที่ตี น้อย แต่ถ้าเป็น Ranger หรือ Explorer ที่ มี Knowledge ทั้ง แมลง สัตว์ ปลา นก แล้วละ ก็ สกิลนี้ น่า ใช้มาก เลยครับ

ถ้า อธิบายไม่ค่อยเข้าใจ ต้อง ขออภัยครับ
