วิธีให้ NPC เพิ่มคุ้นเคย ให้ Pet

~ ให้ NPC รักษา Pet ทั่วไปรักษาให้( เพิ่ม 1 แต้ม / 1วัน)

- ใส่ Pet ไปคุยตาม จุดรักษาได้เลย แต่ได้วันละ 1 แต้มเท่านั้น

~ ให้ NPC คุณปู่ที่ ทุ่งโมโม เพิ่ม ให้( เพิ่ม 3 แต้ม / 1วัน)

- จำเป้นต้องผ่านเควส ทำหนอนลากซะก่อน (สามารถ ดูวิธีทำเควสได้ตาม Link นี้ - วิธีการทำ Ride Crawler )
