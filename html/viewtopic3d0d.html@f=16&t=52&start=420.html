ดีคร่าทุกๆคน มะได้เข้ามานานหลายวันเลย มะว่างคร่า
เกมก้อมะได้เล่น เพลียๆเลยนอนเร็วทุกวัน เวลมะอัพ อิอิจาไปถึงไหนมะนี่
อยากเก่งแบบนู๋ซิ้มมากๆเลยคะ จะถามนิดนึงนะคะ อาชีพที่ต้องเลือกตอ่จาก
ชาวนานี่ต้องเป็นอะไรคะ ช่วยแนะนำให้ด้วย จะได้เล่นตาม เชื่อมะว่าตอนนี้
อาวุธที่ใช้อยุ่ยังเป็นหอกไม้อยุ่เลย มะมีปัญญาหาอาวุธจริงๆคะ ใช้แบบมั่วๆ
ว่าจะหาซื้อขวานตามที่แนะนำมาและก้อซื้อเป๋าด้วย อยากถามว่าเป๋าทำเอง
ได้มะคะ แระก้อตะกร้าใส่ข้างหลังชาวนาใส่ได้หรือปล่าว หรือว่าใช้ได้แต่เป้หลัง
อยากได้ตะกร้าหลังมันเท่ดี แปลกๆรุ้สึกว่าเป็นชาวนาอย่างแท้จริง
นู๋ซิ้มเล่นประมาณกี่ทุ่มคะอยากเจอในเกมค่ะ แต่เราเล่นเวลาไม่ค่อยแน่นอน
บางทีง่วงเร็วก้อนอนเร็วส่วนมากจะนอนเร็วแต่เปิดคอมไว้และก้อขอสิงชาวบ้าน
เค้าให้พาไปเก็บเวลด้วย มีคนจัยดีก้อพาไปคะ ตอนนี้เค้าพาไปทิ้งไว้ที่ฟาร์อีส
ก้อยังตัดสินจัยมะได้ว่าจะเปลี่ยนจุดเกิดเป็นฟาร์อีสดีหรือปล่าวเพราะถ้าให้ไปเอง
ก้อคงมะมีปัญญาจะไปแน่คงตายก่อนถึงตลอดเลยคะ ที่ฟาร์อีสมันน่าอยุ่จริงๆ
แระก้อเหมาะกับอาขีพชาวนาที่สุด เด๋วว่าจะเข้าไปเล่นสะน่อย ขอรีดผ้าแปบนึง
อยากเจอมากๆนะคะ แระก้อเพือ่นๆในบอร์ดทุกคนด้วยอยากคุยกันในเกมคะ

สวัสดีค่ะ คุณนกน้อย + นอกน้อย 2 *0* ( มี 2 เวอร์ชั่นเลยหรอ )

จริงๆ เกรซเอง ( ชื่อเล่น ) ก็ไม่ได้เล่นเก่งอะไรหรอกค่ะ อาศัย ดูด บ้าง ตีเองบ้าง สลับกันไป

ถามว่าตระกล้าใส่ได้มั้ย อาชีพสาย BP เผ่า Emill ใส่ได้ทุกคนเลยละค่ะ

เรื่องอาวุธ นี่ จริงๆ ไม่ต้องไปเปลียนมันทุกเลเวลก็ได้ ใส่ยาวๆ ไปได้เหมือนกัน

เปลี่ยนมันทุกระดับ นี่ตายแน่ๆ เงิน >_< พลังโจมตีก็ไม่ต่างอะไรกันมากมาย เพราะว่า มันแกว่ง

ส่วนถามว่าเซฟไหนดี ก็ฟาอิสก็ได้ค่ะ เก็บที่นั้นได้เรื่อยๆ เลยละ แต่ก็แล้วแต่ชอบนะค่ะ

เกรซเล่น ช่วงเย็นๆ ถึงดึกๆ หน่อย ส่วนมากอยู่ทางใต้ ค่ะ ก็ไปอโครเนีย กับฟาอิสบ้าง

เหนือไม่ได้ไปเลย -*- ( หนาว ) อิอิ เด๋วถ้ายังไง บอกในบอร์ดก็ได้ค่ะ จะไปหานะค่ะ
