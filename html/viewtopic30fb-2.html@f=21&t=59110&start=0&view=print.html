Prologue~
ณ จักรวาลอันกว้างใหญ่ไพศาลนั้น ได้ประกอบไปด้วยกาแลคซี่ต่างๆ มากมายนับไม่ถ้วน แน่นอน ว่ารวมถึงกาแลคซีทางช้างเผือกของเราด้วย
ใน กาแลคซี่ทางช้างเผือกนั้นมีดาวต่างๆ หลากหลายดวงด้วยกัน และหนึ่งในนั้นที่มีความสำคัญมากก็คือ ระบบสุริยะจักรวาล
ในระบบสุริยะจักรวาล อันมีดวงอาทิตย์เป็นศูนย์กลางนั้น ก็ได้มีดาวเคราะห์ต่างๆ มากมายด้วยกัน แน่นอนว่า โลกของเราก็คือ 1 ในนั้นนั่นเอง
ในโลกของเรานั้นได้แบ่งออกเป็นหลายๆ ทวีป ต่างๆ นานา แน่นอนว่า หนึ่งในนั้นก็คือ ทวีปเอเชีย
ทวีปเอเชียจัดว่าเป็นทวีปที่ใหญ่ที่สุด ประกอบไปด้วยประเทศต่างๆ มากมาย หนึ่งในนั้นก็คือประเทศไทย
ในประเทศไทย ได้แบ่งออกเป็นหลายๆ จังหวัด เล็กบ้าง ใหญ่บ้าง คละเคล้ากันไป แน่นอนว่ารวมไปถึง กรุงเทพด้วย
และสุดท้ายนี้ จากเนื้อหาทั้งหมดที่กล่าวมา ประกอบไปด้วยคำพูดต่างๆ มากมาย
แน่นอนว่า ที่กล่าวมาทั้งหมด ไม่เกี่ยวข้องอะไรกับเนื้อเรื่องทั้งสิ้น =w=
( แล้วตูจะเขียนทำ Spear อะไรฟระ )

หมายเหตุ
1. ฟิคชั่นเรื่องนี้ ได้ใช้ภาษาที่ไม่ค่อยสละสลวย ถูกต้องสวยงามเหมาะกับพวกผู้ดีสักเท่าไหร่
2. ฟิคชั่นเรื่องนี้ ถ้าได้รับรางวัล ดอง อวอร์ด ไม่ต้องแปลกใจ ผู้แต่งค่อนข้างขี้เกียจเป็นทุนเดิมอยู่แล้ว =w=~

4. หากท่านอ่านฟิคชั่นนี้ไม่เข้าใจ ก็ขอแสดงความยินดีด้วย~ แปลว่าท่านเป็นบุคคลธรรมดาทั่วไปอย่างแท้จริง
