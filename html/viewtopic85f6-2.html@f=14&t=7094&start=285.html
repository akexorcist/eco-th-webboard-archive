เพระฉะนั้น ปืนสั้น/ปืนคู่ ตกไปเลย ระยะยิง4ช่อง ตายก่อนแหงมๆ(STRมากแค่ไหนยิงธรรมดาก็แรงไม่พอ สกิลทีเดียวถ้ามอนไม่ตายเราก็ตายเอง)

ที่เหลือก็ไรเฟิล แม้จะยิงเบา แต่ที่สำคัญคือ ระยะยิง 8 ช่อง
ซึ่งไกลมากๆ เรื่องยิงเบาก็ทดแทนด้วยค่าSTR

แต่ถ้ามีOver Rangeแล้ว ปืนสั้นน่าจะเหมาะมือนะ เพราะแรง+ค่าSTRเราอีก
(ถ้ามีตังรีสกิล ไว้เปลี่ยนสกิลMasteryนะ - -)
แถม+Lhitอีก10
แรง+แม่น+ไกล = ใครจะเหลือ
แว้นแต่OverRangeหมดกลางคันนะ อันนั้นแนะนำให้โดดขึ้นมังกรแล้วซิ่ง = =

และ "ยังไงก็ตามแต่ จะใช้ปืนอะไรDamageก็ไม่ต่างกันมากมายนักหรอกครับ" - -

ถ้าจำไม่ผิดนะ ย้ำ ถ้าจำไม่ผิด
ปืนสั้น -> VIT -- ระยะ4ช่อง แต่ถึกยังงี้โดน2-3ทีก็ไม่กลัว ซ้ำสกิลสัก2-3ทีมอนก็ฝันร้ายแล้ว ยิ่งมีOverRangeอีกล่ะก็ คริๆๆ
ปืนคู่ -> AGI -- ASPDเหลือ2/3 ลดไปก็ลดไป ยังไงก็ยิงรัวไม่มีเปลี่ยน GDC+OverRangeรับรองงานนี้สาดกระสุนมันส์
ปืนไรเฟิล -> STR -- ยิงอย่างไกลปลอดภัยอย่างแรง แม้จะเบาแต่ค่าSTRล้นหลาม แถมไม่ต้องจิ้มOverRangeด้วย(จิ้มก็บ้าและ ยิงซะสุดจองงั้น = =) สกิลได้ตั้งแต่ระยะไกล มาใกล้ๆก็โดนCharge

แนววิเคราะห์สำหรับข้าน้อย

ปืนสั้น : ส่วนมากมักนะเน้นเล่น Vit เพราะสกิลไม่ต้องร่าย แถมไม่ต้องกัวเรื่องระยะที่แสนสั้นเพราะ ยิงสกิลแหลก

ยังไงๆ ก็สกิลแล้วถอยตั้งหลักยังไหว ถ้าใช้ GDC จะเป็นการกระหน่ำสกิลอย่างโหด

ปืนคู่ : เหมาะสำหรับผู้ที่ชอบ สาดกระสุนเป็นนิจ เพราะได้โบนัส+1นัด ซึ่งก้ทดแทนข้อด้อยความแรงได้

แต่หากจะเล่นสาย AGI แล้วใส่ GDC ก็ไม่เลวแต่อาจจะใช้ Over Rage ควบคู่เพราะระยะใกล้

ทำให้อาจเกิดอารมณ์เสียเนื่องจากเล็งแล้วมอนเดินพ้นระยะ ต้องวิ่งเข้าไปใหม่ และลดอัตตราการเสียหาย (ยิงฟรีหลายดอก)

ไรเฟิล : ใช้ระยะยิงให้เป็นประโยชน์ อาจจะใช้การยิงฟรีเพื่อลดพลังมอนระดับหนึ่ง แล้วทำการปิดด้วยสกิล

เป็นสายที่ค่อนข้างมีความปลอดภัยในชีวิตสูง อาจจะมี Str สูงสักหน่อยเพื่อความรวดเร็วในการฆ่า (ยิงไกลมะกัวโดนตบ)

เพิ่มเติมจากที่ค้างๆไว้ (ได้ กระสุนเต้นรำแล้ว)

สกิลนี้จะมีระยะยิง 5*5 ช่องโดยนับตัวเองเป็นศูนย์กลาง

ซึ่งถ้ามีมอนในระยะจะทำการโจมตีทันที และทำการยิงออกไป 8 นัดแบบสุ่มเป้าหมาย (1ตัวก็รับเต็มๆ)

ภาพยืนยัน



จากรูปตัวละครยิงโจรอยู่โดยมี สุนัขคั่นกลาง เป้นการยิงระยะห่าง 2 ช่อง ซึ่งถ้าทำเป้น 4เหลี่ยมจตุรัสแล้ว

จะได้ขนาด 5*5 พอดี

เมื่อเทียบกับสกิล สาดกระสุน

บัลเล็ตแด๊น ได้เปรียบดังนี้

1. มีจำนวนการยิงที่มากกว่า และไม่จำกัดประเภทปืน ทำให้ใช้ปืนสั้นยิงได้แรงกว่าประเภทอื่น

2. มีความรุนแรง 1/1 มากกว่าแบบมโหศาล

3. ยิงเป็นกลุ่มได้

4. มีระยะเวลาร่ายเท่ากัน

ข้อเสียเปรียบ

1. มีดีเลย์ที่มากกว่า ถึง 3เท่า (สาด 1วิ บัลเล็ตแด๊น 3วิ)

2. อัตราความแม่นยำถูกลดเยอะกว่า สาดกระสุน

3. ทำการยิงโดยสุ่มหากมีมอนสเตอร์มากกว่า 2ตัว จะทำให้เกิดความไม่แน่นอน (ยิงไม่ตาย)

4. ระยะยิงสั้นเพียงรอบตัว ซึ่งหมายความว่าต้องมีการเสียเลือดเนื้อ ในขณะที่สาดกระสุน สาดไปแล้ววิ่งหนีเพื่อซ้ำอีกได้

เพิ่มเติม 2 : สกิล GDC

1. ไม่ลดระยะเวลาร่าย

2. ลดดีเลย์หลังร่าย (ซ้ำต่อได้อย่างรวดเร็ว)

3. ยิงกระสุนเวลาใช้สกิลต่างๆไวขึ้นเช่นกัน (เผ่นได้ไว)
