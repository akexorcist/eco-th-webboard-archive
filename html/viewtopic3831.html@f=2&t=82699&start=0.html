[ECO-JP] Payment -ว่าด้วยช่องทางเติมเงิน


สำหรับ เกม ECO server ญี่ปุ่น ก็จะมีวิธีการเติมเงิน หลายช่อง ทาง

ดูรายละเอียดเพิ่มเติมได้ที่ :
https://secure.gungho.jp/faq/faqdetail. ... e14afdfae9

แต่วิธี ที่สะดวกสำหรับ ชาว ECO ที่อยู่ นอก ญี่ปุ่น คือ การเติมเงินผ่านช่องทางต่อไปนี้

1. Webmoney

web site หลัก : http://www.webmoney.jp/

where to buy : http://www.webmoney.jp/guide/buy.html

Price : 1000 point / 2000 point / 3000 point / 5000 point / 10000 point

* 1000 point = 1000 yen

Neko’s comment : สามารถซื้อได้ ตามร้านสะดวกซื้อ เช่น 7-11 / family mart ในประเทศญี่ปุ่น
จะได้ รหัสบัตร 16 หลัก แล้ว นำมาเติม หน้าเวบ eco jp ได้เลย

………

2. Bit Cash

website หลัก : http://www.bitcash.jp/

where to buy : http://www.bitcash.jp/purchase/

Neko’s comment : สามารถซื้อได้ ตามร้านสะดวกซื้อ เช่น 7-11 / familymart ในประเทศญี่ปุ่น
จะได้ รหัสบัตร 16 หลัก แล้ว นำมาเติม หน้าเวบ eco jp ได้เลย

…………….

สำหรับ bit cash / web money นั้น มีช่องทางเติมเงิน ผ่าน บัตรเครดิต visa / imternet banking ก็จริง แต่ว่า รับเฉพาะ บัตร / ธนาคาร ภายในประเทศญี่ปุ่นเท่านั้น !!!

ถ้าลอง search google ดู จะพบว่า มีบริการรับเติมเงิน หรือ ขายบัตรเติมเงินของ ทาง bitcash / web money เช่นกัน

แต่ web เหล่านั้น ไม่ใช่ เวบ ตัวแทนจัดจำหน่ายบัตรเติมเงินอย่างเป็นทางการ แต่อย่างใดนะคะ

เพราะฉะนั้น ควรระมัดระวัง ทุกครั้ง ก่อนทำการซื้อขาย บัตรเติมเงินค่ะ

หากตัดสินใจทำการซื้อขาย ควรจะเก็บหลักฐานในการซื้อขายไว้ด้วยทุกครั้ง ป้องกันการมีปัญหา ภายหลังจ้า

…………….

แนะนำ ช่องทางเติมเงินกันไปแล้ว ก็ แนะนำ อัตรา Rate ด้วยละกันค่ะ

สำหรับ Rate เติมเงินเกม ECO JP ก็จะมีตามข้างล่างค่ะ

1,000 เยน = 10,000 Shop Point.
2,000 เยน = 21,000 Shop Point.
3,000 เยน = 32,500 Shop Point.
5,000 เยน = 55,000 Shop Point.
10,000 เยน = 112,000 Shop Point.

......................

Exchange Currency (BBL / SCB)

100 Yen = (SCB = 41.375 บาท) / BBL = 41.17 บาท)

แต่ถ้าซื้อบัตรเติมเงินผ่าน paypal จะได้ rate 100 Yen = 41.59 บาท

* อัตราการ แลกเปลี่ยน ของ ธนาคารจะแตกต่างกันไปในแต่ละวัน
ยังไงก็ เชค ได้ที่ เวบไซต์ของธนาคารก่อนนะคะ ^^

...................

* ไม่รับหลังไมค์เรื่องการเติมเงินนะคะ กระทู้นี้อธิบายช่องทางเติมเงิน กับ Rate Shop Point เท่านั้นค่ะ
