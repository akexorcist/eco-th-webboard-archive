≪重要なご案内≫

ガンホーゲームズでは、一部のサービスにおいて、日本国外からの接続を制限しております。

日本国外から接続されている場合には、ガンホーID・ゲームアカウントの登録
ならびに、利用料金の支払いをすることはできません。

※国内のプロキシサーバーを経由した接続についても、接続制限の対象となる場合がございます。
　プロキシサーバー利用の有無については、ご契約のプロバイダーにお問い合わせください。

その他、ガンホーID・ゲームアカウントの登録、ならびに利用料金の支払いに
関するお問い合わせは「サポートセンター」までご連絡ください。

IP ที่ใช้เข้าเกมไม่ใช่ IP ของญี่ปุ่น ครับ มันเลยบล็อกไม่ให้เข้า
