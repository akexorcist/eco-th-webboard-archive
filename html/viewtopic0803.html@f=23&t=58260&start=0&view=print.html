ถ้าเกิด เอาหูกระต่าย กับหางกระต่าย ที่ได้จากกิจกรรม ลอยกระทงนี้
มาหลอมกับกระเป๋าและ หมวกขยะ จะได้รึเปล่าครับ

ผมเสียวว่า ถ้าหมดกิจกรรมแล้ว มันจะหายไปทั้ง หูและหาง พร้อมของที่หลอมไปด้วย..... :yoyo101:

หรือว่ามัน หลอมไม่ได้ เพราะเป็น Event Item :yoyo101:

:yoyo111: ลืมแหะ

เงื่อนไขของการหลอมรวมอาวุธเครื่องป้องกัน
1. ไอเทมจะต้องเป็นประเภทเดียวกัน
๐ ไม่สามารถหลอมรวมอาวุธถือสองมือกับอาวุธถือมือเดียวได้ ถึงแม้จะเป็นประเภทเดียวกัน
๐ ไม่สามารถหลอมรวมไอเทมที่ใช้ติดตั้งคนละตำแหน่งกันได้
๐ ไม่สามารถหลอมรวม อาวุธขว้าง, ลูกธนูหรือกระสุนทุกชนิด
๐ ไม่สามารถหลอมรวม Shoulder Devil หรือ Pet ได้เนื่องจากไม่ใช่ไอเทมสวมใส่
2. ต้องไม่ใช่ Event Item
* Event Item นั้น เป็นไอเทมที่ไม่สามารถเก็บเข้าโกดัง, Trade หรือ Drop ได้นอกจากทิ้งอย่างเดียว
3. เลเวลที่สามารถติดตั้งของไอเทมที่จะให้ [แสดง] จะต้องน้อยกว่าหรือเท่ากับ เลเวลของไอเทมที่จะให้แสดง [ความสามารถ]
