ผมก็ว่า Storm ดีกว่า grove แต่เอาเข้าจริงก็ใช้ยากทั้งคู่ บางโอกาสยังคิดว่า grove ดีกว่า Storm

เวท Storm มันโจมตีหมู่ แถมถ้าไม่มีคนยืนล่อมอนให้ โอกาสโดนมอนก็น้อยอีก แล้วถ้ามอนไม่ตายในทีเดียว มันก็จะมารุมคนร่ายเวทด้วย ต้องระวัง

ส่วน grove ผมว่าดีตรงที่มันโจมตีหลายครั้ง ทำให้มอนมีโอกาสตายในการร่ายเวททีเดียว แถมไม่แฉลบไปโดนตัวที่เราไม่อยากให้โดนด้วย แต่เล็งยากชะมัด


เอ่อ แล้วถ้าจะเล่น Storm ทุกธาตุ ก็ไม่ค่อยแนะนำอ่ะ ตอนแรกผมก็คิดจะเล่นทุกธาตุ แต่พอลองคำนวนพ้อยท์แล้ว มันไม่พอ T_T เพราะ job2 มันเก็บ job level ยากมากๆ ทำให้กว่าจะได้มาแต่ละ lamp ช่างโหดร้ายแสนสาหัสมาก แต่ละ point จึงสำคัญ ถ้าจะอัพอะไรก็คิดดีๆก่อนละกันครับ คำนวนดีๆว่าได้ใช้จริงรึเปล่า

ทุกวันนี้ผมยังใช้ blast เป็นหลักอยู่เลย นานๆทีถึงจะได้ใช้ Storm แถม skill ที่น่าใช้อย่าง Zen กับ แช่แข็ง ถ้าไม่มีก็หากินลำบากอีก เลยต้องแบ่ง point ให้ดีๆ
