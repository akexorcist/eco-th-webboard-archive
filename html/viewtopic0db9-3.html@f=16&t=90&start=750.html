Lafara เขียน:เควส คำสาปแห่ง Mold ทำส่งแล้วคุ้มนะ ทั้ง EXP และเงิน
แต่กว่าจะทำเสร็จ ... เหนื่อย = =

เมื่อยมากๆ ... กด Ctrl+F1 แล้วช้อนซื้อซินนาม่อนมาส่ง ... จบ ... เอากำไรแค่ 300G ก็ได้

ยา Multicondition ล่าสุด ขายโดดๆ แค่ขวดเดียว 1100G ... ยังขายออก = =
ถ้าไม่ติดว่า โกดังมันล้นไปแล้ว
ก็คิดๆ ว่าจะไปถอนหญ้า มาทำยาขาย ....

ไม่แนะนำให้ส่งเควสหาลูกธนูธาตุ
ได้ EXP น้อยกว่าเควสแม่ค้า ตามเลเวลไม่พอ
ยังได้เงินไม่คุ้มค่า (ซื้อ 1600G ส่งเควสได้เงิน 1000G)
หนำซ้ำ ยังต้องถ่อสังขารไปเหมาซื้อถึง Northan ....

แต่ถ้าเมื่อยมากๆ ละก็นะ ....
จำได้ว่า ลูกธนูธาตุ เราทำเองได้อะค่ะ
วิธีทำ มีบอกในบอร์ด อาเชอร์ แต่ จะโพสไว้นี่ละกันค่ะ
1.ซื้อ Wooden Arrow 200 อัน
2. หินซัมมอนธาตุที่เราต้องการทำ 1 ชิ้น
พอได้ 2อย่างนี้ ก้ ไปแมพที่มีภูติตามธาตุที่เราต้องการทำ คุยกับภูตินั้นๆ จะได้ลูกธนูธาตุ
ตามต้องการ มา200ชิ้นค่ะ ทำได้ทีละ200ลูก=2เควสแล้วอะค่ะ
ถ้าจะทำมากกว่านี้ ก้ เตรียมของไปตามอัตราข้างต้นคือลูกธนู200 ดอกต่อ
หินซัมมอน 1ชิ้น ลองทำดูนะคะ ^^
