โอ้ ขอขอบคุณุณ LiTtLeLiGeR มากๆ เลยขอรับ ^ ^ ชื่ออังกฤษที่คาดไว้ก็ราวๆ นี้แหละฮะ

แต่ผมไม่ค่อยถนัดภาษาอังกฤษสักเท่าไหร่ >_<" กลัวใช้ศัพท์ผิดๆ จะขายหน้าเอาแฮะ

ล่าสุด ตอนนี้ฟิคสะดุด เพราะ " หวัด " ครับ >.,<" แต่ยังไงตอนนี้ความคิดในหัวได้เรียบเรียงไว้พร้อมจะบรรเลงแต่งสรรลงไปยังหน้ากระดาษแล้วล่ะฮะ แต่นอกจากหวัดแล้ว ผมยังโดนน้องสาวตัวกวน " ยึด " คอมอีก T^T" เมื่อไหร่จะเปิดเทอมกันนะ

( << รู้สึกตัวเองไม่ใช่สายโลลิหรือซีสค่อนเอาเสียเลย >_<" )

ปล. เรามาเล่นกิจกรรมกันเล็กๆ ดีกว่าครับสำหรับเพื่อนๆ ชาวฟิคชั่น Saga of Acronia โดยหใต่ละคนแนะนำตัวเองฮะ ( รู้จักกันมาตั้ง 14 หน้ากระทู้แล้ว แต่ผมยังไม่ค่อยแม่นชื่อของแต่ละคนเลยฮะ ) กระผมชื่อไอซ์นะ อยู่ริง Going Merry และพอ Open แล้วจะเล่น Gambler สาว ชื่อ Aero ขอรับ ^ ^" ( หวังว่าคงไม่มีใครแย่งชื่อเนอะ >_<" ) ถ้าเจอกันก็ทักทายได้เลยนะคร๊าบ ( แต่สำนวนพูดจาจะเป็นเหมือนจำแลง Aero จังมาใช้ในเกมส์เลยล่ะฮะ ดังนั้นเห็นผม คะขา นี้ไม่ใช่ผมเป็น... น๊า *0* ~ )

ปล. 2 นิยายตอนต่อไป มีคนนึงที่จะต้องจบชีวิตลง !!! เศร้าจัง T^T" แต่เป็นใครกันนั้น... หึหึ ( รอหน่อยนะคร๊าบ ทุกๆ คน >.,<"/ )
