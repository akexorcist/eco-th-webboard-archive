Tip & Trick

โดย ECO » ศุกร์ 12 มิ.ย. 2009 11:18 pm


1. อยากได้มันโตเร็วๆ ใช้ยาเร่งให้โต พ่นที จาก 42 นาทีเหลือ 3 นาที
(แต่ละต้นใช้เวลาไม่เท่ากัน)(ยาเร่งแมร่งโคดแพง ซื้อทีปลูกไปอีก 8 ต้น)

2.พอได้เกสรมาแล้ว ตรงช่อง N/A จะหายไป กลายเป็นผงขาวๆวาวๆ
นั่นคือเกสร ลากมาใส่ต้นอื่นเพื่อผสมได้เลย (แต่ต้นนั้นต้องโตก่อนนะ)

3.พอเวลา มีแมลงมา พยายามจับไว้ เพราะมันคือ คอเล็คชั่นของเรา

4.เวลาขายของแล้ว จอต้องอยู่ที่หน้าจอร้านขายของนะ
ถ้าเปิดร้านแล้ว กลับมาที่โรงเรือน นั่นคือปิดร้านไป

5.เมื่อเวลาผสมเกสรแล้ว รอสักครู่ มันจะมีเมล็ดมาให้ เพราะฉะนั้น
เมื่อผสมแล้วอย่าเพิ่งขาย รอให้ออกเมล็ดมาก่อน จะได้ไม่เปลืองค่าเมล็ด

6.เมื่อได้เมล็ดแล้ว ลากเก็บไว้ที่ช่องเก็บเมล็ดได้ทันที
ถ้าช่องไม่พอ(มี8ช่อง) เอาไปเก็บในลิ้นชักแทน

7.เวลารดน้ำ ไม่ต้องคลิกเมาส์ หลายๆทีเพื่อรดจนเต็ม คลิกค้างไว้

8.ยิ่งเราตกแต่งร้านขายต้นไม้ดีแค่ไหน ลูกค้าก็จะมากขึ้น
และโอกาสซื้อมากขึ้นด้วย

***9.นาฬิกามุมขวาล่างของคอมฯ กดโลดดด***
------------------------
การปรับปรุงสายพันธุ์
1) Fourpetal Maple
= Citrus Ball Cactus + Jalapa Maranta
--> Jalapa Maranta = Spotted Ball Cactus + Citrus Reptans

2) Rosaceae Fern
= Jalapa Maranta + Bluestar Astera
--> Jalapa Maranta = Spotted Ball Cactus + Citrus Reptans
--> Bluestar Astera = Jalapa Maranta + Spotted Reptans

3) Nox Orchid
= Spotted Reptans + Rosaceae Fern

4) Fabled Lemonbush
= Jalapa Maranta + Fragrant Maple
--> Fragrant Maple = Fourpetal Maple + Jalapa Maple
--> Jalapa Maple = Citrus Ball Cactus + Spotted Maranta
--> Spotted Maranta = Spotted Ball Cactus + Spotted Reptans

5) Mela Rare Oak
= Citrus Ball Cactus + Venomous Lemonbush
--> Venomous Lemonbush = Fourpetal Maple + Citrus Maranta
--> Citrus Maranta = Citrus Reptans + Citrus Ball Cactus

6) Aureus Scandens
= Fourpetal Reptans + Venomous Grass
--> Fourpetal Reptans = Spotted Reptans + Citrus Reptans
--> Venomous Grass = Citrus Reptans + Fourpetal Astera
--> Fourpetal Astera = Citrus Reptans + Jalapa Maranta
