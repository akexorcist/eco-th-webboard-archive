เนื่องจากผมมี มาทาดอ +10 อยู่ตัวนึงแต่ผมไม่รู้จะเอาไปหลอมกับอะไรผมจึงนำไปฝากเข้าคลังไว้แล้วพอมาเปิดดูมานกลายเป็นแบบไม่ได้ + อะไรเลยคับ - - แต่พอเอาออกมานอกคลัง มานก็+10 แต่พอใส่กลับเข้าไปใหม่ก็ไม่ + - - มีตัวเดียวในคลังคับ งงว่ามานทำไมเป็นแบบนี้ ฝากจีเอมด้วยนะคับ
