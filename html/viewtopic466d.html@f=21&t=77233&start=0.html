ฉันอาบเสร็จแล้วเดินไปที่ห้องแต่งตัว ห้องมืดนิดหน่อยแต่ฉันไม่ชอบเปิดไฟเวลาใส่เสื้อผ้าน่ะ = =(ไม่อยากมองผิวตัวเอง ยังเศร้าไม่หายT__T^) แต่ฉันต้องชะงักเพราะมีเงาบางอย่างมาอยู่ข้างหลังฉัน หรือว่า....ไม่นะคงไม่ใช่ ฉันเจอเรื่องมิดีมิร้าย T[]T(ผีเหรอ!!!)ฉันหันไปดูทั้งที่ยังไม่ได้ใส่อะไรซะอย่าง(นุ่งผ้าเช็ดตัวอยู่)
