ม่อนสูงกว่าตัวเองมันจะติดลำบาก

ถึงม่อนระกับเดียวกัน บางทีมันก็ติดลำบากนะ

บางที ร่ายไปห้าหกที ยังไม่ติดเลย

เราว่าค่า int น่าจะเกี่ยวนะ

แต่ชาวนาที่ไหนจะอัพ int กันเพื่อ สกิลนี้ล่ะ

เพราะหาประโยชน์ลำบากมาก

ตีก็ไม่ได้แรงหรอกนะ อย่าไปหวังกับมันมาก

ทางที่ดีอัพไว้สนุกๆๆขำๆๆ สักรอบ แล้วรอบหลังก็อย่าไปอัพมันออีก

เรื่องระดับไม่แน่ใจ เพราะตอนที่ได้สกิลนี้ก็เวล 70 กว่าแล้วมั้ง
โดยส่วนตัวไม่รู้ว่า int เกี่ยวไหม แต่เราไม่ได้อับ int เลย ถ้าถามว่าติดไหม ตอบว่าติดประมาณ 50%
ปัจจัยสำคัญคือ ระดับของสกิลที่ใช้ (1 2 3 4 หรือ 5)
