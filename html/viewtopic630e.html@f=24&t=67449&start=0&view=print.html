จริงๆมีคนเคยพูดหลายรอบล่ะนะ ลองหาดูเองก่อนล่ะกันนะครับ ผมจะสรุปสั้นๆว่า

1.ไปที่หอรบฟุจิกิข้างใน

2.คุยกับnpc ใส่หน้ากากฟุจิกิ รับเควส

3.เลือกไปเกาะนักบวชหญิง คุยกับคนในบ้าน

4.มาคุยกับnpc หน้ากากฟุจิกิอีกครั้ง

5.ส่งกับป้าอีกที

6.มาคุยกับเจ้าหน้ากากอีกครั้งเป็นอันจบ เขาก็จะพล่ามๆไปเรื่อยๆก็กดตกลงเออ ออไป

ล่ะก็ไปเกาะนักบวชหญิงใหม่ ทีนี้ลองคุยดูก็จะหลอมได้ล่ะครับ
