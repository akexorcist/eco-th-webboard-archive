เอาเท่าที่รู้/เคยได้ยินนะ
---ปืนสั้น
ระยะยิง 4-5ช่อง
ความสามารถ +L.hit 10(มีอยู่อันนึงไม่+) สามารถใช้ FastDrawได้ พลังโจมตีสูง
สายที่เหมาะ คิดว่าน่าจะVit

---ปืนคู่
ระยะยิง 4-5ช่อง
ความสามรถ มีสกิลเพิ่มความแม่นยำ สกิลสาดกระสุนจะยิงเพิ่ม1นัด สกิลส่วนใหญ่ที่ยิงนัดเดียวจะเอาATKปืนมาx2ก่อน เวลายิงASPDจะเหลือ2/3 แต่จะยิงทีละ2นัด (ถ้าAGIน้อยๆ จะยิง2นัดแล้วเว้นช่วงยาว แล้วค่อยงัดมายิงใหม่) มีความเท่อยู่ในระดับสูง(??) และสุดยอดความสามารถที่มอาจจะลืมเลือนได้คือ ปืนคู่ จะฉีกกระเป๋าตังผู้ใช้ได้ในระยะเวลอันสั้น(ของทำก็แพง เปลืองกระสุนอีก แต่เท่ = =)
ความน่ากลัว อยู่ที่สกิล OverRange + GunDelayCancel (รัวไกลแรง)
สายที่เหมาะ AGIชัวร์ = = ไม่งั้นจะยิงแบบ อนาถาอย่างแรง

---ปืนไรเฟิล
ระยะยิง 8ช่อง
ความสามารถ ยิงไกล!! ยิงได้ไกล!! และระยะยิงไกลมาก!!!(แล้วอิ3ข้อนี้มันต่างกันตรงไหนฟระ) ATKค่อนข้างต่ำ แต่ก็ไม่ได้ต่างกันมากมายจนน่าตกใจ รวมกับOverRangeจะได้ระยะยิง11ช่อง(เกือบๆหลุดจอเลยมั้งน่ะ) แต่อย่าลืมว่ายิ่งไกลก็ยิ่งเบา แม้จะมีShotStanceก็ตาม
สายที่เหมาะ น่าจะSTR เป่าหัวคู่ต่อสู้ได้ตั้งแต่ระยะไกลๆเลย

สกิลที่ควรอัพก็มาสเตอรี่ของปืนชนิดนั้นๆ กับสกิลบางอย่างที่มันซัพพอร์ตปืนชนิดนั้นๆด้วย(เช่น FastDraw หรือ เพิ่มความแม่นยำของปืน2มือ) และก็พวกสกิล Plurality Bullet /Bust Shot /Charge Shot /GDC ให้ยิงเร็วขึ้นและลดดีเลย์สกิล ส่วนOverRangeไม่แน่ใจว่าสำหรับไรเฟิลจำเป็นมากมั้ย และก็Bullet Dance
ส่วนสกิลอื่นๆ ไม่ค่อยแน่ใจ แล้วก็CQBก็น่าสนเหมือนกัน

เอาเป็นว่า อ่านไกด์กันเนอร์เหอะ จบ = ="
