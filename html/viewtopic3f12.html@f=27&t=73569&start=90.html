ได้ความรู้เพิ่มล่ะ เกี่ยวกับทรงผม

ถึงจะรู้รหัส แล้วแค่เอาไปแทนก็ไม่ได้หรอก (หมายถึงเอาไปทับ)

เพราะทรงผม มันจะมี 2 อย่าง เช่น ทรงทวิน มันจะมีจุกผมอีก ซึ่งแยกรหัสจากกัน

ว่าแล้วทำไมเปลี่ยนทรงผม ทวิน ไม่มีปัญหา แต่เปลี่ยนทรงอื่นมีปัญหา เพราะมันเรียกไฟล์ 2 อัน

พยายามอธิบายให้เข้าใจอยู่นะ ถ้าไม่เข้าใจก็ไม่เป็นไร ; w ;

ทรงทวิน หลัก รหัสคือ 03_31 จุกหลังผมคือ 04_44

ทรงทวินสั้น รหัสคือ 03_89 จุกหลังผมคือ 04_44

ตอนเอาไปทับเลยไม่เกิดปัญหานี่เอง

คราวนี้ทำทรง อามุ ในเรื่อง Shugo Chara ว่าอยู่ทำไมมันไม่มีจุกผมติดมาด้วย

เพราะมันใช้รหัสอื่น นั่นคือ 04_74

แถมทรงผมที่ใช้แทน ก็ดันไม่มีจุกผมอีก เท่ากับว่า

"ถ้าจะเปลี่ยนทรงผม โดยการเอาไปทับ ต้องทับ ทั้งรหัสผมหลัก พร้อมกับจุกผม"

; w ; เหมือนบังคับยังไงไม่รู้


ถ้ามีไฟล์ .csv ที่เกี่ยวกับรหัสผม คงง่ายดีนะ แค่เปลี่ยนเลขการแสดงผลเหมือนพวกเสื้อก็คงดี

ไหนๆ ก็ทำมาแล้ว เอามาแจกที่นี่ด้วยละักัน

แต่ไม่รับรองความสมบูรณ์ 100% นะ

ยังไงก่อนทำก็โหลดไฟล์ไว้ให้ครบก่อน แล้วก็ Copy ECO ไว้หลักๆ

แล้วก็ค่อยกดลงทีเดียว แล้วดูผลเอา หรือจะยังไงก็แล้วแต่ท่านๆ ละกัน

เพราะทางนี้ทำแล้วไม่มีปัญหาง่ะ (ก็ไม่รู้สาเหตุเหมือนกัน)

1. เปลี่ยนท่านั่งเหยียดขาเป็นเต้น http://www.mediafire.com/?rnvdtmo2d3u

2. เปลี่ยนพัดทั้งหมด กลายเป็นไมค์ แล้วร้องเพลงท่าที่4 http://www.mediafire.com/?mel2mmiydmj

3. เปลี่ยนท่าเป่าขลุ่ย กะ ตัวขลุ่ยเป็นไมค์ http://www.mediafire.com/?qldyezdtitz

4. เปลี่ยนท่าหนังสือพิมพ์ กะตัวหนังสือพิมพ์หรือนิตยสาร http://www.mediafire.com/?2kyzddwzthh

5.เปลี่ยนพรุ เป็น ไมค์ กะท่าถือเป็นร้องเพลงท่าที่1 http://www.mediafire.com/?nmtnzmzoyqz


ปล. ท่าร้องเพลงมี 4 แบบ อีก 2 แบบจำไม่ได้ว่าท่าที่เท่าไหร่ ที่เปลี่ยนไว้

Edit :

สำหรับผู้ที่โหลดไปแล้ว มันไม่เปลี่ยนผลตาม คือการแสดงผลของไอเท็มไม่สมบูรณ์ หรือท่าเต้น ฯลฯ

ตอนแตกไฟล์ ให้ไปแตกไฟล์ไว้ที่อื่นก่อน แล้วเข้าไปแก้ไข Folder Chara ให้เป็น Chara2
(แก้ชื่อ)

เสร็จแล้วนับไปวางไว้ที่ Folder ECO เหมือนเดิม แล้วกด rebuild

คิดว่าคงได้ผลนะ

ปล. เพราะว่ามีบางไฟล์ มันไม่ได้อยู่ที่ folder chara แล้ว การไปทับ จึงไม่เกิดผล ต้องไปทับให้ถูก folder
แบบนี้เล่นแก้ itempict คงจะดีกว่า ... ; w ;
