ตกลงที่เคืองนี่ เคืองที่รางวัลโดนเบียดเหรอครับ
แล้วไอ้ที่ว่ารัก ECO หรืออยากให้คนเล่น ECO ส่งมากกว่า ตอนแรกอะไรนั่น มันคืออะไรครับ
ไม่ต้องอ้างมาก็ได้นะครับ มีอะไรก็พูดกันตรงๆ - -'



เพราะนกรู้สึกว่าที่คุณเริ่มทำแฟนอาร์ตก็เพราะตัวนกเองไงคะ

เพราะนกทำตัวเอง เลยต้องมานั่งเจ็บใจแบบนี้ไง

ทั้งที่คุณคงไม่คิดจะทำแต่แรก ถ้านกไม่เอางานไปให้คุณดู นกเข้าใจว่าแบบนี้


ง่ายๆ มันก็หมายความว่า ที่นกยกตัวอย่างมาว่า ถึงนกแพ้คุณKaskiaนกก็ไม่เสียใจ

เพราะเค้าเป็นคนเก่าแก่ของECO นี่ก็เป็นเรื่องจริงค่ะ

แต่ถ้าแพ้คุณ ที่พอมาเห็นงานนกก็เลยให้กำเนิดงานขึ้นมาด้วย แล้วก็เพิ่งจะโหลดเกมมาเล่นหลังจากเห็นงานนก นกเสียใจค่ะ

ถูกมั้ยล่ะ ที่งานคุณสวยกว่าจนเบียดนกตกขอบ

แล้วที่คุณเล่นอิโค่เริ่มทำแฟนอาร์ต ก็เพราะนกเอางานไปให้คุณเอง

แล้วนกมีเหตุผลอะไรที่จะไปเจ็บใจ รึเคืองคุณKaskiaเค้าด้วยล่ะคะ

อันนี้ผมค่อนข้างเห็นด้วยนะครับ
เป็นผมผมก็เจ็บใจนะถ้าลงประกวดงานอะไรสักอย่างแล้วไปปรึกษาคน
หลังจากนั้นคนคนนั้นดั้นลงประกวดด้วยหลังจากเราไปปรึกษา

แปลว่าไม่ว่าใครก็ตามที่เห็นงานนกคุงก่อน ก็ส่งประกวดไม่ได้เหรอครับ
เห็นงานนกคุงที่จะส่งประกวดแล้ว วาดส่งบ้างไม่ได้เหรอครับ
แล้วผมทำงานสวยกว่านกคุงไม่ได้เหรอครับ -__-'' ( ซึ่งจริงๆผมถามจากเพื่อนผม เขาก็ไม่ได้คิดว่ามันสวยกว่าอะไรขนาดนั้น คิดมากไปรึเปล่าครับ )
แล้วแปลว่า ถ้าผมส่งงานทีหลังที่ได้เห็นงานนกคุง แล้วออกมาห่วยกว่านกคุง
นกคุงก้จะไม่ออกมาตัดพ้อต่อว่าหรือเปล่าครับ

ตรรกะมันแหม่งๆครับ -__-'

ส่วนเรื่อง kaskia ผมไม่ขอตอบนะครับ เพราะไม่เกี่ยวกัน นกคุงจะเคืองหรือไม่เคือง kaskia ก็ไม่ได้เกี่ยวกับประเด้นนี้เลย ไม่ต้องยกมาก็ได้ครับ = =''

( เรื่องน่ารู้* การประกวดยังไม่ได้ตัดสิน อย่าเพิ่งจิตตกไปสิครับ ที่ 1 อาจจะเป็นคนอื่นที่ไม่ใช่ผมก็ได้ -____-'' ทำไมต้องคิดว่าผมต้องได้รางวัล ไปเบียดตกงานใครด้วย ไม่เข้าใจครับ )

สั้นๆง่ายๆค่ะ

นกเสียความรู้สึก ไม่ได้ตั้งใจจะประจาน

ใจเค้าใจเราดูค่ะ เพื่อนนกเค้าก็บอก ว่าถ้าเป็นเค้า เค้าก็เสียความรู้สึกไม่ต่างจากนก ถ้าโดนแบบนกขึ้นมา

แค่นี้นกก็พอใจแล้วว่านกไม่ได้จิตผิดปกติอะไร แค่คนธรรมดาที่ยังมีโลภโกรธหลง คนนึง

บอกแล้วค่ะ ว่านกไม่ใช่คนดีอะไรมากมาย ความรู้สึกมันก็ห้ามกันไม่ได้ค่ะ

นกไม่ได้บอกว่าคุณไม่มีสิทธิ์ส่งนี่ ไม่ได้พูดรึพิมพ์เลยซักนิด

แต่นกก็มีสิทธิ์จะรู้สึกแบบนี้ค่ะ

ขอโทษไปตั้งหลายครั้งแล้ว จะให้นกทำยังไงอีกคะ
