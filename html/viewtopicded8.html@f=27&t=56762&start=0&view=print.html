สำหรับสายแชท555
ถ้าเราคุยอยู่ในช่อง Open
เมื่อพิมข้อความเสร็จแล้วกด Ctrl+Enter
จะส่งไปที่ปาร์ตี้
ถ้ากด Alt+Enter
จะเป็นการส่งข้อความในริง

แต่ถ้าอยู่ในช่องคุยริง แล้วกด
ถ้ากด Alt+Enter
จะส่งข้อความในช่องOpen
(ก็ตรงข้ามกันแหละ เอาเป็นว่า Ctrl=Party Alt=Ring)

แต่สำหรับซาก้า6แล้วมีอีกระบบเพิ่มเข้ามาคือ Chat
ทำให้คุยรวมเป็นกลุ่มๆกันได้
สำหรับบางคนที่ยังไมรู้
เราสามารถทำให้ข้อความช่องChatขึ้นในช่องคุยรวมของเราได้
โดย

Option>ควบคุมอันที่2>หลังจากการเปลี่ยนเเมบทำการตั้งค่า Camera = Off

แล้วเวลาเราจะพิมล่ะ? ต้องกดที่ตัวCตลอดหรือ?
พึ่งค้นพบได้ไม่นานนี้- -*...(มะกี้เอง)
เมื่อพิมข้อความเสร็จให้เรากด Crtl+Alt+Enter จะทำให้คุยทางช่องChatได้
(หรือลองCtrl+Alt+Delete 2ทีก็ได้นะ 55)

สรุปรวบยอดอีกทีล่ะกัน
Ctrl=Party
Alt=Ring
Crtl+Alt=Chat
