tata น่าจะเป็นคำย่อมากกว่าคำเต็ม และไม่ได้มาจากคำว่า tataki เท่านั้น
แต่ tata ก็อาจจะมาจากคำว่า tatamaru ซึ่งแปลเป็น ภาษาอังกฤษว่า to be folded
(โฟลดฺ) {folded,folding,folds} vt. พับ,ทบ,ห่อ,ไขว้,ปิด,ผนึก,หุ้ม,ผสม

ตามหลักแล้ว tata'rabe เป็นสาย Back Packer ทำให้ความหมายนี้ใกล้เคียงเข้าไปอีกหน่อย

ผมขอยก คำว่า rabe จากข้างบนมาใช้ก่อน เพราะยังหาคำอื่นไม่ได้
"raberu ( ラベル ) ซึ่งตรงกับภาษา อังกฤษ แปลว่า label แปลเป็นไทยว่า ฉลาก,ป้าย,คำอธิบาย,คำนิยาม,เครื่องหมาย,สัญลักษณ์,ฉายา vt. ติดฉลาก,ติดป้าย,ตราหน้าอธิบาย,แบ่งแยกประเภทหรือชนิด"

ถ้าเอามารวมๆแล้ว tatarabe มันก็คือ "พวกบ้าหอบฟาง" แล้วจะต่างไปจาก Back Packer ไปได้ยังไง tatarabe = Back Packer ตรงตัวอยู่แล้ว ไม่ต้องแปล
แต่ tatarabe ต่างจาก Back Packer ทั่วไปตรงที่ พวกนี้สามารถแยกแยะสิ่งของต่างๆที่อยู่ในตัวเขาได้อย่างดี เรียกได้ว่าเขาคือ "ผู้ที่รู้จักไอเทม ทุกชนิด"

ผมว่าน่าจะได้ข้อสรุปบ้างแล้วเน่อ อันนี้ผมว่าเข้าเรื่องมากกว่าอันอื่นนะ
