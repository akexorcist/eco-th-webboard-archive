ไม่ต่างครับ

แต่ dark shield มันเพิ่มแค่ 50

ส่วน dark limit ผมไม่ทราบตัวเลขแน่ชัด แต่จากที่ลองอัพเลเวล 3 มันโดนแรงกว่า dark shield แน่ๆ ก็สรุปว่ามันเพิ่มมืดไ่ม่ถึง 50 อาจจะซัก 20-30

พอคิดๆรวมชุดแล้ว ยังไงก็ไม่น่าเกิน 100 ครับ หรือถ้าใส่ครบจริงๆอาจจะเกินได้นิดหน่อยมั๊ง

ส่วนจากสูตร ถ้าทั้งตัวคน 100 และแมพ 100 (ใช้ DPC เอาก็ได้) ดาเมจก็จะออกมาเป็น 0
