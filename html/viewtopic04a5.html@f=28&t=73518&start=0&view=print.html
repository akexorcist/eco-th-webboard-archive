ECO Flying Garden ScreenShot Contest ประกวดภาพเด็ดโดนใจหัวข้อ "โรงเรียนในฝันกับ ECO" เริ่ม 25 พ.ค. - 14 มิ.ย. นี้








กิจกรรม ECO Flying Garden Screenshot Contest กับหัวข้อ "โรงเรียนในฝันกับ ECO" มาร่วมกันสร้างโรงเรียนในฝันสไตล์ชาว ECO กันดีกว่า งานนี้มีรางวัลแหล่มๆ รออยู่ไม่ว่าจะเป็นเสื้อยืด ECO, แก้วน้ำ ECO หรือแผ่นรองเม้าส์ ECO ที่ส่งตรงจากเกาหลี รวมถึงไอเทมน่ารักๆ มาให้เพื่อนไปใช้กันเลยฟรี!! อยากทราบกติกากันแล้วใช่ไหม อย่ารอช้าไปดูกันเลยค่า ^^v



ระยะเวลากิจกรรม"ECO Flying Garden Screenshot Contest"

โพสภาพเข้าประกวด : วันที่ 25 พ.ค. (14.00 น.) - 1 มิ.ย. (18.00 น.)

เปิดโหวตขวัญใจชาวบอร์ด ECO : วันที่ 2 มิ.ย. (12.00 น.) - 14 มิ.ย. (15.00 น.)

ประกาศผล : วันที่ 15 มิ.ย. (18.00 น.)

กติกาการร่วมสนุกกับกิจกรรม "ECO Flying Garden Screenshot Contest"

1. ผู้ที่จะส่งภาพเข้าประกวด จะต้องมีสถานะเป็นสมาชิก Onenet Member


2. สมาชิก Onenet Member 1ไอดี ต่อ 1 บัตรประชาชน สามารถส่งภาพเข้าประกวดได้เพียง 1 ผลงานเท่านั้น 1 Member ใน Web board ECO สามารถโพสรูปกิจกรรมได้ 1 ครั้ง 1 Reply เท่านั้น

3. ภาพที่ส่งประกวดจะต้องเป็นภาพถ่าย Screenshot ในเกม ECO เท่านั้น โดยจะต้องสื่อถึง "โรงเรียนในฝันกับ ECO" ซึ่งภาพที่เข้าประกวดเป็นมุมไหนหรือส่วนไหนของ Flying Garden ก็ได้ที่สื่อถึงหัวข้อที่ใช้ประกวด ห้ามผู้ส่งประกวดสใช้โปรแกรมตกแต่งเพิ่มเติมใดๆ ทั้งสิ้น

4. สามารถส่งภาพได้ที่เว็บบอร์ดเกม ECO ทางทีมงานจะเปิดกระทู้ในหมวดกิจกรรมและประกวด ในหัวข้อ "Flying Garden Screenshot Contest" ตามกำหนดระยะเวลาเริ่มกิจกรรม ซึ่งมีเงื่อนไขการโพสภาพเข้าประกวดดังนี้

- ภาพที่ส่งเข้าประกวดจะต้องมีขนาด 800 x 600 pixels เท่านั้น
- ภาพที่ส่งเข้าประกวดจะต้องเป็นไฟล์ .jpg เท่านั้น
- ระบุข้อมูลประกอบรูปภาพ ดังนี้
1. ชื่อรูป Screenshot ที่ส่งเข้าประกวด
2. คำอธิบายสั้นๆ ไม่เกิน 2 ประโยคเพื่ออธิบายรูป Screenshot ที่ส่งเข้าประกวด
3. Character Name ระบุชื่อตัวละครที่ส่งเข้าประกวด
4. ระบุ Server ของผู้ที่ส่งเข้าประกวด
ตัวอย่าง
ชื่อรูป : School in the forest
คำอธิบาย : โรงเรียนน้อยในป่าใหญ่
Character Name : [GM]Neko
Server : Takoyaki
*กรุณาเก็บภาพต้นฉบับไว้ด้วยนะคะ
5. ภาพที่ส่งประกวดจะต้องเป็นภาพที่ผู้ประกวดถ่าย Screenshot มาเองมิใช่ภาพของผู้อื่น และไม่เคยนำไปประกวดที่ใดมาก่อน หากพบว่าผู้ประกวดได้ก๊อปปี้งานของผู้อื่น หรือ นำมาเปลี่ยนแค่บางส่วนจะตัดสิทธิ์ทันที

6. ผู้เข้าร่วมประกวดที่ทำการโพสรูปเข้าประกวดเรียบร้อยแล้ว ห้ามทำการ Edit แก้ไขภายหลัง หากทีมงานตรวจพบจะทำการตัดสิทธิ์ทันที หรือหากมีความจำเป็นในการแก้ไขให้ PM แจ้งเพื่อให้ทีมงานรับทราบก่อนจะทำการแก้ไข

7. เมื่อสิ้นสุดระยะเวลากิจกรรมทางทีมงานจะทำการล็อคกระทู้กิจกรรมกรรมและทำการคัดเลือก 10 ภาพที่ดีที่สุด เพื่อแจกของรางวัลตามลำดับ 1 - 10 จำนวน 10 รางวัล และรางวัลพิเศษ ขวัญใจชาวบอร์ด ECO จำนวน 5 รางวัล โดยรางวัลพิเศษนี้จะมาจากการโหวตคะแนนสูงสุดจำนวน 5 อันดับ การตัดสินของทีมงานถือเป็นที่สิ้นสุด

8. หากทีมงานตรวจพบว่าผู้ร่วมกิจกรรมมีการทุจริต หรือกระทำการเอาเปรียบผู้ร่วมกิจกรรมท่านอื่น ทางทีมงานจะทำการระงับไอดีทันที

9. บริษัทฯ ขอสงวนสิทธิ์ในการนำภาพที่ส่งเข้าประกวดในครั้งนี้ไปใช้ในโอกาสต่อๆ ไป

10. บริษัทฯ ขอสงวนสิทธิ์ในการเปลี่ยนแปลงเงื่อนไขต่างๆ ได้โดยไม่ต้องแจ้งให้ทราบล่วงหน้า
