บวกกับ Divine Barrier ของ Sorcerer hock:

อิ้น 100 mdef ตัวหน้าเพิ่มมาราวๆ 30 กว่าๆเองครับ

อีกครึ่งได้จาก vit

แล้วก็สกิลโอน int ของเซจ จะโอน int ไปจำนวนหนึ่ง ให้ int ของคนรับ เท่ากับคนโอนแค่นั้น

อย่างเช่น คนโอน int 100+10 คนรับ 5+10

พอโอนก็จะกลายเป็น 5 + 105 กลายเป็น 110 เท่าคนโอนครับ

ถ้าโอนให้คนที่ int เท่ากับเรา หรือ int น้อยกว่ามันจะ miss

สรุปคือไม่มีประโยชน์เลยสำหรับไนท์ vit int

สำหรับไนท์ โดนเวท 0 ก็ลงแต่ vit int นั่นแหล่ะ แต่ไม่รู้ว่าลงเท่าไหร่บ้าง

ให้ mdef ตัวหน้า มากกว่า 65 ใส่ เกราะเวทของซอ +35 ก็จะได้เกิน 100
