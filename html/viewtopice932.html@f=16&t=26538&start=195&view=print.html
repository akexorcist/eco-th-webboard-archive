หมวดงานไม้

- Piece of Tree : หาจากต้น Wood และ กล่อง Box , Treasure
- Wood : หาซื้อได้ที่คนขาย Furniture ทุกเมือง , หาจากต้น Wood
- Strong Wood : หาจาก Fallen Tree ริมชายหาด กับ Soul Tree ในดันฟาร์อีส
- Log : หาจาก Fallen Tree ริมชายหาด (หายาก)
- Big Log : หาจากต้น Wood (หายาก)

- Zedar Wood : หาจาก Fallen Tree และการเปิดกล่อง (หายากมาก)
- Zedar Branch : หาจาก Unname Tree ที่แมพรอบๆ Light Tower ชั้นล่างสุด
- Earth Branch : เปิดกล่อง,Unname Tree(ยาก)

ตอนผมหา log เอามาทำสวนอะครับผมได้ Zeder Wood มา2อันแต่มันตกจากต้น wood ทั้ง2อันเลยอะครับเลยมาบอกไว้ไม่รู้ว่าข้อมูลมีอะไรผิดพลาดรึเปล่าอะครับ
ออแล้วอีกอย่างนึงพอจะรู้ไหมครับว่า Green Wood ไว้ทำไรอะตีขอนไม้แล้วมันร่วงมาอันนึงอะ
