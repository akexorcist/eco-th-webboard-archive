โพสต์แล้ว: เสาร์ 15 ธ.ค. 2007 2:13 pm
โดย ECO
มาละจ้ากับภาพกิจกรรรมล่าบอสหรรษา ละลายเปอร์สุดขั้ว!!!! งานนี้ต้องขอบอกไว้ก่อนนะค่ะ ว่าเป็นอะไรที่บ้าบิ่นมากๆ

เนื่องจากบอสตัวนี้ มีผู้รู้จักน้อยมากๆ บางคนถึงขนาดกับ เฮ้ยยมีด้วยหรอ

แต่อย่างไรก็ตามแต่ต้องขอขอบคุณเพื่อนๆทุกๆคนนะค่ะ ที่สามารถฝ่าฟันจนทำภารกิจการละลายเปอร์ครั้งนี้ได้สำเร็จ

ไปชมภาพบรรยากาศพร้อมๆกับเรากันเลยค๊า

เปิดมาก้มีผู้เคราะห์ร้าย พี่เป้ของเราลงไปนอนกองกับพื้นซะแล้ว
แว่วมาว่าตอนนี้พี่เค้าชอบทุบบอสตุ๊บๆ มากกว่านั่งขายของซะแล้ว คิคิ



วิ่งสู้ฟัด 3 วิ่งกันหอบแฮกๆก็ห้ามหยุดT^T เพราะมัน
จะโดนวาซาน้อยดูดเลือดจ๊วบๆ จนตายนะสิ เอ้าวิ่งๆ




ในที่สุดกองหนุนพี่กิม มิ้น ตั้ม ก็มาถึงซะที มามะ
มานอนตายเป็นเพื่อนกันหน่อยย



สุดท้ายเจ้าบอสต้นไม้ก็ลงไปนอนกองกับพื้น ด้วยแรงกายแรงใจของพวกเราชาวHMทุกๆคน
งานนี้พระเอกของเราคือเหล่านักวิ่งผลัดวาซาบิ4*100เมตรชายอันได้แก่
ทั่นเดียว ทั่นอุ๊บ นู๋ไอซ์ และ พี่บี ที่ช่วยกันวิ่ง





จบภารกิจ ก็ถึงช่วงเวลาแชะภาพแห่งความประทับใจ
งานนี้กองหนุนอย่าง พี่กิม มิ้น ตั้ม จองแถวหน้าสุดซะเลย คิคิ
ขอลุงเกิดหน่อยว่างั้นเถอะ เอ้า หนึ่ง สอง ซั่ม แชะ!!!







แถมท้ายด้วยภาพกิจกรรมตุ้ยบอสหมา ขอบอกได้คำเดียวว่าแลค
หยุดเวทย์ไม่ทันบ่อยๆ แถมพี่ๆแอบบ่นมาว่านู๋ไอซ์ซนจนพี่ๆตายอีกแล้ววว
แง่มๆๆเด๋วเจ๊พาไปฝึกโหดซะนี่



งานนี้เด็กเล็ก หญิงมีครรภ์ไม่เชื่ออย่าหลบหลู่
เดี๋ยวของจะเข้าตัว อับดุลยังไม่กล้าหือ
ก็เพราะใครก็ตามที่เปิดกล่องครั้งแรก และครั้งต่อๆไปกับพี่กิมมักจะได้!!!!!!!มีดขว้าง ฟิ้วๆๆๆ นะสิ ว๊า ฮ๊า ๆๆๆๆ
เราเตือนทั่นแล้วน๊า โดนปายกี่คนละน๊า ว๊า ฮ๊าๆๆๆ ของเค้าแรงจิงๆ!!





สุดท้ายและท้ายสุดของกิจกรรมนี้ก็คงจะเป็นการพาพี่ๆน้องๆ ที่ยังไม่ได้พ้อยฟรีจากเควสแหวนไปทำกัน โดยแบ่งเป็น2กลุ่ม ทำชั้น 35และ 40 T^T สมรภูมิย่อยๆนี่เอง

เสียดายที่ไม่ได้เก็บภาพบรรยากาศมา ยังไงก็ต้องขอขอบคุณเพื่อนๆ พี่ๆ น้องๆ ที่อุตส่าห์สละเวลามาร่วมสนุก(ละลายเปอร์) กันนะค่ะ

แง่ว มะได้แวะมาดูเลย มาละจ้ะวิธีไปหาบอสต้นไม้

สำหรับเหล่าผู้กล้าที่อยากไป งานนี้สิ่งจำเป็นหนึ่งอย่างที่จะต้องมีคือ ชาวนา หรืออาเค หรือ มารีโอเนต ที่เลเวลสูงพอที่เราสิงได้ พร้อมPet แครอทน้อย 1ตัวจ้ะ

วิธีไป : ให้เพื่อนๆสิงอาชีพชาวนาที่พกPet แครอท และให้เดินไปที่แมพ EastorCape (ถ้าเขียนชื่อผิดต้องขออภัยนะค่ะ ) ให้ชาวนาคุยกับภูติดิน แล้วเราจะวาปเข้าสู่สมรภูมิเดือดจ้า

มอนเตอร์ภายในแมพ : วาซาบิล้วนๆเลยจ้ะ

ตำแหน่งบอสเกิด : ส่วนมากจะพบได้ตามชายหาดริมแมพ อีกทั้งไม่ค่อยมีคนมาล่า ดังนั้นจะไปตอนไหนก็เจอจ้ะ

ข้อควรระวัง : บอสต้นไม้นี้ ต่างจากบอสหมาที่เราฆ่าจนเหลือลูกหมา1ตัวแม่หมาจะไม่เรียกลูกใหม่ แต่บอสต้นไม้ จะเรียกวาซาบิใหม่อยู่ตลอดถ้าเราตีลูกมันตาย ( ไม่นับวาซาบิตัวอื่นๆในแมพที่คอยก่อกวนด้วยนะจ้ะ) และอีกข้อที่น่ากลัว คือเวทย์หมู่ของบอสต้นไม้ ที่ไม่ว่าเพื่อนๆจะพยายามวิ่งหนีวงเวทย์ แต่หากโดนเข้าให้แล้ว มันจะดูดตัวเพื่อนๆเข้าสู่จุดศุนย์กลางของวงเวทย์นั้นจนตายจ้ะ O_o'

ทริกเล็กๆน้อยๆ : ในที่นี้ไม่มีอะไรมากมายนอกจาก อย่างพยายามอยู่กับที่ให้วิ่งล่อวาซาบิ และล่าไม่ให้ตัวแม่ลงเวทย์ใหญ่ ก็จะช่วยประทังชีวิตเปอร์เซ็นน้อยๆของเพื่อนๆได้บ้าง

ไอเทมที่ดรอบ : ตรงนี้ไม่ชี้ชัด เพราะบ้างก้บอกดรอบคูเปอ แต่ที่ไปกันมาดรอบซิลเวอ เมเดลจ้า

สุดท้ายนี้เพื่อนๆคนไหนแวะเวียนไปเยี่ยมบอสตัวนี้ อย่าลืมแวะมาโพสเล่าสู่กันฟังบ้างนะจ้า

เครดิตบอส : คุณโดโรที ริง ดอลส์ จ้า
