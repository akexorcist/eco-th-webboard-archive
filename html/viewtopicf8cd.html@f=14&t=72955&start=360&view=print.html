Phantom Ass เขียน:แล้วแอสสายมีดเอาสกิลอะไรจากคอมไปดีครับ

ที่เลือกๆไว้ก็มี
1. Human Avoid (มะรู้ +พริ้วเท่าไหร่)
2. Martial Art Mastery (เอาไว้ + DMG สกิลจ๊อบ 50 คอม)
3. Wild Dance (+กับสกิลด้านบนเห็นว่าแรงดี)
4. Deadly Attack
5. Sum Command ( PVP +กับสกิลแยกร่าง 5 รุม 1 ท่าจะโหด)
6. Recovery block
7. Sliding (+พริ้ว)
8. Shocking gas (อันนี้วางทับบนพื้นที่ๆอีกฝ่ายยืนอยู่เลยจะเกิดผลไหมครับ หรือรออีกฝ่ายมาเหยียบอีกที)
9. Flash Handgrenade
10. Ashibarai

ช่วยแนะนำทีครับเลือกไม่ถูกเลย


ขอรีวิวทีละสกิลนะครับ จะได้เป็นตัวเลือกให้

* สีแดง = สมควรอัพ สีน้ำเงิน = น่าใช้, สีดำ = อย่าใช้เลย

1. Human Avoid : เพิ่มอัตราการหลบหลีกจากมอนส์เตอร์เผ่ามนุษย์ จริงๆแล้วจะใช้ได้ผลต่อเมื่ออีกฝ่ายทำการล็อคเป้า(คลิกที่ตััวละคร) มาที่เราเรียบร้อยแล้วครับ ซึ่งเอาตามจริงเวลาเราสู้คนก็ไม่น่าจะรอดพวกยิงเวท AoE อยู่แล้ว ส่วนพวกสายไฟท์ทั้งหลาย ถ้าไม่นับสายยิงไกลทั้งหลาย เราก็หลบได้ดีพอสมควรอยู่แล้วครับ

2. Martial Art Mastery : สกิลหมัดมวยพวกนี้ส่วนใหญ่เราจะเน้นด้านสถานะผิดปกติมากกว่านะ ไม่ได้เน้นแรงนะ ผมว่าไม่อัพก็คงไม่เป็นไรหรอก สกิลนี้

3. Wild Dance : เป้นท่าที่แรงก็จริง แต่เป้าหมายก็หลุดได้ง่ายเหมือนกัน ไม่เหมาะไว้ใช้สู้คน เพราะใช้ๆ อยู่เป้าอาจหลุดได้ แถมไม่แน่อาจโดนยิงตายระหว่างคอมโบ...

4. Deadly Attack : เป็นสกิลเฉพาะของสายมีด โอกาสติดเกร็งมีพอสมควร (60%) แนะนำให้ใช้คู่กับระเบิดแฟลชจะดีมาก เป็นสกิลที่ดีสกิลหนึ่ง แต่ไม่เหมาะไว้ใช้เปิดนัก

5. Sum Command : เหมาะไว้ใช้ป่วนมากกว่าเพราะดาเมจค่อนข้างเบา ใช้ขัดเวทขัดร่ายของพวกที่ร่ายสกิลนานๆ ทั้งหลาย แต่คูลดาวน์ก็นานได้ใจ....

6. Recovery block : สกิลตัดท่อลำเลียงอาหาร ใช้ได้ดีกับคน จะได้ไม่ต้องกลัวพวกปั้มของ แต่จะได้วิ่งไล่จับแทนนะ

7. Sliding : เหมาะที่จะใช้เป็นสกิลสำหรับหนีจากวงเวท AoE ทั้งหลายมากครับ แต่ต้องฝึกใช้หน่อยนะ

8. Shocking gas : สกิลดักสายเวท มาเหยียบก็ซวยไป ไว้ป่วนพวกสายเวท เหมาะมากไว้ใ้ช้ในวอให้สายเวทร่ายไม่ออก

9. Flash Handgrenade : สกิลแจกสตันที่ดีสกิลหนึ่ง เหมาะมากเวลาไว้ใช้สู้ 1-1 กับคน

10. Asibarai : สกิลป่วนอีกสกิล ไว้ขัดร่ายสายเวท มีของแถมคือเตะสิงอกได้ด้วยนะเออ
