รบกวนถามนิดนะครับ

พอดีสงสัยเกี่ยวกับสกิล Karasiro ของแอส กับ Sum Command ของคอม อ่ะครับ

1. Karasiro ถ้าตัวจริงถือมีด ร่างแยกจะถือมีดวิ่งเข้าไปฟันครับ ผมลองละ
แล้วถ้าตัวจริงถือปืนหรืออาวุธขว้าง ร่างแยกจะถือปืนแล้วยิงให้หรือเปล่าครับ หรือขว้างอาวุธให้หรือเปล่าครับ แล้วจำนวนกระสุนและอาวุธขว้างจะลดลงหรือป่าวครับ

2. Karasiro กับ Sum Command ใช้พร้อมกันได้หรือป่าวครับ เคยเห็นมีคนบอกใช้ได้ แต่พอไปดูดีเลย์ของ sum com 50 วิ นานมากเลยไม่แน่ใจอ่ะครับ

3. ร่างแยกของ Karasiro กับ Sum Command นี่เราใส่บัฟให้มันได้ไหมครับ

4. ร่างแยกของ Karasiro นี่จะแต่งตัว+ถืออาวุธเหมือนร่างจริงใช่หรือไม่

5. ร่างแยกของ sum command เป็น ช.สายสนับ/ญ.สายปืน แต่งชุดอาชีพ70 ทั้งคู่ใช่หรือไม่ คืออยากแยกออกมาเป็น 5 ตัวแล้วเหมือนๆกันอ่ะ ให้ดูไม่ออกอ่ะครับ จะได้อาศัยจังหวะที่ศัตรูสับสนจัดการได้ ไม่รู้มันมองออกง่ายมั้ยอ่ะครับ ช่วยแนะนำด้วยครับ
