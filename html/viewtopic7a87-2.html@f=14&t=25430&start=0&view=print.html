ผมเล่นปืนนะครับ
จากประสบการณ์นะครับให้ทำใจเลยถ้าจะเล่นสายปืน เพราะ
----------
1.ท่านจะใส่ได้แค่ปืนพกมือเดียวระยะยิง 4-5 ช่องเท่านั้น(ถ้าอยากถือไรเฟิลต้องหาเรปริก้าเอา)
2.ไม่มีกระสุน+ATK20 +ATK40 (กระสุนธาตุก็ไม่ได้)แบบกันเนอร์เพราะเราใส่ได้แค่ Bullet Pack +ATK0 :evil:
3.ยิ่งระยะยิงไกลแดเมจยิ่งน้อยลง แต่กันเนอร์มี Shot Stance แดเมจจึงสเถียรกว่า
4.สกิลโจมตีของปืน(ไกล)มีสกิลเดียว และมาสเตอร์รี่อีก 1 สกิล ที่เหลือท่านต้องเอามาประยุกต์ใช้เอง(อย่างซัมเมอร์ซอลเงี๊ยเจ๋งดี)
5.วันไหนเนตสปีดตกเยอะท่านจะรู้ว่านรกมีจริง(มันจะมีโมชั่นดีเลย์ กว่าจะยิงได้ที :lol:)
-----------
คำแนะนำ จงรำลึกไว้เสมอว่าเรามันไม่ได้เกิดมาเพื่อสิ่งนี้ สิ่งที่เราได้เปรียบกันเนอร์คือ
1.การคริติคอลของเรา 8)
2.สกิลสนับสนุนของเรา
3.กับดัก
4.หายตัว
นึกได้แค่เนี๊ย
