จริงๆเรื่องรีนี่ ถ้าเอาเกมอื่นมาเปรียบคงไม่ได้่อะครับ

เพราะแนวมันไม่เหมือนกัน อย่างเกมอื่น การเล่นของเค้าเป็นไปในทางเดียวกันได้ คือเล่นสายไหนก็สายนั้นไปเลย ตั้งแต่ basic class จนเปลี่ยนเป็น class สูงๆ
แต่สำหรับ ECO ถ้าใครดู tech job แล้วก็คงรู้น่ะครับ ว่าหลายๆอาชีพ มันบังคับให้รีกันเลยทีเดียว อย่าง fencer ที่ tech มี skill ที่ต้องใช้ str - mag ซึ่งจะมีกี่คนเชียว ที่เล่น str mag ตั้งแต่ fencer-knight จนถึง tech job น่ะครับ
อย่าง warlock พอเปลี่ยนเป็น necro ก็ต้องรีอีกอยู่ดี

คือที่พูดมานี่ จะบอกว่า มันวางแผนล่วงหน้าตั้งแต่แรกไม่ได้น่ะครับสำหรับหลายๆ อาชีพในเกมนี้ มันบังคับให้รีกันเลย ไม่เหมือนหลายเกม ที่เล่นได้สายเดียวตลอดเกมน่ะครับ

แล้วยิ่งการที่เอาระบบในเกมที่มีอยู่แล้วออกไป แล้วยัดเข้า item mall เนี่ย มันเป็นอะไรที่ค่อนข้างแย่นะ ถึงจะบอกว่าเป็นการตลาด แต่ item mall ไม่ควรเอาสิ่งที่มีอยูแล้วในเกมออกน่ะครับ คือ ถ้าจะเอาีของที่เหมือนในเกมมาขายก็ได้ เอาีของแฟชั่นมาขายก็ได้ แต่ไม่ควรลดสิ่งที่มีอยู่ในเกมน่ะครับ ไม่ว่าจะเป็นระบบ, npc, อัตราดรอป ฯลฯ

เดี๋ยวพอ saga หน้ามาก็เห็นผลชัดขึ้น ไหนจะ guide ที่หาได้ยากกว่าเดิม เพราะไม่มีคนทดลอง แล้วถ้าเกิดของ switch job จับยัดลง item mall อีก รับลอง คนหายอีกเพียบ -__-'
