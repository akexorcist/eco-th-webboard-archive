ระบุไปซิ

ใหญ่ด้านขนาด byte
หรือใหญ่ด้านขนาด pixel


แต่จะใหญ่ด้านไหน มันก็เละได้ทั้งนั้น
byte = โหลดข้อมูลเยอะเกินจำเป็น
pixel = ตารางกระทู้เละไม่เป็นตามที่ควร

จอ 1024 ไม่เละ แต่ 800 เละ
จอ 800 ว่าพอดี แต่ 1024 ว่ามันรกไปทางซ้าย
