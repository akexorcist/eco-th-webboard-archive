คิดว่าน่าจะ เหมาะสำหรับ คนที่ไม่ได้พกกระเป๋าหลัง + กะว่าใส่กระสุนจำนวนนั้นๆ แน่นอน (งงไหม)

ปกติ กระสุนน้ำหนัก 0 แต่พอกดใส่ มันก็จะมีน้ำหนักทันที บางจังหวะ ดันกดใส่ 999 น้ำหนัก
ก็เด้งมาที่ 99 อาจจะทำให้เดินไม่ได้ (หนีไม่ทันหรืองงว่าทำไมสกิลไม่ได้ ฯลฯ)

แต่ถ้าเป็น pack มา มันจะมีน้ำหนักในตัวของมันเลย เหมือนว่ากำหนดให้พกได้ 50 pack
พอกระสุนหมด ก็กด pack ให้มันแตกเป็นกระสุนธรรมดา แล้วก็กดใส่

ปล. แต่ทางนี้คิดว่ามันไม่มีประโยชน์นะ ปกติพกกระสุน 999 999 999 ยัดกระเป๋าหลัง
พอจะใช้ก็หยิบมาวางไว้ในตัว 300 แล้วกดใส่ แล้วก็ยัดไปอีก 300 เผื่อไว้รอบต่อไป

แต่ก็นะ บางคนอาจจะถนัดแบบนั้นก็ได้ ?!?

หมายถึงลูกนูที่ใช้เชือกมามัดเปนกำๆน่ะ

กับกระสุนปืนที่ใส่เปนแม็ค

มันมีประโยชน์อะไรมั่งมั้ยนอกจากเพิ่มความหนักในการแบกเนี่ย - -.

มันจะบรรจุกระสุนให้เองเมื่อหมดหรืออย่างไร 1_soul


ประโยชน์คือ มีน้ำหนักในตัวเอง ทำให้เวลาใส่กระสุนไม่ต้องคำนวนเรื่องน้ำหนัก ล่ะมั้งนะ (จำไม่ได้ว่าน้ำหนักพอดีกับจำนวนกระสุนรึเปล่า)

แต่ถ้ากระสุนหมด แล้วทำท่าใส่กระสุนเอง (เปลี่ยนแม็ก) ก็คงดี เท่ไม่น้อยด้วย *-*

ต้องทำความเข้าใจก่อนว่า มันเคยมีประโยชน์

เนื่องจากตัวเกมเดิมของเซิฟญี่ปุ่น บรรดากระสุนและลูกธนูทั้งหลายแหล่ มีความจุ 0.1-0.3 แล้วแต่ชนิด ทำให้เวลาแบกเอาไว้เฉยๆ ก็หนักเอาเรื่องแล้ว
ไอเทมพวกแพคธนูและกระสุนจึงช่วยลดปัญหาส่วนนี้ไปได้

แต่เซิฟไทยเราได้ทำการปรับน้ำหนักไอเทม (เกือบทุกชนิด) ให้มีน้ำหนักน้อยลงกว่าตัวเกมเดิมมาก จึงทำให้กระสุนเปล่าๆ ไม่มีน้ำหนักไป บรรดาไอเทมแพคเหล่านั้นเลยกลายเป็นขยะไปโดยปริยาย

เรื่องก็เป็นมาเช่นนี้แล
