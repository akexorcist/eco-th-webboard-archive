(ทำมา 2 Id ได้ทั้ง 2 id : ขออภัยที่เล่นหลายIDครับ)

1. เข้ามาทีแรก คุยกะเด็กที่พาเราเข้ามา (henpiko?) มันจะบอกว่า ให้เราตามไปร่วมงานกะมัน แล้วมันก็วาร์ปไป
2. เดินๆไปคุยกะคนให้เควส (ไม่มีpointง่ะ) แล้วเดินเล่นต่อไป เจอตัวแดง(ปีศาจdevilอ่ะ)
3. กลับมาคุยกะคนให้เควส มนบอกว่าต้องใช้ BatWing หรือ ด้ายแมงมุมมีพิษ
4. เดินรอบๆปราสาท เจอ npc วิญญาณต่างๆ ด้วยความแหล่ม เข้าไปคุยแล้วแสดงความเห็นอกเห็นใจ (เช่น Zombie อยากจับมือก็ให้จับ ไรงี้) จนครบ ได้ของมาแล้ว
5. กลับไปคุยกะปีศาจแดงแมนยู เอ้ย ปีศาจตัวแดง (devil อะไรนั่นแหละ) ทีแรกมันก็บอกเหมือนเดิมว่าห้ามผ่าน ก็คุยกะมันอีกที แล้วมันก็ขโมยของเราไป (โหไอ้นี่ เป็นปีศาจยังไม่วายโลภ) มันบอกว่ากำลังเหม่อดูของ เราก็ย่องเข้าไปได้เลย (จริงๆแล้วเราเข้าไปเองโดยอัตโนมัติหลังกดOkอ่ะแหละ)
6. ข้ามมาอีกฝั่ง เห็นตัวไรหว่าใหญ่ แต่รู้สึกได้ว่า ตัวเมีย เอ้ย ผู้หญิง ด้วยความม่อ ไม่รอช้า เข้าไปคุย ชะแว้บ อ้าวไปซะแร้ว เดินต่อไปๆ คุยกับnpc หน้าวาร์ครบทุกอันเลย เพราะไม่กล้าวาร์ปสุ่มสี่สุ่มห้า ไม่คุ้ม 3เปอ แต่พอได้ใจความว่า ส่วนใหญ่เป็นฟาร์มฟักทอง กะทางออกอีกอันนึง เลยเดินไปคุยกะ npc หน้าวาร์ปในสุด Wizard มันบอกว่าพิธีกำลังเริ่ม แล้วมันก็เตือนว่า อย่าส่งเสียง เดี๋ยวเพราะกว่าเสียงแม่มด เอ้ย เดี๋ยวโดนปีศาจ(ที่ไม่เห็นจะมีซักกะตัว)ตื้บเอาได้
7. ว่าแล้วเข้าวาร์ปไป เอ๊ะคุยกะใครดีหว่า อ๊ะ ไอ้ตัวปัญหา ลากเราไปโน่นมานี่ก็็อยู่ ไปเฉ่งมันหน่อย มันก็สวนกลับมาว่า เค้าทำพิธีกันแล้ว กล่อม...(ตัวไรหว่า)อยู่ แล้วก็กด nextๆๆๆๆๆๆๆซักพักปีศาจที่อันเชิญก็ปรากฏพร้อมกับจอที่ดำมืด (สงสัยไม่อยากเปิดเผยตัว เลยดับไฟ ซ้า) พอคำทำนายจบ ไอ้ตัวปัญหาก็ยุเราให้ไปบวกกับแม่มดRemia
8. ด้วยความคึกคะนองสุดขีด และความเซ้งสุดขั้วว่าเมื่อไหร่กุจะได้ของซักทีว้า ผมก็วิ่งเ้ข้าไป กะจะหาคนมาตื้บระบายเครียด แต่ ทันใดนั้น Remia ก็มอบของที่อยู่ในมือตอนทำพิธีออกมา และ ได้แล้ว ไอเท็มที่เสียเวลานั่งหาค่อนคืน
