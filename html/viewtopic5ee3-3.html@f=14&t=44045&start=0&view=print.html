เข้าใจว่า สกิลประเภทดีเลย์แคนเซิล จะลดดีเลย์หลังการโจมตีทำให้ฟันเร็วขึ้นนะ
ไม่ใช่เพิ่ม aspd
ทดสอบด้วยเซนปูเคนได้เลย ถ้ากด sdc จะสามารถร่าย เซนปูเคนต่อเนื่อง
แบบไร้ดีเลย์ได้เลย แต่ถ้าไม่กด จะมีดีเลย์หลังการใช้
หรือถ้าใช้กับ iai1 2 3 ถ้ากด sdc จะใช้ iai ต่อเนื่องแทบไม่ติดเนื่องจาก ดีเลย์หลัง iai มันโดนลด (เงื่อนไขของ iai ที่ต้องกดท่า 2 ในระหว่างดีเลย์ของท่าแรกถึงจะไม่ต้องร่าย)

สรุป aspd ทำให้ฟันเร็ว ร่ายเร็วแต่ยังมีดีเลย์หน่วงหลังการฟัน
พอกด sdc จะลดดีเลย์ทำให้ฟันเร็วขึ้น และร่ายสกิลต่อเนื่องได้
