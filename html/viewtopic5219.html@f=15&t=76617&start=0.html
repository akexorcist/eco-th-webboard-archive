[Guide&Talk] Vates Class - ผู้ใช้เวทย์มนตร์แห่งแสง

โดย ECO » อังคาร 21 ก.ย. 2010 3:26 pm

+++++++++++++อยู่ระหว่างการพัฒนา!!!++++++++++++++

สำหรับลงข้อมูลครับ ขอเวลาสำหรับทำสักพัก เนื่องจากเห็น guide ของ Vates แต่ละอันค่อนข้างเก่ามากและขาดการเพิ่มเติมข้อมูล รบกวนขอความร่วมมือทุกคนช่วยกันเอาข้อมูลมาลงกันน้า งานเยอะอาจจะทำช้าหน่อยนะครับ ^^


- [ Vates Class : นักบวชผู้ร่ายมนตราศักดิ์สิทธ์ ] -




ลักษณะพื้นฐาน

เป็นคลาสที่เน้นในด้านการใช้มนตราแห่งแสง ช่วยเหลือเพื่อนๆในลักษณะต่างๆ เช่น มนตร์รักษาบาดแผล มนตร์โจมตีด้วยคลื่นแสง มนตร์ป้องกันและรักษาสถานะผิดปกติต่างๆ มนตร์ฟื้นชีพ เป็นต้น

อาวุธที่สามารถใช้ได้

คฑาเวทมนตร์(Staff) , กระบอง(Mace)

ค่า Status ต่างๆของ Vates

Status ต่างๆมีความสำคัญกับ Vates ดังนี้

Mag (Magic) = พลังเวทย์ เป็นค่าที่มีความสำคัญเป็นอันดับแรก เพราะหมายถึงความรุนแรงของสกิลเวทย์มนตร์ต่างๆ(Matk) และขีดจำกัดของพลังเวทย์ (MP Max)

Vit (Vitality) = ความอดทน เป็นค่าที่สำคัญไม่แพ้พลังเวทย์ เพราะ Vates นั้นเรียกได้ว่าเป็นหัวใจของกลุ่ม คอยสนับสนุนเพื่อนๆ ดังนั้นจึงจำเป็นต้องมีขีดจำกัดของพลังชีวิต (HP Max) พลังป้องกันทางกายภาพ(Def) และพลังป้องกันเวทย์ (M Def) ที่สูงพอจะรักษาชีวิตตนเองไว้ได้

Dex (Dexterity) = ความคล่องตัว เป็นค่าที่มีผลต่อความแม่นยำในการโจมตี(S.Hit) ซึ่งดูไม่สำคัญนักสำหรับ Vates แต่สิ่งที่สำคัญจริงๆคือ Dex นั้นมีผลต่อความเร็วในการร่ายเวทย์ต่างๆ(Cspd) ซึ่งมีความสำคัญมากสำหรับ Vates (และชีวิตเพื่อนๆในปาร์ตี้ *0* )

Int (Intelligence) = สติปัญญา เป็นค่าที่มีผลพลังป้องกันเวทย์มนตร์(มากกว่า Vit) และอัตราการป้องกันสถานะผิดปกติต่างๆ ทำให้มีความสำคัญไม่น้อยสำหรับ Vates ที่ต้องรับการโจมตีอยู่เสมอ

Agi (Agility) = ความคล่องแคล่วว่องไว มีผลต่ออัตราการหลบหลีก(Avoid) และความเร็วการโจมตีทางกายภาพ(Aspd) รวมไปถึุงลดดีเลย์ในการใช้สกิลต่างๆ อาจจะไม่ค่อยมีความสำคัญมากนักสำหรับ Vates

Str (Strength) = พลกำลัง มีผลต่อพลังโจมตีทางกายภาพ (Atk) ไม่ค่อยมีความจำเป็นอะไรกับ Vates นัก เพราะเน้นโจมตีด้วยเวทย์มนตร์เป็นหลัก
