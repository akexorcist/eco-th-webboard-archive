กล้องที่มีประสิทธิภาพสูง สามารถสร้างภาพของมอนสเตอร์ติด 100% (ต้องใช้บอร์ดสเก็ตช์ภาพ)





การย้อมสี

สามารถนำอปุกรณ์ต่างๆที่ย้อมสีได้ ไปย้อมได้ที่ ลูกสาวร้านตัดเย็บผ้าที่อัพทาว 「染色娘」
ของ 1 ชิ้นสามารถย้อมได้เพียง 1 ครั้งเท่านั้น





การถอดชุดของเนโกะมาตะ

เมื่อต้องการจะถอดชุดที่เนโกะมาตะใส่อยู่ให้นำไปให้ไทนี่ร้านตัดเย็บผ้าที่อัพทาวถอดออกได้
ชุดที่ถูกถอดออกจะกลับไปเป็นไอเทมเพื่อใช้งานได้อีกครั้ง





การรับชุดของสัตว์เลี้ยงประเภท HeartMate

เมื่อสวมใส่ HeartMate ที่สามารถเปลี่ยนชุดได้ สามารถนำมาคุยกับ 「魔法のスタイリスト」("magical stylist") ที่เกาะไทนี่
จะได้รับชุดสำหรับเปลี่ยน
และสามารถถอดชุดออกได้ที่ 「魔法のスタイリスト」("magical stylist") เช่นกัน

Recycle system



เปิดตัวระบบใหม่! Recycle system

ยังไม่หมดแค่นั้น เมื่อเราทำคะแนนรีไซเคิลได้ถึง 2000
จะได้รับ ECO medal แบบรูปข้างล่างนี่ไปหยอด "แลกของตั๋วกันฟรีๆ" อีกต่างหาก
