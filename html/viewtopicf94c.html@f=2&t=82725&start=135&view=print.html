แม้ใน system จะขึ้น 6600 ซึ่งเดิม 3300 ก็ตาม
แต่ทำไม มันยังรู้สึกช้าเหมือนเดิมเลย (หรือรู้สึกไปเอง)

3.อันนี้ ไม่ขอเอ่ยนาม คนไทยของเรามีชิวเดอร์แล้วจ้า
เหตุเกิดจาก (เจ้าตัวเล่ามาว่า)
เจอโกเลม ตั้งของ ราคา 1-2g (ประมาณว่า เงินเต็ม 999999999 มาโชว์ของ)
แล้วลองดึงเล่นๆ
ของออกมาด้วยเว้ยเฮ้ย
