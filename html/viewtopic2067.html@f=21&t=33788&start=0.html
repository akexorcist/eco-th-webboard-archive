แนวเรื่องของนิยาย

นิยายแนวแฟนตาซี การผจญภัยของกลุ่มผู้กล้า เวทมนตร์และการไขว่คว้าชิงอำนาจและสิ่งมหัศจรรย์เกินกว่าที่ใครจะได้มาด้วยความยากยิ่ง เอาใจช่วยกลุ่มผู้กล้าได้ใน Magical of ECO World.....


จากใจผู้เขียน :


นิยายเรื่องนี้ ข้าพเจ้าแต่งด้วยใจอยากของข้าพเจ้าเอง ข้าพเจ้าเป็นคนชอบอ่านหนังสือแนวนิยาย แฟนตาซีอยู่แล้ว จึงไม่น่าแปลกที่แต่งนิยายขึ้นมาเล่า นิยายเรื่องนี้เปรียบเสมือนกับการผจญภัยเรื่อยๆ แต่ก็ต้องจบลงเหมือนนิยายทั่วไปเป็นธรรมดา Magical of ECO World เต็มไปด้วยเวทมนตร์อัมตะซึ่งอาจจะตราตรึงในใจของผู้รักนิยายผจญภัยของข้าพเจ้า ตัวละครทั้งหมดที่เอ่ยถึง ฉากทุกฉากที่ถ่ายทำ น้ำใจทุกเสียงที่ให้มา จะเป็นแรงบันดาลใจให้ข้าพเจ้า แต่งนิยายเล่มที่สองต่อไปได้

ข้าพเจ้าขอขอบคุณ........

น้องสาวที่รัก ที่ออกไอเดียมุขตลกสร้างความฮาให้กับผู้ชมบางคนได้ และหนังสือนวนิยาย
วรรณกรรมเยาวชนอีกหลายๆเล่มที่ช่วยให้ข้าพเจ้าเขียนบทหนังออกมาได้สำเร็จ...

สุดท้ายนี้ขอให้ท่านร่วมตะลุยฝ่าด่านเอาใจช่วยเหล่าผู้กล้าเหล่านี้ไปถึงที่สุดตราบสิ้นลมหายใจของพวกเขา...............................................................................

ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : การซ้อมวิ่งผ่าแสงของจินนี่
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : รวมพลกลุ่มสุนัขแห่งฟาอีส
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : จินนี่วิ่งแข่งกับสุนัขสีดำ
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ถ่ายรูปหลังจากตอนซ้อม (1)
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ถ่ายรูปหลังจากตอนซ้อม (2)
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ทหารประกอบคนแรกแวะมาเยี่ยมถึงกองถ่าย
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ทหารประกอบมินามินั่งยืดขารอดูฉากอย่างใจจดใจจ่อ
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ทหารของเราเริ่มจะง่วงซะแล้ว นอนหลับกันดีกว่า คร่อก....
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ภาพหลุดของสองหนุ่มนักแสดง (1)
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ภาพหลุดของสองหนุ่มนักแสดง (2)
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ฉากบึ้มเวทดินมหากาฬ
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ท่าประจำตัวของเหล่านักแสดง
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ฉากระบายอารมณ์ความเครียดจากการแสดงที่เหนื่อยอ่อนด้วยเวทไฟและธาตุมืด
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : สุนัขป่าสีดำเผลอเปิดเผยร่างที่แท้จริง ต้องรีบแปลงกลับ
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : เหนื่อยจัง นอนกันสักหน่อยดีมั้ย ? (ตาพีชกดหันมาเองนะ ไม่ใช่ผู้กำกับกดหัน ตั้งใจจะนอนกับเจมส์ -*-)
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : รีบหันหัวออกมาอย่างรวดเร็ว *0* ขณะที่บีทเอ่ยว่า 'รักแห่งสยาม...'
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : เจ้ากรรม ตาพีชยังจะหันมาอีก ลามกจริงจริ๊ง (โชคดีภาพไม่ทุเรศเกินไป เพราะหมาป่าสีดำมาช่วยบัง)
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : บีทถูกหมาป่าบังกล้อง รีบไล่ออกไปซะ ! (ผู้กำกับหันหัวหนีมาอีก แต่ตาพีชยังจะดันมานอนบนตักผู้กำกับ *.*)
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ผู้กำกับเวียนหัวแล้ว ขี้เกียจหนี (หมาป่าสีดำออกอาการลามกอย่างชัดเจน ภายหลัง ได้ส่งเว็บโป๊ให้ผู้กำกับไปดูอีกด้วย ขอไม่ระบุชื่อเว็บ)
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : โบกมือลาใส่กล้องที่บีทเรียกว่าท่าลาว
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : หมาป่าสีดำแปลงร่างเป็นภูติมืด หลังจากทุกคนกลับบ้านกันหลังถ่ายทำกันแล้ว
ฉากเบื้องหลังการถ่ายทำจุดเริ่มต้นแห่งแผ่นดินอะโครเนีย : ผู้กำกับสอนให้ตาเมกหัดพยักหน้า

ฉากเบื้องหลังการถ่ายทำการเดินทางที่ยาวไกล : นั่งผิงไฟให้หายเหนื่อยกับกองถ่าย
ฉากเบื้องหลังการถ่ายทำการเดินทางที่ยาวไกล : นั่งหันหลังผิงไฟ
ฉากเบื้องหลังการถ่ายทำการเดินทางที่ยาวไกล : เมื่ออาคาโดะในร่างจริงตาย...
ฉากเบื้องหลังการถ่ายทำการเดินทางที่ยาวไกล : อาคาโดะฟื้นคืนชีพ เผ่นก่อน !
