แปลจาก ญี่ปุ่น เรื่อง ความเห็น เกี่ยวกะ ชาแมน ทั้ง3เผ่า

1. Emil เนื่องจาก เป็น เผ่าที่มี ค่า MAX.PAL หรือ ค่า น้ำหนักที่เราสามารถ แบกได้ เยอะสุด ใน3เผ่า (STR8VIT10) จึงเป็น เผ่าสามารถแบก Magic candy ได้มากที่สุด (เพิ่มmpแน่นอนแต่ไม่รู้ราคาเท่าไร) แต่ ว่าเนื่องจาก ค่า INT ที่น้อย และ MAG ที่ต่ำ จึงมี M.atkน้อยสุด (Emil จึงเน้น เติม MAG และ INT อย่างเดียวในช่วงแรกๆ) ส่วนข้อดีอีกอย่าง คือ เพราะ ค่า VIT ที่สูง จึงทำให้ Emil มีอัตราเสี่ยงต่อการตาย น้อยที่สุด จาก3เผ่า

2.TiTania เนื่องจาก STR ที่น้อย Vit ปานกลาง ทำให้ MAX. PAL น้อย ทำให้ แบก Magic candy ได้น้อย แต่เนื่องจากค่า MAX และ INT สูง จึงทำให้ Titania ยิง เวทมนต์ได้แรงที่สุดใน3เผ่า (ส่วนจึงเน้นเติม MAG และ INT เพื่อ M.ATK สูงสุด)

3. Dominion เป็นเผ่าที่มี STR 10 เรื่อง MAX.PAL จึงไม่ค่อยมีปัญหากับการบรรทุก Magic Candy และ ค่า MAG ที่สูงพอตัว เรื่อง M.atk จึงไม่มีปัญหา แต่ ค่า Vit ที่น้อยมาก จึงทำ เสี่ยงต่อการตายใน การโจมตีภายในครั้งเดียว (Vit1)

เอามาจเวป ของคุณ Kornit ที่ผมเคยเอามาลงไว้ (อาจแปลไม่ค่อยดีซักเท่าไร อิอิ แต่อาจพอช่วยในการตัดสินใจได้)
