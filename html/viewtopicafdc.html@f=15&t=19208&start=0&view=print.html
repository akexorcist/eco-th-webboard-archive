ตกลงว่าจะเล่นสาย MAG ช่ายม่ะค่ะ

งั้นต้องยอมเรื่องร่ายช้าหน่อยคะ เพราะถ้าเน้นสายนี้จิงๆ

เรื่องของ VIT ควรอัพอย่างยิ่งคะ เพราะร่ายช้า เสี่ยงต่อการถูกมอนยำได้ ควรถึกสักหน่อยดีเหมือนกัน

แต่จะอัพเท่าไหร่ อันนี้แล้วแต่คนเล่นดีกว่าคะ

ส่วน INT จ๊อบ2 จะมีสกิล แช่แข็งมอน อัพสัก 20-30 กำลังดีคะ เพิ่ม M.ATKให้ด้วย

แต่หลักๆยังคงเป็น MAG

เราลงแบบนี้อ่ะ MAG 88 VIT 23 DEX 22 INT 3

ก็ไม่รุ้หรอกว่าดีไหม แต่ของแบบนี้มันไสตล์ใครไสตล์มัน

เน้นอะไรเอาอันนั้นเป็นหลักดีกว่าคะ
