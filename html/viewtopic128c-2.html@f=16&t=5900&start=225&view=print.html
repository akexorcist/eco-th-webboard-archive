ไม่มีซักอย่าง
ผลของ status ทุกอย่างมีดังนี้

str - ช่างมัน อย่ากดเชียว เล่น riot เนี่ย
dex - อ่าน str
int - ใช้สคิล merchant 50 / เพิ่มหลบระยะไกล
vit - เพิ่ม hp/sp / ดาเมจหลักของ riot
agi - ลดเวลาร่าย / เพิ่มหลบระยะใกล้
mag - เพิ่ม mp / ใช้ random healing / roulette healing ได้ดีขึ้น

เพราะงั้น ถ้าจะเล่น riot ต้องทิ้งชีวิตเดิมไปให้หมด..
เหลือแค่ 3 สาย
vit-agi อะไรมากกว่าน้อยกว่า เลือกเอง แต่ถ้าจะร่ายให้เร็วๆ อย่างน้อยควรมี agi รวม 90+
vit-agi-mag ใช้ random healing ทั้งตอนลุย ตอนเก็บเลเวล ควรมีอย่างน้อย 33
vit-agi-int น่าจะเิวิร์คดีใน NvN (ไม่เคยลอง) ค่า int ต่ำสุด ไม่สามารถบอกได้


ปล. จริงๆ ต้องถามว่า dex และ mace mastery มีผลกับ riot hammer ไหม สิ ใช้ภาษาไทยดีๆ หน่อย
