รบกวนถามเรื่องแนวทางการอัพค่าStatusหน่อยค่ะ ไม่แน่ใจว่าควรเล่นยังไงดี ( กลัวอัพไม่ถูก )

ก่อนอื่น เล่นเผ่า Dominion ( เปลี่ยนอาชีพง่ายดี เห็นอีกสองเผ่าบ่นกันเยอะ )

สำหรับเราแนวทางที่คิดจะเล่นคือ ตอนที่เป็นWarlock จะอัพสาย MAG>DEX
จนถึง Job Lv.50 เลย ( ไม่อัพอย่างอื่น )

แต่พอเปลี่ยน Job 2 (ซึ่งต้องเป็น Expert Job ก่อน ) ก็อัพ INT ล้วน จน Job Lv.20
ก็ไปเปลี่ยนเป็น Technical Job จะได้สกิลอาชีพ Expert Job มาสองสกิลพอดี

แล้วเราก็เล่น Technical Job ไปเรื่อย ๆ โดยอัพ MAG>INT>DEX ไปตลอดเลย
( จะเล่นสายคำสาป )

แต่เราไม่มั่นใจว่าเล่นแบบนี้จะโอเคหรือเปล่าเนี่ยสิ อาจจะไปตายเอากลางทาง = ="
จึงมาถามผู้รู้ก่อน ถ้ามีอะไรที่คิดว่ามันดูไม่ค่อยเข้าท่า ก็ช่วยแนะนำเพิ่มเติมหน่อยนะคะ

เปลี่ยนเป็นcabaแล้วอะ แต่สกิล passive ไม่เหมือนกับที่เจ้าของกระทู้มาแปะไว้เร้ย ยังงงๆ ยังไงกันแน่เนี่ย อ่านในเกมส์ก็ยังงงๆ ใครรู้ช่วยอธิบายที

สกิล ผูกมัดความมืดมันเขียนไว้ว่า Passive skill พลังต่อต้านความมืดในตัวเองสูงขึ้น (แล้วจะอัพทำไม)

สกิล เพิ่มความสเร็จยิ่งกว่า เขียนไว้ว่า Passive skill ช่วยเพิ่มความสำเร็จยิ่งกว่า (ความสำเร็จของอร้ายยยย)

สกิล soul of darkness เขียนไว้ว่า ตอนที่ถูกครอบงำ จะทำให้ผู้ที่ถูกครอบงำมีความสามารถเพิ่มขึ้น (อะไรคือครอบงำอะ โดนสาปเหรอ หรือว่าแปลงร่าง หรือยังไง)

สกิล black spirit analysis เขียนไว้ว่า ต้องใช้มนต์ดำในการทำสกิล และถ้าสกิลมีเลเวลสูงๆจะทำให้สามารถได้ไอเท็มเพิ่มขึ้น(ไอนี่คือถ้าใช้แล้ว จะได้ไอเท็มมากก่าเดิมเหรอ)
