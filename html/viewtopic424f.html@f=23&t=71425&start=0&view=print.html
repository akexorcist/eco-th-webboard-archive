โดย ECO
จากหุ่น Fox Hound เบอร์3 (สีฟ้า) ที่จะอยู่ชั้นเดียวกับชั้น(auto)คลื่น

หรือชั้น 1 ณ หอแสง

อยากจะรู้ว่า เหล่าผู้เล่นท่านใดใน ECO (ทั้ง 2 เซิฟ) ไปเวล หรือผ่านทางแล้วตี

แล้วกระบอกปืนตกมาจากตัวนี้บ้าง โดย "ไม่ใช่" อาชีพแมชชีน

พอดีเกิดข้อสงสัย ทางนี้เองมักจะเอาอาชีพแมชชีนไปตีประจำ ถึงจะได้ แต่ค่อนข้างเบื่อตรงที่
กว่าจะฆ่าได้สักตัวนึง

ถ้าอาชีพอื่นๆ ตีแล้วตกเหมือนกัน ก็จะได้เอาตัวอื่นไปเวลที่นั่นแทน


ปล. เกมผ่านมา 2ปีแล้ว ข้อมูลตรงนี้ จะมีใครเคยผ่านหรือได้มาบ้างนะ

มะลองเอา เอเลสิง ให้ทาทา เดินดูละคับ
ถึงเอเลจะรุ้งหุ่นตาย แต่ปราชที่แสดงผลก็คือ Machine นะ

ส่วนตัวผมก็ไม่เคยดรอปเหมือนกานคับ ไรเฟิล60 (เพราะมอนตัวนั้นเปอร์น้อย) แต่ราคาปืนสูงดี


แต่เคยเอาเอเลคลื่น + รุ้ง ก็ได้แค่ ไรเฟิล 70 80 /เดี่ยว ดำ เงิน 70 50 60 /แมกนั่ม 80 / อยากจะลองไปตีดูเหมมือนกานคับ ไว้สอบเสร็จ จะไปลองมาให้นะคับ
