โพสต์แล้ว: พุธ 23 ก.พ. 2011 9:29 pm
โดย ECO
คือผมอยากเล่น striker อ่ะครับแต่ผมไม่รู้เรื่องเกี่ยวกับมันเลยคือ อ่านในไก้แล้วกะพอจะรุ้เรื่องขึ้นมาบ้าง
แต่อยากจะถามว่า ควรอัพสเตตัสเท่าไรสายเกบเวล และก็ควรจะอัพสกิลอะไรบ้าง ตั้งแต่เป้น อาเชอร์ เลยนะครับ
เอาอย่างละเอียดเลย และก็พอมาเป็น สไตรเกอร์อัพไรบ้าง ช่วยบอกทีนะครับ

อย่าว่ากันเลยนะครับถ้าเราให้มาตอบ เครื่องเรามันช้ามากอ่ะครับ จะให้เปิดหาในไก้คงยาก
วานผู้ใจบุญช่วยตอบทีนะครับ อยากเล่นมากๆเลย ขอบคุณมากครับๆๆๆๆๆ
