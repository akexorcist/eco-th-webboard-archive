[How to] วิธีลงสีใน Photoshop^^

โดย ECO » พุธ 09 ม.ค. 2008 1:00 pm

จาแนะนำเทคนิคที่เราลงสีใน Photoshop นะค๊ะ :oops:

Step 1 : ให้เราหารูปมา อาจจะใช้เมาส์ปากกา หรือสแกนรูปเข้ามาก้อด้ายนะ


แต่ถ้าเราใช้วิธีสแกนเข้ามา ภาพจะค่อนข้างมีรอยสกปรก
ให้เราไปที่ Image > Adjustments > Levels... (หรือ Ctrl+L)
แล้วปรับประมาณนี้ (ปรับแล้วแต่ความพอดีนะ ระวังเส้นหายเกิน)


Step 2 : ให้ดูที่ panel Layer (ไม่มีให้กด Window > Layers หรือกด F7 )
สังเกตว่า Layer รูปของเรา จามีรูปแม่กุญแจอยู่ ให้ทัมตามรูปนี้

ก้อจะได้ Layer ที่สามารถปรับแต่งได้

จากนั้นให้เปลี่ยน mode Layer จาก Normal มาเปน Multiply
เพื่อให้รูปของเรา มีลักษณะคล้ายกับแผ่นใส ไม่เป็นกระดาษทึบ


Step 3 : สำหรับใครที่ไม่ถูกใจสีของเส้นที่เราสแกนมา จะทัมก้อได้ ไม่ทัมก้อด้าย
ให้เราสร้าง Layer ขึ้นมาใหม่ก่อง


ที่ Layer 1 ก้อลงสีตามใจเลย ที่ Layer 1 ของเรา เราเทสีเขียวไป


แล้ว เปลี่ยน mode Layer จาก Normal มาเปน Color


แล้วก้อจะได้เส้นอย่างงี้^^


**แล้วก้ออย่าลืมกดรวม Layer ด้วยหละ Layer > Merge Down (Ctrl + E)
และอย่าลืมทัม Mode Layer ของเส้นให้กลับมาเปน Multiply นะ **

เด๋วจามาต่อวิธีลงสีนะ^^
