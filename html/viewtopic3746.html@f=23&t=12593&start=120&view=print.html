ผมก็เล่นพ่อค้าเป็นตัวแรกเลยนะ แต่ก็ซื้อของแพ้เกินจริง0.5-1.0เท่าแทบทุกครั้ง บางทีพอซื้อมาแพงก้อเลยต้องขายแพงหน่อย(มือ2) แต่ก็ขาดทุนทุกทีแหละ ลดราคาเกือบครึ่งแน่ะ
