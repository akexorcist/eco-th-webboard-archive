จำได้ว่าเคยหาในวิกิแล้วพยายามจะ confirm เหมือนกัน

จากที่วิกิบอก resist เมื่ออัพ skill lv สิ่งที่เปลี่ยนแปลงคือระยะเวลาอย่างเดียว โดยผลการ resist จะคงที่่ตลอด (90%)

แต่จากเท่าที่เคยลอง resist confusion กับ stun มาพร้อมกับซากศพ Rubunan / Evil Dead นับหมื่นๆศพในอดีต ตอนแรกอัพแค่ประมาณ lv3 กับตอนหลังอัพเพิ่มเป็น lv5 เราว่ามันให้ผลต่างกันเยอะพอควรเหมือนกัน ซึ่งโดยส่วนตัวคิดว่าที่ lv5 นอกจากระยะเวลานานกว่าแล้ว ยังให้ผลการ resist สูงกว่า.. แต่อันนี้เป็นแค่่ความเชื่อส่วนตัวเหมือนกันเพราะว่าไม่ได้ทำการวัดค่าเป็นตัวเลขจริงๆ จะเชื่อหรือไม่ก็แล้วแต่ *-*

ส่วนเรื่อง INT ของผู้ร่ายนี่มีผลต่อสกิล resist หรือไม่นั้นไม่สามารถตอบได้อ่ะเพราะไม่เคยลองเหมือนกัน แต่คิดว่าไม่น่าจะมี สิ่งที่มีผลจริงๆจาก INT ของผู้ร่ายคือพวกสกิล cure status ต่างๆ ~

Hopes this help
