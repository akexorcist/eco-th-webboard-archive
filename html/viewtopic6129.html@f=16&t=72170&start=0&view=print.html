เรารู้จักๆ ตัวรองเราก็เป็นมาริโอเนท เราแอดเทอเป็นเพื่อนด้วย ^^

ถ้าถามถึงวิธีการเก็บเวล ตอนนี้มันเวลเต็มที่ 110 เนอะ

แต่จ๊อบเราก็คงตันกันก่อนหน้านั้นแล้วหละ

การใช้มาริ คิง ก็ต้องทำดาเมจด้วยตัวเองซะก่อน ในกรณีขอมาริก็มีอยู่ท่าเดียวที่หวังผลได้

คือ Marionette cancle ที่ทำให้ติดเกร็งด้วย

แต่ถ้าเราใช้ มาริ คิง เลย เราจะไม่ได้เปอร์จากการฆ่ามอนส์นะคะ

สกิลมันค่อนข้างแรงคะ ถึงเราจะมี M.atk ไม่สู้สาย spell user แต่มันก็ทดแทนด้วยการที่ตัวสกิลมันทำดาเมจได้ 900กว่าเปอร์เซนต์ของ M.atk เราคะ

ที่เราพอทำให้ M.atk ลงตัวและแรงที่สุด ก็อัพ Mag 98 ใส่หมวกปาตี้ +2 mag ใส่ชุดประจำอาชีพ เวล 85(+1 mag) พอรวมกับจ๊อบโบนัส(+ Mag) M.atk ก็จะลงตัวได้แรงที่สุดละคะ ^^

ตอนนี้เราเวล 100 ไม่แน่ใจว่า ถ้าเวล 110 จะยังโหดกว่านี้อีกมั้ยนะคะ ถ้าจะเอาเวทคงที่หน่อย ก็ลง Int เลยคะ

แต่เราว่า มันร่ายช้าอยู่นา ลง Dex เพิ่มอีกหน่อยกะดีค๊ะ ของเรา dex 60 กว่าๆ ยังว่าช้าเลย(ก็มันแค่ 60 กว่าๆหนิ !!) ต้องเร็วขนาดที่ว่า มอนเดินมายังไม่ถึงตัวเรา ก็โดน คิง ของเราเป่าตายก่อนยังงั้นแหละคะ ถือว่าเร็ว อิอิ ^^



มาเล่นมาริโอเนท กันเยอะๆนะคะ เจอเราได้ตามเกาะโจร จ๊ะ เราไปเครียเควสบ่อยๆ
