Big Log หาจาก Wood เลยจ๊ะ ถ้าเล่นชาวนาเอาไว้ตัวนึงจะมีเควสที่ทำแล้วได้ Tree Seed เอาไว้ปลูก Wood ตีหา Big Log

คอน 1 ได้จากดันปลา


ส่วนผสมของใบเรือนี่ไม่แน่ใจว่าจะเอาใบเรือธรรมดาหรือใบเรือเทอร์โบอ่ะ =w=

ย้vยี้จัv เขียน:
ส่วนประกอบใบเรือ (Canvas of Flying Garden) ( ได้จาก Container 1 )

- Log :: 1
- Waterproof Fabric :: 5
- Strong Wood :: 5
- Great Steap :: 5


ใบเรือ (Big Canvas of Flying Garden) ( ได้จาก Container 1 )

สร้างด้วยสกิว :: Purify Item

ส่วนประกอบใบเรือ (Big Canvas of Flying Garden)

- Big Log :: 1
- Waterproof Fabric :: 5
- Strong Wood :: 5
- Great Steap :: 5



ส่วนประกอบใบเรือ (Rotary sail)

- Log :: 1
- Waterproof Fabric :: 5
- Wood :: 5
- Great Steap :: 5




Wood ซื้อเอาจากคนขายฟอร์นิเจอร์ (แต่ถ้ามีชาวนาและปลูก Tree Seed เพื่อหา Big Log จะมีเก็บไว้แบบเหลือทิ้ง)

Strong Wood หาได้จาก Fallen Tree (ขอนไม้ริมหาด) ต้องมีปราชญ์ไม้ หรือหาจาก Soul Tree โดยไม่ต้องมีปราชญ์

Log ได้จาก Fallen Tree เหมือนกัน แรห์ มีปราชญ์หรือไม่มีก้อมีค่าเท่ากัน

Water Proof Fabric ส่วนผสม Greater Clote + 4 Row

Great Steap ใช้อะไรทำมั่งจำไม่ได้ละ =w=
