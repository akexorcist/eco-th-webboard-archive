ได้เงิน 80k - 100k
ออกแน่ๆ ออกชัวร์ๆ แต่ต้องขนไปตั้งขาย 3 รอบ
ถ้าไม่ขายในช่วงไพร์มไทม์ ก็ต้องตั้งโกเลม 3 คืน =o=

2. ทอเป็น Worst ได้ 95 ผืน แล้ว OC ที่เมือง
ได้เงิน 49k

3. ทอเป็น Worst ได้ 95 ผืน แล้ว OC ที่หน้าดันเหนือ
ได้เงิน 61k
ยังเก็บ Cavier ไม่ถึง 100 อันเลย ... ไม่ไปๆๆ

4. ถักเป็น Knit Cloth 32 ผืน หาซื้อหนังวัว แล้วตัดชุดขาย
ได้เงิน 2400k หักต้นทุนอีก 160 - 320k
ไอเดียดี ... แต่โชคดีๆ ไม่ได้เกิดขึ้นทุกวี่ทุกวัน

5. ถักเป็น Knit Cloth 32 ผืน ทำน้ำหอมลม แล้วเย็บหมวกขาย
ได้เงิน 224k หักต้นทุนอีก 18k
ขายออกยากมาก ... เคยตัดแค่ 3 ใบ กว่าจะหลุดหมดก็ 2+ วัน

6. เอาไปให้ เรนเจอร์น้อยๆ ส่งเควส ยามที่ไม่มีของเควสเหลือ
ได้เงิน 80k กับ EXP 50k/50k
ใช้เวลาทั้งสิ้น 10 วัน

7. ยกให้ใครสักคน ที่รู้จัก
ได้เงิน 0k
