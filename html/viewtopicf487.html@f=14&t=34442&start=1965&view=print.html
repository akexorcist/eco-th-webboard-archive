สวัสดีค่ะ กำลังอับตัวว่าจะเล่น Gunner ตอนนี้ยังเดินเป็นลูกเป็ดอยู่เลย งง ไปหมด ยังไงก่อฝากตัวด้วยนะจ๊ะ

คำถามยอดฮิดอะ

ที่บอกว่า
1. Skill ที่ยอดนิยม ใครๆก็อัพ
2. Status อัพตามนี้แล้วเทพสุดใน 3 โลก
3. ปืน+ อะไรดี
4. Skill ที่ควรเอามาตอนสวิตจ๊อบ
5. เลเวลเท่าไรเวลที่ไหน เวลที่ไหนดี

ถ้ามีเวลาช่วยแนะนำด้วยนะจ๊ะ รออ่านจ๊ะ

แนวทีเราว่าจะเล่น

จริงๆไม่ค่อยลงไปสู้กับใครส่วนใหญ่ก่อเก็บเวล ทั่วไป ถ้าใช้ปืนคู่จะดีมั้ยจ๊ะ หรือว่าใช้อะไรดี

Skill นี้ มีอะไรที่จำเป็นกับGunnerที่จะต้องเอามาจาก FIRST JOB กับ EXPERT JOB บ้างมั้ยจ๊ะ แล้วถ้ามีควรมีอะไรบ้างจ๊ะ

Status ตอนนี้ลง STR นำ INT ตาม AGI นิดๆ ส่วนเวลก่อจะ 50 แล้ว ขอแนวทางด้วยนะจ๊ะ

ยังไงก่อขอความรู้ด้วยนะจ๊ะ แล้วก่อ ขอบคุณร่วงหน้านะจ๊ะ
