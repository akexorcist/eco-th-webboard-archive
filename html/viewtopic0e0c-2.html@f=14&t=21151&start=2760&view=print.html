Str+Mag ไม่กล้าพูดอะไรมาก เพราะไม่เคยเล่น
ดูแล้วสเตตัสมันจะกลางๆ ไม่เก่งซักทาง แต่คิดว่าถ้ามีคนเล่นจริงๆ มันน่าจะเก่งได้นะ
Flare String เป็นสกิลเด่นของ Str+Mag

สเตตัสก็คงเป็น Mag>Str>Vit>Dex (Vit อาจจะมากกว่า Str ขึ้นอยู่ว่ามันเกิดมาเพื่ออะไร)
ประมาณออกมาคงเป็นไนท์สาย Str+Vit ที่ฮิลได้
แล้วมีสกิล Flare String ที่ทำดาเมจหนึ่งเป้า ได้รุนแรง
ที่ให้ Dex น้อยๆ คือกะว่าถ้าเจอพวกหลบเก่งๆ เราก็ใช้ Blood Absorb แทน (Mag เราเยอะ)
ดูแล้วอาจจะด้อยอยู่บ้าง แต่ก็น่าสนใจ อยู่ที่ความชอบอีกนั่นแหละครับ
ถ้าเรารักมัน มันจะพัฒนาไปเรื่อยๆ(รีแล้วรีอีก) แล้วมันจะเก่งเอง
แต่สุดท้าย อาจจะออกมาต่างจากที่คิดไว้ตอนแรกก็ได้
