Source:
http://game.sanook.com/gameupdate/stechnic_10184.php


ในเกม ECO นั้นแม้ว่าจะเลเวลสูงแค่ไหน แต่ถ้าหากเดินทางไปยังโลก Dominion ที่อัพเดตมาใหม่ใน Saga 8 ล่ะก็ ทุกคนจะต้องเริ่มใหม่หมด เพราะสภาพร่างกายมีความเปลี่ยนแปลงไปจากผลของเครื่องย้ายมิติ ทำให้จากเลเวลที่เคย 99 มีสคิลใช้ครบทุกสคิล กลายเป็นเลเวล 1 จ็อบ 1 ไม่มีสคิลใช้ และที่สำคัญคือ Reserve Skill ที่เป็นสคิลอาชีพอีกด้านก็ถูกผนึกไปด้วย และแม้ว่าจะเก็บเลเวลในโลกโดมิเนี่ยนจนเต็มแล้วก็ไม่สามารถที่จะใช้ Reserve Skill ได้เลย หากไม่ทำการขอร้องให้ Dominion Dragon ช่วยปลดปล่อยพลังให้


เงื่อนไข Event ปลดปล่อย Reserve Skill
- เลเวลตัวละครในโลก Dominion World มากกว่า 24 ขึ้นไป


ขั้นตอนของ Event
1.ไปที่ฉาก Warship Island (Day) แล้วนอนให้เป็นตอนกลางคืน Warship Island (Night) แล้วเดินไปทางทิศตะวันออกเฉียงเหนือของฉากให้คุยกับ NPC Darkness Soul แล้วเลือกตอบตกลง แล้วมันจะวาร์ปเราไปที่แห่งหนึ่ง





2. เราจะโดนวาร์ปมาส่วนลับของ Hell Desert (Night) ให้เดินไปทางด้านขวา จะพบกับ Dominion Dragon พูดคุยแล้วเลือกที่จะปลดพลังที่ถูกผนึกอยู่ จะตัดเข้าสู่ฉากต่อสู้ ให้เดินไปยังมุมเดิมที่ Dominion Dragon ยืนอยู่เพื่อสู้กับมัน หากเอาชนะได้แล้วจะได้ไอเทม Dark Orb









3. แล้วให้เดินออกจากฉากต่อสู้โดยไปคุยกับ Darkness Soul เพื่อกลับไปยัง Hell Desert (Night) ฉากปกติ แล้วเดินไปคุยกับ Dominion Dragon อีกครั้งเขาจะใส่พลังความมืดเข้าไปใน Dark Orb จากนั้นให้กดใช้ Dark Orb ด้วยพลังแห่งความมืด ทำให้ตัวละครเราสามารถใช้ Reserve Skill ได้แล้ว







หมายเหตุ: สคิลในส่วนของ Reserve Skill จะสามารถใช้ได้หมดทุกๆสคิลที่ทำการโอนมา โดยไม่มีข้อจำกัดเรื่องเลเวลจ็อบใน Dominion World แต่ทั้งนี้อาจมีการเปลี่ยนแปลงเพราะยังอยู่ในช่วง Test
