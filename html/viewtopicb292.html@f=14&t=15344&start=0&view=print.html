การจะเล่น DS ต้องเป็นนักดาบ แล้วเปลี่ยน หรือ เปล่าครับ ผมหาตาราง ไม่เจอครับ
ถ้ามีผู้รู้ขอลิ้งที่เกี่ยวของในการทำความเข้าใจกับอาชีพนี้หน่อยนะครับ
อาวุธ มีด !!!
สายอาชีพ ก้อต้องเป็น AGI STR ตามกระทู้ใช้ไมครับ
สรุปนะครับ
1.ผมอยากทราบว่าต้องเล่นอาชีพอาไรเบื้องต้น ก่อนจะไปถึง DS
2.แนวทางการอัพสกิล ของสายมีด (ผมเห็น ของ DSในเวบแล้วครับ)
ขอความรู้สึก ว่าเล่นอาชีพนี้แล้วได้ฟิวไมครับ อย่างไรบ้างครับ
คงไม่ถามเยอะไปนะครับ ขอบคุณจ้า
ปล.ถ้าโพสซ้ำอันนี้ขออภัยไว้ก่อนเลยนะครับไม่ได้ตั้งใจน้า
