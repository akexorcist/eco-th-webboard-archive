เวลาทำของสวยๆเเตก เเล้วไม่รู้จะเลือกวิธีซื้อของมาหลอมดี หรือซ่อมมันดี

เเนะนำวิธีคำนวนหาค่าความคุ้มค่านะคะ

เทียบสูตรตามนี้

===========================================================


กำหนดตัวเเปร:
A = ค่าความทนทานของที่เสีย ณ ขณะนั้น
B = ค่าความทนทานของใหม่ที่จะเอามาหลอม
C = ราคาของหลอมชิ้นใหม่
D = ราคาชุดซ่อม
E = จำนวนครั้งที่หลอมสำเร็จ

เเทนค่าสูตรตามนี้:
X = (A - 1) / D
Y = B / C + (10000 x E)

จากนั้นนำค่า X กับ Y มาหาส่วนต่าง


*10000 คือราคาค่าหลอมขั้นต่ำ เราไม่เเน่ใจว่า 10k เป๊ะหรือเปล่านา
ถ้าเอาชัวร์ ลองสอบถามกะป้าหลอมหลอมไอเทมนะคะ



===========================================================


ตัวอย่าง
เเว่นเหลืองหลอมตุ้มหู Cocco เเตก
ความทนทาน max 3

1.หากเลือกวิธีซ่อม
ค่าชุดซ่อมราวๆ 80k เมื่อหลอมเสร็จความทนทาน max จะเหลือ 2
เเปลว่ามูลค่าในการซ่อมคราวนี้อยู่ที่ 40k ต่อ 1 หน่วยความทนทาน

2.หากซื้อเเว่นใหม่เลย ทนทานครบ 3
ราคาเเว่น 150k + ค่าหลอมอีกราว 10k ราคารวมเมื่อหลอมเสร็จเเล้วอยู่ที่ 160k
เเปลว่าค่าความทนทาน 1 หน่วย จะมีมูลค่าสูงถึง 53k


ผลจากการวิเคราะห์ตัวอย่างนี้ ควรเลือกวิธีหลอมค่ะ
เพราะยังมีความทนทานเหลือถึง 2
ซื้อใหม่จะได้ค่าความทนทานเต็ม 3 เเต่ต้องเสียเงินเพิ่มขึ้นมาก ซึ่งไม่คุ้มกับความทนทานที่เพิ่มอีก 1

มาช่วยเจิม + เพิ่มเติมให้

ทางที่ดี เราควรเลือกหลอมไอเท็มสวยงามกับไอเท็มความสามารถเลยจะดีกว่า เพราะว่าความสามารถของของสวยงามยังไงก็เทียบกับไอเท็มความสามารถไม่ได้แน่ และไอเท็มส่วนใหญ่ก็สามารถหลอมกันได้อยู่แล้วจึงไม่น่าจะมีปัญหา ถ้าทำแบบนี้ก็จะได้ไอเท็มความสามารถดีๆ แต่มีรูปลักษณ์ที่สวยงาม เก็บเวลไป สวยเท่ไป เลยล่ะ

ถ้าเกิดว่าของที่หลอมแล้วพัง เราก็สามารถเอาไปหลอมซ้ำต่อได้ในไอเท็มความสามารถอย่างเดิมนะ

สมมุติว่า เราหลอม Big Hair Ribbon lv.15 แสดงภาพ กับ Travel Hat lv.80 ความสามารถ
ก็จะได้ไอเท็ม Travel Hat ติดดาว นั่นคือมีรูปร่างเป็น Big Hair Ribbon แต่ความสามารถทุกอย่างก็ยังเป็นของ Travel Hat

พอ Travel Hat ติดดาวของเราพังแล้ว เราก็เอาหมวกนี้ไปหลอมใหม่กับ Travel Hat อันใหม่ ที่มีรูปร่างมาจาก Travel Hat อันเก่าที่มีรูปร่างเป็น Big Hair Ribbon แล้วล่ะ


แต่ข้อจำกัดของการหลอมก็มีนะ
1. lv. ของไอเท็มแสดงภาพ ต้องต่ำกว่าหรือเท่ากันกับไอเท็มความสามารถ
2. อาชีพของไอเท็มแสดงภาพ ต้องครอบคลุมอาชีพของไอเท็มความสามารถ
3. ไอเท็มทั้งสองต้องเป็นประเภทเดียวกัน Etc. บางตัวจะหลอมกันไม่ได้
4. ชุดบางชุดจะมีส่วนเกินออกมาอย่างเช่นเกราะที่ไหล่ของชุด Matador lv.80 (ไม่มีEX) ก็จะไม่สามารถหลอมกับชุดอื่นที่ไม่มีเกราะที่ไหล่ได้

ข้อควรระวังเพิ่มเติม
1. ไอเท็มแสดงภาพที่หลอมสำเร็จแล้ว ในเกมจะถือว่าไอเท็มนั้นไม่มีตัวตนอีกต่อไป
2. ถ้าหลอมกับไอเท็มความสามารถเลเวลสูงแล้ว ครั้งต่อไปจะไม่สามารถหลอมกับไอเท็มความสามารถที่เลเวลต่ำกว่าได้
3. การหลอมไม่ได้เป็นการซ่อมไอเท็มความสามารถ ดังนั้นทนทานเท่าไหร่ ก็ออกมาเท่านั้น

โอกาสหลอมผิดพลาดมี 20% แต่ถ้าผิดพลาดก็จะไม่เสียไอเท็มที่จะหลอมทั้ง2 จะเสียเพียงแค่เงินเท่านั้น

เราเคยหลอมผิดพลาดติดกัน3รอบรวด หมวกเวล80นั่นแหละ- -"
