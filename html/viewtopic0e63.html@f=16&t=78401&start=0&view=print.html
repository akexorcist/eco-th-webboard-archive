ของแรร์ที่ว่ามันมีหลายแรร์เน้อ บางแรร์ไม่ต้องมี Analysis หรือ Knowleage ก็ดรอป บางแรร์มีแล้วดรอปง่ายขึ้น หรือบางแรร์ต้องมีถึงดรอป

สรุปโดยรวม อัพไว้ไม่เสียหายยกเว้น Point ไม่พอ -..-

Edit :

เพิ่มอีกนิด ไอเท็ม "ส่วนมาก" มี Analysis หรือ Knowleage ของตัวนั้น ๆ แล้วจะทำให้อัตราการดรอปมากขึ้น (เช่น Plant Knowleage เอาไปตี Pururu แล้วมีโอกาสได้ Blue Seriko มากขึ้น มีโอกาสได้ Seriko มากขึ้น พูดง่าย ๆ ทำให้โอกาสแห้วไม่ได้ไอเท็มลดลง)

ส่วนพวก Analysis ถ้ามี Knowleage อยู่แล้วจะไม่ค่อยเห้นผล แต่ "คาดว่า" จะเพิ่มโอกาสดรอปให้มากขึ้น (เช่นแรร์จาก 1% เป็น 3-4% งี้)
