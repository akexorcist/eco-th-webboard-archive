อ้อลืมถาม...วิธีรับของ ตอนเป็นโกเลม (ปกติจะเปิดตอนนอน)

เพราะงั้นเขามีวิธีคิดราคารับ ITEM ยังไงหรอคัฟ

อืมผมไม่รู้จะเอาอะไรมาถามดูดี เอาเป็นว่าลองละกัน

อย่าง Blood Note ที่เขารับตอนนี้ 1700-1800 เนี่ย เขาคำนวนราคารับมายังไง

หรือคน 1 คนตั้งราคามั่ว คนที่ 2 เดินมา อะรับราคานี้กันหรอ 3 4 5 6....เลยตั้งตามนั้นกันหมด แต่คงไม่ใช่อย่างนี้แน่ๆ เขาคงมี วิธีคำนวนกันอยู่ เลยอยากถามว่า เขาคำนวน รับ ขาย กันยังไง

อย่าง Blood Note เนี่ย คำนวนยังไงถึง รับกัน 1700-1800 เอาตามนี้ละกันคัฟ

ถ้าคำนวนได้ อย่างอื่น กะคงคำนวนได้เหมือนกัน ช่วย สั่งสอน เจ้าสัวน้อย ให้เป็น เจ้าสัวGOD ทีคัฟ
