เอ่อ ตอนผมเล่นหอก สาย AGi-STR สายหอก 2มืออยู่อะครับจะเล่นจ๊อบ50 ตอนนี้เวล 87 จ๊อบ 42 แย้วอะครับคืออยากรุ้ว่า ถ้าผมเปลี่ยนจากไนท์เป็นดาร์ค

แล้วต้องเอาสกิลไหนไปมั่งอะครับ หรือเอาไปแบบนี้อะครับ

1. Two-hand Spear Mastery ( ใช้หอกสองมือต้องอัพอยู่แล้น )
2. Spear Strike2 ( อัพอยู่แล้ว เอาตีเบิ้ล - - )
3. Light Add ( เห็นในกระทู้เขาบอกว่าถ้าอัพสกิลนี้ควบคู่กับสกิล Dark Add จะเพิ่มความแรงในการโจมตีไม่หักลบ สว่าง-มืด=โจมตีปกติช่ายมะครับ )
4. Divine Spear ( ต้องอัพไหมนิเห็นเขาบอกสกิลเดี่ยวแรงที่สุดแต่ผมไม่รู้อะคับ หรือว่าจะอัพ Soul of Knight แทนอะคับ แนะนำด้วยครับ)
5. Spear Cyclone ( เอาไปอยู่แล้นมันเป็นสกิลที่แรงที่สุดหนิ = =" )

ปล.อาจจะถามงงไปหน่อยก็อย่าว่ากันนครับ เด็กใหม่ครับ - -
ปล2.ต้องเอาสกิล Dimissory Spear ไปรึปล่าวครับ เพราะเรามี Spear Cyclone แล้วงะแต่ถ้าเอาไปต้องเอาไปแทนสกิลไหน ขอคำแนะนำด้วยครับ
ปล3.ถ้ามีสกิลไหนเพิ่มเติมก็บอกผมหน่อยนะครับยังไม่ค่อยรู้รายละเอียดสกิลมากอะครับ
