ระหว่างปืนสั้นมือเดียวกับ กับสองมืออันไหนคุ้มค่ากว่ากัน หรือน่าเล่นกว่ากัน เพราะรุ้สึกว่าปืนสั้นมือเดียวมันยิงช้า ส่วนสองมือยิงได้รัวกว่า แต่ตอนใช้สกิลรู้สึกจะแรงเท่าๆกัน(อันนี้คิดไปเอง) จึงอยากถามผู้รู้ว่า แบบไหนจะล้มมอนได้ไวกว่าและดีกว่ากัน

ปืนไรเฟิ่ล ยิงไกล(โคด)

ปืนสั้นมือเดียว สกิลร่ายไว(แม้จะไวกว่าไรเฟิ่ลนิดเดียวก็ตาม) ยิงแรง+แม่นมาก

ปืนสั้นคู่ สกิลร่ายช้า(แต่ดีเลย์จะน้ยกว่า) ยิงแม่นเพราะสกิลแฮนด์กันมาสเตอร์รี่
มีผลทับซ้อนกับสกิลดูเอลแฮนด์กันมาสเตอร์รี่ค่ะ แล้วยังได้สกิล อินครีตกันฮิตอีก
โดยรวมจะแม่น+แรงกว่ามือเดียวมากมายค่ะ แต่แลกด้วยความช้าในการใช้สกิล

ถ้าคิดจะเล่นแผงหลังก็ไรเฟิ่ล บุกตะลุยก็ปืนสั้นค่ะ ปืนคู่ไม่เหมาะกับการวอร์เท่าไหร่
เพราะมันร่าย ช้ามากกกกก

ปล. ปกติปืนสั้นมือเดียวค่ะที่ใช้

ตอนนี้กันเนอร์ที่เล่น Str 126 กดมาริกระโห้ได้+10 กดยาเทพ6บาทได้+อีก10 รวม146ค่ะ
ไม่นับรถถังกับคนได้ดีไวน์มานะคะ 90เปอร่วงในนัดเดียว (รถถังบางคันก็นัดเดียวถ้าดีไวน์หมด)
