วานิกได้ยินอย่างนั้นจึงได้กระโดดเข้าชนใส่ชายชุดดำที่กำลังจะเหนี่ยวไกปืน
ทำให้ปืนลั่น กระสุนปืนไปทะลุเพดานแทน ส่วนโรสก็เข้าไปใช้กำปั้นชกใส่ชายชุดดำอีกคนนึงที่ยืนอยู่ใกล้ๆ และเตะมันกระเด็นไปกระแทกกับผนัง
“หนอย!...แกนังเด็กบ้า...” ชายชุดดำคนที่โดนเตะกล่าวขึ้นพร้อมกับลุกขึ้นมาพร้อมปืนหันไปทางโรส
ส่วนวานิกที่ไปชนกับชายชุดดำก็กำลังกำหมัดจะชกใส่ชายชุดดำ แต่ก็ต้องหยุดชะงัก เมื่อชายชุดดำจ่อปืนไปที่ตัวเขา...
“ยุ่งนักนะแก!” ชายชุดดำกล่าวพร้อมค่อยๆเหนี่ยวไกปืนใส่วานิก
“อย่านะ!!...” เสียงตะโกนของชูที่ลุกขึ้นจากรถเข็น ได้กระโดดเข้าไปดึงแขนของชายชุดดำที่กำลังจะยิงปืน.....

แต่ชายชุดดำก็ได้สะบัดแขนใส่ชู ทำให้ชูล้มลงกระแทกกับพื้นพร้อมกับกระอักเลือด

วานิกยืนนิ่งค้างไปชั่วขณะราวกับว่าหัวสมองว่างเปล่า....

“แฮ่กๆ...” เสียงหายใจของโรสที่เหนื่อยจากการต่อสู้..... เมื่อเธอโค่นชายชุดดำลงได้....
ส่วนวานิกนั้น ก็ยืนก้มหน้าอยู่นิ่งๆ...กำมือทั้งสองข้างของตนเองไว้แน่น.......!!

“ตายซะเถอะเจ้าหนู!!” ชายชุดดำกล่าวพร้อมกับหันปืนไปทางวานิก
