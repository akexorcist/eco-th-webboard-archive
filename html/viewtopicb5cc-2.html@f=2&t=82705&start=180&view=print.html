(คงไม่ว่างแปลการ์ตูนแล้ว แต่ลองดูนะว่าจะหาอะไรมาแปะได้มั่ง )

เมื่อลงเมดซังและมีหมวยเป็นตัวละครสำคัญ ขอแปะดาต้าของหมวยไว้ละกัน

Boss ด่าน 3 ภาค 6

ผู้พิทักษ์ประตูแห่งสายรุ้ง/หมวย หง เหม่ยหลิง (Hong Meiling)



- โยวไคผู้ทำหน้าที่เฝ้าประตูหน้าบ้านมารแดง
- มีพลังในการควบคุมปราณ
- เชี่ยวชาญศิลปะการต่อสู้ของจีนโบราณอีกด้วย
- เหม่ยหลิง เป็นผู้รับผิดชอบในการขับไล่ผู้บุกรุกทั้งหมดไม่ให้เข้าไปในบ้านมารแดง ซึ่งโดยมากพวกที่เธอไล่ไปมักจะเป็นโยวไคชั้นล่างๆ
- ถ้าหากผู้บุกรุกยอมขอโทษและถอนตัวกลับไปดีๆ เธอก็จะปล่อยกลับไป
- เรมิเลียให้คำสั่งเอาไว้ว่าถ้าหากศัตรูแข็งแกร่งเกินไปก็ให้ปล่อยเข้ามาข้างในโดยไม่ต้องสู้
- แต่ถึงอย่างนั้นเธอก็จะพยายามขัดขวางอยู่ดี ต่อให้รู้ว่าเกินกำลังตัวเองก็ตาม
- เรย์มุกับมาริสะอยู่ในรายชื่อผู้บุกรุกตัวอันตรายที่ว่า แต่จริงๆก็มีแค่มาริสะคนเดียวที่ฝ่าเข้ามาได้ประจำ
- เหม่ยหลิงเป็นคนดูแลแปลงดอกไม้ใกล้ๆประตู และทำหน้าที่เป็นคนสวนกลายๆด้วย
- เนื่องจากเธอต้องเฝ้าหน้าประตูเกือบตลอดเวลา ทำให้เธอมีเวลาพักน้อย ส่งผลให้เธอต้องหลับในเวลาทำงานเป็นบางครั้งซึ่งโดยมากจะเป็นช่วงบ่าย และโดนแฟนๆเอาเรื่องนี้ไปล้อเป็นประจำ
- เอาเข้าจริง ถึงจะหลับอยู่เธอก็ยังเฝ้าประตูได้นะ
- เหม่ยหลิงจะรำไท้เก็กทุกเช้า
- แต่แม้จะถูกจัดเป็นตัวละครประเภทลูกน้องที่มีชีวิตรันทดคนหนึ่ง เธอก็ได้รับการปฏิบัติที่ค่อนข้างดีและสนิทกับสมาชิกในบ้านมารแดงทุกคน
- เรมิเลียเคยให้การ์ตูนเธอไปยืมอ่านด้วย
- เหม่ยหลิงเป็นคนซื่อตรง กล้าหาญ สดใส และเป็นมิตรมากๆ บางคนอาจจะคิดว่าเธอเป็นมนุษย์ด้วยซ้ำ
- บางทีก็ออกจะดูเอ๋อไปบ้าง นิสัยส่วนนี้เองที่ทำให้แฟนๆจับเธอไปเป็นตัวโจ๊กบ่อยๆ
- ในขณะเดียวกันก็เป็นคนที่มีความหยิ่งในฐานะนักสู้อยู่ไม่น้อยเช่นกัน
- ถ้าถูกท้าดวลอย่างซึ่งหน้า เธอจะไม่ปฏิเสธ และก็มีคนมาขอท้าดวลวัดฝีมือกับเธอบ่อยเสียด้วย
- ถ้าวัดกันตามความสามารถจริงๆแล้ว เหม่ยหลิงจัดว่าไม่แข็งแกร่งนัก แต่เธอไม่มีจุดอ่อนใดๆเป็นพิเศษ
- เธอเอาชนะซาคุยะได้ถ้าเธอเอาจริง
- ซึ่งการเอาจริงของเธอนั้นเกิดขึ้นได้ยากมากนอกการดวล เพราะนิสัยสบายๆนั่นทำให้เธอมักออมมืออยู่เสมอ
- เห็นว่าแม้แต่เวลากำลังสู้เธอยังมีนึกถึงข้าวเช้ากับอะไรพวกนั้น เลยไม่ค่อยสู้ได้เต็มที่เท่าไหร่
- ปัญหาสำคัญอีกอย่างสำหรับเหม่ยหลิงคือการที่เธอนั้นเชี่ยวชาญการต่อสู้บนพื้นดินในระยะประชิด ขณะที่การต่อสู้ในเก็นโซเคียวส่วนใหญ่นั้นจะเป็นการยิงดันมาคุใส่กันบนฟ้า
- ยังไม่มีใครรู้ว่าจริงๆแล้วเธอเป็นโยวไคประเภทไหน เท่าที่ดูจากลักษณะภายนอกแล้วหลายๆคนคาดว่าเธอน่าจะเป็นมังกร ซึ่งถ้าเป็นงั้นจริงล่ะก็...
- เหม่ยหลิงถูกบางคนในเก็นโซเคียว(และคนจำนวนมากในเน็ท)เรียกว่า หมวย หรือ China
- เนื่องจากเธอมีลักษณะการต่อสู้ที่คล้ายมวยคนจีน และชื่อของเธอสามารถอ่านได้ทั้งแบบจีนแบบญี่ปุ่น จึงทำให้เกิดการโต้เถียงอย่างเอาเป็นเอาตายว่าแท้จริงแล้วเธอควรถูกเรียกว่าอะไร การโต้เถียงนั้นดุเดือดและเนิ่นนานจนในที่สุดก็มีคนออกความเห็นว่า “ช่างหัวมันเหอะ เรียกเธอว่าหมวย(China)ก็แล้วกัน” อันเป็นที่มาของชื่อเล่นของเธอในปัจจุบันนี้
- เหม่ยหลิงไม่ค่อยชอบชื่อเล่นนี้เท่าไหร่
- ชื่อของเธอถ้าอ่านแบบญี่ปุ่นจะเป็น คุเรไน มิซึสึ
- มักถูกแฟนๆวาดให้โดนซาคุยะเอามีดปักหัวอยู่บ่อยๆ
