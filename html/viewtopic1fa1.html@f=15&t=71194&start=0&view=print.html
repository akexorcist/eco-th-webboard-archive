ไม่ถามมันซะทุกอาชีพเลยล่ะครับ

เข้าเรื่องเลยล่ะกัน ผมไม่ค่อยเล่น Warlock นะครับ (ส่วนมากเล่น Farmer -3- ไม่ก็ Vates) แนะนำผิดยังไงก็ขออภัยล่ะกัน

อย่างแรกถ้าเป็น Warlock สกิลที่น่าสนใจของคลาสนี้ก็จะมี Shadow Blast ตอนจ๊อบ 40 (มั้ง - -*) Dark Shield กับ Dark Weapon (ใช้เพิ่มพลังโจมตี กรณีอยากเล่นสนับสนุนหรือจะเอามีดไปจิ้มก็ตามใจ - -*) ถ้าถือโล่ก็ Shield Mastery (เพิ่มบล๊อค 10%) ส่วน Dark Globe แล้วแต่จะอัพเถอะครับ เอาเป็นว่าสกิลน่าสนใจของคลาสแรกจะมีสกิลโจมตีคือ Shadow Blast ตัวเดียว (ตัวที่ผมเล่นก็อัพอันนี้อันเดียวด้วย - -*)

ต่อไปถ้าจะเป็น Kabalist ก่อน Necromancer สกิลที่น่าสนใจก็จะมี Mark และ Dark Pain และถ้าจะใช้สกิลโจมตีกลุ่ม (แบบพวกลากยิง) ก็แนะนำสกิล Nassingness (Nothingness) และถ้าเล่นสาย Mark มาจะเอา Infenal Mark มาด้วยก็ได้ (ใช้วาง Mark ทีละ 3 จุด และไม่จำกัดจำนวนครั้ง) แล้วก็สกิลจ๊อบ 50 Dark Blazer ใช้โจมตีได้ ... มาถึงตรงนี้อย่าเชื่อผมมากเพราะผมเล่นแต่ Warlock -3-

ที่เหลือให้ผู้เชื่อยวชาญตอบล่ะกัน - -*
