มากๆ แต่จะโจมตีมอนธาตอื่นๆรวมถึงธาตแสงลดน้อยลงมากๆเช่นกัน

สมมุติ กำหนดให้ B.Blow เบากว่า LS เมื่อ มีผลต่างAtkที่เพิ่มจากอาวุธ เป็น a
สมการได้ดังนี้
Atk*270/100 < ( Atk + a )*210/100 -------(1)
Atk*2.7 < ( Atk + a )*2.1
2.7(Atk) < 2.1(Atk) + 2.1(a)
0.6(Atk) > 2.1a
Atk < ( 2.1 / 0.6 ) a = 3.5 a ------- (2)

เหยื่อของเราคือ pike หอก 2 มือเลเวล 35 ค่าAtk(21/28/40/-)
ได้ a = (40-21) = 19

แทน a ใน (2) Atk < 3.5(19) = 66.5 ~ 66
( ค่าที่ได้อาจไม่ตรง100% เพราะไม่ได้ปัดเศษในสูตร !! ประมาณเอาล่ะกัน)

ดังนั้น ถ้าใช้ pike ซึ่งค่าแทงมากกว่าทุบ 19 หน่วย B.Blow จะเบากว่า LS เมื่อ Atk น้อยกว่า 66 แต่อย่าลืม ว่า atk ในสูตร + ค่าโจมตีของอาวุธเข้าไปแล้ว ดังนั้น Atk แบบไม่รวมของอาวุธ ยิ่งน้อยลงกว่า 66 แน่ pike ใส่ได้ตอน 35 atk มันคงเกินแล้วล่ะ

ก็นานาจิตตังครับ เลือกอัพได้ตามชอบใจเลย

sp 30 หน่วยนั้นใช้ LS ได้4หน ใช้ BB ได้ 3หน

คนที่บอกว่า ถ้าโดนโจมตีเวลาร่ายสกิลจะโดนยกเลิก ผมคิดว่าไม่น่าจะจริงนะครับ

ถ้าเป็นเวทย์อาจจะใช่ แต่สกิลโจมตีแบบนี้ไม่โดนยกเลิกนะครับ

ผมคิดเอาจากตอนที่ไปเก็บเลเวลแมปหมี ผม LS หมีที่มันรุมๆเป็นสิบๆตัวทีละตัวลงไป

นอนตายทีละตัวๆได้สบายๆ โดนตบก็ยังโจมตีด้วย LS ได้ตามปกตินะครับ

ปัญหาของ fencer หรือ knight ใน pvp น่าจะเป็นจุดที่ไม่สามารถโจมตีพวกสาย agi โดน
