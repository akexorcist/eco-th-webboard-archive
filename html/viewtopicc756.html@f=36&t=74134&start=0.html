(208,21)





2. เมื่อคุยเสร็จแล้วให้ไปที่ Infinite Gallery พิกัด [2119300](134,207)

ให้เข้าไปในบ้าน ตาม ในรูป





3. เข้าไปในบ้านจะพบกับ หนังสือ ที่วางอยู่บน โต๊ะกลม กลางห้อง ให้เดินเข้าไปอ่าน

เพื่อส่ง Jewel of Hope ให้ เพื่อเริ่มทำการสุ่ม ชุดเลเวล 99



คำเตือนก่อนส่ง !!!


1. ทางผู้เล่น สามารถเลือกได้ระหว่าง ชาย / หญิง



2. หลังจากเลือก ระหว่าง ชาย / หญิง เรียบร้อย จะเป็นการเลือกสาย อาชีพ
Fighter / Spell User / Backpacker



3. เมื่อเลือกสายอาชีพ แล้ว จะเป็น ขั้นตอนการสุ่ม ชุด Set ของ อาชีพ ที่อยู่ ในสายอาชีพที่ได้เลือกไปใน ข้อ 2 ค่ะ และจะมีข้อความเตือนซ้ำอีกครั้งนะคะ




4. สุดท้าย ต้องมีที่ว่าง ใน ช่องเก็บของก่อนการรับชุด 99 ก่อนการรับชุด

เนื่องจาก ชุดเลเวล 99 ใน 1 set อาชีพ จะมี จำนวน ชิ้น ไม่เท่ากันค่ะ

LV 250 HP ไม่ทราบ
สกิล Emil Dragon ร่างคน

1. Anima Drain
เวทย์ไร้ธาตุ พื้นที่ 15x15 ช่อง, MDEF 0 โดนที่ประมาณ 11000, ดาเมจที่ทำได้จะไปเติมเลือดให้ตัวบอส

2. Alter Fate
สุ่มธาตุลงให้กับอาวุธ และ โล่ของตัวเอง (เหมือนสกิล xx-Weapon xx-Shield ของชาแมน)

3. Alter Zero
ทำให้การโจมตีประเภทธาตุทั้งหมดที่ใช้ใส่ตัวบอสเป็น 0, ระยะเวลาสกิลนาน 3 นาที

4. Zoma Mirage
ทำให้การโจมตีประเภทไร้ธาตุทั้งหมดที่ใช้ใส่ตัวบอสเป็น 0, ระยะเวลาสกิลนาน 3 นาที

หมายเหตุ* Zero กับ Zoma ใชัซ้อนกันไม่ได้ สมมุติบอสใช้ Zoma ก่อน การโจมตีกายภาำพทั้งหมดจะอัดมันไม่ลดเลย แต่ยังใช้เวทย์ธาตุยิงมันลดได้
และในระหว่างเวลานี้บอสจะใช้ Zero ไม่ได้จนกว่าระยะเวลาของ Zoma จะครบ 3 นาทีซะก่อน

แต่ ! บอสสามารถใช้สกิลเดิมซ้ำเพื่อยืดระยะเวลาได้
ตัวอย่าง -> Zoma Mirage -> กันกายภาพผ่านไป 2 นาที -> Zoma Mirage ซ้ำ reset กันกายภาพเป็น 3 นาทีใหม่

ตัวอย่าง2 -> Zero -> กันธาตุ 3 นาที -> Zoma -> กันกายภาพผ่านไป 2 นาที -> Zoma ซ้ำ กันกายภาพ 3 นาทีนับใหม่

อนึ่งเวทย์โจมตีของ Sage/Sorceror จะไม่มีผลกับสกิล Zoma และ Zero กล่าวคือไม่ว่ามันจะร่ายบาเรียกันอะไรก็ตาม สองคลาสนี้เท่านั้นที่จะยิงทะลุบาเรียมันได้ตลอด
เวทย์ที่ Sage/Sorceror ที่สามารถยิงใส่บอสได้โดยไม่เกี่ยงบาเรีย
1. แขนง Energy ทั้งหมด (Enerygy Bolt, Flare,Blast ฯลฯ)
2. Luminary Nova
3. Last Inquest
4. Raving Sword (น่าจะทะลุกายภาพมั้ง.. ในวิธีลุยมันเขียนให้ยิงอันนี้เป็นหลักแฮะ)


ลูกบอส Emil Feather
แบ่งเป็นประเภทๆ แล้วแต่บอสจะซัมมอน แต่ละประเภทมีธาตุติดตัวต่างกัน

1.Emil Feather-R
Fire Attack, Fire Art(ระเบิดตัวเองเป็นธาตุไฟ)
2.Emil Feather-B
Water Attack, Aqua Art(ระเบิดตัวเองเป็นธาตุน้ำ)
3.Emil Feather-Y
Wind Attack、Blaster Art(ระเบิดตัวเองเป็นธาตุลม)
4.Emil Feather-G
Saint Art(ระเบิดตัวเองเป็นธาตุแสง)

ขนนกพวกนี้จะระเบิดตัวเองทันทีเมื่อเวลาผ่านไปได้สักพักหนึ่ง ดังนั้นถ้ารีบกำจัดซะก่อนก็ไม่น่าจะมีปัญหาอะไร
