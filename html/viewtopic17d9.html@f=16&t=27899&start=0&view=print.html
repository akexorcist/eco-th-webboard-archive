สกิล Wood Create ตอนนี้ของชิ้นไหนโดนตัดให้ทำไม่ได้

โพสต์แล้ว: พุธ 31 ต.ค. 2007 10:34 am
โดย ECO
อยากรบกวนเพื่อนๆที่หาของทำงานไม้บ่อยๆหน่อยว่าตอนนี้มีของชิ้นไหนที่โดนอุ้ม เอ๊ย โดนตัดการผลิตออกไปแล้วบ้างอ่ะ คือตอนนี้เล็งๆพวก Big Commrade ไว้แต่มานั่งนึกดูอีกทีเหมือนจะเคยได้ยินว่าของเฟอร์นิเจอร์ที่ลงมอลล์ไป + ของบางอย่างตอนนี้ไม่สามารถทำได้อีกต่อไปซะแล้ว ใครมีข้อมูลของชิ้นไหนก็รบกวนด้วยนะ กลัวหาของมาเก้อแล้วทำไม่ได้จะเศร้าจิต

อีกเรื่องนึงคือ มีNPCที่รับทำพวกกระถาง (Gardening) มั้ยอ่ะ ถ้ามีเราจะได้ไม่อัพ Gardening ไปเอาพ้อยลงสกิลอื่นแล้วไปทำกับ NPC เอาอ่ะ
