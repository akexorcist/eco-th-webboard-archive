ไหนๆก็เปิดกระทู้เกี่ยวกะขายของแล้ว ขอแจมถามด้วยคนนะคับ

เกี่ยวกับโกเลมขายของที่เค้าตั้งกันไว้
จะเห็นว่ามีหลายคนมักจะเอาของปัญญาอ่อนเช่น replica sword หรือ seriko
เอามาตั้งราคาไว้เว่อร์ๆเช่น 99999999 ประมาณนี้รวมกับของที่ต้องการขายจริงๆด้วย
เพื่อที่เวลาของที่ขายจริงๆขายออกไปหมดแล้วโกเลมจะได้ตั้งอยู่ไม่โดนเก็บไป
อยากทราบว่าเทคนิคการเอาโกเลมค้างไว้ในเกมแบบนี้มันมีประโยชน์อะไรหรือเปล่า
ความรู้สึกส่วนตัวผมว่ามันเกะกะนะ ร้านไหนขายหมดแล้วก็น่าจะเก็บๆไป
คนไปเลือกซื้อก็ไม่ต้องเสียเวลาไปเปิดดูร้านที่ของหมดแล้วด้วย
หรือว่ามันมีประโยชน์อะไรแฝงที่ผมคิดไม่ถึง?
