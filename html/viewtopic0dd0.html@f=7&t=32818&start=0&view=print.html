นอกบ้านออกจะดูโหดไปนิดส์นึง เลี้ยงไว้เฝ้าบ้านครับ อิอิ



หน้าบ้านมียามโหดอยู่สองตัว ขึ้นมาระวังช๊อคนะครับ หุหุ



อ่านหนังสือเรื่องไรดีน้า แต่เอ คุณวัวหาเรื่องไรอ่านะ สงสัยจัง ?



ส่วนนี้ห้องอาหารครับ ใครหิวก็มานั้งกินได้เลย มีบ๋อยอยู่ด้วย !!



ส่วนนี้ก็อีกมุมหนึ่งของห้องอาหาร งับป๋ม



มุมนี้มุมรับแขกครับ ใครมาเที่ยวต้องพามานั้งมุมนี้เลย โรแมนติกมาก



อีกมุมหนึ่งของห้องรับแขก บรรยากาศได้เลยนะเนี้ย อิอิ



มุมพักผ่อน ห้องนอนของผมคร๊าบ อิอิ ตู้เยอะจิง งิงิ


อีกมุมหนึ่งของห้องนอน ประดับด้วยต้นไม้เพิ่มความสดชื่น



หึหึ พาสาวมานั้งกินข้าว สั่งน้ำหวานมาให้ กินด้วย อิอิ



หมดแล้ว แล้วพบกันใหม่ โอกาศหน้า คร๊าบ สวยไม่สวย ติชมด้วยนะ ขอบคุณคร๊าบ
