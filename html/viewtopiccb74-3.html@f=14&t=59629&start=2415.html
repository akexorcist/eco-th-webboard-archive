Edit : เพิ่ม

จะว่าไป สถานะ "เกร็ง" กับ "มึน" ต่างกันอย่างไรครับ

ต่างก็ทำให้ค่า Avoid 0 ทั้งคู่เหมือนกันนิ


เอฟเฟรค เกร๊ง กับ สตัน เหมือนกันตรงที่ จะไม่ติดคริติคอล ไม่สามารถขยับได้ หรือท่าร่ายสกิลอยู่ การร่ายจะชะงัก ไม่สามาถเคลื่อนที่ระหว่างติดเอฟเฟรคได้

เกร๊ง ไม่สามารถใช้ยาชนิด ใดใด ในโลกของเกม eco รักษาให้หายได้นอกจากปล่อยไปตามเวลา

สตัน สามารถใช้ยาช่วยรักษาได้ สตันในที่นี้ขอกล่าวรวมทุกสกิลที่ทำให้เกิดผลสตันว่า
สกิลบางสกิลที่ทำให้เกิดสตัน int สามารถใช้ anti body ได้(เลียนแบบไข้หวัดตัวใหม่)
คือ ถ้ามีint จำนวนนึง บางสกิล อาจจะเกิดเอฟเฟรคสตันแปปเดียว ค่ะ ^^

น่าจะ บอกละเอียดและ -_,-"

รู้ล่ะ Poison Needle หาจากไหน (มันมีขายร้านลับใน downtown)
น้ำหนัก 0.0 ก็ดูคุ้มค่าดี ถ้าพกไป แต่ราคาก็หนักเอาการ 450G ต่ออัน

ไม่ได้ถ่ายภาพไว้แหะ แต่ก็สรุปได้คร่าวๆ เกี่ยวกับสกิลนี้

-ถึงสกิล miss แต่ก็ยังติดพิษได้ << ลองแล้วกับน้อง ไม่โดน ก็ไม่ติดแหะ แปลกใจเหมือนกัน
แต่พอใส่ธนู (มี int 40) ขว้างไปปุ๊บ โดนปั๊บ ติดพิษเลย ( ลอง 2 ครั้ง ก็ติด 2 ครั้ง )

Damage สกิลนี้ 100% ที่เวล 5 โอกาสติดพิษ ก็ราวๆ 90%

ทดลองที่แม็พ หอแสง

แพ็ตตินั่ม ติดง่าย ขว้าง 1 ครั้งก็ติดแล้ว ยกเว้นดวงไม่ดีจริงๆ ขว้าง 4 ครั้งก็ไม่ติดเลย
งูเหลือง (ชั้น2) ก็ติดเหมือนแพ็ตตินั่ม
ค้างคาวทอง เหมือนง่ายนะ ขว้างทุกครั้งติดทุกครั้ง

หุ่น GagantoC4 , Fox HoundB3 , Fox TrotR4 , Fox HoundG4 พวกนี้ "ไม่ติด" เลย
ขว้างจนตายเลยครับ อ้อ Kodama ก็เช่นกัน ส่วนหินขาว ไม่ได้ลองแหะ

ยังไงเสีย สกิลพิษ ทั้งหลาย เหมือนจะแพ้ทางพวกสายถึก ( vit ) พวกไหนถึกๆ ไม่ติดพิษแหง
(หุ่นแดง มันถึกด้วยหรอ ? )
