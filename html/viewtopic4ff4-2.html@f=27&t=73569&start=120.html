pri- ความหมายของมันคือ ตัว unpack มันจะเอาไฟล์ที่มีคำๆ นี้ ไป overwrite หรือเขียนทับ
นั่นแหละงิ

ส่วนเวลาพิมพ์ใส่ ให้พิมพ์ใส่ตัวไฟล์งิ ไม่ใช่ในโปรแกรม ; w ;

ส่วนการเปลี่ยนรหัสใน itempict ไม่ใช่ตรงนั้นงิ นั่นมัน ID ของ item นั้นๆ เลย อย่าไปยุ่งจะดีที่สุด

จะเปลี่ยนการแสดงผล ให้เปลี่ยนที่ 09_121_00 หรือ 00_1154_00

เช่น จะเปลี่ยนการแสดงผลเสื้อแอส 65 ให้เป็นเสื้อนักเรียนตัวใหม่

ก็เอา่ำทำการหารหัสชุดใหม่ก่อน นั่นคือ 00_1162_00

เสร็จแล้ว ให้ "Copy" ทั้งแถวตั้งแต่รหัส 00_1162_00 ไปจนขวาสุด
ของรหัสทั้งหมด (ชุดบางชุดมีค่า null อยู่ด้วย ถ้าเอาแต่รหัสไปทับ การแสดงผลอาจจะเอ๋อ)

เสร็จแล้ว ก็เอาไปวางตรง 00_56_50 (ชุดแอส ญ 65 ) เลย แล้ว save

ส่วนการเปลี่ยน ของแต่งบ้าน ... อันนี้ไม่เคยทำงิ ... ไว้ว่างๆ จะลองละกัน (ถ้าว่างจริงๆ)

รหัสลูกไฟ = 08_57_00

ตรงไหนที่ไม่เข้าใจอ่ะครับ

ถ้าตรง pri- ก็ ลองโหลดไฟล์ที่คุณเฟแจก หน้าแรกอ่ะ จะเห็นได้ชัดเจนหน่อย

โหลดมาแล้ว ลองแตกไฟล์ที่ไหนก็ได้ แล้วลองเข้าไปดู ก็จะเห็นว่าไฟล์พวกนั้นเติม pri-


ส่วนถ้าเรื่องการสับเปลี่ยนรหัสใน itempict

เอาแบบง่ายๆ ก่อนเพื่อความเข้าใจ ก็ ลองเปิดขึ้นมาแล้ว ค้นหารหัส (ขอยกตัวอย่างก่อนละกัน
)

ให้ค้นหารหัส 08_48_51 (มันคือรหัสปลอกคอ ฮาโลวีน สีแดง)

เมื่อเจอแล้ว ให้ทำการ เปลี่ยนเลข เป็น 08_57_00



"เปลี่ยนเลขเลยนะ จาก 08_48_51 เป็น 08_57_00 เลย "


เสร็จแล้วลอง save แล้ว rebuild ดูนะ

ลองโหลดไปใช้ได้

แต่มันเปลี่ยนหมดทุกตัวเลยนะ ยกเว้นตัวใหม่ๆ

หุ่นยนต์ > DEM ช
ปลา > DEM ญ
เบรี่ > หุ่นยนต์ DEM แมงมุม (ตัวใหม่ที่ยังไม่มีใน Data eco ไทย)
ซาลาแมน > DEM ดาบคู่
ไอซี่ > ตัวปีกดำ ล่ะมั้ง (จำบ่ได้)
ไทนี่ > ตัวปีกฟ้า น่าจะ
ซานต้าไทนี่ > มังกรน้ำ ?
แมนดาโกร่า > ตัวอะไรหว่าที่อยู่ดันปลาวาฬนั่นแหละ (ตัวต้นไม้อ่ะ)
โฮมูร่า > มังกรอีิมิลร่างคน
ตัวอื่นๆ ถ้ามี > ไปวัดดวงเอาเอง...

ตอบ @loucifer@ :

แก้เลขตรง ที่เราจะเปลี่ยนนั่นแหละ ให้เป็นเลขที่เราอยากเปลี่ยน
ส่วนเลขอะไร ก็ดูจากโปรแกรมแต่งตัว มันเขียนเอาไว้แล้ว พวก 00_xx_00 พวกนี้จะเป็นจำพวกเสื้อ
พวก 09_xx_00 จะเป็นพวกรองเท้า

เวลาแก้ ก็แก้ item ที่มันประเภทเดียวกัน เช่น เสื้อเวล 1 มันประเภท one piece
ก็หาเสื้อที่ต้องการจะเปลี่ยนให้เสื้อเวล 1 นั่น เวลาใส่แล้วจะแสดงผลเป็นเสื้อที่เราต้องการ
ตัวอย่าง : เสื้อเวล 1 รหัส 00_01_00 ส่วนเสื้อ Witch คือ 00_1100_00

เราก็แก้เลข 00_01_00 ให้เป็น 00_1100_00 (สรุปว่าเราอธิบายซ้ำสินะ)

ส่วนที่สงสัยเรื่องเลขนั่น ในภาพตัวอย่าง ไม่ต้องสนใจ นั่นมัน ID รหัสหลักๆ
ถ้าไปแก้ล่ะงานงอก

สรุปคือ
1. ไปที่ unpack>data>xls>table.dat>pri-itempict.csv (หรือ cvs นี่แหละ) เปิดมันขึ้นมา
2. search หา รหัสที่เราต้องการเปลี่ยน(เช่น รหัสชุดวิส)
3. จำเลขไว้
4. search หา รหัสที่เราต้องการเอาไปทับ ( เช่น เสื้อเวล 1 onepiece )
5. จบ save แล้วออกไป rebuild

ภาพปลากรอบอร่อย : [ พร้อมคำอธิบายอย่างตำนาน (ละเอียด) มั้ง... ]




1. หารหัสเสื้อที่ต้องการ (ในนี้ยกตัวอย่างการแก้การแสดงผลเสื้อ นั่นคือ ใส่เสื้อเวล 1 ธรรมดา
แต่รูปที่เราเห็นคือเสื้อ Envy ญ )
สีแดงนั่นคือรหัสที่เราทำการค้นหา (เสื้อ Envy รหัส 1084 )
สีม่วงนั่นคือ ระบบทำการค้นหาเจอแล้ว



2. เมื่อพบรหัสแล้ว ให้ทำการ Copy ตั้งแต่ตรงช่องรหัส แล้วลากยาวไปถึงหลังสุดของรหัส
(น่าจะถึง row AL ล่ะมั้ง)



3. เสร็จแล้ว search หารหัสเสื้อเวล 1 (ในที่นี้สมมุติว่ารหัสในภาพคือ เสื้อเวล 1)
เมื่อพบแล้ว ให้ไปคลิกที่ช่องรหัสนั้น แล้วทำการ paste ( ctrl+v ) รหัสเสื้อ Envy ทับลงไป
