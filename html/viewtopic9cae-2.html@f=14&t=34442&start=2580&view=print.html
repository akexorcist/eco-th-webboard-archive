ตอนแรกก็นึกว่าระบบ Iris เข้ามา การ์ดจะดอปจากมอนหลายๆ ตัวด้วย

( ex. แมชชีน สู้กับหุ่นยนต์ ต้องอัพ int เพื่อหลบ สู้1-1)
