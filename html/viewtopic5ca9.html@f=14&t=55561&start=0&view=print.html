1) พิษตีแรง - แล้วแต่ความชอบนะ ส่วนเราอัพไว้เพราะเน้นความแรงอะ ถ้าไม่เน้นก็ข้ามไปก็ได้ จะได้ประหยัดพ้อยและเงินค่ายา

2) ค่อนข้างงงกับคำถาม คือจะสวิชไปเก็บให้คอมมานโดจ็อบ 30 เพื่อทำชุด 75 แล้วสวิชกลับมาเล่น Assassin ใช่มั้ยงับ จะทำแบบนั้นก็ได้ ผลเสียคือ จ็อบแอสจะลดลง ถ้าไม่อยากลดก็มีทางเลือกคือไม่เก็บจ็อบแอสเลย พอสเก๊าจ็อบ 50 ปุ๊บก็สวิชไปคอมมานโดทันที หรือไม่ก็ นาฬิกาทรายจากแคช สนนราคา 50 บาทถ้วน

3) หนทางหาเงินมีมากมาย เช่นล่าแสตมป์บอสขาย ล่าของเควสขาย ต้องดูว่าเราหาอะไรง่ายสุดแล้วก็ศึกษาตลาดนั้นไว้ หรือไม่งั้นก็หาของมาโยนโกเล็มที่ราคารับดีที่สุด (เช่นหนังม่วง สมุดปกแดง ดาร์กโคโลญจน์)

4) สาย pvp เท่าที่เห็นก็โปรยพิษนะ แต่ที่ถือมีดกันเพื่อจะถือโล่ เพิ่ม DEF ได้ (ปล. ข้อนี้ไม่ชัวร์เพราะเป็นแอสสายเวล)
