พอดีเรื่องสเตตัส(สาย PVP) อยากถามว่าอยู่จ๊อบไหนดีกว่าครับ ระหว่างบาวตี้กับเบลด ส่วนตัวผมคิดว่าเบลด เพราะจะได้อัพ STR 126 DEX 50 AGI 72 VIT 90 INT 30 ได้ รู้สึกว่า จะเป็นค่าพลังที่ลงตัวดีนะครับ(เท่าที่ถามมา) แต่ก็กังวลเรื่องสกิลว่า ของจ๊อบไหนมันจะดีกว่ากัน

หรือใครคิดว่ามีสเตตัสสูตรอื่นอีกบ้างครับ เอามาเผยแพร่กันบ้างนะครับ

int ผมเคยลองอัพ แต่ไม่ยักจะช่วยอะไรเท่าไหร่


เห็นหน้ากระทู้นี้บอกว่า int มันช่วยเพิ่มอัตรา Berserkcontrol และ Warcry นี่ครับ เลยคิดว่ามีประโยชน์ แล้วก็กันเวทย์ได้ด้วย หรือว่าสายPVP ส่วนใหญ่เขาไม่อัพ Berserk หรือครับ
แล้วอีกอย่างตกลง Warcry ถ้าเพิ่ม int แล้วจะกันสกิลนี้ได้มากขึ้นหรือเปล่าครับ เห็นใช้กับมอน บางทีไม่ค่อยโดนเลย


ส่วนใหญ่สายPVP ก็อัพนะสัก10-20 เเต่จิงๆ มันไม่มีค่อยจะมีผล

มันช่วยเพิ่มโอกาสติดสถานนะต่างๆ(Warcry) เเต่บางมันไม่มองเห็นเป็นรูปเป็นร่างเท่าไหร่ยิ่งถ้าทำใส่พวกสายวิทหรือพวกที่อัพInt ด้วยกันก็เเทบไม่เห็นผล

ส่วนตัวผมก็อัพInt ไว้20 ถึงมันจะเห็นผลบ้างไม่เห็นบ้างเเต่ก็อุ่นใจ...
