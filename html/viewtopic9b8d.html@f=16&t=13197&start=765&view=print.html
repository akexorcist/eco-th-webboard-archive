ข้อแตกต่างระหว่าง Merchant / Golem
Merchant
- ตั้งร้านไปเล่นไปได้
- จึงโดนตบตายหรือเก็บ level ได้
- ต้อง online ตลอด เพื่อร้านจะได้ตั้งอยู่
- เล่นอีกตัวละครไม่ได้ ..... แหงซิ!!

Golem
- เสียค่าใช้จ่าย และมีความทนทาน (จะลด 1 ทุกครั้งที่หลังจากสั่ง logout และทิ้ง golem ไว้ทำงาน)
- Golem จะทำงานเมื่อเจ้าของ log out ออกไปแล้วเท่านั้น
- Golem จัดเป็นของประดับฉาก ไม่โดนตบ ไม่โดนทุบ มีแต่โดนจิกหัวใช้แอบร้องกระซิกๆตอนเจ้านายไม่ใช้
- เมื่อ ID ที่สั่ง Golem ทำงาน login ปุ๊บ Golem จะหยุดทำงานทันที (นั่นทำให้ไม่สามารถปล่อย golem อาละวาด 3 ตัวรวดใน ID เดียวได้)
- สามารถเล่นอีก ID แล้วปล่อย Golem ตั้งร้าน ทำงานของมันต่อไปได้ ไม่เหมือน Merchant ที่ถ้าจะทำเช่นนี้ต้องไปหาอีกเครื่องมาแทน
- มี Golem Catalog ไว้ใช้กรณีลงทะเบียนสินค้าซื้อ-ขาย (เสียครั้งละ 500 ต่อการใช้งาน 1 ครั้ง)
