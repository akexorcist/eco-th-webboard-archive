โทดทีคะ ม่ายด้ายเข้ากระทู้มานาน

ก้อทัมตามรูปนี้เลย (อธิบายใหม่ เพื่อว่ายังงงๆกาน)

เริ่มต้นด้วยการลงสีพื้นอ่าจ๊า ก้อเปนการบอกขอบเขตของส่วนทีเราจาลง
เพนท์ทัมมะดาไปเลย


แล้วก้อสร้าง layer เปล่าๆมา วางไว้ข้างบน layer ของสีพื้น (ตอนนี้เค้าตั้งชื่อเปนเลเยอร์ Hair เพื่อป้องกันความสับสนเท่านั้นเอง)


แล้วก้อคลิกขวาที่เลเยอร์ที่เพิ่งสร้างขึ้นมาใหม่ (Layer 1 ในรูป)
เลือก Create Clipping Mask


แล้วเวลาเราเพนท์ มันจะไม่หลุดออกนอก layer ของสีพื้น เลย
ทัมให้สะดวกเวลาเพนท์ (จิงๆนะ)
