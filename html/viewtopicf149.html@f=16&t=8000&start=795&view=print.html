8.สุดท้ายตารางสกิลเพิ่มHp/SPไม่เหมือนกัน มันจะเพิ่มตอนเพิ่มLvด้วยหรอ? อัพดีมั้ย?



1. มีแน่นอนงับ แล้วแต่เราเลยงับ แต่ลงดันควรใช้ของ Explorer มากกว่าครับ

2. แบนดิสน่ะครับ แล้วแต่ใครชอบอ่ะครับ ถ้ากลัวเปลืองการรี ใช้ โบ ก็ได้งับ

3. เปิดกล่องดีมากๆๆๆๆ แต่ใช้กับ TreasureMastery ยังม่ายทราบอ่ะครับ

4. พอเราตีกล่อง ไอเทมดีๆจะตกแทนกล่องงับ ช่น แว่นตา หรือ แรร์ต่างๆอ่ะครับ

5. เวลาใช้จะเหมือนห้องอ่ะครับ เข้าไปอยู่ข้างใน มอนเตอร์อัดไม่ได้ ตั้งได้ทุกที่

อัฟก็ควรอัฟแค่ 4-5 พองับ แล้วแต่ใจเลยงับ

6. ป๋มม่ายรู้ว่าดีป่าวน่ะครับ แต่ป๋มม่ายอัฟ อ่ะครับ รออัฟของ Explorer อ่ะครับ มันจะดีก่า

7. ดีมากงับ ลดนําหนักไปได้เยอะมากๆ ใช้กับ Analysis ได้งับจะสกัดได้เยอะขึ้น

8. Hp Max ควรอัฟงับ เวลา Lv อัฟก็จะเพิ่งขึ้นให้ด้วยงับ

มากกว่านี้ก็ตอบให้ได้น่ะครับ ม่ายต้องเกรงใจครับ สู้ๆ ^^ เปงกามลังใจให้งับ เพื่อเพื่อนๆ
Ranger ด้วยงับ เต็มใจงับ

ผมเข้าใจถูกไหมครับ - -"
