หลอมคือการเอาไอเทมที่มีความสวยงาม+กับไอเทมที่มีความสามารถดี ทำนองนี้

การหลอมมีประโยชน์ยังไง

1.เราสามารถเอาไอเทมที่มีความสามารถดีแต่มันดันไม่สวย ไปรวมกับไอเทมประภทเดียวกันที่มีความสวยได้

2.จะให้ได้ว่าเสื้อผ้าจากแคชนั้น ก็หลอมได้เช่นกัน แล้วยังสามารถเทรดได้ด้วย

การหลอมนั้นไม่ต้องใช้สกิลใดๆเพราะมีที่หลอมอยู่ที่ฟูจิกิแค่ไปหาป้าทำเควสเริ่มแรกนิดหน่อย(เดิน2แมพไปมา)

ถ้าหลอมพลาดกยังไม่หายแค่เสียเงินเท่านั้นเอง มีคนทำข้อมูลเรื่องการหลอมอยู่แล้วนะ ลองหาเพิ่มเติมดูนะครับ
