เพิ่งตอน 2 เอง ตัวร้ายคงไม่โผล่ตอน3 หรอกครับ อย่างเก่งก็ตัวกระจ๊อกที่แสดงความเป็นตัวร้ายชัดเจนเท่านั้นแหละครับ(เช่นเหล่าพลัง K ในตอน 2 ที่ผ่านไปนี่แหละ)

ไม่ก็แบบ davinci code ตัวร้ายระดับหัวหน้าใหญ่อยู่ตรงหน้าแต่คนอ่านก็ยังดูไม่ออกว่ามันเป็นตัวร้าย จนเฉลยตอนใกล้จบเรื่องแล้วนั่นแหละถึงจะรู้กัน(เรื่องนี้ยอมรับว่าคนแต่งมันปิดตัวร้ายได้โค ตะ ระ เนียนครับ เพราะผม พ่อแม่ น้อง อ่านถึงตอนมันเฉลยถึงได้รู้ว่าใครเป็นตัวร้าย)

หรือจะอีกแบบ ดูเหมือนเป็นตัวร้าย แต่ไปๆมาๆกลายเป็นพระเอกซะงั้น เช่นกัปตันไคเอะดะ หรือ darth vader ในภาค return of the jedi เป็นต้น

แค่คาดเดา + มาดันกระทู้ไม่ให้ตกครับ ขี้เกียจไปขุดหา

อ้อ ยินดีต้อนรับสมาชิกใหม่ด้วยนะครับคุณจุ้นจ้าน

ปล. ผมไำม่่ค่อยโผล่มาเท่าไหร่ ถ้าถามไรมาแล้วไม่ตอบสักทีก็อย่าว่ากันนะครับ

ปล2 พลัง K นี่คืออะไรครับ ย่อมาจากพลัง ค ว า ย ใช่ไหมครับ

ปล.3 ชุดเดรสนี่ผมรู้จักครับ แต่แบบซีฟู้ด เอ้ย ซีทรูนี่เป็นแบบไหนเหรอครับไม่เคยเห็น
