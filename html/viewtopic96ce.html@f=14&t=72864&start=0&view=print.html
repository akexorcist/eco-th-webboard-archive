ขอสเตตัสเบลดแบบว่า สามารถเวลคนเดียวสบายๆได้ไม่ต้องพึ่งใครมาก(เพระผมไม่มีใครไห้พึ่ง )
-ถ้าเป็นสายเอจิขอไห้แนะนำการอัพสเตตัสที่ทำไห้ตีแรงเร็วแม่น
-ถ้าเป็นสายวิทขอไห้บอกการอัพสเตตัสไห้ตีแรง(เพราะสายวิทตีเบามาก เบลดเก่าเล่นสายวิท ถึงอัพSTRเข้าไป80ก็ยังตีไม่แรง)
