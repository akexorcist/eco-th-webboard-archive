รายละเอียดต่างๆเกี่ยวกับธาตุ
เกมนี้มีทั้งหมด 6 ธาตุคือ 火ไฟ 風ลม 土ดิน 水น้ำ 光แสง และ 闇มืด


จากแผนผังจะเห็นได้ว่า น้ำชนะดิน ดินชนะลม ลมชนะไฟ ไฟชนะน้ำ
แสงชนะความมืด ความมืดชนะน้ำดินลมไฟ น้ำดินลมไฟชนะแสง

เกี่ยวกับสถานะของธาตุ
- มอนสเตอร์ทุกตัวรวมทั้งผู้เล่นทุกคนจะมีสถานะของธาตุอยู่ในตัว
- สถานะของธาตุไม่จำเป็นต้องมีธาตุเดียว อาจมีหลายธาตุรวมกันได้ โดยจะมี % ความแรงของแต่ละธาตุ สูงสุดก็คือ 100
- ตามแมพต่างๆจะมีพลังของธาตุอยู่ มอนสเตอร์ที่อยู่ในแมพนั้นหรือแม้แต่ตัวผู้เล่นเองก็จะได้รับพลังจากธาตุนั้น ทำให้มีความแรงของธาตุนั้นเพิ่มขึ้น
- ความแรงของธาตุรวมแต่ละธาตุ = ความแรงของธาตุนั้นในตัว + ความแรงของธาตุนั้นในพื้นที่นั้น + ผลของสกิลทั้งหลาย
- ความแรงของแต่ละธาตุจะไม่เกี่ยวข้องกัน แต่จะถูกนำมาใช้ร่วมกันตอนคำนวนความเสียหาย
- สถานะของธาตุที่ต่างกันจะทำให้เกิดผลต่างกันเมื่อได้รับการโจมตีที่เป็นธาตุ
- สถานะของธาตุในตัวจะไม่เกี่ยวข้องกับการโจมตี แต่จะมีผลเมื่อถูกโจมตีเท่านั้น(พูดง่ายๆก็คือสถานะของธาตุอยู่ที่เกราะไม่ได้อยู่ที่อาวุธ)

สูตรการคำนวนอัตราการขยายการโจมตีธาตุ
เมื่อโจมตีด้วย 4 ธาตุหลัก
อัตราขยายการโจมตีธาตุ = floor[(100+ผลรวมผลของทั้ง 4 ธาตุ) * (100+ผลของธาตุแสงหรือธาตุความมืด) / 100]

เมื่อโจมตีด้วยธาตุแสงหรือความมืด
อัตราขยายการโจมตีธาตุ = 100 + ผลของธาตุใน 4 ธาตุที่มีค่ามากที่สุด + ผลของธาตุแสงหรือธาตุความมืด

ผลรวมผลของทั้ง 4 ธาตุ = ผลของธาตุน้ำ + ผลของธาตุไฟ + ผลของธาตุลม + ผลของธาตุดิน
ผลของธาตุใน 4 ธาตุที่มีค่ามากที่สุด หมายถึงให้ดูผลของธาตุที่มีความแรงมากที่สุด
ในกรณีที่โจมตีใส่มอนสเตอร์ที่มีทั้งธาตุแสงและธาตุความมืด ในเว็บบอกว่ายังไม่เคยทดสอบเลยไม่รู้

ผลของธาตุ = floor[ ความแรงของธาตุ * สัมประสิทธิ์ธาตุ ]

ค่าสัมประสิทธิ์ธาตุ
ธาตุที่โจมตี→ธาตุที่โดนโจมตี
สี่ธาตุ→สี่ธาตุ(ชนะทาง) +2/3
สี่ธาตุ→สี่ธาตุ(แพ้ทาง) -1/2
สี่ธาตุ→สี่ธาตุ(ธาตุเดียวกัน) -1.0
สี่ธาตุ→แสง +1/3
สี่ธาตุ→ความมืด -1/3
แสง→สี่ธาตุ -1/2
แสง→แสง -1.0
แสง→ความมืด +2/3
ความมืด→สี่ธาตุ +1/2
ความมืด→แสง -1/2
ความมืด→ความมืด -1.0

*floor หมายถึงทำให้เป็นจำนวนเต็มโดยปัดเศษลง

ตัวอย่าง
- สมมุติว่าเราโจมตีด้วยธาตุน้ำใส่มอนสเตอร์ที่มีพลังธาตุ น้ำ 50
จะได้ว่า
ผลของธาตุน้ำ = floor[ความแรงของธาตุน้ำ*สัมประสิทธิธาตุ(น้ำ->น้ำ)]
ผลของธาตุน้ำ = floor[50*(-1)] = -50
ผลรวมผลของทั้ง 4 ธาตุ = ผลของธาตุน้ำ = -50
เนื่องจากมอนสเตอร์มีธาตุน้ำเพียงอย่างเดียว
ผลของธาตุแสงหรือความมืด = 0 เนื่องจากมอนสเตอร์ไม่มีธาตุแสงหรือธาตุความมืด
ดังนั้น
อัตราขยายการโจมตีธาตุ = floor[(100+ผลรวมผลของทั้ง 4 ธาตุ) * (100+ผลของธาตุแสงหรือธาตุความมืด) / 100]
อัตราขยายการโจมตีธาตุ = floor[(100+(-50)) * (100+0) ]=50%
สรุปว่าเราจะโจมตีใส่มอนสเตอร์ตัวนี้ได้แรง 0.5 เท่าของปกติ

- สมมุติว่าโจมตีด้วยธาตุน้ำใส่มอนสเตอร์ที่มีพลังธาตุ น้ำ 50 ดิน 100
ผลของธาตุดิน = floor[ความแรงของธาตุดิน*สัมประสิทธิธาตุ(น้ำ->ดิน)]
ผลของธาตุดิน = floor[100*(+2/3)] = +66
ผลของธาตุน้ำ = floor[ความแรงของธาตุน้ำ*สัมประสิทธิธาตุ(น้ำ->น้ำ)]
ผลของธาตุน้ำ = floor[50*(-1)] = -50
ผลรวมผลของทั้ง 4 ธาตุ = ผลของธาตุน้ำ + ผลของธาตุดิน = +66 -50 = +16
เนื่องจากมอนสเตอร์มี 2 ธาตุ
ผลของธาตุแสงหรือความมืด = 0 เนื่องจากมอนสเตอร์ไม่มีธาตุแสงหรือธาตุความมืด
ดังนั้น
อัตราขยายการโจมตีธาตุ = floor[(100+ผลรวมผลของทั้ง 4 ธาตุ) * (100+ผลของธาตุแสงหรือธาตุความมืด) / 100]
อัตราขยายการโจมตีธาตุ = floor[(100+16) * (100+0) / 100]=116%
สรุปว่าเราจะโจมตีมอนสเตอร์ตัวนี้ได้แรง 1.16 เท่าของปกติ

- สมมุติว่าโจมตีด้วยธาตุน้ำใส่มอนสเตอร์ที่มีพลังธาตุ แสง 100 ดิน 100
ผลของธาตุดิน = floor[ความแรงของธาตุดิน*สัมประสิทธิธาตุ(น้ำ->ดิน)]
ผลของธาตุดิน = floor[100*(+2/3)] = +66
ผลของธาตุแสง = floor[ความแรงของธาตุแสง*สัมประสิทธิธาตุ(น้ำ->แสง)]
ผลของธาตุแสง = floor[100*(+1/3)] = +33
ผลรวมผลของทั้ง 4 ธาตุ = ผลของธาตุดิน = +66
เนื่องจากมอนสเตอร์มี 2 ธาตุ
ผลของธาตุแสง = +33
ดังนั้น
อัตราขยายการโจมตีธาตุ = floor[(100+ผลรวมผลของทั้ง 4 ธาตุ) * (100+ผลของธาตุแสงหรือธาตุความมืด) / 100]
อัตราขยายการโจมตีธาตุ = floor[(100+66) * (100+33) / 100]=221%
สรุปว่าเราจะโจมตีมอนสเตอร์ตัวนี้ได้แรง 2.21 เท่าของปกติ
