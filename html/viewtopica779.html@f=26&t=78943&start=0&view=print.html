ด้านหน้าโล่งๆ ขนาบข้างด้วยโรงรถ เราทำโรงรถได้หรือเปล่าครับ


ด้านหลัง ต้นไม้ใหญ่ น้ำพุ รั้วเหล็ก มีไหมครับ


ด้านข้าง กระถางต้นไม้ ไม่มีปัญหา แต่เถาวัลย์เกาะบ้านนี่มีไหมครับ


ภายในมองจากด้านหน้า เราทำเกาะลอยน้ำแบบนี้ได้ไหมครับ มีรายละเอียดเล็กๆ ด้วยอย่างรางดอกไม้ยาว โต๊ะกลางห้อง จาน แก้วน้ำ เก้าอี้ พรมปูพื้นสุดแนว


ด้านข้างมีรางดอกไม้ชั้นที่สอง เปลญวน ผนังหน้าต่างเหล็กดัด มีน้ำตกข้างๆ เปลด้วย
