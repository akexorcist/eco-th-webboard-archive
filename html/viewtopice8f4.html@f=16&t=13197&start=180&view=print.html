- ถ้าเล่นใช้อาวุธพวก กระบอง ก็อัพ Mace Mastery ครับ ใช้ขวานก็อัพ Axe Mastery แต่แนะนำเล่นขวานดีกว่าครับ เพราะมันใช้ประโยชน์ต่อไปได้ถึง Job2 และยังมีสกิลเพิ่มความแม่นของขวานอีก ถือว่าครบเรื่องบู๊เลยทีเดียว

- สกิลสู้ แนะนำให้อัพอย่างใดอย่างนึงครับ Blow หรือ Banish blow (ท่าหลังแรงกว่าไม่มากครับ)

- หลักๆที่ควรอัพจะมี ทำอาหาร Refine (ซึ่งควรเต็ม!) นอกนั้นแล้วแต่ชอบครับ ว่า จะไปทางด้านผ้า (เย็บผ้า ซ่อมแซมผ้า) หรือด้านไม้ (สร้าง ซ่อมไม้) แต่ทั้งนี้อยู่ที่ Skill point ด้วยฮะ ถ้าเหลือก็วางแผนอัพดีๆ (แนะนำให้ไปรับ พ๊อยฟรี 21พ๊อย เพราะชาวนาท่าเยอะสุดๆครับ จำเป็นต้องเลือก!)

- ให้อัพตามที่เราคิดว่าได้ใช้มากที่สุดครับ หรือจะหากำไรทางด้านไหนมากกว่ากันครับ
