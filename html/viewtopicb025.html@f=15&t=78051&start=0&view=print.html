เปลี่ยนธาตุมอนให้โดนการโจมตีชนะธาตุดีกว่าอยู่แล้วครับ

แล้วการเปลี่ยนพื้นธาตุเนี่ย ถ้ามอนที่อยู่ในพื้นธาตุไม่ได้มีธาตุตามพื้นนั้น มันจะไม่ไปเพิ่มค่าธาตุให้มอนเลย

ดังนั้นควรใส่พื้นธาตุให้ตรงตามธาตุของมอน จึงจะทำให้โดนการโจมตีชนะธาตุแรงขึ้นได้

แนะนำว่าให้ทำทั้งสองอย่าง คือเปลี่ยนธาตุมอนให้แพ้ทาง แล้ววางพื้นธาตุใต้เท้ามอนตามธาตุที่เราเปลี่ยน



เช่น ยัดธาตุน้ำใส่มอน แล้วลงเวทย์ลาวา จะทำให้แรงขึ้นมากระดับหนึ่ง (ในกรณีที่มอนไม่ใช่ธาตุน้ำแต่แรก)

ยัดธาตุน้ำใส่มอน วางพื้นธาตุน้ำต่อ แล้วลงเวทย์ลาวา จะทำให้แรงขึ้นกว่าเดิมจากข้างบนพอสมควร

ถ้ามอนไม่ใช่ธาตุน้ำ วางพื้นน้ำใส่ แล้วลงลาวา ความเสียหายเบากว่าทั้งสองกรณีด้านบน
