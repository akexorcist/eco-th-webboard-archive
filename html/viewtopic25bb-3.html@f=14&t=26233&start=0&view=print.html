ส่วนมากแล้ว Swordman จะเป็นสาย STR AGI วะส่วนใหญ่เลยครับ
STR ให้เยอะไว้ก่อนก็ได้ครับเพราะเดี๋ยวเราได้สกิล Delay Cancel มาแล้วจะช่วยให้ตีเร็วขึ้นเยอะเลยครับ

ให้ STR นำ AGI ไว้สัก 20-30 ก็ได้นะครับเมื่อตอนเลเวล เยอะๆแล้วนะ

ส่วนมากแล้ว Swordman จะสิงสถิตอยู่แถวๆเมืองเหนือแทบจะตลอดเลยล่ะครับไล่แผนที่ไปจนสุดดันเจี้ยนเมืองเหนือได้เลยครับ
