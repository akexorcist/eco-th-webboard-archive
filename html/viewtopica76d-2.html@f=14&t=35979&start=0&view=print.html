สกิล Land Mine นะครับ

พอดีผมหาซื่อระเบิดไม่ได้ บางคนบอกว่าไม่ต้องใช่ land mine แต่ใช่ กับระเบิดเขียว(แล้วกับระเบิดเดียวคืออะไรหรอครับ )

บางคนบอกว่า ยังไม่มีขายในแพชนี่ เพราะ Npc อยู่ Tonka = ="

บางคนบอกว่า หาได้จากมอนสเตอร์อย่างเดียว

แล้วก็ สกิล Claymore Trap ใช่ระเบิดชนิดเดียวกันหรือปล่าวครับ

รบกวนผู้รู้บอกที่ครับว่าหาระเบิดที่ใช่กับสกิลนี่ได้ที่ไหน (ขอรูปด้วยจะเป็นพระคูณมากงับ ><)

แล้ว ระหว่าง Lind mine กับ Claymore Trap อันไหนดีว่ากันหรอครับ
