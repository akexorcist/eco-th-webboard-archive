Welcome to "BustTong's Showroom"

เอาไว้โพสรูปที่ผมทำขึ้นมาให้มาดูกันครับ ส่วนใหญ่จะเป็นการวาดรูป หรืองาน art work ต่างๆ จากคอมพิวเตอร์นะครับ เพราะว่าช่วงนี้ที่คณะมีงานพวกนี้เยอะ อาจจะโพสเอาไว้ให้ติชม เพื่อที่จะได้แก้ไขครับ หรืออยากจะแลกเปลี่ยนเทคนิค กับเราก้อโพสเอาไว้ได้นะครับ อิอิ จะได้มีมุมมองกว้างมากขึ้น ^^

ก่อนอื่น ไปเยี่ยมชมงานของเราที่ทำมา (จะ upload เรื่อยๆ ครับ) ได้ที่
ที่แรกเลยครับ Deviant art
หรือ Multiply ของผมเองครับ
หรือจะเยี่ยมชม hi5ของผมก็ได้ครับ

ประเดิมรูปแรกละกัน (เพิ่งเสร็จเมื่อวานครับ)
ึ7 มกราคม 2551
ให้ชื่อว่า "Reach for the Star"

คำอธิบาย: อันนี้ทำเป็นหน้าปกสำหรับสมุดของคณะครับ ต้องแข่งกับคนอื่นๆ อีกเยอะแยะเลย เค้าจะ vote เอาไปทำเป็นปกสมุดกันวันนี้ ไม่รู้จะได้หรือเปล่า แต่ว่าถ้าไม่ได้ยังไง ก้อถือว่าเราฝึกวาดละกัน ^^
วาดโดย: ร่างรูปคน, ระบายสี (สีไม้) ในกระดาษก่อนครับ แล้วค่อย scan เข้า ตัดขอบ แล้ววาด background (รูปเมฆ) โดยใช้ penmouse ครับ ท้ายสุดก้อใส่ font และใส่ effect (Fx) นิดหน่อย ^^
Link สำหรับดูรูปละเอียดขึ้นที่นี่ครับ : ขนาด 350kb ครับ

รูปต่อมาครับ
22 มกราคม 2551
ให้ชื่อว่า "Medi C A [T]"

คำอธิบาย: อันนี้เป็นงานออกแบบ "ตุ้งติ้ง" สำหรับเอาไว้ติดเสื้อของนศ.หญิงของคณะ น่ะครับ ตามเคยครับ ต้องเอาไป vote ร่วมกับงานของคนอื่นๆ อีกอ่ะ พรุ่งนี้ตัดสินแล้ว คราวแล้วก้อซิ่วไปทีหนึ่งละ คราวนี้ขอละกัน อิอิ
วาดโดย: ร่างรูปโดยดินสอก่อน แล้วแสกนเข้าคอม, ใช้ path ในการวาดเส้นเป็นหลัก และ stoke โดยใช้ brush สุดท้าย ก้อลงสีครับ โดยงานนี้จะเน้นง่ายๆ เพราะว่าถ้าเกิดได้คัดเลือกไป ก้อจะต้องเอาไปทำเป็นตุ้งติ้งของจริงครับ เลยต้องทำให้เรียบง่ายไว้ก่อน ^^
Link สำหรับดูรูปละเอียดขึ้นที่นี่ครับ : ขนาด 150kb ครับ

รูปต่อมาครับ
27 มกราคม 2551
ให้ชื่อว่า "Silent Night"

คำอธิบาย: ทำเล่นๆ ครับ
วาดโดย: (ทำออกมาแล้วเหมือนผ้าบาติก) ตอนแรกก้อร่างแบบโดยดินสอนะครับ แล้วตัดเส้นด้วยปากกาตัดเส้นสีดำ (แต่ในรูปเป็นสีขาว เดี๋ยวจะบอกให้ครับ ^^) แ้ล้ว scan เข้าคอมเพื่อลงสีครับ โดยผมใช้ความสามารถในการ clipping mask ของ layer เพื่อให้เส้นซึ่งปกติเป็นสีดำ เปลี่ยนสีเป็นสีเขียวอ่อนและสีเหลือง เพื่อให้ภาพดูเหมือนภาพบาติก สำหรับการลงสี ก็ใช้ selection เป็นส่วนๆ แล้วใช้ penmouse ปรับ ให้มี dynamic ตามน้ำหนัก เพื่อที่จะไล่สีได้ครับ จากนั้น ก็ลงสี(ขั้นตอนนี้ตัวใครตัวมันแล้วล่ะครับ ^^)
Link สำหรับดูรูปละเอียดขึ้นที่นี่ครับ : ขนาด 500kb ครับ
