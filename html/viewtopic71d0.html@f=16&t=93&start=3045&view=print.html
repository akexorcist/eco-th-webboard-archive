จะขอบคุณมากๆเลยนะคะ ถ้ามีแล้ว รบกวนขอลิ้งค์ด้วยค่ะ เรามีปัญหาว่า หน้าเยอะเกินไป หาไม่เจอ - -lllll



ปล.ต้องขอบคุณไกด์นี้มากๆเลยนะคะที่ทำให้เราตัดสินใจได้ว่าจะเล่นอาชีพอะไรดี หลังจากนั่งดูไกด์ของแต่ละอาชีพมา และก็ขอชมว่า ไกด์นี้ละเอียดมากๆค่ะ ดีมากเลย
