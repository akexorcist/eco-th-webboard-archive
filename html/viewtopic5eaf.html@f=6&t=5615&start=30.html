แนะนำครับ

สกิลทำไม้ กับ สกิลจัดสวน เป็นสกิลควบคู่กัน

อนาคตใครคิดจะส่งออกเฟอนิเจอร์รายใหญ่

ก็ต้องอัพทั้ง2สกิล

(แต่ดูแล้ว ผมสร้างอีกตัวมาไว้ทำของพวกนี้ดีกว่า โอเพนน่ะ - - )

//

สกิลเกี่ยวกับขวานของชาวนา ทั้ง2 สกิล คิดรวมกันในเรื่องความแม่นยำ

ถ้าตอนเป็นอัลคิมิส คุณอัพสกิลแม่นยำขวาน2มืออีก ทั้ง3สกิลจะส่งผลร่วมกัน

คือจะทำให้การตีของคุณเสถียรและไม่แกว่งอย่างมาก เป็นไปได้ที่ค่า min atk และ max atk จะเป็นเลขตัวเดียวกันสูง

//

สกิลปาอาหาร ข้อดี ช่วยคนในตี้ได้ (กะ pet ยังไม่ได้ลองแฮะ)

แต่ข้อเสียคือ ขณะที่โดนมอน มานัวๆที่คุณ แทนที่คุณจะกินอะไรซักอย่างแล้วเลือดเพิ่ม

แต่คุณก็ต้องกด แล้วคลิกที่ตัวเอง ซึ่งทำให้ผมตายมาหลายรอบแล้ว -*-

//

หากคุณปรับออพชั่น ในส่วน ผสมสายสกิลของตนเองเป็น OFF

นอกจากปาอาหารได้แล้ว (ต้องอัพสกิลด้วยนะ)

คุณยังสามารถใช้สกิลทำของทุกชนิด กับผู้เล่นอื่นได้อีกด้วย

(ยกเว้นสกิล ส่องไอเทม)

//

แบนนิชโบล แรงกว่า โบล 10 เปอเซ็น แล้วทำให้ศัตรูกระเด็นได้

ฮีลลิ่งทรี ฮีลแรงกว่าก่อกองไฟเกือบเท่าตัวและไม่ใช้ไอเทมใดๆ

แต่ทั้ง2สกิล ต้องแลกกับความอดทน หากคุณจะอัพ เพราะ

น่าจะเลือกอย่างใดอย่างหนึ่ง เพื่อให้คุ้มกะ พ้อยท์สกิลอันน้อยนิด

//

เพิ่มเติม อยากเก็บเวลให้สะดวก

ควรมี มาริโอเน็ต ที่ regen hp

ตัวใดตัวหนึ่ง ซาลาแมนเดอ or หุ่นกระป๋อง

ช่วยเก็บเวลได้อย่างดีครับ

หรือถ้าคุณเป็นสายเน้นสกิลอย่างเดียว (แบนนิชโบล)

ควรพกมาริโอเน็ต เด้ง sp ติดตัวด้วย เก็บไวไม่แพ้นักเวทย์เลยแหละ

//

ชาวนาสาย vit - อึด ถึก แต่ของพังง่าย หากใช้ขวาน2มือ คุณจะเป็นมนุษย์ที่ตีช้าที่สุดในโลก ยกเว้นจะปั๊ม sp กระแทกมอนลูกเดียว หากคุณรวยยาพอ เพราะaspd กับ เวลาร่ายสกิล แทบจะไม่ต่างกันเลย

ชาวนาสาย agi - ของพังยาก ใช้ขวาน2มือฟาดไวไม่อายสายมีด พริ้ว (ต้องเวลสูงแล้วหน่อยนะ) ข้อเสีย ถ้าเจอมอนที่แม่นๆ+ตบแรง คุณอาจจะลงไปนอนภายใน 3-4 วิ ทั้งที่มันก็ชื่อสีฟ้าแล้ว -*- (ตัวอย่างมอน - หมีดำ ในเหมืองตะวันตก)

//

ตำราทำอาหาร และตำราทำไอเทม

ที่เล่มละ10k ไม่ควรซื้อ

เพราะมีคนเอามาลงในบอร์ดแล้ว

ของที่ทำได้มันก็มีแค่นั้นแหละ ยกเว้นคุณจะงัดสันหนังสือดู

เผื่อมีสูตรพิเศษอีก

//

ส่วนตำรา ยา ตำราจัดสวน ตำราเย็บผ้า ตำราทำไม้

คงต้องรอท่านผู้ประเสริฐมาสงเคราะห์ชาวเราต่อไป

//

ส่วนผสมที่เสีย นอกจากจะแลกขนมปัง หรือ เซริโกะที่ร้านขยะดาวทาวได้แล้ว

ยังสามารถไปแลกของแบบอื่นได้ที่ร้านขยะเมืองใต้ได้ด้วย (ที่จำได้ก็เซริโกะสีแดง ใช้ 100 อัน)

//

สกิล hp / sp recovery จะไม่ช่วยอะไรคุณเลย

หากคุณ ไม่ได้ นั่ง กิน อยู่ในเต๊นท์ เชลเตอร์ บ้านnpc หรืออยู่ในเมือง

//
