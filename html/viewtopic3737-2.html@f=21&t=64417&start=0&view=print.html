มันขึ้นมาว่า โค้ทนี้ถูกใช้แล้วทั้งๆ ที่ยังไม่เติม
โทไปทางทีมงานบอกว่า ให้ส่งเมลล์พร้อมหลักฐานมา
พมก้อส่งไป แต่ ไม่มีความคืบหน้า ไม่มีการดำเนินการให้ใดๆทั้งสิ้น
แล้วโทไปก้อไมมีคนรับสาย พอรับอีกทีเมื่อวันเสาร์ที่ผ่านมา
บอกให้พมส่งเมลล์ไปให้อีก -*- พมเรยบอกว่าส่งไปแล้ว
เค้าเรยไปเช็ค แล้วบอกว่าวันนี้จา ส่งโค้ทใหม่มาให้ทางเมลล์
แต่แล้วก้อไม่ส่งมา โทไปก้อไม่รับ
