- Dark Elephant Call = เรียกSummon Dark Elephantออกมา *ทางที่ดีควรแท๊งลูกน้องไว้1ตัวเหมือนตีบอสหมานะ

• คำถามวันนี้ (ตอบได้เมลมาหาDeadTeam2มีรางวัล)
1.มีคนละเขาอยู่สุพรรณตัวสั้นๆไม่รู้ว่าใคร
จากข้อ1ให้ตอบเป็นชื่อและนามสกุลนักการเมืองคนนั้นมา
2.ลักษณะเด่นของนักการเมืองคนนั้นคือข้อได (เลือกคำตอบที่ถูกที่สุด)
2.1ทำลิ้นแผลบๆ 2.2กระโดดไปๆมาๆกลางรัฐสภา 2.3เต้นบีบอยโชว์นายก
2.4หัวล้าน(ถ้าแน่ใจก็ตอบแต่ไม่แนะนำเพราะเราไม่รู้- -)

2ข้อตอบถูกได้รางวัล*-*
