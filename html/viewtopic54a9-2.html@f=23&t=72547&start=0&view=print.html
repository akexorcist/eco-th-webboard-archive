คุณสมบัติน่ะ หลอมได้(ถ้าเป็นกระเป๋าเผ่าอีมิล)
- เลเวล Big Ruck 20 มากกว่ากระเป๋าพยาบาล ข้อนี้ผ่าน
- อาชีพ กระเป๋าพยาบาลใส่ได้ทุกอาชีพ เพราะฉะนั้นสายBPก็ใส่ได้ ข้อนี้ก็ผ่าน
- เพศ ไม่จำกัดเพศ ผ่านฉลุย
- ประเภท กระเป๋าเหมือนกัน ก็หลอมได้
(หลอมBig Ruckกะหางแมวมาละ แต่ไปๆมาๆตัวนั้นดันเลิกเล่น - -*)

อัตราความสำเร็จอยู่ที่80% ใช้เงินทีละ20k (เวลของแสดงความสามารถ x1000)
แม้จะหลอมพลาด ของทั้ง2ชิ้นก็ไม่หาย (แต่กะตังน่ะหาย) หลอมใหม่ได้
