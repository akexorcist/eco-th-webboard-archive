ต้องไปคุยกับป้าย้อมสีอ่ะครับ


Shinion cover นี่ ใช้เปาๆรึเปล่าน่ะ ถ้าใช่ ก็ป้าย้อมสีในดาวทาวครับ ( ย้อมทีนึง 10k สุ่มสีให้ )


Shinion cap เอาไปย้อมที่ คุณป้าย้อมสี ที่เกาะไมไมครับ เข้าไปในป่าอ่ะ ( ตรงที่จะไปหาดกลางคืนอ่ะ )


Cowhide high-heeled สีฟ้าอ่อน ใช้ทำเอาครับ ส่วนสีอื่นๆอย่าง ชมพู ขาว ดำ แว๊บๆว่าบางสีมี NPC ขาย แต่จำไม่ได้ว่าที่ไหน =w=


ส่วนกระโปรงมินิสเกิร์ต ถ้าจำไม่ผิดจะเป็น ป้าย้อมผ้าที่ เมืองฟาอีส ครับ
