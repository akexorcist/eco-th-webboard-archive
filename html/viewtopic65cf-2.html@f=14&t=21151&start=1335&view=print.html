ไม่อัพก็ได้ โอนเอา สเตตัสที่จะอัพอิ้นเอาไปลงจิ หลบปืนได้ หลบดาบได้บ้าง

เพราะยิงยังไงก็ไม่ตาย ดาบฟัน ปืนยิง ก็ไม่ค่อยจะโดน โดนก็เบา เสี่ยงโดนคาบาที่สิงอยู่ปลดซะด้วย

แล้วก็จะถึกยังไงก็ยังโดนปลดได้อยู่ดี :lol:

Edit: โอนอิ้นอยู่ได้ 30 วินะ ถ้าวิสาดตายไป int หมด จะหลบไม่ได้ทั้งปืน แล้วก็เวทจะเข้าเต็มๆเลย

ถ้าไม่ได้อัพอิ้นมาก่อน :lol:

เท่าที่ไปคำนวณในเวปมานะคับ ไนท์เวล 90 จ๊อบ 50 สาย vit/int เพียวๆ เยย อัด int 96+6 กะ vit 92+25 สามารถทำ def ตัวซ้ายได้ 65 และ m.def ตัวซ้ายได้ 63

อัพได้แค่นี้เพราะพอยท์ไม่พอ งิงิ

กด def. bust ไปก็ + def กะ m.def ซ้าย ไปประมาณ 10 ได้ devide barria ของซอเซอเรอร์ มาบัพ def/m.def ขวาก็จะเพิ่มขึ้นมาอีกประมาณ 30 hock:

60 + 10 + 30 = 100 (ไม่คิดเศษที่เกินมานะ)

แค่นี้ก็โดนตีทีละ 1 กะโดนเวทย์ทีละ 0 แล้ว (รอผู้มีจิตศรัทธารีสเตตัสมาทดสอบเน้อ -0-)

ปล. ดาร์คผมตายเพราะโดนรุมง่ะ T^T
