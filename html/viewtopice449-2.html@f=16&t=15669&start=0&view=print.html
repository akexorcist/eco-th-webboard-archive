:oops: การทำเควสที่มีเลเวลต่ำกว่าเรา (หรือเควสที่เป็นสีเทา) นั้น :oops:
ไม่มีการลดค่าชื่อเสียงแต่อย่างใดค่ะ ยังสามารถได้รับค่าชื่อเสียงเหมือนกับเวลาทำเควส
ที่มีสีเหลืองหรือสีขาวค่ะ

ความหมายของสีเควสมีดังนี้ค่ะ
:arrow: สีเหลือง หมายถึง เควสนี้เหมาะสมกับระดับเลเวลของเรา
:arrow: สีขาว หมายถึง เควสนี้สามารถทำได้ค่ะ
:arrow: สีเทา หมายถึง เควสนี้มีระดับต่ำกว่าเลเวลของเรามากเกินไป
จะเลือกทำหรือไม่ทำก็ได้ ถ้าเลือกทำก็ยังได้รับค่าชื่อเสียงเหมือนเดิมค่ะ
เพียงแต่ว่าเควสสีเทานี้ ค่าประสบการณ์ กับเงินตอบแทนที่ได้รับ
จะน้อยไปสำหรับเลเวลปัจจุบันของเราค่ะ :oops:
