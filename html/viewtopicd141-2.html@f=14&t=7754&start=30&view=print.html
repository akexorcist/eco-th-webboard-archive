**เกี่ยวกับระเบิด

- ความแรงขึ้นอยู่กับค่า Atk
ดังนั้นอัพค่า STR ก็มีผลโดยตรงกับระเบิดเลย
ถ้าอัพ DEX หรือ INT มันมีผลข้างเคียงครับ แต่ก็ถือว่ามีผลเช่นกัน
ดังนั้นถ้าจะเล่นสายปืน หรือมีด ต่างก็อัพตรงสายได้เลยครับ คือ
ปืน ก็อัพ INT เพื่อเพิ่มความแม่นและกับอัพ STR เพื่อเพิ่มความแรงเข้าไปด้วย
มีด ก็อัพ DEX เพื่อเพิ่มความแม่นยำเช่นกันต่างกันที่ระยะ และก็อัพ STR เพื่อเพิ่มความแรงเช่นกัน

ตามนี้นะครับ แล้วก็สลับความสำคัญระหว่าง DEX กับ INT ให้เหมาะกับอาวุธที่ใช้
