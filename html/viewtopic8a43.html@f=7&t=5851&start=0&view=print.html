บอสราชาไพ่ - อันนี้ลูกน้องโหดอ่ะแต่เท่ ตัวบอสมันอ่ะดูขี้เก๊ก ยังไงไม่รู้




บอสนางไม้ - บอสที่สวยที่สุด >< น่ารักอ่ะ แต่โคตระโหด สุด เวทไฟเวทดิน แต่ ลูกน้องมันอ่ะ เป็นคล้ายน้องแครอทอ่ะ แต่โหดจัง ฮิลได้ ตีแรง เดินเร็ว




บอสปลา - บอสที่หน้าเห้ยมากๆ - - แต่โหดน้อยกว่าตัวอื่นซะที่ไหน เห็นว่าบอสตัวนี้ดรอป มารีโอเน็ทปลาแบบ ที่ 2 ด้วย ไม่รู้จริงเปล่าเพราะตีมันไม่เข้า - -"




บอสนก - บอสตัวใหญ่ และ เก่งที่สุดในเกม(หรือเปล่า) เก่งที่สุดในเกมหรือเปล่าไม่รู้ แต่ใหญ่เนี่ย กินขาดทุกตัว แอบเซ็ง เข้าใกล้ โดนมันเหยียบ กลับเซฟเลย




บอสหมาป่า -GM ปล่อยมาเยอะๆ ลำบากในการไปถ่ายรูป บอสตตัวอื่นมากมาย ตัวนี้ เวทกว้างมากเกือบหมดจออ่ะ สุดๆไปเลย - -




มันบอสอ่ะเปล่าอ่ะ - -" ดูธรรมดามาก ลูกน้องก็ไม่มี หรือว่าตายไปแล้วหว่า --
แต่มันเหมือน ซินนามอน ร่างขยาย + เพิ่มเลือด



บอสหมีไทนี่ เป็นบอส หักมุข ตัวอื่นเขาใหญ่กันหมด มันมาแนวตัวเล็ก เพราะอะไรนะหรอ จะได้ติดสปีดฆ่าคนที่เขาใกล้ไง ขอบอก วิ่งไวกว่า หนอนตัวดำๆที่ดรอปแร่อีก



บอส หมี(ใหญ่)สุดสยอง ที่สยองนะไม่ใช่มันนะ แต่ลูกน้องมันวิ่งไวมากๆๆ ตุ๊บตั๊บ ไปเลยเรา



แถมๆ บอส .......... เออ อะไรไม่รู้ มันเหมือนไก่ + นก หรืออะไรก็ไม่รู้
ปล. ไอ้ตัว ขาวๆลายดำนะ อ่ะ ตรงกลาง ตัวซินนามอน



เหอๆ อยากอยู่อยากนี้ไปนานๆ อยู่ใกล้ Icy นานๆได้หรือเปล่า
