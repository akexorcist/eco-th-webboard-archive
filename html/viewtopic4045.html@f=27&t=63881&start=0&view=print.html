เราเล่นเอเลไม่เก่งเลย ไม่มีสิงโซลไม่มีอะไรหรอกนะ มีแต่พี่ๆลงดันด้วยกันเป็นตี้มีพระด้วยละ

แต่เวลาเราลากมอนเนี่ย ตอนนี้เวล 88/41 มันก็จะลงพายุหิมะ ใช่มะแล้วเราไปโดนหุ่นเขียว

พอโดนหุ่นเขียวมันก้ยิงเรา เราก็ตาย ตายบ่อยมาก พี่ๆ เขาก็ บอกเราไม่มีเทคนิค

ใครมีเทคนิคดีๆ ช่วยบอกหน่อยสิว่า เอเลเนี่ยเล่นยังไงไม่ให้พายุหิมะโดนมอนตัวอื่น

ไม่เข้าใจ เขาก็ว่าเราอ้างนู่นอ้างนี่ เราก็ไม่ได้ว่าอะไร โดนว่าบ่อยจนนั่งเงียบละ

เริ่มเหมือนรู้สึกไม่อยากเล่นเอเลเลยพอโดนว่าเงี้ย ไม่เข้าใจอะ สกิลหยุดมอนก็ไม่มีไง

เห็นเท่าที่เห็น แต่พี่เราไม่เคยเล่นเอเลนะ (พี่เล่นพระแล้วไม่เคยตาย)

ใครมีีวิธีลาก มอนแจ่มๆ มาบอกกันมั่งคะบอกหน่อยสิ

นึกถึงสมัยยังไม่มีไอซี่กะคลื่นเลยอ่ะ เราว่ามันอยู่ที่คนเล่นพระด้วยนะถ้าทีมเวิร์กดีโอกาสที่เอเลจะดับก็ลดลงหน่อยนึงอิอิ ตอนที่เรายังไม่มีไอซี่เราก็เลือกห้องนิดนึง ควรจะเป็นห้องที่ไม่มี3ทหารเสือ55+ (บิ+หุ่นเขียวและสกาย) พอมีไอซี่ก็หลือแค่บิกะหุ่นเขียวที่เลี่ยงได้ก็เลี่ยงเถอะ เวลาลากมอนมาลงก่อนจะลงเวทหมู่ก็เล็งพื้นที่ว่างๆไว้ ถ้าลากโจรขาวก็ระวังเกร็งนะงับ เวลาลงเวทไปแล้วก็อย่าอยู่นิ่งๆเพราะมันจะเป็นกระสอบทรายให้มอนถลุงเอาได้ ส่วนเรื่องไอซี่กะลาวาลากยากง่ายต่างกันมั้ยไม่รุนะ เราชอบแบบถ้ามอนไม่ดับเราก็ม้วยอ้ะเลยเลือกไอซี่ แต่เราว่าถ้าเดกเยอะพอก็ร่ายไม่นานมีเวลาหนีมาร่ายทันสบายๆนะ เอเลเราเล่นแมก-เดก-อิ้นท์ (เพิ่งบ้าไปลงอิ้นท์มาไม่รุลงไปทำไม-*-) วิทมีแค่15มั้งตัวหน้าอ่ะ ก็มีนอนมั่งนะเวลาลากลงไอซี่แต่ไม่บ่อย เราคิดว่าคงมีส่วนที่พระด้วยแหละ

ปล.1 ทั้งหมดจากประสบการณ์ที่ลากเองลงเองนอนเองนะงับ
ปล.2 ไม่คิดว่าจะมีคนลากลงไอซี่+ลาวาในดัน70 เห็นส่วนใหญ่ไปดูดคลื่นกันหมด ไม่งั้นก็ฆาตกรรมหมู่แพลต
ปล.3 หาโซลเลือดใส่ก็ไม่เสียหายนะงับเพิ่มโอกาสรอดอีกหน่อย
