เราตัดสินใจกันแล้วว่ารูปริงของเราคือ


    KoiOboeru

    หัวหน้าริง : Zilenia
    รองหัวหน้า : Comelyfay
    Sever : TAKOYAKI
ไปเยี่ยมกระทู้หลัก ฐานที่มั่นของพวกเรา คลิกทีี่นี้
------------------------------------------------------------------------------------------------------------
ใครมีอะไรจะโพสก็มาได้เลยที่นี้ขอให้ทำตามกฏดังนี้ด้วยนะ

1.ไม่โพสไร้สาระอันก่อเกิดความแตกแยก
2.ไม่ใช้่คำพูดดูหมิ่นพระมหากษัตริย์และผู้อื่น
3.ใช้วาจาสุภาพ
4.ไม่พูดจาโอ้อวดหรือว่ากล่าวรูปที่นำมาโพส
5.ทำตามกฏของกระทู้ Onenet
------------------------------------------------------------------------------------------------------------
ประกาศ : เปิดรับสมาชิกเพิ่ม !!
- พูดจาสุภาพ
- เคารพผู้อาวุโส (ผู้เ้ขามาก่อนหน้าน/รุ่นเก่า/ผู้สูู้งอายุ)
- กล้าแสดงความคิดเห็น (เมื่อมีข้อที่น่าจะแก้ไข หรือประทำ)
- เข้ากับสังคมได้ดี (ในที่นี้หมายถึงไม่เงียบไม่พูดคุยกับคนในริง)

สถานที่ติดต่อ ดักเจอได้ที่หอแสงส่วนลูกไฟได้เลยเพราะที่นั้นไปเวลประจำ งุงิ หรือติดต่อโดยตรงต่อไปนี้


หรือสอบถามบุคคลที่เกี่ยวข้องในริง
----------------------------------------------------------------------------------------------------------
กฏสมาชิกที่ต้องปฏิบัติ
    1.ไม่กระทำการอันเป็นที่ก่อกวนผู้เล่นอื่น
    2.พูดจาสุภาพ ไม่ใช้คำสมัยยพ่อขุนรามจนชินปาก(ใช้ได้แต่อย่าให้มากเกินไป)
    3.ไม่ร้องขอ ดูด โดยการเอาแต่ใจ (ให้ถามเวลาว่างและเห็นที่สมควร)
    4.รักและภูมิใจในตราประจำริง
    5.เชื่อฟังและทำตามคำสั่งได้ดีเยี่ยม
    6.ไม่ต้องคิดว่าตัวเองกระจอก เข้าในสังกัติเรา ทุกคนคือพี่น้อง
    7.ต้องการเสนอ กิจรรม ติดต่อ หัวหน้า , รอง
    8.หากมีเรื่อง กดเซฟ ภาพเหตุการทุกครั้งเพื่อเป็นหลักฐาน คุณถูกเราช่วยเต็มที่
    9.บทลงโทษครั้งแรกคือการตักเตือนให้ปรับปรุงตัว ครั้งต่อไปคือไล่ออก
    10.การกระำทำใดๆที่ผิดต่อผู้อื่นหัวหน้าริงและรองจะดำเนิดการตัดสิดเอง


----------------------------------------------------------------------------------------------------------
ประวัติริงโดยย่อย
    สื่บเนื่องจากริงเดิมที่เคยตั้งได้ประสบปัญหาการก็อปรูปเกิดขึ้นและมีเหตุจราจร ทำให้ผู้เหลือรอดลดน้อยเป็นจำนวนมาก
    และหัวริงเก่าเกิดความท้อในชีวิต+ติดสาวใหม่ จริงทำให้ตัดสินใจลาออกจากริงไป...
    ปัจจุบันจริงได้มีการตกลงที่จะยุบริงแล้วประกาศเป็นริงใหมเพื่อจุดประสง 3 อย่าง คือ
    1.เพื่อรวบรวมหมู่เพื่อนใหม่อีกครั้ง
    2.สร้างสังคมใหม เริ่มนับจาก 0 อีกครั้ง
    3.เพื่อได้อยู่ร่วมกับคนที่รัก(ประสงค์สำคัญตอนแรก)
    แต่ก็ประสบความสำเร็จได้ดีแต่ไม่มากเท่าไร..

----------------------------------------------------------------------------------------------------------------

สมาชิกทุกคนขอให้จำไว้ว่ากระทู้นี้จะเป็นกระทู้ กิจรรม ของพวกเรา
