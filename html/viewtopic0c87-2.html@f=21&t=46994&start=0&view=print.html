ชี้แจงเรื่องนิยายและแกลเลอร์รี่ที่ปิดถาวร

โพสต์แล้ว: จันทร์ 28 เม.ย. 2008 1:29 pm
โดย ECO
ชี้แจงเรื่องนิยายและแกลเลอร์รี่ที่ปิดถาวร : พอดีไม่ได้เข้ามานานมากแล้ว นิยายก็ตกหล่นไป ไม่อยากขุดขึ้นมาอีกรอบ วันนี้จึงมาขอชี้แจงเรื่องนิยายที่ตกไปซักหน่อย

สมาชิกของเว็บวันเน็ตบางกลุ่ม หรือเว็บอื่นๆที่เข้ามาดู บางคนนั้นมีสินิสัยชอบลอกเลียนและนำไปใช้ แอบอ้างและทำการสารพัดที่บอกว่าเป็นของตัวเอง โดยไม่ได้ให้เครดิตคนแต่งที่แท้จริงเลย

แพร์ก็เห็นว่ามันหล่นไปหลายหน้าก็จึงเพิ่งเข้าไปแก้ไขโดยพยายามลบเนื้อหานิยายต่างๆ
เท่าที่จะลบได้ให้หมดเพื่อป้องกันคนจะเอาโครงสร้างนิยายไปใช้โดยไม่ได้บอกกล่าวใดๆ

ปัจจุบันนิยายเรื่อง Princess In The Tales ถูกแต่งเป็นสามภาคด้วยกัน โดยแพร์ได้บรรจุ
เนื้อเรื่องทั้งหมดรวมถึงภาพต่างๆของนิยายไว้ในเว็บ www.ginnysypia.th.gs/ ทั้งหมด
(เพราะมันคือเว็บรวมผลงานของแพร์เอง :oops:)ซึ่งใครอยากจะอ่านก็เข้าไปอ่านในนั้นได้เลย

อีกเรื่องหนึ่งคืออยากจะสนับสนุนเรื่องลิขสิทธิ์ด้วย เพราะเว็บวันเน็ตเป็นเว็บเกี่ยวกับเกมส์
ไม่เชิงเว็บที่ให้ทุกคนไปโพสเรื่องบทความ นิยาย เรื่องสั้นหรือข้อมูลแบบ หมวด Writer
ได้ (ถ้าคนเล่น Dek-d จะรู้ค่ะ) แม้ว่าเราจะสามารถโพสได้ แต่ก็ไม่มีสามารถปกป้องนิยาย
หรือลิขสิทธิ์ได้ดีพอควร ทำให้แพร์ไม่กล้าจะเอามาลง แม้ว่าอยากจะเอามาลงสุดๆเพื่อ
ให้ทุกคนได้อ่าน

ส่วนเรื่องแกลเลอร์รี่กำลังทำอยู่ ซึ่งคาดว่าจะเสร็จและลงในเว็บของแพร์ในไม่ช้า

สุดท้ายนี้ขอขอบคุณแฟนๆ(ที่มีน้อยนิด)และนักแสดงที่ยังเล่นเกมส์อยู่(รวมถึงที่ไม่ได้เล่นเกมส์ด้วย)ที่เคยช่วยขุดนิยายขึ้นมา(และมาช่วยติชมให้กับนิยายของแพร์)

/me พิมพ์ซะยาว ขอพักมือก่อนล่ะ ฮิ้ว ~
