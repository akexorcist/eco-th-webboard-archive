RisingUltimate เขียน:อยากทราบรายละเอียดระหว่าง
Dancing Sword กับ Raving Sword
แล้วที่ว่าทะลุค่าMdef นั้นทะลุข้างไหน

มันไม่ได้ทะลุ mdef (พลังป้องกันเวท) ครับ เพราะ skill นี้คิดเป็นการโจมตีแบบ ภายภาพ (แต่ความแรงขึ้นอยู่กับค่า matk ของคนใช้ skill) ดังนั้น ค่า mdef ของเป้าหมาย จึงไม่เกี่ยว
แต่ค่าที่เกี่ยวคือค่า def (พลังป้องกันกายภาพ) ของเป้าหมายที่โดน skill นี้ ...
และ skill นี้ ไม่ได้โจมตี ทะลุ def ( ทะลุ ในที่นี้หมายถึง การโจมตีโดยไม่คำนึงถึงค่าป้องกันนั้นๆ )

เช่น ใช้ ds, rs ยิงหุ่นอ้วนกลมที่หอแสง แทบไม่เข้า เพราะมัน มี def เยอะนั่นเอง

ส่วนรายละเอียดของ skill นี้
