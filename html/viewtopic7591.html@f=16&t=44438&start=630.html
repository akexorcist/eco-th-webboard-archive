Luceon เขียน:วันนี้ ลองกลับไปดูสกิล Ex

ก็รู้สึกอนาจจิตอีกครั้ง = ='

เกินกว่าครึ่ง ที่ความน่าอัพเป็น 0%


ขนาดนั้นเลยหรอคะ-..- ก้อจิงแบบที่คุณ Luceon พูดนะคะ ทุกวันนี้ก้อยังใช้
B.Blow ของเรนเจอร์ ในการเก็บเวลอยู่เลย
คงรอเล่นจนจ๊อบ 50 แหละค่ะ Ex หนู กะเอาไป 5 สกิล (ตอนนี้เล่น Ex จ๊อบยัง37อยู่ T^T)
โดยคิดว่าสกิลที่หนูจะโอนไปคงมีดังนี้นะคะ
1.First aid => สกิลหากิน แปะกันตายเวลาลุยเดี่ยว
2.Bungestac => เวลาเจอมอนโหด ก้อวางไว้เผื่อมันหยุดได้(ไปลองวางมาละคะ มังกรเกาะไมไม(ลูกมันนะ) แล้วให้นักเวทร่ายเวทใส่
3.Boost Hp => คิดว่าคงมีประโยชน์ ในช่วงที่ดองหินไลฟ์ มาทั้งชีวิตเอกพอเรอร์
4.Fake Death => เจอมอนโหดไม่ไหว ก้อแกล้งตายดีกว่าเสีย 3%
5.Spirit => ประสบปัญหามากมาย เวลาแบกของเควสไปทำเควส ต้องวิ่งไปมาหลายรอบขี้เกียจค่ะ อิอิ

คิดว่าคงมีแค่นี้อ่าค่ะที่จะโอนไป ยังไงช่วยแนะนำหน่อยนะคะ^^
