โดย ECO
ตอนนี้ผมเป็นชาแมนจ๊อบสี่สิบเอ็ดแล้ว ได้มาเจ็ดสกิล อัพเต็มทั้งเจ็ดสกิลแล้ว แล้วก็เหลือพ๊อยอีกสอง (ลูกแดงเล็กสอง)

ซึ่งสกิลที่ผมมี คือ

แม็กเอ็มพี ห้า
เพิ่มอัตราเพิ่มเอ็มพี ห้า
ไฟบลาส ห้า
อควา บลาส ห้า
แคลกบลาส ห้า
ไลท์(เทน)นิ่งบลาส ฟ้า
เกราะลม ห้า

แต่เรากลัวว่า พอจ๊อบห้าสิบ จะอัพเกราะไม่หมด แล้วก็จะอัพออริจินไม่ได้ด้วย

อยากรู้อีกอย่างคือ ถ้าเลเวลซักห้าสิบ ไปทำเควสแหวนทั้งแปดไหวมั๊ยอ่ะครับ
จะเอาไปแลกสกิล แล้วถ้าเลเวลซักห้าสิบ จะขึ้นเขาไฟไหวมั๊ยอ่ะงับ

ยังงัย ช่วยแนะวิธีอัพสกิล และตอบคำถามาหน่อยนะครับ ถ้าผมอัพผิด จะได้ซื้อบัตรรีใหม่ T T
