หากว่าทั้งห้องมีมอนแค่3ตัวนี้จัดว่าไหวแบบสบายมากๆ
DS 400% เทียบกับRS lv1 450%
ตอนเราเป็นเสจจ๊อบ40ไปยิงตัวที่ตายชัวก็3ตัวที่ว่าแหละ
ถ้ากดแคช+mag int โคดามะตาย(รอดบ้าง)
หุ่นเขียวก็ตาย ทีนี้DSดาเมจเบากว่าหน่อย
แสดงว่าตัวอื่นนอกจาก3ตัวแนะนำไม่ตายแน่ๆหละ
หากจำเป็นต้องยิงติดว่าไม่ยาก แต่เสียเวลา

ยิงทีละตัวเรื่อยๆ โดนรุมมากก็เผ่นเข้าวาป

สรุป มีโซล3คิดว่าเลือดน่าจะซัก1300+ใส่เกราะMdefให้เป็นนิสัย

ไม่จำเป็นอย่ายุ่งกับเกราะดำ โดนรุมมากก็เผ่นเข้าวาป
แค่นี้ก็สบายๆแล้วหละ

*เออลืมไปความแตกต่างในส่วนของดาเมจคิดว่าintน่าจะมีผลด้วย
