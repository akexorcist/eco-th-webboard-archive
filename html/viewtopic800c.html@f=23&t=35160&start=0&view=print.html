โพสต์แล้ว: พฤหัสฯ. 17 ม.ค. 2008 6:32 pm
โดย ECO
เกริ่นนำ
ไม่รู้ใครเคยทำรึเปล่า
แต่ว่าที่แน่ ๆ คือเวลาลากปืนน้อยกลอยใจไปที่ใดก็ตาม จะมีคนถามไถ่ตลอดว่า
"ปืนนี้ท่านได้แต่ใดมา"

ก็จะเฉไฉตอบว่า
"ซื้อมาจากพ่อค้า โกเลมเอย"

วันนี้ ไหน ๆ ก็ฉลองสอบตกแค่ 2 วิชา ( จากเดิม 5 วิชา ^^" )
เลยแปะรูปวิธีทำแบบคร่าว ๆ นะครับ
( กดดูรูปขยายได้นะครับถ้าไม่ชัด )


ขั้นแรก
- สมัครเข้าร่วมกองทัพใต้ซะก่อน
( ถ้ามีใบอนุญาติค้าขายปืนGathering Gun แล้วก็ข้ามไปขั้นที่ 3 เลยครับ )


ขั้นที่ 2
- ซื้อใบสมัคร ค้าขาย ปืน Gathering Gun ที่ Iron South อย่าลืมนำตราของทหารไปด้วยนะครับ



- คุยกะเจ๊ที่อยู่ข้างในเลยครับ



- เจ๊แกจะให้แสดงเหรียญประจำตัวทหาร ( ได้ตอนสมัครเป็นทหารทิศใต้แหละครับ )



- จากนั้นก็จะรีดไถเงินเล็กน้อย ( 9,200G หุหุ )



- แล้วเราก็จะได้บัตรรูปร่างหน้าตาแบบนี้ ( ใช้ได้ตลอดชีพครับ )


ขั้นที่ 3

- ลงบันไดไปชั้นล่างของเมือง ตามตำแหน่งในรูปเลยครับ ( ดูที่แผนที่ในรูปก็ได้นะ = =" )



- คุยกะ ...เอ่อ..... จะเรียกผู้หญิงหรือ....ดีอ่ะ.... :oops:



- จากนั้นก็แสดงใบอนุญาค้าขาย Gathering four ให้เจ๊แกดู



- ตรงนี้ถ้าใครรวย ก็จ่ายไปเลย 300 k ( 300,000 G ถ้วน )
แต่ถ้าไม่มีตังให้เลือก แพงจัง ( ผมก็เลือกข้อด้างล่างครับ อุอุ :twisted: เรื่องไรจะจ่าย แพงโคตร )



- แล้วจะมีเควสให้เราเลือกทำ แต่... ต้องใช้แต้มเควส 3 แต้มนะครับถึงจะทำได้


ตรงนี้แนะนำว่า ถ้าไม่ใช่ ทาทาราเบะ แนะนำให้เลือกเควสโจมตีดีกว่า ( หรือเป็นทาทา แต่ขี้เกียจตีหิน ) เพราะจะไวกว่าไปไล่ตีหินให้ครบครับ ^^"

การเปลี่ยนเป็นปืนสีฟ้า Gathering Gun A
เปลี่ยนที่ NPC คนเดิมนี่แหละ


แต่มีข้อแม้ ว่าต้อง เป็นสายอาชีพ Tatarabe มาเปลี่ยน พร้อมเงิน 100k ( 100,000G )







เท่านี้คุณก็จะมีปืนน้อยกลอยใจคอยติดตาม และส่งเสียเอี๊ยดอ๊าดตลอดการเดินทาง + เก็บเลเวลของคุณแล้ว :lol:
