ข้อความจาก ชุบบี้ : จ้า กลับมาแล้ว มีช่วงนึง ติดสอบ ติดงานมหาลัย ติดเกมส์ ฮ่าๆๆ แต่ตอนนี้ หมด คูณ แล้ว ก็เลยว่างแล้วจ้า

UPDATE : จากบทนำภาค ซีลอทบู~ ที่เคยเกริ่นไปว่า จะมีตัวละครเพิ่มขึ้น
วันนี้ เค้าอัพตอนที่1-2 แล้วน้า ตัวละครไหนจะมาเป็นตัวแรก ลองอ่านกันดูเลยจ้า

จุดประสงค์ : ขอบคุณผู้ชม ผู้อ่าน ทุกท่าน ที่ให้ความสนใจนะคะ
ถึงแม้นี่ จะเป็น แค่ บอร์ด เล็กๆ
แต่เราก็ ดีใจค่ะ กับความสำเร็จ เล็กๆ ของเรา
อยากจะให้ทุกคนที่เหนื่อยจากการเก็บเวล การวอ
หรือเรื่องอื่นๆที่ต้องซีเครียดกับชีวิต พอได้มาอ่านการ์ตูนของเรา
แล้วรู้สึกผ่อนคลาย หายเหนื่อยกันค่ะ^w^
