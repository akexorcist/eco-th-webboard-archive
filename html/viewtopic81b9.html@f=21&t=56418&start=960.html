์Navy Field เล่นอยู่พักนึง มันส์มากตอนเล่น 32/32 (หรือ 15/15 หว่า ... เอาเป็นว่าเยอะมากเลยล่ะกันนะครับ ==) เรือผมเพิ่งเล่นเลเวล 5 (จำเลเวลไม่ค่อยได้ จำได้แค่ว่าเปลี่ยนจากเรือลาดตระเวณ เป็นเรือจู่โจม) ทำให้ผมรู้ซึ้งว่า เรือผมเป็นได้แค่กำแพงตอปิโด == (หมายถึง เอาเรือเราตั้งหันข้างเป็นกำแพงกันตอปิโดไม่ให้โดนเรือบรรทุกเครื่องบิน + เรือสำคัญ ๆ แล้วก็ยิงตอปิโดสวนศัตรู ... แต่ ... 3/5 นี่มันเกินไปหน่อยนะครับ ==)

เกมส์นี้มีทริคคือ ยิงแม่น ๆ ต้องแมนมั่ว (Manual) ถ้ายิงอย่างเดียวต้องออโต้ (Auto) อีกอย่างคือแมนมั่วยิงได้ไกลกว่าด้วย ... ส่วนออโต้เอาไว้เวลาไล่ยิงศัตรูเพราะเราคงไม่มีเวลามานั่งกำหนดมุมหรอกนะครับ ... แล้วความหนักกระสุนมีผลต่อระยะและพลังโจมตีด้วย รวมไปถึงความแม่นอีกต่างหาก ==

รู้สึกทางบอร์ด Thaigaming.com จะมีคนยังเกมส์นี้เยอะอยู่นะครับ ยังไงก็ลองไปดูนะครับข้อมูลเยอะมาก ==

ปล. งานมังงะ ไม่ได้ไปแฮะ ลาดพร้าว ไกลไปหน่อย ... ถ้า สาทร อาจแว่บ ๆ ไปถ่ายรูปคุณนาโอโกะ + นานาเสะ + อาเบะ

ปล2. อดซื้อ กีอ๊าส ~ กีอัส อีกล่ะ

Edit : Navy Field ถ้าเล่นกับพวกเลเวลสูง ๆ มีเรือจมไม่รู้ตัวแน่ ๆ ครับ เริ่มมาก็สาดกระสุนใส่กันเลย แม้แผนที่จะค่อนข้างใหญ่ แต่เคยมีครั้งนึงทีมผมเพิ่งเริ่มเกมส์ เรด้าเรือรบศัตรูก็หายไป 4 จุด == พอตรวจดูแผนที่ใหญ่ก็พบว่า เรือจู่โจมประจัญบาญ (จำชื่อจริง ๆ ไม่ได้) จำนวน 2 ลำ กำลังสาดห่ากระสุนใส่ทางศัตรูแบบไม่ยั้ง + ไม่สนพวกเดียวกันด้วย == กว่าจะหยุดยิงก็ตอนโดนเรือบรรทุกเครื่องบินศัตรูส่งเครื่องบินมายิงนั่นแหละครับ (เพราะมัวแต่ยิงเครื่องบินเลยไม่มีเวลามายิงปีนใหญ่)
