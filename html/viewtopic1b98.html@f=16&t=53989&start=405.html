เอาเฉพาะสกิลที่เกี่ยวข้องนะ

- Merchant
Mace Mastery
>> หากคิดจะใช้กระบอง
Support
>> บัฟ +ATK และ MATK เห็นผลพอควร

- Trader
Bag Mastery
>> หากคิดจะเล่นสายกระเป๋าฟาด
Weight Control
>> ถือกระเป๋ามือซ้ายแล้วยัดของไปเยอะๆ จะทุบแรงขึ้น
Beat Smash
>> สกิลโจมตีของสายกระเป๋าฟาด หวดทีละ 250% สุ่มออก 2 หรือ 3 ครั้ง โมชั่นไว ร่ายไม่นาน

- Gambler
Throw Mastery
>> หากคิดจะเล่นสายปาไพ่
Blackleg
>> อัพแล้วทำให้ตีแกว่งน้อยลง [เล็กน้อย]
- Continue Throw
>> ปาไพ่ 6 ใบติด แรง 720% กด Double Up แล้วแรง 1440% =w=b
- One or Eight
>> สกิลเก็บเว่ลชั้นดี แม้จะค่อนข้างเสี่ยงไปหน่อย ใช้กับอาวุธได้ทุกชนิดแรง 777%
>> แนะนำให้ไว้เก็บเว่ลกับตัวที่มันไม่ตีเราก่อน เพราะว่าแม้เราจะพลาด มอนก็ยังไม่สนใจเรา
>> ถ้ามี Bag Smash ใช้ Bag Smash ดีกว่า ไม่เสียวด้วย 555+
- Double Up
>> ทำให้ใช้สกิล Continue Throw กับ Coin Shoot แรงขึ้น 2 เท่า
- Coin Shoot
>> ใช้ตังทีละ 1500G ปา กด Double Up อัพแล้วแรง 900% ใช้กับอาวุธได้ทุกชนิด
>> ยังไม่ได้พิสูจน์เรื่องความแม่นยำของสกิลนี้เลย = =a แต่ดูแล้วเหมาะกับสายกระบอง กระเป๋ามากกว่า
- Flower Card
>> สกิลโจมตีของสายกระบอง แรง 350% x3ที แต่ว่าร่ายช้า โมชั่นก็ช้าเกิน แถมมอนเดินแล้วหลุดอีก
