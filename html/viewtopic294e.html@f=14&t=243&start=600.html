อยากเล่น BH จัง ชุดตัวละครหญิงน่ารักมาก ขอถามผู้รู้หน่อยได้ป่าวครับคือสงสัยอ่าคับว่า

1.ตอนที่เราเปลี่ยนเป็น BM แล้วทำการสวิตซ์ไปเป็น BH เราสามารถนำสกิลของ BM ไปเล่นที่ BH ได้ใช่ป่าวครับ(ทั้งแอคทีพและพาสซิพป่าวคับ) โดยทำการ หาร10 จ็อบ ของ BM ไปที่ช่อง รีเซิฟหรอครับ
2.ถ้าผมเล่น BH ผมสามารถใช้สกิลของสวอตแมน ได้ไหมครับ (น่าจะได้นะ)เช่นท่าตีเร็วอ่าครับ
3.BHมีสกิลปลดของหลายอย่าง อยากทราบว่าโอกาศปลดติดจะขึ้นกับค่าอะไรหรอครับ
4.เรื่องของการอัพค่า vit ดียังไงหรอครับผมเคยอ่านผ่านๆตามมา 3วิทได้ 1def และเคยลองอัพ 1 vit เลือดเพิ่ม 7 (ถ้าจำไม่ผิด)ตอนเป็นสวอตแมนใช่หรือป่าวครับพอเปลี่ยนคลาสสองยังเพิ่มเท่าเดิมไหมครับ
5.สกิลเพิ่มแม็กhp มันเพิ่มเลือดขั้นหละ 10 หรอครับ (นึกว่าเพิ่มเป็นเปอเซ็นต์)
6.สุดท้ายแล้วครับตรงช่อง แสดงสถานะอะครับ ค่า def ที่ปรากฏ คิดยังไหงหรอครับผมเห็น มัน เป้น ย่านหรอครับ เช่น 5-40 อะไรทำนองนี้ ตัวเลขหน้า กับหลังคืออะไรหรอครับแล้วทำการเพิ่มได้อย่างไรครับ


ปล.ใครรู้ช่วยตอบผมทีละข้อทีนะครับ ขอขอบคุณอย่างมากครับเพราะช่วงนี้กลับบ้านเลยยังไม่ได้ลองอะไร จำค่าต่างๆไม่ได้คราวๆมีอะไรผิดขอโทษไว้ที่นี้ด้วย(ขอบคุณที่ตอบนะครับ)

ตอบคุณ มู๋อ้วนงอแง
1. ใช้ได้หมดครับ เลือกไปตาม job Lv /10 มันเตม 40 ก็ได้ 4skill
2. SDC ( sword delay cancle ) ใช้ได้กับ ดาบมือเดียวและ 2มือครับ ขวานไม่เกี่ยวน้า
3. อันนี้ไม่ทราบจิงๆครับ ถ้าให้เดา น่าจะเป็น Dex
4. โบนัส Vit จะเพิ่มตามที่หารอะครับ แต่ความคิดผม สายไหน สายนั้นนะ อย่าMixเลย
5. เพิ่ม เลเวลละ10 แต่ +ผลของ potion เพิ่มขึ้นนิดหน่อยครับ นิดจริงๆ
6. Def หน้า เป็น % ครับ เพิ่มได้จากการอัพ Vit ของตัวละคร
Def หลัง เป็น Damage ที่ลดโดยตรงจากค่าความเสียหาย จากการใส่ equitment
ดังนั้นจึงไม่แปลกเลยครับ ว่าทำไม สาย Vit ถึงโดนดาเมจ จากการ โจมตีเบากว่า
สายอื่นมาก เพราะสาย Vit มี Vit เยอะ จึงมี ค่า Def ตัวหน้า ซึ่งเปนการลดดาเมจ
โดยคิดเป็น % ไงครับ สรุปคือ Def ตัวหลัง ช่วยคุณได้ไม่มากเท่าไร ในช่วงท้ายๆเกมส์
ถ้าจะเลือก Agi ก็ Agi เลย ถ้าจะ vit ก็ vit เลย เพราะหลังๆ โบนัสมัน+ เยอะครับ

โบนัส Def ทีได้จาก Vit คิดแบบนี้ครับ
ทุกๆ 3ค่า Vit จะเพิ่ม Def 1 ทุกๆ 9ค่า Vit จะเพิ่ม Def 3
ง่ายๆคือ
3=1
6=2
9=5
12=6
15=7
18=10
21=11
24=12
ตัวละครผม Vit รวม 24 จึงได้ โบนัส Def หน้า 12 ไงครับ ถ้า Vit 27 ก้อจะได้ 15
พอเข้าใจคร่าวๆแล้วใช่ไหมครับ ส่วนเรื่องของ BH ผมไม่ค่อยทราบนะครับ
