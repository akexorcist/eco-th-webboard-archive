ก่อนอื่นต้องทำความเข้าใจก่อนว่า จากUndead Island เราสามารถนั่งบ้านมาอัพทาวน์ได้

แต่ไม่สามารถที่จะนั่งจากอัพทาวน์มา Undead Island ได้

ก็จะต้องนั่งจาก Warship แล้วเดินย้อนกลับมาประมาณนี้ครับ

ส่วนที่จะนั่งเข้าไปถึงตัวเมืองเลยก็ต้องเข้ากองรบก่อนครับ

สมมุติเราไม่ได้เจ้าสังกัดกองทัพทิศใต้ก็จะนั่งสวนได้แค่ถึง sourin cape

แต่ถ้าเราเข้าสังกัดทิศใต้ก็จะสามารถเข้าไปได้ถึงเมืองใต้เลยทีเดียว


ps.แมพฟูไม่สามารถนั่งไปได้ครับ แต่สามารถกดนั่งกลับได้ครับ เหมือนกับ Undead Island

*ข้อสำคัญอย่าลืมถ่านบ้านบิน
