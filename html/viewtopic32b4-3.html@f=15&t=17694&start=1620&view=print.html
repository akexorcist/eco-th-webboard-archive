- ฆ่าคนแล้วได้แต้ม สะสมแต้มสร้างชื่อเมพในโลกโดมิเนี่ยนได้
- เวลาตายเสีย 10% แต่จะมีทำเควสป้องกันเวลาโดน PK ตาย
- เวลาตายเลเวลลด (Lv.30 แล้วตายจะเหลือ Lv.29 90%)
- โลกเอมิลมี NVN แต่ในโลกโดมิเนี่ยนจะมี PVE
(ทั้ง sv ที่เลเวล 30/30 ต้องช่วยกันฆ่าฝูง DEM-Sniper ที่เข้ามาบุกฐาน)

จะมีเควสพิเศษเก็บแต้มทำอาวุธ 90 อีกแบบ
แล้วก็มีระบบที่เข้ามาเสริมให้ PK สนุกขึ้นด้วยกระมัง
แต่ตรงนั้นยังไม่ได้อ่านละเอียดครับ มองแค่ผ่านๆตาข้ามๆไป
