อืม ยังรับสมัครตัวละครอยู่ไหมนั่นน่ะ?


*ชื่อ – สกุล : ลัคบาร์ส มิดเดย์ดรีม (เรียกสั้น ๆ ว่า บาร์ส)

*อายุ : 22

*เพศ : ชาย

*เผ่าพันธุ์ : Emil

*อาชีพ : Alchemist (เห็นตัวละครยังไม่มีใครจองอาชีพนี้ ยึดเลยละกัน)

*ลักษณะหน้าตา : หน้าตาน่ารัก ตาโตหน่อย ใส่แว่นด้วย (ออกแนวโชตะชอบกล) ผมสั้นแบบโค้งกลมด้านบน มีปรกหน้านิดหน่อย ถึงจะ 22 แล้วแต่ก็มักจะถูกทักว่าเป็นเด็กเสมอ

*ลักษณะร่างกาย : สูงประมาณ 165 cm ผิวเหลือง ก็เพราะไม่สูงมากด้วยจึงมักจะมีคนิดคิดว่าเป็นเด็กอยู่บ่อย ๆ

*ลักษณะการแต่งกาย : แต่งตัวประมาณชุดนักเดินทางแบบคนตะวันตก หมวกแบบ travel hat (80) สีส้ม สวมเสื้อแจ็คเก็ตสีดำ ทับด้วยเสื้อคลุมยาวถึงหัวเข่าสีน้ำตาลอ่อน กางเกงสีดำ รองเท้าก็สีดำด้วยละกัน

*ลักษณะนิสัย : คนใจดี เดินผ่านเด็ก ๆ ก็จะปลูก healing tree ช่วยเสมอ ชอบต้นไม้ใบหญ้ามาก ประมาณว่าถ้าสู้กับม่อนอยู่แล้วมองไปเห็นต้นไม้หรือใบหญ้าแถวนั้น ก็จะเดินไปดูว่าต้นอะไร ฯลฯ

*อาวุธ : ขวานใหญ่ของคุณพ่อ

ทักษะ :
1. ทักษะคุยกับต้นไม้ ใบหญ้า ฯลฯ ได้ อาจใช้เวลาถามทางหรือถามหาคนรู้จัก
2. ท่าขวาน "โค่นต้นไม้ใหญ่" เป็นท่าที่สืบทอดมาจากคุณปู่ ถ้าโจมตีใส่ม่อนประเภทพืชจะได้ผลรุนแรง
3. ท่าขว้างน้องไชเท้า เอาน้องไชเท้าปาใส่ศัตรู มีผลทำให้ศัตรูหัวโนและเบนความสนใจไปที่น้องไชเท้าแทน (มันน่ากิน ว่างั้นแหละ)

ความสามารถพิเศษ : รอยยิ้มอันไร้เดียงสาที่จะทำให้สาว ๆ ทุกคนที่เห็นชะงักด้วยความ "น่ารัก"

สัตว์เลี้ยง : น้องไชเท้าสีขาวตัวอวบตาจุดเดียว ชื่อ "ชะเอม" จุดเด่นคือเป็นน้องไชเท้าที่พูดภาษาคนได้ เวลาโดนม่อนจ้องหรือมีคนบอกว่า "อยากเอาไปต้มกินจัง" จะร้องว่า "ม่ายยยยยย" แล้ววิ่งวนไปวนมา

อยากให้เป็นตัวละครประมาณว่า ออกเดินทางเพื่อตามหาหญ้าวิเศษที่สามารถรักษาได้ทุกโรคเพื่อไปช่วยน้องสาวหรือคนรักที่ป่วยอยู่อะไรประมาณนี้นะ มีน้องไชเท้าพูดได้เป็นคู่หูร่วมเดินทาง ปล่อยมุกน่ารัก ๆ บ้างให้ยิ้มมุมปากได้น่ะนะ (ขอมากไปไหมเนี่ย)
