ไม่รู้วิธีการคำนวณของมันนะ

แต่ถ้าถามว่ารู้สึกปลอดภัยกว่า คงจะเป็น agi

เพราะ agi จะเห็น dmg ขึ้นมาค่อนข้างน้อย แน่นอนว่าถ้าขึ้น miss / avoid เราก็สบายใจ
แต่สาย vit มันถึกอึด พวกนี้ส่วนมากมักจะวิ่งไม่ค่อยจะระวังกันด้วย ถือว่าข้าเลือดเยอะ โดนนิดหน่อยก็ชิวๆ แถมโดนก็ไม่แรงเกราะหนา โอกาสเราร่วงสูง >_<

protect ช่วยให้เจ้าของร่างรับ dmg แทนคนสิงน่ะ เราเซฟกว่า แต่ว่าเวลาใช้งานมันก็แปบเดียว (ถามเพื่อนมา มันบอกไม่ถึงนาที)
