ขอตอบรวมๆนะครับ ทริคการใช้ chaos gate ก็ง่ายๆนะครับสาปน้ำแข็งแล้วก็ร่ายต่อเนื่องไปเลย

หรือ ถ้าถึก+มีพระ ก็ยืนชนไปเลยก็ได้นะ สกิลน้ำแข็งถ้าอัพจะส่งผลต่อ Abalation เขียนผิดเปล่าหว่า

แต่ส่งผลครับ ส่วนในด้านส่งผลให้ถึงเวล 5 ผมคิดว่าน่าจะไม่นะครับ เพราะสกิลของคาบาก็จะมีระยะเวลาของมัน

แต่อัพสาปน้ำแข็งขั้นแรก ก็เพื่อให้ติดสาปง่ายขึ้น

สำหรับการอัพ Int ผมคิดว่าไม่จำเป็นเลยครับ สำหรับสายเวล เอาพ้อยไปอัพ Vit คุ้มกว่าเยอะครับ


ส่วนด้าน Sage ตอนหลังจะมีสกิลอย่าง Divine Barrier มาช่วยทำให้ประหยัดพ้อยไปได้เยอะครับ

อัพดีๆ M.Def 100 ได้เลยล่ะ พูดง่ายๆโดนเวท 0

1.สกิลโอน int ของ sage เนี่ยมีผลกะสายเวทมากน้อยขนาดไหนครับ ถ้าใช้สกิลนี้กะเนโครยิงสกิลบลาสใส่ มังกรไมไมจะแรงไหม
- สกิลนี้จะเพิ่มค่าอินท์นะ สมมติว่าตัวเรา อินท์ 100 โอนให้คนอินท์ 50 คนที่เราโอนให้ จะมีอินท์โบนัส เพิ่มอีก 50 แต้ม ในส่วนของค่้าอินท์นี้จะช่วยให้ มี M.def มาหขึ้น (ถึกเวทย์) ส่วนที่ถามว่าจะยิงแรงขึ้นไหม ขอตอบว่า ไม่แรงขึ้นครับ เพราะ ค่าอินท์จะเพิ่ม M.atk ตัวหน้า เช่น สมมุติว่า M.atk อยู่ที่ 650-800 ใช่ไหมครับ ความแรง จะอยู่ที่ 850 แต่ถ้าอินท์เพิ่มขึ้น จะเป็น 750-800 (สมมุติ) การยิงเวทย์ที่ ความแรงสูงสุด แต่ระยะห่างของแดมเมจจะแคบลง สรุปคือ มันจะช่วยให้เวทย์เสถียรขึ้นนั่นเอง ประมาณว่าปกติจะยิงเจ้า 1200-2200 ใช่ไหม แต่ถ้า M.atk ตัวหน้ามากขึ้น ก็จะล่นระยะของแดมเมจลง ทำให้ยิงเวทย์อยู่ที่ 1700-2200 ประมาณนี้ครับ
2.sage ถ้าอัพ vit ไว้ถึง 100 จะทำให้ถึกมากไหมคับ
- ถึกมากครับ ได้บัพดี อาจโดนตี กายภาพเข้า 1 (Def. ตัวหน้าเป็น 100 นะ ตัวหลังไม่ช่วยให้โดน 1)
3.พอมีทริคการใช้ chaos gate ให้มีประสิทธิภาพสูงไหมคับ แบบทำให้โดนทุกฮิทอารายแบบนี้
- อย่างที่มีคนตอบไปก่อน สาบแข็ง หรือ สาบหิน นอกจากจะทำให้โดนครบทุกฮิทแล้ว ยังเป็นการใส่ ธาตุ น้ำ และ ดิน ให้เป้าหมายด้วย ส่งผมให้ โดน เวทย์ มืด แรงขึ้น มากกกกก
4.สกิลอาบาของคาบาน่ะคับ ถ้าสมมุติผมอัพสกิลน้ำแข็งไว้ที่เวล 5 เมื่อใช้อาบาแล้วติดสกิลน้ำแข็งจะแสดงผลเป้นเวล 5 ไหมคับหรือต้องสาปด้วยน้ำแข็งเลย
- อันนี้ผมไม่ทราบ
5.คาบาถ้าเวลคนเดียวไงก็ต้องใช้สาปอยากถามว่า int อัพที่ประมาณเท่าไหร่จึงเห้นผลคับ แล้วถ้าโอน int ของ sage มีผลกะสาปไหม
- อันนี้ไม่รู้เหมือนกันอิอิ
