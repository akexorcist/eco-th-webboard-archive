นานมาแล้วมีเรื่องเล่าแห่งตำนานอโครเนียว่า หนุ่มสาวของผู้กล้า จะต้องออกเดินทางเพื่อกำจัดจอมมารปีศาจที่อยู่ใน Undaed Island เพื่อปลดพันธนาการให้กับชาวอโครเนีย
และวันนี้ก็ถึงคิวของหนุ่มสาวคู่หนึ่งชื่อ กิล(Gil)l และ โรส(Rose) กิลและโรสเป็นเพื่อนเล่นกันมาตั้งแต่เด็กๆ

"วันนี้แล้วสินะที่พวกเราต้องออกผจญภัยเพื่อปลดพันธนาการให้กับชาวอโครเนีย ที่ตกเป็นทาสให้กับจอมมารปีศาจ เฟลด้า(Faldra)" กิลพูดอย่างหนักแน่น สมชายชาติทหาร

กิลเป็นลูกของ วูฟ(Woft) ทหารเอก แห่งอาณาจักร อโครเนีย ผู้ซึ่งได้รับการยกย่องว่าเป็นบุรุษที่น่ายกย่องต่อการปราบมาร
ส่วนโรส เป็น ลูกของวินเซ้นท์ที่สิบห้า(vinsent 15)นักบุญแห่งโบสถ์แฟนเทียเซีย( phantasia) ถึงแม้เธอจะยังเด็กแต่เธอก็สามารถร่ายเวทย์โฮลี่ไลท์(Holy Light) ซึ่งเป็นเวทย์ที่ต้องใช้สมาธิที่กล้าแกร่ง
วูฟและวินเซ็นท์เป็นเพื่อนกัน และได้สร้างวีรกรรมแทงลูกตาของเฟลด้าก่อนที่จะถูกพลีชีพ กิลและโรส ได้ฟังเรื่องราวที่กล้าหาญของพ่อเค้าทั้งคู่ทำให้เค้าไม่หวั่นกลัวการเดินทางไปปราบปีศาจครั้งนี้ แถมคิดเสียอีกว่าจะต้องนำชัยชนะกลับมาสู่อโครเนียอีกครั้ง

"เอาล่ะถึงเวลาเดินทางแล้วล่ะกิล" โรสพูดอย่างยิ้มแย้ม พร้อมกล่าวคำภาวนาต่อโบสถ์ผมินเซ็นท์

"อืม ไปกันเถอะ" กิลชวนโรสเดินทาง

"เดินทางดีๆนะเด็กๆ"เสียงของชาวบ้านที่เค้าคิดว่าเด็กสองคนนี้จะต้องนำสันติสุขมาสู่อโครเนียอย่างแน่นอน

เด็กทั้งสองยิ้มอย่างเบิกบาน เหมือนไม่รู้ว่าจะต้องประสบพบเจอกันอันตรายที่กำลังคืบคลานเข้ามา

"การเดินทางครั้งนี้กิลว่าเราจะชนะไหมจ๊ะ" โรสพูดอย่างอ่อนหวาน

"ชนะสิ ต้องชนะ ถ้าไม่ชนะก็ขอได้แก้แค้นให้ท่านพ่อของเรา โดยการเอาดาบไปแทงลูกตาอีกข้างหนึ่ง"กิลพูดแบบลูกผู้ชาย

"เดี๋ยวก่อนๆ" ป้า พาเมล่า ตะโกนอย่างสุดเสียง

เด็กหันหลังไปดู เห็นป้าวิ่งมาอย่างหน้าตาตื่น ป้าพาเมล่า เป็น sage ประจำอโครเนีย ป้าหอบแฮ่กๆ ป้ามีของอย่างหนึ่งจะให้พวกเธอ นี่เป็นอาวุธของพ่อของพวกเธอ โรส ได้รับ คฑา (noble rod) เป็นคฑาที่มีอัญมณีอคอเรี่ยมอยู่บนยอด
ส่วนกิลได้รับ (Cerber rus Fang) ดาบสามง่าม ตอนนี้พวกเธออาจยังไม่สามารถควบคุมอาวุธเหล่านี้ได้ เพราะมันมีวิญญาณที่จะเลือกผู้ที่ใช้มัน
เธอจะต้องพิสูจน์ให้วิญญาณเห็นถึงความสามารถมันถึงจะยอมรับว่าเจ้าคือเจ้าของมัน เออ ป้าช่างตัดเย็บเค้าฝากชุดมาสองตัว หวังว่าพวกเธอจะชอบมันนะ
กิลได้รับ(field jacket) โรสได้รับ (leather one-piece) โอ้ นี่อีกอย่างเกือบลืม แซนวิทด้วยป้าตัดเย็บเค้าทำอร่อยนะ (sandwich)
ป้าต้องไปวิจัยต่อแล้วล่ะนะ ดูแลตัวเองดีๆนะเด็กๆ

เด็กทั้งสองลองสวมใส่ชุดที่ได้มาใหม่ๆ

"โอ้ กิล ชุดของเธอเท่ห์มากๆเลยเป็นสีดำดูเข้มแข็ง"โรสพูดอย่างจริงใจ

เธอก็ไม่ใช่ย่อยนะโรส

"เอวเป็นเอวสะโพกเป็นสะโพก" กิลยอโรส

"บ้า เค้าไม่ใช่ท่อนไม้ท่อนซุงนะกิล" โรสเขินบิดไปบิดมา

ไปกันเถอะ ออกเดินทางเป้าหมายเพื่อล้มเจ้าจอมปีศาจเฟลด้า

พวกเค้าทั้งสองจะเจออะไร อันตรายหรือไม่โปรดติดตามตอนต่อไป>>>

จากตอนที่แล้ว ทั้งสองคนได้ออกเดินทางจากดินแดนอโครเนีย หน้าที่ที่ได้รับคือกำจัดจอมมารเฟลด้า การจะกำจัดนั้นไม่ใช่เรื่องยากหากมีทีมที่แข็งแกร่ง และมีความสามัคคี
หลังจากเดินทางออกจากหมู่บ้านไม่นานนักก็ถึงทางเข้าป่าอโครเนีย ป่าอาถรรพ์ กิล คิดถึงเรื่องเล่าโบราณ ว่า

"ป่าแห่งอโคเนีย เป็นป่าที่ลึกลับซับซ้อน มีทางออกทะลุไปได้หลายทาง ผู้คนที่เข้าไปถ้าไม่เข้มแข็งพอจะไม่สามารถออกจากป่าแห่งนี้ได้"

โรสเล่าอย่างมีความหวังว่า หลวงพ่อที่โบสถ์เคยเล่าให้ฉันฟังว่าในป่าแห่งนี้มี ผู้ที่เชี่ยวชาญด้านศาตราวุธ ประเภทธนูอยู่คนหนึ่ง แต่เค้าเก็บตัวไม่คบค้าสมาคมกับใครมานานหลายปีแล้ว

"วันนี้เราคงไม่พ้นป่าอาถรรพ์นี้แน่ๆเลย" กิลพูด

กิลโรสรู้สึกถึงอะไรบ้างอย่างที่คอยจับจ้องเราตั้งแต่เข้าป่ามาตั้งนานแล้ว กิลรู้สึกไหม กิลกระซิบข้างหู กิลก็รู้สึกเหมือนกัน
เมื่อทั้งคู่เดินลึกเข้าไปเรื่อยๆจากกลางวันเหมือนดั่งกลางคืน ทางเดินต่างๆดูเหมือนกันหมด ถ้าหากจะหลงเหมือนเรื่องเล่าโบราณก็ไม่ใช่เรื่องแปลก

ตึ่ง!! เสียงประหลาดใกล้เข้ามาทุกทีทุกที ร่างกายของเค้าทั้งสองคนเริ่มหวั่นกลัวอย่างเห็นได้ชัดจากการยืนขาสั่น มือสั่น แขนขาเย็นไปหมด แต่ในใจก็ยังสู้ ถึงจะไม่เคยได้สู้อะไรที่น่ากลัวแบบนี้มาก่อน

ตึ่ง!! เสียงใกล้เข้ามาเรื่อยๆ กิลเริ่มตั้งท่าสู้ โรสหลบไปอยู่หลังกิล ผู้ที่โรสคิดว่าคนนี้แหละที่เค้าไว้ใจที่สุด

สัตว์ที่ให้เกิดเสียงนี้ปรากฎตัวออกมา มันคือ Killer Beast หมีตัวใหญ่สีแดงเหมือนเลือด เดินเข้ามาใกล้พวกเค้า
เป็นหน้าที่ของนักดาบอย่างเค้า กิลฟาดดาบที่ได้รับลงอย่างรวดเร็ว แต่ดูเหมือนไม่สร้างบาดแผลให้กับเจ้าหมีสีแดงตัวนี้เลย
โรสลองร่ายเวทย์ Holy light มันทำให้หมีหยุดชะงักได้แปปเดียวเท่านั้น ทั้งคู่ตัดสินใจ วิ่งหนี กิลจับมือโรส แล้ววิ่งเข้าไปในป่าลึก ใขขณะที่วิ่งนั้นโรสสะดุดกับรากไม้ โรสหันไปมองคิดในใจว่าเรามาได้แค่นี้หรอเนี่ย
