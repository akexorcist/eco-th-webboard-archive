จากนั้นไปโลกโดมิเนียนกันเลย ^^

เก็บเลเวล ให้ตัวเองเลเวล 6-7

จากนั้นเข้าสู่ช่วงเวลาฟักลูกไก่แล้ว

1. ทำให้เลเวลตัวเองปริ่มๆประมาณ 90%



2. ไปตีลูกไก่ม่วง (ให้เก็บเนื้อระหว่างทางไปด้วยเพื่อความต่อเนื่อง)



3. เลเวลอัพ



4. เก็บแม่ไก่



5. ไปตีจอมเวทย์



6. แน่นอน ท่านตายชัว พร้อมกับเปอร์หายไปอีก 10-13 เปอ (ถ้าเลเวลไม่ลดก็ไปให้มันตีอีกรอบ)



7. เรียกแม่ไก่ + กินเนื้อที่เก็บมา




8. กลับไปดูข้อ 2

แค่นี้ท่านจะได้ลูกไก่ทุกๆ 5-10 นาที (ที่เห็นในรูปน่ะ เก็บ 10นาที ได้ 2 ตัว)
