วิจารณ์ ( เชือดตัวละคร ) ตามแบบฉบับเจ๊เทียร์ =[]= !!!

Treatnitia Lusenbun [ทรีทนิเทียร์ ลูเซ็นบุน ] – อ่า ... เจ๊ไม่แน่ใจนะจ๊ะ ว่าเจ๊อ่านถูกหรือเปล่าเอ่ย ? แต่น่าจะอ่านแบบนี้ ดูแล้วออกแนวมาคู่กับชายหนุ่มผู้ขมขื่นของเราทีเดียว แต่สำหรับเจ๊นั้น ไม่มีอะไรแน่นอน ทั้งสองอาจจะพบกับจุดสุดท้ายที่น่าผิดหวังก็เป็นได้ ( จริงไหม ! การผจญภัยของพวกเรายังไม่เริ่มเลยนะ ! ) เจ๊ก็ไม่ขอรับประกันแล้วกัน ดูแล้วเธอคนนี้จะรักหนุ่มรันทดของเรามาก ( ขอเจ๊เรียกแบบนี้ละกัน ง่ายดี =w=; ) เป็นสาวน้อยในอุดมคติจากสวรรค์เลยทีเดียว และก็ยอมทำทุกอย่างเพื่อคนที่เธอรัก ... แม้แต่การเสียสละเขาหรือ ? ... ดูแล้วน่าจะเป็นตัวช่วยหนุนดราม่าของหนุ่มรันทดมากกว่า แล้วบทก็อาจจะไม่เยอะเท่าไรนัก เพราะดูแล้วเธอคนนี้ก็ดูจะอุดมคติไปนิดนึงนะจ๊ะ ไม่มีข้อเสียเลย ^^”

วิจารณ์ ( เชือดตัวละคร ) ตามแบบฉบับเจ๊เทียร์ =[]= !!!

Ise [ อิเซะ ] – ต้องบอกว่าตัวละครตัวนี้เจ๊อ่านอยู่นานเหมือนกัน เพราะว่าต้องอ่านหลายรอบ นับว่าเป็นตัวละครที่ครี ฯ ออกมาได้ดีเลยตัวหนึ่ง กับสาวน้อยโดมิเนียน นามว่า ‘อิเซะ’ คนนี้ สำหรับเธอคนนี้ต้องเรียกได้ว่า “อัจฉริยะ” ด้วยการที่สะสมความรู้มาเป็นเวลานาน อีกทั้งยังมีประสบการณ์ในการต่อสู้ ที่ดูแล้วไม่เกินจริงเกินไป และยอมรับได้ในระดับหนึ่ง เรื่องนิสัยก็โอเคทีเดียว สำหรับเธอแล้ว ดูแล้วเหมือนลึก ๆ เธอจะเกลียดการสูญเสียอยู่มากทีเดียว จึงได้กลายเป็นคนนิสัยแบบนี้ไป แต่ถ้าหากได้รบเคียงคู่กับเธอแล้วละก็ คงจะเป็นสหายศึกที่น่าไว้วางใจคนนึงทีเดียว แต่ก็ใช่ว่าเจ๊จะไม่มีข้อติเลยทีเดียว สำหรับสกิลของเธอคนนี้ ดูสารพัดประโยชน์เกินไป จนเจ๊ต้องขอให้ตัดสองสักสองสกิล และเหลือสกิลที่จำเป็นไว้ดีกว่า อีกอย่างสกิลของตัวนี้เจ๊จะขอนำสกิลของ Sage มาเป็นหลัก เพราะจะได้ไม่เสียสมดุลในนิยายนะจ๊ะ >w<
