หรือจะอีกแบบ ดูเหมือนเป็นตัวร้าย แต่ไปๆมาๆกลายเป็นพระเอกซะงั้น เช่นกัปตันไคเอะดะ หรือ darth vader ในภาค return of the jedi เป็นต้น
