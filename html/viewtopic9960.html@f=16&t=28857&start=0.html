hannohime เขียน:สุดท้ายแล้วเพื่อนๆจะเป็นอาชีพ EX หรือ TH อ่า ?


หมายถึงถ้าอัพจ๊อบเต็มทั้งคู่ แล้วจะเลือกระหว่างเล่นหลักเป็นอะไรชิมิ?

สายเก็บเลเวล : Ex
สายหาของ : Ex
สาย NvN : TH

ตามนี้ครับ

เหตุผล

เก็บเลเวลทั่วไป

- Ex โบนัส STR เยอะกว่า+มีสกิลใช้หมาโจมตี
- Ex มีค่า HP สูงสุดมากกว่า TH ราวๆ 200+
- Ex มี Cave Hiding+Cave Bivouac ช่วยในการเก็บเลเวลในดันเจี้ยนแบบลุยเดี่ยว
- Ex มีพอยท์พออัพโซล+Attack Assist+Critical Assist กรณีเล่นเป็นตัวสิง
** แค่โอนสกิล Whip Mastery+Whip Rush ตีแส้คริก็ดีกว่าโบลว์เยอะแล้ว

สายหาของ

- Ex มีสกิล Analysis หลากหลายแบบที่เพิ่มอัตราดรอปของหลายชนิด
- Ex มีสกิล Gathering Class เสกปราชญ์ให้ทั้งปาร์ตี้ได้
** แค่โอนสกิล Code Break+Unlock Mastery และบางที Treasure Scanning มาก็พอ

สาย NvN

- TH มีสกิลปลดร่างสิงถึงสองสกิล
- TH มีสกิลหยุดนิ่งเพื่อจับตัวสายโจมตี
- TH มีสกิลค้นหากับดัก+ปลดกับดัก
** แค่โอนสกิลลดแม่นยำและพาสซีฟกับดักมาจาก Explorer หรือจะแถมหมาด้วยก็ยังได้

** ความเห็นส่วนตัว : โปรดพิจารณาก่อนลงมืออัพสกิลเพราะใบรีมันแพง ( :P )
