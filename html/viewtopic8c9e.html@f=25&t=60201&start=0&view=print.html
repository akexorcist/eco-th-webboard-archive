PET TALK; มาช่วยกันรวบรวมทริคการฝึกpet

โพสต์แล้ว: ศุกร์ 16 ม.ค. 2009 2:43 pm
โดย ECO
CASE 1 เมื่อเหตุการชุลมุน

1.ฝูงชนจำนวนมากลุมบอสทำให้สัตว์เลี้ยงหายไปจากสายตา จะทำยังไงดีล่ะทีนี้

2.เอาเมาท์ไปไว้บริเวณที่คาดว่าpetเราอยู่ขณะนั้นแล้วคลิกขวาจะมีรายการแสดงชื่อpet ผู้เล่น มอนเตอร์ที่อยู่บริเวณนั้น ให้คลิกเลือกชื่อสัตว์เลี้ยงเรา

3.เลือกแสดงข้อมูล

4.จะมีแถบแสดงสถานะปรากฏขึ้น ตอนนี้เราก็สามารถติดตามดูพลังชีวิตของสัตว์เลี้ยงเราได้แล้ว

การประยุกต์ใช้งาน
-เราสามารถใช้ itemฟื้นฟู/สกิลบัฟ/ฮิล ให้สัตว์เลี้ยงโดยกดใช้แล้วคลิกที่แถบแสดงสถานะ และ เราต้องอยู่ในบริเวณใกล้ๆสัตว์เลี้ยงหรือในสถานะที่จะเดินไปใช้สกิลได้เหมือนเราใช้กับมอนเตอร์ปรกติ
-สามารถใช้สกิลคำสาปใส่มอนเตอร์หรือช่วยฟื้นพลังให้ผู้เล่นท่านอื่น สัตว์เลี้ยงของคนอื่นได้ด้วยวิธีเดียวกันแต่เปลี่ยนเป้าหมายจากpetของเราเป็นชื่ออื่นๆในขั้นตอนที่2
-หากเป็นสกิลที่มีผลเฉพาะต่อปาร์ตี้เก็ยังคงใช้ได้กับคนในปาร์ตี้และสัตว์เลี้ยงของเขาเท่านั้นเช่น สกิลholy feather หากเป็นสกิลพื้นที่จะมีผลต่อทั้งผู้เล่นและpetแม้จะไม่ได้อยู่ในปาร์ตี้เดียวกันเช่น สกิลsamba


ปล. มาช่วยกันลงข้อมูลทริคต่างๆ ข้อเสนอแนะและอื่นๆกันครับ
หากใครมีคำถามอะไร ก็ถามมาได้ครับแต่จะหาคำตอบให้ได้หรือไม่นั้นต้องลองดูอีกที
