1. ชื่อ - นามสกุล และเพศ - Manuel / ชาย ( ไม่มีนามสกุล ) แต่มักถูกเรียกว่า " จิตรกร " ( เหตุผลว่าทำไมต้องเรียกแบบนี้อยู่ในหัวข้อพลังพิเศษครับ )
2. อายุ และชนเผ่าไหน - 17ปี / ครึ่งเทพปิศาจ ( ปีกขนนกสีดำข้างเดียว ) ถ้าไม่ได้ก็เป็นมนุษย์ธรรมดาก็ได้ครับ..
3. หน้าตา - เรียวปากบางสวยสีกุหลาบ.. ( กลิ่นYคละคลุ้ง ) แววตาสีขาวว่างเปล่าแฝงไปด้วยความลึกลับ.. เรียวหน้าได้รูป.. ผมสีดำขลับยาวเลยบ่าลงมาไปเล็กน้อย.. ผิวขาวเนียนรูปร่างสูงโปร่ง.. ชุดแต่งกายจะเหมือนผู้ดีอังกฤษแนวๆหนึ่ง ( คิดไม่ออกก็นึกภาพชุดของโร้ดในการ์ตูนเรื่อง D-gray man แต่เป็นแนวผู้ชาย )
*- สูง - 178 ซม. *- น้ำหนัก - 55 กก.
4. อาชีพใด - Assassin เชี่ยวชาญเรื่องการแพทย์ตะวันออกและวิชานินจาทุกแขนง ถนัดการใช้เข็มบินเป็นอาวุธ .. ชื่นชอบวิชาพรางกายเป็นชีวิตจิตใจ ..
5. ลักษณะอุปนิสัย - เป็นคนที่สนุกสนานและสุภาพตลอดเวลา ไม่ว่าจะเรื่องคอขาดบาดตาย หรือเรื่องการต่อสู้ นิสัยข้างในลึกๆเป็นคนฉลาดเยือกเย็นโหดร้ายและอบอุ่นในเวลาเดียวกัน ซึ่งนิสัยด้านดีจะแสดงออกมาบางช่วงเวลาเท่านั้น สัญลักษณ์ประจำตัวคือรอยยิ้มที่พรุดพรายบนใบหน้าเสมอ..


- พลังพิเศษ - ภาพหลอนวิญญาณร้าย ( ปัจจุบัน มีภาพในGallary 12,542 ภาพ 8) )

คือพลังพิเศษที่สามารถนำวิญญาณของบุคคลมากักขังในภาพเหมือนที่วาดขึ้นได้ ( ต้องวาดเหมือนมากๆ ) แล้วสามารถควบคุมร่างของเจ้าของวิญญาณได้ตามใจ โดยสามารถใช้ความสามารถต่างๆได้ถึงขีดสุด.. จำนวนที่เรียกได้ขึ้นอยู่กับความสามารถของบุคคลที่เรียก.. ( ถ้าพวกกระจอกก็เรียกได้หลายตัว แต่ถ้าตัวเก่งก็เรียกได้ทีละ2-3ตัวเท่านั้น )

- ลำดับการใช้งาน -
เรียกภาพวาด ( อัดกรอบไม้อย่างดี 8) ) ออกมาจากความว่างเปล่าก่อน.. จากนั้นจึงเรียกร่างของบุคคลนั้นๆออกมาจากภาพวาด.. ซึ่งขณะใช้งานอยู่ภาพวาดจะลอยคว้างอยู่บริเวณผู้ใช้..

เงื่อนไข - การสามารถควบคุมร่างของบุคคลได้ต้องใช้วิญญาณของปิศาจร้าย ( ซึ่งเรียกออกมาจากภาพเหมือน ) จึงจะสามารถควบคุมได้.. กล่าวคือหากสามารถขับไล่วิญญาณออกจากร่างและทำลายภาพวาดได้ผู้ถูกสิงสู่จะถูกปลดปล่อย.. หรือไม่ก็สามารถขับไล่วิญญาณร้ายก่อนจะถูกสิงสู่ได้พลังพิเศษนี้ก็จะไม่เป็นผลเช่นกัน.. ในกรณีที่ร่างกายของผู้ถูกสิงสู่ถูกทำลายหรือเสียหายจนถึงแก่ชีวิต.. ทั้งวิญญาณร้ายและวิญญาณของผู้ถูกสิงสู่จะหายไป.. ( หรืออีกนัยหนึ่งก็คือตายนั่นเอง )

6.* - อยากได้บทอย่างไร - ตอนแรกตัวร้าย ( ใช้ความสามารถของจิตรกร )หลังๆจะอยู่ฝ่ายตัวเอก.. ( ใช้ความสามารถของAssassin )

7.* - เพื่อน - ก็เหล่าตัวเอกแหละครับ.. แต่ช่วงหลังๆที่เข้าฝ่ายตัวเอกอ่ะนะ^__^a"~*
