Tip วิธีดูแลรักษาคอมพิวเตอร์เบื้องต้น

โพสต์แล้ว: อาทิตย์ 22 มี.ค. 2009 8:02 pm
โดย ECO
อันนี้ผมจํามาจาก รายการOS ช่วง ซอกหลืบออนไลค์ ของพี่ตุ้ย กับพี่ ละอองดาว

เค้าบอกว่า

วิธีแก้ คอมพิวเตอร์เบื้องต้น

1.ควรสแกนdiceต่างๆ dice C dice D พวกนี้อ่ะครับ

2.จัดวางเรียงไฟล์เรียบร้อย

3. ติดตั้งโปรแกรมอันตี้ไวรัส

แล้วพี่ตุ๋ยบอกว่าผมมีประสบการณ์ เพื่อนผมมันเครื่องร้อน เครื่องcpuมันร้องวิธีแก้

ง่ายๆครับอาบน้ำให้มัน แล้วต่อจากนั้น ภาพจะขาดหายไป (อันนี้มุขของพี่ตุ๋ยนะ)

ดึงเคสออกมาแล้วเอาเครื่องดูดฝุ่นมาดูดฝุ่นออก แล้วแรมก็ติดไป นั้นแหละความจําม่ะมี

(มุขของพี่ตุ๋ยอีกเช่นกัน)

เข้าสาระแล้วนะ

ดึงเคสออกมาแล้วปัดฝุ่นใช้ผ้านะ แล้วดึงแรมออกมา แล้วใช้ยางลบ ลบตรงขั้วมัน

แต่มีเจ๋งกว่านั้น ใช้ริบควิบเปเปอร์ ลบครับ (พี่ละอองดาวเล่นมุข)

แค่นี้อ่ะครับ แต่อย่าลืมนะน้องๆ ดูแลคอมแล้วอย่าลืมดูแลตัวเองนะน้องๆ (พี่ละอองดาวพูด)

แค่นี้อ่ะครับวิธีดูแลรักษาคอมพิวเตอร์เบื้องต้น จะได้ไม่มีเสียง บีบ เสียงตี้ด เสียงพวกนี้

อ่ะครับ


เครดิต ช่วงซอกหลืบออนไลค์ รายการOs
