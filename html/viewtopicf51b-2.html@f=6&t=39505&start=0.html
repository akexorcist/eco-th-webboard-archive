ต่อเน็ตใหม่แปปเดียว IP ก้อไม่เหมือนเดิมแล้วค่ะ =w=

มีทางเดียว ก้อคือต้องเข้มงวดกะการสมัครเมมบอร์ดให้มากกว่านี้หน่อย เช่นให้ยืนยันเมล์ หรือไม่ก้อบังคับให้ใช้ ID เดียวกะเกมส์ไปเลย นี่แค่ส่วนนึงนะคะ จริงๆแล้วยังมีวิธีกันได้มากกว่านี้อีกเยอะ

ถึงคุณตัวปัญหา บอกตรงๆเลย ไม่ใช่ว่าไม่ชอบนะคะ ที่คุณเอามาแจกน่ะ (มันเป็นธรรมชาติของมนุษย์และสัตว์โลก :oops: ) แต่ถามว่ามันเหมาะสมมั้ย ถูกกาละเทศะมั้ย อันนี้ก้อน่าจะตอบได้ค่ะ


อยากจะแจกไม่ว่า แต่ขอให้มันเหมาะสมหน่อย แจกในที่ที่ควรแจก หรือจะหลังไมค์ PM ตามรายบุคคลเราก้อไม่ว่า แต่อย่าให้มันโจ่งครึ่มแบบนี้ คนเดือดร้อนไม่ได้มีแค่บริษัทอย่างเดียวแต่รวมไปถึงคนที่ใช้บอร์ดหลายๆคนด้วย เราพูดดีๆ หวังว่าจะเข้าใจนะคะ

แต่ถ้ายังทำต่อก้อคิดได้อย่างเดียวแล้วล่ะค่ะว่าไม่ได้ตั้งใจเอามาแจกหรอก แต่ตั้งใจมาก่อกวนเพื่อความสนุกมากกว่า (แล้วนิสัยที่สนุกอยู่บนความเดือดร้อนของคนอื่นนี่ ภาษา IT คนไทยเค้าเรียกว่าอะไรคงรู้ๆกันอยู่นะ...)
