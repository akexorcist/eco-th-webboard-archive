1.คุยกับไทนี่หน้าโรงหนัง 3


2.เข้าไปในโรงหนังเพื่อซื้อตั๋ว PV มาโดกะ

อันนี้

3.เข้าไปดู PV มาโดกะจนจบ(ฉายเวลา .40 ของทุกชั่วโมง)(ต้องเข้าในห้องฉายก่อนเวลาไม่งั้นเข้าไม่ได้นะเอ่อ)


4.ออกมาคุยกับไทนี่ข้างนอกโรงหนังเพื่อรับการ์ดมาโดกะมา

เพิ่มอะไรไม่รู้ 200 แหนะ

5.คุยกับไทนี่อีกทีแล้วไปที่อัพทาวน์แล้วคุยกับคิวเบย์(ถ้ายังไม่ได้ดู PV มาโดกะมันจะไม่โผล่มานะ)

ตรงจุดแดงๆนี้

6.ล่า Grief Seed ที่ตกจากปูรูรุสีรุ้ง



7. Grief Seed 5 อันสามารถมาแลกกล่องได้หนึ่งกล่อง(แลกได้ไม่จำกัด)

การเปิดกล่องคล้ายๆเปิดตั๋วมันสุ่ม
ของที่สามารถเปิดได้
-เสื้อนักเรียน
-กางเกงนักเรียน
-กระโปรงนักเรียน
-ยาชุบ
-ยาเขียว(แก้สถานะผิดปกติทุกอย่าง)
