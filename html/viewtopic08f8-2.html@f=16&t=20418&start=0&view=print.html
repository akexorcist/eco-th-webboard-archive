1. เรื่อง Pet ก่อนเลย Pet ประจำอาชีพ Tatarabe,Blacksmith
สัตว์เลี้ยงคู่หูของ Tatarabe ก็คงต้องเป็นหนอนขี่ กับเนโกะ หล่ะนะครับ
-หนอนขี่ ก็คงต้องสำหรับทาทาที่เป็นสายหาแร่เก่งๆนะครับ
-เนโกะ ก็คงต้องเป็นทาทาที่ฝึกหัด หรือเกบเวลนะครับจะทำให้เกบเวลได้ง่ายขึ้นเพราะมี Pet ของ บัพ ฮิล ชุบ ให้ตลอด
สัตว์เลี้ยงคู่หูของ Blacksmith ก็คงต้องยกให้กับ ปืนใหญ่เลยครับ แต่จะเป็น A หรือธรรมดา ก็แล้วแต่หล่ะครับ
แต่ถ้าจะให้เหมาะสมควรเป็นแบบธรรมดาจะดีกว่าเพราะว่าชุดของอาชีพ Blacksmith นั้นเป็นชุดอออกสี ส้มๆ เขียวๆ
แต่ถ้าจะให้เก่งก็ต้องเป็นแบบ A นะครับเพราะว่าค่า Max เยอะกว่า แล้ว Status เริ่มต้นเยอะ2. เคล็ดลับการอัพ Skill และ Status
-การอัพ Skill ของ Tatarabe ก็ให้อัพสกิล ItemRefine Max HighlyRefine Max MetalwareKit Max เพราะว่าอาชีพ Tatarabe นั้นคงเข้าใจกันดีว่าเป็นสายขุดควรอัพสกิลที่เป็นสกิลสร้างของ ประดิษฐ์ ของจะเป็นอันดี ส่วน Skill โจมตีนั้นก็แล้วแต่ว่าจาอัพอันไหนนะ
-การอัพ Skill ของ Blacksmith ก็ควรจะอัพ RockAnalysis Max WeaponCreate Max ProtectionCreate Max ถ้าจะเลี้ยง Pet ปืนใหญ่ก็อัพ Skill ConcentratedShooting Max Diffused Shooting Max นะครับแต่ถ้าไม่เลี้ยง Pet ปืนใหญ่ก็เอา Potion ที่มีอยู่ไปอัพ Skill โจมตี
-การ Status ของ Tatarabe กับ Blacksmith
จะมีอยู่ 3 สายคือ สายหลบ สายถึก(ป้องกันเยอะ) สายโชคลาภ
-สายหลบ ก็ให้อัพ Str Dex Agi เน้นStr Agi Dex ตามลำดับ สายนี้จะเป็นสายที่หลบเก่ง เลือดน้อย โดนเบา จะเก็บเวลยากตอนแรกๆเพราะเลือดน้อย จะทำให้ตายง่าย แต่พอหลังๆจะเกบเวลง่ายเพราะว่าหลบได้บ่อย
-สายถึก ก็ให้อัพ Str Dex Vit เน้นStr Vit Dex ตามลำดับ สายนี้จะเป็นสายที่เลือดเยอะ โดนแรง และจะแบกของได้เยอะ ตอนแรกๆจะเกบเวลง่าย พอช่วงเวล35จะเก็บเวลยากถึงขนาดว่าตัวนึงเก็บได้5เวลเลยก็ว่าได้ เพราะช่วงหลังๆเลือดจะเยอะแต่หลบไม่ได้เลยแล้วโดนตีแรง มอนเตอร์เวล40+จะตีแรงมากถ้าหลบไม่ได้ก็จบ เลยตอ้งเกบเวลกับมอนเตอร์เวลน้อยๆ
-สายโชคลาภ สายนี้จะทำให้ดรอป หิน แร่ คริสตัล ได้ง่ายแต่สายนี้จะไม่เก่งในด้านเกบเวลเพราะว่าจาเก็บเลเวลยากมาจึงต้องแบ่งออกเป็น 2 ประเภท
-ประเภทหลบ ก็อัพ Str Agi Dex Luk ตามลำดับ สมมุติว่ามีให้อัพ 20 ก็อัพStr8 Agi5 Dex4 Luk3 เพราะถ้าอัพแต่ Luk อย่างเดียวก็เท่ากับว่าไม่มีประโยชน์
-ประเภทถึก ก็อัพ Str Vit Dex Luk ตามลำดับ มีให้อัพ 20 ก็อัพStr8 Vit6 Dex3 Luk3
