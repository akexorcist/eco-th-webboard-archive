(ไม่เหมือนเกรียนบางคน โพสถาม มาโพสด่า กรุณาค้นหาก่อน เค้าหาแล้ว มานไม่เจอ)

ขอบคุงพี่ -คนหน้าตาดี- ในเรื่อง สกินด้วยค่ะ สกินสวยมากเลย เปนกาตูนญี่ปุ่ง ตรงใจเป๊ะๆ><

ขอบคุงพี่ Amestris ที่ช่วยตอบคำถามในเรื่องเควส จ้า <<น่ารักเหมือนกาน

ละก็ขอบคุงพี่ NewLegend ที่ตอบคำถามในเรื่อง ไอเทมจ้า :wink:

ละก็ขอบคุงพี่ chekalzz ที่ทำกาทู้ของเรนเจอให้จ้า สกิลละเอียดมากๆเลย ตอนแรกเกือบอัพพวกสกิลanlysisไปแย้ว เหนในเว็ปบอกเพิ่มประสิทธิภาพในกานหาของเนี่ยแหละ ก็พอได้อ่านกาทู้ของพี่แล้ว เลยได้รู้ว่า พอใช้ใส่มอน จะทำให้ เวลาคนอื่นมาตีมอน จะดอบของปราชญ์ เลยมะได้อัพ อัพแชร์ปราชให้เพื่อนในตี้ ดีก่า ละก็ พอกดลิ้งของเค้าไป ก็เลื่อนขึ้นไปดูข้างบน จะมี เหมือนกะว่า กล่องอะไรหาจากไหน คอนเทนเนอ อิอิ ไม่ต้องไปถามใครให้เสียเวลาเลย ขอบคุงค่ะ:wink:

ก็ ขอขอบคุณไว้ ณ ที่นี้นะจะ

เกมECO เปนเกมที่ให้ความสุขมากเลย ตั้งแต่เล่นมา

ภาพสวย ชุดสวย ถึงแม้ จะเจอเกรียนไล่อาฆาต ฮือๆ เบลดจ้อบ50 ไปโพสในบอดขอความช่วยเหลือ ไม่มีไคช่วยเลย มีแต่คนมาโพสว่า ให้ใจเย็นๆ ให้ตีไป เด๋วเกรียนมันก็จาไปเอง ก็มานไม่เซ็งหรอก มานจาเกบเลเวล แต่มันจาได้เปอจากการแจมมอนที่เค้าตีด้วยอะ T^T

แต่ก็มีเพื่อนๆทุกคน คอยช่วยเหลือในทุกๆเรื่อง

จะต้องเปนเทรเชอฮันเตอที่เก่งๆเหมือนคนอื่นเขาให้ได้เลย อิอิ
