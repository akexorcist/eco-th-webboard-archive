- Lightning Spear
Animation : Lightning Spear
Skill Type : Attack Single Enemy (Physic Damage - Stab)
Range : 1
Weapon require : All Melee Weapon
Can learn at : JobLV. 1
Detail :
สกิลเลเวล 1 ความแรง 130% ใช้ 3 SP ใช้เวลาร่าย 1.0 Sec
สกิลเลเวล 2 ความแรง 150% ใช้ 4 SP ใช้เวลาร่าย 1.0 Sec
สกิลเลเวล 3 ความแรง 170% ใช้ 5 SP ใช้เวลาร่าย 1.0 Sec

สกิลเลเวล 5 ความแรง 210% ใช้ 7 SP ใช้เวลาร่าย 1.0 Sec

Comment : ใช้ SP น้อย แต่ความแรงต่ำ สามารถใช้งานได้ดี แต่เมื่อเลเวลสูงจะมีสกิลอื่นที่ใช้งานแบบเดียวกัน แต่ดีกว่าให้เลือกใช้ เช่น Blow, Banish Blow, Divine Spear ฯลฯ
