Porphyryl เขียน:str agi กับ str dex คิดว่าใครตายง่ายกว่ากัน?



ถ้าพูดถึงสาย Banish นะ โดยทั่วไป Str Dex จะฆ่าเร็วกว่า เนื่องจากตีโดน + แรง ทำให้มีโอกาสตายน้อยกว่า แต่ต้องดูที่มอน+เวล ด้วยนะ

ถ้ามอนเป็นสาย Spell : ตายพอๆกัน เทียบมะได้
โดนเวทย์ไปก็หนีทั้งคู่ละคับ แต่ Str Dex ได้เปรียบ เพราะ One Hit Kill !!

ถ้ามอนเป็นสาย Agi ( ฟันเร็วๆ )
ถ้ามอนเวลสูงกว่า : Agi จะตายเร็วกว่า
เพราะ Str Agi จะตีมันไม่ค่อยโดน กับโดนมีตีบ่อย / Str Dex จะทำ Damage ไวก่า เลยฆ่าได้เร็ว
ถ้ามอนเวลต่ำกว่า : เทียบไม่ได้ครับ เพราะ Dex จะฆ่าไว + Agi จะหลบได้

ถ้ามอนเป็นสาย อัดแม่นๆ + หนัก ( เช่นหุ่นยนต์ ) : Agi มะไหวคับ
Str Dex ยังพอไหว แต่ก็หนักหนาสาหัส

ถ้ามอนเป็นสายลุม : อันนี้ก็ดับทั้ง 2 เลยคับ ^^

---------------------------------------

ถ้าเทียบกับตีมอนปกติ สาย DEX ดับก่อนแน่นอนครับ
