โพสต์แล้ว: อังคาร 12 พ.ค. 2009 9:53 pm
โดย ECO
เปิดดันครั้งหนึ่ง ใช้แต้มเควส 3 แต้ม คงเยอะพอดู
ถ้าบางคนเฮิร์ท เวลวันละ 3-5 ดัน คงไม่พอแน่
ลองเอาตัวละคร ที่เราไม่ใช้ แต่เวลสูงพอที่จะเปิดดันได้
พอเปิดดันเสร็จ ก็ออฟตัวละคร นั้นไป
เวลาเควส ก็จะหยุด
แต่ดัน ก็อยู่ได้แค่ 3 ชั่วโมง
พอมันล่ม เราก็เข้าตัวที่ใช้เปิดดัน
แล้ววิ่งเข้าวาป เปิดดันใหม่
แล้วกดออฟ ไป แค่นี้
ก็ ประหยัดแต้มเควส แล้วครับ
