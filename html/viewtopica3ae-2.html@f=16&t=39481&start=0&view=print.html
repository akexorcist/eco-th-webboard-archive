สกิล Picnic ทาทา ไม่มีนี่นา(ถ้ามีก็คงมีแต่ทาทายัง) Picnic เป็นสกิลของเรนเจอร์นะ เวลาใช้สกิลถ้านั่งไม่ถูกจุด HP/MP/SP จะขึ้นไวกว่านั่งธรรมดานิดหน่อย แต่ถ้านั่งตรงจุด อย่างเช่น มุมล่างของบันไดที่แมปชินนามอน หรือนั่งติดผา หรือตามทางลงเนิน
HP/MP/SP จะขึ้นไวมาก ผมก็อธิบายจุดนั่งไม่ถูกเหมือนกัน บางที่ถ้าเป็นหินสองก้อน แล้วเราเข้าไปนั่งมันก็จะถูกจุดเหมือนกัน อย่างแมปโมโม พอเข้าแมปลองไปทางซ้ายที่จะมีคอก อยู่สังเกตุจะมีหินสองก้อน อยู่ทางซ้ายลองไปนั่งดูก็ถูกจุดเหมือนกัน
