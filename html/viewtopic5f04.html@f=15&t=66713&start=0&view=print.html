สกิืว limit ทั้งหลายเป็นสกิวที่เพิ่มคุณสมบัติธาตุในร่างกาย
พูดให้ง่ายก็คือ คล้ายๆกับใส่โล่ธาตุให้กับตัวเอง
สรุปก็คือ มีผลกับตอนโดนโจมตีเท่านั้น...ไม่มีผลกับสกิวที่ร่ายออกไป


แต่ถ้าอยากคลื่นแรงๆ
็ก็อัพสกิวสีฟ้าๆ (ธาตุน้ำ) เยอะๆ อ่ะ
เห็นว่าในวิกิบอกมา ว่าความแรงของ tsunami ขึ้นอยู่กับสกิวธาตุน้ำที่เคยเรียนมา
((ถ้าแปลตรงๆ ก็น่าจะหมายถึง ยิ่งมีสกิวธาตุน้ำมากเท่าไหร่ ก็ยิ่งแรงขึ้น))
