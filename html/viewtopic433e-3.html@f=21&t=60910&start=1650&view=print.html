โจุ๊กกรู้ก


เติมประโยคคั่นก็ได้มั้ง โควได้ยก โควนั้นยก โควรีบยก โควจับกระบอง ฯลฯ

ดูท่าทางเจ้าตัวนั้นมิได้สนใจกับคำกล่าวว่า ‘ นังปีศาจ ’


ถ้าไม่นับยัยปีศาจนั่น


นับว่าผิดมิ = w=

“ ถ้าให้ฉันพูดตามตรงล่ะก็ ... ”

“ เจ้านี่แหละ เก่งที่สุดแล้ว ... ”


ใส่อากัปกิริยาซักนิด เผื่อให้บางคนได้รู้ว่าเอ้ยถึงใคร น่าจะดี

โลหิตพวยพุ่งขึ้นมาจากพื้นดินบริเวณที่โจุ๊กกรู้ืนอยู่


บุ่ยๆ

ไอร้อนระอุรุนแรงมหาศาลมากเสียจนโควต้องหลับจาลงเพราะไม่


หลับจา หลับเหยือก ? (Jar)

“ ( หลบไม่ทันแล้วเว้ย ! ) ”


คำประเภทนี้เป็ฯลักษณะของคำอุธานมากกว่า เปลี่ยนไปใช้เป็น (ขออภัยหากหยาบ) "ชิบหายแล้ว หลบไม่ทันแน่"

ปีกเทวดาอันแสดงถึงเผ่าพันธุ์ปรากฏอย่างเด่นชัด


ลืมวงแหวนบนหัวนะงิ แต่ถ้าจะให้ดี ก็ต้องอธิบายถึงวงแหวนด้วย

เพราะไททาเนียจะมีวงแหวน ที่เป็นตัวบ่งบอกระดับชั้นของตัวเองอยู่ ซึ่งจะชัดกว่าปีก

ใครอยากรู้ ไปสังเกตุ ทิทา แล้ว ไททัส ในเกมดู

รวดเร็ว ...


อันนี้คงหมายถึง ความรู้สึกของ จีพีสินะ แต่ถ้าจะให้ได้อารมกว่า ใช้เป้นเสียงของเหตุการ์ณที่เกิดขึ้นท่ามกลางความรวดเร็วจะได้อารมกว่ามากกก (คนจะงง อะไรฟะ แล้วก็อ่านคำอธิบายทีหลัง)




“ ... หากมิเอ่ยนามแก่ผู้วายชนม์คงมิใช่วิสัยของเราเสีย ” วาจาอันอ่อนโยนหากแต่ฟังดูเยือกเย็นจนน่ากลัวถูกเอื้อนเอ่ยด้วยน้ำเสียงของ หญิงสาวปริศนา “ นามของเราคือ ”

“ ซิลเวีย ซิลเวอร์วิง ”


สปอยความคิดส่วนตัว ไม่อยากอ่านจงอย่าลาก

คาดว่าเป็นอีกด้านหนึ่งที่แยกออกมาชัวๆ เนื่องจากซิลเวอ เป็นลูกครึ่ง ไททา และ โดมิ (ภาค 1 อยู่ในร่าง ไททา ถ้าจำไม่ผิด)

จิตสำนึกทั้ง 2 ในสายเลือดที่ขัดกันเองแล้วทำการแยกตัวออกเป็นเอกเทศ (ส่วนมากพลังจะอยู่กะฝ่ายมืดซะหมด)


สงครามแห่งแรคนารอคอุบัติขึ้นพร้อมกับเสียงกรีดร้องแห่งวาทยากร


ได้เห็นศาตรา แห่ง เทพ แรคนาร็อค แน่ๆ คราวนี้ อยู๋ที่ว่าใครจะถือ ใครจะใช้ (แอบลุ้ให้ เรดซิสล์ ใช้ Rudra Bow)
