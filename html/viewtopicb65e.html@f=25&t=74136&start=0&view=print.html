ลองๆไล่ตามขั้นตอนเควสดูก่อนครับ ว่า ไปติดตรงไหน และ แต่ละเควสค้างตรงไหน

*************************

จากที่อ่านดู สรุปคือ ตอนนี้ กำลังทำเควสอันสึอยู่ ( ยังอยู่ในร่างอันสึ )

แล้วทีนี้ ไปเจอเควสแมวแฝดมาแทรก เลยไปทำเควสแมวแฝดก่อน

แล้วได้แมวแฝดมารึยังอ่ะครับ ถ้ายัง แนะนำว่า ลองเอาตัวอื่นในไอดีนั้น

ไปเริ่มทำเควสแมวแฝดใหม่ น่าจะได้อยู่ จากนั้นก็กลับมาที่ตัวที่ทำเควสอันสึ

ที่ค้างอยู่ ถ้าต่อได้ก็ทำต่อไปได้เลย แต่ถ้ายัง.....ลองกลับไปคุยที่ Tonka อีกรอบนึงครับ

ตรงจุดที่รับเควสอันสึมาอ่ะ บางทีมันอาจจะบอกเบาะแส หรือบอกให้เราไปหา NPC

ตัวอื่น ซึ่งอาจจะทำให้ดำเนินเควสต่อไปได้ครับ
