ผมเอาเอเลไปสวิทจอบตอนจอบ 50
พอสวิทเสดเเล้วคลื่นเบาลงมากๆ ถึงมากที่สุด
จากปกติยิงงู 1000-1300 ยิงผัก 400-500 (ในดัน70)
ตอนนี้ยิงงู 700-800 ยิงผัก 300-400 เอง
ตอนสวิทเเล้ว เอาสกิล ไอซี่ สตรอมน้ำ/ลม เซน คลื่น

อยากรู้ว่ามันเบาลงเยอะไปไหม (ส่วนตัวผมคิดว่ามันเยอะมาก)

*พอบัฟให้โบนัสเท่าตอนเอเลจอบ 50 ก็ยังยิงเเรงไม่เืท่า
**ผมใช้ตัวโซลชุดเดิมตลอด
