ranger ไม่มีสกิล refine ครับ
skill refine เป็นสกิลเฉพาะของชาวนา แต่ที่โผล่มาที่ tatarabe กับ ranger ตอนนี้เป็นบั๊ก เจ๊ซิ้มโบ๊ะเคยแจ้ง GM ไว้ในบอร์ดหมวดแจ้งบั๊กนานแล้ว

เวบหลักของญี่ปุ่น ranger ก็ไม่มีสกิล refine นะครับ
http://www.econline.jp/data/job/1st-base/job_b03.html

แต่ถ้าไปดูที่ wiki จะมี ซึ่งข้อมูลที่ wiki มันเกิดจากการ update ข้อมูลร่วมกันของคนทั่วไปครับ เชื่อไม่ได้ทั้ง 100% ควรดูเวบหลักมากกว่า

ปัญหาคือ เวลาเค้าแก้ไขบั๊กตัวนี้อะครับ เค้าจะคืน skill point ให้ไหมสำหรับคนที่อัพไปแล้ว ผมเองก็ยังระแวงจุดนี้อยู่เลยไม่อัพไป


53xmax เขียน:Tent มันทำไรได้หรอครับ ถึงต้องมีไอเท็มด้วย


กางเต๊นท์แล้วจะเข้าไปหลบอยู่ข้างในได้ครับ จะเหมือนเข้าเมือง คือ hp/mp/sp ฟื้นไว
เอาไว้พักหรือเอาไว้หลบเวลาโดนมอนฝูงใหญ่ๆไล่ตามในดันเจี้ยนครับ -.-
จำนวนคนที่เข้าไปอยู่ในเต๊นท์ได้จะมากขึ้นตาม skill level
item Tent จะมีความทนทานอยู่ ถ้าทนทานหมดก็พัง ถ้า skill level สูงๆ โอกาสพังเวลาใช้ก็น้อยลงด้วยครับ
