ถ้าจะหลอมของที่เคยเอาหมาหลอมแล้วกับภาพใหม่จะได้ไหมครับ

หมายความว่า สมมุติ
เอาเกราะ 65 มาหลอมเป็นภาพเสื้อยืด -> ได้ภาพเสื้อยืดแต่คุณสมบัติเป็นเกราะ 65

แล้วยังสามารถเอา ภาพเสื้อยืดแต่คุณสมบัติเป็นเกราะ 65 มาหลอมต่อเป็นภาพเสื้อรอยสักได้หรือไม่ครับ

คือหลอมซ้ำภาพใหม่คุณสมบัติเดิมครับ
