โรงเรียนพระราชาอโครเนีย

นี้คือนิยายแบบเล่ากันสดๆเปิดให้คุณผู้อ่านเล่นด้วยได้ไม่จำกัด เรื่องราวสุดป่วน การบู้ล้างผลาญแบบเลือดสาด ไม่ใช่แค่รักหวานหรือเศร้าๆ ไม่ใช่แค่โรงเรียนเวทย์มนย์ แต่การเรียนทุกรูปแบบ ที่ไม่มีที่ไหนในโลก กับความสนุกแบบป่วนๆเล่นกันเอง ตามแบบฟรีสไตรท่าน ยิ่งคนเยอะยิ่งมันจริงๆ ถ้าเราอยู่ด้วย

ประกาศ ไม่ต่องลงทะเบียนเรียนแล้ว แต่งแนวไหน แล้วแต่ท่าน วิชาเรียนคิดกันเอาเอง
ชี้แจง แจมกันได้เลย ยิ่งแบบหลุดโลกชนิผม่ไม่กลับก็ได้

กติกา คล้ายๆกับของเจ๊เทียร์ แต่เรื่องเป็นยังงี้
กฎ – กติกา การเล่นนิยายสด


1. คุณสามารถควบคุมกริยาและคำพูดได้แค่ตัวละครที่อยู่ในสังกัดของคุณเท่านั้น ส่วนผู้ร่วมเล่นคนอื่นไม่สามารถที่จะให้ตัวละครของคุณพูดหรือว่าแสดงกริยาใดขึ้นมาได้ ( นอกเสียจากมีการนัดแนะกันทาง PM แล้ว )


2. การแสดงออกของตัวละครรวมทั้งคำพูดนั้น ควรจะมีเหตุผลที่พอรับได้ ไม่ใช่ว่าจะฆ่าได้หรือว่าทำอะไรไร้เหตุผล หรือว่าอาจจะกระทำสิ่งใดก่อน เช่นเข้าโจมตี ก็ขึ้นอยู่กับว่าอีกฝ่ายนั้นต้องการจะทำเช่นไร ( อาจจะตอบโต้ หรือว่าอาจจะหนีแทน )


3. การสร้างตัวละคร สามารถมีได้หลายตัว ไม่จำเป็นต้องลงรายละเอียด หากแต่ตอนปรากฎตัวนั้นคุณต้องอธิบายลักษณะหน้าตาและเครื่องแต่งกายของตัวละครออกมาด้วย เพื่อจะได้สะดวกต่อการเห็นภาพของอีกฝ่ายที่กำลังเล่นกับคุณอยู่


4. การสร้างตัวละครขึ้นมาตัวนึงนั้น เวลาเจอกับตัวละครที่ไม่เคยเจอมาก่อน ก็อาจจะเลือกได้ว่าจะแนะนำตัวหรือว่าจะทำเช่นไรก็ได้ แล้วแต่คุณจะต้องการ และการสร้างตัวละครนั้นควรจะคำนึงถึงเรื่องความเหมาะสมด้วย ไม่ใช่ว่าจะเก่งเกินไปอะไรเช่นนี้ และการสร้างตัวละครที่มากกว่าหนึ่งตัว อาจจะให้มีความสัมพันธ์อยู่แล้วกับตัวละครตัวเก่า หรือว่าไม่เคยพบกันเลยก็เป็นได้


5. การคุยกันเองระหว่างตัวละครในสังกัด สามารถทำได้ และการพูดหรือกล่าวถึงตัวละครของผู้อื่นนั้นก็สามารถทำได้ด้วยเช่นกัน หากแต่เราไม่สามารถควบคุมอะไรได้


6. หากอีกฝ่ายที่กำลังต่ออยู่กับคุณนั้นหายไปโดยไม่บอกกล่าว อาจจะทำการตัดไว้ก่อน และข้ามเหตุการณ์ช่วงนั้นเพื่อกลับมาต่ออีกทีตอนหลังก็สามารถทำได้

บทแรก

เริ่มต้นจากฝนห่าใหญ่ที่กระหน่ำลงมาไม่มีทีท่าหยุดหย่อน หลั่งทะลักไม่ทันตั้งตัว
เกวียนเล่มหนึ่ง ถูกเทียมด้วยเรดดราก้อนถูกลากมาเรื่อย ภายใต้บรรยากาศ
"ที่นี่สินะ โรงเรียนพระราชาอโครเนีย" ตามด้วยเสียงเอ่ยดังขึ้นของเด็กสาว

ไม่นานนักฝนเริ่มซาลงแล้วหยุดลงไปเรื่อยภาพตรงหน้าคือทางเข้าปราการอโครเนีย แววตาสีฟ้าจ้องมองภาพตรงหน้าปราการที่สูงตระหง่า
ไม่นานนัก
"ลิลลี่!!"
เสียงทักจากคนข้างหลัง ทำให้เจ้าตัวสะดุ้งโหยงพลางหันเหลือไปมองข้างหลัง พลางมีรถศึกขนาดใหญ่เข้ามากระกบข้างๆ ไม่ใช่ใครอื่น นอกจาก วิเวียน เดอะ วอริเออร์ ออฟ คนโนวาล ในมาดเจ้าชาย
"พาหนะของเธอยังดูดีเหมือนเดิม" เจ้าของนัยน์สีแดงพลางยิ้มร่าพูด ก่อนจะเอ่ยขึ้นมาอีก
"ผิดกับของฉันลิบลับ"พลางสายตาเหลือมองเจ้าสัตว์พาหนะตรงหน้ามันคือ

ลาแก่ๆตัวหนึ่ง..
นัยน์ตาคู่สีฟ้าเหลือบหันมามองพลางคิกคักในลำคอก่อนจะเอ่ยขึ้น "อย่าดูถูกรถศึกของนายสิ"พลางทำสีหน้าหงุดหงิดก่อนจะเอ่ยอีก
"ถึงจะเป็นแค่ลาแก่ๆ แล้วทำไมงานแข่งระหว่างเมืองของเราตอนนั้น ลาของนายยังวิ่งเร็วกว่าม้าเข้าเส้นชัยตัวแรก"

เจ้าตัวดีได้ฟังก็หัวเราะก้ากก่อนเอ่ย"แนวดีไหมล่ะเพราะฝึกมาดี เขาว่าขิงยิ่งแก่ยิ่งเผ็ดนะ"
ก่อนเด็กสาว เดอะ ปริ้น ออฟ เวนอลจะเอ่ย "นั่นสินะดูถูกไม่ได้ งั้นขอถามนายละกัน ว่าหัวใจของพระราชากับพลทหารอยู่ที่ไหน"

"ก็ต้องสัญลักษณ์ของประเทศตัวเองอยู่แล้ว หรือไม่หัวใจของกองทัพก็อยู่ที่แม่ทัพนั่นแหละ"เขาย้อนพลางถอนหายใจเฮ้อ

"ผิด"เด็กสาวยิ้มก่อนจะหันมาเอ่ย

"ไม่ว่าจะราชาหรือกองทัพ ที่ไหนจะรบชนะได้ ถ้ากองทัพไม่เดินด้วยท้อง"เจ้าเด็กสาวตัวดีเอ่ยก่อนจะคิกคักก่อนพูดอีก "แล้วนายจะลงวิชาอะไรบ้าง วิเวียน"

"ก็ฉันฉายาว่า วอริเออร์อยู่แล้ว ก็ต้องดาบเป็นหัวใจหลักสิ"
ก่อนที่เด็กสาวจะหันมายิ้มเปรย "อย่างนายนี่นะ เจ้าคนกึ่งเดียว"

เจ้าตัวดีหัวเราะหึหึก่อนจะเอ่ย "ฉันผู้ชายทั้งแท่งแล้วนะเว้ย" ก่อนจะก้มลงอย่างเศร้า พลางถอดกำไลมือ ออก
วู้บ!! ทันใดนั้น โฉมหน้าของเจ้าชาย นาม วิเวียน เดอะ วอริเออร์ ออฟ คาโนวาล ก็เปลี่ยนไปกลายเป็นใบหน้าที่สวยอรชร ผิวพรรณเปล่ง ใบหน้าตาบ่งบอกถึงเพศที่แสนน่ารัก ก่อนจะเอ่ย
"เธอว่า"(เสียงผู้หญิง)
พลางสวมกำไลมือเขาไปต่อ วู้บ!! ทัยใดนั้นก็กลับเป็นอย่างเดิม
"มันแตกต่างกันตรงไหน"

เด็กสาวหัวเราะก๊ากเล็กๆก่อนจะเอ่ย
"ต่างแต่รูปร่าง จิตใจก็ยังคงเด็กผู้หญิง"

เจ้าชายหันมากล่าวต่อ
"ชิ ยัยบ้า ฉันลูกผู้ชายทั้งแท่งนะเว้ย!! "

ก่อนที่เจ้าตัวดีเถียงกลับ
"ก็แค่ถูกเลี้ยงมาแบบนั้นนั่นแหละ พ่อของนายนี่จริงๆเลย"
พลางหันเหลือบไปมองพ่อค้าที่ขายของอยู่ข้าง ก็ต้องเอ่ยถึงขึ้นช็อค เมื่อเห็นบางอย่าง
"แว่นกันแดดบ้าอะไรเนี่ย ราคาตั้ง 2.5ล้าน G "

ก่อนที่เจ้าพ่อค้าจะเอ่ย
"อะไรกันราคาพิเศษสุดแล้วนะแม่คุณ แว่นจีเอ็มชั้นยอดเลยนะขอบอก"

เด็กสาวคิกคักในลำคอก่อนจะเปร่ย
"เนี่ยนะ ขอชั้นยอด บ้านฉันยังแค่ ไม่กี่ตัง ใส่แล้วก็ไม่เห็นจะดูดีตรงไหนยังกะคนตาบอดขอบอกเลยนะ"

เสียงหัวเราะหึหึก่อนจะเอ่ย
ไม่มีเงินอย่าทำเป็นพูดดีเลย"

ฉึก!! แท่งใจดำ
"ไปเถอะลิลลี่ อย่าไปยุ่งเลยกับคนอับจน"
เด็กสาวหันมาคิกคัก
"ไม่ต้องว่าคนอื่นเลยนายเองก็เหมือนกัน แหละ ประเทศจะล่มอยู่แล้ว ดีนะที่พ่อเราช่วยไว้ ไม่งั้นโดยยุบ นายเลยได้พาหะนะเป็นลาตัวแก่ คอยดูคนอื่นๆที่มาเรียนเหอะ เค้าจะมีสัตว์หรูแค่ไหน"
ก่อนจะคิกคักของวิเวียนลั่นขึ้น
"จะหรูแค่ไหนก็มาเหอะ ไม่เร็วเท่าเจ้า ริกุ ของชั้นหรอก"ก่อนจะทำเบ่งอวดดี
