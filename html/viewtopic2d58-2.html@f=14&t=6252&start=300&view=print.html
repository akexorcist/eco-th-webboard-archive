โดย ECO
Open ผมก็เล่น แอสตัวแรก เหมือนกัน เพราะมันไม่ต้องอัพ agi เยอะ
Solid 7Hit ทุกอย่างที่เปน physical damage กันได้หมด
แต่ที่กันไม่ได้ ก็เป็นพวก ติด mod ( ใบ้ มึน slow miss )
กัน mod อัพ int+vit mdef ช่วยได้เยอะมาก
สกิลติด MOD เกมนี้ ถ้าเปน เล็ง target ฟันไม่โดน ก็ไม่ติด
สกิลติด MOD แบบ AOE คิด Hit ทุกอย่าง ยกเว้น Magic
กับ สกิลจำพวกกาง field แล้ว ติด mod พวกนี้จะโดน 100%
จะกันก็ ต้องเปลี่ยน ธาตุเกราะเอา
ที่ wizard ใช้ solid แต่ โดน stun แบบ AOE ของ bm
เพราะว่า สกิล BM ที่ติด mod คิด SHIT ถึงไม่โดน ดาเมท แต่ก็ ติด MOD
สกิลโจมตี แบบ physical แทบทุกสกิล คิด def+Vit หมด
จำนวนครั้งที่โจมตี ยิ่งมาก ก็ยิ่งหักเยอะ เกมส์นี้ def หน้า สำคัญนะ ไม่ใช่ def หลัง

มันตีไม่โดน ก็ไม่ติดนะ เกมส์นี้ Mod แบบเล็ง target ต้องตีโดนถึงติด
Hit น้อย ฟันไม่โดน ก็ไม่ติด mod นอกจากเปน mod แบบ field + magic
แล้วอยากจะบอกว่า mod เกมส์นี้ ไม่ได้ติด เต็มประสิทธิภาพ 100% นะครับ
stun blow ติด stun 3sec อัพ Vit รวม+ 50 ติดไม่ถึง 2วิเลย
ถึงบอกว่า sunder ติด 8วิ ไปฟันพวก ไนท์ + เบลด vit เยอะๆ ติดแปบเดียวหาย
Vit เกมส์นี้ ทั้งกัน mod ทั้งลดเวลาติด mod เลยนะ หลายคนอาจยังไม่เคยรู้
