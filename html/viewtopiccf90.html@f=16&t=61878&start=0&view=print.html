ตอนผมเดินขึ้นไปเอาแต้มสกิลนี่วิ่งย่องขึ้นไปอย่างช้าพร้อมกับมองระยะสุดขอบจอไปเรื่อยๆ
ถ้าเจอมอนก็หยุดรอมันเดินไปทางอื่นก่อนเดินมาทางเราก็วิ่งถอยไปไม่ก็ไปทางตีนเขาแทน
จนถึงบนเขานะ นอนไปหลายทีเหมือนกันตอนนั้นยังเวลน้อยอยู่สู้นกแดงไม่ได้

ส่วนวิธีที่แนะนำ(กรณีไม่มีคนนำขึ้นภูเขาไฟและมาริโอเน็ตล่องหน)

กรณีเลเวล30-35(เปลี่ยนตอนjob30ต้นๆ)
แนะนำให้เดินเลียบเขาไปช้าๆนะ ซูมจอออกให้สุดเพื่อจะได้มองเห็นมอนโดยรอบ ถ้ามอน
ขวางก็รอให้มันเดินไปทางอื่นก่อนหรือถ้าแถวนั้นโล่งๆก็เดินไปทางด้านล่างของภูเขาไฟดู
กรณีเจอมอนเห็นให้รีบวิ่งเข้าบ้านพักที่อยู่ใกล้สุดทันที ถ้าเจอนกแดงให้แปลงเป็นมาริโอเน็ต
แล้ววิ่งเลยเพราะนกแดงมันบินไวกว่าคน ถ้าตรงใกล้ถึงซาลามานเดอร์มีนกแดงอยู่ให้ลากมัน
ออกมาโดยแปลงเป็นมาริโอเน็ตแล้วล่อให้มันเห็นแล้ววิ่งกลับไปเข้าบ้านพักด้านล่างรอจนมัน
เดินไปทางอื่นพ้นระยะแล้วค่อยออกไปวิ่งขึ้นภูเขาไฟเลย
*ย้ำว่าให้เดินสั้นๆอย่าวิ่งยาวไม่งั้นโอกาสเจอมอนเห็นมีสูง

กรณีเลเวล36-45
เวลเท่านี้ก็ใช้วิธีเหมือนข้างบนเพียงแต่เราอาจจะสามารถกำจัดมอนบางตัวบนภูเขาไฟได้
ให้พกdry appleหรือยาปั้มแบบไม่มีดีเลย์ไปปั้มสู้ แต่วิธีสู้นี่แนะว่าควรจะสู้ตอนที่มอนมัน
ขวางทางจริงๆและสู้แบบ1-1เท่านั้น ส่วนจะสู้ยากง่ายแค่ไหนก็อยู่ที่สเตตัสของคุณด้วย

กรณีเวล46-50
ใช้วิธีเดินแบบด้านบนแต่จะไม่ต้องระวังตัวมากนักเพราะถ้าเวลได้ขนาดนี้เรียกว่า1-1กับ
มอนบนภูเขาไฟได้ทุกตัวแหละระวังอย่าให้โดนรุมก็พอ
