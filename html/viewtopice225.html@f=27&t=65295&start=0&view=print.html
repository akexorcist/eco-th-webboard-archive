หมีขาว แมพชื่อไรจไม่ได้ อยู่บริเวณซ้ายกลางของแมพ แถวนั้นจะมีป้ายป้นจุดสังเกต

บอสปลา ชั้น5 สุ่มเหมือนกัน ไม่แน่นอน เดินทั่วเลย
