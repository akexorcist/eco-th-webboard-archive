ส่วนแส้น้าน..นะขราบ ฟาดเร็วแต่พลังโจมตีน้านแกว่งเหลือเกิน ...เหล่ามือเก่าจึงนิยมไว้ใช้กับท่าเฉพาะของแส้เท่านั้นขราบ....

ส่วนใอใหม่จะใช้อะไรนั้น ก้อแล้วแต่รสนิยมขราบ ไม่ต้องตามมือเก่าก้อได้ขราบ..ยังไงก้อยังรีได้ เด้ออออออออออออออออ...
