ง่ายๆก็ลองเช็คแชทล็อกก่อนว่าเยอะเกินไปรึป่าว
ที่โฟลเดอร์เกม>>>chat ถ้ามีเยอะก็ลบๆออกไปครับ

อีกกรณีนึงคือสปีดเน็ตต่ำ อันนี้ผมบอกไม่ได้เพราะไม่รู้ว่าใช้เน็ตอะไรอยู่

กรณีที่สามคือเครื่องใช้ process มากเกินไปครับ
ลองกด ctrl+alt+del แล้วดู performance เครื่องดู(ที่เป็นกราฟเขียวๆ)
ถ้าขึ้น 100% ตลอดแสดงว่าเครื่องกำลังทำงานเต็มที่ตลอดเวลา
ให้ไปดูที่ process กด mem usage สองครั้งก็จะเห็นว่ามีอะไรทำงานมากๆอยู่
ถ้าเป็นกรณีนี้จิงลองดูชื่อที่ไม่คุ้น(พวกที่กิน mem สูงมากๆ) แล้วมาโพสดูครับ
อาจเป็นโปรแกรมแอนตี้ไวรัสก็ได้ หรือไม่ก็สปายแวร์

spec เครื่องก็มีผลนะครับ แรมกะการ์ดจอ
