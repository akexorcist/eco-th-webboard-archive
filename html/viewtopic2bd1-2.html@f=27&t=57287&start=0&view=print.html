[GM]KEN เขียน:ถ้ามีไดร์เวอร์การ์ดจอตัวใหม่ที่โหลดมาแล้วก็ให้ไปที่
คลิกขวา my computer >>> properties
เลือกแถบ hardware >>> กด device manager
คลิกตรง + หน้า display adapters
มันจะโชว์รุ่นการ์ดจอเราให้คลิกขวาเลือก uninstall
ถ้าเครื่องรีสตาร์ทเข้าวินโดว์มาอย่ากด yes กด no เหรอยกเลิกไปเลยแล้วไปลงไดร์เวอร์ที่ดาวร์โหลดมา
ลองดูครับติดตรงไหนสามารถสอบถามได้ครับแนะนำมั่นใจก่อนนะว่ามีไดร์เวอร์ตัวใหม่แล้วอยู่จริงไม่งั้น uninstall ไปแล้วไม่มีลงทีนี้หนักครับเข้าไรสีก็จะเพี้ยนนะครับ
