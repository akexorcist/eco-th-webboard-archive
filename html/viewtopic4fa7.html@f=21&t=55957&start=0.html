ปิดโพล สรุปว่ากระทู้นี้ฟิคเวียนนะคร้าบ


===================

จากการแต่งฟิคเก่า(ที่ปัจจุบันก็ยังไม่จบ)ก็รู้ตัวเองว่า
แต่งฟิคคนเดียวไม่รอดแน่
วางโครงเรื่อง แต่ตนเองก็เขียนเรื่องออกทะเลเอง
ยังหาทางกลับท่าประเด็นไม่ได้เลย
(+1แป้ก)

เลยจึงอยากหาแนวร่วมในการเขียนนิยาย จึงหาแนวร่วมที่จะมาทำฟิคเวียน

เนื้อเรื่อง จะเกี่ยวกับตำนานของอาวุธเลเวล90 ทั้งที่มา และผู้ได้รับเลือกให้ใช้

ใครอยากจะเป็นคนเขียน ก็เชิญมาจองโต๊ะไว้นั่งเทียนเขียนได้เลย(...)

เค้าไม่ค่อยเข้าใจเรื่องคำว่า "นิยายสด"เท่าไร เห็นเข้าไปโพสต์กันจัง
เลยงงๆว่า ถ้าคนนั้นคนนี้เข้ามาเขียน เนื้อเรื่องมันก็จะมาจากหลากมุมมากเกินไป เพราะต่างคนต่างก็อยากเอาตัวละครของตนเองมาเป็นจุดเด่นของเนื้อเรื่อง
แล้วเนื้อเรื่องก็กลายเป็นแบบสะเปะสะปะไป เลย งงๆ ว่าช่วยกันแต่งมันก็สนุกดีนะ แต่มันจะไม่ได้นิยายที่ดีอะจิ แต่ถ้าอ่านเขียนเอาขำๆก็ดีอยู่หรอก

เค้าเคยอ่านฟิคของพวกที่ชอบแฮร์รี่พอตเตอร์อะ ทุกคนเขียนออกมาได้ดีมาก
ภาษาสละสลวยยังกะเรียนแต่งวรรณกรรมกันมาเลย
แต่ในบอร์ดเกมส์ส่วนใหญ่เห็นแต่งเก่งๆ ภาษาสวยๆไม่กี่คน ที่เหลือเหมือนบทละครมากกว่า
กล่าวคือยกมาแต่บทพูดอย่างเดียว เค้าก็เลยงงๆ กับฟิคของบอร์ดนิดหน่อย -*-
