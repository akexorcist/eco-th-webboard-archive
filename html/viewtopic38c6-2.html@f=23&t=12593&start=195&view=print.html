Reenei เขียน:เควสชุด 55 สาย Fighter
รับเควส"ส่งก่อนละลาย (Gadou)" แนะนำให้รับที่ Northan Blomnard เมื่อรับมาแล้วจะมีเวลา 30 นาที ให้เราไปหา Vareria ที่ร้านเหล้าอีกร้านในเมือง (ร้านที่มีน้องหมี) คุยกับ Vareria แล้วจะได้"ไอซ์แคนดี้(เควส)"มา
จากนั้นให้เรานำไอซ์แคนดี้ไปส่งให้ Godou Hunter (เควสเขียน Gadou แท้ๆ) ที่หลังพรมแดน Iron South ก่อนหมดเวลา (ข้ามพรมแดนมาก็เจอเลย ลองเดินๆ หาดู อย่าลืมบัตรผ่านนะ)
เมื่อนำไปส่งรอบแรกจะได้ "Demon Blood"(เป็นส่วมผสมของมีด Lv.52) จากนั้นให้เราทำเควสนี้ซ้ำอีกครั้ง เมื่อนำไอซ์แคนดี้ไปส่งครั้งที่ 2 Godou Hunter จะให้ skill point เรามาอีก 1
*เมื่อเคลียร์ Event นี้แล้ว จะสามารถซื้อชุดประจำอาชีพ Lv.55 ของสาย Fighter จาก Godou Hunter ได้

เควสชุด 55 สาย Spell User
เริ่มที่ร้านหมอดูในDowntownทิศเหนือนะคะ รับเควสหาคริสตัล แล้วเอา Crystal ไปให้ภูติประจำธาตุ(ตัวไหนก้อได้ตัวนึง) แล้วเราจะได้คริสตัล+ธาตุมา ก้อนำมาให้หมอดู ทำสองรอบจะสามารถซื้อชุดสาย Spell User lv.55 ได้ค่ะ
เควสหมวก 55 สาย Spell User
ทำเควส "ขนส่งเอกสาร" ที่ร้านเหล้า โดยให้รับเควสที่ Acropolice จะมีเวลา 15 นาทีให้เราเดินไปหา Sage Master ที่อัพทาวน์ (บ้านของ Sage Master จะอยู่ข้างๆ บ้านคุณป้าช่างเย็บ หากไปไม่ถูกให้ถามทางจาก Guide Machine ดู)
เมื่อคุยกับ Sage Master แล้วจะได้รับ"ประมวลกฎหมาย" มา 1 เล่ม ให้นำประมวลกฎหมายไปส่งให้กับ Miriaria ที่สมาคมพ่อมดเมือง Northan Blomnard (ที่เดียวกับ Event ข้างบน แต่เลือกเข้า"Motoyama Room"แทน/หากไม่ใช่สาย Spell User จะไม่มีให้เลือก ให้เดินเข้าไปเลย) ก่อนหมดเวลา (วิ่งตาเหลือก)
เมื่อทำเควสสำเร็จครั้งแรกจะได้รับ"Text Book"จาก Miriaria (อาวุธสายเวทย์ Lv52) หลังจากนั้นให้เรารับเควสนี้อีกครั้ง (ถ้ารับที่ Northan ต้องตายกลับสถานเดียว ไม่งั้นไม่ทัน 15 นาที) เมื่อทำเควสสำเร็จครั้งที่ 2 Miriaria จะให้ skill point เรามา 1 สกิล
*เมื่อเคลียร์ Event นี้แล้วจะสามารถซื้อหมวก Lv.55 ของสายเวทย์จาก Miriaria ได้

เควสชุด 55 สาย Back Pack
ทำเควส"ยาของท่านแม่(Poroll)" 2 ครั้ง
- วิธีทำเควส
หากลีบดอกไม้ 6 สีซึ่งดรอปจากดอกไม้ทั้ง 6 ธาตุ
*ต้องให้ชาวนาที่มีสกิลปราชญ์ต้นไม้เป็นคนตี กลีบสีถึงดรอป
- ดอกไม้เหล่านั้นหาได้ที่

สีแดง - ทะเลทหาย Steap (ทางเข้า Interior Corridor)
สีเหลือง - เกาะเรือรบ
สีฟ้า - ทุ่งหิมะ Snop
สีส้ม - แหลม Istor, ทุ่ง Momo
สีขาว - ชายหาด Acronia, ทุ่ง Momo
สีดำ - เกาะ Undead, ปราสาท Undead

เมื่อได้ครบแล้วให้นำไปให้คนขายอุปกรณ์เวทย์มนต์ที่ Northan Blomnard จะได้ยา Northan Divine Tonic มา ให้นำยาไปส่งที่ Quest Counter จะได้รับ Poroll's Thank Ticket มา 1 ใบ จากนั้นให้นำ Poroll's Thank Ticket ไปให้ Poroll (จำชื่อเต็มไม่ได้) ที่ Iron City ชั้นล่าง เมื่อให้ Poroll's Thank Ticket ครบ 2 ครั้งก็จะได้รับ Skill Point
*เมื่อเคลียร์ Event นี้แล้วจะสามารถซื้อชุดประจำอาชีพ Lv.55 ของสาย Backpacker จาก Poroll ได้
