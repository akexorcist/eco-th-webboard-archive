เบลดกับไนท์ (สาย agi) ช่วงแรกเล่นเรื่อยๆไม่ลำบาก
หลังเปลี่ยนอาชีพ ถ้าจูงมือพระหรือแม่ค้าสายฮีลไปอัพด้วยกันจะเล่นสบายมาก
โดยรวมแล้วเบลดภาษีดีกว่าไนท์

แอสจะลำบากกว่า ตรงที่เลือดน้อยและมีดมันเบากว่าหอกและดาบ
แต่หลังเปลี่ยนอาชีพและเล่นสายสนับจะอัพง่ายมาก ไม่ต้องกด Delay Cancle ก็อัพได้
(จูงมือพระไปคอยฮีลอย่างเดียวก็พอ)

อาคเชอร์สบายตั้งแต่แรกยันช่วงกลางๆ แต่ไปลำบากช่วงบั้นปลายชีวิต (lv 90-95)
ต้องใช้กระสุนเยอะในการอัพแต่ละรอบ ตัวบางลากเยอะไม่ได้ (ต้องสิงเพิ่มเลือดหลายตัว)
เลยดูจะอัพลำบากกว่าอาชีพที่เหลือ
