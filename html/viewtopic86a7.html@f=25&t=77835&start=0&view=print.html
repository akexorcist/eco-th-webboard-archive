กระทู้นี้ไม่ได้แขวะเอกนะ เพียงแต่ทดสอบให้เฉยๆกันคนเข้าใจผิด
สือเนื่องจากกระทู้นี้ซึ่งเอกบอกว่าPetมีธาตุเลยเอามาลองทดสอบเล่นๆให้ดูละกัน
viewtopic.php?f=25&t=76700

โดยการทดสอบนี้เราใ้ช้Pet หุ่นทองซึ่งเอกบอกว่ามีธาตุไฟ 30 มาทดสอบส่วนอาวุธที่ใช้คือธนูตั๋วฮอบบี้ + ลูกธนูธาตุมาใช้ทดสอบกัน

อันดับแรกทดสอบด้วยธนูธาตุลม ซึ่งธาตุลมเป็นธตุที่ชนะธาตุไฟ

ค่าความเสียหายแกว่งอยู่ระหว่าง 400นิดๆ - 250เศษๆ หลังจากลองยิงไปนานพอดู

อันดับที่สองเอาธนูธาตุไฟยิง ซึ่งธาตุไฟควรจะยิงธาุตเดียวกันลดลงอยู่แล้ว ซึ่งน่าจะความเสียหายต่ำลง

ค่าความเสียหายแกว่งราวๆ 400เศษๆ - 250เศษๆ เช่นเดิมหลังจากลองยิงไปเรื่อยๆเป็นชุดๆดู

และสุดท้ายธนูธาตุน้ำ ซึ่งธาตุน้ำควรจะยิงธาตุไฟเข้าน้อยมากเพราะน้ำแพ้ไฟ ความเสียหายควรจะต่ำลง

ย้อนกลับไปมองด้านบน มันก็เหมือนเดิมแหละ = ="



และได้ลองกับPetรถถังซึ่งบอกว่าไม่มีธาตุแล้วก็ได้ผลแบบเดิม สรุปง่ายๆคือ Pet ไม่มีธาตุนะครับ ส่วนใครที่มองเห็นPetมีธาตุจะเกิดจากการยัดธาตุเข้าไปด้วยสกิล การเปลี่ยนร่างมาริโอเนท หรือการใส่การ์ดไอริสหรืออาวุธ/เกราะ ที่มีธาตุจ้า
