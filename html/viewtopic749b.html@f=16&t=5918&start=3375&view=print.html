NearLy ZerO` เขียน:STR AGI DEX ............ ทุบเองได้ ขี่หุ่นได้ กดสกิลเร็ว
STR VIT DEX ............ ทุบเองได้ ขี่หุ่นได้ เลือดเยอะขึ้น
STR AGI ................... ขี่หุ่น only (ลงมาก็ง่อย สิงเขาก็เด้งบ่อย) พริ่ว กดสกิลเร็ว ใช้สกิลกายภาพบนหุ่นแรงเมื่อกดบัฟ Overrun
STR VIT ................... ขี่หุ่นหรือสิงคนอื่น เลือดเยอะ ใช้สกิลกายภาพบนหุ่นแรงเมื่อกดบัฟ Overrun และ เหมาะสำหรับสิงกด FH, assist ให้คนอื่น
AGI VIT.................... ขี่หุ่น only กดสกิลเร็ว เลือดเยอะ และพริ้ว (ถ้าร่วงจากหุ่นก็มีเวลาให้ควักหุ่นออกมาใหม่ได้นานกว่าสายอื่น) ถ้าไม่คิดจะใช้ Overrun และไม่คิดจะสู้โดยไม่ใช้หุ่นเลย แนะนำให้เล่นสายนี้

* ที่บอกว่า เลือดเยอะ และ พริ้ว หมายถึงตอนไม่ขี่หุ่นเท่านั้น
* ขณะใช้ Overrun จะบังคับการเดินไม่ได้ (มันเดินมั่ว)
