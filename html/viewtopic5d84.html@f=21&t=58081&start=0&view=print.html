รักวัยเรียน

เช้าวันหนึ่งอากาศหนาวและเป็นวันเปิดภาคเรียนของนักเรียนชั้นม.ปลายโรงเรียน เมชิน
ตึก ตึก ตึก~~ “สายแล้วๆ” หญิงสาวผมยาวถึงกลางหลังสีดำใส่ชุดเครื่องแบบนักเรียนที่เป็นเสื้อแขนยาวสีและกระโปรงสั้นสีน้ำเงินเข้มประมาณเข่าของเธอคนหนึ่งรีบวิ่งอย่างเอาเป็นเอาตายไปโรงเรียนเพราะว่ามันกำลังจะสาย
“สายตั้งแต่วันแรกเลยงานเข้าแล้ววว~!!” เธอตะโกนในใจของเธอ
ตึก ตึก ตึก~~ ชายหนุ่มคนหนึ่ง ใส่เครื่องแบบนักเรียนเป็นเสื้อแขนยาวและกางเกงขายาวสีดำล้วน ผมสั้นวีน้ำตาลเข้มก็กำลังวิ่งอย่างเอาเป็นเอาตายเช่นกัน
“งานมาละไง “ชายหนุ่มบ่นกับตัวเอง
“ว๊ายย~~!”
“โว๊ะ~!!”
ผลั่กทั้ง2คนวิ่งชนกันตรงทางแยกก่อนที่จะถึงประตูโรงเรียน
“อูยย- -*เจ็บวุ้ย ขอโทษครับๆผมกำลังรีบน่ะ”
“ไม่เป็นไรค่ะ”
หญิงสาวรีบลุกแล้วรีบวิ่งต่อไปที่โรงเรียนต่อไป

สวัสดีครับที่คือเรื่องราวของผมตอนอยู่ม.ปลายนะครับ เชิญอ่านได้เลยครับ(ไม่เกี่ยวกะโลกจริงนะเฟ้ย จาก ผู้แต่ง)

กริ๊งง~!!!!!!!!!!!เสียงกระดิ่งจะเป็นตัวชี้ว่านักเรียนจะมาสายกันหรือไม่ได้ดังขึ้นแล้วตอนเวลา7.50น.
“แฮ่ก แฮ่ก นะ..ในที่สุด..แฮ่กเราก็มาทันเวลาพอดี” ผมยืนหอบเพราะความเหนื่อยหน้าห้องเรียนของเขาเองที่ชั้น4ห้อง1
ในห้องเรียน...
ชายวัยกลางคนใส่สูทสีเทาผูกเนคไทด์สีเขียวอ่อนใส่แว่นหนาเตอะกำลังเดินเข้ามาในห้องเรียนของผมและอาจารย์คนนั้งก็คืออาจารย์ประจำห้องของผมนั่นเองเขาชื่อ วีระ หรือที่เรียกกันว่าอาจารย์วีนั่นเอง
“นักเรียนทำความเคารพ~!!” หัวหน้าห้องสั่งให้นักเรียนเคารพอาจารย์ผู้สอนตามธรรมเนียม
“อรุณสวัสดิ์ครับอาจารย์~!!!”ผมและเพื่อนตะโกนลั่นห้องเพื่อประชดอาจารย์
“ดีๆนักเรียนวันนี้จะมีคนมาเรียนที่ห้องเราคนหนึ่งนะเอ้าเข้ามาได้”อาจารย์วีได้สั่งให้นกัเรียนที่มาใหม่นั้นเข้ามาในห้องเรียนเพื่อแนะนำตัว
“สวัสดีค่ะ ชั้นชื่อ เรย์ ค่ะ ขอฝากตัวด้วยนะคะ”
“O_O!!เห้ยคนที่ชนเมื่อเช้านี่หว่า”ผมบ่นในใจของผมไม่นึกว่าเธอคนนั้นจะมาอยู่ในห้องเดียวกับผมได้
และแล้วเวลาก็ผ่านไป1เดือนหลังจากสอบกลางภาคเสร็จแล้ว และวันนั้นเป็นวันที่อากาศหนาวเย็นพอดีเหมาะแก่การนอนของผม
ที่สวนหลังโรงเรียน สวนนี้ห้องผมรับผิดชอบให้จัดสวนให้เสร็จภายในสิ้นเดือนนี้(อีก3วันนั่นเอง)
“ เซท แกจะไปไหนอ่ะมาช่วยงานก่อนดิ” อาล เพื่อนสนิทของผมเขาเป็นคนชอบแหย่คนอื่นเล่น กำลังเรียกผมที่แอบโดดงานไปอู้ซักงีบ
“แหะๆ ขอบไปพักซักงีบไมได้เหรอ”
“ไม่ได้โว๊ยยยย ได้งีบเดียวของแกน่ะมันกี่ชั่วโมงเคยนับมั้ยยย”อาล ตะคอกใส่ผมใหญ่



“ไม่อ่ะแล้วมันเท่าไรอ่ะ”
“2ชม.โว๊ยยยยยยยยยยยย~!!” เขาตะโกนใส่ผมพร้อมกับโมโหแบบหยอกล้อกันเล่นแล้วปาหินที่อยู่ในมือเขามาใส่ผมแบบเบาๆ
“> - ไอ้นี่เออช่วยก็ช่วยเมื่อยนี่หว่า”ผมต้องจตำใจเข้าไปช่วยเขา
“ชิ อดอู้เลยแงๆT-T” ผมบ่นในใจของตัวเอง
