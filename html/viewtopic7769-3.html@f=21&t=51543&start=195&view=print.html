วิลเลียมมีสีหน้าไม่เชื่อชั่วครู่ เขาจึงลงมือหั่นเสต็กของเกลในจานเขาบ้างและกัดไปคำหนึ่ง

รสชาติอร่อยนั้นหอมหวานด้วยเครื่องเทศและเนื้อนุ่มๆ ฝีมือการทำอาหารของเกลไม่เลวเลยทีเดียว
วิลเลียมรู้สึกเสียใจเล็กน้อยที่ไม่ได้เรียนอะไรอื่นนอกจากการสู้รบและประวัติศาสตร์เท่านั้น

เมื่อเอวาร่าอธิบายถึงความสัมพันธ์ของเธอและของเขาเสร็จ วิลเลียมวางส้อมลงและเอ่ยชมเกล

"ฝีมือของคุณเยี่ยมมากเลยครับ คุณไปเรียนจากที่ไหนหรือ"...
