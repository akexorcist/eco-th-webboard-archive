เกี่ยวกับ Golem Catalog

ระบบการเปิด Catalog เพื่อทำการซื้อ-ขาย
จะสามารถดูตารางสรุปการซื้อขายได้โดยไม่ต้องตรวจสอบ Golem Shop ทีละร้านๆ ด้วยการใช้ Golem Catalog,
เมื่อเรียกใช้ Golem Catalog ก็จะมีหน้า Window เปิดขึ้นมา, ซึ่งจะแสดง Golem Shop ของ ตัวละครอื่นๆที่ทำการเปิดซื้อขายด้วยตารางบน Map
* สิ่งที่ดูได้โดย Golem Catalog ก็คือ ร้านที่อยู่ใน Map เดียวกันกับตัวละครของตนเอง, และเป็น Golem Shop ที่ชำระค่าลงทะเบียน Golem Catalog แล้วเท่านั้น
* ใน Dungeon นั้น เนื่องจากไม่สามารถลงทะเบียน Shop ใน Golem Catalog ได้,ฉะนั้นถึงจะเปิดดู Golem Catalog ก็ไม่เห็นรายการ Golem Shop

ในส่วนนี้บางท่านอาจจะเห็นว่าไร้ประโยชน์นะครับอันนี้เป็นความคิดเห็นส่วนตัวของแต่ละคนครับ
เนื่องจากความแออัดจากผู้ที่ตั้งร้านโดย Golem Marionette นั้นอาจทำให้บางคนปิดออฟชั่นในส่วนของการโชว์ร้านหรือคำประกาศต่างๆ จึงสะดวกกว่าที่จะไปเดินโดยการเข้าทีละร้าน หากเราอ่านจากประกาศใน Catalog ก็จะทำให้สามารถเลือกร้านที่จะเข้าได้โดยดูจากประกาศที่ตั้งไว้

ในทางกลับกัน หากออกไปเก็บเลเวลนอกแมปที่ไม่ใช่ในเมือง หากเก็บของไว้จนมากเกินไปจนไม่สามารถเคลื่อนที่ได้ อีกวิธีที่เราไม่ต้องทิ้งของไปเปล่าๆ ก็คือการใช้ Catalog แล้วขายของตามที่มีคนมารับซื้อไว้

สรุปก็คือ หากไม่ได้อยู่ในแมปเดียวกันก็จะไม่เห็นร้านที่ตั้งไว้ในแมปนั้นๆ ครับ

จะกัดกันทำไมเนี่ย..... สื่อสารกันไม่ดีเองแท้ๆ ผิดทั้งคู่เลย

คุณ FreedomFighter เค้าหมายถึง Golem Catalog มันก็มีประโยชน์ของมัน ไม่ใช่ไร้ประโยชน์ซะทีเดียว และความหมายของเค้าก็คือ ในเมื่อ Golem Catalog มันออกแบบมาเพื่อให้ลงทะเบียนและดูรายชื่อเฉพาะในแมพนั้นๆตั้งแต่แรกแล้ว การที่ถูกกล่าวหาว่าไร้ประโยชน์"เพราะใช้ดูข้ามแมพไม่ได้" นั้น จึงเป็นเรื่องนอกประเด็น ไม่สามารถนำมาอ้างได้ ดังนั้น คนที่ติในเรื่องที่ไม่ได้ระบุไว้ตั้งแต่แรก(ในการใช้งาน Golem Catalog) จึงพูดไม่ตรงประเด็น และไม่ถูกต้อง เหมือนคนไม่เคยลองและไม่รู้จริง อยู่ๆก็มาติซะงั้น

ส่วนคุณ asukaray ก็หมายถึง มันไม่มีประโยชน์ในข้อที่เค้าต้องการ ก็เลยโวยว่ามันไร้ประโยชน์ เพราะประโยชน์ที่ถูกออกแบบมาตั้งแต่ต้นนั้นมันไม่ครอบคลุมถึงสิ่งในความคาดหวังของเค้า(หวังจะให้มันใช้ได้ทุกแมพรวมกัน) และเค้าเองได้ลองแล้ว และรู้แล้วด้วย ว่ามันใช้งานได้แค่ 1 แมพ เพราะฉะนั้นก็เลยไม่พอใจ

ทีนี้ลองคิดดู คนเราถ้าเห็นว่าอะไรมีประโยชน์และตัวเองก็ใช้ประโยชน์อยู่ทุกวันๆ แต่โดนคนอื่นมาหยาม ว่าว่ามันไร้ประโยชน์ ก็ต้องเคืองเป็นธรรมดาใช่มั้ย?

ในขณะเดียวกัน คนที่ลองใช้ระบบแล้วไม่ถูกใจ เลยว่าว่าไร้ประโยชน์ แต่โดนคนอื่นสวนกลับมาแบบดูถูก ว่า ไม่เคยลองใช้แล้วทำพูดมาก ก็ย่อมต้องเคืองเช่นกัน

ถอยกันคนละก้าวแล้วมองดูดีๆเถอะ
แล้วจะรู้ว่าไม่มีใครถูกต้อง 100%



ส่วนเราเองคิดว่า Golem Catalog มันครอบคลุมแมพเดียวก็พอแล้ว เพราะแต่ละแมพมันก็เป็นแหล่งของไอเทมที่แตกต่างกันไป ใครต้องการอะไรที่หาได้แถวๆแมพไหน ก็ไปเปิดโกเลมหรือไปดู catalog ในแมพนั้นเอา มันก็เป็นหมวดหมู่และแบ่งประเภทย่อยลงมาง่ายดีไม่ใช่หรือ? เราว่านะถ้ามันครอบคลุมทั่วโลกคงเยอะและปนเปกันวุ่นพิลึก
