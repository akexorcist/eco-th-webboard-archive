ช่วยอธิบายสกิล กับความต่างหรือเหมือนของ

Robot Recover Up Passive Skill เพิ่มพลังการฟื้นฟูของ Pet พาหนะ ประเภท Robot

Maintenance พิ่มอัตราการฟื้นฟู HP ตามธรรมชาติ ของ Robot ในขณะที่ ขี่ Pet พาหนะ
ประเภท Robot ผลของสกิลจะเกิดขึ้นต่อเมื่อ หุ่นนั่งอยู่กับที่เท่านั้น


คือเวลาปกติ ได้รับ ผลสกิล เร่งของพระ ดูเหมือนว่าขณะ ขี่หุ่นอยู่ ไม่ได้เพิ่ม เร็วขึ้นแต่อย่างใด เหมือนอย่างคนได้รับ

หรือจำเป็นต้องอัพ Robot recover up เพื่อให้ ฟื้นฟูเร็ว เหมือนอย่างสกิล hp recovery ของคน แล้วสกิลนี้ มีผลให้กินยาแล้ว เพิ่มเยอะกว่าปกติ กับ ได้รับฮีลแรงขึ้นหรือไม่

แล้ว maintenace นี่ มีผลอย่างไรกันแน่ ใช้คู่ กับ robot recover up ได้ไหม มีผล เมื่อได้รับเร่งไหม

มีผลกับ กินยาไหม กับฮีลไหม หรือ เป็นผลขณะ นั่งฟื้นฟูตามธรรมชาติ

หากอัพทั้ง2 เวลานั่ง จะฟื้นเร็วกว่าอัพอย่างเดียวไหม ช่วยชี้แจงแถลง ไขหน่อย แบบว่าอยากรู้จริงๆ ขอบคุณ
