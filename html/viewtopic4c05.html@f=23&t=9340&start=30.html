ทำเขา Gazelle Horn

ชุด 60 ต้องทำ Event ครับ ซึ่งเริ่มต้นที่เจ้าหญิง หลังจากคุยแล้วเจ้าหญิงจะให้หา ตุ้มหู ซ้าย และ ขวา ซึ่งอยู่ภายในปราสาท undead ทั้ง 4 ชั้น (เจ้าหญิงอยู่ชั้นที่5) สังเกตได้จาก ประกายแสงแวววาว ซึ่งมีประมาณ 6 จุด แต่ตุ้มหูมีเพียงแค่ 2 ใน 6 สรุปคือมันสุ่มครับ ต้องวิ่ง ๆ เอา (แนะนำมีเวสไปด้วย มอนตีแรง-เร็วใช้ได้) หลังจากที่เราเก็บตุ้มหูทั้ง ซ้ายและขวาได้แล้ว เจ้าหญิงจะขายของให้เรา โดยของที่ขายมี3 ชุดดังนี้ครับ (ให้ทำเควส Gazelle Horn lv 45 ก่อนครับ ไม่งั้นทำไม่ได้)

** ของทุกชิ้น lv60

Set A
1. ดาบ2มือ เอฟเฟคสายฟ้า passive critical (12/59/38/-)
2. ไม้เท้า (39/-/27/59)
3. ธนู (-/-/53/-)
4. หนังสือ (36/1/1/60)
5. เรเปียร์ (22/37/50/-)
6. กระบอง (mace) (47/26/33/-)

Set B
1. โล่ เอฟเฟค เรืองแสง (21/15) (12/12/5)
2. ไม้เท้า (40/-/26/57)
3. ดาบสั้น (30/48/34/-)
4. หอก (24/35/51/-)
5. หอก 2 มือ (28/38/58/-)
6. ขวาน 2 มือ (57/57/30/-) << อาวุธชิ้นนี้ ถ้าตีเองจะมี skill passive critical ด้วย

Set C
1. ดาบ มือเดียว (35/52/36/-)
2. ลูกคิด (38/-/-/-)
3. ขวานมือเดียว (49/40/35/-)

6. โล่สีฟ้า (23/17) (10/10/6)

เมื่อคุยกับท่านพ่อมดครั้งที่ 2 แล้ว ให้เราไปคุยกับไททาเนียอีกครั้ง แล้วไททาเนียจะขายชุดประจำอาชีพให้กับเรา โดยจะขายเฉพาะชุดสำหรับอาชีพของเราเท่านั้น (เช่นถ้า Druid ไปซื้อก็จะซื้อได้เฉพาะชุดของ Druid) * คงจะซื้อได้เฉพาะนักเวทมั้ง

ผมหาห้องลับไม่เจอครับ มันอยู่ตรงไหน

เสื้อผ้า เลเวล 65 ทำเควสได้ เลเวล 60+

รายละเอียดที่มีภาพด้วย*

ไปหาราชินี แล้วจะได้กุญแจ แล้วออกจากห้องราชินี จะเป็นที่มีองครักษ์ 6 คน ให้เราไปหาคนขวาล่าง (มองจาก ทางเหนือไปห้องราชินี) จะมีให้ทำเควสเคาเตอร์ กับเข้าห้องสมบัติ ให้เราเข้าห้องสมบัติ แล้วเลือกกล่องไหนก็ได้ ใช้กุญแจ จะได้รับยาชุบ ขวดนึง

ให้ออกมา รับเควสจากทหาร คือต้องไปฆ่า หรือไปให้มันระเบิดใส่เล่น ที่ดันเมืองเหนือ ซึ่งมันจะอยู่ทางซ้ายล่างของดัน เป็น miny-do ถ้าเข้าไปตี มันจะเหมือน หดแล้วขยายขึ้น และจะไม่ตีเราก่อน*

เมื่อฆ่าได้หรือโดนระเบิดเละแล้ว (ให้คนทำเควสเป็นคนตีคนสุดท้ายตอนมันระเบิด ถึงเราตายเควสก้เสร็จสิ้น) มารับเควสจะได้รับกุญแจอีกครั้ง ให้เข้าห้องกล่องสมบัติไป โดยมองกล่องให้อยู่ทางเหนือ

- ซ้ายล่าง เสื้อท่อนบน
- ซ้ายบน รองเท้า
- ขวาล่าง หมวก
- ขวาบน กางเกง (อาจจะจำผิด)

ก้คงต้องเหนื่อยหาทำเควสสุดโหดกัน โดยเฉพาะแบ็กแพคเกอร์ (ผมไปทำกะพระคนเดียว กว่าจะตีจนระเบิด แล้วดันมีไอบ้าไหนไม่รู้ มาแจม ซัดเข้า 4000 แล้วยังทำประชด "ว้า 4000 เอง" แล้วก้หายไปเลย)
