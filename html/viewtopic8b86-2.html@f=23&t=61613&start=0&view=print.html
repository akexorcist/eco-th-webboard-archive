ในกระทู้อาวุธที่คุณพี่ทำไว้ คุณน้องเข้าไปดูมันเป็นหยั่งงี้อ่ะคับ


ถ้าคุณพี่พอจะมีเวลาก็ช่วยเปลี่ยนที่อัพรูปหน่อยก็ดีนะคับ
พอดีว่าคุณน้องมาหาข้อมูลส่วนผสมอาวุธที่คุณพี่ทำไว้
พยายามจะเข้ามาดูหลายวันแล้วยังดูไม่ได้ซักที
ถ้าหาที่ฝากไฟล์รูปที่มันอยู่ยาวๆ+ดูได้ตลอดไม่ได้
ขอฝากโปรเจคเพิ่มส่วนผสมอาวุธเวอร์ชั่นข้อความเข้าไปด้วยคับ
แหล่งที่มา
- ลิงค์รูปส่วนผสม
- ส่วนผสมเวอร์ชั่นข้อความ Ax3 + B + C + ...
ส่วนรูปที่อัพไว้แล้ว ใครโชคดีเปิดดูได้ก็แล้วไป
แต่ใครซวยอย่างคุณน้องก็ยังพอกล้อมแกล้มดูที่เป็น text ได้น่ะคับ
ข้อมูลมีอยู่แล้วใน http://board.onenet.co.th/viewtopic.php?t=15482 ของ Porphyryl
น่าจะเอามาเติมเพิ่มความสมบูรณ์อีกหน่อยน่ะคับ

อ้อ.. อันไหนมือเดียวหรือสองมือบอกเพิ่มเข้าไปด้วยก็จะยิ่งสมบูรณ์ขึ้นไปอีกน่ะคับ
