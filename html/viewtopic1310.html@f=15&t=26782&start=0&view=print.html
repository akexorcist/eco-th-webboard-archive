เปิดดูแผนที่มอนส์เตอร์ที่ www.eco.in.th

แล้วดูมอนเตอร์ไล่ไปทีละแผนที่ ตัวที่จะไปเก็บ ควรจะมี hp น้อยกว่า min Matk ของท่านประมาณ 10-20 เป็นอย่างน้อย เพราะจะทำให้ยิงมันทีเดียวตายประมาณ 99 %
(อย่าไป +เปอเซนโจมตีของ e. bolt ก่อนแล้วมาคิดนะครับ โดยให้คิดว่า bonus ที่เพิ่มมาจาก e. bolt จะถูกหักกับค่าป้องกันเวทของมอนจนหมดไปเลย )

ตอนคุณเลเวลต่ำๆ ไม่สมควรจะโดนตีเป็นอย่างยิ่ง เพราะเกราะของท่านในช่วงเลเวล1-40 สำหรับสายspell user แล้ว มันคือ กระดาษกันน้ำอย่างดี ทำให้ชนกะพวกมอนที่มีกรงเล็บ เอาตัวทับ ขวิด ข่วน กัด ฯลฯ ได้ยาก

ดังนั้นการโจมตีของท่าน จึงสมควรจะส่งมอนเตอร์ที่จะเก็บเลเวลไปเกิดใหม่ได้ในการโจมตีอย่างมาก 2 ครั้ง ไม่งั้น อาจมีเฮได้ครับ

แนะนำแค่นี้น่าจะโอเคนะครับ
