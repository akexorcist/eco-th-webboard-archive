วิธีการวางพรมให้ลอย
จากคุณ ティファ หรือคุณบีผู้เปิดร้านเค้กที่เคยรู้จักกันนั่นเอง

เริ่มต้นจากของหลักๆที่ต้องใช้


พรมใหญ่ พรมเล็ก และเตาผิง


เริ่มแรกให้วางพรมเล็กไว้ข้างล่างก่อน


ต่อมาให้วางเตาผิงทับพรมเล็กซ้าาาา


และเราจะวางพรมที่ลอยได้แล้ว

อ๊ะ เตี้ยไปใช่มั้ย? อยากได้สูงกว่านี้ใช่มะล๊าาาา


ก็วางเตาผิงซ้อนอีกชั้นซ้าาาาาา


อ่ะ ได้แล้วพรมที่ลอยสูงขึ้นนนนนน

*ต้องใช้เตาผิงเท่านั้น
*พรมที่รองข้างล่างต้องเป็นพรมเล็ก
*ถ้าจะวางของบนพรม ให้หาอะไรวางไว้ใต้พรมให้เต็มซะ
