ริวงะฮินากิ เขียน:ถึงฝั่งแล้ว :first11:

อยากรู้เกี่ยวกับแอสอ่ะครับ แอสควรใส่หมวกที่+สเตตัสอะไรมากสุดครับ

เต้ง agi def หรือพลังป้องกันเวทย์ หรือ vitครับ

แล้วบอกด้วย หมวกชื่อไร



ว่า กัน ถึง จุดประสงในการไส่ เครื่องป้องกัน ที่ + status ก่อนนะคับ
ส่วนไหญ่จะ + ไห้สเตตัสลงตัวกันทั้งนั้น นะคับ เเต่ ว่า การจะไห้สเตตัส ลงตัวมีหลากรณี นะคับ ลองอ่านดู

1 คือ ไส่เพื้อ + เพิ่ม ไห้สเตตัส มาก(เกินกว่าจะอัพได้) จนถึง ค่าที่ได้โบนัสเช่น 100+14+หมวกอีก 2 เพื่อไห้ได้ 116 เอาโบนัส

2ไส่เพื่อ ไห้ ค่านั้นๆ + บัฟ พระ เเล้วได้โบนั้ส เช่น
str 90+16
int 90+19
ไนตอนเเรก เราอาจไส่ หมวก int 1 เพื่อไห้ int ลง ตัวที่ 90+19+1 str ไม่ต้องไส่เพราะลงอยู่เเล้ว
ใน กรณีที่ได้ บัพ พระ ( str+8 int +11) เราจึงเปลี่ยน เอา หมวก iint ออกเเละไส่ str เเทน
เป็น str 90+16+8(บัฟ)+2(หมวก) ลงโบนัส 126
int 90+19+11(บัฟ)
ในกรณีนี้จะทำไห้ ไช้สเตตัสได้ คุ้มค่า ที่สุด เเล้ว ตอนบัฟ กลับ ไม่บัฟจะเก่งเเบบ ก้าวกระโดดมากเลยคับ

3 การไส่ เครื่องปอ้งกันไห้กลับ ค่าสเตตัสที่เยอะ ที่สุด เพราะ นำค่าที่จะอัพสเตสนั้นๆไปอัพอย่างอื่นเเทนเช่น

str 90
dex60
int 6
agi 70
mag3

จากที่ดู status เเล้วนะคับ str มากที่ สุด ดังนั้น ถ้า เรา ไส่ หมวก str 2 เราก็ จะลด การอัพ str ที่ 90 ไป 2 หรือ 88 ทำไห้เราเหลือ ค่าอัพstatus ไปอัพ อย่างอื่นได้ อีก 30 พอย์ท ซึ้ง อัพ สเตตัส ได้มากกว่าไน ค่าสเตตัสที่น้อยกว่า


วิธีที่ 1 จะ ง่ายสุดนะคับ คือไม่ต้องคิดอะไรมาก
วิธีที่ 3 จะทำไห้ เราไช้โบนัส พอยท์ได้ คุ้ม
ส่วย วิธีที่ 2 นั้น จะทำไห้เราไช้ ค่าสเตตัส ทุกค่าได้ คุ้มที่ สุดเลยนะคับ
