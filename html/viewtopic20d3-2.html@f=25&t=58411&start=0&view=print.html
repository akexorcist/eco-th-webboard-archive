- -" เคยงงเหมือนกันนะ ทั้งที่อ่านหลายรอบ
แต่ก็อยากให้ไปตั้งถามในกระทู้เรื่อง PET มากกว่า

ถ้าจะให้เข้าใจ ลองเลี้ยงเลยแล้วค่อยๆลองเอาไปล้มจะดีกว่านะ จะได้เข้าใจแบบเป้นรูปธรรม

ถ้าเราเลี้ยงแมว แล้วเลือด 240 + 1800 (สมมุตว่าตันแล้วนะ)

พอเอาไปล้ม ก็จะแจ้งว่า ได้ VIT 1

ค่าเลือดก็จะ กลายเป้น 240 + 1 นี่เฉพาะค่าเลือดนะ

แล้วก็เก็บอัพเลือดไปในจำนวนเท่าครั้งแรกนี่ล่ะ คือ 1800

(แต่หน้าจอสเตตัสเราจะเห้นว่า 240 + 1801 ล้มแล้วได้ vit 1)

พอล้มครั้งที่สอง ก็จะได้ เลือด 240 + 2

(พอตันก็จะไปตันที่ 240 + 1802)

น้อยใช่ไหมล่ะ แต่ลองคิดดูนะ ว่าถ้าเต็มทุกค่ามันจะบวกไปเท่าไหร่

มีคนบอกว่า ถ้าเต็ม เราจะได้

str 2
dex 3
int 3
vit 3
agi 3
mag 3

ก็จะได้ + 3 ต่อหลังทุกค่า เมื่อล้ม 30 ครั้ง ก็เท่ากับ

+90 ในทุกค่า ทั้งเลือด ป้องกัน หลบหลีก เวทมนต์ คริ

เลือดแมวตัวเมื่อกี้ก็จะเป็น 240 + 1890

อย่าคิดว่าน้อยนะจ๊ะ เพราะเมื่อรวมกับ หลบหลีกที่ +90

ป้องกัน +90 เลือด 90 นี่ ใส่ลุยบอสได้เลยนะ ลุยฟูก็แท๊งแทนได้นานเลย

ถ้าจะเอาให้คุ้มๆ จะต้องเลี้ยงให้ได้ค่าเต็มทุกค่าครับ
