ผมเคยได้ยินมาว่า มันมีอาชีพที่เปิดโกดังได้ทุกที่ คือสมมุติว่าเราฝากของไว้ที่เมืองเหนือ แล้วมาเวลที่เมืองใต้ พอเดินไปเปิดโกดังกับพ่อค้าที่เมืองใต้ก็เบิกของจากเมืองเหนือมาได้ด้วย อาชีพนั้นคืออาชีพอะไรหรอครับ
ขอบคุณสำหรับคำตอบล่วงหน้าครับ

แบบที่คุณว่ามา ไม่มีนะครับ
มีแต่พ่อค้าครับ สามารถ โอนของไปยังเมืองต่างๆได้ครับ
เช่นอยุ่ เหนือ จะไปใต้ ก็ โอนของ(จากเหนือ)ไปไว้ที่เมืองใต้ ก็จะสามารถ ไปรับที่เมืองใต้ได้ โดยมะต้อง แบกไปเอง
ส่วนทีเปิดได้ทุกที่นั้น คงเป้น ไอเทม ในแคชช๊อบอ่ะงับ เปิด คลังได้ ทุกที่
น่าจะประมาณนี้นะครับ :)

เพียงแค่ท่านเป็น อาชีพ พ่าค้า ไม่ว่าเวลใดก็ได้

ท่านฝากของในคลัง แล้วกดคุยอีกครั้ง จะมีคำสั่งให้เลือกว่า โอนของไปเมืองอื่นๆ
เลือกแล้วเลือดของที่จะโอน + เมืองที่จะโอน
เพียงเท่านี้ก็สามารถไปเปิดได้ที่เมืองที่เลือกไว้แล้ว
