ส่วนเรื่องที่ว่าคนไทย cheat ในข้อมูลที่ได้มาจากหลายคนก็ตรงกันเช่น
1.มีคนไทยคนนึงเอาเบบี้มาแจกคนในปาตี้ โดยการโยนลงพื้น
2.คนนั้นมีของราคาแพงทั้งตัว ทั้งที่เพิ่งเข้ามาเล่น
3.และมีคนบอกว่า คนๆนั้นก็ยอมรับแล้วว่าทำจริง แล้วลบตัวทิ้งไปแล้ว

ี้ผมก็ไม่อยากซ้ำเติมใคร แต่สิ่งที่คุณทำมันทำให้เขามองคนไทยในด้านลบ มองหน้ากันไม่ติด
และทำให้คนไทยกลุ่มนึงที่รักECOเล่นด้วยความไม่สบายใจ หรืออาจไม่ได้เล่น

เท่าที่อ่านเหตุการณ์มา และได้คุยกับ คุณ ชิน

ขอ แนะนำ อย่างหนึ่งนะคะ

1. เขียนจดหมาย ส่งหา ทีมงาน GM

1.1 จดหมาย แสดงความขอโทษ ส่งให้กับ ทีมงาน อินโดนีเซีย

1.2 จดหมาย อธิบาย เหตุการณ์ ในกรณี ที่ พบว่า เป็น BUG (ถ้าจริง)

โดยอธิบาย ขั้นตอน อย่างละเอียด ว่า เป็น BUG อย่างไร ทำไม ถึงทำได้ อย่างละเอียด

เพื่อให้ ทีมงาน อินโด ตรวจสอบว่าเป็น BUG

ทางผู้เล่นไทยก็จะได้ นำไปอธิบายกับผู้เล่น อินโดได้ว่า ส่ง บัค ให้ GM บ้านเค้าตรวจสอบแล้วนะๆ

แล้วผลเป็นแบบบนี้ หรือเป้นยังไง เพื่อที่ ชาวอินโด เค้าจะได้ รู้ว่า

เราเองก็ไม่ได้นิ่งนอนใจนะ ที่มันเกิดปัญหาแบบนี้

ส่วน ข้อมูลที่ ต้องส่ง ให้ ทีมงานตรวจสอบ ก็ คล้ายๆของไทยค่ะ

1. ชื่อตัวละคร / ID

2. ชื่อ Item เจ้าปัญหาชิ้นนั้น

3. วันเวลา ที่เกิดปัญหา


เพื่อให้ทีมงานอินโดนีเซียตรวจสอบต่อไป

ถึงแม้ ตัวละครจะถูกลบไป แต่ ฐานข้อมูลยังเก็บ log ไว้ค่ะ

.......
* ข้อสงสัย กรณี ถ้าเป็น BUG โกเลม

ทำไม เจ้าของ ไอเทมเจ้าปัญหา จึงรู้ว่า ตัวละครใด ซื้อไป

เนื่องจาก การซื้อ ขาย ผ่านระบบ โกเลมนั้น
