คือไม่มีอะไรเปลี่ยน

สามารถใส่พร้อมกันได้

และอีกอย่าง

ถ้าใส่ ดาบมืด + โล่มืด ลงในคนที่มี Dark Add

มันจะมีผลเหมือน โล่มืด + Dark Add และ ดาบมืด + Dark Add ในคราวเดียว

จะว่าไงดีละ

ถ้าใส่ดาบมืดลงในคนที่มี Dark Add จะได้โล่มืดมาด้วย แต่โล่มืดจะไม่ได้มีผลเต็มๆเหมือนคนใส่โล่มืดให้

-คลาส 1 def bust, increase def, max Hp, shield mastery
-คลาส 2 food fighter, def assist, soul knight, protect, appeal
-คลาส 3 stigma blood (อย่างเดียว)
พอย์ทเหลือก็คิดเองว่าจะลงรัย
