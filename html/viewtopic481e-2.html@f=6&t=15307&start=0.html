อยากได้รูปรวมของPaint Paperใครมีช่วยลงหน่อยนะจ๊ะ


อธิบายการทำ หาPaperมา1แผ่น

(สามารถหาได้จากการนำBark PurifyItemจะได้>NewsPaper PurifyItemจะได้>Paper)
Bark หาได้จาก ต้นไม้ PaperWood,Mokuju(ตัวดรอปมาริโอเนทต้นไม้)
Newspaper หาได้จาก ต้นไม้ PaperWood(Farmerมีสกิลปราชญ์จะหาได้ง่ายขึ้นนิดส์นึง)
Paper หาได้จาก กล่อง1และกล่องไหนไม่รู้- -
ลงไปDownTownไปที่ตู้หยอดเหรียญทางด้านตะวันตก

เมื่อสอดกระดาษเข้าไปเครื่องจะทำการพิมพ์ภาพออกมา(สุ่ม)

ไปถามเพื่อนมา เพื่อนบอกว่าใช้ Ink Set ด้วยอ่ะ
ซื้อจาก North Stall Merchant ใน Downtown นั่นแหละ

ซื้อ 1 ขวดก่อนก็พอ เพราะ Ink Set จะสุ่มใช้แล้วหายไปเหมือนเตา Tatarabe (ถ้าเครื่องหมึกหมดแล้วเราไม่ถือหมึกอยู่ มันจะเตือนเราก่อนว่า หมึกหมด ให้ไปหาหมึกมาเติม แต่ถ้าเราถือหมึกอยู่ มันจะถามว่า เติมหมึกมั้ย)
บางทีทำ 20 แผ่น หมึกก็ยังอยู่ดี ไม่หมด ก็เลยไม่ต้องเติม เราก็ยืนใช้เครื่องต่อไปได้เรื่อยๆ


อนึ่ง เอารูป Paint Paper ตอนใช้งานมาฝากค่ะ แต่มีไม่ครบนะคะ

พอดีเพื่อนของเราเค้าเคยไปทำมาเยอะ แล้วพอสุ่มได้ลายที่ต้องการก็เลยโละลายอื่นหมดเลย บอกว่า เอาอันเดียวก็เกินพอละ ลายอื่นไม่ต้องการ อิๆ เราก็เลยได้ฟรีมา 4 ลายค่ะ

ชื่อของมันไม่ได้เป็นหมายเลขนะคะ แต่เป็นชื่อรูป
