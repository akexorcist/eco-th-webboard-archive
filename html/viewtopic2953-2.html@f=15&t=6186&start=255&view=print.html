Aussibum เขียน:
พระหาตัง เวลาไปปาร์ตี้ ก็เก็บของเลยที่มันตกอะ ปกติเค้าไม่ว่ากันหรอก ถ้าเค้าว่าแสดงว่าไม่ปกติ


Stat ของ พระ มีหลายแบบ

-1 Vit นำ เลือดเยอะ ถึก ยืนในตี้ ได้นานมาก
-2 Dex ค่อนข้างเยอะ (สัก70++) ร่ายเร็วทันกินแต่คนเล่น ต้อง เอาตัวรอดเป็น

และ Mag ก็อับในระดับนึง สัก70++
ส่วน INT แล้วแต่คน บางคนไม่ได้อับ


ถ้าไม่ใช่สาย ปาตี้นะ

สาย INT พระสายลาก
สาย Vit พระลุยแบบเดี่ยวๆเช่นพวกหุ่นชั้น 17+
สาย Dex เพียวๆนี่ไม่ไหวมั้งต้องตามด้วย INT สัก 40 สายลากเช่นกัน
เทรินเร็วด้วย คนเก็บวิ่งเก็บแทบไม่ทัน

ส่วนพระ สาย แชท จะมาเล่นทำไมวะ พาเพื่อนในตี้ตาย พอบอกแล้วก็ยังเหมือนจะเข้าใจ
แล้วมันก็แชตอีก เจอแบบนี้ลบชื่อเฟรนลิส เตะออกจากตี้ พร้อมด่าตามด้วย[/quote]

pick290628 เขียน:ถามหน่อยครับ ไม่ได้เล่นนาน พอมาเล่นใหม่ งง -- --*

1. เห็นคนรับตี้ พระอาวเดก มันคืืออะไรหรอครับ
อันเน้ อาจหมายความว่า พระคนนี้เขาหาเด็กมาดูด(เวลต่ำๆ ต่ำมากๆ) เพราะยิ่งเวลต่ำ คนเวลสูงจะได้EXPเพิ่มขึ้นด้วย(ตอน81 เลเวลเด็กดูดไม่เกิน10 ได้EXPเพิ่มเป็นร้อยๆเลย)
มั้งนะ

2. คลื่น มันคืออะไรครับ
Aqua Waveของเอเลเมนทาเลอร์ สกิลที่เกิดมาคู่กับออโต้เมาส์(เค้าล้อเล่นนนนนน >.<")
จะเป็นการยิงคลื่นน้ำสาดไปข้างหน้าระยะหลายสิบช่อง จะกว้างประมาณ3ช่อง
ใช้เก็บเวลในดัน ที่เป็นห้องยาวๆ(ทางเดิน)ได้อย่างดี
แต่ถ้าจะไปออโต้หอแสง เดี๋ยวผมเรียกจีเอ็มไปคุยเป็นเพื่อนให้นะครับ~♪
