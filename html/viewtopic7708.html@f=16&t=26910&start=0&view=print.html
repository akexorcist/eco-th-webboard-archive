โอ้จอร์จเราเอายังไงดีล่ะ
ซาร่าอย่ากลุ้มไป ชั้นลากคอคนโพสมาแล้ว
โอ้จอร์จมันช่างวิเศษอะไรอย่างงี้นะ
Wan Wan,Blacktan,BauBau จะเอาหมาอะไรดีล่ะ

Wan Wan กับ Blacktan เปลี่ยนเปง A ได้ง่ะจ้า
แด๋วนะแล้ว Blacktan จะเอามาจากไหนล่ะอ่ะฮ้า กขกท ยังถามมาไม่สนเลยหรออ่ะฮ้า
เดี๋ยวดิยังตอบไม่หมดอย่าเพิ่งแทรกเดี๋ยวปั๊ด - -*
Blacktan ต้องเอา Keetin ไปส่งที่ร้านสัตว์เลี้ยงใน Eastor Cape ให้ครบ 500000 อัน
มันจะขายให้อ่านะ
อ่อมันเปงอย่างงี้นี่เองนะอ่ะฮ้า

จขกท ถามมาอีกว่าถ้าจะเลี้ยง WanWan เหมาะที่จะเลี้ยง BauBau ใช่ปะอ่ะฮ้า
โอ้วซาร่าเกือบลืมไปเลย คนโพสตอบเด๊ะ - -*
WanWan พอเปลี่นเป็น A แล้วมันใช้สกิลเองได้อ่านะ Blacktan ก็เช่นกัน
BauBau เปลี่ยนเป็น A ไม่ได้แต่จะเก่งกว่า Wanwan กับ Blacktan (ตอนเริ่มต้น)

อ่อมันเป็นอย่างงี้นี่เองจอร์จ
เข้าใจแล้วใช่ไม๊ซาร่า
เปล่าเลยจอร์จ คนโพสพูดเข้าใจย้ากยาก
