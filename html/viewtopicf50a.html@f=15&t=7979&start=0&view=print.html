4.Status
ความหมายและผลลัพธ์ของค่าสถานะต่างๆ

STR มีผลต่อค่า ATK, MAX.PAYL
STR Bonus เมื่ออัพค่า STR ถึงจุดที่กำหนด ค่า ATK, MAX.PAYL จะเพิ่มขึ้น

DEX มีผลต่อค่า ATK, M.DEF, S.HIT, C.SPD, MAX.CAPA, อัตราการป้องกันของการใช้โล่ห์ และช่วยลดการเกิดสถานะผิดปรกติ
DEX Bonus เมื่ออัพค่า DEX ถึงจุดที่กำหนด ค่า S.HIT, C.SPD, MAX.CAPA จะเพิ่มขึ้น

INT มีผลต่อค่า M.ATK, M.DEF, MAX.SP, L.HIT, L.AVOID, MAX.CAPA และช่วยลดการเกิดสถานะผิดปรกติ
INT Bonus เมื่ออัพค่า INT ถึงจุดที่กำหนด ค่า M.DEF, L.HIT, MAX.CAPA จะเพิ่มขึ้น

VIT มีผลต่อค่า MAX.HP, MAX.SP, DEF, M.DEF, MAX.PAYL
VIT Bonus เมื่ออัพค่า VIT ถึงจุดที่กำหนด ค่า MAX.HP, DEF, M.DEF, MAX.PAYL จะเพิ่มขึ้น

AGI มีผลต่อค่า A.SPE, S.AVOID, L.AVOID
AGI Bonus เมื่ออัพค่า AGI ถึงจุดที่กำหนด ค่า A.SPE, S.AVOID จะเพิ่มขึ้น

MAG มีผลต่อค่า M.ATK, MAX.MP
MAG Bonus เมื่ออัพค่า MAG ถึงจุดที่กำหนด ค่า M.ATK จะเพิ่มขึ้น

***จะเห็นว่าค่า Status ส่วนใหญ่ ให้ Bonus ไม่เท่ากับ ผลลัพธ์ของค่า Status นั้นๆ
เช่น DEX มีผลต่อค่า ATK แต่ไม่ให้ Bonus เป็น ATK
ซึ่งก็ไม่ต้องไปสนใจมัน เพราะค่าที่ได้มันคือ Bonus

ATK = ความแรงของการโจมตีทางกายภาพ
M.ATK = ความแรงของการโจมตีทางเวทย์มนตร์

S.HIT = พลังโจมตีระยะใกล้
L.HIT = พลังการโจมตีระยะไกล

DEF = การป้องกันทางกายภาพ
M.DEF = การป้องกันทางเวทย์มนตร์

S.AVOID = การหลบหลีกจากการโจมตีระยะใกล้
L.AVOID = การหลบหลีกจากการโจมตีระยะไกล

A.SPD = ความเร็วในการโจมตี
C.SPD = ความเร็วในการร่ายเวทย์

MAX.HP = ค่าHPสูงสุด
MAX.MP = ค่าMPสูงสุด
MAX.SP = ค่าSPสูงสุด

MAX.PAYL = น้ำหนักของ ของที่บรรทุกได้
MAX.CAPA = จำนวนของ ของที่บรรทุกได้

3.การอัพสเตตัล

การอัพ Status สายต่าง ๆ ของ Kabbalist

A.สาย นักรบมืด !
A1.･AGI>STR>DEX>VIT
- สายนี้เน้นการหลบ และฟันเร็วเป็นหลัก โดยฟันแรง และความแม่นรองลงมา และสุดท้ายคือ อัพ vit เพื่อเพิ่ม hp บ้างเล็กน้อย สายนี้จะโดดเน้นเรื่องการโจมตีที่รวดเร็วและ หลบการโจมตีได้ดีระดับหนึ่ง ด้วยสกิลเปลี่ยนอาวุธเป็นธาตุมืดทำให้ชนะทุกธาตุ จึงเป็นสายที่มีความสมดุลพอสมควร จุดอ่อนคือความเปราะบาง และ ใช้เวทมนตร์ได้ไม่มีประสิทธิภาพเอาเสียเลย .. (ส่วนข้อมูลการใช้คำสาปยังไม่แน่ชัด ว่าขึ้นอยู่กับ Dex หรือ Int)

A2.･AGI>STR>DEX=VIT
- สายนี้เน้การตีเร็ว และฟันแรงรองลงมาเช่นกัน จะค่อนข้างคล้ายๆ กับสายแรก หากแต่สายนี้จะลดความแม่นยำ มาเพิ่มความถึกแทน ทำให้ตายยาก มากกว่าสายด้านบนมากขึ้น

A3.･STR>AGI>DEX
- เน้นตีแรงเป็นหลัก เป็นสายที่ตีแรง และ เร็วมากที่สุดในทุก ๆ สายของนักรบมืด ยิ่งมีเวทย์เปลี่ยนอาวุธเป็นธาตุมืดอีก ทำให้เป็นสายที่ทั้งแรง และเร็วน่าเล่นอีกสายหนึ่งเลยทีเดียว จุดอ่อนคือความเปราะบาง และ ใช้เวทมนต์ได้ไม่ดีเท่าที่ควร

A4.･STR>VIT>DEX
- เน้นตีแรง แต่ช้าที่สุดในทุก ๆ สาย สิ่งที่ทดแทนขึ้นมาแทนนั้นคือ ความถึก และ hp สูงนั้นเอง เหมาะสำหรับเป็นตัวแท้งได้ในระดับหนึ่ง อันเนื่องมาจากการเปลี่ยนเกราะเป็นธาตุมืด ทำให้ธาตุอื่นๆ โจมตีเข้ามาเบากว่าที่จะเป็น จุดอ่อนคือ การโจมตีช้า และใช้เวทมนต์ได้ไม่ดีเท่าที่ควร

B.สาย นักเวทย์มืด
B1.･MAG only
- สายบ้าพลัง เน้นยิงทีเดียวให้ตาย ถึงจะร่ายช้า เปราะบาง หลบไม่ดี โจมตีห่วย แต่เวทย์แรงตูมเดียวจอด เหมาะสำหรับเน็ตดี ๆ และเสต็ปการวิ่งหนีสูงเมื่อมอนไม่ตาย -*-

B2.･MAG>DEX
- สายเวทย์แรง อีกทั้งยังเร็วเสริมขึ้นมา ลบจุดอ่อนการยืนร่ายช้าเป็นเป้านิ่ง เป็นนักเวทย์สายยอดฮิตในหลาย ๆ เกมส์ จุดอ่อน บาง หลบไม่ดี ..

B3.･MAG>INT
- (ด้วยเหตุมีการอัพint จากทางเวบของญี่ปุ่น) ทำให้คาดว่าสายนี้ น่าจะเป็นสายที่ใช้คำสาปติดง่ายขึ้น ! นั้นหมายความว่า สายนี้เป็นสายที่เน้นการโจมตีรุนแรง และการใช้คำสาปติดง่ายขึ้น ! แต่ยังคงร่ายช้า เหมือนกับสายแรก จุดอ่อนก็เหมือนเดิมๆ -*-

B4.MAG>>INT=DEX
- สายนี้เป็นการผสมผสานระหว่างการร่ายเร็ว และการใช้คำสาปได้ดี (โดนคำสาปยากขึ้นด้วยแหละ) เป็นสายที่น่าสนใจอีกเช่นกันสำหรับคนที่จะเล่นป่วน ๆ ใช้คำสาป!

B5.･MAG>>AGI
- เป็นสายเวทย์ออกแนวบู๊ ๆ ประเภทถึงฉันจะร่ายช้า แต่แกก็ตีฉันไม่โดน โฮะๆ -*-

B6.･MAG>>VIT
- สายเวทย์ถึก (มิรู้ว่าเกมส์นี้เวลาร่ายเวทย์โดนขัดจังหวะหรือเปล่า ต้องรอดูอีกที) สายนี้ตายยากที่สุดในบรรดาสายนักเวทย์ที่กล่าวมา ข้อเสียที่มาแทนนั้นก็คือ การร่ายเวทย์ช้า และคำสาปง่อยไม่ติด -*-

B7.･MAG>>DEX=VIT
- อีกสายหนึ่งที่ประสมประสาน ระหว่างการร่ายเร็ว และ อึดขึ้น (เป็นสายยอดฮิตในเกมส์ดัง ๆ อย่างRo) ซึ่งเหมาะที่จะเล่นในระยะยาว เผื่อการเล่นสงครามเป็นต้น !

C.สาย นักรบเวทย์
C1.･STR=MAG
- เป็นสายที่ใช้สกิลได้มีประสิทธิภาพสูงที่สุด เพราะตีใกล้ก็แรง ไกลก็แรง ใช้สกิลคุ้มค่าเกือบทุกสกิล (ได้ข่าวมาว่า ญี่ปุ่นเล่นสายนี้มากที่สุดเลยล่ะ) เสียด้านอึด และ หลบ แต่อาจชดเชยด้วยสกิลแปลงร่าง !

C2.･AGI>STR>MAG>DEX
- เป็นสายที่เพิ่มการหลบหลีกเด่นขึ้นมาผสมผสานการโจมตี ทั้งเวทมนต์และกายภาพ ! ตบท้ายด้วยการอัพ Dex เพื่อการร่ายเวทย์เร็ว และโจมตีแม่นขึ้นอีกด้วย จุดอ่อนคือบาง -*-

C3.･MAG>AGI>STR
- สายนี้เน้นการใช้เวทมนต์มากที่สุดในสายนักรบเวทย์ หลบดีพอสมควร และสามารถบู๊เองได้ในบางโอกาส (ใช้สกิลโจมตีได้นั้นเอง) อีกทั้งสายนี้ยังใช้สกิลแปลงร่างได้ดี เพราะไม่ว่าจะค้างคาว หมาป่า ก็เล่นบู๊ได้ แปลงเป็นจอมมาร ก็ใช้เวทย์ดี !

D.สาย ก่อกวน
D1.･DEX>>MAG
- เน้นการร่ายเวทย์เร็วไว้ก่อน ร่ายเวทย์ขัดจังหวะศัตรูได้ดีเยี่ยม ก่อกวนได้ดีระดับหนึ่ง ข้อเสียคือเก็บเวลยาก ต้องมีคนให้ดูด -*-

D2.･INT ล้วน
- เน้นบ้าคำสาปอย่างเดียว สายนี้ดูดกระจาย ! แต่พอถึงเวลาสงคราม จะเป็นสายที่น่ากลัว บ้ามากๆ คำสาปติดทุกเม็ด ยิ่งมีสกิลใครมาโจมตีติดหินอีกต่างหาก !

D3.･MAG=INT
- เป็นสายที่พอเก็บเวลเองได้บ้าง (อย่างน้อยก็ดีกว่าสายข้างบน ถึงคำสาปจะติดยากกว่านิดนุง) สำหรับคนที่ไม่มีใครให้ดูด แต่อยากก่อกวนนิหน่า !
