ทุกอาชีพครับ ถ้าไม่รวมมังกรดำ เพราะขี่ได้เฉพาะบรีดเดอร์

3. มังกร ต้องให้อาหารมันรึป่าวครับ
ให้ก้ได้ไม่ให้ก็ได้ คือให้มันก็เพิ่มเลือด ไม่ให้มันก้อาจโดนมอนอัดตาย
