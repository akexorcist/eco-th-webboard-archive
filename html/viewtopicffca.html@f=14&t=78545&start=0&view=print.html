แต่พวกอาหาร หรือยาต่างๆที่เพิ่มได้ดีในระดับ 250-450 (ยังไม่รวมผลจาก skill ต่างๆของตัวละครคุณอีก) สามารถหาทำได้เองครับ

พวกยาจะกินไว น้ำหนักไม่มาก แต่อาจจะได้ hp ไม่เยอะ
ส่วนพวกอาหาร กินช้าหน่อย น้ำหนักเยอะ แต่ทำง่าย และเพิ่มพลังได้เยอะครับ

พวกยาแนะนำง่ายๆสองอัน
อันนี้น้ำส้ม วิธีทำต่างจากอาหารและยาอื่นๆ ต้องให้ NPC เฉพาะที่ Fareast ทำให้ครับ(แต่ทำง่ายนะ)
