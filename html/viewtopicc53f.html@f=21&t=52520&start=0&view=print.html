ก็สลบเหมือดคาที่"โย่ จารย์ใหญ่อยู่ที่นี้ใช้ไหม"saitoเอ่ยถาม อาจารย์ ใหญ่ผยักหน้า

"โฮ่ ไม่นึกว่าจะพังห้องครูใหญ่นะเนี้ย หือ saito" "ชิ เงียบไปเรื่องงานคราวนี้ว่าไง"

saito ตัดบทแล้วถามเรื่องอื่นแทน"โฮ่ ขยันทำงานดีนะเนี้ย"อาจารย์ใหญ่ตอบแบบขำๆ

"ชิ"saito เริ่มไม่ค่อยสบอารมณ์"โฮ่ๆ" "อาจารย์ใหญ่เป็นคนที่มีอารมณ์ขันดีจริงๆ"saito

พูดเบาๆ"เอาละงานในครั้งนี้ให้ไปกำจัดปีศาจ3ตัว ไหวรึเปล่าละ โฮ่ๆ" อาจารย์ใหญ่ถาม

"เหอะ แค่3ตัว ค่าจ้างคงขี้ประติ๋วแหง่" saito เริ่มเซง"โฮ่ๆ ค่าจ้างคราวนี้ก้อ 4000G"

"ก็ได้รับ รับ รับ เงินค่าเช่าบ้านก็ใกล้หมดแล้วด้วย" "โฮ่ รับเพราะเงินหมดเหรอเนี้ยโฮ่ๆ"

"เจ้าปีศาจคราวนี้มันดวงกุดแล้ว"
