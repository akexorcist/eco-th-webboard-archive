ดูในรูปน่าจะตอบอะไรต่างๆได้ทั้งหมดนะ



ขอบคุณครับที่ช่วยดึงมาให้ดูเป็นข้อมูล

แต่ตรงนั้นพอจะทราบดีอยู่แล้ว อาจจะเป็นเพราะผมตั้งคำถามไม่ชัดเจน หรือใช้คำผิดไป


ที่ผมตั้งคำถามหมายถึงว่า หากจัด status ทุกอย่างให้เท่ากันหมด
คือเฉลี่ยลง str agi vit mag dex int

ให้มีค่าเท่ากันทั้งหมด อุปกรณ์สวมใส่เดียวกันเลเวลเท่ากัน

ระหว่างไนท์กับดาร์ค ผลที่ออกมาจะเหมือนกันไหม

เพราะถ้าเหมือนกันทุกประการ ผมก็ไม่จำเป็นต้องสวิซ์กลับไปไนท์เมื่อดาร์คตันแล้ว

หรือถ้าไนท์มีค่า HP ที่เหนือกว่า หรือ DEF ที่เหนือกว่า ใน status และอุปกรณ์เดียวกัน ก็จะได้พิจรณาเลือกแนวทางเล่น

และสมตติว่าถ้าไนทืมีค่า HP และ DEF ที่มากกว่าดาร์ค ใน status และอุปกรณ์เดียวกัน

ดาร์คจะมีค่าอะไรที่เหนือกว่าไนท์หรือเปล่า เช่น ASPD หรือ ATTACK

(ผมสมมตินะครับคือผมไม่ทราบ เลยมาตั้งคำถาม)
