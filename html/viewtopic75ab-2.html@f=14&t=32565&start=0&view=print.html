สกิล บีส หรือ บาซาค มันต้องอัพคู่กะอีกสกิลที่ช่วยควบคุมใช่ป่าวอ่ะ

แต่ผมเห็นว่า กระทู้ไกด์สวอด เหมือนจะแนะนำให้อัพ แต่ไปเอะใจตรงว่า ต้องมีค่า int ตั้ง 40 ถึงช่วยควบคุมได้ 50 เปอร์เซ็น แล้วจะแนะนำให้อัพไปทำไมอ่ะ สกิลนี้ เสียไปอัพ int ตั้งเยอะ ลดค่าเอจิ สเตรง เด๊ก ไปบานโขเลยอ่ะ
