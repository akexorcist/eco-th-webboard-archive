เอาของตัวเองมาโพสเอิ้กๆ

ภาพทั้งหมด มาจากการไปถ่ายที่ การรวมกลุ่มกันของ ฟาร์มเมอร์ เราไม่ได้เป็นฟาร์มเมอร์หรอก เราเป็น Vates แต่เล่นใหม่เพื่อไปงาน ><

งาน สวนดอกไม้ ของเจ๊ ซิ้มโบ๊ะ

ที่ ฟาร์มลับ ฟาอิส



ภาพนี้ก็เอารูปตัวเองมาลง สร้างตัวใหม่เพื่อนไป งานสร้างสวนดอกไม้><


รูปใครก็น่าจะรู้ตัวใหญ่ๆ ^^ แล้วก็หุ่นใครไม่รู้(ไม่รู้จิงๆมายืนเฉย!!) หนูแก้ผ้า ฮ่าๆ


ถ่ายกันจนเหนื่อย นอนล้า ^^ ดูตัวใหญ่มักๆ><


บะบายโคสเบต้า


ใครหว่านั้นมายืนดูเราถ่าย


ลุงแห้ว หนอนจะเข้าแล้ว หุบ !!
แต่ละคนหอบข้าว หอบของกลับบ้านเก่ากันหมด ถือกันพลุงพลัง เอิ้กๆ




อยู่ใน ฟาวร์เวอร์การ์เด้น ในฟาร์มลับ ถนนฟาอิส รึป่าว>< น๋านละ ><
