มันจะค้างงงง....แล้วรู้สึกว่ามัน ซู่ๆด้วยครับทำยังไงดีครับจีเอมทุกๆคน

ปล.ตอนที่ผมเข้าไปแล้วก็เข้าได้นะครับพอไปถึงตอนที่ผู้หญิงโดมิเนี่ยนคนนึงที่ใส่ชุดสีดำอะครับแล้วมันก็ค้างเลย TT"
ทำยังไงดีครับ จีเอมมม ช่วยผมทีครับ T^T"

ปล.2 รบกวนกรุณาตอบกลับโดยเร็วที่สุดนะครับ ToT"

ปล.3 ก่อนหน้านี้ผมก็เล่นได้ดีเหมือนปรกตินะครับแต่ทำไมตอนนี้ผมเล่นไม่ได้ ฮือออๆ TiT
