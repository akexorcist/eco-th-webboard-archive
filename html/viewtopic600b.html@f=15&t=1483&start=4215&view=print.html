อีกอย่างมันเป็นกิจกรรมที่ทำให้คนในริงมารวมตัวด้วยอ่ะ ( ถ้า nvn ไม่มีใครสนเลยในริงนี้)

อาจเพราะได้โชว์ฝีมือ โชว์ pet ด้วยล่ะมั้ง




อีกเหตุผล ถ้า nvn ไม่มีการสิง ก็คงเข้าไปเล่น เพราะเกลียดการสิงมาก เราเล่นตัวคนเดียว

ก็ไปเล่นกันเยอะ เพื่อนเยอะกว่า ลุยตี้ด้วยกัน ผจญภัยด้วยกัน สนุกกว่าไหนๆ )
