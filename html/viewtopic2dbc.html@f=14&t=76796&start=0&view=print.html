เข้ามาแย้ง = =

เก้บเวล จำเป้นต้อง agi ? เห้นยังไงก็เรียกหาพระอยู่ดี กว่าจะเจ๋งต้องเวลสูงๆนู่น

สาย vit ถึกๆเลย ?? แรกๆต้อง str นำ vit ติดตัวไว้นิดหน่อย สกิลมันอย่างเดียว กระหน่ำ iai ไป ( ค่าโทนิคถูกกว่าค่าอาหาร )

ไปทางสายสกิล ควรเปลี่ยนเป็น blademaster มากกว่า ทั้งเรื่องโบนัส str และสกิลสนับสนุน
ส่วน bounty สำหรับพวก agi แต่ก้มีสกิลสำคัญควรดึงมาตั้งแต่เพิ่งเปลี่ยนคือ iai combo

ทริกหลักคือเก้บศัตรูให้ได้ ใน 1 คลิ๊ก ( คลิ๊ก iai combo นั่นแหละ ) ดังนั้นจึงต้องการ str ที่สูง ซึ่งยังแรงไม่พอหรอก เอาอาวุธไปเจาะรุ ยัดการ์ดเพิ่มธาตุไป แล้วจะแรงขึ้นทันตา (ไม่ต้องห่วง ค่าเจาะรู ไม่เกินหมื่น + การ์ดอีกอีกหมื่น รวมเป็น 2 หมื่น เด็กๆหาได้อยู่แล้ว ชิวๆ ไม่ต้องเอาการ์ดแพงๆใบละเอ็มหรอก atk ยังต่ำอยู๋ แรงต่างกันไม่กี่หน่วย orz ) แล้วจะ 1 คลิ๊กสบายๆ เลือกมอนตามธาตุหน่อย

ช่วงหลังๆ ก็ไปลากในห้องสี่เหลี่ยมๆ อยู่ได้ทั้งชาติ 555 อย่าลืมอัพ provocation จะลากมันส์มากๆ

ถ้าเริ่มมองเห้นแววว่าไม่รุ่ง เลเวลพ้นกลางๆ ช่วง 60+ หนีไปอัพ agi ก็ได้ (ถึงได้บอกให้ str นำ) และก็จะเข้าตาม step สามัญ SDC ฟันเอาอย่างเดียว ไม่ต้องห่วงยังไงก็เรียกพาพระอยู่ดี ฮาๆ ถ้าไม่คิดจะปั้มยา

ถ้ายินดีก็ จิ้ม str และ vit ต่อไป
