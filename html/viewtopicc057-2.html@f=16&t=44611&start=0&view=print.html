Analysis มันอาจจะมีผลมากขึ้นกับคนที่มีปราชญ์นั้นๆอยู่แล้ว อย่างเรนเจอร์เรามี ปราชญ์แมลง แล้วถ้าเราใช้ Analysis ของแมลงใส่มอนฯตัวที่เป็นแมลงก็อาจจะทำให้โอกาสได้ของจากปราชญ์นั้นเพิ่มขึ้น แต่ถ้าคนไม่มีปราชญ์เลย อย่าง Swordman ถ้าเราใส่ Insect Analysis ใส่หนอนขน นาย Swordman คนนั้นก็มีโอกาสตีตก White fur ได้

ปล.แต่ก็ไม่กล้าฟันธงอยู่ดี เพราะเคยอัพสกิล Insect Analysis แล้วลองตีหนอนขนที่แมปโมโม่ ผลของการดรอป White fur มันไม่แตกต่างจากตอนไม่ร่าย Analysis ใส่จนเห็นได้ชัดเท่าไรเลย
