พอดีเพิ่งเริ่มเล่นแบบว่ามีเพื่อนพาเก็บพาดูด หาของให้ทุกอย่างเลย
จนเลเวล51และ
เล่นมาประมาณหลายเดือนแล้วก็เลยยังไม่ค่อยรู้เรื่องอะไรมาก

วานถามคนในบอร์ดหน่อยนะครับ

-ไอเทมมาริโอเน็ตต้องหาจากไหนอ่ะครับ(มีรูปด้วยจะดีมากเลย)

-ไอเทมสัตว์เลี้ยงแบบต่างๆหาจากไหนบ้างอ่ะครับ

-ไอเทมที่เป็นกองไฟที่เวลานั่งแล้วเอชพีเด้งเอาๆอ่ะครับ หาได้จากไหนบ้าง

-จะได้สวนลอยฟ้าต้องทำยังไงอ่ะครับ

อ่าครับ ขอบคุณล่วงหน้าทุกคำตอบนะครับ
