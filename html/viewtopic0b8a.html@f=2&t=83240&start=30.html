เจอ 3 อีเวนท์ผสมกันเลยครับ

1. รับเควสจากผับมาสเตอร์ไม่ได้
เราไปรับงานจากผับมาสเตอร์มาครับ
เราจะได้ บัตร์เข้าเมืองมอร์ค 1 ใบ กับเงินล่วงหน้า 3000
อีเวนท์นี้เป็นอีเวนท์เปิดร้าน 3 พี่น้องแม่ค้าในดาวน์ทาวน์ครับ
มีขายของใช้ราคาถูกหลายอย่าง ส่วนรายล่ะเอียนเควส ตาม Quote ด้านล่างนี้เลยครับ
(เป็นภาษาญี่ปุ่นนะ)

เควสร้านเหล้าดาวทาว ゴルドーの遺言状
- สำหรับคนที่(เผลอ)กดรับเควส ได้เงิน3000G + บัตรมอร์ค Morg มา
- ไม่สามารถซื้อของจากร้านเหล้าดาวทาวได้เมื่อติดเควส



ลิ้งค์รายละเอียดเควส ゴルドーの遺言状
http://ec.gamedb.info/wiki/Event/Others.html#o2e9e49b



2. อีเวนท์สำหรับสอนผู้เริ่มต้น
ในนี้คือ บ้านของอีมิล ครับ

หลังจากทิทาส่งเรากลับมาจากฝันมาที่ดาวน์ทาวน์ จะอยู่แถวๆหน้าบ้านอีมิลนี่แหละ
อีเวนท์นี้มี navi นำทางครับทำง่ายมาก แค่เดินๆไปคุยกับ กลุ่มของอีมิลตามที่ต่างๆในเมืองอโครโพลิส
อีมิลในบ้านของอีมิล เบเรี่ยลในผับ มาช่าบนบ้านบิน รูรูเยในโบส์ดำ ทิทัสในโบสถ์ขาว
จะได้บัตรเข้าอัพทาวน์ ของเล็กๆน้อยๆ และเกราะสีเขียวสำหรับผู้เริ่มต้นจนครบครับ


3. อีเวนท์หัวใจเครื่องจักร์
ที่เจอเดมในบ้านของอีมิล
อันนี้เป็น Cross Event ของเผ่าธรรมดา 3 เผ่า กับเผ่าเดมครับ ซึ่งเนื้อเรื่องจะไม่เหมือนกัน
เผ่าธรรมดาจะทำได้แค่หัวใจเครื่องจักร์อีเวนท์เดียว
ส่วนเดมจะทำอีเวนท์ออโต้มาตะต่อจากอีเวนท์นี้ได้ครับ
