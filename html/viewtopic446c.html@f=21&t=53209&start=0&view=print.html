อาชีพนี้เป็นอาชีพที่แต่งขึ้นเพื่อความสนุกสนานของคนแต่งเพียงอย่างเดียวเท่านั้น

ขอบคุณบุคคลหลายคนที่นำสกิลของเกมต่างๆมาลงเป็นลายละเอียดในลายเซ็นต์


Webboard user เป็นอาชีพที่มีทักษะในการใช้เวปบอร์ดสูง แต่ พลังโจมตีต่ำ โดยมีสกิลที่เพิ่มความเร็วในการโจมตีเยอะพอควรมาทดแทน

อาวุธที่ใช้ได้ คีย์บอร์ด เมาส์
คีย์บอร์ดจะเป็นอาวุธประชิด แต่ สกิลที่เพิ่มความเร็วอาวุธนี้จะมีเยอะ
เมาส์จะโจมตีได้ประมาณ2ช่อง แต่ดาเมจเบากว่า มักจะใช้ในกรณีต้องการให้ศัตรูติดสถานะบางอย่างจากสกิล...
