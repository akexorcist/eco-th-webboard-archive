คุณคิดผิดอย่างแรงแล้วล่ะครับ(ก็งี้ล่ะความคิดเด็กๆ) คุณไม่รู้หรอกวันๆจีเอ็มเค้าต้องทำอะไรบ้าง ต้องมานั่งทำข้อมูลตั้งเยอะแยะ เข้าเกมมาก็ใช่ว่าจะเล่นซะที่ไหนล่ะ ต้องมานั่งประกาศหรือคอยโดนคนเล่นรุมถามนู่นถามนี่ แถมเวลากิจกรรมมีปัญหา จีเอ็มไม่ได้คิด แต่ก็โดนผู้เล่นรุมด่า เงินเดือนก็ไม่ได้เยอะแยะ ของแรร์ใส่ไปก็เท่านั้น มันไม่ได้เท่กว่าผู้เล่นเพราะเค้ารู้ว่าเป็นจีเอ็มยังไงก็ได้ใส่อยู่แล้ว
