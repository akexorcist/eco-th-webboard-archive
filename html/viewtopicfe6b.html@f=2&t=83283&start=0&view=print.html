Palringo
เป็นโปรแกรมแชทมีปัญหาอะไรถามสดในนั้นได้เลย

เพื่อที่จะได้มีข้อซักถามกันในหลายๆเรื่องของเซิฟยุ่น ขอเชิญมาแชทที่นี่ก่อนเล่น เพื่อประโยชน์ของทุกๆคน
โหลดที่นี่
https://www.palringo.com/en/gb/download

เลือก Windows Download (Download for Windows PC)

สมัคร ID ที่เว็บให้เรียบร้อย จากนั้นเมื่อโหลดเสร็จ โปรแกรมจะหน้าตาราวๆนี้
(ตอนลงโปรแกรมถ้ามันถามว่าให้ลง Growl มั้ย ไม่ต้องลงก็ได้นะครับ)


ของคุณที่พึ่งลงใหม่จะยังไม่มีห้องให้เห็น ให้ทำตามขั้นตอนนี้ก่อน

1. กด Groups ที่อยู่ข้างบน
2. กด Join a Group
3. ในช่องว่าง ใส่ "eco-th"

เรียบร้อย แค่นี้คุณก็โผล่ในห้องแล้ว



- วิธีแชทหน้าหลัก ให้ดับเบิลคลิกที่รูปเลเนตจัง (eco-th ข้างบน) จะโผล่หน้าต่างคุยขึ้นมา
- เวลาจะซิบหาใครให้ดับเบิลคลิกที่ชื่อในลิสท์ข้างล่างครับ จากรูปตัวอย่างตอนนี้ก็มีอยู่ 3 คน



วิธีโพสรูป ที่หน้าต่างแชทให้กด photo จะมีปุ่ม capture photo กดเข้าไป จะมีให้เลือกว่า
- Capture อันนี้คือใช้กล้อง cam ถ่ายสดๆเลยครับ
- Load file ไว้โหลดรูปสกุล jpg bmp gif ฯลฯ จากเครื่องมาโพส
- Paste ไว้โหลดรุปที่คุณพึ่งกด printscreen หรือ copy มาหมาดๆเมื่อครู่ครับ
- Send กดเพื่อส่งรูปที่คนจะโพสลงห้องแชทครับ

*ข้อแนะนำเรื่องการโพสรูป เพื่อไม่ให้คนอื่นโหลดรูปอืดดึงเนตช้า ผมแนะนำให้เอารูปที่คุณ printscreen มาไปตัดก่อน
เช่น คุณติดตรงสมัครไม่ได้เพราะกรอกอะไรบางอย่างผิด ก็ printscreen จากนั้นเปิดโปรแกรม paint ไปตัดมาเฉพาะ
ส่วนที่เป็นสีแดงว่าคุณกรอกผิด จากนั้น copy มาวางโพสในห้องแชท เป็นต้น
