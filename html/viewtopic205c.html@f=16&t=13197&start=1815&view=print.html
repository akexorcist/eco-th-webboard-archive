ตอนจะเปลี่ยน เพื่อนก็ช่วยขนกันมาช่วย ทั้งๆที่ตอนนั้นก็อยากจะนอนแล้วล่ะนะ แต่เกรงใจเพื่อน เขาอุตส่าห์จะช่วย ปรากฏว่าขาดหญ้าmeetee เพื่อนก็อุ้มไปที่ฟาร์อีส ตีหญ้าจนได้มา แต่แล้วทุกคนก็เกิดหันไปปราสาทอันเดทเพื่อช่วยเพื่อนอีกคนหาsoda treasure โดยแบกผมไปด้วย ผมยังช่วยทำไรไม่ได้ ออกไปก็ตาย เลยได้แต่เสกฮีลลิ่งทรีช่วยฟื้นพลังให้...

ตี2เพื่อนหาของเสร็จ ก็กลับมา บอกจะอยู่ช่วยจนผมเปลี่ยนอาชีพได้ เย้ย อั๊วะง่วงเลี้ยว แต่ก็ไม่กล้าบอก เลยวิ่งหาของต่อจนเปลี่ยนได้สำเร็จ รีบปิดเครื่องมุดที่นอน เฮ้อ...
