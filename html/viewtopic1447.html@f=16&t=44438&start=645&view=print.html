ในความคิดเรานะ (แต่ส่วนใหญ่เราจะเล่นคนเดียว ริงก็ร้างไปแล้ว เพื่อนก็เลิกเล่นไปจะหมดแล้ว เวลาล่าบอสเราจะเล่นสาย FT มากกว่าเรน เพราะเรนมีจุดด้อยเรื่องสกิลหมู่ที่หวังผลได้น้อย และการวางกับดักเพื่อกันลูกบอสกว่าจะเสร็จ ถ้าในบริเวณนั้นมีอาชีพสายอื่นๆอยู่ บอสก็ถูกสายอื่นๆจัดการไปแล้ว )

บทบาทคงจะเป็นสกิล Gathering Class ที่ใช้ในการกระจาย knowledge ให้สมาชิกในปาร์ตี้ทุกคน (บอสบางตัวต้องใช้ knowledge ในการดรอปของหายากบางชนิด)

ส่วนเควสบอสมังกรโหด เรนเจอร์ จะได้ผลจากสกิล lucky ในการหลบเวทได้บางครั้ง และเควสออกจากเกาะใหม่ต้องหาไข่มุกจากหอยที่เป็นมอนเตอร์ประเภทแมลง สกิล knowledge ของเรนจะช่วยให้หาเปลือกหอยได้ง่ายขึ้น (เปลือกหอยเมื่อนำมา refine จะได้ ไข่มุก หรือ เปลือกไข่มุก [เควสแม่ค้า] ) แต่สามารถเลือกทำเควสรับ Skill point โจรสลัดแห่งโลกเงียบ (เควส วิญญาณโจรสลัด Collins กับ Uruz) เมื่อจบเควสจะได้ไข่มุกมา 1 อัน ใช้กลับเมืองได้

ส่วนเรื่องกับดัก ที่จะใช้ในการล่าบอส ถ้าสมาชิกสายลุย (Figther) ในปาร์ตี้ไม่พลาดจริงๆ ก็แทบจะไม่ได้ใช้



ขออภัยด้วยที่ช่วยได้ไม่มาก เพราะมีประสบการณ์เรื่องไปล่าเป็นปาร์ตี้น้อยมากๆ
