พอดีไปเอจ ข้อความนี้มา เลย ทำให้ งง กาน ซะงั้น แง

การที่จะเลือกเผ่าไหนที่สเตตัส ต้องดูก่อนครับ ว่าเราเล่นสายไหนอย่างเช่นเล่น MAG + DEX + VIT ก็นำค่ามาเขียนไว้ อย่างเช่น Emil MAG 3 + Dex 3 + VIT 10 แล้วนำมาบวกกัน 3+3+10 จะได้ค่า point ที่ได้ในการเริ่มต้น ของแต่ละเผ่า โดยค่าที่มากกว่า 6 ต้องแบ่งออกเป็น 2 ส่วน คือ 6 + ค่าที่มากกว่ามัน (n-6) หรืออาจเข้าสูตร 2n-6 ก็ได้ โดย n คือจำนวนที่มากกว่า 6
ดังนั้นถ้าเล่นสาย MAG + DEX + VIT เผ่า Emil : 3 + 3 + (2*10-6) = 20
MAG + DEX + VIT เผ่า Taitania : (2*10-6) + 3 + 4 = 21
MAG + DEX + VIT เผ่า Dominion : (2*8-6) + 5 + 1 = 16


ขอถามอีกสักหน่อยนะครับ เพิ่งไปดูเตตัส เริ่มต้นมา ดูเหมือนว่า เผ่าปีศาจ จะโจมตี เบาที่สุดเลย(หรอครับ)

INT ก็น้อย MAG ก็น้อยอ่าครับ มีDEX ที่มากอยู่ คือ 5 แล้ว อย่างนี้ จะเล่น เผ่า เทวดาดีมั้ยครับ

หรือว่ามันแล้วแต่คนชอบ เทวดา จะเน้นแรง แต่ปีศาจจะเน้น ความเร็วในการร่าย

เอ หรือว่า -3- มานอยู๋ที่การอัพเตตัสเริ่มต้นมานไม่เกี่ยว -*-

แล้วตกลงเผ่าไหนเหมากับอาชีพนี้หรอครับ :x
