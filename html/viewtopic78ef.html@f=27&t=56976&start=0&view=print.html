โดย ECO
คืองี้ครับผมฝากของจิปาถะไว้ในคลังทั้งที่เมืองกลางแล้วก็เกาะฟู ทีนี้วันนี้พอผมจะมาเอา
คทา 70 ที่ฝากไว้ในคลังที่เกาะฟูไปใช้ ลากไอเทมออกมาจากคลังแล้วมันไม่ขึ้นให้กดใช้อ่ะครับ แต่พอจะฝากกลับเข้าไปใหม่มันก็บอกว่ามีให้ฝาก(อธิบายงงป่ะครับ ?) ผมก็ลองไปเรื่อยๆกับไอเทมอื่นๆด้วย ปรากฎว่าเป็นแต่เฉพาะไอเทมที่เป็นอาวุธอ่ะครับที่พอลากออกมาจากคลังมาใส่ที่ตัวเองแล้วไม่มีรูปไอเทมขึ้นมา กดใช้ก็ไม่ได้ (ไอเทมอื่นๆใช้ได้หมด) ลองกับตัวอื่นในไอดีอื่นก็เป็นเหมือนกัน ถามหน่อยครับว่าใครเคยเจอแบบนี้บ้าง มันคืออะไร ? บัคเหรอครับ ?
