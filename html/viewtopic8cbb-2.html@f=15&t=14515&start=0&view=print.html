ทำได้ตอนเวล20 คับ

ให้เอา Crystal ไปหาหมอดูที่ดาวทาว หมอดูจะบอกว่า

ต้องการคริสตัลที่มีพลังอบอวล ให้นำคริสตัล ไปหา ภูติประจำธาตุ ธาตุอะไรก็ได้

-ธาตุดิน อยู่แม๊พก่อนทางเข้าเมืองฟาอีส
-ธาตุน้ำ อยู่แม๊พ Snop
-ธาตุไฟ อยู่แม๊พ Steap Desert ที่มีบอสไฮดร้า
-ธาตุลม อยู่แม๊พ Warship Island

ไปหาธาตุใดธาตุหนึ่ง แล้วกลับมาหาหมอดู ก็จะได้ คทา52

ถ้าทำเหมือนเดิมอีกรอบ จะได้ Skill point 1point
