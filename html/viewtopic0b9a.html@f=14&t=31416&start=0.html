แหล่มสุด

dex ซัก 40+ เอาไว้เวล
int แค่ 20 ก้อพอแล้วมั้ง ถ้าไม่ใช่ว่าจะเอาไปต่อกรกับกันเนอร์นะ

สายปืนน่ะข้อเสียข้อมันคือ "ชาตินี้ไม่ได้เวลหร้อก กินเอสเยอะมาก"

ถ้าเคยเร่ร่อนไปกระทู้เกี่ยวกับกันเนอร์น่ะ ที่ว่า "ตีบวกปืนด้วยหินพาว ดีสุด"
แต่พอมาอยุคอม บอกได้เลยครับว่า "ไม่ใช่"
เพราะมีสกิลคริ ตีบวกคริปืนสัก 4-5 ทีก้อพอแล้วนะ (ความคิดเห็นส่วนตัว)
***job 34 ถ้ายังไม่มียิงรัว ผมว่านะ "อย่าเล่นจะดีกว่าสายนี้"

Ps. จะไปเล่นกันเนอร์เสียทีเดียว บอกตรงๆ เป็นไปไม่ได้
อาชีพนี่ไม่มีพวกชาร์จช๊อตเหมือนกันเนอร์นะเออ
ทางที่ดี ควรมีเอจิไว้บ้างนะ (90 อย่างต่ำ) ถ้าไม่มี บอกตรงๆ เวลไม่ไหว

สำหรับผมตอนนี้เรียกว่าสายผสมปืนกรงเล็บก็ได้มั๊ง เพราะอัพ Hand gun mastery กะ ยิงรัวแล้ว แล้วก็เห็นด้วยว่า เปลือง SP จิงๆ ง่ะ

ดูๆแล้ว ปืนจะเหมาะกะ PVP มากกว่า ส่วนถ้าจะเวล เล่นกรงเล็บดีกว่า ใช่ป่ะคับ

อันนี้ส่วนตัวผมว่ากรงเล็บกะปืนดูไปกันไม่ค่อยได้อ่ะ เพราะเสียสกิลไปกับ Mastery กะ triple attack เยอะมาก แทนที่สวิชมาแล้ว เอาพวกหายตัว กินพิษ เพิ่ม cri มาน่าจะดีกว่าอ่ะคับ

สงสัยอีกอย่าง อัพ Vit มั่งป่ะคับ หรือกดแต่ Str Agi dex Int เป็นไปได้มั๊ยถ้าจะเล่นเป็นสาย Vit Str ไม่อัพ Agi เลย

รบกวนถาม Status ของคุณ exdeplez ได้มะคับว่าเป็นเท่าไหร่บ้าง แล้วตอนสวิชมา เก็ยสกิลไรมาใช้บ้าง อยากรู้เป็นแนวทาง

ตอบ exdeplez
สกิล cyclone กะไว้ใช้ล่าบอสหรือเก็บเวลอ่ะคับ เห็นด้วยว่าเราไม่ใช่สายวิท คงไม่ไปวิ่งลากมอนแน่ๆ แต่มันก็น่าใช้อ่ะ ชอบเปนการส่วนตัว

ณ ตอนนี้คงยังเลือก cyclone ไว้ก่อนอ่ะนะ หรือคุณ exdeplez คิดว่ามีสกิลอื่นน่าโอนมากกว่า ลองแนะนำหน่อยนะคับ เช่น Human Avoid (อันนี้ไม่ชัวว่าช่วยใน pvp ป่าว) หรืออัพเปอร์คัทไว้ต่อยกระเด็น หรือ flash Bomb อันนี้ยังไม่ลองใช้แฮะ
