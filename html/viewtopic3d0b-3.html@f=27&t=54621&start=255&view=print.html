ละเอียดแบบเข้าใจง่ายๆเลยนะครับ ก็......
ไปเกาะโจร...... เข้าไปในฟุชิกิกิลด์ คุยกะ NPC ไอ้โม่ง ( มีอยู่ตัวเดียวน่ะแหละ )
แล้วมันจะให้เราเอายาไปส่ง ก็วิ่งเข้าประตูข้างหลัง NPC ไป แล้วเลือกไปเกาะนักบวชหญิง
เข้าไปในบ้าน คุยกับป้า ส่งยา แล้วป้ามันจะบ่นๆ เรื่องของของไอ้โม่ง
ให้ถามว่า คืออะไร แล้วป้าจะให้ของชิ้นนึงมา ก็เอาออกมาส่งให้ไอ้โม่ง
จากนั้น ไอ้โม่งจะวานให้เราเอายาไปส่งอีกรอบ ก็ทำแบบเดิม
ในรอบนี้พอส่งแล้ว ป้าก็จะให้หลอมของได้แล้วล่ะครับ

2.เรื่องรับชิ้นส่วนบ้านบินอ่างับ(3ชิ้นหลังน่ะงับ)คือว่ารับที่ pirate tiny ไม่ได้อ่างับ เลยสงสัยว่าต้องเอาตัวที่เริ่มเควสไปรับอย่างเด๋วหรองับ หรือเอาตัวละครอื่นในไอดีเดียวกันไปรับได้? จะได้ไม่ต้องเดินวนหลายที่ แหะๆ^^
