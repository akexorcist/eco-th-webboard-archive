ทำธนูธาตุ ทำได้ 200 ดอก / รอบครับ ใช้ wooden arrow ทำก็ได้ครับ
ซื้อที่ลุงอ้วนเขียว ดอกละ 1G. เสียดายลูกธนูทำเอง

1 summon stone + 200 wooden arrow => เอาไปคุยกับภูติธาตุ => ลูกธนูธาตุ 200 ดอก

ตอนนี้ยังทำลูกธนูแสงกับมืดไม่ได้ แต่ 4 ธาตุที่เหลือทำได้หมด

ส่วนลูกธนูทำเอง (handcraft arrow) เอาไปประกอบกับ หัวลูกธนู จะได้เป็น steel arrow (atk 20) มั้งนะ ถ้าจำไม่ผิด แต่ steel arrow จะมีน้ำหนัก ถ้าจะใช้ ต้องค่อยๆทยอยทำ (หัวลูกธนูไม่มีน้ำหนัก)

ใช้ยิงปกติ ซื้อ wooden arrow ยิงเอาล่ะ ง่ายสุดละ
