Oblivion เขียน:มีคำถาม...
ถ้ากลายเป็นรูปหมดพอ Search หาก็จะหาไม่ได้นะสิ...

ขอบคุณมากครับ นึกว่าจะไม่มีคนถามซะแล้วนะเนี๊ย :?:

ตอนแรกก็คิดเหมือนกัน แต่พอคำนวนเอาเข้าจริงๆ มันก็คุ้มค่า ดูจากพฤติกรรมคนในบอร์ด Searchหรือ มันคืออะไรล่ะบ้างคนยังไม่เคยแตะเลยมั้ง จะเห็นว่ามักมีคนถามคำถามเดิมๆซ้ำๆกันทั้งที่ขนาดคำตอบของคำถามนั้นก็ถูกปักหมุดไว้ คุณค่าของระบบค้นหาจึงไม่มีความหมายมากนัก บวกกับระบบมันก็ไม่ได้จะค้นหาได้ละเอียดถี่ถ้วนอะไรนัก เพราะฉะนั้นการหาได้หรือไม่ได้นั่นก็ไม่มีประโยชน์มาก อีกอย่างนึงคือ กระทู้นี้เป็นguideหนึ่งเดียว ของอาชีพนักดาบ และได้รับการปักหมุก ผู้เล่นที่เล่นอาชีพนี้หากจะหาข้อมูลก็ต้องเข้ามาที่กระทู้นี้อยู่แล้ว อาจไม่จำเป็นต้องใช้ Search แต่ก็ไม่ได้ตัดทิ้งโดยสิ้นเชิญ วิธีแก้อาจจะใช้วิธีแทรกkeywordหัวข้อและใจความสำคัญ แต่ละอันไว้ภายในsectionแต่ละส่วนโพสนั้นๆแทนครับ ส่วนเหตุผลที่ว่าทำไมต้องทำเป็นรูปภาพ เด๋วผมเขียนไปที่หน้าแรกเลยดีกว่า :!:
