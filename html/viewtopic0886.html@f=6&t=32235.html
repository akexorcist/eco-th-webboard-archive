ตอนนี้เท่าที่ดูเป็นไปได้ 2 ปัญหา และอีก 2 แนวทาง

ปัญหา**

อย่างแรกคือ ตัวเกมส์ ECO มีปัญหาเนื่องจากไฟล์ในตั้วโฟลเดอร์เกมส์ไม่ครบซึ่งอาจเกิดจากไวรัสหรือฮาร์ดดิสเกิด Bad Sector ในบริเวณที่มีการยันทึกข้อมูล (กรณีหลังมักมีโอกาสเกิดมากกว่าถ้าเครื่องคอมพ์เก่าแล้ว แต่เราก็ไม่ได้หมายความว่าเครื่องคอมพ์ใหม่ไม่มีปัญหานะ)

*-วิธีแก้ ลบตัวเกมส์ด้วย Uninstall และลบโฟลเดอร์ ECO ทั้งหมด (ให้สะอาด) แล้วลงเกมส์ใหม่+โหลด Pacth ใหม่ตั้งแต่ 1 (ถ้าเน็ตช้าแนะนำก๊อปของเพื่อนมาลงแทน ใช้ได้เหมือนกัน ไม่ต้อง Install ใหม่ด้วย)

อย่างที่ 2 คือตัว Windows มีปัญหา ไม่ว่าจะเกิดจากไวรัส หรือ Bad Sector ของฮาร์ดดิสก็ตามที ถ้าหาก Windows ที่ใช้งานอยู่เกิดอาการไม่เสถียรเวลาใช้งานเช่น ค้างหรือช้าลงหรือเกิดอาการ Error กับโปรแกรมอื่น ๆ ทั้งที่เคยใช้งานได้ปกติ

*-วิธีแก้ ถ้าจะเอาแบบได้ผลคือ Format ทั้ง Hard disk แล้วลงโปรแกรมใหม่ทั้งหมด ซึ่งวิธีนี้ถ้าหาก Windows เคยติดไวรัสมันก็จะหายไปหมดด้วย แล้วอย่างเพิ่งนำ Handy Drive มาเสียบเป็นอันขาด ถ้าจะเสียบ Handy Drive ควรมีดปรแกรม Anti-AutoRun ติดเครื่องเอาไว้หน่อย แต่ถึงอย่างนั้นก็ไม่ควรคลิกไฟล์ประหลาดใน Handy Drive ของเราด้วย

แนวทาง**

แนวทางที่ทำให้เกิดปัญหา Eco ไม่รัน แบบแรกคือมีไฟล์ที่ ECO ต้องการในระบบ Windows ไม่ครบ

*-วิธีแก้ ลอง Search หาไฟล์ที่หายไปใน Google แล้ว Download (ระวัง Web ไวรัสด้วย) ไฟล์ที่ต้องการไว้ใน System32 ใน โฟลเดอร์ Windows ดู ***ข้อควรระวัง วิธีนี้สำครับผู้ที่มีความรู้ด้านคอมพิวเตอร์พอสมควรนะ

แนวทางที่ 2 คล้ายกับแนวทางแรก แต่เปลี่ยนเป็น โปรแกรมแทน ซึ่งอย่างที่ Rep. บนพูดว่า WMV (Windows Media Video) เป็นไฟล์ของ Windows Media Player หากโปรแกรมนี้ไม่มีหรือเสียหาย ก็ทำให้ไม่พบไฟล์นี้เช่นกัน

**-วิธีแก้ ลองลงโปรแกรม Windows Media Player Version ใหม่ หรือ Update Windows Media Player ซะ หรือถ้าไม่มี Windows Media Player ก็ลองหามาลงดู

******ทั้งหมดนี้ไม่ใช่ว่าจะสามารถแก้ปัญหาได้ แต่เป็นเพียงแนวทางและปัญหาที่น่าจะทำให้เกิดปัญหาเท่านั้น



************ ทั้งนี้ทั้งนั้น ปัญหาอาจเป็นปัญหาเส้นผมบังภูเขาแบบที่เคยบอกไว้ว่ามีหาร Mod. (เปลี่ยนแปลง) ตัวเกมส์หรือมีการข้าม Patch จึงแนะนำให้แก้ด้วยวิธีที่ง่ายที่สุดก่อน
