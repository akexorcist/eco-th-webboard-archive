Valkyrie สกิลนี้มีข้อพิเศษอยู่นิดๆในการใช้คือ
1. สกิลนี้จะมี limit ของ Hp ที่สามารถลดได้อยู่ โดยคิดเป็น % จาก Max Hp ของคนที่ถูกใช้ซึ่งเปลี่ยนไปตามสกิลเลเวล
2. Limit Max Hp เป็น % ตาม เลเวล คือ 90% / 80% / 70% / 60% / 50%
3. เราจะไม่สามารถใช้สกิลนี้ ฆ่าใครได้เนื่องจาก หากเลือดของ monster / player ที่ถูกสกิลนี้นั้น เท่ากับหรือต่ำกว่า limit แล้ว เลือดจะลด "0" เช่น

ที่สกิลเลเวล 5 จะมี limit Max HP = 50% เพราะฉะนั้น หาก monster มีเลือด 100 แล้ว สมมุติเราใช้ครั้งแรกตีเข้าไป 50, เมื่อใช้อีกครั้งจะลด 0 เนื่องจากว่า monster เลือดลดไปแล้ว 50% จึงไม่ได้รับผลจากสกิลนี้

สมมติเลือด monster มีเลือด 100, หากโดนใครไม่รู้ซัดไปจนเลือดเหลือ 60 เมื่อเราใช้ สกิลนี้ซ้ำเข้าไป เลือดก็จะลดไปแค่ 10 เช่นกันที่เลเวล 5เนื่องจากว่า limit hp ที่ lv5 = 50% แต่ถ้าหากเราใช้ lv1-lv4 เราจะแทงเข้า 0

4. สกิลนี้ใช้ dmg ของอาวุธแบบ Piercing ในการคำนวณนะ 100% /112% /125% / 137% / 150% ตาม lv
5. จากการแปลในวิกิ (ยังไม่ชัวร์)ได้บอกไว้ว่า สกิลนี้ จะไม่ได้ตีทะลุ def ทั้งหมด (นั่นคือไม่ใช่ได้รับ dmg ทั้งหมดไป) แต่(ถ้าแปลไม่ผิดนะ)จะทะลุเฉพาะ def แบบ addition เท่านั้น (เทียบกับ player คือ def ขวาที่ลดตรงๆ ไม่ใช่ def ซ้ายที่ลดเป็น %) <-- ไม่ชัวร์ๆๆๆ
