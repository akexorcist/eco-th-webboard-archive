อยากทราบว่ามีวิธีใดที่จะทำให้ใช้เวท Scroll พวก Lightning Blast / Thunder Strom เร็วขึ้นอ่ะคับ

ที่ทำให้ร่ายเร็วขึ้น ที่ผมรู้ก็มี
1. สกิว Read Mastery (Sage) หรือป่าวคับ

2. สกิว Speed Enchant (Enchanter) หรือป่าวคับ

3. แล้วอัพ Dex ให้มี Cspd เยอะๆนี่จะใช้ Scroll เร็วขึ้นหรือป่าวคับ

ที่ทำให้ร่ายแรงขึ้น ที่ผมรู้ก็มี
1. Att. Ass.(Bp,Bm) หรือป่าวคับ

2. Zen (Elementaler) หรือป่าวคับ

ที่อ่านมาจากบอร์ดเท่านั้นคับ ไม่ได้ลองจิงๆ
ขอท่านผู้รู้โปรดชี้แนะด้วย

ลืมบอกไปอย่างเกี่ยวกับสกิล read mastery

การทำงานของสกิลนี้คือ จะทำให้ cspd และ delay มันเหลือ 10% ของเวลาที่ใช้ร่ายปกติ(นอกโหมด pvp/nvn) และจะทำให้เหลือ 75% ในโหมด pvp/nvn

ตัวอย่าง

เสจ A มี cspd 600 เท่ากับเวลาร่ายเหลือ 40% เมื่อใช้กระดาษเวทย์ + อัพสกิล mastery จะทำให้เวลาร่ายเหลือเพียง 0.1*40% = 4%

เสจ B มี cspd 200 จะเหลือเวลาร่าย 0.1*80% = 8%

ป.ล. ที่ปัจจุบันทำอยู่ cspd 940(dex 108 + spd enchant) ใช้กระดาษเวทย์ เวลาร่ายเหลือ 0.1*6% = 0.6%

กด blast ไม่มีหลอดขึ้นที่หัว กด storm กดแล้วมองหลอดแทบไม่เหน บางทีก็ไม่เหนเลย
