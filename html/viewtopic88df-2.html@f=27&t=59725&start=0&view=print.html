อันนี้ผมเพิ่งคิดได้อ่ะครับ ถ้าจะเล่นเกมแนวเก็บเลเวลถ้าเอาแต่เก็บเลเวลก็เบื่อแย่อ่ะดิ

ผมเลยมีทริคมานําเสนอ แต่ถ้าใครอยากให้ตัวเองเวลเยอะๆก็เวลไปทั้งวันเลยครับ

แต่สําหรับผม เวลช้านิดๆ แต่ก็สนุกนะ ยังไงหรอมาดูกัน

1.เราควรเก็บเลเวล อาทิตย์1 ไม่เกิน3ครั้ง หรือไม่ก็1ครั้งก็พอ (ถ้าใครเก็บ1ครั้งเก็บทั้งวัน

ไปเลย)

2.เดินหาดูของสวยๆเอามาใส่เล่น (หาเงินหาเอาเองนะ)

3.PVP กับ NVN แก้เครียด

4.คุยกับเพื่อนในเกมแชทให้มันสนุกสนานครับ

5.ปิดเสียงเพลงเกมนี้ไปมันหน้าเบื่อ ลองเปิดเวปแล้วฟังเพลงที่คุณชอบ ก็ได้

ปล.ข้อ5แล้วแต่คนนะ ถ้าใครฟังเพลงเกมecoแล้วเบื่อก็ปิดไปนะครับ
