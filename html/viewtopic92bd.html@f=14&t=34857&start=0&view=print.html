Fast Draw ยิงแบบไร้ร่าย ไร้ดีเลย์ ยิงเร็วเท่านิ้วเรากด จะ aspd เท่าใหนก็ยิงเร็วเท่ากันหมดแหละ (ขึ้นอยู่กับนิ้วเรา)

Plurality Bullet ใช้ได้กับทุกปืน แต่ถ้าถือปืนคู่ มันจะยิงเพิ่มมาอีก 1-2 นัด (ประมาณนั้นมั้ง จำไม่ค่อยได้)

ใช้ปืนที่คุณชอบอ่ะดีที่สุด

ปืน 2 มือทุกชนิดต้องเอาปืนสั้นมือเดียวมาประกอบเอง

ชอบปืนมือเดียว งั้นปืนมือเดียวก็ดีที่สุด แล้วสาย str ใช้ปืนมือเดียวมันเป็นไงล่ะ ผมสาย str ถือปืนคู่อ่ะ

Fast Draw จะยิงได้เร็ว = ASPDของ "คนเล่น" ไม่ใช่ ตัวละคร เข้าใจมิ= =
คือ นิ้วท่านยิกแค่ไหน มันก็ยิงได้เท่านั้นแหละครับ

สาดกระสุน ใช้ได้กับปืนทุกชนิด ปืนสั้น/ไรเฟิล ยิงได้ 4-6นัด ปืนคู่ ยิงได้ 5-7นัด(+มา1)

ปืนคู่ ประกอบอย่างเดียว NPCไม่มีขาย อาจหาซื้อได้ตามร้านนแผงลอยของผู้เล่นทั่วไป

ชอบปืนไหนก็ใช้ปืนนั้นแหละ
แต่STRอาจจะเหมาะกับไรเฟิลมากกว่า
เพราะยิงแรง+ระยะไกล ทำให้ลบจุดด้อยเรื่องความเปราะบางได้(มอนตายแกล ไม่ต้องกลัวถึงตัว(ถ้าผีมือมีพอ))
ถ้าใช้ปืนสั้น อาจจะทำให้ศัตรูเข้าถึงตัวได้ง่าย เพราะระยะยิงสั้น ต้องมั่นใจว่า ยิงชุดเดียวแล้วตายจริงๆ
