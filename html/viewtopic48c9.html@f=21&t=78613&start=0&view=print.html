จากเท่าที่ดู แสดงว่าใช้ดินสอ HB วาดสินะครับ (ไม่ก็ใช้ 2B วาดแต่ลงน้ำหนักเบามาก ๆ -..-)

ถ้าหากใช้ดินสอ HB วาดแนะนำลองใช้ 2 B วาดสิครับ พอแสกนแล้วเส้นจะคมชัดมากกว่า (นิดนึง) จริง ๆ ถ้าจะให้ดีแนะนำ 4B แต่เวลาลบมันจะมีคราบดำ ๆ (โดยเฉพาะถ้ากดแรงลงเส้นหนัก ๆ) จึงแนะนำให้ใช้ 2B นะครับ (ผมวาดรูปปกติก็ใช้ 2B -..-)

ส่วนเรื่องรูป เอาเป็นว่าตั้งแต่บนลงล่างเลยล่ะกัน

- ส่วนศีรษะ : โดยรวมแล้วผมคิดว่าใช้ได้เลยทีเดียว (ขนาดผมยังวาดได้ไม่ดีขนาดนี้เลย -..-) จริง ๆ แล้วผมเป็นพวกมีปัญหากับตำแหน่งของดวงตาและปาก แต่ในรูปนี้ตำแหน่งของดวงตาและปากถือว่าคล้อยตามไปกับโครงหน้าที่วาดเอาไว้ โดยส่วนรวมผมว่าเป็นเอกลักษณ์ดี

- ส่วนลำตัว + ท้อง+แขน : ไหล่ตรงมาก ... หน้าอกตรง ... เข้าข่ายมาตรฐานชายไทย ... ไม่ใช่ล่ะ ... ส่วนของลำตัวมันดูตรง ๆ เกินไปหน่อย อาจจะเนื่องจากไม่มีรอยหยัก (ยับ) ของเสื้อ แต่มันกลับมีส่วนเว้าโค้งของหน้าอกขึ้นมาซะดื้อ ๆ แนะนำลองฝึกวาดส่วนยับ (หยัก) ของเสื้อดู น่าจะดูดีขึ้น ส่วนแขนใช้ได้แล้ว แต่ถ้าจะวาดข้อพักศอกกรุณาดูการบิดงอของแขนหน่อยก็ดีนะครับ มันดูผิดธรรมชาติ -..- ส่วนนิ้วมือผมเองก็วาดได้ไม่ดีเหมือนกัน จึงไม่ขอเม้นล่ะกันนะครับ

- ส่วนสะโพกลงมาถึงปลายเท้า : หลัก ๆ เลยคือขาเบี้ยว ... เบี้ยวแบบไม่ค่อยน่าเกลียดแต่มันดูผิดธรรมชาติ เพราะออกจะมองหน้าตรงขนาดนั้นแต่ขากลับเห็นข้อพับตรงเข่าได้ชัด (เหมือนยืนเฉียงหน่อย ๆ) ส่วนลักษณะของขาถือว่าใช้ได้แล้ว (ของผมยังวาดขาเป็นท่อน้ำไทย (ตรง) อยู่เลย) ส่วนรองเท้ามันไปเข้าข่ายกับขา คือมันเฉียงหน่อย ๆ ถ้าจะให้ดี ลองวาดให้ทั้งตัวไปด้วยกันจะดีมากที่สุด

โดยรวม แล้วสิ่งที่อยากจะตีมากที่สุดคือการที่ทั้งลำตัว ขาดความสามัคคี (ไม่ไปด้วยกัน) และส่วนของขาที่มันเบี้ยวอย่างเห็นได้ชัดไปหน่อย แต่ถ้าหากถามว่าแย่ขนาดใช้ไม่ได้เลยรึเปล่า? ผมขอบอกได้ว่า "ดีแล้วครับ ... ฝึกวาดต่อไปนะครับ"

การวาดรูปเหมือนเราเรียนนั่นแหละครับ แต่เปลี่ยนจากการอ่านหนังสือเป็นมาลงแรงเท่านั้นเอง ผมบอกตามตรงเลยนะครับว่าฝีมือการวาดของผมมาจากการฝึกล้วน ๆ ไม่ได้มาจากคำแนะนำของหนังสือสอนการวาดรูปเล่มไหนเลย (จริง ๆ ถ้าผมทำตามนั้นผมน่าจะมีฝีมือมากกว่านี้ -..-) จึงขอแนะนำว่าอย่าย่อท้อนะครับ
