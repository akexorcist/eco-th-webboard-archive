โดย ECO
พอกดคุยกะดอกไม้ดอกแรก แล้วเข้าฉากโลกมายา (BGM เปลี่ยน)

ให้กดใช้หน้าลุงอาเบะเลย แล้วจะแปลงร่างเป็นลุงเบะได้ (All stat+100) มีเวลา 5 นาที

พอเป็นลุงเบะแล้วให้วิ่งฝ่าดงมอนไปคุยกะดอกไม้อย่างเดียว

ถ้าเจอดอกปลอมก็ให้ตีไชเท้าที่โผล่มาทิ้ง แล้ววิ่งหาดอกอื่นไปเรื่อยๆ

ถ้าลุงเบะหมดก่อน 5 นาทีก็สามารถไปขออันใหม่ได้เรื่อยๆ

โดยดอกไม้จริงนั้น เมื่อสุ่มมาครั้งนึงแล้วจะอยู่ตำแหน่งเดิมไปตลอด แม้จะตายหรือออกเกมก็ตาม

หลังจากเจอครบ 3 ดอกแล้ว ตอนสู้บอสเนื้อเรื่องจะบังคับให้แปลงเป็นลุงเบะอีกครั้งเอง (ถ้าไม่ได้ขี่เพ็ท) เป็นลุงเบะก็หวดบอสตายง่ายนิดเดียวละ
