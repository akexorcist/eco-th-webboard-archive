โพสต์แล้ว: จันทร์ 10 ก.ย. 2007 10:02 pm
โดย ECO
วันนี้ (10 ก.ย. 2550) หลังจากเสียเงินไปรี STATUS มา 2 หน (LV 57) เลยได้ความจริงเกี่ยวกับค่า Int ครับ

1. Cure ไม่ต้องอัพ Int สามารถรักษาได้เกือบ 100% อยู่แล้วครับ และคาถา Cure มี Combo คู่กะคาถา Ares ครับ คือ ถ้าเราอัพ Cure ชนิดใดๆ ไปแล้ว ถ้าอัพ Ares LV1 จะสามารถเพิ่มโอกาสรักษา อาการนั้นๆ (ที่เราอัพ Cure) ได้ 94% ที่ LV2 96% ครับ และที่ LV6 99% ครับ <-- จาก ECO wiki นะครับ ผมลองมาแล้วครับ รักษาได้ชัวร์ครับ เพราะผมอัพ Ares 2 เท่านั้นครับ แต่ Cure อัพเกือบหมดครับ

2. Int มีผลทำให้ติดสถานะผิดปกติยากขึ้น ชัวร์ครับ!!! เพราะลองมาแล้วครับ จากเดิม MAG ล้วนครับ ผมลองรีเป็น Int 60+17, MAG 63+16 เห็นผลได้ชัดเจนครับ เวลาไปยิงผี แทบจะไม่ติดสถานะผิดปกติครับ หรือแม้กระทั่งตอนสิงสู้บอส ก้อแทบไม่โดนใบ้ โดนสตัน หรือสับสน (แต่ยังโดนพิษอยู่บ่อยๆ แต่ไม่เป็นไรครับ ฮีลคนถูกสิงได้ก้อพอ)

ฉะนั้นตอนนี้ พระผมเลยเล่นสาย INT + MAG ครับ เวลาลุยบอส สิงใส่ สาย Back Packer ที่ใส่สร้อยกันคนสิงตายด้วย ทำให้เป็นสาย Full Support และ Undead Killer ได้ในเวลาเดียวกันครับ
