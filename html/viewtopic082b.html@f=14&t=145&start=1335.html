โอ้ว ความรู้อย่างแรง thx มากๆคับ
อย่างงี้ผมเล่น str vit ก็คงต้องดอง point รอ banish blow เลย

เพราะอัพ Hp rev กะ Max Hp เต็มเลย ( เพราะวิ่งชินนาม่อนอะ )
แล้วอัพ vit พอๆกะ str เลย
แต่ว่าก็มีบางช่วงที่เพื่อนไม่ออนแล้วต้องมาเกบเอง
combo blow+banish blow นี้เยี่ยมมากคับ ต้องลองให้ได้ ^^

สำหรับคนที่ใช้คอมโบนี้ระดับเซียนก็มะต้องอัพ vit เลยอะดิคับ อัด str อย่างเดียว

parry เมื่อกดใช้จะเพิ่มหลบ 30% ยิ่งlvสูงก็จะใช้ spมากขึ้นแต่ก็อยู่นานขึ้น delayก็น้อยลง
เรื่อง sp ก้ up int ครับเพิ่ม max sp แต่ไม่แนะนำ อิอิ
โดยที่เวล 5 ใช้ sp 25 อยู่ได้ 10วิ delay 1วิ ท่านี้สำหรับpvpอาจจะชี้เป็นชี้ตายกันได้เลยทีเดียวโดนเฉพาะการสู้กันของสาย agi ถ้าคิดว่าจะเล่น pvp upไว้ไม่เสียหายครับ
ส่วน counter อย่าไปยุ่งกะมันเลยครับ เปลืองพ้อยปล่าวๆ
เพิ่ม max sp ก็up intครับถ้าไม่ up skill
