โดย ECO
คือสมมุติว่าเรามีไอเทม Aและฺ B

หากเราเอาไอเทม Aแสดงรูปแล้วให้ไอเทม B แสดงผล
พอหลอมเสร็จแล้วจะได้ ไอเทมที่แสดงผลของไอเทม B แต่รูปจะเป็นของไอเทม
A ใช่ไหมครับ ทีนี้จะขอเรียกไอเทมนี้ว่า ไอเทม C เพื่อความไม่งง

จากนั้นถ้าเราเอา ไอเทมC มาหลอมกับไอเทม D ซึ่งเป็นไอเทมอีกชิ้นหนึ่ง
ถ้าเราให้ ไอเทม C ที่มีการแสดงผลภาพเป็น A นั้นเป็นไอเทมแสดงภาพ
จากนั้นให้ ไอเทม D เป็น ตัวแสดงผล พอหลอมแล้ว ไอเทมที่เกิดขึ้นมา จะแสดงผลรูปภาพเป็นของไอเทม A หรือ B ครับ

ในกรณีนี้หมายถึง ไอเทมทั้งหมดสามารถหลอมกันได้แน่นอนอยู่แล้ว
คงไม่ งง กับคำถามเกินไปนะครับ
