คือยังงงกับ

เมือ่คุยกับเอมิลดราก้อนขณะที่มีอาวุธทั้ง 3 ชิ้นข้างต้นอยู่กับตัว จะสามารถทำการสู้กับ serious เอมิลดราก้อนได้ (แปลว่าไงดี -*- เอมิลดราก้อนเอาจริง??)
ปล.ไม่สามารถเริ่ม event นี้ได้ถ้าไม่เคยทำการปลดปล่อยอาวุธอื่นๆมาก่อนอย่างน้อย 1 ครั้ง(แบบจ่ายเงิน)


คือ เมื่อคุยกับ เอมิลดราก้อน ตอนที่มีอาวุธทั้ง3อยู่ในตัว จะทำให้อาวุธใช้ได้แล้ว

ต้องสู้กับ เอมิลดราก้อน หรอ

แล้วก็ ปล.ไม่สามารถเริ่ม event นี้ได้ถ้าไม่เคยทำการปลดปล่อยอาวุธอื่นๆมาก่อนอย่างน้อย 1 ครั้ง(แบบจ่ายเงิน)


นี้คือ จะต้องทำวุธ99 ชิ้นอื่นก่อนหรอครับ แล้วจึงมาทำวุธ99 3ชิ้นนี้ได้

ใครรู้ ช่วยอธิบายแบบละเอียดทีครับ วิธีทำ ดาบ992มือ อยากได้มาก

มันใกล้จะมาแล้ว จะรีบๆทำแล้วเอาไปตี+อ่างิ

ใครรู้ก็ช่วยอธิบายแบบละเอียดให้ ผมเข้าใจทีน้าครับ พอดีงงมากเลยอ่ะ


ข้อแรก ถูกต้องตามที่คุณเข้าใจ
เฉพาะ ดาบ 2 มือ, หอกมือเดียว กับหอก 2 มือ ที่ก่อนจะปลดปล่อยอาวุธได้ จะต้องทำการสู้อีมิลดราก้อนแบบโหดก่อน (ขนทั้งกิลด์ไปสู้เลย ไม่งั้นไม่ผ่านแน่ๆ)

ข้อที่สอง นี่ก็ถูกต้องตามที่คุณเข้าใจ
การจะเริ่มเควสข้างต้นได้ จะต้องผ่านการทำเควสปลดปล่อยอาวุธอื่นๆมาก่อนอย่างน้อย 1 ครั้ง

สรุปคือ อาวุธอื่นๆ => ต้องเตรียม 5 ล้าน และ 3000 cp ทุกรอบที่ทำ
ดาบ 2 มือ, หอกมือเดียว กับหอก 2 มือ => ต้องเตรียม 5 ล้าน และ 18000 cp เฉพาะครั้งแรก หลังจากนั้น เตรียมแค่ 15000 cp ทุกรอบที่ทำ
