1.คือตกลงแล้ว Emil Op จะ + พื้นที่เยอะกว่า เผ่าอืนๆใช่ม๊ะงับ

- ใช่ค่ะ เผ่าอื่นใส่เป้ข้างหลังมะได้(ติดปีกล่ะมั๊ง) ก็เลยทำให้ emil แบกได้มากที่สุดไงคะ

2.กระเป๋าที่ว่าใส่ได้ทุกอาชีพ ที่เอว หรือมือถืองับ - -* เพราะไปเห็นที่มือถือมา

- กระเป๋าที่ถือที่มือ มีแค่โนวิสกับสายแบ๊คแพ๊คเท่านั้นที่ถือได้ค่ะ ส่วนกระเป๋าที่เอว เรามะรู้เหมือนกาน

3.ละก็ของพวกนี้ขายที่ Fareast ส่วนมากหรือเปล่า แบบว่า หาเป๋าที่เอวไม่เจอ - -*

- ข้อนี้มะรู้ค่ะ แต่เราก็เห็นขายตามเมืองต่างอ่ะนะ(กระเป๋าคาดเอวเราไม่เคยเห็นอ่ะ คงเพราะเราไม่สนใจล่ะมั๊ง)

4.ปลูกต้นไม้ 5 นาที แล้วมันเหี่ยวตายหมดเลย !! ถึงกับอึ้ง ฮา

- มะวานเห็นคนปลูกต้นไม้เล่นข้างๆเมืองเหมือนกาน ปลูกหนาๆอยู่ดีๆ ก็หายหมดทั้งๆที่มะมีคนตี คงเหี่ยวภายในห้านาทีล่ะมั๊ง(สันนิษฐานไปเรื่อย อิอิ)
