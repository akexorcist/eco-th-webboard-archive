kjtkotop เขียน:เน้นสายถึกซัพเร็วยิงมิเบานิดหน่อยมิเป็นไรอัพอาไรบ้างอ่า

งั้นผมสรุปว่า ต้องการสายถึกไว้ก่อนนะครับ ตามด้วยยิงเร็ว และแรงเป็นอันดับสุดท้าย

ดังนั้นสรุปสิ่งที่ต้องอัพนะ ถึก = vit,int
เร็ว = dex
แรง = mag

มาไล่กันทีละตัว ขึ้นกับว่าท่านอยากได้ถึกแบบไหน ในที่นี้ผมไม่เอา stat ของพวกตัวหน้า 100 มาละกันนะครับ เพราะมันลุยคนเดียวไม่ได้
สกิล Divine Barrier ของเราเพิ่ม Def/M.def ได้ 19/35 ถึกๆหน่อย ผมว่าให้ป้องกันหลังบัฟซัก 70+ คงโอเค
มาเริ่มจาก Def ค่า vit ที่ผมแนะนำเป็น... รวมหน้า+หลังได้ 100 ละกัน ที่ตรงนี้จะได้ def 55 ครับ รวมกับ DY จะเป็น 74
ส่วน int สำหรับ vit 100 จะได้ M.def มา 25 แล้วใส่ int หน้า+หลังซัก 75 ก็จะเป็น 50 รวม DY จะเป็น 85 ถึกดี

สำหรับความเร็วในการร่าย ผมคิดว่า Dex หน้า + หลังแค่ 99 หรือ 90 ก็โอเคละครับ 108 นั่นสำหรับสายเร็วจริงๆ

และที่เหลือก็ลง mag ไปเลยทางที่ดีคือให้ถึง 103 (หน้า+หลัง)

สรุปๆ
Vit =88 +12
Int = 56 +19
Dex = 78 +12
Mag = 79 +24
สำหรับซอที่จ๊อบ 50 ครับ

ปล.รีแล้วลองกดค้างไว้ก่อนนะ ผมไม่แน่ใจว่าโบนัสมันถึงรึเปล่า ถ้าไม่ถึงปรับ int เป็น 53 หรือ 50 ก็ได้ครับ
