อยากทราบว่าถ้าดาบอัพสเตตัสแบบนี้พอเล่นไปช่วงหลังๆจะดีมั้ยครับนี่
จากที่ลองมาผมลองไปตีมอนที่ฟูจิกิ

พบว่า
1.ตีเร็วดี
2.เลือดเยอะพอสมควร
3.มอนอัดเราเข้าแค่ครั้งละ70-150
4.หลบได้เยอะ
5.โดนเวทอัดแรงประมาณ200-400
6.ตีแรงพอสมควรประมาน300-600

แต่...

ขอความเห็นด้วยครับ

จขกท สายเดียวกับผมเลย ครับ str agi vit

อย่าอิง base ที่ฟุมากครับ มอนตรงนั้นมันกระจอกนัก เลเวลคุณก็สูงแล้วด้วย

ส่วนดันปลาวาฬ เวลได้แน่นอนครับ แรงไม่แรง อยู่ที่ตัวโซลเป็นสำคัญครับ มีชาแมน หรือ bs ก็เวลได้แล้ว

สายนี้ผมเล่นตั้งแต่เลเวลแรกๆยัน 100 กว่าแล้ว เก็บดันช้างคนเดียวมันส์มาก จนมาปัจจุบันอยู่วาฬก็ไม่มีปัญหาอะไร

agi พอแล้ว aspd 750 ก็ไวมากแล้ว ถ้าจะเน้นเก็บเลเวลก็ลง str ต่อไป

ความจริง aspd ควรหยุดที่ 700 ต้นๆ เพราะรวมบัฟมันจะได้ 800

แต่ไม่ต้องรีหรอก เก็บไว้รีตอนอยากเล่นสายอื่นดีกว่า
