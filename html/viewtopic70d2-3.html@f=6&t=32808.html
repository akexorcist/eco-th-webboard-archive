[ฟุ้งซ่าน~]ความแตกต่าง...ของ กระเป๋าlv. 20 กะ กระเป๋าlv.75

โดย ECO » อังคาร 18 ธ.ค. 2007 10:05 pm





เอาเป็นว่าดูรูปประกอบตามดีกว่า (ของตัวอย่างอยู่ใน สภาพโทรม พอดู - -" )

ถ้าว่ากันตามคุณภาพ ทุกคนอาจจะเห็นว่า กระเป๋า 20 เจ๋งกว่าแน่ๆ
เพราะ Payl +60 Capa ตั้ง +100

แต่ถ้าเหลือบไปช่องที่ 3 ตรง detail จะเห็นว่า น้ำหนักของเป๋า 75 ถ้าเปรียบเทียบเป็นมวย
ก็ประมาณ heavy weight กะรุ่น light weight เลยนะนั่น - -
ผมจะไม่พูดถึง Payl เพราะเกินยาก สำหรับสาย BP เดินเก็บเลเวล ...

เป๋า 20 : เพิ่ม Capa +100 หัก น้ำหนักตอนใส่ (จากช่อง body) - 25 = เพิ่ม Capa 75
เป๋า 75 : เพิ่ม Capa +80 หักน้ำหนักตอนใส่ (จากช่อง body) - 5 = เพิ่ม Capa 75

(ถึงในช่อง back จะเพิ่มต่างกัน แต่อย่าลืมลบน้ำหนักจากที่สวมใส่ด้วยนะจ๊ะ :wink: )

อืม ...สรุป คุณภาพในการบรรจุ เท่ากัน ... แล้วเอ็งจะตั้งกระทู้มาทำด๋อยอะไร? (นั่นสิ - -")

ช่างเถอะมาพูดถึงข้อดี ข้อเสียของทั้ง 2 กระเป๋าดีก่า ...

กระเป๋า Big Ruck Lv.20
ข้อดี ::
1. ใช้ได้ตั้งแต่ lv.20
2. ดูแลรักษาง่าย ใ้ช้ Coat Repair Kit [Copper] เอง
3. ดูเป็นนักเดินทางดี เหมาะสมกับ Backpacker ดี
4. มีกระเป๋า หลากหลายแบบ ให้หลอมเล่น

ข้อเสีย ::
1. จำกัดเผ่าเฉพาะ Emil
2. ราคายังเหยียบ แสนอยู่ ... เห็นใจ BP สายยากจน (บางคน)
3. วัตถุดิบการทำ หายาก(ตรงไหน?) ถ้าจะไปหาเองตอนเลเวล 20 คง ลำบากน่าดู
4. มันบังผมด้านหลัง (-_-)~○ (สำหรับคนไว้ผมยาวดูแล้ว แปลกๆ)

กระเป๋า Tool Bag กับ Mechanic Bag Lv.75
ข้อดี ::
1. ไม่จำกัดเผ่า ...โดมิเนี่ยน ไททาเนีย ก็ใส่ได้
2. Tool bag สีส้ม Mechanic Bag สีแดงเล็กๆกิ๊บเก๋ ... ดูเข้ากับชุดเลเวลสูงๆของ BP
3. ดูแล้วทำง่ายกว่า กระเป๋า 20 นะ เพราะของที่ทำมันเป็นของในที่เก็บเลเวล ...
4. แก้เบื่อ กระเป๋า 20 ... (ใส่มากันกี่ เลเวล แล้วล่ะ - -)
5. เพื่อโชว์แผ่นหลัง และผมยาวสลวย ของ สตรีชาว BP ...(อ๊าง~)

ข้อเสีย ::
1. กว่าจะได้ใส่ ก็โน่น Lv.75
2. ใช้ Coat Repiar Kit [Golden]่ บางทีทำกระเป๋าใหม่มาใช้เลยอาจจะเร็วกว่า (-__-")
3. เจ๊งง่ายชอบกล ... (หรือผมคิดไปเอง?)

ฟุ้งซ่าน ก่อนสอบ ... ไปอ่านหนังสือละ :lol:
