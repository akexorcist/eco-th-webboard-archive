-----------------------------------------------------------------------------------------------


Event Navigation by Fairy Primula {ระบบภูตินำทาง}



(ขอหยิบภาพมาจากจีเนโกะ)


ระบบภูตินำทางมีข้อดีอย่างไร???

• เหมาะสำหรับผู้เริ่มเล่นที่ไม่รู้จักถนนหนทางรวมไปถึง NPC
• เหมาะสำหรับผู้เล่นที่ปิด interface (ยกตัวอย่างเช่น ไม่โชว์แมพและจำทางไม่ได้)
• น่ารัก (?)


ระบบภูตินำทางมีข้อเสียอย่างไร???

• ปรากฏในเฉพาะแมพที่มีการสำเร็จอีเว้นท์เท่านั้น (แมพเฉพาะอีเว้นท์นั้นๆแมพเดียว)
• สังเกตภูติจิ๋วได้ค่อนข้างยาก (สำหรับคนที่อยากยลโฉมความน่ารักใกล้ๆ)


-----------------------------------------------------------------------------------------------


วิธีใช้ระบบ Event Navigation



เปิดหน้าต่างอีเว้นท์ขึ้นมา (อยู่ที่แถบเมนูหลัก) แล้วก็เลือกอีเว้นท์ที่ต้องการทำ หรือคลิกที่ เริ่มการนำทาง



ยกตัวอย่าง ตัวละครของเราจะไปหากะหรี่ (Curry) ที่ป่าอะโครเนีย กัน



พอเราไปถึงที่หมายแล้ว สังเกตว่าบนแมพ จะมีลูกศรโชว์ตรงบริเวณซึ่งกระหรี่สถิตเฝ้าอยู่



กลับมาดูที่ตัวละคร ภูติน้อยโผล่มาแล้ว พร้อมลูกศรเช่นเดียวกัน
(ภูติน้อยของเราจะหันหน้าไปยังทิศเดียวกับลูกศรตลอดเวลา)



ในที่สุดก็เจอกะหรี่สักที สังเกตว่าด้านบนของ NPC จะมีป้ายบอกอยู่ คุยกับเขาเพื่อทำการจบอีเว้นท์ด่านนี้แล้วภูติน้อยของเราพร้อมลูกศรต่างๆก็จะหายไปเช่นเดียวกันจนกว่าเราจะทำอีเว้นท์อื่นๆเพิ่มเติม


-----------------------------------------------------------------------------------------------


แถบ Symbol บนหน้าต่างอีเว้นท์




สัญลักษณ์แรกคือ ตัวแสดงของภูตินำทาง (Primula Cursor)
สัญลักษณ์ที่สองคือ ตัวแสดงลูกศรบนแมพ (World Map)
สัญลักษณ์ที่สามคือ ตัวแสดงป้ายบอกบน NPC อีเว้นท์นั้นๆ (Event Marker)
