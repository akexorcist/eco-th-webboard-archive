1.ไอเทมชุดตั๋ว จะเป็นรูปกล่องแบบนี้ใช่ไหมครับ
    กล่องนั้นเมื่อเปิดจะสามารถเลือกชุดของแมวในกล่องนั้นๆได้1ตัวครับ

2. ชุดตั๋วเมื่อใส่ให้แมวไปแล้ว สามารถถอดเปลี่ยนเป็นชุดอื่นๆได้ไหมครับ หรือเป็นชุดนั้นติดตัวไปเลย
    สามารถถอดใส่ได้ตลอดครับ สเตตัสก็เหมือนเดิมไม่ต้องฝึกใหม่
    รูปดาวนั้นคือใส่ชุดอยู่ครับ

ส่วนรูปนี้ที่เห็นเป็นชุดนั้นคือเอาออกมาจากกล่องแล้วครับ (ส่วนกรอบสีเขียวคือสัตว์เลี้ยงที่เข้าระบบยูเนี่ยนครับ)


3. วิธีใช้ คือเอาไปให้ที่ป้าแมว หรือดับเบิ้ลคลิ๊กใช้ได้เลยครับ
    หากแมวไม่ได้ใส่เสื้ออยู่(ไม่มีรูปดาว)ก็กดดับเบิ้ลคลิ๊กใส่ได้เลยครับ
    ถ้าต้องการถอดให้ไปหาไทนี่ในร้านป้าตัดเย็บที่อัพทาวน์
