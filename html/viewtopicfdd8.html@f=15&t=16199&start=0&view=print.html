การตอบคำถามในการเปลี่ยนอาชีพของ Elementaler
นั้นจะอ้างอิงเกี่ยวกับธาตุ ซึ่งจริงๆ สายของ Shaman ทั้งหมดจะเกี่ยวกับธาตุอยู่แล้วค่ะ
คำถามของ Elementaler จะถามว่า "ธาตุอะไรที่จะมีประสิทธิภาพใน map (ในคำถาม)"
ซึ่งสามารถหาคำตอบได้ง่ายๆ เลยค่ะ ความหมายของคำถามคือ ธาตุอะไรที่สามารถชนะ map นั้นๆ ได้
อย่างแรกเราต้องรู้ก่อนว่า map นั้นๆ เป็นธาตุอะไร ด้วยการใช้สกิล Sense Elemental
ของอาชีพ Shaman Job lv.25 ไปส่องที่พื้นที่ของ map นั้นๆ จะปรากฎเป็นสีตามธาตุค่ะ
ถ้าเราสามารถรู้ได้ว่า map นั้นๆ เป็นธาตุอะไร เราก็มาดูที่ วัฏจักรของธาตุอีกทีค่ะ
ว่า ธาตุอะไรแพ้-ชนะธาตุอะไร ลองทำตามวิธีนี้ดูนะค่ะ :wink:
