ขอรายละเอียดเควสราชินีพันปีหน่อยครับ(เควสเวล75)

เห็นเค้าบอกว่าทำแล้วจะมีคนขายเสื้อกับรองเท้า 75 ให้นะครับ

แล้วดาบกับโล่ + หมวก (ตั้งแต่ 75 + ) มีขายไหมครับ ซื้อที่ไหนครับ แนะนำหน่อยนะครับ

มีอีกเรื่องสงสัยละครับ สรุปแล้วต้องอัพ agi กับ str เท่าไหร่ เหรอครับ ที่พอ+กับที่เกมให้

แล้วจะพอดีละ (ตอนนี้ agi 84+12 str 63+18 ชุดเดิมๆไม่มี+ครับ) เห็นเค้าบอกกันว่า agi สูงสุดที่ 108

งงจังเลยครับ อธิบายแบบละเอียดได้ไหมครับ ขอบคุณครับ
