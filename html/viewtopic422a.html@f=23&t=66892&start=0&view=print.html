ราคาไอเท็ม ที่ได้จากตั๋วต่างๆ มันขึ้นอยู่กับอะไรหรอคับ

หายาก หรือว่าเป็นที่นิยม หรือว่าอย่างอื่นอีก

ตั๋ว 10 ก็มี

pet - ชุดเชียร - ชุดเทนนิส - ชุดนักธนู แพงตามลำดับ

ชุดเชียร์กับเทนนิสคุณสมบัติพอๆกัน ต่างกันที่ vit +3 กับ dex/str +1

แต่ราคาแพงกว่า 2 เท่าแนะ

เท่าทีรู้ คือตาม % การออก ของแต่ละอย่างอะจ๊ะ อันไหนออกง่ายก็ถูกออกยากก็แพง รวมไปถึงความสวยกับความนิยม ในช่วงเวลานั้นๆ บ้างที่ของมีขายมานานแล้วแต่ราคาแพงขึ้นก็มี ถูกลงก็มี อยู่ที่ ความต้องการในตลาด ด้วย อีกส่วน

แต่พอรวมๆแล้วจะไปตกที่ความพอใจในการตั่งราคากับความพอใจในการซื้อราคานั้นอันก็มีส่วน บ้างคนรับของแพงเพื่อต้องการได้ของเร็วขึ้นทำให้ราคาขึ้นไปด้วย บางที่ตั่งแพงๆหลายๆๆร้านก็ทำให้ราคาขึ้นไปด้วยก็มี แต่แพงมากไปก็ไม่มีคนซื้อ กับกันบางคนตั่ง
ถูกเพื่อต้องการให้ของออกเร็วๆก็มี พอตั่งมากๆๆของก็ราคาตก

มันเกิดได้จากหลายอย่างอะจ๊ะ สรุปคือความพอใจทั้งคนซื้อคนขาย
