เมื่อ n เป็นจำนวนครั้งที่ได้โบนัส

Str
Min Atk = 9n
(หารด้วย9ลงตัว)
Max Atk = 5n+1
(ลงท้ายด้วย1หรือ6)
===========

Dex
S.hit = 10n
(หารด้วย10ลงตัว)
C.Spd = 9n
(หารด้วย9ลงตัว)
===========
Agi
S.avoid และ A.spd = 9n
(หารด้วย9ลงตัว)
===========
Vit
Hp = 5n
(หารด้วย5ลงตัว)
Def =3n+1 หรือ 9n+3
(ลบ1แล้วหารด้วย3ลงตัว หรือลบ3แล้วหารด้วย9ลงตัว)
M.Def = 4n+1
(ลบ1แล้วหาร4ลงตัว)
===========
Mag
Min Matk = 8n-1
(บวก1แล้วหารด้วย8ลงตัว)
Max Matk = 6n+1
(ลบ1แล้วหาร6ลงตัว)
===========
