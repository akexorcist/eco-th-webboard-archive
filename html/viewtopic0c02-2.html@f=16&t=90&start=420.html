หึหึ แวะมาอ่านหลายรอบแล้วงับ ลงชื่อพ่อค้าแม่ขายด้วยคนล่ะกันงับ

หึหึ เมื่อวันก่อนไปเจอปัญหารับซื้อของจนน้ำหนักเกินงับ(เกิดไปร้อยก่าๆ>_<) จาทิ้งมันก็เงินเรางับ รับซื้อมา>_< พวกทั่นทำไงกันงับ(หมายถึงก่อนรับซื้องับ )

คือว่าเราจารู้ได้ไงว่าจารับเท่าไหร่ดี ไม่ให้หนักเกิน หรือว่าต้องมานั่งกดเครื่องคิดเลขงับ(พ่อค้าแม่ขายมันก็ต้องมานั่งคิดน้ำหนักของด้วยซิ ไม่ใช่มานั่งตี ตี ตี งั้นหรอคับ!)
คือ...ถ้าจาต้องมานั่งคิดกันจิงๆนี่ น้ำหนักที่แสดงออกมาคือน้ำหนักจิงใช่ไม๊งับ ไม่ใช่เป็นเปอร์เซนต์

ปล. ของเต็มเดินไม่ได้ ยืนรอคนมาช่วยเกือบช.ม. >_<


วิธีที่เราใช้นะ เวลาไปรับหนังที่แมปหมี(ใช้ได้ในบางกรณี)

ให้ซื้อกุญแจ หรือ รอตายกลับก็ได้ พอรับของจนนน.เกินแล้วก็ให้กลับเซฟ เอาที่อยู่ใกล้ๆพ่อค้ากิลนะ จากนั้นก็โยนไอเทมที่หนักๆลงไปจนเราเดินได้ (ต้องรีบๆนะ เพราะตอนแรกๆคนอื่นจะยังเก็บของเราไม่ได้) จากนั้นก็วิ่งไปในระยะที่เก็บของถึง และเก็บมันขึ้นมา ทำแบบนี้จนถึงพ่อค้ากิล-''-~
