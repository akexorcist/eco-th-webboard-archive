:oops: แนะนำให้ไปที่ My Computer > Tools > Folder Options.. แล้วเลือก Tap : View
ให้สังเกตุข้อมูลตรงที่ถูกวงไว้ด้วยสีแดง (Hide extensions for known file types)
มีเครื่องหมายถูกหรือไม่ ถ้ามีให้คลิ๊กเอาเครื่องหมายถูกออกไปค่ะ (ดังภาพ)



แล้วกลับไปดู File เกมที่เรา Download มาว่าถูกมองเห็นเป็น File . exe แล้วหรือยังค่ะ

ถ้าทำแล้ว File เกมที่ Download ยังคงไม่สามารถมองเห็นเป็น File . exe
แบบนี้ต้องทำการ Download ที่หน้าเวปไซต์อีกครั้ง เมื่อกด Download ทีนี้ก็จะมองเห็นเป็น File . exe ค่ะ



:!: แนะนำอีกวิธีค่ะ ถ้ามีเพื่อนๆ ที่สามารถเข้าเล่นเกมได้ตามปกติ
สามารถขอ Coppy Folder เกม Eco ของเพื่อนมาลงไว้ที่เครื่องของคุณ ก็จะเข้าเล่นเกม Eco ได้เช่นกันค่ะ
