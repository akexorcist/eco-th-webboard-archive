Atk ครับ แล้วก็ที่บอกว่าดาเมจมีสองช่วงนั่นคงจะเป็นท่า Flare string นะครับ ไม่ใช่ Darkness of Night

อยากทราบเรื่องการคำนวณดาเมจน่ะครับ แล้วร่าย 6.5 วินี่สามารถลดได้ด้วย ASPD รึเปล่าครับ?

ลดได้ด้วยค่า agi ครับ รวมถึง สปีดเอนชานท์ก็ช่วยท่านได้เช่นกัน

แล้วสกิล Divine Spear นี่ดาเมจเป็นธาตุแสง ถ้าเกิดเราเคลือบอาวุธเป็นธาตุมืด เวลาใช้ ดาเมจที่ออกไปจะเพิ่มขึ้นด้วยสกิล Dark Add หรือเปล่าครับ?

Divine Spear เป็นการโจมตีธรรมดาไม่คิดธาตุครับ แต่ถ้าเอาไปใช้ใส่อันเดดจะแรง 500% ถ้าไม่ใช่ก็ 300% ครับ
ส่วน Dark Add จะมีผลให้ดาเมจเพิ่มขึ้น ต้องใช้สกิล Dark Weaponใส่ตัวเองก่อนนะครับ

ขออภัยที่ถามเยอะ เพราะเล่นเป็นตัวแรกครับ หาข้อมูลไว้กันอัพพลาด
