ฟิคนี้แต่งขึ้นมาเล่นๆ ไม่อ้างอิงยึดหลักกับระบบในเกมป็นส่วนใหญ่เน้อ=w=

บทนำ

ณ ที่ๆหนึ่งในหุบเขาน้ำแข็งแห่งอณาเขตNorthan

"ฟิ้ว~~ ตึ่ก ตึ่ก"ท่ามกลางเสียงลมพายุหิมะอันหนาวเหน็บที่พัดอย่างบ้าระห่ำราวกับจะพัดทุกสิ่งทุกอย่างให้กระเด็นไป และในท่ามกลางพายุหิมะนั้นได้มีบุคคลลึกลับคนหนึ่งที่สวมผ้าคลุมปิดไว้ทั้งตัวเดินฝ่าพายุหิมะ

"อึก... ลมแรงเป็นบ้าเลย ให้ตายซิ"คนลึกลับผู้นั้นสบถออกมาเล็กน้อยก่อนที่จะจับผ้าคลุมของตัวเองให้มั่นขึ้น

"เห็นทีคงจะต้องรีบเดินทางไปจากที่นี่ให้เร็วที่สุด ไม่งั้น.... อ๊ะ!!!"

"ฟิ้ว~~~ ฉึกๆๆๆ!!!"ในขณะที่บุคคลลึกลับกำลังพลางบ่นอยู่ ทันใดนั้นก็ได้มีมีดคุไน(Kunai)จำนวนหนึ่งพุ่งจู่โจมมายังคนลึกลับคนนั้นทันที

"ชิ... ตามมาทันแล้วรึ"ฟึ่บ!! คนลึกลับคนนั้นได้กระโดดหลบมีดบินที่พุ่งมาจู่โจมตนได้ก่อนที่จะหันไปมองยังต้นทางของที่อาวุธนั้นพุ่งออกมา

"อย่างเธอน่ะหนีฉันไม่พ้นหรอก"บนแท่นน้ำแข็งที่คนลึกลับที่หันไปมองอยู่ก็พบว่ามีคนอีกคนที่อยู่ในชุดผ้าคลุมเช่นเดียวกับเจ้าตัวยืนมองมาที่ตน

"แกนี่มันขี้ตื๊อซะจริง ไปให้พ้นซะทีจะได้มั้ย!!"

"ไม่มีทาง ถ้าฉันไม่ได้'สิ่งนั้น'กับชีวิตของเธอแล้วล่ะก็ ไม่มีทางที่จะรามือเด็ดขาด!! ตายซะ!!!"ฟุ่บ!!! หลังจากที่คนลึกลับที่ยืนอยู่บนแท่นน้ำแข็งพูดจบก็ได้พุ่งตัวคว้ามีดคุไนมาจู่โจมที่คนลึกลับที่ยืนอยู่เบื้องล่างทันทีโดยไม่รอช้า

"อยากได้มันนักใช่ไหม ได้ เข้ามาซะสิ!!"แควก!!! ฟึ่บๆ ชิ้ง~ คนลึกลับคนที่อยู่ข้างล่างก็คว้าห่อผ้าอะไรบางอย่างออกมาแล้วฉีกผ้านั้นออกจนเผยรูปร่างของหอกเล่มหนึ้งออกมาพร้อมที่จะรับมือกับคนที่กำลังมุ่งตรงมายังตน

"พิ้ง!! ฟึ่บ!!! ฟุ่บ!! แก๊ง!!"หลังจากที่ทั้งสองต่างได้งัดอาวุธออกมาก็ได้เริ่มการปะทะกันอย่างดุเดือดโดยที่ไม่มีใครด้อยไปกว่าใคร

"ฝีมือยังดีไม่ตกเลยนี่ แต่ว่า..."

"แบบนี้ไม่มีทางที่จะเอาชนะฉันไปได้หรอก"ฟึบ!! ในขณะที่คนลึกลับที่ถือมีดคุไนกำลังพูดอยู่จู่ๆก็ได้หายไปปรากฏอยู่ข้างหลังคนลึกลับที่ถือหอกอยู่ทันทีโดยไม่ทันตั้งตัว

*เสร็จกัน!!*แควก~~~!!! คนลึกลับที่ถือมีดคุไนได้ฟันใส่ผ้าคลุมของคนลึกลับที่ถือหอกจนขาดกระจุย

"เกือบไปแล้วสิ"กึก!! คนลึกลับที่ถือหอกหลบได้ทันก่อนที่จะเสียผ้าคลุมส่วนที่คลุมส่วนหัวจนได้เผยใบหน้าของเธอออกมา(ผมสีน้ำเงิน ตาสีฟ้า ไว้จะวาดรูปมาให้ดู จิ้นๆไปก่อนละกัน-__-)

"ไวดีนี่ แต่ก็ไม่มีทางรอดอยู่ดี หึๆ"

"อ๊ะ!! นี่มัน.."กึก.. หญิงสาวผมน้ำเงินได้รู้สึกตัวถึงอะไรบางอย่าง เธอพบว่าที่คอของเธอมีแผลเล็กๆและมีเลือดไหลออกมาเล็กน้อย

"มีดของฉันนี่ได้อาบยาสารพัดพิษไว้ ถ้าโดนเข้าไปแม้เพียงเล็กน้องก็เตรียมตัวตายได้เลย"

"กรอด...*ตัวเริ่มชา.. ท่าจะแย่ล่ะสิ แถมเราก็ไม่มียาแก้พิษซะด้วย*"หญิงสาวผมน้ำเงินกัดฟันแน่นพลางคิดหาทางแก้สถานการณ์ไปด้วย

"ยอมรับที่จะตายได้แล้วสินะ งั้นก็ตายซะ"ฟุ่บ!! วืด!! คนลึกลับที่ถือมีดคุไนได้พุ่งเข้ามาจู่โจมเพื่อที่จะปลิดชีพของหญิงสาวผมน้ำเงินทันที

"ไม่มีทางหรอก!!!"เปรี้ยง!!! ตึง!!! หญิงสาวผมน้ำเงินเธอได้ฟาดหอกออกเป็นวงกว้างจนคนลึกลับคนนั้นกระเด็นออกไปกระแทกกับกำแพงน้ำแข็งอย่างรุนแรง

"อั้ก!!!"คนลึกลับคนนั้นถึงกับกระอักแทบชักดิ้นหลังจากที่โดนโจมตีเข้าอย่างจัง

"แฮ่ก แฮ่ก อุ่ก..."หญิงสาวผมน้ำเงินก็เหนื่อยหอบหลังจากที่เหวี่ยงหอกออกไปเมื่อครู่อย่างแทบหมดแรง

"กึก... ครืน~~!!!"แต่ในทันใดนั้นเองพื้นที่ๆหญิงสาวผมน้ำเงินยืนอยู่ก็เกิดพังทลายลงไป และตัวเธอเองก็ร่วงลงไปพร้อมกันด้วยเช่นกัน

"จะหนีรึ!! อั้ก..."คนลึกลับคนนั้นคิดจะตามไปแต่ก็ต้องชะงักลงเพราะอาการเจ็บปวดที่โดนหอกฟาดมันยังออกฤษธิ์จนแทบเดินไม่ไหว

"คิดจะยืดเวลาออกไปสินะ ได้ ยังไงซะเธอก็ไม่มีทางรอดจากฉันได้หรอก ฮะๆ"คนลึกลับคนนั้นยืนมองจากบนผาที่หญิงผมน้ำเงินได้ร่วงลงไปก่อนหน้าก่อนที่จะหายไปจากพื้นที่แถวนั้นทันที

....หญิงสาวผู้นั้นเป็นใคร แล้วที่เธอถูกตามล่าเพราะเหตุใดกันนะ....

ชื่อไทย : ฮาคุเรย์ เรย์มุ
ชื่ออังกฤษ :Hakurei Reimu
ชื่อญี่ปุ่น : 博麗　霊夢
เผ่าพันธุ์ : มนุษย์
ความสามารถ : ผนึก,พลังชำระล้างและสัญชาตญาณระดับสูง
สถานะ : มิโกะ
ที่อยู่ : ศาลเจ้าฮาคุเรย์
อาวุธ : ไม้ปัดรังควาน,ยันต์นำวิถี,ลูกแก้วหยิน-หยาง


ฮาคุเรย์ เรย์มุ มิโกะแห่งศาลเจ้าฮาคุเรย์ สาวน้อยผู้เป็นตัวเอกแห่งโทโฮซีรี่ย์
อาศัยอยู่ในศาลเจ้าฮาคุเรย์ อันเป็นศาลเจ้าแบบศาสนาพุทธนิกายชินโต
ซึ่งตั้งอยู่ทางสุดทิศตะวันออกของเกนโซเกียว และมักจะเป็นศูนย์รวมในการ
พบปะชุมนุมสังสรรค์ของเหล่าโยว์ไคต่างๆอีกด้วย เมื่อเกิดปัญหาเรื่องใหญ่
หรือภัยพิบัติต่างๆในเกนโซเกียว ก็เป็นหน้าที่ของเธอด้วยเช่นกัน ที่จะต้อง
เข้ามามีส่วนในการคลี่คลายปัญหาที่เกิดขึ้น(ทั้งที่บางทีก็ขี้เกียจและไม่เต็มใจ)
เรย์มุเป็นคนเรียบง่าย เธอจึงกลายเป็นที่นิยมชมชอบของทั้งผู้คนและโยว์ไค
และทำให้แวะเวียนมาหาเธอและก่อความยุ่งยากให้อยู่เสมอ เธอมีสติปัญญา
เฉียบแหลม และมักจะโชคดีอยู่เสมอ กระนั้นเธอก็ออกจะเป็นคนขี้เกียจเช่นกัน
เกลียดการฝึกฝน ไร้ซึ่งความทะเยอทะยาน และปล่อยชีวิตให้ผ่านไปวันๆเสียนี่
ถึงอย่างนั้น ด้วยสิ่งที่เรียกว่าเป็นพรสวรรค์ของเธอ ทำให้เธอมีความแข็งแกร่ง
อย่างถึงที่สุดเลยทีเดียว ถึงแม้จะไม่ยอมฝึกฝนเลยก็ตาม นอกจากนี้ เธอยังชอบ
ดื่มชาเป็นที่สุด นอกจากนี้เรย์มุยังมีพลังมหาศาลไร้ซึ่งขีดจำกัด แถมยังมีไอเท็ม
อย่าง "ลูกแก้วหยินหยาง" สุดยอดไอเท็มพลังมหาศาลที่มีความนึกคิดของมันเอง
และความสามารถของลูกแก้วหยินหยางนั้นก็คือ "แปลงร่างเป็นอะไรก็ได้ตามใจนึก"
แต่ในความเป็นจริงแล้ว มันไม่ได้เปลี่ยนร่างได้แค่ตัวเองเท่านั้น แต่ยังสามารถใช
ความสามารถนี้กับทุกสิ่งรอบๆตัวได้ด้วย ราวกับว่ามันสามารถดลบันดาลทุกสิ่งได้
ดั่งใจคิด และยังช่วยให้เรย์มุสามารถใช้สุดยอดท่าไม้ตายที่เรียกว่า "มุโซเทนเซย์"
หรือที่แปลว่า "ลิขิตฟ้าชะตาจินตนาการ" ซึ่งจะทำให้เรย์มุเข้าสู่สภาพไร้เทียมทาน
ที่ไม่ว่าใครก็ตามก็ไม่สามารถที่จะเอาชนะได้เลย จนกว่าจะศิโรราบกันไป ส่วนเรื่อง
ชาติกำเนิดของเรย์มุนั้นยังไม่ทราบอย่างแน่ชัดและคงความเป็นปริศนาอยู่ รู้เพียง
แต่ว่าเธอเป็นเด็กผู้หญิงไร้ประวัติที่มาซึ่งมีชะตากรรมในการรับสืบทอดตำแหน่งมิโกะ
แห่งศาลเจ้าฮาคุเรย์เป็นรุ่นที่ 13 ต่อจากรุ่นก่อนซึ่งสืบทอดกันมาหลายต่อหลายรุ่นก่อน
ทั้งนี้มิโกะแห่งศาลเจ้าฮาคุเรยอย่างเรย์มุก็มีหน้าที่ในการดูแลดินแดนเกนโซเกียวให้
สงบสุขเช่นกัน เหมือนกับศาลเจ้าฮาคุเรย์ที่ถูกสร้างมาเพื่อจุดประสงค์ในการแบ่งแยก
ระหว่างเกนโซเกียวกับโลกภายนอก เพื่อกักขังเหล่าโยว์ไคเอาไว้ และเพื่อความสงบสุข
