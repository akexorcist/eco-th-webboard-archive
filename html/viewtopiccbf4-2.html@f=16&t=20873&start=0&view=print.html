รู้สึกมั้ยว่าเล่น tatarabe,ranger เนี่ย บางครั้งอาจจะต้องเดินเท้าเปล่าบ่อยครั้ง

เนื่องจากรองเท้าประจำอาชีพเนี่ย มีคุณสมบัติอย่างที่รู้กันว่า -1 str
และโบนัส str ก็ลงที่ 5n+1

ถ้าเกิดว่าใส่รองเท้าอยู่แล้วเล่นไปเล่นมาอัพ str แล้วกลายเป็น 5n ก็ต้องถอดรองเท้าเพื่อให้กลับมาเป็น 5n+1 พอเลเวลต่อมาอัพ str ค่อยกลับมาใส่รองเท้าเหมือนเดิม

มีใครเล่นแบบนี้บ้าง
แต่ว่าไปแล้วมันก็ถือว่าสะดวกดีเหมือนกันนะแบบนี้

รองเท้าประหลาดใส่แล้วแรงตก - -"

สำหรับผมก่อนที่จะได้ใส่รองเท้าที่ว่านี้ผมก็จะอัพ str เผื่อไปเลย 2 ค่าครับ เพราะพอถึงเลเวลที่ใส่รองเท้านั่นได้พอดี str มันก็จะลดแค่ 1 ทำให้ยังไม่เสียโบนัส atk ครับ
