เวลาชาร์ทของจขกทนี่ หมายถึง อะไรหว่า ใช่ระยะเวลาร่ายสกิล รึเปล่า

แรนความเร็วร่ายไม่น่าห่วงหรอก ห่วงดีเลย์หลังร่ายสกิลมากกว่า(คนละค่ากับ โมชั่นดีเลย์นะ) ที่มีถึง 3 วิ ขณะติดดีเลย์จะโจมตีหรือใช้สกิลต่อไม่ได้ ปั้มยายังทำไม่ได้เลย

วิธ๊ลดดีเลย์คือ กด Sword Deley Cancel เลเวล 3 ลดได้ตั้งครึ่งนึง

ส่วนตอนฟัน 5 ครั้งจะเร็วแค่ไหน อยู่ที่ โมชั่นดีเลย์ ซึ่งขึ้นกับ agi และ Sword Deley Cancel ก็ช่วยได้

ขอสรุปล่ะกัน

ถ้าคิดในมุมมองใช้แรนเป้นหลัก

สาย Str-Dex-Vit ที่คุณต้องเจอเลยคือ ดีเลย์หลังใช้แรน 3 วิ ซึ่งหากไม่อยากติดตรงนี้ ต้องกด SDC ก่อนแรน(แต่ความจริงก็ไม่จำเป็นหรอก ติดดีเลย์ไปเหอะ มีตัวสิงดีๆ ก็ไม่ตาย มีพ่อค้าสิงฮิลจะทำอะไรก็ทำได้ ) แต่สาย str agi ที่กด SDC เป็นชีวิตอยู่แล้ว ก็ไม่มีปัญหาอะไร
