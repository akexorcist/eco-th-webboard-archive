อ้างอิงจาก 11/12/52 ได้ถามดังนี้

คือว่าเลี้ยง Maid อยู่อ่าค่ะ แล้วข้อมูลก็หายากมากมาย(เพราะเหมือนจะเป็นpetที่มีเฉพาะในไทย)

ทีนี้อยากจะรู้ว่า ค่า Hp Recovery ของ Maid นี่มันเต็มเท่าไรหรือคะ

(เท่าที่รู้มามันมีผลต่อค่า Vit ที่ได้ตอนล้มด้วย แต่ไม่มีข้อมูลเลยว่ามันเต็มที่เท่าไร - -)

ท่านใดช่วยชี้แจงแถลงไขจะเป็นพระคุณอย่างสูงค่ะ

ปล.มิเช่นนั้นคงต้องอัดอาหารกระป๋องไปสัก 10000 ป๋อง แล้วลองเอาไปล้มดู - -"



ผลปรากฏว่าคำตอบในตอนแรกว่าค่านี้ไม่เกี่ยวกับการล้ม Pet

...

แต่ดันมีเรปต่อมาจากอีกคนบอกว่าเกี่ยว



ด้วยความไม่แน่ใจและไม่ได้รับคำตอบ วันนี้จึงได้ทำการทดลองอัด Pet Food ให้ Maid กินไป 3000 กระป๋อง(คืออัดจนค่ามัน+100 แล้วอัดต่ออีก 100เพื่อยืนยันว่าตันแล้ว)

ได้เซฟภาพก่อนและหลังการอัดกระป๋องไว้แล้วพบว่า

ค่า HP Recovery เกี่ยวของกับค่า Vit ที่ได้ตอนล้ม Pet ค่ะ!

เลยนำรูปมาลงไว้ในที่นี้ เนื่องจากหากระทู้อ้างอิงเรื่องนี้ไม่เจอแล้ว ทำไว้ให้นักฝึกสัตว์หน้าใหม่ทั้งหลายได้อ่านค่ะ



แล้วก็ มีคำถามแถมท้าย มีใครรู้มั่งคะว่าจะฝึกค่า Matk ของ Maid ยังไง ฮีลไปฮีลมาจนค่าอื่นเต็มแล้วยังได้แค่+3อยู่เลย(เต็มแค่12แต่ขึ้นยากมากมาย)



...รึว่าต้องตายให้มันชุบ
