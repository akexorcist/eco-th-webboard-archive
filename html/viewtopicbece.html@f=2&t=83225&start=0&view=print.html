เท่าที่เห็นคนที่เคยเป็นGM ของ eco ในบอร์ดนี้มีแค่ คุณตั้ม กับ เนโกะ ล่ะมั้ง
แล้วไม่ได้เข้ามาตอบบอร์ดนี้มานานมากแล้วครับ

เว็บนี้เป็นแค่เว็บแฟนเพจที่เพื่อนๆช่วยกันทำขึ้นมาเป็นที่รวมพลคนที่ยังรัก eco อยู่
จึงไม่มีระบบแบบบริษัทเกมครับ เป็นแค่เว็บบอร์ดเฉยๆที่เพื่อนๆคอยจัดการดูแลกันเองครับ

ส่วน ตัวเกมกับเว็บบอร์ดeco ของเซิฟไทยปิดไปเกือบครบรอบ 1 ปีแล้วครับ

ถ้าอยากสัมภาษณ์อาชีพนี้ ลองไปขอสัมภาษณ์ตามบริษัทเกมดีกว่าครับ น่าจะได้ชัวร์ๆกว่าครับ
