ไม่แน่ใจนะว่าที่เอามาแจกนั่นฟอนต์อะไร แต่ผมว่า MS PGothic แหงๆ

คือมันมีโปรแกรมนึงที่แถมมากะวินโดว์เลย คือโปรแกรม Character Map ที่เอาไว้ Preview ฟอนต์ต่างๆที่มีอยู่ในเครื่องเรา ผมก็ใช้โปรแกรมนี้หาตัวอักษรประหลาดๆตอนตั้งชื่อเหมือนกัน

ให้เข้า Start > All Program > Accessories > System Tools > Character Map
