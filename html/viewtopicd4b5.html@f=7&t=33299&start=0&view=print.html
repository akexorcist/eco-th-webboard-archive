แต่อิฉัน ต้องพูดด้วยความเสียใจว่า

อิฉัน ไม่ได้หมีน้อยซานต้า อันเหตุเนื่องมาจาก

เพราะมีซานต้าไทนี่ไว้ในครอบครองก่อนแล้ว

เหตุการ์นเป็นดังนี้-

-คนรุ้จัก(เพื่อน)ได้ซานต้าไทนี่มา บอกว่า 'เปิดกล่องแรกก็เจอเลย' แต่มันบังเอ้ญไม่ใช้ เพราะเจ้าตัวเล่นอาชีพ Scout ไม่จำเป็นใช้ MP แต่ตัวอิฉัน เล่นสาย Shaman เจ้าเพื่อนสุดแสนดีนั้น มันเลยมอบซานต้าไทนี่ให้ โดยที่อิฉันไม่รุ้ว่าต้องไปทำอย่างไรจึงจะได้กล่องมา อิฉันอยากทำเควสหมวกซานต้า เห็นในบอร์ดบอกคร่าวๆว่าต้องทำเควส เลยจะไปหา ชินนาม่อน แคน มาทำเควส แต่บังเอิญเจอ ปลาสีส้มๆเสียก่อน เลยตีมัน...ปลาตาย เลยได้กล่อง (แอบหวังลึกๆเอาไว้ว่าคงโชคดีได้เหมือนมัน) เดินๆไปในเมืองเอากล่องไปเปิด

.......!!.....ห๊าาา ได้ มาชแมโล T-T ดูเหมือนจะไม่มีดวงจริงๆ แต่พอมาอ่านในบอร์ดว่า ทุกคนนเปิดกล่องแรกก็ได้ซานต้าไทนี่ ก็มาฉุกคิดได้ว่า "ไม่น่าเอามาก่อนเลยเรา " T-T :cry:
