Assist ค่อนข้างบ่อยนะครับ คือ จะใช้คำว่าเอาดาเมจของเจ้าของร่างไปให้คนสิงก็ไม่ค่อยจะใช่ซะทีเดียว เพราะดาเมจที่ได้รับขณะที่สกิลแสดงผลนั้น มันจะเอา def./mdef. ของคนกดสกิล (คนกดสกิล = ไนท์) มาคิดอ่ะคับ ดังนั้นดาเมจที่ไนท์ได้รับจึงไม่ใช่ดาเมจของเจ้าของร่างแน่นอนครับ (เป็นดาเมจของไนท์นะคับ :lol: )

และการที่คนสิงคนอื่นๆ ในร่างจะโดนด้วยนี่ น่าจะโดนเพราะผลของสกิลหมดไปนะครับ เพราะจากที่เคยลองใน nvn สิงกัน 3 คนเต็มที่ ไนท์กด def. assist ตายก่อนเสมอ (สิงดาบ) ซอสิงอกกะพระสิงเกราะนี่เลือดยังเต็มอยู่เลย ซอจะร่วงก่อนมีสาเหตุเดียวที่เป็นไปได้ก็คือ โดนตีตอนที่ผลของ def. assist หมดไป และไนท์กะลังกดสกิลต่ออยู่ (สกิลนี้กดรัวๆ ไม่ได้นะ :twisted: ) แต่ไม่ยืนยันเรื่องการแบ่งดาเมจจากเจ้าของร่างนะครับ เท่าที่สังเกตุดู บางทีไนท์ก็จะรับดาเมจทั้งหมด แต่บางทีก็มีหลุดๆไปให้เจ้าของร่างบ้างนะครับ
