ประมาณว่า...ไม่ว่าเค้าจะตั้งกระทู้เรื่องอะไร ตั้งให้ใครอ่าน ตั้งให้ใครตอบ
ตั้งเพื่อใคร ตั้งทำไม ตั้งแบบไหน
..................แต่
ก้มีบุคคลบางคน ที่ชอบเข้ามาแสดงความเหน ชึ่งบางทีก็ประชด
บางทีก้เชิงท้าทาย บางทีก้หาว่าเจ้าของกระทุ้ไร้สาระมั่งล่ะ
ชึ่งบางกระทุ้ที่ ระบุว่า ขอแค่คนมีส่วนเกี่ยวข้องตอบ แสดงว่าเค้าต้องการความคิดเหนของคนนั้นจิงๆ แต่ท่านก้เข้ามาก่อกวน แถวบ่นอุบอิบบ้างล่ะ ว่าทำไมไม่PM คุยกันเอา ทำไมมาตั้งในบอร์ดบ้างล่ะ ทั้งที่ก้ระบุชัด ขอแค่คนมีเรื่อง อย่าอยากมีส่วนร่วม ชึ่งเข้ามาอ่านก้ไม่ว่า แตถ้าเข้ามาแล้วโพสไม่สร้างสรรค์ อย่าโพสดีกว่าไหม
ชึ่งมันส่อให้เหนว่า ท่านมีนิสัยเช่นไร
..................คนมีมารยาท เข้ามาอ่าน แล้วก้ผ่านไป
เจ้าของกระทุ้ บางทีอาจจะโดนหาว่า ตั้งกระทู้ดักควาย ที่จิงมันไม่ใช่
ท่านที่โพสตอบ กรุณาดูความเหมาะสม ไม่ใช่แค่จะตำหนิอย่างเดียว
..................สมมุติ
คุณประกาศ ขอความช่วยเหลือ แต่....กลับมีคนมาโพสไรรมั่วไปหมด
ไม่ว่าจะบอกไปหาเองมั่งล่ะ (แบบว่าหาไปแล้ว100กว่ารอบแต่มันไม่เจอ)
หรือขุดกระทู้ด้วยการตอบแบบไร้สาระ เช่น เซ็ง...หาเองดิว่ะ
ก่อนจะตั้งกระทู้ หาเองก่อนดิ มันรกบอร์ดไปหมดแล้ว....แล่วท่านรู้ไหม
ว่าการหาเองกับการรอคนมาโพสบอก อันไหนไวกว่า....ถุกต้องนะค่ะ
หาเองไวกว่า เปนคำตอบสุดท้าย..... แต่มันหาไม่เจอเลยต้องโพสถาม
ถ้าท่านไม่ช่วยก้อย่าต่อว่าคนตั้งกระทุ้เลยนะ บางคนเพิ่งมาใหม่
แล้วข้อความที่เคยมี มันอาจจะหายไปแล้ว หรือหาไม่เจอจริงๆ ผุ้รุ้ทั้งหลาย
จะช่วยกันทำแบบนี้ได้ไหม ดีกว่าจะต่อว่าคนตั้งกระทู้...ขอบคุณทุกท่านที่อ่าน
..........กระทู้นี้ไม่ต้องการความคิดเห็นนะค่ะ แต่ต้องการให้นำไปใช้ในการตอบกระทู้ท่านอื่นๆ เพื่อที่จะรักษามารยาทของผู้รู้ที่มีมารยาท อัพเกรดความคิดตัวเองให้สุงขึ้น........
.............อีกอย่างนะค่ะ ถ้าท่านเจอกระทุ้ที่ถามช้ำๆกัน ในเรื่องเดิมๆ แต่คนละคนถาม ก้ตอบเถอะค่ะ ถ้าไม่ตอบก็รอคนอื่นตอบ แต่อย่าโพส ข้อความแบบว่า...หาเองดิ
ทำไมต้องโพสช้ำกันด้วย หาเองไม่เปนรึไง...นี่แสดงว่า คุณ!!! ไม่มีความรุ้จริงในการตอบ

ส่วนใหญ่ผมตอบแต่กระทู้ที่ผมรู้คำตอบ ถึงแม้ว่ามันจะเป็นคำถามที่ซ้ำซากก็ตาม

เพราะบางคนที่เข้ามา เค้าอาจจะไม่รู้จักระบบบอร์ด ที่สามารถค้นหากระทู้เก่าๆอ่านได้ และที่สำคัญ บางคนก็มืใหม่จริงๆ ( ดูได้จากจำนวนการโพส )

หรือถ้าคิดในแง่ที่ต้องการคำตอบที่รวดเร็ว ส่วนใหญ่ มักตั้งกระทู้ถามเลย


บางทีผมก็ลองใช้วิธีค้นหา มันก็เจอบ้าง ไม่เจอบ้าง

บางกระทู้ที่เจอ......มันยาวเกินกว่าจะอ่านได้ ( แล้วก็ไม่เจอสิ่งที่ต้องการ )

แถมบางกระทู้ ก็ไม่ได้มีส่วนเกี่ยวข้องกับสิ่งที่ต้องการจะรู้เลย


ซึ่งถ้าเทียบกันแล้ว ระหว่างตั้งกระทู้ถาม แล้วมีคนตอบ กับ

ค้นหากระทู้เอง ที่ไม่รู้ว่าจะใช้เวลาหานานเท่าไหร่ถึงจะเจอ

หลายคนเลือกที่จะตั้งกระทู้ถามเลยมากกว่าอ่ะครับ
