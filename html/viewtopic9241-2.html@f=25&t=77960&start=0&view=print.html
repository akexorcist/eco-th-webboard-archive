เข้าเรื่องเลยนะครับ
1.ลูกเจี๊ยบมี2ขนาด 2ขนาดนี้ทำจากไก่ ที่ต้องเวลขึ้นมันถึงจะฟักใช่ไหมครับ
2.นกที่ดรอปที่ฟูจิเป็นไข่ดรอปยาก ดรอปได้แล้วต้องให้กันเนอร์ฟักอีกใช่ไหมครับ
3.ผมได้ยินว่าที่เหนือ มีนกสีขาว มีคนบอกว่า ดรอปจากตัวนั้นได้ ใช่ไหมครับ เห็นว่าชื่อ "Thunfer Bird" นี่อะครับ
ตกลงมันดรอปได้ไหมครับผมเป็นพวกชอบสะสม ถ้าดรอปได้เห็นเขาบอกว่ามีที่ดัน30 ใช่ไหมครับ
มีที่ดัน30 แล้วมีที่ไหนอีกไหมครับ ตอบกลับที
ตอบมาเป็นข้อๆนะครับ
ขอบคุณไว้ก่อนครับ
