ชิ้นส่วนทำสวนลอยฟ้า รับเมืองใต้ จันทร์-ศุกร์ (เสาร์-อาทิตย์ไม่แจก) พลาดวันไหนอาทิตย์หน้าก็ไปเอาวันนั้นใหม่

ถ้าชิ้นส่วนที่ทำให้บินได้รับเป็นอาทิตย์ อาทิตย์ละชิ้น เปลี่ยนชิ้นทุกวันศุกร์ มีทั้งหมด 3 ชิ้น นอกนั้นก็ของอีกนิดหน่อย หาตามโกเล็ม
