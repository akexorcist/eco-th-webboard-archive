สนับ80 ทำเอง
คทา80 ทำเอง

ธนู80 ร่วงจากกล่อง กะอีกแบบ ทำเอง

ฆ้อน80 ทำเอง โดยตัวฆ้อน(วัตถุดิบ) จะร่วงจากกล่องหอแสง
ขวาน80 ทำเอง
