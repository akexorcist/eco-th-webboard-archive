Abelnic เขียน:คือผมพึ่งมาเล่นใหม่น่ะครับเลยอยากรู้ว่า
เกมส์นี้นอกจากเควสเปลี่ยนอาชีพไม่ต้องทำเควสอื่นได้หรือเปล่าครับ
ที่ถามก็ไม่ใช่ว่าขี้เกียจทำหรอกแต่ที่ผมเคยเล่นเกมส์แนวนี้มาบางเควส
มันยากเกินที่จะทำพอดีว่าเล่นคนเดียวด้วย

ขอบคุณล่วงหน้าที่เข้ามาตอบนะครับ

ปล.ไม่รู้ว่าผมตั้งผิดหรือถูกหมวดหรือเปล่าถ้าผิดก็ ขออภัย นะครับ



เควสเกมนี้ จะแบ่งตามนี้จ้ะ

1.เควสเนื้อเรื่อง (สามารถ ดูได้ ที่ ปุ่ม event แล้วเลือก main story )

2.เควสรับแต้ม skill point

3.เควสประจำวันที่ใช้ แต้มเควส ที่ได้ปรีวันละ 5 แต้ม รับได้ที่ร้านเหล้าค่ะ

(เควสร้านเหล้าจะได้ทั้ง exp / เงินค่ะ ถ้าไม่ค่อยมีเวลาเล่นเกมก็เข้ามาส่งเควสทุกๆ 3 วัน เพราะแต้มเควสจะตันที่ 15 แต้ม
แทนการเก็บเลเวลทุกวันก็ได้ค่ะ )
