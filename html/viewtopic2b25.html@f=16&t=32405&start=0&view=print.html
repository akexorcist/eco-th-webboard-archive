ก็พูดเกินไป แต่ถ้าเล่นสายขอทานจิงๆก็ของประนามด้วยคน
จะเล่นก็อย่าให้ลำบากคนอื่น

ลองเล่นสายของเราดิดีกว่าของทานนิดนึง คือไม่เดือดร้อนใคร แต่อาจจะเกะก่ะ
ลูกตาชาวบ้านนิด สายที่ว่าคือ สาย โจรกระจอก
อาชีพอะไรก็ได้ที่ vit สูงๆ Def สูงๆ MDef สูงๆ เก็บของได้เยอะๆ

1.แหล่ม --เวลาเวลสูงๆเขาตีแล้วไอเท็มที่เขาไม่สนใจเราก็เก็บได้ แต่อย่าน่าเกียจ
เอาพองาม แต่หาแจมเด็จขาด ว่าด้วยมารยาทและเดวหาเรื่องใส่ตัว
แจมเดวเขาก็เดินหนีเราไปทีนี้ใครจะชนมอนให้เราเก็บของเหลือละ
แจมแล้วเผื่อมอนหันมาไล่เราแล้วหมอนั้นก็ประมาณใจดีฉันยกให้แต่เรานะ
จะตาย
2.แรง -- แรง แรงมากครับ กดวิ่งงี้ยิกๆๆๆเลย ไม่ใช่ตีแรงนะ
3ช่วยตัวเอง--ช่วยตัวเองได้ ก็เอายาไปเยอะๆดิ Vit ก่ะ Int เยอะๆ
4.รวยเร็ว --ของตายนายรวยแน่ เข้าดันไม่ตีมอนหาเก็บแต่ของ
(จะรวยแค่ไหนขึ้นก่ะข้อ 2 ก่ะ 3)
5.ไปได้ทุกสถานที่ --อันนี้สำคัญที่ใจ เราเอาชาวชาวนาไป ยอดภูเขาไฟ เหมืองในเมือง
ไอออนชั้นล่างสุด เวลไม่เกิน 24 ด้วย ทุ่งดงหมีเมืองเหนือหากลีบได้
หลายเอมตอนเวล 8 ปราสาทอันเดทเวล 15 หอคอยแสงเวล 20 เกาะต่างๆแถวุพุจิกิ
เวล 18(หลงทางและอยากสำรวจด้วย)ทุกที่เราไปคนเดียว
ไม่พึ่งใคร (ขึ้นก่ะข้อ 2 ก่ะ 3)
6.มีสิทธิ์ได้บู๊ส --ทำตามข้อ 1-5 ได้ จะไปกลัวอะไรเรื่องแค่นี้
7.สบายทุกอย่าง สะบายแน่ถ้ารอดนะ (ขึ้นก่ะข้อ 2 ก่ะ 3)

รึไม่ก็นะมีหลักสูตรรวบลัดทำได้หมดทุกข้อ
ฟันแรง+อึด+ตังเยอะ+มีบูส+ได้เวลเยอะด้วยไปไหนก็ได้=สบายทุกอย่าง
ไปซื้อ ID ชาวบ้านซะเลย เอมก็ซื้อเอา อัดตังจิงๆก็สิ้นเรื่อง
ทั้งนี้ขึ้นก่ะคนสองคนแฮปปี้ด้วย จะได้ดีแค่ไหนแล้วแต่นายจะไปเจอใครแหละกัน

แต่เราขอผ่านวิธีีนี้ถึงเราจะเวลน้อยไปดันโหดๆ เยอะแต่ก็ทำให้ฝึกทักษะเอาตัวรอด
เป็นเยี่ยม เราสนุกก่ะการวิ่งหนีมอนมากกว่า พอมีคนตายก็ย่องไปหาแล้วบอกว่า
ชุปเม็ดละ 10k สนม่ะพี่(ติดนิสัยมาจากวาเตสแหะ)
