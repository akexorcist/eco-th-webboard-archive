สาเหตุที่เลือกเล่น
1. สกิลสวย
2. ดูเป็นเอกลักษณ์ของ คอมมานโด ดี ^^
3. ติดมาจาก ม้อง ใน เกม R(ตรู๊ดดดด) อา(ตรู๊ดด)ร่า สไตรส์~*

ตอนนี้ สาย Tech มันอัพได้ job.40 สินะ

ว่าด้วยสกิลที่ข้าน้อยจะอัพก่อนเลย


Martial Art Mastery
สกิลหลักเลย เพราะเพิ่มพลังโจมตี ของสกิลสายนี้ขึ้นมากมาย


Summersault Kick
ตีลังกาเตะ >_< ความแรงหลังจากอัพ Mastery แล้วคือ 260% แน่ะ
เปนสกิลจาก Scout


Tackle
ท่าแทคเคิ่ล อเมริกันฟุตบอล *-* ความแรงหลังอัพ Mastery คือ 169% ( เบาแฮะ -*-a )
เอาไว้กระแทก แล้วเผ่น


Ashibarai
ชื่อภาษามวยวัด เรียกว่า เถรกวาดลาน ( เอ้ยย ไม่ใช่แล้ว ) ความแรงหลังอัพ MAstery คือ 182% ( เฮ้อ เบากว่า Blow อีก )
มีข้อดีคือ ออกท่าไว หยุดร่ายได้ โดยเฉพาะ สกิล Riot 555+


Combination
สกิลท่าชุด ชุดแรก
Ashibarai -> Summersault Kick -> Tackle !!
ความแรงที่อัพ MAstery เต็มรวมแล้วคือ 611% *-*
แต่เด๋วก่อนนะ
Continue thrust ของ Scout มัน 120% 6 ที = 720% นินา -*-
ดูเหมือนไม่คุ้มท่าที่อัพเลย
แต่เวลาแทคเคิ่ลไป 6 ช่องแล้วใช้ Continue throw หรือ Plurality Bullet ยัดต่อได้นินา ( มั้งนะ ไม่แน่ใจ รอคนมาคอนเฟิม ) ถ้าอัพไว้นะ แหะๆ


Sliding
ท่าหมู่แนวตรงทางยาว 9 ช่อง ( ไกลนะนี่ ) หารดาเมจ
เมื่ออัพ Mastery เต็มแล้วแรง 286% โอว ความแรงระดับเดียวกับ Strike Blow ของ บาวตี้เลยแฮะ ( สกิลพุ่งเหมือนกัน )


Rush
จาก http://translate.google.co.th/translate ... n%26sa%3DG
มานบอกว่าเปน Body Art Skill ด้วยแฮะ
แต่ถึงยังไงๆ ก็ไม่น่าใช่อยู่ดีอ่ะ ถึงจะอัพสกิล Mastery มาก็แรง 132% 4ที = 528%
ซึ่ง กิน SP 50 ไม่มี เอฟเฟคอะไรเลย
เทียบกับ Continue thrust ของสเก๊า ซึ่งแรง 120% 6ครั้ง = 720% ใช้ SP แค่ 30
ก็คงพอรู้แหละ - -a



Uppercut
สกิลสตั้น ที่ทั้งแรงทั้งไว DMG 364% เมื่ออัพ Matery แล้ว 1 ในสกิลที่หลายคนติดใจ =w=


Cyclone
ท่าหมู่รอบตัว ร่ายช้า ระยะแคบ ( จากที่หลายคนบอกมา ) ความแรงเมื่ออัพ Mastery แล้วคือ 390%
จัดว่าอยู่ระดับเดียวกับ Sennpuuken ( 400% ) ท่าหมู่ของเบลดเลยทีเดียว

-------------------------------------------------------------------

ในซาก้า นี้ ก็มี ท่า Martial Art อยู่แค่นี้แหละมั้ง ( แค่นี้พ้อยก็ไม่พออัพแล้ว T^T )

ส่วนตัวข้าน้อยแล้วคิดว่าจะลง
Martial Art Mastery
Ashibarai
Tackle
Combinetion <- อาจตัดออก เพราะค่อยๆ กดทีละสกิลก็ได้ แล้วเอามาอัพ Uppercut แทน
Flash Handgrenade <- อันนี้ดูเป็นสกิลที่น่าอัพยังไงไม่รู้แฮะ หยุดหมู่เนี่ย

แล้วก็สกิลที่จะเอามาจาก Assasin

Bawl เอาไว้แก้สกิล ลด Agi ของ บาวตี้ และสกิลลดแม่นทั้งหลายแหล่ โดยเฉพาะ
Utusemi แน่นอน สกิลเด็ดสกิลนี้
Cloaking อ่ะแน่นอน เราไม่ได้เกิดมาเพื่อ เข้าชนนี่นา
Critical DMG ไม่เอามาคงไม่ได้หรอก สกิลนี้ 20% นี่ เยอะโขเลยแหละ

ส่วนตัว คาดว่า คงเล่นแอสได้ไม่ถึงจ๊อบ 50
แต่ถ้าเล่นถึง อีกสกิลนึงก็
[Sudden attack]

อิอิ ครบ 5 สกิล

ไม่ชัวร์เรื่องสกิลเหมือนกันนะ ตรงนี้ อยากได้คนแนะนำมากๆ

Deadly Attack
สกิล Martial Art ในอนาคตที่จะมาแทน Uppercut มีโอกาสทำให้ศัตรูติดเกร็ง 60% *-*
ความแรงปกติ 350% และ 455% เมื่ออัพ Mastery แล้ว ใช้ SP



Wild Dance
สกิลนี้ ใน http://ec.gamedb.info/wiki/Skill/Comman ... html#tre22
ให้ความแรงไว้ที่ 240% 4 ครั้ง และ 312% 4 ครั้ง เมื่ออัพ Mastery เต็ม ใช้ SP 45
ข้อมูลบอกว่าใช้สกิล Upper, Kick, Summersault และ Cyclone ต่อเนื่อง
