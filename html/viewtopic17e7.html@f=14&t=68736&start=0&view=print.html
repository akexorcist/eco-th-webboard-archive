ไปแมป ก่อนวอลคาโน่อ่ะ ชื่อแมปอาไรจำมะได้และ ใช้บัตรผ่านเมืองใต้เข้ามาแล้วก็เจอเลย

มะก่อนผมยิงอยู่ช่วง 50-60 ขึ้นดีใช้ได้เลย

tip มันจะเกาะเป็นจุดๆ ที่มอนมันเกิดเยอะๆ ด้านขวาอ่ะ ให้ไปที่่หน้ารู แล้วค่อยๆ ไล่ยิงมอนที่หน้ารู
