Red เขียน:ก็อัพ blow สิครับมันมีสกิลโจมตี 2 สกิลไม่ใช่เหรอ - -"
วันนี้ชาวนาผมพิการไปแล้วยังปวดหัวเลยว่าจะเล่นยังไงดี

มีคำถามอีกละช่วยตอบหน่อยนะครับ
1. ชาวนาเลเวล 23 จะเก็บเลเวลที่ไหนดี สาย vit>>str>>dex นะครับ

2. ระหว่างสกิล "เพิ่มความแม่นยำขวาน" และ "เพิ่มพลังโจมตีขวาน" อัพอันไหนก่อนดีครับที่จะช่วยในการเก็บเลเวลให้ไวขึ้น

3. สกิลทำอาหารน่าอัพขนาดไหนครับคือทำแล้วได้อาหารที่คุ้มขนาดไหน (ใครเคยทำแล้วมาบอกอาหารที่ทำที่ดีที่สุด ทีนะครับจะได้รู้ว่าดีไหม)

4. สกิลก่อกองไฟอัพเต็มเลเวล 3 นี้จะเพิ่มระยะเวลาและความแรงในการเพิ่มเลือดใช่ไหมครับ หรือเพิ่มแค่ระยะเวลาที่สกิลมันอยู่เท่านั้น

ถ้าตอบคำถามจะขอบคุณมากครับ :wink:



ตอบคุณ Wink นะจ๊ะ ...

1 . สาย Vit หาที่เก็บง่ายอยู่เพราะว่าโดนเบา แนะนำให้ไปที่ดันทางตะวันออกเฉียงใต้
วิธีการไป จากสะพานตะวันออก ออกเมืองมา เข้าวาร์ปล่าง จากนั้นเข้าวาร์ป ขวาล่าง
อีกที ดันจะอยู่ วาร์ปซ้ายบน

2 . มาทำความเข้าใจ 2 สกิลนี้กันก่อนนค่ะ ..
-สกิลเพิ่มพลังโจมตีขวาน ... ที่ สกิล lv 5 จะเพิ่มค่าพลังโจมตีรวม +30 และ แม่นยำรวม +12
-สกิลเพิ่มความแม่นยำขวาน .... ที่ สกิล lv 5 จะเพิ่มความแม่นยำรวม +18
** แนะนำให้อัพ อันแรกก่อนดีกว่าค่ะ ^^

3. สกิลทำอาหาร นี้ถือว่าเป็นสกิลที่จำเป็นมาก ของ ฟาร์มเมอร์ และใช้ควบคู่กับสกิล ทำไอเทม ( สกัดไอเทม ) ค่ะ แนะนำให้อัพเต็มให้หมดทั้ง 2 สกิลนี้ ค่ะ ส่วนสูตรทำอาหาร ให้ลองๆ ทำไปเรื่อยๆนะค่ะ ไม่ก็ไปซื้อคู่มือ ที่เมืองอัพทาว อยู่ทางซ้ายบน ^^

4. สกิลก่อกองไฟ ที่เลเวล 3 ฟื้นฟู hp ทีละ 30 เป็นเวลา 60 วินาที จากดาต้าเบส บอกว่า ฟื้นฟู รวมทั้งหมด 360 จ้า ... ไม่ว่าเลเวลอะไร ก็จะมีเวลาคงอยู่ 60 วินาที เหมือนกัน


*** สกิล ก่อกองไฟ และ สกิล Healling Tree

คุณสมบัติ ของ 2 สกิล นี้แทบจะไม่ต่างกันเลย ไม่ว่าระยะเวลาสกิล รวมไปถึง
จำนวนการฟื้นฟู hp ที่เลเวลสกิลเท่ากัน เพียงแต่ การจะได้มาของ Healling Tree นั้น ต้องมี job lv 50 ทีเดียว
ถ้าคิดว่าจะเล่นจ๊อบ 50 แล้วเอา Healling Tree ไม่แนะนำให้อัพ สกิลก่อกองไฟค่ะ
จริงอยู่ที่ จำนวนพ้อยในการอัพ ต่างกัน ( ถ้าจะเอาสกิล Healling Tree เต็ม 5 )
แต่ด้วย lv สกิลที่มากขึ้น ก็ฟื้นฟูได้มากขึ้นเช่นกัน

ที่ สกิล lv 5 Healling Tree จะฟื้นฟู hp 50 เป็นเวลา 60 วินาที รวมฟื้นฟู hp ทั้งหมด 600 ( ถึงจะใช้ sp มากถึง 50 แต่ก็คุ้มค่ากว่าแน่นอนค่ะ )
