พอดีว่าน้องเขาเลิก จะไปให้เพื่อนแต่ด้วยความเสียดาย+อยากเล่น
ผมเลยไปกอดเข่าขอร้องเขามา แต่ประสบปัญหาหนักคือ

"ผมเล่น eco ไม่เป็น "

งงระบบแบบสุดยอดมาก

เลยอยากสอบถามเรื่องที่จำเป็นจากเพื่อนๆก่อนครับ

ตอนนี้เบลดเพิ่งจะเวล 90 จ็อบน่าจะ 39 ไม่ก็ 40
stat ไปเน้น str เต็ม dex 20 กว่าๆ ที่เหลือลง vit หมดเลย

ผมอยากเล่นสายเก็บเวล ตีมอนพาเพลินไม่ยุ่งเกี่ยวกับ pvp แต่อย่างใด

แล้วแบบนี้ชีวิตของผมควรจะอัพอะไรแล้วทำอย่างไรเดินไปทางไหนถึงจะเจอกับแสงสว่างใน eco ครับ ช่วยให้คำตอบผมด้วยครับ


ป.ล.ผมเคยเล่นตอน close beta เข้าเมืองตอนนี้อย่างกับคนเพิ่งเข้าเมืองเลยครับ -- -- เจอแต่ของแปลกตา ชอบเกมนี้แต่ไม่ีเพื่อนเล่นเลยสักคน
