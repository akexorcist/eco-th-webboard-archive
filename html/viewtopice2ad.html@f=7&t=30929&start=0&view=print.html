สำหรับหอกลองกินุสที่นำมาให้ดูกันนี้ เป็นของเลียนแบบที่ถูกทำขึ้นมาในแคมเปญ EVA at WORK ช่วงเดือนม.ค.-ธ.ค. 2006
ซึ่งให้ศิลปินแต่ละคนแสดงความเป็น EVA ของตัวเองออกมา และหนึ่งในผลงานนั้นก็คือ หอกลองกินุสที่ตีขึ้นจากเหล็กทั้งแท่งของคุณคาโอรุ
วาตานาเบ้ดังที่เห็น หอกชิ้นดังกล่าวมีความยาว 2.2 เมตร กว้าง 20 ซม. น้ำหนักก็ 28 กิโลกรัม โดยเมื่อช่วงปลายเดือนที่ผ่านมา

เพื่อต้อนรับการฉายของอีวาภาคหนังโรงนั้นทาง GAINAX จึงได้มีการจัดประมูลหอกชิ้นดังกล่าวขึ้นมาผ่านทาง Yahoo Auction ที่เป็นสปอนเซอร์
ซึ่งในตอนนี้มีผู้เข้าร่วมประมูลถึง 1450 คน และราคาตอนนี้ก็ไปแตะอยู่ที่ 13,703,000 เยนแล้ว ซึ่งการประมูลกำลังจะปิดลงในวันพรุ่งนี้แล้วด้วย
