ในเบื้องต้นหากผู้เล่นต้องการเล่นเกม ECO ณ ตอนนี้ ก็มีวิธีแก้ไขแบบชั่วคราวให้เข้าเกมได้นะคะ โดยจะต้องทำตามขั้นตอนดังนี้ค่ะ

1. download แพทช์ชั่วคราวที่ www.onenet.co.th/download/upsv.rar หรือ www.onenet.co.th/download/upsv.zip







2. เมื่อโหลดได้แล้วให้คลิกขวา Extract file ดังกล่าวก่อนนะคะ















4. Extract file นั้นมาไว้ใน Folder **โดยแปะทับไฟล์เดิมไปเลย





5. เข้าเกมอีกครั้ง ก็จะเล่นได้ค่ะ

หลังจากนั้น หากทางทีมงานแก้ไขระบบจนสามารถใช้ได้เป็นปกติแล้ว ก็จะสามารถเล่นต่อได้เลย ไม่ต้องลบไฟล์ทิ้งนะคะ


ทั้งนี้ ต้องขออภัยอีกครั้งในความไม่สะดวกที่เกิดขึ้นด้วยค่ะ และขอขอบพระคุณผู้เล่นทุกท่านที่ให้ความสนใจและติดตามสนับสนุนเกม ECO มาโดยตลอด

คุณ duomay ชมกันแบบนี้ พลอย ก็ เขิน สิค่ะ อิอิ ^.^

แต่ พลอย ต้อง ขอบคุณค่ะ ที่ ชม พลอย อิอิ คืนนี้ คง นอน ฝันดี มีคน ชม ^^

คุณ เคโระฑูต คำถาม ที่ คุณ ถาม มาอะค่ะ พลอย จะตอบ เท่าที่พลอย เข้าใจ นะค่ะ อิอิ

เควส ที่ ทำ เป็น เควส ปาร์ตี้ ดังนั้น ถ้าจะพา เด็ก ไปดูด ควร อยู่ในตี้เดียวกัน

ถ้า เด็ก เวล 28 แล้ว คุณ เวล 65 เด็ก จะไม่สามารถ สิง ได้ แต่ วิ่งตามได้

ถ้า เด็ก วิ่ง ตาม ก็ ระวัง ตายนะค่ะ พลอย ว่า ทางที่ดี ควร เก็บเวลให้เด็ก จน 35 ก่อน

จะดีกว่า ค่ะ เพราะ พอเด็ก เวล 35 จะสิง คนที่มี เลเวล 65 ได้ค่ะ

พลอย ตอบได้แค่นี้อะค่ะ แต่ ถ้า มี วิธีที่ดีกว่านี้ เดียว พลอย จะเอามาบอกใหม่นะค่ะ

.......................

ช่วง นี้ ว่างมากๆ อิอิ ไม่รู้ทำไร เลยจัด ประกวด สาว งาม สะเลย งิ

เมื่อมี สาวงาม ย่อม ต้อง มี ชาย หนุ่ม ที่ คอย ให้กำลัง ใจ ^^

ลองดูกัน นะค่ะ ใคร สวย ที่ สุด อิอิ
