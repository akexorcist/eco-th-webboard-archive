“ตอนนี้ทุกคนคงกำลังทำงานกันอยู่น่ะครับ ส่วนใหญ่จะทำไร่นากันหรือไม่ก็อยู่ในบ้าน”เจ้าตัวพูดพลางเดินไปเปิดประตูบ้านด้วยขาที่เจ็บแปล็บๆ
“ฝากด้วยนะคะ”เสียงของแอร์พร้อมกับ ทุกคนเดินเข้าไปในบ้านของอาเมล แล้ววางอาเมลลงพร้อมกับข้าวของต่างๆ
“ทุกคนพักที่นี่นะฉันมีห้องเพียงพอสำหรับทุกคนพอดี”เจ้าของบ้านยิ้มต้อนรับ

“อ่า งั้นรบกวนด้วยนะคะ”ภูติตัวจิ๋วยิ้มพลางบินวนไปรอบๆ เอลก็กำลังหิ้วข้าวของสัมภาระต่างของทุกคนมาวางไว้มุมห้องโถง

“เอ๊ะ! จริงสิพวกเธอ ไปที่ลานกว้างเลยนะตอนนี้เรชี่คงรออยู่ ลานกว้างอยู่แถวๆทิศเหนือของบ้านฉันน่ะมองไปก็เจอเองล่ะ” เด็กหนุ่มผมขาวพูดจบแล้วพลางกระโดดขึ้นบนโซฟา

“แต่ว่า”หญิงสาวผมแดงกังวลใจ

“ไม่ต้องเป็นห่วงฉันหรอกน่า”อาเมลพูดขึ้น
ไม่นานนักก็มีคนแก่คนหนึ่งเปิดประตูเข้ามา พร้อมกับใส่ชุดสีขาว
“เอ่อ~ คนเจ็บอยุ่ไหนครับ”
“ผมเองแหละ”แววตาของเด็กหนุ่มมองมาที่ประตูพลางยกมือขึ้นอย่างไม่รอช้า
“อ่า! มาแล้วหรอคะ”
นัยน์ตาสีฟ้าผมแดงจ้องไปที่คนที่เดินเข้ามา
“ใช่แล้วพวกเธอรีบไปเถอะ ตอนนี้”หมอคนที่มากล่าวออกมาพลางเดินเข้าไปหาอาเมล
“ทุกคนไปที่ลานกว้างเลยนะ”
ก่อนที่จะหันมาพูดอีกครั้ง
เอล แอร์และมาค่ารู้สึกสงสัยขึ้นมา เอ๋! จะมีอะไรกันนะ แล้วทั้งสามคนกับทามาเอะก็ออกมาจากบ้านอาเมลแล้วลองมองไปตามที่อาเมลบอก แล้วเจอลานกว้าง แต่! ทำไมคนถึงมารวมตัวกันเยอะอย่างนี้

ทุกคนมองไปเห็นชาวบ้านจำนวนมากมารวมตัวกันที่ลานกว้าง
“เอ๋! มีอะไรกันแน่นะ”เด็กสาวผมสีชมพูอ่อนครุ่นคิดขึ้นมาอย่างสงสัย
“งั้นเราลองไปดูเถอะคะ”ภูติตัวจิ๋วใกล้ๆเอ่ยขึ้นมา
“อือ” เอลตอบรับ

แล้วทุกคนก็เดินมุ่งหน้าไปที่ลานกว้าง เมื่อเดินข้ามสะพานไม้จนไปถึงทางแยกพลางเดินดูบรรยากาศรอบๆ
เงียบๆแหะ ทุกคนไปรวมกันทำไมนะ
ได้เจอกับเด็กหญิงผมสีแดงคนเมื่อกี้มาพร้อมกับชายวัยชราคนหนึ่งข้างๆ
“อ่าว มากันแล้วหรอคะ งั้นจะขอแนะนำท่านผู้นี้เค้าคือหัวหน้าหมู่บ้าน ชื่อ โทเมย์ น่ะ”ไม่รอช้าเด็กหญิงกล่าวแนะนำคนที่ยืนอยู่ข้างๆ

“พวกเธอเป็นนักเดินทางที่พึ่งเข้ามาอาศัยอยู่หรอ” ชายชราคนนั้นกล่าวออกมา

“เออ ใช่ครับพวกเรามาพักที่หมู่บ้านนี้น่ะครับ”เด็กหนุ่มผมม่วงตอบรับ
“คือ หมู่บ้านของพวกเรามีกฏอยู่ พวกเรามีพิธีกรรมทุกครั้งที่มีคนนอกเข้ามาในหมู่บ้านของเรา”ชายสุงอายุกล่าวพร้อมกับเดินเข้ามาหาพวกเขา

“เอ๋! พิธีอะไรหรอคะ”เด็กสาวนัยน์ตาสีฟ้าเบิกพล่านขึ้นถามขึ้นมา
“ทุกคนเดินตามฉันเข้าไปในลานนะ เมื่อไปถึงฉันจะแนะนำให้เอง”โทเมย์กล่าว แล้วเดินนำเข้าไป โดยมีเรชี่เดินตามไปด้วย

“งั้นพวกเราลองไปกันเถอะคะ”หญิงสาวผมแดงพูดขึ้นเชิญชวนทุกคน

“อืม จะมีอะไรกันนะ”
เด็กหนุ่มสงสัยเอามือแตะที่คางคิดขึ้นมาพร้อมแล้วเดินตามโทเมย์ไป
