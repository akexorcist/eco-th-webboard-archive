ชุด 45 สายอาเชอร์

1. มีเงินเกิน 100,001
2. ให้ไปคุยกับคุณยายหน้าเลือด แม่ของ arus ที่ iron town upstair
ตำแหน่งของร้าน : หลังจากเข้าเมืองให้เดินลงมานิดนึง (ถ้าเล่นเซิฟโมจิ)
ร้านของยายแกจะอยู่ด้านหลังฝูงโกเลมที่ขายอาหารยืนเรียงกันเยอะๆ นั่นล่ะครับ

3. เข้าไปคุยกับยายแล้วแกจะเพ้อถึงลูกชายที่ชื่อ arus
4. กลับมาหา arus ที่อัพทาวน์อโครเนีย คุยแล้วกลับไปหายายแกอีกที แกจะเปิดร้านให้ครับ
