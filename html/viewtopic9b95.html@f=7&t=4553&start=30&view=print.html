เจ๊ไป๋ยังมีนู๋ด้วยนะ T T

ถ้านู๋พอจะช่วยอะไรก็บอกนะคะ มีอะไรไม่สบายใจ เครียดๆ ก้อมาคุยกันได้

เห็นเจ๊ไป๋อยู่คนเดียวบ่อยๆเหมือนกาน.. เฮ้อ เส้านะคะ อยู่คนเดียว

เก็บเลเวลคนเดียวมันทรมานนะคะ... ranger ไม่ใช่เล่นง่ายๆ เพราะเราก็เล่นมาแล้ว

แต่ตอนนี้เปลี่ยนมาเล่น vates แล้ว (อ้าว แย่ไปใหญ่นะนี่ = =)


วันก่อนที่จะได้รูปริงค์ ก็นัดไปเจอกันไม่ใช่หรอ??
แล้วเจ๊ไป๋ก้อไป ไม่ใช่หรอ???
แล้วทำไมไม่ถ่ายรูปวันนั้นมาลงมั่งอะ = =''


= = เอาเถอะ ค่าของคนเราไม่ได้อยู่ที่เลเวล หรือเวลาในการออนไลน์นะคะ
อย่าคิดว่าคนไม่เก่ง ต้องยอมทนทุกอย่าง


คนเล่นเกมส์ไม่เก่ง ก็มีหัวใจ มีความรุสึกนึกคิดเหมือนพวกคุณ

เราก็เป็นคนเหมือนพวกคุณ คิดบ้างมั้ย ว่าถ้าคุณโดนแบบเราจะเป็นยังไง...

รึว่าคุณไม่คิดจะสนใจพวกเรา เพราะเราเป็นแค่ต้นหญ้าริมทาง

คุณสนแค่ .. จะต้องก้าวเดินต่อไปจนถึงจุดสูงสุดสินะ

ปล. ที่พูดมา กล่าวรวมๆ = = ไม่ได้ระบุถึงไคบางคน
