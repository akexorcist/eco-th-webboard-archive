สเกาท์ (Scout) ครับ ไม่ใช่ สก๊อต (Scot) :wink:

ส่วนใหญ่ สกิลของสเกาท์ จะเป็นสกิลมีดน่ะครับ

เพราะงั้นสกิลที่จำเป็นสำหรับกรงเล็บเลยไม่ค่อยจะมี

โดยส่วนตัวแล้ว(ผมเล่นสายมีดควบกรงเล็บ 80/32 ) สกิลที่ผมอัพ ก็มี

Increase Max Hp << เลือดเยอะ = โอกาสที่จะโดนสอยร่วงเหลือน้อย
Increase Max Sp << อาจจะไปอัพ Increase Sp Recovery ก็ได้ แล้วแต่ชอบ แต่ผมชอบเห็นหลอดเยอะๆมากกว่า
Short Sword Mastery << สายมีด
Avoid Bust << นานๆกดที = =
Walk Around << อัพทำแมวอะไรก็ไม่รุ = = (อาจจะมีประโยชน์ใน PVP/NVN แต่ผมว่าไร้ค่าตอนเก็บเวล)
Increase Short Sword Hit << สายมีด
Banish Blow << เป็นสกิลโจมตีที่กิน SP น้อยดี
Summersault Kick << เวลาโดนรุมก็เตะมอนออกไป แล้วสอยทีละตัว
Short Delay Cancel << สายมีด
Critical << เอาไปกดเล่น คริสะใจดี
Continue Thrust << สกิลหากินผม = =

ผมอัพไปงี้นะครับ ดีรึเปล่าไม่รู้ รู้แต่ว่า เวลได้ละกัน :?


ส่วนตอนนี้ผมเป็นแอส 32 คอม 34

สกิลแอสก็มี

Claw Mastery << จำเป็นมากสำหรับสายกรงเล็บ
Claw Strike3 << จำเป็นมากสำหรับสายกรงเล็บ เพราะทำให้ตีได้ถึง 3 HIT
Cloaking << เอาไว้ยามฉุกเฉิน หนีมอนได้ง่ายดี (จำเป็นสำหรับสกิลแอสจ๊อบ 50 ด้วย)
Utusemi << มีประโยชน์บางครั้ง แต่เก็บเวลไม่เวิร์คเท่าไหร่ = =

ส่วนสกิลคอม ที่เอามาให้แอส

Martial Art Mastery << มีผลต่อสกิลล่าง
Upper Cut << แรงพอสมควร มีไอสกิลบนด้วย ATK 312% มั้ง ถ้าจำไม่ผิด
Cyclone << สวิตมาเพื่อสิ่งนี้ สกิลหมู่ของสนับโดยเฉพาะ

ป.ล. ถ้ารีใหม่ได้อีกรอบ ผมจะเอา Walk Around ออก ไปอัพ Brandish แทน = =

แล้วก็เอา Utusemi ออก ไปอัพ Assault แทน

ป.ล.2 สำหรับการจะเอาสกิลสเกาท์ให้ได้ตามที่ผมพิมพ์มา ต้องไปตระเวนเอาสกิลฟรีให้เกือบครบเลยนะครับ

ผมขาดไป 2 พอยต์ คือเควสเปิดชุด SU และ BP เวล 55 :wink:

สุดท้ายนี้ ขอให้สนุกะการเป็นแอสแซสซินครับ :wink: :idea:
