จะย้ายกลับต้อง
1. เอาตัวอื่นไปเปิดคลังที่ปลายทาง แล้วขนใส่ตัว เอากลับเมืองหลวง
2. เอาพ่อค้าไปอยู่ที่คลังปลายทาง แล้วส่งผ่านระบบ (เสียเงิน) ส่งกลับเมืองหลวง

ก็มี 2 แบบเท่านั้นแหละ ผมว่าวิธีที่ 2 ง่ายสุด

ปล. เคยคิดว่าจะสร้าง ID ไว้ ID นึงเป็นพ่อค้าล้วน ประจำตามเมืองต่างๆ คอยส่งของไปมาจะได้สะดวกงับ

ทางที่ดี
1. หาหลักแหล่งของเราให้แน่ชัดว่าจะเอาที่ไหนเป็นหลัก
2. จัดการสร้างพ่อค้ามาเลย 2 ตัว

5. โอนบ่อยๆมันเสียตังบ่อยนะ งิงิ
