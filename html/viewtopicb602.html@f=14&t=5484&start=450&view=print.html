สายไฟเตอร์ ใช้ sp ล้วนๆ ฮับ mp ไม่ต้องก็ดะ

แต่ int มันเพิ่ม sp ทีละติ๊ดๆ ไม่ค่อยคุ้มอะฮับ คนเลยนิยมอัพเพื่อเอาความแม่นเฉยๆ แล้วไปเพิ่มค่าอื่นๆ เช่น Str ดีกว่า

int เยอะ Str น้อย มี sp เยอะ แต่ก็ใช้สกิลเยอะกว่ามอนจะตาย

int พอประมาณ Str Max ได้ sp พอใช้ สกิลครั้งเดียวจบ คุ้มกว่าเยอะ
