โดย ECO
skill นักธนู ~~

Throw Create << จำเป็น ประหยัดธนูเหอๆ

Bow Mastery << ไม่อัพได้ไง เดี๋ยวก็ยิงไม่นิ่ง

Marksman Aura << อัพไว้เวลายิงวืด

Charge Arrow << เอาไว้กันตายกะ NVN แล้วจะรู้ว่าเบลดวิ่งไล่สับคุณมะได้ถ้า 1-1 และใช้สกิลเป็นนะ

Long-range Strategy << สกิลติดตัวทำให้ยิงแม่น ไม่อัพได้ไง

Bow Delay Cancel << อัพไว้เวลาใช้สกิลรัวหรือยากยิงเร็วเหอๆ

Dual Arrow << สกิลโจมตีพื้นฐาน สองดอกโจ๊ะๆ วืด

Strike Arrow << จิงๆ ไม่ได้ใช้งานหรอก แต่ถ้าอยากเล่นสไตร์ ไม่ใช่กันเนอร์ต้องอัพ เพื่อเพิ่มความแรงของสกิล Blast Arrow สกิลหากินของนักธนูเหอๆ

ถ้าสกิลเหลือก็ไปอัพพวกสกิล เพิ่ม max sp หรือ hp หรือ hp , sp recovery ก็ได้นะ

ต่อด้วยสไตร์เกอร์

Shot Stance << ถ้าไม่อัพก็ไม่ควรมาเล่นสายนี้แล้วแหละ ช่วยให้ยิงใกลๆ ดาเมดไม่ลด

Multi Arrow << สกิลหากินในช่วงแรก ดีเลย์เยอะหน่อยแต่ก็ใช้เก็บเวลได้ดี ยิง 5 ดอก แต่ก็มีวืดนะ

Hunting Art Strategy << ถ้าเล่นสายสัตว์เลี้ยงก็ควรอัพ เพราะถ้าสั่งสัตว์เลี้ยงเราไปตี เฉย แล้วเรายิงตามเราจะยิงแรงขึ้น

สกิล Go และสกิลสายสัตว์ทั้งหลาย ถ้าอยากใช้นกก็อัพสกิลนก ถ้าอยากใช้หมาป่าก็อัพสกิลของหมาป่า

Soul of Archer << อัพเก็บไว้เผื่อสิงคนอื่น อิอิ สิงคนอื่นก็ใช้สกิลยิงออกมาได้นะ

Arrow Damage << จะอัพหรือไม่อัพก็ได้ คอมโบกะสกิลเพิ่มสถานะผิดปกติของ เอนเช้น หรือ ใช้คู่กับสกิล vital shot ของ กันเนอร์ก็ได้

Blast Arrow << สกิลหากินเต็มรูปแบบ ไม่อัพมะได้ แต่ต้องอัพ Strike Arrow จากจ๊อบแรกให้เต็มด้วยนะ ถึงจะแรงได้ใจ ยิงโจรฟูสองทีตาย ถ้าบัพครบๆ ทีเดียวตายเลย

Combine Force << แค่ตั้งตี้ก็โจมตีแรงขึ้น 5% อย่าคิดว่า 5 % มันน้อยนะ เยอะอยู่ลองดูแล้วจะรู้เหอๆ

Arm Break << จะอัพไม่อัพแล้วแต่ แต่จากที่ใช้จริงติดไม่ค่อยดี และไม่นานถ้าเป็นสาย vit หรือมี int แล้วก็ พวกนักเวทย์โดนไปมันก็ร่ายเวทย์ได้ =="

Groove Arrow << สกิลคลื่นเต่า อัพไว้เท่เฉยๆ ว่าข้าเล่นถึงจ๊อบ 50 เหอๆ ใช้ยากมาก แต่ถ้าโดนเต็มๆ ก็แรงน่าดูเหมือนกัน เทสกับพระ vit ร้อย โดนทีเดียวนอน ถ้าโดนตั้งแต่ช่องแรกนะ มันกระเด็นไปประมาณ 11 ช่อง ยิงแล้วหายไปเลย

ปล. เจ้าของกระทู้กรุณาอย่าโพสกระทู้ซ้ำนะ เหอๆ ใจเย็นๆ เดี๋ยวก็มีคนมาตอบให้

ปล2. จากประสบการณ์การเล่นนักธนูมาสองปี ถึงปัจจุบันจะ ไปเป็นมือปืนแล้วก็เหอะ แต่ก็เล่น สไตร์จนจ๊อบ 50 พึ่งจะเป็นมือปืนเมื่อเดือนที่แล้วเองเหอๆ ชัว ฟันธง !!!

คูณสองตูจะจ๊อบ 50 กันเนอร์ให้ได้ อีก 5 จ๊อบสุดท้ายวุ้ย ~~
