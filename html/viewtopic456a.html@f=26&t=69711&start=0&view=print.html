คือแมพนนั้นจะมีมอนสเตอร์ และมีเควสให้ทำ แยกเป็น 2 ประเภท 1.รวบรวม

2.โจมตี(party)

ซึ่งรวบรวมก็ได้จากมอสเตอร์ที่เราทำเควสโจมตีนั้นแหละครับ

ซึ่งจะมีอยู่ 3 อย่าง คือ

1.Zombie powder

2. Bat Wing

3. Posion Spider Web

ก็จะต้องรวบรวมให้ได้แต่ละอัน 10 ครับ

สมมุติเราเก็บ Posion Spider Web ได้ครบ 10 ก็จะทำเควสรวบรวมได้ 1เควส และได้ใบเพื่อ
นำไปแลกเขาไงครับ
