เหตุเกิดขึ้นเมื่อ 1 เดือนก่อน เจ้าของหนอนตัวเมียที่ถูกกระทำลามกอนาจารอย่างไม่ได้รับอนุญาติได้ขอยื่นเอกสารต่อนักข่าวว่า หนอนตัวเมียของเธอถูกกระทำการที่ลามกอนาจาร และได้นำหลักฐานมาให้ดูด้วย

ตอนแรกเธอเล่าว่า เจ้าหมาตัวนี้ได้เดินตามหนอนของเธอมาหลายชั่วโมงแล้วดังภาพ



จากนั้น ก็ออกลายเต็มที



เธอจึงเกิดอาการระงับอารมณ์ไม่ได้ จึงคว้าค้อนหนามในกระเป๋าออกมาและเงื้อจนคอของผู้ต้องหาเกือบหลุด ผู้ต้องหาหนีไปได้สำเร็จ เพราะเธอยังห่วงหนอนของเธออยู่

ทางนักข่าวได้ทราบชื่อมาว่า ผู้ต้องหารายนี้มีนามว่า Shiro ลูกน้องของ Taro เจ้าถิ่นผู้โหดเหี้ยม จึงขอร้องให้จับตัวผู้กระทำผิดลงโทษด้วย
