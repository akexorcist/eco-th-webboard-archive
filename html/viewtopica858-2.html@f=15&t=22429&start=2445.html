ยกเป็น case เลยละกัน

A = คนใช้สกิล
B = คนที่เป็นเป้าหมาย

A มี int 90 + 2x
B มี int 21+2x

ค่าที่ได้ ของ A = 21 + 8x

อ่ะ เอาอีก case......

A มี int 90 + 2x
B มี int 9+1x

ค่าที่ได้ ของ A = 9 + 9x

จะเห็นได้ว่ามันคำนวนจาก base int ของปลายทางหาก ปลายทางมีเยอะเป็นทุนเดิมอยู่แล้ว ค่าที่จะเพิ่มให้ จะไม่มากอย่างที่คิด

(ที่เป็น x ตามหลังอยู่ในช่วงทดสอบ จึงยังไม่ขอเปิดเผย)
