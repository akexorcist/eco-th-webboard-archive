กาลอวสานบทที่ XV : `Noche de la Fe` ( Faith Night )



“(หลับไปแล้ว ... อย่างนั้นรึ?)” แซคหรือว่าราชันย์แห่งความจริงคิดในใจพลางมองเจ้าชายของตนด้วยแววตาอ่อนโยนอย่างน่าประหลาด เขาใช้พลังของซิลเวียที่ได้รับมอบมาทำให้บาดแผลของเวลน์มีอาการดีขึ้นอย่างรวดเร็วจนปลอดภัยแล้ว แต่ดูท่าทางเจ้าชายของเขากำลังอยากจะพักผ่อนหลังจากผ่านเรื่องวุ่น ๆ มามากมาย “(ข้าจะปกป้องท่านเอง ... เจ้าชายของข้า)” รอยยิ้มบางปรากฏบนใบหน้าสุขุมนั้น



แต่ฉับพลันนั้นเองที่ภาพมายาของกิ่งก้านไม้อันเต็มไปด้วยพิษร้ายและหนามอันแหลมคม รวมทั้งสัตว์ร้ายอันมิเคยปรากฏบนโลกนี้ก็ปรากฏขึ้นรอบกายของแซคและเวลน์ และนั่นทำให้แซคต้องหยุดชะงักลงก่อนจะหรี่ตามองภาพตรงหน้าด้วยท่าทีครุ่นคิด สำหรับราชันย์แห่งความจริงอย่างเขานั้น การจะแยกให้ออกระหว่างความจริงและภาพมายานั้น ช่างเป็นเรื่องที่ง่ายดายยิ่งนัก ...



ภาพมายาก็คือภาพมายาวันยังค่ำ แถมภาพมายาเช่นนี้น่าจะเกิดจากค่ายกลที่มีการเตรียมตัวไว้ล่วงหน้า ...
แต่ใครกัน? ใครกันที่สามารถคาดเดาเส้นทางที่เขาจะใช้ได้อย่างรวดเร็วเช่นนี้ ...
จริงด้วย ยังมีอยู่อีกคนที่สามารถกระทำการเช่นนี้ได้ ...



กิ่งก้านไม้อันเต็มไปด้วยพิษร้ายแตกแขนงออกอย่างไร้ที่สิ้นสุดจนแทบจะปกคลุมท้องฟ้า สัตว์ร้ายอันมีรูปลักษณ์แสนจะอัปลักษณ์ยืนแยกเขี้ยวขู่คำรามและตั้งท่าพร้อมจะเข้าขย้ำทั้งสองอยู่ทุกเมื่อไป แสงอาทิตย์มอดดับลงพร้อมกับความมืดที่เริ่มปรากฎรอบกาย “ต้องการอะไรกันแน่?” แซคเอ่ยด้วยน้ำเสียงและใบหน้าที่เรียบเฉย สีหน้าของเขานั้นแสดงถึงความไม่พอใจอย่างเห็นได้ชัด



ไร้เสียงตอบอันใด ...
สัตว์ร้ายตนหนึ่งพุ่งเข้าใส่แซคจากด้านหลัง เขายืนนิ่งด้วยความคิดที่ว่ามันเป็นแค่ภาพลวงตา ...
แต่ทันใดนั้นสัญชาตญาณของเขาก็บอกให้เขารีบหลบการโจมตีนั้น!



ฉัวะ!!
เสื้อคลุมของแซคถูกกรงเล็บอันแหลมคมของสัตว์ร้ายนั้นกระชากจนขาดวิ่น หากเขายังคงยืนนิ่งอยู่คงจะเจ็บหนักไม่น้อยเลยทีเดียว ดวงตาของราชันย์หรี่ลงด้วยท่าทีครุ่นคิดอีกครั้ง ภาพลวงตาอันรุนแรง ... รุนแรงเสียจนสามารถปรากฎขึ้นมาได้ราวกับของจริง สามารถสร้างความเจ็บปวดและส่งผลต่อประสาทสัมผัสทั้งห้าของอริร้าย



“จะบอกว่าน่าชื่นชมหรืออย่างไรดีล่ะ?” แซคเปรยพร้อมกับรอยยิ้มที่มุมปาก “ออกมาได้แล้ว เลิกเล่นกลเสียที”



กระนั้นก็ยังไร้คำตอบจากอีกฝ่าย ...
วูบ! เหล่าสัตว์ร้ายแสนอัปลักษณ์พร้อมด้วยเขี้ยวและเล็บ อีกทั้งยังกิ่งก้านไม้อันเพียบพร้อมด้วยพิษร้ายต่างพุ่งเข้าใส่ร่างของแซคอย่างรวดเร็ว เขี้ยวถูกฝังลงสู่ร่างของชายหนุ่ม! เล็บแหลมกระชากแผ่นหลังของเขาจนโลหิตสาดกระเซ็น! มวลไม้เข้าตรึงร่างของเขาพร้อมกับใช้หนามของมันทิ่มแทงทั่วร่าง ก่อนจะสูบโลหิตออกจากร่างของเขาจนเหลือแต่ซากอันแห้งกรัง



เปรียะ ...
เสียงม่านกระจกแตกออก พร้อมกับร่างของแซคและเวลน์ในอ้อมแขนที่ยังคงปกติดี ทั้งสองยืนอยู่เบื้องหลังของบุรุษอีกคนหนึ่งที่อยู่ห่างออกไปไม่ไกลจากจุดที่พวกเขาถูกโจมตีมากนัก แซคยกมือขึ้นก่อนที่ไพ่สองสามใบจะลอยอยู่หลังศีรษะของอีกฝ่าย ราวกับพร้อมจะปลิดชีพได้ทุกเมื่อที่เขาสั่ง ...



“จะพอได้หรือยัง? เกียร์ล็อต ...” เสียงเรียบเฉยถูกเอื้อนเอ่ย กระนั้นกลับปรากฎเพียงรอยยิ้มที่มุมปากอย่างไร้ท่าทีเกรงกลัวจากฝ่ายตรงข้าม ...










กลับมายังอโครเนีย ...
ยามค่ำคืนอันเป็นที่เกรงกลัวของผู้คนได้เริ่มต้นขึ้น เทพธิดาสีเหลืองนวลทอประกายอยู่บนฟากฟ้า หมู่เมฆเคลื่อนคล้อยอย่างแผ่วเบาตามกระแสวาโย มิต่างอะไรจากจิตใจของอีกหนึ่งบุรุษซึ่งกำลังนั่งจ้องเทพธิดาอยู่บนซากปรักหักพัง การที่ออกมานั่งอยู่ในเมืองอโครเนียยามวิกาลเช่นนี้ คงจะถูกคนส่วนมากคิดว่าบ้าหรือไม่ก็เสียสติจิตวิปลาสไปเสียแล้ว ทุกคนรู้ดีว่าเวลาแห่งค่ำคืนนั้นคือเวลาของใคร? หรือว่าอะไร?
มันคือเวลาแห่งการล่า ..



แต่กระนั้นด้วยความสามารถของชายหนุ่ม ไม่สิ ... ความตายยากของเขาทำให้หลายคนไม่คัดค้านการที่เขาจะออกมาเดินเล่นยามวิกาล อีกทั้งในเมื่อเขาทำมันอยู่ทุกค่ำคืนเป็นกิจวัตรไปแล้วด้วย ชายหนุ่มเจ้าของนามฟอลนั่งจ้องเทพธิดาสีเหลืองนวลบนฟากฟ้าด้วยแววตาเหม่อลอย เขารู้สึกว่าชีวิตของเขานั้นช่างไร้จุดหมาย ไม่สิ ...
ชีวิตของเขามันไร้ความหมายต่างหาก ...



สหายร่วมรบสิ้นชีวาอยู่ทุกวี่วัน ความหวังที่เคยมีแต่แรกนั้นกลับริบหรี่ลงเรื่อย ๆ จนแทบจะไม่มีอยู่แล้ว ตัวเขายามนี้รู้สึกเหมือนกับว่าตนเองนั้นกำลังเดินถือตะเกียงอันเล็ก ๆ เดินอยู่ในความมืดมิดเพียงลำพัง ด้วยเปลวเพลิงแค่นี้จะมีผลอะไรกับความมืดมิดที่กลืนกินสรรพสิ่งไปหมดกันล่ะ? ความหวังในตอนนี้คงจะเป็นการได้พบกับเธอคนนั้นอีกสักครั้งหนึ่ง แต่ก็ช่างยากนัก มันจะเป็นไปได้ไงล่ะ จริงไหม?



กึด ...
ชายหนุ่มกำมือแน่นจนโลหิตไหลรินออกมาจากกำปั้น เขาเม้มริมฝีปากแน่นด้วยความรู้สึกที่อัดแน่นอยู่ในใจหากแต่มิอาจจะหาที่ระบายออกมาได้ เขาต้องรับภาระอีกทั้งหน้าที่ความรับผิดชอบอีกมากมายในการที่ผม้เอกราชของอโครเนีย ช่างยากนัก ยากเหลือเกิน “โธ่เว้ย!” ฟอลสบถเสียงดังก่อนจะกระแทกหมัดของตนลงไปบนซากปรักหักพังที่ตนเองนั่งอยู่ และ โครม!



แผ่นหินที่เขานั่งอยู่เริ่มร้าวและแตกออกอย่างรวดเร็ว จนร่างของเขาร่วงลงสู่พื้นดิน ...
“อูย ...” ฟอลที่เริ่มตั้งสติได้ยกมือขึ้นจับหลังศีรษะที่กระแทกพื้นอย่างแรงเมื่อครู่ พร้อมกับลูบไปมา “เจ็บเป็นบ้า” ชายหนุ่มบ่นกับตนเอง บัดนั้นเองที่เมื่อเขามองตรงไปข้างหน้า ดวงเนตรคู่นั้นก็ต้องเบิกกว้างด้วยความตกใจ



หญิงสาวเจ้าของเรือนผมสีเงินอันทอประกายเมื่อต้องกับแสงจันทร์ ดวงเนตรสีโลหิตที่บัดนี้ดูงามราวกับทับทิมสูงค่า ริมฝีปากบางสีกุหลาบน่าถนอม เครื่องแต่งกายอันมีเพียงชุดนอนยาวสีดำสนิทตัดกับผิวขาวสว่างราวกับหิมะราตรี หากแต่ดูงดงามและสูงค่าอย่างน่าประหลาดใจ เธอมองฟอลด้วยสีหน้าเรียบเฉยราวกับว่าเขาเป็นเพียงแค่ซากปรักหักพังที่มิควรค่าแก่การสนใจ ดวงเนตรเหยียดมองอย่างเย็นชาจนฟอลรู้สึกหนาวจนจับขั้วหัวใจ



ซิลเวียหันหลังพร้อมกับทำท่าจะเดินจากไป แต่กระนั้นเธอกลับหยุดชะงักลงเมื่อฟอลร้องเรียกเธอเสียงดังลั่น ...
น่าแปลกที่หญิงสาวผู้ทรงอำนาจกลับยอมหันกลับมาเพียงเพราะเสียงเรียกนั้น ฟอลไม่รู้ตัวเลยว่าเขาเผลอยกมือทำท่าจะคว้าหญิงสาวเอาไว้ตอนไหน สมองของเขานั้นคิดเพียงแต่ว่า ถ้าเขาไม่เรียกเธอในตอนนี้ เขาจะต้องเสียใจไปตลอดชีวิตอย่างแน่นอน แต่กระนั้นเขากลับไม่รู้ว่าจะพูดอะไรต่อ ความเงียบงันอันน่าอึดอัดเข้าปกคลุมทั้งสองเป็นเวลานาน เหงื่อเม็ดเล็กเริ่มผุดขึ้นตามใบหน้าของชายหนุ่มผู้หาญกล้าแต่ไร้ความคิด



“เจ้าเรียกเราทำไมกัน? มนุษย์ ...” ซิลเวียเป็นฝ่ายเริ่มเปิดฉากการสนทนา เธอค่อย ๆ เดินย่างกรายอย่างสูงส่งและสง่างามเข้ามาหาชายหนุ่มที่ยืนนิ่ง ดวงเนตรสีแดงทับทิมนั้นมองลึกเข้าไปในดวงตาของฟอลราวกับจะอ่านความคิดของเขาทั้งหมด “เจ้าเรียกเรา แต่กลับเป็นฝ่ายเงียบจนเราต้องเป็นฝ่ายเริ่มเปิดการสนทนา” ซิลเวียเอ่ยเสียงเบา



ฟอลนั้นมิได้ตั้งใจจะเงียบแต่อย่างใด แต่เพราะว่าซิลเวียเดินเข้ามาหาเขาซะจนใกล้ขนาดนี้! เธอคนนั้น เธอคนนั้นที่เขาปรารถนาจะพบเธอมาโดยตลอด อยากจะพูดคุยด้วย มาอยู่ใกล้เขาเพียงแค่เอื้อม! แถมกลิ่น ... หอมสุด ๆ เลย ... โอย ... ตั้งสติหน่อยสิโว้ย! ทันใดนั้นเองที่ฟอลก็ทำสิ่งที่ต้องทำให้ซิลเวียประหลาดใจ เขาหันหลังก่อนจะวิ่งเข้าไปหาเสาหิน พร้อมกับใช้ศีรษะกระแทกเข้าไปอย่างรุนแรงหลายต่อหลายครั้ง หญิงสาวผู้สูงส่งขมวดคิ้วด้วยความแปลกใจ แต่กลับบังเกิดรอยยิ้มที่มุมปากของเธอ เล็กน้อย ... เพียงแค่เล็กน้อยเท่านั้น ...



ฟอลนั้นเมื่อคิดว่าตนเองนิ่งและพอตั้งสติได้แล้ว เขาก็หันกลับมา แต่ก็ต้องสะดุ้งโหยงอีกครั้งเมื่อซิลเวียเดินเข้ามาประชิดร่างของเขาตั้งแต่เมื่อไรก็มิอาจจะทราบได้ ทำเอาชายหนุ่มแทบจะหันกลับไปเอาหัวชนเสาอีกรอบนึง “คะ ... คือ ... อรุณสวัสดิ์ครับ!” ฟอลเอ่ยทักทายอย่างรวดเร็วพร้อมกับยื่นมือให้ซิลเวีย ใบหน้าของชายหนุ่มขึ้นสีเลือดแดงก่ำอย่างแรงเมื่อรู้สึกตัวว่าใช้คำทักทายผิดที่และผิดเวลาเป็นอย่างที่สุด! แถมยังมีหน้ายื่นมือไปให้เธออีกต่างหาก!



หมับ ...
ซิลเวียยิ้มบางก่อนจะยื่นมือไปจับมือของฟอลอย่างแผ่วเบา ...
ความรู้สึกบางอย่างถูกส่งเข้าสู่ร่างของฟอลอย่างมิทันตั้งตัว ความรู้สึกนั้นช่าง ... เย็นเฉียบ น่ากลัว และชั่วร้าย ...



ฟอลเผลอดึงมือกลับอย่างรวดเร็วพร้อมกับแววตาที่เบิกกว้างเพราะความตกใจจากความรู้สึกนั้น ใบหน้าของซิลเวียยังคงฉาบไว้ด้วยรอยยิ้มอยู่ หากแต่เขารู้ว่ารอยยิ้มของเธอนั้นมิได้เกิดจากความสุขหรือความพอใจอะไรทั้งสิ้น มันคือรอยยิ้มที่เกิดจากความรู้สึกบางอย่าง ... ความรู้สึกที่ตัวเขาเองก็มิสามารถจะอธิบายออกมาเป็นคำพูดได้



“คะ ... คือ ... ผม ...” ฟอลพยายามที่จะขอโทษเธอในสิ่งที่เขากระทำไปเมื่อครู่ เขารู้ตัวว่าตนเองนั้นได้กระทำการเสียมารยาทกับเธอไปเสียแล้ว



“ไม่เป็นไรหรอก มันเป็นเรื่องปกติ ...” ซิลเวียเอ่ยตอบด้วยน้ำเสียงเนิบ ๆ ราวกับว่าไม่ใส่ใจในกริยามารยาทของฟอลเมื่อครู่เท่าไรนัก “ถ้าไม่มีอะไรแล้ว เราขอตัวก่อนละกัน” หญิงสาวเอ่ยต่อด้วยน้ำเสียงที่เย็นชาขึ้นอย่างเห็นได้ชัด ก่อนจะหันหลังกลับและทำท่าจะเดินจากไป แต่เธอก็ต้องชะงักอีกครั้งเมื่อฟอลคว้ามือของเธอเอาไว้แน่น หญิงสาวหันกลับมามองใบหน้าของฟอลที่บัดนี้กำลังพยายามยิ้มแย้มอย่างเต็มที่ ถึงแม้ว่าจะโดนความรู้สึกอันชั่วร้ายทั้งหลายวิ่งเข้าสู่ร่างดุจดังคลื่นทะเลที่โหมกระหน่ำซัดเข้าใส่ชายฝั่งอย่างรุนแรงและไม่มีท่าทีว่าจะหยุด ตามปกติแล้วไม่น่าจะมีใครทนได้ขนาดนี้ ...



“ผะ ... ผม ... ผมชื่อฟอล”
ฟอลพยายามเอ่ยแนะนำตัวอย่างยากลำบาก ขณะที่ความรู้สึกอันน่ากลัวและชั่วร้ายมากขึ้นไปอีกกำลังถาโถมเข้าใส่ร่างของเขาอย่างบ้าคลั่ง แต่กระนั้นใบหน้าของเขากลับยิ้มแย้มอย่างมีความสุข “คุณ ... ชะ ... ชื่ออะไรครับ?” ชายหนุ่มเริ่มรู้สึกว่าภาพตรงหน้าของเขากำลังเริ่มถูกความมืดมิดครอบคลุมแสดงถึงสติที่ใกล้จะหลุดลอยเต็มทน ไม่นะ ... อย่าเพิ่งหมดสติสิ! ฉันยังไม่อยากจะให้ภาพตรงหน้าสูญไปหรอกนะ!



จากความรู้สึกอันเลวร้ายเริ่มกลายเป็นความเจ็บปวด เขารู้สึกเหมือนกับว่าร่างของตนนั้นถูกคมมีดนับร้อยกรีดทั่วร่างอย่างไม่มีวันสิ้นสุด สติของเขาใกล้จะดับเต็มทนแล้ว ซิลเวียนั้นก็ยืนนิ่งมิได้ตอบอะไร สีหน้าเรียบเฉยของเธอนั้นไม่อาจจะบ่งบอกได้เลยว่าตัวเธอเองนั้นกำลังคิดอะไรอยู่ ร่างของฟอลทรุดลงคุกเข่าลงกับพื้น กระนั้นมือของเขาก็ยังคงกำมือของซิลเวียเอาไว้แน่นไม่ยอมปล่อย



“ซิลเวีย ...” หญิงสาวเอ่ยเสียงเบาพลางย่อตัวลง เธอใช้มืออีกข้างสัมผัสเข้าที่แก้มของชายหนุ่มก่อนจะเอ่ย ...
“เราคือซิลเวีย ซิลเวอร์วิง ...”



“ยะ ... ยินดี ... ที่ ... ดะ ... ได้ รู้ ...” ฟอลมิอาจจะทนต่อไปได้อีกต่อไป แต่กระนั้นภาพสุดท้ายที่เขาได้เห็นก่อนจะหมดสติ คือภาพของเทพธิดาในฝันของตนที่กำลังส่งยิ้มให้เขา มือของฟอลที่กำมือของซิลเวียอยู่นั้นก็ยังคงกำอยู่เช่นนั้นแม้ว่าตัวของฟอลเองจะหมดสติไปแล้วก็ตามที ซิลเวียมองร่างของชายหนุ่มตรงหน้าด้วยแววตาที่ยากจะเข้าใจ เธอย่อตัวลงก่อนจะนั่งคุกเข่าและดึงศีรษะของฟอลขึ้นมาหนุนที่ตักของเธอ ความรู้สึกที่เคยห่างหายไปนานกลับมาอีกครั้ง ...



“... นึกว่าจะมีแต่นายแล้วนะ ... ที่ทนได้ขนาดนี้ ...” หญิงสาวผู้งดงามเปรยเสียงเบาพลางเงยหน้ามองเทพธิดาสีนวล
“... จะไว้ชีวิตละกัน ... วันนี้ ...” ซิลเวียเอ่ยด้วยน้ำเสียงเรียบเฉยพร้อมกับก้มลงใบหน้าของฟอลที่หมดสติ ...



แม้แต่ซิลเวียเองก็มิอาจจะทราบว่าเวลาผ่านไปเท่าไรเมื่อเธอลุกขึ้นยืนและปล่อยให้ร่างของฟอลนอนอยู่เช่นนั้น ...



และตอนนั้นเองที่เธอกำลังจะจากไป อีกบุรุษจากร่างเดิมกลับปรากฏตัวต่อหน้าเธอด้วยแววตาเคียดแค้นและอาฆาต
อีกหนึ่งวิญญาณ ... ปีศาจแห่งการทำลาย ... โคว ...



โดยมิได้สนใจสิ่งใด ... โควบุรุษผู้บ้าคลั่งขานเรียกศาสตราวุธในมือขึ้นพร้อมกับประกาศกร้าวเอาชีวิตนังปีศาจที่เขาปรารถนาอยากจะทำลาย! มิใช่เพราะเคียดแค้นและอาฆาตในเหตุผลใด แต่เป็นเพียงความเคียดแค้นและอาฆาตที่ถูกอุปโลกน์ขึ้น เพื่อให้การต่อสู้นี้มีคุณค่าและน่าจดจำเท่านั้นเอง! ความปรารถนาที่จะเหนือขึ้นไปอีก แม้นั่นจะหมายถึงการเหยียบย่ำซากศพจำนวนมากขึ้นไปเมื่อให้ตนเองไปได้ไกลมากขึ้น แต่นั่นแหละคือสิ่งที่เขาต้องการ!



แม้เรื่องราวในค่ำคืนนี้จะน่าจดจำเพียงใด จักรพรรดินีแห่งความมืดก็มิอาจจะยอมให้สุนัขตัวไหนกล้าหันคมเขี้ยวเข้าใส่เธออย่างแน่แท้! แววตาสีแดงทับทิมวาวโรจน์อย่างน่ากลัว หอกสีเงินสลับดำปรากฏขึ้นในมือของเธอ พลังของซิลเวียถูกปลดปล่อยออกมาอย่างแรงกล้าและรุนแรงจนแผ่นดินและท้องฟ้าสะเทือน รุนแรงจนกระทั่งอีกฝ่ายมิอาจจะขยับได้ ในตอนนั้นที่โควเผชิญหน้ากับซิลเวีย เขาไม่ได้รู้สึกถึงความน่ากลัวของเธอเพราะว่าหญิงสาวมิได้ใช้พลังอันใดแม้แต่น้อย แต่บัดนี้ โควรู้แล้วว่าตัวเขาเองที่กำลังจะกลายเป็นซากศพให้หญิงสาวเหยียบย่ำขึ้นไปเสียแทน เขาจะต้องตายโดยมิได้ทำความปรารถนาของตนให้เป็นจริง



เพราะตัวเขาตอนนี้เปรียบได้ดั่งสุนัขที่กล้าหันคมเขี้ยวเข้าใส่พญามังกรที่กำลังเกรี้ยวกราด ...
ความรู้สึกต่อมาที่โควสัมผัสได้คือความเย็นเยือกของโลหะที่ถูกเสียบทะลุร่าง เยือกเย็นในตอนแรก แต่กลับร้อนผ่าวและแสนจะทรมานในวินาทีต่อมา ร่างของโควกระเด็นลอยไปและถูกปักกับซากปรักหักพังโดยหอกของซิลเวีย



เหมือนจะตาย ... หากแต่ทรมานยิ่งกว่าความตายหลายร้อยเท่านัก ...
นี่คือโทษ ... ของการกล้าหันศาสตราวุธเข้าใส่จักรพรรดินีแห่งความมืดมิด ...



คำสาปกัดกินร่างอันเกิดจากบาดแผลซึ่งเกิดจากคมศาสตราวุธแห่งความมืดนั้นเริ่มแสดงผล ความทรมานอันมิอาจจะจินตนาการได้ทำให้โควถึงกับละทิ้งศักดิ์ศรีและร้องออกมาด้วยความเจ็บปวด ขณะที่นางพญาแห่งโลกมืดนั้นยืนมองด้วยดวงเนตรอันแสนเย็นชาและสมเพชในตัวบุรุษตรงหน้านัก เธอเดินเข้าไปหาร่างของโควที่กำลังกรีดร้องด้วยความเจ็บปวด แต่กระนั้นก็ยังไม่วายสบถด่าสาปแช่งตัวเธอไม่หยุด น่าทุเรศ แต่ก็น่าสนใจ ... เจ้าสองคนนี้อาศัยอยู่ในร่างเดียวกัน หากแต่มีความน่าสนใจที่แตกต่างกันอยู่



จักรพรรดินีสะบัดมืออย่างแผ่วเบา หอกนั้นก็หายไปหากแต่ร่างของโควยังคงถูกตรึงเอาไว้กับซากปรักหักพังอยู่ ซิลเวียยกมือขึ้นเหนือบาดแผลของโควที่ถูกหอกเสียบทะลุร่าง “แกจะทำอะไรนังปีศาจ! ปล่อยข้า! ข้าจะฆ่าแก ต่อให้เหลือแต่หัว เขี้ยวของข้าจะไล่ขย้ำคอแกไปจนวันตาย! ปล่อยข้า!!” โควร้องตะโกนสบถด่าซิลเวียโดยไม่มีท่าทีว่าจะหยุด เวทสายความมืดถูกร่ายออกมาอย่างแผ่วเบา ขณะที่แผลของโควนั้นเริ่มสมาน ชายผู้บ้าคลั่งถึงกับแปลกในในการกระทำของอีกฝ่าย แผลของเขาหายสนิท ... ได้อย่างไร? ในเมื่อเวทที่ถูกปล่อยออกมาเมื่อครู่นั้นคือเวทสายความมืด แต่ทำไมถึงทำในสิ่งที่ต้องเป็นเวทสายแสงอันเป็นปฎิปักษ์เท่านั้นถึงจะทำได้เช่นนี้



“แกช่วยข้าทำไม!” โควร้องตะโกนใส่ซิลเวียที่กำลังหันหลังเดินจากไป ถึงแม้ว่าแรงจะยังไม่กลับมา แต่เขาก็ไม่ต้องการเช่นนี้ เหมือนกับว่าศักดิ์ศรีของเขาจะถูกทำลายไปอย่างไม่มีวันกลับ เขาถูกเล่นงานอย่างเละเทะและง่ายดาย แต่อีกฝ่ายนั้นกลับมาช่วยชีวิตเขา ทั้งที่การคร่าชีวิตของเขานั้นเป็นสิ่งที่เธอสามารถกระทำได้โดยง่ายแท้ ๆ ...



ซิลเวียหยุดเดิน ก่อนจะหันกลับมามองโคว ...
“ เพราะเราพูดไว้แล้ว ว่าจะไม่ฆ่าเจ้าในวันนี้ ...” ซิลเวียเอ่ยพร้อมกับรอยยิ้มบาง “และกษัตริย์ไม่มีวันตระบัตสัตย์ ...”
ประโยคสุดท้ายถูกทิ้งเอาไว้ก่อนที่ร่างของเธอจะหายไปกับความมืดมิด ...



ชิ ...
เสียงสบถเบา ๆ จากชายผู้เกลียดชังความพ่ายแพ้ยิ่งกว่าสิ่งใด “... ข้าพอจะเข้าใจแล้วล่ะ เจ้าโง่ฟอล ...”
“ว่าทำไมเจ้าถึง ...”










โรงงานผลิตอาวุธและยานรบที่ใหญ่ที่สุดในโลกแห่งอโครเนีย THE LAST ECLIPSE ...
ดวงเนตรสีฟ้าสว่างดูงดงามแตกต่างจากคนธรรมดาอย่าสิ้นเชิงจับจ้องไปยังสิ่งที่อยู่ตรงหน้าของตนด้วยสายตาครุ่นคิด สิ่งที่จะทำให้พวกเขามีชัยเหนือทุกสิ่ง แต่กระนั้นอาจจะต้องแลกมาด้วยความสูญเสียเป็นอันมาก เขามองสิ่งนั้นผ่านบานกระจกบานใหญ่จากห้องทำงานของเขาเอง ชายหนุ่มยกมือขึ้นเสยเรือนผมสีทองยาวสลวยไปด้านหลังอย่างแผ่วเบาด้วยท่าทีครุ่นคิด มืออีกข้างนั้นถือรูปถ่ายใบหนึ่งเอาไว้ราวกับว่ามันเป็นส่วนหนึ่งของร่างกายไปเสียแล้ว ช่างน่าเศร้านัก ทั้งที่รู้ว่าการมองรูปถ่ายนี้ทำให้เขารู้สึกเศร้าเหลือคณา แต่เขากลับห้ามใจตนเองไม่ได้ ...



ทั้งที่เขามียศถาบรรดาศักดิ์สูงส่งเหนือทุกชีวิตบนแผ่นดินอโครเนีย ยศและศักดิ์ศรีแห่งกษัตริย์! ...
กษัตริย์แห่งอโครเนีย วิลาเนเซีย เซราเดียส มัลฟอร์ด ...



ช่างน่าแปลกที่กระแสแห่งเวลานั้นเหมือนจะไม่มีผลกับร่างกายของพระองค์ พระพักตร์ช่างดูอ่อนวัยอย่างไม่น่าเชื่อ พระพลานามัยทรงแข็งแรงราวกับคนหนุ่ม ไม่สิ ... ต้องบอกว่าเหนือกว่าคนหนุ่มทั่วไปเสียด้วยซ้ำ แต่เพราะเหตุใดกันพระองค์ถึงกลายมาเป็นเจ้าของโรงงานผลิตอาวุธเช่นนี้ได้ แล้วราชบัลลังก์ที่อโครเนียเล่า? แล้วกษัตริย์พระองค์นั้นที่ปกครองอโครเนียเรื่อยมาเล่า? กษัตริย์แห่งอโครเนียถอนพระทัยเฮือกใหญ่ ก่อนจะทรงนั่งลงยังเก้าอี้ประจำตำแหน่งของตน ทรงครุ่นคิดถึงหลายสิ่งที่เกิดขึ้นในช่วงเวลาที่ผ่านมา “ซิลเวีย ...” พระองค์เอ่ยนามหญิงสาวแห่งความมืดอย่างแผ่วเบา พร้อมกับพระเนตรที่จับจ้องไปยังรูปถ่ายที่ทรงถืออยู่



“ใครกัน?” ฉับพลันพระองค์ก็ตรัสถามขึ้นอย่างไม่มีปี่มีขลุ่ย ทรงเก็บรูปถ่ายนั้นไว้ในเสื้อคลุมของตนและดีดนิ้วเพื่อเป็นการปิดหน้าต่างและบานเกล็ดทั้งหมดในห้อง ราวกับพระองค์ทรงรู้ว่าผู้มาเยือนนั้นเป็นใคร “ว่ามา ...” ดำรัสสั่งเสียงเบาหลังจากที่แน่ใจว่าการสนทนาภายในห้องนี้จะไม่รั่วไหลออกไป



เสียงมากมายดังอื้ออึงอยู่ในห้องของพระองค์ราวกับต่างพากันแย่งกันพูด ...
“เข้าใจแล้ว” พระองค์ตรัสขึ้นในที่สุดราวกับเป็นการตัดบทหลังจากทรงรับฟังเสียงเหล่านั้น ...
“เราจะเดินทางไปอโครเนีย ... แต่เพียงลำพัง ...” เสียงอื้ออึงจำนวนมากดังขึ้นอีกครั้งราวกับว่าเสียงเหล่านั้นพยายามที่จะห้ามปรามพระองค์มิให้ทรงกระทำการเช่นนั้น



“หุบปากเสีย และทำหน้าที่ของพวกเจ้าไป ...” ดำรัสอันแน่วแน่และเด็ดขาด “ทำการตามพาพยัคฆ์สายฟ้า ค้นหาผู้รอดชีวิต และนำพวกเขากลับมาอย่างปลอดภัยเสีย ...”
พระองค์ทรงปิดพระเนตรลงอยู่ครู่หนึ่ง ก่อนจะดำรัสอีกครั้งด้วยพระเนตรที่แสดงถึงความมุ่งมั่น ...



“จากนี้ไปจงละเว้นการใช้ราชาศัพท์กับเราเถิด สหายทั้งหลาย” พระวาจาอันแสดงถึงความจริงจังนั้นสร้างความแปลกใจให้กับเจ้าของเสียงอื้ออึงเหล่านั้น “... และจงกระทำการตามแผนการของข้าพเจ้าต่อไป ...”



“ส่วนเรื่องของอโครเนีย ... แฟนธอมจะจัดการทุกอย่างเอง ...”
