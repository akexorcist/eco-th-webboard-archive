แปล(งม)ต่อเอง

背負い魔・ネコマタ（茜）入手 †

ネコマタ姉弟の末妹、茜ちゃんです。
巷ではツンデレ、ツンデレいわれていますが、公式にはそんな記述は一言もありません。過度の期待をしないようにしましょう。
以下、イベントの手順です。
憑依されている、あるいは憑依アイテムを持っているとイベントの開始、進行ができません（イベント用インスタンスに入れません）。
イベントが進行しないときは憑依されていないか確認してください。
背負い魔・ネコマタ（茜）（1アカウント1個）
Lv30＆名声・クエスト成功20回？以上
内容 備考
背負い魔・ネコマタを装備した状態で、
トンカ中央やや上にあるリタのマリオネット工房に入る。 宿主の状態だとイベントは始まりません。
装備するネコマタはどれでも構いませんが、
持っているネコマタは全て連れて行きましょう。
「リタ」か「リタのハレルヤ」に声をかける。
ハヤルヤの案内を依頼される。
トンカ北西部の作業台の上にいる「マスターウィル」と話す。
ファーイースト街道の「飛空庭職人」と話す。
リタの工房に戻り、ハレルヤと話す。 ネコマタを装備していないと話が進みません。
ハレルヤの飛空庭への移動は待ってもらえます。
飛空庭に行かずに、ネコマタを替えて何度も話してみるのもいいでしょう。
ハレルヤの飛空庭へと移動し、ハレルヤと話す。
ギルド評議長の娘を紹介するように頼まれる。 評議長の娘＝マーシャです。
ダウンタウンの「下町の上品なおばさん」と話す。
アップタウン南可動橋の南軍の館長官室にいる「マーシャ」と話す。 この時、誰かが憑依してるとマーシャはいません。
マーシャの飛空庭への移動は待ってもらえます。
この後のために準備を整えてきましょう。
マーシャの飛空庭へ入れてもらう。
マーシャ達と話をする。 エミルも忘れずに。
飛空庭で光の塔まで連れて行ってもらう。 光の塔に入った後にログアウトしたり、セーブポイントに戻っても
自力で光の塔に戻ればイベントは問題なく続けられます。
メインフロア4Fの北西側外周で「機械のかたまり（イベント）」を壊して
「コンピューターROM（イベント）」を手に入れる。 オニックスとインキュバスのいるマップです。
ここはインスタンス生成されている特別マップです。
リタの工房に行き、ハレルヤにコンピューターROMを渡す。 ハレルヤの飛空庭への移動は待ってもらえます。
ネコマタは持っていますか？
ハレルヤの飛空庭でリタ達と話す。
リタの工房でリタと話すと「背負い魔・ネコマタ（茜）」が手に入る。 装備しているネコマタの一言があります。
誰を装備しますか？
