Credit kiKie
kiKie เขียน:เอาล่ะห้องเงียบๆ
กีกี้จะมาสาธยาย status ของธนูที่เคยเล่นมาให้อ่านกันเล่นๆ
เนื่องจากว่าตอนนี้ กีกี้ รี status เป็นอีกสายนึงแล้วอ่ะนะ

แต่ status ที่จะเล่าให้ฟังเป็น status ก่อนที่จะเปลี่ยนนะ (status ใหม่บอกไม่ได้ ไว้รีเมื่อไหร่จะมาเล่าให้ฟังเนื่องจากอาจมีผลใน NVN)

อาชีพ : Striker
LV/JOBLV : 99/50 (GunnerJOB 42)
เผ่า : Emil
สายที่เล่น : str > agi~int >> vit

Status เขียน:str ~ 99+16 (+2 ใส่หมวกปาร์ตี้สีแดงค่ะ) = 117
int ~ 61+24 (+5 ใส่กุหลาบคาบ) = 90
agi ~ 81+16 (+2 ใส่รองเท้าบูธสั้นสีขาว) = 99
vit ~ 34+9 = 43


จะเห็นว่าที่สามารถลง status ได้มากขนาดนี้ เพราะเครื่องประดับและสายอาชีพเป็นหลัก
เนื่องจากโบนัสจ๊อบ (ที่บวกด้านหลัง) มีค่ามาก ถ้าอัพสายโดยลง status เหล่านั้นจะช่วยประหยัดพ้อยได้มากนั่นเอง

รูปแบบที่เล่น :
- เป็นสายที่ค่อนข้างคลาสสิค สำหรับธนูค่ะ ...ใช้ NVN และเก็บ LV เป็นหลัก
- จะเห็นว่าเน้น str คือ...โหดไว้ก่อน ยิงไกลได้ก็ต้องเก็บมันก่อนมันมาเก็บเรา
- มี agi กับ int เพื่่อให้ยิงได้เร็ว แระแม่นพอ ถ้าไม่แม่นล่ะก็...พลาดทีก็จบกัน ฮ่าๆๆ

ข้อเสีย :
- ต่อให้มี str เยอะ แต่เจอพวกสาย vit ถึกๆ อึดๆ ก็แทบจะทำอะไรไม่ได้เลย
เพราะพวกที่เล่นสายถึกส่วนใหญ่ก็ลง vit กันทั้งนั้น
ซึ่ง Striker ไม่มี skill โจมตีอะไรที่รุนแรง ขนาดเจาะทะลุ def ได้
(vit ช่วยเพิ่ม def มากกว่า m.def ....เพราะฉะนั้น พวกเวทย์แรงๆ
ก็ยังยิงสาย vit ได้..... แต่ ธนู ไม่สามารถค่ะ)
- vit ยังคงน้อยอยู่ เคยเจอเบลดมาแรนค่ะ... miss เกือบหมด โดนแค่สองดอกเอง ...ก็ตายอยู่ดี

ข้อดี :
- สายนี้เล่นได้ทั้ง NVN และเก็บ LV ได้เร็ว เพราะมี str เยอะ (เค้ามีธนู90+pow10 ด้วย ก็เลยยิ่งแรงอ่ะนะ)
- การที่มี int เยอะ ทำให้หลบพวกปืนได้ดี เพราะปืนมักลง agi str ...เน้น agi กันมากอ่ะ เพื่อกลบจุดอ่อนของปืนคือ ร่ายนาน และดีเลย์เยอะ
- มี agi เยอะด้วย ทำให้สามารถหลบพวกเบลดและแอสซาซินที่ไม่ใช่สาย dex ได้ดีมาก


other comment :
- ตอนนี้เปลี่ยนสายแล้วค่ะ ไม่ได้เล่นแบบนี้แล้ว...แต่จะเป็นไงนั้น มิบอก ฮ่าๆๆๆ
- ถ้าสังเกต status ดีๆ จะเห็นว่าอัพให้ลง bonus ทั้งหมดค่ะ str agi int แล้วที่เหลือค่อยลง vit
- ใช้ bonus job (ค่าบวกตัวหลัง) กับ ค่าพื้นฐานของเผ่า (vit 10) ...ให้เป็นประโยชน์สูงสุด ทำให้ประหยัดพ้อย...และใช้พ้อยได้คุ้มค่า
- สาเหตุที่เปลี่ยนสายเพราะ
1.เริ่มเห็นธนูเล่นเหมือนแบบนี้เยอะแระ เราต้องก้าวนำไปอีกก้าว ฮ่าๆๆๆ
2.ลง NVN แล้วตายง่ายมากค่ะ เด๋วนี้พวกสาย vit กับพวกเล่นสิงเยอะมาก...ยิงใครแทบไม่ได้เลย
3.อยากลองเล่นแบบใหม่ๆ *-*

ปล. ก็มาเล่าสู่กันฟังอ่ะนะ เห็นห้องมันเงียบๆ ก็เลยมาบอกให้ดูไว้เป็นวิทยาทาน *-*

Credit evo
evo เขียน:เอามาให้ดูบ้าง เพื่อเป็นแนวทางในการอัพ แต่ละค่าของสเตตัส เพื่อให้เหมาะกับการเล่นของเรา (ไม่ได้ให้เลียนแบบ ไม่ได้บอกว่าสเตตัสนี้เทพ แค่เอามาให้ดูกัน) เน้นยิงคน ไม่ได้เน้นยิงมอน

อาชีพ: Gunner(rifle)
เลเวล: 99/50
เผ่า: Dominion

โค้ด: เลือกทั้งหมด
สเตตัสตอนนี้
STR: 98+16 (ถ้าใส่หมวก+str2 จะลงโบนัส Min.ATK แต่ใส่หมวก ออร่า+str 3 จะลงโบนัส Max.ATK) ATK ~ 301-739
DEX: 6+12 (point เหลือ 1 เลยลง เพื่อเพิ่ม MIN.ATK) ~ DEF16 / M.def 40
INT: 71+24 (ใส่กุหลาบคาบ 71+29) ~ L.HIT 312 / L.AVOID 292
VIT: 21+9 (ลงโบนัสHP) ~ HP 1580 / SP 647
AGI: 78+12 (ลงโบนัสA.SPD) ~ A.SPD 688 / S.AVOID 266
MAG: 8+4


*เป็นสเตตัสตอนแข่ง rvr (95/50) แต่มาอัพเพิ่ม เลยดูไม่ค่อยลงตัวเท่าไร แต่ก็ใช้ประโยชน์ได้ดี

สเตตัสหลักคือ STR INT AGI เด่นในทาง ยิงแรง และยิงโดน ถ้าจะเก็บเลเวล ควรลด INT ไปเพิ่ม AGI เพื่อให้ ยิงให้ไว และหลบเก่ง จะดีกว่า

สเตตัสนี้กับ pvp / nvn
ข้อดี:
ยิงแรง - เมื่อใช้ Cross Crest หรือ Bullet Dance ถ้า def ไม่เยอะจริง ทีเดียวน่าจะตายหมด
ยิงแม่น - ถึงไม่บัฟ Precision Fire(บัฟยิงโดน100%) แทบไม่เคยยิงคนไหนวืดเลย นอกจาก GM
ยิงไกล - เมื่อถือไรเฟิล + บัฟ (Over Rage) จะยิงได้ไกลสุดๆ

เกือบจะดี:
หลบหลีกได้พอสมควร - ถ้าเจอพวก สายเวล มักจะหลบได้เกือบทั้งหมด ทั้งระยะใกล้ และ ไกล แต่อาจ หลบได้บ้างสำหรับพวกที่มี dex หรือ int น้อย
ร่ายสกิลไว - ร่ายเกือบไว ทำให้ยิงคนอื่นได้ก่อน

ข้อเสีย:
ตัวบาง - เลือดและพลังป้องกันต่ำ มักจะเป็นลมได้ง่าย(แปบๆ ตาย)

ข้อได้เปรียบของสเตตัสนี้
เมื่อเจอสายไฟเตอร์ - ยิงฟรี เพราะเรายิงไกล อาจใช้สกิลได้2ทีติดก่อนอีกฝ่ายจะถึงตัวยิ่งเรายิงแรงด้วย ถ้าไม่ถึกจริงคงไม่รอดเข้ามาทำอะไรเราได้
เมื่อเจอสายเวทย์ - ณ ปัจจุบัน 80%+ ที่เราจะยิงตายภายใน 1 สกิล
เมื่อเจอสายสาป - อาจจะทนสกิลสาปที่คิดค่า int ได้ เพราะ int เราสูง
เมื่อเจอปืนสายเวล หรือแอสสายปืน - จะหลบลูกปืนได้หมด

ปัญหาของสเตตัสนี้
เมื่อเจอแอสปล่อยพิษ - ทนพิษได้น้อย โดนไม่กี่ทีตาย
เมื่อเจอสายไฟเตอร์ที่s.hitเยอะ - อาจหลบได้บ้างบางhit แต่80%+ เราจะโดนละก็ตาย
เมื่อเจอสายเวทย์ - ถ้าโดนสกิลยิงที่ตัวมักจะตายภายใน 1 hit
เมื่อเจอไพ่ของGambler - ไพ่ของGambler ตอนนี้แทนโดนตลอด def และ hp ที่น้อยทำให้เรา โดนไพ่แทงไม่เกิน 3 ทีตาย (ซาก้าก่อนไพ่แทงเราไม่โดนเลย)

สเตตัสนี้กับการใช้สกิลยิง
ทุกอาชีพที่defน้อย - ใช้สกิล Plurality Bullet 1ครั้ง โอกาศยิงตาย 80%+
ทุกอาชีพที่defพอสมควร - ใช้สกิล Cross Crest หรือ Bullet Dance 1ครั้ง โอกาศยิงตาย 80%+

ข้อจำกัดของทุกสเตตัส
ทุกอาชีพที่defสูง - ปัญหาของอาชีพนี้เลย เพราะทุกสกิลโจมตีจะหักล้างกับdefศัตรู อาจจยิงสร้างดาเมจได้แค่ 1 -*- (แต่ยังดีที่gunner มีสกิล stun เพื่อหยุดฝั่งตรงข้ามได้)

*อ้างอิงประสบการณ์จากการเล่นเซิฟทาโกะ
