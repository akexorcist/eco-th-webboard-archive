โห้~ Flying Garden ของแท้ ติดเทอร์โบแล้วบินข้ามมเืองได้ด้วย (หวังว่าไม่ต้องจ่าย Cash สำหรับความสามารถนี้นะ -*-)

ตอนนี้กำลังคิดหนักเรื่องเติม Cash เพราะได้ยินว่ามีปัญหามากมายรุมเร้า ทำให้ไม่กล้าซื้อ

*ขอเข้าเรื่องหน่อยล่ะกัน*

1. เราสามารถเริ่ม Event รับ Flying Garden ฟรีได้ที่ไหน (กดไปหลายที่แล้วแต่ก็หาไม่เจอ) ขอแบบละเอียด ๆ หน่อยนะ *0*

2. อุปกรณ์ทำ Flying Garden ได้ยินมาว่าจำเป็นต้องใช้ 6 อัน แต่ก็ได้ยินมาอีกว่า NPC แจกแค่ 5 อัน ไม่ทราบว่าอีกอันคืออะไรหรือแค่ 5 อันก็เพียงพอแล้ว (อันนี้งงมาก)

3. อุปกรณ์ใน Flying garden ใช้งานได้ด้วยรึปล่าว (ได้ยินมาจากกระทู้อื่นว่าตู้สามารถเก็บของได้ <<< ถ้าเก็บได้จะไปซ้ำกับที่ Merchant Guild มั้ย) ถ้าใช้งานได้ มีอะไรที่ใช้งานได้บ้าง ให้ผลอย่างไร

4. ในการตั้ง เฟอร์นิเจอร์ เราต้องมีบ้านก่อนรึปล่าว หรือแค่มีตัว Flying Garden ก็ทำได้เลย

*หมดแค่นี้แหละจ้า ที่มาตั้งถามเพราะหาคำตอบที่มีนเคลีย์ไม่ได้อ่ะจ้า

** ขออภัยถ้าหากมีคนเคยตอบไปแล้ว -*- แบบว่าไม่เคลีย์จริง ๆ :oops:

ชิ้นส่วนที่ NPC Flying Garden Keeper ต้องการ ( ทุกชิ้นสามารถหาซื้อได้ในไอเทมมอ หรือ หาเอาในเกม )

1. = Flying Garden Base
2. = Flying Garden Lathe
3. = Steering Wheel
4. = Catalyst
5. = Flying Garden Engine
6. = Rotary sail 6 ใบ หรือ Rotary sail Set 1ชิ้น

ชิ้นส่วนทุกชิ้นหนักมาก ผู้เล่น สามารถขนไปฝาก NPC ที่ละชิ้นได้
