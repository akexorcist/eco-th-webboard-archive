ในขณะเดียวกันนั้น ได้มีหญิงสาวที่มีปีกสีขาวพร้อมด้วยเนโกมาตะสีส้มกำลังบินเที่ยวอยู่ในเมืองฟาร์อีสแบบไร้จุดหมาย (เพราะเธอไม่ได้มีจุดประสงค์ในการเก็บโจรสลัด เนื่องจากยังไม่เก่งนัก-*-) แล้วทันใดนั้น สายตาของเธอกำต้องสะดุดลงที่ป้ายชื่อคาเฟ่แห่งหนึ่ง พร้อมเหลือบเห็นป้ายรับสมัครงาน

' 'The Moon' งั้นเหรอ อืม... คนเยอะดีนี่นา น่าจะลองเข้าไปดูอะไรมากินเป็นอาหารเช้าบ้าง... อ๊ะ ป้ายรับสมัครงานนี่ hock: จะลองทำที่นี่ดูไม๊นะ' สาวเจ้าคิด พลางยื่นมือสีขาวอมชมพูไปจับกลอนประตูเพื่อเปิดประตูให้เธอเข้าไปข้างใน

ซึ่งเมื่อเธอย่างก้าวเข้าไปอยู่ในคาเฟ่แล้ว เธอก็พบกับบรรยากาศอันแสนแออัดที่เต็มไปด้วยนักผจญภัยระดับสูงมากมาย และนั่นก็ทำให้เธอรู้สึกแย่ลงทันตา เพราะคงไม่มีใครคิดแม้แต่มองหน้าเธอแน่-*- แต่ถึงกระนั้น เธอก็สาวเท้าไปยังเคาน์เตอร์โดยพยายามไม่คิดอะไรมาก

สิ่งที่เธอเห็นตรงข้ามเคาน์เตอร์ก็คือ หญิงสาวคนหนึ่งกำลังง่วนกับการจัดการภาชนะให้สะอาดเรียบร้อยเหมือนของใหม่ตลอดเวลา แต่หารู้ไม่ ว่าหญิงคนนั้นเป็นเจ้าของคาเฟ่
