คือเราอ่านๆ กระทู้ใหม่ๆ เห็นเค้าว่าล้มแค่ 10-20ครั้งก็ได้ ก็วิ่งไวเท่าล้ม30 (7-8ค่าต่อการล้ม)

ถ้าเรา ล้ม15ครั้ง(ครั้งละ7-9ค่า) มันจะวิ่งไวต่างกับล้ม30ไหม เพราะอ่านบางคนตอบเห็นว่า ล้ม10-15 ก็พอ

ถ้ามีสูตรคำนวณ ก็ขอทีจ้า พอดีเราคำนวณจากสูตรกระทู้นี้ ล้ม15ครั้ง 7-9ค่า มันวิ่งไม่เท่าคนแฮะ
http://board.onenet.co.th/viewtopic.php ... &start=540

ปล.อีกคำถาม ตอนเปลี่ยนหนอนเล็กเป็นหนอนขี่ มันจะ+ค่าstat ตอนหนอนเล็กมา แล้วถ้าเราไปฝึกหนอนขี่เพิ่ม ค่าmax status ต่อค่า มันจะเพิ่มขึ้นไหม หรือเต็มเท่าของหนอนขี่

รบกวนตอบทีเน้อ กำลังฝึกหนอนอยุ่ ขอบคุณมากจ้า
