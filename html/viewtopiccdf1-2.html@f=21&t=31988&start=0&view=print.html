คนแบ่งเป็น8ส่วน ตามนั้นล่ะ
1.หัว
2.คอถึงรักแร้ (ครึ่งหนึงของช่องที่2 จะได้หัวไหล่)
3.อกถึงข้อศอก
4.เอว-สะโพก
5.สะโพก-น่อง
6.น่อง-หัวเข่า
7-8.ดูเอาเองละกัน
คือมีคนเขาสอนมาอีกที เอามาให้ดูเผื่อมีคนที่เคยเจอปัญหาเหมือนผม(วาดออกมาไม่สมประกอบ)

*ระบายนิดๆหน่อยๆ*
แรกๆวาดแต่หน้า แต่แล้วก้มีคนมาทัก "วาดได้แค่หน้ามันก็ไม่ใช่การ์ตูนหรอก" เออ จริงของมัน ว่างั้นเลยลองหัดวาดส่วนอื่นๆดู ไปๆมาๆ โอ้~ เราทำได้แค่นี้เองหรอ แต่ก็ไม่ละความพยายาม(บ้า) หัดวาดส่วนอื่นๆไปเรื่อยๆ แรกๆก็อาศัยจาก รู ป ที่คนอื่นวาด วาดตามเขา แต่มันก็ไม่ได้ช่วยอะไรเท่าไร ยังขาดๆเกินๆ เลยลองไปเอาแบบคนจริงๆ จากเวปพวก pic post มาลองวาด ไปๆมา... โอ้ มันใช้ได้ ตอนนี้ก็เลยเอาแบบมาจาก รู ป(ไก่ เรื่อ อู = แบน -*-)คนจริงๆ มากกว่าพวก cg เกม หรือรูปที่คนอื่นวาด โดยส่วนตัวผมว่าแบบที่ได้จากพวก รู ป คนจริงๆ ลงตัวสุดนะ ใช้ได้ดีกว่าหุ่นไม้(โมเดลกันดั้ม) หรือวาดตามที่คนอื่นเขาวาดไว้
(ข้อควรระวัง เวปพวก pic post มีหลายเวปที่ห้ามเปิดเกินวันละ2ครั้ง เด็กและคนชรา โรคหัวใจไม่ควรเปิด โปรดสังเกตุคำว่า 18+ ก่อนเปิดทุกครั้ง) <-- มิเช่นนั้นความเป็นโอตากุ อาจเจือจางจนกลับเป็นคนปกติได้ แบบผม - -"

ฟาร์มแมวแห่งประเทศไทย เขียน:ชักอยากได้ tablet...
ต้อง wacom เท่านั้น เก็บตังๆ (หัวสูง)




bamboo 4x6 สำหรับผู้เริ่มต้น(เริ่มต้นตั้ง 4200 กับwacomO-o") ราคา 4200 กว่าๆ (ถูกที่สุดในโปรดักส์ใหม่) ถ้าต้องการรุ่นต่ำหว่านี้เเต่ราคารับได้ ก็ไปมองหาที่พันธ์ทิพย์ก่ะที่อื่นๆ แต่ถ้าไม่หัวสูงนัก- -" แนะนำ ACECAD (เรียกตามบอร์ดต่างๆว่า "ตราแมว") คุณภาพมาตรฐานชายไทย เเต่เคยลองซื้อมาใช้เเล้วต้องใช้ถ่าน AAAA 1.5V 1 ก้อนใส่กับปากกา (นับเป็นเรืื่องยุ่งยากอย่างหนึ่งที่ต้องคอยเปลี่ยนถ่าน) บางครั้งก็มีไฟดูดบ้าง(ไม่รู้ว่าคนอื่นเป็นไหม?) ใช้ไปเรื่อยๆก็เริ่มออกอาการงอแงบางครั้งเพราะถ่านเริ่มจะหมด ใช้ได้ดีสำหรับผู้เริ่มต้น เเต่เราไม่ใช่อย่างนั้นสุดท้ายลองของแปลกมา 3 เืิดือนก็ไปใช้WACOM สุดที่รักเหมือนเดิม

ปล. พื้นฐานกายวิภาคเป็นสิ่งสำคัญในการวาดรูป (อย่างน้อยก็ต้องรู้พื้นฐาน ยังไม่จำเป็นต้องระดับสูงอ่านะ) บางครั้งเห็นว่าทำไมการ์ตูนวาดไม่ค่อยถูกกายวิภาคบางครั้งถึงดังได้ ต้องเข้าใจว่าสัดส่วนเป็นองค์ประกอบหนึ่งเท่านั้น ส่วนมากขายได้เพราะเนื้อเรื่องมากกว่า แต่ถึงอย่างไรนักเขียนทุกคนก็ต้องเข้าใจพื้นฐานของหลักกายวิภาคมาก่อน เมื่อมาเขียนการ์ตูนเเล้วจึงใช้หลักกายวิภาคนั้นมาตัดทอนลักษณะ ดัดแปลงลักษณะของตัวการ์ตูน เพราะวาดการ์ตูนเราไม่ได้วาดท่ามันยืนตรงอย่างเดียวนี่นา- -" มีมุมสูง มุมต่ำ เดิน นั่ง กระโดด สาระพัดที่จะนึกออกก็เเล้วกัน ไม่รู้ว่าจะมีใครคิดเป็นอย่างอื่นไหม?

อีกอย่างมีรุ่นพี่คนนึงบอกว่า "เริ่มต้นอย่าไปจริงจังกับพวกโปรแกรมก่อนเลย ให้ฝึกพวกการออกแบบ องค์ประกอบพื้นฐานของศิลปะไปเยอะๆ เพราะพวกนี้เราจะดััดแปลงไปใช้ได้กับอย่างอื่นเยอะเเยะ โปรแกรมหน่ะ ไม่กี่เดือนมันก็ออก เวอร์ชั่นใหม่เเล้ว แต่ความรู้ทางศิลป์หน่ะ ติดตัวเเละเป็นหลักเกณฑ์ในการทำงานจนตายเลยล่ะ" น่าคิดนะ.... :idea:
