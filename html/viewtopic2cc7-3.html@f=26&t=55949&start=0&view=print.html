พอเวล20 ก็ไปรับชิ้นส่วนฟรี ที่เมืองใต้ npc อยู่ชั้นล่างครับ ซ้ายมาสุดตรงกลาง
รับฟรี 5 ชิ้น เปลี่ยนของรับทุกวันศุกร์ (5อาทิตย์ก็รับครบ) ใจร้อนซื้อเอามีคนรับมาขาย
แล้วต้องทำใบเรือ 6ใบ (Rltary Sail) (หรือใจร้อนก็ซื้อ Rotary Sail Setในแคช แทนก็ได้)

วิธีทำใบเรือ 1ใบใช้
ใช้ log 1ชิ้น ไปตามแมทที่มีหาดทราย จะเห็นขอนไม้ ตีมันไปเรื่อยๆตกง่ายใจเย็นๆตีไป เรื่อยๆ ใจร้อนซื้อเอา 50000-75000
waterproof fabric 5ชิ้น ทำจาก Row4ชิ้น +Greater colth1ชิ้น (Rowตี พูรูเหลืองกับผึ้ง)(greater colth ซื้อเอาดีกว่าทำไม่คุ้ม ซื้อเอา 1100-1500ซื้อโกเล็ม)
wood 5ชิ้น ซื้อเอาเลย มีnpcขาย 700 ที่กลางเมืองอัพทาวน์ คนขายเฟอร์นิเจอร์
Great Steap 5ชิ้น ทำจาก Greater thead 4 ชิ้น (ซือ้เอาที่ ร้านตัดเย็บเมืองเหนือ 1300)
ถ้าใครไม่อยากซื้อทุกอย่างก็สามารถตีหาเองได้ฟรีหมด เท่ากับไม่เสียอะไรเลยเสียเวลานิดหน่อย (ใครหาซื้ออะไรไม่ได้ ซื้อที่ คิเนะ (โมจิ)เมล์มาถามได้)
