วิธีหาชุดTatarabe 55 มีสองวิธีครับ เปิดกล่อง container 2 ในเหมืองตะวันตก มีโอกาสได้ชุด55

กับอีกวิธี คือ สะสม กลีบดอกไม้ธาตุ 6 ธาตุ สีละ สอง อัน รับเควส ทำยาให้แม่ของโปรอน(ชื่อไม่แน่ใจ) แล้วไปเอากลีบดอกไม้ไปส่งที่ร้านขายยา ที่เมืองเหนือ แล้วก็เอายาที่ได้ส่งที่ ที่รับเควสครับ ทำสองรอบ จะได้ ตั๋ว ขอบคุณ มา เอาไปส่งที่เมืองใต้ ชั้นล่าง ตรง ที่ๆมีตัวตลกเล่านิทานให้เด็กฟัง ส่งตัวกับเด็กคนนั้นครับ รอบแรกได้ metal archen thorn พอรอบสองก็ จะได้สกิลพ้อยฟรีมา กับปลดล๊อคร้านขายเสื้อผ้าBP 55ครับ

ส่วนหมวกของTatarabe นั้นทำเควสส่งเอกสารสองรอบครับ ตัวที่เราไปส่งเอกสารจะปลดล๊อคร้านขายหมวกให้เรา
