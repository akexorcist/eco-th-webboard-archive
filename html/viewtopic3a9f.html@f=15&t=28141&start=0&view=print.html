2. Soul Harp = Soul Water+Platina Bow Part+Earth Branch

Lv.5
1. Mysteail Note = Tuning Fork Tube+Melody Stone

2. Titania Rod =Plattinum Staff+Golden Ribbon+Peridot

3. Tachnic Magic Book =Ancient Book+Strap

4. Guitar = Broken Guitar+Platina Bow Part

5. Packet Lord =Tree Of Life Staff+Great Ribbon+Brisoft Bouquet+ManaWater

Brisost Bouquet = Brisoft Flower*4 +Insoluble Ice(สกิลทำเครื่องประดับ)
Brisoft Flower = Clear Flower+Red Powder+Career Oil(สกิลทำเครื่องประดับ)

6. Parasol = Scented Cloth+Golden Furniture+Tree Of Life Staff+Race

Scented Cloth = Silk+Happy Cologne+Spring Bouquet(สกิลเย็บผ้า)
Happy Cologne = Distilled Water+Ether+Career Oil+Four Leaves Clover
(สกิลทำยา)

7.Mystic Dewdrop = Light Green Archen Thorn+Plattinum Staff+Crystal
