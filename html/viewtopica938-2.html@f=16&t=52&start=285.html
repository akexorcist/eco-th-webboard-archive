monochi เขียน:รบกวนถามคุณซิ้ม หน่อยครับ
1.เล่นสายอารายอ่า vit หรือ agi
2.stat นี่อัพ str นำ หรือ vitกะagi นำ
3.หนังสือคู่มือแนะนำซื้อเล่มไหนดีบ้าง แบบว่ามันแพงอ่าแล้วงบน้อย ><
ขอบคุงงับ


ตอบ คุณ โมโนชิ นะค่ะ

1.อันนี้แล้วแต่ความชอบนะค่ะ
-สาย vit นี้หน่อย โดนเบา เลือดเยอะ
ถ้าอัพสกิล เพิ่ม max hp เต็ม ไปด้วย นี่จะทำให้ เลือดเยอะขึ้นด้วยค่ะ เพราะว่า
ค่า vit มีผลกับสกิลนี้ นอกจาก เลือดเยอะแล้ว พลังป้องกันก็สูงตามไปด้วย
ก็พอที่จะเก็บมอนได้เรื่อยๆ เลยค่ะ

-สาย เอจิ นี่จะทำให้เราตีไวขึ้น และ หลบหลีกได้ดี ( แต่อย่าไปหวังกับหลบหลีกเลย นานๆหลบได้ที -*- ) agi จะเห็นผล เมื่อตอน มี agi รวม 50+ ขึ้นไปนะค่ะ ถึงจะเริมตีไวขึ้น
ถ้าหลบได้ก็ดีไป แต่ถ้า โดนทีก็ กระอัก เหมือนกันค่ะ >< ( คุณซิ๊มเล่นสายนี้เจ้าค่ะ ฮี่ๆๆ )

2.อันนี้ แล้วแต่ความชอบเช่นกันค่ะ ต้องดูว่าเราเล่นสายอะไรก่อน อย่างเช่น
เนื่องจาก อาชีพเรา ตีเบา + ใส่โล่ไม่ได้ ทำให้ลำบากหน่อยนึงนะค๊า >_<~*
( ทั้งนี้ ต้องอัพมาสเตอร์รี่อาวุธ กับแม่นยำด้วยนะค่ะ V('-^) )

สายการเล่น ( ทั้งนี้ขึ้นอยู่กับความชอบนะค่ะ )
-Str >> Agi >> dex

-Agi >> Str >> dex

-Str >> Vit >> dex

-Vit >> Str >> dex

-Str >> Dex
โค้ด: เลือกทั้งหมด
[ >> ] = มากกว่า  โดยค่าแรกนำโด่งลิ้ว  ค่าที่สองน้อยลงมาหน่อยค่ะ
ส่วนค่าที่ 3 dex แนะนำให้อัพลงท้ายด้วย 0 เช่น 20-30-40 เป็นต้นค่ะ



3. เสียค่าโง่ช่วงโคส ดีกว่า เสียค่าโง่ตอนโอเพ่น จริงมะค่ะ ( คำพูดใครคุ้นๆ *0* )
ที่ซื้อ นี่จำชื่อไม่ได้นา แต่ว่า ให้ซื้อ ตำราไม้ เย็บปัก และก็ อาหาร มาอ่ะค่ะ เล่มละ 10เต
แหนะ >_<~*
