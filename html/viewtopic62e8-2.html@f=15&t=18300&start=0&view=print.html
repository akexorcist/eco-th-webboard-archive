คลิ๊กขวาที่ item นะค่ะ ดูในส่วนของ ข้อมูล ค่ะ
ดูที่ไอเทมซ่อมแซม นะค่ะ จะระบุ ชุด kit ที่ใช้ซ่อมอยู่ค่ะ
สามารถซื้อได้จากผู้เล่นที่มีอาชีพสายตามชุด kit ชนิดต่างๆ ค่ะ

ไอเทมที่เป็นไม้ อาชีพที่ทำชุด kit ได้คือ อาชีพ Famer
ไอเทมที่เป็นเหล็ก อาชีพที่ทำชุด kit ได้คือ อาชีพ Tatalabae
ไอเทมที่เป็นผ้า อาชีพที่ทำชุด kit ได้คือ อาชีพ Famer
ไอเทมที่เป็นหนัง อาชีพที่ทำชุด kit ได้คือ อาชีพ Ranger
