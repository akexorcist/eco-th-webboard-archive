พูดถึง Berserk กับ Berserk Control

หนูขอลองนำเสนอให้เอา Transporter ไปแทน Berserk Control นะ

โอกาสติด บาวตี้อิ้นน้อยๆ ( หนูอิ้น 50นิดๆ ) เบอเซิกคอนโทรลมัน 50/50 น่ะ

( บางทีติดตลอด บางทีไม่ติดเลยอ่ะเธอว์ =w=" )

เวลาติดเบอเซิกเรายังสามารถกดสกิลและปั้มยาได้อยู่ แต่แค่ไม่สามารถกดเดินไปจิ้มมอนได้ =3=

แนะนำให้เอาสกิล Transporter มาไว้กดพุ่งไปหาตำแหน่งที่มอนเยอะๆ

จะช่วยให้เก็บมอนสเตอร์ได้เร็วขึ้นโข ( สับไวนรก -*- )

แถม !!! ถ้าเกิดว่า สามารถใช้ Transporter พาตัวเราไปที่ๆ มีมอนเตอร์ได้ตลอด
เราก็สามารถอยู่ในสภาพเบอเซิกได้น๊านนานขึ้นด้วยจ้า

แล้วก็ ถ้าต้องการหนีก็กดสกิล Transporter นี้ยิกๆ เลย ฮา
