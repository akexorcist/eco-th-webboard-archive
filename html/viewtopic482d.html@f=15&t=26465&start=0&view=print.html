คือเห็นว่าในเว็บก็บอกไว้นะ แต่ ไปเล่นเกมมีคนบอกว่าต้องยิงอีกธาตุนึกถึงจะแรง
เลยงงๆครับว่าสรุปแล้วมอนฯมันธาตุอะไรกันแน่?
ทำให้ไม่มั่นใจตามรางมอนฯของเว็บ (สืบเนื่องมากจากแผนที่กับมอนฯไม่ค่อยตรงเลย ไม่รู้ว่าเขาเอามาจากไหน กดแผนที่นี้ดูปรากฏว่ามอนฯบางตัวในแผนที่นั้นมันไม่มี เอ๊ะ ยังไง)
ใครพอจะมีตารางมอนฯแบบชัวร์ๆ หรือว่ามีเว็บที่บอกตารางมอนฯ ก็ช่วยบอกมาหน่อยนะคับ จะขอบคุณมาก... :wink:

ปล.มีเว็บตารางอาวุธ+ไอเท็มด้วยก็ดีนะ ขอบคุณคร้าบบ.. :P
