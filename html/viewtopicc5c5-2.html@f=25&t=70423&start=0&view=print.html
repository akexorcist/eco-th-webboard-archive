กรณีจะอัพค่า Def/Mdef/S.avoid/L.avoid/HP/M Resis

สกิลที่ต้องการ(Breeder) Go!/Acrobate Vasion/Heal fire

อาชีพหลักที่เหมาะแก่ฝึกที่สุด - พระ หรืออาชีพอะไรที่ฮีลได้(หรือจะมีPet Foodเยอะๆก็ดี)

มอนสเตอร์เป้าหมาย!!! - บะหมี่เกี๊ยวหมูแดง(Wild Boar)

สถานที่เหมาะสมที่สุด - Momo Plan

วิธีการฝึก - อันดับแรกให้เราสวมใส่สัตว์เลี้ยงซะก่อน จากนั้นค่อยมุ่งหน้าไปยังสถานที่ฝึก โดยอันดับแรกเราต้องสั่งสัตว์เลี้ยงด้วยสกิลGo!ไปต่อยหมูก่อนทีนึงแล้วค่อนเรียกกลับมาด้วยCome back ต่อจากนั้นก็คอยกดสกิลAcrobate Vasionไปเป็นระยะสลับกับHeal fireไปเรื่อยๆ ที่สำคัญ อย่าลืมดูHPกับMP/SPของเราด้วยล่ะ

ข้อควรระวัง!! - การฝึกPet แบบนี้ไม่เหมาะกับPetที่มีพลังป้องกันต่ำ(เช่นเนโกะมาตะ กระรอกบิน หนอนลากบางตัว เป็นต้น)แต่ถ้าอยากจะฝึกจริงๆควรให้มีหมูชนเพียงตัวเดียวจะดีที่สุด และต้องระวังมอนรอบข้างด้วย

ข้อแนะนำ - 1.หมูแดงเป็นมอนที่จะเลือกเป้าหมายเดียวโดยที่จะไม่มีวันเปลี่ยนเป้าหมายอื่นอีกไม่ว่าเราจะตบจะต่อยกระทืบบัฟยังไงก็ตาม ดังนั้นสามารถฮีลได้สบายใจเฉิบโดยที่ไม่ต้องกลัวว่ามอนจะหันมาตบเรา
2.ยื่งลากหมูมาเยอะมากเท่าไหร่Petเราก็จะอัพstatusได้เร็วขึ้น แต่ต้องระวังด้วยว่าPetเราก็จะตายเร็วได้เช่นกัน
3.หมูแดงมักจะใช้สกิลบ่อย ถ้าใครที่อยากจะเน้นค่าMdefก็มาที่นี่ได้ ไม่ผิดหวัง เพราะขึ้นเร็วมาก
