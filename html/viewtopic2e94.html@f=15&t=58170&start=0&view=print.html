สายเวล
ถ้าเล่นบู๊ผมก็ไม่รู้นะครับไม่เคยเล่นสาย บู๊ เล่นแต่เวทย์
ถ้าสายเวทย์สเต จะคล้ายๆกัน ผมเล่นเอเลเมนท์น่าจะพอ ปรับใช้กันได้

หลัก
mag 90 - 100
dex - 75 - 85

รอง (เลือกเอานะครับ)

ยิงแรงล้างผลาญก็อัพ int ต่อ ซักประมาณ 30-50 (ถ้าพอ)
ถ้าขอแบบถึกลากได้ก็อัพ vit ต่อ ประมาณ 30-50 เช่นกัน

แต่ยังไงก็ควรจะอัพทั้ง vit int ให้พอเหมาะนะครับ (ไม่ควรปล่อยให้เป็นค่าเริ่มต้น โดยเฉพาะ ค่า vit )
ก็ลองไป + - เอานะครับ แค่คร่าวๆ ว่าน่าจะประมานนี้

สายวอ

int - 100
dex - 80
vit - 45 up

ส่วน mag จะอัพหรือไม่ก็สุดแล้วแต่จะโปรด



ส่วนสกิล
ท่าหลักเลย บลาสครับ ที่เหลือก็แล้วแต่ชอบครับ
