SEAL Of 3 Worlds
Chapter1
From past to present
> The Begining

ท่ามกลางเปลวไฟที่ร้อนระอุ พื้นที่แห่งนี้เคยเป็นเมืองที่เงียบและสงบสุขมาหลายชั่วอายุคน

แต่บัดนี้มันกลับกลายเป็นเพียงซากเมืองที่กำลังมอดไหม้ด้วยเปลวเพลิงจักรกล

“ท่านแม่! ท่านพ่อ!” เสียงเด็กชายตัวเล็กๆคนหนึ่งตะโกนอยู่ท่ามกลางเปลวไฟ

ขณะที่เขากำลังตามหาพ่อแม่ของเขาอยู่ ก็พบกับศพของชาวบ้านที่อาศัยอยู่ในหมู่บ้านเดียวกัน

แต่บัดนี้กลับเป็นเพียงร่างไร้วิญญาณ...


“เคร้ง!....” เสียงของเหล็กที่กระทบกันดังมาจากด้านหลังของเด็กน้อยคนนี้ ทันทีที่ได้ยินเสียง

เขาเริ่มสั่นกลัว และค่อยๆมองกลับไปหาที่มาของต้นเสียงอย่างช้าๆ....

สิ่งที่อยู่เบื้องหน้าของเขา คือ สิ่งไร้ชีวิตที่มีชีวิต ร่างกายของมันประกอบขึ้นจากเหล็กจักรกลพร้อมกับใบมีดแหลมคมที่แขนทั้งสองข้าง

สิ่งนั้นกำลังเดินตรงมาที่เขา “ไอ้บ้า! เอาพ่อแม่ของข้าคืนมานะ!” เด็กน้อยตะโกนจนสุดเสียงพร้อมกับหยิบก้อนหินบนพื้นปาไปยังสิ่งที่อยู่ตรงหน้าของเขา


ณ. ถนนในเมือง อโครโพลิส(Acropolis) แห่งดินแดน อโครเนีย(Acronia) หลังจากสงครามจักรกลในครั้งนั้น บัดนี้ได้ผ่านมานับหลายร้อยปี...

ศูนย์กลางแห่งกองกำลังประจำทิศทั้ง4....

บนถนนอันคับคั่ง เด็กน้อยคนหนึ่งที่เพิ่งเดินทางมาถึงเมืองหลวงเป็นครั้งแรกกำลังตะลึงกับผู้คนที่เดินทาง...และโกเล็มค้าขาย

แต่พอนึกถึงสิ่งที่ตนเองต้องทำได้จึงหยิบกระดาษแผ่นหนึ่งขึ้นมามองดู นั่นคือ แผนที่ของเมืองอโครเนีย พร้อมกับคิดในใจ

“เป้าหมายของข้าที่จะเป็น เซจ ( Sage ) ก่อนอื่นต้องผ่านการทดสอบการเป็น วิสาร์ด (Wizard)ก่อนสินะ ”

เธอยิ้มกริ่มขึ้นในใจพร้อมกับเดินเข้าสู่ตัวเมือง

ขณะที่เธอกำลังเดินทางไปยัง ส่วนบน( Uptown )ของเมืองอโครเนีย

“ว้าย! ” ด้วยความไม่ระวังเธอจึงเดินชนกับคนๆหนึ่งเข้า จนเธอและอีกฝ่ายล้มลงทั้งคู่ “อูยเจ็บจัง.......อะขอโทษค่ะ ”

เธอกล่าวขอโทษพร้อมกับยื่นมือให้กับผู้หญิงในชุดสีแดงที่เธอเดินชน “ไม่เป็นไรจ้ะ” หญิงในชุดแดงยิ้มให้พร้อมกับจับมือแล้วพยุงตัวขึ้น

“ท่าทางกำลังรีบ แต่ก็ควรระวังหน่อยก็ดีนะ” หญิงในชุดสีแดงยิ้ม และเดินจากไป เด็กหญิงจึงวิ่งไปยังสมาคมวิสาร์ด

“ท่าน TeaMoTea ครับ เด็กคนนั้น...” ชายในชุด Vates สีขาวกล่าวถามหญิงชุดแดง

“อีกไม่นานเดี๋ยวก็ได้รู้จักแล้วล่ะ” หญิงสาวในชุดแดงยิ้มแล้วจึงเดินต่อไป...

ณ.ห้องโถงสมาคม วิสาร์ด เมื่อเด็กหญิงมาถึงก็รีบยื่นใบสมัครให้กับ เจ้าหน้าที่ประจำสมาคมทันที

“Saionchi May ( ไซองจิ เมย์ ) เจ้าต้องรับการทดสอบจากทางสมาคมก่อน เจ้าจงลงไปหาชายที่ชื่อ Magic ใน เมืองชั้นล่าง ( Downtown ) แล้วกลับมาหาข้าอีกครั้ง ”

สิ้นประโยคของเจ้าหน้าที่ประจำสมาคมวิสาร์ด ร่างของเด็กหญิงก็ลอยละลิ่วออกจากห้องไปในทันที ถึงแม้ร่างของเธอจะอยู่บนอัพทาวน์แต่ใจของเธออยู่ที่ดาวทาวน์เสียแล้ว

ทันทีที่เธอมาถึงดาวทาวน์ก็วิ่งตามหา ชายที่ชื่อ magic ทันที

แต่ทว่า..

เธอลืมฟังที่อยู่จากเจ้าหน้าที่สมาคมด้วยความใจร้อน เธอจึงต้องวิ่งหาเกือบทุกที่ในเมือง แต่ทว่า ก็หาไม่พบ

เธอจึงนั่งลงบนม้านั่งฝั่งตะวันตกเฉียงเหนือของ ดาวทาวน์ “คุณ magic ค้า...อยู่ไหนของคุณคะเนี่ย...” เธอเปรยออกมาทันทีที่ก้นสำผัสม้านั่ง

“ ข้าบอกให้เอาไหม? ” เสียงสวรรค์ที่ลอยมาเตะหูครั้งนี้ ทำให้เมย์รีบหันไปหาที่มาของเสียงทันที

เจ้าของเสียงที่ว่า เป็นชายผมสีส้มใส่เกราะหนังสีน้ำตาลและ google (Wise man นั่นเอง) เธอรีบตรงเข้าไปหาทันที

“จริงเหรอคะ! อยู่ที่ไหนคะ!? อยู่ที่ไหน!?” เมย์ เค้นถาม จน Wiseman แทบจะคิดว่าเธอจะกินเลือดกินเนื้อเขาให้ได้เลยทีเดียว

“ครืน....” เสียงอะไรบางอย่าง ดังขึ้นมาจากใต้พื้นดิน ทำให้เด็กสาวที่กำลังเอะอะเสียงดังอยู่ ตกใจกับเสียงที่ไม่เคยได้ยินมาก่อนทันที

“เอ๋ นั่นเสียงอะไรน่ะ..?” เมย์ถามWiseman ด้วยความสงสัย

“เสียงนี้ข้าก็เพิ่งเคยได้ยินครั้งแรกนี่แหละ ข้ายืนอยู่ตรงนี้มาตั้งแต่ โคลสเบต้า(ฮา)แต่ไม่ยักกะเคยได้ยินเสียงแบบนี้ในที่ตรงนี้เลยนะ ” หลังจากนั้น เสียงที่ว่าก็เพิ่มจำนวนครั้งขึ้นเรื่อยๆ

“ครืนนนน.......!!!” เสียงนั้นใกล้เข้ามาเรื่อยๆ ผู้คนที่อยู่ในดาวทาวที่แสนจะจอกแจกจอแจ นั้นเริ่มรู้สึกได้ถึง แรงสั่นสะเทือนจากใต้ดิน

“แผ่นดินไหวเหรอ!?” ชาวเมืองดาวทาวน์คนหนึ่งส่งเสียงขึ้น

ทันใดนั้นเอง

ประตูมิติ( Warp Gate )ก็ถูกเปิดขึ้นท่ามกลางความงุนงงของชาวเมืองในตลาดดาวทาวน์

ชาวเมืองและผู้คนที่สัญจรไปมาในดาวทาวต่างงุนงงกับสิ่งที่เกิดขึ้นตรงหน้า

ชายคนหนึ่งค่อยๆเดินเข้าไปใกล้ๆกับประตูมิติ แต่แล้วก็ถูก[บางสิ่ง]ดึงเข้าไปในประตู

“อ๊า!!” เสียงร้องด้วยความเจ็บปวดของชายที่ถูกดึงเข้าไปผ่านออกมาจากประตูมิติ

ทันใดนั้นเองก็ปรากฏร่างของ Hologram จำนวนมากบินออกมาจาก ประตูมิติ

เหล่า Hologram ต่างพุ่งเข้าทำร้ายชาวเมืองอย่างไม่เลือกหน้า ผู้คนที่เดินจับจ่ายซื้อของ บัดนี้ กลับต้องวิ่งหนีตายอย่างจ้าละหวั่น

“พวกแกมีความกล้ารึเปล่า!! สู้มันสิ!!” เบลดมาสเตอร์คนหนึ่งตะโกนขึ้นพร้อมกับแกว่งดาบและวิ่งเข้าไปยังฝูง Hologram และทำลายเหล่า Hologram ลงได้จำนวนหนึ่ง

“กระจอกน่า! ฮ่าๆ! ” ทำให้คนอื่นๆในละแวกตั้งสติและเริ่มสู้กลับ แต่ไม่ทันสิ้นเสียงหัวเราะของเบลดมาสเตอร์ เขาก็ล้มลงบนพื้นพร้อมกับบาดแผลฉกรรย์ที่ท้อง

เหล่าสิ่งมีชีวิตจักรกลที่เส้นผมเปล่งประกายได้เดินออกมาจากประตูมิติ พร้อมกรงเล็บขนาดใหญ่ และ ปืน ทำให้เหล่าผู้กล้ากลับกลายเป็นผู้ที่ต้องหนีอีกครั้ง

“เธอรีบหนีไปก่อนเร็ว!” wiseman เอ่ยขึ้น เมื่อเมย์ตั้งสติได้กับสิ่งที่อยู่ตรงหน้า ก็รีบวิ่งหนีไปทันที แต่ทว่า ตอนนี้เธอถูกล้อมด้วยฝูง Hologram เสียแล้ว...
