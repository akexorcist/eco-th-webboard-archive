แต่แค่ไม่ค่อยมีคนรู้ว่าใช้ตัวอะไรเล่น เพราะถ้าเราไม่ใช่มันก็เสียเปรียบ

แต่ตอนนี้เลิกวอล่ะ เลยไม่ค่อยรู้สถานการณ์ แต่ถ้าจะให้ทุกคนเลิกใช้ก็คงจะเป็นไปไม่ได้
