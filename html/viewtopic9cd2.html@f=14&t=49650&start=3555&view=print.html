今回のアップでかなり大きな影響を受けたといってもいいスキル。
確実にクリティカルが出る上、スキルのクリティカル値も大きいので相当なダメージ上昇が期待できる。
軽くプルルに通常攻撃と比較してみたら、7倍近くのダメージが出た。
何よりこのスキルは詠唱は1秒でディレイ0秒（モーションディレイが少しあるが、メタモル等で解決？）と優秀。
AGI振らなくても連打できる700％のスキルと考えられるわけだ。
さらに検証の結果、相手が氷結状態でもクリティカルが発生する事が判明した。
さすがに警戒状態の相手にはクリティカルは発生しなかった。

Tekkamon เขียน:พอดีกะไว้ใช้ร่วมกะอาชีพอื่นที่มีสกิลจำพวกตีแรงขึ้นเมื่อศัตรูติดสถานะผิดปรกติ


"สกิลจำพวกตีแรงขึ้นเมื่อศัตรูติดสถานะผิดปรกติ" จะนับแค่กับพวกที่ติดสกิลดังต่อไปนี้เท่านั้นครับ

- Magic #### (Poison, Stun, Confuse, Slow, Stone, Frozen, Sleep, Silence)
- Fanaticsim
- Hinder Hand

สกิลประเภทเพิ่มลด status จะไม่ถูกนับ ดังนั้นสกิล Agitate กับ Bluff จะไม่เสริมให้ "สกิลจำพวกตีแรงขึ้นเมื่อศัตรูติดสถานะผิดปรกติ"

อ้อ Bluff กับ Agitate โอกาสติดขึ้นกับ m.resist เป้าหมายนะครับ ถ้าสูงมากก็ไม่ค่อยติด แต่ส่วนใหญ่ที่ลอง เห็นติดง่ายพอสมควร แต่ส่วนตัวไม่แนะนำให้ใช้ทั้งสองท่า เพราะ

Bluff Lv5 = S/L.Avoid เป้าหมายลดลง 50% แต่ DEFซ้ายและขวา +72%
Agitate นี่ข้อมูลไม่ค่อยมีเท่าไรว่ากี่ % แต่ผมคิดว่าผลตรงข้ามมันก็พอๆกับ Bluff น่ะแหละ

- กรณีที่เรียนมาแค่ 2 ท่า ก็จะออก 3 ครั้งเหมือนเดิม สุ่มจาก 2 ท่าที่มี

- ความแรง + โอกาสสำเร็จ ขึ้นกับท่า Slash ที่เรียนมาล้วนๆ ไม่ขึ้นกับท่า Slash Combination

- ถ้าไม่เรียนท่า slash อะไรมาเลย แต่ใช้สกิล slash combination จะกลายเป็นแค่ตีธรรมดา 0-3 ครั้ง
