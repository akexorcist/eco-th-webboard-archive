マリオネットキング召喚 †
Active
JOBLV　50
対象　地面・単体
射程　6
制限　なし
MAXLV　3
巨大マリオネットの色違いを召喚して攻撃します。
Lv 1 2 3
消費MP 40 50 60
威力(MATK比%) 約370 約670 約960
詠唱時間(s) 約3 約4 約5

該当スキルはマリオネットキング召喚　火、マリオネットキング召喚　水、マリオネットキング召喚　風、マリオネットキング召喚　土でそれぞれサラマンドラ、インスマウス、ニンフ、マンドラゴラの色違いを召喚して攻撃する
威力は使用者のM.ATKに依存(ドラゴ等騎乗ペットに騎乗してる時でも騎乗ペットのM.ATKではなく使用者のM.ATKに依存する)
詠唱時間はキング召喚のためのもので、召喚後キングの詠唱が約1s程度
キングの出現予定位置に障害物があると、召喚に失敗する
インソウル未修得でも移動可能
フォーティファイ、ゼン、AAは乗らない
逆に自身が毒状態でも威力が減らないという特性もある
アルケミストのケミカルプラント同様このスキルのみで敵を倒しても経験値は入らない
セージのスキルリフレクションで反射された場合ダメージはキングに跳ね返る
土のみ他のキング召喚とは違い、召喚されたキングの周囲5*5を攻撃。4セルのノックバックと混乱の追加効果がある
ただし他のキング召還と違い、ターゲットが使用範囲外に移動してヒットしない事がある
ネクロマンサーの死神と違い、視線チェックが無い。PVPでは召還に成功すると、壁、段差に逃げられても発動するので強力。
