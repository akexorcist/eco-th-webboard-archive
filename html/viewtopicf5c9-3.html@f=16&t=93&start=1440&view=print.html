petจะมีstatusเป็นของตัวเองดังนี้ครับซึ่งสามารถพัฒนาได้(ค่าบวกสีฟ้าๆคือค่าที่พัฒนาจากเดิม ส่วนค่าเริ่มต้นคือค่าด้านหน้า)และสามารถพัฒนาไปได้ในระดับหนึ่งจนถึงค่าmaxของมัน ส่วนการฝึกนั่นฝึกโดยการให้มันทำสิ่งนั่นๆเช่นค่าโจมตีก็ให้มันโจมตีไปเดี๋ยวพลังโจมตีจะขึ้นพลังแม่นยำคริจะขึ้นถ้าร่ายสกิลบ่อยๆความแม่นยำเวทย์ก็ขึ้นอะไรทำนองนี้
โดยปกติถ้าเราไปตีมอนเตอร์petจะไม่ช่วยสู้ แต่petจะร่ายสกิลช่วยเรา(ถ้าpetชนิดนั้นมีสกิลช่วยเหลือในตัวมันเอง)
petจะโจมตีศัตรูต่อเมื่อ 1.เมื่อpetถูกมอนเตอร์โจมตีก่อนมันจะสวนกลับ 2.ใช้คำสั่งgo ซึ่งเป็นสกิลสั่งให้มอนเตอร์โจมตีแบบปกติหากมอนเตอร์ตัวนั้นมีออโต้สกิลมันก็จะใช้ออโต้สกิลด้วยเช่นกัน(bsมีสกิลนี้ให้อัปและบางอาชีพก็มีให้อัป) 3.ใช้สกิลโจมตีของpetโดยสั่งจากผู้เล่น
ส่วนปืนใหญ่มี2ชนิดชนิดแรกไม่มีออโต้สกิลในตัวมันเอง แต่แบบที่สอง(สีดำปนน้ำเงิน)จะมีออโต้สกิลในการโจมตี3สกิล
ส่วนเรื่องมอนจะโจมตีใครนั้นขึ้นกับว่าตัวเราหรือpetเริ่มโจมตีมอนเตอร์ก่อนกันหากเราตีมอนเตอร์ก่อนมอนก็ตีเรา หรือ petตีมอนเตอร์ก่อนมอนเตอร์ก็จะตีpet
