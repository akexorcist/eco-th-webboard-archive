ปืน สไตเกอร์ถือได้ ด้วยปืน เลเซอร์ จากโลกโดมิ เวล70

ค่าพลังโจมตี 0

เอาไป+7 มา ได้ราวๆ Atk 24 นี่แหละ

เสร็จแล้วพอดีซื้อปืนไทยมาใช้แทน +3 ค่า atk 24+6 = 30

เลยเอาปืนเลเซอร์ไป +8 ดู แหก


ว่าไป ทั้งธนูไทย ทั้งปืนไทย ถือได้ทั้งสองอาชีพ (สไตเกอร์ กันเนอร์) ทางนี้เองเก็บจ็อบ
ให้สไตรเกอร์ด้วยการใช้สกิลปืน ( CC ) ไปยิง Armor จ็อบ 49 ไป 50 ไม่ถึง 1 สัปดาห์

ลืมไปอีกข้อ มีธนูฝึกหัด ถือได้ทุกอาชีพ atk 1


สรุป : ปืนเลเซอร์ เวล70 , ธนูฝึกหัด ถือได้ทั้ง2อาชีพ (อยากให้แรงไปตี + เอง )
หรือไม่ก็เอาธนูไทย หรือ ปืนไทย ไปใช้แทน ...


ปอลิ่ง: สกิล50ธนู ไม่ไหวแหะ ถึงจะแรงเรื่องธาตุ (เอาไปยิงหอแสงมา) แต่มีผลโดนหลาย
ตัวที่ไม่พึงประสงค์ ดีไม่ดีพาซวยด้วยสกิลนี้อีกตะหาก ... =w= อีกข้อ เสียเวลามักๆ ต้อง
ให้มันวิ่งเข้ามาใกล้ๆ ถึงจะโดนแบบเต็มๆ เก็บตัวรอไอริสเข้าเท่านั้น ... ... ...
