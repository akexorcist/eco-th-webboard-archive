ถ้าใช้เวลระดับสูง (มอนเวลร้อยขึ้นไป) สายผสมจะดูดีกว่านะครับ Str Vit/Agi ที่เหลือลงDex
Vit กับAgi เน้นค่าใดค่าหนึ่งสูงกว่า เพราะเราต้องAtk Rand(จ้อบ50เบรด)หลายครั้งกว่ามอนจะตาย ถ้าเลือดเยอะและทนการโจมตีได้มาก ก็จะดี
แต่สายAgiสูงกว่าVitมีดีที่ แรนได้ไวกว่าสายVit ทำให้มอนตายไวกว่านะ
