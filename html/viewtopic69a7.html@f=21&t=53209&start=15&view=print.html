Technical job : Webboard Kreanmaster
อาชีพคลาส2อีกอาชีพหนึ่งของWebboard User เป็นคนใช้เวปบอร์ดในทางที่ตนเองคิดว่าดี จนมีชื่อเสียทั่วเวปบอร์ด

อาวุธที่ใช้เป็นหลักคือคีย์บอร์ด แต่ก็ยังคงใส่คีย์บอร์ดและเมาส์พร้อมกันได้อยู่

อาชีพนี้เมื่อโจมตีด้วยคีย์บอร์ด จะมีโอกาสโพสต์สแปมโดยอัตโนมัติ(0.1 x จ้อบเลเวล %)

ลักษณะสกิลของอาชีพนี้จะเป็นสกิลที่ใช้เพื่อเรียกบุคคลให้มาช่วยกันโพสต์ข้อความต่อต้านอะไรบางอย่าง รวมทั้งจะเชิญชวนคนที่ใช้เวปบอร์ดให้มาเล่นอาชีพเดียวกันนี้ด้วย
