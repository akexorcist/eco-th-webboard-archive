หุ่นยนต์ มีค่า DEF ตัวหน้า(%) เท่าไร tab_ต่อสู้ ไม่ได้บอกเอาไว้ ... แต่เดาว่าน่าจะอยู่ที่ 0 - 10 ไม่น่ามากกว่านี้

ส่วนค่า DEF ที่เห็นใน tab_ต่อสู้ เป็น DEF ตัวหลังล้วนๆ ค่ะ

แต่ถ้าอัพหุ่นจน HP , DEF , HP recovery(มองไม่เห็น) เต็ม
แล้วเอาไปล้มได้ VIT 3
VIT 3 ของหุ่นที่ได้มาจะไปเพิ่ม DEF ตัวหน้าให้หุ่น 3% และเพิ่ม DEF ตัวหลังให้อีก +3


ไม่แน่ใจนะว่า PET Robota มันจะโดนกั๊กป้องกัน

ถ้านึกภาพไม่ออก ....
มอน ATK 200 โจมตีหุ่น DEF หน้า 00 หลัง 200 .... หุ่นจะเจ็บ 20 DMG
มอน ATK 200 โจมตีหุ่น DEF หน้า 30 หลัง 150 .... หุ่นจะเจ็บ 14 DMG
มอน ATK 200 โจมตีคน DEF หน้า 30 หลัง 150 .... คนจะเจ็บ 1 DMG

จะเลี้ยงให้ HP เต็ม ก็ค่อนข้างจะบ้าพลัง ... ฝึกยังไง ก็ไม่เต็มแน่ๆ ภายในวันเดียว

ปกติจะได้ +1 VIT กัน ... ทุกๆ 3 - 4 รอบ จะได้ +2 VIT สักที

Robota ถ้าจะอัพให้ HP Recovery เต็ม ทำได้ไม่ยาก ขอแค่มีทรานเยอะๆ
จะอัพให้ DEF เต็ม ทำได้ไม่ยาก หมดเงินกันไม่ถึงล้าน
จะอัพให้ HP เต็ม ... ขายบูสเตอร์เอาเงินไปซื้อทราน ซื้อ Circuit ยังล้มได้ไม่ถึง 15 รอบ
ปกติจะได้ +1 VIT กัน ... ถ้าหาทรานแรร์ได้ ก็ +2 VIT
