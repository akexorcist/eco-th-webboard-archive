โดย ECO
เราอ่านในกระทู้ของคุณ Senzt แล้วค่ะ แต่ว่าอ่านถึงหน้า 20 มันแฮงค์ซะงั้น กว่าจะเปิดอ่านใหม่ได้ ก็แฮงค์อีก ถึงช่วงหน้า 20 -25 พอเปิดอ่านจากท้ายๆ เลย งงๆ

คือเราพยายามหาข้อมูล ดังนี้ค่ะ ช่วยบอกเราทีนะ

คือเราจะเล่น Machinery สายยิง Missile

อยากทราบว่า จะต้องอัพ Status อย่างไรบ้าง

ต้องอัพอะไรถึงจะร่ายยิง Missile เร็ว และ แรงขึ้น

เท่าที่อ่านดู จะร่ายเร็วต้องอัพ Agi ใช่มั้ยค่ะ แล้ว Str ช่วยทำให้ยิงแรงขึ้นหรือเปล่า

อ่อ อีกอย่างค่ะ การอัพหุ่น อัพได้เรื่อยๆ ไม่มีจำกัดใช่มั้ยค่ะ หรือว่าอย่างไร

แล้วต้องใช้ Transister สีอะไร ถึงจะอัพคุ้มที่สุดกับการเล่นสาย Missile
