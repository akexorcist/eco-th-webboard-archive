โดย ECO
เบื่อไหม ที่ ฟูจิกิ มีคนเยอะแจม วันนี้กระผมมีทริคมานําเสนอ เก็บที่ไหนไม่มีคนแจม

แนะนําให้เข้าไปหอรบ ครับ เพราะ คนจะมีน้อยครับ บางทีอาจเยอะหน่อย

วิธีเข้าหอรบฟรีครับ http://board.onenet.co.th/viewtopic.php ... ht=fushigi

เครดิต babor ครับ

ท่าท่านเวล64 ให้คุยกับnpcที่ใส่ชุดนักดาบเวล55หรือ65นี่แหละครับ

ขอทําเควส โจรสลัด(2) อะไรนี้แหละครับ ท่ามันไม่ขึ้น ต้องทําเควสไปส่งยาให้คุณย่าครับ

วิธีทํา ขึ้นไปบันไดเลือกอันที่2 แล้วคุย แล้วส่งให้npcที่ใส่ชุดนักดาบเวล55หรือ65

พอทําเสร็จจะได้ไปแล้วครับ เกาะโจรแดงอ่ะครับ ไม่ก็เก็บ เกาะไม่ฝักฝ่ายใดนะครับ

ปล.ท่าทําเควสโจรสลัด(2) ไรนี้แหละ จะไม่สามารถไปเกาะไม่ฝักฝ่ายใด ได้
