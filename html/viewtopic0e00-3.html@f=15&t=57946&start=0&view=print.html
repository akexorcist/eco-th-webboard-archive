หมายถึงไรอะ จะเอา INT 100 หรือ ว่า MDEF 100 อะคับ
เพราะ INT 100 อย่างเดียว ไม่เพียงพอจะทำให้ได้ MDEF 100 นะ ต้องมีปัจจัย(ตัวแปรอื่น)มาเกี่ยวเนื่อง

คือว่า ปกติ เพียวๆ mdef65

มันต้องใช้ int เท่าไหร่อะครับ เอาแบบรวมทั้งตัวหน้าตัวหลังเยยนะ

เพราะว่า มากสุด65ปะครับ แล้วใส่ สกิลไปอีก เปน 65+35 จะได้100พอดี

แค่อยากรู้ว่า intรวมต้องเท่าไหร่ ถึงจะทำให้ โอนแล้วได้65 พอดีอะครับ
