ส่ง รูปภาพ เข้าร่วมกิจกรรม Eco Cosplay Contest ได้ที่นี่ค่ะ

โดย ECO » พุธ 21 ก.ค. 2010 10:02 pm


สำหรับผู้เล่น ที่ต้องการ โพส ภาพ เพื่อ เข้าร่วมกิจกรรม Eco Cosplay Contest สามารถ ส่งรูปเข้าร่วมกิจกรรม ได้ที่กระทู้นี้เท่านั้นค่ะ !!!


หาก ต้องการ แก้ไข หรือ EDIT ใน Reply ของตนเอง ให้ทำการ PM ติดต่อ [GM]Tum หรือ [GM]Neko เท่านั้นค่ะ


เงื่อนไขการโพสภาพเข้าประกวดดังนี้

- ภาพที่ส่งเข้าประกวดจะต้องมีขนาด 800 x 600 pixels ไม่เกิน

- ภาพที่ส่งเข้าประกวดจะต้องเป็นไฟล์ .jpg เท่านั้น

- ระบุข้อมูลประกอบรูปภาพ ดังนี้
1. ชื่อรูปภาพที่ส่งเข้าประกวด
2. ระบุชื่อตัวละครที่แต่งเป็นตัวนั้น พร้อมแนบภาพต้นแบบมาด้วย เช่น แต่งเป็นตัวละคร ฮาโตริ
ในการ์ตูนเรื่อง นินจาฮาโตริ ก็แนบภาพ ฮาโตริ มาด้วยเป็นต้น
3. Character Name ระบุชื่อตัวละครที่ส่งเข้าประกวด
4. ระบุ Server ของผู้ที่ส่งเข้าประกวด
