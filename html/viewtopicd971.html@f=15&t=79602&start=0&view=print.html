เออ.... มันมีหลายสายนะ เหมารวมหมดเลย
สายอาชีพ warlock จะมีสายหลักๆอยู่ 3 สายครับ

1.สายเวท เป็นสายหลักของสายอาชีพนี้ มีสกิลหมู่แรงๆจัดการมอนได้ที่ล่ะหลายๆตัวได้
สายนี้ใช้คทา

2.สายมีด เป็นสายที่มีลูกเล่นเยอะ ไม่ค่อยมีคนเล่นเท่าไหร่
ถ้ามีสกิลที่จำเป็นครบจะมีความสามารถในการเอาตัวรอดได้ดีมาก
สายนี้ใช้มีดเป็นหลัก ใช้กระบองได้ด้วยนะ แต่ไม่แนะนำให้ใช้ เพราะสกิลไม่สนับสนุน

3.สายสาป สายที่มีไว้ฆ่าผู้เล่นด้วยกันโดยเฉพาะไม่เหมาะกับการเก็บเวล
ไม่จำเป็นต้องใช้อาวุธ
