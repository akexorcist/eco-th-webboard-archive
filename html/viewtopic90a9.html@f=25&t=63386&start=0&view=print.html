ที่จริงมันก็มีมานานและน่ะ แต่อยากมาถามความรู้สึกเพื่อนๆ หน่อย ว่า รู้สึกใงกับพวกนี้มั้ง

แต่สำหลับเราเสียอารมมาก แถมมันพูดจากวนๆ แล้วก็เหมือนจะอวดสกิว(ตามภาษาเกรียน)

คือมันเห็นจนเบื่อแล้วก็ไม่ได้รุ้สึกตื่นเต้น หรือ ดีกับสิ่งที่พวกนี้มันทำเลย แล้วมันจะอวดเพื่ออะไร

ยิ่งว่ามันๆยิ่งทำ เสียดาย ใน ร.ร. ฆ่ากันไม่ได้ไม่งั้นมันคงนอนจมกองตินไปและ

แล้ววันนี้ก็ยังมาเจอพวกนี้อีก เลยถ่ายรูปมาให้ดูเป็นตัวอย่าง เกรียน อ่อนๆ บร้าเฮ่อสกิว



ใครเจอมันขอความช่วยเหลือ ไม่ต้องไปให้ความช่วยเหลือ โทศฐานทำตัวเป็นมารสังคม
