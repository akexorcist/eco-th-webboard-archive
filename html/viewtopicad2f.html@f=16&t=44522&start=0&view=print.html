ผมเคยอัพ Dex ไปถึงที่พอรวมแล้วได้โบนัส น่าจะราวๆ มีค่า Dex เกือบ 60 ได้ ก็ยังมีวืดอยู่ตอนนี้เลยไปรีฯมาเหลือค่า Dex ประมาณ 40 ต้นๆ ก็ยังมี Miss อยู่เหมือนกัน เคยสังเกตุคนที่ตีแบบไม่ค่อย Miss นี่ส่วนใหญ่จะตีไวมาก แล้วก็แรงพอได้เลย เลยสงสัยว่าคงจะมีตัวสิงมา Soul ช่วยเหมือนกัน (คิดว่าเค้าคงลงค่า Agi เยอะ ส่วนค่า Str กับ Dex น่าจะมีผลมาจากตัวที่โซลให้)
ส่วนค่า Int ไม่ได้อัพเลยไม่มั่นใจเท่าไรแต่คิดว่าน่าจะมีผลเฉพาะโจมตระยะไกลอย่างธนู แต่อาวุธประเภทขว้างไม่รู้เหมือนกันว่าคิดความแม่นยำจาก Int หรือ Dex
