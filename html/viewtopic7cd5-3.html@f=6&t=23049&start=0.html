ยิงมอนที่โจมตีก่อน แล้วเราตาย กะลังกดกลับเมือง ---- เอาหน้าต่างResurrectionมาบัง แถมตรูก็กดโดนปุ่มokไปเต็มๆ ฟื้นขึ้นมาโดนตบตายอีกรอบ
ยิงหมู ---- บัฟAtk (ขอบใจ แต่ตรูจะตายซะก่อนเพราะหมูอัดแรง-*-)
ยิงหนอนแก้วยักษ์ ---- บัฟDef (แล้วงี้เมื่อไหร่หนอนมันจะตาย-*-)

เจอเจ้าแมวน้อยกวนตีนมาพอๆกันเลยค่ะ-*-
โดยเฉพาะโมโมจัง กับยามะจัง (ไอจังไม่ค่อยใช้ มันไม่ฮีล+เราเล่นสายsu)
นั่งจะฟื้นmp - counter (เพื่อ- -) ทีเวลาวิ่งยิงชินดันไม่ใช่ มาฮีลให้แทน เลือดก็เต็มอยู่- -
ใกล้ด้องแล้วดันฮีลตัวเอง
ทีเวลาอยากให้ชุบดันไม่ชุบ ไม่อยากให้ชุบมันดันจะชุบให้-*-
นั่งฟื้นเลือดจนเต็มแล้ว ลุกจะไปต่อ เอาสายฟ้าฟาดต้นไม้ซักต้นก่อนไป healing อยากถีบมันจริงๆ ให้นั่งอยู่ตั้งนาน-*-

มีอยู่ครั้งนึงสุดๆค่ะ เรื่องฮาๆของเจ้ายามาบุกิ
