มันก็ ได้ ทั้ง 2 อย่างนะครับ แล้ว แต่เรา จะเลือก

วางอะไรเป็นแสดงภาพ หรือ ความสามารถ
แต่ของทั้ง 2 ชิ้นต้องมีคุณลักษณะเหมือนกัน เช่น Type เผ่าติดตั้ง เพศ อาชีพ เป็นต้น

Sol . นำหมวกปาร์ตี้เหลือง นำไปหลอมกับ หูหมาดำ = ได้ ความสามารถหมวกปาร์ตี้เหลืองแต่แสดงภาพหูหมาดำ

หลังจากนั้น นำไปหลอม ครั้งที่ 2 / โดยครั้งนี้เลือก หลอมกับ หูฟังขาว = ได้ ความสามารถ ปาตี้เหลือง แต่แสดงภาพ หูฟังขาว

ครั้งที่ 3 นำหมวกปาตี้เหลืองแสดงภาพหูฟังขาว ไปหลอมกับ หมวกปาร์ตี้แดง = ได้ ความสามารถปาร์ตี้แดง แต่แสดงภาพเป็น หู ฟังขาว
