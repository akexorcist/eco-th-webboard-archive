เกี่ยวกับเควสการเปลี่ยนคลาสเป็นชาแมน ข้อ7คือ คุยกับ Spell User Master อีกครั้งจะได้รับ Soul Bead และสกิล (เวทมนต์พื้นฐานเลือกได้ 1 ชนิดจาก 4 ธาตุ)(หาก JobLV ยังไม่ถึง ตามสกิลที่เลือก จะได้รับเป็น Skill Point มาแทน) คือไอ้ Soul Bead นี่ทำไมผมถึงไม่ได้หละ่คับลองไปหาดูแล้วก็ไม่มีงงมาก น้องผมก็เหมือนกันเล่นเป็นชาแมนแต่ทำเควสเปลี่ยนก็ไม่ได้ไอ้ Soul Bead อยากรู้ว่าทำไม ไอ้ที่มันเป็นคล้ายสร้อยหนะคับลองอ่านดูในเวบมันบอกว่าจะได้ไอ้ Soul Bead อันนี้มาตอนเปลี่ยนคลาส
