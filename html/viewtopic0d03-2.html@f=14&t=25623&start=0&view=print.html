ผมเบลดสายเอจินะ ผมอะเล่นดาบ2มือ
ฟันมันก็ไม่ช้ามากไช้ฟันไวก็พอต่อๆกันได้แต่มีพระบัฟได้เอจิก็+ไปอีก10กว่า
และถ้าเปนเบลดจะมี เพิ่ม min attack ของดาบสองมือ จึงทำไห้แรงด้วยหลบได้ด้วย

ส่วนตัวผมชอบ2มือเพราะรู้สีกไช้แรงกว่าและฆ่าไวกว่า
