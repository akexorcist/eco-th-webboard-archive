ไม่มีขาย ต้องทำเอาเองครับ.. ใช้

- Small Silver Sword
- Steel Holder
- Round Shield

ค่าแรง.. 4000g นะ ถ้าจำไม่ผิด

ทำที่ npc ในโรงเหล็กทิศใต้ของ downtown ถ้าไม่มีของเลย ทั้งค่าของ + ค่าแรง + ค่าเหนื่อยนี่.. หาซื้อจากคนที่ทำมาขายเอาดีกว่าครับ เด๋วนี้เห็นขายๆกัน ~ 20k (server. Moji)

แต่ถ้าอยากทำเอง เพื่อความสนุกสนานก็

Small Silver Sword <- Silver Nugget + น้ำกลั่น + Rust Plate + Steel Hammer เลือก ทำอาวุธ ( ค่าแรง..1000g มั้งจำไม่ได้ )
Silver Nugget <- Alloy Stone2 เลือก ทำแร่ให้บริสุทธิ์
นำกลั่น <- Mineral Water 2 อัน Purify เอา
Rust Plate <- ซื้อได้ที่ npc ตรงกลางดาวทาว ( 500g )
Steel Hammer <- ซื้อได้ที่เมือง Fareast ในร้านเครื่องประดับ ( 1000g )

Steel Holder <- Steel Nugget (แบบก้อนกลม) + น้ำกลั่น ( ค่าแรง.. 1000g มั้ง ลืม -_-" )
Steel Nugget <- Alloy Stone แบบไม่มีเลข เลือก ทำแร่ให้บริสุทธิ์

Round Shield <- หาซื้อได้ที่ npc กลางดาวทาว ราคา 2000-3000 เนี่ย แถวๆนี้ จริงๆชิ้นนี้ประกอบเองได้แต่ของหายาก ซื้อเอาเหอะ - -"

ทั้งนี้ทั้งนั้น ข้างบนเกือบทุกชิ้น ต้องมี Tatarabe Stove ติดตัวอยู่ด้วย ซื้อได้ที่ กลางดาวทาว 2500g
