ประกาศ !! The Story Of Cinderella ตอนที่ 1

: Intro - ตำนานศาตราต้องสาป กับกษัตริย์ดาเรียสผู้เหี้ยมโหด


..........นานมาแล้ว ณ ดินแดน Acronia ยังมีชนเผ่าผู้ทรงภูมิปัญญาทั้ง 4 ได้อาศัยอยู่ในพื้นพิภพแห่งนี้

.........." มนุษย์l ( Emi ) - ฑูตสวรรค์ ( Titania ) - ปีศาจ ( Dominion ) และ ชนเผ่าโบราณ ( Ancient Lineage ) "

..........ประวัติศาสตร์จารึกสิ่งสำคัญต่างๆ แต่จู่ๆ หน้าบันทึกกลับเลือนลางซึ่งอดีตกาลการกระทำของชนเผ่าโบราณ และสุดท้ายพวกเขาก็หายไปจากหน้าประวัติศาสตร์ เหลือทิ้งไว้แต่ตำนานเล่าขานถึงพวกเขาด้วยนามใหม่... " ชนเผ่าที่สาบสูญ " ( Lose Lineage )

..........หากแต่สิ่งที่พวกเขาเหลือทิ้งไว้ กลับกลายเป็นคำสาปร้ายให้แก่ผู้ที่หลงเหลือ ในเวลาต่อมาพลังจากอารยธรรมของชนเผ่าที่สาบสูญ เป็นที่ยั่วกิเลสตัณหาแก่ทุกๆ คน ทำให้เกิดสงครามเพื่อแย่งชิงพลังอำนาจที่เหนือสิ่งอื่นใด

..........เพื่อรับพลังจากศาสตรา ความอมตะ และคำต้องสาป...

..........สงครามแย่งชิงนี้กลับดำเนินอย่างลับๆ ในทุกช่วง 2000 ปีที่ผ่านมา เพราะจากในอดีตที่ผู้คนได้เริ่มแย่งชิงกัน จนกระทั่งกลายมาเป็นสงครามที่มีผู้นำทัพอย่างเชื้อพระวงศ์และกษัตริย์เท่านั้นที่มีบุญบารมีเพียงพอที่จะครอบครอง จนเกิดการต่อสู้แย่งชิงพลังดุจพระผู้เป็นเจ้านี้ สุดท้ายความสูญเสียทำให้ผู้คนเอือมระอา และเริ่มตระหนักถึงคุณค่าแห่งสันติภาพ ทำให้การแก่งแย่งศาสตรายุติลง ความสงบสุขจึงกลับมาสู่ผู้คนส่วนใหญ่

..........แต่สำหรับกษัตริย์ ขุนนาง และเชื้อพระวงศ์ กลับยังพยายามค้นหาและครอบครองมัน ผลัดเปลี่ยนหมุนเวียนกันมาตลอด 2000 ปี ศาตรากลายเป็นตำนาน ที่ชโลมสายเลือดของพระเจ้าแผ่นดิน ประวัติศาสตร์บิดเบือน ว่าศาสตรากลายเป็นสิ่งของจากนรกภูมิ อันสามารถเปิดประตูระหว่าง 3 โลกเพื่อรับความเป็นอมตะได้

..........ณ สุดท้าย ศาตราได้ตกอยู่ในมือกษัตริย์ผู้หลงระเริงในพลังอำนาจ " ดาเรียส มิลาบีส ฟราโก้ " ( Darius Milabis Franco ) และใช้ศาตราเพื่อการก่อสงครามเพื่อยึดพลังอำนาจในโลกทั้งหมดให้ตกอยู่ในมือของตนเอง

..........พลังแห่งศาตราทำให้ทุกๆ เมืองตกอยู่ภายใต้แทบเท้าของดาเรียส เสียงร้องร่ำไห้ดังระงมภายใต้ท้องฟ้าสีดำของกลีบเมฆแห่งควันไฟ ผู้คนอดยากแร้นแค้น และความหวาดกลัวปกคลุมอยู่ทั่วทั้งโลกใบนี้

..........ประวัติศาสตร์จารึกไว้ว่ามีผู้ต่อต้านดาเรียสอยู่มากมาย แต่สุดท้ายพวกเขาจบลงที่ความตายและการสูญเสีย เหลือแต่คำร่ำลือถึงกองทหารไร้พ่ายของดาเรียส และคำเปรียบได้ดั่งปีศาจจากขุมนรก

..........แต่สวรรค์ยังประทาน โชคชะตายังมิสิ้นไป 5 ผู้นำพาความหวัง พร้อมกับกองทัพแห่งแสงและเอเลเมนท์ ได้เข้าต่อสู้กับทัพของดาเรียส และทั้ง 5 ได้ผนึกกำลังจนสามารถเอาชนะดาเรียสได้

..........โลกกลับมาสงบสุขอีกครั้ง พร้อมยุติตำนานศาสตราเลือดของชนเผ่าที่สาบสูญ

..........20 ปีต่อมา... ประวัติศาสตร์หน้าใหม่กำลังจะถูกจรดปลายปากกาขนนก เพื่อจารึกลงในประวัติศาสตร์อีกครั้ง...

..............." แกหนีไม่รอดแล้ว คืนถุงนั่นมาซะดีๆ แล้วไปกับชั้นซะ !! ราฟท์ เรเน็ต ( Raf Ranett ) " ชายหนุ่มยืนตั้งหลักพร้อมชักดาบออกมา

..............." ฮึ่ม... " เขาลุกขึ้นมาพร้อมกับปัดฝุ่นที่กางเกง " ถ้าแกทำได้ก็ลองดูเซะ !!
