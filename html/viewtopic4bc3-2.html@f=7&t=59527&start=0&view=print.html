เรื่องที่ผมโดนเรียกว่าลุง อยากฟังจริงๆเหรอ เรื่องมันยาวนะ... (เลียนแบบบุญชู)
คือตอนที่โดนเรียกคือผมแก่สุดในผีบอร์ด เลยโดนเรียกว่าลุง ก็เท่านั้นล่ะจ้า

มาแล้วจ้า รูปเซ็ตใหม่ ตอนแรกตั้งใจว่าจะทำเป็นช่องๆแบบคอมิค แต่คอมบึ้มไปแล้ว ใช้โฟโต้ชอปไม่ได้ เลยได้แต่ย่อรูปให้เล็กลงเท่านั้นจ้า



ชื่อตอน "รร. แห่งใหม่ของดานิเลีย"


สวัสดีค่ะ หนูชื่อดานิเลีย เช้านี้เป็นวันที่หนูจะต้องเข้าเรียนที่ รร. แห่งใหม่ค่ะ ไม่อยากไปสายตั้งแต่วันแรกจึงขี่เจ้าโบ้ เซนต์เบอร์นาร์ดคู่ใจไปรร. ค่ะ



นี่ล่ะค่ะ โรงเรียนใหม่ของหนู ดูใหญ่โตหรูหรามากเลยนะคะเนี่ย


อาจารย์ - "นักเรียนคะ โรงเรียนไม่ใช่สวนสัตว์นะคะ ไม่อนุญาตให้เอาสัตว์เลี้ยงเข้ามาในห้องเรียนค่ะ"


ดานิเลีย - "ขอโทษค่ะอาจารย์"
อาจารย์ - "ไม่เป็นไรจ๊ะ คราวหลังก็อย่าทำอีกแล้วกัน ไปนั่งที่ของเธอเถอะ อยู่หลังห้องโน่นแหนะ"
ดานิเลีย - "ค่ะ"


ดานิเลีย - "ที่นั่งไกลจังเลย ฟังอาจารย์สอนไม่ค่อยได้ยิน ว่าแต่... ทำไมมีคนมาเรียนน้อยจัง... อ๊ะ ผู้ชายคนนั้นหน้าตาดีจังแฮะ มีแฟนหรือยังน้า..."


ครึ่งชั่วโมงผ่านไป...

ดานิเลีย - "Zzzz...zzzz...zzzzz"

อนันตชัย - "ได้ครับ"
