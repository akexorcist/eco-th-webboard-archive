ต่อไปนี้เป็นรายชื่อไอเทมเลียนแบบที่ดรอปจากกล่องชนิดต่างๆ

มาดูรูปตัวอย่างกันก่อน



วงกลมสีดำบนสุด = ที่มาของไอเทม

สี่เหลี่ยมสีเเดง = กล่องเเดง

สี่เหลี่ยมสีเขียว = กล่องคอน

วงกลมสีน้ำเงิน= ตัวอย่างหมายถึงไอเทมชิ้นนั้นได้มาจากกล่องเเดง11 กล่องคอน1,2

ส่วนอื่นๆ ไมได้เเปลมาเพราะมีบางชิ้นได้จากNPC หรือซื้อจากNPC เลยเอาเฉพาะส่วนที่ดรอปจากกล่องชนิดต่างๆพอ

เมื่อรู้สัญลักษณ์แล้วก็ตามลิ้งค์ข้างล่างไปเลยครับ
