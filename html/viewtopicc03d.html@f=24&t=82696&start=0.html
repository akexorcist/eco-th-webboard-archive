Mushroom Incarnation Man Event



1. ชายลึกลับ キノコの化身 ปรากฏตัวขึ้น รอบๆ เมืองหลวง
East Acronia Field / West Acronia Field
South Acronia Field / North Acronia Field



2. เงื่อนไขเควส : ค่าชื่อเสียง 10 / 1 ตัวละคร ทำได้ 1 ครั้ง

วิธีทำเควส

1.คุยกับ NPC : Mushroom Incarnation Man / キノコの化身



2.รวบรวม :
Doubyful Mushroom / あやしいきのこ 10 ชิ้น
White Mushroom / 白いきのこ 5 ชิ้น

3.ส่ง Item แล้ว รับ ของรางวัล

Reward Item : Mushroom Hat





......................................................................................................................

เมื่อทำเควส Mushroom Hat เสร็จแล้ว ให้ คุยกับ NPC : Mushroom Incanation Man ทั้ง 4 ทิศ

( East Acronia Field / west Acronia field / South Acronia field / North Acronia Field )

โดยสนทนา และเลือกข้อ ที่ 1 ฟังเสียง mushroom

จากนั้น นำไอเทม ต่อไปนี้

Mushroom Stew / きのこシチュー
( ได้จากการทำอาหาร Recipe = Mushroom + Great Meat + Mineral Water + Butter )

Dangerous Mushroom / あぶないきのこ ( เห็ดสีม่วง )

Strange Mushroom / おかしなきのこ ( เห็ดสีฟ้า )

Rotten Mushroom / いけないきのこ ( เห็ดเน่า )

และ ใช้ สกิล Cooking ของชาวนา ทำการผสม



จะได้รับ ไอเทม Rich Mushroom Stew / たっぷりきのこシチュー ไอเทมเฟอร์นิเจอร์
