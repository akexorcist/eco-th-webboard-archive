เกี่ยวนะคะ สกิลปิคนิคจะฟื้น HP และ SP ได้มากหรือน้อย จะขึนอยู่กับ HP SP Increse Recoery ไม่ได้ช่วยให้เด้งไวนะคะ แต่จะช่วยให้เพิ่มปริมาณในการเพิ่มระดับฟื้นฟู

สกิล Cabibag เหงพูดกันว่าจะดีกว่า สกิล Picnic มากๆ เพราะฟื้นฟูได้มากกว่ากาน และได้ผลดีเมื่ออยู่ในดันเจี้ยน และ Picnic จะฟื้นฟูได้ไวก่านั่งพักเฉยๆดวยคะ

ไม่เกี่ยวกะมาริโอเนตคะ
