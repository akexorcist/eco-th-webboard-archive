วิธีหาหินสีเลขต่างๆ

มันดรอปจากก้อนนี้ครับ :

• ต่างแผนที่กันก็จะดรอปต่างกันนะครับ
• ทุกอาชีพตีตกหมด
• แต่ Tatarabe ตีตกหินที่หายาก ง่ายกว่า + สกิล Ore Analysis ยิ่งง่าย
• ระดับความหาง่าย 4 > 1 > 2 > 3 (70%)
• ส่วนมากจะตกเลข 4
• ขายได้ก้อนละ 1000G
• น้ำหนักเยอะมาก (ไม่ใช่จุนะ)
• หมดแระมั้ง อ่อ มีบอกว่าเปิดจากกล่องไหนด้วย แต่ขี้เกียจหา จาก WIKI หายาก >< ใครว่างๆก็ทำเลยงับ

------------------------------------

MAP : ถ้ำทวีป ฃั้น 3 และ ชั้น 4
Drop
• Grey Cystal1~5

------------------------------------

MAP : เหมืองโบราณ (ตะวันตก) ชั้น 2 และ ชั้น 3
Drop
• Red Cystal1~4
• Yellow Cystal1~4
• Green Cystal1~4

------------------------------------

MAP : ถ้ำบอสหมีตัวล็กๆอ่า จำชื่อบ่ได้ > < ชั้น 3
Drop
• Blue Cystal1~4

------------------------------------

MAP : หมาป่าขาว?? อันนี้ไม่รู้คืออาราย อยู่ตรงไหน
Drop
• Blue Cystal1,4
• Grey Cystal3,4,5
• Green Cystal1~4

------------------------------------
