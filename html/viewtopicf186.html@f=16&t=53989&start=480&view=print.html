แต่คุณจะคิดเอาเองไม่ได้หรอกนะว่าคำถามพวกนั้นน่ะจะทำให้ถูกทั้งหมด
ขนาดตอนข้าพเจ้าปลี่ยนยังต้องวิ่งทำน้ำยาตั้งสิบกว่าขวด กว่าจะเปลี่ยนได้ - -/

ถ้ายังดูไม่ทั่วหรือเข้าใจอะไรผิดก็ถามก่อนจะทึกทักเอาเองด้วยนะ...
