* สวัสดีครับทุกคน ^ ^" วันนี้ตื่นแต่หัววัน ( หรอ ? ) มาลงฟิคก่อนเวลาเดิมนตั้งเกือบ 1 ชม. ... อันที่จริงเพราะเดี๋ยวผมจะไม่มีโอกาสได้ใช้คอมแล้วน่ะครับ ( โดนน้องสาวยึด T^T" ) เลยรีบชิงโอกาสตอนน้องหม่ำข้าวเที่ยง มาลงฟิคให้ทุกท่านได้รับชมกันก่อนเลย

ทั้งนี้ที่จริงผมอยากจะลงวันพรุ่งนี้นะ ฤกษ์ดี แต่เกรงว่าจะไม่มีเวลาได้มาลงเพราะต้องออกไปข้างนอกเกือบตลอดทั้งวันเลย >_<" พรุ่งนี้เป็นวันคล้ายวันเกิดของผมฮะ ^ ^" และอยากให้ทุกคนมีรอยยิ้ม และมีความสุขกับนิยายของผม เลยรีบปั้นมาลงจนเสร็จได้ทัน ( แหม การทำอะไรดีๆ จนเสร็จก่อนวันเกิดนี่รู้สึกดีใจแฮะ ^0^/ )

สำหรับในตอนนี้ ส่วนที่แนะนำอาจเป็นพลังแห่งปราชญ์ของยูเรยครับ เขาสามารถใช้พลังบางอย่างในการเปิดช่องว่างระหว่างมิติได้ ซึ่งในนิยายเขาจะเปิดมิติด้านหนึ่งเพื่อรับคมจากอาวุธ และเปิดมิติอีกด้านใกล้ๆ ตัวของศัตรูเพื่อใช้คมอาวุธเหล่านั้นโจมตีกลับไปยังศัตรู ( เรียกง่ายๆ ว่าโดนอาวุธของตนเองไปเต็มๆ เลยนะกลุ่มกบฏเอ๋ย >_<" จุดจบไม่น่าพิศมัย )


สำหรับตอนต่อไปก็จะเป็นตอนสุดท้ายของบทที่ 1 แล้ว และเช่นกันว่าการรับสมัครตัวละครก็จะสิ้นสุดลงเช่นกันเมื่อตอนที่ 3 ได้โพสลงสู่สายตาเพื่อนๆ เรียกว่าโพสปุ๊บก็ไม่สามารถส่งได้แล้วนะครับ แต่ทั้งนี้หลังจากโพสตอนที่ 3 ไปนั้นจะมีเวลาอีก 1 วันครับในการแก้ไข Edit ลักษณะตัวละครของเพื่อนๆ ที่ได้สมัครกันเข้ามาแล้ว ก่อนที่ผมจะนำตัวละครทั้งหมดไปเมครวมกับเนื้อเรื่องหลักครับ ^ ^"/

ขอขอบคุณทุกๆ คนที่ติดตามผลงานของผมคร๊าบ~

ปล. ผมลองใช้คำสั่ง list ในการย่อหน้าดูนะครับ แต่ไม่เวิร์คเลย >_<" คือมันจะย่อทั้งย่อหน้าเลยอ่าครับ ไม่ได้ย่อเฉพาะบรรทัดแรกของย่อหน้า แต่จะย่อทุกบรรทัดเลย ผมเลยใช้จุดไข่ปลาดังเดิมครับ ไงจะลองหาวิธีที่ดีกว่านี้ต่อไปครับ
ปล. 2 ผมอัพเดท Character ใหม่แล้ว และเพิ่มดีเทลตัวละครเข้าไปอย่างละเอียดเลย ^ ^" แต่ทว่าอาจจะยังไม่สามารถเขียนทุก Character ได้ทันนะครับ แต่จะมา update เรื่อยๆ ครับป๋ม ^ ^"/
