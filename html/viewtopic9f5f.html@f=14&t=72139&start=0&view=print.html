มันมีวิธีรีฟรีอยู่ครับ แต่ก็โหดอยู่เหมือนกัน

คือไป"ตาย"ในโลกโด จนเลเวลลดอ่ะครับ(ที่โลกโด ตายจนเหลือ % ต่ำกว่า 0 เลเวลลดลงได้)
status ที่เราเคย up ไว้จะถูกลดลงมา (ซึ่งจะ random ค่าที่ลดลงนะ ไม่ใช่ว่าเวลนี้เราอัพไรไปแล้วมันจะรีออก)

- ถ้าอัพผิดไม่มาก ตายจนเหลือซักเวล 15 แล้วเก็บเลเวลใหม่ ก็น่าจะโอเคครับ

- ถ้าอัพผิดหมดเลย จะรีออกทั้งหมด(เช่นลง str ไป 50 อยากเปลี่ยนมาลง vit 50)
แบบนี้ก็ต้องฆ่าตัวตายจนเหลือเลเวล 1 แล้วก็เก็บเลเวลใหม่อ่ะครับ

ปล.ตายที่โลกโด Jobs level ไม่ลด ลดแต่ Base level
