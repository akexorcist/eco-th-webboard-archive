ชุดเฟนเซอร์ มีเลเวล35จ้า ถ้าเวลประมาณ39-42 อยากเปลี่ยนเสื้อ ต้องไปซื้อที่ใส่ได้ทุกอาชีพไรงี้อะครับ รู้สึกว่าจะมีที่เมืองเหนือนะ

พอเลเวล45เปลี่ยนเป็นไนท์ ก้ใส่ชุดไนท์ได้ครับ แต่ถ้าเล่นจ็อบ50ก้ใส่อย่างอื่นไปก่อนนะ

ท่อนล่างเฟนเซอร์เวล35 ต้องเปิดกล่องเอาครับ ลองเดินดู ตามตลาดขาย30-40k ก้เหมาะสมครับ อ้อ รู้สึกว่าจะเป็นกล่อง 3 นะครับ (ไม่แน่ใจว่ากล่องอะไรบ้าง รอคนมาเสริม :oops: )
