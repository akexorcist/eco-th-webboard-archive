60 จะลำบากมากงิสำหรับสาย backpacker มาสาย vit แบบนี้อาจจะน๊อคได้
ถ้าไม่รีบอะไรแนะนำรอจน 70+ ก่อนดีกว่างิ

เพราะให้หมาดูจาก status
s.hit - ตีหมาสองตัวโดนลำบาก
def - โดนหมาสองตัวกัดตลอด อาจจะโดนทีหลายสิบด้วย
atk - ต้องสู้กันนาน

ถ้าอยากรีบทำมังกรดำจริงๆ แนะนำให้ยอมสละความเชื่อง pet เอาหน่อย ใช้พวกหมาที่เลี้ยงมาเก่งๆช่วยกัดสู้ มันจะตายก็รอไปรักษาเอา

จะไปก็แบกพวก Dry Plum, Dry Apple, Mix Juice, Sandwich ให้เต็มที่เหลือ CA ติดไปซัก 10-20 พอ
เวลาสู้ เริ่มมาให้วิ่งหนีวนรอบๆหาดเลย ไกลแค่ไหนก็ได้ให้สลัด Arc ให้หลุดให้ได้ ส่วน White, Gold มันสลัดไม่หลุดอยู่แล้ว แล้วถอดเข็มกลัด Breeder ออกชั่วคราวใส่ชุด Def หนาที่สุดที่จะหาได้ Blow สู้หมา ปั้มเลือดดีๆพยายามอย่าให้เหลือต่ำกว่า 500 (ไม่งั้นเจอ Rage สวยๆสองทีติดอาจจะนอนกองก่อนเจอ Arc เอา) ถ้าจะปั้ม sandwich ก็ให้วิ่งหนีไปปั้มไป
พอล้มหมาสองตัวได้ก็พักเตรียมตัวให้เต็มที่ ตอนเจอ Arc ถ้ามี pet มาช่วยล่อเป้า Tank arc ได้ซัก 4-5 วินาทีก็สบายแล้วงิ สั่ง pet ให้วิ่งเข้าไปโดน Arc มันตีๆแล้วเราก็วิ่งไป Blow มัน พอ Arc หันมาตีเราก็ค่อยวิ่งหนีสลัดให้หลุดแล้วทำแบบเดิมจน Arc แพ้ได้
อย่าลืมใส่เข็มกลัด Breeder กลับก่อนตี Arc ร่วง - ออกจาก warp นะงิ
ตอนสู้ Arc พยายามให้เลือดตัวเองเต็มเข้าไว้ เพราะไม่รู้พี่แกจะ Anger แล้วสับรัวเราตอนไหนด้วยเวลาสู้กันนานๆ



แต่ถ้าไม่รีบ แนะนำให้รองิ หืดขึ้นจริงๆสาย vit lv ~ 60 เนี่ย

PS : ของหมาใช้ Healing Tree ช่วย tank นำแล้วให้หมาช่วยกัด พอ tree ใกล้ร่วงก็วิ่งเข้าไปทุบๆ มันหันมาก็เผ่นโล้ด :p

มันพูดยากเอาเรื่องน่ะงิว่า s.hit def atk อะไรประมาณไหนถึงจะเหมาะสม

s.hit ยันให้ถึงอย่างน้อยเกือบๆ 200 ก็ยังดีงิ
def จะให้ดีสาย vit ตัวหน้า 20 ตัวหลัง backpacker .... ดึงได้ถึง 80 ก็หรูแล้ว = ="
atk เท่านี้ก็ได้งิ สู้นานหน่อย เอาตัวรอดให้ได้สำคัญกว่า =w=~

แต่ที่แน่ๆคืออย่า up status อะไรเป็นพิเศษถ้าไม่ได้ใช้ค่านั้นจริงๆเพื่อมังกรดำ ไม่คุ้มน่ะ
ไม่ใช่ s.hit ไม่พอ up มันซะ dex 50 60 ผลสรุปพอได้มังกรดำไม่รู้เอา dex มหาศาลไปทำอะไรต่อ อันนี้ก็ไม่เข้าท่างิ
