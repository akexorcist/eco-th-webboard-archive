ลูก้าเจ้าน้ำตา เขียน:ใหนๆก็มาละ ถามเลยดีกว่า อิอิ
:?: สกิล เปิดกล่องที่ได้ตอนจ็อบ 40 อัพแล้วสามารถเปิดกล่องไม้ ได้ทุกเลเวล เลยหรือเปล่าครับ

แล้วสามารถเปิดหีบได้ด้วยหรือเปล่า

และสกิลนี้มันมีกี่เลเวลครับ ? ขอบคุณครับ :)


สกิลมี 1 เลเวล คับ แนะนำว่าควรอัพเป็นอยากมาก สามารถเปิด Wood Box Treasure Box
ได้ทุกเลเวล คับเท่าที่เปิดมา แต่ว่า Container ยังเปิดไม่ได้นะคับ ต้อง SunClass เป็น Truasure Hunter ถึงจะมีสกิลเปิด Container คับ เวาไปดัน เราตีกล่องได้ก้อเปิดเลย ประหยัดตังค่าเปิด และก้อ ลดน้ำหนักได้เยอะมาก คับ

มี ทริค มาฝาก นิดนึง บางคนอานจะุรู้็แล้ว ว่า เราสามารถใช้สกิล ของเรา ไม่ว่าจะเปิดกล่อง ซ่อมของ หรือว่า ทำอาหารของฟาเมอ สามารถให้คนอื่นใช้ ได้ ตัวอย่าง เพื่อนเราตีก่องได้ เราก้อใช้สกิลเปิดกล่องของเราให้เพื่อน โดยเพื่อนเป้นคนเปิดเองเหมือนคุย NPC
โดยไปปรับที่ Option กด Ctrl+O เลือกไปที่ ควบคุม แล้วปรับตรง การผสมสาย Skill ด้วยตัวเองเป็น OFF แล้วทีนี้พอเราใช้สกิล อย่างเปิดกล่อง แล้วก้อเลือกไปที่ตัวเพื่อน เพื่อนเราก้อจะเปิดกล่องเองได้ หรือ ทำชุดซ่อม ทำอาหารได้คับ
