- แม่ค้าเลเวล 47/45 จะเก็บเลเวลที่ไหนดีคะ ขอทั้งแบบที่ลุยเดี่ยว กับ แบบไปเป็นตี้นะคะ

- เราสามารถจัดการกบเหลือง(จำชื่อไม่ได้) ที่โมโม่เพลนแบบเดี่ยวๆ ได้ยังคะ มันเป็นสีฟ้าแล้วค่ะ แต่เห็นมีคนบอกว่ามันโหด

- เราเล่นสาย str+agi เป็นไงบ้างคะ เล่นสายนี้ดีป่าวคะ แนะนำด้านการอัพสเตตัสหน่อยค่ะ (เพิ่งเคยเล่นเกมส์ออนไลน์)

- เลเวลอย่างเราสามารถเดินไปขายของ(0C)ที่ร้านหน้าดันเหนือได้ยังคะ ไม่มีหนอนขี่กับทหารจ้างนะคะ (เราสามารถป้องกันตัวเองจากเหล่าร้ายได้ยังคะ โดยไม่ตายอ่ะค่ะ ) :oops:
