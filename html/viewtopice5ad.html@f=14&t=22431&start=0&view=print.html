ไปวอคาโน่เมืองใต้เรยงับ

ก่อนอื่น ไปเซฟพ๊อยไว้ที่เมืองไอรอน เดินเข้าไปอีกนิด ไม่ต้องกังวลงับ
กังวลได้แต่หนอนแดงนะ อย่าไปใกล้มันเชียว ที่เหลือ จะเดินชนมันก้อไม่ไรเกิดขึ้น

พอเซพพ๊อยเสร็จ มาลุยที่ วอคาโน่เลยครับ ถ้าอยู่รอบ ๆ ภูเขาไฟ ไม่ต้องกังวลเรื่องมอนสเตอร์เลยครับ ไม่มีมอนเตอร์โจมตีก่อน(ถึงหนังสือจะบอกว่าโจมตีก่อน)

เก็บกับตัวลูกกลิ้งครับ ที่ชื่อ ชินเนม่อน เก็บกับเจ้าตัวนี้ได้ทีละ หนึ่งถึง หนึ่งจุดห้าเปอร์เซ็นต์เชียวนะ ถ้าเลเวลสามสิบ เก็บกับเจ้าตัวนี้ไปจนกว่านายจะเปี่ยนจ๊อบเลย
ซึ่งก้อคือเลเวล ห้าสิบ ไม่ต้องห่วงว่ามันจะโหดหรือไม่ เพราะอาเชอ ตีไกลได้อยู่แล้ว ตีซักสองสามทีก็ตายแล้ว ได้ค่าประสบการณ์เยอะด้วย อีกอย่าง มันเดินเช้า


หรือถ้าคุณอยากสบาย ไปทางเมืองฟาอีสสิ เป็นอีกทางเลือกที่หรูหรา และมีระดับอย่างนักสู้ ไฟเตอร์ สายธนูโดยเฉพาะเลย

ไปยิงใส่กบเหลืองเจ้า งับ ยิงแล้วหนี ทำงี้ไปจนกว่ามันจะตาย ได้ค่าเยอะมักๆ

หรือจะเก็บต่อเมืองเหนือก็ไม่ว่าไร
