abyssal เขียน:วิธีได้ :

1.2 จากนั้นไปที่ Insmouth Village ใน Territory Cave B5F (ไปที่ป้าย)คุยกับ Insmouth Elder จะได้Raigyo Sweat จากนั้นคุยอีกทีอีกที(ถ้าให้ Dryfish จะได้ Salmon , ถ้าให้ Strange Dryfish จะได้ Marionette )
*ถ้าต้องการทำอีกครั้งข้ามข้อ 1 ได้เลย
2. ดรอปจาก Raigyo (Underwater living knowledge)
