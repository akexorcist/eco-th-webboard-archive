ถ้าเอาแบบเป๊ะๆเลยก็ตามสูตรนี้ครับ

ค่า dex มันจะไปเป็นตัวคำนวณค่า C.spd
และค่า C.spd จะนำไปคำนวณเวลาร่ายอีกที

C.SPD = DEX &times; 3 +floor[(DEX+63)/9]^2 + 129
เวลาร่าย = C.spd/1000 x base เวลาร่าย
และค่า C.spd ขึ้นได้สูงสุด(จากการอัพ) ได้แค่ 800 เท่านั้น(dex รวม 108)

ถ้าอย่างที่ จขกท.บอกมา สมมุติว่า dex รวมตัวหน้าหลัง 100 นึง
C.spd = 100 x 3 +floor[(100+63)/9]^2 + 129
*floor หมายถึงปัดเศษทิ้งครับ
จะได้ C.spd = 753
หรือเท่ากับ 24.7% ของเวลาร่ายปกติครับ

ปล.ผมเข้าใจว่า จขกท.จะอัพ dex ตัวหน้าให้ถึง 100 ซึ่งไม่จำเป็นครับ
เอาให้ผลรวมหน้าหลังเป็น 108 ก็สูงสุดแล้วครับ
