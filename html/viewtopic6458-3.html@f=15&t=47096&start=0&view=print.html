ขั้นตอนการทำมาริโอเนต Peeno


- ให้เดินทางไปยังเมือง Tonka แล้วไปยังอาคารของ Marionest Headquarter ซึ่งด้านในจะพบกับ NPC Emil อยู่คุยกับเขาแล้วตอบคำถามจนจบ






- จากนั้นให้เดินทางไปยังหอคอยแสง ที่ชั้น 16F จะพบกับซากของหุ่น D-bot ชื่อว่า Broken Robot เมื่อสำรวจแล้วให้เลือกว่า ลองทุบดู ก็จะได้รับไอเทม Strange Dog-end มา






- นำไอเทม Strange Dog-end กลับไปให้ Emil ที่ Marionest Headquarter แล้วเขาจะพาเราวาร์ปไปที่แห่งหนึ่ง ให้คุยกับ NPC Machinery Agent จนจบ จากนั้นก็กลับมายังเมือง Tonka





- เดินไปที่รูปปั้น Peeno ขนาดใหญ่ซึ่งอยู่ทางใต้ของเมือง ให้สำรวจสวิตซ์ด้านหลังรูปปั้น จะพบทางลับไปห้องใต้ดิน




- คุยกับ Marionest Agent และ Emil ที่อยู่ในห้องเขาจะให้เราช่วยทำลายเครื่องล้างสมอง Brain Control Machine ที่ทำให้พวกหุ่นยนต์บ้าคลั่งอยู่ในตอนนี้ ระหว่างที่บุกเข้าไปทำลายระวังพวก D pibot ที่เป็นศัตรูด้วยนะ






- เมื่อทำลายได้แล้วให้คุยกับ Marionest Agent และ Emil อีกครั้งก็จะออกจากห้องลับนี้



- เดินไปยัง Marionest Headquarter อีกครั้ง คราวนี้คุยกับ Marionest Agent ก็จะได้รับ Marionet Peeno แล้ว
