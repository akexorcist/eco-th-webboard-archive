ถ้าคิดถึงผลระยะยาว Throw chemical ค่อนข้างมีประโยชน์คะ

สร้างสถานะผิดปกติลงบนพื้น ได้นานประมาณ 20 วิ

นี่ถ้าใช้ลาก แค่ขวดเดียวก็พอจะช่วยได้อยู่ ตอนวอร์ไม่ต้องพูดถึง มีเท่าไหร่โยนลงไปแบบไม่ต้องเสียดาย ให้มันเดินมาเหยียบแล้วติดมึนเรื่อยๆเลย 555 สะจัย


นอกนั้นก็อัพสกิลหากิน พวกโซล Boot เพราะมาริคิงมันใช้ตอนสิงได้น่อ ส่วนท่าระเบิดมันไม่ค่อยได้หวัผลอะนะ

ถ้าเราเป็นสายเวทก็ได้ใช้ข้อดีของมันแค่ทำให้ตาบอดแหละนะ แต่ในกรณีเราใช้ลากอาจจะดีก็ได้

คือถ้ามอนโจมตีก่อน เราก็ต้องเสียเวลาไปทุบมอนก่อนทีนึง ก่อนเรียกคิงใช่มะคะ แต่ถ้ามันรุมมาเยอะๆ เราจะมามัวแต่เล็งทีบะตัวมันก็รุมตายก่อนชิมิคะ เราก็ใช้สกิลระเบิดที่ว่าเนี่ยเปิดไปก่่อน จะเข้า 1 หรือเท่าไหร่ มันก็เป็นดาเมจที่ถือว่าเราทำได้แล้วหละคะ

ต่อไปก็เรียกลูกๆคิง ของเรามาเก็บมัน เราก็ไม่ชวด EXP ละค๊าา



ปล เราเพิ่งหัดเล่นบอร์ดน้อ เห็นแล้วมันอยากอธิบาย อิอิ
