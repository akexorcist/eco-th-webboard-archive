หลักการหาค่า damage แบบคร่าวๆ



การโจมตีปกติ Damage = Ceil [ (Revision ATK - DEF (armor) ) * ( 100 - DEF (vit) ) / 100 ] * [X] - floor( VIT/3 )

การโจมตีด้วยสกิลทางกายภาพ Damage = ceil [(Revision ATK * Skill Magnification Ratio - DEF(armor) ) * (100 - DEF(vit) ) /100]*[X] - floor [VIT/3]

## note ##

• ceil ปัดเศษขึ้น floor ปัดเศษลง

• X คือผลสกิลที่ reduce damage จะมาคิดตรงนี้(ถ้ามี)

• Revision ATK = floor [floor [ATK * Attribute Magnification Ratio] * distance revision]

........... • distance revision
......................... • Distance 1: 100%
......................... • Distance 2: 90% [ spear & both hands weapon]
......................... • Distance 3: 90% [ stone hit/vacuum wave/sonic boom ]
......................... • Distance 4: 81% [ continual throwing/มีดปา/หน้าไม้ ]
......................... • Distance 5: 81% [ ธนูส่วนใหญ่/เวทย์ติดสถานะ ]
......................... • Distance 6: 73% [ long bow/เวทย์ต่างๆ ]
......................... • Distance 7: 73% [ long bow ]
......................... • Distance 8: 66% [ eagle eye Lv1-2 ]
......................... • Distance 9: 66% [ eagle eye Lv3-4 ]
......................... • Distance 10:60% [ eagle eye Lv5 ]

• AMR ค่าดูได้จากการคิดธาตุ ด้านล่าง

4ธาตุหลัก --> 4ธาตุหลัก (ธาตุชนะ) = 1.66
4ธาตุหลัก --> 4ธาตุหลัก (ธาตุแพ้) = 0.50
4ธาตุหลัก --> 4ธาตุหลัก (ธาตุเดียวกัน) = 0.00
4ธาตุหลัก --> ธาตุแสง = 1.33
4ธาตุหลัก --> ธาตุมืด = 0.66
ธาตุแสง --> 4ธาตุหลัก = 0.50
ธาตุแสง --> ธาตุแสง = 0.00
ธาตุแสง --> ธาตุมืด = 1.66
ธาตุมืด --> 4ธาตุหลัก = 1.50
ธาตุมืด --> ธาตุมืด = 0.00
ธาตุมืด --> ธาตุแสง = 0.50
