ขออนุญาตแกะของคุณออฟิน่าให้ละกัน

เท่าที่มองๆมี vit 103
int 100 พอดี
คำนวณ def จาก vit โบนัสหนักที่ 99 [Def55] และโบนัสรอง 102 [Def56]
คำนวณ M.def จาก vit โบนัสที่ 100 [M.def25] รวมกับ int โบนัสที่ 99 [M.def58] +เศษจากการคำนวณ[M.def59]

แต่ในคลิปตั้งต้น Def 71 / M.def 70 [ก่อนบัฟ]
ที่คำนวณได้ Def 56 / M.def 59
แสดงว่ามีตัวโซลออฟ เพราะไม่เห็นตัวโซลใช้สกิล

เวลคง 110 ไปแล้ว ถึงจะได้ stat ขนาดนั้น (จริงปรับให้มันลงโบนัสหน่อยก็ดีนะครับคุณออฟิน่า มันไม่ลงซักตัวเลยน่ะ เสียดายพ้อยท์ )
เลือดเยอะมาก ใ้ช้ไอริสเซ็ต 2000HP ด้วยแน่ๆ น่าจะมีชุด + กับโซลสายถึกด้วยมั้ง

ปล.สำหรับคุณ Bakana ล่าตัวก๊อบปี้สิงเข้าไปไม่ได้ ทำให้เราต้องพึ่งแค่ชุดที่ตัวเองมี แถมเสี่ยงแหกด้วย...
สเตตัสแบบคุณออฟิน่าสามารถล่าตัวก๊อบปี้ได้เลย แค่บัฟ Aura ทั้งสองอย่างอย่าให้หลุดก็พอ (แย่กว่าซอตรงบัฟมันอยู่แป๊บเีดียวนี่แหละ)
