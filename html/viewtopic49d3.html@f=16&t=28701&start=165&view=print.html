ปกติแล้ว ถ้าสกิลสายเวทย์ (กิน mp) จะใช้ c.spd ในการคิดความเร็วตอนร่าย ส่วนสกิลสายโจมตีกายภาพ (กิน sp) จะใช้ a.spd ในการร่ายนะ
หมายเหตุ : c.spd เพิ่มด้วย dex ส่วน a.spd เพิ่มด้วย agi นะ

ตอบเท่าที่รู้
1. blow ใช้ agi
2. dust explosion ถ้าวิเคราะห์แล้วคิดว่าใช้ agi
3. Chemical plant ใช้ dex
4. Phalanx ถ้าวิเคราะห์แล้วคิดว่าใช้ agi
