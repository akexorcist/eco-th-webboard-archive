อ่า...เควสนี้มันต้องมีตัวตายตัวแทนครับ

ต้องไปมากกว่า 1 คน เพราะเควสนี้ ถ้าตายคือเควสไม่ผ่าน

เช่น ไปลุยคนเดียว แล้ว ตาย = เควสไม่ผ่านชัวร์

ไปลุย 2 คน แล้ว ตายทั้ง คู่ = ไม่ผ่านเช่นกัน

แต่ถ้า ไปลุย 2 คน แล้ว ตาย 1 รอด 1 = ผ่านทั้งคู่ครับ

( กรณีไป 2 คน ทั้ง 2 คนต้องรับเควส แล้วต้องตี มินิดู ด้วยนะ )

ช่วยกันตีครับ แล้วพอเลือดมันเหลือครึ่งหลอด ให้ 1 คน เดินห่างออกมา

เหลืออีกคนยืนตีอยู่ แล้วรอรับระเบิดพลีชีพ ของ มินิดู


หรือจะใช้ สายเวทย์ช่วยอย่างที่ Rep บนบอกก็ได้ครับ แต่ถ้าไม่มี

แนะนำว่า เอาอาชีพเทรเชอร์ฮันเตอร์ หรือ แกมฯ ไปยืนรับตอน มินิดู พลีชีพ ครับ

เพราะ มีสกิล Lucky ( แรงระเบิดพลีชีพของ มินิดู มันเป็น เวทย์ )

ถ้าโชคดี มัน Aviod เลยด้วยซ้ำ = =' ( แต่โอกาสต่ำ )

อย่างมากคือ ความแรงลดลงอ่ะ ( ส่วนใหญ่โดนที 2 - 3 พัน )


เคยไปครั้งนึง โดนระเบิดรอดหวุดหวิด ( เลือดเหลือราวๆ 100 - 200 )
