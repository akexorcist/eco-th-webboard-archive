เอามาลงไว้ เพราะมีคนตั้งคำถามเกี่ยวกะค่าสถานะ

ความหมายและผลลัพธ์ของค่าสถานะต่างๆ

STR มีผลต่อค่า ATK, MAX.PAYL
STR Bonus เมื่ออัพค่า STR ถึงจุดที่กำหนด ค่า ATK, MAX.PAYL จะเพิ่มขึ้น

DEX มีผลต่อค่า ATK, M.DEF, S.HIT, C.SPD, MAX.CAPA, อัตราการป้องกันของการใช้โล่ห์ และช่วยลดการเกิดสถานะผิดปรกติ
DEX Bonus เมื่ออัพค่า DEX ถึงจุดที่กำหนด ค่า S.HIT, C.SPD, MAX.CAPA จะเพิ่มขึ้น

INT มีผลต่อค่า M.ATK, M.DEF, MAX.SP, L.HIT, L.AVOID, MAX.CAPA และช่วยลดการเกิดสถานะผิดปรกติ
INT Bonus เมื่ออัพค่า INT ถึงจุดที่กำหนด ค่า M.DEF, L.HIT, MAX.CAPA จะเพิ่มขึ้น

VIT มีผลต่อค่า MAX.HP, MAX.SP, DEF, M.DEF, MAX.PAYL
VIT Bonus เมื่ออัพค่า VIT ถึงจุดที่กำหนด ค่า MAX.HP, DEF, M.DEF, MAX.PAYL จะเพิ่มขึ้น

AGI มีผลต่อค่า A.SPE, S.AVOID, L.AVOID
AGI Bonus เมื่ออัพค่า AGI ถึงจุดที่กำหนด ค่า A.SPE, S.AVOID จะเพิ่มขึ้น

MAG มีผลต่อค่า M.ATK, MAX.MP
MAG Bonus เมื่ออัพค่า MAG ถึงจุดที่กำหนด ค่า M.ATK จะเพิ่มขึ้น

***จะเห็นว่าค่า Status ส่วนใหญ่ ให้ Bonus ไม่เท่ากับ ผลลัพธ์ของค่า Status นั้นๆ
เช่น DEX มีผลต่อค่า ATK แต่ไม่ให้ Bonus เป็น ATK
ซึ่งก็ไม่ต้องไปสนใจมัน เพราะค่าที่ได้มันคือ Bonus

ATK = ความแรงของการโจมตีทางกายภาพ
M.ATK = ความแรงของการโจมตีทางเวทย์มนตร์

S.HIT = พลังโจมตีระยะใกล้
L.HIT = พลังการโจมตีระยะไกล

DEF = การป้องกันทางกายภาพ
M.DEF = การป้องกันทางเวทย์มนตร์

S.AVOID = การหลบหลีกจากการโจมตีระยะใกล้
L.AVOID = การหลบหลีกจากการโจมตีระยะไกล

A.SPD = ความเร็วในการโจมตี
C.SPD = ความเร็วในการร่ายเวทย์

MAX.HP = ค่าHPสูงสุด
MAX.MP = ค่าMPสูงสุด
MAX.SP = ค่าSPสูงสุด

MAX.PAYL = น้ำหนักของ ของที่บรรทุกได้
MAX.CAPA = จำนวนของ ของที่บรรทุกได้

Innocent เขียน:Alchemist Guide
หลังจากที่เราชาวนาอยู่กับควาย เอ้ย ไม่ใช่สิ อยู่กับเกมมานานแล้ว ถึงเวลาสักที ที่เราจะเปลี่ยนจากชาวนาจนๆ ไปสู่นักเคมีผู้รอบรู้ จะมัวจมอยู่กับความยากจนทำไมกัน ได้เวลาที่เราจะต้องเปลี่ยน "อาชีพ" กันแล้ว

เงื่อนไขการเปลี่ยนอาชีพ
- JobLV 30

สถานที่เปลี่ยนอาชีพ
- ที่ทำการกิลมาสเตอร์ ชั้น4 ห้องทิศตะวันออก

วิธีการเปลี่ยนอาชีพ
1. ให้ไปที่อัลเคมิสกิล ที่ตึกกิลมาสเตอร์ แล้วคุยกับหัวหน้ากิลในห้อง แล้วเลือก ข้อ3
2. เขาจะพูดถึงเรื่องการสอบ10ข้อ จากนั้นคุยกับเข้าอีกที่ แล้วเขาจะทำการสอบ ซึ่งมีด้วยกัน10ข้อ โดยแต่ละข้อจะให้หาของมาให้ ตามนี้

ข้อที่3 ให้หา Rune Grass

ข้อที่5 ให้หา Tum Tum Grass

มาช่วยเพิ่มเติมครับ

ลักษณะทั่วไป Farmer นะครับ

 เป็น BP ที่มีความหลากหลายของสกิลสูงมากครับ บางครั้งอาจทำให้เลือกอับสกิลไม่ถูก เพราะเยอะแยะไปหมด
• ปลูกต้นไม้ได้ !!
• เป็นอาชีพที่มีความสามารถในการกลั่นไอเทม ( Purify ) เช่น เอา Fur มากลั่น ทำให้ขายได้แพงขึ้น
• เป็นอาชีพที่มีสกิลตัดเย็บ สามารถสร้างตั้งแต่ชุด ยันกระเป๋า (ที่มี Recipe นะ ^^)
• มีความสามารถในการทำอาหาร ข้อดีของอาหารคือน้ำหนักเบาและเพิ่มเยอะครับ
• มีความสามารถในการผลิตงานไม้ ตั้งแต่ไม้แบบง่ายๆ ยัน Furniture
• มีปราชญ์ต่างๆ มากมาย ตั้งแต่ ดอกไม้ ยัน ต้นไม้
• มีความสามารถในการผลิต ฃุดซ่อมไม้ ชุดซ่อมเสื้อผ้า
• มีความสามารถในการจัดสวน นั่นหมายถึง Flying Garden ในอนาคตครับ (ใช้เงิน 10m+ !!)
• วางกับดักได้ แต่ไม่เหมาะเท่าไหร่ครับ
• มีสกิล Healing Tree ซึ่งจะดีกว่าก่อกองไฟมากๆ เพิ่มก็มากกว่า และไม่ต้องใช้ของอะไร
• มีสกิลผลิตธนูครับ
• ถนัดการใช้ขวานมากกว่าค้อน เพราะสกิลสนับสนุกเยอะ รวมทั้งอนาคตสกิลของ Alchemist มีผลอีกด้วยครับ
• เลือดน้อยมากครับ ต้องยอมรับเลย
• เก็บเวลค่อนข้างยากถ้าเทียบกับ BP สายอื่น

เรื่องเสื้อผ้า ถ้าคิดจะขึ้นเหนือแนะนำให้ใช้ Warm Coat Lv27 ครับ (ซื้อได้ที่ชายแดนเหนือ) หรือจะซื้อเสื้อ Lv30 ที่เกาะไทนี่ก็ได้ครับ ส่วนกางเกง แนะนำให้ใช้เกราะขา Lv30 (แบบที่พวกอัศวินใส่กัน ซื้อได้ที่ดันน้ำแข็งชั้น 3 หรือซื้อกับคน) ซึ่งจะได้ไม่ต้องซื้อรองเท้าด้วย (def รวมสูงพอควร) แต่ถ้าไม่ชอบก็ไปซื้อกางเกงขาสั้น Lv30 ที่ ฟาอีส หรือ ขายาว Lv30 ที่เกาะไทนี่ ก็ได้ครับ
