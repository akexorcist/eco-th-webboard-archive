ข้อความในกรอบคำพูดนั่นบอกให้รู้ว่านั่นคือโลกของ Emil

แสดงว่ามีอย่างน้อยๆ 3 โลก(Titania,Dominion,Emil)

แล้วโลกที่เราเล่นๆ กันอยู่นับเป็นโลกอะไรล่ะ ที่แน่ๆ ไม่ใช่ไททาเนียหรือโดมิเนียนอยู่แล้ว

ไม่ได้สนใจอ่านเนื้อเรื่องมันเท่าไหร่ด้วยค่ะก็แค่วิเคราะห์ไปเท่าที่รู้

ถ้าที่เล่นๆ อยู่ตอนนี้เป็นโลก Emil ก็เป็นไปได้ว่าที่อาเจ๊ Tita พาไปดูอาจจะเป็นอดีตที่เคยเกิดสงครามมาก่อน แล้วตอนนี้มันกำลังจะเกิดขึ้นอีกครั้ง บลา บลา บลา

ก็เป็นไปได้นะ เพราะซากของหอแสงก็เหมือนเป็นผลจากสงครามอยู่แล้ว

Edit::

ต่อๆ กำลัง(มั่ว)เพลิน

ดูจากพวก DEM คิดว่าคงไม่ใช่คนธรรมดาอะ น่าจะเป็นพวกแอนดรอยด์หรือพวกที่ถูกสร้างขึ้นมากกว่า

ไม่แน่ว่า [พวกเขา] ที่ Tita พูดถึง อาจจะเป็นกลุ่มคนที่สร้างเหล่า DEM ขึ้นมาทำสงครามกับโลก Emil

ส่วนซากเครื่องจักรที่เห็นอาจจะเป็นไปได้ว่าเป็นของฝ่าย Emil ที่สร้างขึ้นมาเพื่อใช้ต่อสู้กับเหล่า DEM ก็ได้

สงครามคราวนั้น อาเจ๊ Tita ไม่ได้บอกว่าใครเป็นฝ่ายชนะ แต่ดูจากโลก Emil ยังอยู่ก็เป็นไปได้ว่าทางฝ่ายนั้นอาจจะแพ้ก้อได้

แล้วตอนนี้ ยุคสมัยของผู้เล่นเนี่ย มันกำลังกลับมาคุกคามอีกระลอกนึง แล้วจากที่บอกว่าทางมิติ ก็อาจจะรวมถึงทั้งสามโลกเลยก็ได้

เลยอาจเป็นเหตุผลที่ในโลก Emil ที่เราเล่นๆ กันอยู่เนี่ย มีเผ่าพันธุ์ของโลกอื่นๆ สามารถอยู่ได้อย่างอิสระ อาจจะเป็นเหมือนการเชื่อมสัมพันธ์เพื่อการต่อสู้กับกลุ่มพวกนี้ก็ได้ บลา บลา บลา

ชักหนุกแฮะ แต่พอเถอะ เริ่มจะมั่วหนัก = =
