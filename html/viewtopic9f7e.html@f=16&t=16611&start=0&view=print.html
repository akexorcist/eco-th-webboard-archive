ชุด Ranger Expoler ซื้อที่นี้ !!!! (ถ้ากระทู้นี้มีประโยชน์ ขอให้ผู้ดูแลระบบ ตั้งไว้เป็นหน้าแรกเลยก้ได้ครับ ไม่อยากให้ตก)


จากการที่มได้พบกับ Expoler คนนึง ได้ถามว่า ซื้อชุดมาจากไหน ?

คำตอบที่ได้คือ ซื้อจากNPC ชื่อ Ryu อยู่หน้าทางเข้า เมืองตะวันออก ดังรูป hock:



จากนั้นผมได้เดินทางไปที่ ทางเข้าเมืองตะวันออก เจอกับ Ryu ดังรูป



รูปต่อไปผมจะคุยกับNPC ตัวนี้ตามเสตป







ได้ความ ว่าเค้าไม่ยอมขายให้ แต่บอกว่าSafane ซักผ้าไม่เส็จซะที แล้วพอกดต่อ ก็บอกว่าไม่ให้คุยกับคน

แปลกหน้า น๊ะพี่ขอร้อง :x

ผมเลยเดินทางไป หา Safane ที่เมือง กลาง ทางด้านตะวันออก uptown


อันนี้คือ ผมคุยหลังจากทำเควสเอา ช่อดอกไม้10อันไปส่งแล้ว ก็เหมือนปกติ ตอนจะซื้อชุด






มันทำให้ผมงงว่า ตกลงเควสซื้อชุดเรนเจอร์ มันไปทำที่ไหน ถ้าใครมีคำตอบ เพื่อนๆ ที่ ตอบมาอย่างละเอียด และ ทำ

ให้เพื่อนๆ อีกหลายคนหายสงสัย ได้ ในกระทู้ นี้ ผมจะมีรางวันเป็นเงิน 10000 G ในเกม เป็นค่าตอบแทน(

สำหรับคนหน้าเลือดขอเงิน ถ้าใคใจดีก็โพสได้เลยจ้า)

ผู้รู้ ช่วยๆ กันตอบ หน่อยครับ ช่วยๆกันสร้างสังคมที่เป็นสุข ไม่ใช่สังคมแห่งความงก(เกรียนนั้นเอง)
