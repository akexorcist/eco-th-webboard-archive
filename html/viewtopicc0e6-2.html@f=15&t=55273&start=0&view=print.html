ความจริงประเด็น int กับ vit มันน่าสนใจมาก ยากจะตัดสินใจจริงๆ

แต่ผมจัด priority ให้ int มากกว่า ด้วยเหตุผลหลายประการ

ผมใบ้เป็นแนวทางอย่างง่ายนะ ไม่ว่าเลือก int หรือ vit ก็ตาม

อย่าทิ้ง stat อีกส่วนที่ให้ค้างที่หลักหน่วย


บางคนเลือก อัพ vit แต่ไม่เห็นความสำคัญของ int เลย ก็ปล่อยจมที่ 1 (ค่าเริ่มต้นของ dominion)
