คงหมายความว่า มีหลายๆสกิลเป็นพวกโบลว์ที่ใช้กะธนูไม่ได้มั้ง = =

โดยทั่วๆไป สกิลที่Archerควรอัพ คือ
1. Throw Create เพื่อลดจำนวนCatridgeที่เสียไป(เลเวล5มีโอกาส50%ที่ยิงไปไม่เสียธนู/กระสุน)
2. Bow Mas. ชีวิตนักธนูยังอีกยาวนาน อัพไว้เต๊อะ
3. Maskman Aura จำเป็นในช่วงแรกๆ หลังๆจะใช้เปิดก่อนสกิลสาดรัวเป็นบางครั้ง
แล้วก็ ข้ามไปสกิลจ็อบ30+โลด
4. L.avoid UP รึอะไรสักอย่างนี่แหละ จ็อบ30 (ชื่อสกิลเปลี่ยนใหม่ได้ทุเรศสิ้นดี) +ทั้งหลบทั้งแม่นระยะไกล ถือว่าควรอัพ
ถ้าคิดจะเล่นกันเนอร์แบบถาวร ก็เปลี่ยนอาชีพได้เลย รึไม่ก็อัพพวกHP/SP max/re บ้าง
แต่ถ้าจะเล่นสไตรยาวๆ ก็
5. Dual Arrow สกิลหากิน
หรือจะอัพBow Delay Cancelด้วยก็ได้
