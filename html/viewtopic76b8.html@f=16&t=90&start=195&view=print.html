- การฮีลตัวเองแบบสุ่ม ถ้าโชคดีก็จะได้ hp เพิ่ม ถ้าซวยก็จะเป็นการลด hp แทน(ซะงั้น)
- การฮีลคนในปาร์ตี้แบบสุ่ม ในที่นี้คือสุ่มคนโดนฮีลนะครับ
- โจมตีศัตรูโดยการหมุนสล็อตแมชชีน ดาเมจอยู่ระหว่าง 0-777
แล้วก็มีสกิลอื่นๆอีก เช่น
- ปาไพ่ทีเดียว 2 ใบ (เหมือนกับพวก double strafe ใน RO อะครับ)
- สกิลติดตัวเพิ่มการหลบหลีก

ไม่รู้จะต่อไงแล้วอะ ใครรู้ช่วยที แง้วๆ ><
