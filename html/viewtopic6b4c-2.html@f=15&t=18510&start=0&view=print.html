โดย ECO
เวลาร่ายจริง = เวลาร่ายที่ระบุ x ( 1 - CSPD/1000 )
CSPD = (DEX × 3) + floor[(DEX+63)/9]^2 + 129

คิดง่ายๆก็ 1 DEX จะร่ายไวขึ้น 0.3 %
และทุก 9 DEX จะไวขึ้นอีกราว 1.5-2.5 % แล้วแต่จำนวนที่อัพ

อ้างอิง : http://ec.gamedb.info/wiki/Status.html#CSPD
