คำตอบมันตีกันนะคับ ผมเชื่อใครได้เนี่ย?


ลองร่ายสกิล แล้วให้อีกฝ่ายวิ่งไปไกลๆ จนตกขอบจอสิครับ บอลวิ่งไปแล้วหายกลางอากาศ

คำอธิบายสกิลมันเป็นเพียงการไกด์ครับ อยากได้ข้อเท็จจริง แบบจริงๆ ต้องลองเองเลย พอดีผมเคยเจอกรณีดังที่ว่า ก็เลยแบ่งปันประสบการณ์น่ะครับ
ธรรมดาแล้วแม้ศัตรูมีปาป้าก็หลบไม่พ้นน่ะถูกครับ แต่ถ้าศัตรูวิ่งออกไปตั้งแต่เราร่าย มันก็มีสิทธิ์มิสได้ครับ เพราะถึงแม้ตอนร่ายจะต้องกดที่ตัวศัตรู แต่ตอนปล่อยสกิล ถ้าศัตรูตกขอบจอเราแล้ว บอลมันตามไม่ถึงครับ
