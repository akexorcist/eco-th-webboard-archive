- แล้วถ้าพระกดกระจก แต่สายบู๊ไม่ได้กดกระจก

อืม...จากประสบการณ์


ถ้าตัวบู๊กดจก ตัวบู๊ได้ exp + exp ที่เพิ่มตามผลของกระจกครับ

ส่วนตัวพระ ก็จะได้ exp แบบปกติ ( ได้ exp ตามจำนวนคนแชร์ในตี้เหมือนเดิม )


ส่วนกรณีว่า ตัวบู๊ไม่ได้กด แล้วตัวพระกดใช้จก มันก็คือๆกันอ่ะ

ตัวบู๊จะได้ตามปกติ ส่วนตัวพระก็จะได้ตามปกติ + exp ที่ได้เพิ่มจากกระจก


ก็คือเอาง่ายๆเลยว่า ถ้าเท่าไหร่ก็ + เพิ่มไปตามผลของกระจกน่ะนะ
มันไม่สนว่าใครตี ใครไม่ได้ตีอ่ะ เพราะกระจกมันเพิ่มให้โดยคำนวณจาก exp ที่ได้
