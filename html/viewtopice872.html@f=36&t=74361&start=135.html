รวมเลขเวกเตอร์แล้วเทียบกับตาราง


อย่างเช่น all nekomata AV เป็น Giant Killing | Knowledge of Iron Slasher
(จาก http://board.onenet.co.th/viewtopic.php ... 1&start=74)
(ในเกมขึ้นเป็น Critical UP | Level Difference Down ซึ่งยังผิดอยู่ มันใม่ใช่ AVแต่เป็น RA)
ตัวเลขด้านหลังคือเวกเตอร์ (ไพ่นี้ 15 และ9 ตามลำดับ)
เอา AV มาเทียบตารางดู RA
(ตารางหน้านั้น หรือหน้า http://board.onenet.co.th/viewtopic.php ... 1&start=38 ก็ได้)
ในกรณีนี้จะได้
Giant Killing => Critical UP
Knowledge of Iron Slasher => Level Difference Down

ซึ่งจะได้ค่าเท่าไหร่ต้องเอา AV มาบวกกันแล้วเทียบกับตาราง ในกรณีของคุณ
Giant Killing 15x3 (3ใบ) =45
Knowledge of Iron Slasher 9x3(3ใบ) = 27

ผลของการ์ดจะออกมาเป็น
Critical UP Lv2 => Critical +4%
Level Difference Down Lv1 => ลดการหัก S.HIT ในกรณีที่ตีมอนเวลมากกว่า 10%

ยาว แต่น่าจะทำให้เข้าใจบ้าง(?)

VI: Card index
Blank Iris Card EX
มาอีกแล้วกับการ์ด set ใหม่ Iris card พวกนี้หาซื้อได้เฉพาะใน Cash shop เท่านั้น ด้วยราคาที่...

แต่ด้วยความแตกต่างอันชัดเจน ระหว่าง EX และการ์ดธรรมดา การ์ดจากแคชพวกนี้มีศักยภาพสูงกว่าในทุกๆด้าน
ซึ่งคงจะมาเปลี่ยนสมดุลตลาดและการใ้ช้งานการ์ดต่อไปอีกในอนาคต
ดังนั้นผมเลยคิดว่า คงเป็นการดีที่จะให้เพื่อนๆได้รู้ถึงรายละเอียดของการ์ผม EX ไว้ก่อน โดย....
Set ที่ว่านี้ ถ้าเราเปิด Card Holder ดูมันจะไปอยู่ที่หน้า 1,3-5,7 และ 9 ครับ (มี 6 set นั่นเอง ณ ตอนนี้)
###คาดว่ามันจะค่อยๆทะยอยมาทีละชุด (อิงจาก wiki ญี่ปุ่น) ดังนั้นผมก็จะค่อยๆ(อู้)ลงทีละนิดเช่นกันครับ
เริ่มจาก
หน้า 1 นั้นคือ set ที่ได้จากการสุ่ม EX Blank Iris Card โดยไปแลกกับ Dreamer Hallelujah ที่ Downtown หรือที่ Card Laboratory
หน้า 3 คือ set ที่ได้จากการสุ่ม EX Blank Iris Card โดยไปแลกกับ Dreamer Hallelujah ที่ Northan Promnard
หน้า 4 คือ set ของตั๋วตุ๋น AA (Aquarian Age) ซึ่งจะผลุบๆโผล่ๆแล้วแต่ทางวันเน็ตเค้าแหละครับ
หน้า 5 คือ set ที่ได้จากการสุ่ม EX Blank Iris Card โดยไปแลกกับ Dreamer Hallelujah ที่ Iron city Upstairs
หน้า 7 คือ set ที่ได้จากการสุ่ม EX Blank Iris Card โดยไปแลกกับ Dreamer Hallelujah ที่ Tonka Island
หน้า 9 คือ set ที่ได้จากการสุ่ม EX Blank Iris Card โดยไปแลกกับ Dreamer Hallelujah ที่ Fareast Republic city
หน้า 10 คือ set ที่ได้จากการสุ่ม EX Blank Iris Card โดยไปแลกกับ Dreamer Hallelujah ที่ Eastor cape
