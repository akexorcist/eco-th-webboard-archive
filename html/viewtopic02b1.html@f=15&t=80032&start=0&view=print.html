เยอะเลยนะ แต่หลักๆก็คือ
Skill Samba JobLv. 8
เพิ่มพลังป้องกันของเป้าหมาย ที่อยู่ในขอบเขต
Skill Fusion JobLv. 24
เพิ่มพลังกายของเป้าหมายในขอบเขต หากเป็นผู้เล่นจะเพิ่ม STR VIT AGI หากเป็น PET จะเพิ่มพลังโจมตีทางกายภาพ การหลบหลีกระยะใกล้ และพลังป้องกันทางกายภาพ
Skill Pop JobLv. 27
เพิ่มสมาธิของเป้าหมายในขอบเขต หากเป็นผู้เล่นจะเพิ่ม MAG INT DEX ในกรณีที่เป้าหมายเป็น PET จะเพิ่มพลังโจมตีด้วยเวทมนตร์ พลังต้านทานเวทมนตร์ และพลังป้องกันเวทมนตร์
Skill Relaxation JobLv. 38
เพิ่มอัตราการฟื้นฟู HP MP SP ของผู้ที่อยู่ในขอบเขต โดยมีตนเองเป็นศูนย์กลาง ในระยะเวลาที่กำหนด
Skill Attract March JobLv. 40
บังคับให้เป้าหมายมาอยู่ที่หลังตนเอง แต่ไม่มีผลกับ Monster บางชนิด
Skill Oratorio JobLv. 43
ฟื้นฟู HP ตามธรรมชาติให้แก่ผู้ที่อยู่ในขอบเขตโดยมีตนเองเป็นศูนย์กลาง ในช่วงเวลาหนึ่ง
Skill Dead March JobLv. 50
ปล่อยคลื่นเสียงสร้าง Damage เป็นวงกว้าง พร้อมติดสถานะผิดปกติด้วย

ที่ใช้หลักๆก็คือสกิลพวกนี้อะ แต่จะอัพสกิลไหนก็ลองๆชั่งใจละคิดถึงประโยชน์ใช้สอยละกัน
