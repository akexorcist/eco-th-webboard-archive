Lugia เขียน:สำหรับ DEX นั้นค่า C.spd จะอัพทุก 9 จาก 0 ก็คือ 9,18,27,...
ส่วน mag จะมีสองส่วนคือการเพิ่ม min M.atk และ max M.atk
-min M.atk จะเริ่มการนับที่ 7 และขยับเพิ่มทีละ 8
ดังนั้นจึงเป็น 7,15,23,31,39,47,55,63,71,79,...
-max M.atk จะเริ่มนับที่ 7เช่นกันและขยับทีละ 6
ดังนั้นจึงเป็น 7,13,19,25,31,37,43,49,55,61,67,73,79,...

และถ้าสังเกตดีๆ จะมีจุดร่วมของการเพิ่มทั้ง max และ min(สีแดง) เป็นฟังก์ชันง่ายๆคือ
24n+7 เมื่อ n=0,1,2,...
แทนค่าลงไป จุดร่วมคือ 7,31,55,79,103,...

ใครไม่มีอะไรทำ อยากคิดจุดบรรจบของ dex,mag ดูก้อได้เน้อ :lol:

จบการรายงาน อัพกันตามสบายครับผม

Lugia เขียน:ค่าของ vit ช่วยเพิ่มได้สามอย่างคือ hp,def และ M.def
HP จะเพิ่มทุกๆ vit ที่เพิ่มขึ้น 5 จากค่า 0
ดังนั้นจะเป็น 5,10,15,20,25,30,35,40,45,50,55,...
Def จะเพิ่มทุกๆ vit ที่เพิ่มขึ้น 3 จากค่า 0
ดังนั้นจะเป็น 3,6,9,12,15,18,21,24,27,30,33,36,39,42,45,48,51,...
M.Def จะเพิ่มทุกๆ vit ที่เพิ่มขึ้น 3 จากค่า 1
ดังนั้นจะเป็น 4,7,10,13,16,19,22,25,28,31,34,37,40,43,46,49,52,...

ของผมใช้จุดร่วม hp,def(สีแดง) เป็น 15,30,45,60,...(ขยับทีละ15เริ่มที่0) คงไม่มีใครอัพขนาดนี้มั้ง
ถ้าจะเอา hp,M.def(สีน้ำเงิน) เป็น 10,25,40,55... (ขยับทีละ15เริ่มที่10)
และจุดร่วมของ Def.M.def (สีเขียว) เป็น อินฟินิตี้(อนันต์) เพราะไงๆมันก็ห่างกัน 1 ---แล้วตูใส่สีเขียวทำไมหว่า

ดังนั้นหากใครคิดการณ์ไกลจะทำจุดร่วมสามละก็ คงไกลจริงๆล่ะ เพราะอัพไปถึง อินฟินิตี้นู่น เหอๆ 8)
