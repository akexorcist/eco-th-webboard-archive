Cherry Jam ใช้ Cherry กับ Sugar เจ้าค่ะ
ใช้สกิลcooking เอาไปให้ป้าร้านตัดเย็บทำให้นะ (เช่น ป้าบนอัพทาวก็ได้)
ส่วน sugar ใช้ Cold Candy สกัดโดย Item refine (ตาลุงที่เปิดกล่องจะมีสกิลนี้)
ส่วน coldcandyลองตี amber jellyหาดูนะ



เอาผลไม้(อะไรก็ได้)กับน้ำตาลไปทำก็ได้เชอรรี่เเยมเหมือนกัน
(ถ้าจำไม่ผิดเมื่อก่อนเราเคยทำแต่นานมาแล้ว)
