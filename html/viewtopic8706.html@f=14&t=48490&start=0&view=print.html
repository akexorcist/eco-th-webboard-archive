ถ้าอยากเล่นปืนใดปืนหนึ่งระหว่างปืนสั้นกะปืนไรเฟิล

ก้ต้องถามตัวเองก่อนว่าชอบยิงเรว หรือยิงไกล

ถ้ายิงเร็วก้ปืนสั้น ยิงไกลก้ปืนไรเฟิล

แต่โดยส่วนตัวชอบไรเฟิลมากกว่าเพราะความแรง

ก้พอๆกะปืนมือเดียว แต่ระยะยิงไกลกว่าและ ความเร็วเรากว่ามีสกิล

Gun Delay Cancleมาช่วย และส่วนมากGunnerจะยัดสกิลซะเปนส่วนมากถึงมากๆๆ
