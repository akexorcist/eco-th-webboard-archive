ชื่อ :ซิกครอส โวล์ฟสเตน ไชนีไวส์ (SiegX volfstein schneeweiß)

เพศ : ชาย

อายุ : 17 ปี

เผ่า : อีมิล

อาชีพ : เบลดมาสเตอร์

อาวุธ : ดาบคาตานะสีขาว ชื่อ เทนกะ(天花 - หิมะ)เวลาฟันจะมีเกล็ดหิมะกระจายออกมาจากตัวดาบ

ความสามารถ : เป็นนักดาบที่รวดเร็วมาก สามารถเคลื่อนย้ายในพริบตาได้ ชักดาบได้รวดเร็วปานเป็นแขนของตัวเอง
มีท่าไม้ตายประจำตัวอยู่ 3 ท่า
- ชิรายูคิ โนะ ไม (ระบำหิมะขาว) เป็นท่าที่ฟันโดยการหมุนตัวเป็นวงกลมทำให้เกิดพายุหิมะ(ตัวดาบเวลาฟันจะมีเกล็ดหิมะกระจายมาอยู่แล้ว)พัดเอาศัตรูกระเด็นขึ้นไปบนฟ้า
- มุเก็นคาคุซัน (ผ่ามุมไร้จุดจบ) เป็นการฟันศัตรูจากทั่วทุกทิศอย่างรวดเร็วปานแสง มักจะใช้คอมโบต่อจากท่าแรก เพราะศัตรูอยู่กลางอากาศมักป้องกันไม่ได้
- เก็กคะ โนะ ราเซ็น (เกลียวบุปผาจันทรา) เป็นท่าที่โจมตีจากฟ้า โดนการหมุนตัวควงสว่างลงมาแทงเป้าหมายที่อยู่ข้างล่าง

อื่นๆ : เป็นคนนิสัยซื่อบื้อ ไม่ค่อยรู้เรื่องรู้ราว ตามคนอื่นไม่ค่อยทัน โดนหลอกโดนแกล้งได้ง่ายมาก แพ้น้ำตาและการออดอ้อนเป็นที่สุด ขี้เกรงใจ มักตอบตกลงเพราะเกรงใจเสมอ แต่ในสิ่งที่ตนคิดว่าไม่ถูกก็มักจะปฏิเสธโดยไม่รักษาน้ำใจอีกฝ่ายเช่นกัน
โดยปกติเป็นคนเกลียดการต่อสู้ เป็นไปได้จะไม่ชักเทนกะเลย แต่ถ้าสถานการณ์มันบีบบังคับก็จำต้องชักดาบออกมาฟันจริงๆ พอจับดาบสมาธิจะสูงทำให้เคลื่อนไหวได้รวดเร็วมาก เป้าหมายมีเพียงเอาชีวิตศัตรูเท่านั้น

อดีต ฝึกวิชาดาบมาจากสำนักดาบทางตะวันออกและได้รับสืบทอดดาบชื่อ "เทนจิเซย์ฮะ(พิชิตฟ้าดิน)" มา ต่อมาเมื่ออกจากสำนักได้ใช้วิชาดาบต่อสู้เพื่อหาเงิน เพราะพื้นฐานเป็นเด็กกำพร้า หาเงินจนหน้ามืดตามัวหลงลืมความเป็นมนุษย์ไป กลายเป็นอาวุธมนุษย์ที่ทำงานให้กับราชวงศ์หนึ่ง คอยแต่ฆ่าคนตามคำสั่งเพื่อเงินเท่านั้น และถูกตราหน้าว่าเป็นคนทรยศที่ทรยศต่อหลักการและวิถีทางแห่งดาบของสำนัก
