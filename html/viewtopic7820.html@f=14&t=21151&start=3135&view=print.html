รู้อยู่แค่ไม่กี่อาชีพ

พ่อค้า ไรออตแฮมเมอร์ คิด dex int ในการตีโดน ไม่100% เหมือนตอนนี้
(แว่วๆ มา ปรับดีเลย์หลังใช้ เป็น3วิ อันนี้ไม่แน่ใจ ได้มาจากไหนจำไม่ได้แล้วด้วย)

ส่วนของไนท์ เห็นปรับ 2 สกิล

1 คือ สกิล ช๊อคเวฟ ให้ ดาเมจไม่หาร แต่ ดาเมจสกิล เหลือ 120% มั๊งนะ

2 คือ สกิล โฮล ชิล สกิลที่ทำให้ เป้าหมายและเรา เคลือนที่ไม่ได้ แต่เป้าหมายต้อง ติดกำแพงอยู่ ให้ใช้ sp มากขึ้นอีกเท่านั้น

ไร้ประโยช จริงๆ พะผ่า = ="
