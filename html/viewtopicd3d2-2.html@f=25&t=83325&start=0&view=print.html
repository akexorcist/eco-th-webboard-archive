และเจ้าหุ่นนั่นแหละที่คุยตามอีเว้นท์แล้วไม่เกิดอะไร

- เนโกะมาตะที่ทำไปแล้วมี โมโมะ ยามาบูกิ สุมิเระ อากาเนะ อันสึ คุรุมิวากานะ

- เนโกะที่ใช้ดำเนินเควสคือเนโกะโมโมะ ตัวอื่นเข้าคลังหมด

- ของที่ใช้ดำเนินเควส คริสตันทั้ง 4 สี ฮาร์ทรูบี้ คอตตอนริบบิ้น ด้าย ผ้า ส่วนบอดี้ของหุ่นประกอบเข้าด้วยกันเรียบร้อยแล้วค่ะ
