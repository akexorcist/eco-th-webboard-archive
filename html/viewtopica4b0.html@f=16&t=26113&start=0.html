รายชื่อนักพนันที่โดนบังคับให้มาเข้าร่วม (รับเฉพาะตัวละครหญิง)

===== สเตตัสเรามีดังนี้ ======
Str 94+6 << เพิ่มค่าพลังโจมตีของไพ่
Dex 8+13 << เพิ่มความแม่นยำของการใช้มือต่อย
Int 46+13 << เพิ่มความแม่นยำของไพ่ และค่าพลังโจมตีขั้นต่ำ
Vit 32+9 << เพิ่มพลังป้องกันและค่าพลังชีวิต
Agi 46+16 << เพิ่มความเร็วในการดจมตี และอัตตราหลบหลีก
Mag 6+5 << เพิ่มค่าพลังเวทมนต์ และความแรงของการฮิล
===== สกิลที่เราอัพมีดังนี้ =====
Throw Mastery << สกิลจำเป็นสำหรับสายที่ใช้ไพ่เป็นอาวุธ
Blackleg << มีประโยชน์มากสำหรับสายไพ่
Random Healing << สกิลยอมเยี่ยมที่สุดของอาชีพนี้ =0=
Lucky << มีผลช่วยผลสกิลเวทมนต์ถ้าดวงดีนะ
Continue Throw << สกิลเก็บเลเวลหลักของสายไพ่
Three Seven << ถ้าถามว่าอัพมาทำไมก็ตอบได้ว่าอัพมาให้คุณถามนั่นล่ะ
Double Up << เพิ่มความรุณแรงสกิลเป็น 2 เท่าใช้ได้เฉพาะสกิลของนักพนันบางสกิล
===== แนวทางการอัพสเตตัส =====
Str เยอะๆ สำหรับผู้ที่ชอบความรุณแรงของการโจมตีด้วยไพ่
Int สำหรับคนที่ต้องการเพิ่มความแม่นยำและต้องการให้ดาเมจสูงบ่อยๆ
Agi สำหรับความเร็วในการใช้สกิล และอัตตราหลบหลีก
Mag สำหรับคนที่ต้องการใช้ฮิลในการเก็บเลเวล
===== สกิลแนะนำ =====
Ramdom Healing Lv 3
ฮิลนี้ดีอย่างไร
ความสามารถของสกิลนี้คือ การฟื้นฟูค่า hp mp sp แบบแรนดอมซึ่ง Hp จะฟื้นฟูแน่นอน
ท่าสกิลประสบความสำเร็จ ส่วน Mp Sp จาฟื้นฟู แบบแรนดอม โดยจะเพิ่มมากขึ้นเมื่อค่า Mag เยอะ
ข้อเสีย ไม่สามารถใช้เวลาใกล้ตายเพราะ อาจจะทำให้ตายเร็วขึ้นเนื่องจาก
ท่าสกิลนี้มีการผิดพลาด จะทำการลด Hp ของผู้ใช้ตามค่า Mag ยิ่งมากยิ่งลดเยอะ[/img]

ความสามารถของสกิลคือ
การเรียกสลอตแมคชีนออกมา 3 ตัวแต่ละตัวจามีเลข 1 3 5 7 อยู่
