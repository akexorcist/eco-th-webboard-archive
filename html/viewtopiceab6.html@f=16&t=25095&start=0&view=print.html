ผลลัพธ์ Passive Skill เมื่อสวมใส่หอกคฑาสองมือแล้วจะเพิ่มค่า Min Attack มีผลซ้อนกับ Mace Mastery


คำว่า มีผลซ้อนกับ Mace Mastery คือไรครับ


ภาษาไทยวันนี้ ซ้อน เป็น กริยา แปลว่า วางทับกัน แสดงว่า Mace Mastery จะไม่มีผลเพราะ Two-Hand มันจะมาซ้อนทับ ใช่หรือเปล่า

มีผลร่วมกัน


ซึ่งถ้าใช้ Mace 2 มือ ก็จะได้ผลของทั้ง 2 สกิลนี้

แต่ถ้าใช้ Mace มือเดียว ก็จะได้ผลแค่ Mace Mastery เท่านั้น


สมมติ

ไม่อัพสกิลใดๆ เลย มินแอทแทค อยู่ที่ 150


- ถ้า อัพ Mace Mastery แล้วใช้ Mace มือเดียว จะได้ มินแอทแทค เป็น 180


- ถ้า อัพ Two-Hand Mace Mastery แต่ใช้ Mace มือเดียว ก็ยังจะได้มินแค่ 150


- ถ้า อัพ Mace Mastery และ Two-Hand Mace Mastery ด้วย แล้ว แต่ใช้ Mace มือเดียว จะได้มินเป็น 180

- ถ้า อัพ Mace Mastery และTwo-Hand Mace Mastery ด้วย และใช้ Two-Hand Mace Mastery จะได้มินถึง 230


พอจะเข้าใจป่ะครับ ผมก็อธิบายไม่ถูกอ่ะ

แต่ผลมันจะแสดงร่วมกันเมื่อ ใส่ Two-Hand Mace

แต่ถ้าใส่ Mace มือเดียว มันจะแสดงผลแค่ Mace Mastery เท่านั้น



คือมัน + ทับให้น่ะ ไม่ใช่ไปแทนของเก่า
