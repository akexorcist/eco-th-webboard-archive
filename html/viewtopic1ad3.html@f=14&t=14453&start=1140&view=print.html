-ขอถามผู้เชี่ยวชาญการลอบสังหารทุกท่าน-

1. สกิลที่ใช้ระหว่าง possessionไม่ได้ มีสกิลใดบ้างคับ แบ่งเป็น
1.1 เราถูงสิงอยู่
เท่าที่รู้มี poisonreate 1 2 3 / จักจั่นลอกคราบ รึป่าวคับ

1.2 เราสิงผู้อื่นอยู่
เท่าที่รู้มี Hiding ตอนไปสิงเพื่อน จะให้เพื่อนดำดินไม่ได้คับ แต่มีคนสิงเราแล้วเราดำดินได้นะ
แล้วก็พวกสกิลโจมตีระยะประชิดตั้งแต่Blow-->Continue th ใช้ไม่ได้เพราะไม่มีมือไปตี(เป็นผีอยู่นีนะ) SummerSult,walkaround ก็ไม่ได้ รึป่าวคับ

2. สกิลholy featherของdruidที่เพิ่มอัตราฟื้นฟู นี่ใช้ตอนถูกสิงได้ป่าวคับ

3. ถ้าเควสพังมีดสุดทนทานนี่เราเอาชุดซ่อมแซมมาซ่อมให้ความทนทานมันลดลงได้ป่าวคับ

4. สกิลสาย poisonreate ที่ใช้แล้วเราติดพิษนี่ใช้ poison resist ของ vates กันได้ป่าวคับ

5. สกิลคอมมานโดที่ +30% human aviod แล้ว % นี่คิดจากอะไรอ่ะคับ avoid เราหรือป่าว แล้วถ้า human ยิงเวทนี่เราจะหลบได้เพิ่มหรือป่าวคับ

ขอขอบคุณผู้มีอุปการะทุกท่านด้วยเกียรติของลูกเสือสำรองคับ
