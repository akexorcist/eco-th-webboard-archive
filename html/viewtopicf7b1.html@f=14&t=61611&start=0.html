กีกี้มาตอบให้อีก
(ตอนนี้เปงกันเนอร์แระนะ...แหะๆ)

ถ้าพูดถึง skill หมู่นะ
Striker จะมีแค่สกิวเดียวคือ
Blast Arrow
- Blast Arrow ยิงแบบ 3x3ช่อง แบบล๊อคเป้าหมายเดี่ยว
- ส่วนใหญ่แล้วยิงไกลๆ ม่อนมันก็ไม่อยู่ติดๆ กันให้เรายิงโดนทุกตัวอยู่แล้วอ่ะ
- ถ้าลากมาม่อนมารอบตัว กดยิงก็นึกถึงตอนใช้ Riot อ่ะ ก็โดนแค่สามตัวหน้า กับสองตัวข้าง
- มีม่อนมากๆ ก็หาร damage ไป
- ต้องอัพ skill "Strike Arrow" ของ Archer มาด้วย ไม่งั้นก็ไม่แรง
- ประหยัดลูกธนู เพราะยังไงก็ถือว่าเป็น 1 ดอก
- ความแรงของสกิวนี้ที่เลเวล 5 อยู่ที่ 410% (จากวิกิ)
- ข้อดีของ Blast ก็คือ "ไม่มีดีเลย์" สามารถซ้ำได้เลย

Gunner มีสองสกิว คือ Bullet Dance กับ Shot
Bullet Dance
- Bullet Dance ยิงแบบ 5x5 ช่องรอบตัว ไม่ต้องล๊อกเป้าหมาย
- ต้องลากมาก่อนแล้วกดถ้าจะยิงเป็นหมู่
- ลากมาแล้วกด ก็โดนทุกตัวรอบตัวเราเลย โดนตัวไหนมากน้อยไม่รู้อ่ะ = ="
- มีม่อนมากๆ ก็หาร damage เหมือนกันกับ Blast
- ใช้ลูกกระสุน 8 นัด
- ความแรงที่เลเวล5 อยู่ที่ 200% ต่อนัด (หมายความว่า ถ้าเป้าหมายเดี่ยว และ 8นัด ไม่มี miss ก็รับไปเต็มๆ 1600%)

Shot
- Shot ระยะยิง 3ช่องด้านหน้าตัวเองทั้งแนวตรงและทะแยง (นับไปสามช่อง) แบบนี้
　■■■■■■■　　　■
　　■■■■■　　　　■■
　　　■■■　　　　　■■■
　　　　☆　　　　　　☆■■■ (credit : รูปจากวิกิ)
- กด skill แล้วออกเลย...หันไปทางไหนก็ยิงทางนั้นแหละ ไม่มีล๊อกเป้าหมาย
- เป้าหมายทุกตัวที่อยู่ในระยะ skill จะโดนหมด
- ไม่มีการหาร damage โดนแรงเท่ากันทุกตัว
- ใช้กระสุนนัดเดียว (ประหยัด)
- ใช้ลากก็ได้นะ ยิงๆ ลากมา....ถอย แล้วกด shift คลิกหันไปทางม่อนที่เดินตามมา แล้วกด!
- ความแรงที่เลเวล5 อยู่ที่ 550%
- ข้อดีก็คือ "ไม่มี delay" สามารถซ้ำได้เลย


โดนรวมก็ชัดเจนอ่ะ... Gunner มี skill ที่แรงกว่า
Striker มีจุดเด่นคือความเร็ว แทบไม่มี delay ให้เห็นเลย

สรุป
เล่น Gunner ถ้าสไตล์เป็น โหด~ ขี้เกียจบังคับกดหลาย skill ต่อเนื่อง
เล่น Striker ถ้าชอบยิงหลายๆ skill เอาคลิกมันส์ กดมันส์...~

จากที่เล่นมาบ้างแล้ว เค้าว่าความแรงถ้านับเป็นเวลาเลยนะ
ในเวลาที่เท่ากัน ทั้งสองอาชีพ ทำดาเมจได้พอๆ กันแหละ
Gunner ยิงสกิวเดียวดาเมจสูง...แต่มีเวลาร่าย กับ delay
Striker ยิงได้หลายสกิวต่อเนื่อง กดซ้ำๆ สองทีก็ได้ damage พอๆ กันอ่ะ

ขึ้นอยู่กับ def ของเป้าหมาย...
ถ้า def เยอะๆ - คิดเป็นเปอร์เซ็นก็เห็นชัดๆ ว่า Gunner ได้เปรียบ
ถ้า def น้อยๆ - ในเวลาที่เ่ท่ากัน Striker จะทำ damage ได้สูงกว่า
