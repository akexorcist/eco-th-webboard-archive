ไม่ว่าจะทำยังไง ซอก็ร่ายเร็วสู้เอเลไม่ได้ เพราะเอเลมี speed enchant -0-

มันก็แก้ทางกันได้หลายแบบแหละ อย่าไปคุยมันเลย เรื่อง 1-1 อะ

เอเล = สายเน้นพลัง วัดกันทีความเร็ว speed enchant เส็ดแล้วก็พายุหมุนๆๆ

ซอ = จ้าวเทคนิค เทคนิคทุกอย่างมีทุกรูปแบบ มากมายจริงๆนะ

เอาเทคนิคคร่าวๆที่ผมพอจะรู้ตอนนี้นะ

- invis + scroll (Mag - stat อะไรก็ได้)

- perfect wall ขวาง + teleport เพิ่มระยะ + invis + scroll (Mag - dex - แล้วแต่)

- สาป + ยิง (Mag = dex = int)

- E.flare + หนีด้วยทุกวิถีทาง ถ่วงเวลา (Mag int dex ใช้กับไนท์อึดๆไม่ก็แม่ค้าได้ดี ถ้ามันไม่มีพระนะ)

มากมายก่ายกอง

ถ้า 1-1 กะเอเลแบบไม่มีเวลาเตรียมตัวก็ใช้วิธี perfection wall ขวางระหว่างกลางก่อนก็ได้ แล้วค่อยเตรียมสกิลของเราไป (เปนการซื้อเวลาได้นิดหน่อย)
