ถ้าเวลอยู่แถว ๆ ฟาอีส ตรงโมโมแพลน อาหารที่เบา ๆ เพิ่มเลือดก็ โอเค( นิดหน่อย ) หาได้จากแถวนั้นหมดเลย เช่น

1 carrot stick <- น้ำหนักเบา กดใช้ปุ๊บกินปั๊บ ทำจาก Carrot 1 อันเอาไปทำกับข้าวกะป้าแถวนั้น =w= เหมือนจะใช้ตัง 0g มั้ง แครอทตีเอาจาก Vega หรือ Heaven rebecca ก็ได้

2 mix juice <- หนักนิดหน่อย แต่เพิ่มเลือดเยอะ กดใช้ปุ๊บกินปั๊บ ทำจาก Carrot + Apple + orange + mineral water เหมือนจะใช้ 0g อีกเช่นกัน Carrot หาจากม้า 2 ตัวเหมือนเดิม แอปเปิ้ลกับส้ม ตีต้นไม้ในฟาอีส น้ำแร่ก็ตีคริสตัลในโมโมเอา

3 smoke ham <- เบา แต่ต้องรอกิน เพิ่มเลือด 100 กว่า ๆ ต้องใช้ purify กับคนทำของในอีสเตอกับฟาอีส ทำจาก meat ตกจากไก่ Cococo กะ ไก่สีชมพูอีกตัวงิ
