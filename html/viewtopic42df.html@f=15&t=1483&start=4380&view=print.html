สกิลหลายHit จะได้รับผลของZenเมื่อ ร่ายสกิลอื่นๆระหว่างที่สกิลอันเก่ายังแสดงผลอยู่ ครับ

เช่น
กดZen ใช้Aqua Wave แล้วก็ไม่ได้ร่ายสกิลอะไรอีก : Aqua Wave ไม่ได้รับผลของZen
กดZen ลงLava Flow แล้วกดใช้สกิลอื่น ขณะที่ลาวายังไม่หาย+Zenยังอยู่ : ลาวาได้รับผลของZen จนกว่าสกิลที่ร่ายอยู่จะร่ายเสร็จ / ลาวาหายไป

ที่เข้าใจว่ามีผลกับHitท้ายๆ น่าจะเป็นเพราะ พอใช้Zenแล้วคลื่น มันร่ายลูกใหม่ได้ทั้งๆที่ลูกเดิมยังไม่หาย Hitของลูกเก่าที่อยู่ในระหว่างร่ายลูกใหม่ ก็จะได้รับผลของZen

(ง่ายๆก็คือ ไม่ใช่ได้รับผลของZenเพราะเป็นHitท้ายๆ
แต่ได้รับผลเพราะเป็นHitที่อยู่ระหว่างการร่ายสกิล)
