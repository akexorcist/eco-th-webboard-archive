วิทีรีฟายเราทำเหมือนnimbleเยย แต่ไม่ได้ทำตั้งแต่ซาก้านี้มา วุ่นวายกะอย่างอื่นมากมาย

ตี1ครึ่งเข้าไปเล่นกะเพื่อน ไปตีบอสของวาซาบิ
เอามิกไป74 พระ1(ตัวเราให้เพื่อนกด) ชาวนา1(เราอีก) หอก1(เพื่อน)ดาบ1(ตัวเพื่อนเรากด)
จัดระบบทุกคนสิงหอก พอโดนรุมตัวหอกจะใช้พวกท่าเกราะทั้งหลาย+ม้วนสกิลเอิธชิลที่ซื้อมาแล้วก็เปิดจอพระฮิวอย่างเดว
พอเจอใบ้ก้อปั้มมิกเอา ส่วนเราใช้ฟาแลงหยุดมอน(ทำให้ตีสบายขึ้นเยอะมากๆเลือดแทบมะเสีย) แล้วใช้ดาบสกิลหมู่ สลับไปมา2ตัว
ทดลองกะวาซาบิ6-8ตัว สรุปตีสบายมากๆ เลยเดินหาบอสกาน
พอเจอบอสก็ลุยปรากฏว่า พอลูกกระจ๊อกตายหมด บอสมานวาปหนีช้านนนน
เดินหาทั่วแมพยังไม่เจอ เกิดอาการเครียด ล้างบางวาซาบิทั้งแมพ ผลคือได้ทัมๆมาเกือบร้อยชิ้น(ไม่รวมของอย่างอื่นที่ดรอป) เหลือมิก50+ แต่ไม่ได้เอาชาวนาชนเลยไม่มีเหรียญเงินสักเหรียญ ส่วนวาซาบิจากชุมๆกลายเป็นเดินหาก้อไม่มี-0- และแล้วเราก็ได้ที่เกบเวลที่ใหม่ เดินลากเเปปเดว6-8ตัว(ลากได้ไม่เดือดร้อนใคร) ได้ทีครึ่งเปอประหยัดยาด้วยเพราะทุกตัวสิงหมด ยกเว้นหอกที่ปั้มโทนิกนิดหน่อย
