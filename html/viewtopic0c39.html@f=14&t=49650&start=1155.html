เหมือนเดิมอาจ่ะ - -

ถ้ามี บัพ ชนิดเดียวกัน ซ้อนขึ้นมา

ผลที่ได้คือ ความสามารถที่เพิ่ม และ เวลา ถูกเปลี่ยน เป็นของอันที่ดีที่สุด

Zilenia เขียน:คิดจาก Base จ้า

ละก็จากที่พูดมานั้น เป็นไปไม่ได้

เนื่องจาก Solid Body ก็เป็นบัพที่ให้ผลเพิ่ม Def ชนิดหนึ่ง

เพราะฉะนั้น จริง ไม่มีผลซ้อนทับกับบัพเพิ่ม Def ชนิดอื่น

เพราะฉะนั้น จะเกิด ผลเพิ่ม Def ของอันที่ดีที่สุดนั่นก็คือ ของ วิ จร้า > <

พูดง่ายๆ กะคือ ถ้ามี 50 กดใช้เพียวๆ จะเป็น 56 (50+6)

แต่ถ้าระหว่างนั้นมี ซอหรือเซจ มาบัพ ก็จะเป็น 85 (50+35 เพิ่มราวๆนี้มั้ง) >>> ดีวาย + Def 19 และ Mdef 35 ครับ

ปล. ผลของเพิ่ม Def จะถูกเปลี่ยน แต่ผลของสภาวะ Solid Body ยังอยู๋น๊า
