คาดว่าจะเป็น % นะครับ
เพราะหลังจากที่ไปเดินเล่นแถวเมืองเหนือให้ Magician ยิงพิษเล่น

ตอนแรกไปเวล 35
ตอนหลังไปเวล 50

พบว่า มันลดไม่เท่ากัน แต่ถ้าคำณวนเป็น % มันจะเกือบเท่ากัน


พิษ เกมนี้ แบ่งเป็น 2 ประเภท คือลดเป็น หน่วย กับลดเป็น %

ส่วนมากลดเป็น % จะพบได้กับพิษ จากมอน

และ

ลดเป็น หน่วย จะพบได้กับ พิษจากคน (ความแรงน่าจะมาจากเวทย์)

แต่ว่าข้อดีข้อเสีย ก็พอมีอยู่บ้าง

นั่นคือ พิษจาก คนจะทำให้เราตีเบาอย่างมหาศาล ในขณะที่พิษจากมอน (บางตัวอาจ) ลดไม่มาก
