Mag Hit - ทำให้เเมวใช้เวทย์เเบบรู้จักกาละเทศะมากขึ้น เช่นเจ้าของจะตายก็จะมีโอกาสฮีลเจ้าของมากขึ้น ไม่ใช่ฮีลตัวเอง

Matk - ความรุนเเรงเวทย์ เวทย์ Heal จะเห็นผลได้เด่นชัดที่สุด

ทั้งหมด ตัดสินจากประสบการณ์ ความรู้สึก และเซ็นต์ส่วนตัว ที่ใช้เเมวมาตลอดตั้งเเต่เปิด Server ใหม่ๆยันปัจจุบัน จริงเท็จมีอาจรู้ได้ เเต่ผมเชื่อว่ามันเป็นเช่นนี้
