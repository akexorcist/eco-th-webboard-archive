โดย NETIX
มาเรียกเหล่าอัลม่า ขึ้นมาบนสวนลอยฟ้าของคุณครูอามิสกันเถอะ

สมุดพก 「生徒手帳」 สามารถเรียกได้แค่อัลม่าในเดือนของชื่อสมุดนั้น เท่านั้น
EX event tickets 「ＥＸイベントチケット」 สามารถเรียกอัลม่าได้ทุกตัว



มาเรียกภูตพิทักษ์กับเนโกะมาตะ ขึ้นมาบนสวนลอยฟ้ากันเถอะ

สมุดพก 「生徒手帳」 สามารถเรียกได้แค่ภูตพิทักษ์หรือเนโกะมาตะในเดือนของชื่อสมุดนั้น เท่านั้น
EX event tickets 「ＥＸイベントチケット」 สามารถเรียกภูตพิทักษ์หรือเนโกะมาตะได้ทุกตัว
* 1 ชิ้นเรียกได้แค่ 1 อย่าง ถ้าจะเรียกทั้งภูตพิทักษ์และเนโกะมาตะต้องใช้ 2 ชิ้น *



สมุดพก 「生徒手帳」 ได้จากไหน?
สมุดพกนั้นจะได้จากอัลม่า ถ้าทำอีเวนท์อัลม่าผ่านไปแล้ว
เมื่อเปลี่ยนอีเวนท์อัลม่าใหม่ จะสามารถรับ สมุดพก 「○月の生徒手帳」 จากอัลม่าได้ 2 เล่ม
โดย ○ จะกำหนดเลขเดือนของสมุดพก เช่น สมุดพกของเดือน1 「１月の生徒手帳」



EX event tickets 「ＥＸイベントチケット」 ได้จากไหน?
ได้จากการเปิดตั๋วได้ขยะหรือสกอเวท จะแถมมาให้
