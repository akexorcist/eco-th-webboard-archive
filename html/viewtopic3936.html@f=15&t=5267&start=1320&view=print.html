Criticism เขียน:ควรอัพ สกิลบัฟ Def และ M.Def รึเปล่าครับ
ขอความเห็นแยกเป้นแต่ละสกิลเลยนะครับ

ผมเล่นจนเป็นซอร์ จ๊อบ 38 แล้ว ตอนเป็น วิ เล่นจ๊อบ 50

ยังอัพไปไม่กี่สกิลเองครับ ดองเม็ดไว้


ขอบคุณสำหรับคำตอบครับ



ถึงแม้ว่าจะมี Divine Barrier ให้ตอนเป็น Sorcerer แต่ผมว่าอัพไว้ก็ดีครับ

เพราะว่าค่าที่ +จาก Skill พวกนี้จะทบกันได้ ทำให้ค่า Def/Mdef สูงกว่าใช้ Divine เดี่ยวๆ ครับ

คนส่วนใหญ่จะไม่อัพบัพ Def เดี่ยวเพราะว่าพอเป็น Sorcerer แล้วจะได้ Solid Aura ซึ่งทำให้การโจมตีกายภาพเข้า 0 มา ค่า Def เลยไม่มีความหมายครับ

แต่คนส่วนมากมักลืมไปว่า มอนบางตัวในเกมนี้ (เช่น DEM) มันตีรัวมากจน Solid Aura แตกได้ในไม่ถึง 3 วินาที ซึ่งจะอันตรายมาก หากถูกรุม 2 ตัวขึ้นไป

ซึ่งตรงนี้หากเรามี Energy Shield อาจจะช่วยได้บ้างเวลาเกราะแตก ทำให้ลดความเสียหายลงได้จนอาจจะแค่สาหัส แต่ยังไม่เสีย 3 เปอร์ ก็คุ้มนะครับ

ส่วน M.Def เดี่ยว จะเป็นตัวหลักในการหากินของท่านเลยล่ะครับ ในการเก็บเลเวลกับมอนยิงเวททั้งหลาย เพราะ Solid Aura ของ Sorcerer ไม่กันเวทนะครับ ฉะนั้นก็ควรอัพไว้ครับ จะได้เจ็บน้อยลงหน่อย
