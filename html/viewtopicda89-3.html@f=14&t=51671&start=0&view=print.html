P.a.n.g เขียน:คือว่า ตอนนี้เราเล่น scout เวล 40 เองอะคะ
อยากรู้ว่า..
1. status ควรอัพอะไรบ้าง
(ตอนนี้อัพ str, dex, vit, agi แนะนำทีค่ะว่าควรอัพเท่าไหร่บ้าง)
-> เน้นถือมีดใช้สกิล 50 ( ปั้มโทนิคเอา ) เน้น STR ไปเลย Dex ซัก 25 ก็อยู่ตัวแล้ว
-> ใช้กงเล็บ ก็ Agi Str ควบคู่กัน
2. มีด กับ craw อะไรดีกว่ากัน (รู้สึกว่ามีดแรงกว่า. ป่ะ?)
-> มีด ATK เยอะกว่า แม่นกว่า ใช้สกิลได้รุนแรงกว่า มี Delay Cancel ทำให้ใช้สกิลได้รวดเร็ว
-> กงเล็บ โจมตีปกติ ติด ดับเบิ้ล มีสกิลโจมตีติดทริปเปิ้ล 75% ตอนเป็นแอส สามารถทำดาเมจได้ต่อเนื่องกว่า
3. เปลี่ยนเป็น แอส job 50 เลยดีกว่ามั้ย
-> สกิล 50 สเก๊า เป็นอะไรที่สุดยอดแล้ว
4. skill ที่ควรอัพ-ไม่ควรอัพ (อัพมั่วเเล้ว.. ว่าจาไปรี รอคำตอบก่อน ><*)
-> แล้วแต่สายที่เล่น แนะนำว่าดูที่ ไกด์แล้วอัพตามอาวุธที่ใช้งานให้หมด ดีที่สุด - -a
