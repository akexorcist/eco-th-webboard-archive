Swordman สายขวานอัพสเตตัส กับสกิลไงคับ
- เน้น ตีแรง+เร็ว str(ประมาณ 90หรือ100)>agi(108)>dex(20-40รวมโบนัส จ๊อบ) >vit(แล้วแต่)
- เน้น ตีแรง+ถึก str(ประมาณ 90หรือ100)>vit(90-100)>dex(20-40รวมโบนัส จ๊อบ) >agi (แล้วแต่)
หลักๆนะครับที่เหลือลองที่ดูที่กระทู้อาชีพได้
สกิล Sword Delay Cancel นั้น ใช้ได้เฉพาะ ดาบมือเดียว, 2 มือ กับ เรเปีย (ดาบเรียวๆ)
สกิล ที่สนับสนุน อาวุธประเภทขวาน
- Axe Mastery ของ คลาส ซอร์ดแมน
- Two-hand Sword Mastery ของ คลาส เบลดมาสเตอร์
สกิลโจมตีที่ขวานสามารถใช้ได้
-IAI 1-3
-BLOW, BANISH BLOW
-CONFUSION BLOW,STUN BLOW, SLOW BLOW
ที่กล่าวมาด้านบนของคลาส ซอร์ดแมนนะครับ
ส่วนสกิลโจมตีของคลาสเบลดมาสเตอร์กับบาวตี้ฮันเตอร์นั้น ส่วนใหญ่ ใช้ได้กับขวานเกือบทั้งหมดรวมถึง ATK Rand และมุโซ ซึ่งเป็นท่าจ๊อบ50 ของทั้ง2คลาส
แต่ผมไม่แนะนำเล่นขวานนะครับ เพราะอาชีพสายนี้เหมาะกับดาบมากกว่าครับ(ดูชื่ออาชีพก็รู้แล้ว) เพราะจะดึงประสิทธิภาพของสกิลออกมาได้ดีกว่าเพราะฉนั้นผมว่าใช้ดาบเถอะครับไม่งั้นจะเป็นซอร์ดแมนทำไมกัน
(แล้วตูจะร่ายยาวมาทำไมฟระเนี่ย )
