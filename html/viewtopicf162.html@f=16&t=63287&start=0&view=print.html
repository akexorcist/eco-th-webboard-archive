สกิลที่เลือกมาจากตอนที่เปลี่ยนจากเอ็กโพลเป็นเทร มันหายไปหมดเลยอ่ะครับ

เพราะว่าสกิลพวกที่โอนมามันจะหายไม่ได้นี่ครับ ขนาดรีสกิลยังไม่หายเลย

แต่ไม่รู้ว่าเป็นเพราะตอนผมสวิตซ์มา ผมไม่ได้เลือกสกิลของเทรมาให้เอ็กโพลหรือเปล่า
หรือเป็นเพราะผมสวิตซ์กลับมาเป็นเอ็กโพล และสกิลที่จำมาเป็นของเอ็กโพลมันเลยให้กลับมาอัพใหม่อะคับ
