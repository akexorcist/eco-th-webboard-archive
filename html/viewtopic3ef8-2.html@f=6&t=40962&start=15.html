ตอนนี้ผมเองก็ได้ประสานงานกับ จีเอ็มเป๊ปเป้ และทางทีมงานผู้พัฒนาตัวเกมอยู่ครับเรื่อง จม. ผิดซองอันนี้

เพราะตอนแรกข้อมูลที่เราได้รับมา มันเขียนไว้เลยครับ(ภาษาเกาหลี)ว่า "อย่ารับจดหมายก่อนทำเควสหาง+ปีก มิฉะนั้นจะจบเควสไม่ได้"
และมี ป.ล. มาเล็กๆว่า เควสจดหมายเป็นเควสต่อเนื่อง แค่นั้น ไม่ได้บอกเลยว่าเอาไว้ทำอะไรต่อ และจะได้รับอะไร ... และผมเองก็ไม่เคยเจอเควสต่อเนื่อง ระหว่างการ patch แบบนี้เหมือนกัน
( เพราะคิดตลอดว่า มันไม่ถูกต้อง ถ้ามีคนเพิ่งมาเริ่มเล่นตอนนี้ ก็จะทำเควสนั้นๆไม่ได้ )

ซึ่งทางเราทดสอบใน server test แล้ว ก็ปรากฏว่า พอรับจดหมายแล้ว NPC ตัวสุดท้ายมันไม่ให้หางหรือปีกจริงๆครับ
แบบว่าค้างกันไปซะงั้นเลย เราจึงแนะนำผู้เล่นไม่ให้รับเช่นกัน

ไม่เป็นไรครับ ที่ผมได้ขอไปแล้วคือ ให้ทำการเพิ่มจดหมายให้กับทุกตัวละครเพื่อให้ผู้เล่นทุกคน สามารถเข้าร่วมกิจกรรมนี้ได้

ตอนนี้สรุปว่า ... ถ้าวันอังคารหน้าทางผู้พัฒนาไม่แก้ไขให้นั้น ทาง GM จะจัดกิจกรรมเพื่อชดเชยในส่วนนี้เองครับ
ยังไงก็รบกวนรอสักนิดครับ
