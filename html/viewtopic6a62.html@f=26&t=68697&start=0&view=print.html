การจะยกพรมให้ลอยขึ้นกลางอากาศ จำเป็นต้องใช้ "เตาญี่ปุ๋น" หรือ "Japanese Grill"
(หาจากตั๋วปีใหม่)

ถ้าใช้เตานี้รองพื้น จะสามารถยกพรมให้ลอยได้ครับ แต่ถ้าอยากทำให้สูงๆ ก็ต้องใช้เตาหลายๆ อัน ซ้อนกันขึ้นไปก็จะสูงได้ครับ^^

แต่ ที่บอกว่าเนียนๆ นี่ ผมไม่ทราบครับ^^ รู้แค่ว่าจัดยากเอาเรื่องเหมือนกันนะ ถ้าจะเอาของขึ้นวางเป็นชั้นๆ อีกยิ่งยากครับ(ผมลองแล้ว กว่ามันจะยอมซ้อนกันT-T)
