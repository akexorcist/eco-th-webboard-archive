พอดีว่า แม่ค้า 45 ปุ๊ป ก็จะเปลี่ยนเปน Trader แล้วสวิช Gambler เลยอะคะ

ค่าสเตตัสควรจะเน้นไปทางไหนคะ

เราไม่ค่อยแน่จัยว่า ใช่ Str + dex รึป่าวอะคะ

ขอคำแนะนำด้วยนะคะ

โดย ECO
str - เพิ่ม atk
int - เพิ่มความแม่นยำ และ min atk (ถ้าใช้ไพ่โจมตี)
dex - เพิ่มความแม่นยำ และ min atk (ถ้าใช้ค้อน / กระเป๋า)
agi - เพิ่ม a.spd และ avoid ทั้งหลาย (ช่วยลดเวลาร่ายสกิลได้ด้วย สกิลนะ ม่ายช่ายเวทย์)
vit - เพิ่มเลือด และ def

ส่วน mag มะรู้งุงิ (เผื่ออยากฮีลแรง 555)
