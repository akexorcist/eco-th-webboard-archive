—"PoRsChE"— เขียน:เบลดสายวอร์น่าจะใส่เสื้อบวกได้ดีอ่า

อย่างถ้าบวกเลือดจริง ๆ ก่าเพิ่มแค่สี่ร้อยกว่า ๆ
ถ้าวอร์จริง ๆ โดนรุ้งทีเดียวยังไงก่าตายอยู่ดี

ทีนี้ถ้าเป็นบวก Def ล่ะ
แต่ถ้าบวก Def ก็เพิ่ม 39เองงิ
แต่ที่ข้องใจคือ ที่+Def 39 นี่มันช่วยได้มากไม๊คะ
สมมุติว่า ดาเมจ 1000 นึง มันจะโดนจริง ๆ เท่าไหร่

คืออันนี้กะเอาไว้ตัว ๆ กับไฟ้เตอร์เลยนะ(ยอมสายเวทย์)
สรุป บวกแบบไหนน่าลุ้น น่าคุ้มมากกว่ากัน


ต้องดูก่อนว่าเบลดที่เล่นเป็นสายอะไร หมายถึง Vit หรือ Agi นะ

เบลดสาย vit โต๊งๆเลย ก็คงมี def ซ้ายประมาณ 60 ถ้ากดโซลิดบอดี้ก็จะอยู่ที่ประมาณ 70+ อันนี้ผมว่าให้ +10 Def ที่เสื้อและโล่ และถ้าหาชุดใส่ดีๆ ก็คงจะได้ def ขวาประมาณ 180+ แหละ นี่น้องๆไนท์เลยนะ (ไนท์ผม def ขวา 60 def ซ้าย 220+ อันนี้บวก 7 แค่ชุดกะโล่ ไม่มีปัญญาบวก 10 เจอแอสปามีดยิงปืนระยะประชิดนี่ได้แค่ดอกละ 30-40) ถ้าพูดถึงเบลดตัวนี้ เดมเมจ 1000 คงโดนประมาณ 200+ แหละมั้ง

เบลดสาย agi พริ้วๆ ยังไงก็น่าจะมี def ซ้ายที่ประมาณเกือบ 30 (อันนี้ประมาณการ) เลือดราวๆ 2600+ ถึงจะมี def ซ้าย 200+ โดนยังไงก็ม่องเพราะ def พื้นฐานมันน้อย ควรบวก 10 เลือดยื้อชีวิต แล้วถือดาบสองมือท่องยุทธภพดีกว่า อ่อใส่โล่ถือดาบมือเดียวก็ได้ โล่มันบวกหลบด้วยนี่ ตี+def เข้าไปอีกที่โล่ก็ได้ (เพราะมัน + เลือดที่โล่ไม่ได้ เซง) แล้วแต่สะดวกนะ

สายผสมกะสาย str ไม่แนะนำ เพราะไม่เด่นซักอย่าง เออ สายวอร์นี่ มันอัพรัยมั่งอ่ะ ไม่รู้จริงๆ = =*
