ผมรวม Int ได้เท่าของ เซจที่โอน



ตัวอย่าง 1 ให้เซจที่จำใช้สกิลโอน มี int ที่ 80+20 (รวมโบนัสก็ 100)
เบลด มี int 8+10 (18)

เมื่อเซจใช้สกิลโอน int ให้เบลด เบลดจะมี int เพิ่มขึ้น = 8+92 (100)

สรุป Int เพิ่มจากของเดิมมา 82
________________________________________________


ตัวอย่าง 2 ให้เซจที่จำใช้สกิลโอน มี int ที่ 80+20 (รวมโบนัสก็ 100)
ดรูอิดส์ มี int 58+10 (68)

เซจใช้สกิลโอน int ให้ดรูอิดส์ ดรูอิดส์จะมี int เพิ่มขึ้น = 58+42 (100)

สรุป Int เพิ่มมาจากของเดิม 32
________________________________________________


ตัวอย่าง 3 ให้เซจที่จำใช้สกิลโอน มี int ที่ 80+20 (รวมโบนัสก็ 100)
ไนท์ มี int 95+10 (105)

เซจใช้สกิลโอน int ให้ไนท์ สกิลจะแสดง Miss เนื่องจากเป้าหมายที่โอนนั้น มี int ที่สูงกว่าเรา สกิลจึงไม่ส่งผล
