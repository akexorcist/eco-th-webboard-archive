คือของที่ได้จากการเติมเงินเพื่อซื้อน่ะครับ

ถ้าเป็นเกมอื่นก็แคชไรทำนองนี้อ่ะครับ เติมเงินซื้อตั๋วมาเปิด

แต่ในตั๋วมันก็มีของอยู่หลายอย่าง เปิดแล้วมันก็สุ่มๆกันไปน่ะครับ


แต่ที่เรียกว่าตั๋วตุ๋นเพราะมันเปิดไม่ค่อยจะได้ของดีนัก ส่วนใหญ่จะได้แต่ขยะ
