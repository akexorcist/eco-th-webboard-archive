เราก็รู้สึกดีด้วย เค้าก็รู้สึกดีด้วย แต่ถ้าหากยังไม่แน่ใจ ก็ลองถามใจตัวเองก่อน .. เวลาที่ไม่

เจอเค้า เราคิดถึงเค้ารึเปล่า .. เวลาที่เจอเค้า เราดีใจมั้ย เราใจเต้นแรงมากมั้ย .. ถ้าเป็นไป

ตามที่บอกล่ะก็ .. ความรักน่ะ มาเยือนเราแน่ ๆ แล้วล่ะ ในเมื่อคนสองคนหัวใจตรงกัน ความ

รักก็ก่อเกิดขึ้น .. ไม่ผิดหรอกนะถ้าคนจะมีความรัก .. ก็ยังดีกว่าเราไปโกรธ ไปเคียดแค้นเค้า

ไม่ใช่เหรอ .. ความรักน่ะ มีทุกที่ .. เกิดขึ้นได้ทุกเวลา .. เพียงแค่ว่าเราจะให้ความสำคัญ

มากมั้ยเท่านั้นเอง .. คนที่เค้ารักกันน่ะ .. ก็ดูเค้ามีความสุขดีใช่ไหม .. ? แต่เชื่อฉันสิ .. ไม่มี

คู่รักคู่ไหนที่ไม่เคยเสียน้ำตาให้กันหรอก .. อาจจะไม่ใช่เพราะเสียใจ .. แต่อาจจะซาบซึ้ง

ตรึงใจกับความรักที่เค้ามีให้เราก็ได้ .. เรารักเค้า .. เค้าก็รักเรา . มันก็ทำให้เรามีความ

สุข .. แต่ .. ถ้าวันไหนใจเราหรือใจเค้าเปลี่ยน .. ความสุขนั้นก็จะถูกทำลายลงด้วยความ

เศร้าโศกเสียใจ .. แต่ .. ความรักไม่เคยทำร้ายใคร .. ใจคนต่างหากที่ทำร้ายกันและกัน .. ”

ความห่างไกล กับ การพิสูจน์ใจ

คุณอาจเคยได้ยินบางคนพูดกันว่า “ความห่างไกลทำให้ใจคนเปลี่ยน” ความจริงแล้ว เปล่าเลย หากคุณคิดดูดีๆแล้ว ความห่างไกลไม่เคยทำให้ใจคนเปลี่ยนหรอกนะ...ใจคนต่าง

หากไม่ใช่เหรอ ที่เปลี่ยน แล้วที่พูดออกมาว่า “เพราะความห่างไกล” นั่นน่ะ มันก็แค่ข้ออ้าง

เพื่อหลอกตัวเองและทุกๆคนเท่านั้น แต่ ใจคุณเองคุณคงจะรู้คำตอบนะ ว่าแท้จริงแล้ว ใจ

คุณเปลี่ยนเพราะอะไร...??


คุณรู้มั้ย ว่าการที่ห่างไกลกัน มันก็เป็นข้อพิสูจน์ที่ชัดเจนที่สุด.... เพราะหากว่าห่างไกล

กันไป แล้วเค้าคนนั้นยังคงไม่มีใครมีแค่คุณ นั่นก็เป็นเรื่องที่ดี และการที่คุณจากคนคนนั้นไป

ก็เพื่อพิสูจน์ใจคุณด้วย ว่าถ้าคุณห่างคนคนนั้น คุณคิดถึงเค้าบ้างไหม รู้สึกเหมือนขาดอะไร
มั้ย เหงาบ้างรึเปล่า

และคุณจะได้รู้คุณค่าของใครสักคน ที่ได้ชื่อว่า เป็นคนที่คุณแคร์

แต่ถ้าหากไม่มีความรู้สึกนั้นเลย ไม่ว่าคุณหรือเค้า มันอาจจะเจ็บ แต่ มันก็ทำให้คุณได้รู้สึก
ตัว ก็ดีไม่ใช่เหรอ หากคุณรู้ตัวก่อนที่ ทุกอย่างจะสายเกินไป และก่อนคุณจะรักคนคนนั้น

มากเกินถอนตัวหรือให้ความหวังกับคนคนนั้นมากไป



เพราะฉะนั้น จงอย่าเอาแต่โทษสิ่งไหนอีกเลย เรื่องอย่างนี้โทษใครไม่ได้ เพราะทุกสิ่งมันเกิดขึ้นโดยที่ไม่มีใครผิด แม้ใจเราเอง.....
