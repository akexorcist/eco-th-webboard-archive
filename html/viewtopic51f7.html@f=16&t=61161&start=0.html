สายBPอาชีพไหนก็รวยเร็วได้ทั้งนั้นล่ะครับอยู่ที่ตัวผู้เล่นเองมากกว่า เพียงแต่ทั้ง4อาชีพ
จะมีวิธีรวยที่ต่างกันเท่านั้นแหละ ขึ้นอยู่กับว่าตัวคุณเหมาะกับสไตล์ไหนครับ

แรนเจอร์ - เน้นตีมอนสเตอร์หาของไปขาย มีสกิลเปิดกล่องสมบัติต่างๆได้ ล่ากล่องได้ดี
ชาวนา - เน้นตีพวกต้นไม้ ใบหญ้า ปลูกต้นไม้ก็ได้ มีสกิลสร้างอะไรได้หลายอย่าง
พ่อค้า - เน้นที่การซื้อขายตามชื่อ สกิลจะสนับสนุนการค้าขายมาก จะรวยอยู่ที่ความฉลาด
ทาทา - เน้นการตีพวกหินแร่เพื่อเอาไปขาย มีสกิลเกี่ยวกับการหลอมแร่ สร้างอาวุธได้

ที่พูดมามันแค่คร่าวๆเพราะแต่ละอาชีพมันมีรายละเอียดต่างๆเฉพาะตัวเยอะแยะมากมาย
แน่นอนวิธีหาตังไม่จำเป็นต้องทำตามรูปแบบก็ได้แล้วแต่บุคคล ส่วนข้อมูลและแนวการอัพ
แนะนำว่าให้ไปอ่านเอาเองในกระทู้ปักหมุดครับ ไม่เข้าใจค่อยมาถามดีกว่า
