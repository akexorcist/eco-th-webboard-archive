ตอนนี้เราก็จะขึ้นปี 4 แ้ล้ว ไม่ค่อยจะได้เข้าเกมเท่าไหร่ เพราะโปรเจคมันลนก้น T T

แต่เหตุผลที่สำคัญกว่าที่เป็นสาเหตุที่เราเลิก ก็มาจากระบบการบริหารเกมนี้

นอกจากเบื่อเกมและผู้บริหารแล้ว ในบอร์ดก็ยังลุกเป็นไฟอีก

รู้สึกเหมือนจะไม่มีที่ไหนอยู่ได้อย่างสบายใจอีกแล้วใน ECO

เราคงต้องโบกมือลากันตรงนี้แล้ว

ที่จริงเราชอบบอร์ดที่นี่มากก่อนมันจะมีปัญหามากมายก่ายกองแบบนี้

เพื่อนๆที่เราเคยพบ รู้จัก และเป็นมิตรกับเรา เราจะไม่มีวันลืมเลยค่ะ

1 ปีกับ ECO มีทั้งเรื่องดีและไม่ดี ตลก สนุกสนาน เศร้า โกรธ ครบทุกรสชาติ

ขอบคุณสำหรับทุกสิ่งทุกอย่างที่ผ่านมาค่ะ

เราขออนุญาตลบรูปและทิปในกระทู้นี้ออกนะคะ เพราะเราคงไม่มีโอกาสเข้ามาดูแลกระทู้นี้อีกแล้ว

แต่เราจะเก็บกระทู้ How to ไว้ สำหรับคนที่รักการทำภาพ

เพียงแต่ว่า คงต้องกดค้นหากันแทนนะคะ เพราะเราจะไม่ขุดมันขึ้นมาแล้วงิ

ข้างล่างนี้คือที่อยู่ใหม่ของเราค่ะ เพิ่งหัดทำ งานต่างๆของเราก็ยังอยู่ที่นี่

็http://ramcom69.exteen.com

ว่างๆก็เข้ามาคุยกันได้นะ หวังว่าเราจะได้พบกับเพื่อนๆจากบอร์ดนี้อีก บะบายค่ะ TwT/
