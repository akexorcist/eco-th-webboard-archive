ในส่วนของอาวุธเลเวล 60 ทั้งหลาย สามารถไปขอซื้อกับเจ้าหญิง ได้ที่อันเดท

โดยต้องทำเควสต่างหูของราชีนีครับ ( รับเควสที่เจ้าหญิง นั่นแหละ )

รับแล้วก็วิ่งไปยังจุดต่างๆ (ของเควส)เพื่อหาต่างหู 2 ข้าง

ซึ่งในบางจุดต้องใช้ เปเปอร์ โน๊ต ที่จะเข้าไป

เมื่อได้ต่างหูครบแล้ว ก็นำกลับมาให้เจ้าหญิง แล้วเจ้าหญิงก็จะขายอาวุธเวล 60 ให้ครับ

แต่.......เจ้าหญิงจะสุ่มขายให้เป็น Setๆ ครับ ถ้าเราทำแล้วไปเจอ Set ที่ไม่มีอาวุธ

ที่เราต้องการ ก็ต้องรับเควสวิ่งหาต่างหูใหม่ ( ไม่ต้องใช้แต้มเควส )


อ่อ......ก่อนส่งเควสกับเจ้าหญิง ตรวจเชคน้ำหนักตัวเองให้ดีด้วย

เพราะถ้าซื้อแล้ว น้ำหนักเกิน เจ้าหญิงจะไม่ขายให้ครับ
