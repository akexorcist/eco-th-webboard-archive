วิ้งงง!!!

นั้นใครนะ ... เทวทูต หรือ ท่านจะมารับวิญญาณข้าหรือ?

ช้าก่อน...ข้ามาเพื่อช่วยเหลือเจ้า...

ช่วยข้าหรือ มันสายไปเสียแล้ว ท่านมาช้า ดูหมู่บ้านข้าสิ
ดูสิ พ่อแม่ข้าเพื่อนๆข้า อยู่ที่ไหน ..





ข้ารู้.. ว่ามันคงทำใจร้ายจิตใจมาก .. แต่อย่าเสียใจเถิด...
ข้ามาเพื่อช่วยเหลือเจ้า... มากับข้าสิ ข้าจะพาเจ้าไปสู่โลกใบใหม่
ที่ไร้สงคราม มีแต่ความรัก และพ้องเพื่อนมากๆมาย..

จิงนะหรือ..ได้โปรดอย่าหลอกข้า..ข้าเหนื่อยมาเกินทนแล้ว

หากท่านเหนื่อยก้อจงพักซะ หลับตาซะเถอะ ข้ามาเพื่อช่วยเจ้า...

ชะแว่บบบบบบบบ





ตื่น...ลืมตาตื่นเสียเถิด ถึงโลกใหม่ของเจ้าแล้ว ....


อ่ะ!!! ที่นี้คือที่ใดกัน ทำใมผู้คนช่างมากมายนัก... ดูสงบสุขเหลือเกิน...

ที่นี้ก้อคือโลกใหม่ของเจ้ายังไงกันล่ะ...จงใช่ชีวิตและเรียนรู้เถิด
บัดนี้เจ้าได้เกิดใหม่แล้ว...ขอจงเดินตามเส้นทางแห่งแสงสว่าง เมตตา และยุติธรรม
ขอให้เจ้าจงเป้นอัศวินที่สง่างามแห่งพระผู้เป็นเจ้าเถิด .. ขอให้พระผู้เป้นเจ้าทรงอวยพร...

............. เด่ว... ข้าอยากรู้ชื่อท่าน ท่านเทวทูต

(เทวทูตยิ้มแล้วชะแว่บบบบ หายตัวไป )

...... ขอบคุณ........




.....................

นั้นก็เป็นเวลา ที่ผ่านมาเนิ่นนาน ร่วม 22 ปี.....
ข้าเติบโตขึ้นในโลกใหม่ที่ไร้สงคราม
ข้ามีรอบยิ้มที่เป็นสุข ข้ามีเพื่อนๆที่รักของข้า
และ
ข้าก้อได้ฝึกฝนตัวเองจนกลายเป็น อัศวินเทวทูตที่สง่างาม ตามที่ท่านผู้นั้นบอกไว้
และข้าก้อต่อสู้เพื่อความยุติธรรมแต่นั้นมาตลอด........ เพราะข้าไม่อยากให้มีสงคราม..

ทุกครั้งที่ข้ามองฟ้า..ข้าจะก้อ อดคิดถึง เทวทูตองค์มิได้ ท่าน Tita ....
