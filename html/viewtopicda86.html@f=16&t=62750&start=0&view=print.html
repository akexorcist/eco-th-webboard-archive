บอกที่เลเวล 5 และกัน
ใช้ SP 50
เป้าหมายเดี่ยว
ดาเมจ 350% ทุบ 3 ครั้ง
สกิลนี้ไม่ค่อยต่างจาก IAI Combo เท่าไหร่นักคือ
-ถ้าเป้าหมายตายที่การทุบครั้งแรกหรือครั้งที่สองจะไม่มีครั้งต่อไป(ง่ายๆคือตายเมื่อไหร่หยุดทุบเมื่อนั้น)
-ถ้าในระหว่างการทุบครั้งแรกหรือครั้งที่สองหากเราคลิกที่เป้าหมายซ้ำอีกครั้ง จะหยุดสกิลแล้วไปตีธรรมดาทันที
-สกิลนี้ร่ายช้า ถ้ากดใส่มอนที่กำลังเดินมีโอกาศที่จะทุบ 1 ทีแล้วก็หยุด แล้วจะมีข้อความระบบขึ้นมาว่า "เป้าหมายพ้นระยะการโจมตี"
-เป็นสกิลกายภาพ A.spd กับสถานะ Delay Cancle ไม่ส่งผลให้โมชั่นลดลง

เดี๋ยวมาแปะรูปให้ทีหลังเน้อ กำลังสูบโปรบันทึกภาพเคลื่อนไหวของ -คนหน้าตาดี- อยู่ =w=
