1.หาลูกเจี๊ยบ

- เข้าบ้านหลังหมายเลข 6 ไป
- คุยกับ npc ที่อยู่ข้างในเขาจะบอกว่า ลูกเจี๊ยบทั้ง 7 หายตัวไป
- หาลูกเจี๊ยบแต่ละเบอร์ให้ครบตามที่กำหนด เมื่อเจอแล้วให้คลิกคุยกับลูกเจี๊ยบและเลือกจับตัว แต่ลูกเจี๊ยบจะตอบกลับมาว่า "โกรธ ไม่ยอมให้จับตัว"
- ทำอย่างนี้ไปเรื่อยๆจนหาครบทั้ง 7 ตัว แล้วกลับไปคุยกับ npc คนเดิมก็จะได้ skill pointแล้ว ^^
2.หาวัชพืช
- หา npc ที่อยู่หมายเลข 5
- รับงาน
- ทำลายวัชพืช 50 ต้น ภายในเวลา 7 นาที
- เมื่อเสร็จแล้ว กลับไปคุยกับ npc คนที่มอบหมายงานก็จะได้ skill point
- ไปรับรางวัลที่ร้านเหล้า

ที่กล่าวมาไม่รู้ว่ามีใครเคยเอามาโพสแล้วหรือเปล่า -*-
ลองทำดูละกันคับ ถ้าเจอ skill point ฟรีๆแบบนี้อีกจะเอามาฝากนะคับ
