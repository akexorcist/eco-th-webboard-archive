ใครรู้ช่วยตอบทีนะคะ สงสัยมานานแล้ว

1.สกิลของจ็อบ40น่ะค่ะ(จำชื่อไม่ได้ โทดทีนะคะ) ต้องอัพมั้ย คือตอนนี้จ็อบมันจะไม่พออัพของเวล50ถ้าเราอัพสกิลของเวล40อ่า เลยอยากถามว่าสกิลนี้จำเป็นมากมั้ย แล้วอันไหนแรงกว่ากัน
ก็แล้วแต่เน้อส่วนตัวไม่อัพ ไปอัพ 50 เลยอ่ะ

2.ค่าสเตตัสนี่ประมาณนี้พอมั้ย คืออัพแล้วรู้สึกว่าเก็บเลเวลลำบากมากๆเลย เก็บอยู่ใต้อะ ตอนนี้เวล 44/42 Str38+8 Dex 20+8 Agi54+11 ฟันมอนแทบไม่เข้า ใส่กรงเล็บเลเวล30 ฟันทีนึงราวๆ20-60 เหลือบไปเห็นคนอื่นเขาตีกันที2ทีตาย นักเวทยิ่งไม่ต้องพูดถึง ยิงตูมเดียวจบ น้อยใจอย่างแรงT T
Agi เยอะไปไหมหว่า แต่เล่นกรงเล็บก็แบบนั้นละครับ ดีในระยะยาว หานักเวทวิ่งสิงยิงดีกว่า
ปล. เอามีดมาใช้ก่อนก็ได้นะ

3.เลเวลประมาณนี้เก็บแถวไหนดีสุดอะ คือมอนเหนือตีได้น้อย ลองลงดันเหนือดูก็โดนไพ่แจ็คตีตายทุกที มีที่ไหนเก็บไวๆบ้างอะ ต้อมปั้มยาบ้างก็ไม่เป็นไร มีงบราวๆmนึง
ผมวิ่งเก็บของหน้าเมืองใต้ส่งเควสอ่ะ ขึ้นน้อย อดทน


4.ตีบวกอาวุธนี่ช่วยได้เยอะรึเปล่าคะ ความจริงอยากลองใช้หินคริตี+กรงเล็บดู แต่กลัวมันจะไม่คุ้มกับค่าตี แล้วมีอาวุธอะไรที่พอใช้ได้ช่วงนี้บ้างไหมคะ อยากลองเล่นสายกระบองดู(ไม่แน่ใจว่าเรียกว่าอะไร แต่ที่มันใช้ค้อนอันใหญ่ๆอะ) แต่ก็ไม่รู้จะเก่งมั้ย
เล่นมีดหรือ กรงเล็บดีกว่า= = ส่วนตีบวกไม่แนะนำช่วงเวลเท่านี้ครับ
