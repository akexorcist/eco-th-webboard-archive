Go!
Skill Type : Active Skill
JOB LV. ขั้นต่ำ : 1
คำอธิบาย : สั่งให้สัตว์เลี้ยงโจมตีใส่เป้าหมาย

Come Back!
Skill Type : Active Skill
JOB LV. ขั้นต่ำ : 3
คำอธิบาย : สั่งให้สัตว์เลี้ยงหยุดการโจมตีเป้าหมาย

Biology
Skill Type : Passive Skill
JOB LV. ขั้นต่ำ : 5
คำอธิบาย : เพิ่มพลังต้านทานสถานะผิดปกติทั้ง 7

Proof of reliance
Skill Type : Active Skill
JOB LV. ขั้นต่ำ : 8
คำอธิบาย : สั่งให้เป้าหมายที่เป็นสัตว์เลี้ยงหยุดชะงัก (ใช้ไม่ได้กับสัตว์ประเภทขี่)

Healing fire
Skill Type : Active Skill
JOB LV. ขั้นต่ำ : 10
SP ที่ใช้ : 25
ระยะเวลาสกิล : 60 วินาที
คำอธิบาย : ก่อกองไฟรักษาอาการบาดเจ็บ ผู้เล่นจะได้รับผลที่ 20 หน่วย แต่สัตว์เลี้ยงจะได้รับผลที่ 50 หน่วย

Bridle
Skill Type : Passive Skill
JOB LV. ขั้นต่ำ : 13
คำอธิบาย : เพิ่มประสิทธิภาพให้กับสัตว์เลี้ยงประเภทขี่ (ส่งผลให้สามารถขี่ Black Dragonได้)

Encouragement
Skill Type : Active Skill
JOB LV. ขั้นต่ำ : 14
SP ที่ใช้ : 12
ระยะเวลาสกิล : 60 วินาที
คำอธิบาย : เพิ่มพลังโจมตีทางกายภาพให้กับ Pet ในชั่วเวลาหนึ่ง (Min ATK+6, Max ATK+12)

Glow Rise
Skill Type : Passive Skill
JOB LV. ขั้นต่ำ : 15
คำอธิบาย : เพิ่มอัตราการเติบโตของสัตว์เลี้ยง

Metamorphosis
Skill Type : Active Skill
JOB LV. ขั้นต่ำ : 20
SP ที่ใช้ : 25
ระยะเวลาสกิล : ไม่จำกัด
คำอธิบาย : แปลงร่างกลายเป็นสัตว์เลี้ยง (ไม่สามารถใช้ได้กับสัตว์ประเภทขี่) ผลของสกิลนี้จะหายไปเมื่อเปลี่ยนแผนที่ แต่สามารถใช้สกิลซ้ำ

Jishi Power
Skill Type : Passive Skill
JOB LV. ขั้นต่ำ : 23
คำอธิบาย : เพิ่มค่า HP สูงสุดให้แก่สัตว์เลี้ยง 10%

Acrobat Evasion
Skill Type : Active Skill
JOB LV. ขั้นต่ำ : 27
SP ที่ใช้ : 25
เป้าหมาย : รอบตัวๆ โดยสัตว์เลี้ยงเป็นจุดศุนย์กลาง
คำอธิบาย : ยั่วยุศัตรูที่อยู่รอบๆ ให้เข้ามา และทำการโจมตี รวมทั้งเพิ่มอัตราการหลบหลีกด้วย

Pet Delay Cancellation
Skill Type : Active Skill
JOB LV. ขั้นต่ำ : 30
SP ที่ใช้ : 36
คำอธิบาย : เพิ่มความเร็วการโจมตีของสัตว์เลี้ยง (มีผลทั้งสัตว์เลี้ยงปกติ และสัตว์เลี้ยงประเภทขี่)

Prominence
Skill Type : Active Skill
เงื่อนไข : ต้องขี่ Black Dragon
SP ที่ใช้ : 25
คำอธิบาย : ทำการโจมตีบริเวณด้านหน้า 2 ครั้ง (Damage 250% x 2)
