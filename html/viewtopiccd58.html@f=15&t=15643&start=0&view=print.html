อยากได้แนวทางการเล่นอะคับสาย
ปาร์ตี้แล้วก็ยิงเวทเองบางครั้ง
จะเอาค่าสเตตัสยังไงดีคับเอาร่ายเร็ว
ฮิวไม่เบาเกินไปและยังอึดคงเดิม
ขอสกิลแนะนำด้วยนะของดรูด้วยก็ดี

โดยตอนนี้อัพ
vit 30
mag 41
เวล 32 ครับ
ก็ยิงมอนเองได้บางตัวแต่ไม่ค่อยสะใจอะเบา
แต่ว่าด้านตี้นี้แจ่มฮิวก็แรง mp เยอะจนเริ่มเหลือละ
สิงสายบู๊ทั้งหลายไปตีดันน้ำแข็งสบายๆไม่ต้องกลัว
มอนตบทะลุเกราะมาแล้วจะตายถ้าสายเวทก็ให้เขาสิงเราแล้ว
แท็งได้เลยจัดว่าโอเชแต่ด้านช่วยยิงนี่ทำไรไม่ได้เลยอะ

ทำไมทั้งๆที่ทางเข้าเมืองเหนืือเป็นทางแสง
แต่เรายิงพวกมอนแถวนั้น 0 เกือบหมดเลยอะ
ไม่ได้ยิงพวกทางแสงด้วยนะพวกมืดแถวแม็พ
ซ้ายก็ยิงไม่เข้างง -*-

พวกคนเล่นโยวกังมาก่อนจะเรียกวาเทสว่าหมอ
แต่เกมอื่นจะเป็นพระแทน

ขอบคุณสำหรับทุกความคิดเห็นและทุกคำตอบครับ
