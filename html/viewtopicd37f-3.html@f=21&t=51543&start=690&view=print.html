มิกุรินั่งอยู่มุมห้องหนึ่งพูดกับยาคุที่อยู่อีกมุมห้อง
"เธอช่วยเอาพลังเวทย์ใส่ในนี้หน่อยสิ"มิกุริส่งกล่องสีน้ำตาลให้
ยาคุไปหยิบกล่องนั้นมาแล้วพยายามร่ายเวทย์ลงไป แต่ก็ไม่ได้ผล
"แค่เอาพลังเวทย์ออกมานะ ไม่ต้องร่าย"มิกุริบอก เหมือนมิกุริจะรู้เรื่องเวทย์มนต์มากกว่ายาคุอีกงานนี้
ยาคุลองอีกครั้งโดยไม่พูดอะไรเลย แล้วจึงสามารถนำพลังเวทย์ออกมาได้0.5จูล(มันชักเรื่มเข้าวิชาการซะแล้ว)
"แค่นั้นก็พอแล้ว" มิกุริบอก มิกุริไปหยิบกล่องนั้นคืนมาแล้วก็ง่วนอยู่กับสิ่งประดิษฐ์ต่อไป
"ฉันไปซ้อมต่อนะ" ยาคุบอก และเขาก็เดินออกจากห้องลงบันไดไป
"เพียงแค่มีพลังเวทย์แค่นี้ก็พอที่จะทำอะไรบางอย่างได้แล้วล่ะ"
