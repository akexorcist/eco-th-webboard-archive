rouse mental // pop // rouse body // fusion สามารถใช้ร่วมกันได้ทั้งหมด ไม่มีอันไหนทับกัน

ส่วน Holy feather กับ relaxation นั้น holy feather ดีกว่ากันหลายขุมเลย

relaxation ไม่ทำให้เกิดผล MP SP เด้ง ทุกๆ 2-3 วินาที ต่างกับ holy feather มันแค่ทำให้ได้รับฮีลแรงขึ้น กินของเพิ่มเลือด SP MP แรงขึ้นเฉยๆนะ เท่าที่ดู
