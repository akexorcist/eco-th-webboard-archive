การอัพของสาย BP ก็คล้ายๆกัน เพราะมักจะเป็นสายที่ใช้สกิลในการเก็บ lev

หลักๆที่เราทำก็ อัพ dex ให้ถึงระดับที่ตีม่อนที่เราจะเกบเวลโดน จากนั้นก็อัพ str และ vit ตามแต่สถานการณ์ เช่นว่ามีพระไปเวลด้วยหรือไม่ ถ้ามีพระด้วย ก็ยัด str ล้วนไปก่อนเลย แต่ถ้าไม่มีก็ต้องแบ่ง vit มั่งไม่งั้นเด๋วตาย

ก้มีอยุ่แค่ราวๆนี้ ส่วนว่าจะอัพเท่าไหร่ ไม่มีตัวเลขตายตัวครับ
