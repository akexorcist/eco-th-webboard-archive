เอาเป็นว่าตอบเท่าที่เข้าใจก่อนนะครับ

1. ติดสถานะบ่อย แก้ได้โดย 2 วิธี

1.1) อัพ INT จะช่วยลดอัตราการติดสถานะได้ (อัตราที่ลดได้ยังเป็นปริศนา แต่ถ้ามีจะช่วยลดการติดสถานะต่าง ๆ ได้ และเป็นการช่วยเพิ่มอัตราที่สกิลประเภทคำสาป เช่น Puppet จะมีโอกาสติดสูงมากขึ้น ... Monster Charming ถึงจะถือเป็นสายคำสาปเหมือนกัน แต่ INT ไม่มีผลเน้อ)

1.2) ให้ Druid ใช้สกิลประเภท Resist ให้ เห็นผลทันตาแต่อยู่แปปเดียวเน้อ


2. สกิลที่โอนมาถ้าเล่นสายลาก แนะนำไม่ควรเอาพวกสกิลสายเวทย์หรือสายก่อกวน (คำสาปต่าง ๆ) เข้ามาจะดีกว่าครับ ถ้าหากให้ผมเลือกระหว่าง Monster Charming กับ Crate Figure ผมเลือก Monster Charming นะครับ เพราะ Crate Figure นั้น Marionette Master ก็ทำให้เราได้ (หรือตอนนี้ทำไม่ได้แล้วหว่า -..-)

ปล. ถ้าหากตอบไม่ตรงคำถามต้องขออภัยนะครับ
