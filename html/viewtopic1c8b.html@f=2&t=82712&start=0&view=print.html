นานา แข้วเหล็ก เขียน:คืออยากรู้อะค่ะว่าคลิป วีดีโอ สวยๆเหมือนที่เค้าทำประกวดกันอะค่ะเค้าทำกันยังไงหรอค่ะใครรู้ช่วยบอกทีนะค่ะ ขอบคุนค่ะ


อันดับแรก วาง คอนเซป วีดีโอ ที่ต้องการคับ อยากได้อารมไหน
จากนั้น หาถาพ และ วีดีโอ ที่เกี่ยวข้อง
มาเรียงต่อๆกัน ตรงนี้ต้องค่อยๆทำคับ ทำแล้ว
ย้อนดูหลายๆรอบ จนรู้สึกว่า ภาพ และ วีดีโอ
ที่เราตัดมานั้น คล้อยตามเป็นเรื่องเดียวกันและไม่สะดุด

ปล.1 สะดุด คือ อารมณ์ไม่ต่อเนื่อง ไม่ใช่ เดินสะดุดนะเออ

โดย ใช้ โปรแกรม ต่างๆ
ดัง เรปบน ครับ
จากนั้น ใส่เอฟเฟค และอาจมีตัวอักษร บรรยายด้วยก็ได้

และที่สำคัญ ซาวน์ ประกอบ
ซาวน์ทำให้ได้ความรู้สึกมากขึ้นๆๆ

ปล.2 หากจะใช้เป็นภาพนิ่ง แนะนำ ไปตัดต่อ เอฟเฟคใน โฟโต้ชอป ก่อนคับ
