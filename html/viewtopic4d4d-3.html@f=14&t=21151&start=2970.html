- ใช้สกิลใส่มอนสเตอร์

ค่า hate บนตัวผู้เล่นจะลดลงเรื่อยๆจนกลับสู่ค่าที่เป็น 0 หากผู้เล่นไม่ได้กระทำเงื่อนไขด้านบนนี้
ยิ่งมอนสเตอร์ระดับสูงเท่าไร จะยิ่งไวต่อค่า hate ต่อผู้เล่นต่างๆมากขึ้น สังเกตได้ว่าเวลารุมโจมตีบอส
บอสจะสวนกลับเข้าใส่ผู้เล่นที่ค่า hate มากที่สุด(ซึ่งมักเป็นเบลดมาสเตอร์) หรือไม่ก็พระที่ฮีลแรงๆ
