กรณีนี้ ที่หลอมดาบ 80 เป็นคุณสมบัติ และ ดาบ 70 เป็นแสดงภาพ

ถ้าหากจะหลอมอีกครั้ง โดยนำดาบ 70 เป็นคุณสมบัติ ไม่สามารถทำได้แล้วครับ

เพราะ หลอมกับ ดาบ 80 ไปแล้ว การหลอมทับโดยที่จะเอาคุณสมบัติใหม่

ต้องอาวุธที่มีเลเวลเท่ากัน หรือ มากกว่า ตัวคุณสมบัติเดิม ครับ
