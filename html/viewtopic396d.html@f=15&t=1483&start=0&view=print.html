shaman
shaman เป็นอาชีพในสาย spelluser ที่เน้นการใช้เวทธาตุทั้ง 4 คือ ไฟ ลม ดิน น้ำ โดยสกิลส่วนใหญ่จะเน้นไปในทางโจมตี และทุกสกิลต้องใช้เวลาในการร่ายเวทย์ นอกจากนี้ยังมีสกิลที่ใช้ในการสนับสนุนเกี่ยวกับธาตุ เช่นเพิ่มพลังธาตุให้กับเกราะและเปลี่ยนอาวุธให้กลายเป็นธาตุ
link วิธีเปลี่ยนอาชีพเป็น Shaman(หน้า 42)
link skill shaman(หน้า 8 )
link เควสประจำอาชีพของ shaman(หน้า 72)


elementaler
เป็น expert job ของ shaman เมื่อเล่น shaman จนถึง job lv30 ขึ้นไปสามารถเปลี่ยนเป็น elementaler ได้
elementaler จะสามารถใช้สกิลโจมตีด้วยธาตุที่หลากหลายมากขึ้น และยังมีสกิลที่สนับสนุนการโจมตีธาตุให้ดียิ่งขึ้น
link วิธีเปลี่ยนอาชีพเป็น Elementaler(หน้า 42)
link skill elementaler(หน้า 15)


enchanter
เป็น tecnical job ของ shaman สามารถเปลี่ยนเป็น enchanter ได้โดยการ switch job จาก elementaler รายละเอียดเกี่ยวกับ job switch
enchanter จะมีสกิลที่เน้นไปในทางสนับสนุนมากขึ้น สามารถเสกพื้นที่ให้กลายเป็นพื้นที่ธาตุได้ และมีสกิลที่ใช้โจมตีลงบนพื้นที่ที่เป็นธาตุดินและไฟ
นอกจากนี้ในเลเวลสูงๆยังมีสกิลสนับสนุนที่ไม่เกี่ยวกับธาตุอีกด้วย
link skill enchanter(หน้า 4)

shaman มีสกิลปราชญ์แห่งวิญญาณซึ่งทำให้ดรอปไอเท็มจากมอนสเตอร์ประเภทวิญญาณง่ายขึ้น
link มอนสเตอร์ประเภทวิญญาณ(wiki)

ค่า status ที่จำเป็นสำหรับ shaman เรียงตามลำดับความสำคัญ
-mag-
เพิ่มพลังโจมตีเวทย์มนต์สูงสุดและต่ำสุด
เพิ่ม mp สูงสุด
ค่า status ที่สำคัญที่สุดสำหรับสายเวทย์ ช่วยให้ยิงเวทย์ได้แรง และยังเพิ่ม mp สูงสุดทำให้สามารถใช้เวทย์ได้อย่างต่อเนื่อง
-dex-
เพิ่มความเร็วในการร่ายเวทย์
เพิ่มค่า capa
เป็น status ที่ช่วยให้ร่ายเวทย์ได้เร็วขึ้น มีประโยชน์มากเวลาใช้สกิลที่ต้องอาศัยความคล่องตัวสูง และเนื่องจากทุกสกิลของ shaman ต้องใช้เวลาในการร่าย ดังนั้นค่า dex จึงจำเป็นมาก
-int-
เพิ่มพลังป้องกันเวทย์
เพิ่มอัตราการหลบหลีกระยะไกล
เพิ่มอัตราการป้องกันสถานะผิดปกติ
เพิ่มพลังโจมตีเวทย์ต่ำสุด
เพิ่มอัตราสำเร็จในการใช้สกิลลดความสามารถหรือทำให้เกิดสถานะผิดปกติ(debuff)
เป็น status ที่มีประโยชน์หลายด้าน คือช่วยเพิ่มพลังโจมตีเวทย์ต่ำสุดทำให้พลังโจมตีเวทย์แกว่งน้อยลง และยังช่วยลดความเสียหายที่ได้รับจากระยะไกล ซึ่งอันตรายมากกว่าระยะใกล้ นอกจากนี้ยังเพิ่มอัตราสำเร็จในการใช้สกิล debuff
-vit-
เพิ่ม hp สูงสุด
พลังป้องกันการโจมตีทางกายภาพ
พลังป้องกันการโจมตีทางเวทย์มนต์
เป็น status ที่ช่วยให้รอดตายได้ง่ายขึ้น อาจไม่จำเป็นต้องอัพก็ได้ แต่ถ้าอยากอึดตายยากแนะนำให้อัพ

agi โดยทั่วไปไม่จำเป็นต้องอัพ แค่ช่วยเพิ่มอัตราหลบหลีกระยะใกล้และระยะไกล แต่ไม่คุ้มเท่าอัพ int และ vit
str โดยปกติแล้วไม่จำเป็นต้องอัพ เนื่องจากเพิ่มแค่พลังโจมตีทางกายภาพซึ่งไม่จำเป็นสำหรับสายเวทย์
