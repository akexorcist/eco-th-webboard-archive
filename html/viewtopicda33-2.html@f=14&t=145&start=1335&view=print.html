banish blow ถ้าใช้ร่วมกับ blow แล้วบางทีจะเห็นดาเมจติดสองจังหวะเลยครับ
หวดให้ถอย แล้วพอมอนวิ่งกลับมาจะหมดดีเลย์ท่าพอดีก็ซ้ำด้วย blow ได้

แต่ blow นี่จะมีผลดีที่สุดก็ต่อเมื่อใช้อาวุธที่คิดค่าพลังโจมตี "ทุบ" เช่นกระบองหรือค้อนครับ

ส่วน counter อย่าไปยุ่งกะมันเลยครับ เปลืองพ้อยปล่าวๆ
เพิ่ม max sp ก็up intครับถ้าไม่ up skill
