ภาค กำเนิดมหาเทพเอสทราน่า เอกิส

===============================================

บทนำ


ถ้าคู่ต่อสู้ของคุณคือจ้าวมังกรดำที่มีร่างกายอันใหญ่โตปานขุนเขา ในมือของคุณมีเพียงดาบเล่มเดียว คุณรู้ดีว่าไม่มีทางสู้ได้เเต่เพราะต้องปกป้องใครคนหนึ่งที่เคยเสี่ยงชีวิตของตนเองเพื่อความปลอดภัยของคุณมานักต่อนัก ดังนั้นจึงไม่อาจหลีกหนีการต่อสู้ที่เกินกำลังครั้งนี้ไปได้เด็ดขาด
เบื้องหน้าทะเลเพลิงที่โหมกระพืออย่างบ้าคลั่ง เสียงเปลวเพลิงกระพือโหมดังฟู่ฟ่า จ้าวมังกรสบายปีกทั้งเเปดออกคำรามก้อง ป่าทั้งป่าสั่นกระเพื่อมราวกับระลอกคลื่นบนผิวน้ำ
คุณตกลงใจอย่างเเน่วเเล้วว่าจะปกป้องเธอ เเม้จะต้องเเลกด้วยชีวิตของตนเองก็ตาม
การต่อสู่เหนือจินตนาการเช่นนี้ หากเป็นคุณ คุณจะทำเช่นไร!
