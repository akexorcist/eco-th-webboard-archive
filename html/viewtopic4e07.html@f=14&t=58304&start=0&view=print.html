ตอบเหมือนไม่ได้เก็บกันเอง - -

อ่ะ เค้าตอบให้เฉพาะตอนเป็นธนูแระกัน
1-10 เวลรอบๆ เมืองนี่แหละ เน้นทางตะวันตกหน่อย มีผึ้งอ่ะ
11-20 เวลกะผึ้งทางตะวันตกต่อไป ไม่ก็เสี่ยงตายลงมาเวลกะปลาบินทางใต้ (ระวังหุ่น)
30-40 เวลกะหมีทางตะวันตกเลย เรืื่่อยๆ
(ถ้าเล่นปืนหลายคนอาจเก็บไม่ถึง50 แล้วเปลี่ยนเลยก็ได้)

ส่วนใหญ่ถ้ามี dual arrow แล้วก็หมกตัวอยู่ทางใต้
ยิงชินาม่อนนั่นแหละเร็วสุดแระ เพราะใช้ dual arrow
ยิงประมาณ 2 ที ชินาม่อนก็ตายแล้วอ่ะ

ต่อจากนี้ไม่บอกแระ เพราะเค้าเล่นธนูอ่ะ ไม่ได้เล่นปืน (- -a

trick status
- แรกๆ ลง str ล้วนไปก่อนเลยอ่ะ เลือดเราน้อย จำเป็นต้องยิงแรงเพื่อรักษาชีวิต
- ถ้ารู้สึกว่ายิงไม่ค่อยจะโดนแระ อนาถ ก็อัพ int ซะหน่อย (เวลแรกๆ ให้ได้ intรวม20 ก็โอเคแระ)

คร่าวๆ ก็คือ สมมติว่าเวล 20/20 ก็ควรจะมี
strรวม27 intรวม20 agiรวม18
ที่เหลือจะลง vit ให้มีเลือดหน่อยก็โอเค
