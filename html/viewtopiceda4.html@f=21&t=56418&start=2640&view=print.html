ไหนๆพรุ่งนี้ก็จะไปอยู่ยาวละ(เปิดเทอมวันที่7)
มาเล่าเรื่องที่ไปเจอมาตอนเข้าค่ายอัตลักษณ์นิดๆหน่อยๆก็แล้วกัน

ก็สนุกดีครับ ได้เจออะไรเยอะแยะ เพื่อนใหม่ๆ สังคมใหม่ๆ รวมถึงสิ่งแวดล้อมใหม่ๆ(ที่โน่นร้อนมากก)
ม.กว้างกว่าที่คิดซะอีก ดันไม่ได้ซื้อจักรยานไปซะด้วย-*-(แต่ก็มีรถประจำทางวิ่งรอบ ม.)
ในเอกวรรณกรรมเด็กฯมีอยู่26คนด้วยกันครับ เป็นหญิงซะ22ชายอีก4 ซึ่งใน4คนนี้เป็นตุ๊ดไป2 อีก1ดูจะติ๋มๆ(อาจแอ๊บหลุดได้) สรุปเหลือผมชายแท้คนเดียวเหรอ(วะ)เนี่ย!?!
คิดในแง่ดีก็มีสาวๆล้อมรอบเยอะแยะไปหมดเลยอะนะ
เพื่อนๆก็น่ารักดี คุยกันได้สบายๆ (อาจเป็นเพราะมีความชอบอะไรเหมือนๆกัน บวกกับ คนน้อย )ส่วนใหญ่จะบ้าการ์ตูนเหมือนๆกัน

เสียอย่างเดียวบางคนเป็นสาวY(?)แล้วมันดันชอบจิ้น ชาย-ชาย (ผมเป็นผู้ชายคนเดียวก็เลยไม่พ้นจากการโดนจิ้น ไม่เอานะเว้ยยยยย)

อ้อ อีกเรื่อง เอกวรรณกรรมสำหรับเด็กมีชื่อเล่นว่า"เอกลูกเป็ด"เพราะป้ายชื่อเป็นรูปเป็ดสีชมพู(สีประจำเอกนี้)เวลาเดินไปไหนมาไหนต้องห้อยป้ายเป็ด พร้อมกับติดโบว์(แน่นอนว่าสีชมพูเหมือนกัน)ไว้บนหัว น่ารักมากเด่นมาแต่ไกลเชียว
(แต่ให้ตูติดโบว์เนี่ยนะสีชมพูอีกต่างหาก ) เห็นว่ารุ่นพี่ปีที่แล้วได้เอกช้างน้อย=w=


คราวนี้มาถึงเรื่องหอ โชคดีมากครับที่ได้หอแอร์ (แต่ก็คงได้จ่ายค่าไปกันบานเลยทีเดียว )
ห้องอยู่ชั้นสองก็สะดวกดี แต่แคบไปนิด ไม่มีเครื่องใช้ไฟฟ้าให้ มีล็อคเกอร์อยู่4ตู้ เตียงสองชั้นอีกสองเตียง(ผมนอนชั้นบน) และโต๊ะไว้ทำงานอีกสี่ ห้องนึงอยู่กันสี่คน หอชายห้องน้ำรวมสนุกสนานนักเชียว
แต่ที่กังวลไม่ใช่เรื่องห้องแคบหรืออะไรหรอกครับ ที่กลัวคือกลัวได้เมทตุ๊ด!
โชคช่วยที่เมทอีกสามคนชายแท้ๆทั้งนั้น (และสนิทกันได้ในเวลารวดเร็วมากกก )

ห้องข้างๆกะเทยจะเยอะหน่อย เวลาเดินไปอาบน้ำแล้วโดนจ้องรู้สึกเสียวสันหลัง (ตัวมันใหญ่ด้วย กลัวโดนลากเข้าห้องน้ำ )

แล้วเรื่องบนหอเนี่ยมีเรื่องหน้าแตกอยู่เรื่องนึง
คือได้อยู่ชั้นเดียวกับเพื่อนคนนึงในเอก(ที่ว่าติ๋มๆน่ะ)ก็เลยแวะไปเที่ยวเล่นบ้านเวลาที่เมทยังไม่กลับหอ ระหว่างที่กำลังนั่งคุยกันไปนั่งอ่านหนังสือไปกันอยู่ดีๆ ก็มีคนเปิดประตูเข้ามา
