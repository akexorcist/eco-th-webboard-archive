STR: Min ATK ,Max ATK

INT: Min ATK (valid only at long range attack)

แก้หน่อย สับสนกับอาชีพอื่นของสายไฟเตอร์นิดหน่อย DEX เพิ่ม Min ATK (only at close range attack) แต่ปืนมันโจมตีระยะไกล

อย่าที่ข้างล่างตอบ int เพิ่ม min.ATK สำหรับอาวุธโจมตีละระยะไกล ถูกต้องแล้ว

มีข้อสงสัยอย่าง ที่ค่าINTเท่ากัน ถ้าเป็นอาเชอร์แล้วถือมีด min.ATK จะเปลี่ยนไปรึเปล่า ไม่เคยสังเกตุเลย -.-
