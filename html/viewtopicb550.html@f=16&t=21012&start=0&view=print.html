เพิ่มช่องในคลังครับ เพราะถ้าเพิ่มในตัวละคร มันไม่น่าจะเกี่ยวกัน เพราะอัตราบรรทุกของตัวละครจะขึ้นกับ PAYL และ CAPA เป็นหลัก

แต่ช่องของโกดัง มีจำกัด แต่ไม่จำกัดเรื่อง PAYL และ CAPA

และก็หวังว่าคงไม่มีบัตรเพิ่ม CAPA หรือ PAYL ทีหลังนะครับ ไม่งั้นเสียสมดุลย์โครตๆ อาชีพสาย BP เป็นหมาหัวเน่าทันที




ส่วนเรื่องราคาของผมไม่มีความเห็นนะครับ แต่ถ้าถามความเห็นส่วนตัวผม ผมก็ว่าโอเคแล้วสำหรับ 20 ช่อง ราคา 139 เนี่ย (อัตราเทียบกับเกมอื่นๆ ที่ใช้ระบบ Item Selling) ออกจะถูกด้วยซ้ำไปครับ
