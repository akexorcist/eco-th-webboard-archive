ซัตสึกิ Talk

T T หลังจากที่ฉันหายเงียบไม่มีบทไป2ตอนเต็มๆ และติดร่างแห คดีบ้าๆบอๆ ขณะนี้ฉันอยู่ที่ห้องปกครอง แน่เหรอเนี้ย ทำไมมันหลอนเยี่ยงเน้~~~ อ.ทาเคชิ อาคาโดะ คนนี้ว่ากันว่าโหดมากๆ น.รหลายคนถูกทำโทษหนักจนถึงขั้นหายไปเลยก็มี หยา~ ซวยตั้งแต่วันแรกเลยเรา

“ยังมีใครอีกมั้ย?” อ.ทาเคชิเป็นผู้เริ่มการสนทนา สังเกตได้ว่า หลายๆคนในนั้นสะดุ้งกันเล้กน้อย

“เอ่อ...มะ..มิคาเอลคุง หายไปค่ะ”ยูเรโกะ ตอบอย่างหวาดๆ ไม่กล้าพูดถึงรุ่นพี่ฮิเมะ

“งั้นเหรอ ซิลเวอริโอ” อ.ทาเคชิ หันไปเรียกผู้ช่วยของตนที่มีลูกแมวอยู่ในมือ

“หา?”ซิลเวอริโอตอบรับ

“ไปเอาตัวคุณมิคาเอล มาให้ฉันที”

“ครับ” ร่างนั้นหายไป ทิ้งไว้เพียงขนนก

+++++++++++++++++
+++++++++++++++++++++++

“ฮัดเช้ยยยยยยยย!!!!”มิคาเอล จามออกมาอย่างแรง

“เฮ้ยยยย อะไรเนี้ยยยยย เอ้าทิชชู่ = =”โรเว่นที่นั่งอยู่ตรงกันข้าม โยกตัวหลบรัศมีได้ทัน ก่อนจะส่งทิชชู่ให้มิคาเอล อีกฝ่ายรับไป

“รู้สึกเย็นวูบๆน่ะ อ่า ขอบใจ”

“เย็นวูบๆ = = ? อะไรของนาย”โรเว่นงงกับคำตอบเล็กน้อย

“เออๆ ช่างมันเหอะ”

ความรู้สึกเมื่อกี้มันอะไรกันนะ สังหรณ์ไม่ดีเลยวุ้ย = =” แต่ช่างเหอะ คงไม่มีอะไรมั้ง

//แอ๊ดดดด//

“สวัสดีครับ ขออภัยที่เสียมารยาท ไม่ได้เคาะประตูก่อน”ร่างๆหนึ่ง โผล่พ้นบานประตูห้องพยาบาลเข้ามา ทั้งคู่หันไปพบกับชายชุดขาว ในมืออุ้มลูกแมว ใบหน้ายิ้มละไม

“เอ๋ นายเป็นใคร” มิคาเอลถามออกไป ใจนึกหวั่นๆเล็กน้อย

“ผมรับคำสั่งจาก อ.ทาเคชิ มารับตัวคุณ และ....ถ้าหากมีผู้เกี่ยวข้องอีก อย่างคุณ ก็จะต้องไปด้วย”ซิลเวอริโอเหล่มอง โรเว่น ก่อนจะยิ้ม

“เอ๋ ผมด้วยเหรอ อะไรกันครับ”โรเว่นหันไปถามซิลเวอริโออย่าง งงๆ ‘กุเกี่ยวอะไรฟะ = =’

“เอ นึกออกแล้ว คุณ โรเว่น ลอว์เดอร์ ปี2 คลาสมนุษย์ อายุ18ปี ระดับการเรียนอยู่ในระดับA+ ชมรมดนตรี มีชื่อเสียงพอสมควรในหมู่น.รชายและหญิง ปัจจุบันทางชมรมข้อมูลก็มีรูปภาพของคุณจำหน่ายอยู่ ในราคาใบละ1000เยน ผมเองก็มีนะ ^^” ซิลเวอริโอ ร่ายประวัติ ก่อนจะชูรูปภาพ

ครายมานแอบถ่ายช้านฟร้า!!!!~ : โรเว่น

“เอาล่ะ เห็นทีคงได้เวลาไปกันได้แล้วล่ะครับ”

“เอ๋” กลุ่มควันสีขาวเข้าล้อมรอบตัวทั้ง3ก่อนที่ จะหายไปจากห้องพยาบาล

//ฟุ่บ//

+++++++++++++++
+++++++++++++++++++++++

“ขออภัยที่ให้รอครับ มิคาเอลคุง กับ โรเว่นคุงมาแล้ว” ซิลเวอริโอเดินโผล่ออกมาจากมุมมืด หลังจากหายไปซักพัก ตามด้วย โรเว่นกับมิคาเอล

“สวัสดีครับ อาจารย์ทาเคชิ”มิคาเอลกล่าวเรียบๆ เค้าเป็นอีกหนึ่งคนที่ไม่เกรงกลัว อ.ทาเคชิ อาคาโดะ

“หึหึ ว่าไงล่ะ เป็นถึงประธานนักเรียน กลับก่อเรื่องวุ่นวายซะเอง”อ.ทาเคชิเหล่มอง เด็กหนุ่มอย่างไร้อารมณ์

“ครับ ผมยอมรับว่าเป็นความผิดของผมเอง งั้นก็แล้วแต่อาจารย์จะลงโทษละกันครับ” มิคาเอล กระตุกยิ้ม ทุกคนในบริเวณนั้น รู้สึกได้ถึงรังสีมาคุ ที่อ.ทาเคชิ และ มิคาเอลปล่อยใส่กัน ช่าง...เป็นบรรยากาศที่ดีจริงๆ

“หึหึ ก็ได้ สำหรับพวกนาย ฉันเตรียมบทลงโทษไว้แล้ว อ้อ และยังมีเด็กน.รอีกกลุ่มที่ได้รับบทลงโทษเดียวกัน ซึ่งเดี๋ยวพวกนายก็ได้เจอ”อ.ทาเคชิ ส่งกระดาษใบหนึ่งให้ซิลเวอริโออ่าน

//พั่บ//

“... โทษของพวกคุณคือ”
1.กักบริเวณ1เดือน ห้ามออกนอกบริเวณโรงเรียน เด็ดขาด
2.ต้องเข้าร่วมกิจกรรม ในงานกีฬากระชับมิตร ที่จะมาถึงในอีก1เดือน ซึ่งกิจกรรมนั้น อ.ทาเคชิจะเป็นผู้จัดเตรียม
3.ทำความสะอาดโรงเรียน ทุกวันอาทิตย์
“เท่านี้แหละครับ รายละเอียดอื่นๆ อ.ทาเคชิจะเป็นผู้อธิบาย”ซิลเวอริโอร่ายจบ

ทุกคน ต่างอ้าปากค้างไปตามๆกัน ม่ายยยยยยยยยยยยยยยยยยยยยยยยยยยยยยยย

“และ ในระหว่างนั้น ฉันจะใจดี จัดบั๊ดดี้ให้พวกนาย ซึ่งจะเป็นรูมเมทคนใหม่ของพวกนายใน1เดือนนี้ อีกอย่าง พวกนายทุกคน ต้องย้ายไปอยู่หอจันทรา”

“แล้ว จะเลือกยังไงเหรอครับ”หลันฮัว เอ่ยปากถามมั่ง

“เรื่องนี้ ฉันสุ่มชื่อพวกนายไว้แล้ว เอ้าซิลเวอริโอ”อ.ทาเคชิส่งกระดาษให้ซิลเวอริโอ1แผ่น

//พั่บ//

“ฟังกันดีๆนะครับ”

1.อาชิการะ นามิเฟีย / ชินากาว่า เคนอิจิ

2.ซีโร่ เกียร์น่า / ชินาโอะ ซัตสึกิ

3.ยูเรโกะ คุมิงะ / อเล็กซานเดอร์ ลูซิอัส ลีโทย่า

4.โอริฮิเมะ ซานาดะ / โคซึจิ คิรามะ

5.ฮิเดโบชิ ซานาดะ / ฟุจิระ เอมิยะ

6.แนช ลาครีมาล / หลันฮัว

7.โรเว่น ลอว์เดอร์ / มิคาเอล ออสเตอร์ฮาเก็น

“หา!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!!~~~~”ทุกคนร้องขึ้น

“อะไร ทำไม ผมต้องโดนหางเลขด้วยล่ะครับ แล้วทำไมต้องคู่กับเจ้านี่”โรเว่นโวยวาย ก่อนจะชี้หน้ามิคาเอล

“ก็ฉันเห็นพวกนายรักกันดี” ดูคำตอบท่าน

“ครับๆ โรเว่น อย่าโวยวายไปเลยน่า ไม่มีประโยชน์หรอก”มิคาเอลดึงชายเสื้อโรเว่นให้นั่งลง

//แอ๊ดดดด//

“อาชิการะ นามิเฟีย / ซีโร่ เกียร์น่า / อเล็กซานเดอร์ ลูซิอัส ลีโทย่า มารายงานตัวแล้ว ค่ะ/ครับ”ประตูถูกเปิดขึ้น พร้อมด้วยร่างของ3คนที่เหลือ ซึ่งต้องร่วมชะตากรรมด้วย

“รู้แล้วสินะว่าใครเป็นบั๊ดดี้ของพวกเธอ” อ.ทาเคชิ กล่าวเสียงเรียบ แฝงด้วยความรื่นรมย์

“ถ้าหากต้องการทราบรายละเอียดของบั๊ดดี้ของคุณ มาถามผมได้ทุกเมื่อนะครับ” ซิลเวอริโอกล่าว ก่อนจะขอตัวออกไปข้างนอก

“เดี๋ยวค่ะ!!! ฉันมีคำถาม คือ แล้วพวกเราจะเรียนกันยังไงล่ะคะ” ยูเรโกะ กล่าวถามอย่างสงสัย

“ก็ง่ายๆ ในระหว่าง1เดือนนี้ พวกเธอ ไม่ต้องเข้าชั้นเรียน เอาล่ะ ไปเก็บของได้แล้ว มาที่หอจันทรา ก่อน2ทุ่ม”อ.ทาเคชิกล่าว ก่อนจะ เดินหายไปอีกคน

“ก็น่าสนุกดี” มิคาเอลมองตามอ.ทาเคชิ ด้วยสายตาเรียบเฉย ก่อนจะ ยิ้มเย็นๆ
