ผมจะบอกให้เป็นนัยละกันครับ ไม่แน่ใจว่าเป็นความลับทางการทหารรึเปล่านะ - -

วิเพียวๆ สามารถทำ M.def 100 ได้เท่านั้นครับ
จากนี้คือ stat ของ sage นะครับ
status ที่เกี่ยวกะ def ทั้งสองแบบคือ vit และ int
โดย vit เพิ่ม def ได้ 1 ทุกๆการอัพ 3 และ ได้ 2 ทุกๆ 9
และทุกๆ 4 จะเพิ่ม M.def ได้ 1

int ทุกๆ 3 เพิ่ม M.def ได้ 1 (ต้องให้ vit หาร 4 ลงตัวด้วย)
และ sage + 4vit และ +19 int ที่จ๊อบ 50

ดังนั้น ถ้าเราอัพ
int = 98 + 19
vit = 100 + 4

จากสูตรเราจะได้ M.def = 117/3+104/4 = 39+26 ได้ 65
และจะได้ def = 104/3 + (104/9)*2 = 34+22 ได้ 56
จากนั้นบัฟ Devine +19/35 เข้าไป
ก็จะได้ M.def 100 และ def 75 ครับ
def อีก 25 แซมบ้าปุ๊บ 100 พอดีเลย
