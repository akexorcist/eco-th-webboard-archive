Riot Hammer

Damage = A+B+C

โดย

A = HP ขณะออกสกิล /2 + Atk ตัวเอง
B = HP ปาร์ตี้ที่เหลือทั้งหมด ขณะออกสกิล /15
C = SP+MP ปาร์ตี้ที่เหลือทั้งหมด ขณะออกสกิล /5

ตัวอย่าง

จากเรปแรกๆ >> ตัวเรา Hp 4850 ไนท์ 5650 พระ 2422 รวมก็ 12922

กรณีที่ตอนใช้สกิล เลือดเต็มหมดทุกคน จะได้ Damage คิดได้แค่ส่วน A+B
เท่ากับ (4850/2) + ((5650+2422)/15) = 2,963 พอรวมค่า Atk ทั่วๆ ไป หลังถือ Mace ถ้าเวล 80 ก็คิดที่ +80
ได้ 3,073 (เพราะมันต้องได้โบนัส Atk จากการใส่ Rouse Body อีกเล็กน้อย)

ที่เหลือก็เป็นส่วน MP/SP ของคนอื่น ของเราไม่เกี่ยว! (ลองมาแล้ว)

คิดคร่าวๆ ว่า ไนท์สาย VIT กับพระสาย VIT/MAG สองคน มี SP/MP ตอนเต็มๆ
รวมใส่สกิลหลังบวกโน่นนี่ น่าจะได้รวมกันราวๆ 1,800-2,200 คิดที่ 1,800 นั่นแหละ

ไนท์ประมาณ 700+ พระราวๆ 1,100+ ไม่รวม Rouse Body/Mental จากค่าทั่วไป
และไนท์ส่วนมากไม่บ้าพอที่จะอัพ Increase SP Max แน่ๆ

C = 1,800/5 = 360

จากค่าคำนวณคร่าวๆ ได้ A+B+C = 3,433
