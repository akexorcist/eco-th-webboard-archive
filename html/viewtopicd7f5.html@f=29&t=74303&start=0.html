สามารถโพสสอบถามได้ในกระทู้นี้นะคะ
จากนั้น Neko จะรวบรวม คำตอบของคำถาม ไว้ หน้าแรก เป็น FAQ ต่อไปค่ะ :second05:


FAQ



1. การตั้งชื่อ ชุดเลเวล 99 นั้น สามารถตั้งชื่อ เป็นตัวอักษร ภาษาอังกฤษ เท่านั้นค่ะ

2. ในการโพสคำตอบให้ โพส รูปทั้งชายและหญิง ไว้ใน Reply เดียวกันค่ะ

3. ของรางวัล คือ เสื้อ +10 สามารถเลือกหิน Crystal ในการอัพเกรดได้

โดยแจ้งกับทีมงาน ตอน ที่ ยืนยัน รับของรางวัลค่ะ

4. ในการตั้งชื่อนั้น ต้องตั้งชื่อ ทั้ง Set Male & Set Female นะคะ

5. การ Edit Reply นั้น สามารถ ทำได้ 1 ครั้ง ต่อ 1 Reply

โดย ต้องแจ้ง GM ด้วยการ PM ก่อนทุกครั้ง และ [GM] เท่านั้น จะเป็นผู้แก้ไข Reply นั้นๆให้ค่ะ

6. สำหรับ การโพสเข้าร่วมนะคะ

1 Reply ต่อ 1 Member ของ Board ECO ต่อ 1 ID

ซึ่ง 1 ID นี้ ทางทีมงานจะตรวจสอบจาก 1 Character ที่โพสไว้

ตอนที่ ทำ การ ยืนยันตัวตนรับของรางวัลค่ะ

หากพบว่า เป็น เลขบัตรประชาชน เดียวกัน จะโดนตัดสิทธิ์ในการรับของรางวัล


7. สำหรับ การตั้งชื่อ ชุด Male Set / Female Set นั้นสามารถ ตั้งให้เหมือนกัน หรือ แตกต่างกันได้ค่ะ ไม่จำเป็นต้องเหมือนกันทั้งสอง SET นะคะ

รวมถึง การ ตั้งชื่อ ชิ้นส่วนอื่นๆ ใน SET ที่ สามารถ ตั้งให้เหมือนชื่อ SET หรือ แตกต่างจาก ชื่อ SET ได้ค่ะ


8. การรับของรางวัล เลือก รับได้ 1 SET ระหว่าง Male / Female และ 1 อาชีพเท่านั้นค่ะ


9. หากทางทีมงาน พิจารณาแล้ว พบว่า ไม่มี ชื่อที่เหมาะสม ทางทีมงานจะเลือก ชื่อที่เหมาะสมให้กับ ชื่อ ชุดนั้นๆ แทนค่ะ


10. สำหรับ Member ท่านใดไม่สามารถโพสรูปได้ ให้ ทำการ โพส ชื่อ Set ของอาชีพนั้น จากนั้นให้ PM มาแจ้ง Neko เพื่อให้ GM ทำการใส่รูปให้ได้ภายหลังค่ะ

11. สามารถตั้งชื่อเป็นภาษาอื่น เช่น ภาษาฝรั่งเศส หรือ เสปบนได้ แต่ต้องไม่มีอักขระพิเศษนะคะ เพราะ ไม่สามารถนำไปใช้ได้จริง

12. การตัดสิน เรื่อง ชื่อ ขึ้นอยู่กับทีมงานค่ะ ตามกติกา ค่ัะ
