คือ จะไม่อัพ int ก็ได้คับ เพราะ PvP ผมก็แช่ ติดเกือบตลอด

ถ้าเจอพวกสายนักเวทไม่ต้องเสียเวลาแช่หรอกคับ ยิงเวท ไปดื้อๆก้ตายแล้วคับ เลือดพันกว่าๆ

เวทเลเวล 5 mag 128 ยิงราวๆ 2พัน + คับ

ถ้าเปิด zen ก็ไม่ต้องคิด -*- แรงมาก

ส่วนใหญ่ ที่ยิง 4000+ ก็ล้มช้างแล้วคับ สสายไฟเตอร์เลือดเยอะๆ ส่วนใหญ่ราวๆ 2- 3พัน จะมี 4พันก็หลุดมาที ต้องใช้ครบ Set -*-

ส่วนใหญ่ zen+ยิงเวทธรรมดาก็แรงสุดๆแล้วคับ

เคยยิงลองกับเพื่อนในริง(ลุงแห้ว) เปิด zen+ยิงธรรมดา ไม่ต้องยิงแพ้ทาด ก็ราวๆ 5พันได้ -*-

เคยใช้ เวท ที่แถมมา ตอนเริ่มต้น เลเวล 1 ความแรง 120% เปิด zen ยิงเข้า 1200+ ใส่นักเวทก็ตายแล้วคับ (แถมร่ายไวด้วย 0.8 วิ เร็วยิ่งกว่าเอาคทาไปเคาะถึง 2-3เท่า ) ถ้าเจอสายไฟเตอร์ ก็น่าจะฟอสติดง่ายมากๆเพราะส่วนใหญ่เค้าไม่อัพ int กันหรอก -*-

แนะนำเล่น สาย Mag Dex แล้ว Int ก็แล้วแต่คับ Debuff เป็นแค่ปัจจัยรอง

สู้กันจิงๆ หยั่งกับ ซามูไร เจอ คาวบอย แลกคนละหมัดก็ตายแล้ว

ปล.Zen เปิดได้เฉพาะตอนสถานะปกติ หากสิงคนอยู่จะเปิดไม่ได้อ่าคับ
