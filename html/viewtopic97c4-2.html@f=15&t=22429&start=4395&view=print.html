เออเนอะDopไม่มี r - -

ถ้าจะว่าโง่ยังไง ก็คงต้องเข้าใจธรรมชาติของมันก่อน
การที่Dopจะไปโจมตีใครก็ต่อเมื่อ
1. ผู้ใช้ร่ายสกิวล็อคเป้าใส่เป้าหมาย ขอแค่ล็อคเป้าใส่พอ ร่ายติดไม่ติดอีกเรื่องนึง
2. Dopโดนโจมตี เมื่อโดนโจมตีมันจะหันไปโจมตีใส่เป้าหมายที่โจมตีมันทันที

ทีนี้ทำไมถึงว่าโง่?
- ถ้าจะเอาไปใช้เวว มันช่วยอะไรแทบไม่ได้เลย
เพราะพอเราล้อคเป้าที่มอนนั้น Dopจะไม่วิ่งไปหามอนทันที
ต้องรอซัก2วิได้หละมั้ง มันถึงจะเข้าโจมตีเป้าหมาย
นั่นหมายความว่า....กว่ามันจะวิ่งไปช่วยตีเป้าหมาย เป้าหมายที่เราเก็บเวว
มันก็คงตายไปแล้วหละ- - (เนี่ยคือความโง่ของมันอย่างนึง)
- มันวิ่งช้า...คือช้ากว่าเรา บางทีไม่เป็นอันทำมาหากิน

แต่มันก็มีประโยชน์อีกเยอะอะนอกจากความโง่ของมันด้านบน
เช่นว่าถ้าDopถูกโจมตี มันจะพุ่งเข้าใส่เป้าหมายทันทีอย่างไม่คิดชีวิต
และไล่ฟัดกับเป้าหมายจนกว่าจะตายกันไปข้าง

กะว่าหน้า300จะพูดถึงเรื่องการใช้สกิวหน่อย
ไม่รู้ว่าจะเป็นไง เพราะอยากให้หลายๆคนใช้สกิวเป็น
จะได้เล่นกันหนุกขึ้น จากที่สังเกตุมามีเยอะเหมือนกันใช้ไม่เป็น
ทีแรกกะว่าจะพูดเรื่องการอัพstatด้วย แต่มีรีฟรีไปก่อนละคงไม่ต้องกล่าวถึง

โอ้ คำผมโดนใจขนาดนั้นเชียว

ย้อนไปดูหน้าที่แล้ว มาเสริมข้อมูลด้วย Dex 99 กะ 108 เห็นด้วยกะคุณ krittakorn
เพราะสูตร Dex มัน... C.SPD = DEX x 3 +floor[(DEX+63)/9]^2 + 129

ถ้า Dex 99 ได้ C.spd = 750>>เหลือเวลาร่าย 25%
ถ้า 108 รู้กันอยู่ละว่า = 800>>เหลือเวลาร่าย 20%
ถ้าเทียบกับท่าที่ร่ายอย่างยาวๆของเราก็ RS เต็มๆ 8 วินาที
ถ้า DEX 99 ก็ใช้เวลา 2 วิพอดี
ถ้า DEX 108 ใช้เวลา 1.6 วิ
ความแตกต่าง 0.4 วินาที สำหรับร่ายปะทะมอนแทบไม่มีผล แต่สำหรับ PvP อาจมีผลบ้างเล็กน้อย

สำหรับท่าที่เร็วกว่านั้นอย่างเบิร์น 4.2 วินาที เวลาร่ายจะต่างกันแค่ 0.21 วินาที

ผมก็ใช้ 99 อยู่เหมือนกัน แม้มีความแตกต่างกันนิดหน่อย แต่แต้มที่ได้คุ้มที่จะไปลง vit int มากเลย
