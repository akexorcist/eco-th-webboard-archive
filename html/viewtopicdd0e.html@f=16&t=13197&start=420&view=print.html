1.คือถ้าผมจาทำตะกร้ากะเป้เองเนี่ย ใช้ทุนแพงกว่าซื้อของไม๊ครับ คือไหนๆเล่นBPแล้วก้ออยากจะผลิตของใส่เอง มันภูมิใจไงบอกมะถูก(เกี่ยวมะเนี่ย ) แล้วมีnpcเย็บผ้าป่ะครับ
