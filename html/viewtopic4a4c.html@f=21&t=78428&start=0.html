ประเดิมเป็นคนแรกละกัน

ชื่อ: ไฮน์ เอเก้น(Hein Eken)
อายุ : จะ30
เพศ : ชาย
เกิด : 11 พฤศจิกายน
เลือดกรุ๊ป : 0
ส่วนสูง-น้ำหนัก : 176ซม. 62กก.
การแต่งกาย : ไม่ค่อยใส่ใจเท่าไหร่ แต่ดูรวมๆก็เป็นพนง.ออฟฟิศอยู่ มักจะไม่เอาชายเสื้อเข้ากางเกง วันไหนขี้เกียจมากๆก็ใส่บ๊อกเซอร์ตัวเดียวอยู่ห้องไปเลย
รูปร่างลักษณะ : ตัวค่อนข้างสูง ผอม หน้าตาเหมือนคนไม่ค่อยกินอาหาร ผมก็กระเซอะกระเซิง
อาชีพ : NEET
สิ่งที่ชอบ : เหล้า เบียร์ กาแฟ เล่นเน็ท
สิ่งที่เกลียด : อะไรก็ตามที่ดูมีสุขภาพ วงดนตรีประเทศเกาหลี
นิสัย : เพี้ยนใช้ได้ และจะเพี้ยนหนักเมื่อมีแอลกอฮอลเข้าปาก ถึงขนาดระบำเตี่ยวกลางวงเหล้าก็มี ที่สำคัญ มันไม่เคยจริงจังกับชีวิต ชอบกินเหล้ายิ่งกว่าข้าว3มื้อ แต่ก็ยังพูดจากันรู้เรื่อง ใจกว้าง และเป็นคนมีอารมณ์ศิลป์อย่างไม่น่าเชื่อ ว่างๆก็มักขึ้นดาดฟ้า/หลังคาแล้วนั่งเล่นกีตาร์อย่างสบายอารมณ์
ความสามารถพิเศษ :เล่นกีตาร์ได้เป็นเรื่องเป็นราว แต่กลับไม่อยากตั้งวง สกิลภาษาอังกฤษดีมาก วาดรูปจำพวกโมเอะๆได้สวยจนเป็นที่รู้จักกันในเน็ท
ครอบครัว : อยู่ตัวคนเดียว ไม่เคยคิดจะกลับไปหาญาติ
เพิ่มเติม : อดีตพนง.ดีเด่นของบรษัทชื่อดังแห่งหนึ่ง แต่ถูกไล่ออกเพราะดันไปล้วงหน้าอกเมียหัวหน้าฝ่ายตอนไปดื่มที่บ้าน แต่โชคยังดีที่เขายังมีเงินเก็บอยู่พอสมควรจากการทำงาน ทำให้ไม่ต้องไปนอนใต้ทางด่วน เห็นท่าทางหมดไฟแบบนี้ จริงๆก็ยังมีฝีมือในการทำงานอยู่เยอะ เพียงแต่พี่แกขี้เกียจเท่านั้นเอง ปัจจุบันกำลังชาร์จไฟชีวิตและยังมีความคิดที่จะหางานใหม่ทำอยู่บ้าง โสดสนิท มีความรู้เรื่องเกมอยู่พอสมควรจึงทำให้คุยกับอิกนอร์ได้รู้เรื่องอยู่คนเดียวในหอ
ในห้องของหมอนี่ออกจะดูโอตาคุหน่อยๆ รกนิดๆ มีโมเดลกันดั้มและสาวน้อยจำนวน5-6ตัว โปสเตอร์อนิเมะ มีโน๊ตบุคอย่างดี PSP แต่ไม่ค่อยมีหนังสือการ์ตูนหรือแผ่นเกมให้เห็น กีตาร์โปร่งที่เป็นของหวงสมัยเรียนมัธยมปลาย ที่เหลือก็เป็นของใช้ทั่วๆไปอย่าง เตียง ตู้เย็น ตู้เสื้อผ้า โต๊ะวางคอมสภาพค่อนข้างดี เก้าอี้ล้อเลื่อนมีพนักพิง โต๊ะรับแขกแบบกระจก โดยรวมๆก็ดูหรูอยู่เหมือนกัน

ชื่อ อิกค์นอร์ โฟลิเทน ( ignore politen)

อายุ : 15
เพศ : ชาย
เกิด : 14 กันยายน
เลือดกรุ๊ป : B
ส่วนสูง-น้ำหนัก : 169 ซม. - 57 ก.ก.
การแต่งกาย : ชุดสบายๆ เสื้อยืด กางเกงยีนส์ ขาสั้นบ้าง ในเวลาอยู่ที่พัก หรือออกไปเที่ยว ปกติจะแต่งชุดนักเรียนตามกฎของ รร.(เชื้ตมีไท เกงสแลคสีดำ รองเท้าสีดำ)

รูปร่างลักษณะ : เป็นเด็กหนุ่มร่างสูงโปร่ง หุ่นกำลังดี ผมสีดำสนิทยามระต้นคอ ปกติจะหวีเรียบร้อย(ตอนไปเรียน) กลับมาจะกระเซิงทันที ตาสีแดง(คอนเท็คเลนส์)
อาชีพ : นักเรียนม.ปลายปี1 รร.ชื่อดังในย่านนั้น
สิ่งที่ชอบ : เกม สร้างเกม อนิเมชั่น เซิร์ตขุดข้อมูลในเน็ต ปล่อยโหลดเกม หานิยายอ่าน
สิ่งที่เกลียด : เน็ตหลุด ! ไฟดับ

นิสัย : ดูไม่ค่อยสนใจใครเท่าไหร่ตามชื่อ ==” แต่จริงๆ แอบสนอยู่ลึกๆ มักทำหน้าตาย หน้านิ่ง แต่ก็ไม่ได้หยิ่งตามหน้าตา ตามความคิดของตน(แต่คนอื่นไม่) ถ้าพูดเรื่องเกม จะน้ำไหลไฟดับมาก อย่างอื่นไม่ค่อยสนใจเพราะเบื่อด้วยความรู้ที่เกินวัย

ความสามารถพิเศษ : เกือบกลายเป็นฮิคคิโมริแต่ยังไม่ถึงขั้นนั้น วันๆเอาแต่คลุกอยู่หน้าจอคอม แทบจะไม่ค่อยไปเรียน เพราะด้วยความอัจริยะภาพของตนที่ฉลาดเป็นกรด แต่อย่างน้อยหนึ่งอาทิตย์จะไป 3 วัน ออกเที่ยวบ้างเดือนละครั้ง
รู้สึกว่ากำลังแอบสร้างเกมจากโปรแกรมที่หามาอยู่ ควบคู่ไปกับการเล่นเกมทุกชนิด

Ps. สรุป เล่นเกมได้ทุกชนิด จนเกือบเทพ ไอคิวสูงมากเรื่องวิชาการปรึกษาได้แต่จะเข้าใจหรือเปล่าก็อีกเรื่อง

ครอบครัว : มีพ่อแม่อยู่ที่ต่างเมือง(มากๆ) ไม่ค่อยสนใจลูก เพราะเหมือนจะได้เชื้อมาคล้ายๆกัน(คลุกอยู่กับสิ่งที่ตัวเองสนใจ)

เพิ่มเติม : ปกติจะมานั่งแหมะเล่นคอมโชว์ ไม่ก็ชวนเล่นสารพัดเกมของตนที่ด้านล่างหอในช่วงค่ำ ก่อนจะเข้าไปหมกตัวอยู่ในห้อง

ในห้องมีสารพัดเกมทุกชนิด ทุกประเภท ที่สามารถมาเล่นด้วยได้ แต่ไม่ให้ยืมออกไป เกมที่มักชวนเล่นคือไพ่ !(ดูดตังเอาไปพัฒนาเกม?) และ PS2 + WII ด้วยหน้านิ่งๆ

มีคอมประมาณ 3 เครื่อง ตั้งโต๊ะ 1 โน๊คบุ๊คอีก 2 คู่มือเกมอีกเป็นลัง พร้อมของพรีเมี่ยนจากเกม นอกนั้นเป็นหนังสือเรียนที่วางไว้เพราะไม่อ่านก็เข้าใจ (ที่เหลือก็ของตามแต่ที่ห้องพักควรมีครับ)

ชื่อ : เลอา เมดิสัน (Leah Medison)
อายุ : 26 ปี
เพศ : หญิง
เกิด : 31 มีนาคม
เลือดกรุ๊ป : A
ส่วนสูง-น้ำหนัก : 170 เซนติเมตร/ 45.5 กิโลกรัม

รูปร่างลักษณะ : รูปร่างปกติสมส่วนและ สูงกว่าผู้หญิงทั่วไปเล็กน้อย ตาดำ ผิวขาว ทรงผมเหมือนในภาพ (ดูภาพประกอบเพิ่มเติมได้ที่ส่วนรูปภาพ)
อาชีพ : อดีตนักดนตรีร็อคชื่อดัง ปัจจุบันผันตัวเป็นนักเขียนนิยาย Y (Yaoi เท่านั้น) ใช้นามปากกาว่า 'Lost and Found'

นิสัย : เมื่อก่อนเป็นคนเฮฮา สนุกสนาน แต่หลังจากถูกไล่ออกจากวงเพราะเผลอกระดกแก้วดื่มไปจนเมามายก่อนแสดง ทำวงขายหน้าในคอนเสิร์ตเมื่อสองปีมาแล้ว...จึงกลายเป็นคนเงียบๆ ไม่ค่อยมีสังคม ชอบอยู่ในโลกส่วนตัว ไม่สังสรรค์กับคนนอกเท่าไหร่นัก/ หมกตัวอยู่กับนิยาย Y...ชอบใส่หูฟัง และเปิดเสียงดังตลอด (ประมาณว่า ข้างบ้านทะเลาะกันซะบ้านแตก ก็ยังไม่ได้ยิน) ไม่ค่อยสนใจใครเท่าไหร่และนอนหลับง่ายสุดๆ
