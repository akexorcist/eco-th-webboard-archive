- ความเร็วโมชั่นการโจมตีไม่ขึ้นกับ ASPD (Enchanter ใส่ Speed ก็ไม่ช่วยให้เร็วขึ้น)
- เป้าหมายเคลื่อนที่ออกนอกระยะระหว่างใช้ท่า ก็จะไม่โจมตี
- ด้วยสภาพในตอนนี้(อ่านข้อ1) จัดว่าท่านี้อยู่ในระดับที่ "ห่วย" กว่า Blow ดังนั้นทำใจใช้ Beat Smash ยังจะดีเสียกว่า

นอกจากนี้อาวุธที่ใช้สกิลนี้ได้ ขอแค่เป็นแม่ค้าใส่ได้ แต่ไม่จัดเป็น Card หรือ Etc ก็สามารถใช้สกิลนี้ได้หมดครับ ไม่จำเป็นต้อง Mace only~

*ส่วนตัวถ้าจะถามว่าทำไมคิดว่ามันห่วยกว่า Blow... ผมว่า Blow 260%, ไร้ดีเลย์+ร่ายด้วย ASPD800
สามารถใช้งานได้จำนวนครั้งมากกว่าการใช้ Flower Card ครั้งเดียว และไม่ต้องห่วงเรื่องเป้าหมายหนีพ้นระยะอีกด้วย.... ส่วนดาเมจที่ได้ก็พอๆกันละมั้ง

======================
ATTACK ASSIST
ผลลัพธ์ : เพิ่ม Atk และ Matk ของเราให้กับเจ้าของร่าง เมื่อเราเป็นตัวสิง
=ย่อตาราง=
ติดตรงคำว่า "Atk.Matk ที่เพิ่มขึ้น"

กำกวมไปนิด ควรเพิ่มให้อ่านเข้าใจง่ายๆคือ
เอา % ของ Atk/Matk ของเรา เพิ่มให้เจ้าของร่าง

Example: LV5 40%
คนใช้สกิล Atk 800-1200 = min(800x40%)/max(1200x40%)+(min/max เจ้าของร่าง)
=min/max 320-480 + (min/max เจ้าของร่าง)

ดังนี้ครับ
