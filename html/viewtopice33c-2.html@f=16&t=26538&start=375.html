ลองทำ Japanese Floor มาแต่งบ้านดู .... ๕๕๕ พื้นปูบ้านของแท้
จัดเป็น Type : พื้นของสวนลอยฟ้า มีรูปร่างสีเหลี่ยม =A=

แต่ที่สำคัญกว่า ... เอาสีทาบ้านมาเล่นๆ พบว่า
1.ฐานของ Flying Garden - ทาสีได้ ทาแล้วสีหายไปเลย 1 กระป๋อง
2.ใบพัดของ Flying Garden - ทาสีได้ กินสีครั้งละ กระป๋องเช่นกัน
3.พื้นของ Flying Garden - พื้นตอไม้ว่างๆ ทาสีได้ แต่พื้นกลมๆ เช่น Teak Patchwork ทาสีไม่ได้
... แถมพอวางพื้นไม้แล้วถอดออก สีของพื้นตอไม้ที่เคยทาไว้ ดันหายไปดื้อๆ เลย
4.บ้าน - ทาสีไม่ได้ (บอกว่า ไม่สามารเปลี่ยนสีอะไหล่ได้ = =?)
5.พื้นบ้าน - ทาสีไม่ได้ พอวาง Japanese Floor ก็ยังคงทาสีไม่ได้
6.ผนังบ้าน - ทาสีไม่ได้ (บอกว่า ในที่นี้ไม่มีไอเทม)


ปล. ตะัลอนๆ ไปหา Row Wax ที่ดันทวีป ... บินกลับเมืองมาอีกที มีกล่องติดมา 25+ ใบ
ปล2. ตะลอนๆ ไปหา Row Cement ที่ Killer Bee Hill ... บินกลับเมืองมาอีกที ก้มีกล่องติดมา 15+
