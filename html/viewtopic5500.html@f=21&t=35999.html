=== บันทึกการจีบสาว บทที่ 1 ===
ว่าด้วยเรื่อง
1. การปรับเปลี่ยนความคิดตัวเอง
มันคืออะไร ? การปรับเปลี่ยนความคิดมุมมองและทิศนคติต่อตนเองและผู้อื่น
ปรับอย่างไร ? เลิกดูถูกตัวเองไม่ว่าจาเปน นิสัย หน้าตา บุคลิก
เราไม่ด้อยไปกว่าใครไม่ดีไปกว่าใคร มั่นใจว่าเราก็เปนแฟนกับคนที่เราชอบได้
เท่าเทียมกับผู้ชายทุกคน ที่มาจีบผู้หญิงคนเดียวกัน~
เลิกดูถูกผู้อื่นด้วย ? เปิดใจให้กว้าง ยอมรับในสิ่งต่างๆที่เขาคนนั้นเป็น ผู้หญิงทุกคน
ก็เท่าเทียมกันอย่ามองแต่เพียงภายนอก(การแต่งตัว หน้าตา) เปิดตาให้กว้างมองออก
ไปรอบๆตัวเรา มีใครบ้างที่มีความรู้สึกดีดีให้กับเรา การจีบหญิงคนนึงแบบไม่สนใจสิ่ง
แวดล้อมรอบข้างเพื่อนเขา เพื่อนเรา มันย่อมไม่เป็นผลดีแน่นอน *-*
2. การทำความรู้จัก
เพิ่มความกล้าให้กับตัวเอง เอาความผิดหวังมาเป็นแรงผลักดันและกำลังใจกับตัวเรา
คนที่ขี้อายไม่กล้าพูดกับคนที่ตัวเองชอบ ย่อมไม่มีทางประสบความสำเร็จ ความกลัว
ที่จะล้มเหลวตั้งแต่ยังไมเริ่มต้นนั้นย่อมทำให้เราพลาดโอกาศดีดีไปอย่างง่ายดาย
!!! กล้าได้ อายอด ช้าจะหมด อดแดรกนะง้บ !!!
ความรักไม่ใช้การครอบครอง อย่าเอามันมาอ้างกับการกระทำผิดๆ จงใช้มันเป็นสะพาน
ก้าวข้ามอดีตอันเจ็บปวด เริ่มต้นเดินไปข้างหน้าซักที การจมอยู่กับอดีตมันจะพบกับ
ความสดใสในอนาคตได้อย่างไร ชิมิ -0-
จาก ประสบการณ์อันยาวนานได้บอกเอาไว้ว่า การขอเบอสาวในที่สาธารณะนั้นเป็นสิ่ง
ที่ควรจะกระทำในเวลาและสิ่งแวดล้อมอันควร
เวลาอันควร ? ขณะที่เธอคนนั้นกำลังว่างพักผ่อนอยู่ด้วยการทานขนม พูดคุยกับเพื่อนสนิท
อย่างสนุกสนาน เดินเล่นในสถานที่ต่างๆอย่างสบายใจ
สิ่งแวดล้อมอันควร ? ขณะที่เธออยู่กับเพื่อนสาวไม่เกิน 2 คน(รวมเธอเป็น 3 คน)
เป็นสิ่งแวดล้อมที่กะลังเหมาะสมเป็นอย่างมาก รวบรวมความกล้าแล้วเดินเข้าไปทักทาย
แบบเป็นธรรมชาติด้วยรอยยิ้ม - 0 -
สถานที่อันควร ? ตามประสบการณ์แล้ว มหาลัยและโรงเรียนเป็นสถานที่ง่ายต่อการทำ
ความรู้จักเป็นอันมาก สถานที่พักผ่อนต่างๆ เช่นสวนสาธารณะ ที่เรียนพิเศษ สถานที่ท่อง
เที่ยว เช่นสวนสนุกก็น่าสนใจนะ มิมิ แต่มันก็ไม่เสมอไปหรอก สำหรับสถานที่ไม่เหมาะ
สมอย่างบนรถโดยสาร(รถเมย์น่ะ) เราอาจจะเจอสาวน่ารักๆ ได้บ่อยๆแต่ยากยิ่งนักที่จะขอ
เบอสาวบนรถเมย์แล้วเธอจะให้อ่านะ แต่ท่าเรามีความกล้าพอแล้วมีดวงที่เธอคนนั้นมานั่ง
ข้างๆเราล่ะก็ ลองชวนเธอคุยซักนิดก่อนแล้วค่อยขอเบอนะ เธออาจจะให้เราก็ได้ มิมิ
3. การพูดคุย
ได้เบอร์ ของคนที่เราฃอบมาแล้วจะคุยอะไรดีน้า มิมิ เวลาที่เหมาะสมคือหลังจากที่เธอ
ทานข้าวเย็นแล้วซักพัก เป็นช่วงเวลาที่เธอน่าจะกำลังพักผ่อนด้วยการดูทีวีหรือละคร
ท่าไม่ใช่พวกบ้าดาราติดละครมากเกินไป เวลานี้เธอคงจะคุยกับเราได้แบบไม่ติดธุระ
การทักทาย ด้วยการสวัสดีใช้ได้ดีในทุกโอกาศ แต่การพลิกแพลงคำทักทายในหลาก
หลายรูปแบบจะทำให้เธอรู้สึกตื่นเต้นและประทับใจกับการที่ได้คุยกับเรามากยิ่งขึ้น
ประมาณว่าแค่โทรมาเธอก็อยากรู้แล้วว่าเราจะทักทายเธอว่าอย่างไรในวันนี้
โทรนานแค่ไหนถึงจะดี ? ระยะเวลาการโทรอันเหมาะสมนั้นขึ้นอยู่กับจังหวะเวลา
แต่สิ่งสำคัญไม่ใช่ การนับเวลานาที หรือชั่วโมง แต่เป็นความรู้สึกทของเราและเธอที่อยาก
จะคุยกันนั้นมีมากแค่ไหน เราและเธอต้องการจะคุยกันนานเพียงไรต่างหากล่ะ มิมิ
บางครั้งการคุยกันเพียง 5 นาทีอาจจะทำให้เธอรุ้สึกดีมากกว่าการคุยกันยาวนานหลาย
ชั่วโมงก็เป็นได้ อย่าเอาแต่ใจอยากคุยกับเธอนานๆทั้งที่เธอมีธุระ หรือสิ่งที่จะต้องไปทำ
คุยเรื่องอะไรถึงจะดี ? ในบางครั้งท่าเป็นผู้หญิงที่คุยเก่งอยู่แล้วมันก็คงจะไม่ยากในการ
ชวนคุยหลายเรื่อง ทั้งมีสาระและไร้สาระแต่ท่าเธอเป็นคนที่คุยไม่เก่งนั้นควรจะทำอย่างไร
ในระหว่างที่เธอกะลังเงียบ ท่าเราก็เงียบไปด้วยบรรยากาศดีดีคงหมดไปในทันที่เลยทีเดียว
กับผู้หยิงแบบนี้ มีทริคอยู่ว่าการพูดคุยในเรื่องที่เธอชอบนั้นมันช่วยให้เธอ สามารถคุยได้เป็น
อย่างดีเพราะเธอนั้นรู้จักมัน และพร้อมที่จะแสดงความคิดเห็นของเธอในเรื่องที่เธอนั้นชอบ
เช่น เพลง หนัง การ์ตูน - - หนังสือ นิยาย หรือบางคนอาจจะชอบการสะสมของต่างๆ
คำพูดหวานๆ ? ไม่ควรจะพูดหวานหรือชมหรือเอาใจเธอมากจนเกินไป พูดในแบบที่พอดี
หวานซักนิดให้เธอรู้สึกเขิน อายบ้าง บางครั้งเธออาจจะใจเต้นเวลาที่เราพูดหวานๆกับเธอ

4. เรื่องส่วนตัว
คนเราทุกคนไม่ว่าหญิงหรือชาย ย่อมมีเรื่องส่วนตัว ย่อมต้องการที่จะมีเวลาเป็นส่วนตัว
การที่เราไปซักไซร้ไล่เรียง ถึงจะอยากรู้แต่หารู้ไม่ว่า การไปซักถามถึงเรื่องแบบนี้บ่อย
ครั้งกลับกลายเป็นการขุดหลุมฝังตัวเอง แทนที่จะได้คุยกันสนุกสนานกลายเป็นการจ้อง
จับผิด ถึงจะอยากรู้แค่ไหนเราก้ควรจะให้เธอเป้นฝ่ายอยากพูดออกมาเองมากกว่าไป
พยายามซักถามกับเรื่องส่วนตัวของเธอ เช่นอย่างไรบ้างลองมาดูกัน
ex 1 คำถามประเภทอยากรู้มากเกินควร
เรา : ทำอะไรอยู่เหรอ
เธอ : อยู่ข้างนอกจ้า
เรา : อยู่ไหนเหรอ
เธอ : เซ็นทรัลเวิลจ้า(หรือสถานที่ชอบปิ้งอื่นๆ)
เรา : อยู่กับใครเหรอ
เธอ : เพื่อนจ้า
เรา : เพื่อนกี่คนเหรอ
เธอ : หลายคนน้า
เรา : เพือนชายหรือหญิง
เธอ : ก้มีทั้งชายและหญิงแหละจ้า
เรา : อ่านะไปกับผู้ชายสินะ
เธอ : แปร่ว
เรา : อืมๆชั่งมันเหอะแค่นี้แหละ
เธอ : = =!!
end ex1 ประเภทนี้ เป็นประเภทอยากรู้เรื่องส่วนตัวเค้ามากเกินไปเค้าจะไปกับใครเราไม่
ควรเข้าไปยุ่งนะ มันจะกลายเป็นว่าเราไปละเมิดเรื่องส่วนตัวของเค้า เค้าคงไม่คิดหรอกว่า
จริงๆแล้วเราอาจจะเป็นห่วง แต่คงคิดว่ามันจาถามไรนักหนาวะ เหอๆ
จริงๆแล้ว ถ้าแค่รู้ว่าเค้าไปเที่ยวที่ไหนแล้ว เราก้ควรจะบอกว่า
เที่ยวให้สนุกนะครับ หรือ เที่ยวเผื่อด้วยน้า ก้พอแล้ว
ex 2 คำถามประเภทเซ้าซี้
เช่น คุณต้องการชวนเธอออกไปเดทกันซักครั้งในวันหยุดของสองเรา วันดีดีแบบนี้พลาด
ไปก้เสียดายแย่ คุณจึงมีความต้องการที่จะประสบความสำเร็จในการชวนเธอเดทครั้งนี้
เรา : นี่วันเสาร์นี้ว่างมั๊ยไปดูหนังกันนะ
เธอ : พอดีเราต้องไปทำรายงานกับเพื่อนอ่า
เรา : (แย่ละผิดแผน)อ่า ไปทำรายงานกับเพื่อนวันอื่นมะได้เหรอ
เธอ : เรานัดเพื่อนไว้ก่อนแล้วอ่า
เรา : ไปกับเราเถอะน้า เด๋วเราเลี้ยงเองก้ได้
เธอ : คือเราไม่ว่างจริงๆนะ
เรา : ทำไมอ่ะ ไม่อยากไปกับเราเหรอ
เธอ : ไม่ใช่น้าก้ไม่ว่างจริงๆอ่า
เรา : ทำไมอ่ะ ไปกับเพื่อนวันอื่นแทนมะได้เหรอ
end ex2 คำถามแบบเซ้าซี้ ยิ่งจะทำให้เธอไม่อยากไปกับเรามากขึ้นไปอีกในการชวนเดท
ข้อ สังเกต 1 ถ้าเธออยากจะไปกับเราจริงๆ หลังจากที่เธอบอกว่าไม่ว่าง
เธอจะบอกกับเรามาเองว่า เป้นวันอื่นแทนได้มั๊ย
ถ้าเธอไม่พูด แสดงว่าเธออาจจะยังไม่อยากไปกับเรา หรืออาจจะยังไม่ไว้ใจ
อาจจะต้องใช้เวลาอีกซักพัก ลองให้เวลาเธอดู ถ้ามันไม่เวริคก้ทำใจซะดีกว่า -0-

5. ของขวัญ
ของขวัญ ควรจะให้เฉพาะในโอกาศพิเศษต่างๆเท่านั้น ไม่ควรจะให้พร่ำเพื่อ หรือเรียกว่า
อวดรวย ให้มันแทบทุกสับดาห์ หรือแทบทุกครั้งที่เจอกัน แต่ถ้าเป็นดอกไม้ซักดอก
หรืออมยิ้มซํกแท่งล่ะก็จะให้ ทุกครั้งที่เจอกันก้มะเปนรัยนะ คิคิ
ให้ อะไรดีล่ะ สำหรับผู้หญฺงที่เราชอบ เราควรจะให้อะไรดี
ตุ๊กตา หรือของขวัญสิ้นคิด เป็น 1 ในของขวัญอันดับต้นๆที่ ผู้ชายส่วนใหญ่เลือก
เพราะคิดว่า สาวๆคงชอบของแบบนี้ ก็เป็นของขวัญที่ดีนะ น่ารักน่ากอดดี แต่ว่านะ
ตุ๊กตาของคุณมันก้จะเข้าไป จมอยู่ในกองตุ๊กตาของเธอ แล้วแบบนั้นมันจะมีความหมาย
อะไร มันก้เป็นได้เพียงแค่ตุ๊กตาที่ กองอยู่รวมๆกับของผู้ชายคนอื่นแค่นั้นเอง *-*
แล้วอะไรดีล่ะ ถ้าจะซื้อของขวัญให้กับผู้หญิงซักคนน่ะ
ผม ขอเสนอของขวัญในหัวข้อต่อไปนี้ สำหรับคุณที่มะรุ้จาซื้ออะไรดี
รองเท้า เป็นสุดยอดของขวัญที่มีความหมายมากสำหรับผู้หญิงนะ
เพราะอะไรน่ะเหรอ ก้เพราะว่าคนที่จะซื้อรองเท้าให้คนที่ชอบได้นั้น จำเป็นจะต้อง
เป้นคนที่เอาใจใส่เธอเป็นอย่างดีนั่น ก้เพราะว่า คุณมะได้มองเธอที่แค่หน้าตารูปร่าง
แต่คุณยัง ใส่ใจไปจนถึงรองเท้าของเธอ รู้แม้กระทั่งว่าเธอใส่เบออะไร ชอบแบบไหน
และถ้ามันเป็น ที่ถูกใจเธอจะใส่มันออกมาเดินเคียงข้างคุณ วันนั้นมันจะมีความสุขมาก
เลยล่ะ ถ้าแบบนั้นคุณก้จะเป้นคนที่โชคดีมากๆเลยด้วยนะ ^^"
ลิบสติก-แป้งพับ อีกนึงในเครื่องสำอางราคาไม่แพง และสาวๆใช้กันเกือบทุกคน
เป็นสิ่งที่คุณทั้งหลายมองข้ามมาเสมอใช่มั๊ย เป็นอีกสิ่งนึงที่แสดงถึงการเอาใจใส่กับเธอ
สีอะไรที่เธอชอบใช้ หรือชอบพกพาไปไหนต่อไหนตลอดเวลา คุณยังรู้แม้กระทั่งแป้ง
ยี่ห้อไหนที่เธอชอบใช้ เธอคงมองเห็นคุณในกระจกเวลาใช้มันเสมอๆแน่ๆเลยล่ะ
สมุดโน๊ต สมุดจดโน๊ตเล่มเล็กๆ สำหรับจดบันทึก หรือเป็นไดอารี่ประจำวัน
สำหรับคนที่คิดว่าตัวเองเป็นคนโรแมนติกบ้างเล้กน้อย มันไม่ใช่แค่สมุดธรรมดาแน่นอน
เพราะเรา จะเขียนสิ่งที่อยากจะบอกเธอออกจากหัวใจ แต่ไม่กล้าพูดต่อหน้าเธอ
เราจะเขียนมันลงในสมุดโน๊ตเล่มนั้น ในหน้าสุดท้ายพร้อมกับห่อเป็นของขวัญ
แล้วมอบให้กับเธอ วันไหนที่เธอเผลอไปเปิดอ่านหน้าสุดท้ายเข้า วันนั้นเธอจะคิดถึงคุณ
แล้วอาจจะแอบยิ้มกับถ้อยคำแปลกๆ ที่คุณได้เขียนมันลงไปจากใจก้ได้
