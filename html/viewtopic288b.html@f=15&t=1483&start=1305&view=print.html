ก็เอาไว้ต่อท้ายเลย (คนอ่านจะได้ไม่สับสน)

1.ชาแมนยิงเวทย์แรงที่สุดในเกมส์เปล่าครับ (ถ้านับแพ้ธาตุด้วย)
ข้อนี้จะชอบมากเลย ถ้าตอบเป็น ตอนต้นเกมส์ กลาง จนถึงท้ายที่สุด

2.ชาแมนหลังเปลี่ยนเป็น Class 2 elementaler และ enchanter
บทบาทหน้าที่ในปาร์ตี้จะเป็นไงครับ เช่น สนับสนุน ยิงเวทย์ อื่นๆ

3.อยากรู้ว่าหลังๆเกมส์อ่ะ สถานที่เก็บเลเวลส่วนใหญ่จะเป็นดัน มืด อะไรทำนองนี้
แล้วชาแมนจะเอาอะไรไปสู้ครับ

4.ชาแมนเก็บเองเลเวลได้มั้ยครับ หรือต้องหรือสิง-แช
(ตอนแรก >>>> กลาง >>> ช่วงหลัง เลเวลสูง)

5.อยากให้กระทู้ Shaman Guide เป็นแบบของ Wizard หรือ ของ Warlock อ่ะ
ที่รวบรวมแนวทางการเล่น วิธีการ คำแนะนำต่างๆไว้ คิดว่าน่าจะเป็นไปได้ไหม

6.อยากรู้ว่าที่ตอบว่าสามารถเล่นได้ครบทุกธาตุเมื่อเลเวลจ๊อบ 40 คือเราไปทำ Event Skill Pointด้วยเปล่า หรือไม่ทำ

7.ทำไมถึงแนะนำให้เล่นธาตุลมอ่ะครับ (ตอนแรก)ทำไมไม่เล่น 2 สายอ่ะจะได้สมดุลกว่า

7.ทำไมถึงแนะนำให้เล่นธาตุลมอ่ะครับ (ตอนแรก)ทำไมไม่เล่น 2 สายอ่ะจะได้สมดุลกว่า




1. ช่วงแรกๆ ความแรงคงจะไม่ต่างกัน มาก ช่วงกลางๆ ความแรงคงจะสู้ สายอื่นไม่ได้ ช่วงหลังคือช่วงที่ได้สกิลจ๊อบ 40 มาใช้ ชาแมนก็จะยิงแรงที่สุด

2. ก็คงจะเหมือนตอนเป็นชาแมน นั้นละครับ เพราะส่วนใหญ่ มีแต่สกิล ที่เพิ่มความแรงของเวท

3. ก็คงจะใช้เวท ที่เราอัพไปสู้ หละคับ ไปกันเป็นปาร์ตี้ แต่ถ้าไป คนเดียวคงจะลำบาก

4. ช่วงแรกๆ ก็ เก็บเองได้ พอช่วงกลางๆ มอนเตอร์มี atk ที่แรงขึ้น ถ้าจะไปคนเดียว ก็คงจะลำบาก (exp อาจจะขึ้นช้ากว่าไปกันเป็นตี้) ช่วงหลังเลเวลสู้ ก็ ควรจะเป็นเป็นตี้ครับ

5. อันนี้ คงต้องให้บีทจัง มาทำ คริคริ ( เจ้าของกระทู้ )

6. ถ้า ไม่ทำก็ได้ ครับ แต่ยังไงก็ต้องทำ Event Skill Point อยู่แล้ว อยากอัพ สกิลอะไร ก็ ต้อง เพื่อ 4 ธาตุ ตอนจ๊อบ 40 ไว้ 28 พ๊อย นะคับ (ลองคำนวนดูนะคับ)

7. ในความคิดของผม เล่น เวทลม เก็บ เลเวล ง่าย กว่าครับ แล้วที่แนะนำให้อัพเวทเดียวก่อน เพราะว่า จะได้ เอาพ๊อย ไปอัพสกิล Increase Max Mp กับ Increase Mp Recovery จะทำให้เราเก็บเลเวลง่ายขึ้น แล้วหลังจาก นั้น อยาก จะอัพเวทไรต่อก็ คำนวน พ๊อยให้ดีๆนะคับ ถ้าไม่อยากจะ รีสกิลตอนหลัง

ปล. ถ้าผม ผิดพลาดตรงไหน หรือ ยังตอบไม่กระจ่าง ก็ช่วยเพิ่มเติมได้นะคับ
