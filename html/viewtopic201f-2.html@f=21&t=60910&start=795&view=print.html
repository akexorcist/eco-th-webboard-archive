- จิ้นเองซะส่วนใหญ่ นิสัยคัดลอกมาจากตัวเองแล้วมาเพิ่มให้เด่น(คนอื่นบอกว่าเราเข้ากับคนอื่นง่าย เลยเติมมากเข้าไป)

6.ถ้าวันนี้เป็นวันปิด ฟิคชั่น เรื่องนี้ อยากให้ตัวละครทำอะไร :
