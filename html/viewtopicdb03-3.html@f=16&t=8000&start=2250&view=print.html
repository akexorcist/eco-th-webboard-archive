มันก็เพิ่มspทีละ20เท่ากัน รู้สึกเสียดายพอยเอามากๆ


Picnic ใช้ได้ทุกที่ ทั้งข้างนอกและในดัน ถ้าจะให้เพิ่มเยอะๆต้องไปนั่งให้ตรงจุด Picnic (*เรื่องจุด Picnic มีกระทู้อยู่ในหมวดนี้แหละ ลองหาดูนะ)

Cave Bivouac ใช้ได้เฉพาะในดัน ถ้านั่งปกติก็เพิ่มเท่าๆ Picnic แหละ แต่ ถ้าไปใช้ตรงมุมๆหน่อยจะเพิ่มเยอะมาก ต้องเป็นมุมนะ ชิดผนังด้านเดียวก็ยังเพิ่มไม่เยอะจนรู้สึกได้ซักเท่าไหร่ แต่ถ้าชิดขอบสองด้านละก็ สุดยอดด ไม่ต้องถึงกับเป็นผนัง แค่เป็นกองหิน หรือเสาก็ใช้ได้แล้ว ลองดู



จุดของปิคนิกประมานไหนครับบมี100กว่าน่าแน่ะหุหุห
