ในการใช้ บังคับว่าต้องมี Killer land only หากไม่มีนั้น จะเป็นสกิลขยะอย่างมาก

มีประโยชน์ใช้ใน NVN เท่านั้น ซึ่ง Strike blow จะเป็นท่าที่จัดการ SU ปรกติ ที่ไม่ใช่สาย VIT ตัวที่แยกวง หรือกำลังหนีอยู่ได้ดี่ที่สุด ทีเดียวตายเกือบทั้งหมด ถึงแม้ว่า ผมจะไม่ได้อัพ INT เลย ก็ยังโดนไม่ต่ำกว่า 80% (ไม่นำ Gunner มานับ เพราะ MISS หมด)

แต่หากจะใช้ในการตะลุมบอนนั้น ส่วนใหญ่จะไม่เหมาะสม ด้วย Delay 2 วินาที ถ้ากด SDC และจะเป็น 4 วินาที หากลืมกด SDC ซึ่ง โดนคนอื่นสกรัมตาย 100% นอกจากนี้ พวกที่เลือดและ VIT น้อยๆ ยังไงก็ไม่หลุดมาให้เสียบที่แถวหน้าแน่นอน (ยังไง ATK Rand/Gravity ก็ดีที่สุด)

ประโยชน์ที่ผมสังเกตุอีกอย่างหนึ่งของท่านี้คือ แม้ว่าคนโดนจิ้มจะยังไม่ตาย แต่จะมีการเกิด การหยุดนิ่งไปประมาณครึ่งวินาทีจากการ lagging ของภาพ action ของคนที่ถูกจิ้ม ซึ่งจะเป็นจังหวะที่พรรคพวกที่เหลือ ที่กำลังตามมา เชือดอย่างไม่ปราณี กรณีนี้ มักได้ใช้กับพระ VIT 100 ที่กำลังหนี

อย่างไรก็ตาม ตามความเห็นผม ใน NvN เป็นท่าที่สำคัญอันดับ 3 ของ BH เลยทีเดียว ฮ่าๆๆๆ

:twisted:
