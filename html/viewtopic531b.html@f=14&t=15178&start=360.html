ไม่ได้มาตอบซะหลายวัน

เริ่มมีคนเสนอแนวทางการเล่นกันบ้างแล้วอิอิ
จิงๆตอนเป็น fencer ถ้าอยากให้ไวสุดก็คงต้องเล่น str dex ไปไล่ทุบ ซินามอนนะคับ
หรือไม่ก็ไปตีไพ่ สองอย่างนี้คือไวสุดแล้วสำหรับแช1-1 หรือไปเดี่ยวๆ

ถ้ามีตี้ประจำก็อาจจะ เล่น vit ลากดันใต้พอได้ แต่ถ้าจะเล่น agi ยาวๆผมว่าในช่วงที่เป็น
fencer นี้อาจจะเหนื่อยหน่อยเพราะหลบไรไม่ได้เลย เลือดน้อยฟันไม่แรง ไม่คริ จะต่างกับ swordman กับ scout ที่เลเวลเท่าๆกันอยู่พอควร

ความเห็นผมคือถ้าอยากเล่น agi ก็ควรรอไปรี stat ตอนเป็นไนท์แล้วจะดีกว่าเพราะสกิล
สนับสนุนจะมีให้ใช้ได้ตั้งแต่ job ต้นๆเลย ยิ่ง agi ปลายๆเยอะๆแล้วจะรัวเสียยิ่งกว่าเบลดมาสเตอร์สาย agi อีก (แต่ไม่คริเท่านะ แต่ติดเบิ้ลแทน)

สาย vit ก็อย่าน้อยใจไป dimissory spear ก็มีดีใช้ได้ อาจจะลำบากกว่า senpuken หน่อยในการใช้ แต่ถ้าฝึกลากดีๆก็สามารถกวาดมอนเปนกลุ่มๆได้ดีทีเดียว (ต้องหันหน้าเข้าหามอนเวลาใช้สกิลให้มอนตามเรามาเปนฝูงๆแล้วหันกลับไปกวาด)

เล่นไนท์ทำใจอย่างครับไม่ใช่อาชีพฉายเดี่ยว แต่ถ้าเป็น DS แล้วก็จะน่ากลัวกว่าถ้าเล่น agi

พิจารณาการเลือกอาวุธ กับสกิลตามนี้ก็ได้ครับ
อาวุธสำหรับไนท์ เลือกได้สามอย่าง ดาบเรเปีย หอก1มือ หอกสองมือ
ถ้าเล่น fencer job50 อาจจะเลือกเล่นอาวุธได้ 2 ใน3 อย่างเลย

1.เรเปีย ดาบยาวแบบแทง ถือโล่ได้
สกิลที่ใช้ร่วมกับดาบนี้ได้ ตอนเป็นไนท์: holy blade ,divine spear, strike spear,cyclone spear valkyrie,arm trust(ไม่สามารถใช้ dimisory spear ได้)
passive skill ที่ต้องอัพสำหรับสายนี้ word mastery,rapier mastery,shield mastery
spear strike2
วิเคราะห์: คนมักไม่ค่อยนิยมเล่นดาบเรเปียเพราะมันไม่มีสกิลเร่งความเร็วโจมตีได้ แต่เนืองจากดาบเรเปีย นี่ถือเป็นอาวุธประเภทดาบ ดังนั้นถ้าเรามีเพื่อนเป็นนักดาบ
ที่มีสกิล sword delay cancle มาสิงก็จะสามารถใช้สกิล sdc (ผ่านเพื่อน)ได้
และถ้าอัพ spear strike2ก็จะทำให้โจมตีเบิ้ลได้ เร็วแถมใส่โล่ได้ด้วย
เรเปียเป็นอาวุธที่สวยงามมีให้ใช้เกือบทุกระดับเลเวล เหมาะกับคนที่มีเพื่อนเป็นนักดาบ
หรือมีเพื่อนๆแชกันบ่อยๆจะเลือกเล่นสาย rapier ก็ได้ครับ สกิลโจมตีเด่นๆก็ใช้สกิลไนท์ได้เกือบหมดยกเว้นท่าหมู dimissory spear เท่านั้นที่ใช้ไมได้ และเป็นอาวุธประเภทเดียวที่ใช้ holy blade, valkyrie ,arm trust ได้ แต่ความแรงโดยรวมก็ยังสู้ divine หรือ strike ไม่ได้ จุดด้อยของเรเปียที่เห็นได้ชัดคือไม่มีท่าหมู่ใช้ในช่วงแรกๆเลย โดยสรุปถ้าจะเล่นเรเปีย ควรเล่นสาย agi มีเพื่อนเป็นนักดาบสิงจะดีที่สุด หรือเหมาะกับในช่วงบั้นปลายชีวิตไนท์มากกว่า ที่ได้สกิลแรงๆ เช่น divine,strike หรือ cyclone มาแล้วตอนหลังๆอาจจะเลือกรีสกิลเอาเรเปียมาใช้แทนหอกมือเดียวครับ เนื่องจากมี mastery เฉพาะทางทำให้โจมตีแรงกว่าหอกมือเดียวอยู่เล็กน้อย

2.หอก1มือ ถือโล่ได้
สกิลที่ใช้ร่วมกับหอกได้:divine spear strike spear dimissory spear spear cyclone
passive skill ที่ต้องอัพสำหรับสายนี้:spear mastery,shield mastery
วิเคราะห์:หอกมือเดียวเป็นอาวุธที่เหมาะสมกับไนท์สาย vit ที่สุด เพราะสามารถใช้สกิล dimissory spear ซึ่งเป็นสกิลหมู่ในช่วงแรกของไนท์ได้ดีที่สุด และถือโล่ได้ด้วย โดยรวมๆนั้นถือเป็นอาวุธที่สมดุลใช้ได้ตั้งแต่ช่วงต้นๆ fencer ยาวจนเป็นไนท์เลย ข้อเสียที่สำคัญคือ
หอกมือเดียวในช่วงเลเวลกลางๆ 40+ นั้นจะทิ้งช่วงห่างมากทำให้กว่าจะได้ใช้หอกอันใหม่ก็หลายเลเวลอยู่ อีกทั้งพลังโจมตีหลังๆเมื่อเทียบกับหอกสองมือ หรือเรเปียแล้วก็ยังเบากว่ากันมาก เนื่องจากอาวุธอีกสองแบบหลังนันมี mastery เฉพาะตัวกันอีก ทำให้ความรุนแรงของหอกมือเดียวเทียบกับอาวุธอีกสองชนิดก็จะเบากว่า

3.หอก2มือ
สกิลที่ใช้ร่วมกับหอกได้:เหมือนหอกมือเดียวแต่เพิ่ม spear strike2
passive skill ที่ต้องอัพสำหรับสายนี้:spear mastery,2-hand spear mastery,spear strike2
วิเคราะห์:หอกสองมือเป็นหอกที่มีพลังโจมตีสูงที่สุด แต่แลกกับการที่ไม่สามารถถือโล่ได้
ดังนั้นสายนี้จึงเหมาะกับสาย agi มากกว่า เพื่อผลของสกิล SDC + spear strike2 จะ
สามารถจัดการกับมอนได้รวดเร็วมาก และสายนี้ก็จะใช้สกิลต่างๆได้คล่องแคล่วว่องไว
กว่าสาย vit มากด้วย สกิลโจมตีไหนใช้กับหอกมือเดียวได้หอกสองมือก็ใช้ได้หมดครับ
ส่วนมากแล้วการใช้หอกสองมือก็เลือกใช้ได้ทั้งเป็นอาวุธหลักสำหรับสาย agi และเป็นอาวุธรองสำหรับสาย vit ได้ด้วย ถ้าเล่น job40+นั้นก็น่าจะมีสกิลพอสำหรับเลือกที่จะอัพได้ทั้งสกิลของหอกมือเดียวและสองมือครับ ข้อเสียของหอกสองมือที่เห็นชัดก็คือใส่โล่ไมได้นั่นเองทำให้ def mdefและ avoid ลดลงอย่างเห็นได้ชัด ยิ่งเลเวลสูงๆนี่ถือโล่กับไม่ถือก็ต่างกันพอควรเลยทีเดียว

สกิลที่ job50 เป็นสกิลป้องกันการแทง มอนที่ใช้การโจมตีแบบแทงมีไม่กี่แบบ
แล้วก็ไม่เก่งเท่าไหร่ด้วย และในpvp ก็ใช้ป้องกันแค่สู้กับไนท์หรือDSด้วยกัน

แต่ถ้าจะให้ครบเครื่องสายป้องกันก็ควรเล่น job50 เพราะจะได้สกิลป้องกันครบหมด
ทั้งฟันแทงทุบ และก็ได้พ้อยเยอะกว่าครับอัพสกิลขั้นแรกได้เยอะ

ไม่ควรเปลี่ยนตอนต่ำกว่า job40 ครับ

ส่วนที่เล่นแล้วลำบากนั้น ช่วง lv30-50 ถ้าเป็นสาย agi จะรู้สึกว่าหลบไม่ค่อยได้โดนหนัก
ฟันช้าแถมเบาอีกต่างหาก แนะนำว่าให้รีสกิลเป็นสาย str dex แล้วไปไล่โบล์ซินาม่อนเมืองใต้ อาศัยปั้มยา หรือมีพระช่วยก็จะไวมากครับแปบๆ40 เลย หรือให้นักเวทสิงยิงเอาก็ได้

ข้าน้อยก็เป็นอีก 1 คน ที่เล่นจนถึงจ๊อบ 50 ขอรับ

เพื่อต้องการแต้ม มาเสริมให้ตัวละครที่เล่นแกร่งมากที่สุด(ตอนนี้ทำเควส สกิลพ้อยท์ฟรี 21 สกิลครบแล้ว เพราะยกริง ทยอยถล่มหอคอย 40 ชั้น )


พูดกันจริงๆ ก็ไม่เสียเวลาเท่าหร่นะขอรับ สำหรับการเล่นถึงจ๊อบ 50 แถมยังได้สกิลเสริมตัวหลักๆ ครบถ้วนสมบูรณ์เลยทีเดียวขอรับ(แถมแต้มเหลือ ไว้รองรับการอัพสกิลประเภท
ใช้ประโยชน์ ในการ PVP NVN ด้วยขอรับ )

ไม่ยากและ ไม่ง่ายจริงๆขอรับกับการเล่น จ๊อบ 50

ตอนนี้เพิ่งเปลี่ยนเป็นไนท์ขอรับ กำลังปั่นจ๊อบให้ได้ท่าหมู่ ต้องขอบพระคุณทุกๆท่านที่ตั้งคำถาม และ ท่านที่ตอบคำถาม
ด้วยนะขอรับ เพราะการนำข้อมูลต่างๆไปจากที่แห่งนี้ ข้าน้อย ยอมรับว่ามีประโยชน์มากมายจริงๆ
และ ยังอัพสกิลได้อย่างตรงใจ ใช้แต้มคุ้มค่า เป็นที่น่าพอใจจริงๆขอรับ


ปล. ข้าน้อยเล่นสาย STR VIT หอกมือเดียว+โล่ นิยมเก็บเลเวล คนเดียวขอรับ นับว่าข้อมูลต่างๆ
ที่นำไปประกอบการตัดสินใจนั้น เป็นประโยชน์จริงๆขอรับ ขอบคุณในความมีน้ำใจแบ่งปันข้อมูล
