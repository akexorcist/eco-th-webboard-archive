[ของเก่ามาเล่าใหม่]กำจัดหน้าต่าง chat รกจอกันเถอะ

โพสต์แล้ว: พุธ 17 มี.ค. 2010 5:24 pm
โดย ECO
จริงๆน่าจะโพสลงหมวด Ring นะเนี่ย เพราะส่วนใหญ่คนที่ใช้ chat room คือคนที่มีริง แต่มันก็ถือเป็น Tip&Trick แถมจำไม่ผิดเคยมีคนลงไว้เมื่อนานมาแล้ว แต่เห็นมันสาบสูญ บวกกับคนไม่ค่อยใช้ chat room เลยเอามาลงให้ใหม่

1.ก่อนอื่น เข้า option แล้วปรับดังนี้

ภาษาถ้วย "หลังจากการเปลี่ยนแมปทำการตั้งค่า Camera" น่ะ จริงๆมันต้องเป็น "แสดง Chat Room Window อัตโนมัติเมื่อมีการพูดคุย" ต่างหาก
ปรับมันเป็น "OFF" โลด

2.จากนั้นใครก็ได้ตั้งห้อง chat ขึ้นมาห้องหนึ่ง


3. กด C ข้างล่างตรงแถบพิมพ์เพื่อเปลี่ยนเป็นหมวด chat


หน้าต่างห้อง chat จะเด้งขึ้นมา ให้ปิดหน้าต่างห้อง chat ทิ้งไปเลย

เนื่องจากข้อแรก เราปรับมันเป็น OFF ไปแล้ว ดังนั้นทุกครั้งที่เราคุยผ่านหมวด C หน้าต่างห้อง chat จะไม่เด้งขึ้นมาอีก (ยกเว้นเรากดใส่ตัว C อีักครั้ง)

4.ผลที่ได้จะเป็นแบบนี้


แล้วก็ใช้ช่องนี้แทนช่อง Ring ได้แบบถาวรณ์ไปเลยก็ได้

ข้อดีของห้อง chat แบบไม่มีจอแยก
- ต่อให้มีริง 4 สาขา คนออนร่วม 80 คน ก็สามารถคุยกันทั่วถึงได้หมด เพราะห้อง chat จุได้ถึง 100 คน
- ประยุกต์ใช้ในการสั่งงาน NvN / OD War ได้ อีกทั้งไม่มีอะไรบังจอ เพราะหน้าต่างห้อง chat มันไม่เด้งขึ้นมาแล้ว เล่นสะดวกขึ้น

ข้อเสียการใช้ระบบ chat
- ทุกครั้งที่เข้าเกม ต้องเสียเวลาเปิด comment list เพื่อสร้าง/เข้า ห้อง chat ของริงตัวเอง
- คนที่ใช้แรกๆจะไม่ค่อยถนัดละมั้ง
- เผลอออกห้อง chat บ่อย เพราะคำสั่ง "จบการแชท" จะไปโผล่ตรงล่างสุดเวลาคลิกขวาตัวเอง
- คนที่ใช้ช่อง C สลับกับ R บ่อยๆจะรำคาญ เพราะทุกครั้งที่กด C มันจะมีหน้าต่างห้องเด้งขึ้นมา ทางที่ดีแนะนำให้เลิกใช้ช่อง R ไปเลยง่ายที่สุด

หวังว่าจะนำไปใช้กัน แล้วหวังว่ามันจะช่วยลดปัญหาโข่งคุยกับเพื่อนโดยไม่อายคนทั้งเซิฟไปได้บ้างนะ

=====================================
สุดท้ายนี้ของ รณรงค์เรื่องการใช้ Comment List ให้ถูกหมวดกันหน่อยนะครับ

-รับตี้ลากดูด ฯลฯ -> หมวดปาร์ตี้
-ซื้อขายแลกของ -> หมวดไอเทม

เพื่อความสะดวก อ่านง่าย สบายตา และเป็นระเบียบ เรามาช่วยกันพัฒนาสังคม ECO ให้ดียิ่งขึ้นกันเถอะครับ
