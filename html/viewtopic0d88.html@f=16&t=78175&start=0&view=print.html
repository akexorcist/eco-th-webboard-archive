เล่นสาย str ไปก่อนก็ได้ครับ เพราะสกิลของมาริที่ใช้ค่า mag โจมตีแบบหวังผลได้นั้นอยู่จ็อบท้ายๆหน่อย

ถ้าจ็อบสูงแล้วก็ไปรีสเตตัส รีสกิลฟรีที่เมืองเหนือได้ 1 ที เป็นสาย mag, vit, dex

ตอนนี้ก็อัพ str, vit, dex ไปก่อนครับ banish blow สกิลหากินไปเรื่อยๆ first aid ใช้เพิ่ม hp สบายๆ

สกิลของมาริก็อัพพวกเสริมความสามารถของมาริโอเนต ใช้จนกว่าจะรีเป็นสายเวทย์นั่นแหละครับ

ไม่ควรอย่างยิ่ง ที่จะเล่นสาย mag ก่อน จ๊อบ 50 หากคุณเก็บเวลเอง เพราะคุณจะมารู้สึกเสียดายทีหลัง

เพราะหลังจากรี จะไม่มีสกิลโจมตีเลย ถึงมีก็ใช้ยาก เงื่อนไขเยอะ

ฉะนั้น เล่นสาย Str ไปจนมาริจ๊อป 50 แล้วค่อยรีสแตต หรือจะสวิซกลับไปเก็บอัลเค ต่อก็ได้ แต่เป็นสาย mag นะ
