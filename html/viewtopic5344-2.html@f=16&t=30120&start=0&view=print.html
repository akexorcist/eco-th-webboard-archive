Str ล้วนๆ ก็ต้องมี Dex บ้าง Vit บ้าง
เพราะหลังๆ มอนมันตีแรง
หรือถ้าไปหอแสง
ท่านอาจจะโดนปืนยิงเป็นชุด ทำให้หลอกเลือดของท่านดำไปได้ในพริบตา

ลง Dex บ้าง เพราะถ้า Miss = 0 ถึงจะโดนเบากว่าพวก Str ล้วนๆ แต่มันก็ยังดีกว่าตีไม่โดนเลย

ของเราเล่น 3 ตัว Treasure Hunter/ Trader / Alchemist
ก็เล่นเหมือนๆกันหมด
Str เป็นหลัก
Dex รวมๆสัก 50-60
ลง Vit สัก 20-40 ตามแต่ความต้องการ
และ Agi ตามความเหมาะสม ซึ่งช่วยให้ใช้สกิลได้ต่อเนื่องยิ่งขึ้น
