มุมนั่งเล่นกับโต๊ะอุ่นขาพร้อมส้มแสนอร่อย อา... มีความสุขจัง


มุมพักผ่อนกับเตียงนอนนุ่มๆ ดอกไม้สีสันสดใสพร้อมกลิ่นหอม และเสียงดนตรีขับกล่อมยามนิทรา


มุมอ่านหนังสือ เพลิดเพลินกับหนังสือเล่มโปรดบนเก้าอี้โยกและดื่มด่ำอรรถรสของตัวหนังสือและรสชาติน้ำชาไปพร้อมกัน


มุมรับแขก พร้อมต้อนรับผู้มาเยือนด้วยโซฟานุ่มๆ และน้ำหวานแสนอร่อย



และนี่ก็คือบ้านหลังน้อยอันแสนสุขของผมจ้า ตอนนี้ก็รอเพียงแค่ว่าต้นไม้ Legendary Tree จะมาลงมอลล์ขายเมื่อไหร่ จะไปเหมาซื้อเอามาถมสวนนอกบ้านให้เต็มสมกับคอนเซปต์ "บ้านเล็กในป่าใหญ่" อิอิ
