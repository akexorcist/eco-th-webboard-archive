สวัสดีครับ =[]= ! ผมมีนามว่า Elvis Nightroad หรือจะเรียกว่า 'เอลวิส' ก็ได้ ! ผมเพิ่งเล่นเกมส์ ECO ได้ประมาณ 2 - 3 สัปดาห์ แล้วเกิดหลงใหลอย่างยิ่ง ! จนอยากจะลองแต่งฟิคของเกมส์นี้ขึ้นมา !

ตอนนี้ผมก็เป็นนักเขียนของสำนักพิมพ์แก่นปัญญาอยู่ครับ เขียนเรื่อง "Zeles - สงครามศักดิ์สิทธิ์" ( จะมีใครเคยได้ยินไหมนะ =w= ? ) ก็ ... ผลงานอาจจะไม่ค่อยดีนะครับ เพราะว่าผมห่างงานเขียนมาเล็กน้อย ( ชีวิตมหาลัยเทอมแรกลำบากหน่อย )

ก็ ... ลองไปดูบทนำกันเลยครับ =[]= !!!



๐ The Miracle ! ๐ : สู่การผจญภัยไร้พรมแดน ~



เมืองฟาอีสต์ เมืองที่มีมนต์เสน่ห์อยู่ภายในตัวของมันเอง แตกต่างจากเมืองหลายแห่ง กลิ่นอายของธรรมชาติอันน่าหลงใหล บรรยากาศของคนในหมู่บ้านที่ดูเป็นกันเอง ช่างเป็นบรรยากาศที่อบอุ่นยิ่งนัก ซึ่งบรรยากาศเช่นนี้ หาได้ยากยิ่งในเมืองหลวงของโลกใบนี้ ‘อโครโพลิส’


ณ คฤหาสน์เมืองฟาอีสต์


“ไม่ได้นะ ! อัสเทีย ! พี่ไม่ยอมให้เราได้ออกจากบ้านหลังนี้แม้แต่ก้าวเดียว !” เสียงอันมุ่งมั่นถูกเอ่ยขึ้นมาด้วยชายหนุ่มผู้หนึ่ง น้ำเสียงนั้นแสดงถึงความมั่นใจในความคิดของตนเอง และฟังจากน้ำเสียงแล้ว อายุน่าจะราว ๆ ยี่สิบปีกว่าได้ ชายหนุ่มเจ้าของเรือนผมสีเงินยาวสลวยที่ถูกมัดเอาไว้เอาไว้อย่างดียืนจังก้าขวางประตูคฤหาสน์เมืองฟาอีสต์ไว้ด้วยท่าทีแข็งกร้าว ชุดของเขานั้นเป็นชุดคลุมสีดำสนิทขลิบขอบทองทั้งตัว เสื้อและกางเกงข้างในก็เป็นสีดำขลิบทองด้วยเช่นกัน


“ต่อให้พี่ต้องใช้กำลัง !” เจ้าของเสียงยังประกาศกร้าว ดวงตาสีแดงโลหิตดูแข็งกร้าวมากขึ้น ปีกสีดำสนิทและหางสีดำที่โบกไปมาอย่างไม่พอใจนั้น แสดงให้เห็นว่า เขานั้นเป็นคนของเผ่า ‘โดมิเนียน’ หรือว่า ‘ปีศาจ’ นั่นเอง และชุดของเขานั้นก็เป็นชุดของ ‘คาบาลิสต์’ หรือว่า ‘ผู้รับใช้ความมืด’ แล้วแต่ผู้บคนจะเรียก


“แล้วไงล่ะ ! พี่จะมาทำแบบนี้ได้ยังไงพี่เอลวิส !”


เสียงโต้กลับของคู่กรณีดังขึ้นอย่างไม่ลดละเช่นเดียวกัน หญิงสาวที่ดูจากหน้าตาน่าจะอายุประมาณสิบหกหรือสิบเจ็ดปียืนเท้าเอวอยู่เบื้องหน้าคาบาลิสต์หนุ่ม ‘เอลวิส’ อย่างไม่พอใจนัก ชุดของเธอนั้นเป็นเสื้อหนังแขนกุดที่ดูคล่องตัว และกางเกงขาสั้นที่ เอ่อ ... ออกจะ ... สั้นไปหน่อยล่ะมั้ง ? และที่น่าแปลกก็คือ ร่างกายของเธอนั้นเหมือนกับพวกมนุษย์ธรรมดา หรือว่า ‘อีมิล’ ทุกประการ


แปะ ๆ ... รองเท้าบูทหนังของเธอตบพื้นอย่างไม่ค่อยพอใจ ดวงตาสีแดงเฉกเช่นพี่ชายทอประกายแข็งกร้าวยิ่งกว่าผู้พี่ เรือนผมสีม่วงเข้มยาวสลวยนั้นไหวไปมาช้า ๆ ราวกับจะแสดงให้เห็นว่าเธอ ‘หงุดหงิด’ มาก เธอมีนามว่า ‘อัสเทีย’ เธอยกมือขยับกรอบแว่นสี่เหลี่ยมเล็กน้อย “ทำไมล่ะคะ ! ทีพี่เอลวิสล่ะ ! ออกไปผจญภัยข้างนอก ทิ้งหนูเอาไว้ ! แถมกลับมายังได้เป็นถึงคาบาลิสต์อีก ! พี่จะเอายังไงกันคะ !”


“พี่ไม่สน ! ไม่ยอมให้น้องสาว สุดรัก สุดหวง สุดขี้หงุดหงิด ของพี่ออกไปข้างนอกหรอก ! มันอันตราย น้องก็รู้ !”


“พี่อย่ามาขี้โกงนะพี่เอล ! ยังไงวันนี้หนูก็จะไปให้ได้ !” ควับ ! ... แส้ที่ไขว้อยู่ด้านหลังกางเกงของเธอนั้นถูกตวัดขึ้นแล้วรัดรอบตัวพี่ชาย ( บังเกิดเกล้า ) ของเธอเอาไว้อย่างแน่นหนา กว่าเอลวิสจะรู้ตัว เขาก็ถูกพลังมหาศาลของน้องสาวดึงให้ตัวเขาลอยเข้ามาหาเธอแล้ว


“ฮะ ... เฮ้ย ! อัสเทีย =[]= !!!!” ....


ศาสตราคู่กายของอัสเทียอีกอย่างถูกดึงขึ้นมา ค้อนเหล็กขนาดใหญ่ถูกฟาดใส่พี่ชาย ( จะเหลือเรอะ ? ) ของเธออย่างแรง เกิดเสียงสนั่นหวั่นไหวไปทั่วเมืองฟาอีสต์ และพอทุกอย่างจบแล้ว ร่างของคาบาลิสต์หนุ่มก็ถูกซัดจนลอยไปไกลจนถึงเกาะอันเดด ( แรงเธอนี่มัน ... ) หญิงสาววิ่งออกมาจากคฤหาสน์ พร้อมกับหันกลับมาอีกครั้ง


“คุณพ่อ ! คุณแม่ ! หนูไปแล้วนะค๊า !!!”


เธอวิ่งออกจากบ้านอย่างรวดเร็ว แสงแดดทอประกายอบอุ่น สายลมเคลื่อนไหวอย่างอ่อนโยนดูราวกับว่าจะรับขวัญเธอคนนี้ และโลกใบนี้จะเป็นอย่างไรกันนะ ? มันจะมีการเปลี่ยนแปลงอะไรเกิดขึ้นบ้างหรือเปล่า ? ... แต่ที่แน่ ๆ ในตอนนี้ การผจญภัยที่เราไม่อาจจะทราบเรื่องภายภาคหน้าได้ ได้เริ่มต้นขึ้นแล้ว ...
