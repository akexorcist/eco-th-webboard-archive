อยากทราบว่าความแม่น กับความเร็วของสกิลแต่ละอย่างขึ้นกับอะไร

Scoutสายปากับสนับต้องอัพสกิลไรบ้าง

สายปา ถ้าปาไกลจะแรงน้อยลงไหม
สายสนับไม่เห็นมีPassiveเลย จะตีโดนหรอ
สายปาใช้Intใช้ไหม แล้วจะผสมกับสกิลอื่นได้รึเปล่า
สายปา จะใช้สกิลอื่นได้ไหม ผลต่างกันกับสายอื่นอย่างไร

การอัพStatแต่ละสายสูงสุดเท่าไรแต่ละค่า

โดยรวมอยากได้ข้อมูลทั้งหมด ยกเว้นสายมีด(เล่นนักดาบAGIมาก่อนแล้วเอียนแล้วครับ)

โอว...ขอชี้แจงให้แบบคร่าวๆนะครับแล้วลองอ่านกระทู้ของ ass ที่ปักไว้ต่อก็ได้ครับ

ความเร็วของสนับและอาวุธปาขึ้นกับ AGI ทั้งคู่ครับ
ความแม่นยำ สนับอยู่ที่ DEX อาวุธปาอยู่ที่ INT

ส่วนสกิลทั้งหลายแนะนำให้ลองดูกระทู้ Ass ของเพื่อนเลยครับ

พวกสกิลของสายปาต้องระวังนะครับเพราะอาวุธปาจะใช้สกิลบางอย่างไม่ได้ เช่น สกิลพวกเอาอาวุธไปฟาด (Blow ทั้งหลายแหล่)

ส่วนเรื่อง stat อันนี้แล้วแต่ชอบครับบางคนชอบ Str เยอะ บางคนชอบ Agi เยอะ ส่วน INT นั้นจะเอาเยอะไหมอยู่ที่เราชอบ NVN กับ PVP ไหม ถ้าชอบเอาเยอะก็ดีครับ เพราะถ้าไปเจอพวกพลิ้วๆ อย่าง Gunner จะปาไม่ค่อยจะโดน - -'~
