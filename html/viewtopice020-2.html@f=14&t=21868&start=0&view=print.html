ขอถามเกี่ยวกับ skill ประเภท Delay Cancel ของสายอาชีพ Fighter ต่างๆครับ

เนื่องจาก atk-speed จะสูงสุดที่ 800 ASP(ข้อมูลจากหนังสือ Weekly Online)
ถ้าจำไม่ผิด ที่ agi = 108 จะได้ค่า ASP 800
ซึ่งถ้าอัพ agi ต่อไปก็จะไม่เห็นผลในการโจมตีปรกติไวขึ้นอีกแล้ว

ทีนี้เลยอยากจะขอถามว่า ถ้าหาก ผมอัพ agi 108 ได้ ASP 800 แล้วกด skill delay cancel นี้จะทำให้
-ผมไม่ได้ bonus จาก skill เลย
-หรือว่าจะสามารถตีเร็ว *2 ขึ้นไปได้อีก

และสมมุติ ถ้าไม่สามารถจะเร็วขึ้นได้อีกแล้ว การที่ผมอัพ agi ประมาณ 45 เพื่อทำ asp 400
และใช้ผลจาก delay cancel เพื่อให้ได้ asp*2 ได้ 800 พอดี อย่างนี้ถือเป็นการคำนวณ asp ที่ถูกหรือไม่ครับ

ขอรบกวนผู้รู้ด้วยนะครับ ^^

skill Delay Cancel นั้นมีผลทำให้การโจมตีของตัวละตัวไวเพิ่มขึ้น2เท่าตัวจากค่าปกติ รวมทั้งยังลดเวลาดีเลย์หลังใช้สกิลต่างๆด้วย ซึ่งค่าเหล่านี้จะไม่แสดงในหน้าต่างstatus

ถึงaspdเท่ากันแต่อาวุธต่างกันความเร็วในการโจมตีก็ย่อมไม่เ่ท่ากัน
