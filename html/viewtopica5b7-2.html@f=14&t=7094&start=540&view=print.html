ค่า Int สำหรับเก็บ Lv. อัพไว้ที่ 40 ก็แทบจะหมดปัญหาเรื่อง Miss แล้วหล่ะ ถ้าหาก Miss ก็บัพเสริมเล็กน้อย

ค่า Int สำหรับ Nvn อยู่ที่คู่ต่อสู้ อันตัวเรานี้ Int 31+19 ไม่ค่อยประสบปัญหาเรื่องยิง Miss

สักเท่าใด นอกเสียจากเจอมือปืนสาย Full Agi จึงจะพอเห็นปัญหามาบ้าง

ถ้าไม่อัพเลย มันจะโหดร้ายแน่นอน เพราะ Int ขั้นต่ำควรมีซัก 30 (11+19 15+15 ฯลฯ)

โดนโดยไม่พลาดก็คงต้องซัก 60 70 แล้วหล่ะ ทั้งนี้ขึ้นอยู่กับว่าเจอกับใคร สาย Agi ทั่วไป 50 ก็เละแล้ว

แต่ถ้าสายอาชีพเดียวกันที่เน้น Agi ก็คงต้องประมาณที่บอกไป

ส่วนประเภทปืน ไม่ค่อยแตกต่าง เพียงแต่ว่า ปืนคู่จะมีสกิลที่ช่วยเพิ่ม L.Hit อยู๋ประมาณ 20-30

เลยอาจช่วยทำให้แม่นกว่าเก่าระดับหนึ่ง

ส่วนประกอบของปืนยิงเองจะตกหรือเปล่า


ถ้าไปยิงพวกปืนที่หอแสงก็ คาดว่าตกอะนะ แต่คิดว่าคงยากหน่อย ส่วนประกอบหลักๆเลยคือ

1.ปากกระบอกปืน ชนิดที่จะประกอบ

2.ด้ามปืน

3.ไกปืน

4.น้ำมันเครื่อง

ที่ว่ายิงเองจะตกหรือเปล่านั้น ต้องดูที่ว่าต้องการปืนชนิดไหนมากกว่า เพราะบางอันก็ต้องตีจาก เศษเหล็กอย่างเดียว

แล้วก็ ส่วนประกอบนอกจาก ปากกระบอกปืน สามารถหาได้จาก คอน 1 นะจ๊ะ

(เปิดได้ปืนสั้น 60 กับไรเฟิล 50 ด้วยแหละ)

คือเข้าใจว่าส่วนมาก ค่า L.Avoid Bonus มาจาก Int แต่ที่ว่าสาย Full Agi คือ

1. ได้ L. Avoid เท่ากับสาย Agi ทั่วไป

2. ได้ L.Avoid จาก Int จึงทำให้พริ้ว (ต่อปืนและธนู) กว่าสาย Agi ทั่วไป

3. มีสกิล L.Avoid Up เสริมอีกทอดหนึ่ง

ด้วยเหตุผล 3 ข้อหลักนี้ก็ทำให้สาย Full Agi ของ Gunner Striker พริ้วต่อปืนหรือธนู

มากกว่าสาย FT เพื่อนพ้องทั้งหมดนั่นเอง ซึ่งถ้าจะยิงสายนี้ให้โดนคงต้อง Int ซัก 60 70

ถึงจะชัวร์ สายนี้ข้อด้อยอยู่ที่ว่ายิงไม่แรงมาก แต่ก็รุนแรงพอที่จะยิงสาย Agi อื่นๆ ให้หงายได้

ส่วนเวลาร่าย สกิลสายต่อสู้นับเป็น Battle Skill ( หรือง่ายๆความแรงคิดจาก Atk ) ค่าร่ายจึงลดได้ด้วย A.SPD
