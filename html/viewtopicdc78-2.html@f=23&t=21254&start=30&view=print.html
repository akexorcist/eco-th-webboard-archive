ชุดนักเรียนหญิงได้จากการเอาแหวนชั้น 5F ( เควส ที่หอคอย 40 ชั้น ) ไปแลก กะลุงในอัพทาว์ครับ ( ลุงแก่ๆยืนอยู่ที่ตะวันออก )

ส่วนชุดนักเรียนชาย ได้แหวนชั้นจากชั้น 10F ส่วนชั้นอื่นๆ ก็จะได้ของแรร์แบบอื่นๆ ( ขยะก็มีเยอะ )

แหวนที่เอาไปแลก จะเป็นแบบสุ่มไอเท็ม แล้วแต่ดวงนะครับว่าจะได้ไอเท็มอะไร ทุกทั้งมีทั้งขยะ และ ของแรร์ แต่ ขยะก็มีเยอะ เช่น Bone ( กระดูก ) หรือ Seriko เป็นต้น

ปล.นอกจากจะมีชุดนักเรียนแล้ว ยังมีของแรร์อีกมากมาย เช่น หูกระต่ายสีชมพู ( Rebbit Ear ) , มาริโอเน็ต P-Bot ฯลฯ , ที่ปิดตาจรสลัด , กางเกงขายาวสีขาว ฯลฯ

ปล.2 ขอให้ทุกท่านโชคนะดีคร๊าบบบบ ได้แต่ของแรร์กานทุกคน สาธุ~~~~
