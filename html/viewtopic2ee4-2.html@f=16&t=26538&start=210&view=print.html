เวลาตั้งจำนำ : รับซื้อของ (ผ่าน Catalog ได้ด้วย)

ของที่รับซื้อมาได้ จะอยู่ในกระเป๋าของตัวละครคะ
อย่าง Novice น้อยๆ Capa 173 ตั้งรับซื้อ Great Meat หนัก 3.5

เปิดหุ่นไป 5 วัน ซื้อเนื้อมาได้ 1000 ชิ้น คิดเป็นน้ำหนัก 3500 Capa
พอ Login เข้ามาปุ๊บ หนูโนวิซน้อยๆ ก็หนัก 3500+/173
จะตั้งโกเลมรับซื้อของต่ออีกครั้งก็ทำไม่ได้ เพราะ Over Capacity

จำใจกดใช้ Empty Key บินกลับอโครเนียสถานเดียว

--------------------------------------------

เวลาตั้งหาของ : หาของ....

ของที่โกเลมน้อยๆ ไปดูดมาจากมอนสเตอร์ได้
จะเข้าโกดังของโกเลม (ความจุ 100 ชนิด ชนิดละ 9999 ชิ้น)
ซึ่งเปิดดูโกดังที่ว่านี้ได้เรื่อยๆ

แต่ ...

เมื่อถอนของออกมาแล้ว จะใส่กลับเข้าโกดังไม่ได้
และของทุกชิ้นที่หามาได้ จะยังไม่ได้ Identify (ต้องเอาไปส่องกับคุณปู่ข้างๆ คุณเมดโต๊ะ Quest Counter)

และ ...

โกดังโกเลม จะเป็นของตัวละครตัวหนึ่ง ใน 1 ไอดี
แม้ว่าโกเลมจะพังไปแล้ว (สมมุตว่า หาของด้วยโกเลม Mandra)
พอกดเปิดโกดังโกเลม ด้วยโกเลมตัวใหม่ (สมมุติว่า ไทนี่)
ก็ยังเชื่อมต่อเข้ากับ โกดังโกเลมอันเดิม ... ของที่เคยหามาได้ ก็ยังคงอยู่เหมือนๆ เดิม

---------------------------------------------

ในทางปฏิบัติ โกดังรับซื้อของ คุ้มที่สุดแล้วเพราะ ตั้งครั้งเดียว อยู่ได้ถึงเ้ช้าวันอังคาร
ส่วนโกเลมหาของ ปฏิบัตการได้ 24 ชม. เต็ม ก็จะหายตัวไปจากสารบบ

แต่เวลาที่เซิฟมันปิดบ่อยๆ จะด้วย GM เตะปลั๊กไฟ หรือ ไล่ถอด Skill Point ออกจากพวกคนปั๊มสกิล
โกเลมหาของ แค่ Login เ้ข้ามาแล้วก็เปิดโกเลมได้ทันที (เพราะ ของที่หามาได้อยู่ในโกดัง = ตัวละคร น้ำหนักไม่เกิน)
โกเลมรับซื้อของ พอ Login เข้ามาแล้ว ... ต้องบินกลับอโครเนีย
แล้วกระดึ๊บๆ เอาของไปเก็บเข้า โกดัง Merchant Guild
แล้วก็วิ่งหน้าตั่งกลับไปที่จุดตั้งโกเลมอีกครั้ง ... กว่าจะเปิดโกเลมได้ = =

ยุ่งยากจริง :?
