บกวนถามหน่อยนะครับเพราะบางอย่างยังไม่เข้าใจแน่ชัด
1.สรุปแล้ว ใช้ธนู+ลูกธาตุ กับ ใช้สมุดยัดการ์ดธาตุR4 5ใบ อันไหนแรงกว่ากัน ข้างต้นใช้กราวิตี้ยิง
แบบไม่ทำอะไรเลยสมุด99แรงกว่า 2ขั้นอยู่แล้วจ้า แต่ถ้าในกรณ๊ที่เธอถามนั่นคือจะทำให้สมุด99 แรงกว่า3-4ขั้นเลยละ
(1ขั้นคือ สเตตัสลงตัว1ทีอ่ะ)

2.แล้วถ้าใช้ธนูยัดการ์ดธาตุR4 5ใบ จะแรงกว่า สมุดยัดการ์ดไหม ในกรณียิงกราวิตี้
กรณีไหนสมุด99ก็แรงกว่า ยกเว้นว่าเรายังเลเวลต่ำๆใส่สมุด99ไม่ไ่ด้

3. แล้วถ้าใส่โล่ดินในตัว25 +การ์ดดินที่ใส่ในอาวุธ 25 เป็น50 ยิงกราวิตี้ใส่เฟค คน หรือมอน ยังไงสะท้อนมาก็โดน 0 ใช่หรือไม่
ไม่ใช่จ้า ยังโดนนกราวิตี้อยู่50% เธอไม่สามารถเอาดินในตัวกับดินที่อาวุธมา+กันได้
ถ้าอยากให้เธอโดนธาตุดิน0 ต้องมีธาตุดินในตัว50นะ(หมายถึงโ่ล่ดิน50อ่ะแหละ)

4. แล้วในกรณีของออริจิ้น สมมุติจะยิงกราวิตี้ ถ้าในดันปลาวาฬ มันมีธาตุดิน กราวิตี้ และธาตุทั้ง 6ก็จะยิงแรง แต่ถ้าสมมุติ เราไปในที่ๆ ไม่มีธาตุดินละ จำเป็นต้อง อัพวางพื้นดินไหม เพื่อที่จะได้ความแรงแบบ ออริจิ้น ที่อยู่ดัน ปลาวาฬ
กรณีที่ถามมาผิดหลักการเสริมความแรงจ้า เธอกำลังคิดว่าพื้นดินเพิ่มความแรงให้กับกราวิตี้ เพราะเธอใช้ออริิจิ้นในดันปลาวาฬแล้วกราวิตี้แรงขึ้นใช่ไหมจ้า
ความเป็นจริงคือ ออริิจิ้นไม่ไ่ด้เพิ่มค่าธาตุของการโจมตีในตัวเธอ แต่ไปเพิ่มค่าธาตุลมในตัวมอนสเตอร์จ้า(เสกลมก่อนยิงกราวิตี้ใช่มะล่ะ)
ออริิจิ้นก็คือพื้นธาตุแหละจ้าพื้นธาตุที่มีสีตามพื้นแมพ แต่ดันปลาวาเป็นพื้น6ธาตุ มันเลยทำให้เราทำอะไรก็ได้อิสระเต็มที่

5.ลาวาที่เลเวล 1 ความแรงเท่าเลเวล 5หรือป่าว มันปรับหรือไม่อย่างไร
เลเวล1 8ฮิต เลเวล5 11ฮิต ต่อฮิตความแรง200%ไม่เปลี่ยนจ้า

6. ถ้าใส่การ์ดธาตุดินในตัว กะอาวุธ มันเหมือนกันไหม ในกรณีที่ต้องการความแรงของ กราวิตี้ เช่นใส่การ์ดธาตุดิน ในตัวมันจะไป+ความแรง ใน่ช่อง ดินไหม หรือบวก ป้องกัน แล้ว ถ้าใส่ในอาวุธละ มันจะไปบวกธาตุดิน ในช่องเหมือนกับที่ตัวไหม ในช่องสตาตัสธาตุอะนะครับ แล้วถ้ายัดการ์ดธาตุดิน ไปใน อาวุธ หรือตัว มันมีจำกัดความแรงไหม เช่น ถ้าใส่การ์ด R4 ธาตุดิน 10ใบ ทั้งตัว ความแรงมันจะทวีคูณหรือไม่ หรือจำกัดแค่ 50
ยัดธาตุดิน10ใบทั้งตัว จะได้ดินที่อาวุธ40 ดินที่เกราะ40 เวลายิงนับแค่40ที่อยู่ในอาวุธ เวลาโดนดินโจมตีใส่นับ40ที่อยู่ในเกราะ
ความแรงสามารถทวีคูณขึ้นได้เรื่อยๆ ตราบที่เรายังทำได้ เราเองก็พยายามทำให้เห็นเพดานแล้วว่ามันจะสุดที่เท่าไหร่ แต่ก็ยังไม่เคยเห็นว่ามันจะเป็นเพดานซักที

7. ในทางกลับกันถ้าในตัวมีธาตุดิน 50 ไปยิงกราวิตี้โดนเฟคกลับมา ไม่ว่าตัวอะไรในเกมก็จะ 0 ใช่หรือป่าว
ถูกต้องจ้า ค่าดินที่เกราะ50 ถือเป็นการป้องกันดินที่สมบูรณ์แล้ว ถ้ามากกว่า50 จะสามารถส่งผลเรื่องด้านต้านธาตุชนะ
เช่น ดิน100 โดนลมเบามากๆ หรือ1 เลยละ และการคำนวนดามเจเข้าตัวอ่ะจา เช่นดิน100โดนน้ำ4เท่า อะไรแบบเนี้ย
