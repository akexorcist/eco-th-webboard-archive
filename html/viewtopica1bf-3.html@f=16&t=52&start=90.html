นั้นก็เป็นอีกวิธีนึงนะค่ะ แต่ว่า ถ้าอดทน เก็บสกิล ตีไอเทม จนเลเวลสกิล 3 ก็ไม่ต้องไป จ้าง npc ทำแล้วค่ะ ทำเองเลย คุ้มด้วย อิอิ

การทำอาหาร ก็เป็นอีกทางนึงที่ทำให้ชาวนาที่เก็บเวลคนเดียว ไม่ต้องนั่งบ่อยนะค่ะ
พยายาม ลอง แปรรูป ( ทำไอเทม ) ทำอาหาร แล้วจำสูตรไว้ หรือคลิ๊กขวาที่ไอเทมที่ทำแล้วจะมีบอกสูตร ค่ะ ไม่ก็ไปซื้อหนังสือ ตำรามาใน อัพทาว ค่ะจะมีบอกหมดว่าแต่ละอย่างใช้อะไรบ้าง


lunar เขียน:อัพสกิลทำสวนมาแล้ว แต่สร้างอะไรมะได้สักอย่างเลย ใครสร้างได้แล้วบ้างคะ รบกวนบอกทีน้า ว่ามันใช้อะไรสร้างบ้าง แล้วสร้างเสร็จแล้วได้อะไรออกมา แบบว่าสงสัยมั๊กๆ รบกวนผู้รู้บอกทีนะคะ


ต้องมีของอย่างใดอย่างหนึ่งก่อนนะค่ะ มันถึงจะ แสดง ลิสต์ มาว่า ไอเทมนั้นทำอะไรใน สกิลทำสวนได้บ้าง

ของทำสวนนี้ ไม่แน่ใจว่า ทำของตกแต่ง สวนลอยฟ้าของเราหรือป่าว แต่คิดว่าน่าจะใข่อ่ะค่ะ

อยากรู้ว่า ใช้อะไรทำบ้าง ก็ไปซ์อตำรา ที่ อัพทาว นะค่ะ จะมีบอกค่ะ
