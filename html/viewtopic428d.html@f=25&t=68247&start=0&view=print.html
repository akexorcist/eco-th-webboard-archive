ก็ท่าฝึก hp recoery ก็จะได้ Vit+1 รวมกับท่าตอนนั้น HP กับ Def เต็มด้วยก็จะได้ Vit+3

- Def เพิ่ม 90
- ฟื่นฟู เพิ่ม 90
