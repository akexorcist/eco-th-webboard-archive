//

“... สองล้านจี =[]= !!!!!! ...”

//

ดวงตาสีน้ำตาลเข้มนั้นดูจริงจัง พร้อมกับใช้กุญแจที่เธอเป็นคนทำขึ้น กำลังไขตู้เก็บอะไรบางอย่างด้วยความมุ่งมั่น เธอยกมือข้างที่ว่างอยู่เสยเรือนผมสีน้ำตาลอ่อนนั้นขึ้นเพื่อให้ถนัดมากกว่าเดิม ส่วนเครื่องแต่งกายของเธอตอนนี้นั้น นับว่าไม่เข้ากับสถานการณ์ตอนนี้เลยแม้แต่น้อย เพราะมันเป็นเพียงแค่ชุดเดรสแบบซีทรู โดยข้างในนั้นมีเพียงเสื้อชั้นในสีดำเท่านั้น !

//

“เพราะฉะนั้น ... ไปให้พ้น ๆ ได้แล้วนะจ๊ะ !” เธอยิ้มพลางขยิบตาให้พวกเขา “และจำชื่อของฉันไว้ด้วย ...”

//

ยังไม่ทันที่เธอจะเอ่ยชื่อของเธอออกมา เบื้องหลังของชายเหล่านั้นก็เกิดการระเบิดอย่างรุนแรง และแรงระเบิดนั้นก็ส่งผลให้เธอต้องยกผ้าคลุมของเธอขึ้นปิดหน้าเลยทีเดียว พอแรงระเบิดหายไปแล้ว เธอก็ลดผ้าลง และพบกับอีกหนึ่งบุรุษอยู่ตรงหน้าของเธอ “... ไม่เป็นไรใช่ไหม ? เอเรน่า ...”
