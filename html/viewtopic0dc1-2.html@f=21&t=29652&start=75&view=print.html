Sefira Artasia [ เซฟิร่า อาร์ทาเซีย ] – เจ๊ไม่รู้ว่าเจ๊อ่านถูกหรือเปล่านะจ๊ะ =w=; หญิงสาวบาร์ดเผ่าไททาเนีย หญิงสาวผู้สวมใส่กิโมโนสีม่วง ซึ่งออกจะมีลุคที่เป็นเอกลักษณ์เฉพาะตัวอยู่สมควรเหมือนกับ เนื่องด้วยแปลกตาที่เป็นเผ่าไททาเนีย หากแต่สวมใส่เครื่องแต่งกายประเภทกิโมโน แต่เจ๊อยากจะตินิดนึงเรื่องกีต้าร์นะจ๊ะ =[]= ! เพราะว่ามันผิดลุคมากเกินไปนิด ถ้าคุณน้องเปลี่ยนเป็นพวกพิณ หรือว่าเครื่องสายอื่นก็จะโอเคมากกว่านี้อ่ะนะ เรื่องอุปนิสัยถือว่าโอเค เพราะเหมือนคนที่มีสองด้าน คือคนภายนอกจะดูเหมือนกับว่าหญิงสาวคนนี้เรียบร้อย แต่หารู้ไม่ ว่าเธอรักสีม่วงเป็นชีวิตจิตใจ ! ( ตรงนี้ได้คะแนนพิศวาสจากเจ๊นะจ๊ะ ล้อเล่น ฮา ) เรื่องทักษะนั้นก็โอเคอยู่เหมือนกัน ไม่โกงมากเกินไป และสมดุลเหมาะกับอาชีพอยู่ แต่ว่าเรื่องเนียะไคเนี่ย คุณน้องต้องเลือกนะคะ ว่าจะเอาเนโกะมาตะหรือว่าเนียะไค คือว่าเจ๊อยากจะให้เรื่องสักอย่างอ่ะค่ะ แล้วก็นิยายเนี่ย จะไม่มีการตายแล้วชุบนะคะ >w< จะมีแต่เจ็บสาหัส ไม่ก็ ... ลงโลง
