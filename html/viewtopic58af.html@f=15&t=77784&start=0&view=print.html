ไม่น่าถึงมั้ง

ท่านต้องเลือกล่ัะครับว่าจะเน้นยิงหนัก+เร็ว
หรือจะโคตรถึก(สายลานส่วนใหญ่เลือกอันนี้)

สายแรกอย่างท่าน (ps)smart ว่า
ใส่ DEX 108 (C.spd 800)
และ Mag สูงพอควรที่ 103++
Stat อื่นกระจายให้ลงตัว ไปเน้น Int นิดนึงก็ได้เสริมกันเวทย์

ส่วนสายโคตรถึกก็อย่างคุณ (ps)smart ว่าอีกนั่นแหละ ต้อง DY แล้ว M.def100
ซึ่งก็คือต้องการ M.def ซ้าย 65
นั่นเท่ากับ Int 117 / Vit 104 (โบนัส Sage จ๊อบ 50)
ที่เหลือกระจายลง Mag/Dex ตามสบายครับ
