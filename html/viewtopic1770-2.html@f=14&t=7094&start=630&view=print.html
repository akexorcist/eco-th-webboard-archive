เวล 1 น่าจะติด 2 วิมั้ง
ส่วนที่เวล 5 ติดนานพอสมควร (ราวๆ 4-6 วิ )

ความแรงในแต่ละเวทเท่ากันหมด ส่วนดีเลย์ ผมบอกไม่ถูกแหะ


1. นู๋ไม่รู้มะได้อัพ แต่ถ้าว่างจะปั้นกันเนอร์มาทดสอบให้

2. กล่อง Only

3. ไม่ทะลุ Def แต่ถ้าเกิดตีตัวที่ Def หนาจะทำความแรงได้มากกว่า เพราะ % โจมตีสกิลมากกว่า

ส่วนเรื่องเหตุผล ไม่แน่ใจนัก แต่แรงกว่าชัวร์

คุณหมายถึงข้อไหน

1. พริ้วต่อลูกกระสุนปืน (ระยะไกล)

2. พริ้วต่อคมมีดและหอก (ระยะใกล้)

=======================

หากเป็นข้อ 1 หากต้องการจะพริ้ว ค่าที่ช่วยเหลือได้ดีที่สุดคือ Int เนื่องจากได้โบนัส L.Avoid

และ L.Hit ทำให้ สามารถหลบลูกกระสุนได้ในระดับหนึ่ง ซึ่งเหล่า Gunner ก็มักจะมีกันอย่างน้อย 50

(Int Bonus สายนี้เยอะมาก)

ถาม : แล้ว Commando หล่ะ อัพเท่ากันจะพริ้วเท่ากันไหม

ตอบ : ไม่ เพราะ Archer Class มีสกิลสนับสนุนการโจมตีระยะไกล ค่อนข้างมาก และ Int Bonus เยอะกว่าชาวบ้าน

จึงทำให้มีความสามารถ ทางระยะไกล มากกว่า

=============================
