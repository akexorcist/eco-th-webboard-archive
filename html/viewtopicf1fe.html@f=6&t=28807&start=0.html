ราคาขายของ Zedar Wood
แนะนำให้ ไล่เปิดกระทู้ Recipe ทั้งหมดที่มีในบอร์ดดูให้ละเอียด ก่อนตั้งราคาขาย
ของชั้นสูงหลายอย่าง ใช้ Zedar Wood 1 - 2 ชิ้นเป็นวัตถุดิบ ในการผลิต
ตั้งโกเลมขาย 250k >>> 3 ชม. หายวับไปเลย
ตั้งโกเลมขาย 300k >>> 3 ชม. ก็หายไปอีก
ตั้งโกเลมขาย 400k >>> 1 วัน ก็หายไปอีก (3 ท่อนติดๆ)
ตั้งโกเลมขาย 500k <<< ไม่กล้าตั้ง เกิดหายไปอีก นี่ยุ่งแน่ๆ
ตั้งโกเลมขาย 1M >>> อยู่ยงคงกระพัน ประดับร้านได้ยาวนาน


ตู้ความจุ 20 ช่อง ชื่อ Big Commode
รายละเอียดอยู่ในกระทู้ Recipe : Life with Tree (Wood Create)


ปลูก Wood 700 เมล็ดได้ Zedar Wood 2 ท่อน

ตอนนี้กำลังรวบรวม Tree Seed ไว้ปลูกรอบต่อไปอยู่ ... ถ้ายังได้ Zedar 2 ชิ้นอีก ... ก็นะ :x
