- JobLv.40
- สามารถเคลื่อนที่ได้ในช่วงเวลาหนึ่ง ถึงแม้ว่า Payload กับ Capacity จะ Over ก็ตาม แต่จะสามารถรับปริมาณได้มากสุด 2 เท่าจากค่าสูงสุดเดิมเท่านั้น

ดูจากความสามารถแล้ว คิดว่าไม่น่ามีประโยชน์อะไรนัก เลยอยากถามว่า

- ถ้าเราจาขายของโดย Golem จะต้องมี Payload กับ Capacity พอดีไม่เยอะเกิน เพราะถ้าเกินจะไม่สามารถใช้ Golem ได้ เลยอยากรู้ว่าสามารถใช้สกิล Nature เพื่อบรรทุกของเกินอัตราแล้วนำมาขายด้วย Golem จะได้รึป่าวครับ
