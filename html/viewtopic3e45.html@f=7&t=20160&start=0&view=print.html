เนื่องจากช่วงนี้ยังคงมีเข้าไปเดินเล่นใน server เกาหลีอยู่บ้าง
ที่เกาหลีตอนนี้เป็น saga4 แล้ว อัพไปตั้งแต่ต้นเดือนสิงหาคม
ก็เลยกะว่าจะถ่ายรูปสวนลอยฟ้ามารวบรวมไว้ในนี้

ถ้ามีโอกาสได้เดินเล่นใน acropolis ของ server เกาหลีตอนนี้ละก็ จะเห็นเชือกของบ้านลอยฟ้าวางอยู่มากมายเลย
เท่าที่ดูคือบ้านลอยฟ้านี่ใครจะเดินเข้าไปเมื่อไรก็ได้


พอลองขึ้นไปดูก็เห็นว่างเปล่าอย่างที่เห็น


สักพักก็มีบ้านโผล่ขึ้นมา


พอเข้าไปข้างในก็เห็นโล่งๆ


สักพักก็เริ่มมีเฟอร์นิเจอร์โผล่


รูปนี้สงสัยว่าเขาเข้าไปบนเตียงได้ยังไง?? เพราะลองกดเดินเข้าไปบนเตียงแล้วปรากฎว่าเดินเข้าไปไม่ได้


เพิ่งรู้ว่ามีแต่เผ่า titania เพศชายเท่านั้นที่สามารถนอนบนเตียงได้ ว่าแต่พี่แกเล่นเอาหนอนออกไปนอนข้างนอกบ้านตั้งครึ่งตัว ^ ^"


หลังจากนั้นก็ได้เข้าไปดูอีกหลายๆบ้าน มีเชือกวางอยู่ทั่วเมืองจริงๆ
บ้านนี้เขามีนกยักษ์มายืนอยู่ด้วย








ส่วนนี่ก็เป็นไอเท็มมอลล์ของเกาหลี ในส่วนที่เกี่ยวกับบ้าน






ไว้ถ้ามีโอกาสก็อาจจะนำมาลงอีกเรื่อยๆ
