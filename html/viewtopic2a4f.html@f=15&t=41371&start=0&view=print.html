ท่านกำลังประสบปัญหาเหล่านี้หรือไม่
- ไปตี้ก็ไม่ได้ของ
- เก็บเวลต้องง้อคน
- เล่นไม่ดีก็โดนว่า
- พอไม่มีประโยชน์ก็โดนทิ้ง

ปัญหาเล่านี้จะหมดไป เพียง ท่านฝึกฝนตนเอง
