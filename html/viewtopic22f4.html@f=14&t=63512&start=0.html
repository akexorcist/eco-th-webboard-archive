ประเด็นคือ

Stun Blade มันดาบสองมือ แรงกว่า (จะว่าติดคริมากกว่า หรือ+atk รวมๆแล้วก็คือแรงกว่านั่นแหล่ะ ><b )
Treasure Sword ดาบมือเดียว เบากว่า แต่เร็วกว่าหน่อยเดียว กับติดโล่เพิ่มได้


ผมว่าใช้วิธีเลือกอย่างงี้นะ

เอาไปสู้กับอะไร? ใช้สกิลทีเดียวแล้วตายมั้ย? ติดโล่แล้วคุ้มกว่าตอนไม่ติดโล่มั้ย?

เช่น เราจะไปตีโจร

เราสกิลใส่โจร ทีเดียวตาย ทั้งดาบสองมือ ดาบมือเดียว > ก็เลือกดาบมือเดียว เพราะไวกว่า, ติดโล่ได้
เราสกิลใส่โจร ดาบสองมือทีเดียวตาย ดาบมือเดียวไม่ตาย > ก็เลือกดาบสองมือ
เราสกิลใส่โจร สองที โจรถึงจะตาย ทั้งดาบสองมือ มือเดียว > ก็เลือกดาบมือเดียว
