เป็นอาชีพพ่อค้าคับ ทำไมส่งของข้ามเมืองไม่ได้ จะส่งจากเกาะเรือรบมาเมืองกลางคับ คลังของก็มีที่ว่างคับ อยากรู้ว่าทำยังไงถึงส่งได้ ตอนเริ่มเล่นเคยลองส่งจากเมืองกลางไปฟาอีสได้คับ แต่ตอนนี้อยากส่งจะเกาะเรือรบมาเมืองกลางทำไมทำไม่ได้คับ ช่วยบอกวิธีทีคับ ขอบคุณมากเลยคับ ถ้าถามซ้ำขออภัยคับเพราะค้นหาแล้วไม่เจอคับ ค้นหาคำว่าการส่งของนะคับ
