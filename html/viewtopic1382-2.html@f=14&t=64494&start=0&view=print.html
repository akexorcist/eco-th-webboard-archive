- สาย str+vit จากที่เคยลองมานานแสนนาน ใจตอนนั้นกะว่าเลือดเยอะตายยากน่าจะสวนได้มั่งล่ะ
แถมมีซัพพอรต์ให้ด้วยเอ้า แต่ในความเป็นจริงแล้ว เลือดกันเนอร์น้อยต่ำเตี้ยติดดินมากๆ
ต่อให้วิท 100 เลยเอ้า โดนกันเนอร์ด้วยกันยิง CC สวนทีเดียวดับ เผลอๆ จะโดนยิงธรรมดาตอดจนตายเลยก็มี

ไหนจะเวทย์มนตร์อีก - .- ร่ายไวๆ กันทั้งนั้น รุ้งทีละเป็นหมื่น เลือด 5000 def 70-80 โดนทีเดียวก็ดับ

สเตตัสนี้เหมาะกับช่วงเก็บเลเวลมากกว่าจะเอาลงวอร์

- ตอนวอร์สาย str+agi ยังยิงแทบไม่ทัน โดนสวนบ่อยๆ แต่ได้ถึกจากซัพพอร์ตตัวอื่นๆ มาช่วยทำให้ยืนระยะได้
แถมยังยิงสวน หรือยิงดักก่อนได้ด้วยถ้าล๊อคเป้า CC ได้ก็มีลุ้น (ยิ่งถ้ามีทาทาสิง เฟลมฮาร์ทให้ ยังไงก็ต้องมีร่วง 1 ตัว)


ถ้าจะเน้นถึก ลง vit + int + agi เล็กน้อยไปเลยดีกว่า แต่ไม่ได้ลงไปยิงคนนะ
ลงไปยิง tear gas grenade คอยจับคนมึนหมู่ให้เพื่อนสอยต่อ
