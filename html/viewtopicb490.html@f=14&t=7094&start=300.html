Atk จะมาจาก Str มากกว่า อย่างเช่น :

ที่ Str 91 (รวม job bonus) จะมีค่า Atk ตอนไม่ใส่อาวุธ 212 - 532 :

ใส่ปืนสั้น Masket(เลเวล60) โจมตี 58 + Mastery ค่า Atk รวมจะเป็น 386 - 590

ใส่ปืน 2 มือ Masket[2 hands] (เลเวล 60) โจมตี 36 + Mastery ค่า Atk รวมจะเป็น 364 - 568

ใส่ปืนไรเฟิล Rifle(เลเวล 60) โจมตี 47 + Mastery ค่า Atk รวมจะเป็น 375-579

*ยังไม่ + ความแรงของกระสุน

จะเห็นว่า Atk รวมแล้ว ต่างกันไม่มากเท่าไหร่ครับ

1. มีจำนวนการยิงที่มากกว่า และไม่จำกัดประเภทปืน ทำให้ใช้ปืนสั้นยิงได้แรงกว่าประเภทอื่น

2. มีความรุนแรง 1/1 มากกว่าแบบมโหศาล

3. ยิงเป็นกลุ่มได้

4. มีระยะเวลาร่ายเท่ากัน <<< ไม่เท่านะครับ 2.5 วิ กับ 1.5 สกิลนี้ช้ากว่าเห็นๆ

ข้อเสียเปรียบ

1. มีดีเลย์ที่มากกว่า ถึง 3เท่า (สาด 1วิ บัลเล็ตแด๊น 3วิ) <<< สาด 0.75 ครับ

2. อัตราความแม่นยำถูกลดเยอะกว่า สาดกระสุน

3. ทำการยิงโดยสุ่มหากมีมอนสเตอร์มากกว่า 2ตัว จะทำให้เกิดความไม่แน่นอน (ยิงไม่ตาย)

4. ระยะยิงสั้นเพียงรอบตัว ซึ่งหมายความว่าต้องมีการเสียเลือดเนื้อ ในขณะที่สาดกระสุน สาดไปแล้ววิ่งหนีเพื่อซ้ำอีกได้

เพิ่มเติม 2 : สกิล GDC

1. ไม่ลดระยะเวลาร่าย

2. ลดดีเลย์หลังร่าย (ซ้ำต่อได้อย่างรวดเร็ว)

3. ยิงกระสุนเวลาใช้สกิลต่างๆไวขึ้นเช่นกัน (เผ่นได้ไว)[/quote]
