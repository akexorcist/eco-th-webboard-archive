ตัวต่อไปละกัน ( สับวันละตัวเลยแฮะ งานยุ่งจัด ) เรื่องแรก ลักษณะภายนอก โอเค ... พอรับได้อยู่ เพราะว่าพอที่จะจิ้นภาพตามออกมาได้ แต่ทรงผมข้างหน้านี่ขอจัดให้เลยละกัน โฮะ ๆ แบนซะด้วยแฮะ เรื่องการแต่งกายนี่ก็บรรยายออกมาได้สั้น ๆ ได้ใจความมากมาย ( ฮา ) คือชุดในรูปแต่ว่าจะมีผ้าพันคอสีแดงเป็นเอกลักษณ์ด้วยสินะ เรื่องนิสัยนี่ ... ผ่าน ! เพราะมียูริ ( มิใช่และ ) ดูท่าทางจะเอามาเล่นได้เยอะดี ฮึ ฮึ สิ่งที่ชอบ ... สรุปยัยนี่คือยูริแท้สินะ มาถึงเรื่องสกิล ! ขอตัดสกิลสุดท้ายออก เพราะคิดว่าน่าจะมีผลกับเนื้อเรื่องอยู่มาก แล้วก็ลดความเร็วของ ‘Speed Rush’ ลง เพื่อเป็นการปรับสมดุล ! ประวัตินั้น น่าตบมาก ... เอารูปมาแบ่งกันบ้างเซ่ =[]= !!
