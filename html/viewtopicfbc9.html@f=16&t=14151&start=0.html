เรื่องการปลูกต้นไม้ก็ยังไม่ทราบรายละเอียดเหมือนกัน เพราะเท่าที่ปลูกๆมาเอง ไม่ค่อยได้ผล
ทำให้สงสัยว่าอาจจะต้องมีปัจจัยอื่นๆอีก
(tree seed ปลูกมาไม่เคยได้ zendar wood เลย อยากด้าย)

ข้อดีของชาวนาก็ตรงที่ว่า ไปตีตรงไหนพอเห็นหนักๆก็รวมเอง ทำอาหารเอง
ทำให้ของที่แบกมี capa น้อยลงมาก ไม่ต้องกลับเมืองบ่อย
ดังนั้นหากแบบเป้ไปเก็บเกี่ยววัตถุดิบที่ Tiny ก็เป็นทางเลือกยอดอีกทาง
แต่เสียตรงที่ Tiny Island มันไม่ได้เลเวลหนะสิ เสียดายจัง -*-
