ขอพื้นที่บ่นและเตือนเล็กน้อย...

หนังสือรุ่นม.6ของพี่สาวผมที่พิมพ์กับหจก.พร้อมมิตรการพิมพ์ ออกมาห่วยมาก OTL
บางหน้าหลุดออกจากด้าย(ให้นึกถึงหนังสือของสนพ.ผีเสื้อที่ใช้ด้ายเย็บ ไม่แน่ใจว่าเรียกว่ากี่หรืออะไร) เย็บกี่ชุ่ยมาก ตัวอักษรเลือนและแตก สันยุบ บางหน้าก็เด้งขึ้นมามากกว่าเพื่อน บางหน้าก็ยุบแบนเรียบเสมอกับปกเลย สรุปว่าอ่านยาก มึน...
แต่พอดีหนังสือทำออกมานานพอสมควรแล้ว(หลายเดือนเหมือนกัน) เพิ่งได้เห็นและได้เอาไปให้คนรู้จักที่อีกสนพ.ดู ได้รับคำตอบว่า ถ้าเป็นที่สนพ.นั้น หนังสือคุณภาพระดับนี้ในราคาสั่งพิมพ์ขนาดนั้น ไม่วายต้องโดนสั่งยัดเครื่องทำลายเอกสารแล้วกลายเป็นถาดรองไข่CPฮะ...
พวกเพื่อนของพี่สาวเพิ่งเคยสั่งพิมพ์หนังสือเป็นครั้งแรก(คนที่เคยพิมพ์หนังสือก็มี แต่คนที่ไม่เคยพิมพ์ดันรับไปทำซะก่อน?) และเป็นหนังสือรุ่นที่สำคัญและสั่งพิมพ์ในราคาแพงมากด้วย... ผลสรุปคือ เสียหายย่อยยับ คนสั่งพิมพ์ได้หนังสือคุณภาพต่ำไม่คุ้มราคาสั่งพิมพ์ และไอ้ครั้นจะโทรไปจิกก็ไม่รู้ว่าจะนานเกินไปหรือยัง(ไม่รู้รายละเอียดตรงจุดนี้) สนพ.ได้กำไรเต็มๆฮะ OTL

ก็แค่จะบอกว่า ถ้ามีใครพิมพ์โด ฟิค หรือแอนโธ ระวังและตรวจสอบสำนักพิมพ์ที่จะสั่งพิมพ์ให้ดีก่อนนะฮะ...
ไม่ได้ไซโคว่าสนพ.พร้อมมิตรฯไม่ดีอย่างงู้นไม่ดีอย่างงี้ แต่ก็... รับฟังไว้หน่อยแล้วกันฮะ OTL

- ปืนยิง ฉมวก 2 ลูกแขนซ้าย
- โฮมิ่งตอปีโด 2 ลูก ( ติดที่ ขา )
- แขนกลยาว 2 เมตร หยิงจับสิ่งของที่อยู่ห่างได้ ไม่เว้น ชุดว่ายน้ำ ( แขนขวา )

- สามารถหลบการตรวจับเรดาร์ได้
- ดำได้ลึก 50 เมตรเท่านั้น
- กล้องถ่ายภาพ บนหมวก
- ไฟฉายส่องทางใต้น้ำ ( หมวก )
