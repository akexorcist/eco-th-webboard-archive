ปามีด จะมีอาวุธประเภทปาอยู่ครับ มีขายตามพ่อค้าชุดเขียวทั่วไปเมืองอาโครโพลิส

เลเวลสูงขึ้นก็จะมีขายตามที่อื่น ต่างๆกันไปครับ

จะเล่ยสายปา เงินหนาหน่อยละกันนะครับ เพราะอาวุธปามันต้องเหมือนกับลูกดอก ถ้าเวลาปา จะต้องคลิกค้างเพื่อร่าย(หรือเปล่าไม่แน่ใจ) ถ้าปาแบบนั้นรู้สึกจะไม่เสียอาวุธปานะครับ แต่ถ้าใช้สกิล จะเสียอาวุธปาอย่างมาก ยิ่งสกิล Continue trowing (ถ้าสะกดผิดขออภัย)
เลเวลสูงๆใส่เวลาร่ายนานหน่อยละก็ใช้ของขว้างหลายชิ้นขึ้น :wink:
