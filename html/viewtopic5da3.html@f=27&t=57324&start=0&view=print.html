เห็นมีคนทำจุดเกิดบอสปลากับบอสหมีม่วงยังไม่สมบูรณ์แฮะ
จากประสบการณ์ที่ล่ามาบอสปลานี่บริเวณเส้นทางเดินก็เกิดได้นะ แล้วก็ห้องขวาล่างก็เกิดได้เหมือนกัน
ส่วนหมีม่วงนอกจากตรงมุมขวาล่างแล้ว ก็เคยเจอมันเกิดตรงบึงพิษม่วง ๆ ด้านบนด้วยเหมือนกัน
(ยืนยันวาเห็นด้วยตาจริง ๆ ว่ามันเรียกลูกน้องตรงนั้นเลย)

นอกนั้นโอเค แต่ที่อยากรู้คือบอสหุ่นกระป๋องในอูเทน่าลิเวอร์นี่จนป่านนี้เราก็ยังไม่รู้เลย - - มีใครพอรู้มั่งน่ะ
