1. Dual-Hand Gun แรงกว่าเนื่องจากหากถือปืนชนิดนี้แล้ว จะทำให้ยิงได้มากกว่าปืนอื่นๆ 1นัด จากที่สุ่มระหว่าง 4-6 เป็น 5-7

2. คาดว่าหายากเพราะส่วนมากลง Agi เพื่อความปลอดภัยและการยิงที่รวดเร็วยิ่งขึ้น

แต่จะเล่นแบบนั้นก็คงไม่เสียหาย แต่ที่ไม่มีใครเล่นเพราะประโยชน์ออกจะน้อย อัพแค่พอประมาณ

ถ้าจะลงจริงๆ ควรแบ่งไปลง Vit บ้างเพราะจะช่วยได้มาก การยิงโดนทุกดอกโดยไม่ Miss ก็อาจเป็นตัวช่วยที่ทำให้ฆ่ามอนได้อย่างแน่นอน

แต่ปัญหาไม่ค่อยจะมีเพราะว่ามีสกิล Markman Aura ที่อัพกันอยุ่แล้ว

3. ไม่แสดงในหน้าต่าง Status แต่ช่วยให้แม่นและหลบดีจริงๆ (ในระยะประชิดแทบจะไม่มีการ Miss)


แล้วคุณ Zilernia เล่นปืนแบบไหนอ่ะคับ แนะนำหน่อยคับ แล้วอัพ stat เปนงัยบ้างอ่าคับ ตอนนี้รู้สึกกันเนอร์โหดดี แต่รู้สึกบางที miss เยอะ ไม่โดนทุกลูกเนี่ยแหละคับ ก้อเลยอัพ INT เยอะไปหน่อย แล้วคุณ Zilernia อัพ INT ไปเท่าไหร่ถึงคิดว่าโออ่ะคับ

แค่นี้ก่อน


อันนี้ค่อนข้างอธิบายยากซักหน่อย เพราะแต่ละคนมีแนวทางไม่เหมือนกัน

กบเหลือง คือตัวที่มีรูปร่างเหมือนชื่อ = = อาศัยอยู่แถว Momo plain แมพต่อจาก Eastor Cape

ชินนาม่อน อาศัยอยู่แมพ Valcano เดินลงมาจากแมพ Soutrin Cape 2แมพ

ส่วนตัวเราเก็บเลเวล ก็ตามนี้

1-10 ตีรอบเมืองไปเรื่อย หนักไปทาง Ckoco

10-25 ไปตีแมพ Momo Plain เน้นยิง หนอน และลูกไก่ (เลี่ยงหมูบ้า)

25-40 สลับยิงไปมาระหว่างหมีที่แมพ Warship Island และ กบเหลืองที่ Momo Plain

40-55 ยิงกบเหลืองต่อ แวะไปยิง ชินนาม่อนบางครั้ง

55-65 ยิงไพ่ในดันน้ำแข็ง สลับ กับโจรฟุชิกิ

65+ ลูกไฟหอแสง

ส่วนมากท่องเที่ยวไปเรื่อย เพราะเป็นช่วงหาข้อมุลตัวเกมส์ แต่หลักๆที่เก็บเลเวลด้วยก็ตามที่บอกหล่ะจ้า
