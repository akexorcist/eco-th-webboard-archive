กดดาวน์โหลดที่รูปเลยจ้า

ความต้องการของโปรแกรม
1.Window ที่ตั้ง System locale เป็น ญี่ปุ่น
2.สามารถใช้ applocale แทน System locale ญี่ปุ่นได้(ไม่แน่ใจ)
3.Microsoft Visual C + + 2008 SP1 Redistributable Package (x86)
4.DirectX 9 หรือ 8.1

-EcoDresser ตัวนี้ไม่มีผู้ชายจ้า
-ใช้ได้กับตัวเกมญี่ปุ่นเท่านั้น
-ไม่มีตาแบบเนโกะมาตะ-หรืออีโมบางท่า
-ของบางชิ้นอาจจะไม่เห็น





ตอนแรกแตกไฟล์ EcoDresser แล้วเลือก


โปรแกรมจะถามหาตัวเกม eco.exe ก็หาให้มันซะ =w=!!(ใช้ของยุ่นเท่านั้นนะ)

หน้าตาของโปรแกรมก็ประมาณนี้


เอาล่ะ!! ต่อไปนี้จะเป็นรายละเอียดของตัวโปรแกรม



อันนี้ข้าพเจ้าแปลให้คล้ายๆโปรแกรมอื่น


มาเริ่ม สร้างสาวน้อย กันตรงนี้




กดที่ Character กดปุ่ม H เพื่อเรียกหน้าต่างสร้างตัวละครออกมา


ปรับแต่งได้ตามใจชอบ เสร็จแล้วกดปุ่ม OK



1.หมวดหมู่ของไอเท็ม(แยกตามชนิด)
2.หมวดหมู่ของไอเท็ม(แยกตามตั๋ว)
3.ปรับเปลี่ยนEmotion ตาม Emotionของไอเท็มนั้นๆ

เลือกไอเท็มมาตกแต่ง จากแถบใหญ่ๆด้านขวา


ต่อไปมาดูแถบข้างล่าง



-แถบข้างบนคือ หมวดหมู่ Emotion
-แถบใหญ่ๆข้างล่างคือ ท่าทางตัวละคร หรือ Emotion สามารถกดเลือกได้เลย

รายละเอียดส่วนอื่นๆ(ขอไม่แปลแล้วนะ แต่จะบอกวิธีใช้แทน)

(เรียงจากบนลงล่าง)

-เปลี่ยนมุมมองแบบหน้าหลัง-หันข้าง โดยแยกเป็นช่องๆ
ภาพตัวอย่าง


-ปรับมุมมองให้เป็นมุมมองเริ่มต้น(หันหน้านั่นเอง)

-ยังไม่ทราบ(ถ้าทราบแล้วจะเอาข้อมูลมาเพิ่มให้)

-เปิด-ปิด เส้นขอบของตัวโมเดล
ภาพตัวอย่าง
ซ้ายเปิด ขวาปิด

จะเห็นได้ชัดเจนกับคางตัวละคร

-เปิด-ปิด การเคลื่อนไหวแบบลื่นๆ(จะว่าไงดีล่ะ เอาว่ามันไม่กระตุกละกัน )

-ค้นหาไอเท็ม(มั้ง? ไม่แน่ใจ)
กดแล้วจะจะขึ้นหน้าต่างเยี่ยงนี้


-เปิดโมเดลของ เอ็นพีซี-มอนเตอร์-เพ็ท
กดแล้วจะจะขึ้นหน้าต่างเยี่ยงนี้

(ขอบอกว่าแหล่มสุดๆ เพราะสามารถดูโมชั่นของเพ็ทหรือมอนต์ได้
แล้วก็ได้ส่องน้องอัลม่าหรือเพ็ทไหม่ๆเต็มที่ )

-เปลี่ยนพื้นบ้าน+ปรับสีพื้นหลัง


-ปรับแสงเงา
ภาพตัวอย่าง


-เปลี่ยนท่าทางเริ่มต้นตามเผ่าพันธ์อื่นๆ


-ยังไม่ทราบ(ถ้าทราบแล้วจะเอาข้อมูลมาเพิ่มให้)

เสร็จ!!!!หมดๆๆๆๆ ทำเสร็จแล้ว
ขอบคุณที่อุตส่าอ่านนะนิ ขอให้สนุกกับโปรแกรมน้า เอ้อ แล้วก็
ถ้า จขกท.เห็นว่า ไม่อ่านกัน แล้วไปตั้งขอหรือถามกันในกระทู้อื่นที่ไม่ใช่กระทู้นี้อีก จขกท.จะลบกระทู้นี้ทิ้ง
เพราะถือว่าทำแล้วไม่มีใครอ่านนะ

ปล. จขกท.เหนื่อยมาก ถ้าเอาไปแจกจ่ายกรุณาใส่เครดิตให้ด้วย
ปล.จขกท.ไม่เก่งด้านแต่งภาพ อาจจะแต่งได้ไม่ดีนัก
ปล.ข้อมูลบางส่วนที่ไม่รู้ ถ้ารู้แล้วจะนำมาเติมให้ภายหลัง
