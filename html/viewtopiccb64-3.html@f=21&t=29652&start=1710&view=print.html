กรรม อารมณ์ค้างจนได้สิน่า นึกว่า 1 ตอนก็จบซะอีก ว่าแต่ แบบนี้จะยืดได้ถึง 16 ตอนเลยนะเนี่ย แค่รอบแรก

ผมว่า น่าจะทำแบบดราก้อนบอลภาคแรก (ย้ำว่า ภาคแรก) คือข้ามบางคู่ในรอบ 16 คนไปนะครับ แล้วไปเขียนบรรยาย รอบ 8 คนสุดท้ายให้ครบทุกคู่ไปเลย จะดีไหมครับ (เช่น เจาสึ ซัดกับ เถาไปไป ก่อนรอบ 8 คนสุดท้าย ตอนศึกชิงจ้าวยุทธหลังจากปราบพิคโกโร่ครั้งแรกน่ะ ก็โดนข้ามไป ไม่มีบรรยายการสู้ บอกผลแพ้ชนะไปเลยน่ะครับ )

ไม่ใช่ว่าผมใจร้อนนะครับ แต่ถ้าค่อยๆ กระดึ๊บ ไปทีละคู่ กว่าจะครบ 8 คงหลับก่อนพอดี ไม่ก็บางคนอาจเบื่อซะก่อน แต่ถ้าจะเขียนให้ครบ ผมก็ไม่ได้ว่าอะไรนะครับ เพราะเป็นคนบ้าอ่านนิยายเหมือนกัน ไงๆก็อ่า่นแน่ๆ ล่ะครับ
