เอาสเตปแบบของผมนะ

ช่วงแรกๆก็อยู่แมปรอบๆเมืองหรือตีหมีไปก่อน ( แมป warship )

ทำเควสไปด้วยเรื่อยๆ ประมาณ 3 - 4 วันก็น่าจะ 30 แล้ว

พอเลเวล 30 อัพ str ล้วน ใส่ dex นิดหน่อยพอให้ตีไม่วืด แล้วก็ไปแมปซินนามอนเลยคับ ( Iron South Highway หน้าเมืองใต้อะ ) ถ้าให้ดีหาคนสิงมือที่ str เยอะๆมา Soul ให้ จะสบายมาก

พอเลเวล 40 นิดๆ ก็ไปดันไพ่ที่เมืองเหนือ ตีไพ่เอา ( พกพระไปด้วยก็จะดีมาก )

พอ 50 กลางๆเปลี่ยนอาชีพแล้ว ก็พกพระ ไปอยู่ Undead Castle ให้พระเสกอาวุธแล้วไปตีพวกผีดิบกับโครงกระดูก อยู่ตรงนั้นได้จน 65 ล่ะครับ ( พอได้สกิล Devine spear ก็ไม่ต้องใช้พระแล้วก็ได้ )


ปล. ถ้ามีเพื่อนเล่นอยู่ก่อนหน้าแล้ว ช่วงแรกๆให้ไปดูดเพื่อนก่อนจะสบายขึ้นมาก ( วันเดียวก็ 40 แล้ว )

ปล.2 วิธีแบบของผม ถ้าไม่มีคนสิงมือ หรือไม่มีพระฮีล จะเปลืองของปั๊ม hp มากเลยนะ

ปล.3 ตอนผมเล่นมีนักธนู str101 สิงมือ + พระคอย Rouse body ให้ตลอด ถ้าคุณไม่มีซัพพอตแบบนี้ แต่ละแมปก็อาจจะต้องบวกเพิ่มไปอีกสัก 5 เลเวลนะ
