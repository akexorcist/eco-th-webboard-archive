สกิล hexagram สร้างม่านพลังป้องกันทุกคนในขอบเขตป้องกันการโจมตีทางกายภาพ ถ้าเราไม่ตีมอน มอนก็ไม่ตีเราครับ แต่ถ้าเราตีมอน มานวิ่งมาสอยเราในวงเลยครับ
มานมีข้อเสียตรงที่สมมุตว่าคนไปยิงหุ่นเขียวในดันใต้นะครับมานจะร่ายเวทเกิดเราใช้สกิลนี้มานก็จะโดนเราด้วย พุดง่ายๆคือไม่ป้องกันเวทมนต์
โดยรวมแล้วก็ถือว่าดีสมควรอัพ ใช้ช่วยเหลือปาร์ตี้ ยกตัวอย่างในกรณีคนตายกลางมอน เราใช้เวทนี้แล้วให้พระชุบเขาตื่นขึ้นมาก็ไม่เป็นไร แล้วก็สามารถสิงต่อได้เลยประมาณนั้น ไม่ต้องลำบากวิ่งหาที่หลบสิงใหม่หรือเสี่ยงกับการตื่นขึ้นมาแล้วตายต่อ อธิบายแค่นี้พอจะมองเห็นภาพนะครับ
