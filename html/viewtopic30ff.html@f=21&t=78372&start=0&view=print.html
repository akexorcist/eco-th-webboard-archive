คุณสร้างtime machineได้ด้วยตัวเอง...เชื่อไหม?(มีสาระนิด)

โพสต์แล้ว: อังคาร 28 ธ.ค. 2010 4:14 pm
โดย ECO
ในเมื่อมันเกิดขึ้นแล้วก็ต้องยอมรับล่ะนะ เคยดูโดราเอม่อนกันไหม การ์ตูนเรื่องนี้แม้ในการ์ตูนมันจะมีของวิเศษมากมาย มี

time machine

แล้วคุณเคยไหมที่ดูการ์ตูนเรื่องนี้ แล้วคุณคิดจะหาของวิเศษมาใช้ในโลกแห่งความจริง ซึ่งมันไม่สามารถเป็นไปได้ เพราะ

ของวิเศษมีแค่ในการ์ตูน

แล้วคุณเคยไหมที่จะหา time machine หรือ คิดว่าอยากจะมีมันก็ดีจะได้ใช้ประโยชน์จากมันเพื่อแก้ไขอดีต ซึ่งมันไม่

สามารถมีจริงๆ

คุณเคยไหมคุณมัวแต่ที่อยากจะได้ของวิเศษเหล่านี้เหมือนกับโนบิตะ ที่มีอะไรก็ต้องพึ่งแต่ของวิเศษ

คุณไม่จำเป็นที่จะต้องพึ่งของวิเศษพรรคนี้เลยด้วยซ้ำ ในโลกนี้มันคือโลกแห่งความจริง

แต่คุณอยากรู้ไหมถึงแม้ของวิเศษในการ์ตูนจะไม่มีในโลกแห่งความจริง

แต่คุณก็สามารถทดแทนของวิเศษเหล่านั้นได้ คุณไม่เคยคิดถึงข้อนี้เลยใช่ไหม

หากคุณลองคิดดีดีอย่างเช่น time machine ที่สามารถย้อนเวลาได้ กลับไปสู่โลกแห่งอดีตได้ คุณจะใช้มันเมื่อไหร่

คุณจะใช้มัน เพื่อแก้ไขอดีต ซึ่งในโลกแห่งความจริงมันทำเช่นนั้นไม่ได้ แต่คุณสามารถแก้ไขมันโดย

ให้คุณคำนึงถึงปัจจุบัน ณ ตอนนี้ time machine คือ "ความคิดของคุณ" และ "สติของคุณ"

คุณใช้ความคิดที่ถูกต้องและคำนึงถึงผลเสียของมัน หากคุณใช้สติในการทำสิ่งที่ถูกต้อง แล้วคุณยังจะนึกอยากจะกลับไป

ย้อนเวลาอีกไหม ?

การ์ตูนโดราเอม่อน แม้จะมีแต่คนบอกว่าเป็นการ์ตูนที่ไร้สาระ ปัญญาอ่อน แล้วคุณเคยไหมที่จะดูการ์ตูนเรื่องนี้สักหนแล้ว
