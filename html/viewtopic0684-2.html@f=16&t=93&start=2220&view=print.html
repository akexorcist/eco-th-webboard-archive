คืออยากให้บอก Tips ผู้เล่นใหม่นิดนึงว่า ไม่ต้องเสีย Steel Nugget ตอนเปลี่ยนอาชีพ 3 อันก็ได้~

1.ไปคุยกับ Npc เปลีย่นอาชีพ(อย่าลืมถือ Steel Nugget ไปด้วย)
2.เมื่อเค้าบอกให้ไปหา Steel Nugget มา 3 ก้อน ให้ถือมาให้เค้า
3.เมื่อเค้ายอมคุย และบอกให้ "แก้ผ้า" ให้เราถอดเสื้อผ้าทั้งหมดออก รวมทั้งโยน Steel Nugget ออกไปทั้ง 3 อัน
4.เมื่อคุยอีกที่ เราจะได้เป็น tatarabe และมีข้อความแสดงว่า "คุณเสีย 3 Steel Nugget"(ขึ้นงี้เป่าไม่แน่จาย~) โดยที่เรายังไม่เสียอารายเลย~
