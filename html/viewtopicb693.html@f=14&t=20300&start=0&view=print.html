ความเสียหายที่ได้720% แถมถ้าใช้หมัดจะต่อยช้ามากๆ

พอใช้สกิลนี้จะเร็วกว่ามาก

เล่นสายกรงเล็บอยู่ คิดว่าสายกรงเล็บไม่มีใช้ก็ไม่เป็นปัญหา เพราะชกเอาเร็วกว่าไปกดสกิล
แถมเวลากดแล้วมันจะค่อยๆบรรจงจิ้มจนครบห้าครั้ง
ตัวสกิลไม่มีดีเลย์ก็จริง แต่ด้วยแอกแทกสปีดของกรงเล็บ ทำให้โมชั่นดีเลย์ช้าน่ารำคาญมากๆ :x
สายกรงเล็บกด SSDC ไม่ได้ ก็เลยเร่งให้มันแทงเร็วๆไม่ได้
จะกด poisonสำหรับเร่งความเร็ว ก็ยังไงชอบกลอยู่
รวมๆแล้วถือว่าไม่ค่อยเวิร์คครับ

แต่สายมีดคิดว่าจำเป็นมาก ใช้หากินได้เลย
เพราะดาเมจแรงและนิ่งกว่าแบรนดิช(จ๊อบ40) มากๆ
แถมสปีดการแทงก็เร็วกว่าฟันธรรมดา ถ้ามี SSDC ยิ่งแจ่มเลย
สรุปว่าถ้าเล่นสายมีด ยังไงก็ต้องมี :P
