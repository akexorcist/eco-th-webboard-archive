ตอนทำอีเวนท์ยามาบุกิ ก็สนุกดีนะ ชอบที่มันไม่เปลืองมากอ่ะ
(เสียค่าคริสตัลอย่างเดียว)
แต่น้องแมวโมโมะเกือบดับ :lol:

เมื่อวานไปลองทำอีเวนท์ไอจัง เหนือยมาก
ตอนแรกไปคุยกะหุ่นมันก็ขึ้นมาประมาณว่าเป็น มาริโอเนต ที่พัง
ต้องไปอัดเควสอีก 2 รอบ แล้วกลับไปคุยใหม่ถึงเริ่มเควสได้ :wink:
เริ่มเควสได้ก็ต้องไปหาของอีก
กว่าจะได้หินคริแทบแย่ (30 เค...แพงไปมั้ย)
ค่าใช้จ่ายรวมๆแล้วก็ร่วม 70 เค
(มีของทำอีเวนท์เหลืออยู่พอสมควร เลยไม่ต้องซื้อใหม่)

แต่ของที่ทำผ้าสามเหลี่ยมติดใจมาตั้งแต่ตอนน้องโมโมะแล้ว
ว่ามันไม่ใช้ Needle อ่ะ
ใช้แค่ Cotton Ribbon กับ Fabric กับThread เองอ่ะ
(ตอนทำ พกไปอย่างละอัน :? )

ต้องขอบคุณผู้ทำข้อมูลดีๆแบบนี้น้อ ไม่งั้นคงไม่ได้เลี้ยงน้องแมวนะเนี่ย
ตอนนี้รอน้องแมวตัวที่เหลืออยู่ เมื่อไหร่จะได้น้อ :)

หรืออาจจะไม่ได้ติดตั้ง Nekomata [Momo] ในขณะที่กำลังดำเนินเควสอยู่

เอางี้นะคะ เดี๋ยวเรามาไล่กันอีกทีว่า ทำอะไรไปแล้วบ้างเผื่อว่าตกหล่นตรงไหนเนอะ

:arrow: วิธีทำ Nekomata [Yamabuki] เริ่มจาก
1. รับเควสที่ NPC : Return Goldo ที่ Warship Island (ติดตั้ง Nekomata [Momo] ด้วยนะคะ)
2. คุยกับเค้าเลือก ข้อ 2 เค้าจะให้กระเป๋ามา 1 ใบ ให้นำไปส่งให้กับ Merchant Guild ที่ Ancient Palace Guild ชั้น 4
3. กระเป๋าถูกขโมย ถูกเจ้าหน้าที่สอบสวน ต้องคุยกับ NPC ในห้องทุกตัว (คุย 2 ครั้ง แล้วจะออกจากห้องได้ค่ะ)
4. กลับไปหา NPC : Return Goldo ที่ Warship Island
เค้าจะให้เราไปสอบถามข้อมูลจาก NPC : Guide Machine ที่หน้า Ancient Palace Guild
5. มาสอบถามข้อมูลจาก NPC : Guide Machine ที่หน้า Ancient Palace Guild
6. ไปคุยกับป้าเย็บผ้า Sewing Aunt
7. กลับมาคุยกับ NPC : Guide Machine ที่หน้า Ancient Palace Guild อีกครั้งค่ะ
8. ไปที่ Ancient Palace Guild ชั้น 5 แล้วไปทางห้องสีน้ำเงิน (ทางเดินสีน้ำเงินค่ะ)
เราจะเข้าไปไม่ได้ เพราะมีบาเรียกั้นไว้
9. ไปร้าน Junk Shop มอบ Crystal 1 ชิ้น หรือ Crystal Piece 5 ชิ้น
ให้กับ NPC : Junk Shop's Worker แล้วเค้าจะมอบ Crystal Quartz 1 ชิ้น
10. กลับไปที่ Ancient Palace Guild ชั้น 5 แล้วไปทางห้องสีน้ำเงิน (ทางเดินสีน้ำเงินค่ะ)
11. เข้าไปจะพบกับ NPC : Doubtful Boy สู้กับเค้าเราจะได้รับ Unknow Part
12. นำ Unknow Part มาให้กับ Merchant Guild ที่ Ancient Palace Guild ชั้น 4
13. กลับไปหา NPC : Return Goldo ที่ Warship Island ค่ะ

:oops: ทีนี้เราก็จะได้รับ Nekomata [Yamabuki] มาไว้ในครอบครองแล้วค่ะ :oops:
