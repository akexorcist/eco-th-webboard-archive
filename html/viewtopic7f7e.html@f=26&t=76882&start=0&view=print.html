*คำเตือน* - เลียนแบบไม่ว่าแต่อย่าทะลึ่งเอาไปประกวดแล้วกัน
หากเข้ามาเล่นอะไรแล้วรบกวนช่วยปรับให้เป็นอย่างเดิมด้วยนะเจ้าของบ้านขี้เกียจมานั่งแก้บ่อยๆ

เอาล่ะจุดที่จะพบเจอสวนลอยฟ้าของกลุ่มฟุชิกินั้นจะเจอได้ที่~~~~ กลางอัพทาวน์หน้าไทนี่เป็นบางครั้งบางคราหากอารมณ์ดี


เอาล่ะ ประเดิมด้วยโรงเรียนประถม(หรืออนุบาลหว่า)ฟุชิกิ


หน้าโรงเรียนแอ๊บแบ๊วมาก ตัวโรงเรียนทำความสะอาดบ่อยๆเลยมีแสงประกายวิบวับ และน้องแกะน้อยที่ต่อแถวเดินเข้าเรียนอย่างสง่างาม


คุณพนักงานร้านอาหารทำอาหารหอมเชียว~~ แต่เอ๊ะ!! ในตู้ล็อกเกอร์นั่นใครขังอะไรไว้น่ะ!?


ในโรงเรียนแบ่งเป็นสัดส่วนย่อยๆมากมาย ตั้งแต่ที่นั่งผอ.โรงเรียน สนามบาสในร่ม ห้องดนตรี และห้องเรียน

เอาล่ะโอยาสุมิ~~~ ง่วงแล้ววันนี้พอแค่นี้ก่อนละกันเอาไว้ค่อยหาฟิกเกอร์ลงเพิ่ม


ขอบ่นหน่อยเถอะกิจกรรมประกวดบ้านบินอ่ะน่าจะให้คนถ่ายภาพหลายๆมุมหน่อยก็ดีนะ ไม่ใช่แค่ในบ้าน1ภาพนอกบ้าน1ภาพ แบบนั้นแต่งบ้านโดยเน้นเหมือนการทำแบ๊กกราวน์ให้ภาพสวยมันก็ทำได้อ่ะสิเพราะจงใจถ่ายแค่มุมนี้ มุมนี้ต้องสวยที่สุด จริงๆน่าจะกำหนดในบ้าน3มุมไม่ซ้ำกัน นอกบ้าน3มุมไม่ซ้ำกัน ถึงผมจะไม่ได้ลงประกวดก็เถอะนะ(ไม่ว่างตอนมีประกวด) แต่รู้สึกกติกาไม่แฟร์อ่ะ *3*
