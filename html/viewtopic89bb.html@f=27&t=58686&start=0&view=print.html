ถ้าใช้โกเล็ม จะทำได้ทุกอาชีพเค่อะ
แต่ถ้าเป็นพ่อค้า จะตั้งร้านด้วยตัวเองได้ ไม่ต้องพึ่งสกิลหรือโกเลมใดๆ ขอให้มีของที่จะขาย และเวลาพอ (ฮา)
โดนคลิกขวาที่ตัวเอง เลือก ติดตั้งร้านแผงลอย แล้วใส่ของ ราคาของ ชื่อร้าน ลงไป พอกดตกลงแล้ว เราก็จะทำการตั้งร้านเรียบร้อย (สามารถ เดิน วิ่ง นั่ง ทำท่า ได้อิสระเวลาตั้งร้านะ)

ส่วนวิธีใช้โกเล็มก็ตามนี้

ถ้าจะขายของ ให้ดับเบิลคลิกตัวโกเล็ม เลือก ขายของ
แล้วนำของที่จะขายใส่ในช่อง ตั้งชื่อร้าน ตั้งราคา ระวังตั้งผิดราคาล่ะก๊ะ
เมื่อเสร็จเรียบร้อยให้กด OK เท่านี้ตัวละครเราก็จะพร้อม (แต่ยังไม่ตั้งโกเล็มนะเคอะ)

ส่วนการขาย ทำคล้ายๆกับซื้อ แต่ให้เลือก จำนำ และต้องมีของที่เราจะรับซื้อในตัว อย่างน้อย 1 ชิ้นด้วย

เมื่อเราตั้งร้านซื้อ/ขาย เวร็จขั้นตอนตามขั้นตอนด้านบนแล้ว เมื่อเราจะลอคเอาท์ มันจะมีหัวข้อเพิ่มอีก 1 หัวข้อคือ "ลอคเอาท์โดยทิ้ง Golem ไว้" เมื่อเราลอคเอาท์โดยใช้เมนูนี้ โกเล็มก็จะขายของให้เราตรงจุดที่เราลอคเอาท์ ดังนั้น จะขายที่ไหนลอคเอาท์ที่นั่นนะเคอะ
