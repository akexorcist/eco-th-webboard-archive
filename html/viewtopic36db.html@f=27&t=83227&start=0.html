[DEM] DEM Skill

โดย NETIX » ศุกร์ 17 ส.ค. 2012 11:05 am

กระทู้นี้จะเป็นการรวบรวมข้อมูลของสกิลของเดมที่ไม่มีในอาชีพไหนเลย หรือก็คือเป็นสกิลของเดมโดยเฉพาะนั้นเอง

ข้อมูลจาก eco wiki Jp
http://ec.gamedb.info/wiki/DEM/Skill/Explanation.html

ระดับความน่าใช้งานของสกิล แบ่งได้ดังนี้
☆ = น่าใช้มาก
◎ = น่าใช้
○ = น่าใช้ปานกลาง
△ = ใช้ได้บางสถานการณ์
× = ไม่น่าใช้อย่างยิ่ง!!

ルーキーブロウ[Rookie Blow]
ประเภท : Active
เป้าหมาย : เป้าหมายเดียว
ระยะ : เท่าระยะแขน
เงื่อนไข : แขนมีการโจมตีแบบฟัน, ทุบ และ แทง
เลเวลสกิลสูงสุด : 1

ระดับความน่าใช้งาน : ×
สกิลแบบประชิดสกิลแรกที่ได้รับจากเนื่อเรื่องเริ่มต้น

ヴァリアブルウエポン[Variable Weapon]
ประเภท : Active
รายละเอียด : เป็นสกิลที่เพิ่มธาตุในอาวุธสามารถเพิ่มได้ทั้ง 6ธาตุ ตามระดับเลเวลสกิล
เป้าหมาย : ตนเอง
เงื่อนไข : ไม่มี
เลเวลสกิลสูงสุด : 6

ระดับความน่าใช้งาน : ☆ หรือ ○
น่าใช้มากสำหรับสายโจมตีทางกายภาพควรมีติดตัวไว้
ส่วนสายเวทจะได้ใช้กับพาร์ทหลังที่มีสกิลโจมตีเท่านั้น ไม่ส่งผลต่อเวท

ソリッドコーティング[Solid Coating]
ประเภท : Active
รายละเอียด : ทำให้ผู้ใช้สกิล และ ผู้ที่อยู่ในปาร์ตี้เดียวกันในบริเวณใกล้เคียง ได้รับดาเมทจากการโจมตีทางกายภาพเป็น 0
เป้าหมาย : ผู้ใช้สกิล และ ผู้ที่อยู่ในปาร์ตี้เดียวกันในระยะ 13*13 ช่องรอบตัวผู้ใช้สกิล
เงื่อนไข : ผู้ใช้มี Lv.100 ขึ้นไป
เลเวลสกิลสูงสุด : 5

ระดับความน่าใช้งาน : ○
เป็นสกิล Solid Aura แบบหมู่
เทียบจาก Mpที่ใช้ ราคาชิพ และ ขนาดของชิพ หากไม่ได้เวลแบบเป็นปาร์ตี้ ใช้ Solid Aura เหมือนเดิมดีกว่า

オーバークロック[Overclock]
ประเภท : Active
รายละเอียด : เป็นสกิลที่ทำให้เพิ่มประสิทธิภาพให้แก่ผู้ใช้สกิลเป็นอย่างมากพร้อมกับลด Hp ตลอดเวลา
เป้าหมาย : ตนเอง
เงื่อนไข : ผู้ใช้มี Lv.100 ขึ้นไป
เลเวลสกิลสูงสุด : 3

ระดับความน่าใช้งาน : ☆
เป็นสกิลที่เพิ่มสเตตัสให้กับผู้ใช้สกิลเป็นอย่างมาก ถึงจะมีข้อเสียเมื่อใช้งานจะติดสถานะ flare ทำให้ Hp ลดตลอดเวลา
แต่ก็คุ้มค่ากับสเตตัสที่ได้เพิ่มมา

ガラスフロムレン[Glass from Len]

สกิลนี้ส่งผลเหมือน แจวาป(empty key) ทุกประการ
