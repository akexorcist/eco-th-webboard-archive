โดย ECO
คือ ตอนนี้อยากลองเล่น Archer แล้วไปถือปืนเล่นดูอ่างับ เลยอยากรู้หน่อยอ่างับ
- ถ้าเราเล่น Archer ควรเปลี่ยนตอนจ๊อบไหนดีอ่า (เก็บ ถึงจ๊อบ 50 เลยรึป่าว) ถ้าเน้นไปเล่นที่กันเนอร์อย่างเดียว
- แล้วพอเปลี่ยนอาชีพเป็น striker เก็บถึงจ๊อบเท่าไหร่ดีอ่ะคับ
- แล้วควรโอนสกิลอะไรมามั่ง (ผมดูแล้ว เอามาได้ไม่กี่สกิลเอง เช่นสกิลเปลี่ยน Sp เป็น Hp นี่น่าโอนมาม้ยอ่างับ)
- Stat ถ้าเล่นปืนคู่ เน้น Agi หรืแ Str นำหรองับ
- แล้วจาก Striker เปลี่ยนเป็น กันเนอร์ ตอนเลเวลเท่าไหร่ดีงับ

รบกวนถามมากไปรึป่าวงับ
แต่อยากรู้จิงๆ น่ะงับ T^T วานผุ้รู้ตอบทีจ้า
