ใช้กล้องแบบไหนครับ ผมจะบอกวิธีลงแบบขั้นตอนดีกว่า ง่ายดี
1.ถ้าเป็นกล้องแบบมีพอร์ต(ที่เสียบแบบUSB) ก็เสียบเข้าได้เลยครับ เหมือนแฟลสไดร์แหละครับผม สำหรับกล้องถ่ายรูปดิจิตอลบางรุ่น
2.ถ้ามีแผ่นไดร์เวอร์มาด้วย ก็ลงไดร์เวอร์ครับ โปรแกรมพวกนี้จะเป็นเหมือนที่เปิดฝากระป๋องครับ(คือกล้อง=ปลากระป๋องแหละนะ)
3.ถ้าเป็นแบบการ์ด อันนี้ยุ่งยากหน่อย ถ้าเป็นโน็ตบุคแบบมีช่องเสียบการ์ด อันนี้สบาย แต่ถ้าเป็นPCทนหน่อย เพราะต้องหาซื้อพ่วงครับ แต่ถ้าเป็นแบบการ์ด แต่มีสายพอร์ตแบบข้อ1 ก็สบายดีเหมือนกัน เพราะใส่ได้2ทางเลย


ยาวไปไหมครับ เข้าใจไหมครับ...อธิบายอย่างคร่าวๆครับ ไม่ละเอียด ถ้ายังไงศึกษาจากตัวเครื่องหรือลองผิดลองถูกเองนะครับ เพราะการศึกษาไม่ใช่จากในห้องเรียนครับผม
