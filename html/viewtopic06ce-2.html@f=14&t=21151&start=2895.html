reiina.rins เขียน:แล้ว Vit โบนัส Def ตัวหน้ามันทุกๆ กี่แต้ม คะ ?

ทุก 3 Vit ได้ 1 Def
ที่ 9 Vit ได้ 3 Def แทน
เช่น Vit 3 = 1 Def : Vit 6 = 2 Def : Vit 9 = 5 Def
ชัดเจนไหมอ่า ชอบว่าเราตอบไม่ชัดเจน T T

Dark Protection เคยเป็นสกิลที่เอาไปตอนสวิทกลับไนท์ครั้งแรกนะ
สมัยเลเวลตัน 65 (ปราสาทอันเดดนี่บ้านผมเลย)
การล่าบอสหมาดำ ก็เป็นอะไรที่หวาดเสียวอยู่ สมัยนั้น
มีสกิลนี้ก็ทำให้ชนหมาดำและลูกน้อยได้สบายใจหน่อย
สกิลโดยรวมแล้วมีผลไม่คุ้มเงื่อนไข

สมัยนี้เลเวลมันขึ้นได้สูง ทำอะไรไม่ลำบากแล้ว
ไม่ต้องอัพ นอกจากมันเป็น คอนเซ็ป
