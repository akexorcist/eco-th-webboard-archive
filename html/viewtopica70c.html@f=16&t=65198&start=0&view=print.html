เควสหมวกเลเวล 35ของชาวนา มันจะให้ไปหาของกินอะไรไม่รู้เยอะแยะใช่มั้ยคะ
พอดีเราติดอาหารอยู่อย่างนึงค่ะมันคือ
*Calsium biscuit* ครือว่าเราก็ไปดูตำราทำอารแล้วค่ะว่ามันต้องใช้อะไร
แต่ คุณป้าทำอาหารมันดันไม่ขึ้นของที่เราจะทำอ่าค่ะ

ส่วนผสมคือ Butter + Barley powder + Sugar + Milk

คุณป้าดันขึ้นสว่นผสมของchocolateship biscuit อย่างเดียวเลยไม่ยอมให้ทำแคลเซียมบิสกิต
รบกวนถามใครพอจะรู้ได้บ้างคะว่าเป็นเพราะอะไร หรือเป็นบัคหรือปล่าว
ถ้าเป็นบัคอยากใช้ช่วยแก้เร็วๆด้วยค่ะ เพราะตอนนี้ชาวนานู๋ของกินไอ้เควสนี้มันรกมั่กๆเลยT^T
