โดย ECO
คือว่าส่งของจาอวอเตอร์เลเยอร์ไปฟาอีสใช่ไหมคะ
จริงๆแล้วคลับฟาอีสมันมีสองจุดอ่ะค่ะ

มีคลังที่เขตแดน กับ คลังที่ฟาอีส (งงไหมเนี้ย...)

คลังที่เขตแดงก็จะเปิดดูได้ที่ อีสเตอร์เคป
ส่วนคลังฟาอีส ก็จะเปิดได้ที่ฟาอีสโดนตรง

แล้วโดยปกติคลังวอเตอร์จะเป็นคลังเดียวกับคลังฟาอีส

แต่!!!เวลาส่งของผ่านพ่อค้าอ่ะ มันจามีให้เลือกระหว่างคลังเขตแดนและคลังฟาอีส
ซึ่งหากเลือกเป็นคลังเขตแดน(fareast pulbic?)ล่ะก็ จะหาของที่จะส่งไปฟาอีสมันก็คงจะไม่เจอหรอก(ก็คนละอันกันนิ)

ลองไปเช็คดูที่คลังตรงอีสเตอร์เคปดูนะคะ
