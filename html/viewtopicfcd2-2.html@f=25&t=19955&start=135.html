ถ้าลองคิดเล่นๆ ปรับสูตรคำนวน จากเดิม ที่ว่า

โค้ด: เลือกทั้งหมด
ค่าความเร็วที่ได้ = 210 + (ค่า stat รวม x 3 / 4) + (จำนวนครั้งการพัฒนา Lv x 8 / 3)

ลองเปลี่ยนมาเป็น แบบนี้ดู
โค้ด: เลือกทั้งหมด
ค่าความเร็วที่ได้ = 110 + (ค่า stat รวม x 3 / 4) + (จำนวนครั้งการพัฒนา Lv x 8 / 3)

น่าจะใกล้เคียงความจริงมากกว่ามั้ย อย่างเช่น หนอนเรา ถ้าคำนวนด้วยสูตรที่แก้ไขแล้วจะได้
โค้ด: เลือกทั้งหมด
110 + (248x3/4) + (30x8/3) = 376 ช่อง / 100 วินาที


ซึ่งเทียบกับคนแล้ว สูสี แทบไม่รุ้สึกแตกต่าง....
สปีดคนวิ่ง = 380
สปีดหนอนที่คิดใหม่ได้ = 376
น่าจะใกล้เคียงความจริงกว่า...

เพราะว่า 210 มันก้เป็นค่าคงที่ ที่ตั้งมาจากไหนก้ไม่รู้ ถ้าเอามาปรับแต่ง ซะหน่อย
ก้ไม่น่าที่จะมีปัญหาอะไร...



ค่าคงที่ 210 ที่นายว่า ก็คือค่าความเร็วเริ่มต้นที่น้อยที่สุดของหนอนซิ่ง..

ลองไปคิดดูเองนะ

เออ นั่นสินะ 210 มันก้คือ ค่าความเร็วเริ่มต้น ที่น้อยที่สุดของหนอนซิ่ง ตามสูตร นี่เอง (ทำไมโง่แบบนี้เนอะ = =)

ถ้าเป็นแบบนั้นจริงๆ สูตรนี้ก้เชื่อถือไม่ได้... จบข่าว...
เพราะ 210 เป็นค่าความเร็วเริ่มต้นที่น้อยที่สุด ของหนอนซิ่ง จริงหรือเปล่าก้ไม่รู้...

และค่าที่คำนวนได้ตามสูตร มันก้ออกมา มากกว่า ค่าความเร็วของ มังกรแดง ซะอีก...

และผลการทดสอบกับ มังกรแดง มันก้วิ่งได้ ช้ากว่ามังกรแดงอย่างเห็นได้ชัด

และผลการทดสอบกับคน มันก้วิ่งได้ เทียบเท่ากับคน อย่างเห็นได้ชัด

ช่วงนี้คงไม่มีเวลาหาหนอนน้อยมาทดสอบ เพราะ หนอนน้อยหมดซาต๊อกแล้ว

และอีกอย่าง ตอนนี้กำลัง เห่อ อาชีพอาเคมิส เสียด้วย - -.

อย่างไรก้ตาม จะพยายาม หาข้อมูลเพิ่มเติม มาเปรียบเทียบให้ละกัน

หากแต่ว่า...
