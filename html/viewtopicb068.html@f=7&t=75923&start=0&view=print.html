ความฝันของข้าเจ้า

1.ปาป้าเทพ (รออีกชาติ)
2.มีเงินพอใช้ตลอดชีพ (ค่อยเก็บๆ)
3.ได้ถ่ายรูปบอสสุดโมเอะเดี่ยวๆแบบใกล้ๆ (ปกติตายตลอด)


หลังจากที่รอคอยมานาน

ในที่สุด

ก็ทำความฝันที่3ได้สำเร็จสักที


มันจะมีอยู่วันนึงที่เฮียจีมาปล่อยบอสที่เกาะไทนี่

เราก็เลยนึกสนุก

ใช้ไอเทม Copy Monster Card

แปลงร่างเป็นบอสโมเอะซะเลย


อาจจะคิดว่าแค่รูปบอสโมเอะมันดูธรรมด๊าธรรมดา(สำหรับบางคน)

แต่ก็ตั้งใจเอามาลงนะค่ะ

คราวนี้รูปไม่เหมือนที่ทุกคนเคยเห็นแน่นอนค่ะ







มีหลับตาด้วย (กริ้ดในใจ)













มองมุมไหนก็ดูดีเนอะ







มองออกไปในทะเลก็ดูเท่ไปอีกแบบ










ท่าตอนใช้เวทมนตร์ (มีอาวุธมือเดียว)













ท่าตอนตีธรรมดา(มีอาวุธ2มือ)








ลั้ลล้าก่อนจาก

รู้สึกดีมากเลยนะค่ะที่ได้เป็นบอสโมเอะครั้งหนึ่งในชีวิตของอีโค่

ถึงจะเพียงแค่30นาทีก็ตาม
