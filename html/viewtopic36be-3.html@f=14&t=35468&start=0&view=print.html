ไม่มีรูปนะครับอัพโหลดไม่เป็น

สำหรับคนที่รู้ข่าวเกี่ยวกับอาชีพBreederแล้วคงจะอยากเล่นกันไม่น้อยซึ่งอยู่ไนโหมด

Job joint Systemสำหรับระบบนี้ถ้าว่าไปแล้วก้อคล้ายกลับเพิ่มความสามารถไห้ตัวละครอะ

คัรบทำไห้ไช้สกิลไนสายจอยจ๊อบสิสเตมทันทีโดยไม่จำกัดว่าเปนอาชีพอะไรเพียงแค่เปลี่ย

สัญลักประจำอาชีพไส่ตัวละครของเราก้อเป็นbreedได้แล้วง่ายชิหละแต่คาดว่าไนอนาคต

คงจะไม่ไช่แค่breedอาจจะมีอย่างอื่นด้วย

Breederสามารถขี่มังกรสีดำได้ด้วยนะขอร๊าบเป็นอาชีพเดียวที่ขี่ได้

อันนี้ยังไม่รู้ข้อเท็จจริงคือเวลาจ๊อบอัพจะอัพสกิวเองรึเปล่านะ

วิธีเปลี่ยนอาชีพ
ต้องมีเลเวล30ขึ้นไปไม่จำกัด อาชีพ เผ่า เพียงเวลถึง

แล้วไปคุยกับBreeder guildที่เมืองฟาอีสคาดว่าทุกคนรู้

พอถึงไนเมืองแล้วไห้เราเดินไปทางเหนือที่มีลูดเจี๊ยบอยู่ข้างบ้าน

เดินเข้าไปคุยเพื่อรับการทดสอบหลังทดสอบเสร็จก้อจะได้รับฺBreeder Brooch

เพียงไส่ก้อจะกลายเป็นBreederพอถอดก้อกลายเปนอาชีพเดิมที่เราเอามาเปลี่ยนเช่น

Assไส่Breeder Broochก้อจะกลายเป็นBreederพอถอกก้อจะกลายเนASSเช่นเดิม[/size]
