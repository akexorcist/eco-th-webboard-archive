Job Level ที่ต้องการ : 5
ชื่อ Skill : Gathering (Surround Plant Tree) "เก็บเกี่ยวผลผลิต"
ลักษณะ Skill : Active
SP ที่ใช้ : 0
ความสามารถ : มีผลเฉพาะ Farmer ที่มี Skill "Cultivation" เท่านั้น โดยจะทำการปลูกต้นไม้ 8 ต้น รอบ ๆ ตัวเอง โดยจำเป็นต้องมีเมล็ดพืชชนิดนั้น ๆ 8 เมล็ดด้วย
เป้าหมาย : พื้นที่รอบ ๆ ตนเองระยะ 3*3 ช่อง
ระยะ Skill : -
** รายละเอียด Skill : ทำการปลูกต้นไม้ 8 ต้นรอบ ๆ ตนเอง จะเป็นต้องมี Skill "Cultivation" ของ Farmer และ Item พิเศษ
- ใช้เพียงเมล็ดพืช 8 เมล็ดเท่านั้น (ไม่มีการกิน MP หรือ SP) <<< ยอดมาก~!!!!!
- จุดที่ทำการปลูกคือ 8 ช่องรอบตัวเรา
- ต้องมีเมล็ดพืชแบบเดียวกัน 8 เมล็ด หากมีน้อยกว่านี้จะไม่สามารถใช้ Skill ได้
