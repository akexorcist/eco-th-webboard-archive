มันก็เก่งกันคนละแบบอ่ะค่ะเราว่า ตอนเราเลเวลประมาณ 30 - 45 เราบ่นๆ กะเพื่อนเราที่เล่น warlock ว่า shaman นี่มันอาชีพลุกเมียน้อยของ spell user รึเปล่าเพราะว่า เวลาเจอมอนต้องคอยเลือกธาตุยิง แถมเบากว่า + ติดดีเลย์มากกว่า + ร่ายนานกว่าเวทของ warlock แต่พอตอนที่ warlock กับ shaman ใช้เวทของจ็อบ 40 ยิงเหมือนกัน เราว่ามันก็ไม่ต่างกันเท่าไหร่นะคะ เวทย์ shaman ยิงแรงกว่านิดหน่อย (จากที่เทียบกะเพื่อนคนเดิมมานะ แบบเลเวลเท่ากัน mag + dex เท่ากัน แต่ matk กับ cast speed อาจไม่เท่ากันเน้อ ตาม bonus) แล้วเวลาเจอมอนพวก undead เพื่อนเรายิงไม่เข้าเลย เวทย์ชาแมนยิงแรงกว่า แต่ว่าชาแมนเสียเปรียบตรงที่เวลาเจอมอนร่ายธาตุมืดใส่ แทบจะลงไปนอนกับพื้น แต่ warlock มีเสกโล่มืดให้ตัวเอง ทำให้โดนเวทของมอนเบาลง แล้วเวทของ warlock มีความหลากหลายกว่าของชาแมนเยอะ เพราะเวทชาแมนมันจะเน้นไปทางเวทซ้ำๆ แต่เปลี่ยนธาตุ ส่วนตัวเราเลือกเล่น shaman เพราะว่า... ชุดมันน่ารักดี -0-
