แนะนำว่า ไปอ่านตามลิงค์ครับ จะได้ข้อมุลครบจาก ผู้เชี่ยวชาญ

แต่ถ้าหาไม่เจอ จะย่อๆให้ (จากผู้เล่น lv20 หุหุ)

1.อาวุธ ขึ้นอยู่กับสกิลที่อัพครับ (เฉพาะสายตีเอง)
ถ้าอัพ ax mastery ก็ใช้ขวาน ถ้าอัพ mace mastery ก็ใช้กระบอง
แต่ถ้าสายสร้างของ(ดูดเอา)ซึ่งไม่ได้อัพmastery ก็อะไรก็ได้
(แต่ถ้าให้ชัวร์ เล่นขวานแล้วอัพax mastery ดีกว่า คลาส2 มีสกิลช่วยเยอะ)

2.อัพ plant+tree knowledge ก่อนเพื่อล่า googo seed (เควสรวบรวมlv.14)
ปรุงอาหาร เออ แนะนำ item refine ดีกว่า
แล้วเก็บพอยน์ไปตัดเย็บ แล้วก็ ปรุงอาหาร (ซึ่งถ้าไม่อัพ mastery จะอัพปรุงก่อนก็ได้)

3.-5. ผมเลเวลไม่มากแฮะ วิเคราะห์ไม่ถูก อ่านในกระทู้หลักดีกว่านะ
http://board.onenet.co.th/viewtopic.php?t=13197
แต่สำหรับผม ผมยังไม่อัพซักกะอย่าง แล้วก็เล่น dex20 ที่เหลือstr ไปเรื่อยๆ
(มี ax mastery + ax hit ก็ตีได้สบายๆ)

ยังไงก็อ่านกระทู้หลักอีกทีนะครับ ผมมันแค่20
