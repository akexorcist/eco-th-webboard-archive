คือผมหาของไปตามที่มันบอกแล้วอะ
ก็มี
Beef Bread(ซาลาเปาเนื้อ)
ฺBoiled Egg(ไข่ต้ม)ล
Dry Apple(แอ๊บเปิ้ลตากแห้ง)
Rotten Mushroom(เห็ดสีม่วงๆ)
ลองเดินไปคุยแล้วมันเหมือนเดิมอะต้องเข้าทางไหนหรอคับ
ผมลงดันปลาชั้นสุดท้ายตรงป้ายไปคุยแล้วมันไม่เห็นมีไรเลยอะ
ต้องมีเงี่อนไขอะไรรึเปล่าอะคับบอกที
