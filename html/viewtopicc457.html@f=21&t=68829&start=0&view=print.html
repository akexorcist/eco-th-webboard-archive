"แถวนี้หรอคะท่านพี่?"
"อืม แถวนี้ละ กลิ่นของวิญญาณอันโสมม"
"เท่านี้ก็ดวงที่ เก้าร้อยเก้าสิบเก้าแล้วสินะคะ"
"ยังเหลืออีกมากนัก น้องพี่จนกว่าจะครบ เก้าพันเก้าร้อยเก้าสิบเก้าดวง"
"เมื่อครบพวกเราจะได้ไปสู่สถานที่ที่ท่านพ่อท่านแม่อยู่ใช่มั้ยคะ?"
"อื้ม ฉะนั้นตอนนี้เป็นเด็กดีแล้วช่วยกันรวบรวมวิญญาณเถอะนะ"
"ค่ะท่านพี่"
เสียงสองเสียงดังก้องในความมืด ท่ามกลางหมู่เมฆสีดำทมิฬของรัตติกาล
เบื้องล่างเป็นสถานที่อันเป็นแหล่งอาศัยของเหล่านักท่องราตรี แหล่งซ่องสุมของสิ่งของอันดำมืด
ดวงตาสีแดงสองคู่จ้องมองสู่เบื้องล่าง อาคารไม้เตี้ยๆแปะป้ายไว้ว่า
'Red Moon Pub'
"จะเข้าไปยังไงดีคะท่านพี่"ร่างเล็กๆในผ้าคลุมสีดำเรียบๆเอ่ย
"หลังร้าน"คำสั้นๆง่ายๆออกจากปากของร่างในผ้าคลุมสีดำสนิทอีกผืน แล้วทั้งคู่ก็ดิ่งลงสู่เบื้องล่าง
โดยมีจุดหมายคือในร้าน Red Moon Pub นั่นเอง
