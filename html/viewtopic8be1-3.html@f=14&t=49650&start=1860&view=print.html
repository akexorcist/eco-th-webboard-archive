ค่าคริของคนผมว่าไม่น่าจะถึง10%นะครับ

เพราะผมฟันไปเกิน10ทีไปพอควรถึงจะติดคริซักที(ดาบมือเดียว)

มันไม่ได้บอกว่า+เป็น%

ส่วนของสัตว์ค่าคริยิ่งเยอะมันแค่เพิ่มโอกาสการติดคริไม่ได้เพิ่มความแรงนะครับ

เท่าที่ผมฝึกมาความแรงยังขึ้นอยู่กับค่า Phys Atk อย่างเดียวนะครับ

ถ้าจะขึ้นอยู่กับค่าใดค่าหนึ่งคงจะเป็น Dex เพราะเวลาค่าคริของสัตว์เต็มแล้วเอาไปล้มจะได้ค่า Dex เพิ่มขึ้น

แต่ก็ไม่มีใครยืนยันว่าลง Dex ไปเยอะๆแล้วโอกาสคริมันจะเพิ่มขึ้น
