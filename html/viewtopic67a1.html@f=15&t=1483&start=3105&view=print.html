สกิวSorceror บัฟ
-DY DEF +19/+20 MDEF +35/+20
ระยะเวลาคงอยู่ 125วิ
(ส่วนสกิวบาเรีย จะได้DEF MDEF ที่ +9/+15 & +35/+15

สกิวEnchanter บัฟ
-Earth Aura DEF +30/+40
-Water Aura MDEF +30/+40
แต่ข้อเสียคืออยู่เพียง30วิ แล้วก็เป็นบัฟรายตัว (แต่ถ้านั่งในรถถัง มันคุ้มค่ามาก กับการ ขับไปแหกด่าน 30วิ เป็นอะไรที่มากโขแล้ว)

สรุปว่า ถ้าได้บัฟ DY+Aura ในระยะเวลา 30วิ ที่ออร่าแสดงผล
DEF +30/+40
MDEF +35/+40
MDEF น่าจะถึง100 แต่ DEF อาจจะเฉียดมาก ยกเว้นคนได้รับ บัฟ เป็นไนท
หลังจากนั้น ก็จะเหลือแค่ผลของ DY แต่ถ้าเจอ Block + ปลด ก็ตัวใครตัวมัน อ่อ ลืมโดนทุบด้วย
