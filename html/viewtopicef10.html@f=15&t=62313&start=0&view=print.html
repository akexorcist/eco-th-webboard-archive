สายสแต๊งคาบามีสกิลให้เล่นเยอะกวาครับหลายๆสกิลสายบู๊ประยุกใช้ได้ดีเลย โบนัสก้บวกสเต๊งกะเด้กมากกว่าเนโครที่สำคัญพลังชีวิตจะเยอะกว่าสกิลสำคัญๆที่เอาไป ท่าูดุดเอ็มพี เมดูซ่าสกิ มารคก้ได้ครับเอาไว้ล๊อกมอนใช้ง่ายร่ายไว ท่าอัลตร้าอีโก้อีกท่ากันมอนรุม อีกท่าก้กริมล่ะครับ อาจะดูเยอะครับแล้วแต่ว่าจะรีบไปรึป่าวถ้าไม่รีนเก็บจ๊อบคาบาไปก่อนถ้ารักการสาปก้อัลเรทกะอบราชั่นติดไปครับ
เชียให้เล่นจนห้าสิบครับถ้าทนไหวแล้วค่อยไปถือโอกาศลองใช้สกิลต่างๆไปด้วยครับ ท่าดุดเลือดของเนโครยังไมได้กดยาแทนก้ได้ครับอีกอย่างจะได้ขนสกิลไปเล่นเยอะเผื่อติดใจจะอยุ่เนโครขึ้นมาจะได้ไม่ต้องเสียดาย
ส่วนเนโครโบนั้สเน้นไปที่เอจีไอกะแมกได้อิ้นเยอะกว่าคาบาด้วยสกิลเนโครที่เอากลับคาบาสำหรับสายบู๊ก็ท่าดูดเลือ ฟอลโลอัพ ท่าตายแล้วฝื้น ดา๊คใลท์ครับช่วยลดความแม่นมอน ท่าเรียกก็อดจ็อบ44ครับ ส่วยจะเล่นอะไรก่อนดีผมว่าคาบาน่าจะดีกว่าเพราะสกิลช่วยเล่นเยอะสายบู๊ล้วนๆเล่นง่ายกว่าครับ
ก็ลองไปเลือกใช้เลือเล่นเอาเองละกันแนะให้ไว้เยอะๆแต่ละคนสเต็ปไม่เหมือนกันจะให้ดีต้องลองเองครับท่าที่คนอื่นไม่ใช้คุนอาจจะใช้แล้วดีก็ได้ ผิดพลาดไรก้ขอโทษไว้ด้วยครับผมเล่นแม๊กสแต๊งไม่ได้บู๊ล้วน
