คริคริ

int ผมแนะนำว่าไม่ต้องอัพ เพราะ สาปติดไม่ติดมัน "ดวง" ครับ แต่ถ้าจะเอา Mdef ก็โอเค แต่มันจะไปเบียดบังค่า stat หลักพวกข้างต้นด้วยน่ะครับ เลยยิ่งน้อยไปใหญ่


อันนี้เห็นด้วยงับ เพราะไม่เล่น int ก้อได้นี่หว่า
เลยทำให้ผมได้ข้อสรุปอ่ะนะ แหะๆ

เวทย์ที่เราเล่นเราเน้น สายสนับสนุนดีก่านะ
เด่วจะบอกว่าใช้อะไรบ้าง


พอเป็นซอเซอเรอร์ ก็จะสบายหน่อยที่ โซลิด แต่มันก็จำกัดเราให้ตีแต่มอนโจมตีกายภาพเท่านั้น หากเป็นมอนใช้เวท (อย่างงูดำ ที่หอแสงที่เรามักไปเก็บบ่อยๆ) ล่ะก็ ก็ต้องเป็นมอนที่ไม่ใช้เวทล๊อกตัว + ต้องอาศัยความไวในการหักหลบเวทลงพื้น ถ้าเจอมอนเวทล๊อก ถึงคุณจะมี shield อยู่ แต่ผมบอกเลยว่า มันไม่ได้ช่วยอะไรเท่าไหร่เลยครับ เพราะต่อให้มี คุณก็ยังโดนทีละ 150- 200 อยู่ดี


ที่พูดมาตั้งแต่ตั้งกระทู้นี้เนี้ย ตั้งใจจะลองด้วยน่ะนะ...อิอิ

1.สกิลสายสาป แน่นอนต้องมีไว้แม้ไม่อัพ int
2.โซลิด+รีเฟลก+divine barrier
3.สกิลweaken+noise ไว้ป่วน
4.overwork ต้องอัพ

Mag ~ ไว้เล่นสายเวทย์ค่อยคุยกัน
