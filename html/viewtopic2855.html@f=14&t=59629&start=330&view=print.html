++ ตัว Setup ประกอบด้วย ++
1. Garana สำหรับทำเกมส์ Lan ให้ Online ทั่วโลก
2. Warcraft III+DotA 6.57b พิมพ์ไทยได้

++ กล่าวนำนิดนึง ++
ปกติถ้าจะเล่น Dota จะเล่นได้ 2 แบบคือเ่ล่นผ่าน Lan ในร้านเกมส์ หรือเล่นผ่าน Internet โดยใช้ Battle Net ซึ่งต้องตั้งค่าหา Server ของ Thaicybergame ในการเล่นผ่าน BN ต้องมาตั้งค่าให้ Router เปิด Forward Port ซึ่งบางคนก็ทำได้ บางคนก็ทำไม่ได้ ถ้าทำไม่ได้ ก็เล่นผ่านเน็ตไม่ได้ เป็นปัญหาอย่างแรง Router บางรุ่นก็ไม่รองรับการ FW Port ต้องหาเปลี่ยนกันวุ่นวาย

ขณะเล่นผ่าน Internet ก็พบปัญหาอืด และไม่สามารถ Chat กันด้วยภาษาไทยได้ต้องพิมพ์ ภาษา คาราโอเกะ บอกตรง ๆ ผมอ่านไม่ออกเลย 55+ ชุดโปรแกรมชุดนี้ จะแก้ปัญหาเหล่านี้ให้หมดสิ้น ส่วนการติดตั้ง ง่าย มาก ๆ ดับเบิ้ลคลิกอย่างเดียวเลยครับ ไม่ต้องทำอะไรเลย

++ ข้อดีของโปรแกรม Garena ++
1. Create VLAN ผ่าน Tunnel ไม่ Lag เหมือน Hamashi
2. มีเกมส์ให้เลือกมากมาย นอกจาก DOTA ยังมี RA3 และอื่น ๆ
3. มีระบบ Level ของ ID ที่ใช้เล่น
4. รองรับภาษาไทย
5. อัฟเกรดอัตโนมัต เหมือนการโหลดแพท
6. สามารถพูดคุยกันใน Room ได้
7. เพิ่มเพื่อนได้ คล้าย ๆ กับเล่น QQ หรือ Camfrog
8. อื่่น ๆ อีกมากมาย

++ ขั้นตอนการเข้าเล่น ++
1. ติดตั้งเสร็จเปิดโปรแกรม Garena ตามรูป



2. ก่อนอื่นต้องลงทะเบียนสมัครสมาชิกก่อน โดยคลิกที่ปุ่ม Register



3. กรอกรายละเอียดให้ครบถ้วน เหมือนสมัคร ID เกมส์ทั่ว ๆ ไป ID นี้ใช้เล่นเกมส์ได้ทุกเกมส์ที่มีใน Garena



4. เมื่อสมัครเสร็จแล้วให้มาเข้าก็ login ตามปกติ




5. เมื่อเข้ามาก็เลือกเกมส์ เลือกห้องตามรูปเลย



6. เมื่อเข้ามาใน Room แล้วก็จะมองเห็นเพื่อน ๆ พูดคุยกันได้ที่นี่ และก็เข้าเกมส์ได้ที่นี่



7. ยกตัวอย่างที่Dot Aเมื่อเข้าเกมส์มาแล้ว ก็ปรับ กราฟฟิก ก่อนเลย เพราะผมไม่ได้ Fix ค่าไว้ ส่วนอย่างอื่น ไม่ต้องปรับ ถ้าจะเล่นเกมส์ก็ให้เข้าเล่นที่ Network เหมือนเล่นผ่าน LAN



8. ขั้นตอนนี้ทุกคนคงจะคุ้นเคยนะครับ ไม่กล่าวแระ



9. เป็นไงครับพิมพ์ไทยได้ด้วย
