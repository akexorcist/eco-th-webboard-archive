โดย ECO » พุธ 02 ก.พ. 2011 8:36 pm

กว่าจะหาเจอ

ต้องยอมรับว่ากระทู้เก่ามาก - -
(หรือไม่ก็มนหาไม่เป็นเอง)

1.เควส ลดราคาเข้า Light Tower

1.1เริ่ม Event ไปคุยกับ Jiggy Writer ที่อยู่ ในบ้านด้านซ้าย ของ ทิศเหนือ เมืองม็อค เขาจะวานให้ไปหา NPC ที่อยู่ บ้านข้างๆ

1.2 ให้ย้ายสังขารไปอีกบ้านนึง จะเจอ NPC แต่งตัว แบบ แอส คุยกับเทอ เทอ จะ บอกให้ไปหา แอสอีกคนที่อยู่ใน โรงถลุงของ Diamant

1.3 เดินไปตงกลางๆ เมืองอะครับ หาๆ เอา ก็จะเจอ ห้อง ที่มี Black Market Merchant กะ คนขายของ ข้างๆ จะ มี NPC แอส อีกคน ให้ไปคุย เขา จะ ให้ไปหา หลักถาน มา

1.4 ก็จงยอมเสียตังอีกครั้ง บินไป Light Tower ขึ้นชั้น A หรือ B ก็ได้ ไปชั้น 8 ออกมาตงระเบียงทางเชื่อม จะ เจอ NPC ชื่อ Doubtful Man คุยกะเขา

1.5 เขาจะบอกหลักถาน อะ หายไปแล้ว (ถึงตรงนี้ หลายคน หา ไมเจอ ละ สิ อิอิ)

1.6 เดินกลับไปชั้นล่างสุด ออกมาตงที่ มี พลาตินั่ม เยอะๆ อ่ะคับ เดินไปตรง ซากปรักหักพัง (บริเวท สีทา ของแผนที่ ที่ ร่ม เกิดบ่อยๆ อ่ะ) ให้เดินไปตรง ขอบๆ ซากสะพานเลย

1.7 จะเกิด อีเว้นได้ ไอเท็มมา ! ซึ่งก็คือ หลักถาน นั่น เอง !

1.8 ให้เผ่นกลับไปหา Juggy Writer เขาจะให้เงินตอบแทน 5k ทีนี้ เราจะ สามาด ซื้อ ตั๋วในราคา ครึ่งนึง ของ ปกติ + เปิดร้านขายของเวล 80 (ชุด เห่ย มาก)

พ่อค้าผม 60/28 ไปทีแรก ได้ proof file มาแล้ว ไม่อยากเดินกลับ ขึ้นไปทีละชั้นๆ จนถึงชั้นดาดฟ้า ก็เลยสิงเพื่อนกลับ Uptown เพือนก็ใช้บ้านบิน มาเกาะวอร์ชิพ แล้วก็มอร์ก(ผมสิงอยู่ข้างในเพือน) ออกสิงมาคุยกับ Jiggy แต่เขาเงียบกริบ ลองดูช่องไอเท็ม แล้ว proof file หายไป ไม่รู้ว่าหายไปตอนไหน เลยจำใจกลับไปทำใหม่ คราวนี้ ไม่วาร์ปลัดหนี เพราะ ป๊อดๆ ละ ลงไปเก็บ แล้วก็ ฝืนเดินฝ่าดง นรก ขึ้นไปชั้นดาดฟ้า กดคุยกับ npc คุมบ้านบิน มาส่งมอร์ก กดคุยกับ Jiggy ทั้งๆที่มี proof file อยู่ในช่อง ไอเท็ม เห็นๆ ก็เป็นอันสำเร็จ

ทีแรก หลังจากทีี่ jiggy เงียบกริบ ผมลอง ไปหอแสง ทำการเข้าวาร์ป ให้เควสมันรู้ว่า เราเข้าวาร์ปไหนมั่ง โดยการ ลงไปชั้น Main Floor 4F แ้ล้วกลับดาดฟ้า คุย npc บ้านบินกลับมอร์ก มาคุยกับ Jiggy ก็ยังเงียบอยู่ ผมก็เลยสงสัย ว่า ถ้าจะลัดวาร์ปกลับเลย นี่ หลังจากเก็บ proof file แมพข้างนอกหอแสง แล้ว จำเป็นต้องเข้าไปแมพ Main Floor 1F ที่เราออกมารึเปล่า กับ Main Floor 4F ที่ลงมาจากชั้นดาดฟ้า แต่ถ้ามันตรวจว่า ต้องเข้าวาร์ปจากแมพชั้นล่าง ขึ้นมาเรื่อยๆ ทุกแมพ ก็หนี มะได้ละ เหอๆ
