===============================
True internet and MobileFree.jp
===============================

สำหรับคนที่ใช้เน็ตทรูกับ MobileFree.jp แล้วเข้าเล่นได้เฉพาะช่วงดึกๆ
ทรูมีกั๊ก proxy ไว้ตัวนึงครับ ตัวนี้ทำให้ต่อไป MobileFree.jp ได้ลื่นๆเลย

proxy.trueinternet.co.th

วิธีใช้ก็
1. เปิดหน้าโปรแกรม Packetnix ขึ้นมา ให้คลิ๊กขวา ที่ MobileFree.jp เลือก properties แล้ว
2. ตั้ง HTTP proxy ใส่
Hostname : proxy.trueinternet.co.th
Port : 8080

* เวลาโหลดแพชช่วยปิด VPN กันก่อนนะครับ เพื่อความเร็วและประหยัด bandwidth ของ VPN *
======================================================
ทำให้หน้า login กับเกม eco วิ่งผ่าน vpn อย่างอื่นวิ่งผ่านเน็ตปกติ
======================================================
* จำค่าเดิมไว้ด้วยนะ ถ้ามีปัญหาให้ตั้งกลับเป็นเหมือนเดิม
* ถ้าเซ็ต route แล้วพังแก้ไม่ถูก ให้ใช้คำสั้ง route -f แล้ว restart มันจะลบ route ทั้งหมดที่เคยตั้ง
* ทุกคนควรทำ เวลาเปิดเว็บจะได้ไวและเป็นการลดภาระ bandwidth VPN *
* ip ในตัวอย่างข้างล่างนี้ คือในกรณีของ MobileFree.jp
* ถ้าเป็น admin เครื่องและปิด UAC ด้วยจะทำง่ายขั้น

ที่ทำนี่คือทำให้หน้า login กับเกม eco วิ่งผ่าน vpn อย่างอื่นวิ่งผ่านเน็ตปกติ (เว็บ ยูทูป บิท หนังโป๊ ฯลฯ)
ถ้า vpn ip เหมือนกันก็ไม่น่ามีปัญหา (ซึ่งมันควรจะเป็นแบบนี้)

[ขั้นตอนที่ 1 เปลี่ยนให้เน็ตทั้งหมดวิ่งผ่านเน็ตปกติ]

=== Win 7 === (xp ไปดูอันล่าง)
1.
control panel > network and sharing center > change adaptor setting >
คลิ๊กขวาที่ vpn > prop > internet protocal v4 (ถ้า v6 ติ๊กอยู่ ติ๊กออก) ดับเบิลคลิ๊ก v4
> advance > Interface metrice ตั้งเป็น 60 (หรืออะไรก็ได้ที่มากกว่าอันเน็ตปกติ) ถ้ามี Use default gateway on remote network ให้ติ๊กออกด้วย

2.
control panel > network and sharing center > change adaptor setting >
ปกติใช้เน็ตจากตัวไหนก็คลิ๊กขวาอันนั้น > prop > internet protocal v4 (ถ้า v6 ติ๊กอยู่ ติ๊กออก) ดับเบิลคลิ๊ก v4 > advance > Interface metrice ตั้งเป็น 30 (หรืออะไรก็ได้ที่น้อยกว่า vpn)


=== Win XP ===
ไม่ได้ใช้ xp ไม่รู้ แต่ลองทำตามหน้านี้
http://codifying.wordpress.com/2011/01/ ... n-gateway/
สำคัญคือ ต้องติ๊ก Use default gateway on remote network ของ vpn ออก

อธิบาย
> metric เหมือนกับค่าระยะทาง โดยปกติแล้วเน็ตจะวิ่งไปในทางที่มีค่า metric ต่ำสุดก่อน ตามตาราง route

[ขั้นตอนที่ 2 ทำให้หน้า login กับเกม eco วิ่งผ่าน vpn]
ตอนนี้เน็ตทั้งหมดจะวิ่งผ่านเน็ตปกติแทน
ต่อไปคือทำให้ login กับเกม eco วิ่งผ่าน vpn โดนการเซ็ต route ใหม่

start > run > cmd
แล้วพิมพ์ 2 บรรทัดนี้ลงไป (ใช้"เมาส์"คลิ๊กขวา copy paste ได้)

route -p add 211.13.228.0 mask 255.255.255.0 2.0.0.254

(แล้ว enter ถ้าถูก มันจะขึ้น ok)

route -p add 61.215.212.0 mask 255.255.255.0 2.0.0.254

(แล้ว enter ถ้าถูก มันจะขึ้น ok)

อธิบาย
> 211.13.228.02 และ 61.215.212.0 คือ range ของ ip เว็บ gungho (สำหรับ login) กับ เซิฟ eco ทุกเซิฟ (มีทั้งหมดเกือบ 10 เครื่องต่อ 1 เซิฟเกมได้)
> ถ้าใช้ VPN ตัวอื่น ให้เปลี่ยนจาก 2.0.0.254 เป็น gateway ip ของ VPN นั้นๆ
> route -p หมายถึงการตั้งเส้นทางเดินใหม่แบบคงทน (Persistent) ถึงจะ reboot เครื่องมันก็ยังอยู่ หากอยากตั้งแบบชั่วคราวก็เอา -p ออก
> ถ้าจะลบเส้นทางทิ้งก็ใช้คำสั้ง route delete ตามด้วย ip ที่จะลบ
> จะเช็คว่าตอนนี้เส้นทางเป็นอย่างไรบ้างใช้คำสั้ง route print
> อ่านวิธีหารใช้ route เพิ่มเติม

***คำเตือน - การเชื่อมต่อผ่านเครือข่าย VPN นั้นมีความเสี่ยง เพราะข้อมูลที่เชื่อมต่อจะถูกดัก จัดเก็บไว้ที่เครื่องเซิฟเวอร์ ถ้าไม่ใช่เซิฟเวอร์หรือผู้ให้บริการที่น่าเชื่อถือ อาจถูกโจรกรรมดักข้อมูลไปได้ อาทิ พาสเวิร์ดอีเมล์ log in account ต่างๆ

แต่เดิมเมื่อก่อน VPN จะถูกใช้เพื่อการใช้เชื่อมต่อระหว่าง บ้าน-บริษัทสำนักงาน เสียส่วนใหญ่
