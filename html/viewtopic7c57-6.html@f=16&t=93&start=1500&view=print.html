แนวทางอัพสกิล ที่ลองวางไว้คร่าวๆ
ช่วง lv 1-28 เรากะจะเล่นสายดูดตลอดน่ะ ไว้มี banish blow แล้วค่อยลุยเอง ^ ^
สกิลที่อัพตอน job 29(เรากะจะเริ่ม start จากจุดนี้ ก่อนหน้านี้ก็ดูดไป)
ที่จุดนี้คาดว่าเราจะมี skill point รวม 43 point โดย point จาก lv มี 34 +เควสอีก 9
โดยเควสง่ายมี 7 เควส จากทิศเหนือ 2 ทิศใต้ 2 ทิศตะวันออก 3
ส่วนอีก 2 เควสก็คือขนส่งเอกสารกับส่งก่อนจะละลาย ซึ่งเหนื่อยหน่อยแต่ก็ทำได้ง่าย
ore know ledge(3)
mace mastery(7)
increase mace hit(7)
สกัดแร่(5)
increase max sp(7)
increase max hp(7)
banish blow(7)
รวม 43 point พอดี
จากนั้นก็ต่อด้วย
increase sp recovery(7)
ที่เหลือลง
camp(เท่าที่ point เหลือ)
แล้วก็เผื่อ point ไว้อัพ
DOGEZA(7)
เล่น job50 แน่นอน

เวลาเก็บเลเวลก็ banish รัว

status ที่ lv29
str 27+4
dex 27+3
int 6+1
vit 4+5
agi 30+4
mag 10+0

จากนั้นก็ agi รัวๆ

จริงๆเรื่อง status ได้วางไว้คร่าวๆตั้งแต่ตอนได้ทดสอบใน close แล้ว แต่ตอนนั้นไม่ได้กะว่าจะกลับมาเล่นอีก
