โดย ECO
ตอบ บางข้อนะคะ เพราะบางข้อนู๋ ก็มะรู้
1.หูแมวของ เวลไหนก็ได้ หาได้จากไหนเหยอ (กล่องเจ้าค่ะ กล่อง6มะแน่นะ แต่กล่อง9นี่แน่ใจมีคนได้มาแล้ว)
2.คทา คุนปู่ พังแล้วจะได้อารายเหยอ (รองเท้าเลเวล55ค่ะ)
3.เป็นปายได้ไหม ที่จะแช่แข็ง มอนสเตอ ระดับ บอส กะ มอนธาตุมืด (บอสมะรู้ แต่ธาตุมืดแช่ได้ค่ะ)
4.High Immortal Dominian มีเวทไหนที่ยิงเข้าบ้างอ่ะ (มันเข้าเกือบทุกเวทแหละค่ะ แต่มันอยู่ในดันใต้ชั้น2กับ3แนนนำเวท ลมนะคะจะแรงกว่าเวทอื่น ยิงที่ตรงแถวๆสะพานไฟดอกละ1000+เรายิงนะ4ทีก่ะตายและ)
5.Enchanted Spell Caster นี่มันยิงเวทอไร ได้บ้างทีเดียว ลดเกิน 500ป่าวงิๆ (มะรู้ค่ะ)
6.มีชุดของ อาริ เวล 50-55 ที่ใสแล้ว ไม่เหมือน ขอทานบ้างป่าวเอ่ย (เอเลเมนท์ทาเลอร์น่ะเหรอคะ เรียกอาริเราเลยงง ของผู้ชายหรือหญิงล่ะ ถ้าหญิงสวยทุกชุดเลย ผู้ชายคงต้องชุด75แล้วล่ะค่ะถึงเท่)
