เสร็จล่ะ หึหึ

===========================================

หลังจากที่ อัสเทียร์ ตอบกลับควอเร่ ไม่ทันไรควอเร่ก็คว้ามือของอัสเทียร์ แล้วดึงไปอีกฟากของล๊อบบี้

แล้วควอเร่ก็ปล่อยมือของอัสเทียร์

ในความคิดของควอเร่ว่า "(ผู้จัดการบอกให้เราขอโทษเธอก่อน สินะ เริ่มจากไหนก่อนดี)"

(เอาล่ะ) "ขอโทษ" คำพูดนี้หลุดออกมาจากปากของควอเร่ พร้อมกับการที่ควอเร่ โน้มตัวไปด้านหน้า แต่ทว่าศีรษะของ ควอเร่ก็ดันไปชนเข้ากับหน้าผากของ อัสเทียร์ "โป๊ก"

"อุ๊ปสงสัยจะผิดขั้น" "ใหม่ละกัน" ควอเร่ บ่น

จากนั้นควอเร่ก็ยื่นหน้าไปใกล้ๆ กับหน้าของ อัสเทียร์ ในขณะที่เลือดไหลลงมาที่ใบหน้าของเค้า

"โผมมม ขอออออ โทษษษ"
