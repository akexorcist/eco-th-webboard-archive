ถามสกิล
1. Vacuum โจมตีด้วยการฟาดคลื่นพลัง อันนี้ใครลองใช้แล้วมั่งดีมั้ยคับ
2. Bersek เพิ่มความเสียหายตามที่กำหนดและจะกลายเป็น Bersek เป็นไงคับ Bersek นี่ งง อย่างแรง
3. Bersek control จะควบคุมผู้เล่นได้ขึ้นอยู่กับ Lv. กับ int อันนี้กะ งง อย่างแรงเหมือนกัน แต่เบลดอย่างเรากะไม่เคยอัพ int ด้วยอ่ะจิ

ช่วยอธิบายวิธีใช้ให้หน่อยนะคับ หรือมีสกิลอะไรแนะนำ บอกหน่อยนะคับ (ตอนนี้มะอยากลองเองอ่ะคับ เพราะรีสกิลมานต้องซื้อบัตรแล้วอ่ะคับ นี่กะเพิ่งเสียตังรีสเตตัสไปนะเนี่ยะ ดันไปลองรีเปงสาย Agi แระไม่เวิร์คเลยต้องรีกลับเปงสาย vit Evil or Very Mad )

1.เป็นสกิลโจมตีระยะไกล (ประมาณ3-5ช่อง ขึ้นอยู่กับอาวุธ) ไร้ธาตุ แบบกายภาพ อาศัยL.hitในการคำนวนควาแม่นยำ พลังโจมตีต่ำ-ต่ำมาก - -* ยังไม่เห็นประโยชน์ของมันครับ รอสกิลพุ่งของBH ยังดีกว่า (เปลืองพ้อย ฟันธง ^^)

2.ที่เลเวล5ของสกิลberserk หากHP เหลือต่ำกว่า30% จะเข้าสู่สถานะ "บ้าคลั่ง" (ตั้งเอง ^^) ส่งผลให้ค่าATK ทั้งminและmaxของตัวละคร x2 ขณะติดเบอร์เซิกจะมี2ลักษณะคือควบคุมได้กับควบคุมไม่ได้ ซึ่งการที่จะให้ควบคุมได้จำเป็นต้องอาศัยสกิล berserk control ยิ่งเลเวลสกิลสูง+ค่าintตัวละคร โอกาสคุมได้ก็จะยิ่งเพิ่มขึ้น หากตัวละครไม่สามารถควบคุมได้ จะคล้ายกับอยู่สภาวะ "สับสน"(ATKx2เหมือนกัน) แต่จะไม่สามารถคลิกเดินหรือคลิกฟันได้ มันจะวิ่งเข้าไปหามอนเตอร์ที่อยู่ใกล้ๆ หรือใช้สกิลที่เรามีอยู่ขึ้นมาเอง หากไม่มีมอนเตอร์อยู่ในบริเวณสายมักจะเกิดอาการ "อื้อ" ประมาณจะไม่รู้จะทำอะไร ถ้าเป็นเช่นนี้จะหลุดออกจากสถานะเบอร์เซิกอย่างรวดเร็ว(ประมาณ10วินาที) แต่หากมีมอนเตอร์อยู่ในบริเวณสายตาก็จะเข้าไปโจมตีเองทันที (บางทีมันวิ่งเข้าไปกลางวงมอนแล้วตีตัวละไม่กี่hitทำให้ไม่ตาย เราก็จะโดยมอนเตอร์รุมตายแทน - -*) ลักษณะนี้จะอยู่ประมาณ30วิ [[[ขณะสับสนเรายังสามารถกดยาเพิ่มพลังหรือสกิลที่ต้องการได้ ถ้าเรายังไม่ตายซะก่อนนะครับ Y_Y]]]
***มีสกิลนี้แล้วไปกับพระจะโหดมากสามารถที่จะเลี้ยงระดับHPเพื่อให้อยู่ในสถานะเบอร์เซิกบ่อยๆได้สบาย สรุปก็คือหากคิดจะอัพสกิลนี้แล้วจำเป็นต้องอัพ berserk controlด้วย*** ยาวไปไหมเนี่๊ย

3.ตามนั้นแหละครับที่berserk control lv.5+ int30 โอกาสที่จะควบคุมอยู่ที่50%
