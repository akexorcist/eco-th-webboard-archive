ผมว่ากำลังจะกลับไปเป็นเนโครคืน
เนโคร จ็อบ 50 แล้ว ถ้าผมจะอัพสกิลซัมม่อนโกส(ซัมม่อนเดธ อัพแล้ว 5)อยากซาบว่า
พ้อยน่าจะพอไหมคับ แล้วก็ควรอัพสกิลไรบ้างคับ(ไม่ pvp/nvn)
ที่ผมคิดไว้
1.evil soul
2.summon deat
3.chaos gate
4.dark ligh
5.Necro Resurrection
6.Summon Ghost
แล้วถ้าผมอัพซัมม่อนโกสผมต้องอัพสกิลเสริมไหมคับ(จะใช้ตัวเกราะดำเวล5)
ปล.ผมสายเวทน่ะคับ แต่ไม่อยากเป็นคาบา
