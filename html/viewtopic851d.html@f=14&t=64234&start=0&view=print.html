โพสต์แล้ว: พฤหัสฯ. 07 พ.ค. 2009 8:06 pm
โดย ECO
ขอแบบหลักๆ นะครับ

1. ไม่มีสิง
2. มีสิง
3. hit ที่สามารถทำได้สูงสุด

ปกติ คนส่วนใหญ่จะอัพ str แล้วก็ dex แล้วค่อยลงมา vit กัน (สำหรับวอร์ ) อาจจะมี agi อยู่
บ้าง แต่หลักๆ แล้วคงไม่มีใครบ้ากด dex 100 กัน( มั้ง ไม่แน่ใจ ) ก็เลยอยากรู้ว่าส่วนใหญ่

แบบไม่มีสิง จะได้ hit สูงสุดเท่าไหร่ (อาจจะมีสกิลซัฟก็ได้)

แล้วก็แบบ สิงครบ (พวกสาย dex ช่วยสิงไรงี้) อ่ะครับ

ส่วนข้อ 3 ก็โดยรวมที่ทำได้สูงสุดเลยครับ ตามนี้

ปล. พอดีจะไปคำนวน avoid สำหรับหลบ
