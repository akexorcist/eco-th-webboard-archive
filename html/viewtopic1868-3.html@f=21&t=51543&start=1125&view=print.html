หุหุ ไอ้2คนนั้นไม่ได้มาพักแค่มาหาคาโต้ร่างปีศาจอะนะงิงิ

_____________________________________________________________

ชายคนหนึ่งใน2คนนั้นจับได้ถึงพลังปีศาจแรงกล้า"หือ เจ้าปีศาจนั้น"ชายคนนั้นพูด"เอะเดี๋ยวสิครับอาจารย์"ชายอีกคนรั้งไว้"นายรออยู่นี้ละนะ"พูดเสร็จเข้าก็วิ่งไปทางพลังนั้น


พอไปถึง"เจ้าปีศาจ!!!"ชายคนนั้นตะโกนเสียงดัง"หือ"คาโต้หันไป"อ้อ เจ้าเรียวกะแกอีกแล้วเหรอไม่เข็ดรึไงตั้งหลายรอบแล้วนะเบื่อแล้วที่จะสู้กับแก"คาโต้พูดอย่างเบื่อกนาย
"หนอยแก!!!"เรียวกะกระโดดแล้วชักดาบขนาดใหญ่จากด้านหลังออกมาแล้วตั้งใจจะฟันไปที่ศีรษะของคาโต้ แต่คาโต้ก็รับดาบใหญ่ของเรียวกะได้ด้วยนิ้วเดียวแล้วปัดออกไป"ฮึ"
"หมัดคลื่นปีศาจ"ที่หมัดของคาโต้มีคลื่นพลังสีดำขนาดใหญ่แล้วซัดเข้าไปที่ท้องของเรียวกะ
ทำให้ปรากฎคลื่นทอนาโดขนาดใหญ่สีดำทำให้เรียวกะปลิวออกนอกสวนของหอพักไป
"อ้ากกกกกกกกกกกกกกกกกก"เรียวกะที่กระเด็นไปทำให้เรียวกะดระแทกกับภูเขาที่ไกลออกไป"หึ กระจอกเหมือนเดิมเลยนะนายเนี้ย"คาโต้พูดแล้วเดินกลับเข้าหอไป
