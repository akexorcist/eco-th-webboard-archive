เวล ไม่ค่อยน่ามีปัญหา เรื่องทรงผม เพราะ เกริ่นไว้ว่าสีทอง + ใส่ฮูด ตอนนั้น

ซึ่งก็ คาดเดาได้ 3 แบบ อย่างง่าย

1. เชื้อพ่อมันแรง : ทรงคล้ายๆ กัน ประมาณว่าอยู่ทรง ใส่เจลไว้แข็ง ใส่ฮูดก็ไม่เสียทรง

2. ก็ตรูขี้เกียจ : จากนิสัยดูเป็นพวก รักอิสระ ตามประสา คนที่เกิดในวัง ราวๆ นั้น ทรงเลยเป็น พวก ปล่อย ไม่ได้จัด

3. มาตรฐาน : ผมสั้น หรือ ผมยาวทั่วไป

เป็นถึงเจ้าชาย จะให้ไป ตัดทรงแปลกๆ ก็เสียชาติตระกุลหมด


ชุดนี่ ไม่มีเกริ่นบอก คาดว่าลืม หรือจะเป็น ตัวละคร ใช้แล้วทิ้งก็ไม่ทราบ เลยไม่ใส่รายละเอียดมาก
