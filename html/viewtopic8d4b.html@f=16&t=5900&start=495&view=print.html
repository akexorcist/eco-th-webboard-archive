1.เวลาเปลี่ยนGamblerต้องทำเควสรึสวิชได้เลย

gambler เป็นอาชีพเดียวที่ต้องทำเควสก่อนครับถึงจะสวิตซ์ได้ ซึ่งเควสมีบอกอยู่แล้วที่หน้าเว็บ eco

2.ปกเค้าอัพค่าstatusอะไรบ้าง

เล่นสายอะไรล่ะครับ มันมีหลายสายแล้วแต่คนเล่นนะครับ

3.ปกเค้าอัพสกิล(Gambler)อะไรกันบ้าง

ก็ต้องดูสายอีกล่ะ แต่แน่ๆเลยก็ random heal , สกิลซัมม่อนไพ่(เรียกไพ่มาช่วย),สกิล 50 ห้ามพลาด
