JOB SWITCHING

หรือเปลี่ยนคลาสนั่นเอง ซึ่งเราหลายๆคนก็คงพร้อมที่จะเปลี่ยนแล้วเสียด้วย
ระบบการ switch จ๊อบ เป็นระบบที่สร้างไว้รองรับพวกไม่มีหลักแหล่ง--- เอ้ย พวกที่ต้องการใช้ความสามารถของคลาสสองรูปแบบ มาผสมผสานกัน
แต่ระบบนี้จริงๆแล้วต้องเงินหนาใช้ได้ทีเดียวครับ


ข้อมูลต่อจากนี้เป็นการพยายามนำข้อมูลในหน้าเวปมาอธิบายให้ละเอียดยิ่งขึ้นนะครับ ถ้าเข้าใจแจ่มแจ้งจากหน้าเวปแล้วก็คือๆกันครับ :P

เราจะมาเริ่มกันนะบัดนี้ครับ

"ชั้นของอาชีพ"ต่างๆในอีโค สามารถแบ่งได้เป็นกลุ่มๆดังนี้ครับ
*คลาสเริ่มต้น---Novice อาชีพ(รึป่าว)ที่ทุกคนต้องเคยผ่านมาแล้ว คำอธิบายคงไม่ต้องบอกนะครับ
*คลาสอาชีพพื้นฐาน---Base job มีสิบสองอาชีพ สามสาย ทุกคนก้อผ่านมาแล้วอีกนั่นแหละครับ มีเงื่อนไขการผ่านจากชั้นโนวิทนิดหน่อย โดยการผ่านเควสประจำอาชีพ
และเมื่อ Job level ถึง 30 จะสามารถเลื่อนสู่คลาสที่สูงขึ้นได้ แต่จะกลับมาคลาสนี้ไม่ได้อีกแล้ว
ตัวอย่างอาชีพคลาสนี้ก็เช่น Wizard
*คลาสอาชีพขั้นสูง---High class job เปลี่ยนโดยการทำเควสเปลี่ยนอาชีพจาก base job มา มีสองกลุ่ม คือ
****Expert class อาชีพจ๊อบต่อจาก base โดยตรงนั่นเอง
****Technical class เป็นอาชีพขั้นเดียวกันกะข้อบน สามารถเปลี่ยนได้จาก expert โดยอาศัยเงื่อนไขนิดหน่อย
เพื่อความง่าย นี่คือผังอาชีพต่างๆในเกม ECO ครับผม
