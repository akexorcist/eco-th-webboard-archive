การพังไวพังช้า อยู่ที่ การใช้งานด้วยครับ

อย่างเช่น เป็นเบลด ถ้าเอาไปฟันมอน ที่ชื่อเขียว หรือแดง + ใช้สกิลดีเลย์แคนเซิ่ล

อัตราการลดของความทนทานจะสูงกว่า ตีปกติโขครับ

แล้วก็อยู่ที่ประเภทของมอนด้วยครับ ( เกมนี้มัน RPG มันจะอิงความจริงบางส่วนด้วย )

เช่น....เอาดาบไปตี หนามเหลือง หรือหุ่นในหอแสง

อัตราการลดของความทนทานก็จะสูงกว่า ไปตีพวกมอนประเภทอื่นครับ

2. พวกหุ่น มันเป็นมอนหุ่นยนต์ = เหล็กเดินได้ เอาอาวุธไปสู้กะเหล็ก ทนทานก็ลดฮวบฮาบได้
