แหล่งรวมชาว Eco แห่งใหม่

โพสต์แล้ว: อังคาร 02 ต.ค. 2007 10:04 am
โดย ECO
เปิด ห้อง Camfrog ให้ ขาว Eco ได้เข้ามาคุยและแลกเปลี่ยน ความคิดเห็นเกียวกับ เกมส์

เชิญเข้ามาได้ ที่ห้อง ooOThai_GreeneyesOoo

วิธีการเข้าห้อง ให้ไปโหลด โปรแกรม Camfrog ได้ ที่ http://www.download.com/Camfrog-Video-C ... tag=button แล้ว install กันได้ เลยครับบ

วิธีเซตไมค์สำหรับคนอยากเป็นดีเจครับ
1.ให้ไป ที่ control panel เลือก sounds and audio devices
เลือก advanced
2. กดที่ options เลือก properties เลือก Recording
3. ให้ติ๊กเครื่องไม้ ถูกหน้าช่องดังนี้ microphone wave out mix หรือบ้างคนจะเป็น สเตริโอ มิก พอติ๊ดแลว้ กด ok
4.wave out mix หรือบ้างคนจะเป็น สเตริโอ มิก ให้พยายาม ปรับไม่ให้เกิน 3 ขีด
5. microphone ปรับให้สุด หากยังไม่ดัง ให้ กด ไป ที่ advanced ลองติ๊ด 1.MIC Boost
หรือ Mic2 Select ดูน่ะคับบ
6.เวลาเปิดเพลงก็ สามารถใช้โปรแกรม winamp หรือ ของวินโด จากเวปก็ได้น่ะคับบ
