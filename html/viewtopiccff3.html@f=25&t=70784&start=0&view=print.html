สิ่งที่จำเป็นคือ

1 พระ
2 ตนขี่มังกร(มีอกบรีเด้อสกิว15จะดียิ่งขึ้น)

วิธีการฝึก
1ไปที่ฝึกเพจทางใต้ดังรูป

2เข้าไปเสร็จเดินทางไปชั้น3
3ลากมอนเต้อทุกตัวในแมพตามใจชอบเลย(รังวัง!!ระวังบอสนะ)ดังรูป

4เสร็จแล้วให้พระที่สิงฮิวรัวๆ(ถ้าเลือดตัวนั้นยังน้อยอยู่)

เสร็จละครับขึ้นไวใม้ครับ

พระสิงอกครับแล้วควรเลือด1500+
ไม่ก็ใส่ชุด80ก็ได้ครับ

เพิ่มนิด

ถ้าฝึกกับมอนสเตอร์ที่ตีเราแม่นๆ อย่างผีดิบ จะได้ค่า def ไวมากๆค่ะ
จากที่ได้ฝึกมาพบว่า cri ขึ้นเร็วเหมือนกัน (ใช้สติ๊กยิ่งเยี่ยม)
(THX พี่กีกี้สำหรับคำแนะนำค่ะ)

ไปฝึกกับบอสในแมพโรงเรียนแล้วส่วนมากได้แต่เลือด
ตอนนี้เลยจิ้มตีตามแมพต่างๆ เอา
พอเพ็ตของเราเก่งขึ้น ก็ขยับเลเวลของม่อนขึ้นเรื่อยๆ ค่ะ สนุกดีเหมือนกัน
(เหมาะสำหรับคนมีเวลานั่งดู, กดเปลี่ยนเป้าหมาย แต่ถ้านั่งดูไม่ได้ตลอดก็ไปหาบอสโรงเรียนโล้ด~)

ขอบคุณสำหรับเทคนิกดีๆ ค่า

ถ้าไม่ใช่ Pet ขี่แนะนำที่ Barn ก็เข้าท่าค่ะ (อีกทางเลือกละกัน อิอิ)
จะมีไก่สีน้ำตาลๆ ใช้สกิล 27 ของบรีดเดอร์แล้วก็ค่อยๆสั่งให้ Pet ไปลากไก่มาซัก 8 ตัว
(ลากไก่นี่มันเหมือนตัวอะไรเลยแฮะ - -*) แล้วก็นั่งฮีล Pet ไปเลยค่ะ สลับกับใช้สกิล 27

ข้อดีของไก่พวกนี้คือมันไม่เปลี่ยนเป้าหมาย ไม่ว่าเราจะฮีลเพทยังไงมันก็จะไม่มากัดเราค่ะ
จะได้ค่า Def / HP / M Def เร็วมาก แต่ Pet ต้องถึกระดับนึงด้วยนะคะ (ไม่งั้นเหมือนไปฆ่า pet เล่น)
