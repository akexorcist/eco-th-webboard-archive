รู้สึกว่าจะมีปัญหากันหมดเลย เรื่อง Int กะ vit(ผมด้วย)
Int รวด...ยิงแรง+หนาเวทย์
Vit รวด...เลือดเยอะ +ถึก แต่หนาเวทย์ไม่เท่าInt รวด...
ผมว่าผสมๆทั้ง2ค่าให้ลงตัวดีกว่า
โดยการอัพInt ไม่ต้องไปมองที่ความแรงที่เพิ่ม
แต่มองความคุ้มค่าที่อัพไปแล้วเพิ่มMdefแทน
ผมก็อัพผสมๆอ่ะ โดยรวมไม่ว่ายังไง ติดดิวายปุ๊บก็ถึกทันตาละ- -
