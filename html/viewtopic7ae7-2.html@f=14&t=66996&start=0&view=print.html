ที่ทามมาทั้งหมดสายมีดอย่างเดียวนะครับ
อย่าทราบว่า
1.สเกาสายมีดเล่นแอสหรือคอม
2.ถ้าเล่นแอสหรือคอมช่วยบอกด้วยว่าควรอัพสกิลไรบ้าง
3ตอนเปนสเกายุอ่ะครับอัพสกิลไรบ้าง(สายมีด)และก็อัพสกิลจอบ40ดีไหมที่แรนดอมไรไม่รุ้
4.สกิลจอบ40กะ50อันไหนดีก่ากัน
5อัพสกิลฺblowดีไหม
6.อัพสเตงให้เท่าไรเอจิให้เท่าไรเดกให้เท่าไรและวิทให้เท่าไร
7มีดอ่ะครับเวล50-80ซื้อที่ไหน

ใครพอจะรุ้ขอไรกะตอบมานะงับ
