Connection
ได้เมื่อ - Job Lv33
ประเภทสกิล - Passive
- ทำให้สนิทสนมกับผู้อื่นได้ง่าย
- ไม่ต้องใช้บัตรในการผ่านแดน ยกเว้นที่เกาะเรือรบ
- ชื้อของจากสามพี่น้องในดาวทาวน์ได้
- ลดราคาตีเพิ่มประสิทธิภาพไอเท็มลง 25%
- ลดราคาในการลง วัดไร้ขอบเขตลง 20%
- เมื่อผ่านการทำ Event จาก กอลโด้
- จะสามารถลดราคาชื้อของจากสามพี่น้องลงได้อีก(อันนี้ไม่แน่ใจครับ)

ก๊อปมาจากกระทู้ Trader
ส่วนตัวผมคิดว่าน่าอัพนะ อย่างน้อยก็ช่วยลดค่าใช้จ่ายได้(โดยเฉพาะตีบวก -0-) แถมยังซื้อของจากสามพี่น้องได้อีก(ได้ข่าวว่า 3 คนนี้ขายพวกปืน ระเบิด อะไรเทือกนี้แหละ)
