Skill Type : Passive Skill
JOB LV. ขั้นต่ำ : 5

- รอดูว่าต้องใช้ไม้ในการใช้สกิลหรือไม่

Encouragement

เหอๆ เบอร์โทรศัพท์นี่ใช้มาตั้งแต่สมัยเรียนมหา'ลัย รุ่นที่มือถือใช้แทนสากได้(ไม่นะ แก่~) เป็นตัวเครื่องที่ได้มรดกมาจากพ่อ กว่าจะได้เปลี่ยนก็หลังจบมหา'ลัยมา2ปี แล้วก็เปลี่ยนเป็นอีกเครื่องเนื่องจากพ่อทำเครื่องเก่าของตัวเองหาย เลยแลกเครื่องกันแล้วซื้อใหม่- -"...
