ขอถามนิดเยอะหน่อยนะครับ แบบว่าอ่านมาทั้งกระทู้แล้วยังไม่หายงง

อันแรกนะครับ
ที่บอกว่าหลังจากที่รีฟรีแล้วแต้ม Skill point ฟรี เนี่ยจะไปรวมกับ Base Job เนี่ย
ใช่หมายความว่าสมมติว่าเป็นคลาส1จ้อบ50แล้วมี Skill point ฟรีอยู่ 8 แต้ม พอไปรีฟรีแล้วจะมีแต้มรวมทั้งหมด 3(ตอนเริ่มต้นอันนี้มะแน่ใจว่ามีมั้ย)+49(ที่เล่นๆมาหนะแหละ)+8(แต้มฟรีงับ)=60ใช่เปล่าครับ

อันที่2
Skill point ฟรีที่ได้จะนำไปใส่ในสกิลของคลาส2ได้มั้ยครับ(Skill point ของคลาส1ก็เอาไปใส่ในคลาส2ไม่ได้อยู่แล้วนิเนอะ)

อันที่3
ถ้าไปรีฟรีตอนคลาส2แล้วแต้มมันจะปนกันหมดใช่มั้ยครับ
อันนี้จะได้ไปวางแผนใส่แต้มลงคลาส2ก่อน แต้มของคลาส2จะได้ไม่ไปเกินที่สกิลของคลาส1งับ

อันที่4
ในกรณีที่จะ Reskill แบบเสียเงินอะครับ การที่รีทีละสกิลเนี่ยหมายถึงสมมติว่าสกิลที่ผมต้องการจะรีผมอัพไปเลเวล5แล้วเนี่ย พอมารีแบบที่กล่าวมามันจะลบไปทั้งสกิล(ได้แต้มคืนมา7)
หรือว่าจะลดทีละเลเวล(จากสกิลเวล5ลดเป็นสกิลเวล4)งับ

ช่วยตอบด้วยนะครับ แบบว่าสงสัยอยู่ครับ รบกวนด้วยครับที่ถามแบบเป็น Package
