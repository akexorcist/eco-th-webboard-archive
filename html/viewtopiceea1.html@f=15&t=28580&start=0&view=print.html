บอกว่าไร้บลาส แปลว่า ไม่อยากรีสกิล และเลเวลมากกว่าสี่สิบแล้ว

ถ้าคุณมีสกิล แดนซิ่งสวอด ใช้มันให้เป็นประโยช เก็บเลเวลที่ดันใต้ หรือ ปราสาทอันเดทก็ได้คับ

ถ้าไม่มี ไปรีเถอะครับ ไม่มีทั้งสอง ชีวิตวิซาดคงต้องจบกันแล้ว ว่าแต่ จีเอ็มเค้ารีสกิลให้ใหม่แล้วหนิ วู้้
