วิธีแก้
1. บันทึกสิ่งที่อยู่ในช่อง F1-F12 ไว้ โดยแยกเป็นของแต่ละตัวละคร (เช่น จดชื่อสกิล,ยา ไว้ในNotepad) ถ้าต้องการให้หลังจากแก้เสร็จแล้ว Shortcut ต่างๆอยู่ในตำแหน่งเดิม
2. เข้าไปที่โฟลเดอร์ที่ลงเกมECOไว้ (เช่น C:\Program Files\ONENET\Emil Chronicle Online\ สำหรับคนที่ลงไว้ไดรฟ์ C) จากนั้นเข้าไปที่โฟลเดอร์ config
3. ลบไฟล์ที่อยู่ในโฟลเดอร์ config ทั้งหมด โดยจะมีลักษณะของชื่อไฟล์เป็น MACRO00.xml, MACRO01.xml, MACRO02.xml, ...
4. อย่าเพิ่งปิดโฟลเดอร์ config จากนั้น Log in เข้าเกมECO ในหน้าเลือกตัวละคร ให้เลือกตัวละครตัวทางซ้ายมือสุด แล้วกด Start เข้าเกมไป
5. กลับมาที่โฟลเดอร์ config จะสังเกตุเห็นไฟล์ MACRO00.xml ไม่ต้องลบ (ถ้าไม่เห็นกด F5 เพื่อรีเฟรชใหม่เรื่อยๆ)
6. Log outออกมา แล้ว Log in เข้าไปหน้าตัวละครอีกครั้งเลือกตัวที่อยู่ถัดมาทางขวา แล้วกด Start เข้าเกมไป
7. กลับมาที่โฟลเดอร์ config จะสังเกตุเห็นไฟล์ MACRO01.xml ไม่ต้องลบเช่นกัน (ถ้าไม่เห็นกด F5 เพื่อรีเฟรชใหม่เรื่อยๆ)
8. ถ้ากด F5 เพื่อรีเฟรชแล้วยังไม่เห็นไฟล์ MACRO01.xml ให้กลับไปทำใหม่ตั้งแต่ข้อ 2. แต่ถ้าเห็นไฟล์ MACRO01.xml แล้ว ทำตามข้อ6-7กับตัวละครที่เหลืออีกตัว(ถ้ามี) โดยไฟล์ที่เพิ่มขึ้นมาจะชื่อ MACRO02.xml
9. เมื่อเสร็จการ Log in ทั้ง 3 (หรือ 2) ตัวละคร แล้ว โฟลเดอร์ config จะมีไฟล์อยู่ 3 ไฟล์คือ MACRO00.xml, MACRO01.xml และ MACRO02.xml ห้ามลบ
10. Log in แต่ละตัวละคร แล้วนำสิ่งที่เคยอยู่ใน Shortcut ช่องต่างๆกลับมาไว้ที่เดิมโดยดูจากสิ่งที่ใช้จดในข้อ1.
11. เสร็จเรียบร้อยแล้วครับ

Macro มันเพิ่มได้... Ctrl+k จะเห็นชื่อ Macro ให้ลองลบแล้วตั้งเป็นชื่อใหม่ ก็จะได้เพิ่มมาล่ะ
ก็ตั้งไว้ตามที่ตัวละครมี เวลาจะใช้ก็เปลี่ยนเป็น Macro ของตัวนั้นๆไง


คือ ถ้าผมเข้าใจไม่ผิด วิธีของคุณ -คนหน้าตาดี- จะต้องเข้าไปเปลี่ยน Macro ให้ Shortcut ตรงกับที่ตัวละครนั้นๆใช้ ทุกครั้งที่ Log in

แต่วิธีของผม แค่เลือกตัวละครก็เล่นได้เลย ไม่จำเป็นต้องเข้าไปเปลี่ยน Macro ให้ Shortcut ตรง
้
อย่างไรก็ตาม วิธีของคุณ -คนหน้าตาดี- เหมาะสำหรับคนที่เล่นหลายๆ ID เพราะ จะสามารถตั้ง Macro ให้มี Shortcut เฉพาะตัวละครได้

ส่วนวิธีของผมเหมาะสำหรับคนที่มี ID เดียว แล้วมีปัญหา Shortcut ตีกัน และไม่อยากเปลี่ยน Macro ทุกครั้งที่เข้าเล่น
