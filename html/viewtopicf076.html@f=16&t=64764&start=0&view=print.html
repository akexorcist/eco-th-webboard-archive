มีหลายคำถามหน่อยนะครับ

1.ความแรงของไพ่ขึ้นอยู่กับสเตตัสตัวไหนหรอครับ

2.สายไพ่ควรอัพสเตตัสอะไร เท่าไหร่ และสกิลไรที่จำเป็นมีอะไรมั่งครับ

3.สายไรออทควรอัพสเตตัสอะไร เท่าไหร่ และสกิลที่จำเป็นมีอะไรมั่งครับ

4.สายไรออทกับสายไพ่ แตกต่างกันยังไงครับ (สายไหนเก่งเรื่องอะไร)

ขอบคุนล่วงหน้าครับ

สายไรออต ควร อัพ Agi ให้ a.spd 800 พอ(ตีไวสุดเท่านี้ ถ้าไม่มีเอเล ใส่สปีด) แล้วก็ Vit100 ไปเรย เพราะความแรงในการทุบ ต้องใช้เลือดตัวเอง+เลือดคนในตี้

Oakstory เขียน:คืออ่านไกด์ของพ่อค้าแล้วยังงงอยู่น่ะครับ

ใครเก่งเรื่องพ่อค้าโปรดชี้แนะด้วยครับ

มีหลายคำถามหน่อยนะครับ

1.ความแรงของไพ่ขึ้นอยู่กับสเตตัสตัวไหนหรอครับ

- ความแรงขึ้นกับ STR ความแม่นขึ้นกับ INT

2.สายไพ่ควรอัพสเตตัสอะไร เท่าไหร่ และสกิลไรที่จำเป็นมีอะไรมั่งครับ

- สเตตัสตัวอย่าง -> STR 99 INT 21 ที่เหลือ VIT หรือ AGI ตามสายที่อยากเล่น แล้วตามด้วย MAG ซัก 40+ เพื่อ Random Heal
- สกิลที่จำเป็นมี Double UP กับ Continue Throw ที่ใช้ในการลุย ที่เหลือคือ Random Heal กับ passive ต่างๆเช่น Blackleg Badluck Lucky

3.สายไรออทควรอัพสเตตัสอะไร เท่าไหร่ และสกิลที่จำเป็นมีอะไรมั่งครับ

- VIT 100 AGI ให้รวมโบนัสได้ 108 ที่เหลือ ลง MAG แต่ SAGA หน้าไรออทจะมีความแม่นที่ขึ้นกับ DEX+INT อันนี้ต้องรอดูกันต่อไป เพราะมันจะมี miss แล้ว
- สกิลที่จำเป็น ไม่มีอะไรนอกไปจาก Riot Hammer พวกท่า Mastery ที่เกี่ยวกับพลังโจมตี ATK ไม่ต้องไปอัพ อัพแต่ที่มันทำให้เพิ่มเลือด เพิ่ม SP และอื่นๆ

4.สายไรออทกับสายไพ่ แตกต่างกันยังไงครับ (สายไหนเก่งเรื่องอะไร)

- ต่างกันสิ้นเชิง.. แค่วิธีลุยก็ต่างกันแล้ว ไพ่ลุยเดียวได้ ไรออทจะแรงต้องไปกันเป็นทีม
- สายไพ่ดีตรงลุยเดี่ยว แต่จุดด้อยคือเผา SP ไวมาก แต่หากดวงดีเรื่อง random heal ได้ SP บ่อยๆ จุดนี้จะไม่มีปัญหา
- สาย VIT ปาไพ่อืด แต่ถึก SP เยอะ เสียตรงจะ random heal ทีใช้เวลานานกว่าจะเต็ม
- สาย AGI ปาไำำพ่ไว เก็บเลเวลง่าย แต่ตัวบางเหมือนสาย AGI ทั่วไป

- สาย Riot ด้วย VIT AGI มหาศาล นอกจากจะหนาแ้ล้วยังพลิ้วหลบเก่ง แต่เวลาลุยไม่สามารถไปคนเดียวได้เลย เนื่องจากท่ามันบังคับให้ต้องมีคนในอยู่ในระยะ 3x3 ที่เราใช้สกิล (สิงเราอยู่ก็ได้นะ)
- อย่างที่บอก อนาคตมันจะมี miss ต้องปันไปลงค่า DEX หรือ INT ซึ่งไม่รู้ว่าจะมีผลซักเท่าไร อันนี้เก็บไว้้คิดเองละกัน

ขอบคุนล่วงหน้าครับ
