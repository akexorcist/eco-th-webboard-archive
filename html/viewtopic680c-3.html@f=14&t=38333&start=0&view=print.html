ถาม สไตล์การเล่นนักดาบทั้ง สาย agi และ สาย vit

โพสต์แล้ว: ศุกร์ 22 ก.พ. 2008 3:23 pm
โดย ECO
อยากรู้ว่าสไตล์การเล่นของสาย Agi และสาย Vit ของอาชีพนักดาบแตกต่างกันอย่างไร
แบบว่าแต่ละสายใช้ skill อะไรบ่อยๆ ใช้ดาบสองมือ หรือมือเดียว เปลืองค่ายาเปล่า แบบไหนไปลุยคนเดียวได้หรือต้องไปกับตี้ อื่นๆถ้ามี ใครที่เล่นสายไหนอยู่ช่วยอธิบายให้ฟังหน่อย

ปล.มีใครเคยเล่นแบบผสม Agi และ Vit มั่งป่ะ มันรุ่งป่าวอ่ะ

ผมสายมั่วอะ

-เวลดัน70คนเดียวได้ ใช้โทนิกนิดหน่อย ชั่วโมงละร้อยขวด ไม่ต้องใช้พระ ไม่ต้องปั๊มยาเพิ่มเลือด เอาห้องที่ไม่มีวาซาบิพอ หลบเวทงูเอา อย่าตีหุ่นเขียวเพราะมันเจ็บ
-ก่อนหน้านั้นก็เวลที่โจร เลือดหมดก็เข้าบ้าน มีพระก็สบาย
-ดันสามสิบ(ได้จนถึงเวล62 ไว้ไปคนเดียว) เปิดกะโห้กะกินสโมกแฮมที่ไก่ดรอป หลบเวทเอานะ (ไม่ต้องปั๊มเลย)

ที่อื่นก็มี ดันห้าสิบ(ควรไปกะพระ) ละก็ หอแสง(ถ้าไปคนเดียวตีตรงข้างนอกของชั้นสี่ ถ้าแชร์พระ ไปบนๆ(A9-12/B9) หรือชั้น1-2 ก็ได้

ลากให้สายเวทผมไม่แนะนำ เพราะถือเป็นการเสียศักดิ์ศรีของเบลด อาชีพที่เวลเองได้ดีที่สุด

ผมSTR+VIT

สกิลหากินอิไอ1-2-3 เวลาลากสกิลหมู่ผมใช้Gravityของบาวตี้

ถ้ามีโซลstr100มาสิงซัก2-3คน เวลดัน70สบาย ตีมอนตายใน3ดาบ

จะเก็บเวลเร็วมาก...ถ้ามีพระคอยเร่งละสบายไม่ต้องวิ่งเข้าวิ่งออกหลายรอบ

ส่วนแนวทางการเวลผมเวลแบบก้าวกระโดด....ไม่แนะนำให้ทำตามเพราะมันเปลือง-*-
เวลต้นๆ-30 เก็บตัวหนวดฟ้าๆroper
30-35ไปตีเมืองเหนือ
35-40เมืองใต้-ดันไพ่
40-50เควสกันกัน34-ขนนกดำเมืองเหนือ(ตัวอะไรก็ได้ที่เน้นจ๊อบ...ฮ่า-*-)
50-60ดันฟาอีส-ฟุชิกิ(กว่าจะตีโจรตายเหนื่อยหน่อยมิสบ่อย)
60-70ฉลองซาก้า4บุกหอแสงชั้นA-11 ตีหมดทุกอย่าง ปืนกล หุ่นแดง งู
70+ดันส่วนตัว70 ฟุชิกิ หอแสง
80จะเก็บจ๊อบที่ไหนก็ได้ที่คุณคิดว่าเก็บเร็ว
