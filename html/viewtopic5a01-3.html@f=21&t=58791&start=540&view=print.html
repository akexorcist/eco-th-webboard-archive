และเมื่อวันแรกที่ฉันมาถึงก็ไปตระเวณหาท่านพี่เรื่อยๆจนไปเจอชื่อของกลุ่มประธานนักเรียนคลาสแวมไพร์ก็ไปเจอชื่อของท่านพี่ค่ะ หนูดีใจมากเลยที่ได้รู้ว่าท่านพี่เป็นถึงประธานนักเรียนคลาสแวมไพร์เลยตัวฉันดีใจสุดๆเลยล่ะค่า

เนื้อหาข้อความ

วันหนึ่งชั้นได้เจอเรื่องเหลือเชื่อของท่านพี่เข้า

ตอนที่ชั้นกำลังเดินอยู่นอกห้องพยาบาลก็ได้ยินเสียงบางอย่างเกิดขึ้น

“โอ๊ย เจ็บนะ นายทำบ้าอะไรเนี่ย”

"โฮะ นั้นเสียงท่านพี่นี้น่า"ชั้นอุทานขึ้นแล้วกอดหนังสือแน่นแล้วเดินเข้าไปดูที่หน้าต่างก็พบกับ

“ข้อหาสั่งสอนรุ่นพี่ - -* ฉันปี2 นายปี1 อย่าลืมสิ ฉันเป็นรุ่นพี่นาย” เจ้าแมลงสาปชั้นต่ำนั้นก็กดสำลี ลงไปแรงขึ้น

[ไอ้นั้นมันใครกันบังอาจมาสั่งสอนท่านพี่]ออร่าดำทมึนโชยออกมาจากตัวของชั้นสายต่าอยากจะฆ่าเจ้าคนที่บังอาจสั่งสอนท่านพี่

“แต่ฉันเป็นประธานนักเรียนนะ”

[ใช่แล้วค่ะ ใช่แล้วท่านพี่เป็นประธานนักเรียน]

“แต่ ฉันอยู่คลาสมนุษย์” เจ้าแมลงสาปชั้นต่ำนั้นหัวเราะขึ้นมา จนชั้นอยากจะฆ่ามันทีเดียว

“อึก...เออ ก็ได้”

[ท่านพี่ ยอมมันง่ายๆได้ไงเนี้ย]ชั้นอึ้งจนสะดุดล้มกองหนังสือหล่นทับหัว

นั้นเป็นครั้งแรกที่ชั้นเห็นท่าทางแบบนั้นของท่านพี่ในโรงเรียนนี้ TT_TT
ม่านพี่ในใจชั้นกำลังเลือนหายไปตั้งแต่ที่ชั้นมาที่โรงเรียนนี้

+++++++++++++++++++++++++++++++++++++++++++++++++++++

กรั่กๆ ไม่มีไรทำเดี๋ยวบันทึกลับของมิโกะ ในตอนบทนำมันจะมา ฮึฮึ
อ้อวันที่

x2/1/xxx1 คือ x2 = บทที่2นะ 1 = เดือนที่1ผ่านไป4ตอนจะเปลี่ยนใหม่ไปเรื่อยๆ xxx1 คือ เดือนผ่านไป12แล้วจะเปลี่ยนใหม่นะงับ

สรุปคือมันยังมีต่อ ฮึฮึฮึ

ถึงมันจะไม่ใช่ซับนรกแบบที่ท่านต้องอการก็เถอะนะ ฮึฮึ ไม่มีไรทำง่ะเลยเอาน้องเจ้ามิมาแต่งเองกรั่กๆ
