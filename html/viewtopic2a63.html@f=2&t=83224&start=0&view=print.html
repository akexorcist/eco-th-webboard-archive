สวัสดีค่ะ ยินดีที่ได้รู้จักทุกคนนะคะ

จริง ๆ แล้วจะปรึกษาเรื่องเน็ต VPN แบบเสียเงินนิดหน่อย
แต่อีกใจก็อยากเพ้อเจ้อระบายความรู้สึกพอเป็นพิธี เพราะงั้นข้ามช่วงต้น ๆ ไปได้เลยนะคะ ^^

---------------------------------------------

เราเป็นคนหนึ่งที่เล่น ECO มาตั้งแต่ซาก้าแรก และตามมาจนถึงเซิร์ฟไทยปิด โดยที่ไม่ได้เล่นเกมอื่นเลย
(ปกติเราไม่ใช่คนชอบเล่นเกมอยู่แล้ว อย่าง ECO นี่ก็จำไม่ได้แล้วว่าเจอกันได้ยังไง)
จำได้ว่าประมาณช่วงนี้ของปีก่อน เราพยายามเข้าไปเล่นเซิร์ฟญี่ปุ่น
ปกติเราใช้ภาษาญี่ปุ่นบ่อยกว่าภาษาไทยอยู่แล้ว เลยไม่มีปัญหาเรื่องภาษา
แต่ว่าด้วยปัญหาทางเน็ต ที่เข้าไปแล้วหลุดบ่อยมาก บวกกับยุ่งเรื่องเรียนกับทำงาน
เราเลยตัดใจเลิก เพราะเห็นว่าเล่นไปก็เสียเวลาเปล่า ๆ
ทำใจซะว่าเดี๋ยวพอไปอยู่ที่ญี่ปุ่นเมื่อไหร่ค่อยเริ่มเล่นใหม่ แต่มันก็อีกตั้งหลายปีกว่าจะถึงตอนนั้น

แต่ปรากฏว่าตลอดหนึ่งปีที่ผ่านมานี้ เราเอาแต่คิดถึงที่นี่มาตลอด คิดว่าคงไม่ใช่เราคนเดียวที่เป็นแบบนี้
ลังเลแล้วลังเลอีก สุดท้ายก็ทนไม่ไหว ตัดสินใจกลับมาจนได้
ทีนี้เจอกับปัญหาเดิมอีกค่ะ เรื่องเน็ต VPN เนี่ย ตอนนั้นเราใช้ MobileFree.jp แบบฟรี (ซึ่งเน็ตเต่าบ้านเราเล่นแทบไม่ได้)
เลยตัดสินใจจะเลือกแบบพรีเมียมที่เสียตังค์แทน แต่ไม่ค่อยมีความมั่นใจและความรู้เท่าไหร่ เลยขอปรึกษาหน่อยนะคะ

---------------------------------------------

เอาล่ะ เข้าเรื่อง (ซะที ฮา)

- ดูจากกระทู้แนะนำเห็นมีแนะนำ VPN อยู่สามอันใช่ไหมคะ เราไม่ค่อยรู้ศัพท์คอมพิวเตอร์
ตอนเข้าไปอ่านแพคเกจแต่ละอันก็งงมากว่าอะไรคือ SSH PPTP ฯลฯ
เลยไม่รู้จะเลือกใช้อันไหนดี และไม่รู้ด้วยว่าจะต้องจ่ายเงินช่องทางไหน เพราะเราเองก็ไม่เคยซื้อของทางเว็บด้วย

- เห็นมีเว็บ playpoint ที่มีให้ซื้อแบบ VPN Secure.me ด้วย และวิธีจ่ายเงินค่อนข้างสะดวกเพราะเราไม่มีบัตรเครดิต
แต่ไม่แน่ใจว่าจะใช้ได้ผลเหมือนกันไหม และเชื่อถือได้หรือเปล่า

สรุปเราสงสัยหลัก ๆ ก็เรื่องจะเลือกแบบไหนดี กับเรื่องการจ่ายเงินน่ะค่ะ
จะลุยเองคนเดียวก็ไม่กล้า เลยคิดว่าปรึกษากับคนที่มีประสบการณ์เล่น ECO เซิร์ฟญี่ปุ่นโดยตรงดีกว่า

ขอโทษที่พิมพ์ซะยาวเหยียดนะคะ ยังไงก็รบกวนช่วยแนะนำด้วยค่ะ

ของคุณที่พึ่งลงใหม่จะยังไม่มีห้องให้เห็น ให้ทำตามขั้นตอนนี้ก่อน

2. กด Join a Group
3. ในช่องว่าง ใส่ "eco-th"

เรียบร้อย แค่นี้คุณก็โผล่ในห้องแล้ว



- วิธีแชทหน้าหลัก ให้ดับเบิลคลิกที่รูปเลเนตจัง (eco-th ข้างบน) จะโผล่หน้าต่างคุยขึ้นมา
- เวลาจะซิบหาใครให้ดับเบิลคลิกที่ชื่อในลิสท์ข้างล่างครับ จากรูปตัวอย่างตอนนี้ก็มีอยู่ 3 คน



วิธีโพสรูป ที่หน้าต่างแชทให้กด photo จะมีปุ่ม capture photo กดเข้าไป จะมีให้เลือกว่า
- Capture อันนี้คือใช้กล้อง cam ถ่ายสดๆเลยครับ
- Load file ไว้โหลดรูปสกุล jpg bmp gif ฯลฯ จากเครื่องมาโพส
- Paste ไว้โหลดรุปที่คุณพึ่งกด printscreen หรือ copy มาหมาดๆเมื่อครู่ครับ
- Send กดเพื่อส่งรูปที่คนจะโพสลงห้องแชทครับ

*ข้อแนะนำเรื่องการโพสรูป เพื่อไม่ให้คนอื่นโหลดรูปอืดดึงเนตช้า ผมแนะนำให้เอารูปที่คุณ printscreen มาไปตัดก่อน
เช่น คุณติดตรงสมัครไม่ได้เพราะกรอกอะไรบางอย่างผิด ก็ printscreen จากนั้นเปิดโปรแกรม paint ไปตัดมาเฉพาะ
ส่วนที่เป็นสีแดงว่าคุณกรอกผิด จากนั้น copy มาวางโพสในห้องแชท เป็นต้น
