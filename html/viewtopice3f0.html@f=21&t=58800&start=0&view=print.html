50 วิสัยนักวาดสุดนู้บ!!!

โพสต์แล้ว: อังคาร 02 ธ.ค. 2008 1:16 pm
โดย ECO
เพิ่งไปเห็นจากในอากิบักโกะ แต่เพราะคนที่แปล แปลจากคอมเมนท์ภาษาอังกฤษในยูทูบอีกที เนื้อหาเลยไม่ตรง ( บางข้อก็ไปกันคนละโยชน์ ) อ่านแล้วรู้สึกไม่ถูกใจ เลยหยิบมาแปลเอง + เอามาเผยแพร่ด้วย

ต่อไปนี้คือเรื่องที่มักจะเกิดขึ้นในบรรดานักวาดนู้บๆ ลองเช็คกันดูว่าตัวเองมีข้อที่แทงใจกี่ข้อ ยิ่งมีมากเท่าไรก็ยิ่งนู้บขึ้นเท่านั้น มีทั้งหมด 50 ข้อ อนึ่ง คนที่รวบรวมคำถามนั้นโดนเข้าไปเกิน 30 ข้อเลยล่ะ orz ( ส่วนที่เป็นวงเล็บจะเป็นคอมเมนท์เพิ่มเติมของคนแปลเน่อ )

01. เรียกการวาดแบบเผาๆขอไปทีว่างานแบบเรียบง่าย ( ทำนองว่า "ตูวาดเน้นความซิมเปิ้ลเฟ้ย ไม่ได้จะวาดให้มันออกมาดูอลังการเข้าใจ๋!" น่ะ... )

02. เวลาเอารูปไปให้คนอื่นดู ก็จะออกตัวว่า " กำลังฝึกอยู่อะ.. " อะไรทำนองนี้ตลอด

03. มักจะแก้ตัวว่า " ก็เค้าวาดด้วยเมาส์หนูอ่า... " หรือ " นู๋ไม่มีแทบเล็ตอ่า " ( อ้างไม่ได้หรอก.. เมาส์หนูวาดเทพๆมีเยอะจะตาย.. )
04. วาดมันแต่ใบหน้าตัวละคร ( กะเอาดีทางยุคคุริไง! XD )

05. วาดให้หันไปทางเดียวกันหมดตลอดเลย

06. ใส่ใจวาดแค่ส่วนใบหน้า แต่ส่วนสำคัญอย่างร่างกายดันวาดไม่ได้

07. ไม่สามารถวาดให้แยกแยะบุคลิกตัวละครจากใบหน้าได้ ( จะนิสัยแบบไหนก็หน้าเดียวกันหมด... )

08. ใช้วิธีแยกแยะตัวละครจากทรงผม ( ใบหน้าโขลกพิมพ์เดียวกันออกมาหมด )

09. เขียนแบ่งแยกซ้ายขวาไม่เป็น ( วาดหันไปอีกทางแล้วไม่สอดคล้องกับตอนวาดอีกทาง )

10. " ร่างภาพเรอะ? ไม่เห็นจำเป็นต้องทำเล้ย!! "

11. เอาแต่ร่างมันอย่างเดียว... ( ตัดเส้นวาดจริงมั่งเหอะ.. )

12. " เลเยอร์ เนี่ยมันคืออะไรเหยอ? กร๊ากกก "

13. ภาพนึงวาดตัวละครได้แค่คนเดียว ( วาดภาพหมู่ ให้ตัวละครมีกิจกรรมร่วมกันไม่ได้ )

14. วาดแต่ละทีก็มีแต่คอมโพสเดิมๆ

15. วาดแต่ละทีตัวละครก็แสดงแต่สีหน้าเดิมๆ

16. ไม่สามารถวาดภาพที่มีการเคลื่อนไหวได้ ( วาดแล้วออกมาดูแข็งทื่อ นิ่งๆ )

17. ไม่สามารถวาดลงไปถึงเท้าได้

18. วาด 俯瞰 ( มุมมองลงต่ำ / bird's eye view ) หรือ アオリ ( มุมมองขึ้นสูง / worm's eye view ) ไม่เป็น

19. " คำว่า 俯瞰 มันอ่านว่ายังไงเหยอก๊ะ? アオリ นี่เป็นชื่อตัวการ์ตูนตัวไหนน่ะ??? " ( กระทั่งมุมสูงมุมต่ำยังไม่รู้จัก.... แต่ส่วนตัวคิดว่าว่าไม่ได้หรอกเพราะภาษาญี่ปุ่นมันไม่สื่อจริงๆน่ะแหละ - -" คันจิก็ยาก )

20. พอพยายามวาดแบบใส่ใจคอมโพสสุดๆ ก็กลายเป็นภาพต่างมิติไปซะงั้น

21. ทั้งๆที่เป็นตัวละครเดียวกัน แต่พอเปลี่ยนมุมคอมโพสปั๊บก็เหมือนเป็นคนละคน

22. วาดเป็นแต่คน หรือ วาดแค่คน ไม่ก็ตรงกันข้าม

23. วาดได้แต่ภาพโมเอะ

24. วาดแต่วัยสะรุ่นเลยวาดคนแก่ไม่เป็น

25. วาดมือ, นิ้วออกมาสวยๆไม่ได้

26. พยายามอย่างเอาเป็นเอาตายเพื่อที่จะได้ไม่ต้องวาดมือ เช่น เอามือตัวละครไปซ่อนไว้ข้างหลัง

27. ฝันไว้สูงลิบลิ่ว แต่ไม่ค่อยจะลงมือทำ ( ประมาณว่าอยากเก่งแต่ไม่ยอมฝึก )

28. พยายามแทบเป็นแทบตายวาดตาข้างนึงออกมาซะสวยนิ้ง แต่พอไปวาดตาอีกข้างแล้วภาพเละหมด

29. พอฟลิบภาพกลับซ้ายเป็นขวาแล้วมันน่ากลัวมวากกกกกกกกกกกกกกกกกกกกกกกกกกก!!

30. ยิ่งวาดออกมาดูดีเท่าไรยิ่งไม่ยอมเอาไปลงสี ( กลัวเละ.. )

31. วาดรัฟเสร็จแล้วจบกัน ( ไม่ยอมตัดเส้นลงสีต่อให้เนี้ยบ )

32. แทบจะไม่เข้าใจโครงสร้างของกล้ามเนื้อ, กระดูกเอาซะเลย

33. " ยึดติดว่า ใบหน้าคือก้อนเนื้อที่แปะครอบอยู่บนกะโหลกอีกที มากเกินไปแล้วเฟ้ย "

34. วาดหน้าหรือดวงตาใหญ่เกินเหตุ

35. ตำแหน่งหน้าอกมั่วแหลก ( อยู่สูงเกินมั่ง ต่ำเกินมั่ง )

36. COOL ไดรฟ์! [ มี 6 นิ้ว ] คุณ J ไกล์ [ วาดมือสลับกัน ( มีมือซ้าย 2 ข้าง ) ]

37. ติภาพคนอื่นซะจู้จี้จุกจิกเกินเหตุ แต่ไม่เคยเอาภาพตัวเองให้คนอื่นดูเล้ย...

38. พอเผลอฟลุควาดภาพที่ออกมาดูดีได้ภาพนึง ก็มักจะเอาภาพนั้นมาดูซ้ำแล้วซ้ำอีกแล้วยิ้มน้อยยิ้มใหญ่ ( ข้อนี้แดเมจแรงมาก.. OTL )

39. บอกว่ารวบรวมผลงานคนอื่นเอาไว้ใช้อ้างอิง แต่ไปๆมาๆก็กลายเป็นงานอดิเรกไปซะงั้น ( คือรวมมาดูเล่นอย่างเดียว ไม่ได้ใช้อ้างอิง ฝึกวาดแล้ว )

40. วาดได้แป๊บๆก็ตบะแตก หนีไปทำอย่างอื่นแทน

41. คิดว่าแทบเล็ตเป็นอุปกรณ์ที่ทำให้วาดเก่งขึ้น ( ความเชื่อชัดๆ... )

42. พอได้ติงานนักวาดนู้บคนอื่นแล้วสบายใจ หรือวางใจว่า " อย่างน้อยตูก็ยังดีกว่ามันล่ะฟระ 555+ "

43. ตอนวาดงานเสร็จใหม่ๆแล้วภูมิใจในงานตัวเองอย่างมาก แต่เมื่อนอนไปได้ตื่นนึงแล้วกลับมาดูภาพตัวเองอีกทีแล้วอยากตาย ( พอมองเห็นข้อผิดพลาดที่มองข้ามไปทีแรกแล้วเฟลแดกกันเลยทีเดียว )

44. พอไปดูภาพของนักวาดคนอื่นที่เก่งกว่าตัวเองแล้วก็ท้อใจ หดหู่ จนรู้สึกเกลียดการวาดภาพไป

45. อาทิตย์นึงวาดแค่ครั้งเดียว หรือไม่ก็น้อยกว่านั้น ( ในรูปประกอบคือทิ้งการอัพเดทไปเป็นปี... )

46. มีเว็บไซต์รวมผลงานของตัวเอง แต่ปิดปรับปรุงไม่อัพเดทมานานชาติแล้ว ( Critical hit!! OTL )

47. วาดภาพเรทหื่น แต่ออกมาเป็นภาพเรทโหด [ เพราะสมดุลของร่างกายแปลกๆ ] ( ทำนองว่าวาดออกมาแล้วดูเป็นแขนหัก ขาหักมั้ง? )

48. ความสามารถก็ไม่มี แถมไม่เคยมีความคิดที่จะลองพยายามเลียนแบบซักกะติ๊ด ( ทู่ซี้วาดแต่อะไรประหลาดๆ ไม่เรียนรู้ )

49. วาดไม่ได้มาตั้งแต่แรกแล้ว~ ( จำพวกฝึกให้ตายก็ไม่มีวันวาดได้ )

50. พอทำคำถามทั้งหมดนี้จบ ก็คิดว่า " นี่เราประเมินตัวเองนี่นา ไม่เป็นไรหรอกน่า 555+ " แล้วก็ไม่ได้พัฒนาขึ้นเลย ( ทำนองว่า "ประเมินตัวเองก็ต้องถ่อมตัว มีข้อที่ใช่เยอะๆอยู่แล้ว จริงๆอาจจะไม่ถึงขนาดนี้ก็ได้" แล้วไม่สนใจฝึกฝนต่อ )

ขอบคุณที่ดูจนจบ! ขอให้ทุกท่านดูแล้วอย่าท้อแท้ มาพยายามด้วยกันเพื่อเข้าใกล้ตัวเองในอุดมคติให้มากขึ้นกันเถอะ!
