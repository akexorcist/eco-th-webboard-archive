ถ้าคุณมีพระสิงหรือสาย FT มหาอุตม์ เรื่องแบบนี้ก็ขี้ปะติ๋ว แต่กับ Spell user ที่ดันเล่นสายทุบ มันจะเป็นความเสียหายที่ร้ายแรงมากๆ เพราะเราจะหลบไม่พ้น แล้วยังเลือดน้อย def น้อยอีก ต้องโซลิดสถานเดียว แต่ถ้าใช้โซลิด ก็จะกลายเป็นว่าเราจะติดท่าตัวแข็งจากโจรขาว 100 % ซวยไปอีกแบบ
