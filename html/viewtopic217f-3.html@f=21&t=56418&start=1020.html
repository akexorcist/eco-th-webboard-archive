ขอมาก้อจัดให้ค่ะ .....หุหุ


ผีฮานาโกะในห้องน้ำหญิง........ ในสมัยอดีตของประเทศญี่ปุ่นเชื่อกันว่าห้องน้ำหรือสุขามีปีศาจ"คาวายากามิ"อาศัยอยู่ในห้องน้ำแม้ในปัจจุบันก้อยังมีเรื่องเล่าแปลกๆเกี่ยวกับห้องน้ำอยู่เยอะมาก. ช่วงหลังนี้เรื่องราวของผีฮานาโกะซังจะเป้นเรื่องที่โด่งดังมากๆ....
ฮานาโกะซังเป็นผีที่ปรากฏตัวในห้องน้ำที่โรงเรียน. เล่ากันว่าถ้าอยากพิสูจน์ให้เคาะประตูห้องน้ำที่ไม่มีคนอยู่3ครั้งในช่วงเวลา16.00นาฬิกาเป็นต้นไป.แล้วให้ถามว่า"ฮานาโกะซัง... อยู่ไหม?" ถ้าโชคดีก็จะมีเสียงตอบกลับออกมาเบาๆว่า"ค่ะ"เฉยๆ.บางครั้งถ้าดวงซวยจะเจอมือขาวๆซีดๆยื่นออกมาจากใต้ประตูห้องน้ำห้องนั้นที่เราเคาะ. และแล้ว วิญญานของเด็กหญิงผมทรงกะลาครอบหน้าขาวซีดจะปรากฏตัวขึ้น...... ที่โรงเรียนประถมแห่งหนึ่งในเขตอาดาจิ ในจังหวัดโตเกียว. ก็มีเรื่องเล่าการปรากฏตัวของผีฮานาโกะในห้องน้ำของโรงยิมว่ากันว่า ถ้า วิ่งริบโรงยิม 40รอบ(ป๊าดด 10รอบก็หอบแฮ่กแล่ว... - -* ) แล้วให้ตะดกนว่า "ฮานาโกะซัง"ดังๆ. จะมีเสียงตอบกลับมาว่า "ค่า" แล้วให้พูดต่อว่า"มาเล่นกันเถอะ." แล้วน้องฮานาโกะจัตอบกลับมาว่า.."ได้สิ.. จะเล่นอะไรกันดี..."
