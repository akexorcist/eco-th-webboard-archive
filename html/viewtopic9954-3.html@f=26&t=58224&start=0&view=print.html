ชมจันทร์ลอยกระทง~

หลังจากผ่านปราสาทจอมมารในช่วง Holloween ไปแล้วเลยกะจะแต่งบ้านตามเทศกาลต่อ ปรากฏว่าพบปัญหาเข้าจนได้... มันคือ

เป็นเทศกาลชมจันทร์ลอยกระทงแท้ๆ ท้องฟ้าในสวนดันสว่างจ้าซะงั้น !!

ด้านนอกตอนนี้เลยไม่รู้จะจัดยังไง เพราะฟ้าไม่มืดเลยนึกไอเดียดีๆไม่ออก..

ตอนนี้เราเข้ามาดูข้างในกันก่อนดีกว่า


ในบ้านจัดเป็นสไตล์ญี่ปุ่นตามเทศกาลชมจันทร์เต็มที่


ตรงเข้ามาก็จะเห็นโต๊ะหมู่บูชา(?) ตั้งไว้บูชาหินพระจันทร์ ว่าจะวางของบนโต๊ะเพิ่ม ไม่รู้วางอะไรดี


โต๊ะของเซ่น เทพสึคุโยมิ ที่แยกออกมาต่างหาก ขอให้ปีหน้าพระจันทร์ก็งามเหมือนปีนี้นะ

และเหล่าแมวทั้งหลายที่ตั้งใจดูแลบ้าน แุถมคอยเปลี่ยนดังโงะที่เซ่นใหม่เรื่อยๆไม่ให้มันบูดอีกต่างหาก ขยันกันแบบนี้น่ากอดจริงๆ

"ว่าแต่อากาเนะ ทำอะไรอยู่นิ"
อากาเนะ : อย่ามากวนเวลาทำงานได้มั้ย !!
"อ่า ไม่ใช่ว่าแต่งหน้าอยู่รึนั่น"

"หนูไอไปทำอะไรบนน้้าน !!"
ไอ : หาของค่ะ

"โซระ มาทำอะไรอยู่คนเดียวตรงนี้ล่ะ ?"
โซระ : เผลอตัวไปกินดังโงะเลยโดนไล่ออกมาอะ T-T
"....."

และยังมีอยู่อีกมุมหนึ่งที่ยังไม่รู้จะจัดยังไงดี ตอนนี้ปล่อยไว้ก่อนละกัน

โล่งสนิท..

ปัญหาตอนนี้คือนอกบ้านละครับ ฟ้าสว่างแล้วไิอเดียไม่เกิดเลย ทำยังไงดี T-T
เอาเถอะ ถ้าไม่ work จริงๆ คงรื้อทิ้งหมด แล้วเตรียมจัดรับเทศกาลต่อๆไปดีกว่า เดือนหน้าก็คริสมาสต์แล้วนี่นะ
