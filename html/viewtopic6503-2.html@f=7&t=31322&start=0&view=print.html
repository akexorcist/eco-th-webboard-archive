อันนี้เจอทุกเกมส์เลยค่ะ แผนนี้ เรื่องมันมีอยู่ว่าสมมุติชื่อเอานะ นาย A1 และนายA2 ซึ่งก็คือคนๆเดียวกันแต่เล่น2ตัว และนายB1คือคนที่โดนหลอก
ขั้นแต่แรกมันจะตั้ง โกเลมขายของไว้ ซึ่งสมมุติว่า มันตั้งขายมังกร800k
ขั้นตอนที่2มันจะเข้าอีกตัว แล้วจะตั้งป้ายเอาไว้หรือประกาศว่ารับมังกร 1ล้าน
ซึ่งมันก็จะวนเวียนเพื่อประกาศหรือให้คนเห็นแถวนั้น หลังจากนั้นก็จะมีนายB1เข้ามา
และซื้อมังกรไป ซึ่งหลังจากซื้อไปมันก็จะบอกเราว่ามีคนขายให้เราแล้วซึ่งนายb1ก็จะเสียไปฟรีๆ บางรายอาจใช้แผนนี้กับสิ่งที่ขายไม่ออก แต่บางรายใช้เพื่อขายในราคาที่โก่งสุดๆ
ระวังอาจถูกหลอก มีอีกหลายแผนที่เรารู้ - -* แผนนี้เรายังไม่เคยโดนกับตนเอง แต่มีเพื่อนคนนึงเคยโดนมาแล้ว ถ้าใครมีวิทีอื่นอีกๆช่วยโพสหน่อยนะ อยากกำจัดเกรียนให้มันหมดๆไป
