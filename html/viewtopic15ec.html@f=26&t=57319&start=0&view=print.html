เสา อาทิดไปรับไม่ได้ใช่ไม๊ครับ

แล้ววันนึงจะไม่เหมือนกันหมายความว่าไงครับ

สมมติสัปดาห์นี้ผมรับไอเทมสร้างสวนลอยฟ้า วันอังคาร พะหัด ศุกร์
แปลว่าสับดาห์หน้าผมต้องรับไอเทมวัน จัน กะพุดรึป่าวครับ
หรือว่าสัปดาห์หน้าแม้ผมจะรับวันอะไรก้ตามอีกแค่ 2 วัน ผมก้จะได้ไอเทมครบ 5 ชิ้น
(ไม่ซ้ำกันเลย)

ถามเพิ่มอีกนิดนะครับ
หลังจากผมได้ไอเทมครบทั้ง 5 ชิ้นแล้ว วันต่อๆมาผมยังสามารถไปรับไอเทมสร้างสวนได้เรื่อยๆอีกรึป่าวครับ(หรือเค้าให้รับแค่ไอดีละ 5 ชิ้นแค่นั้นครับ)

ขอบคุณมากๆเลยครับ
