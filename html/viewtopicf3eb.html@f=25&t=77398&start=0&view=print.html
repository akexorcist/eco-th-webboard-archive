เลเวล เกี่ยวข้องแค่ ให้เราเริ่มทำเควสหรือรับ Event ในการเริ่มเควสสัตว์เลี้ยงครับ

ส่วนเวล 30 กะ 110 มันก็ดรอปเหมือนกัน / จะต่างกันตรงที่เวล 110 ฆ่ามอนเตอร์ตายไวกว่า เลยดรอปไวกว่ามั้ง 55+

เกมนี้เน้นไปทางระบบปราชญ์ หรือสกิว Knowledge ซะมากกว่า สุดท้ายก็ศึกษาข้อมูลให้ดีว่ามอนเตอร์ตัวไหนดรอปดีกว่ากัน จะได้ไม่ต้องเหนื่อยมาก
