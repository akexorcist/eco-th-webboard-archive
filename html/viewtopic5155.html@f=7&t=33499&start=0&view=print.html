ข่าวนี้ควรจะมีพ่อแม่ผู้ปกครองในการควบคุมกิริยา อาจมีภาพหรือเนิ้อหาที่ต้องใช้
วิจราณญาณในการรับชม เด็กอายุที่ต่ำกว่า 18 ปีควรได้รับคำแนะนำ



เด็กผู้ชายคนนี้ได้แจ้งต่อนักข่าวของเราว่า เมื่อวันที่ 5 ธันวาคมที่ผ่านมา ซึ่งเกาะไทนี่มีการ
เฉลิมฉลองอย่างรื่นเริง ต่อพ่อหลวงของชาวไทย ซึ่งมีคนคิดพิเรนทร์จำนวนมาก ซึ่งรวมถึงการเล่น นอกเหนือไปจากที่เกาะไทนี่ด้วย ด้วยการที่เยาวชนชาวอีโค่ ได้จุดพลุสีน้ำเงิน
ใส่ผู้เล่นกลาง 'เป้า' ส่วนใหญ่เหตุทั้งหมดเกิดขึ้นกับประชาชนอีโค่เพศชาย

ดังภาพ



โดยภาพนี้นักข่าว (ฉันเอง) ได้สะกดรอยตามเด็กผู้หญิงคนนึงกับเพื่อนชายคนนึงที่จะไปจุดพลุกันที่เกาะไทนี่ บริเวณริมทะเลสาบที่ลับตาผู้คน โดยนักข่าวได้เดินตามไปเนื่องจากมี
ลางสังหรณ์พิเศษว่าคืนนี้จะได้ข่าวที่ทำเงินมากมายเป็นแน่ (หึหึ นักข่าวเจ้าเล่ห์)

และถ่ายภาพแชะทันทีเมื่อเด็กหญิงปราง (นามสมมติ) จุดพลุลงใส่เป้าของเด็กชายเน
(นามสมมติ)เด็กชายเน (นามสมมติ) ได้ร้องอย่างเจ็บปวด เมื่อพลุพุ่งขึ้นใส่บริเวณ....ของเขา ทางนักข่าว และกลุ่มทีมงานได้รีบนำพาเด็กชายเน (นามสมมติ) ส่งโรงพยาบาล ECO THAILAND ในอัพทาวน์ทันที ขณะที่เด็กหญิงปราง (นามสมมติ) ได้หลบหนีความผิดไปด้วยมังกรสีแดงตัวนึงที่ติดเสนียดของเจ้าของเดิมไปในทันที ซึ่งล่าสุดวันนี้ เด็กชายเน (นามสมมติ) ยังอยู่โรงพยาบาลด้วยอาการบาดเจ็บสาหัส และติดเชื้อเล็กน้อย แต่หมอได้ช่วยเหลือไว้ทันการและขณะนี้ได้สืบประวัติคนร้ายมาแล้ว

เด็กหนุ่มเน (นามสมมติ) กล่าวว่า หญิงคนนี้เป็นเพื่อนของเขามานานแล้วหลายปี และชวนเขาไปเกาะไทนี่ไปเฉลิมฉลองกัน แต่หลังๆมานี้ เด็กหญิงปราง (นามสมมติ) ดูแปลกๆ
ไป และโหดกว่าเดิม จนกระทั่งเกิดอาการหื่นขึ้นมา และลงมือก่อเหตุอย่างที่เห็น

ตำรวจ ECO ได้เร่งติดตามเด็กหญิงปราง (นามสมมติ) คนนี้ แต่ไม่มีวี่แววของเธอเลย ยกเว้นจดหมายที่เธอทิ้งไว้ที่เกาะไทนี่ว่า

"ฉันเกลียดแก ! จาก เด็กหญิงปราง (นามสมมติ)
