ยินดีต้อนรับสู่กระทู้ Collecter Knowledge : Gathering Material
ในกระทู้นี้จะเป็นการรวบรวมข้อมูลของ "วัตถุดิบ" ต่างๆใน ECO ที่ใช้ในการทำสิ่งของต่างๆขั้นต่อไปทั้งหลายแหล่ หากท่านพึ่งเข้ามาครั้งแรก โปรดอ่านในส่วนของคู่มือใช้งานก่อนสอบถาม คู่มือช่วยท่านได้ โปรดอย่าอ่านเป็นอันดับสุดท้าย
ข้อมูลในกระทู้ถูกจัดทำขึ้นโดยหมานิม (Nimble Crossier) และได้รับความช่วยเหลือจากหลายๆท่านจึงมีกระทู้นี้ขึ้นมาได้ หากท่านใดต้องการนำข้อมูลไปใช้ โปรดติดต่อผ่านทาง pm ใน board T-ECO หรือ irc.thai.com #pme ([MIL]*****) ก่อนนำข้อมูลไปใช้ หากท่านติดต่อหมายินดีสนับสนุนข้อมูล แต่หากไม่ติดต่อ อะแฮ่ม..... จิ้ม pm ถามยากมากเหรองิ =w=?
RM : Credit ที่ถูกต้องควรสอบถามเจ้าตัวก่อนน่อ แค่นำไปแปะยังไม่ถูก แต่ก็ยังดีกว่าแฮ๊ปไปเฉยๆ
ขอบคุณที่เข้ามาใช้งานกระทู้นี้ ขอให้กระทู้นี้เป็นประโยชน์แก่ท่านเป็นอย่างยิ่งงิ >w<

♪ ~ วิธีการใช้งาน~ ♪
- เลือกหมวดหมู่ของวัตถุดิบที่ต้องการ
- หากต้องการค้นหาด้วยระบบ Search สำหรับ IE กด ctrl+f และใส่ชื่อวัตถุดิบที่ต้องการหาโดยมี # นำหน้า เช่น #Meat, #Sugar หลังจากเจอที่หมวดไหน ให้กลับมาที่สารบัญและหาต่อจากหมวดนั้นๆ
- ค้นหาด้วยชื่อในเกมเท่านั้น แม้ชื่อมันจะผิดก็ตามที
- ข้อมูลเรียงตามตัวอักษรภาษาอังกฤษ ถ้ามันดันเป็นภาษาไทย ก็คงอยู่ล่างสุด...
- วัตถุดิบจะถูกจัดรวมเป็นหมวดหมู่ต่างๆตามชนิดของวัตถุดิบ มิใช่ชนิดที่ใช้งานใน recipe เช่น Meat ถูกจัดรวมในหมวดอาหาร Tumtum Grass จัดในหมวดพืชและไม้ Row จัดในหมวดชิ้นส่วนจากศัตรู
- การดูว่าหาวัตถุดิบได้จากไหนให้ดูที่ตัวในหมวดหมู่ของวัตถุดิบนั้นๆ

--- บรรทัดแรกจะเป็น Monster Drop [M] (ถ้ามี)
----- โดยจะไล่จากตัวที่ drop ง่ายไปถึง drop ยากจากซ้ายไปขวา
----- [M]* หมายถึงยังไม่ได้ตรวจสอบว่าตัวไหน drop ยากง่าย
----- ถ้ามี ? หลังชื่อหมายถึงยังไม่ได้ตรจสอบแน่ชัดว่า drop จริงๆไหม อาจจะ drop ยากจนเกินไป
----- ถ้ามี + ตามหลังชื่อ หมายถึงจำเป็นต้องมี Knowledge มาช่วยถึงจะ drop
----- ถ้ามี - ตามหลังชื่อ หมายถึงถ้ามี Knowledge มาช่วยจะ drop ง่ายขึ้น
----- Knowledge ที่เกี่ยวข้องและที่อยู่ monster รบกวนหาข้อมูลเองเด้อ

--- บรรทัดที่สองจะเป็น NPC Sell [N] (ถ้ามี)
----- โดยจะเขียนเป็นชื่อ npc (แผนที่ที่อยู่) : ราคา
----- คั่นด้วย, ต่อ npc 1 ตัวที่ขายของชนิดนั้น
----- ราคาที่ระบุเป็นราคาที่ไม่ได้ทำการ DC หรือหาเรื่องใช้ส่วนลดใดๆ
----- กรณี npc ชื่อเดียวกันราคาเดียวกันจะเขียนไว้ในแผนที่ชุดเดียวกันเลย

--- บรรทัดที่สามจะเป็นการใช้ skill ช่วยแปรรูป [R] (ถ้ามี)
----- (bc) หมายถึง Bow Create
----- (co) หมายถึง Cooking
----- (dc) หมายถึง Drug Create
----- (hr) หมายถึง Highly Refine
----- (ir) หมายถึง Item Refine
----- (se) หมายถึง Sewing
----- (wc) หมายถึง Wood Create
----- level และค่าใช้จ่ายหาข้อมูลเองน่อ
- นี่เป็นรายการรวม"วัตถุดิบ"ทั้งหมดเท่านั้น เพราะฉะนั้นจะไม่มีรายการของที่"ไม่ได้เป็นวัตถุดิบ"มาเกี่ยวข้อง เช่น Short Rope, Cracker, Mix Juice, Sandwich
- อาจจะมีหมายเหตุอย่างอื่นอีก เช่น [O] หมายถึงวิธีได้มาอื่นๆ (กล่อง/quest?)
