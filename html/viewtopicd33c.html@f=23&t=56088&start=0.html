ขอถูกๆหน่อยนะ

เห็นแต่ +3 STR อ่ะ(หน้ากากเสือ)

พวกรองเท้ารึ ดั้นไปเพิ่ม Mag (เจริญจิงๆ)
อกบวกก็ไม่มีแบบอาชีพอื่น (เเย่ๆ)
ชุดก็อย่าหวังว่าจะบวก (เข้าป่าเข้าดงไปเลย ตีก็เบ้าเบายังจะลบอีก STR ดีนะชุด 85 ไม่มีลบ)
