คือว่า ถ้าสมมุตินะว่า เราไปตัชินนามอนซึ่งเป็นธาตุดิน แต่แมพนั้นเป็นไฟ ถ้าเรายิงลมจะได้บวกตรงแมพแต่ลบตรงมอน เพราะมอนธาตุดิน ลม แพ้ดิน
แต่สงสัยว่า ทำไมมอนดิน แล้ว ยิงลม ใช่เพราะว่า ถ้าเทียบดู ธาตุในแมพเป็นจุดใหญ่กว่าธาตุของมอน ดังนี้

0 ชินนามอน ธาตุดิน

และถ้าสมมุติว่าเรากางวงธาตุให้ตรงกับมอนเช่น

ชินนามอน ธาตุดิน กางวงธาตุดิน

มันจะแรงขึ้นไหมเมื่อทั้งมอนและแมพแพ้ธาตุหมดเลยอ่ะคับ

ครับ แต่ก็ต้องดูก่อนนะครับว่ามอนสเตอร์นั้นธาตุดินเท่าไหร่ เช่นว่าชินนามอนธาตุดิน 50 (หมายถึงเกราะป้องกัน หรือพลังป้องกันที่เป็นธาตุดินนั่นเอง) เมื่อเรายิงเวทย์ธาตุลมใส่ พลังโจมตีเวทย์ลดลง 25% ครับตามสูตรในลิ้งค์นี้

http://board.onenet.co.th/viewtopic.php?p=133007#133007

เราจะเห็นได้ว่า

ความแรงเมื่อยิงใส่ธาตุน้ำ = floor[ความแรงเกราะศัตรู*สัมประสิทธิธาตุที่แพ้ทางกัน]
จะได้ว่า = floor[50*-1/2] = -25

เมื่อเข้าสูตรหาความเสียหายจะได้ว่า

พลังโจมตีุ = floor[(100+ความแรงที่ได้จากตอนที่แล้ว) * (100+ผลขยายเวทย์ของแสงหรือ/และความมืด) / 100]
พลังโจมตี = floor[(100+-25) * (100+0) / 100]=75% หรือ ลดลง 25% นั่นเองครับ

ส่วนหากธาตุศัตรูมี 2 ธาตุ (หมายถึงรวมพื้นที่ด้วย) จะคำนวณทีละธาตุครับ เช่น เราใช้เวทย์ธาตุลมโจมตีใส่มอนสเตอร์ธาตุดิน 20 พื้นที่ธาตุไฟ 50

ความแรงเมื่อโจมตีใส่ธาตุดิน = floor[ความแรงเกราะศัตรู*สัมประสิทธิธาตุที่แพ้ทางกัน]
ความแรงเมื่อโจมตีใส่ธาตุุดิน = floor[20*(-1/2)] = -20

ความแรงเมื่อโจมตีใส่ธาตุุไฟ= floor[ความแรงเกราะศัตรู*สัมประสิทธิธาตุที่แพ้ทางกัน]
ความแรงเมื่อโจมตีใส่ธาตุไฟ = floor[50*(+2/3)] = +33

เมื่อนำเข้ามาคำนวณจะต้องนำมาบวกกันก่อนนะครับ เป็น = -20 + 33 = +13

พลังโจมตีุ = floor[(100+ความแรงที่ได้จากตอนที่แล้ว) * (100+ผลขยายเวทย์ของแสงหรือ/และความมืด) / 100]
พลังโจมตี = floor[(100+13) * (100+0) / 100]=113% นั่นเองครับ

*หมายเหตุ [ผลขยายเวทย์ของแสงหรือ/และความมืด] จะนำมาคำนวณก็ต่อเมื่อในบริเวณนั้นมีธาตุแสงหรือความมืดอยู่ด้วย หรือมอนสเตอร์มีเกราะแสงหรือมืดด้วยนั่นเอง
