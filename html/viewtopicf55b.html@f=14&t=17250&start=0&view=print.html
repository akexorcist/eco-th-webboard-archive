โดย ECO
มาช่วยเสริมจากประสบการณ์ของตัวเองครับ ซึ่งทั้ง 4 สายของ fighter จะเก่งไปคนละด้านเลย
ตามพื้นฐานของสายอาชีพตัวเองครับ

1. swordman - สมดุลย์ ฟันเร็วกลางๆ ตีแรงกลางๆ และถึกกลางๆ แนะนำให้เล่นสายผสม
2. fencer - ถึกจริงๆ
3. scout - พริ้วมากๆ ตีรัวสุดๆ
4. archer - ยิงไกล วิ่งไปยิ่งไป เน้น step

ซึ่งถ้าต้องการเล่นข้ามสายก็สามารถทำได้ครับ อยู่ที่ผู้เล่นชอบแบบไหน
เพราะบางทีอาจจะชอบพริ้วๆ เลือดเยอะๆ รวมถึง skill ที่น่าสนใจบางอันไม่มีในสายที่ตัวเองชอบ ..... ซึ่งแต่ละอาชีพนั้น จะมีข้อดีที่ได้จากพื้นฐานอาชีพอยู่ และการเล่นแบบข้ามสายก็ทำได้อีกเช่นกันครับ แต่จะไม่ดีเท่าเจ้าของอาชีพเท่านั้นเอง เช่น
- fencer ( AGI ) หลบได้ไม่เท่า scout แต่แทนที่ได้ด้วยเลือด
- scout ( vit ) สายนี้จากที่ได้ลอง หลังจะจะเน้นที่ vit และ agi ครับ ไม่เน้น str ... และใช้ skill พิษในการจัดการ monster
- swordman - ไปทางไหนก้อได้ เก่งหมดเลย
- archer ข้ามสาย นึกไม่ออกครับ เพราะยังงัยก็ต้องเน้น agi ให้ยิงเร็วอยู่แล้ว ( อาจจะไม่เกี่ยวกัน แต่ชุดตอนเป็น gunner เท่ห์ได้ใจจริงๆครับ )
