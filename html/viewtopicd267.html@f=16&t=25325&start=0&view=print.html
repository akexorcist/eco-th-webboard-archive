Healing Tree ดีครับลองแล้วดีกว่ากองไฟเยอะ:D

1.ไม่เสียฟืนแถมเพิ่ม Hp ได้ครั้งละ 50 ถ้าเวล 5 เสียแค่ sp
ถ้าท่านมี Sp Recovery สบายครับ

2.ใช้ฝึก pet ได้ไม่เปลืองไม่ต้องมาคอยจ้องฮีลจ้องฮีล

3.ต้นไม้มันใช้ล่อมอนได้ครับถ้ามอนประเภท Auto เห็นต้น
ไม้ก่อนเรามันจะวิ่งมารุมตีต้นไม้ซึ่งต้นไม้อึดพอสมควรแถมฮีล
ตัวเองได้ใช้เอาตัวรอดได้ดี

4.ปลูกกี่ต้นก็ได้ถ้าเหลือ sp พอแต่ต้องไม่อยู่ในระยะของต้น
เก่าครับไม่เหมือนกองไฟได้ทีละกอง
