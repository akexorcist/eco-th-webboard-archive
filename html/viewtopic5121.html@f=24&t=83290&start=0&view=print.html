ของที่ได้ตอนจบเควส




เมื่อจบเควสจะได้รับเคียว 「○○の鎌」 ทันที ( 1 ตัวละคร 1 ชิ้น )

เมื่อผ่านพิธีสำเร็จการศึกษาแล้ว จะได้รับ ต้นไม้ 「絆の樹」 และ 「○○○・アルマ」
*ต้นไม้ 「絆の樹」 มีทั้งหมด 4 แบบ ซึ่งผู้เล่นจะได้รับแตกต่างกันไปตามจำนวนเนโกมาตะและภูตที่เรียกมา

หลังจบเควสแล้ว ใช้ตั๋ว 「ＥＸイベントチケット」 6ใบ หรือ 7ใบ หรือ 16ใบ
เพื่อแลกหนังสือ พรมแต่งบ้าน 「じゅうたん」 จาก ภูตพิทักษ์ โรเก็ทสึ ได้ (แลกได้หลายครั้ง)

โดยจำนวนในการแลกของมีดังนี้
ของเดือน 1-4 ใช้ 6ใบ
ของเดือน 5-8 ใช้ 6ใบ
ของเดือน 9-12 + ปุรุรุ ใช้ 7ใบ
แลกทั้งหมด ใช้ 16ใบ


(*หมายเหตุ* ○ คือชื่อที่ถูกซ่อนอยู่ และชื่อนี้คือชื่อของมอนสเตอร์ที่มีอยู่ในเกมด้วย!!!)

「ＥＸイベントチケット」 ได้จากการเปิดตั๋วได้ขยะ/สกอ จะแถมมาให้
สามารถหาซื้อในเกมได้ตามโกเลมของผู้เล่นทั้วไป



การดำเนินเควส



1. คุยกับ ภูตพิทักษ์ โรเก็ทสึ ที่ลานน้ำพุอัพทาวน์หน้าโบสถ์ดำ






2. คุยกับ โรเก็ทสึ บนห้องเรียนลอยฟ้า (ตัวเลือกตรงนี้ตอบอะไรก็ได้)






3. ไปที่เกาะไทนี่ ให้คุยเพื่อรวบรวมความทรงจำกับ NPC ที่เกี่ยวข้องกับเควสอัลม่า ตั้งแต่เดือน 1 ถึง 11 ทั้งหมด 11ตัว
โดยเมื่อคุยตัวนึงแล้วจะมีลูกศรชื้ไปหาตัวอื่นๆต่อ ไม่จำเป็นต้องคุยเรียงตามลูกศรชี้ก็ได้ เจอตัวไหนก่อนก็คุยได้เลย
(*ถ้าวิ่งตามลูกศร จะวิ่งวนไปวนมา จากเกาะฟากนึงไปอีกฟาก หลายรอบมาก )





4. กลับมาคุยกับ โรเก็ทสึ บนห้องเรียนลอยฟ้า ให้เลือกตอบ 「はい」 ตามรูป






จบเควสคาบเรียนที่ 12 และได้รับเคียว 「デスの鎌」









พิธีสำเร็จการศึกษา



เงื่อนไข : มีอัลม่าอยู่บนห้องเรียนลอยฟ้าครบ 12 ตัว


เมื่อเงื่อนไขครบแล้วให้คุยกับ เดธอัลม่า เลือกตอบ 「はい」 ตามภาพจะเริ่มอีเวนท์ พิธีสำเร็จการศึกษา






เมือจบอีเวนท์เราจะได้รับ 「プルル・アルマ」 และต้นไม้ 「絆の樹」
ซึ่งต้นไม้ที่ได้รับจะมี 4 แบบ เปลี่ยนไปตามจำนวนของแมวและภูตที่เรียกมาบนห้องเรียนลอยฟ้าก่อนเริ่มพิธีสำเร็จการศึกษา
