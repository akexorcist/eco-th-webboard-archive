Treasure Hunter นี่ ถ้าไม่ใช่สายvitโดยตรงควรจะอัพvit ไว้ซักเท่าไหร่ดี

แบบว่าผมเล่นสายผสมออกจะมั่วๆ ตอนนี้ vit ได้ 50 เลือด 3k นิดๆ(ถ้าได้การ์ดที่ต้องการก็+ไปอีก1k) ถ้าตีเล่นๆอยู่ฟูก็สบายๆ แต่ไม่มั่นใจว่าจะไปตีกับมอนระดับสูงกว่านี้ไหวรึเปล่า

แล้วก็ อาชีพนี้นี่ไปตีวาฬได้ไหมครับ แล้วต้องใช้เวลประมาณไหน


ตีได้ค่ะแต่จะฆ่านานมากกกก
(หญ้าๆๆๆ แล้วก็หญ้า ปิดด้วยกล่อง จักการได้เฉพาะสมเสร็จม่วง เพราะทหารเกราะเดินไม่ตรงหญ้าไม่โดน )

ส่วนตอนที่ไปก็มีหญ้า กล่อง และท่าเพิ่มเดฟแล้ว ก็น่าจะไหวอยู่ แต่อีเอ็กพีก็ไม่ค่อยคุ้มกับเวลาที่เสียไปหรอก

ตอนนี้มนเวล 101 ใช้วิธีลากโฮโลแกรมซักเจ็ด แปดตัว แล้วลงกล่องเอาสองสามทีตาย (วิท100 ใช้ท่าเพิ่มเดฟแล้วโดยทีละ1)
