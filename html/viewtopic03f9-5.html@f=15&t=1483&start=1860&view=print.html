side note เกี่ยวกับ instance:
- ไม่ทราบว่าทุกคนรู้จัก 'instance' กันรึเปล่า เลยจะมาชี้แจงเพิ่มซึ่งเกี่ยวข้องกับเควสนี้โดยตรง สำหรับเควสโบราณสถานทุกอัน จะเป็น quest instance ซึ่ง คำว่า instance นี้ มันเหมือน dungeon ส่วนตัวเฉพาะปาตี้ๆนึงเท่านั้น ทั้งๆที่อยู่ที่เดียวกัน แต่คนละปาตี้ ก็จะอยู่คนละ instance กัน ซึ่งระบบนี้เริ่มใช้กันมากในเกมต่างประเทศฝั่ง U.S. เนื่องจากจะไ่ม่มีปัญหาในการแจม จอง monster จอง boss แล้วยังให้ความรู้สึกได้ตะลุย dungeon มากขึ้นด้วย
เกี่ยวกับ instance สมมุติ ปาตี้ A จะไป dungeon C แล้วเมื่อคนในปาตี้ A คนแรกวาปเข้าดันไป ทางserver จะสร้าง Instance X ขึ้นมาซึ่งคนในปาตี้ A ทั้งหมดเมื่อวาปหลังจากนี้ จะเ้ข้าไปที่ instance X (ซึ่งเป็น dungeon C) ต่อมา ปาตี้B ก็จะไป dungeon C เหมือนกัน แล้วเมื่อเข้าวาปไป ทาง server ก็จะสร้าง instance Y ขึ้นมาสำหรับคนในปาตี้ B ทั้งหมด แน่นอนว่าคนในปาตี้ A กับ ปาตี้ B เวลาแสดงที่อยู่ ทั้งหมดจะอยู่ใน dungeon C แต่ ทั้ง 2 ปาตี้นี้ถึงจะอยู่ dungeon C เหมือนกัน แต่ก็อยู่คนละที่กันและไม่เจอกันเนื่องจากอยู่คนละ instance นั่นเอง
สมมติสมาชิกคนนึงในปาตี้ A เรียกว่า A1 ละกัน วาปออกจาก dungeon C แล้วออกปาตี้ไปเข้าปาีตี้ B แทน เมื่อวาปเข้า dungeon C อีกครั้ง ก็จะไม่เจอคนในปาตี้ A อีกต่อไป เพราะว่าตอนนี้ A1 อยู่ในปาตี้ B จึงถูกส่งไปยัง instance Y แทน


instance ที่ถูกสร้างขึ้น จะมีระยะเวลาเท่ากับระยะเวลาเควส เพราะฉะนั้น ถ้าอ่านข้างบนนี้ น่าจะสรุปได้นะ ^^ (ได้ เนื่องจาก instance ถูกสร้างขึ้นมาแล้ว และยังไม่หายไป)

นอกจากนี้ ยังมีเด็ดกว่านั้นอีก ถ้าคนสร้างอยู่ปาตี้ A เข้าไปสร้างแล้วออกตี้ ไปเข้าปาตี้ B แล้วสร้างใหม่อีกที แล้ว offline ไป ทั้งตี้ A และ B ก็ยังสามารถเข้า instance ได้
