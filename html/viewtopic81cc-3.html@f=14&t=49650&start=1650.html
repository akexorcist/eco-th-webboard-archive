appleshiro เขียน:9 สกิลที่ปรับมีดังนี้ครับ

Warcry -> Cast time, adjusting fainting decision <- ปรับค่าร่าย + ระยะการสตั้นนะ รู้สึก ( เหมือนเคยอ่านเจอว่า จะกว้างขึ้น )
TRANSPORTER -> Consumption SP, adjusting delay time <- ลด SP ที่ใช้ ปรับ ดีเลย์หลังการใช้งาน
Slash combination -> adjusting consumption SP <- ลด SP ที่ใช้
Strike Blow -> Adjusting delay time <- ปรับดีเลย์ใหม่
Disruption -> Adjusting fainting probability <- ปรับโอกาสติดสตั้น
Sword Assail -> Adjusting power revision <- ปรับ ค่า ATK ใหม่
ATK Rand -> Adjusting consumption SP <- ลด SP ที่ใช้
SENNPUUKEN -> Adjusting on-target hit revision <- ปรับจำนวนเป้าหมาย
Vacuum -> Modifying on-target hit decision processing <- ปรับระยะเป้าหมาย ( น่าจะไกลกว่า 3 ช่องแล้วนะ )
