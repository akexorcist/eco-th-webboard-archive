ก็เห็นมีข้อเสนอประมาณว่า "มีปาป้าเทพขอแลก อีมิล +เงิน ... m "

แสดงว่าคนแลกต้องการเผ่าอีมิล แต่ตัวเองมีเผ่าเทพ อยากขอแลกกะคนอื่น ยังต้องให้คนอื่น ให้ตังเพิ่มอีก การให้อีกฝ่าย + ตังเพิ่มก็ทำให้อีกฝ่ายยิ่งไม่อยากแลกไม่ใช่หรอครับ ถ้าแลกกันเพียวๆอาจจะอยากแลกมากขึ้น



แค่น้อยใจแทนปาป้าอีมิลนะครับ ดูเหมือนมีค่าน้อยกว่าทั้ง 2 เผ่าเลย

เล่น + ตังกันซะขนาดนี้ ถ้าอยากได้เผ่าอีมิลมาใช้ ก็แลกเอาเผ่าเทพหรือมารมาแลกเป็นอีมิลกับผู้เล่นด้วยกัน จะได้ + ตังด้วย

ผลก็คือ ได้ปาป้าอีมิลตามต้องการแถมได้ตังอีกต่างหาก
แต่ก็ .. แบบนี้คงตลก เพราะในเซิฟคงมีแต่เ่ผ่าเทพกะมาร แล้วหาแลกอีมิล + ตัง แล้วก็หาแลกได้ยาก ถ้า คนคิดแบบนี้กันหมด
