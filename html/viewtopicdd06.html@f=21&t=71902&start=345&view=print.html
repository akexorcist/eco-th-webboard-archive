ระหว่างที่คาโต้วิ่งตามไปพวกทหาร ก็วิ่งตามมาจากด้านหลัง พอพอกับ dynasty warriors
"ง่ะ เห้อ หมดแรงแล้ว ท่าจะสู้ไม่ไหว ส่วนรูน(ไอ้เด็กหัวขาวตบกับคาโต้)ก็ดดนสูบเวทย์ไปหมด งั้น มันต้องนี้ ยาแดงแรงสามเท่า"คาโต้หยิบขวดยาที่มีเขาสีแดงติดอยู่ออกมาแล้วกินไปสิบเม็ด
พอคาโต้กินเสร็จก็มีระเบิดควันออกมา พร้อมเผยให้เห็นถึง คาโต้ ที่กลับกลายเป็นเด็ก มีผมยาวถึงกลางหลัง เส้นผมสีชมพู ทำให้เด็กชายที่ยืนอยู่ข้างๆ งง เป็นไก่ตาแตก
"ปรากฏ กาย ฮ่าฮ่า รออยู่ตรงนี้นะ Clamp"(คาโต้ตอนเด็กรั่วนะ)[Clampเป็นใครไปหาดู ใน กินทามะ ตอน ร้อยเจ็ดสิบเอ็ด ไม่ก้ไปย้อนดูกันดั้มภาคหนึ่ง เอาเดี๋ยวรู้เอง]พูดเสร็จคาโ๖้ พุ่งตัวเข้าไปด้วยความเร็ว สามเท่า แล้วคาโต้ก้เรียกดาบออกมาหนึ่งเล่มพร้อม ฟันไป ในระหว่างที่ฟันอยู่
"Clamp เนี้ยใครกัน"รูนทำหน้างงแล้วพูดออกมา ไม่ทันไร พวกทหาร ก็กองเป็น ภูเขา
"จงจำไว้ ในสนามรบ อย่าประมาถ เด้ด ขาดไม่งั้นนายได้กลายเป็นศพแน่" คาโต้(เด็ก)หันไปพุดกับรูน ที่ยังงงๆอยู่
"เอาล่ะไปกันได้แล้ว"คาโต้พุดเสร็จก้วิ่งตรงไปทางจัสท์แล้วกระโดดไปเกาะ จัสท์
"ไงจัสท์คุง"คาโต้(เด็ก)ทักด้วยสีหน้ายิ้มแย้ม
