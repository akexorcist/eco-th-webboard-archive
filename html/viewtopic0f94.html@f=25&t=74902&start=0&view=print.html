ห้องรีจิส - คุยกับลีดเดอร์(โดมิถือปืนในห้องมั้ง)
บ้านบราฟรุสกี้(วัน/คืนก็ได้) - เข้าไปทางด้านซ้ายของถ้ำแล้วคุยกับเด็กหนุ่มปริศนา(ตรงนี้มีเขียนเหมือนต้องโจมตีไรซักอย่างด้วยแต่อ่านแล้วไม่เข้าใจ- -)
เกาะวอร์ชิป(กลางคืน) - ไปคุยกับภูตแห่งความมืด จากนั้นให้คุยกับนาจิโตะ(นาจิท??ไม่แน่ใจชื่อ) แล้วภูตให้ความมืดจะทำไรเราซะอย่างเลยเหลือHP1 ควรระวังมอนแอคทีฟด้วย
เวสฟอร์ต - หาถังขยะ(อยู่ใกล้ๆเสา5) จะได้พิณที่แตกหักมา
เกาะวอร์ชิป(กลางคืน) - คุยกับนาจิโตะ
เวสฟอร์ต - ไปคุยกับนักดนตรีเรเร่อน(ไม่แน่ใจเรร่อน)ที่ประตูทิศใต้(เอาไม้ กาว กระดาษทรายไปอย่างละอันด้วย)เขาจะซ่อมพิณพังที่ได้มาตอนแรกให้
เกาะวอร์ชิป(กลางคืน) - เอาพิณไปให้นาจิโตะ
เวสฟอร์ต - ไปหาเด็กดูงานรีจิตแทนซ์ใต้บันได(ห่ะ???)แล้วก็ไปที่ห้องตัดสิน(???)ทางคนละด้านกับร้านขายของ คุยกับพ่อค้ามืดแห่งคุสก้า(ของงอีกรอบ- -) จะได้นาฬิกากระเป๋าของนาจิโตะมา(จะมีชอยส์ที่ต้องเสียตังให้เลือกตอบแต่เลือกอันไหนก็ไม่ต้องเสียอยู่ดี)
เกาะวอร์ชิป(กลางคืน) - เอาไปให้นาจิโตะ จะได้แผนที่มา
เวสฟอร์ต - ไปที่เสา6ทางเหนือออกของแมป(ถ้าใช้แผนที่โบโระโบโระมันจะโชว์แมปอื่นให้แทน(ห่ะ???))ไปที่ที่คุยกับมิอุได้(ตรงนี้ไม่แน่ใจว่าต้องทำไรกับแผนที่ซักอย่าง เหมือนจะกดใช้)แล้วก็คุยกับมิอุ
บ้านของ??? - เราจะถูกวาปไปอัตโนมัติ พอคุยกับมิอุเสร็จให้จับผิดเหมือนตอนทำแมวแฝด(ตัวถูกจะอยู่ในห้องนอน) พอเลือกตัวถูกได้แล้วคุยกับมิอุอีกครั้งก็จะวาปไปทะเลทรายนรก
เวสฟอร์ต - ไปคุยกับชายที่บาดเจ็บตรงประตูด้านเหนือ จะได้กล่องสกปรกๆมา
เกาะวอร์ชิป(กลางคืน) - ไปคุยกับนาจิโตะแล้วเอากล่องสกปรกกับแผนที่ให้นาจิโตะไป
เวสฟอร์ต - ไปคุยกับดร.ชูไทน์แล้วชมคุกิ จะได้ชูไทน์บ็อกซ์มา
ในโลกโดมิ - กดใช้กล่องที่ได้มารวบรวมจิตวิญญาณของนาจิโตะ(สถานที่ที่กดได้ก็มีเวสฟอร์ต เกาะวอร์ชิป หอคอยฝั่งโดมิ(ไม่แน่ใจ) ทะเลทรายนรก)
เกาะวอร์ชิป(กลางคืน) - เอากล่องไปให้นาจิโตะ (ตรงนี้มีเตือนอะไรซักอย่างเกี่ยวกับอันซึแล้วก็แมวแฝด แต่อ่านไม่เก็ทง่ะ-0-)
เวสฟอร์ต - ไปคุยกับดร.ชูไทน์ (คุยแล้วจะได้อะไรซะอย่าง อ่านแล้วงงขี้เกียจแปล-0-)
เกาะวอร์ชิป(กลางคืน) - คุยกับนาจิโตะ ตัวเราจะหมดสติไป(???)
เวสฟอร์ต - ไปคุยกับราโตะ(ลัท?)กลางแมปจะได้จดหมายถึงน้องสาวมา
