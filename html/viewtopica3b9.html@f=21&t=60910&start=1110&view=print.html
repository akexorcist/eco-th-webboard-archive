SS : ถ้ามันมีเหตุจำเป็นจริงๆก้อต้องรัฟังดูก่อน แต่ ถ้าไร้เหตุผลจริงๆ "ฆ่ามัน!!"

3. ถ้าคนรัก มาอยู่ตรงหน้า ในฐานะของ ศัตรู อีกเช่นกันจะทำยังไง

SS : หะ คนอย่างเราจะมีโอกาสมีคนรักด้วยหรอ ถ้ามีจริงๆ เปลี่ยนฝั่งโลด

(ตอบตัวเองก็ได้นะ)

5.ถ้าสามารถเลือกคู่ต่อสู้ได้ อยากให้ตัวละครของคุณสู้กับตัวละครตัวไหนมากที่สุด เหตุผล
