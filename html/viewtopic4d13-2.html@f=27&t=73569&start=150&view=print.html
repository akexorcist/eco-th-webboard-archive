อันนี้ขอฝากเตือนไว้หน่อยนะ

เนื่องจากว่า ECO ไทย จะทำการ Update เป็น Iris

คาดว่าไฟล์ mod ที่ทำไว้ เฉพาะพวก pri-itempict.csv นั้น จะมีปัญหา

เพราะว่า ไฟล์ที่ทำการดัดแปลงนั้น ตัว itempict.csv เป็นของเก่า

เมื่อ eco ไทย update มันจะเป็นตัวใหม่

ซึ่งจะมีพวก item ใหม่ๆ เข้ามาด้วย ทำให้ตัว itempict ของเก่านั้น ไม่ควรนำมาใช้อีกแล้ว

เพราะอาจจะทำให้มองไม่เห็นไอเท็มใหม่

สรุปก็คือ ไม่ควรโหลดไฟล์ที่เกี่ยวข้องกับไฟล์ .csv ไปก่อนระยะนี้

ไว้เมื่อมีเวลาอาจจะทำการ update เปลี่ยนตัว itempict.csv ใหม่และทำการเปลี่ยนใหม่อีกครั้ง

แต่ก็นะ ... เมื่อมีเวลาเท่านั้นจริงๆ ขออภัยด้วย

ส่วนไฟล์ ที่ใช้การทับ ( .txt .mrb .tga ) พวกนี้ไม่ค่อยมีส่วนสักเท่าไหร่ เพราะใช้หลักการ
เขียนทับไฟล์ไปเลย ไม่ได้ไปแก้รหัสใน itempict


สรุป : หลังจาก eco ไทยอัพเดตเป็น iris ควรเล่นปกติไปก่อน หรือถ้าอยากจะใช้ก็ควร Copy เผื่อไว้ก่อนมีปัญหา อย่าหาว่าทางเราไม่รับผิดชอบเน้อ เพราะเตือนแล้วนะ
(ก่อนใช้งานควร backup ไว้ก่อนเสมอ)

เหตุผล : itempict เก่าที่ใช้ทำ mod มันเป็นแค่ของ eco ไทย รหัสต่างๆ ในนั้นเลยเก่า
เมื่อ iris เข้า หมายความว่า itempict จะถูกเปลี่ยนใหม่ เพิ่มรหัสใหม่ต่างๆ เข้าไป
ถ้าต้องการชุดที่ถูกเปลี่ยนรหัส ก็ต้องทำใหม่หมด แค่นั้นเอง

ปล. น่าจะใช้ itempict ของญี่ปุ่นซะตั้งแต่แรกแหะ แต่เพราะตอนนั้นยังไม่รู้อะไรมาก

ปล2. บ่นมาเยอะล่ะ ขอตัวก่อนนะครับ ... ช่วงนี้มีสอบเลยพยายามจะไม่เข้ามาเท่าไหร่
แต่มาตอบส่วนนี้เพื่อความปลอดภัยของผู้ที่ใช้ mod (เผื่อบางคนอัพ patch เสร็จแล้วดัน rebuild ทำให้มองไม่เห็นของแล้วจะไปตั้งกระทู้... )

ปล3. ถ้าเป็นไปได้ อยากให้โหลด eco ตัวใหม่มาลงใหม่แล้วก็โหลด patch iris ทีเดียวเลย
( กรณีเกิดปัญหาหลายๆ อย่าง นี่คือทางเลือกสุดท้าย)

เพิ่ม Edit : ไม่ใช่แค่ itempict หรอกนะ จำพวกไฟล์ที่อยู่ใน folder xls ทั้งหมดเลยล่ะ
( monsterpict , marionet ฯลฯ )

ปล4. พอเห๊อะ ... ไปอ่านแคลคูลัสล่ะ ปีนี้จะจบไหมเนี่ย...
