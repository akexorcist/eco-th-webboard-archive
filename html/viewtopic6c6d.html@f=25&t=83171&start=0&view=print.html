วิธีฝึกเพ็ทแตกต่างกันไปตามอาชีพค่ะ จะขอเแนะนำทางปกติค่ะ

เริ่มเเรกจะต้องฝึกกับพวกสกอไปก่อนค่ะ
เมิ่อเพ็มเริ่มเก่งขึ้น โจมตีเต็ม / เลื่อดเยอะ เอาไปให้มอนรุมในที่ฝึกเพ็ท อินฟินิต กับ สนอป ค่ะเพราะแถวนั้นมอนจะเยอะ
พอสเตเตัสที่เหลือเริ่มเต็ม ลุยเดี่ยวบอสของที่ฝึกสัตว์เลยค่ะ

อาชีพที่เเนะนำคือ พระที่สวมเข็มบรีด เพราะว่าสามารถฮิลเพ็ทตอนมอนรุมหรือตอนสู้บอสได้ค่ะ
ถ้าไม่มีพระขอให้เตรียมอาหารเพ็ทไปเยอะหน่อยค่ะ นอกจากนี้อย่าลืมเตรียมแครอทฝึกเพ็ทไปด้วยนะคะ จะช่วยประหยัดเวลาขึ้นเยอะเลยค่ะ
วิธีนี้เป็นเพียงแค่วิธีฝึกเพ็ทวิธีเดียวเท่านั้น ยังมีวิธีฝึกเพ็ทอีกหลายวิธีค่ะ
