จากประสบณ์การล่าบอส มา6-7เดือน ทุกวัน วันละ6-18 ช.ม เท่าที่พอจะรู้
1.เลลเวลห่างเกินบอส20เลลเวล มีผลต่อการดรอปของบางชนิด จากบอส เช่น เหรียญไทนี่Label จากบอสหมี <ถ้าล่าบอสแล้วอยากได้ของพวกนี้ เอาตัวเลลเวลประมาณมะเกิน52-55ไปด้วย รับรองดรอปเกือบทุกรอบ>อีกตัวอย่าง เอาไนท์เลลเวล30ไปตีบอสไก่ เจอ ตีไปแค่3-4ที ที่เหลือคนอื่นตีแต่เลลเวลสูงๆกันทั้งนั้น ปรากฎว่าของที่ตก เราเก็บได้ จะเปิดก่อนหรือเปิดทีหลัง ผลก็ออกมาแบบเดียวกัน
2.EXP เมื่อคุณเก็บเลลเวลจนถึงขึ้นที่ว่าคุณเลลเวล80กับอีก99.9เปอ แล้วคุณได้exp 0
ล่าสุดเอาเบรดเลลเวล80กับอีก99.9เปอ ไปตีบอสไทนี่ เข้าเปิดก่อน ตีก่อนแท้ๆ บอสกำลังจะตาย พอแอสเลลเวล75มาฟันที2ที แตมป์ไทนี่ตก แอสดันเป็นคนได้ของไป เพราะผมได้expจากบอส 0 <ก่อนหน้านั้นเอาตัวเบรด ไปลดเปอร์exp ตลอด เพื่อที่ว่าจะได้exp เวลาตีบอส ตีบอสทีไรตีตามปกติ เปิดก่อน ตีเยอะกว่า ได้ของทุกรอบ>
ปล. ที่กล่าวมาข้างต้น ไม่ได้เกิดขึ้นแค่ครั้ง2ครั้ง อย่างข้อ2ก้ได้ทดลองหลายๆรอบ ว่าการได้exp0นี่มีส่วนไหม จากการสังเกตุเวลาขยะจากบอสตก แล้วเราเก็บได้หรือไม่ได้
