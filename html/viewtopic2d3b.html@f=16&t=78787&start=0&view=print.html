เอ่อ havest เท่าที่เรารู้ บางแห่งบอกว่ามีสกิล สร้างพืชขึ้นมาคลุมร่างตัวเอง แล้วสามารถสะท้อนดาเมจได้ โดยที่เลเวล max สามาถสะท้อนได้ 90% โดยมีโอกาสเพียง 35% นี่คือสกิลไฮไลท์เลยแหละเราว่า


สกิลอื่นๆ ส่วนใหญ่เป็นสกิลสำหรับปาตี้ เช่น เพิ่มค่า max capa ให้กับทุกคนในปาร์ตี้


อ้อลืมไป เหมือนกับจะมีสกิลสำหรับตัวเองอีกสกิลนึง เราชอบมากเลย มันจะทำให้ตัว Havest เองสามารถโจมตีดูดเลือดได้ โดยไม่เกี่ยงว่า เป็นการโจมตีทางกายภาพหรือเวทย์มนต์ แต่เราไม่รู้ว่า มาริคิงจะใช้ดูดได้รึปล่าวนะ เพราะตัวมาริเองไม่ได้เป็นคนโจมตี แต่ถ้าสิงเอเล ให้เอเลดูดได้ละก็ อึดขึ้นอีกเป็นกองเลย ^0^
