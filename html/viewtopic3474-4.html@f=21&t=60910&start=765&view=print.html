ร้านขนมที่หมดกับมันมาเยอะ

1. จุดเด่นของตัวละคร :
อยู่ที่ตัวละครตัวนี้จะทำอะไรๆก็ต้องเป็นสิ่งที่ดีไปเกือบทุกอย่าง ไม่ชินกับความรุนแรง (เพราะมีประวัติฝังใจมาตั้งแต่เล็กๆ) เวลาเจอของพวกนั้นเลยกลัวไปหมดทุกอย่าง


2. ที่มาของตัวละคร :
จากชื่อตัวละครในเกมส์อีโค่เนี่ยแหละ - -/


3.เปิดอก กันนิดนึง อยากให้ตัวละครของตัวเอง ได้คู่รักแบบไหน :
เป็นมนุษย์ที่คุ้มครอง ปกป้องผู้คนจากอันตรายได้เสมอ สร้างเสียงหัวเราะและทำให้เธอมีความสุข (หน้าตาดีมากๆนี่สำคัญ กร้ากกกกก)


4.ตัวละครที่คิดว่าจะเป็น คู่ปรับของตัวละครของคุณคือใคร เพราะอะไร :
ไม่คิดว่าน่าจะมีแต่ถ้ามีก็น่าจะเป็นพวกที่บ้าความรุนแรง การฆ่าฟันและคนที่ชอบความตาย...


5.ถ้าจะตั้ง ฉายา ให้ตัวละครของตัวเอง คิดว่า ฉายานั้น คืออะไร (เจ้าวอก, หนอนหนังสือ , บ้าแมว etc) :
- เนโกะจัง
- ฮาร์ป รอยัล


6.ถ้าวันนี้เป็นวันปิด ฟิคชั่น เรื่องนี้ อยากให้ตัวละครทำอะไร :
ให้ตัวละครแต่งงานกับคนรัก


7.สิ่งของที่สำคัญที่สุดในตัวละครของคุณคืออะไร :
พิณ


8.สุดท้ายและท้ายสุด คาดหวังอะไรกับ ฟิคชั่นเรื่องนี้กัน :
หวังว่าเจ๊จะหาคู่ให้ตัวละครตัวนี้ 555+
