No comment ... สำหรับเรื่องที่ว่าจะปิด

แต่เรื่องของสัญญามันก็มีหลายแบบนะครับ ไม่ใช้ทำว่าจะทำสัญญาเป็นปีกันเสมอไป อาจทำสัญญากี่ปีก็ได้แต่รายได้จะต้องไม่ตำกว่า ... (ตามที่กำหนด) ... อะไรประมาณนี้ก็มี และตัวสัญญายังมีข้อแม้ต่าง ๆ มากมาย ไม่ใช่ว่าแค่หมดสัญญา ... (ตามที่กำหนด) ... ปีแล้วจะต้องยกเลิกการให้บริการนะครับ อาจมีข้อยกเว้นอย่างว่า "หากมีรายได้มากกว่า ... (ตามที่กำหนด) ... จะทำการต่อสัญญาฉบับนี้ไปอีก ... (ตามที่กำหนด) ... ปี" ก็จะกลายเป็นว่าสัญญานี้ตราบเท่าที่มีรายได้ส่งให้เจ้าของลิขสิทธิ์ ตามจำนวนที่กำหนดไว้ในสัญญา ก็จะไม่ยกเลิกอย่างแน่นอนยังไงล่ะครับ

แต่ถึงอย่างนั้นก็อาจมีข้อแม้ในเรื่องต่าง ๆ ที่ทำให้สามารถยกเลิกสัญญาได้ในทันทีเหมือนกันนะครับ แต่เห็นอยู่มานานแล้ว (ตั้งแต่สมัย Ra.... ดังเป็นพลุแตก จนตอนนี้ดับเกือบจะมอดไปแล้วด้วยซ้ำ) ก็คิดว่าคงไม่มีปัญหาอะไรนะครับ

ปล. เรื่องในสัญญาเป็นเรื่องของบริษัทนะครับ ลูกค้าอย่างเรา ๆ ไม่สามารถล่วงรู้ได้ ถ้าจะปิดคงจะประกาศก่อนอย่างน้อย 1 เดือนล่ะครับ (คงไม่ประกาศวันนี้ปิดเอาพรุ่งนี้นะครับ เซอร์ไพรท์ แบบนี้ไม่ขำ ==)

Edit : OK ครับ ช่วยให้ความร่วมมือปล่อยกระทู้ตกตามที่คุณเอกบอกด้วยนะครับ จะได้จบเรื่องกันซักที ท่าน GM ก็ออกมายืนยันแล้วด้วย ==
