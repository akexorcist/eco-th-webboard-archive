ตอนนี้ผม เวล/จ๊อบ = 95/47 อาชีพคาบา
ผมอยากรู้ว่าเวลที่ไหนดี ให้เวลและจ๊อบขึ้นเยอะๆ
หรือจะทำเควสก็ได้
บางคนบอกว่าเวลฟู 1 ชม. ขึ้น 10%
เวลดัน 3 ชม. ขึ้น 10% เท่ากัน เพราะ ต้องแบ่งเปอร์กัน
ผมอยากจะเวลดันวาฬเพราะตีตัวนึงขึ้น 1.0 % เลย แต่ไม่มีคนพาเวล
เข้าเรื่องเลยนะครับ
1.เวลที่ไหนขึ้นดีที่สุด (ขอวิธีไป)
2.ผมอยู่เซิฟ โมจิ อยาก จะหาคนพาเวล ดันวาฬ หรือ ดันช้าง ก็ได้

ดันปลาวาฬเหมาะสำหรับเวลเป็นปาร์ตี้นะครับ ถ้าจะไปต้องหาเพื่อนไปด้วย

เก็บคนเดียวลำบาก ส่วนดัน 70 ถ้าไปลากก็เร็วเหมือนกันแต่ต้องดูตัวดูดด้วย

ถ้าไปลากดัน 70 ผมว่าไปลาก 80 ดีกว่าครับ

แต่ถ้าไม่อยากลาก หรือ มีแต้มเควสไปทำเควสที่ฟูด้วยก็ดีครับ

เลือกเอาเวลเยอะกว่านะครับ คุ้มกว่าส่งแอปอีกนะ
