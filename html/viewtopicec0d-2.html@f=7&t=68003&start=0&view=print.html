คนผิดผมไม่รู้หรอกนะครับ ผมรู้แค่ว่ากฎคือกฎ

แต่คุณเคยบอกเขาเรื่องนี้หรือมีใครเคยบอกไหมเรื่องกฎน่ะ ก่อนที่จะให้บูสไป คำว่าแจกคือให้

ให้ไปเลยจะมาเอาคืนได้ยังไง? ล่ะอีกอย่าง ผมคิดว่าคนที่ให้ควรไปคุยด้วยตัวเองนะครับ

ไม่ใช่ผ่านคนกลาง ใครๆก้อาจจะคิดได้ล่ะครับ ว่าอยากได้เอง เรื่องนี้ต้องให้เขา 2 คนตัดสินกันเองนะครับ

เพราะถึงจะไปแจ้ง gm ไงก็เอาผิดไม่ได้เพราะแจกไปเอง ไม่ได้โกง หรือบังคับ ข่มขู่ ให้ซะหน่อย

ถ้าหัวริงคุณอยากได้จริงๆก็ให้เขาคุยกันเอง จบ~

กรณีนี้ ผมว่าให้หัวริงไปคุยเองจะดีกว่าครับ


มันก็ต่างคนต่างคิดอ่ะครับ ทางเค้าเองก็อาจจะคิดว่า

ถ้าให้คุณไป คุณก็อาจจะชิ่ง แล้วโบ้ยความผิดให้เค้า

( แต่ถ้าเค้าหลีกเลี่ยง หรือหลบหน้า คนในริง นั่นอีกเรื่องอ่ะนะ << อันนี้ถือว่าตั้งใจเข้าริงเพื่อเอาบูส แล้วสบโอกาสชิ่งหนี )


ในฐานะคนกลาง เราก็คงได้แค่บอกเค้าเรื่องฏกของริงอ่ะครับ

แต่เราคงไม่มีสิทธิ์ ทวง

แล้วผมก็คิดเหมือนคุณ (ps)smart อ่ะ ความหมายของคำว่า "แจก" เนี่ย คือ ให้ไปเลยอ่ะครับ
