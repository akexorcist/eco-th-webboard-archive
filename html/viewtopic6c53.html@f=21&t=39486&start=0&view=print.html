ผมวาดรูปไว้นานแล้ว แต่ไม่ได้เอาลงซักที เพราะยุ่งมากๆครับ ช่วงปิดเทอมนี้ก็เลยขนรูปมาลงไว้เลย เหอๆ

ปล. ช่วยคอมเมนต์ให้ด้วยนะครับ เพราะผมอยากรู้จุดเด่นจุดด้อยของตนเองเพื่อไปปรับปรุงงานครับ



อันนี้เป็นรูปส่งประกวด "กิจกรรมภาพนี้เพื่อพ่อ" ของ Onenet ครับ ได้รางวัลรองชนะเลิศที่ 2 (พูดง่ายๆ ก้อคือที่ 3 อ่าแหละ = ='') ได้รางวัลเป็นหนังสือคู่มือกะเสื้อ ECO (เสื้อตัวใหญ่จังอ่า ToT)

ความจริงแล้วรูปนี้ลงสีไม่เสร็จครับ จะต้องมีเนโกะมาตะโมโมะกะไอจังอยู่ข้างๆพ่อกะลูกครับ แต่ทำไม่ทัน ก็เลยไม่ลงสีมันซะเลย 55+ (ปัจจุบันก็ยังไม่ได้ลง = ='')
