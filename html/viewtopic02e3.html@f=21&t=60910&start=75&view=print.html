ใส่เสื้อเอวลอยมีลูกไม้และภู่เล้กน้อย แล้วทับด้วยเสื้อกั๊กสไตล์ คาวบอย (กระเป๋าคอปก ฯลฯ) สีแดง ใส่กางเกงยีนต์ หรือ สแลคขาว (เกงขายาวนั่นล่ะ)

รองเท้าที่ใส่เป็นรองเท้าสเก็ต (ชอบทำอะไรคนเดียวจึงเน้นความคล่องตัว) สวมแว่นสไตล์ Cell Frame (ทรงสี่เหลี่ยมผืนผ้า)

ลักษณะนิสัย : [ * สำคัญที่สุด !! ... เจ๊สับเละ !! ]

ไม่ค่อยที่จะแสดงอารมออกทางสีหน้า เนื่องจากเคยชินกับความโดดเดี่ยว จึงทำให้มีสัมพันธภาพกับคนอื่นค่อนข้างยาก

ด้วยเหตุนี้จึงมักใช้เวลาส่วนใหญ่ไปกับการอ่านหนังสือ ตำราต่างๆ จนหยั่งกับว่าเธอเองเป็นห้องสมุดเคลื่อนที่ยังไงยังงั้น (แต่มีต้องคีย์ในการถามซักนิดถึงจะนึกออก)

ถึงแม้ว่าจะเป็นคนที่ไม่ค่อยแสดงอารมณ์ แต่ลึกๆ อยากให้มีใครซักคนที่คอยเอาใจใส่

ถึงแม้จะเป็นคนเส้นลึก แต่ถ้าได้คุยกับคนที่ตนเองเปิดใจคุยด้วยแล้ว

ก็จะเหมือน สาวน้อยธรรมดา คนหนึ่ง เนื่องจากเธอแสดงอารมและพูดได้ไม่เก่งนัก

ในบางครั้งอาจจะถึงกับไม่พูดอะไรเลย หรือมไม่ก็ แสดงอาการระเบิดออกมาอย่างน่าตกใจ (โดนแหย่จนบอม ใครอยู่ใกล้ตาย)

หากพูดกับเธอไม่ถูกวิธีหล่ะก็ อาจจะไม่ได้เข้าใกล้เธออีกเลยทีเดียว

ถ้าหากไม่นับเรื่องการอ่านหนังสือแล้ว เธอค่อนข้างเป็นพวก ที่ใช้ชีวิตสบายๆ ไม่เรื่องมาก

เธอจึงไม่ค่อยขัดคอ หรือ ขัดใจ คนอื่นซักเท่าใด แต่หากเธอละวางหนังสือเมื่อใด อาจจะได้เห็นตัวตนอีก แบบของเธอก็เป็นได้

อาวุธ : [ จะให้มันมีเอกลักษณ์ยังไงก็ได้ แต่ขอให้อยู่ในขอบเขต ! อย่าให้มันเว่อมากก็พอ ! โอเค๊ ? ]

Dimention Word : เป็นหนังสือ ที่สืบทอดกันมาของตระกุล โดยภายในจะแบ่ง เป็น 2 ส่วน

คือส่วน วิชาเวทย์ และส่วนพันธะสัญญา ซึ่งจะมีสัญลักษณ์ แห่งธาตุทั้ง 6 ติดอยู่

และตัวหนังสือ เองก็มีความหนักมากด้วยสิ ? (ทุบคนคอหักได้)

Eastern Sea : ดาบที่เรียวเล็กจนดูคล้าย กระบี่ (Rapier) ถูกประดับไปด้วย ซัพพลาย ตัวดาบไม่มีคุณสมบัติพิเศษอะไร

แต่มันคือขของดูต่างหน้า แม่ของเธอ

ความสามารถพิเศษ ( Versus ) : [ เรียกอีกอย่างว่า `Skill` หมายความว่าเป็นทักษะพิเศษที่นอกเหนือจากอาชีพของตน ! ใส่มาเท่าที่อยากจะใส่ ]

Elemental Spirit : เรียกภูติ ธาตุต่างๆ เพื่อทำการช่วยเหลือ ในสิ่งต่างๆ ซึ่ง จะมีจุดเด่นต่างกันตามลักษณะ ธาตุ ดังนี้

ไฟ - เด่นด้านการโจมตี / ลม - เด่นด้านความเร็ว / น้ำ - เด่นด้านการฟื้นฟู / ดิน - เด่นด้านการปกป้อง

แสง - เด่นด้านการช่วยเหลือ&รักษา / มืด - เด่นด้านการก่อกวนและคำสาป

โดยมีทั้ง ประเภท เสริมความสามารถ ต่อสู้ และ สนับสนุน ตามแต่ ภูติที่ทำสัญญา

ซึ่งจะต้องทำให้ภูตินั้นยอมรับ ผู้ทำพันธะ เสียก่อน จึงจะใช้งานได้ ซึ่งแบ่งเป้นหลายระดับ

หมายเหตุ : เรียกได้มากกว่า 1 แต่นั่นหมายถึง เสียพลังเวทย์มากขึ้นนั่นเอง

Enchant : ผสาน เวทย์ 2 ธาตุเข้าด้วยกัน ทำให้เกิดเวทย์ที่มีลักษณะพิเศษเฉพาะตัว

หมายเหตุ : ไม่สามารถผสาน แสง และ ความมืดได้



ความสามารถพิเศษ ( Other ) : [ ความสามารถพิเศษที่ไม่เกี่ยวกับการต่อสู้ อาทิเช่น กินจุ อะไรประมาณนั้น =w=/ ]

เส้นลึก : ไม่มีการตองสนองต่อมุกแป๊กใดๆ

Bomp !! : เมื่อถูกแหย่มากๆ จนอาย จะเกิดอาการ สติแตก ยิงไม่เว้นหน้าอินทร์หน้าพรหม

หนอนหนังสือ : อ่านหนังสือได้ทุกที่และทุกเวลา แม้อยู่ที่มืด

ฮิคคิโคโมริ : สามารถ อยู่ที่ใดที่หนึ่งได้เป็นเดือนๆ โดยไม่ออกไปไหน (หากอาหารไม่หมด)
