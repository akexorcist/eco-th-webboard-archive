แอสสายพิษมีข้อเสียตรงที่ว่า
หากมีการวางกับดักหรือพิษดักที่ทำให้แอสพิษไม่สามารถพิษได้
ก็ลำบากแล้วครับ
การที่แอสพิษจะเข้าโจมตีได้คือการเข้าประชิดตัวแล้วพิษ
หากเราวิ่งออกจากพิษก็จบ
แอสพิษจะแพ้การโจมตีระวังไกลเช่นเวทหรือกันเนอร์ยิงใส่ไปเลย
แต่แอสพิษก็หลบดีแล้วก็ถึก ระวังช่วงดำดินเข้ามา
สรุปคือ แอสพิษถ้าให้เล่นเป็นโล่แล้วคนสิงยิงจะดีมาก
หากจะบู้เองแล้วละก็ไม่ค่อยจะดีสักเท่าไหร่
ถ้าอยากเล่นแบบมันส์ๆฆ่าไวๆก็ต้องแอสสายมีดกะหมัด
แต่สายหมัดจะเวลดีกว่าไวกว่าไม่เก่งทางด้านpvp สักเท่าไหร่สกิลร่ายช้า
^^
