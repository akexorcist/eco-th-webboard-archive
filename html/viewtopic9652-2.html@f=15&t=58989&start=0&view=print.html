น่าจะมีการทดสอบสกิลจำพวก limit นะ

ถ้าให้ผมเดา กดอัพไป เต็มเวล5 (รึเปล่า ไม่แน่ใจ) ก็อาจจะได้ธาตุน้ำ 50%
พอใส่สกิลเกราะน้ำเสริมเข้าไปอีก ก็คงจะกลายเป็นธาตุน้ำ 100% เลย

เหมือนกับ เล่นเอเล แปลงมาริโอเน็ตเป็นนิม ก็จะได้ธาตุลม 50%
เสริมเกราะลมไปอีก ก็ 100% ทำให้โดนเวทลม 0 ตลอด (แต่แน่นอนว่าโดนดินแรงขึ้น)


แต่ถ้าคิดว่าขี้เกียจแปลงร่าง อัพ limit ไปก็คงแทนการได้ธาตุจากมาริโอเน็ต ล่ะมั้ง ?

ปล. เกมส์นี้ข้อมูลน้อย(ถึงน้อยมาก) และคงไม่มีใครทดสอบ เพราะคงไม่อยากรีสกิลกัน
(ผมอยากลองอัพนะ แต่รีสกิลฟรีไปแล้วเมื่อสมัยเวลตัน 65)
