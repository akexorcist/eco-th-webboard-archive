ผมลองโหลดของตัวเองดู แล้วเปิดไฟล์ดู มันก็มีครบนะครับ

มี pri- ทุกอัน = มันจะเข้าไปใส่ data eco ไทย ทำให้เห็นตัวใหม่ๆ ทั้ง 3 ตัวนั้น

( DEM ถือปืน , DEM แมงมุม , อีมิลคน )

โดยทั้ง 3 ตัวนั้นรหัสคือ 1471 , 1470 , 1477

ซึ่งก็ หยิบไฟล์เฉพาะ ทั้ง 3 ตัวนั้นมาครบแล้วนะ ไม่น่าเกิดปัญหาได้

( anim.dat = folder การแสดงท่าทาง : attr.dat = folder เรียกไฟล์ )
( mrb.dat = folder ตัว 3D (ร่างกาย) : tex.dat = folder สี พื้นผิว )

ถ้าทั้ง 4 folder นั้น มีรหัส 1471 1470 1477 ทั้ง3ครบ และมี pri- ทุกตัว เวลา rebuild
ก็น่าจะเห็นนะ

@loucifer@ เขียน:ได้ละขอบคุณมากครับอิๆ
แล้วแก้อีโมนี่ไปที่ไหนอ้ะครับ
กะเอามอนเตอร์มาเป็นมาริทำวิธีเดียวกันป่ะครับ(ตะกี้ทำไม่ได้ )



แก้อีโม ก่อนอื่นก็ search รหัส emo นั้นๆ มาดูก่อน ว่ารหัสเต็มๆ อะไร

เสร็จแล้ว emo นั้น แยกเผ่าหรือไม่ ถ้าแยกเผ่า ก็ใส่ให้ครบตามเผ่า (อันนี้ไม่ยืนยัน 100% เพราะไม่เคยทำ emo เฉพาะเผ่า)

แล้วก็ search หา emo ที่ต้องการ มา rename เพื่อ "ทับ" (ย้ำว่า ทับ นะ อย่าลืม backup ด้วยล่ะ)

ทำเสร็จแล้ว (อย่าลืม pri- ) เอาไปไว้ที่ anim.dat

ที่ folder chara

แต่ถ้าไม่มีการเปลี่ยนแปลง ก็ลองเอาไปไว้ที่ chara2

แก้มอนเตอร์ กับ มาริ ใช้วิธีเดียวกันกับเปลี่ยน item นั่นคือแก้รหัส

เพียงแต่ไฟล์ที่เปิด มันคือ monsterpict กับ marionettepict นี่ล่ะมั้ง
