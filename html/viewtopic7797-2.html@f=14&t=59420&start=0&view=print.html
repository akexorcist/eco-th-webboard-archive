หากินกับ plurality (ยิงรัวไป 4-5-6 นัดแล้วแต่ดวงว่าจะออกมากี่นัด ถ้าใส้ปินคู่ จะเป็น 5-7 นัดแทน) ไปจนjob35 แล้วอัฟbullet dance
อัฟเต็มนะ .... ใช้ยิงเดี่ยวๆที่ฟูเวล3-4 ก็ตายแล้วท่านั้น
อัฟไว้ไม่เสียหาย ท่านี้ความแรงมากที่สุดในสาย fighter ที่ 1600% ที่เวล5
ข้อเสียคือ ดีเลย์สูง

gun delaycancel จะช่วยลดค่า delay ของทุกสกิลโจมตตี แต่cross ไม่สนใจหรอก มันไม่มีดีเลย์อยู่แล้ว มี0.1 วิมั้ง แต่ถ้าคิดอัฟแล้วไปยิงรัวๆแบบเบลดกด delaycncel เลิกคิดไปได้เลย... มันไม่ไวหรอก ใช้คอมโบกับ bullet dance / pluralityดีกว่า


ท่า charge shot กับstun shot เลือกอัฟไว้อันหนึ่งก็ดี ถ้าเน้นเก็บเลเวล charge shot น่าจะดีกว่า vitual อย่าเลย โอกาสติดต่ำ+ติดแปปเดียว เดี๋ยวมันหาย +slow มันคอมโบกะ dance ไม่ต่อเนื่องเพราะมอนเดิมช้า(เดินมาหาเรานะ)

แนะนำให้อัฟ over range ระยะของปืนจะเป็น 8 ช่อง(เดินมากๆเวลช้าลงนะ เหมือนใส่บูสแล้วเวลไวอะ) ความแรงจะตกลงไม่มากเพราะว่า shot stance กันไปแล้ว7ช่องแล้วใช้ท่าplurality bullet ยิงก็ได้ ซ้ำ2ครั้งโจรที่ฟูตายถ้าไม่ชอบดีเลของ dance ก็เล่นแบบนี้(ผมเล่นแบบนี้นะ มันดี ถ้าเบื่อก็ยิงสลับกะ dance)

shot > 550% (มั้ง) อันนี้ไว้ลากแรงพอสมควร ทีเดียวโจรขาวตาย แต่ถ้าเล่นสาย PVP ไม่ต้องก็ได้ ท่าอื่นคุ้มกว่า

cross job50 1300% ความแรงสูงมาก ถึง% จะต่ำกว่า dance แต่ไม่มีดีเลย์+หักค่า def หลังครัเดียว (ร่ายคอดอึด พอๆกับ ease SP ของเบลด )



สกิลซัฟอื่นๆที่อัฟไว้ก็มี
hand gun mastery +เลขหน้าatk50 ที่เวล5 +30ที่เวล1 อันนี้ควรอัฟไว้ ไม่ต้องเต็ม5ก้ได้เพราะเวล1-3 , 3-5 เห็นผลไม่ต่างกันมาก

CQB ดีพอสมควร แต่เน้นสายวอร์ที่ลงเอจิเยอะๆมากกว่า

API อย่าเลย..... ยิงรัวใส่ยังู้สึกดีกว่า หรือถ้ามอนมาเยอะก็ shot เปรี้ยงไปเลย เล็งเป็นเส้นโดนไม่เกิน3ตัวหรอก
ท่า grenate + tear bomb ท่า ไม่ค่อยน่าใช้ โอกาสติด 50%ได้ + เบา

(มีท่าอะไรอีกมั่ง ลืม)
..................
precision fire ที่เวล3 ล็อกเป้าได้ 15วิ ไว้วอร์ดีกว่านะท่านี้
จะยิงไม่มี miss avoid guard ไม่ติด bad lucky ของtrader แต่ถ้าเจอโซลิดของวิสาดก็ 0เหมือนเดิม

Fast draw กดแล้วยิงทันที ไม่มีดีเลย์ ความแรง 160% ละมั้งครับ
