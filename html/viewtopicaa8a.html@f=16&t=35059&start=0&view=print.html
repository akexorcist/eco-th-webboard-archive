Barbed Trap - JobLv.5
- สร้างกับดักหนามบนพื้นดิน สร้าง Damage อย่างช้าๆ ด้วยค่าที่กำหนดไว้แก่เป้าหมายที่เหยียบจุดนั้น จำเป็นต้องใช้ไอเท็ม [TrapTool] ด้วย

Bungestac - JobLv.15
- สร้างกับดักหนามบนพื้นดิน สร้าง Damage และไม่สามารถกระทำอะไรได้ แก่ศัตรูที่เหยียบจุดนั้น จำเป็นต้องใช้ไอเท็ม [TrapTool] ด้วย

*****************************************
ข้อสงสัยคือ
1. Barbed คือ ติดกับดัก มอนขยับไม่ได้ แต่ยังโจมตีอยู่ ( ใช่หรือไม่ )

2. Bungestac คือ ติดกับดัก มอนขยับไม่ได้ และ ไม่โจมตี ( ใช้หรือไม่ )

3. ที่บอกว่า "สร้าง damage อย่างช้าๆ"
Barbed เวล 5 จับได้ 12 วินาที จะมี Damage ขึ้นกี่ครั้ง ( กี่ครั้ง )
Bungestac เวล 5 จับได้ 12 วินาที จะมี Damage ขึ้นกี่ครั้ง ( กี่ครั้ง )

4. ขอบเขตการจับมอนของกับดัก มีขนาดเท่าใด ( 1x1 , 3x3 หรือ 5x5 )

5. พอจะทราบไหมว่า พลังโจมตีของกับดักเนี่ย คิดจากอะไรครับ ( str หรือ Mag หรือ ? )

6. มีคนบอกว่า กับดัก ไม่สามารถจับ มอนประเภทบิน กับ ผีลอยๆ ได้ ( จริงหรือไม่ )

แค่เนี่ยอ่ะครับ ( 6ข้อ โฮโฮโฮ )

เนื่องจากผมลองมาทั้ง 2 อันแล้วได้ผลมาเป็นแบบนี้อ่ะครับ

Barbed Trap
วางกับดักไว้ที่พื้น ถ้ามอนมาเหยีบแล้วจะติด Slow !! โอกาสติดไม่ 100 % นะครับ ยิ่งสกิลเลเวลสูงจะยิ่งโอกาสติดมาก แต่เวลาที่แทรปวางอยู่บนพื้นจะยิ่งน้อย (12วิที่ถามถึงนั่นคือแทรปวางอยู่ 12 วิครับ) โดนดาเมจหน่อยนึงตอนเหยียบ 1 ที (เบาก่าโบล์วอีก) พอมอนเหยียบแล้วแทรปจะหายไป


Bungestac
เหมือน Barbed Trap แหละครับ แต่ผลคือจะทำให้มอนหยุดนิ่งอยู่ตรงนั้นโอกาสไม่ 100% เหมือนกัน โดนดาเมจ 1 ที แล้วแทรปหายเหมือนกัน ความแรงก็เท่ากันครับ

เรื่องความแรงนี่คงคิดจาก STR ครับ เพราะผม MAG 3 แต่ลองกะตัวหุ่นๆที่อยู่กะแพตตินั่ม แล้วมันโดน 700 ก่าๆ อ่ะ

ขอบเขตของแทรปทุกชนิดเป็น 1x1 ครับ
