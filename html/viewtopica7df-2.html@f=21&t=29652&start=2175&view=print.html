ขอโทษทุกคนด้วยที่หายไป … ไม่บอกกล่าว ...

เหมือนกับจะทิ้งทุกคนไป ... ใช่ ... ในตอนแรกเจ๊ก็คิดแบบนั้น หลังจากตอนนั้นที่เจ๊เข้ามาเป็นครั้งสุดท้าย เจ๊ก็เจอปัญหาหลายอย่าง เรื่องการเรียน และที่หนักที่สุด ... คือเรื่องทางบ้าน ซึ่งเจ๊มีปากเสียงกับคนในครอบครัวบางเรื่องขนาดหนักจนคิดจะไม่กลับบ้านอีกแล้ว

มันเครียด มันตันไปหมด ... ปรึกษาเพื่อนแล้วแต่มันก็ไม่ดีขึ้น ทั้งผลสอบที่ออกมาตอกย้ำให้เฟลขนาดหนักเข้าไปอีก ตอนนั้นเจ๊ไม่รู้จะทำไงดี เลยบอกทางบ้านไปว่า จะไปอยู่บ้านญาติที่ต่างจังหวัด ( ไปอยู่กาญ ฯ ) แล้วก็เก็บเสื้อผ้าหนีไปตรงนั้นตัวคนเดียว ( ยังดีว่าสนิทกันหน่อย )

ไปช่วยทางนั้นทำงานบ้าง ( เป็นธุรกิจส่วนตัวเล็ก ๆ น้อย ๆ ) แล้วเจ๊ก็ไปเที่ยวคนเดียวไปเรื่อย แต่ไม่ได้กลับบ้านเลย จนเมื่อไม่นานมานี้ ทางครอบครัวมาตามถึงบ้านญาติ แล้วก็เคลียร์ปัญหากันจนเข้าใจ แล้วก็เพิ่งกลับมาบ้านไม่นานนี้เอง เรื่องการเรียนก็เริ่มทำใจ แล้วก็หาทางแก้ปัญหาจนได้แล้ว

...
...
...

ขอโทษที่หายไปไม่บอกกล่าว แต่ตอนนั้นมันตันและเครียดมากจริง ๆ เพื่อนสนิทเราก็ใช่ว่าจะพึ่งได้ เขาก็มีปัญหาของเขา เราก็ไม่อยากจะให้ปัญหาของเราทำให้เขาเครียดมากกว่าเดิม

ไม่ใช่ว่าไม่ห่วงกระทู้นิยายของเจ๊นะ เจ๊ก็คิดตลอดแหละ แต่รู้ว่าตัวเองยังไม่พร้อมที่จะคุยกับใคร แล้วก็ทำอะไรทั้งสิ้น อยากจะใช้เวลาอยู่กับตัวเอง แล้วคิดให้ดี ๆ ซะมากกว่า เจ๊ก็ห่วงทุกคน อยากจะคุยกับทุกคน แต่ว่าสำหรับเจ๊ตอนนั้นแล้ว การอยู่คนเดียว มันเป็นการแก้ปัญหาที่ดีที่สุดแล้ว

ตอนนี้ ก็อยากจะบอกว่า “กลับมาแล้วนะ !” ไม่รู้ว่าเป็นยังไงบ้าง ยังสบายดีกันไหมเอ่ย ? ยังไงเจ๊ก็จะมาสานนิยายเรื่องนี้ต่อให้จบให้ได้แหละ ! ( อาทิตย์หน้าเจ๊จะขึ้น ม. แล้ว )
