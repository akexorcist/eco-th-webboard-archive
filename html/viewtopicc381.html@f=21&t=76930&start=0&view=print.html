ขอมาก็จัดให้ค่ะ = =

เน้นหนักๆในเรื่องของ "แสง" และ "เงา" ภาพดูไม่มีแสงเงาเท่าที่ควรค่ะ อาจจะเพิ่มระดับเข้มสุด กับอ่อนสุด ตามทีท่านเฟย์บอกไว้

เงาในส่วนของผม ข้างหน้า กับส่วนที่อยู่หลังคอ ควรมีระดับความเข้มต่างกัน ช่วงหน้าม้า ควรจะมีไฮไลท์เข้ามาเสริมด้วยให้สวยขึ้นและเห็นชัดขึ้นว่าอยู่าข้างหน้าค่ะ

ส่วนทีเ่ป็นผิวที่มีผมปิด ก็ควรจะมีเงาตกกระทบจากผมลงมาด้วยค่ะ ไม่งั้นก็เหมือนว่าแสงส่องเข้าหน้าจังๆ แต่เงาที่จมูกและรอบๆกลับไม่ใช่

ตรงส่วนของไหปลาร้าเบี้ยวไปนิดนึงค่ะ ถ้าออกแนวโมเอะๆ อาจจะไม่ต้องวาดเพื่อควา่มสมจริงก็ได้ เหมือนกับพวกรอยที่หลังมืออะไรพวกนี้ เหมือนเน้ให้ดูสมจริงมากขึ้นค่ะ

แล้วบางจุดที่คิดว่าเข้มได้ก็เอาให้เข้มกว้านี้อีก(ในส่วนของผิวนะคะ สีผม สีดำมันลงยากอยู่- -''สำหรับเรา)

ในเชิงการร่างภาพไม่ขอติอะไร เนื่องจากเป็นความถนัดเฉพาะบุคคลค่ะ เพราะบางคนไม่ร่างก็วาดออกมาได้

* โดยรวมถือว่าดูโอเค แต่ขาดหนักๆในเรื่องของ แสง และ เงา เท่านั้นค่ะ

กล่าวอะไรผิดไปก็ขออภัยดพ้วย เป็นความคิดเห็นส่วนบุคคลค่ะ -/โค้ง
