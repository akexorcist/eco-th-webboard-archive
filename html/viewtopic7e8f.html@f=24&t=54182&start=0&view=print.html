โพสต์แล้ว: พุธ 30 ก.ค. 2008 12:29 pm
โดย ECO
Armor LV.90 (ชุดทหารประจำทิศ)
เงื่อนไข : ค่าชื่อเสียง 100 ขึ้นไป
ผ่านการสำรวจซากโบราณสถาน (ส่งรายงานความเสียหายซากโบราณสถาน)
ส่งรายงานความเสียหาย ชิ้นขึ้นไป (Ruin Report) 100,000 ชิ้นขึ้นไป (ทหารแต่ละสังกัดทิศจะแยกกันส่งรายงาน)
ผู้ที่เข้าสังกัดทิศแต่ละทิศสามารถขอรับเควสได้ที่ NPC Agent Xxxxxx Knight Explore (Xxx คือทิศที่เราอยู่)
ผู้ที่ไม่ได้เข้าร่วมสังกัดกองทหารรับเควสได้ที่ NPC Commando see sea
วิธีการทำเควส
- เริ่มต้นให้ไปคุยเพื่อขอรับเควสจาก NPC ของทิศที่เราสังกัดอยู่ (หากไม่ได้เข้าร่วมสังกัดของทหารประจำทิศให้ไปคุยกับ Commando see sea) ที่นั่งอยู่ด้านล่าง เมื่อคุยแล้วเราให้ทำการรับเควสการสำรวจภายในโบราณสถาน (หากใครที่ทำเควสดังกล่าวมาแล้ว เคยส่ง Ban Report มาแล้ว ซึ่งในการทำเควสครั้งแรกนั้นจะเป็นการส่ง Ban Report – Xxx ของประตูนั้นๆ เพื่อเปิดประตูการสำรวจของเควสต่อไปในประตูอื่นๆ ที่เหลือ) เมื่อรับเควสเดิมอีกครั้ง จึงจะได้รับ Ruin Report เพื่อใช้ในการส่งให้กับ NPC เพื่อสะสมช่วยกันของทหารแต่ละสังกัด


- เมื่อผ่านการทำเควสครั้งแรกแล้ว เมื่อรับเควสเดิมอีกครั้ง เมื่อสำเร็จแล้วจะได้รับ Ruin Report ตอบแทน



- สามารถตรวจสอบจำนวน Ruins Report ทั้งหมดของสังกัดเราได้โดย การคุยกับ NPC ที่เรารับเควสแล้วเลือก ตรวจสอบจำนวน Ruins Report








- เมื่อได้รับ Ruins แล้วก็สามารถนำส่งให้ NPC ได้เลยทันที เพื่อสะสมร่วมกับเพื่อนๆ คนอื่นที่สังกัดเดียวกัน โดยการคุยกับ NPC แล้วเลือกหัวข้อ ให้ Ruins Report





- เมื่อทิศของเรารวบรวมส่ง Ruins Report ครบ 100,000 ชิ้น ทิศที่เราสังกัดอยู่ ก็จะได้รับ เสื้อจาก NPC เป็นการตอบแทนในความอุตสาหะ (สามารถรับได้ตัวละครละ 1 ครั้ง)
