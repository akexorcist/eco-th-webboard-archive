คงต้องทำใจยอมรับให้ได้อย่างเดียว เพราะระบบ การเก็บค่าบริการเปนแบบนี้

ระบบ ยังเปนแบบนี้ คงต้องมีด่า One net กันแน่นอน
ถ้ารัก เกมส์นี้ แล้วไม่หนักหนาเกินไป ก็ช่วยๆ กันเติมแคส คนล่ะนิด ซื้อไอเท็มมอล์

ประเทศอื่น ที่เค้ามีกัน ใจเขาใจเรา ครับ
