แต่มันจะเก่งกว่าตัวข้างนอก แถมหนอนเราอ่อนโคดป้าอีกตะหาก -*-

ช่วงแรกๆ ตีหมาก่อนคับ จนพลังโจมตีเพิ่มมาเยอะๆหน่อย พอหลังๆพอตีได้แรงๆแม่นๆแล้วก้อให้มอนมารุมจะขึ้นเร็วคับ (รุม 3 ตัวก้อพอ เยอะเกินตายอีก)

ถ้ามีสกิลกองไฟจะดีมากเลยคับ ก่อไฟไว้แล้วก้อให้หนอนตีอยู่รอบกองไฟ ให้มอนรุมก้อได้(ผมไม่ได้อัพเลยต้องให้เพื่อนก่อไฟให้ -*-)
