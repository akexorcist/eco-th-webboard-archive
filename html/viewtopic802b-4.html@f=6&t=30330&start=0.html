เข้าไปที่ D:\Games\Gungho\Emil Chronicle Online(foulder ที่ทั่น install เกมส์ไว้)

แล้วเปิด file eco.ver ด้วย notepad โดยวิธีเปิด ก็ทำด้วยการ คลิกขวาที่ file แล้วเลือก properties จากนั้นตรง open with ก็เลือก เอา note pad มาเปิดซะ....ถ้าไม่มีตรงส่วนดังกล่าวให้เลือก ก็ double คลิก ที่ file แล้วพอมีคำถามขึ้นมาประมาณว่า จะหาจาก internet ไหม ก็ให้เลือกอันที่สอง เพื่อเลือกจากรายการที่มีอยู๋แล้วก็เลือกที่ note pad ซะ

แล้วแก้ เลขที่มีให้น้อยกว่าเดิมไป 1

เช่น อย่างของผมตอนนี้เป็น 67 ก็แก้เป็น 66 ซะ

ของผมหายนะ

วิธีแก้อีกอย่างโดย gm paul งับ

[GM]Paul เขียน:ให้เข้าที่ Folder ตัวเกม Eco นะครับ



หากหา ไฟล์ eco.ver ไม่เจอนะครับ ให้เข้าไปที่เมนู Tools ด้านบนนะครับ

เลือก Folder Options... จะมีหน้าต่างใหม่ขึ้นมา เลือกหัวข้อ View

ดูลงมาเรื่อยๆนะครับ ที่หัวข้อ Hide extensions for known file types

หากมีเครื่องหมายถูก ให้ ติ๊ก ออกนะครับ

ทีนี้ ตัวไฟล์ใน folder เกมก็จะแสดงชื่อไฟล์ ออกมาครับ

พอเข้ามาที่ ไฟล์ eco.ver แล้ว ให้เปลี่ยนตัวเลข ให้เป็น 66 นะครับ แล้วกด save

เท่านี้ก็เรียบร้อยครับผม สามารถเข้าเกมได้ตามปกติครับ
