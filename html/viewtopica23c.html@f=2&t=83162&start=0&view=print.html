ก่อนอื่นเลยก็ ได้ทำ Route ไว้หรือไม่?

ถ้าไม่ ให้ลองเข้า http://www.speedtest.net/ เชคความเร็ว ค่าปิง ค่าIP ว่าปัจจุบันเป็นเบอร์ของประเทศไหนอยู่
ถ้าไม่ใช่ประเทศญี่ปุ่น ยังเป็นธงชาติไทยอยู่ แสดงว่า VPN เราต่อไม่ติดนิ
ถึงได้ขึ้นแจ้งว่าห้ามใช้ Proxy เชื่อมต่อ ๆลๆ ที่นอกเหนือจากเบอร์ IP ประเทศเขา

ถ้าใช่ ให้ตั้งค่า Route ใหม่ให้เหมาะสมนิ ที่ควรจะแก้คือค่า Metric ให้มีค่าสูงกว่าตัว
Internal IP เครื่องของตัวเอง จะดู route ทั้งหมด พิมพ์คำสั่ง Route print

ดูจากตารางแล้ว ตอนแอด route ไม่ได้ใส่คำสั่ง -p ไว้นะ
เวลารีเครื่องที่ตั้งไว้จะหาย

ยังไงก็เข้าไปดูกระทู้นี้ดูนิ มีอัพเดท route ip แพทเซิฟเวอร์เกมเพิ่มด้วย (ปัจจุบันเวลาโหลดแพทต้องเปิด VPN โหลดแล้ว)
viewtopic.php?f=2&t=82782

เวลาตั้งค่า Metric จะต้อง ตั้งให้ค่าสูงกว่าค่า IP ต่อเนทเครื่องเรา
เวลาใส่ route ตัวอย่างก็
route -p add 211.13.228.0 mask 255.255.255.0 2.0.0.254 1200<<<<(Metric ตัวอย่างที่จะเซท)

ที่ตั้งเป็น 1200 ก็เพื่อให้มันวิ่งเป็นอันดับสุดท้าย ดูจากตารางที่แปะมาขอแค่เป็นเลขอะไรก็ได้ที่มากกว่า 1125

ปล. แปะภาพมาไม่ครบนะนิ เลยดูไม่ออกว่าโค้ดในภาพเป็นอะไร แต่ค่า 1200 ก็สามารถใช้ได้เหมือนกัน

1. เขียนลืม mask และไอพีที่ต้องการจะรูทไปหา (VPN)
ตัวอย่างเช่นบรรทัดแรกมันควรจะเป็น route -p add 61.215.220.0 mask 255.255.255.0 2.0.0.254 metric x (x คือค่าที่มากกว่า เมตริกซ์ของเน็ตเราครับ)

2.ถูกจำกัดอำนาจเพราะไม่ได้รันจาก Administrator (ส่วนมากเป็นกัน Win7 ของวิสต้าผมไม่รู้ไม่ได้ใช้) ให้คลิกขวาที่ Command Prompt แล้ว Run as Administrator ทำดูครับ
