= = ให้รอGMอะหรอ??!! เมื่อวานไปโพสถามนะว่าเจ้า Cement กับ Plasma มันหาได้จากที่ไหน GMบอกไม่สามารถตอบได้ไม่มีข้อมูล แต่พอเข้ามาดูกระทู้อีกที มีคนตอบให้เรียบร้อยว่าดรอบอะไรยังไง

โดยส่วนตัวคิดว่ามันเป็นไอเทมพื้นฐานนะ จะเควสไหนอะไรยังไงแต่มันดรอบเป็นพื้นฐานอยู่แล้วก็น่าจะมีข้อมูล (แต่บังเอิญเราไปใส่บอกว่าเป็นของทำ Flying Garden ทั้นผู้นั้นก็เลยบอกยังไม่มีข้อมูลให้ = =)

ยังไงฝากกลับไปเป็นการบ้านกับเหล่าGMเน้อ ว่าการตอบมันมีหลากหลายวิธี การบอกมะมีก็ทำได้หลายอย่าง (ศิลปะในการพูด การเขียน การใช้ภาษา ต้องรู้จักพลิกแพลงหยิบยกขึ้นมาใช้บ้าง) เพราะบางที ความหมายเดียวกัน แต่เขียนนำเสนอด้วยกลวิธีต่างกัน คนฟัง คนอ่าน ก็ทำให้เกิดความรู้สึกต่างกันได้นะเจ้าค่ะ (ว่าเอ่อ ฉันพึ่งเธอไม่ได้แล้วใช่ไหม ?จะถามอะไรทำอะไร ก็ซ้ำซากเหมือนเดิม และก็หายไปกับสายลมหรือ ไม่รู้อะไรเลยนอกจากเรื่องเสียตัง 2.เอานะเค้ายังไม่รู้ แต่บอกไว้แล้วว่าจะรีบนำข้อมูลมาแจ้งให้ทราบ คอยดูแลตอบเราเป็นระยะๆอย่างน้อยก็สบายใจเค้ายังใส่ใจ คำร้องขอเราบ้าง (แต่ก็ต้องมาดูเป็นระยะๆไม่ใช่ไปแล้วไปลับแบบนี้ก็เกินไป) )

สิ่งนี้มันคงไม่ยากเกินไปมั้งนะ สำหรับคนวัยทำงาน เพราะคิดว่าน่าจะผ่านอะไรมา ไม่มากก้น้อยกันบ้างละ (จากประสบการณ์ที่เคยทำงานแบบนี้นะ บอกได้เลย สมมตินะ เกมส์คุณอาจมีปัญหาเยอะ คนเล่นอาจไม่มาก เด๋วปิดเซิฟ เด๋วบั๊คนั้นนี้ แต่ถ้ามีสักคนออกมาใส่ใจสนใจกับทุกๆคำถามที่จะตอบ (ซึ่งยอมรับนะว่ามันเหนื่อยมาก!!) แต่ถ้าคุณทำได้มันก็ซิ้อใจพวกเค้าละ คงไม่เกินกำลังชิมิถ้าจะทำงานอะไรสักอย่างให้ดีที่สุด
