V . ) Whirlwindbreeze Phoenixwing ( เวิร์ลวินบรีซ ฟินิกซ์วิง ) / บรีซ / 25 ปี / ชาย / Emil / Wizard – [ •SohigH• ]


เอาล่ะ มาสับต่อเลยดีกว่า ! สำหรับตัวนี้ยอมรับว่าแนวคิดเยอะมาก แต่กระนั้นในความคิดทั้งหลายที่สร้างมากลับมี `จุดขัด` อยู่หลายจุด จุดแรกเลยนั้นคือ `อาชีพ` กับความสามารถหลากหลายอย่างของเจ้านี่ ที่ทำให้เกิดความรู้สึกว่า `โกง` อยู่มากทีเดียว อันนี้ทางเจ๊มิได้บอกบังคับให้เปลี่ยน แต่จะถามก่อนว่า ถ้าความสามารถหลากหลายขนาดนี้ การที่จะเก่งและเป็นหนึ่งในทุกด้าน ย่อมเป็นไปไม่ได้อย่างแน่นอน ดังนั้นความสามารถในแต่ละส่วนจะหลากหลายก็จริง แต่จะถูกหารเรื่องประสิทธิภาพลงไป 3 – 4 เท่าเลยทีเดียว เพื่อเป็นการสร้างสมดุล อันนี้แล้วแต่ว่าจะเอายังไง ? เครื่องแต่งกายและลักษณะภายนอกนั้นไม่มีปัญหาอะไร ขอผ่านไปเลยละกัน


จากนิสัยที่ดูไปนั้นออกจะเป็นพวกชิว ๆ ไม่คิดอะไรมาก จะบอกว่านิสัยแนวนี้นี่มีหลายคนอยู่มากนะ อันนี้ก็ขึ้นอยู่กับว่าตัวละครไหนเหมาะสมกว่าก็จะโผล่มาในช่วงนี้ หากจะให้พูดโดยสรุป ตัวละครที่มีนิสัยคล้ายกับตัวของเรานั้น คือคู่แข่งทั้งหมดก็ว่าได้ แต่หากอยากจะคงเอาไว้ ก็ไม่ได้ว่าอะไร ก็โอเค ในจุดนี้ถือว่าผ่านไปได้ อีกจุดที่โดนแก้แน่ ๆ คือเรื่องความสามารถที่หลากหลายเกินไป มันจะทำให้เสียสมดุลในการต่อสู้อย่างมาก เพราะว่าตัวละครในแต่ละอาชีพนั้นล้วนแต่มีจุดอ่อนและจุดแข็งในตัวของมันเอง แต่การปิดจุดที่ว่านั้น ทำให้เกิดช่องว่างระหว่างอาชีพขึ้น ที่จะทำให้ตัวละครตัวนี้ `เทพ` เกิน และอีกอย่าง ชื่อที่จะใช้ในปัจจุบันล่ะ ? ใส่มาให้หรือยังคะ =w=; เรื่องประวัตินี่มีจุดให้แก้ตามเรื่องความสามารถกับอาวุธ ( เรื่องอาวุธนี่ก็เหมือนเรื่องความสามารถนั่นแหละ ที่หลากหลายเกินไป )

VI . ) ชาออส เรโกโร่ / ออส / 18 ปี / ชาย / Emil / Blademaster – [ Onepid01 ]


หลังจากอ่านเจ้าตัวนี้เสร็จนั้น มาเรื่องนิสัยก่อนเลย ถือว่าสามารถผ่านไปได้ เนื่องด้วยความบ้า ? อันถือว่าเป็นจุดเด่นของตัวละคร แต่กระนั้นเรื่องที่ว่าเวลาต่อสู้เอาจริงเอาจังเนี่ย ขอพิจารณาไปก่อน เนื่องด้วยเยอะมากที่เขียนมาแนวนี้ =w=; ( ประมาณว่า สรุปว่าจะบ้าหรือจะจริงจัง ก็เลือกเอาสักอย่าง ) เรื่องของชอบและความสามารถพิเศษด้านการต่อสู้นั้นก็ถือว่าโอเค สรุปง่าย ๆ ว่าเจ้านี่มันลิงใช่ไหม ? ( ฮา ) ถือว่าผ่านละกัน แต่กระนั้นเรื่องจริงจังเวลาสู้เนี่ย ขอดูอีกที เพราะมันแนวนี้เยอะมากมาย

VII . ) Zaccheus Alfio (แซคซิอาส อัลฟิโอ ) / ไอ้ตัวบ้าแมว / 23 ปี / ชาย /Emil / Gambler – [ MischievousDemon ]


เอาล่ะ ๆ ! มาต่อกันเลยสำหรับตัวต่อไป เอาเรื่องการแต่งกายก่อนละกัน เขียนเรื่องสีของชุดและรองเท้ามาด้วยนะ โอเคไหม ? เพราะว่าเจ๊ขี้เกียจคิดเอาเองให้ เดี๋ยวจะไม่ถูกใจด้วยนั่นแหละน่า อืม ... เป็นนิสัยที่สั้น ๆ ง่าย ๆ ได้ใจความสุด ๆ สำหรับตัวละครตัวนี้ ยังไงช่วยเพิ่มความชัดเจนของนิสัยให้มากกว่านี้นิดนึงจะดีกว่านะ เพราะว่าแค่นี้มันทำให้คนแต่งลำบากใจนิดนึง อยากให้มีมุมมองหลาย ๆ ด้านเกี่ยวกับตัวละครสักหน่อย เรื่องทักษะและความสามารถพิเศษนั้นเจ๊ขอชมว่าทำออกมาได้สร้างสรรค์และมีเอกลักษณ์มากมาย จนอยากจะเอาออกมาใช้เร็ว ๆ แล้วสิ ! จุดนี้ถือว่าน่าสนใจมาก อีกทั้งประวัติยัง เอ่อ ... ไม่ขอพูดละกัน เอาเป็นว่ายังไม่ผ่านละกันนะคะ ขอแค่เพิ่มลักษณะนิสัยให้เจ๊หน่อยก็พอ โอเค๊ ?

VII . ) Azenthia Stella Lelouch ( เอเซนเทีย สเตลล่า ลูลูซ ) / ลูลูซ / 120 ปี / หญิง / Titania / Sage – [ Yutsuha ]


เอ้า ! เอาให้ยาว ... ตัวสุดท้ายของวันนี้มั้ง ? เพราะไม่อยากจะฝืนมากเท่าไร ผมสีเงิน ... ( อีกแล้ว ) เยอะแฮะ =w=; เปลี่ยนหน่อยกีนะคะ ตาสีแดงอีกต่างหาก ! เหมือนตัวละครในบทนำเป๊ะเลย ( ฮา ) เรื่องเครื่องแต่งกายไม่มีปัญหาอะไร แต่เรื่องนิสัยเนี่ยสิ จะว่ามันได้ใขความก็ใช่หรอก แต่เจ๊รู้สึกเหมือนมันขาดอะไรบางอย่างไป ยังไงขอเพิ่มรายละเอียดหน่อยก็ดีนะคะ เรื่องสกิลก็โอเคไม่มีปัญหาอะไร ถึงจะรู้สึกขัด ๆ ที่มันเป็นโน้ตดนตรีก็เถอะนะ แต่เรื่องความสามารถพิเศษที่ว่า `มองเห็นออร่า` เนี่ย มันคืออะไรค๊า ? ช่วยอธิบายให้ชัดเจนหน่อยนะคะ
