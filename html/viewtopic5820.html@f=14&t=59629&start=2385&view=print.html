ผลของการติดพิษ ...

นกที่เกาะไมไม โจมตีผมปกติ 134 พอติดพิษ เหลือ 34 ( อย่าลืม + - ดาเมจแกว่งด้วยนะ )
งูเหลือง เวทสายฟ้า ปกติ 300-400 พอติดพิษ เหลือแค่ 130+ -

สรุป ... ก็ไม่เปลืองอะไรมากนะ ยาพิษขวดละ 290 (เดินลานมาเจอพอดี) หนัก 0.2
ใช้จริง ก็ดี ทำให้ตัวเองประหยัดยาได้หน่อย (บาดเจ็บน้อยลง) แต่ถ้าเก็บกับมอนเตอร์ที่
ไม่ติดพิษแล้วละก็ ... ไร้ประโยชน์ทันที ...

[ โดยรวม มอนเตอร์ในเกมนี้ ข้อมูลน้อยมาก
่ว่าตัวไหน vit เยอะ (คาดว่ามีผลทำให้ไม่ติดพิษ) เท่าที่ดูหลายตัว "ไม่ติด" ค่อนข้างเยอะ
เอาเป็นว่าใครพ้อยเหลือใช้ + อยากหาสกิลแปลกๆ เล่นก็อัพได้ ]

ส่วนสกิล Poison Rate Up อัพมาแล้วอีกที ดูเหมือนจะไม่ค่อยมีผลเท่าไหร่นะ
อัพ กับ ไม่อัพ มันก็ติดพิษปกติเหมือนเดิมง่ะ (ยังไม่ได้ลองกับสกิลเข็มพิษ)

ส่วนสกิล Poisonreate1 ผมจัดอยู่ในจำพวก "ดี" นะ ถึงจะติดพิษ แต่ได้พลังโจมตีเพิ่มขึ้นมา
ก็ดูคุ้มอยู่ (จาก 879 กดสกิลแล้วกลายเป็น 999 เลย)

ปล. ติดพิษ รู้สึกกินลูกอม ที่ดอปจากหมูในดันฟาอีส จะแก้ได้นะ

ส่วนตัวแล้วคิดว่า Poison Sting มีภาษีดีกว่า

เพราะ มีการโจมตีระยะไกล และ มีโอกาศแน่นอนไม่ต้องลุ้น

Damage อย่างหรูก้ 200%

โอกาศติดราวๆ 50% ใช้กับ ผู้เล่น

พิษเกมนี้ ค่อนข้าง แปลกกว่าเกมอื่น ตรงที่ว่า

ไม่ได้มุ่งเน้นที่จะ ทำให้ถึงตาย (ลดฮวบฮาบ)

แต่มุ่งเน้นที่ทำให้อ่อนแอลง (ตีเบาลงรวมถึงเวทย์ด้วย)

เหมาะสำหรับกรณีที่ว่า ใช้เปิดเพื่อเข้าแลก (ถ้าดวงดีติด และมั่นใจว่ารอด)

สกิลหลักๆ สำหรับแอสแล้ว ส่วนมากเน้นไปทาง ก่อกวน และ ลูกเล่นซะเยอะ

เพราะงั้นถ้าจะทดสอบคุณค่า ไปลองที่ สเตเดี้ยม น่าจาดีที่สุด

สกิลเก็บเวลน่ะ มันมีตายตัวอยู่แร้น (ฮา)
