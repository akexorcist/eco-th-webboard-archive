Chapet III : The Four student

อีกแค่นิดเดียว....... แสงสว่าง......ใกล้จะออกจากโรงเรียนขนหัวลุกนี่ได้ซะที!!!!

“ฮึก.....ฮึก.....ฮือ.......”

เสียงร้องไห้คร่ำครวญอย่างขื่นข่มดังขึ้นมาจากที่ไหนสักแห่งที่อยู่ในความมืดมิด... เรย์ถึงกับหยุดชะงักทันทีเมื่อได้ยินเสียงนี้ดังขึ้นมาอีกครั้งหนึ่ง...

“มันไม่ใช่ความผิดของฉันเลยสักนิด..... ฉันแค่ได้เห็นคนๆนั้นตายแค่นั้น.......มันไม่ใช่ความผิดของฉันเลยสักนิดเดียว....”
เสียงนั่นยังคงครวญครางต่ออย่างขื่นขม.

ประจวบเหมาะที่เรย์หันไฟฉายไปโดนตัวต้นเสียงพอดี.... เด็กผู้หญิงในชุดนนักเรียนเก่าๆ. ยืนหันหลังเอาหน้าชนมุมกำแพงกำลังร้องสะอึกสะอื้นอย่างน่าเวทนาในความมืด..
หล่อนค่อยๆ...หันหน้ามาหาเรย์อย่างช้าๆ..... ..........

ใบหน้าของหล่อนอาบโชกไปด้วยเลือดสีแดงสดเต็มหน้า.. ชุดนักเรียนหญิงที่เก่าคร่ำครึถูกละเลงด้วยเลือดสดๆสีแดงเข้มเต็มไปหมด... สภาพของแขนขาบิดเบี้ยวซึ่งน่าจะถูกบางสิ่งบางอย่างกระแทกอย่างรุนแรง...

“เหวอ!!!!” เรย์ตกใจสุดขีดรีบวิ่งไปยังประตูทางออกของโรงเรียนทันที....

“ความฝัน....นี่มันต้องเป็นความฝันแน่ๆ..... ไอ้ของแบบนี้น่ะมันก็มีได้แค่ในความฝันเท่านั้นแหละน่า!!!”

เรย์รำพึงรำพันกับตัวเองอย่างเสียสติ..ในระหว่างที่วิ่งไปยังลานจอดรถ.....

“ใช่.....นี่คือความฝัน....”

เสียงของเด็กผู้หญิงแว่วขึ้นมากลางทางระหว่างทาง.... หลังเสียงของเด็กผู้หญิงดังขึ้นมา..ก็มีเสียงลูกกระพรวนใสๆดังขึ้นตามมา....

“ ฝันแห่งความสิ้นหวังอย่างที่เจ้าเคยต้องการยังไงล่ะ....”

เด็กผู้หญิงในชุดฮาโอริสีขาวเปื้อนเลือด..ผมยาวสยายปรากฏออกมาต่อหน้าเรย์ที่กำลังใกล้เสียสติเต็มที... ใบหน้าที่ถูกเส้นผมสีดำปรกไปเกือบครึ่งใบหน้าแสยะยิ้มอย่างน่ากลัว... หล่อนระเบิดหัวเราะออกมาเหมือนคนเสียสติ...
เสียงหัวเราะของหล่อนดังก้องไปทั่ว...ก่อนที่ทุกสิ่งทุกอย่างจะดับมืดลงไปในที่สุด.......
= = = = = = = = = = = = = = = = = = = = = = = =
เวลาเดียวกัน.........

"เอาล่ะ!!! มากันครบแล้วใช่ใหม?.."

เด็กหนุ่มทีมีผมสีน้ำเงินยาวประบ่าและสวมชุดชุดโทนสีฟ้าขาวพูดขึ้นท่ามกลางความมืด..

"อืม"

เด็กหนุ่มผมสีดำขลับไว้ผมทรงหมาป่าตอบรับ.

"ทำไมชั้นต้องมาเล่นทดสอบความกล้าแบบนี้ด้วยฟะ!! ไม่ใช่เด็กประถมซักกะหน่อยที่จะต้องมาเล่นทดสอบความกล้ากลางค่ำกลางคืนแบบนี้.!"

เด็กหนุ่มอีกคนที่ผมยาวถึงบ่าสีเงินปลายเทาอ่อนๆและมีนัยน์ตาสีน้ำตาลอ่อนร้องโวยวายขึ้นมา..
"ไม่ใช่ทดสอบความกล้าหรอก...เคปเปอร์. เพราะฟีรัสน่ะแหละ.... ดันลืมรายงานชิ้นที่จะส่งวันพรุ่งนี้ไว้ที่ห้องเรียนน่ะสิ.."

เด็กสาว ผมหยักศกสีดำสนิทยาวถึงสะโพกเพียงคนเดียวของกลุ่มพูดขึ้นมา...

"เอาเหอะน่า ชินระ!! รีบๆเข้าไปเอาแล้วรีบๆกลับกันซะที!!!"

ฟีรัสพูดจบก็ลงมือปีนกำแพงโรงเรียนเข้าไปเป็นคนแรกของกลุ่ม...

"ว่าแต่ว่า.....โรงเรียนเกชโชคุของพวกเรานี่...มันไม่แตกต่างอะไรกับบ้านผีสิงดีๆนี่เอง.."

โคทาโร่พูดพร้อมกวาดแสงจากไฟฉายไปรอบๆตัวอาคารใหญ่.

" นายจะบ้ารึไง!! เดี๋ยวครูประจำเวรดึกก็มมาเห็นเข้าหรอก!!!" เคปเปอร์เอ็ดโคทาโร่..

" ไม่ต้องห่วงไปหรอก...ที่นี่น่ะพอตกกลางคืนแล้วไม่มีวี่แววของคนเลยซักคนเดียว..." ชินระกล่าว.

" เพราะคนส่วนใหญ่เล่ากันว่าที่โรงเรียนนี้พอตกกลางคืนจะมีวิญญานออกมาเดินเพ่นพ่านบนอาคารเรียนยังไงล่ะ..." ฟีรัสกล่าวต่อ...

"ก็แค่เรื่องโกหกหลองลวงนั่นแหละน่า!!! รีบๆเข้าไปเอารายงานงี่เง่านั่นซักทีเซ่!!!"
เคปเปอร์เริ่มทนไม่ไหว..

"ใจเย็น.เคป... ไปกันแล้วล่ะ" ฟีรัสถือไฟฉายแล้วเดินนำหน้าเข้าไปก่อน...

โคทาโร่เองยังคงยืนสำรวจสิ่งที่อยูรอบๆตัวต่อไป.....ราวกับถูกมนต์สะกดอะไรซักอย่างเข้า..

ทันใดนั้นสายตาของโคทาโร่ได้เหลือบไปเห็นผู้หญิงในเครื่องแบบของโรงเรียนเก่าๆ...

ยืนแหงนหน้าเหม่อมองพระจันทร์เต็มดวงอยู่ตรงกลางสนามฟุตบอลหน้าโรงเรียน...

หล่อนค่อยๆหันหน้ามาทางโคทาโร่มาอย่างช้าๆ.....

เผยใบหน้าที่เลือนลางและพร่ามัวไม่ชัดเจนเหมือนกับภาพลวงตาที่กำลังฉายอยู่บนใบหน้าของหล่อน...

โคทาโร่จึงรีบเร่งเท้าตามพวกฟีรัสเข้าไปในอาคารเรียนอย่างรวดเร็ว.....

"ว่าแต่.....ห้องเรียนของพวกนายนี่มันชั้นไหนกันน่ะ?" เคปเปอร์ถามขึ้นมา.

"ชั้น3น่ะ..." ชินระตอบ.

"แต่ว่านะ....โรงเรียนนี่มันก็สมควรอยู่หรอกที่จะมีข่าวลือเรื่องพรรคนี้น่ะ...สภาพตอนกลางคืนนี่ไม่ต่างอะไรกับป่าช้าเลยสักนิด.." เคปเปอร์ยังคงพูดต่อไป...

"ชู่ว์!!! พวกนายเงียบก่อน!!!" จู่ๆฟีรัสก็สั่งให้เงียบ....

"อะไร??" โคทาโร่ถาม

"ลองเงี่ยหูฟังดูสิ....." ฟีรัสพูดด้วยเสียงเบาๆเหมือนเสียงกระซิบ..

" คิก คิก คิก คิก คิก คิก คิก คิก คิก คิก คิก คิก คิก " เสียงหัวเราะเล็กแหลมของเด็กผู้หญิงดังออกมาจากเครื่องกระจายเสียง.....ชวนให้ขนลุกยิ่งนัก....

"ท่าจะไม่ดีแล้วมั้ง....." เคปเปอร์พูดด้วยน้ำเสียงสั่นๆ

"อดทนอีกนิดสิ.... ใกล้จะถึงห้องของพวกเราแล้วล่ะ..." ฟีรัสเร่งฝีเท้าให้ไวขึ้นอีก.....ในที่สุด...กลุ่มของฟีรัสก็ได้มาหยุดอยู่ตรงหน้าห้องมัธยมปลาย 4 ชินระค่อยๆเลื่อนบานประตูห้องเรียนอย่างช้าๆ....

"ฟีรัส นายเข้าไปเอาสิ....จะได้รีบๆกลับกันซักที..." โคทาโร่พูด.

"เออๆ....รู้แล้ว." ฟีรัสเดินเข้าไปในห้องเรียนพลางกวาดแสงจากไฟฉายไปรอบๆห้อง...พลางล้วงลงไปในเก๊ของโต๊ะแถวที่อยู่ติดกับหน้าต่าง....

"เจอแล้ว!!! อันนี้แหละ." ฟีรัสหยิบไฟฉายขึ้นมาส่องบนปกสมุด..ก่อนละสายตาจากมันมามองพวกเพื่อนๆที่กำลังรอเขาอยู่..

" พวกนาย......ทำไมถึงทำหน้าเหมือนเจอผีแบบนั้นล่ะ?" ฟีรัสถามเพื่อนๆที่ยืนอยู่ที่บานประตูด้วยสีหน้าที่ไม่ค่อยสุ้ดีนัก.

"ข้างหลัง......" เคปเปอร์พูดด้วยน้ำเสียงตะกุกตะกัก...ชี้นิ้วไปยังกระจกหน้าต่างด้านหลังของฟีรัส...

เขาค่อยๆ....หันไปยังกระจกด้านหลังอย่างช้าๆ.....

ร่างของผู้หญิงที่อยู่ในชุดเครื่องแบบของโรงเรียนเก่าๆ...ร่วงลงมาจากฟ้าผ่านลงมายังห้องที่พวกฟีรัสอยู่....ใบหน้าที่ขาวซีดราวกับไม่มีเลือดจ้องมองมายังพวกเขา.....และตามมาด้วยเสียกรีดร้องที่น่าเวทนาร่วงลงมาพร้อมร่างของหล่อน..
