ปาป้า แพงกว่า แลกได้จากแสตม 108 ดวง มีหนวดเวลาบินจะมีไอพ่นสีฟ้า บางเผ่ามีสีขาวขอบๆ บินไวกว่าเบบี้ด้วย

เบบี้ ได้จากบอสทั่วไป ตอนแรกจะได้เป็นเผ่าคนให้หาหิน เช่นต้องการให้เผ่าโดมเนียนใส่ก็ต้องหาหินมืด100ก้อน+ถั่วเพิ่มความคุ้นเคย

จึงถือเป็นข้อดีของเบบี้ครับ
