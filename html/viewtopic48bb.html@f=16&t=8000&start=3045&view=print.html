ก็สาย bp ก็จะเน้นไปทางนี้ล่ะครับ และ อาชีพนี้ก็เหมาะสำหรับล่าของจากมอนเตอร์เป็นอย่างยิ่ง

ด้วยสกิลปราชญ์ที่ครอบคลุมสัตว์ต่างๆทั่วโลก Eco เลยก็ว่าได้ เลยไม่ต้องแปลกว่าทำไมเยอะ

ส่วนอัพอันไหนถ้าเป็นไปได้ก็น่าจะอัพทุกอันเลย เพราะมีประโยชน์เยอะ (ในด้านถ้าเราล่าด้วยนะ)

แต่ถ้าต้องเลือกก็ึคงจะต้องตัดประเภทที่เราไม่ได้ไปแถวนั้น ไม่ค่อยได้ล่าของจากประเภทนี้ตัดออกไป

ส่วนสกิลจำพวก Hp Sp ก็ถ้า Point เหลือ ก็น่าจะอัพไ้ว้นะครับ เพราะการผจญภัยล่าของสเตตัสก็เป็นสิ่งจำเป็นอย่างยิ่ง


ส่วนสกิลโจมตีในขั้นแรก ผมแนะนำว่าาให้ใช้ Blow นะครับ หรือจะใช้ Banish Blow ก็ได้แต่ผมไม่ค่อยชิน

และก็การอัพสกิลที่เยอะมาก แต่ก็ไม่ต้องกลัวที่ Point จะไม่พอครับเพราะสามารถไปเอา Point ฟรีขั้นแรกมาอัพได้
