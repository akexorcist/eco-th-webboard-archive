ชื่อ รอย ไพธอน สมิท [ Roy P. Smith ]
เพศ ชาย
อายุ 14 เผ่า มนุษย์
หน้าตา ขาวๆ คิ้วเข้มๆ หน้าตาย ผมสั้น มีรอยแผลเป็นที่ผ่ามือเพราะกรีดไว้สัญญากับตัวเองว่าจะไม่รักใครอีก
อาชีพ คอมแมนโด
อาวุท เข็มพิษ
สกิลพิเศษ หายตัวไปกับความมืด ใช้พิษเก่งมาก
อุปนิสัย ไม่ชอบพูด นัยตาแสดงถึงความโศกเศร้าตลอดเวลา จริงจังกับความรัก ทำอะไรแบบมีความคิดนิสัยเป็นผู้ใหญ่เกินตัว รักพระเอกมากแต่ไม่แสดงออก

พลังพิเศษที่มี
ฝนเข็มพิษ ทำให้ เข็มพิษตกมาจากฟ้าคล้าย ฝน
เงื่อนไข จะใช้ได้ต่อเมือ ได้รับจูบจากพระเอก
ขอเป้นเพื่อนพระเอก [ พลัง Y โดยแท้จริง ]

ประวัติของ Roy P. Smith
มีคนเก็บทารกได้แถว เตียงแห่งภูติผี จึงเอามาไว้ที่บ้านเด็กกำพร้าที่เมืองไอออนเซาส์และตั้งชื่อว่า Roy P. Smith ตั้งแต่เด็กโดยไม่รุ้จักปูมหลังของตัวเองเลย อาศัพทำงานอยู่ที่นั้น และเข้าฝึกเป็นทหารที่เมืองไอออนเซาซ์ จนอายุ 16 ปี จึงได้แต่งงานกับหญิงสาวที่ตนรัก นามว่า แมร์รี่ แต่งมาได้ไม่นานก็ถูกสาวที่ตนรักหนีไปอยุ่กับชายอื่น รอยจึงสัญญากับตัวเองว่าจะไม่รักใครอีกแล้ว แล้วก็กรีดผ่ามือตัวเองเป็นรูปตัวM และออกเดินทาง ไปทั่วแบบคนไร้จุดหมาย จนมาถึงเมือง Acropolice City จนเกิดเรื่องวุ่นวายขึ้นจนได้

รายงานความคืบหน้าครับ
ตอนที่ 2 กำลังอยู่ในช่วงเกลาบทเอง
>_<" ขอโทษครับที่ดำเนินเรื่องได้ช้า
จนผมมีความรู้สึกว่า..

1. จะตัดแบ่งเนื้อเรื่องออกเป็นหลายภาค - ถ้าเช่นนั้นจะมีภาคใหญ่ๆ อยู่ 3 ภาคฮะ ก็คือภาคปรกติ สงครามศาตรา / ภาคอดีตของครอส ( ยาวมาก ) / ภาคความเป็นไปของอนาคต ( เคร์อาร์เป็นนางเอก ) โดยรวมก็จะมี 8 บทสำหรับภาคปรกตินี้ครับ ( บทละ 3 ตอน )

2. แต่งต่อไปเรื่อยๆ โดยเอาธีมเดิมดั่งที่วางไว้แล้ว ( มากกว่า 8 บทแน่นอน )

ข้อแตกต่างจะอยู่ที่ระยะเวลาและตัวละครของเพื่อนๆ ครับ แน่นอนว่าถ้าเลือกแบบที่ 1 ตัวละครของเพื่อนๆ อาจจะออกไปตามภาคต่างๆ แต่ถ้าเป็นแบบที่ 2 เนื้อเรื่องก็จะยาวมากเลย ( เดี๋ยวเกมส์ก็จะเปิดกันแล้วด้วยสิ )

>_<" ไงก็ขอปรึกษาเพื่อนๆ ด้วยนะครับ ส่วนตอนที่ 2 นี้จะพยายามเข็นมาลงก่อนวันพุธนี้ครับ
