thepisces เขียน:ขอเป็นสมาชิก Assassin ด้วยคนนะครับ ^^"
แต่ผมมีข้อสงสัยอยู่เล็กน้อยรบกวนช่วยทีนะครับ
1. Scout เนี่ยมันใช่อาวุดปา,มีด,กรงเล็บใช่ไหมครับที่นี้ เราจะเปลี่ยนไปใช้อาวุดสลับไปสลับมาได้ไหมครับ แบบว่าบางทีเบื่อมีดอยากไปใช้ กรงเล็บแบบนี้อ่ะ
2. ตอนที่เป็น Scout ผมอยากเล่นสายที่ใช้อาวุธประเภท Claw ผมควรจะอัพสกิลอะไรบ้างขอแบบว่ายาวถึงเปลี่ยนเป็น Assassin เลยนะครับ
3. มีดเนี่ยมันคืออาวุดปาหรือเปล่าครับ หรือ ว่าคนละอย่างกัน ผมดูสกิลล่ะงงไม่เห็นมีท่าที่เขียนว่าใช้กับมีดเลย

ขอบคุณไว้ล่วงหน้าเลยนะครับ -/\-


ขอตอบให้เป็นข้อๆไปนะครับ

1.มีดกับกรงเล็บสามารถสลับกันใช้ได้ครับ เพราะมันต้องการ stat แบบเดียวกันแต่ อาวุธบิน มันต้องการ stat int แทน dex ครับ เพราะถ้า int น้อยเราก็ปาวืดรัวล่ะ - -"

2.ถ้าตอน scout แนะว่าเล่นมีดไปก่อนดีกว่านะครับเพราะ skill มันมีแต่ใช้ มีด ทั้งนั้นเลย กรงเล็บไว้เล่นตอน ass ดีกว่าครับ แต่จะเล่นเลยก็ได้แต่ skill ที่เป็นพวกมีดไม่ต้องอัพเลย

3.คนละอย่างกันครับ อาวุธบิน จะใช้แล้วหมดไป แต่มีดเป็นอาวุธถือทั่วๆไปครับ จะเล่นอาวุธบินบอกเลยว่าไว้มีเงินก่อนจะดีกว่าครับ เพราะถ้าซื้อกับ NPC จนแน่ๆ เว้นแต่จะอึดพอหาวัตถุดิบมาทำเอง...แต่กว่าจะทำเองได้ก็ต้องมี skill ทำก่อนจะได้ตอนเป็น ass
