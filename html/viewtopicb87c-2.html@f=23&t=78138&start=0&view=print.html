[ไร้สาระ]อยากให้พี่เอกมาดูหน่อย

โพสต์แล้ว: อาทิตย์ 12 ธ.ค. 2010 8:24 pm
โดย ECO
พี่เอกผมได้ข่าว (นานแล้วและ) ว่าพี่เอกหามอนส์เตอร์ที่ชื่อ เลย์ รสมันฝรั่ง ที่รูปร่างมันเป็นห่อ สีเหลือง
ด้วยความที่ผมนั้นหวังดี จึงได้บุกน้ำลุยไฟ เพื่อที่จะได้เจอกับมันซึ่งวันนี้ผมเจอมันแล้ว รูปร่างมันเป็นยังงี้นะ



การที่จะหามันเจอนั้นพี่เอกต้องไป MAP นี้นะคับ



แม็ปนี้อันตรายมากๆ เพราะระหว่างทางเข้าอาจมีควันพิษทำให้เราตายเร็วขึ้น ( คนนั่งสูบบุหรี่ )
และเมื่อถึงแล้วต้องให้แน่ใจว่าเป็นแม็พนั้นจริงพี่ต้องหา สัญลักษณ์ของมันให้เจอ



เมื่อแน่ใจแล้วพี่ก็บุกเข้าไปเลยพอบุกเข้าไป เราถือเลย์ออกไปเลยไม่ได้นะต้องเสีย ค่าเข้าแมพด้วยแถมคนเก็บค่าผ่านทางยังมี เล่ห์กลในการชักชวนให้เราจ่ายแพงขึ้น เช่นพูดว่า " รับขนมจีบซาลาเปาเพิ่มมั้ยคะ " ต้องระวังให้ดีนะคับ
หน้าตาคนเก็บค่าผ่านทาง



และผมมีคำเตือนก็คือพี่ไม่ควรเกบเลเวลแมพนั้นมากเกินไปซึ่งมีคำเตือนบอกไว้ชัดเจนแจ่มแจ้ง



ภารกิจของผมเสร็จสิ้นแล้ว บ๊าย บาย
