พูดอีกก็ถูกอีกงับ CAPA มันจะเพิ่มตาม Dex กับ Int ครับ เป็นตัวสำคัญที่ทำให้ต้องกลับเมืองเลย ทั้งๆที่น้ำหนักก็ยังไม่ถึง

เกี่ยวกับค่า Vit
• ผมว่าข้อมีจริงๆมันคือ เลือดเยอะครับ กับโดนคริเบา
• แต่ลองมาเทียบจริงๆ แล้ว lv แรกๆ สาย vit กับ agi โดนแทบไม่มีความต่างกันเลยคับ เพราะชุดคับ แต่พอเวลสูงๆ อาจจะเห็นครับ แต่สาย vit จะมีเลือดเยอะกว่า
• บางทีจะอยู่ได้นานกว่าครับ เวลามอนตีคริก็จะเบาลงด้วย
• ข้อเสียมันคือ ไม่มันครับ ตีช้ามาก > < ยิ่งถือสองมือนะ สุดๆเลย
• ความเก่งจะคงที่ตลอด อาจจะเบื่อนะ ทุบๆ เท่าเดิม โดนทีลดน้อยๆเหมือนเดิม

เกี่ยวกับค่า Agi
• เลือดจะน้อยก่าสาย vit คับ เน้นเก็บศัตรูเดี่ยวๆ สุดยอดเลยคับ
• ตีเร็ว สะใจมากครับ
• แต่โดนรุมหละอ้วกได้งับ
• ยิ่ง lv สูงจะยิ่งเก่ง ยิ่งแจ่มคับ

* โดยรวมแล้วแต่ชอบมากกว่าครับ เป็นสายใหญ่ๆที่พูดถึงนะครับ *

แต่สิ่งที่อนาคตจะรู้มากกว่านี้คือ
1. Status ผิดปกติครับ
2. PayLoad อาจมีความหมายมากกว่านี้ ที่ lv สูงๆ
3. ของพังง่าย ไม่ง่ายขึ้นอยู่กับอะไร
4. เวลาทำของ Status มีผลไหม แต่ไม่ต้องกลัวมากมีรีเซ็ตครับ

อีกสายหนึ่งที่เห็นคือเน้น Str Dex คับ จะได้แบกของเยอะๆ ใช้ Banish แบบทีเดียวตายคับ แจ่มดีเหมือนกัน และอนาคตอาจมีสายทำของครับ เพราะ อย่างอาชีพ Marionet ค่า int มีผลต่อการจับมอนสเตอร์มาเป็นหุ่นคับ ดังนั้นเวลาทำของน่าจะมีซักค่าที่เกี่ยวข้องคับ แต่ยังไม่รู้หงะ T T

สำหรับผมแล้ว อยากให้มันเกิดสาย Mix อิอิ

* หุ่นยนต์ของ Machinery เป็น Pet ชนิดหนึ่งครับ นั่นคือข่าวดีว่า มันไม่พัง ^ ^ และซื้อครั้งเดียวคับ เวลาขี่หุ่นปุ๊บเดาว่าจะเหมือนมังกรคือ เราก็จะใช้ค่าต่างๆของหุ่นอย่างสมบูรณ์
