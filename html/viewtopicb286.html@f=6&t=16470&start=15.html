Joesave เขียน:
[GM]Paul เขียน:ได้ครับ โดยการ สลับ User

อยากให้จีเอ็มมาบอกว่าทำยังไงแบบว่าพอเปงแนวว่ามันแก้ยังไงเพราะทำเองแล้วระบบ network มะเข้า เอาแบบถูกกฏหมายหน่อยก็ดีนะครับ


มันคือการ สลับ user ของ window ค่ะ -*- ซึ่งถ้าเครื่องไม่แรงมีสิทธิ์ตายได้..(ไม่รุว่าเครื่องตายหรือตัวละครตายกันแน่ หึหึ) เอาง่ายๆก้อคือ
1. สร้าง user account ขึ้นมาใหม่ โดยกดที่ contorl panel แล้ว หาicon user account พอดับเบิ้ลคลิกเข้าไปก้อหาปุ่ม create a new account เมื่อสร้างเสร็จ เราจะได้ มาอีก user

2.วิธีใช้ก้อคือ เข้า user หลัก(ที่ใช้เล่นประจำ) เปิดเกม
2.1เสร้จแลว้กด ปุ่ม start>> log off >> switch user
2.2หลังจากนั้นจะไปโผล่ที่หน้า login user account ก้อเข้าอีก user ที่เราเพิ่งสร้าง แล้วก้อเปิดเกมตามปกติ
2.3จัดการอารายให้เรียบร้อยที่ตัวใหม่เสร็จแลว้ก้อ switch user อีกครั้งเพื่อมาเล่นตัวหลัก

---- สลับ user ไปมาได้โดยใช้วิธีที่2 แต่ทำบ่อยๆ มักจะ error -*- ดีที่สุดคือสองเครื่องค่ะ *-*(ถ้ามีอ่ะนะ)

แค่นี้แหละค่ะ -0-

แอบเนียน



บอกวิธีดีลของอีกวิธีให้เป็นทางเลือกนะครับ


ในกรณีที่ทั้งสอง ไอดี มี โกเลมนะครับ

อยากดีลของอะไรให้ไอดีที่ 1 ก็ให้ตั้งโกเลม ขายของไว้ครับ
อาจตั้งแอบๆหลับตาคนหน่อย แล้วกำหนดเงินซือ้เป็น 1 g แล้ว
ออกเกมส์ เข้าอีกไอดีนึง มาซื้อเอาครับ

วิธีนี้ อาจมีเสียวหน่อย ถ้ามีคนมาเจอโกเลมแล้วแอบซื้อของไป

แต่ปกติ ผมก็ใช้วิธีนี้ แต่ตั้งราคาไว้เกือบปกติของราคาตลาดอยู่แล้ว
เพราะมีเงินใช้อยู่ทั้งสองไอดี เหมือนย้ายเข้ากระเป๋าซ้าย-ขวา


ปล. เกมส์นี้มีแมพเยอะ ขนาดในเมือง ยังมีที่ว่างๆที่คนไม่เดินไป ตั้งขายแล้วเข้าอีกตัว จริงๆไม่ถึง2 นาที ยังไงก็อยากที่จะมีคนมาเจอแล้วซื้อได้ทันอยู่แล้วครับ

วิธีนี้ ง่ายกว่า สลับยูเซอร์ครับ กรณีต้องการดีลของนะ

ปัญหาของการใช้โกเลมเทรดของอย่างนั้นอ่ะคือ
ในแต่รอบที่ตั้งร้านเสีย1แต้มความเสียหายนะฮะดังนั้นโกเลมตัวนึงทำได้แค่50ครั้ง
ถ้าจะใช้ก็ใช้ให้คุ้มๆหน่อยละกันแล้วก็ระวังเรื่องน้ำหนักดีๆนะฮะ


จริงๆแล้วมีคนเอาไฟล์รีจิสทรีมาปล่อยละฮะทำให้เปิด2จอได้แต่เราลองละerror
ใครทำได้แนะหน่อยก็ดีนะฮะ
ส่วนวิธีของปอมโปะมีปัญหาอยู่ตรงที่เน็ตdial-upทำไม่ได้อ่ะเพราะในการสวิทยูสเซอร์เน็ตมันจะตัด

จริงๆมีระบบโกเลมระบบเมลล์น่าจะมีตู้ไปรษณีย์ด้วยนะฮะเอาไว้ส่งของไปเลยอิอิ


ปล.รำคาญมากมายพวกปั๊มไอดีมาหาของอ่ะGMจัดการหน่อยฮะ ยิงไอ้พวกสมองสั้นมันปั๊มไอดีมาหาของแล้วยังมีการบอกด้วยว่าเจ้านาย(ก็ตัวคนปั๊มอ่ะแหล่ะ)ชื่ออะไร

ยิ่ง "นายรัน"เนี่ยเจอเยอะมากช่วยจัดการมันทีรำคาญแมพเน่า
