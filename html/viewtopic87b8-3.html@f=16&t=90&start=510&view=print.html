ถามเกี่ยวกับ ทหารรับจ้าง คับ

1.ค่า Max Status ของ ทหารรับจ้าง(สีเขียว) นี่เท่าไหร่บ้างหรอครับ

2.แล้วก็ ถ้าเราเอาทหาร(สีเขียว) ไปอัพเกรด แล้วพอเอาไปเปลี่ยน เป็นหทาร(สีน้ำเงิน) ค่าสเตตัสมันจะดีกว่าเดิมหรือปล่าวครับ

3.เปลี่ยน ทหาร(เขียว) เป็น ทหาร(สีน้ำเงิน) ทำไงคับ

4.แล้วถ้า เปลี่ยนเป็นทหาร(สีน้ำเงิน) แล้วจะเอาไปอัพเกรด ได้อีกไหมคับ
