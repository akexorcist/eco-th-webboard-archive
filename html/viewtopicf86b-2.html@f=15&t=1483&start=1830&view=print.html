โดยส่วนตัว เราว่าไปได้ตั้งแต่เปลี่ยนอาชีพอ่ะ เพราะต้องการเลือดมากนิดนึง ตอนวิ่งหาห้อง (ในดันเควสนี้มี บรรดาไพ่กับหุ่นเพียบเลย ที่จริงจุดประสงค์หลักจริงๆของเควสคือให้ฆ่าบอสไพ่ กับบอสหุ่น (outdoor) แต่เราเอามาทำเป็นที่เก็บเลเวลแทน เพราะมันแบ่งเป็นห้องๆ แล้วมอนเกิดตลอด

ถ้าจะไปจริง ที่เสียเวลานานสุดคือ "หาห้อง" ที่ดีๆให้ได้ (ควรมีแต่หุ่น เพราะไพ่เรายิงกันไม่เข้า T-T) และตอนหาห้องเนี่ยแหละ เหนื่อย +โอกาสตายสูงสุดแล้ว เพราะไพ่มันโหด T-T shaman ยิ่งเลือดน้อยๆอยู่

อ่ะ ลืม.. เควสนี้ใช้ตัวเลเวลไหนก็รับได้ เนื่องจากเป็นเควส 2 ราชา ชื่อในwiki 2体のキング เลเวล(?) แต่แนะนำให้หาอีกตัวมารับเควสแล้ว offlineจริงๆ ไม่งั้นไม่คุ้มกับ quest point ที่เสียไป 3 point แหนะ.. กว่าจะหาห้องเจอ บางทีเสียเวลาเกือบชั่วโมง
ส่วนการสร้าง instance นั้น ต้องให้คนรับเควส (คนเดียวก็พอ) อยู่ในปาตี้แล้ววาปเข้าไปก่อนเพื่อสร้างดัน คนที่เหลือถึงจะเข้าได้(เฉพาะคนในตี้นะ) หลังจากดันสร้างแล้ว คนสร้างที่รับเควส จะออกหรือ offline อะไรก็ทำไปได้ ถ้าต้องการสร้างใหม่อีกครั้ง(ในกรณีที่ดันพัง) หรือจะสร้างให้ปาตี้อื่น ก็ให้ออกปาตี้เก่า แล้วเข้าปาตี้ใหม่ จากนั้นเมื่อวาปเข้าอีกที ก็จะสร้างดันใหม่ได้อีก

สิ่งที่ควรจะต้องมี
- Druid (ไม่ต้องมี holy feather ก็ได้) เพราะว่าเราใช้แต่เวทย์เลเวล 3 เป็นหลัก (ถ้า Small M. atk ประมาณ 410+ น่าจะยิงเลเวล 2 ได้ หรือ Magล้วนน่าจะยิงได้ตั้งแต่ 50 กว่าๆ)
- Fire Shield *** ต้องมีอย่างยิ่ง ลด damage จาก เวทย์ไฟ 50% ที่ lv5
- Lighting Shield *** ถ้ามีจะดียิ่งขึ้น ลด damage จาก เวทย์ไฟอีก 25% ที่ lv5
- ความอดทนในการหาห้องที่ดีเจอ (เสียเวลามากมาย - -)
- ตัวละครอีกตัวที่ไว้เปิดดัน ^^'' (นั่นหมายถึงต้องมี 2 id หรือไม่ก็หาเพื่อนเอาตัวที่ไม่ใช้มาเปิดให้แล้ว offline ไป) วิธีนี้สามาถทำให้เปิดดันใหม่ได้เรื่อยๆจนกว่าคนรับเควสจะ online เป็นเวลา 2 ชั่วโมง (offline เวลาเควสไม่เดิน ^^)



side note เกี่ยวกับ instance:
- ไม่ทราบว่าทุกคนรู้จัก 'instance' กันรึเปล่า เลยจะมาชี้แจงเพิ่มซึ่งเกี่ยวข้องกับเควสนี้โดยตรง สำหรับเควสโบราณสถานทุกอัน จะเป็น quest instance ซึ่ง คำว่า instance นี้ มันเหมือน dungeon ส่วนตัวเฉพาะปาตี้ๆนึงเท่านั้น ทั้งๆที่อยู่ที่เดียวกัน แต่คนละปาตี้ ก็จะอยู่คนละ instance กัน ซึ่งระบบนี้เริ่มใช้กันมากในเกมต่างประเทศฝั่ง U.S. เนื่องจากจะไ่ม่มีปัญหาในการแจม จอง monster จอง boss แล้วยังให้ความรู้สึกได้ตะลุย dungeon มากขึ้นด้วย
เกี่ยวกับ instance สมมุติ ปาตี้ A จะไป dungeon C แล้วเมื่อคนในปาตี้ A คนแรกวาปเข้าดันไป ทางserver จะสร้าง Instance X ขึ้นมาซึ่งคนในปาตี้ A ทั้งหมดเมื่อวาปหลังจากนี้ จะเ้ข้าไปที่ instance X (ซึ่งเป็น dungeon C) ต่อมา ปาตี้B ก็จะไป dungeon C เหมือนกัน แล้วเมื่อเข้าวาปไป ทาง server ก็จะสร้าง instance Y ขึ้นมาสำหรับคนในปาตี้ B ทั้งหมด แน่นอนว่าคนในปาตี้ A กับ ปาตี้ B เวลาแสดงที่อยู่ ทั้งหมดจะอยู่ใน dungeon C แต่ ทั้ง 2 ปาตี้นี้ถึงจะอยู่ dungeon C เหมือนกัน แต่ก็อยู่คนละที่กันและไม่เจอกันเนื่องจากอยู่คนละ instance นั่นเอง
สมมติสมาชิกคนนึงในปาตี้ A เรียกว่า A1 ละกัน วาปออกจาก dungeon C แล้วออกปาตี้ไปเข้าปาีตี้ B แทน เมื่อวาปเข้า dungeon C อีกครั้ง ก็จะไม่เจอคนในปาตี้ A อีกต่อไป เพราะว่าตอนนี้ A1 อยู่ในปาตี้ B จึงถูกส่งไปยัง instance Y แทน

หวังว่าคงไขความกระจ่างให้บางคนได้บ้างนะ ^^
