เรื่อง Skill OC และ Skill Trust ต่างกันอย่างไร

โพสต์แล้ว: จันทร์ 23 ก.ค. 2007 11:01 am
โดย ECO
ชี้แจงเรื่อง Skill OC ของ merchant และ Skill Trust ของ Trader นะคับ
Skill OC ของ Merchant นั้นจะทำให้เราสามารถขายของได้ในราคาที่สูงขึ้น
ต.ย. เรามีไอเทม 1 ชิ้นราคา 100G เมื่อเรามี Skill Oc แล้ว จะทำให้ขายไอเทมชิ้นนั้นเป็น 120G เป็นต้น

ส่วนในเรื่องของ Skill Trust ของ Trader ที่สงสัยกันคือ Skill นี้เป็น Skill ที่สามารถทำให้ขายของราคาแพงได้ >> ซึ่งหมายความว่าเราจะสามารถไอเทมที่มีราคาแพงได้นั่นเอง ไม่ใช่ทำให้ขายของแล้วเงินเยอะขึ้น
ต.ย. ลองสัังเกตุดูว่ามีไอเทมบางชนิดที่มีราคาสูงแต่ไม่สามารถขายให้กับ NPC ได้ (จะเป็นตัวหนังสือสีดำไม่สามารถกดขายได้) เช่น เรามีหอกที่ขายได้ราคา 5000G อยากจะขายเข้าร้านแต่ขายไม่ได้ เราจำเป็นต้องอัพ Skill Trust ก่อนถึงจะขายของที่มีราคาสูงได้ ซึ่ง Skill นี้เมื่อเลเวลมากขึ้นจะทำให้ขายของที่มีราคาสูงมากให้แก่ NPC ได้ตามลำดับคับ

แต่เราถาม gm มาเค้าบอกว่ามันทำให้ขายได้เงินเยอะขึ้นกว่าใช้แค่สกิล OC
แล้วสกิล Trust มี 3 เลเวลด้วยจากเวปวิกี้ มันเขียน+เพิ่มเป็น% ขึ้นมาอีก 20%
แต่ความจริงเป็นอย่างไรก็ไม่รู้เหมือนกัน แต่รุ้สึกว่าสกิลมันบัคหรือป่าวไม่รุ้นะ

ชี้แจงแถลงไข
Skill name: 信頼 (Trust)
パッシブスキル商人毎に設定されている買取上限単価を上昇させ、高価な物を売る事ができる
Passive Skill เพิ่มวงเงินการขาย ทำให้สามารถขายของที่มีมูลค่าสูงต่อ NPC Merchant Guild ทุกตัวได้ (โดยสกิลนี้มี 3 ขั้น คือเพิ่มวงเงินการขาย 10%, 15% และ 20%)

*สกิลนี้ไม่มีผลต่อการขายของแล้วจะได้เงินเยอะขึ้นแบบ OC นะครับ แต่มีผลในการขายของราคาสูงๆ ให้แก่ NPC ได้ จากการทดลองจริง ตัวละครจะสามารถขายของ ราคาไม่เกิน 5,000-6,000 G ต่อชิ้นแก่ NPC ได้ (อันนี้คาดว่าจะแปรผันตามค่าชื่อเสียงของแต่ละคน)หากราคาของ มีมูลค่ามากกว่านั้นจะเห็นราคาขายของไอเทมชิ้นนั้นเป็นอักษรสีทึบ และไม่สามารถกดขายแก่ NPC ได้ เว้นแต่มี สกิล [Trust] นี้ ก็จะทำให้ขายของที่มีราคาสูงขึ้นได้ครับ
ปล. สกิลนี้ไม่เป็นบั๊คนะครับ ทีมงานตรวจสอบเรียบร้อยแล้วไม่มีปัญหาครับ

คือลองสังเกตในหนังสือคู่มือดูนะครับ

NPC แต่ละตัว มันจะมีช่องนึงเขียนเอาไว้ว่า


เรทการซื้อ และ วงเงินการซื้อ


ซึ่ง วงเงินการซื้อนั้นคือ NPC แต่ละตัวจะสามารถซื้อของจากเราในราคาไม่เกินวงเงินที่เขามีอ่ะครับ
(นับต่อ 1 ไอเทม หรือ 1 ชิ้นนะครับ)


สมมติเช่น

NPC A มีวงเงินการซื้ออยู่ที่ 5000

เรามีไอเทม B ที่มีราคาขายคืนร้านได้ 6000

ซึ่งเกินวงเงินการซื้อของ NPC ซึ่งจะทำให้เราขายไอเทมชิ้นนั้นคืนไปยัง NPC ตัวนั้นไม่ได้


แต่ถ้าเรามีสกิล Trust จะทำให้ข้อจำกัดของ วงเงินการซื้อหายไปอ่ะครับ

แล้วทีนี้สกิล OC ก็จะมีผลอีกทีตอนนี้อ่ะครับ




ปล. ผิดพลาดประการ ขออภัยด้วยนะครับ
