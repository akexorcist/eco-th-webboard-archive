- โดนซีลเมจิคแล้วหยุดร่าย (เวทย์)
- ไม่มีมิส ไม่มีคริ (เวทย์)
- โดนรีเฟรคที่เป็นกำแพงโดนไปทีมีุจุกเอง แต่รีเฟรคใส่ตัวไม่โดนสะท้อน (เวทย์)
- ใช้ sp (กายภาพ)
- ใช้ agi ลดร่าย (กายภาพ)
- ตีใส่ โซลิค ของวิเข้า 0 (กายภาพ)
