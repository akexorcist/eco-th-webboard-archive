อาชีพโปรดผมเลยนะครับเนี่ย เพราะว่าเท่ห์จริงๆ

สกิลที่จำเป็นๆเลยครับ คืออันดับหนึ่ง Spear Delay Cancle แน่นอนที่สุดครับ ต้องอัพให้เต็ม lv 3
และ passive skill อย่าง
- HP max
- HP recovery
- spear hit
- spear mastery
- increase defense

ส่วนที่เหลือก็แล้วแต่ชอบเลยครับว่าจะเล่นสายโล่ ( ก้ออัพ shield mastery )
หรือจะเล่นสาย rapier
ส่วน skill การโจมตีก็แล้วแต่ชอบเช่นกันครับ ระหว่าง
- charge strike ( แรงที่สุดของ fencer แต่ ชาร์จนาน เปลือง sp )
- หรือ banish blow ( เบากว่า แต่ไม่เปลืองเท่าไหร่ )
- spear lightning ( เบาลงมาหน่อย แต่ต่อเนื่อง )
