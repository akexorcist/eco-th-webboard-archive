เกี่ยวกับสกิว relaxation

แต่สามารถใช้ร่วมกับสกิวเพลงอื่นๆได้

และสามารถใช้ร่วมกับสกิว holy feather ได้ แตกต่างกันนิดนึงตรงที่การแสดงผลของทั้ง 2 สกิว holy feather แสดงผล ตอนที่เราวิ่งหรือโจมตี monster ค่า hp mp เราก็จะฟื้นฟูโดยต่อเนื่อง แต่ relaxation จะมีผลก้ต่อเมื่อตัวละครนั่งอยู่นิ่งๆ

การใส่ สกิว relaxation ร่วมกับ สกิว holy feather ก็จะทำให้การได้รับผลจาสกิวฮีลแรงขึ้นด้วย

ev0 เขียน:
Chorus เขียน:***สรุปคำถามแบบสั้น ๆ คือ
1. อยากรู้ว่าถ้าใช้สกิล bard ซ้อนกับสกิล druid (ที่โอนมา) จะมีผลของสกิลจะเป็นสกิลไหนคะ
2. สกิลที่มันดูคล้ายกันระหว่างสกิล bard กะ druid ถ้าเลือกอัพในอาชีพเดียวเลยดีกว่า หรือต้องอัพทั้ง 2 อาชีพ แล้วถ้าอาชีพเดียวสกิลไหนควรอัพของอาชีพไหนคะ
3. สกิลแนวสู้ของ bard กะ holy light หรือ holy groove ของ druid สกิลไหนดีกว่ากันคะ แล้ว bard ควรอัพสกิลสู้อันไหน (ถ้าไม่เน้นว่าสู้ผีอ่ะค่ะ)
4. รวมๆแล้วสกิล bard ที่จำเป็น (มาก) ที่ต้องอัพคืออะไรบ้างคะ (แล้วถ้าสกิลที่จำเป็น คือสกิลประเภทสาป แต่ไม่มี int จะ...นะ - -* )


1. สกิล druid และ vates ทุกสกิล(น่าจะ - -) สามารถใส่ทับกันได้และมีผลของสกิลจะอยู่จนหมดระยะเวลาของสกิลนั้นๆ เช่นใส่ rouse metal + rouse body + planer + holy feather + holy weapon + holy shield ก็จะมีแถบบัพขึ้นยาวๆ

2. สกิลบัพ druid ต้องกดใส่ที่ตัว ได้ทีละ 1 ตัว / ส่วนสกิลbard กดแล้ว นับตัวเราเป็นศูนย์กลาง ใครอยู่ในวงของบัพได้รับบัพหมด | (rouse body,metal /Fusion,pop) ถ้าจะถามว่าอัพอะไรดีกว่า ผมว่าถ้าเล่นเป็น bard มันจะมีแต้มเหลือพออัพได้ แต่ถ้าเล่น druid มันมีสกิลอื่นที่ผมว่าจำเป็นที่จะเอาสวิตมามากกว่า 2สกิลนี้

3. เห็นมีสกิลที่สร้าง dmg ได้ก็ musical blow ที่แรงตาม mag คนใช้ จะแรงกว่า holy light นิดหน่อย(ถ้าเน้น pvp/nvn ผมแนะนำ skill scroll เพราะมันแรงกว่าที่ mag เท่ากัน)

4. ตามความคิดผม samba +DEF 25 สกิลเดียว | ถ้าสกิลที่น่าสนใจ ก็มี session ที่ไม่คิด int ของเรา มีโอกาสติด xx% จำไม่ได้ / shout ทำให้ศัตรูติดสตัน จากที่ลอง int 20 ก็ติดไม่ยากนะ แต่ต้องมี dex หน่อย ไม่งั้นกว่าจะร่ายเสร็จ ศัตรูหนีหมด
