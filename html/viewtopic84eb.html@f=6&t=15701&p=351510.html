เห็นมีคนถามหากันเยอะคับ

อย่างที่รู้ๆกันว่าTiny medal เจ้าปัญหานี้คือเหรียญสำหรับแลกสารพัดรางวัลที่หลายๆคนใฝ่ฝัน ทั้งอัพเกรดหมา ทั้งแลกไข่มังกร และอะไรอีกมากมาย

โดยวิธีการที่จะได้ Tiny medal มานั้น ผมแจงได้เป็นสองวิธีดังนี้

1.ล่าบอสระดับสูง เช่น ไรโอ ไมโอ
2.เปิดจากกล่องไม้10และ11

สำหรับผู้เล่นระดับสูง ข้อแรกคงจะไม่ใช่ปัญหาอะไรเลย
กระทู้นี้ผมจึงขอเสนอ วิธีที่2แด่เพื่อนๆที่สนใจในเหรียญเจ้าปัญหานี่ แต่ไม่สามารถล่าบอสได้ละกันนะคับ ^^

กล่องไม้เบอร์10และ11นั้น จะสามารถหาได้จาก การทำเควส ในดันเจี้ยนที่เรียกว่า Instance Dungeon

ตามแหล่งข้อมูลนี้คับผม(เป็นเครดิตให้ไปในตัว):
http://ec.gamedb.info/wiki/?cmd=read&pa ... F5%C8%A210

ซึ่งจะต้องใช้ความรู้พื้นฐานในการอ่านภาษาญี่ปุ่นสักหน่อย - -'' แต่กระผมจะรวบยอดให้สำหรับล่าเฉพาะกล่อง10และ11เลยละกันนะคับ เพราะถ้าให้นั่งแปลนี่ คืนนี้ไม่ได้นอนแน่ๆ


Instance Dungeon นั้นเป็นระบบที่ผู้เล่นสามารถรับเควสประเภทล่ามอนสเตอร์ และสามารถได้รับดันเจี้ยนส่วนตัวสำหรับทำเควสนั้นโดยเฉพาะได้ทันที โดยดันเจี้ยนที่ตัวเกมสร้างให้ จะมีลักษณะคร่าวๆดังนี้ครับผม

1.เควสมี2ชนิด แบ่งเป็น เควสริง และเควสปาร์ตี้

2.ดันเจี้ยนที่สร้างมาจะเป็นดันเจี้ยนส่วนตัว เช่น คนในปาร์ตี้เดียวกัน รับเควสปาร์ตี้เดียวกัน จะถูกส่งไปที่ดันเจี้ยนเดียวกัน แต่หากเป็นคนละปาร์ตี้แล้ว แม้จะรับเควสเดียวกัน ก็จะโดนส่งไปคนละดันเจี้ยน

3.ถ้าคนใดคนหนึ่งในปาร์ตี้หรือริง ฆ่ามอนสเตอร์ที่ระบุไว้ในภารกิจได้ จะถือว่าคนทั้งปาร์ตี้หรือริง ได้ฆ่ามอนสเตอร์ตัวนั้นด้วยกันทั้งหมด

4.ลักษณะดันเจี้ยนเป็นเขาวงกต ทิศทางจะวกวนและเต็มไปด้วยทางแยก จนถึงห้องบอส ห้องทุกห้องเมื่อเข้าไปจะโดนขังไว้ และการจะเปิดทางไปยังห้องต่อไป จะต้องทำการฆ่าkey monsterในห้องนั้นๆเสียก่อน โดย key monster จะต่างกันไปในแต่ละเควส

โดยวิธีการรับเควสและเข้าร่วมใน Instance dungeon นั้น ก็จับริงหรือเพื่อนๆในปาร์ตี้(หรือจะสดคนเดียวก็ได้ไม่ว่ากัน) เข้าไปคุยกับทหารหน้าร้านหมอดู ที่ดาวน์ทาวน์ได้เลยจ้า

ต่อไปเป็นรายละเอียดเควสที่ผมแนะนำ สำหรับคนที่ต้องการตามหาtiny medal จากกล่อง10และ11นะคับ
