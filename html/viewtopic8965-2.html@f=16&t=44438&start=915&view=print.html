ถ้าเล่นสายหมา หมาต้องเก่งจริงๆนะ (หมายันเดมได้สักนาทีครึ่งก็โอเคแล้วแหละ)

Cave Bivonc : ได้ใช้เสมอตอนลุยดันน่อ เลือดขึ้นเร็วและไว

Grinder Attack : มาวัดกับ Go แล้ว Grinder แรงกว่าหลายขุมน่อ ที่เลเวล 1 Grinder วิ่งไปกัดราวๆ 200 คริอยู่ที่ 450 เสีย Sp นิดเดียว และเอาไว้ฝึกหมาด้าน Matk และ Mhit กับบอสในโรงเรียนได้ด้วย

Roaring : สกิลที่ต้องเอาไปสำหรับหมาเลย ที่เลเวล 5 มีเวลากดโบลวได้ประมาณ 3 ทีและฟาดอีกทีนึงเป็นของแถม

First Aid : อืม ถ้าเล่นกับคนสาย Vit ก็ดี แต่อันนี้ใช้กับหมาที่รักด้วย ถ้าหมาฝึกมาอย่างดีอย่างเลือดเต็ม (หมาเลือดเต็ม ราวๆ 400+1950) ดูก็ใช้ First Aid คุ้มเนอะ - -+

Fake Death : เพื่อความบันเทิง - -" 2 ใจระหว่าง cave hiding แต่เอาแกล้งตายเพราะมันสนุกอ่ะ - -"

Pincer ใช้ยากเกิน โยนทิ้งไปซะ สัปดาห์ที่แล้วเอาหมาเข้าดันพาร์ติซานตายครั้งเดียวล่ะมั้ง โดนพาติซานยิงเวทย์ แต่สบายขึ้นมากตอนสู้กับเดมสไนเปอร์เพราะเราสั่ง Roar ให้เดมมึนได้ ซื้อเวลาได้พอประมาณเลยล่ะ

สายหมาก็ดีแหละ แต่ว่าต้องใช้เวลาฝึกทั้งคนฝึกทั้งหมาด้วยแหละ แบ่งเวลาให้ดีน่อ - -

เอาคร่าวๆก่อน
1. รู้ว่าเพทของเราฝึกเต็มที่เท่าไหร่... สำคัญมาก เพราะฝึกแบบเต็มแล้วมันจะไม่ขึ้นน่อ

2. เตรียมเสบียง Petfood เอาไปเยอะๆนะ เพราะเพทฟูตนั้นดีมากในเชิงการฝึก Def ซึ่งจะอธิบายในขั้นตอนต่อไปน่อ

3. เข้าใจแพทเทิร์นคร่าวๆของการฝึก มันก็มีดังนี้น่อ ย่อๆละกัน

การฝึกโจมตี - จะขึ้นเมื่อ pet ของเราทำการโจมตี ค่าที่เกี่ยวข้องก็ Phy Shit Lhit Cri กับความเร็วการโจมตีซึ่งค่านี้เราจะมองไม่เห็น

ฝึกป้องกัน - จะขึ้นเมื่อเพทเราโดนโจมตี ค่าที่เกี่ยวข้องก็ Def Savoid Lavoid หลบคริ ซึ่งมองไม่เห็นเหมือนกัน

โจมตีเวทย์ - ขึ้นเมื่อเพทใช้สกิลโดน (ต้องโดนด้วยนะ) ค่าที่เกี่ยวข้องก็ Matk Mhit ความเร็วการร่ายที่มองไม่เห็น

ป้องกันเวทย์ - ขึ้นเมื่อเพทโดนโจมตีเวทย์ ค่าที่เกี่ยวข้องก็ Mdef Mresist 2 ค่า


ทีนี้เป็นทริคส่วนตัวน่อ - -

- ฝึกป้องกันกับกันเวทย์ผมมักจะไปดันใต้ชั้น 3 นะ เพราะหมาก็ทนในระดับหนึ่ง และมอนแถวนั้นเยอะ มีการโจมตีด้วยเวทย์ด้วยพร้อมกับเวทย์ติด Status ที่หายง่ายๆ (ก็มีโรปเปอร์ที่ร่าย Sleep แปบเดียวก็หาย)
- ไม่จำเป็นต้องลากแบบสัตว์เลี้ยงขี่ ด้วยการใช้คำสั่ง Come back โดยปกติ เมื่อมอนสเอต์ตีเพทของเรา เพทเราจะสวนกลับ ทำให้ฝึกไม่ได้นานแล้วมันจะขึ้นทางฝั่งโจมตีแทน แต่ถ้าเราใช้ Come Back เพทของเราจะไม่ตอบโต้ช่วงเวลาหนึ่ง
ถ้าเข้าใจแล้ว...ก็ลากมาสัก 4-5 ตัว แล้วเราก็กดใช้สกิล Come Back เรื่อยๆ ค่า Def ทั้งหลายก็จะขึ้นอย่างเต็มที่ ทำไปจนกว่าจะเต็มน่อ

PS: การใช้ Come Back นั้นดีที่ไม่เสีย SP และเพทจะไม่ตอบโต้มอนสเตอร์ช่วงนึง ช่วงนั้นเราสามารถใช้ Pet Food รักษาได้

PS2 : พวกเวทย์ฮีล(ไม่ว่าฮีลเดี่ยวหรือฮีลกลุ่้ม) หรือแคมป์ไฟ...อย่าใช้ในการฝึก Def นะ เพราจะทำให้มอนสเตอร์ในรัศมีสนใจเราแทน (คนส่วนใหญ่ที่ฮีลเพทกับบอสหนอน แล้วบอสหนอนวิ่งไล่ตีก็เพราะงี้แหละ จะฮีลจะบัฟมันหันหาหมด) แต่ PetFood กับ First Aid ทดลองแล้ว มันไม่สนใจน่อ

- พอเต็มแล้ว...เราจะได้ก้อนอิฐ 1 ก้อน หนาปึ้ก ไปตะวันออกโลด ตีหนอนม่วงยักษ์เลย - -+ (เพราะแถวนั้นโรงเรียนคนเยอะที่สุด) แต่ถ้าไม่มีคนและไม่มั่นใจ หนอนเขียวยักษ์ก็โอเค เลือดเยอะดี

PS : ถ้า Savoid เต็ม(+150)กับเลือดสัก +1000 หมาเราก็สามารถสู้กับหนอนม่วงยักษ์แบบ 1-1 ได้แล้วล่ะ เอาเวลาว่างทำโน่นนี่ได้ด้วย สบาย

- การฝึก Matk ถ้าสนใจ แนะนำ Grinder Attack ระดับ 1 น่อ จ่าย SP ถูกดี

เต็มแล้วก็เอาไปล้มโลด ล้มกี่ครั้งถึงจะดีแล้วแต่เจ้าของน่อ

เออ...แนะนำว่าถ้าล้มเยอะๆ จดโบนัสด้วยนะ ว่าล้มได้โบนัสเท่าไหร่ ล้มครั้งหน้าจะได้ง่าย เปิดโพยดูเลยว่าเต็มเพิ่มขึ้นแค่ไหน
