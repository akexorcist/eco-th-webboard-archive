รูปสีเหลี่ยม ( สีเหลือง ) คือ ประตูวาบธรรมดา ข้ามห้องไปมา

รูปสามเหลี่ยมชี้ลง มันคือ วาบที่เป็นบันไดลงไปชั้นล่าง

รูปสามเหลี่ยมชี้ขึ้น คือ วาบที่เป็นบันไดขึ้นชั้นบน

ดาว คือ จุดที่จะต้องไปค้นหาต่างหู ในเควสต่างหูราชินี

รูปสีเหลี่ยม และ สามเหลี่ยม ที่เป็น สีส้ม คือวาบที่จะต้องใช้ Paper Note เผา เพื่อเข้าห้อง
