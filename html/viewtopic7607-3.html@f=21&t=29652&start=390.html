เห็นแบบนี้ทำไมโหดจังฟะ =[]= !!!

ชื่อ – สกุล : ซิลเวีย ซิลเวอร์วิง

เพศ : หญิง

อายุ : 18 ปี 3 เดือน

เผ่าพันธุ์ : โดมิเนียน + ไททาเนีย

อาชีพ : Fencer

ลักษณะหน้าตา : เรือนผมสีเงินยาวสลวยถึงกลางหลัง ดวงตาสีมรกตที่ทอประกายกับแสงแดดยามเที่ยง ใบหน้ารูปไข่ได้รูปไร้มลทนใด ๆ บนใบหน้า ริมฝีปากบางสีกุหลาบอ่อน คิ้วเข้มเล็กน้อยแต่ว่าไม่มาก ผิวหน้าเนียนสวยขาวราวกับหิมะ

ลักษณะร่างกาย : สูงราว 168 ซม. หนัก 55 กิโลกรัม ร่างกายดูเหมือนจะบอบบาง แต่ว่าก็ได้รับการฝึกฝนมาอย่างดี จนดูเหมือนมีกล้ามเนื้อเล็กน้อย ถึงกระนั้นหุ่นก็ยังโอเคอยู่ดี หุ่นของเธอนั้นก็ ... ในยามปกติเวลาออกนอกบ้านไม่ค่อยเห็นอะไรมากนัก เพราะว่าจะสวมชุดเดรสแบบเรียบร้อยซะมากกว่า แต่อีกส่วนหนึ่งนั่นก็เพราะว่า “หน้าอก” หน้าอกของเธอนั้นนับว่าใหญ่อยู่ ซึ่งสำหรับ Fencer นั้น ถือว่าเกะกะ =w=” ( ประมาณ C + ) ผิวของเธอนั้นเนียนสวยขาว ไร้มลทินเช่นเดียวกับใบหน้า อีกอย่างจะปกปิดเพราะว่าเบื่อสายตาพวกผู้ชายหื่นกาม

ลักษณะการแต่งกาย : จะมีสองแบบคือยามปกติและยามฝึกซ้อมหรือว่าต่อสู้ ในยามปกติดเวลาออกนอกบ้านนั้น จะดูเหมือนกับสาวน้อยเรียบร้อยคนนึงเท่านั้น จะเป็นชุดวันพีซสีขาวประโปรงบานยาวสลวย พร้อมกับเสื้อนอกสีน้ำตาลแขนยาวอีกตัว และที่ขาดไม่ได้ก็คือรองเท้าแตะสีน้ำตาล และตะกร้าสำหรับซื้อของ อ้อ ! และที่ขาดไม่ได้ก็คือรอยยิ้มที่เต็มไปด้วยเสน่ห์ ( ที่ไม่ใช่ตัวของเธอเองเลย =w= ) ส่วนอีกแบบนั้น ในยามต่อสู้หรือฝึกซ้อม เธอเลือกที่จะแต่งกายด้วยเครื่องแต่งกายที่กระทัดรัด โดยเป็นเสื้อแขนกุดสีดำสนิทและรัดรูปเพื่อความคล่องตัว และกางเกงหนังสีขาวขายาว โดยมีรองเท้าบูทสีขาวเข้าชุดใส่ไว้ด้วยเช่นกัน จากนั้นจะสวมด้วยเสื้อโคทยาวสีขาวยาวถึงเข่าไว้อีกชั้นหนึ่ง และที่มือทั้งสองข้างก็สวมถุงมือยาวสีดำถึงศอก ( แต่โผล่นิ้วทั้งห้า ) เพื่อจะได้จับหอกได้ถนัดด้วยเช่นกัน

ลักษณะนิสัย : ก็จะมีอยู่สองแบบเช่นกัน คือนิสัยภายนอก และนิสัยที่แท้จริง ( ธาตุแท้ ) นิสัยภายนอกของซิลเวียนั้น จะเป็นสาวน้อยอ่อนหวาน และใสซื่อดูงดงามยิ่งกว่านางฟ้า คำพูดแสนสุภาพและกริยามารยาทแสนจะเรียบร้อยทำให้ได้รับการเอ็นดูจากเหล่าผู้เฒ่าผู้ใหญ่ อีกทั้งยังดู “บริสุทธิ์” ในสายตาหนุ่ม ๆ อีกด้วย หากแต่ว่านิสัยที่แท้จริงของซิลเวียนั้น ตรงข้ามอย่างแท้จริง คือเธอเป็นคนโมโหร้ายง่าย คิดอะไรก็ทำ บางทีทำไปก่อนที่จะคิดด้วยซ้ำไป เธอเป็นคนพูดตรง ( มาก ) และขี้รำคาญอยู่พอสมควร อีกทั้งยังชื่นชอบการอยู่คนเดียวซะมากกว่า เพราะจะได้ไม่ต้องฟังใครมาบ่น หรือพูดอะไรให้รำคาญเล่น ซิลเวียชอบการฝึกซ้อม แต่จะซ้อมดึก ๆ เวลาไม่มีคนมาดู เพราะกลัวผิดภาพลักษณ์ และอีกอย่างที่เจ้าตัวชอบคือการทำอาหารนั่นแหละ ( เพราะอยู่คนเดียวมานาน ) สำหรับเรื่องรัก ๆ ใคร่ ๆ นั้น ซิลเวียไม่เคยมีเลยด้วยซ้ำไป เพราะว่าหนุ่ม ๆ ทั้งหลายต่างพยายามแล้วพยายามอีก แต่ก็ไม่ได้ผลเสียที ( ทนจีบนานสุดสามปี แต่เจ้าตัวไม่แม้แต่จะชายตามอง แค่ยิ้ม ๆ แล้วพูดว่า “เพื่อนกันนะคะ” )

อาวุธ : Diavolo D'Argento – ( ปีศาจสีเงิน ) เป็นหอกที่ซิลเวียรักมาก ไม่ทราบว่ามีที่มาจากไหน หากแต่ว่าเป็นมรดกที่คุณปู่ให้ไว้ก่อนที่จะเสีย ตัวด้ามหอกยาวประมาณ 1.50 เมตร ทำจากอัญมณีสีดำทั้งตัวด้าม และเป็นเงาตลอดเวลา อีกทั้งเมื่ออยู่กลางแสงแดดจ้า จะทำให้ตัวด้ามนั้นใสจนมองทะลุได้ ตัวคมหอกนายเป็นคมหอกที่ยาวออกไปประมาณครึ่งเมตรได้ ( ยาวมาก ) และเป็นสีเงินดูสง่างาม อีกอย่างที่แปลกของอาวุธนี้คือ เมื่อโดนแสงของดวงจันทร์แล้วจะทำให้เกิดประกายสีเงินท่ามกลางความมืดมิด และความสามารถของอาวุธจะสูงขึ้น

ทักษะ :

- Moonlight Spirito ( จิตวิญญาณแห่งแสงจันทร์ ) : ท่านี้เป็นท่าที่จะใช้ได้ก็ต่อเมื่อตอนกลางคืนเท่านั้น และมีแสงจันทร์พอที่จะทำให้ Diavolo เปล่งประกายสีเงิน ทำให้ซิลเวียสามารถเร่งพลังของหอกให้พุ่งถึงขีดสุด และเพิ่มความเร็วขึ้นเป็นทวีคุณ ดังนั้น ความสามารถของซิลเวีย จะมากขึ้นใต้แสงจันทร์
