ถ้าเปน สาย เอจิ คงใช้แต่ Sword Delay cancle กันหล่ะคับ กดแล้วมันจะ aspd *2 ฟันรัวๆ

ถ้าสาย vit ก็คงลากแล้วใช้ SENNPUUKEN อย่างที่ผมบอกแหละ ท่านี้แรง 400% คับ

ถ้า pvp นี้ต้องดูคับว่า เราเล่นสายอะไร แล้วเจอกับสายอะไรอ่ะคับ

ถ้าเรา agi เจอ สายเวทย์ต่างๆยกเว้น วิซาร์ด (เพราะมันมีสกิล Solid aura กันกายภาพ 8-10 ครั้ง ) ผมใช้ Strike Blow ท่าของ บาวตี้ อ่ะคับ เปนท่าหมู่แนวตรง ประมาณ 5 ช่อง ไม่ร่ายคับ กระโดดเข้าไปฟัน ก่อนที่ สายเวทย์ต่างๆจะร่ายเสร็จ แรงใช้ได้คับ

ถ้าเรา agi เจอ วิซาร์ด + Solid Aura ผมกด Sword Delay Cancle ฟันสดเลยคับ ดูสิ ว่าเกราะจะแตกก่อนหรือเราจะตายก่อน 555

ถ้าเรา agi เจอ สายบู๊ agi ก็ต้องดูหล่ะคับ ใครเบอเซิกก่อน ใครจะมีดวงมากกว่ากัน เอิ้กๆ

ถ้าเรา agi เจอ สายบู๊ vit ถ้าเข้าอัพ dex มาเยอะ เรามีสิทธิ์ โดย สกิลเค้าทีเดียวตายคับ

-----------------------------------------------------------------------------------------------------

ถ้าเรา vit เจอ สายเวทย์ต่างๆยกเว้น วิซาร์ด ก็ เหมือน agi เลยคับ โดดฟัน ก่อนที่จะโดนร่ายเวทใส่ แต่ จะมีเครดิตดีกว่าสาย agi ตรงที่ อาจจะไม่โดนเวททีเดียวตายคับ

ถ้าเรา vit เจอ วิซาร์ด + solid aura ..... สู้ไม่ได้คับ ( สำหรับผมนะ ) ฟันช้า โดนวิซาร์ด ยิง วิ่ง ใส่เกราะ ไปเรื่อยๆ ฆ่าไม่ได้คับ เส้า T^T

ถ้าเรา vit เจอ สายบู๊ agi - -" ดวง + dex คับ สกิล ทีแรกจะโดนมั้ย แล้วโดนทีเดียวจะตายมั้ย ถ้าไม่โดนเราก้อตายคับ เอิ้กๆ

ถ้าเรา vit เจอ สายบู๊ vit - - สูสีคับ ใครเบอเซิกก่อนมีสิทธิ์ชนะสูง
