สาเหตุ - ส่วนใหญ่ปัญหานี้จะกิดกับร้าน internet ที่ทำการลง program การจัดการร้านค้าไว้
ซึ่ง program เหล่านี้จะทำการ block การ download หรือการเข้าเวปต่างๆ
วิธีแก้ไขเบื้องต้น - แนะนำให้เจ้าของร้าน เปิด "port 21" ซึ่งเป็น port ที่ใช้สำหรับการ update patch ต่างๆ
ถ้าเป็น program ฟรี อาจจะต้องทำการลบ program นั้นๆแล้วลงใหม่
ส่วนถ้าเป็น program ลิขสิทธิ์ - ให้ทำการติดต่อเจ้าของ program เพื่อเปิด port 21 ดังกล่าว


แบบว่าเล่นคอมตัวเองอ่ะนะ เล่ยอยู่ทุกวันอยู่ดีๆ มาเป็น แล้ว แก้ยังไงหรอคะ[/quote]
