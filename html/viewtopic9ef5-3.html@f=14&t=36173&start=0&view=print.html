ถามรายละเอียดสกิล berserk ครับ

โพสต์แล้ว: จันทร์ 28 ม.ค. 2008 9:49 pm
โดย ECO
ผมลองอัพดูแล้ว มันบ้าแล้วฟันแหลกเลยอ่ะ

ทีนี้ยังไม่ได้ลองอัพ berserk control

ใครที่ใช้บ่อยๆนะครับคุยให้ฟังที ว่า

-การที่เราจะคุมตัวได้นี่ อัพ int มันเพิ่มเยอะไหม berserk control ถ้าอัพเต็มแล้วนี่จะคุมได้เยอะไหม ขอแบบประมาณก็ได้ครับ ว่าซัก 10 ที นี่คุมได้กี่ที ถ้าเป็นไปได้มาคุยให้ฟังทั้งแบบมี int และไม่มีจะดีมากเลยครับ

-ถ้าคุมไม่ได้นี่จะบ้าไปประมาณ 10วิ แล้วถ้าคุมได้นี่ สกิลจะอยู่นานเท่าไรครับ

อันนี้ทราบแล้วครับ ถ้าบ้าขึ้นมา
-ตีแรง คูณสอง
-สกิลติดเมื่อเลือดลดลงกว่า 30%
-ถ้าคุมไม่ได้อยู่นาน 10sec
-การคุมสำเร็จขึ้นกับค่า int และ ระดับสกิล berserk control

แต่ที่มาโพสถามเพราะว่าลองอัพดูแล้วไม่ค่อยชอบมันคุมไม่ได้อ่ะ
แถมใช้ aresของพระก็ไม่หายบ้าด้วย อยากจะใช้ให้ดีแบบที่มันไม่บ้าอ่ะ ชอบตีแรงๆ
แต่ไม่รู้ว่าอยู่นานเท่าไร ---ยังไม่ได้อัพ berserk control นะครับ---
แนะนำด้วยนะครับ แบบว่าอยากใช้เก็บเวลอ่ะ

ตามข้อมูลที่ได้รับมา
Berserk Control Lv.5 จะมีโอกาสคุมได้ 30%
Berserk Control Lv.5 + Int 30 จะมีโอกาสคุมได้ 50%

ย้ำ! นะคับ ย้ำ! ว่ามีโอกาสคุมได้เท่านั้น

เท่าที่สังเกตุดู โอกาสที่จะคุม berserk ได้ น่าจะคล้ายๆ กับโอกาสการติด critical ของดาบ 2 มือ ดังนั้นบอกไม่ได้ว่าติด 10 ที จะคุมได้กี่ที โอกาสที่จะคุมได้มันเป็นแบบ ครั้งต่อครั้ง คับ ดังนั้น ถ้าอัพ int ในแต่ละครั้งที่ติด berserk ก็จะมีโอกาสคุมได้เพิ่มขึ้นกว่าตอนที่ไม่ได้อัพคับ

ในกรณีการติดสกิล berserk แล้วคุมได้ จะอยู่ในสถานะ berserk 30 วิ โดยประมาณ (จำเวลาที่แน่นอนมะได้อ่ะนะ เลยต้องประมาณ)

และในกรณีที่ติดสกิล berserk แล้วคุมไม่ได้ จะแบ่งได้อีก 2 กรณี คือ
1. ไม่มีมอนเดินป้วนเปี้ยนอยู่ด้านหน้าตัวละคร มันจะมีสภาพคล้าย confuse ไป 10 วินาที
2. ถ้ามีมอนอยู่ด้านหน้าตัวละคร มันจะวิ่งไปฟัน แล้วจะติด berserk ต่อไปอีกรวมเป็น 30 วินาที (เท่ากับตอนคุมได้)

ปล. ถ้าจะใช้เก็บเวลก็แล้วแต่ฝีมือพระอ่ะนะ ฮ่าๆๆ
