บัตรผ่านรับได้จาก ชายลึกลับในบ้านในเมืองฟาอีส ซึ่งต้องบอกรหัสผ่าน
รหัสได้จากผู้ชายคนที่เราส่งอาหารเพื่อskill point ตอบชื่อหมาตามสีที่ถูกต้องเค้าจะบอกรหัสผ่านมา

รหัสง่ายมาก แต่ไม่อยากบอกเด๋วไม่สนุก (รหัสเป็นภาษาอังกฤษ ไม่ต้องใส่เครื่อง[])

พอบอกรหัสถูกเราจะได้บัตรผ่านเข้าไปในหอรบของกลุ่มผู้ลึกลับได้

NPC หลอมitemต้องทำเควสคิดหน่อย รับเควสได้จากหัวหน้ากลุ่มลึกลับ ส่งยาไปที่เกาะนักบวชด้านหลัง (เซฟที่จุดเซฟอยู่หลังตึกกับพกกุญแจไปด้วย ไม่งั้นกลับไม่ได้)
ไปกลับ2รอบ เธอจะยอมหลอมitemให้กับเรา โดยมีข้อแม้ว่า
- ต้องเป็น Eqiup ชนิดเดียวกัน (มีดกับมีด,รองเท้ากับรองเท้า,โล่กับโล่ อื่นๆ)ไม่สามารถหลอมของต่างประเภทกันได้
- ความสำเร็จขึ้นอยู่กับเลเวลของของทั้ง2สิ่ง
- ความเข้ากันได้ ฯลฯ อื่นๆอีกมาก

ก่อนตกลงหลอมจะมี%การสำเร็จบอกอยู่
ในเกาะนั้นจะมีชุดเลเวล60 อยู่ทุกอาชีพ ด้านหลังเกาะจะมีอีกเกาะนึง ชื่อเกาะไม่ฝักฝ่ายใด มีมอนเตอร์โจรสลัด เหมือนข้างนอกอยู่ไว้สำหรับเก็บเลเวล

ช่วยตอบให้แบบพอจะรู้คร่าวๆ
1. Item ชิ้นที่เคยหลอมแล้ว (ติดดาวแล้ว) เอาไปหลอมต่อได้นะ การหลอมก็ดีอีกอย่างหนึ่งคือ ค่า ทนทานจะกลับเต็มเท่าเดิม(อาจเพิ่มขึ้นด้วยเพราะ Item ที่หลอมเพิ่มมามันมีเยอะ)
2.หลอมได้เฉพาะ item ชิ้นที่เราใส่ได้(เลเวลถึงกำหนดแล้ว แต่ไม่เจาะจงต้องสวมได้) สามารถนำของที่เรา ใส่ได้หรือเลเวลถึงกำหนดไปหลอมรวมกับของเลเวลที่สูงกว่าตัวละครเราได้ (แต่หลอมเสร็จ เราก็จะใส่ไม่ได้อยู่ดีเพระ ความสามารถนั้นเป็นของ Item ที่เลเวลสูงกว่า แต่ผลของภาพที่แสดงออกมาตอนสวมใส่ จะเป็นของเลเวล ต่ำ)
อีกกรณีคือ ไม่สามารถนำ Item ชิ้นที่เลเวลสูงกว่าตัวละคร มาหลอมเป็นตัวแสดงผลเวลาใส่

**Fake คืออะไรหว่า?
**ตัวแสดงผล คือ Item ที่เราต้องการใส่แล้วให้ปรากฎเป็น Item ชิ้นนั้นๆ

ยกตัวอย่าง(ที่ Chii เคยหลอม)
Chii ชอบ โบว์ใหญ่ติดหลัง แต่อยากได้ Def เยอะๆ ก็เลยไปซื้อหมวกทางใต้มา( ที่ Def 5 )

แล้วเอาไปผสม

ของต้นแบบให้แสดงผล = โบว์ใหญ่ติดผมข้างหลัง
ความสามารถที่ต้องการ = หมวก Def 5

หลอมแล้ว รูป Icon ของไอเทมที่ออกมา จะเป็นรูปของหมวก Def 5 แต่จะมีดาวติดอยุ่
พอใส่แล้ว จะเป็นโบว์ ที่มี Def 5
