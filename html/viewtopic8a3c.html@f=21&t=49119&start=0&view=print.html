ตอนที่1~เคียวกับยูคาริ

งึมงัม~~โอ๊ยนี่มันกี่โมงแล้วเนี่ยผมหันไปมองนาฬิกาอ้อ7โมงครึ่งหรอกรึฮ่าๆไม่เป็นไรนอนต่อๆ.....เฮ้ยอะไรนะ7โมงครึ่งเหรอเวรแล้วจะไปทันมั้ยเนี่ยผมรีบวิ่งลงมาโดยที่ผมยังไม่ได้กินข้าวเช้า-____-"แน่นอนทำไมผมต้องรีบขนาดนี้เหรอก็วิชาแรกตอนเช้าเป็นวิชาของอาจารย์ยูทานิน่ะสิ ถ้าผมไปสายอีกมีหวังผมโดนสั่งให้ยืนหน้าห้องอีกแน่ โอ๊ยแฮ่กๆ~~ทันเวลาพอดีผมเปิดประตูเข้าห้องไปและนั่งที่โต๊ะของผมเอง ซักพักนึงเพื่อนผมทักมาอย่างที่ทักประจำ ไงเคียววิ่งหอบแฮ่กๆเป็นสุนัขบ้าไล่งับคนเลยสิแก55+~ เพื่อนของผมที่ชื่อยูจิทัก "เออแล้วแกนึกว่าชั้นเดินมารึไงขืนทำงั้นก็โดนจารย์ยูทานิลงโทษอีกอ่ะดิ-__-" อืมมันก็จริงเพื่อนซี้ผมมันพูดด้วยท่าทางกวนๆแล้วกลับไปนั่งที่เดิม เฮ้อผมล่ะเบื่อวิชาของอาจารย์ยูทานิจริงๆเล๊ย~~เพราะเวลาผมเรียนทีไรผมแทบจะหลับทุกทีน่ะสิเซ็งจริงๆ ผมมองออกไปนอกหน้าต่างพลางคิดว่าชีวิตของผมนี่มันน่าเบื่อจริงๆเล๊ยมันน่าจะมีอะไรสนุกๆหน่อยสิอย่างเช่นว่าสลับร่างอะไรแบบเนี้ย55+ ผมเหม่อได้ซักพักผมรู้สึกว่ามีอะไรลอยมาโดนหัวผมจึงมองดูว่ามันคืออะไร"ชอล์ก"ผมอุทานด้วยเสียงเบาๆพลางมองไปที่อาจารย์ยูทานิอาจารย์ขยับแว่นนิดนึงและพูดว่า"นี่ห้องเรียนนะไม่ใช่ที่บ้านจะได้เหม่อไม่สนใจการเรียนมีอะไรจะแก้ตัวมั้ยเคียว มิทานิ" ผมนึกพลางคิดในใจว่าซวยแล้วและมันก็ต้องเหมือนเดิมผมต้องออกมายืนหน้าห้องเฮ้อรู้งี้ผมมาสายยังดีกว่าอีก-_____- หลังจากหมดวิชาอาจารย์ยูทานิผมจึงเดินเข้าห้องไป ผมเห็นเพื่อนกำลังคุยกันอยู่ผมก็ไม่รู้นะว่าเค้าคุยกันเรืองอะไรผมจึงเข้าไปถาม เพื่อนผมจึงตอบกลับมาว่า"เคียวแกไม่รู้เหรอว่าห้องข้างๆเราน่ะมีเด็กใหม่สวยโครตเลยนะเว้ย" ผมจึงถามไปว่าเหรอถ้าสวยแล้วทำไมแกไม่จีบแบบที่ชอบทำประจำล่ะยูจิจึงตอบกลับมา"แกไม่รู้อะไร ก็เพื่อนของยัยนี่น่ะสิโหดจิ๊บเป๋งรู้สึกจะชื่อยูคาริมั้งนะ" ห่ะๆผมหัวเราะอย่างเบาๆเพราะยัยยูคารินี่เป็นคนที่เค้าลือกันว่าโหดถึงขนาดต่อยผู้ชายสลบ
-_____- แต่เค้าก็ลือกันว่ายัยยูคาริก็สวยไม่แพ้เพื่อนเธอ ผมจึงบอกเพื่อนเค้าไปว่า"แกก็ไปจีบเธอตอนที่ยัยยูคาริไม่อยู่สิ" ยูจิพูดกลับมาว่า"เอาเหอะแกลองไปดูเธอก่อนละกันว่าสวยขนาดไหน" ผมก็บอกว่า"เออไปก็ไปรอกินข้าวเสร็จละกัน55+" หลังกินข้าวเสร็จผมจึงลองไปดูสาวสวยคนนั้นที่ยูจิว่าพร้อมกับยูจิมัน!! เฮ้ยๆนั่นไงเดินมาโน่นแล้ว ผมจึงหันไปดู"แม่เจ้าโว้ยสวยโครตๆจริงด้วย"ผมคิด แต่ก็ความงามของเธอคนนั้นได้ไม่นานเพราะยัยเพื่อนของเธอน่ะสิหันมาหาผมและเพื่อนพร้อมตรงหรี่เข้ามาและกระชากคอเสื้อผมกับเพื่อนผม "หวาดูท่ายัยนี่จะโหดอย่างที่เค้าลือกันจริงๆด้วย!!"

อ่าเมื่อยตอนต่อไปเดี๋ยวขอเขียนพรุ่งนี้ละกันค่ะเข้ามาอ่านแล้วช่วยCommentหน่อยนะคะขอบคุณฮับ^^

ตอนที่2~เจ็บแล้วไม่จำ
"โอ๊ยให้ตายเถอะยัยนั่นแรงเยอะชะมัด"ผมบ่นออดแอด "เฮ้อให้ตายเหอะทำไมยัยนั่นถึงโหดขนาดนี้นะแค่จะขอชมโฉมเพื่อนคุณเธอหน่อยก็ไม่ได้55+"ยูจิพูดอย่างสนุกแผมไม่สนุกไปกับมันเลยนะเพราะผมเป็นคนที่โดนหนักที่สุดนะสิ "แล้วเราจะเอาไงต่อดีวะยูจิพูดพลางพร้อมเอายาแดงมาป้ายที่แขนผมเล่น "ข้าว่าเรากลับไปเรียนเถอะเดี๋ยวโดนจารย์บ่นอีก~อ้อแล้วก็ยาแดงน่ะจะเล่นก็เอาไปป้ายขาแกสิโว้ย" พูดจบผมก็ลุกขึ้นกระชากขวดยาแดงมาจากมันและเทราดไท่ขามัน "เฮ๊ยแกเล่นไรวะเนี่ย" เอาคืนไงผมพูดพร้อมเดินกลับไปที่ห้องเรียนอย่างเซ็งๆ "งายนายเคียวสุดเก่งไปแอบดูสาวสวยแล้วโดนเพื่อนเธอเล่นงานล่ะสิ" ไคเพื่อนสนิทของผมอีกคนหนึ่งพูดด้วยความสนุก "แล้วถ้าไม่โดนเล่นงานแผลที่หน้าผมมันจะขึ้นมาได้
เรอะ"ผมคิด-______- "แต่ทำไมนะผมถึงรู้สึกแปลกๆเหมือนเธอไม่อยากจะเล่นงานพวกผมเท่าไหร่" เอาล่ะงั้นเย็นนี้ผมจะลองดูอีกที "เคียวเมื่อวานนายยังเจ็บไม่พอหรือไงว๊าถึงจะมาให้เจ้าหล่อนเล่นงานอีกน่ะ" "เออน่าถ้าแกกลัวแกก็กลับไปก่อนละกันยูจิ" "ชะไม่เอาหรอกก็ฉันอยากเห็นหน้าสาวสวยคนนั้นอีกนี่นา" ยูจิพูดด้วยท่าทางสนุก "ตามใจนาย"ผมรอตอนที่ยูคาริจะออกจากห้องมาพร้อมกับเพื่อนของเธอ นั่นไงเธอออกมาแล้วผมจึงวิ่งรี่เค้าไปถามเธอทันที "เอ่อคุณยูคาริ...ผะ.ผมอยากจะถามคุณว่าเมื่อวานคุณตั้งใจเล่นงานพวกเเหรอครับ" ให้ตายสินี่ผมถามคำถามบ้าอะไรออกไปนะที่จริงที่ผมอยากถามมันไม่ใช่แบบนี้นี่ เธอช้อนหางตามามองด้วยสายตาน่ากลัวยังกะจะกินผมแน่ะ-_____-" "นายพูดเรื่องอะไรอ๋อหรือว่าอยากจะโดนชกอีกรอบได้งั้นชั้นจะสงเคราะห์ให้นายเอง!!" "หวาเวรแล้ว" แต่ก่อนที่ผมจะหลุดคำนั้นออกมาผมโดนยูคาริชกกระเด็นก่อนแล้ว "ให้ตายเถอะผมนี่เจ็บแล้วไม่จำจริงๆนะ!!"
