ด้วยความเห็นส่วนตัว...

AGI 99 หรือ 108
INT 80 หรือ 90
VIT 65 หรือ 75
STR 91 หรือ 99 หรือ 108

แนะนำให้ลองอัพดูโดยเลือกค่าจากที่บอกนี่
จะเป็น Gunner ที่มีความสมดุลในระดับสูง

ขออธิบายรายละเอียด ดังนี้

STR ก็แค่ให้ยิงแรงๆ มอนจะได้ตายไวๆ!!!
ความถึกเกิดจาก VIT ที่มีค่ามากกว่า60 ก็ถึกพอสำหรับสู้กับมอนในฟิวล์ทุกตัวแล้ว
การอัพ INT ให้มีค่ามากจะช่วยให้ได้ค่า m.def ที่มากขึ้น จะทนกับเวทย์ได้ดี แถมยังเพิ่ม L.hit ด้วย
(โดยส่วนตัว ถือว่า INT ในอาชีพนี้ คุ้มค่าที่จะอัพมากที่สุด เพราะได้ค่าปลดปล่อยถึงสองชนิด)
การอัพ AGI ที่ค่า 99 หรือ 108 เป็นค่าที่ช่วยให้หลบหลีกการโจมตีของมอนบนฟิวล์ได้ถึง 80-90%

โดยสรุปคือการอัพแบบนี้จะช่วยให้มีความทนทานต่อเวทย์สูง แล้วหลบการโจมตีทางกายภาพได้ดี
แบบนี้เรียกว่าถึกในสายตาของเรานะ

แต่ถ้ามองว่าความถึกดูจากเลือดเท่านั้น ก็อัพไปแต่ VIT อ่ะ ไม่ต้องคิดมาก
