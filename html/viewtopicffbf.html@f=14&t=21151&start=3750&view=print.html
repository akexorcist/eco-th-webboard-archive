คิดในวงเล็บก่อนดิ ถ้ามีหลายเครื่องหมาย ก็คิด * / ก่อน

= Cast Time * (1 - ASPD/1000)
= 6.5 * (1 - 712/1000)
= 6.5 * (1 - 0.712)
= 6.5 * 0.288
= 1.872 sec.

ถ้า Aspd 800 ก็ร่าย 1.3 sec.
