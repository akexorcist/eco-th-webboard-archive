ตัวละครของเค้าเหรอคะ???

อินุกามิ โคทาโร่คุงในเรื่อง"คุณครูจอมเวทย์เนกิมะ"มีอิทธิพลกับตัวละครซึกิโนะส่วนนึง(นามสกุลน่ะนะ ก้ออยากเป็นส่วนนึงของอินุกามิคุงหนินา =w=).
แต่โดยความสามารถกับตัวละครนั้นเกิดขึ้นจากจิตนาการของตัวเองล้วนๆบวกกับตำนาความเชื่อเรื่องสตรีหิมะหรือเจ้าหญิงหิมะของชาวญี่ปุ่นอีกนิดหน่อย(?).จึงเกิดมาเป็นสาวน้อยน่ารัก(เหรอ?)ซึกิโนะจังขึ้นมาค่ะ.

ส่วนอาวุธที่เป็นพัดนั้นได้แรงจินตนาการมาจาเรื่อง "อินุยาฉะเทพอสูรจิ้งจอกเงิน" ซึ่งเป็นพัดที่ของนางรำปีศาจ"คากุระ"ของฝั่ง นาราคุ ใช้เป็นอาวุธค่ะ. ตอนแรกๆก้อกะจะให้ตัวละครของหนูใช้กระจกผนึกวิณญานนะ. แต่ว่ามันก้อออกจะดูโกงเกินไปเลยหันมาใช้พัดแทนดีกว่านะ....


จบจ้า~ ของตัวไปถ่ายโฆษณา ครีม Faris ต่อละนะ

ชื่อเล่น : ไลท์
อายุ : 15 (แต่หน้าตาดูเด็กๆ)
น้ำหนัก : เบาเหมือนขนนก!! 40!
ส่วนสูง : เตี้ยเหมือน ... = = 160
เพศ : หญิง!
เผ่า : อีมิล
อาชีพ : มาริโอเนส!!!
อาวุธ : มือเปล่าๆเพียวๆ~กับร่างที่แสนบอบบาง
มาริโอเน็ต : Mermaid!!
ชุด : ชุดมาริโอเนสสี"ดำ" ทรงผมของ"Tita"สีดำ
นิสัย : - ขี้กลัว
- ชอบยิ้มอยู่บ่อยๆ (ถึงจะไม่มีเรื่องให้ยิ้ม)
- จะเป็นคนเงียบๆถ้าไม่มีเพื่อนคุยด้วย

- มองโลกในแง่ดี ^^ (ถึงแม้ตอนนั้นเพื่อนรอบข้างจะบอกว่ามันแย่ก็ตาม = =")
- ชอบของหวาน
- กลัวเลือดเยอะๆ(ต้องเยอะจริงๆนะ= ,=).. สิ่งนี่จะทำให้ไลท์คลั่ง
- ชอบสะสมของจุกจิกโดยเฉพาะตุ๊กตามาริโอเน็ต
จุดเด่น : เสียงที่เพราะจนควบคุมจิตใจได้ (ลัล~ลา)
จุดด้อย : ค่อนข้างจะเป็นจุดด้อยที่ดูติ๊งต๊อง เพราะเธอ! ความรู้สึกช้า! ช้ามากจะเรียกไลท์ ต้องเรียกซ้ำไปซ้ำมาสักสามครั้งถึงจะหัน
ภูมิหลัง : อันที่จริงแล้วไลท์ก็ไม่ใช่คนซะทีเดียว...แต่เป็นมาริโอเน็ตที่ทำให้มีจิตใจ ถูกสร้างจากใครคนหนึ่งซึ่งไม่ทราบแน่ชัด และเหมือนมนุษย์ตอนนี้จึงดูเหมือนคู่เหมือนคนทุกประการ
อื่นๆ : ไลท์ติ๊งต๊อง!! ซุ่มซ่าม! เป็นคนที่มักจะถูกมอนสเตอร์ไล่ต้อนประจำ! เช่น เวลาอยู่ในโบราณสถาน(ดันเจี้ยน)กับเพื่อนๆ เพื่อนๆเดินอยู่ดีๆไม่มีมอนสเตอร์ที่ไหนมาตบมาตี แต่ไลท์เดินไปที..... เพื่อน : "อ๊ะนั้นมันคาบไลท์จังไปแล้ว!"

รูปร่าง-หน้าตาของตัวละคร ตาสีแดง ผมสีชมพู สวยมากๆๆๆ(น้อยกว่าโยซึ่งเป็นหุ่นยนต์)ผอม สูงไม่มาก
เครื่องแต่งกาย - ใส่กิโมโนสีขาว ผมรวบใว้ด้านหลัง ตรงคอมีหยกที่ท่านพ่อไห้ไว้ก่อนหายไป

อุปนิสัยใจคอ – ร่าเริงมาก~มากๆๆๆๆๆ ติ๊งต๊อง แอ๊บแบ๊ว เชื่อคนง่ายมาก มองโลกในแง่ดี(ขอบอกดีมากๆๆๆ)
ภูมิหลังของตัวละคร/วัตถุประสงค์ในการเข้าร่วมเกม - เคยมีทั้งคนรัก ทั้งครอบครัวบัดนี้ทั้งหมดได้หายไปแล้วจึงต้องตามหา~ มีหุ่นยนต์รับใช้คือโย
อื่นๆ - ปกติแล้วเวลาต่อสู้จะออกคำสั่งโยตลอดจนเหมือนคน...โง่=,,,=แต่ที่จริงแล้วริกะฉลาดมากแต่คิดว่าถ้าฉลาดเกินคนอื่นจะไม่มีคนรัก ท่าพิเศษคือสามาเพิ่มอิท+189และวิท+189ได้ =,,=จบแย๊ว

ทรงผม: ผมสีดำ ข้างหน้าข้างหลังและด้านข้างชี้ๆ ปลายผมด้านหลังยาวและมัดเอาไว้
นิสัย : มั้นใจในตัวเอง สูบบุหรี่จัด(ติด) ชอบสัตว์ตัวเล็กๆ ชอบเขกหัวคนอื่น
หน้าตาดูเหมือนคนอารมไม่ดีตลอดเวลา ยิ้มเวลาเจอคู่ต่อสู้เก่งๆ ใจร้อน
จุดเด่น : ขอบตาที่ดำแต่กำเนิด
ร่างกายที่แกร่งจากการฝึกฝนและประสบการ ทำไห้ไม่ต้องพึ่งชุดเกราะ
มาพร้อมกำปั้นที่บดหินได้
จุดด้อย : มากมาย ทำไรไม่ค่อยคิด ออกแนวพวกมีกำลังไร้สมอง ยุขึ้นง่าย
สู้ไม่ค่อยเต็มที่ถ้าอีกฝ่ายเป็นผู้หญิง
ภูมิหลัง : เดินทางตามหาคู่ต่อสู้เพื่อพิสูจตัวเองหลังจากฝึกฝนมวยจีนขั้นสูงสำเร็จ
แต่มักไช้การต่อสู้แบบนักเลงมากกว่า จะไช้มวยจีนเมื่อเอาจริงเท่านั้น
อื่นๆ : เข้าร่วมเพื่อท้าพระราชาสู้ แน่นอน คำขอของเขาคือ ขอไห้พระราชาเป็นคู่ต่อสู้
