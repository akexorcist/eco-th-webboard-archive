เอ่อ พูดถึงเรื่อง NPC ส่งซิริโก๊ะเนี้ย ขอกล่าวถึงเซิฟโมจิหน่อยนะเจ้าค่ะ ที่เปิดช้ากว่าเซิฟทาโก แต่ยังไงซะขอเอ่ยนามผู้เสียสละในการขนซิริโกะเปิดNPC ให้ทำบ้านทั้งเซิฟละกัน (ขอเอ่ยนามเจ้าที่ขนมาส่งที่ละมากๆละกันนะค่ะ เพื่อนๆคนไหนที่ส่งแล้วมะได้เอ่ยนามต้องขออภัยด้วยจ้ะ )

อันดับแรก ต้องขอขอบคุณเจ้าของกระทู้ คุณย้งยี่ ที่เป็นแม่งาน

ลำดับต่อมา ริง หน้าราม ที่รวมคนทั้งริง เดินโยนๆซิริโกะ จนถึงNPC ตั้งแต่เย็นจนถึงตี1 และเรื่อยจนถึงตอนเช้า 9โมง จึงเปิดNPC ทำบ้านได้ (ขอบอกว่าหลายหมื่นชิ้นมากๆ)

นอกจากนี้ยังมีคุณ AmaGi Joker Iberry SakuraIceChan LockeCole หมอเทรุ สมาชิกริง Harvest Moon และเพื่อนๆ น้องๆ พี่ๆ แรนเจอร์ตัวน้อยๆ นักดาบ แอส และอีกหลายๆคนที่ไม่ได้เอ่ยนามมานะจ้ะ

อันนี้ขอพื้นที่ให้พวกเค้าหน่อยละกัน เพราะเห็นเด๋วนี้มีแต่โชว์พาวด่ากันไปมาในPVP ว่าใครเกรียน ใครเทพ ว่างๆ หัดลืมตา แล้วมาทำสิ่งดีๆ ต่อส่วนรวมแบบเค้าเหล่านี้บ้าง

หากใครที่ไม่รู้ ว่างๆ เจอบุคคลเหล่านี้ก็อย่าลืมแวะไปขอบคุณพวกเค้าบ้าง เพราะการที่พวกเค้าเสียสละทั้งแรงทรัพย์ แรงกาย และเวลา มันทำให้พวกคุณมีบ้าน แล้วไปท้ากันแหยงๆ

อ๋อฝากอีกเรื่อง วันนี้ไปนั่งในPVP แล้วเห็นเด็กคุยEng กัน ทับกันไปถมกันมา ว่าอินเตอร์ คืออยากจะบอกนะ ว่าเก่งพูดEng ได้ แต่อย่าลืมว่ากำพืดเป็นคนไทย ในประเทศ อาจดูกิ๊บเก๋ แต่ออกไปนอก เค้าก็เหยียดผิวพวกเราทั้งนั้น รักกันไว้เถอะคนไทย ก้าวให้ทันโลก แต่อย่าลืมกำพืดตัวเอง

ป.ล.พอดีไม่ได้ไปมีเรื่องอะไรกับพวกเค้าหรอกนะ แต่เห็นพูดๆ กัน มีแต่ด่าหยาบๆ แล้วดูถูกสัญชาติตัวเองไงมะรู้ เอาเป็นว่าพี่มาเตือนน้องละกัน
