...อืมครับเด่วจะไปดู...ฝากนี่ด้วยและกัน...แบบนี้ใช่ป่าวก่าจะได้ชุดใบเรือ...^.^

Rotary Sail Set = Rotary Sail 6ใบ > สร้างโดย NPC Flying Garden ที่ Map Fareast Highway

Rotary Sail > ใช้สกิล Item Refine Lv.3 ในการสร้าง ประกอบด้วย:

- Log 1 ท่อน
- Water Proof Fabric 5 ผืน
- Wood 5 ชิ้น
- Great Strap 5 เส้น

Water Proof Fabric > ใช้สกิล Sew. Create Lv.4 ในการสร้าง ประกอบด้วย:

- Greater Cloth 1 ผืน
- Row 4 ชิ้น

Great Strap > ใช้สกิล Sew. Create Lv.2 ในการสร้าง ประกอบด้วย:
- Great Thread 4 หลอด

Great Thread > ใช้สกิล Sew. Create Lv.2 ในการสร้าง ประกอบด้วย:
- Thread 1 หลอด
- Row 1 ชิ้น

...สรุป...ไอเท็มที่จำเป็นต่างๆทั้งหมดเพื่อสร้าง Rotary Sail Set ก็น่าจะเป็น- Log 6 ท่อน
- Water Proof Fabric 30 ผืน = ( Greater Cloth 30ผืน + Row 120ชิ้น )
- Wood 30 ชิ้น
- Great Strap 30 เส้น = Great Thread 120 หลอด = ( Thread 120 หลอด + Row 120 ชิ้น )

...ใช่ไหมครับ ^__^'

...แล้วของทั้งหมดนี่อะไรหาซื้อจากNPCที่ไหนได้...รึดรอปจากมอนตัวใดที่ไหนบ้างก็ช่วยทีนะครับ...ช่วยบอกเราหน่อย

ขอบคุณครับ ^.^
