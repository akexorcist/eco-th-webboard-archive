FAQ:พิมพ์ไทยได้ไหม
ตอบ : ได้ แต่เนื่องจากเซิฟจีนใช้คนละ font กับเราทำให้มองไม่เห็น วรรณยุกต์ และพวกสระอิ อี อึ อือ
วิธีแก้คือเอาโฟลเดอร์ xls (อยู่ใน \data\xls\ ) ของไทยไปทับจะทำให้ font อ่านไทยได้ ใครลบตัวเกมไทยไปแล้ว
ไปโหลดเฉพาะ xls ได้ที่ http://www.mediafire.com/?olrqgp39fp0p300 เครดิตคุณ Tenshiro Kanake
***แต่อย่าลืม สำรองไฟล์ดั้งเดิมไว้ เนื่องจากการไฟล์ของไทยจะทำให้
มองไม่เห็น item หลายชนิดในเซิฟอินโด ทำให้อาจต้องเปลี่ยนสลับกลับไปมา

FAQ:เซิฟจีน จะโดนปิดเหมือนของ ไทย, มาเลย์, สิงคโปร์, เกาหลี, อินโด ไหม
ตอบ : ไม่ทราบ แต่ก็มีความเป็นไปได้ที่จะโดนปิดเช่นกัน แต่ส่วนมากจะอวสานกันที่ saga 10.2 ทำให้สบายใจไปได้เยอะ
เกี่ยวกับการปิดของเซิฟจีน แต่เมื่อมีเกมเเปิดมาก็ต้องมีการอำลา มันเป็นเรื่องปกติ

FAQ:เซิฟแลคไหม
ตอบ : เท่าที่ทดลองมาและเพื่อนๆทดลอง ก็แทบจะไม่แลคเลย ลื่นไหลสบาย ๆ กันเลยทีเดียว
แต่ตอนเริ่มดึกจะแลคๆหน่อย อยู่ที่เน็ตของแต่ละคนด้วย ยิ่งแรงยิ่งลื่นปรื้ด ♥

FAQ:เซิฟปิดอัพแพทช์วันไหน
ตอบ : เซิฟจีน ปิดซ่อมบำรุง, อัพแพทช์, ลงขอตั๋ว ฯลฯ ทุกวันอังคาร เวลา 10.00 - 12.00 น.
แต่มี late บ้าง ไม่ตรงเวลาบ้าง (ผลัดวันบ้างประจำ) เปลี่ยนวันบ้าง แล้วแต่อารมณ์แอดมิน server เจอมาหลายทีละ
พอๆกับเซิฟไทยนี่แหละ

FAQ:เซิฟจีนพวกเกรียนเยอะไหม
ตอบ : ไม่ค่อยมีเท่าไร ถ้านิสัยดีก็ดีมาก ถ้าเกรียนหรอยังไม่เห็นแหะ ขอให้สนุกกับการเล่นนะจ้ะ ♥
