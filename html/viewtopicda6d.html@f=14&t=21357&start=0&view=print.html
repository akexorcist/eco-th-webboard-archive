วิเคราะห์สกิล+คริ 2 อย่าง

แอสเซา

ข้อดี
1. อยู่นาน 30วิ ทำให้ไม่ต้องกดบ่อย
2. มี icon ลด def จาก vit พอมันหาย ก็ทำให้รู้ว่าเราต้องกดใหม่

ข้อเสีย
1. โอกาสคริน้อยก่า สกิลคริติคอล น่าจะราวๆ 30%
2. ลด def จาก Vit ครึ่งนึง

คริติคอล

ข้อดี
1. โอกาสคริมาก 50%แน่ะ
2. ไม่มีผลลบ def

ข้อเสีย
1. อยู่แปปเดียว 6วิ ทำให้กดบ่อย 1ตัวต่อ1สกิล เลยก่อว่าได้ (แต่ความจิงเสียเวลา ก่าจะกดตีอีก หายไปอีก1-2วิ)
2. ไม่มี icon บอก ต้องดูใน System บอกว่า สถานภาพ คริติคอล ได้หายไปแล้ว ลูกเดว

ปล. สกิลแอสเซา กดร่ายซ้อนก่อนของเก่าหมด จะไม่เริ่มนับใหม่ พอหมดของเก่า ก่อหมดไป ทำให้ถ้าอยากใช้อีก ต้องรอของเก่าหมดก่อน :wink:
