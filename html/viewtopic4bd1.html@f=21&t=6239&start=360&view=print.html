รายงานความคืบหน้าครับ

บทหน้านี้มีความเข้มข้นทีเดียว ( แต่คนที่ชอบฉากตุ่อสู้อาจต้องรอกันนิดนึง เพราะตอนหน้าคงยังไม่มีประกายไฟแห่งการทำลายสักเท่าไหร่ )

แต่ความน่าสนใจอยู่ที่...

- ตัวละครรับเชิญ ' ชุดเด็ก ' ( ผมเรียกแบบนี้อ่านะ ^ ^" ก็คือชุดที่ได้ออกเป็นเพื่อนของรอยคุงทั้งหมด ) จะได้เผยกัน ณ ตอนหน้าจนครบแน่นอน ( มี 5 - 6 คนเลยทีเดียว )

- เปิดเผยประวัติต่างๆ ตอนหน้านับว่าเป็นการเปิดเผยอดีตที่คลุมเครือเกือบทั้งหมดเลยทีเดียว อาทิเช่น อดีตของแอโร่ ไอรีน่า และออร์ซาร์ด / อดีตของศาสตรา สมัยยังคงอยู่ในมือของกษัตริย์ดาเรียส

- เปิดเผยกลุ่มชน ' ดีส ' ซึ่งพวกเขามีความสำคัญต่อเนื้อเรื่องมากพอๆ กับการดำเนินไปของศาตราเลยทีเดียว

- อันนี้ต้องขออภัยคนอื่นๆ เล็กน้อย ที่ตัวละคร " ไอรอน " จะได้โชว์มากเป็นพิเศษในตอนที่ 2 ครับ >_<" บทของเธอ ' โดน ' ในช่วงเนื้อเรื่องนี้ครับ ( คนอื่นๆ อย่าเพิ่งน้อยใจไปน๊า~ )
