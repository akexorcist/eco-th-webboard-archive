แต่ลงทะเบียน สามารถเลือกลงได้ทิศเดียว ตัวไหนตัวนั้นด้วยนะครับ

ถ้าลงใต้ = บ้านจะบินไปเมืองใต้ได้

ลงทิศเหนือ = บ้านก็จะบินไปเมืองเหนือได้


อ่อ....ลงทะเบียนไม่ได้หมายความว่า ทั้งไอดีนะครับ

สมมุติว่า ตัวแรก ลงทะเบียนไว้ ทิศใต้ เวลาที่ขึ้นไปบนบ้านบินแล้วจะมี

ตัวเลือกปลายทางเมืองใต้ แล้วจะมีขึ้นให้เฉพาะตัวละครตัวแรก เท่านั้นครับ

เอาตัวที่สอง ขึ้นบ้าน ก็จะไม่มีตัวเลือกไปเมืองใต้

สรุปง่ายๆคือ ตัวไหนลงทิศไหนก็ได้ของตัวนั้นอ่ะครับ
