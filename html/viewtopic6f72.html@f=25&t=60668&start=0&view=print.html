ถามเรื่องการขี่หุ่นยนต์ และการอับหุ่นนะครับ
ขี่หุ่นยนต์ต้องใช้สกิส ทาทา คราส3ใช้มะครับ แล้วการอับมันใช้เอาไปล้มเหมือนสัตว์อื่นหรอป่าว และเห็นที่ดาวทาวเขาขาย ทานซิดเต้อ(พิมผิดขออภัย) เห็นว่าให้เอาไปอับหุ่น ใช้ยังไงครับไอ่นั้นนะ เห็นมีให้เลือกค่าด่วย แล้วบางตัวขาย หลักหมื่น กับอีกแบบอับเล้กหว่า เห็นขายอยู่ 3พันมั่ง(ราคาเมื่อ5เดือนที่แล้ว ไม่ค่อยได้เดินตลาดครับ) ขอคำอธิบายแบบเต็มๆหน่อยครับ อยากเล่นสายหุ่น
