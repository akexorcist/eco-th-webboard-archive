อธิบายโดยรวมคร่าวๆดีกว่า = =

นี่คือหน้าต่างหลักของโปรแกรม (เล็กน้อยดี) หน้าแรกจะเป็นส่วนของ General
จะมีรายละเอียดของโปรแกรมและให้ปรับได้เล็กๆน้อยๆ มีดังนี้
Start Fraps minimized เวลาเปิดโปรแกรม โปรแกรมจะซ่อนอยู่ในแถบโปรแกรมทางขวามือตลอด (ใกล้ๆนาฬิกาในคอม)
Fraps window always on top ให้โปรแกรมอยู่ด้านบนสุดของจอคอม ไม่ว่าจะเปิดโปรแกรมไหนอยู่ โปรแกรมนั่นจะไม่บังหน้าจอโปรแกรม Fraps
Run Fraps when Windows Starts ให้โปรแกรม Fraps เปิดใช้งานทันทีที่เริ่มเปิดคอม
Monitor Aero Desktop (DWM) ให้โปรแกรมทำงานที่เดสก์ทอป (ปกติโปรแกรมนี้จะทำงานเฉพาะโปรแกรมที่เราเปิดใช้งานอยู่)
Minimize to system tray only เมื่อย่อโปรแกรม โปรแกรมจะซ่อนในแถบโปรแกรมทางซ้ายมือ (ใกล้ๆนาฬิกาในคอม)


นี่คือส่วนของ FPS หรือก็คือ Frame Per Second ที่จะบอกว่า โปรแกรมของคุณทำงานที่ Framerate เท่าไร (ยิ่งเยอะแปลว่ายิ่งลื่น)
ในโซนซ้ายมือผมไม่ขออธิบายนะ เพราะเป็นส่วนของการ Benchmark หรือทดสอบการทำงาน แต่ถ้าใครจะใช้ก็ลองดู เพราะดูแล้วก็พอเข้าใจได้
ส่วนโซนขวามือ จะประกอบไปด้วยดังนี้
Overlay Hotkey เซทปุ่มสำหรับปิดเปิดการแสดงเลข Framerate (อยากรู้มันคือเลขอะไร เปิดโปรแกรมปุปคุณจะเห็นทันใด...)
ต่อมาคือการปรับตำแหน่งที่จะให้แสด Framerate ที่ตำแหน่งต่างๆของจอ
Only Update overlay once a second คือให้ค่า Framerate เปลี่ยนค่าทุกๆ 1 วินาที (ปกติมันจะเปลี่ยนแปลงแบบ Realtime)


ต่อมาคือส่วน Movies เป็นส่วนที่เราเซตติ้งสำหรับการอัดวีดีโอนั่นเอง ประกอบไปด้วยดังนี้
Folder to save movies in เราสามารถเลือกได้ว่าจะให้โปรแกรมอัดวีดีโอแล้วเซฟไว้ที่ได้ โดยกดที่ปุ่ม Change หรือ View เพื่อเปิดโฟลเดอร์นั้นทันที
Video Capture Hotkey ปุ่มลัดที่ใช้กดเพื่ออัดวีดีโอ ในรูปผมจะเซ็ทให้กดปุ่ม End เพื่อเริ่มอัดวีดีโอ (และกดปุ่มนี้อีกครั้งเพื่อหยุดถ่ายวีดีโอ)
Video Capture Settings กำหนด FPS ที่จะให้บันทึก และกำหนดขนาดของจอโปรแกรมได้ว่าจะเอาเต็มจอโปรแกรมหรือครึ่งนึงก็ได้
Sound Capture Setting กำหนดเสียงที่จะบันทึกในวีดีโอว่าจะให้อัดจากเสียงในคอมหรือจากไมค์
Don't sync audio and video เวลาอัดวีดีโอ จะไม่สนใจว่าภาพกับเสียงนั้นพร้อมกันหรือไม่ เห็นผลได้ชัดตอนอัดวีดีโอแล้วกระตุกๆ ต้องไปลองเองดีกว่า
Hide Mouse cursor in Video ซ่อนเคอร์เซอร์ในขณะที่อัดวีดีโอ (มันแค่ไม่บันทึกภาพเคอร์เซอร์เม้าส์ตอนอัดวีดีโอนั่นแหละ ไม่ต้องกลัวว่าเราจะไม่เห็น)
Force lossless RGB Capture (May be slower) บันทึกภาพแบบสูญเสียน้อยที่สุด จะได้คุณภาพสีที่สมจริงที่สุด แต่ถ้าคอมไม่แรงจะทำให้คอมกระตุกตอนอัดได้
เวลาอัดวีดีโอ เลขที่บอก Framerate จะเป็นสีแดงนะ ถ้าไม่ได้อัดจะเป็นสีเหลือง


ต่อมาคือส่วน Screenshots เป็นส่วนที่เซตติ้งสำหรับการบันทึกภาพจากหน้าจอคอม
Folder to save screenshot in อันนี้คงไม่ต้องอธิบาย เหมือนกับ Video เป๊ะ
Screen Capture Hotkey อันนี้คงไม่ต้องอธิบาย เหมือนกับ Video เป๊ะ
Image Format นามสกุลภาพ ว่าจะบันทึกภาพแบบไหน (อันนี้ถ้าต้องการภาพคุณภาพดีผมก็ใช้ PNG แต่ถ้าไม่เอาไรมากนักผมก็ใช้ JPEG แทน)
Include frame rate overlay on screenshots เวลาถ่ายภาพจากจอจะเห็นเลข Framerate ติดอยู่ด้วย
Repeat Screen capture every [x] seconds (Until hotkey pressed again) เป็นการถ่ายภาพแบบต่อเนื่อง โดยสามารถกำหนดได้ว่าถ่ายทุกๆกี่วินาที
เหมาะกับการถ่ายภาพเรื่อยๆเป็นจังหวะ จะได้ไม่ต้องมานั่งกดถ่ายเองตลอด โดยจะหยุดทำงานเมื่อเรากดปุ่มลัดสำหรับถ่ายภาพอีกครั้ง
(ปุ่มเดียวกันใน Screen Capture Hotkey นั่นแหละ)
