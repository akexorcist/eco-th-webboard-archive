ปัญหามันแปลกๆเกิดจากหลังเปลี่ยนเป็นกลางคืนครับ

เหมือนมันแฮ็งๆไงไม่รู้ เพราะ พอเปลี่ยนเป็นกลางคืนเส็ด ฉากมันมืดไปหมด(ดำสนิท) เห็นแต่ชื่อของ NPC กล่อง(มีตัวเดียวจิงๆทั้งแผนที่) ผมก็เข้าไปคุยก้อคุยได้ปรกติ ก้อมีdem ออกมาคุย (แต่ฉากก้อยังดำมืดอยู่ดีไม่เห็นอะไรเรย นอกจากตัวเรา) พอคุยเส็ดใช้ของเส็ด ผมก็กลับเป็นกลางวันไม่ได้เพราะไม่มี npc ให้กลับ มืดไปหมด ก็เรยออกจากเกมส์แล้วเข้าใหม่ มันก้กลับมาเป็นกลางวันจากนั้น ก้อลองไปคุยกับพ่อค้าเลี่ยนเป็นกลางคืนก็ไม่ได้แล้วมันไม่ให้ไปกลางคืนแล้วอ่ะ ผมก็เรยไปที่หลุมศพ ก็ทำอะไรไม่ได้ คลิ๊กที่หลุดมศพไม่ได้ ทำอะไรไม่ได้ซักอย่าง

หรืออาจเป็นบั๊กตอนโหลดแพทช์เป่าครับเพราะ ผมเพิ่งได้มีโอกาสโหลดเอง แล้วก็เจอปัญหา 254 ไรเนี่ยแหละ ก้อแก้ไขตามบอร์ดแล้วนะ ที่ให้แก้ที่ notepad อ่ะ เพราะผมเห็นบั๊กหลายอย่าง ไม่ว่าจะเป็น item ตลอดที่ทำแมวมันเป็นเครื่องหมาย ? หมดเรย ของใน item mall ด้วย (อันใหม่ๆเท่านั้นนะ) แล้วnpc บางตัวก็ไม่มีรูป npc มีแค่ ชื่อในคลิ๊กแล้วคุเท่านั้นเอง แถมกิจกรรม ตีพูรูรูสีชมพู ทั้งๆที่ผมใส่ ปืน แล้วก้อกระสุนกิจกรรมแล้วก็ตามยิง ไม่เห้ฯได้เรย
