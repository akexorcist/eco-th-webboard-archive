- นิยายตอนที่ 3 ครับ ความยาวมากกว่าตอนที่ 1 อยู่หลายย่อหน้าเลย
- โรงละครหรรษา เป็นฟิคสั้นๆ ขำขันครับ
- ข้อมูลตัวละครทั้งหมดที่ปรากฏในบทที่ 1 ครับ ( ยืนยันใหม่ครับ ว่า 5 ผู้กล้าจะปรากฏชื่อและข้อมูลด้วยทั้งหมดครับ )
