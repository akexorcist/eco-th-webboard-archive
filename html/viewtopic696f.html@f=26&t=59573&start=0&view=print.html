หา log อย่าเอา farmer ไปตี fallen tree ครับ มันจะได้ strong wood แทน.. แนะนำให้เอาตัวอาชีพอื่นไปตีจะง่ายกว่า ส่วนแมพที่ fallen tree เยอะ ผมแนะนำ Nozarin cape ทางชายฝั่งด้านขวา (อ้อมลงขวาล่างแล้ววิ่งขึ้นขวาบน)

ส่วน wood นั่นได้จากต้นไม้ที่ชื่อ wood ครับ ถ้าเล่นชาวนาอยู่เคยส่งเควสได้ tree seed มั้ยล่ะครับ เมล็ดนั่นแหละปลูกแล้วเอาชาวนาทุบเลยครับ ตกง่ายมาก แต่ถ้าไม่มีเมล็ด ก็ต้องวิ่งหาหน่อยละกันนะครับ เพราะมันเกิดน้อยพอสมควร รอบๆ้เมือง กับ ป่าอโครเนีย

แต่ผมคิดว่าเอาชาวนาไปตีแหละดีแล้ว ถึงยังไงมันก็ได้ Strong wood มาใช้

ดวงดีก็ได้ Log เองละครับ มันค่อนข้างดรอปยากหน่อย

ถ้าอาชีพอื่นไปตี ถ้าไม่ได้ Log ก็คือ ลม หรือไม่ก็ เศษไม้ไปเลยนะครับ
เพราะอาชีพอื่นก็ใช่ว่าจะตกง่ายกว่านะ มันก็ต้องดวงเหมือนกัน

แล้ว wood ชาวนาตีได้จากต้น wood ที่ฟุจิจะเกิดเยอะและถี่มาก อาจได้ Big Log มาทำใบเรือบ้านบินด้วย

แต่วิธีง่ายที่สุดคือ ซื้อ npc ที่ขายถ่านบ้านบินแหละครับ อันละ 800 (ถ้าจำไม่ผิด)

ช่วงนี้ไม่ได้เอาอาชีพอื่นๆไปหา นอกจากชาวนา เพราะต้องใช้ strong wood 1 ชม. ก็ได้ log มา อย่างน้อย 1-2 ชิ้นแล้ว ง่ายกว่าเมื่อก่อนตั้งเยอะ ตีเป็น ชม. ยังแทบจะไม่ได้เลย ถ้ารีบใช้อาชีพอื่นๆดีกว่าเพราะ tree knowledge ของชาวนาทำให้โอกาสได้ strong wood สูงมากๆ (เท่าที่ตีมาจะได้พอๆกับเศษไม้เลย ส่วนยาเขียวไม่เคยเก็บมานับ)

เพิ่มเติม ถ้าเอาชาวนาตี fellen tree มีโอกาสได้ green wood ด้วย

ปล. อย่างที่โพสทุกครั้ง "เวลาหาของ ถ้าอยากได้อะไรจะไม่ค่อยได้ ทำใจให้สบายๆค่อยๆตีไป เดี๋ยวก็ได้เอง"

ตี wood แล้วได้ zedar wood โอกาสน่าจะได้ยากมากนะ ปลูกมาเป็นพันเมล็ด เพิ่งจะได้zedar wood 3 ชิ้นเอง (เราได้ zedar wood จากกล่อง 11 มากกว่าหาจาก wood ตั้งเยอะ)
