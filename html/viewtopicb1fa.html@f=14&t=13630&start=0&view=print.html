17 ลูกใหญ่ + 1 ลูกเล็ก = 52 พอย
แต่ถ้านับแบบผมคือ 49 + 3 + 3 เป็น 55 พอยอ่ะคับ
จากตอนเริ่ม 1 อัพถึง 50 ก็คือ 49
เริ่มเกมส์จ๊อบ 1 จะมีให้ 3
และสกิลที่ได้มาหลังเปลี่ยนอาชีพจะนับเป็นอีก 3 คับ

ส่วนพอยฟรีตามนั้นคับ ผมก็นึกว่าเป็นบั๊กอยู่เควสเดียวนะนั่น
