weapon ถ้าไม่ได้ตี้กับสาย fighter ไม่ได้ใช้เลยครับ แล้วถึงจะตี้ด้วย แต่เรายิงเองเลยก็แรงกว่าจะไปบัฟช่วยให้สายไฟต์นะครับ
ผมว่าไม่น่าอัพเลย ให้สายไฟต์ชนกับลากอย่างเดียวก็พอ ดาเมจไม่ต้องพี่จัดเอง

shield นี่ควรอัพไว้เล่นเรื่องธาตุ ถ้าไม่อยากอัพหมดทุกธาตุ ก็อัพให้เหมาะสมกับตัวที่เก็บเวลบ่อยๆก็ได้ครับ

แต่อย่างน้อยๆ shield น้ำ ควรอัพเพราะเป็นแต้มสกิลรวมให้คลื่นได้
