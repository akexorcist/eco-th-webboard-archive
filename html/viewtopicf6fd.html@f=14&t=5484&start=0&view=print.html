>พื้นฐาน Archer
ชี้แจงเกี่ยวกับ Archer จุดเด่น จุดด้อย สเตตัสที่สำคัญ สายการเล่นต่างๆ ที่เป็นไปได้

>สถานที่เก็บเลเวล
แนะนำการเก็บเลเวลของ Archer

>สกิลที่แนะนำให้อัพ
สกิลที่อัพแล้วจะช่วยให้เก็บเวลง่ายขึ้น

>เปลี่ยนอาชีพ Archer
เควสการเปลี่ยนอาชีพเป็น Archer

>เปลี่ยนอาชีพ Strike
เควสการเปลี่ยนอาชีพเป็น Striker และการรับไข่สัตว์เลี้ยง

>ข้อมูลชุดเกราะ
ข้อมูลเกราะ เลเวลที่ใส่ได้ ราคา สถานที่ที่หาซื้อ

>ข้อมูลธนู
ข้อมูลธนู เลเวลที่ใส่ได้ ราคา สถานที่ที่หาซื้อ
