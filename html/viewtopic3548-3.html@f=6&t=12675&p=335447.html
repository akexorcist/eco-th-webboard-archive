Azure เขียน:~Mail and Bilboard System~

ส่งเมล์ให้เพื่อนกัน!

การใช้ Mail System จะทำให้สามารถส่ง Message ให้เพื่อนในเกมได้ เนื่องจากเมล์นั้น จะถูกบันทึกไว้ใน Game Server ดังนั้นจึงสามารถส่ง Message ได้ทั้งในสภาพที่เป้าหมาย offline อยู่

การสร้างเมล์

Mail Window นั้น จะแสดงออกมาโดยการกดปุ่ม friend ที่อยู่ด้านล่างของ Main Window หรือ Short cut key "Ctrl+F" จากนั้นกดปุ่ม mail ที่มีอยู่ทางขวาของ Friend Window

1. รับเมล์ แสดงรายการของเมล์ที่ได้รับแล้ว
2. ส่งเรียบร้อย แสดงรายการของเมล์ที่ส่งเรียบร้อยแล้ว
3. สร้างเมล์ สร้างเมล์ใหม่
4. Option ยังไม่ใช้
5. ลบออก ลบเมล์ที่ส่งหรือรับแล้วออก

สร้างเมล์

ในกรณีที่สร้างเมล์นั้น ให้คลิกปุ่ม สร้างเมล์ ที่อยู่ทางด้านบนของ Mail Window เมื่อ Window สร้างเมล์ถูกแสดงออกมา ให้กรอกข้อมูล จุดหมายที่จะส่ง หัวเรื่อง ตัวเนื้อหา จากนั้นคลิกที่ปุ่ม ส่ง เมล์ก็จะถูกส่งเรียบร้อย

จุดหมายที่จะส่ง : ชื่อ Character ที่จะส่งเมล์ให้
หัวเรื่อง : ขอบข่ายของหัวเรื่อง

ตัวเนื้อหา : เนื้อหาของเมล์ * พิมพ์ด้วยอักษรเต็มได้ถึง 512 ตัว

เมล์ที่ส่งเรียบร้อยแล้ว จะถูกแสดงอยู่ในรายการ ส่งเรียบร้อย
การสร้างเมล์จาก Friend List
ในกรณีที่จะส่งเมล์ให้ตัวละครที่ได้ลงทะเบียนไว้แล้วใน Friend List แล้วนั้น ให้คลิกขวาที่ชื่อของตัวละครที่จะส่งให้ใน Friend List Window แล้วเลือกหัวข้อ Mail จากเมนูที่แสดงออกมา เมื่อเลือกแล้ว Mail Window จะแสดงออกมาในสภาพที่บ่งบอกจุดหมายที่จะส่งแล้ว

การรับเมล์

การจะรับเมล์นั้น ผู้ได้รับเมล์ จะมีไอคอนเมล์อยู่ทางซ้ายบนของหน้าจอ

ดับเบิ้ลคลิกที่ไอคอนเมล์นั้น ก็จะเปิด Mail Window และดูในหน้ารับเมล์ ก็จะสามารถอ่านเมล์ได้
เมล์ที่รับแล้วนั้น จะถูกแสดงในรายการของ รับเมล์ ของ Mail Window
เลือกเมล์ที่อยากจะเช็คดูจากรายการ โดยการดับเบิ้ลคลิกก็จะสามารถอ่านเนื้อหาข้างในเมล์ได้
เมล์ที่ยังไม่อ่านนั้น จะแสดงตัวอักษรด้วยสีเหลือง หากอ่านแล้ว จะแสดงตัวอักษรด้วยสีขาว

การตอบเมล์กลับ

เมื่อกดปุ่ม ตอบกลับ ก็จะสามารถเปิด Mail Window ใหม่ ในสภาพที่กรอกชื่อของตัวละครที่จะส่งกลับไว้แล้ว
เกี่ยวกับ Option
ในส่วนล่างของ Mail Window จะมีเช็คบ็อกซ์แสดงอยู่ ซึ่งใช้เลือกเกี่ยวกับการบันทึกเมล์ที่ได้รับ

บันทึกใน Client

หากติ๊กในช่อง บันทึกใน Client และปิด Mail Window ด้วยการกดปุ่ม ตอบกลับ เมล์ที่ได้รับนั้นจะถูกบันทึกไว้ใน Folder ที่ Install ECO
* ในกรณีที่ลบเมล์ด้วย Mail Window จากในเกม เมล์ที่ถูกบันทึกไว้ใน Client จะถูกลบด้วย

บันทึกใน Server

หากติ๊กในช่อง บันทึกใน Server และปิด Mail Window ด้วยการกดปุ่ม ตอบกลับ เมล์ที่ได้รับนั้นจะถูกบันทึกไว้ใน Server

การบันทึกเมล์ที่ได้รับแล้วใน Server นั้น จะสามารถบันทึกเมล์ในสภาพที่ยังไม่อ่านก็ได้ เมื่อบันทึกเช่นนี้แล้ว จะมีแสดงไอคอนของเมล์ที่ด้านบนซ้ายของหน้าจอเกม เมื่อล็อกอิน หรือกำลังเคลื่อนที่ใน Map

การลบเมล์

ในกรณีที่จะลบเมล์ จากรายการเมล์ที่ส่งแล้วหรือเมล์ที่ได้รับแล้ว นั้น ให้เลือกเมล์ที่อยากจะลบ และกดปุ่ม ลบออก ซึ่งเมล์ที่ถูกลบไปแล้วครั้งหนึ่ง จะไม่ผม้คืนกลับมาได้อีก


บอร์ดติดประกาศ

มาลองใช้บอร์ดติดประกาศกันเถอะ!

ใน Acropolis City นั้น จะมี บอร์ดติดประกาศ ตั้งอยู่ โดยที่บอร์ดติดประกาศนั้น ไม่ว่าใครก็สามารถกรอกได้อย่างอิสระ ซึ่งสามารถนำไปใช้ประโยชน์ได้อย่างหลากหลาย เป็นต้นว่าจะประกาศรับสมัคร Party หรือ Ring Party ก็ได้ แต่ในการกรอกข้อมูลขึ้นบนบอร์ดนั้น จำเป็นจะต้องใช้เงินด้วย ส่วนการอ่านบอร์ดเฉยๆ นั้นฟรี


ในบอร์ดประกาศนั้น จะแสดงเนื้อความกับหัวเรื่อง, เวลา และชื่อตัวละครที่กรอกข้อมูลไว้

วิธีใช้บอร์ดติดประกาศ

กรอกข้อมูล

คลิกที่บอร์ดติดประกาศ จะมีวินโดว์แสดงบอร์ดออกมา จากนั้นคลิกปุ่ม กรอกข้อมูล ที่ด้านซ้ายบน แล้วช่องกรอกข้อมูลก็จะแสดงออกมา

กรอกหัวเรื่อง และเนื้อหาลงไป จากนั้นกดปุ่ม Ok รายละเอียดทั้งหมดก็จะถูกตีพิมพ์บนบอร์ดทันที

* ในแต่ละบอร์ดนั้น ที่ด้านขวาของปุ่ม กรอกข้อมูล จะแสดงจำนวนเงินซึ่งจำเป็นต่อการกรอกข้อมูลเอาไว้ด้วย หากจำนวนเงินที่แสดงไว้ในส่วนนี้เป็น 0 ก็จะสามารถกรอกข้อมูลขึ้นบอร์ดนั้นได้ฟรี

* ถึงจะมีบอร์ดติดประกาศที่เสียค่าใช้จ่ายอยู่ด้วย แต่ในกรณีที่ดูข้อมูลที่ลงไว้เฉยๆ จะไม่เสียค่าใช้จ่ายใดๆ

แก้ไข Page ใหม่

หากกดปุ่ม แก้ไข ที่มีอยู่ตรงกลางส่วนบนของวินโดว์บอร์ดติดประกาศ ก็จะสามารถให้แสดงข้อมูลใหม่ได้

อ่านข้อมูลที่กรอกในอดีต

ที่ด้านขวาบนของวินโดว์บอร์ดติดประกาศ จะมีปุ่มตัวเลขอยู่ ซึ่งสามารถคลิกดู เพื่ออ่านข้อความที่กรอกไว้ในอดีตได้ โดยตัวเลขที่บอกหน้าเพจนั้น 1 จะเป็นเพจที่ใหม่ที่สุด และ 10 ก็จะเป็นเพจที่เก่าที่สุดซึ่งจำนวนการลงตีพิมพ์สูงสุดของบอร์ดติดประกาศคือ 50 เรื่อง ในกรณีที่มีผู้ลงเกิน ข้อความที่เก่าที่สุดจะถูกลบทิ้งไปโดยอัตโนมัติ

ระบบ Party

ในเกม ECO นั้นผู้เล่นสามารถสนุกกับการผจญภัยร่วมกับเพื่อน Character อื่นๆได้โดยการปาร์ตี้ ซึ่งเมื่อมีคนจำนวนมากเข้าร่วมปาร์ตี้ ก็จะมีประสิทธิภาพในการต่อสู้สูงกว่าการสู้เดี่ยวๆ ลองค่อยๆ ใช้ดูก็จะเข้าใจถึงความสนุกสนานของระบบปาร์ตี้นี้นะ

การจัดปาร์ตี้นั้นทำอย่างไร ?

Character ที่สร้างปาร์ตี้คนแรกจะกลายเป็น Leader (หัวหน้า) ทันที, แล้วจะสามารถชักชวนผู้อื่นเข้าร่วมปาร์ตี้ ได้ ซึ่งจำนวนสมาชิกมีได้สูงสุดถึง 8 คน

Party Leader นั้นสามารถกำหนดขอบเขตอำนาจหน้าที่อย่างไรก็ได้

ทำการคลิกขวาใส่ตัวละครที่ต้องการจะชวนเข้าปาร์ตี้ จากหัวข้อที่แสดงออกมาให้เลือกหัวข้อ ชวนร่วมปาร์ตี้

ตัวละครที่ถูกชักชวนเข้าปาร์ตี้นั้น จะได้รับวินโดว์ เชิญร่วมปาร์ตี้หากกด OK ก็จะเข้าร่วม กด Cancle ก็จะเป็นการปฏิเสธไม่เข้าร่วม

ข้อดีของการปาร์ตี้

1 ) การแบ่งค่าประสบการณ์และโบนัส
สมาชิกในปาร์ตี้ทุกคนจะได้รับค่าประสบการณ์หลังจากกำจัดมอนสเตอร์ได้ แล้วยังมี Bonus ค่าประสบการณ์เพิ่มตามจำนวนคนในปาร์ตี้การคิดค่าโบนัสมีตามกรณีต่างๆ ดังนี้
ยิ่งจำนวนสมาชิกที่ร่วมโจมตีในปาร์ตี้ยิ่งมาก ค่า Bonus ประสบการณ์ก็จะยิ่งสูงไปด้วย
และจะได้รับค่าประสบการณ์ที่สูงขึ้นอีก หากล้ม Monster ด้วยสมาชิกในปาร์ตี้เต็มขีดจำกัด 8 คน
และในกรณีที่ทำการ Possession ใส่สมาชิกในปาร์ตี้เดียวกัน, ผู้ Possession จะได้รับค่าประสบการณ ์ Possession ในเวลาเดียวกันกับค่าประสบการณ์ในปาร์ตี้
ตัวอย่าง โจมตี Monster ที่ให้ค่าประสบการณ์ 100, Bonus ค่าประสบการณ์หลังจากจัดการได้แล้วเป็นดังนี้
กรณีที่คว่ำด้วยการโจมตีเพียง คนเดียว.................ค่าประสบการณ์เป็น 100
กรณีที่คว่ำด้วยการโจมตี 2 คน.................ค่าประสบการณ์เป็น 130
กรณีที่คว่ำด้วยการโจมตี 3 คน.................ค่าประสบการณ์เป็น 145

ค่าประสบการณ์ที่ถูกแบ่งให้กับสมาชิกในปาร์ตี้แต่ละคน จะแตกต่างกันตามเลเวลของตัวละคร นอกจากนี้ จะต้องระวังว่าจะไม่ได้รับการคำนวณแบ่ง Bonus ค่าประสบการณ์ หากอยู่ในเงื่อนไขที่จะได้รับค่าประสบการณ์ดังต่อไปนี้

เมื่ออยู่คนละ Map กับParty Member ที่ทำการล้ม Monster
สมาชิกในปาร์ตี้ Log Out อยู่
การโจมตีของผู้ทำ Possession ที่ถือว่าเป็นการโจมตีของเจ้าของ

2) สามารถตรวจสอบ Status และ ตำแหน่งปัจจุบันของสมาชิกใน Party ได้

สามารถตรวจสอบสถานะต่างๆ ของ Member ที่ร่วม Party ได้ 3 วิธีดังนี้
ที่ Tab Party ของ Window Friend List สภาพการเชื่อมต่อ ณ ปัจจุบัน และชื่อ Map ที่อยู่เป็นต้น

Window ข้อมูล แสดง HP/MP/SP และ Status ผิดปกติ เป็นต้น
Map Window ในกรณีที่อยู่ใน Map เดียวกัน, จะบอกจุดอย่างละเอียด

ที่ Tab Party ของ Window Friend List
วิธีการเปิด Tab Party ใน Window Friend List
1. กดปุ่ม Friend บน Menu Button ที่อยู่ด้านใต้ของ Main Window, หรือ เปิด Window Friend List ด้วย Shortcut Key "Ctrl +F"
2. กด Tab Party ใน Window Friend List
สิ่งที่แสดงใน Window Friend List ที่ Tab Party จะแสดงรายละเอียดคือ
ชื่อตัวละคร อาชีพ LV/Job LV ชื่อ Map ที่อยู่ สถานะการเชื่อมต่อ


Window ข้อมูล
ถ้าใช้ Window ข้อมูล, จะสามารถตรวจสอบสภาพ HP/MP/SP, Status ผิดปกติ ของ Party Member ได้
เป็นต้น ซึ่งจะสะดวกมากในตอนผจญภัยร่วมกับ Party Member
วิธีใช้ Window ข้อมูล จะใช้วิธีไหนก็ได้ดังนี้
1. Double Click ที่ ชื่อของสมาชิก ใน Tab Party ของ Window Friend List
2. Click ขวาที่หัวข้อ แสดงรายละเอียด บน Character ของ Party Member

Map Window
หากมีสมาชิกในปาร์ตี้อยู่ใน Map เดียวกันกับ Character ของตนเอง, ก็จะมีการแสดงที่ตั้งปัจจุบันใน Map Window อย่างชัดเจน

ลูกศรสีแดง คือ ทิศทางและตำแหน่งที่ตั้งของ Character ของตนเอง
จุดสีแดง คือ สถานที่อยู่ของ NPC
จุดสีเหลือง คือ สถานที่ที่มี Warp Ring (จุดเคลื่อนย้ายไปยัง Map ต่อไป)
จุดสีต่างๆ คือ ตำแหน่งปัจจุบันของ Party Member

3. หลังทำการ Log Out สภาพของ Party ยังดำเนินต่อไป
ถอนตัวออกจาก Party, โดยไม่ได้ยุบ Party ถึงจะ Log Out แล้ว Party ก็ยังคงดำเนินต่อไป

Ring

Ring นั้น เป็นเรื่องของ Group ที่สามารถสร้าง Player ได้ โดยพื้นฐานแล้ว Ring เป็น Group ที่ประกอบขึ้นด้วย Member คงที่ โดยมี Ring Master เป็นศูนย์กลาง ต่อ Group ชั่วคราวที่ถูกยุบ

ด้วยการเข้าร่วม Ring นั้นจะทำให้สามารถใช้ Function Chat สำหรับได้ยินเฉพาะสมาชิกใน Ring Member ได้

ใน 1 Ring นั้น สภาพเริ่มแรกจะสามารถเข้าสังกัดได้ถึง 16 คน และยิ่ง Ring เจริญเติบโต มากเท่าไหร่ ก็ยิ่งขยายจำนวนคนสังกัดได้มากขึ้นอีก

การสร้าง Ring
การสร้าง Ring นั้น, ให้พูดคุยกับ NPC ชื่อ ผู้ดูแล Ring ที่อยู่ใน Up Town ของ Acropolice City ซึ่งมีขั้นตอนที่จำเป็น

ผู้ดูแล Ring มีความสามารถในการสร้าง Ring ตามเงื่อนไขที่กำหนด อย่างน่าพอใจ
Character ที่ทำการสร้าง Ring แล้วก็จะกลายเป็น Ring Master มีอำนาจหลากหลายในการจัดการกับ Ring

คุยกับ ผู้ดูแล Ring แล้วเลือกหัวข้อ สร้าง Ring โดยจำเป็นจะต้องเสียค่าธรรมเนียม 10,000 Gold จากนั้นจะมี Window ให้ป้อนชื่อ Ring แสดง ออกมา, เมื่อป้อนชื่อ Ring ที่จะสร้างเรียบร้อยแล้ว ก็กดปุ่ม OK โดยชื่อที่สร้างนั้น ต้องไม่ซ้อนทับ ชื่อ Ring ที่มีอยู่แล้ว

Possession System คืออะไร ?
Possession System นั้น คือการสวมวิญญาณเข้าไปอยู่ในไอเทมสวมใส่ต่างๆ ของตัวละคร, เมื่อตัวละครอื่นๆ สวมใส่ไอเทมที่มีการ Possession แล้วความคงทนของอาวุธจะไม่ลดลง ซึ่งถือเป็นความได้เปรียบในการต่อสู้

ตำแหน่งที่สามารถสวมวิญญาณเข้าไปได้นั้นมี 4 ตำแหน่งคือ แขนขวา แขนซ้าย เครื่องสวมใส่ท่อนบน Accessory ที่อก ซึ่งสามารถติดตั้งได้ 3 ตำแหน่งในเวลาเดียวกัน
ตัวอย่างเช่น, ที่มือขวาของเราถือ ดาบ อยู่ ซึ่งเป็นดาบที่ถูกผู้เล่นอื่นสิงไว้ ด้วยสภาพนั้น หากมีการแช็ทก็ดูราวกับว่า ดาบพูดได้ และเนื่องจากระบบนี้ สามารถกระทำได้สูงสุด 3 ตำแหน่งในเวลาเดียวกัน ผู้เล่น 1 คน จึงถูกสวมวิญญาณจากผู้เล่นอื่นได้อีก 3 คน กล่าวคือ ทั้งๆที่มีตัวละครแค่ 1 ตัว แต่สามารถร่วมมือปาร์ตี้กันได้ 4 คน, ซึ่งสามารถร่วมผจญภัยไปด้วยกัน พร้อมรับคำแนะนำต่างๆไปด้วยเช่น ไปขวาอีกหน่อย ศัตรูตัวนี้ต้องใช้ธาตุไฟนะ เป็นต้น

นอกจากนี้, หากผู้เล่นทำการล็อกเอ้าท์ทั้งๆที่ยังอยู่ในสภาพสวมวิญญาณอยู่นั้น ก็จะยังคงหลงเหลือสภาพการสวมวิญญาณอยู่ ยิ่งไปกว่านั้น เมื่อผู้เล่นอื่นทำการต่อสู้โดยที่ยังสวมใส่ไอเทมสวมวิญญาณอยู่ ก็จะแบ่งค่าประสบการณ์ให้กับผู้เล่นที่ล็อกเอ้าท์ไปแล้วด้วย พูดง่ายๆก็คือ Possession System นั้น สามารถได้รับความร่วมมือจากผู้เล่นอื่น ทั้งๆที่ล็อกเอ้าท์ไปแล้ว ซึ่งเป็นระบบที่ทำให้ตัวละครพัฒนาไปได้รวดเร็ว และนี่คือ "Possession System" ระบบใหม่ที่ถูกออกแบบมาเพื่อความรู้สึกประมาณว่า รู้สึกดีใจที่ได้พยายามเพื่อผู้อื่น

ข้อได้เปรียบของ Possession System
ตัวละครที่ทำการสวมวิญญาณ หากเกิดการต่อสู้ด้วยสภาพติดตั้งนั้น จะได้รับค่าประสบการณ์ด้วย โดยไม่สนใจว่าจะทำการ ล็อกอิน ล็อกเอ๊าท์ อยู่

หากล็อกอินอยู่ ก็สามารถใช้ Skill หรือ Item ในการสนับสนุนเจ้าของร่างได้

ในระหว่างทำการสวมวิญญาณอยู่นั้น ผู้ที่สวมวิญญาณ จะมีสภาพไม่ต่างจากอยู่ในเมือง นั่นคือ จะฟื้นฟู HP, MP, SP ด้วยสภาพที่ไม่ต้องทำอะไรเลย แต่หากเจ้าของร่าง ไม่สามารถกระทำสิ่งใดได้แล้ว (ตาย) HP, MP, SP จะไม่ฟื้นฟู
ตัวละครเจ้าของร่าง
Item Possession จะมีระดับประสิทธิภาพที่สูงกว่า Item ธรรมดา จึงสามารถนำไปใช้ในการต่อสู้ได้เป็นอย่างดี

Item Possession นั้นจะไม่มีการพังเสียหาย, จึงสามารถใช้ได้โดยไม่ต้องคำนึงถึงค่า ระดับความทนทานของ Item

ในกรณีที่ตัวละครที่สวมวิญญาณล็อกอินอยู่ ก็มีโอกาสที่จะถูก Damage ในตำแหน่งที่ติดตั้ง Item นั้นแทน

Azure เขียน:~Quest System~

Quest คือ?
Quest นั้น คืองานที่ถูกไหว้วานจาก Character ที่อยู่ใน Guild ของแต่ละอาชีพ หรือร้านเหล้า เมื่อเควสท์เสร็จสมบูรณ์ จะได้รับค่าตอบแทนเช่น ไอเทม, gold, ค่าประสบการณ์ เป็นต้น จึงเป็นระบบที่ง่ายต่อการเก็บเงิน และพัฒนาตัวละครด้วย

ประเภทของ Quest
เควสท์นั้นมีหลายประเภท เช่น ขนย้าย รวบรวม โจมตีขับไล่ เป็นต้น
Quest ขนย้าย นำส่งไอเทมที่ได้รับการไหว้วานมา โดยขนย้ายไปยังที่ต่างๆ
Quest รวบรวม รวบรวมไอเทมที่ได้รับการไหว้วานมา ตามจำนวนชิ้นที่กำหนด
Quest โจมตีขับไล่ จัดการกับ Monster ที่ได้รับการไหว้วานมา ตามจำนวน และใน Map ที่กำหนด

นอกจากนั้น ยังมีเควสท์ที่สามารถรับจาก NPC เฉพาะได้ด้วย เช่น เควสท์เฉพาะอาชีพ, Instant Dungeon Quest เป็นต้น

มาลองทำเควสท์ที่ท้าทายกันเถอะ

Step 1 รับเควสท์
คุยกับ Guild Master ของแต่ละอาชีพ หรือ Master ของร้านเหล้า เลือกหัวข้อ Quest Counter ก็จะมีรายการเควสท์ที่ผู้เล่นนั้นๆ สามารถรับได้แสดงออกมา

Step 2 เลือกเควสท์
เมื่อกดเลือกเควสท์ที่ต้องการจาก Quest List ที่ด้านบนของ Window จะแสดง [ประเภท] กับ [ระยะเวลาที่กำหนด] ไว้ด้วย และหากต้องการจะทราบรายละเอียดของเควสท์อย่างละเอียดก็สามารถกดที่ปุ่ม [รายละเอียด] ที่อยู่ทางขวาบนได้ ในกรณีที่ต้องการจะรับเควสท์นั้นๆก็เพียงแค่กดปุ่ม [ok] ก็จะสามารถรับเควสท์ได้ทันที
* หากไม่เลือกเควสท์ ก็จะกดปุ่ม [ok] ไม่ได้ กรุณากดปุ่ม [ok] เมื่อเห็นแถบสีน้ำเงินในหัวข้อเควสท์ที่เลือกแล้ว

หากกดปุ่ม [ขนย้าย][รวบรวม][โจมตีขับไล่] ที่มีอยู่ส่วนบนของ Quest List Window ก็จะสามารถกำหนดให้แสดงชนิดของเควสท์ได้
เมื่อปุ่มใดปุ่มหนึ่งจาก [ขนย้าย][รวบรวม][โจมตีขับไล่] เป็นสีเหลือง ก็หมายความว่าเควสประเภทนั้นแสดงรายการอยู่ แต่หากปุ่มใดเป็นสีดำ ก็หมายถึงปิดรายการเควสท์ประเภทนั้น
ในกรณีที่เป็นสีเหลืองทั้ง 3 ปุ่ม ก็จะอยู่ในสภาพที่แสดงรายการเควสท์ทั้งหมดนั่นเอง

สนับสนุน Quest Level
เควสท์ที่แสดงใน Quest List นั้น จะสามารถรับได้ทั้งหมดแต่ จะแบ่งสีของหัวข้อเควสท์ตามความแตกต่างของ Quest Level กับ Level ของตัวละคร

การตรวจสอบสีของหัวข้อเควสท์นั้น จะทำให้สามารถเลือกเควสท์ที่เหมาะสมกับ Level ของตัวละครได้

การเปลี่ยนแปลงตารางเควสท์ตามเลเวลของตัวละคร
ยิ่งเลเวลของตัวละครมากขึ้น ตารางรายการเควสท์ก็จะเปลี่ยนไปด้วย
เมื่อเลเวลสูงขึ้น ก็จะสามารถรับเควสท์ที่มีเลเวลสูงขึ้นได้
เมื่อเลเวลสูงขึ้น ก็จะไม่สามารถรับเควสท์ ที่เลเวลต่ำเกินไปได้
* การไม่สามารถรับเควสท์เลเวลต่ำได้นั้นเป็นการจำกัดเควสท์ที่สามารถรับได้จากทางร้านเหล้า
ประโยคสีเหลือง = เลเวลที่เหมาะสมที่สุด
ประโยคสีขาว = เลเวลที่พอดีๆ
ประโยคสีเทา = เลเวลไม่เหมาะสม

Step 3 ตรวจสอบเควสท์
เควสท์ที่รับทำแล้วนั้น จะสามารถตรวจสอบเควสท์ได้โดยการกดปุ่ม Menu Quest ที่อยู่ใต้ Main Window ซึ่งที่ด้านบนขวาจะมีปุ่ม [แสดงแผนที่] อยู่ หากกดดูก็จะสามารถตรวจสอบบริเวณที่เราต้องไปทำเควสท์ได้อย่างง่ายดาย

Step 4 เควสท์สำเร็จ
เมื่อเควสท์ที่รับทำนั้นครบตามเงื่อนไขทั้งหมดแล้ว Quest Window จะแสดงข้อความ เงื่อนไขของเควสท์สำเร็จแล้ว

Step 5 รับค่าตอบแทนของเควสท์
ถ้าเคลียร์เควสท์ที่รับเรียบร้อยแล้ว ก็ให้กลับไปคุยกับ NPC ที่รับเควสท์มา (Guild Master ของแต่ละอาชีพ หรือ Master ของร้านเหล้า ก็ได้) เมื่อคุยแล้วเควสท์ก็จะเคลียร์พร้อมกับได้รับค่าตอบแทน
* เควสท์นั้น ถูกจำกัดจำนวนครั้งที่สามารถรับได้ใน 1 วัน
จำนวนเควสท์ที่รับได้ในวันนั้น, สามารถตรวจสอบ จำนวนที่เหลือ ที่มีอยู่ที่มุมซ้ายล่างของ Quest Window นอกจากนี้ ที่มุมขวาล่างจะแสดงสภาพเวลาในการ ปรับปรุง และจะสามารถรับเควสท์ใหม่ได้อีก

มาใช้สำนักงานสาขาร้านเหล้ากัน
ที่สำนักงานสาขาร้านเหล้าที่มีอยู่ใน Field นั้น เมื่อคุยกับพนักงานร้านเหล้า ก็สามารถรับเควสท์ หรือรับค่าตอบแทน ได้เหมือนกับร้านเหล้าที่ Downtown นอกจากนี้ เควสท์ที่รับจากร้านเหล้าที่ Downtown ยังสามารถมารับค่าตอบแทนที่สำนักงานสาขาร้านเหล้าได้ โดยไม่ต้องวกกลับไปที่ร้านเหล้าที่ Downtown อีก

Cancel Quest
หากคุยกับ NPC ที่รับเควสท์อีกครั้ง เลือก Cancel Quest ใน Quest Counter ก็จะสามารถยกเลิกเควสท์ที่รับมาได้
*แต่ทว่า การ Cancel Quest หรือการทำเควสท์ล้มเหลว นั้น เป็นเรื่องที่เสียเกียรติมาก หากเป็นเช่นนั้น อาจจะมีการตอบกลับที่ไม่ดีจาก NPC ก็ได้.........

Repair System คือ?
อาวุธกับเครื่องป้องกันนั้น ในระหว่างการผจญภัย จะเริ่มสึกกร่อนกล่าวคือ ระดับความทนทาน นั้นจะน้อยลงเรื่อยๆ และนี่คือระบบ Repair System ระบบซ่อมแซมไอเทมที่ชำรุดด้วยค่า ระดับความทนทาน ลดลง หรือไอเทียมเสียหายด้วย ระดับค่าความทนทาน เป็น 0 แล้ว ให้กลับมาใช้ใหม่ได้อีกครั้ง

Point ของ Repair System
จำเป็นจะต้องใช้ ชุดซ่อมแซม ที่รองรับการซ่อมไอเทมแต่ละชนิด เพื่อที่จะทำการซ่อมแซมไอเทมนั้น
ชุดซ่อมแซมนั้น ไม่ว่าใครก็ใช้ได้ โดยไม่เกี่ยงว่าจะต้องมี Skill เฉพาะหรือไม่
ชุดซ่อมแซมนั้น จำเป็นจะต้องใช้ 1 ชิ้น ต่อการซ่อม 1 ครั้ง
เมื่อซ่อม 1 ครั้ง ระดับความทนทานสูงสุด ของไอเทมที่ถูกซ่อมจะลดลง 1
เมื่อไอเทมมีค่า ระดับความทนทานสูงสุด ต่ำกว่า 1 ก็จะไม่สามารถซ่อมไอเทมชิ้นนั้นได้อีก

ชุดซ่อมแซมนั้น สามารถสร้างขึ้นได้ด้วยการใช้สกิล Repair Kit โดยจะต้องจัดเตรียมวัตถุดิบที่จำเป็นในการสร้างด้วย

ระดับความทนทานที่สามารถฟื้นฟูด้วยชุดซ่อมแซมนั้น มิได้ถูกกำหนดด้วยชุดซ่อมแซมแบบเดียวกัน แต่จะถูกกำหนดเป็นพิเศษในตอนที่จะสร้างขึ้น ซึ่งระดับความทนทานที่สามารถฟื้นฟูได้ต่ำสุดคือ 1 และสูงสุดคือ 20

หากได้รับสกิลเฉพาะ จะมี Point ในตอนที่จะใช้สกิลสร้างชุดซ่อมแซมนั้นด้วย โดยจะถูกเพิ่มค่าต่ำสุดของระดับความทนทานที่สามารถฟื้นฟูได้ด้วยชุดซ่อมแซมที่ผลิตขึ้นเอง

ประโยชน์ในการใช้ Repair System
ในการซ่อมแซมไอเทมนั้น แน่นอนว่าระดับความทนทานสูงสุดของไอเทม จะลดลง 1 ทุกครั้ง จึงควรซ่อมแซมโดยใช้ชุดซ่อมแซมที่มีระดับความทนทานมาก ในกรณีที่ซื้อชุดซ่อมแซมมา, ชุดซ่อมแซมนั้นสามารถฟื้นฟูระดับความทนทานได้แค่ไหน ลองตรวจสอบดูให้แน่ใจก่อนก็ได้

Arena (สนามแข่งขัน)

แข่งขันกันด้วยสนามแข่งขัน!
ที่ Acropolis City จะมี สนามแข่งขัน ที่สร้างขึ้นเพื่อให้ผู้เล่นได้ทำการแข่งขันอยู่ ที่สนามแข่งขันนั้น ไม่ใช่การต่อสู้ของผู้เล่นกับมอนสเตอร์อีกต่อไป แต่เป็นการตัดสินหาผู้ชนะด้วยการต่อสู้ของ Player กับ Player นั่นเอง

* ปัจจุบันนั้น เป็นเพียงการต่อสู้แบบดวลตัวต่อตัว ซึ่งเมื่อหลังจากอัพเดตแล้ว ก็จะสามารถต่อสู้กันแบบกลุ่ม Party ได้

ลักษณะเฉพาะของสนามแข่งขัน

ที่สนามแข่งขันมีลักษณะเฉพาะดังต่อไปนี้
หลังจากเข้าสู่สนามแข่งขันแล้ว จะสามารถต่อสู้ได้เมื่อประกาศเข้าร่วม
ในบรรดาผู้ที่เข้าไปในสนามนั้น จะทำการต่อสู้ได้เมื่อประกาศเข้าร่วมการต่อสู้แล้วเท่านั้น

โดยจะมีโหมด สนามแข่งขัน (สู้รบ) สำหรับผู้ที่ต้องการเท่านั้น

สิ่งที่สามารถทำได้
เข้าหรือออกจากสนามแข่งขันได้อย่างอิสระ โดยไม่มีข้อจำกัดในเรื่องของเวลาและจำนวนครั้งที่เข้า
ไม่มีมอนสเตอร์ และ หีบสมบัติ ปรากฎออกมา
ถึงจะจัดการกับผู้เล่นอื่นๆได้ ก็ไม่ได้รับค่าประสบการณ์
ในสนามแข่งขัน จะมีความแตกต่างสำหรับโหมด เข้าชม กับโหมด สนามแข่งขัน ดังต่อไปนี้
โหมดสนามแข่งขัน สิ่งที่ทำได้ โจมตีใส่ตัวละครอื่นที่อยู่ในโหมดสนามแข่งขัน
ใช้สกิลฟื้นฟูและสนับสนุนตนเอง
จะเลิกเมื่อไหร่ก็ได้ และจะกลายเป็นผู้เข้าชม

สิ่งที่ไม่สามารถทำได้
การใช้สกิลฟื้นฟูและสนับสนุนผู้อื่นที่นอกเหนือจากตนเอง
โจมตีผู้เข้าชม

โหมดเข้าชม
สิ่งที่ทำได้
รับสกิลฟื้นฟูกับสกิลสนับสนุนจากผู้เข้าชม
เข้าชมการต่อสู้ของผู้เล่นอื่นที่อยู่ในโหมดสนามแข่งขัน
เข้าสู่โหมดสนามแข่งขันเมื่อไหร่ก็ได้ และสามารถเข้าร่วมการต่อสู้ได้ทันที
สิ่งที่ทำไม่ได้
ไม่สามารถโจมตีใส่ผู้เล่นคนใดในสนามแข่งขันได้
ใช้สกิลฟื้นฟูและสนับสนุนตัวละครที่อยู่ในโหมดสนามแข่งขัน

วิธีเข้าร่วม?

เข้าสู่สนามแข่งขัน
สนามแข่งขันนั้น จะสามารถเข้าได้ด้วยทางเข้าเฉพาะ ทางตอนเหนือของ Downtown และ หากคุยกับ NPC Owner ที่อยู่ตรงปากทางเข้า ก็สามารถเปลี่ยนจุดเซฟ มาอยู่ที่ปากทางเข้าได้

สมัครเข้าร่วม
คุยกับ NPC Staff หรือ Owner ที่อยู่ในสนามแข่งขัน แล้วเลือกหัวข้อ ประกาศเข้าร่วม หลังจากนั้น 15 วินาที ก็จะเข้าสู่โหมดสนามแข่งขัน และสามารถต่อสู้กับตัวละครอื่นๆ ที่ประกาศเข้าร่วมอยู่แล้วได้

สามารถโจมตี หรือใช้การโจมตีด้วยสกิล ใส่ผู้เล่นที่เข้าร่วมในโหมดเดียวกัน หากอยู่ในสภาพไม่สามารถกระทำได้ ตาย ก็จะย้อนกลับไปที่จุดเซฟ
ผู้เข้าชม จะแสดงชื่อตัวละครเป็นสีขาว ส่วน ผู้เข้าร่วม จะแสดงชื่อตัวละครเป็นสีแดง

หยุดการเข้าร่วม
ในกรณีที่อยากจะเลิก หลังจากที่ประกาศเข้าร่วมแล้ว ก็ให้กลับไปคุยกับ NPC Staff หรือ Owner อีกครั้ง และเลือกหัวข้อ หยุดการเข้าร่วม เมื่อเลือกเรียบร้อย ชื่อของตัวละครก็จะเปลี่ยนจากสีแดงกลับไปเป็นสีขาว และกลายเป็นผู้เข้าชม

ออกจากสนามแข่งขัน
หากต้องการจะออกจากสนามแข่งขัน ก็ให้ทำการคุยกับ NPC Staff หรือ Owner แล้วเลือกหัวข้อ ออกจากสนามแข่งขัน

ร้านซื้อขายไอเทมแผงลอย

ในกรณีที่เป็นอาชีพ Merchant หรือ Trader จะสามารถเปิดร้านเพื่อขายไอเทมของตนเองให้แก่ผู้เล่นคนอื่นๆได้
*หากเป็นอาชีพอื่นๆที่ไม่ใช่สาย Merchant ก็ยังสามารถตั้งร้านค้าขายไอเทมได้ด้วยการใช้ Golem

Marionette
ตัวละครที่เปิดร้านแผงลอยจะมีสัญลักษณ์ ตราชั่ง ติดอยู่ ส่วนการซื้อไอเทมจากผู้เล่นที่เปิดร้านแผงลอยนั้น ก็เพียงแค่ทำการคลิกขวาที่ตัวละครนั้นๆ แล้วเลือกหัวข้อ ดูร้านแผงลอย จากเมนูที่ปรากฎออกมา หรือจะใช้การดับเบิ้ลคลิกที่ตัวละครก็สามารถซื้อได้เช่นกัน

STEP1
ในกรณีที่เป็นอาชีพสาย Merchant เมื่อทำการคลิกขวาที่ตัวละครของตนเองจะมีหัวข้อ ตั้งร้านแผงลอย ปรากฎอยู่ในเมนู พอเลือกแล้ว ก็จะเปิดวินโดว์ที่ใช้ในการติดตั้งร้านแผงลอยออกมา


STEP 2
เคลื่อนย้ายไอเทมที่จะขายด้วยการ Drag & Drop จากวินโดว์ไอเทมด้านซ้ายบนของ window ตั้งร้านแผงลอย ไปวางยังฝั่งทางขวา หากไอเทมที่เคลื่อนย้ายมีจำนวนมาก ก็จะมีวินโดว์สำหรับกำหนดจำนวนชิ้นขึ้นมา


STEP 3
กรอกราคาที่จะขายในช่อง ราคา ที่อยู่ทางฝั่งขวาของ window ตั้งร้านแผงลอย ที่ด้านซ้ายล่างจะมี ช่องกรอก Comment อยู่, เมื่อผู้เล่นอื่นเลื่อนเคอร์เซอร์มาที่ตัวละครของเรา ก็จะเห็น Comment นี้ปรากฎอยู่


STEP 4
ตรวจสอบ ไอเทมที่ขาย, จำนวนเงินที่ตั้งขาย, จำนวนเงินที่กำหนดสูงสุด, จำนวนเงินที่กำหนดต่ำสุด เมื่อแน่ใจว่าไม่มีความผิดพลาดในการติดตั้งแล้ว ก็กดปุ่ม Ok เป็นอันเสร็จสิ้นการติดตั้ง


STEP 5
หลังจากติดตั้งเรียบร้อย ตัวละครที่เปิดร้านแผงลอยจะมีสัญลักษณ์ ตราชั่ง ติดอยู่ การซื้อไอเทมจากผู้เล่นที่เปิดร้านแผงลอยนั้น ก็เพียงแค่ทำการคลิกขวาที่ตัวละครนั้นๆ แล้วเลือกหัวข้อ ดูร้านแผงลอย จากเมนูที่ปรากฎออกมา หรือจะใช้การดับเบิ้ลคลิกที่ตัวละครก็สามารถซื้อได้เช่นกัน


การยกเลิกร้านแผงลอย
ในกรณีที่ต้องการจะยกเลิกร้านแผงลอย จำเป็นที่จะต้องนำไอเทมที่แสดงอยู่ทั้งหมดกลับสู่ วินโดว์ไอเทม ซึ่งจะต้องเคลื่อนย้าย ไอเทมวางขายทางฝั่งขวาไปยังวินโดว์ไอเทมที่อยู่ด้านบนซ้าย ด้วยการ Drag & Drop เมื่อเคลื่อนย้ายไอเทมกลับสู่วินโดว์ไอเทมครบหมดแล้ว ก็คลิกที่ปุ่ม Ok ร้านค้าแผงลอยก็จะถูกยกเลิก

มาลองกลั่น และ ผสม ไอเทมกันเถอะ!
สามารถใช้การกลั่น หรือการผสมไอเทมที่รวบรวมมาแล้ว ให้เกิดประโยชน์ได้โดยการเปลี่ยนแปลงไอเทมที่เป็นวัตถุดิบในการผสม ให้เป็นระดับที่สูง และบริสุทธิ์กว่า

การผสมไอเทมคือ?
การผสมไอเทมนั้น เป็นการผสมไอเทมหลายๆ ชิ้น ให้เป็นไอเทมพิเศษเพียงชิ้นเดียว โดยการรวบรวมวัตถุดิบจำนวนมาก แล้วผสมไอเทมวัตถุดิบเหล่านั้น เพื่อให้เกิดไอเทมใหม่ๆ ได้ และหากไอเทมใดเป็นวัตถุดิบในการผสม ก็จะมีเขียนไว้ชัดเจนว่าเป็น วัตถุดิบในการผสม ที่แถบ รายละเอียด ในวินโดว์ ข้อมูลไอเทม

การกลั่นไอเทมคือ?
เป็นการกำจัดสิ่งไม่บริสุทธิ์ออกไป และเพิ่มระดับความบริสุทธิ์ให้สูงขึ้น ซึ่งในส่วนของการกลั่น ก็จะทำการแปรรูปวัตถุดิบด้วย เมื่อกลั่นไอเทมแล้ว ค่า Payload จะน้อยกว่าไอเทมก่อนทำการกลั่น ทั้งยังนำไปใช้เป็นวัตถุดิบในการผสมได้ไอเทมได้ง่ายอีกด้วย

วิธีการกลั่น, ผสม ไอเทม
การกลั่น และการผสมไอเทมนั้น จำเป็นจะต้องไปขอร้อง NPC ที่เรียกกันว่า Item Maker's Teacher
ซึ่งจะต้องคุยกับ Item Maker's Teacher โดยมีไอเทมที่จำเป็นในการกลั่นและการผสมอยู่ด้วย จากนั้นเขาจะสอน Recipe ที่สามารถใช้กับไอเทมที่ถือครองอยู่ได้ แต่ทว่า เขาจะสอนเพียงแค่ Recipe การผสม การกลั่น ของไอเทมที่ตัวละครนั้นมีอยู่เท่านั้น ในบรรดา Recipe นั้น สามารถกำหนดปริมาณไอเทมที่ต้องการจะกลั่น หรือ ผสม ได้ เมื่อกดปุ่ม Ok แล้ว ก็จะสามารถผสม หรือกลั่นได้ทันที

ใช้สกิลของแต่ละอาชีพ
สามารถกลั่น และ ผสมไอเทม โดยใช้สกิลอาชีพของตัวละครได้ด้วย เช่นการใช้สกิลของ Farmer [Item Refine] [Wood Create]้ เป็นต้น

เรื่องของการล้มเหลว
การกลั่น และผสม นั้น มีโอกาสล้มเหลวได้ แต่ไม่บ่อยนัก
ในกรณีที่ล้มเหลว, ไอเทมที่ใช้ในการ กลั่น, ผสม จะหายไป และกลายเป็น [Mixture's Failure] (ของผิดพลาด)
ในตอนนั้น อาจจะนำของผิดพลาดจากการผสมที่มีอยู่ในมือ ไปแลกกับของบางอย่าง ที่ร้าน Junk ได้โดยไม่ต้องทิ้ง

เรื่องของช่องว่างที่จำเป็นใน Item Window
หากทำการกลั่น หรือผสมไอเทมไม่ได้ โดยถูกเตือนว่า ไม่มีที่ว่างในช่องไอเทม จะต้องลดจำนวนไอเทมลงก่อน แล้วจึงกระทำใหม่อีกครั้ง

จำนวนชนิดที่จำกัดในการถือครอง รวมทั้งไอเทมที่ติดตั้งอยู่ด้วยนั้น คือ 100 ชนิด แต่, ผลของการกลั่น ผสม อาจจะทำให้จำนวนไอเทมที่ถือครองนั้นเกินขีดจำกัด ในกรณีเช่นนี้ ก็จะไม่สามารถทำการกลั่น หรือ ผสม ได้
เงื่อนไขอย่างละเอียด
มีความเป็นไปได้ว่าผลลัพธ์ของการผสม จะทำให้ได้รับไอเทมมากกว่า 2 ชนิด ถึงแม้ว่าจำนวนที่นำมาผสมนั้นอาจเป็นแค่ชิ้นเดียวก็ตาม ดังนั้นก็จำเป็นที่จำนวนช่องว่างในไอเทมวินโดว์จะต้องเท่ากัน กับจำนวนชนิดของไอเทมที่อาจจะได้รับจากการผสมด้วย
* ไอเทมที่กลายเป็น Mixture's Failure ก็ยังคงถูกจัดการในลักษณะที่เป็นไอเทม 1 ชนิดอยู่ดี

ตัวอย่าง ในกรณีที่ผสม Apple ให้เป็น Dry Apple, เนื่องจากมีความเป็นไปได้ ที่จะได้สิ่งที่ล้มเหลวจากการผสมออกมา ดังนั้นที่ไอเทมวินโดว์ จำเป็นจะต้องมีช่องว่าง 2 ที่

มีไอเทมที่สามารถเก็บเข้าสต๊อกสินค้า จากไอเทมที่มีความเป็นไปได้ว่าจะได้รับจากการผสม ในกรณีที่ได้รับไอเทมด้วยสภาพที่มีไอเทมลักษณะนี้ ถึงจะมีการเตรียมสต๊อกเอาไว้ แต่ในตอนที่จะผสม ก็ยังจำเป็นจะต้องใช้ช่องว่างในไอเทมวินโดว์ที่มีจำนวนเท่ากันกับ จำนวนชนิดของไอเทมอยู่ดี
* เนื่องจากจำนวนสูงสุดในการสต๊อกไอเทมนั้นคือ 999ชิ้น ในกรณีที่ได้รับไอเทมจากการผสมเป็นชิ้นที่ 1000 ก็จำเป็นจะต้องใช้ช่องว่างในไอเทมวินโดว์ 2 ช่อง

ตัวอย่าง ในกรณีที่จะผสม Archen Thorn ให้เป็น Archen Slow ผลที่เป็นไปได้จาก Archen Thorn 1 ชิ้น อาจจะกลายเป็น Archen Slow 10 ชิ้น หรืออาจจะกลายเป็น Mixture's Failure 1 ชิ้น, ซึ่งในกรณีที่ผสม Archen Thorn 100 ชิ้น ก็มีความเป็นไปได้ที่จะได้รับไอเทม Mixture's Failure ด้วย และเนื่องจากจำนวนของ Archen Slow ที่ได้ออกมาต้องน้อยกว่า 1000 ชิ้น จึงอาจจะกลายเป็น Mixture's Failure 1 ชิ้น และ Archen Slow 999 ชิ้น นั่นหมายความว่า จะต้องจัดเตรียมช่องว่างในไอเทมวินโดว์ถึง 3 ช่อง

Comment ประกาศ

> Comment การประกาศคือ?
อยากจะจัด Party ให้ง่ายขึ้น, รวบรวมไอเทมได้รวดเร็วขึ้น, แลกเปลี่ยนข้อมูลกับคนที่ไม่รู้จักได้อย่างสบายๆ หากรู้สึกเช่นนั้น ต้องลองใช้ Comment ประกาศ ดู
ด้วย Comment ประกาศนั้น สามารถดู Comment ของตัวละครทั้งหมดที่ล็อกอินอยู่ในสถานที่นั้น และถึงจะยืนอยู่ห่างกัน การ Communication กับผู้อื่นก็ไม่ติดขัด

> ลองดู Comment ประกาศกันเถอะ!

เปิด Comment List ประกาศ
ทำการคลิกขวาที่ตัวละครของตนเอง จะมีหัวข้อที่เรียกว่า [Comment ประกาศ] เลือกหัวข้อนี้ ก็จะเป็นการ เปิด Comment ประกาศ
* สามารถทำการเปิด ปิด Comment ประกาศ ด้วยการพิมพ์ [/ui_commentlist] ลงในช่อง Chat Window ได้ ทั้งในตอนที่สวมวิญญาณผู้อื่นก็สามารถทำได้

วิธีดู Window Comment List ประกาศ

ใน Window Comment List นั้น, จะแสดงเนื้อหาการประกาศรับสมัคร Party, ประกาศเกี่ยวกับไอเทม, ประกาศเกี่ยวกับข้อมูลของผู้เล่นที่ล็อกอินอยู่ ณ ปัจจุบัน เป็นต้น

1.หัวข้อประกาศ
จะสามารถดู Comment ประกาศ แยกตามประเภทได้โดยการกดที่ปุ่ม, และจาก Window ที่ปรากฎออกมาให้เลือกที่หัวข้อ [Party]


Party
แสดงตารางสรุป Comment ประกาศรับ Party Member

Item
แสดงตารางสรุป Comment ประกาศเกี่ยวกับ Item

ข้อมูล
แสดงตารางสรุป Comment ประกาศเกี่ยวกับข้อมูลต่างๆ


2.การแก้ไขใหม่
เมื่อคลิกแล้ว, จะแสดงข้อมูลใหม่ล่าสุดใน Comment List ที่ประกาศออกมา

3.Page
ที่ด้านบนขวาของ List, จะแสดงจำนวนหน้า และหมายเลขหน้าที่แสดงอยู่ ณ ปัจจุบัน หากกดปุ่มลูกศรที่อยู่ด้านซ้ายขวา, ก็จะเป็นการย้อนกลับไปหน้าที่แล้ว หรือเลื่อนไปยังหน้าถัดไป

4.หัวเรื่อง
แสดงหัวข้อของ Comment ประกาศ

5.ชื่อ
แสดงชื่อของตัวละครที่ออก Comment ประกาศ
(2) ที่แสดงอยู่หลังชื่อของตัวละครนั้น แสดงจำนวน Party Member ที่สังกัดเดียวกับตัวละครที่ลง Comment ในกรณีที่จำนวนเป็น(8) ก็จะไม่สามารถเข้าร่วม Party นั้นได้อีก

6.ตัวเนื้อเรื่อง
แสดงเนื้อเรื่องของ Comment ประกาศ, ซึ่งจะแสดงอยู่แล้วส่วนหนึ่ง, หากนำ Curser ไปตรงกับข้อความนั้น ก็จะแสดงข้อความทั้งหมดออกมา

เนื้อหาที่ประกาศจะแตกต่างกันไปตามตวัละครที่ประกาศ, ลองตรวจสอบก่อนการติดต่อ

7.ตำแหน่งปัจจุบัน
แสดงตำแหน่งที่อยู่ปัจจุบันของตัวละครที่ออก Comment ประกาศ

>มาออก Comment ประกาศกันเถอะ
ต่อไปนี้คือข้อควรระวังในตอนที่จะใช้ Comment ประกาศ
จะสามารถลงทะเบียน Comment Party ได้ในกรณีที่เป็น Party Leader หรือไม่สังกัด Party ใดๆเลย
หลังจากลงทะเบียน Comment Party แล้ว, Comment ประกาศที่ลงทะเบียนสังกัดใน Party นั้น จะถูกลบออกไป
* ในกรณีที่มี Party Leader อยู่ จะไม่ถูกลบ
ไม่สามารถลงทะเบียน Comment ประกาศ 2 รายการในครั้งเดียวได้ หากกระทำผลที่ใช้แสดงออกมาคือ Comment ประกาศ ที่ลงทะเบียนอันหลังสุด
หากทำการล็อกเอาท์ Comment ประกาศจะถูกลบออก

>สมัครใน Comment ประกาศ!
ส่งกระซิบไปยังตัวละครที่ทำการประกาศ
ที่ Window Comment List, เมื่อกดปุ่ม [w] ที่อยู่ด้านขวาของชื่อตัวละคร ก็จะสามารถส่ง Whisper Chat เพื่อพูดคุยแสดงความคิดเห็นกับตัวละครที่ เป็นผู้ออก Comment ประกาศได้

ร่วม Party กับตัวละครที่ประกาศ
หากกดปุ่ม [p] ที่อยู่ด้านขวาของชื่อตัวละคร ก็จะสามารถยื่นขอเข้าร่วม Party กับผู้ที่ออก Comment ประกาศได้ทันที
* ในกรณีที่ตัวละครของตนเอง สังกัดกับ Party อื่นอยู่ก่อนแล้ว, ก็จะไม่สามารถยื่นคำขอเข้าร่วมได้
* ในกรณีที่ Party Member ของตัวละครที่ออก Comment ประกาศครบ 8 คนแล้ว ก็จะไม่สามารถเข้า Party นั้นได้อีก

>ลงทะเบียน Comment ประกาศ

1.เมื่อคลิกขวาที่ตนเองจะมีหัวข้อ [ลงทะเบียน Comment ประกาศ] แสดงออกมาในเมนู ทำการเลือกหัวข้อนั้น Window [ลงทะเบียน Comment ประกาศ] ก็จะปรากฎออกมา

ในกรณีที่สังกัด Party อยู่ก่อน, หรือไม่ได้เป็น Party Leader, เมนู [ลงทะเบียน Comment ประกาศ] จะไม่แสดงออกมา และไม่สามารถลงทะเบียน Comment ได้

สามารถทำการเปิด ปิด ลงทะเบียนComment ประกาศ ด้วยการพิมพ์ [/ui_comment] ลงในช่อง Chat Window ได้ ทั้งในตอนที่สวมวิญญาณผู้อื่นก็สามารถทำได้

2.กดปุ่มที่ด้านขวาของ [หัวข้อประกาศ] แล้วเลือกชนิดหนึ่งจาก 3 ชนิด
[หัวเรื่อง] สามารถกรอกด้วยตัวอักษรเล็ก 30 ตัว, ตัวเต็มได้ 15 ตัว
[ตัวเนื้อเรื่อง] สามารถกรอกด้วยตัวอักษรเล็ก 90 ตัว, ตัวเต็มได้ 45 ตัว

3.เมื่อลงทะเบียนเสร็จแล้วจะปรากฎ Log Window Message System ว่า [ลงทะเบียน Comment ประกาศเรียบร้อยแล้ว]
ถ้าลงทะเบียน Comment ประกาศแล้ว ก็ให้รอการติดต่อจากผู้เล่นอื่นๆ ในลาน Party อย่างสบายๆจนกว่าจะมีผู้ติดต่อมา และร่วมผจญภัยด้วย

การลบ Comment ประกาศ
หากไม่ใช้ Comment ประกาศแล้ว อย่าลืมลบทิ้ง
1.คลิกขวาที่ตนเองแล้วคลิกที่ [ลงทะเบียน Comment ประกาศ] Window ลงทะเบียน Comment ประกาศจะแสดงออกมา

2.ทำช่อง [หัวเรื่อง] และ [ตัวเนื้อเรื่อง] ให้ว่าง แล้วคลิกปุ่ม [ok]

3.เมื่อลบเรียบร้อยแล้วจะปรากฎ Log Window Message System ว่า [ลบ Comment ประกาศเรียบร้อยแล้ว]

Macro คือ?
Macro คือฟังก์ชั่นการทำงานที่สามารถดำเนินการได้ทันทีเพียงแค่กด Shortcut Key ตามลำดับที่มีการลงมะเบียนไว้แล้ว ซึ่งใน Macro นั้นจะสามารถลงทะเบียน สกิล, Message, Motion-Emotion และ System Command ได้ เมื่อลงทะเบียน Macro แล้ว จะสามารถควบคุมตัวละครและจัดการกับคำสั่งได้อย่างรวดเร็ว ด้วยการกด Shortcut Key ง่ายๆเช่น Ctrl + A เป็นต้น

สิ่งที่ลงทะเบียนได้ /ข้อดีเมื่อลงทะเบียนใน Macro แล้ว
System Command เปิดการควบคุมวินโดว์ได้อย่างรวดเร็ว
Motion-Emotion สามารถแสดงอารมณ์ความรู้สึกได้ง่าย
Message สามารถพูดคำทักทายได้บ่อยๆโดยไม่ต้องพิมพ์ใน Chat Window
สกิล สามารถใช้สกิลได้ทันทีด้วย Shortcut Key

Macro ในตอนเริ่มแรก
เมื่อ Install เกมส์ ECO เสร็จแล้ว System Command และ Motion-Emotion ส่วนหนึ่งจะถูกลงทะเบียนไว้ใน Macro ล่วงหน้าแล้ว เพียงแค่จำมาใช้บ่อยๆ ก็จะเป็นประโยชน์ต่อผู้เล่นอย่างแน่นอน

วิธีใช้ Macro
Macro ที่ลงทะเบียนเรียบร้อยแล้ว จะสามารถใช้งานจริงได้ด้วยการกด Shortcut Key ที่ตรงกับที่ตั้งไว้ ซึ่งจำนวนทั้งหมดที่สามารถลงทะเบียนใน Macro ได้ คือ 72 อัน โดยแบ่งเป็น Ctrl Key 36 อัน, และ Alt Key 36 อัน
ประเภท ประกอบกับ
Ctrl Key + Key [0~9]
+ Key [A~Z]
Alt Key + Key [0~9]
+ Key [A~Z]

ตัวอย่าง ใช้แบบนี้!
ด้วยสภาพเริ่มต้นนั้น หากกดปุ่ม Alt กับปุ่ม Y พร้อมกัน, Macro ที่ลงทะเบียนไว้จะแสดง Emotion Thanks! ออกมา เมื่ออยากจะพูดขอบคุณอย่างฉับพลันก็ให้กด Alt + Y ก็สามารถกล่าวขอบคุณได้ทันที

ลงทะเบียน Macro ใหม่
เกี่ยวกับการลงทะเบียน Macro ทั้งหมดนั้น จะทำได้ที่ Macro Window
1. เปิดวินโดว์มาโครด้วยวิธีดังต่อไปนี้
* คลิ๊กปุ่ม Macro ที่อยู่ใต้ Main Window
* พิมพ์ /ui_macro ในช่อง Chat
* กดปุ่ม Ctrl พร้อมกับปุ่ม K (เปิด Macro ที่ลงทะเบียนด้วยสภาพเริ่มต้น)

2. คลิ๊กหัวข้อของวินโดว์ Macro เพื่อกำหนด Shortcut Key
เช่น กรณีตามภาพนี้ กำลังลงทะเบียน Macro ที่สามารถเรียกใช้ได้ด้วย Ctrl +3

* ที่ Tab Ctrl จะลงทะเบียน Macro ที่ตรงกับปุ่ม Ctrl ได้
* ที่ Tab Alt จะลงทะเบียน Macro ที่ตรงกับปุ่ม Alt ได้
3. ในกรณีที่ Macro มีการลงทะเบียนไว้ก่อนแล้ว ก็ลบได้ด้วยปุ่ม Delete หรือ Back Space ที่ Macro นั้นๆ

4. กรอกเนื้อหา Macro ที่ต้องการจะลงทะเบียนใหม่

5. กดปุ่ม Enter ก็จะเป็นการลงทะเบียนที่ Macro ที่ตำแหน่งนั้น

* ในกรณีที่เปลี่ยนใจ ก็ให้คลิ๊กไปที่ช่องอื่นๆ ของ Macro Window โดยไม่กดปุ่ม [Enter]

6. กด Shortcut Key ก็จะแสดง Macro ที่ลงทะเบียนไว้แล้วออกมา

ลงทะเบียน Skill, Motion-Emotion อย่างง่ายๆ!
Skill, Motion-Emotion นั้นสามารถลงทะเบียนได้ง่ายๆ
เพียงแค่ Drag & Drop Icon จาก Skill Window หรือ Emotion Window มายัง Macro Window เท่านั้น

Acropolice City (10 Points)

หลังจากนั้นให้ไปหาคริสตัลมาทำ Event นี้อีกครั้ง เมื่อทำสำเร็จเปนครั้งที่ 2 ก็จะได้รับ Skill Point มา
*เมื่อเคลียร์ Event นี้แล้วจะสามารถซื้อชุดประจำอาชีพ Lv.55 สายเวทย์จากหมอดูได้

Fareast City (3 Points)

1.คุยกับ Mother ที่กลางเมือง คุณแม่จะขอร้องให้นำกล่องข้าวไปส่งให้ Water Guard ที่อยู่ขวาล่างสุด ตรงกังหันน้ำ เมื่อนำกล่องข้าวไปส่งแล้ว

แถวแปลงผัก 50 ต้น ภายในเวลา 7 นาที แต่อย่าเพิ่งสนใจวัชพืช ให้เราคุยกับลุงแซมอีกครั้ง ลุงแกจะให้ skill point เรามาเป็นกำลังใจในการถอนหญ้า ^^
หลังจากได้สกิลมาแล้วจะถอนหญ้าหรือไม่ถอนก็ไม่เป็นไร (รับรางวัลแล้วเบี้ยวงาน) ถ้าทำเควสสำเร็จสามารถไปรับเงินที่ร้านเหล้าได้ (300G)
*เควสนี้ ไม่จำเป็นต้องมีแต้มเควสเหลือก็สามารถทำได้

3.เข้าไปในบ้านบนเนินเขาซ้ายบน คุยกับ Sharuru เขาจะขอร้องให้เราช่วยจับตัวลูกเจี้ยบทั้ง 7 ให้เขาหน่อย จากนั้นให้เราเดินไปคุยกับลูกเจี๊ยบรอบๆ หมู่บ้าน

เมื่อคุยกับลูกเจี๊ยบครบ 7 ตัวแล้ว ให้กลับไปคุยกับ Sharuru อีกครั้ง จะได้รับ skill point อีก 1
