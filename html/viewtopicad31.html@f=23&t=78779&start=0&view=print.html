ผมเข้าไปฉะกับมันตัวนึงที่วอเตอร์เลเยอร์ ตอนแรกมันจะเลือดน้อย

ไม่กี่วิก็ตายแล้ว แต่ตอนตายจะเสกตัวเลือดเยอะหลักล้านได้มั้งครับ

เจ้านี่จะวิ่งหนีตลอดต้องต้อนไปชิดแมป สกิลที่ใช้ก้อมีไฮเปอร์ ชาร์จ

สาปแช่แข็ง แล้วก็คลื่น (อาจมีอีกแต่นึกไม่ออก) พอใกล้ตายจะคลื่นไม่ยั้งเลย

ชนิดวิ่งหนีไปคลื่นไป

สรุป ขอบอกว่าก็ไม่ยากเท่าไหร่ แต่ก็ไม่ง่ายครับ ดันมันให้ไปติดขอบแล้ว
