ใครมีบ้านบินเก็บสบายเลยครับ

ลงทุนทำบ้านบินแล้วซื้อลังเก็บของมา1อัน10ช่องก็ได้

พอไปถึงเหมืองที่ Morg เราก็ลงเชือกบ้านบินไว้เลยละครับ

ที่เหลือก็แค่ เก็บ พอมันเต็ม ก็หอบขึ้นไปเก็บไว้กล่องบนบ้าน จากนั้นก็ลงมาเก็บต่อได้เลยครับ

ถ้าเดินหอบไปมา ทีละั100ชิ้น มันเหนื่อยนะ

ใช้กระจกดรอป*2 โอกาศตก2ชิ้น 100% ลองไปเก็บมาแล้วครับ 1ชม. เก็บได้เกือบ1พันชิ้นเลย

///

แต่ถ้าจะหาเงินจริงๆ แนะนำให้ไปตีหาดินน้ำมัน(Alphast)ดีกว่าครับ รวยกว่า โอกาศตกก็สูงด้วย

เก็บถ่าน 1ชม.ได้450ชิ้น (ไม่มีกระจก) ตกทุกชิ้น ไม่ต้องลุ้นให้เหนื่อย

ขายได้ราคารวม 337,500 (ผมขายอันละ750นะ)

เก็บดินน้ำมัน 1ชม. ได้ 25-40ชิ้น แล้วแต่ดวง

ขายได้ราคารวมในกรณีได้25ชิ้น 475,000 (ขายอันละ19,000) กำไรกว่าเยอะ

ปล.ดินน้ำมันหาได้จาก Moutain Rock ที่แมพ ผาผึ้งนะครับ(ทางตะวันออก) โอกาศตก1/3มั้ง
