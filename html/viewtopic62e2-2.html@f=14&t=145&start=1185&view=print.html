หน่วยที่ลงท้าย เลขเช่น9n อะครับคือตัวหาร หากเราอัพ สเตตัส ที่เลข9n คือ n = หาร

เช่น strสำหรับ min atk คือ => 9,18,27,36,45,54,63,72,81,90 ซึ่งตัวเลขพวกนี้ คือ

เลขที่ n หารด้วย9แล้วลงตัว จะทำให้ได้ สเตตัส โบนัส ครับ :roll:

ส่วน Vit DEF = 3n/9n
　=> 12,15,18,21,24
=> 9,18,27,36,45
มีตัวหาร 2ตัวคือ 3กับ9 ก็ดูตาม ด้านล่างแหละครับ สมมุติ อัพ vit 18 ก็ได้โบนัสและ
