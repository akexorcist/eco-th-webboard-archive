หลอมที่ฟูจิกิอ่ะ พอเข้ามาในหอรบแล้วเข้าไปก็จะเจอกับ Leader Blue's
คุยแล้วจะขอร้องให้เราเอายาไปส่งเจ้อะไรเนี่ยแหละ จากนั้นเดินเข้าประตูหลังห้องนั้น
แล้วไปเกาะนักบาชหญิง แล้วก็เดินเข้าบ้านในเกาะนั้น(เกาะนี้มีบ้านหลังเดียว)
แล้วก็ส่งยาให้ เจ้คนนี้ก็ขอร้องให้เราเอาหน้ากากไปส่ง Leader Blue's
จากนั้นก็วิ่งกลับมาที่เดิมแล้วส่งหน้ากาก แล้ว Leader Blue's ก็ให้เราไปส่งยาอีกละ(- 0 - หงุดหงิดละงิ)
แล้วก็เอายาไปส่งเจ้คนเดิมที่เกาะนักบวชหญิง แล้วเจ้คนนี้ก็รับหลอมแล้น -w-

ถ้าจำมะผิดเจ้เค้าชื่อ Yoko ละมั้ง =w=a
