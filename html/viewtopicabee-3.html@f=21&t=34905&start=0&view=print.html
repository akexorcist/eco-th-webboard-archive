ประสบการณ์ในโลก Acronia (ตอนแรก)

พอฉันสาวเท้าเข้ามาสู่โลกแห่งนี้ ฉันนึกว่าฉันหลงเข้ามาในแดนหิมะซะอีก :? ก็เพราะหันไปไหนก็มีแต่สีขาว-*- แล้วฉันก็เห็นนางฟ้า (Titania เหมือนฉันนั่นแหละ-*-) ฉันเลยเข้าไปคุยด้วย :P ได้ความว่า ที่นี่เป็นยุคอนาคตที่ Acronia ล่มสลายไปแล้ว (อ่าวเวง-*-) เขาชื่อ Tita และจะสอนอะไรเล็กๆ น้อยๆ กับฉัน :oops: ฉันจึงตกลงไป แล้วก็ได้ยินเสียงระเบิด อกสั่นงับพี่น้อง ใครกัน Tita บอกเป็นการเคลื่อนไหวของ [พวกเขา] (พวกเขาไหนยะ Dominion เรอะ :x )

พอรู้ตัวอีกที ฉันก็มาอยู่ที่ห้องบังคับการณ์แล้ว hock: สีหน้าคนที่อยู่ในนั้นเคร่งเครียดอย่างหนัก (พอเดาได้ว่าเป็นทหารระดับนายพลคนนึง และกำลังสู้รบผ่านหน้าจอคอมฯ :? ) พอฉันเข้าไปคุยกับพวกเขา พวกเขาบอกว่า ประชาชนอย่างฉันไม่ควรเข้ามาที่นี่ ควรจะรีบลี้ภัยออกไปทางประตูทางด้านหน้านั้น (ฉันเองก็กลัวโดนระเบิดตายที่นี่เหมือนกันย่ะ-*- :x ) แล้วฉันก็บินออกนอกห้องนี้ไป :twisted:
