fencer ตี้ไวกว่าแน่นอนคับ ถ้าเก็บเองจะสู้อาชีพอื่นที่เน้นโจมตีไม่ได้อยู่แล้ว เรามันเน้นป้องกันมากกว่า แรกๆเก็บเองต้องเลือก str-vit ,str-dex,str-agi อยู่ดี สายแปลกๆไว้ไปเล่นตอนเปลี่ยน พอเป็น knight ก็ตี้ไปจะโดดเด่นกว่า

vit+mag เป็นสาย tank+sup แบบไม่พึ่งพระคับ ถ้ามีพระประจำตัวก็ไม่แนะนำ ( ซึ่งเราเป็นพระซะเอง และควรมีสาย backpack มาตั้งแคมด้วย )
สายนี้ถ้าเลือกเป็น knight จะเป็น tank ตรงๆ มีสกิล defence แบบต่างๆ และ heal ที่ใช้ค่า mag แต่ heal เรามีแค่ 3 เลเวลนะคับ ของพระเขามี 5 เลเวล
ถ้าเป็น dark stalker จะ tank+support มีบัฟ เพิ่มอาตุมืดให้อาวุธ และอีกท่าทำให้ธาตุมืดตีแรงขึ้น สกิลที่ใช้ค่า mag มี flare(job 36) ดูดเลือด(job 43)

vit+dex โล่ติดบ่อยดีคับ stun blow ตอนเก็บเวลปกติแทบไม่ได้ใช้เลยครับ ถ้าคุณจะเล่นแบบตี้ ให้พวกนักเวทย์ยิง เอาแปปเดียวก็ตายล่ะ เห็นบางคนบอก พวกมอนสเตอร์ติด stun ยากด้วย

vit+int int ให้เป็น stat เสริมดีกว่าคับ หลักๆเลือก vit,str ส่วนสกิลตายแล้วมีโอกาสฟื้นไม่รู้ว่าเกี่ยวกะ int รึเปล่า แต่เคยมีคนลองใช้แล้วบ่นๆว่า ไม่ดี อย่างแรง

เพิ่มเติม. ถ้าคุณจะเล่นพวกสกิลทำให้ศัตรูติดสถานะผิดปกติ แนะนำให้ใช้ rapier มีสกิลให้เลือกใช้มากมายกว่า มีสกิลของ darkstalker(job 16) ทำให้ตีพวกติดสถานะแปลกๆแรงขึ้นด้วย
