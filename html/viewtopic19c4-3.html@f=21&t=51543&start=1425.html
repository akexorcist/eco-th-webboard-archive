"สวัสดี เอวาร่า ..."หญิงสาวแปลกหน้าโค้งคำนับ เอวาร่าย่อกายลงอย่างดูหมิ่นที่สุดเท่าที่จะทำได้

===============================================

ตอนนั้นเอง ... ที่ไม่มีใครรู้ หญิงสาวเจ้าของเรือนผมสีแดงกุหลาบและดวงตาสีเหลืองทองในชุดเมด ก็เดินเข้ามาในห้องนั่งเล่นที่มีพวกหนุ่มผมสีเงินรวมทั้งคนอื่น ๆ กำลังนั่งอยู่ เธอไม่ได้สนใจอะไรนอกจากเริ่มทำความสะอาดเท่านั้น และที่สวนหน้าบ้านนั้น ก็มีหญิงสาวที่งดงามไม่แพ้กันเจ้าของดวงตาสีแดงโลหิตและเรือนผมสีน้ำเงินเข้มในชุดเมดอีกเช่นกัน กำลังกวาดใบไม้อยู่ด้วยรอยยิ้มงดงาม

และ ... ในห้องครัว หญิงสาวในชุดเมดอีกคนกำลังเตรียมอาหารด้วยท่าทีคล่องแคล่วและรอยยิ้ม น่าแปลกกว่าคนอื่นตรงที่หญิงสาวผู้นี้มีหูและหางแมวสีขาว !? เรือนผมสีดำที่ดูสั้นนั้นทำให้ดูน่ารักมากขึ้นไปอีก เมื่อรวมกับดวงตาสีน้ำเงินคู่นั้นยิ่งน่าดูหลงใหล ...
