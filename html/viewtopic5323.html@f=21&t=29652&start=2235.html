ตำนานบทที่ XIV
“Amicizia – [ Friendship ]”


หญิงสาวนิ่งไปครู่ใหญ่ หลังจากได้ยินการประกาศศึกที่ดังขึ้นจากปากของโฆษกการแข่งขัน เธอคงจะยินดีกว่านี้ หากนามของผู้ที่เธอต้องประมือด้วยนั้น ไม่ใช่เพื่อนที่ร่วมผจญภัยด้วยกันมาอย่าง วิลาเนเซีย มัลฟอร์ด ผู้นี้ ...


เธอนิ่งไปครู่ใหญ่ ... ก่อนจะตัดสินใจลุกขึ้นอย่างองอาจพร้อมกับเดินออกจากที่นั่งชมของผู้เข้าแข่งขัน เพื่อไปเตรียมตัวกับการต่อสู้ วิลก็ทำเช่นเดียวกัน ทั้งสองต่างเดินลงไปคนละทิศคนละทาง และต่างแยกย้ายกันไปเตรียมตัว โดยไม่ได้พูดอะไรกันเลยแม้แต่น้อย เอเลน่าเดินเข้าไปยังห้องเตรียมตัว เธอถอนใจเฮือกใหญ่ ... ราวกับว่ากำลังคิดอะไรบางอย่างอยู่


“... ทำไม ... ต้องเจอกันเร็วแบบนี้กันนะ ?” เธอเอ่ยพึมพำกับตัวเอง เสียงแผ่วเบาราวกับมีบางสิ่งบางอย่างอยู่ในใจของตนเอง “... ก็ต้องสู้สินะ ...” เอเลน่าเอ่ยขึ้นราวกับว่าได้ตัดสินใจลงไปแล้ว เธอเริ่มเตรียมตัวโดยการเช็คอาวุธและเสื้อผ้าของตนเองให้พร้อม เวลาผ่านไปสักพักใหญ่ ...


ก๊อก ! ก๊อก ! ก๊อก ! ...


เสียงเคาะประตูดังขึ้น แสดงถึงการมาเยือน ... “รู้แล้ว ! เดี๋ยวจะออกไปเดี๋ยวนี้แหละ !” เธอเอ่ยอย่างรำคาญ


ก๊อก ! ก๊อก ! ก๊อก ! ...


หากแต่ว่าเสียงเคาะประตูนั้นก็ยังไม่ยอมหยุด ราวกับว่าจะบังคับให้เธอมาเปิดให้ได้ ...


“โอ๊ย ! อะไรนักหนา !” เอเลน่าว่าอย่างหัวเสีย ก่อนจะเดินตรงไปยังประตูและเปิดออก สีหน้าไม่พอใจอย่างมาก แต่สีหน้านั้นก็ต้องอ่อนลงเมื่อพบว่าคนที่มาเคาะประตูห้องของเธอนั้น คือใครกัน ? “มีธุระอะไร ? วิล ...”


บุคคลตรงหน้าเธอนั้นไม่ใช่ใครอื่นไกล หากแต่เป็นคู่ประลองของเธอ รวมทั้ง ... ‘เพื่อน’ ของเธอด้วยเช่นกัน ...


“ตกลงจะเอายังไง ?”


คำถามถูกถามโดยชายหนุ่มที่อยู่เบื้องหน้าของเธอ บุรุษผู้อยู่ในชุดสีขาวบริสุทธิ์ รวมทั้งหอกที่สะพายไว้ด้านหลังนั้น ก็น่าเกรงขามไม่น้อยทีเดียว เอเลน่าทำสีหน้าฉงน ด้วยความที่ไม่ค่อยจะเข้าใจคำถามของบุรุษตรงหน้าเสียเท่าไรนัก “นายหมายความว่ายังไง ? วิลาเนเซีย มัลฟอร์ด ?”


“เธอก็รู้ ... ใช่ว่าฉันจะไม่ลำบากใจที่จะสู้กับเธอ ...”


“อ๋อ ? นายจะมาถามว่าจะให้ฉันหรือว่าตัวนายเองยอมแพ้ใช่ไหม ?”


“ฉันไม่ได้หมาย ...”


“พูดมาตามตรงเถอะ !” เสียงของเธอดังขึ้นขัดเขา ...


“อย่ามาดูถูกให้มากนัก ...” เอเลน่าย่างเข้าประชิดตัววิล ซึ่งเขาก็เงียบไม่ได้พูดอะไร ราวกับรู้ว่าเธอมีอะไรที่กำลังคิดจะพูดกับเขาอยู่ “จงต่อสู้ ... อย่างสมศักดิ์ศรีของนายซะ” เอเลน่าเอ่ยด้วยน้ำเสียงที่ไม่อาจจะทราบอารมณ์ของเธอได้


“หาไม่แล้ว ... ฉันจะไม่อภัยให้นาย ...” เอเลน่าหันหลังให้วิล ก่อนจะเดินตรงไปหยิบแส้อาวุธคู่กายของตน


“ตลอดชีวิต ... อย่ามาให้ฉันเห็นหน้า ! นายก็มีศักดิ์ศรีของนาย ! และ ฉันก็มีศักดิ์ศรีของฉัน !!! ถ้าไม่คิดจะสู้ก็ไสหัวออกไปจากชีวิตของฉันซะ ! เข้าใจไหม !?”


มือที่กำแน่นนั้นสั่นระริก ราวกับว่ากำลังเก็บอารมณ์ที่พุ่งขึ้นอย่างไม่อาจจะระงับได้ ชายหนุ่มมองหญิงสาวตรงหน้าด้วยแววตาที่แปลกออกไปจากทุกครั้ง ตลอดเวลาที่อยู่ด้วยกันนั้น เอเลน่าจะทำหน้าที่เข้าไปสืบข่าวหรือไม่ก็เป็นนางนกต่อ ไม่ได้ต่อสู้อะไรอย่างจริงจังเท่าไรนัก จนเขา ... เผลอคิดไป ว่าเธอนั้นเป็นเพียงแค่หญิงสาวคนนึงเท่านั้น ซึ่งตอนนี้ก็พิสูจน์ให้รู้ได้แล้วว่า ... ‘เขาคิดผิด’


“ฉันเข้าใจแล้ว ... เอเลน่า ...”


แกร่ก ...


และนั่นคือประโยคสุดท้ายที่วิลได้เอ่ยขึ้น ก่อนที่ประตูจะปิดลงพร้อมกับความเงียบสงัด ...


กลับไปทางด้านลานประลอง ตอนนี้ผู้ชมทั้งหลายก็เตรียมพร้อมที่จะชมการประลองอันแสนตื่นเต้นในรอบถัดไปกันแล้ว พวกเขาต่างพูดถึงการประลองที่กำลังจะเกิดขึ้นอย่างตื่นเต้น หากแต่มีอยู่คนนึง ... ที่รู้สึกไม่สบายใจเลยสักนิดกับการประลองเช่นนี้ “... ( จะเป็น ... ยังไงบ้างนะ ? )” ทรีทคิดในใจ เธออยู่กับทั้งเอเลน่าแล้วก็วิลมานาน


ถึงแม้ว่าเธอกับวิลจะผ่านเรื่องอะไรมาก่อนที่จะมาเจอเอเลน่าก็ตาม แต่เธอก็คิดเสมอว่าเอเลน่าเป็นเพื่อนคนสำคัญของเธอคนนึงเลยทีเดียว เธออยู่กับวิลมานาน ย่อมรู้ฝีมือของชายหนุ่มดี หากแต่เอเลน่าน่ะสิ ... เธอไม่เคยเห็นเอเลน่าสู้แบบจริงจังเลย ! และนั่น ก็ทำให้เธอคิดไปว่า ... ‘เอเลน่าจะแพ้วิล’ ...


“( ไม่หรอก ... ไม่หรอก ... น่าจะมีใครยอมแพ้สิ ! ... จะมาสู้กันทำไม ... )” เธอพยายามมองโลกในแง่ดีไว้ก่อน


“เอาล่ะครับ ! ... ท่านผู้ชมทั้งหลาย ! พร้อมจะชมการประลองอันแสนตื่นเต้นในคู่ต่อไปหรือยังครับ !?”


เสียงของโฆษกดังขึ้น ... ยิ่งทำให้ทรีทนั้นรู้สึกไม่สบายใจมากขึ้นไปอีก ขณะที่เสียงโห่ร้องด้วยความตื่นเต้นของฝูงชนนั้นดังขึ้นอย่างต่อเนื่อง และไม่มีท่าทีว่าจะลดน้อยลงไปเลยสักนิด การประลองทุกรอบที่ผ่านไปนั้น ล้วนแต่สร้างความตื่นเต้นเหนือคำบรรยายให้กับทุกคน และพวกเขาก็หวังว่า การประลองของคู่นี้ จะสร้างความตื่นเต้นและระทึกใจไม่น้อยไปกว่าคู่อื่น ...


“งั้นเราจะมัวรอรีอะไรอยู่ล่ะครับ !? ขอเชิญท่านพบกับศึกประลองซิลเวอร์ฮาร์ท ! คู่ที่สี่ !”


“เอเลน่า อาบิเกลล์ ! และ วิลาเนเซีย มัลฟอร์ด !”


สิ้นเสียงประกาศของโฆษกหนุ่ม เสียงโห่ร้องของผู้ชมก็ยิ่งดังทวีมากขึ้นไปอีก ... ตอนนั้นเองที่ผู้ร่วมการประลองทั้งสองก็ได้เดินออกมาจากทางออกทั้งสองข้าง ส่วนทรีทนั้นก็ยิ่งใจเสียมากขึ้นไปอีก ทั้งเอเลน่าและวิลต่างขึ้นมาบนเวทีด้วยท่าทีที่มั่นใจและไร้ความลังเล ... ดวงตาของวิล ... มั่นคง ราวกับสลัดทิ้งความไม่แน่ใจที่อยู่ในใจของตนออกไปแล้ว ...


ทั้งสองเดินเข้าหากัน ... และอยู่ห่างกันเพียงนิดเดียว เครื่องแต่งกายที่แตกต่างกัน เอเลน่า ... ในชุดสีดำ และวิล ในชุดสีขาวบริสุทธิ์ ซึ่งเข้ากับปีกสีขาวนั้นของเขาอย่างไร้ที่ติ “ละทิ้งความลังเลแล้วสินะ ...” เอเลน่าเอ่ยขึ้นก่อน


“...............” วิลเงียบไปครู่นึง “... ฉันจะทุ่มสุดฝีมือในการเอาชนะเธอ ... เอเลน่า ...”


สิ้นคำพูดของชายหนุ่ม ... รอยยิ้มอย่างพึงพอใจของหญิงสาวก็ปรากฎขึ้น “ยินดีที่ได้ ... ร่วมเดินทางกับนาย ...”


“... ฉันก็เหมือนกัน ...”


ทั้งสองต่างหันหลังให้กัน และเดินตรงไปที่มุมของเวที เพื่อทำการเตรียมพร้อม ...


“ศึกประลองชิง ‘ซิลเวอร์ฮาร์ท’ คู่ที่สี่ !! ขอเริ่ม ณ บัดนี้ !”


ตู้ม !!! ...


สิ้นเสียงการประกาศของโฆษก พลังทำลายอันรุนแรงก็ระเบิดขึ้นอย่างรวดเร็ว ... เมื่อชายหนุ่มพุ่งเข้าใส่เอเลน่าพร้อมหอกในมือที่ส่องประกายหมายจะพิฆาตในกระบวนท่าเดียว ...


“S P E A R A C C U R A T E ! ! !”

ย้อนกลับไป ... เมื่อนานมาแล้ว ...


ฉัน ... เคยอยู่เพียงเพื่อตัวเองเท่านั้น ... ชีวิตที่แสนสุข ? ความสุขช่วงวัยเด็ก ? มันคืออะไร ?


เมื่อเกิดมา ... ก็ถูกผู้เป็นพ่อกล่าวว่าเป็นตัวซวย ... เมื่อแม่ที่พอรักยิ่งนั้น ต้องจากลาอย่างไม่มีวันกลับเพราะว่าให้กำเนิดตัวเรา เราผิด ? หรือว่าใครผิด ? แล้วทำไม ... เราต้องเกิดมาด้วยนะ ? ชีวิตทุกวันผ่านไปอย่างฝันร้าย รอยยิ้มไม่เคยปรากฎให้เห็น ...


ถูกพ่อที่กลายเป็นขี้เมาทุบตีระบายอารมณ์ทุกวัน ... อยากจะหนี อยากจะหนีเหลือเกิน แต่ก็ทำไมได้ ...


เพื่อน ? ... เคยมีด้วยหรือ ?


มีแต่พวกสวมหน้ากากแสร้งเข้าหาตัวฉัน โดยแท้จริงแล้วหวังเพียงแต่ผลประโยชน์ที่ฉันพอจะทำได้เท่านั้น ...


แต่ฉัน ... คงจะเป็นตัวหายนะ ... จริงล่ะมั้ง ?


เปลวเพลิงโชติช่วง ... เผาไหม้สถานที่ที่ถูกเรียกว่า ‘บ้าน’ ไปพร้อมกับชีวิตของพ่อขี้เมา ไม่เหลือสักอย่าง ... มีแต่เพียงฉัน ที่เป็นเหมือนหลักฐานสุดท้ายว่ายังมีคนของที่นี่มีชีวิตอยู่ แต่ใครจะสนใจ ? ตอนนั้นเองที่ฉันตัดสินใจแล้ว ว่าชีวิของฉัน ... ฉันจะเลือกทางของฉันเอง และฉัน ... จะต้องมีความสุข ต่อให้ต้องเหยียบผู้อื่นเพื่อจะได้เป็นฐานขึ้นไปก็ตาม


เวลาผ่านไปนาน ... ฉันฝึกฝนทุกอย่าง ศิลปะการใช้แส้ และศิลปะการต้มตุ๋น ...


แต่น่าแปลกนะ ... ตอนนั้นเองที่ฉันก็ได้พบกับนาย ... และ เธอคนนั้น ...


ตอนแรกฉันยอมรับ ... ฉันคิดเพียงแต่จะหลอกใช้พวกนายเท่านั้น ... แต่ทำไมกันนะ ? ทำไมฉันถึงรู้สึกสนุกเวลาอยู่กับพวกนาย จนพาพวกนายไปเที่ยวตามที่ต่าง ๆ ด้วยนะ มาถึงตอนนี้แล้ว ... อยากจะบอกว่า ‘ขอบคุณ’ ... ขอบคุณ ... ที่ทำให้ฉันรู้จักคำว่า ‘เพื่อน’ ... และ คำว่า .. ‘ความรัก’ ...


ฮึ ... แต่ให้ตาย ... ฉันก็ไม่บอกนายหรอก เจ้าบ้า ! ... ฮะ ฮะ ฮะ ...ฉันตัดสินใจแล้ว ...


จบการประลอง ... ฉัน ... จะไปจากพวกนาย ...

ลาก่อน ...


...
...
...


พริบตาก่อนที่คมหอกจะพุ่งเข้าถึงตัวเธอ รอยยิ้มปรากฎขึ้นบนใบหน้าของเอเลน่า ... หากแต่ ... สิ่งที่วิลเห็นนั้น มันคือ ... รอยยิ้ม ... ที่เฉิดฉายอย่างงดงามบนใบหน้าของหญิงสาวที่น้ำตากำลังไหลริน ...


“ขอบใจ ... วิล ...” เอเลน่าเอ่ย “... จงดูสิ่งที่ฉันจะฝากให้นายให้ดี !”


เปรี้ยง ! ...


สิ้นเสียงกระแทก ... ภาพที่ทุกคนเห็นนั้นทำให้พวกเขาตกใจอย่างมาก ... เมื่อหอกของวิลนั้นทิ่มลงไปที่พื้นจนเกิดรูโหว่ขึ้น หากแต่ร่างของเอเลน่านั้น ก็ไม่ได้หายไปไหน เธอกลับยืนอยู่บนตัวหอกของวิลอย่างงดงาม และไร้บาดแผลใด ๆ ทั้งสิ้น ... ในมือของเธอนั้นถือแส้หนังสีดำเอาไว้ด้วย


“... มีคนเคยบอกว่า ... สตรีงามเปรียบเสมือนกุหลาบ ... หากจะแตะต้องก็ต้องระวังหนามของมันให้ดี ...”


“และตอนนี้ ... หนามกุหลาบ ก็พร้อมจะทิ่งแทงนายด้วยพิษร้ายแล้ว ...”
