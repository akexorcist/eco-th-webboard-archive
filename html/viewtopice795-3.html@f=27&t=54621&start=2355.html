westlykung เขียน:QuilPen

หรือเปล่าจำชื่อไม่ได้ทำไงอ่ะที่สีฟ้าๆ อะ

ไปดุรูปตามกระทู้เควส + หนังสือแล้วรูปหายหมด


Quil Pen(5) = Soft Wing(1)+Zedar Branch(1) อุปกรณ์ Knife
ทำโดยสกิลทำไม้ของชาวนา ไม่ก็เอาไปให้ตัวเปิดกล่องทำได้ในราคา 1k ครับ

Soft Wing หาได้จากตัวปีก ๆ (คล้ายพวกปีกดำปีกขาวอ่ะ ผมจำชื่อไม่ได้) ที่อยู่ในปราสาทอันเดท
Zedar Branch หาได้จาก noname wood (ชื่อนี้ป่าวหว่า - -" ) ต้นไม้ที่อยู่ตรงหนามเหลืองรอบหอแสงครับ (ต้องเอาชาวนาไปตีถึงจะได้ไม่งั้นจะตก Branch ธรรมดา)

รบกวนถามด้วยฮะ

คือน้องไม่แท้ผมจะกลับมาเล่นเกมนี้งะ แล้วทีนี้เข้าเกมแล้วพื้นมันเป็นสีดำหมดเลย

ลองลบแล้วลงใหม่ก็ไม่หาย

เค้าบอกว่าตอนแรกเล่นอยู่ดีๆก็ไม่เป็น

พอฟอแมทเครื่องทีมันก็เป็นเลย พอจะมีวิธีแก้ไขมั้ยอะงิ

พอดีอยุ่กันคนละบ้านงะ ถ้าเป็นคอมผมเองยังลองผิดลองถูกง่า ไม่รุ้จะช่วยยังไงดี

ขอบคุณมากฮับ

ปล.ไม่รู้จะไปตั้งถามที่ไหนดี กลัวจะเป้นกระทู้ย่อยเกินไป ขออณุญาติถามตรงนี้แล้วกันนะฮะ

Rouen เขียน:ใช้สกิล/แปลงมาริโอเน็ต เล่นในเมือง (ดาวทาวด์ อัพทาวด์ พวกเนี้ย) ของจะทนทานลดป่าวอ่ะ?


เท่าที่สังเกตค่าความทนทานของมาริโอเน็ตจะลดก็ตอน
-แปลงร่างเป็นมาริโอเน็ตอยู่แล้วโดนมอนตบตาย(มีสิทธิ์ค่าทนทานลด)
-ใช้งานเกินขนาดแปลงร่างบ่อย ๆ ถึงจะไม่ต้องโดนมอนตบตายคาที่ (มีสิทธิ์ค่าทนทานลด)

เพราะงั้น จากคำถาม ถึงจะแปลงร่างเล่นในเมือง แต่ถ้าใช้บ่อยเกิน ก็มีสิทธิ์ลดได้ครับ (คิดว่านะ)

(ลดมากๆ เข้าก็จับทำโกเล็มโลด) :yoyo110:
