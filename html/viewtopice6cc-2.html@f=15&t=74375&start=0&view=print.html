วิธีหาตังแบบเบสิก(ง่ายๆ)

1.มั่นเก็บเล็กผสมน้อย
2.ไม่ซื้อของที่ไม่จำเป็น
(อย่างของแรร์ที่ใส่ทำเท่เนี่ย ไม่จำเป็นก็ไม่ต้องซื้อ แพง+เปลืองตัง+เปลืองเนื้อที่เก็บ ยกเว้น กรณีที่ได้ฟรีก็เก็บไว้ )
3.เลือกวิธีที่ใช้ตังน้อยที่สุด
(สมมติว่ามีคนรับจ้างพาบินไปส่งที่โน่นที่นี่ ถ้าไม่รีบอะไร ก็เลือกเดินดีกว่า ประหยัดตังในกระเป๋า แต่ถ้าเขาพาไปส่งฟรี ก็เหมาโลด )
4.เลือกซื้อของร้านที่ถูกที่สุด
(ถ้าซื้อเสื้อผ้าก็เลือกชุดที่มีความทนทานเต็ม หรือเหลือเยอะๆ เพื่อความคุ้ม)
5.ขายของให้โกเลมที่รับแพงที่สุด
6.สเก็ตรูปมอนที่หายาก หรืออยู่ที่ไกลๆ(เช่น โลกใต้น้ำ เป็นต้น)ขาย
(วิธีนี้สำหรับซอ)
