เกี่ยวกับอาวุธ

อาวุธที่นักรบใส่ได้มี ดาบใหญ่,เคียวยักษ์

อาวุธสำหรับมือปืน ดาบติดปืน(คือดาบที่ยิงปืนได้)ปืนยาวและปืนคู่

อาวุธสำหรับมันติเวพอลได้แก่ อาวุธของนักรบ,มือปืนและนักดาบ

เกี่ยวกับโลกแห่งเกมส์ออนไล

เป็นโลกที่มีระบบต่างๆมากมายทั้งระบบค่าหัว,ระบบแลกเปลี่ยนสิ่งของ,ระบบPKและอีกหลายๆระบบมากมายซึ่งมีเมืองตั้งอยู่ในหลายๆเมืองและผู้เล่นก็สามารถวาปไปในเมืองต่างๆได้และผู้เล่นยังสามารถสร้างผื้นที่สำหรับเก็บเลเววเองได้ แต่ว่าในโลกนี้ก็ยังมีระบบที่ยังเป็นปัญหาอีกอยู่บ้าง

เมืองในโลกออนไล

เมืองเม็คอานุ เป็นเมืองที่ใหญ่ที่สุดในหมู่เมืองต่างๆเป็นเมืองที่ไม่มีการPKกันในเมืองเป็นเมืองที่ใช้ในการ แลกเปลี่ยน เข้ากิลด์ต่างๆ เป็นเมืองหลักนะ

เมืองต่สู้ ลูมิน่า โคลธ เป็นเมืองที่มีสนามประลองสำหรับการต่อสู้ต่างๆแต่ต้องสมัครเข้าร่วมก่อนนะ

เน็ตสลัมทาร์ทาร์ก้า เป็นเมืองที่ห่างไกลจากเมืองต่างๆและไม่อยู่ในแผนที่เมืองเพราะเป็นเมืองที่อยู่บนหุ่นยนต์เต่าที่เคลื่อนที่อยู่ตลอดเวลา
