โพสต์แล้ว: ศุกร์ 28 ก.ย. 2007 7:44 pm
โดย ECO
คืออยากรู้ว่า อาวุธที่ใช้และดีที่สุดของทาทาคือค้อน 2 มือใช้มั้ยงับ

ตามกระทู้ของblacksmith แต่ว่าส่วนใหญ่ชุดของทาทาจะ+vit-strอ่า

คือถ้าเล่นสายวิทก็ต้องค้อนมือเดียวแล้ว แล้ว ถือกระเป๋าอีกข้างใช่มั้ยงับ

แล้วถ้าไปถือค้อน2มือจะอัพเท่าไหร่ให้ตีไวๆเยยอ่าครับ

คือตอนนี้มีความลังเลว่าจะเล่นยังไงดี vit หรือ agi ดี

อยากถามว่าแบบไหนดีกับทาทาราเบ้มากกว่ากันอ่าครับ

สเตตัสผมตอนนี้น้า

str51+6
dex35+10
vit18+9

ถ้า สายเอจิถือค้อน 2 มือดีกว่าจาได้รีอ่าครับ

พอดีงบประมาณน้อย ขอคำแนะนำด้วยนะครับ :oops:
