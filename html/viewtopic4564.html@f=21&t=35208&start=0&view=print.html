1.ลอง save as เป็นไฟล์ Adobe PDF (*.PDF) หรือ illustrator (*.EPS) ถ้ายังไม่ได้อีกให้ลองsaveลด version ลง เป็นversion10 ดูนะ ถ้าไม่ได้อ่านข้อ2ต่อเลยเงี๊ยววว =^-.-^"=/
2.อาจจะต้องดูที่สเปคของเครื่องคอมว่า แรมมีเท่าไหร่แต่ถ้าแรมไม่พอมันจะขึ้นอีกอย่าง(บังเอิญว่ากลับมาใช้version10 เลยไม่รู้ว่าขึ้นerror เหมือนกันกับcsหรือเปล่า) ต่อมาให้ดูเนื้อที่ว่าง ของ hard disk drive ว่ามีเนื้อที่เหลืออยู่ อย่างดีๆก็สัก 1 Gb. ทั้ง drive ที่เป็น windows(drive c: ) และ drive อื่นๆด้วยที่เราจะsave เก็บตัวงานไว้
3.อาจจะมีปัญหาที่ตัว fileงานที่ทำอยู่มีปัญหาเอง
3.1 ให้ลองเปิดงานตัวอื่นแล้ว save as ดู
3.2 ให้กด ctrl+a ในหน้างานที่ทำอยู่เพื่อเป็นการเลือก select path ทั้งหมด แล้วกดctrl+c เพื่อ copy path ทั้งหมดที่ select ไว้ ต่อมาให้ ctrl+n เพื่อเปิดหน้างานใหม่แล้ว กด ctrl+f เพื่อ paste งานที่ copy ไว้ไปลงในจุดเดิม(จะแตกต่างกับ ctrl+v ที่ paste งานไปไว้ตรงกึ่งกลางของหน้าจอเราเอง) สังเกตุเห็นว่าจากในรูปมีการสร้าง layer ด้วย ให้ copy ทีละ layer แล้วลองกด save as ดู ว่าได้หรือไม่ได้ (วิธีนี้อาจเป็นการเชคทีละlayerได้ในตัวว่าlayerไหนที่มีไฟล์เสียหาย โดยการsave as เปลี่ยนชื่อไปเรื่อยๆแล้วเชคดู)
4.ถ้าไม่ได้อีกให้ลองหาตัวโปรแกรมใหม่ ลดversionลงเป็น version 10 แล้ว ลงpatch เป็น 10.0.2 จะใช้งานได้ดีมากๆ แต่ feture ใหม่ๆก็มีให้ใช้ลดลงไปตามลำดับ(ปัจจุบันนี้ทางสำนักพิมพ์ทั่วๆไปยังใช้ illustrator version 10 อยู่จ้า ) =^-.-^"=/
