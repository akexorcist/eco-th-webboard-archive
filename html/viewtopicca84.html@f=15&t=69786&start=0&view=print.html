สกิลนี้ มันมีหลักการใช้งานยังไงครับ ทำไมผมใช้ให้บางคน ติด บางคนขึ้น miss และ int ที่มันโอนให้ คือ int ตัวหน้า หรือ ตัวหลัง เหรอครับ

ง่ายๆครับ คุณโอนใส่ใคร คนนั้นจะมีintเท่ากับคุณ
แต่ถ้าคุณโอนใส่คนที่มีintมากกว่าคุณ มันจะโอนไมได้

เช่นสมมุติคุณมีntรวมหน้าหลัง70(50+20) คุณโอนใส่คนที่มีintรวมหน้าหลัง30(20+10) คนๆนั้นจะมีint70(20+50)เท่ากับคุณทันที
แต่ถ้าคุณโอนใส่คนที่มีint80 มันจะขึ้น miss เพราะเค้ามีมากกว่า
