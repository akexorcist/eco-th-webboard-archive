วี้--- มากระจายข่าวเน้... เป็นอีเว้นท์เล็กๆ ที่สุมหัวคุยกับท่านอ๊อฟอ่ะนะ

ย้อนกลับไป2-3หน้าละมั้ง(ทำไมต้องมี'มั้ง'?) ที่ท่านออฟชวนทำแฟนฟิค
ตอนนี้ คุยกันจนได้ข้อสรุปแล้วน้ะจ้ะ.. ว่าจะทำการ์ตูน4ช่องกัน

รูปแบบที่จะทำ.. ก็คงทำเป็นพวกฉากหลุดของแต่ละตอน ก็คือ ตัวละครที่ไม่มีบทในตอนนั้นๆ ไปทำอะไรอยู่ที่ไหนกัน
Example : ตอนที่มิกะกำลังคาราโอเกะ... เน่จังก็กำลังหม่ำไทยากิอยู่ที่ห้องวิทย์

และ เพื่อไม่ให้ชนกับนิยายของแรนจี้... 4ช่องที่จะทำกัน ก็จะเขียนถึงตอนที่ผ่านๆตั้งแต่3ตอนขึ้นไป นะจ้ะ
(สมมติว่า 4ช่องอิงถึงตอนที่ราฟาเอลกับAกำลังสู้กันอยู่ เน่จังที่ไม่มีบทก็กินไทยากิไปแบบไร้บท... ตัดกลับมาดูที่นิยาย แรนจี้ใส่บทให้เน่จังโผล่มาเตะราฟาเอลกระเด็น.. ชนกันพอดี อ้าว ซวย..)

ตอนนี้นิยายอยู่ที่ตอนที่8.. ดังนั้น 4ช่องที่จะทำกัน ก็ต้องอิงเหตุการณ์ในตอนที่1-5เท่านั้น(นับย้อนลงไป3ตอน) ห้ามเกินออกมาเด็ดขาด นะจ๊ะ นะจ๊ะ..

ตอนนี้ กำลังหาแนวร่วม.. ใครคิดว่าอยากทำ ก็เอาเลย ต้องการแนวร่วมอย่างด่วน XD

เดี๋ยวสักพัก ถ้าผม หรือท่านอ๊อฟ เขียน4ช่องเสร็จ... จะสร้างกระทู้ใหม่ขึ้นมา โดยใช้ชื่อใช้คล้องกับกระทู้นี้(เป็นกระทู้Subแตกย่อยออกไป อะไรทำนองนี้) ไว้เป็นที่แปะ4ช่อง
.. อ้อ แต่ถ้าใครไฟแรงเกิ๊น อยากเขียนโด ก็เอาเลย แปะในกระทู้4ช่องได้เลยฮะ สนับสนุน XD
(ตอนแรก ว่าจะเขียนโด.. โว้ว ไม่ไหว ตีช่อง เส้นสปีด แอคชั่น วาดกันลากเลือดแน่ OTL)

** สรุป Concept..

การ์ตูน4ช่อง ► ฉากหลุด ► ใครอยากใส่ก็เอาเลย (ไม่มีข้อผูกมัดว่าจะต้องอยู่กับ4ช่องไปจนวันตายหรืออะไรทั้งสิ้น รับหมดทั้งขาจำขาจร) ► เดี๋ยวจะแยกกระทู้ แต่ตั้งชื่อให้คล้องกัน ► ใครอยากแปะโด ก็แปะในนั้นได้เลยฮะ
