ตามความเห็นผม

shaman ไม่ได้ด้อยเรื่อง support เลยนะ (เผลอๆ ดีกว่า wizard ด้วยซ้ำ)

ที่คนส่วนใหญ่มองเห็นแค่ reflection , divine barrier , int rise แล้วรู้สึกว่ามันดีกว่าอาชีพอื่นๆ
หรือเห็นว่า shaman มี zen โดยกำเนิดไม่ต้องให้ใครมาสิง เลยคิดว่าเวทย์มันแรงสุด
ทั้งหมดนี้ ผมว่ามันเป็นแค่ภาพลวงตา


ผมเล่น wizard อย่างเดียว ไม่เคยเล่น shaman นะ แต่ผมไม่อาจเข้าข้าง wiz ว่าเก่งกว่าหรือดีกว่าได้เลย
ยังไง ทั้ง2อาชีพนี้ก็มีส่วนสำคัญตลอดในการ NvN ครับ

ระดับความน่าสนใจ ผมให้เท่าๆกันทั้ง 2 อาชีพครับ สำหรับคนที่รักเวทย์มนตร์


เพิ่มเติมครับ ...
หลายคนบอก wizard ต้องการ step มาก พลิกแพลงเยอะ ถ้าไม่คล่องไม่ควรเล่น
แนวคิดนี้ผมไม่เห็นด้วยเท่าไหร่นะ ... ไม่ว่า shaman, wizard หรือ warlock ก็สามารถพลิกแพลงได้ทั้งนั้น
สิ่งที่ตัดสินใจในการเลือกเล่นของผม มีแค่ความชอบส่วนตัวครับ

hint...
-ชอบธาตุต่างๆ
-ชอบเวทย์มนตร์ดำ
-ชอบเวทย์ไม่มีธาตุ (จะเรียกว่าเวทย์พลังจิต หรืออะไรก็ได้ครับ)
