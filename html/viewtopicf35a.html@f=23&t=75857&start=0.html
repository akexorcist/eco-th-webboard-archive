Item Drop [ไอเท็ม]
[สีดำ] = แม้มีสกิล Knowledge ก็ไม่ดรอปง่ายขึ้นครับ
[สีเทา] = เป็นไอเทมที่มีดรอปตามปกติ แต่ถ้ามีสกิลพวก Knowledge จะดรอปง่ายและบ่อยขึ้น
[สีแดง] = ไอเท็มบังคับ ต้องมี สกิล Knowledge ถึงจะดรอป แต่ถึงจะดรอป อัตราการดรอปก็ไม่ได้เพิ่มขึ้น บางอันหล่นยากง่ายไม่เหมือนกัน
[สีน้ำเงิน] = Rare Item ถึงจะมีสกิลพวก Knowledge ก็ไม่ดรอป ง่ายขึ้น
[PT] = เป็นไอเทมที่จะดรอปให้กับสมาชิกทุกคนใน Party คนละ 1 ชิ้น

Personality [ลักษณะ]
NonActive คือจะไม่ทำอะไรเราก่อน
Active คือ เป็นนักเลงหาเรื่องเราตลอด
DetectSkill คือ ถ้าเราใช้สกิลที่มีระยะเวลาร่ายอยู่ในรัศมี มันก็จะมาตบเรา
Link คือมันจะเชื่อมไปถึงสิ่งที่ผมพิมไว้
อย่างเช่น Link GeckoType ก็คือ ถ้ามันเห็นมอนประเภทGeckoถูกเราโจมตี มันก็จะมาช่วยพวกGeckoตีเรา
ChainReAction ก็คือ หมาหมู่หรือรุมน่อ


Time of birth คือ ถึงเวลเกิดของบอสนั้นๆ
Skill คือ ท่าความสามารถ ความชำนาญที่ใช้โจมตีใส่เราให้แรงขึ้นหรือเพิ่มความสามารถให้กับ boss
Summonคือการเรียก ลูกน้องออกมา
Otherคือ สิ่งที่ไม่ได้เขียนไว้ในข้อมูลดังกล่าว จมาเขียนตรงนี้แทนถ้าเกิดมีข้อมูลเพิ่มเติม
