WhiteRose เขียน:แล้วใช้นาฬิกาทรายเท่าไหร่ครับที่ job lv. 50


เราจะใช้นาฬิกาทรายในกรณีที่ เราจะต้องการกลับไปสู่ class อีกอันที่เราเคยเก็บจ๊อบไว้แล้ว ดังนั้น ที่ว่า job 50 นี่ ก็จะต้องหมายความว่า เราเคยเก็บจ๊อบให้กับอีก class ไว้แล้ว 50เลเวล ถ้าในกรณีนี้ หากเราเปลี่ยนกลับไป class เก่า(ที่มีจ๊อบ50) โดย...
1.ไม่ใช้นาฬิกาทราย เราจะถูกปรับ โดยค่าปรับคือ JobLv. ครับ วิธีคิดคือ เอา JobLv. ของ class ที่เราต้องการเปลี่ยน (ไม่ใช่จ๊อบของ class ปัจจุบันนะ) มาหาร 5 ดังนั้น จะถูกปรับลด JobLv. เป็นจำนวน 50/5=10 --> สรุป ถ้าไม่ได้ใช้นาฬิกาทราย จะเหลือจ๊อบที่เคยเก็บไว้ 50 เป็น 40 ทันที เพราะว่าถูกปรับไป 10
2. ใช้นาฬิกาทราย จะคิดจำนวนที่ใช้คือ 1เรือน:1JobLv.ที่จะต้องเสียไป ถ้าหากเราไม่ใช้ จะเสียไป 10job ดังนั้น ถ้าเรามีจ๊อบของอีกclass เป็น 50 จะต้องใช้นาฬิกาทราย เป็นจำนวนทั้งหมด 10 เรือนครับ
