โดย ECO
รู้สึกว่า คำถามนี้มันบ่อยน่าดูเลยนะเนี่ย

ถ้าไม่ซื้อของปั้มก็ลุยยากครับ ยกเว้นว่าเล่นพระ เพราะมีสกิลเร่งตอนจ๊อบ 2 (regen MP +Sp เองได้+ ฮีลตัวเองได้) แต่พระก็มีข้อเสียคือ สกิลตีส่วนใหญ่มีไว้ตี undead แล้วมอนส่วนใหญ่ในเกมมันไม่ใช่อันเดต แถมยังยิงเป็นธาตุแสงซึ่งแพ้ทุกธาตุยกเว้นธาตุมืดอีกต่างหาก ถ้าจะเล่นพระจริงๆ ก็ต้องแชร์ครับ แต่ เลือกคนแชร์ที่แบ่งของด้วยนะ ไม่งั้นถังแตกแน่ๆ ไม่มีเงินหมุน

พอตอนหลังๆมอนธาตุมืดจะมีเยอะขึ้นทำให้พระเล่นสบายขึ้นครับเพราะมันแพ้ทางเราเต็มๆ

warlock จะเป็นพวกที่่ต้องเล่น 1 shot ครับ (1 ทีตาย) เพราะถ้ามันไม่ตายคนที่จะตายก็คือเรา (ยกเว้นว่ามันวิ่งช้ามาก + ไม่ใช่พวกเวทย์หรือตีไกล) ข้อดีคือยิงได้เกือบทุกอย่าง แทบทุกตัวแพ้ทางเวทวอลอคหมด(เพราะยิงเป็นธาตุมืด) ยกเว้น ธาตุมืิดกับแสงครับ ที่เจอแล้วแทบจะยิงไม่เข้า แถมพวกนี้เจอตอน late game อีกต่างหาก ทำให้ตอนหลังๆ ก็ไปไหนคนเดียวยากครับ + ไม่มีรีเจนเอมพี + เลือดด้วย ถ้าไม่พกของฟื้นพลังคงนั่งกันเยอะแหละ

ชาแมน เหมือนวอล๊อค แค่ชุดมันน่ารักมากๆ และยิงเป็นธาตุทั้ง 4 ซึ่งแดเมจจะแรงกว่าธาตุมืดของวอล๊อคมากๆๆ ถ้าใช้ถูกวิธี (ใช้กับตัวที่แพ้ธาตุนั้นๆ) + มีเวทเบิ้ลเอมพีเพื่อพลังโจมตีเวทคูณ 2 ด้วย ทำให้ยิงแรงที่สุดในเกมไปเลย (ในสายเวทนะ)

ข้อเสียคือตัวนิ่มมากๆ (ยกเว้่นคุณเล่นสาย Vit จริงๆนักเวทมันก็นิ่มทุกตัวแหละยกเว้นพระ) ต้องอาศัยไว ยิงให้ตายก่อนเราจะตายแทนเท่านั้น ท่าเบิ้ลเอมพีทำให้ยิงแรงก็จริง แต่เอมพีเราก็หมดไวขึ้นเช่นกัน รีเจนเอมพี+เลือดไม่ได้ทำให้ต้องนั่งบ่อยเช่นเดียวกับวอล๊อค

สุดท้ายก็วิซาร์ด สายนี้ต้องเรียกว่า นักเวทสายป่วนประสาท+สนับสนุนการรบครับ เพราะเวทส่วนใหญ่มีไว้ก่อกวน+ช่วยเพื่อนโดยเฉพาะ และข้อดีอีกอันคือสายนี้เวทยิงไม่มีธาตุทำให้ยิงได้ทุกตัวในเกมโดยไม่ต้องกังวลเรื่องธาตุ

ตอนหลังๆจะมีสกิลโซลิดออร่าที่ทำให้ศัตรูโจมตีกายภาพใส่เราเข้า 0 แดเมจ ทำให้ลุยสบายพอควรตราบเท่าที่ไม่เจอมอนใช้เวทย์ ใส่ท่านี้เข้าไปเราก็แทบอมตะแล้ว

ข้อเสียคือยิงเบาที่สุดใน 4 สาย เวทโจมตีที่น้อยมาก + ตัวนิ่มครับ

จะเลือกตัวไหนก็เลือกเอาละกัน
