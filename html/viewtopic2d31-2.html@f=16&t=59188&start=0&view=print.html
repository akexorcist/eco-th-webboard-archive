NPC Item Maker
เปิดกล่องสมบัติ = Unlock
Purify Item ให้หน่อย = Item Refine
ผสมยาให้หน่อย = Drug Create (Alchemist)
ประกอบไม้ให้หน่อย = Wood Create (Farmer)

NPC Forge Shop Worker
ให้ทำอาวุธ = Weapon Create,Staff Create (Blacksmith)
ให้ทำเครื่องมือป้องกัน = Protection Create (Blacksmith)
ให้ทำเล็กให้บริสุทธิ์ = Highly Refine (Tatarabe)
ให้ทำ Arrow = Throw Create (Archer)

NPC Junk Shop's Worker
สั่งประกอบเครื่องจักร = Machine Create (Machinery)

NPC Sewing Aunt
สั่งงานตัดเย็บ = Sewing Create (Farmer)

NPC Marionest Master
Golem สำเร็จ = Marionette Create (Marionest)
หุ่นมอนสเตอสำเร็จ = Create Figure (Marionest)

NPC Aunt of Restaurant
ขออาหาร = Cooking (Farmer)

NPC Adjudicater
วินิจฉัยของ = Scholar Art

เข้าใจถูกหรือเล่าครับ แล้วยังมีอะไรอีกหรือเปล่า
